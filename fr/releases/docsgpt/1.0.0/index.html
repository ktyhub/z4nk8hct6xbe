DocsGPT 1.0.0

Highlights

  • CLI & dev-loop tooling — docsgpt up --native (#2800) joins new dev, doctor, and restart commands (#2803) plus first-class backup/restore (#2799), turning local operation and upgrade/rollback into a repeatable workflow instead of ad-hoc Docker wrangling. For self-hosters this is the biggest operational change in the release: run doctor on an existing install first, and take a backup before upgrading — both are now scriptable.

  • Scoped tokens & quotas — Personal access tokens (#2812) give CI/CD and CLI clients scoped credentials rather than reusing a user session, while admin-set per-user and per-team usage quotas (#2816) let operators cap spend. Together these are the primitives for safe programmatic access; adopt PATs for automations and set quotas before opening API access broadly.

  • LLM observability — GenAI OpenTelemetry spans with a trace waterfall in Logs (#2825), a data-plane activity/audit feed with spend and latency (#2822), and token counts on source chunks (#2823) make cost and latency attributable per request. Watch the usage fix in #2876: streamed replies are now tokenized once instead of per chunk, so any dashboards or alerts calibrated on inflated per-chunk counts may need re-baselining.

  • Retrieval & ingestion behavior — Default retrieval jumps from 2 to 6 chunks (#2841), so expect fuller answers at higher token cost; DeepSeek-OCR is now native-only behind an ocr-check guard (#2868), dropping hosted-OCR paths. GraphRAG retrieval/extraction also finally works in a default install (#2804) — if you had added custom config to make it function, simplify it.

  • Agents, connectors & background work — Connectors consolidate account linking for Sources and Tools (#2843), with new MCP presets (ClickUp #2921, Zapier #2931, Trello #2929, Miro), while the code sandbox is rebuilt from a single manifest with persistent state and office/browser/OCR tools (#2963, #2964, #2968, #2971). Background jobs with auto-resume, notifications and monitors (#2972) make long-running agent work durable; note that tool-returned images are now fed to vision models inside tool results (#2920).

  • Security & robustness — The model registry is loaded once under a lock and can no longer leak a key to a different provider's endpoint (#2989), five frontend crash classes (invalid locale, page translation, stale chunks) are fixed (#2988), and PostgreSQL URIs normalize case-insensitively (#3004). Also fixed: promptable share links failing every follow-up due to NULL agents.agent_type (#3006) — prioritize upgrading if you expose multi-provider keys or shared links.

No breaking changes were explicitly flagged in this release.
