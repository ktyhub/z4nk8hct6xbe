daily_stock_analysis v3.7.0

Nouvelles fonctionnalités

  • 💼 Gestion de positions P0 entièrement fonctionnelle en ligne (#677, correspondant au Issue #627)
    • Grand livre de base et boucle fermée d'instantanés : ajoutez de nouveaux comptes, transactions, flux de trésorerie, comportement d'entreprise, cache de position, instantanés quotidiens et autres modèles de données de base et points de terminaison API ; prend en charge la lecture de la méthode à double coût FIFO/AVG ; l'ordre des événements d'un même jour est fixé à 现金 → 企业行为 → 交易 ; L'écriture d'instantanés de position utilise des transactions atomiques.
    • Import CSV de courtier : prend en charge le premier lot d'adaptations par Huatai/CITIC/China Merchants, y compris la compatibilité des alias de liste ; interface en deux étapes (aperçu d'analyse + soumission de confirmation) ; Priorité trade_uid, déduplication idempotente du hachage du champ clé ; Les principaux codes de stock zéro sont entièrement conservés.
    • Rapport sur les risques du portefeuille : risque de concentration (meilleures positions + calibre du secteur des actions A), surveillance des retracements historiques (prend en charge le remplissage des instantanés manquants), avertissement d'approche stop loss ; conversion unifiée de plusieurs devises au calibre CNY ; lorsque l’extraction échoue, retour au taux de change réussi le plus récent et à la marque obsolète.
    • Page Web de position (/portfolio) : aperçu du portefeuille, détails de la position, diagramme circulaire de concentration, résumé des risques, changement de portefeuille complet/compte unique ; saisie manuelle des transactions/flux de capitaux/comportement des entreprises ; entrée de création de compte intégrée ; Analyse CSV + soumission en boucle fermée et sélecteur de courtage.
    • Agent Position Tool : ajout de l'outil de données get_portfolio_snapshot, résumé compact par défaut, détails de position facultatifs et données de risque.
    • Requête d'événement API : Ajout de GET /portfolio/trades, GET /portfolio/cash-ledger, GET /portfolio/corporate-actions, prenant en charge le filtrage des dates et la pagination.
    • Extensible Parser Registry : enregistrement partagé au niveau de l'application, prend en charge l'enregistrement à l'exécution de nouveaux courtiers ; Interface de découverte GET /portfolio/imports/csv/brokers nouvellement ajoutée.
  • 🎨 Système de conception front-end et bibliothèque de composants atomiques (#662)
    • Introduction d'une architecture progressive à double thème (jeton de conception variable HSL), nettoyant le CSS historique Legacy ; refactorisation de plus de 20 composants principaux tels que Bouton / Carte / Badge / Pliable / Entrée / Sélection, etc. ; ajout des outils de fusion de noms de classe clsx + tailwind-merge ; améliorer la lisibilité de l'historique, de la configuration LLM et d'autres pages.
  • ⚡ Analyse du contrat asynchrone API et optimisation du démarrage (#656)
    • Standardiser le contrat de retour de la demande asynchrone POST /api/v1/analysis/analyze ; optimiser la logique auxiliaire de démarrage du service ; résoudre le problème d’alignement entre la définition conjointe du type de rapport frontal et la réponse back-end.

Correction

  • 🔔 Compatibilité ascendante des variables d'environnement Discord (#659) : Ajout de la lecture de secours de DISCORD_CHANNEL_ID → DISCORD_MAIN_CHANNEL_ID pendant l'exécution ; les utilisateurs de la configuration historique peuvent restaurer les notifications de Discord Bot sans modification ; tous les documents associés sont alignés sur .env.example.
  • 🔧 Mise à niveau du nœud 24 des actions GitHub (#665) : mettez à niveau toutes les actions officielles du GitHub vers les versions compatibles avec le nœud 24, en éliminant l'avertissement de dépréciation du Node.js 20 dans le journal CI (affecte la fenêtre de mise à niveau forcée du 02/06/2026).
  • 📅 Localisation de la date par défaut sur la page de position : La date par défaut dans le formulaire de saisie manuelle est changée en heure locale (getFullYear/Month/Date) pour résoudre le problème de décalage de date pour les utilisateurs du fuseau horaire UTC-N le soir du même jour.
  • 🔁 Renforcement de la logique de déduplication d'importation CSV : le hachage de déduplication intègre le numéro de série de la ligne comme facteur distinctif pour garantir que les transactions légales distinctes dans le même champ ne sont pas mal repliées ; dans le même temps, le hachage est également conservé lorsque trade_uid existe pour empêcher l'écriture répétée à partir de sources mixtes.

Changement

  • POST /api/v1/portfolio/trades renvoie 409 lorsque trade_uid est en conflit au sein du même compte.
  • Un nouveau champ sector_concentration est ajouté à la réponse au risque de position (expansion incrémentale), et le champ concentration d'origine reste inchangé.
  • Analyser la documentation du contrat de comportement asynchrone de l'interface API analyze ; mise à jour conjointe de type rapport frontal. ###Tester
  • Ajout de nouveaux tests de service de base de position (vente partielle FIFO/AVG, séquence d'événements le même jour, retour trade_uid répété 409, instantané du contrat API).
  • Ajout de l'idempotence de l'importation CSV, de la déduplication légale des transactions fractionnées, de la limite de déduplication, de la limite du seuil de risque et des tests de comportement de dégradation du taux de change.
  • Ajout du test d'appel de l'outil Agent get_portfolio_snapshot.
  • Ajout de l'analyse du test de régression de contrat asynchrone API.

daily_stock_analysis v3.7.0

新功能

  • 💼 持仓管理 P0 全功能上线（#677，对应 Issue #627）

    • 核心账本与快照闭环：新增账户、交易、现金流水、企业行为、持仓缓存、每日快照等核心数据模型与 API 端点；支持 FIFO / AVG 双成本法回放；同日事件顺序固定为 现金 → 企业行为 → 交易；持仓快照写入采用原子事务。
    • 券商 CSV 导入：支持华泰 / 中信 / 招商首批适配，含列名别名兼容；两阶段接口（解析预览 + 确认提交）；trade_uid 优先、key-field hash 兜底的幂等去重；前导零股票代码完整保留。
    • 组合风险报告：集中度风险（Top Positions + A 股板块口径）、历史回撤监控（支持回填缺失快照）、止损接近预警；多币种统一换算 CNY 口径；汲取失败时回退最近成功汇率并标记 stale。
    • Web 持仓页（/portfolio）：组合总览、持仓明细、集中度饼图、风险摘要、全组合 / 单账户切换；手工录入交易 / 资金流水 / 企业行为；内嵌账户创建入口；CSV 解析 + 提交闭环与券商选择器。
    • Agent 持仓工具：新增 get_portfolio_snapshot 数据工具，默认紧凑摘要，可选持仓明细与风险数据。
    • 事件查询 API：新增 GET /portfolio/trades、GET /portfolio/cash-ledger、GET /portfolio/corporate-actions，支持日期过滤与分页。
    • 可扩展 Parser Registry：应用级共享注册，支持运行时注册新券商；新增 GET /portfolio/imports/csv/brokers 发现接口。

  • 🎨 前端设计系统与原子组件库（#662）

    • 引入渐进式双主题架构（HSL 变量化设计令牌），清理历史 Legacy CSS；重构 Button / Card / Badge / Collapsible / Input / Select 等 20+ 核心组件；新增 clsx + tailwind-merge 类名合并工具；提升历史记录、LLM 配置等页面可读性。

  • ⚡ 分析 API 异步契约与启动优化（#656）

    • 规范 POST /api/v1/analysis/analyze 异步请求的返回契约；优化服务启动辅助逻辑；修复前端报告类型联合定义与后端响应对齐问题。

修复

  • 🔔 Discord 环境变量向后兼容（#659）：运行时新增 DISCORD_CHANNEL_ID → DISCORD_MAIN_CHANNEL_ID 的 fallback 读取；历史配置用户无需修改即可恢复 Discord Bot 通知；全部相关文档与 .env.example 对齐。
  • 🔧 GitHub Actions Node 24 升级（#665）：将所有 GitHub 官方 actions 升级至 Node 24 兼容版本，消除 CI 日志中的 Node.js 20 deprecation warning（影响 2026-06-02 强制升级窗口）。
  • 📅 持仓页默认日期本地化：手工录入表单默认日期改用本地时间（getFullYear/Month/Date），修复 UTC-N 时区用户在当天晚间出现日期偏移的问题。
  • 🔁 CSV 导入去重逻辑加固：dedup hash 纳入行序号作为区分因子，确保同字段合法分笔成交不被误折叠；同时在 trade_uid 存在时也持久化 hash，防止混合来源重复写入。

变更

  • POST /api/v1/portfolio/trades 在同账户内 trade_uid 冲突时返回 409。
  • 持仓风险响应新增 sector_concentration 字段（增量扩展），原有 concentration 字段保持不变。
  • 分析 API analyze 接口异步行为契约文档化；前端报告类型联合更新。

测试

  • 新增持仓核心服务测试（FIFO / AVG 部分卖出、同日事件顺序、重复 trade_uid 返回 409、快照 API 契约）。
  • 新增 CSV 导入幂等性、合法分笔成交不误去重、去重边界、风险阈值边界、汇率降级行为测试。
  • 新增 Agent get_portfolio_snapshot 工具调用测试。
  • 新增分析 API 异步契约回归测试。
