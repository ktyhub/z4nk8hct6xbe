Vibe-Trading v0.1.9

pip install -U vibe-trading-ai · 36 outils MCP · 77 compétences · 29 préréglages d'essaim Une version roll-up couvrant tout depuis 0.1.8.

Faits saillants

  • Profils de courtier axés sur le connecteur (IBKR + Robinhood). L'accès au trading commence à partir d'un profil de connecteur sélectionnable au lieu de points d'entrée de courtier/en direct séparés ; vibe-trading connector list/use/check/account/positions/orders/quote/history et les outils MCP trading_* partagent le profil sélectionné, avec paper/live comme attribut du connecteur. IBKR est utilisable immédiatement en tant que profil TWS/IB Gateway local en lecture seule ; le chemin MCP distant officiel d'IBKR est généré en tant que sonde OAuth mcp.read jusqu'à ce que les noms d'outils de lecture stables soient expédiés. Robinhood Agentic Trading est un connecteur limité derrière OAuth, un mandat engagé, un garde d'ordres, un grand livre d'audit et un commutateur d'arrêt instantané.
  • Exécution des objectifs de recherche. Objectifs de longue durée réservés à la recherche avec des critères de liste de contrôle vérifiables, des budgets et une commande /goal CLI, ainsi que des points de terminaison REST + MCP et un Web GoalDrawer.
  • Swarm pass. Réconciliation en direct + MCP keepalive (#132), outils MCP externes configurés par l'opérateur dans les travailleurs (#142), contrôle DAG en cas d'échec d'une tâche en amont (#145), contrôle aléatoire strict du banc alpha (#143) et un nouveau retry_run pour relancer les exécutions ayant échoué/périmées — 36 outils MCP maintenant.
  • Refactor de package CLI (agent/cli/) avec une interface utilisateur de terminal actualisée, plus un chargeur de partage A sans jeton mootdx et une prise en charge de proxy-env CCXT.

Correctifs

  • --version ne dérive plus (#156) — dérive des métadonnées du package, retombant sur pyproject.toml ; il ne reste plus aucune constante codée en dur à oublier lors de la sortie.
  • Réussite de robustesse : validation avant vol pour les moteurs de signaux générés par LLM (#149), sortie gracieuse de la boucle d'agent au budget d'itération (#148), écritures de session flush + fsync qui ignorent JSONL corrompu en lecture (#147) et gestion de la saisie IME dans le compositeur Web (#146).
  • L'indicateur d'état de fonctionnement de la session survit à la reconnexion/rechargement/navigation dans la barre latérale ; liens vers le rapport complet multi-navigateurs (#150) ; délai d'inactivité SSE configurable via VIBE_TRADING_SSE_TIMEOUT (#157) ; Alignement des horodatages de corrélation entre marchés (#158).

Vibe-Trading v0.1.9

pip install -U vibe-trading-ai · 36 MCP tools · 77 skills · 29 swarm presets

A roll-up release covering everything since 0.1.8.

Highlights

  • Connector-first broker profiles (IBKR + Robinhood). Trading access starts from a selectable connector profile instead of separate broker/live entry points; vibe-trading connector list/use/check/account/positions/orders/quote/history and the MCP trading_* tools share the selected profile, with paper/live as an attribute of the connector. IBKR is usable immediately as a local read-only TWS / IB Gateway profile; the official IBKR remote MCP path is seeded as an OAuth mcp.read probe until stable read tool names ship. Robinhood Agentic Trading is a bounded connector behind OAuth, a committed mandate, an order guard, an audit ledger, and an instant halt switch.
  • Research Goal runtime. Long-running, research-only goals with auditable checklist criteria, budgets, and a /goal CLI command, plus REST + MCP endpoints and a Web GoalDrawer.
  • Swarm pass. Live reconcile + MCP keepalive (#132), operator-configured external MCP tools in workers (#142), DAG gating when an upstream task fails (#145), a strict alpha-bench random control (#143), and a new retry_run to relaunch failed/stale runs — 36 MCP tools now.
  • CLI package refactor (agent/cli/) with a refreshed terminal UI, plus a mootdx no-token A-share loader and CCXT proxy-env support.

Fixes

  • --version no longer drifts (#156) — derives from package metadata, falling back to pyproject.toml; no hardcoded constant left to forget on release.
  • Robustness pass: pre-flight validation for LLM-generated signal engines (#149), graceful agent-loop exit at the iteration budget (#148), flush + fsync session writes that skip corrupted JSONL on read (#147), and IME Enter handling in the Web composer (#146).
  • Session running-status indicator survives reconnect / reload / sidebar nav; cross-browser Full Report links (#150); configurable SSE idle timeout via VIBE_TRADING_SSE_TIMEOUT (#157); cross-market correlation timestamp alignment (#158).
