diffuseurs v0.36.0

La version comprend un certain nombre de nouveaux pipelines d'images et de vidéos, une nouvelle méthode de mise en cache, un nouveau script de formation, de nouveaux backends d'attention alimentés par kernels, et bien plus encore. Il regorge de nombreuses nouveautés, alors assurez-vous de lire entièrement les release note 🚀

Nouveaux pipelines d'images

  • Flux2 : Flux2 est la dernière génération de modèle de génération et d'édition d'images de Black Forest Labs. Il est capable de prendre plusieurs images d’entrée comme référence, ce qui le rend polyvalent pour différents cas d’utilisation. -Z-Image : Z-Image est le meilleur modèle de génération d'images en son genre dans le régime de paramètres 6B. Merci à @JerryWu-code dans https://github.com/huggingface/diffusers/pull/12703.
  • QwenImage Edit Plus : Il s'agit d'une mise à niveau de QwenImage Edit et est capable de prendre plusieurs images d'entrée comme références. Il peut servir à la fois de modèle de génération et d’édition. Merci à @naykun pour sa contribution à https://github.com/huggingface/diffusers/issues/12357.
  • Bria FIBO : FIBO est formé sur les sous-titres structurés JSON allant jusqu'à 1 000 mots et conçu pour comprendre et contrôler différents paramètres visuels tels que l'éclairage, la composition, la couleur et les paramètres de la caméra, permettant des sorties précises et reproductibles. Merci à @galbria pour cette contribution dans https://github.com/huggingface/diffusers/pull/12545.
  • Kandinsky Image Lite : Kandinsky 5.0 Image Lite est un modèle de génération d'images léger (paramètres 6B). Merci à @leffff pour cette contribution dans https://github.com/huggingface/diffusers/pull/12664.
  • ChronoEdit : ChronoEdit recadre l'édition d'images en tant que tâche de génération vidéo, en utilisant les images d'entrée et éditées comme images de début/fin pour exploiter des modèles vidéo pré-entraînés avec une cohérence temporelle. Une étape de raisonnement temporel introduit des jetons de raisonnement pour garantir des modifications physiquement plausibles et visualiser la trajectoire d'édition. Merci à @zhangjiewu pour cette contribution dans https://github.com/huggingface/diffusers/pull/12593.

Nouveaux pipelines vidéo

  • Sana-Video : Sana-Video est un modèle de génération vidéo rapide et efficace, équipé pour gérer de longues séquences vidéo, grâce à son incorporation d'attention linéaire. Merci à @lawrence-cj pour cette contribution dans https://github.com/huggingface/diffusers/pull/12634.
  • Kandinsky 5 : Kandinsky 5.0 T2V Lite est un modèle de génération vidéo léger (paramètres 2B) qui se classe n°1 parmi les modèles open source de sa catégorie. Il surpasse les modèles plus grands et offre la meilleure compréhension des concepts russes dans l'écosystème open source. Merci à @leffff pour cette contribution dans https://github.com/huggingface/diffusers/pull/12478.
  • Hunyuan 1.5 : HunyuanVideo-1.5 est un modèle de génération vidéo léger mais puissant qui atteint une qualité visuelle et une cohérence de mouvement de pointe avec seulement 8.3 milliards de paramètres, permettant une inférence efficace sur les GPU grand public.
  • Wan Animate : Wan-Animate est un modèle vidéo d'animation et de remplacement de personnages de pointe basé sur Wan2.1. Étant donné une image de personnage de référence et une vidéo de conduite, il peut soit animer le personnage avec le mouvement de la vidéo de conduite, soit remplacer le personnage existant dans cette vidéo par ce personnage.

Nouveaux backends d'attention alimentés par kernels

La [bibliothèque] kernels (https://github.com/huggingface/kernels) vous permet de gagner beaucoup de temps en fournissant des interfaces de noyau prédéfinies pour divers environnements et accélérateurs. Cette version comprend trois nouveaux backends d'attention alimentés par kernels :

  • Flash Attention 3 (+ sa variante varlen)
  • Flash Attention 2 (+ sa variante varlen)
  • SAUGE Cela signifie que si l'un des backends ci-dessus est pris en charge par votre environnement de développement, vous devriez pouvoir ignorer le processus manuel de construction des noyaux correspondants et utiliser simplement :
# Make sure you have `kernels` installed: `pip install kernels`.
# You can choose `flash_hub` or `sage_hub`, too.
pipe.transformer.set_attention_backend("_flash_3_hub")

Pour plus de détails, consultez la documentation.

Cache TaylorSeer

TaylorSeer est désormais pris en charge dans les diffuseurs, offrant des accélérations jusqu'à 3x avec un compromis de qualité négligeable, voire nul. Merci à @toilaluan pour cette contribution dans https://github.com/huggingface/diffusers/pull/12648. Consultez la documentation ici.

Nouveau script de formation

Notre intégration Flux.2 comprend un script de réglage fin LoRA que vous pouvez consulter [ici] (https://github.com/huggingface/diffusers/blob/main/examples/dreambooth/README_flux2.md). Nous proposons un certain nombre d'optimisations pour l'aider à fonctionner sur des GPU grand public.

Divers

  • Réutilisation de AttentionMixin : créer une sous-classe de certains modèles compatibles de la classe AttentionMixin nous a aidé à nous débarrasser de la LoC 2K. À l’avenir, les utilisateurs peuvent s’attendre à davantage de refactorisations de ce type qui contribueront à rendre la bibliothèque plus légère et plus simple. Consultez https://github.com/huggingface/diffusers/pull/12463 pour plus de détails.
  • Backend des diffuseurs en SGLang : https://github.com/sgl-project/sglang/pull/14112.
  • Nous avons lancé le [programme Diffusers MVP] (https://github.com/huggingface/diffusers/issues/12635) pour travailler avec des membres talentueux de la communauté qui nous aideront à améliorer la bibliothèque sur plusieurs fronts. Consultez le lien pour plus d’informations.

diffusers v0.36.0

The release features a number of new image and video pipelines, a new caching method, a new training script, new kernels - powered attention backends, and more. It is quite packed with a lot of new stuff, so make sure you read the release notes fully 🚀

New image pipelines

  • Flux2: Flux2 is the latest generation of image generation and editing model from Black Forest Labs. It’s capable of taking multiple input images as reference, making it versatile for different use cases.
  • Z-Image: Z-Image is a best-of-its-kind image generation model in the 6B param regime. Thanks to @JerryWu-code in https://github.com/huggingface/diffusers/pull/12703.
  • QwenImage Edit Plus: It’s an upgrade of QwenImage Edit and is capable of taking multiple input images as references. It can act as both a generation and an editing model. Thanks to @naykun for contributing in https://github.com/huggingface/diffusers/issues/12357.
  • Bria FIBO: FIBO is trained on structured JSON captions up to 1,000+ words and designed to understand and control different visual parameters such as lighting, composition, color, and camera settings, enabling precise and reproducible outputs. Thanks to @galbria for contributing this in https://github.com/huggingface/diffusers/pull/12545.
  • Kandinsky Image Lite: Kandinsky 5.0 Image Lite is a lightweight image generation model (6B parameters). Thanks to @leffff for contributing this in https://github.com/huggingface/diffusers/pull/12664.
  • ChronoEdit: ChronoEdit reframes image editing as a video generation task, using input and edited images as start/end frames to leverage pretrained video models with temporal consistency. A temporal reasoning stage introduces reasoning tokens to ensure physically plausible edits and visualize the editing trajectory. Thanks to @zhangjiewu for contributing this in https://github.com/huggingface/diffusers/pull/12593.

New video pipelines

  • Sana-Video: Sana-Video is a fast and efficient video generation model, equipped to handle long video sequences, thanks to its incorporation of linear attention. Thanks to @lawrence-cj for contributing this in https://github.com/huggingface/diffusers/pull/12634.
  • Kandinsky 5: Kandinsky 5.0 T2V Lite is a lightweight video generation model (2B parameters) that ranks #1 among open-source models in its class. It outperforms larger models and offers the best understanding of Russian concepts in the open-source ecosystem. Thanks to @leffff for contributing this in https://github.com/huggingface/diffusers/pull/12478.
  • Hunyuan 1.5: HunyuanVideo-1.5 is a lightweight yet powerful video generation model that achieves state-of-the-art visual quality and motion coherence with only 8.3 billion parameters, enabling efficient inference on consumer-grade GPUs.
  • Wan Animate: Wan-Animate is a state-of-the-art character animation and replacement video model based on Wan2.1. Given a reference character image and driving motion video, it can either animate the character with motion from the driving video, or replace the existing character in that video with that character.

New kernels-powered attention backends

The kernels library helps you save a lot of time by providing pre-built kernel interfaces for various environments and accelerators. This release features three new kernels-powered attention backends:

  • Flash Attention 3 (+ its varlen variant)
  • Flash Attention 2 (+ its varlen variant)
  • SAGE

This means if any of the above backend is supported by your development environment, you should be able to skip the manual process of building the corresponding kernels and just use:

# Make sure you have `kernels` installed: `pip install kernels`.
# You can choose `flash_hub` or `sage_hub`, too.
pipe.transformer.set_attention_backend("_flash_3_hub")

For more details, check out the documentation.

TaylorSeer cache

TaylorSeer is now supported in Diffusers, delivering upto 3x speedups with negligible-to-none quality compromise. Thanks to @toilaluan for contributing this in https://github.com/huggingface/diffusers/pull/12648. Check out the documentation here.

New training script

Our Flux.2 integration features a LoRA fine-tuning script that you can check out here. We provide a number of optimizations to help make it run on consumer GPUs.

Misc

  • Reusing AttentionMixin: Making certain compatible models subclass from the AttentionMixin class helped us get rid of 2K LoC. Going forward, users can expect more such refactorings that will help make the library leaner and simpler. Check out https://github.com/huggingface/diffusers/pull/12463 for more details.
  • Diffusers backend in SGLang: https://github.com/sgl-project/sglang/pull/14112.
  • We started the Diffusers MVP program to work with talented community members who will help us improve the library across multiple fronts. Check out the link for more information.
