Highlights

  • More provider paths — yuanbao-web adds cookie-only Yuanbao access (hy_user/hy_token) with SSE-to-OpenAI translation, including reasoning_content, for DeepSeek V3/R1 and Hunyuan models (#6196). Requesty adds an OpenAI-compatible BYOK gateway at https://router.requesty.ai/v1 (#6120). Agentrouter now receives Claude-Code wire-image headers and fingerprinting without losing its own baseUrl or x-api-key authentication (#6056); live WAF acceptance still requires VPS validation.
  • Session stickiness becomes optional — Round-robin and random combos can now rotate connections per request instead of pinning conversations by their first-message hash (#6168). Precedence is per-combo config.disableSessionStickiness → global settings.disableSessionStickiness → default false. Defaults preserve existing behavior, but disabling stickiness may reduce prompt-cache locality protected by the earlier #3825 fix.
  • Cloudflare Workers AI bulk imports are account-safe — #6174 adds a name|accountId|apiKey format and builds providerSpecificData per entry, fixing shared-object reuse that could associate multiple keys with the wrong account. Use the three-field form for multi-account imports.
  • Streaming semantics are tightened — Combo failover now triggers only for truly zero-byte bodies, preserving pass-through behavior for [DONE]-terminated empty streams and incomplete Claude lifecycles; #6216 also addresses locked-stream 500s and Gemini content-filter failover. Zero-width characters are stripped from tool-call argument strings, preventing invisible command/path corruption without reparsing or otherwise altering JSON.
  • Deployment configuration needs attention — OMNIROUTE_NO_SUDO removes sudo from MITM certificate setup, so rootless operators must trust the CA manually, such as through NODE_EXTRA_CA_CERTS (#6122). Tests and CI now set OMNIROUTE_SKIP_SYSTEM_TRUST=1 to prevent host trust-store mutation (#6310). The CLI binds using OMNIROUTE_SERVER_HOST rather than POSIX HOSTNAME (#6195), and default logs move to DATA_DIR (~/.omniroute/logs/application/app.log), so update custom bind and log-collection settings (#6197).

  • fix(proxy): stop the v3.8.44 proxy regression that leaked the real IP and disabled healthy proxies (#6246). Fix: the sweep decision is extracted into a pure, network-free decideProxyHealthAction (src/lib/proxyHealth/decision.ts) — by default the health check now only counts/logs and never downgrades status (a proxy is downgraded/removed only with PROXY_AUTO_REMOVE=true, after PROXY_AUTO_REMOVE_AFTER consecutive conclusive failures); probes are classified tri-state so an inconclusive result (our timeout, or a 5xx from the probe target) never penalizes the proxy, and the probe timeout is raised 5s→15s.
