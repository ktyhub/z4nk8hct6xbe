feu d'artifice v2.5.0

v2.5.0 - Les meilleures données Web au monde API

Nous disposons désormais des données Web API les plus complètes et de la plus haute qualité disponibles, alimentées par notre nouvel index sémantique et notre pile de navigateur personnalisée.

Voir les références ci-dessous :

<img width="1200" height="675" alt="image" src="https://github.com/user-attachments/assets/96a2ba36-0c7f-4fa3-829e-d6ac91b53705" />

Nouvelles fonctionnalités

  • Implémentation de scraping pour les fichiers .xlsx (Excel).
  • Introduction d'une nouvelle architecture d'analyse et du système de suivi de la concurrence NUQ.
  • Limitation de la concurrence par propriétaire/groupe + calcul de concurrence dynamique.
  • Ajout de la gestion du backlog de groupe et amélioration des opérations de groupe.
  • Ajout de la mise à jour des prix /search
  • Ajout du drapeau de l'équipe pour ignorer la vérification du pays.
  • Remplissez toujours les métriques NUQ pour une meilleure observabilité.
  • Nouvelle application de site de test pour des tests CI améliorés.
  • Extrayez les métadonnées de l'en-tête du document pour une sortie plus riche.

Améliorations et améliorations

  • Amélioration du chargement de la liste de blocage et des messages d'erreur de site non pris en charge.
  • Version x402-express mise à jour.
  • Amélioration de la gestion des includePaths pour les sous-domaines.
  • Mise à jour de la recherche auto-hébergée pour utiliser DuckDuckGo.
  • Les JS & Python SDK ne nécessitent plus la clé API pour les déploiements auto-hébergés.
  • Améliorations de la gestion des délais d'attente Python SDK.
  • Rust client utilise désormais tracing au lieu de print.
  • Réduction du bruit dans les notifications Slack de recharge automatique.

Correctifs

  • Garantit que les avertissements du fichier robots.txt apparaissent de manière fiable.
  • Résolution des blocages de concurrence et de la gestion des tâches en double.
  • Correction des paramètres par défaut des pays de recherche et des bugs de logique de tarification.
  • Correction des conflits de ports dans les environnements de harnais.
  • Correction de la prise en charge des dimensions de la fenêtre et du comportement des captures d'écran dans Playwright.
  • Résolution des problèmes de test CI (cache du dramaturge, tests de production).

firecrawl v2.5.0

v2.5.0 - The World's Best Web Data API

We now have the highest quality and most comprehensive web data API available powered by our new semantic index and custom browser stack.

See the benchmarks below:

<img width="1200" height="675" alt="image" src="https://github.com/user-attachments/assets/96a2ba36-0c7f-4fa3-829e-d6ac91b53705" />

New Features

  • Implemented scraping for .xlsx (Excel) files.
  • Introduced new crawl architecture and NUQ concurrency tracking system.
  • Per-owner/group concurrency limiting + dynamic concurrency calculation.
  • Added group backlog handling and improved group operations.
  • Added /search pricing update
  • Added team flag to skip country check.
  • Always populate NUQ metrics for improved observability.
  • New test-site app for improved CI testing.
  • Extract metadata from document head for richer output.

Enhancements & Improvements

  • Improved blocklist loading and unsupported site error messages.
  • Updated x402-express version.
  • Improved includePaths handling for subdomains.
  • Updated self-hosted search to use DuckDuckGo.
  • JS & Python SDKs no longer require API key for self-hosted deployments.
  • Python SDK timeout handling improvements.
  • Rust client now uses tracing instead of print.
  • Reduced noise in auto-recharge Slack notifications.

Fixes

  • Ensured crawl robots.txt warnings surface reliably.
  • Resolved concurrency deadlocks and duplicate job handling.
  • Fixed search country defaults and pricing logic bugs.
  • Fixed port conflicts in harness environments.
  • Fixed viewport dimension support and screenshot behavior in Playwright.
  • Resolved CI test flakiness (playwright cache, prod tests).

👋 New Contributors

  • @delong3
  • @c4nc
  • @codetheweb
