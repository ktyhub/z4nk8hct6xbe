InternLM v0.2.1dev20240102

Highlights

  • LLaMA checkpoint support and required config rename — Adds checkpoint loading for LLaMA models (#532), but the selector changes from model_type = "LLAMA" to model_type = "LLAMA2" (#539). Update conversion scripts and model configs, and set ckpt_type correctly—loading now rejects incompatible checkpoint types (#542).
  • Configurable RoPE base — The new rope_base interface (#512) exposes the rotary-position base used for context-length extrapolation. Match it to the source checkpoint rather than assuming the default, especially when converting or fine-tuning external models.
  • Cloud checkpoint recovery and storage changes — Automatic resume is now supported on Volcengine and Alibaba Cloud (#529), while OSS uploads use multipart transfer (#520) for more reliable large-checkpoint handling. Access-key/secret-key naming is standardized (#527), so audit deployment environment variables for the new names.
  • Distributed-training correctness — Fixes sequence-parallel norm reductions when communication is not overlapped and adds sequence-parallel guards (#528, #534), alongside MoE ZeRO and tensor-parallel token grad-norm fixes (#548, #547). These affect gradient synchronization and scaling; revalidate convergence for sequence-parallel, MoE/ZeRO, and TP configurations.
  • Data-pipeline compatibility fixes — Corrects type_ids unpacking with use_flash_attn=False (#516, #530) and fixes pipeline-parallel loading failures on no-packed datasets (#538). Recheck data configurations if you disabled FlashAttention or trained on unpacked samples.
  • Performance, diagnostics, and partial resume — Adds optional TF32 output embeddings (#523), vocabulary grad-norm profiling (#519), metric dtype control (#533), and buffered TensorBoard key/value logging (#549). Learning-rate scheduler resume without loading an optimizer is also fixed (#565), improving partial-checkpoint recovery.
