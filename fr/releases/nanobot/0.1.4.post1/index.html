nanobot v0.1.4.post1

🎉 Encore une grosse sortie de la communauté 🐈 nanobot — merci à tous les contributeurs, en particulier nos 19 nouveaux ! Cette version apporte des améliorations majeures aux canaux de Feishu, Slack et Discord, un nouveau fournisseur, une mise en cache des invites et une refactorisation importante de la boucle d'agent. Un code plus fiable, plus performant et plus léger 😄.

Faits saillants

  • Feishu Media — Le robot peut désormais envoyer et recevoir des images, de l'audio et des fichiers (#844, #922)
  • Slack Media Upload — Envoyez des fichiers directement depuis l'agent (#904)
  • Discord Long Messages — Divise automatiquement les messages dépassant 2 000 caractères (#900)
  • VolcEngine Provider — Nouveau support du fournisseur LLM (#812)
  • Prompt Caching — Prise en charge de Anthropic et OpenRouter cache_control pour réduire les coûts (#854, #905)
  • MCP Auth Headers — En-têtes HTTP personnalisés pour les serveurs MCP authentifiés (#807)
  • Améliorations de Telegram — Comportement de réponse configurable, /help contourne l'ACL (#879, #824)
  • Prise en charge du sous-agent CLI — CLI est désormais acheminé via le bus de messages, permettant une prise en charge complète des sous-agents (#908)
  • Mémoire fiable — La consolidation de la mémoire utilise des appels d'outils structurés au lieu de l'analyse fragile du JSON (#866)
  • Leaner Agent Loop — Logique de mémoire extraite, méthodes redondantes fusionnées, -31 % de lignes (#930)
  • Édition de fichiers plus intelligente — edit_file affiche désormais une différence lorsque old_text ne correspond pas (#921)
  • Corrections de bugs — Reconnexion MCP, persistance des clés de session, réponses en double, exécution cron, etc. (#892, #902, #832, #821, #823, ...)

nanobot v0.1.4.post1

🎉 Another big release from the 🐈 nanobot community — thanks to all contributors, especially our 19 new ones!

This release brings major channel improvements across Feishu, Slack, and Discord, a new provider, prompt caching, and a significant agent loop refactor. More reliable, more capable, leaner code 😄.

Highlights

  • Feishu Media — Bot can now send and receive images, audio, and files (#844, #922)
  • Slack Media Upload — Send files directly from the agent (#904)
  • Discord Long Messages — Automatically splits messages exceeding 2000 characters (#900)
  • VolcEngine Provider — New LLM provider support (#812)
  • Prompt Caching — Anthropic and OpenRouter cache_control support for lower costs (#854, #905)
  • MCP Auth Headers — Custom HTTP headers for authenticated MCP servers (#807)
  • Telegram Improvements — Configurable reply-to behavior, /help bypasses ACL (#879, #824)
  • CLI Subagent Support — CLI now routes through message bus, enabling full subagent support (#908)
  • Reliable Memory — Memory consolidation uses structured tool calls instead of fragile JSON parsing (#866)
  • Leaner Agent Loop — Extracted memory logic, merged redundant methods, -31% lines (#930)
  • Smarter File Editing — edit_file now shows a diff when old_text doesn't match (#921)
  • Bug Fixes — MCP reconnection, session key persistence, duplicate replies, cron execution, and more (#892, #902, #832, #821, #823, ...)
