rea rea-agents-6.0.0

6.0.0 (2026-10-08)

⚠ CHANGEMENTS DE RUPTURE

  • contrats : Les entrées du système de fichiers MCP nécessitent désormais des chemins d'hôte absolus, y compris les chemins de cible/instantané, les chemins d'ensemble de preuves, les entrées gérées et de micrologiciel, les chemins de lancement du navigateur/Electron et les chemins de serveur attendus. Les appels tels que open_binary({"path":"./app"}) doivent envoyer un chemin absolu tel que /home/analyst/app ou C:\analysis\app. Les chemins facultatifs restent facultatifs. Les chemins relatifs à l'opérateur CLI continuent de fonctionner. Voir #948 et #1004.

rea rea-agents-6.0.0

6.0.0 (2026-10-08)

⚠ BREAKING CHANGES

  • contracts: MCP filesystem inputs now require absolute host paths, including target/snapshot paths, evidence bundle paths, managed and firmware inputs, browser/Electron launch paths and expected server paths. Calls such as open_binary({"path":"./app"}) must send an absolute path such as /home/analyst/app or C:\analysis\app. Optional paths remain optional. CLI operator-relative paths continue to work. See #948 and #1004.

Features

  • artifacts: trace Mach-O dylib resolution in bundles (78d594c)
  • browser: inspect historical web network captures (#992) (2bf3663)
  • evm: inspect offline bytecode interfaces through EVMole (#1051) (7af7bc8)
  • ghidra: support native x86 PE applications on Windows (#1030) (c6dad93)
  • native: inspect offline ELF layout through pwntools (#1037) (4fc6565)
  • native: inspect recorded crashes through pwntools and pwndbg (#1054) (163ee09)
  • native: observe function and Objective-C method calls under LLDB (1d13cef)

Bug Fixes

  • dotnet: validate managed metadata and CIL boundaries (#938) (bda4ada)

  • build: clarify generated-file check hint and drop redundant catalog step (#998) (6f0ef16)

  • release: extend npm propagation window and improve diagnostics (#943) (06b047a)

  • contracts: require absolute local paths for session filesystem inputs (#948) (5b172b1)

  • ci: generate source catalog before shard tests (#1002) (eb8f649)

  • contracts: require absolute local paths for remaining caller-supplied file inputs (#1004) (cbc0dd1)

  • cli: classify ENOTDIR JSON input failures (#1000) (a6132be)

  • browser: preserve authorized redirect hops (#986) (ae0f725)

  • mcp: reject unknown MCP tool inputs (#975) (fe64fd6)

  • release: publish from explicit source checkpoints (#1003) (64c7188)

  • release: publish from explicit source checkpoints (#1006) (b4fc0ec)

  • javascript: bound semantic node projection for resource safety (#966) (96a46ad)

  • ci: avoid slow Azure archive for the native cross compiler (#1016) (51956c1)

  • ci: decouple stdio smoke tests from Linux display probes (#1014) (93731e1)

  • cli: stream large JavaScript JSON results (#1024) (0e25bef)

  • javascript: complete large-ASAR analysis with file-local projection (#1055) (b9fb438)

  • javascript: recognize digits in artifact URI schemes (#1045) (03424ae)

  • javascript: reconstruct HTML script loads accurately (#1042) (1154f2f)

  • javascript: report application analysis progress on the CLI (#1008) (7b18c58)

  • javascript: resolve module URLs and reject invalid exports targets (#1031) (8d5c88f)

  • javascript: resolve root package exports arrays (#1046) (53409ab)

  • mcp: advertise JSON values without recursive schemas (#995) (7425f70), closes #919

  • mcp: bound capture comparison input schema depth (#1005) (6b55de0)

  • process: preserve partial evidence and verify detached cleanup (#1011) (63cf28f)

  • release: support built-in credentials and refresh release boundary (6a278a6)

  • release: support default credentials and record 5.0.0 boundary (#1012) (6a278a6)

  • release: sync 5.0.0 checkpoint back to main (966cca8)

  • snapshot: replay validated workflow evidence (#984) (1d62e54)

  • windows: allow Java to read retained target snapshots (#1027) (28d5c39)

Performance Improvements

  • artifacts: replace quadratic ZIP overlap checks (#1013) (76e7e51)
  • javascript: cache canonical export comparison sort keys (#1028) (63ba742)

Code Refactoring

  • build: generate MCP tool catalog at build time instead of committing it (#997) (35a4e18)

  • process: separate capture implementation from analyst workflows (#988) (6aa9afb)

  • artifacts: move inventory and extraction into provider owners (#1032) (6e4535c)

  • remove abandoned test-only analysis scaffolding (c93422a)

Documentation

  • improve Korean wording and particles (#1047) (c5d165b)
  • simplify the English README and organize guides (#1043) (28f10cf)

Tests

  • process: wait for observable snapshot ctime changes (#999) (161ed91)

  • browser: consolidate CDP workflows and colocate parser coverage (2682904)

  • ci: stabilize browser source identity fixture delivery (#1023) (ed725da)

  • cli: reduce repeated startup and filesystem setup (d88d6c1)

  • consolidate service and process fixtures (f8a53a8)

  • javascript: consolidate source analysis and export regressions (f517a5a)

  • javascript: cover plain long-line loader identities (#1025) (984fc27)

  • mcp: consolidate SDK schema checks and scenario ports (9c3479e)

  • providers: verify framing through client socket boundaries (1fd1989)

  • prune redundant conformance checks and document test priorities (aafdf8a)
