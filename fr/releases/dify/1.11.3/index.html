🚀 Quoi de neuf dans le v1.11.3 ?

Notre dernière version, v1.11.3, vous apporte une multitude de corrections de bugs et de fonctionnalités axées sur les performances, les fonctionnalités et l'expérience utilisateur. Voici un aperçu de ce qui a changé :

🎬 Nouvelles fonctionnalités

  • Améliorations des outils MCP : ajout de la prise en charge de embeddedResource et affichage direct des outils MCP pour un accès plus rapide par @IthacaDream et @fatelei dans #30261 et #30019.
  • Opérations par lots : introduction de l'opération de réindexation dans les opérations par lots de documents par @fatelei dans #30275.
  • Mises à jour des agents et des workflows : la nouvelle AgentMaxIterationError et les améliorations apportées aux vérifications du mode application rendent les workflows et les agents plus robustes par @fatelei.
  • Intégration OAuth : la connexion frontend prend désormais en charge l'indicateur oauth_new_user de @zyssyz123 dans #30370.
  • Extraction PDF : extracteur RAG amélioré pour prendre en charge l'extraction d'images à partir de PDF par @yangzq50 dans #30399.
  • Stockage et archivage : Ajout du stockage d'archives client et des paramètres de configuration par @hjlarry dans #30422.
  • Traduction et internationalisation : ajout du support RSC initial pour les traductions destinées à un public mondial par @hyoban dans #30596.

🛠️ Corrections de bugs

  • Redis et Cache : pipelines utilisés pour optimiser les suppressions de cache Redis, améliorant ainsi la vitesse et la fiabilité par @fatelei dans #30159.
  • Corrections UI/UX : De la prévention des plantages de page dus à des erreurs d'autorisation à la correction de la taille des boutons d'actionnement, plusieurs problèmes liés à l'interface utilisateur ont été résolus par divers contributeurs.
  • Opérations sur les données : correction des erreurs d'accès aux ensembles de données et amélioration de la gestion des erreurs dans les opérations par lots par @zhaobingshuang et d'autres.
  • Performances : publication de références d'état d'exécution sous charge élevée pour éviter les fuites de mémoire potentielles par @SherlockShemol dans #30236.
  • Sécurité : correction des problèmes CORS et SSL qui auraient pu affecter les intégrations de robots et les opérations de Celery.
  • Internationalisation : les traductions et le contenu coréens ont été mis à jour pour plus d'exactitude par @sangyun-han dans #30347.

🔧 Sous le capot

  • Améliorations CI/CD et build : actions GitHub améliorées et processus de build pour une meilleure fiabilité et moins de temps d'arrêt par @bowenliang123 et @hyoban.
  • Optimisation du code et des requêtes : correction des inefficacités dans les requêtes SQL et la gestion des données dans les flux de travail et le API, améliorant ainsi la stabilité globale.

Cette version met l'accent sur la rationalisation des opérations backend, le renforcement de la sécurité et l'enrichissement de l'interface utilisateur pour une expérience plus fluide et plus productive. Merci à tous les contributeurs d'avoir affiné Dify et fait avancer notre plateforme ! 🛠️💡

Guide de mise à niveau

Déploiements de composition Docker

  1. Sauvegardez votre fichier docker-compose YAML personnalisé (facultatif)

    cd docker
cp docker-compose.yaml docker-compose.yaml.$(date +%s).bak

  2. Obtenez le dernier code de la branche principale

    git checkout main
git pull origin main

  3. Arrêtez le service. Veuillez exécuter dans le répertoire docker

    docker compose down

  4. Sauvegarder les données

    tar -cvf volumes-$(date +%s).tgz volumes

  5. Services de mise à niveau

    docker compose up -d

🚀 What's New in v1.11.3?

Our latest release, v1.11.3, brings to you a slew of bug fixes and features focused on performance, functionality, and user experience. Here's a look at what's changed:

🎬 New Features

  • MCP Tool Enhancements: Added support for embeddedResource and made MCP tools display directly for quicker access by @IthacaDream and @fatelei in #30261 and #30019.
  • Batch Operations: Introduced re-index operation in document batch operations by @fatelei in #30275.
  • Agent and Workflow Updates: New AgentMaxIterationError and enhancements in app mode checks make workflows and agents more robust by @fatelei.
  • OAuth Integration: Frontend login now supports oauth_new_user flag by @zyssyz123 in #30370.
  • PDF Extraction: Improved RAG extractor to support image extraction from PDFs by @yangzq50 in #30399.
  • Storage and Archive: Added archive storage client and config settings by @hjlarry in #30422.
  • Translation and Internationalization: Added initial RSC support for translations for a global audience by @hyoban in #30596.

🛠️ Bug Fixes

  • Redis and Cache: Used pipelines to optimize Redis cache deletions, enhancing speed and reliability by @fatelei in #30159.
  • UI/UX Fixes: From preventing page crashes due to permission errors to fixing flicking button sizes, multiple UI-related issues have been addressed by various contributors.
  • Data Operations: Fixed dataset access errors and improved error handling in batch operations by @zhaobingshuang and others.
  • Performance: Released runtime state references under high load to prevent potential memory leaks by @SherlockShemol in #30236.
  • Security: Rectified CORS and SSL issues that could've affected bot integrations and Celery operations.
  • Internationalization: Korean translations and content were updated for accuracy by @sangyun-han in #30347.

🔧 Under the Hood

  • CI/CD and Build Enhancements: Enhanced GitHub actions and build processes for better reliability and less downtime by @bowenliang123 and @hyoban.
  • Code & Query Optimization: Addressed inefficiencies in SQL queries and data handling in workflows and the API, improving overall stability.

This release emphasizes streamlining backend operations, fortifying security, and enriching the user interface for a smoother, more productive experience. Thank you to all contributors for refining Dify and pushing our platform forward! 🛠️💡

Upgrade Guide

Docker Compose Deployments

  1. Back up your customized docker-compose YAML file (optional)

    cd docker
cp docker-compose.yaml docker-compose.yaml.$(date +%s).bak

  2. Get the latest code from the main branch

    git checkout main
git pull origin main

  3. Stop the service. Please execute in the docker directory

    docker compose down

  4. Back up data

    tar -cvf volumes-$(date +%s).tgz volumes

  5. Upgrade services

    docker compose up -d
