Collaboration

<img width="2632" height="1190" alt="img_v3_02117_67a67218-1ae5-4d68-a45b-3ada592f87fg" src="https://github.com/user-attachments/assets/1d4a3660-8a6a-4b29-9766-4d5b5fd9a51b" />

La collaboration permet aux membres de l'espace de travail de modifier ensemble le même flux de travail, avec des mises à jour de graphiques synchronisées, une présence en ligne et une visibilité partagée sur qui travaille où.

Sur les déploiements auto-hébergés, la collaboration est désactivée par défaut. Activez-le en définissant :

ENABLE_COLLABORATION_MODE = true
SERVER_WORKER_CLASS = geventwebsocket.gunicorn.workers.GeventWebSocketWorker
NEXT_PUBLIC_SOCKET_URL = your deployment’s WebSocket URL (e.g., wss://dify.example.com)

Pour plus de détails, voir Documentation complète

Humain dans la boucle (HITL)

  • Service API pour HITL — prise en charge programmatique des flux humains dans la boucle parallèlement au comportement de la console existante.

MCP et plugins

  • Métadonnées de l'outil MCP : actualisez après les mises à jour afin que l'interface utilisateur reste synchronisée.
  • URL du serveur MCP — correction du double /v1 qui pourrait casser OAuth et l'autorisation (404).
  • Découverte MCP OAuth — gérez le JSON malformé en toute sécurité.
  • Publication de schéma MCP — mappez correctement les types checkbox et json_object.
  • Plugins — persistance de la stratégie de mise à niveau automatique, comportement de l'installateur local et de la saisie de fichiers, portée du locataire pour la recherche interne de l'utilisateur final du API.

Marketplace et OAuth

  • Marketplace et OAuth — correctifs ciblés pour les flux de Marketplace et la connexion OAuth (y compris les cas extrêmes tels que les e-mails nuls sur GitHub OAuth).

Kit d'interface utilisateur et plateforme frontale

  • @langgenius/dify-ui — primitives partagées (par exemple PreviewCard, Meter), jetons de conception et large migration de web/base/ui ad hoc vers le package.
  • Accessibilité — sélecteurs de date et d'heure, sélecteur de stratégie de mise à jour automatique, barres de défilement dans les sélecteurs de plugins et de modèles, et peaufinage associé.
  • Goto Anything — éléments récents, commande /go, sous-sections d'application plus profondes ; correctif pour Cmd+K (importation dynamique problématique supprimée).
  • Éditeur d'invites — filtrage de variables déclenché par une barre oblique ; clavier haut/bas dans les listes de variables.
  • Questions de suivi : paramètres améliorés et limites de jetons pour les questions suggérées.
  • Modals — ApiKey, configuration du fournisseur et autres refactorisés vers un modèle Dialog partagé avec des tests.

Observabilité et analyse

  • Langfuse — rapport facultatif délai d'obtention du premier jeton (TTFT).
  • Explorer — suivi des impressions de bannière ; suivi des événements d'aperçu de l'application sur les cartes.

Facturation et quotas

  • Intégration Quota v3 dans la pile de produits.
  • Interface utilisateur de facturation — Présentation de l'utilisation basée sur un compteur ; nettoyage plus résilient en cas d'échec de la facturation des API.
  • Téléchargeur de fichiers : comportement tenant compte de la facturation et copie des mises à jour.

Données, RAG et connaissances

  • Index récapitulatif et Weaviate — correctifs de compatibilité lors de l'utilisation de l'index récapitulatif avec Weaviate.
  • Projection vectorielle — inclut is_summary et original_chunk_id dans la projection par défaut, le cas échéant.
  • Ensembles de données externes et liés — contrôles plus stricts des locataires sur les connaissances API.

Infrastructures et opérations

  • Docker Compose — vérifications de santé pour api, worker et worker_beat ; mises à jour des modèles et des exemples d'environnement (par exemple, style d'adresse S3).
  • Céleri — travailleur par défaut concurrence augmentée à 4 ; correctif de file d'attente manquant.
  • PostgreSQL — connexions maximales par défaut plus élevées (200) pour le chemin de base de données de l'application mis à jour.
  • Redis — préfixe de clé configurable ; Logique réessayer pour les opérations Redis.
  • TiDB — prise en charge des points de terminaison et migration des liaisons d'authentification associées (Point de terminaison Qdrant sur les liaisons d'authentification TiDB).
  • Markdown — variable d'environnement facultative ALLOW_INLINE_STYLES pour autoriser le CSS en ligne dans le rendu Markdown si nécessaire.

Sécurité

  • Flux de courrier électronique modifié — gestion plus stricte des jetons liés aux phases (GHSA-4q3w-q5mc-45rq).
  • Durcissement IDOR — validation du locataire sur la liaison de source de données ; L'ensemble de données et la propriété API vérifient les lacunes trouvées.

Performances

  • Performances optimisées de l'initialisation du graphique.

API et composants internes de la plateforme

  • Graphon — mise à niveau vers Graphon 0.2.2 autonome (en remplacement de la dénomination et du packaging dify_graph dans l'arborescence).
  • OpenAPI — script pour générer OpenAPI v2 JSON et pointeur de documentation.
  • Obsolescence — certaines anciennes consoles API sont marquées comme obsolètes au profit de modèles plus récents.
  • Grande migration SQLAlchemy 2.0 select(), Pydantic BaseModel pour de nombreuses réponses de console et de service, et tests de stabilité basés sur testcontainers.

🚀 What's New in v1.14.0?

Collaboration

<img width="2632" height="1190" alt="img_v3_02117_67a67218-1ae5-4d68-a45b-3ada592f87fg" src="https://github.com/user-attachments/assets/1d4a3660-8a6a-4b29-9766-4d5b5fd9a51b" />

Collaboration allows workspace members to edit the same workflow together, with synced graph updates, online presence, and shared visibility into who is working where.

On self-hosted deployments, collaboration is turned off by default. Enable it by setting:

ENABLE_COLLABORATION_MODE = true
SERVER_WORKER_CLASS = geventwebsocket.gunicorn.workers.GeventWebSocketWorker
NEXT_PUBLIC_SOCKET_URL = your deployment’s WebSocket URL (e.g., wss://dify.example.com)

For more details, see Full Documentation

Human-in-the-loop (HITL)

  • Service API for HITL — programmatic support for human-in-the-loop flows alongside existing console behavior.

MCP and plugins

  • MCP tool metadata — refresh after updates so the UI stays in sync.
  • MCP server URL — fix double /v1 that could break OAuth and authorization (404).
  • MCP OAuth discovery — handle malformed JSON safely.
  • MCP schema publishing — map checkbox and json_object types correctly.
  • Plugins — auto-upgrade strategy persistence, local installer and file-input behavior, tenant scoping for inner API end-user lookup.

Marketplace and OAuth

  • Marketplace and OAuth — targeted fixes for marketplace flows and OAuth sign-in (including edge cases such as null email on GitHub OAuth).

UI kit and front-end platform

  • @langgenius/dify-ui — shared primitives (for example PreviewCard, Meter), design tokens, and broad migration from ad-hoc web/base/ui toward the package.
  • Accessibility — date and time pickers, auto-update strategy picker, scrollbars in plugin and model selectors, and related polish.
  • Goto Anything — recent items, /go command, deeper app sub-sections; fix for Cmd+K (removed problematic dynamic import).
  • Prompt editor — slash-triggered variable filtering; keyboard up/down in variable lists.
  • Follow-up questions — improved settings and token limits for suggested questions.
  • Modals — ApiKey, provider config, and others refactored toward a shared Dialog pattern with tests.

Observability and analytics

  • Langfuse — optional time-to-first-token (TTFT) reporting.
  • Explore — banner impression tracking; app preview event tracking on cards.

Billing and quotas

  • Quota v3 integration in the product stack.
  • Billing UI — Meter-based usage presentation; more resilient cleanup when billing APIs fail.
  • File uploader — billing-aware behavior and copy updates.

Data, RAG, and knowledge

  • Summary index and Weaviate — compatibility fixes when using the summary index with Weaviate.
  • Vector projection — include is_summary and original_chunk_id in default projection where relevant.
  • External and bound datasets — stronger tenant checks on knowledge APIs.

Infrastructure and operations

  • Docker Compose — healthchecks for api, worker, and worker_beat; template and env example updates (for example S3 address style).
  • Celery — default worker concurrency raised to 4; missing queue fix.
  • PostgreSQL — higher default max connections (200) for the updated app DB path.
  • Redis — configurable key prefix; retry logic for Redis operations.
  • TiDB — endpoint support and related auth binding migration (Qdrant endpoint on TiDB auth bindings).
  • Markdown — optional ALLOW_INLINE_STYLES environment variable to allow inline CSS in rendered Markdown when needed.

Security

  • Change-email flow — stricter phase-bound token handling (GHSA-4q3w-q5mc-45rq).
  • IDOR hardening — tenant validation on data-source binding; dataset and API ownership checks where gaps were found.

Performance

  • Optimized performance of graph initialization.

API and platform internals

  • Graphon — upgrade to standalone Graphon 0.2.2 (replacing in-tree dify_graph naming and packaging).
  • OpenAPI — script to generate OpenAPI v2 JSON and documentation pointer.
  • Deprecation — some legacy console APIs marked deprecated in favor of newer patterns.
  • Large SQLAlchemy 2.0 select() migration, Pydantic BaseModel for many console and service responses, and testcontainers-based tests for stability.
