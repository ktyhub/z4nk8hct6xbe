anything-llm v1.0.0

Highlights

  • Pluggable vector backends come of age — v1.0.0 turns vector storage into a genuine choose-your-own layer: Chroma (#1), LanceDB (#6, #155), Weaviate (#181) and Qdrant (#192) round out the options, with Chroma API-key auth (#260) and host.docker.internal support (#195) for containerized setups. The sleeper change is #112: chat/conversation mode is now the default across all vector DBs, which silently alters retrieval behavior for anyone who relied on the old default — verify answer quality after upgrading. Pinecone users also get bulk ID deletion capped at 1000 (#210).

  • LLM providers beyond OpenAI — The hard-coded OpenAI coupling is gone. A multi-LLM framework adds Azure OpenAI (#180), Anthropic Claude 2 (#305), fine-tuned models (#314) and GPT-4-turbo 128K (#340), while OpenAI calls are isolated behind their own class (#162) — the seam you'll use to add your own provider. Streaming responses (#35) and "infinite prompt" input with context compression (#332) change how long conversations behave, and Azure embedding calls now run concurrently to sidestep per-call token limits (#211).

  • Multi-user auth and a real role model — This release graduates from a single shared password to full multi-user instances (#158), with a distinct manager role and safer default permissions (#351), owner-controlled rotation of the system password and secret (#156), and API keys explicitly blocked from mutating sensitive keys (#256). Re-audit your permission assumptions: workspace deletion, for example, is now hidden from non-admins when the setting is disabled (#227).

  • Storage layer replaced with Prisma — plan the migration — PR #239 swaps the hand-rolled SQLite DBMS for Prisma. If you're upgrading an existing install rather than starting clean, budget for a data migration and back up before cutover; the new instance import/export capability (#146) is your safety net. Note that imports are intentionally disabled on hosted instances (#339) and dumpENV behaves differently in production (#207).

  • Headless access via a full developer API — #221 ships a complete developer API and #261 adds chatting through it, so ingestion, workspace operations and conversations can all be driven programmatically. Be aware of the guardrails: #333 fixes a missing API import, and certain keys are deliberately not writable through the API (#256) — design integrations around that restriction.

  • Deployment and security hardening — Multi-arch Docker (#48, #60) plus AWS CloudFormation (#52), GCP (#142) and DigitalOcean/Terraform (#148) templates lower the ops bar for private instances. Two things to watch: the default server port moved off 5000 (#15), so update proxies, health checks and firewall rules; and several traversal/injection fixes (#233 exports, #258 document deletion, #234 SQLi) make this a worthwhile upgrade for any internet-facing deployment.

Hey everyone, it's high time we start a formal release cycle for AnythingLLM. As such, we will now be tagging releases as we have some both large and smaller features that will require version tracking.
