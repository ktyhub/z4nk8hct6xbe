anything-llm v1.17.0

Highlights

  • Model-parameter controls mature — Reasoning effort is now configurable (#6269), workspace temperature is applied to agents and omitted entirely when unset (#6285), Anthropic calls drop the temp parameter (#6472), and Generic OpenAI can send max_tokens: 0 to omit the field from requests (#6470) while TogetherAI gains configurable max_tokens to stop response truncation (#6463). Worth verifying how your providers behave when these fields are absent, since omission is now an intentional signal.
  • Two new image-generation backends — Gemini (#6520) and llmman (#6497) join the image providers, and generated images are now included in chat exports (#6482). Expect new API-key configuration and larger export payloads if you rely on image chats.
  • Agent web search widens — Firecrawl is a selectable web-search provider (#6480), SearchApi engines work in agent web browsing (#6465), and DuckDuckGo result links are decoded once with HTML stripped from titles (#6544). With more engines available, check which backend your agents actually route through after upgrading.
  • Vector-store behavior changes — Weaviate and Astra now score chunks by cosine similarity like the other providers (#6488), which can shift relevance rankings without any config change; changing the Azure embedding deployment now resets vectors and warns (#6461), so plan for re-embedding when you switch it; and Milvus/Zilliz can embed into workspaces whose slug starts with a digit (#6527).
  • Stability and state fixes — Malformed agent WebSocket frames are ignored instead of crashing the server (#6493); manually set env vars survive .env rewrites (#6457), password protection can be disabled persistently (#6562), and the saved LiteLLM key is masked (#6556). Compressed RAG context is no longer lost when a prompt or chunk literally contains "Context:" (#6503) — relevant if you use context compression.
  • Ingestion and export correctness — Spreadsheet dates are read as dates rather than serial numbers (#6478), multi-sheet XLSX uploads keep every sheet (#6450), text uploads use their original encoding (#6486), and HTML-only mbox messages are ingested (#6484); created Excel files preserve IPs, versions, and decimal commas as text (#6534) and JSONL/Alpaca exports use each workspace's prompt and ID (#6551).

No breaking changes.
