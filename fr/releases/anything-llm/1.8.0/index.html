anything-llm v1.8.0

Highlights

  • Full MCP compatibility with zero-downtime reload — PR #3547 makes AnythingLLM a first-class MCP client, so agents can consume external tools over the Model Context Protocol. The operationally meaningful detail is that MCP config can be updated and reloaded on the fly without restarting, which removes the usual restart penalty when adding or changing a tool server. Docker images now bundle npx and uv, so npm- and Python-distributed MCP servers run out of the box instead of requiring a custom-built image — review your existing server definitions against the expanded config surface, and note the MCP UI link fixes in #3569.

  • SQL agent connection-string parser replaced — #3560 swaps out the connectionString parser used by the SQL agent. This is the quiet high-risk change in this release: if you use the SQL agent with nonstandard connection strings (special characters, custom drivers, or unusual URI schemes), verify parsing and connectivity before rolling out, since a parser swap can introduce silent regressions that the changelog doesn't call out.

  • Gemini provider refactored onto the OpenAI-compatible interface — #3616 routes Gemini through the OpenAI interface API, accompanied by a model-list sync in #3609. The upside is more consistent streaming and tool-call behavior with other providers; the watch-out is that provider-level refactors can subtly change function-calling semantics, so re-test any Gemini-backed agents that depend on precise tool invocation or pinned behavior.

  • Agent crash-loop protection — #3617 disables automatic agent retry. A crashing agent run will now halt rather than retry indefinitely, trading a chance at transient-failure recovery for protection against runaway loops. If you were relying on retries to ride over intermittent errors, expect those to surface as stopped runs instead.

  • Broad UI refresh and small behavioral fixes — A new chat home page (#3555) plus redesigned onboarding with teal CTA styling (#3533, #3627) change the default look and feel, and workspace-setting save buttons moved to the top of screens (#3613). Under the radar but useful: usernames now accept periods (#3592), OpenRouter citation handling was corrected (#3620), repo URLs get .git normalization (#3655), and the embed widget was synced for "thought" models (#3596) — check these if you had local workarounds in place.

  • Provider and locale coverage expanded — Azure AI options and the model map were updated with new configurations (#3660), and Japanese (#3651) and Russian (#3658) translations were added, with CI build infra fixed via a Buildx bump for the GHA cache deprecation (#3653). Mostly additive, but worth noting if you use Azure models or were blocked by the deprecated cache action.

No breaking changes are documented for this release.
