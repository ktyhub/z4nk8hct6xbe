n'importe quoi-llm v1.20.0

Extension de navigateur mise à jour

L'[extension de navigateur] (https://github.com/Mintplex-Labs/anythingllm-extension) a été améliorée au-delà de sa fonction d'origine consistant simplement à collecter des documents pour devenir désormais une barre de discussion d'interface utilisateur à part entière avec la possibilité de cliquer directement sur click -> Ajouter un contexte (texte et image) et de discuter directement dans Chrome. Cette barre latérale devrait avoir une parité presque complète pour les outils et plus encore avec l'interface utilisateur de chat traditionnelle. Bien qu'il soit compatible en amont et en aval, seules les fonctionnalités complètes sont attendues lorsque le serveur et l'extension sont sur la version 1.20.0 ou ultérieure. La boutique en ligne Chrome a également été mise à jour vers cette version. https://github.com/user-attachments/assets/830069a6-34cb-4f37-80b0-6d52eb4622d0

Refonte de l'outil PowerPoint

<img width="1990" height="1099" alt="pptx-generation" src="https://github.com/user-attachments/assets/05689972-1296-4869-b208-dd9301222dd3" /> L'outil PowerPoint de l'agent a été entièrement repensé pour produire des présentations plus claires et plus esthétiques. - **Thèmes et mises en page :** les présentations utilisent de nouveaux thèmes de couleurs et un ensemble de mises en page sélectionnées pour s'adapter au contenu de chaque diapositive, de sorte que la même mise en page n'est pas répétée diapositive après diapositive. - **Aperçus des diapositives en direct :** les diapositives apparaissent dans le chat au fur et à mesure de leur création, afin que vous puissiez regarder le deck se rassembler. Click un aperçu pour le voir en taille réelle. - **Contenu fondé :** les chiffres, les valeurs des graphiques et les citations ne sont conservés que lorsque votre plan, votre recherche ou votre conversation les contient, et le texte est dimensionné pour s'adapter à chaque diapositive. ### Cartes d'approbation par courrier électronique pour Gmail et Outlook <img width="1990" height="1099" alt="email-drafting" src="https://github.com/user-attachments/assets/0b571869-c43b-454f-bdf1-0e2e3d4b4beb" /> Lorsqu'un agent souhaite envoyer ou rédiger un e-mail avec les outils [Gmail](https://docs.anythingllm.com/agent/usage/gmail-agent) ou [Outlook](https://docs.anythingllm.com/agent/usage/outlook-agent), la demande d'approbation s'affiche désormais sous forme de carte e-mail. Vous pouvez modifier les destinataires, Cc, Bcc, le sujet et le corps directement dans la carte avant de l'approuver. Le minuteur d'approbation s'arrête pendant que vous modifiez et vous pouvez développer un e-mail envoyé pour voir exactement ce qui s'est passé. ### Améliorations du MCP - **Transfert d'identité :** les serveurs MCP peuvent désormais recevoir l'espace de travail et l'utilisateur qui les appelle. Inscrivez-vous par serveur avec `anythingllm.forwardIdentity`. Voir [Transfert d'identité vers des serveurs MCP](https://docs.anythingllm.com/mcp-compatibility/forward-identity). - **Délai d'expiration par serveur :** définissez `anythingllm.timeout` (en secondes) sur un serveur MCP pour contrôler la durée d'exécution de ses appels d'outils. La valeur par défaut est de 60 secondes. - **Développeur API :** les nouveaux points de terminaison `/v1/mcp-servers` vous permettent de répertorier, d'ajouter, de mettre à jour, de supprimer, de démarrer, d'arrêter et de recharger les serveurs MCP, et d'activer ou de désactiver des outils individuels. - Les serveurs MCP dotés de nombreux outils chargent désormais chaque page d'outils, le anything-llm v1.20.0

Updated browser extension

The browser extension has been improved beyond its original function of just collecting documents to now a full fledged UI chat bar with the ability to right click -> Add context (text and image) and chat directly in Chrome. This sidebar should have mostly full parity for tooling and more with the traditional chat UI.

While it is backward and forward compatible, only full functionality is expected when the server and extension are on version 1.20.0 or later. The Chrome webstore has been updated to this version as well.

https://github.com/user-attachments/assets/830069a6-34cb-4f37-80b0-6d52eb4622d0

PowerPoint tool overhaul

<img width="1990" height="1099" alt="pptx-generation" src="https://github.com/user-attachments/assets/05689972-1296-4869-b208-dd9301222dd3" />

The agent's PowerPoint tool has been rebuilt from the ground up to produce cleaner, better looking presentations.

  • Themes and layouts: decks use new color themes and a set of layouts that are picked to fit each slide's content, so the same layout is not repeated slide after slide.
  • Live slide previews: slides appear in the chat as they are built, so you can watch the deck come together. Click a preview to see it full size.
  • Grounded content: figures, chart values and quotes are only kept when your outline, research or conversation contains them, and text is sized to fit each slide.

Email approval cards for Gmail and Outlook

<img width="1990" height="1099" alt="email-drafting" src="https://github.com/user-attachments/assets/0b571869-c43b-454f-bdf1-0e2e3d4b4beb" />

When an agent wants to send or draft an email with the Gmail or Outlook tools, the approval request is now shown as an email card. You can edit the recipients, Cc, Bcc, subject and body right in the card before you approve it. The approval timer pauses while you edit, and you can expand a sent email to see exactly what went out.

MCP improvements

  • Identity forwarding: MCP servers can now receive the workspace and user that is calling them. Opt in per server with anythingllm.forwardIdentity. See Forwarding identity to MCP servers.
  • Per-server timeouts: set anythingllm.timeout (in seconds) on an MCP server to control how long its tool calls can run. The default is 60 seconds.
  • Developer API: new /v1/mcp-servers endpoints let you list, add, update, delete, start, stop and reload MCP servers, and turn individual tools on or off.
  • MCP servers with many tools now load every page of tools, starting one server also picks up any newly saved servers, and disconnected servers can be deleted.
