10/29
v5.3.3 Correctif MT

Celui-ci nettoie le groupe. Sur les machines Team, Enterprise et gérées, l'avertissement de votre première invite disparaît et la bande affiche à nouveau votre modèle et le nom de votre session.

 10/16
v5.3.2 Correctif MT

Ponytail 5.3.2 apporte vos anciennes sessions au tableau. /ponytail band import lit une fois vos précédentes sessions Claude Code et les ajoute avec leur coût, le temps de l'agent et les jetons, afin que vous puissiez les comparer avec celles d'aujourd'hui.

 10/16
v5.3.1 Correctif MT

Ponytail 5.3.1 corrige le groupe de 5.3. D'autres mods au-dessus de l'invite Claude Code s'affichent désormais sous le groupe au lieu de disparaître, et sous Windows, le groupe trouve ses fichiers sans HOME et écrit le registre des tâches et le tableau…

 10/16
v5.3.0 Mineure MT

Ponytail 5.3 place une bande au-dessus de l'invite Claude Code : combien coûte la tâche en cours, ses jetons et le temps de l'agent, quelle quantité de code existant elle a réutilisée et si les tests réussissent toujours.

 10/13
v5.2.0 Mineure MT

Principalement des correctifs pour le niveau que vous choisissez. Il survit désormais au compactage du contexte au lieu de revenir à la valeur par défaut, et sur macOS, les hooks ne peuvent plus perdre leur sortie, donc l'ensemble de règles arrive toujours.

 10/12
v5.1.1 Correctif MT

Une version de correctif. Le plus important est la carte de base de code de 5.0 : un dépôt pourrait glisser son propre texte dans le contexte de session caché, et un lien symbolique dans le dépôt pourrait suspendre le démarrage de la session jusqu'à ce que l'ensemble de règles n'arrive jamais.

 10/08
v5.1.0 Mineure MT

Ponytail n'écrit plus son nom dans votre code. Les raccourcis délibérés sont désormais marqués d'un commentaire neutre, raccourci : , et /ponytail-debt trouve toujours l'ancienne queue de cheval : celles, donc rien dans votre grand livre ne se perd.

 10/08
v5.0.0 Majeure MT

Ponytail 5 est entièrement reconstruit : de nouvelles règles, une nouvelle revue, un nouvel audit.

 10/05
v4.13.0 Mineure MT

Cette version concerne principalement la queue de cheval restant au niveau que vous avez défini. Changer de niveau sur le Codex fournit désormais les règles du nouveau niveau, chaque projet conserve son propre mode, "off" signifie vraiment "off", et le badge de statut survit...

v4.12.0 Mineure MT

Review and audit findings are numbered now, so you can answer 'fix 2 and 4' instead of quoting lines back. CodeBuddy runs ponytail through the existing Claude plugin, and /ponytail-gain shows the honest agentic…

Depuis v4.10.2, un changement d'une ligne dans le plugin racine.json a permis au Codex, VS Code et Qwen de charger la queue de cheval en tant que plugin d'agent réservé aux compétences, de sorte que les hooks ne se sont jamais enregistrés et les règles jamais…

 10/03
v4.10.3 Correctif MT

Plusieurs séances, une seule machine, plus de bagarre. Le mode queue de cheval est désormais conservé par projet, de sorte qu'une session dans un référentiel ne change ou n'efface plus le mode d'une session dans un autre.

 10/03
v4.10.2 Correctif MT

Une version de sécurité et de fiabilité. Les hooks de cycle de vie ne fusionnent plus le chemin du plugin dans le texte du shell, un comparateur de sous-agent lent ne peut plus suspendre une session et la publication npm attend désormais les tests verts.

 10/02
v4.10.1 Correctif MT

Prise en charge d'OpenCode 2. Le plugin OpenCode n'a pas réussi à se charger sur OpenCode 2 avec « Le plugin doit exporter une définition par défaut », et maintenant il s'y charge avec toutes les commandes et compétences.

 09/14
v4.10.0 Mineure MT

Deux nouvelles maisons pour Ponytail. Le titre : prise en charge native du curseur via hooks.json, avec une installation scripts/cursor-hooks.js qui fusionne dans votre fichier de hooks de curseur existant et laisse tout le reste seul.

 08/07
v4.9.0 Mineure MT

Cinq semaines de travail fusionné en une seule goutte. Le titre : /ponytail default permet au mode choisi de survivre aux redémarrages, et un simple /ponytail signale désormais le niveau actif au lieu de le réinitialiser.

 06/29
