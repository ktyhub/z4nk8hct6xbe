ponytail v4.13.0

Mineure Publié5 oct. 2026 SourceDietrichGebert/ponytail Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

queue de cheval v4.13.0

Cette version concerne principalement la queue de cheval restant au niveau que vous avez défini. Changer de niveau sur le Codex fournit désormais les règles du nouveau niveau, chaque projet conserve son propre mode, "off" signifie vraiment "off", et le badge de la ligne d'état survit aux mises à jour du plugin. Kimi Code rejoint en tant que nouvel hôte, le README est désormais également disponible en espagnol, coréen, chinois simplifié et japonais, et la prise en charge de ZCode est abandonnée.

Anglais original / English original

ponytail v4.13.0

This release is mostly about ponytail staying at the level you set. Switching levels on Codex now delivers the new level's rules, each project keeps its own mode, off really means off, and the statusline badge survives plugin updates. Kimi Code joins as a new host, the README now also comes in Spanish, Korean, Simplified Chinese and Japanese, and ZCode support is dropped.
