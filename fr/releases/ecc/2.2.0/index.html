ECC v2.2.0

Mineure Publié28 août 2026 Sourceaffaan-m/ECC Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

#ECCv2.2.0 ECC 2.2 est ici, dirigé par un installateur guidé pour Claude Code, Codex et Kimi. Il ajoute également la prise en charge native de l'Antigravity 2.0 et un Nasiko expérimental et opt-in. Pont de cycle de vie CLI. Le pipeline de versions est également plus strict : l'archive npm exacte doit réussir son cycle de vie tests sur Linux, macOS et Windows avant le déplacement de latest.

Un chemin guidé vers ECC

Démarrez le programme d'installation guidé avec :

npx --yes ecc-universal@2.2.0 install --guided

L'installateur vérifie chaque harnais sélectionné avant d'écrire des fichiers, puis applique la configuration en une seule opération. Modèle appartenant au fournisseur et paramètres d'authentification rester sous le contrôle du fournisseur. L'accueil du terminal apparaît seulement après un installation interactive réussie.

Nasiko : expérimental, opt-in et explicite

ECC 2.2 peut inspecter, installer et supprimer une version épinglée de Nasiko v0.1.0 CLI :

npm install -g ecc-universal@2.2.0
ecc nasiko status --json
ecc nasiko install --version v0.1.0 --dry-run --json
ecc nasiko install --version v0.1.0 --yes --json

Les téléchargements sont adressés par contenu et vérifiés SHA-256, le statut est en lecture seule et la désinstallation protège les binaires modifiés ou non qualifiés. Le tableau de bord ci-dessus est Le propre produit de Nasiko. ECC ne connecte pas les agents, ne démarre pas un serveur, n'active pas télémétrie, partager des données ou exploiter ce plan de contrôle. Le pont reste expérimental et opt-in. Apprenez-en plus dans le [référentiel Nasiko] (https://github.com/Nasiko-Labs/nasiko).

Plus fiable sur tous les harnais

  • Native Antigravity 2.0 : ECC s'installe sur .agents/{rules,workflows,skills,agents} et migre en toute sécurité la propriété héritée.
  • Désinstallation fiable : les installations sélectives répétées conservent la propriété complète grand livre, de sorte que les fichiers inchangés gérés par ECC puissent être supprimés proprement.
  • Migrations plus sûres : OpenCode utilise ~/.config/opencode, tandis qu'OpenCode et Le Codex conserve les fichiers modifiés ou non suivis pendant le nettoyage.
  • Plus de workflows : Pi, Itô, évaluation d'agents, conseil multi-modèle, dev-team, les documents vivants, le terminal sécurisé, TasteForge et skill-comply étendent tous la distribution expédiée. L'ECC 2.2 est livré avec 68 agents, 286 compétences et 94 cales de commande, plus les règles, crochets, mémoire, apprentissage continu et surfaces d'installation autour d'eux.

Assurance de libération

Le commit balisé doit correspondre à origin/main. Une archive npm est compressée, hachée, et testé sur les trois systèmes d'exploitation, puis publié sous une balise intermédiaire. L'intégrité du registre doit correspondre avant que latest ne soit déplacé. Le package 2.1.0 précédent reste la cible immédiate du retour en arrière.

Installer ou mettre à niveau

Pour le plugin natif Claude Code :

/plugin marketplace add https://github.com/affaan-m/ECC
/plugin install ecc@ecc

Les installations Claude existantes peuvent exécuter /plugin update ecc.

ECC v2.2.0

Highlights

  • Guided installation and release assurance — npx --yes ecc-universal@2.2.0 install --guided validates every selected harness before writing files, preserves provider-owned model and authentication settings, and applies setup as one operation. latest now advances only after the exact npm archive passes lifecycle tests on Linux, macOS, and Windows.
  • Harness migrations and cleanup — Native Antigravity 2.0 support installs into .agents/{rules,workflows,skills,agents} and migrates legacy ownership. OpenCode now uses ~/.config/opencode, while OpenCode and Codex cleanup preserves edited or untracked files; check any custom configuration that references old paths.
  • Reliable selective installs — A persistent ownership ledger keeps track of ECC-managed files across repeated selective installs, allowing unchanged files to be removed cleanly instead of leaving stale assets behind.
  • Experimental Nasiko bridge — The opt-in lifecycle tools are pinned to Nasiko v0.1.0, with SHA-256-verified downloads, read-only status checks, --dry-run, and uninstall protection for modified or unqualified binaries. Installing the bridge does not start Nasiko, connect agents, enable telemetry, or operate its control plane.
  • Expanded workflow catalog — The release ships 68 agents, 286 skills, and 94 command shims. Notable developer-facing changes include Pi support (#2759), the /evolve repair (#2664), and hardened hook parsing (#2405); existing hook integrations should be retested after upgrading.
  • Breaking changes — None announced.

ECC 2.2 is here, led by one guided installer for Claude Code, Codex, and Kimi. It also adds native Antigravity 2.0 support and an experimental, opt-in Nasiko CLI lifecycle bridge.

The release pipeline is stricter too: the exact npm archive must pass lifecycle tests on Linux, macOS, and Windows before latest moves.

One guided path into ECC

Start the guided installer with:

npx --yes ecc-universal@2.2.0 install --guided

The installer checks every selected harness before writing files, then applies the setup as one operation. Provider-owned model and authentication settings stay under the provider's control. The terminal welcome appears only after a successful interactive install.

Nasiko: experimental, opt-in, and explicit

ECC 2.2 can inspect, install, and remove one pinned Nasiko v0.1.0 CLI build:

npm install -g ecc-universal@2.2.0
ecc nasiko status --json
ecc nasiko install --version v0.1.0 --dry-run --json
ecc nasiko install --version v0.1.0 --yes --json

Downloads are content-addressed and SHA-256 verified, status is read-only, and uninstall protects modified or unqualified binaries. The dashboard above is Nasiko's own product. ECC does not connect agents, start a server, enable telemetry, share data, or operate that control plane. The bridge remains experimental and opt-in.

Learn more in the Nasiko repository.

More reliable across every harness

  • Native Antigravity 2.0: ECC installs to .agents/{rules,workflows,skills,agents} and safely migrates legacy ownership.
  • Reliable uninstall: repeated selective installs keep a complete ownership ledger, so unchanged ECC-managed files can be removed cleanly.
  • Safer migrations: OpenCode uses ~/.config/opencode, while OpenCode and Codex preserve edited or untracked files during cleanup.
  • More workflows: Pi, Itô, agent evaluation, multi-model council, dev-team, living docs, secure terminal, TasteForge, and skill-comply all expand the shipped distribution.

ECC 2.2 ships 68 agents, 286 skills, and 94 command shims, plus the rules, hooks, memory, continuous-learning, and installation surfaces around them.

Release assurance

The tagged commit must match origin/main. One npm archive is packed, hashed, and tested on all three operating systems, then published under a staging tag. Registry integrity must match before latest moves. The prior 2.1.0 package remains the immediate rollback target.

Install or upgrade

For the native Claude Code plugin:

/plugin marketplace add https://github.com/affaan-m/ECC
/plugin install ecc@ecc

Existing Claude installs can run /plugin update ecc.
