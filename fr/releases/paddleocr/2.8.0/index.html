PaddleOCR v2.8.0

Highlights

  • Model zoo expands — Adds ParseQ (#10836, TIPC #10843), CPPD including the u14m variant (#10990, #11052), SVTR-large (#10937), and an exportable r45 ABinet config (#10892), alongside PP-OCRv4 act/det recipes (#11345, #11258). Real new architecture choices for recognition, but note ParseQ needed a follow-up net fix (#11126) — favor the corrected weights rather than the initial drop.

  • Tools spun out of the core repo — PPOCRLabel (#12104) and StyleText (#12121) were relocated to the PFCCLab organization. This is the release's genuine breaking change: any CI or script that pulls these from the PaddleOCR tree must repoint its URLs/imports, and existing labeling or style-transfer workflows will break on upgrade.

  • Packaging and dependency housekeeping — Build metadata moved from setup.py to pyproject.toml (#12013, #12520) with a PyPI publishing workflow added (#11804), making installs more predictable. Watch the transitive deps though: ppocr extras were trimmed (#11946), VisualDL made optional (#11947), pymupdf lazy-imported (#11692), and fonttools bumped to 4.43.0 for a security fix (#13091) — a likely source of environment drift when upgrading.

  • NumPy 2 / Python compatibility stabilized — The project temporarily pins numpy<2.0 (#13136), fixes the OpenCV import crash under NumPy 2 (#13105), and patches the removed np.int alias (#12249), plus Python 3.10/3.11 fixes (#11012, #11287) and Paddle 2.6 type-promotion adaptation (#11698). Little new API surface here; treat this as a compatibility-hardening release and align on a Paddle 2.6-aligned environment.

  • ONNX deployment path matured — onnxruntime gains GPU execution (#10668), layout analysis gains ONNX support (#12068), and a broken onnxruntime inference path was repaired (#13154). If you ship exported models instead of the Paddle runtime, these materially widen where v2.8.0 can run in production.

  • Inference behavior shifts — Large-image handling improved via sliding-window inference (#12152) and long-image prediction with deduplication of overlapping multi-label boxes (#11366); --savefile now writes per-image .txt results (#10628), layout returns a score (#13068), and wrong output under --det=False was fixed (#12589). Re-validate downstream parsers that assumed the old output shape. Separately, VQA was migrated to PaddleNLP's updated LayoutLM syntax (#9791), a breaking config change for KIE/VQA pipelines.
