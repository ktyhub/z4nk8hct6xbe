WeKnora v0.9.0

Highlights

  • Assistant becomes a privileged workspace control plane — The built-in assistant reads bundled documentation, opens with page context, and manages knowledge bases, FAQs, documents, agents, skills, and MCP services. Durable multi-agent collaboration adds live task views, while catalog restrictions, role-aware access, and unified grants/run modes constrain operations. Review permissions before exposing batch mutations or scheduled runs. (#4302, #4314, #4317, #4342, #4438, #4490)

  • Scheduled agents run through the assistant — Scheduled executions now include in-app notifications, improved task controls, enforced execution identity, cancellation, and scheduling limits. Existing workflows should be migrated to this execution path and audited for appropriate grants; invalid one-shot local times are rejected rather than silently scheduled. (#4492, #4506, #4514, #4522, #4551)

  • Sandbox and shell execution become first-class runtime features — Web and Lite gain async shell jobs and a shared background-work runtime. Shared-sandbox lifecycle support adds short-session directories and removes tool-layer directory restrictions, which changes isolation assumptions. Earlier allocation work was explicitly feature-gated, so verify your deployment’s gate state before enabling it. (#4507, #4509, #4510, #4533, #4579, #4580)

  • Connectors improve fidelity and recovery — Feishu/Lark gains folder mirroring, block parsing, and embedded objects; Notion stops advancing its cursor when attachments fail, preventing permanently skipped files. DingTalk can preserve source directories through a default-off option and validates only the selected scope, while Confluence supports personal access tokens. Recheck connector permissions and resumed-sync behavior. (#3497, #4413, #4421, #4422, #4549)

  • Parsing changes include an .xls compatibility break — Legacy binary .xls uploads are now rejected with an actionable error; convert existing files to .xlsx or CSV before upgrading (#4374). Image processing is now configurable, with bounded OCR preprocessing available opt-in (#3746, #4381). Excel percentage handling and HTML body-only indexing are also opt-in and default off, so enable them deliberately after regression-testing extracted content (#4423, #4424).

  • Search APIs and runtime safeguards are tighter — RRF is user-configurable, a standalone JSON graph-search API is available, MCP results preserve chunk types, and read_document pagination semantics are clarified (#4300, #4395, #4402, #4403). Response-body caps now protect IM, web-search, model, and MinerU paths; ambiguous MCP failures are no longer replayed, and SSE connection lifetime is separated from request timeouts. Expect oversized responses to fail cleanly, and review retry and proxy-timeout behavior (#4124, #4140, #4369, #4370, #4396, #4397, #4432).
