coredns v1.15.0

Cette version améliore la mise en cache DNS, le transfert et la fiabilité du transport, avec des correctifs pour la gestion des caches obsolètes, les connexions en amont, les correctifs de plantages/courses, ainsi que l'amélioration de nombreux plugins. Le transfert prend désormais en charge les amonts DNS sur QUIC. Les nouvelles fonctionnalités supplémentaires incluent Journalisation des requêtes JSON en option, mises à jour DNS dynamiques authentifiées RFC 2136, prise en charge SIIT, modèles expr-lang et métadonnées du protocole PROXY v2. La version est construite avec Go 1.27.3, couvrant CVE-2026-56865, CVE-2026-56864, CVE-2026-33818, CVE-2026-97032, CVE-2026-78659, CVE-2026-97031 et CVE-2026-111943, ainsi que d'autres correctifs de sécurité.

coredns v1.15.0

This release improves DNS caching, forwarding, and transport reliability, with fixes for stale-cache handling, upstream connections, crashes/race fixes, as well as enhancemence from quite a few plugins.

Forwarding now supports DNS-over-QUIC upstreams. Additional new features include optional JSON query logging, authenticated RFC 2136 dynamic DNS updates, SIIT support, expr-lang templates, and PROXY protocol v2 metadata.

The release is built with Go 1.27.3, covering CVE-2026-56865, CVE-2026-56864, CVE-2026-33818, CVE-2026-97032, CVE-2026-78659, CVE-2026-97031, and CVE-2026-111943, along with other security fixes.
