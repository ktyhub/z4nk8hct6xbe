codex rust-v0.171.0

Nouvelles fonctionnalités

  • Ajout de GPT-6.2 Sol et Astra aux catalogues de modèles, avec Sol comme sélection de catalogue par défaut. (#62106)
  • Activation de l'espace de travail TUI par défaut, avec des aperçus de documents consultables, des aperçus d'images et des transcriptions de sous-agents à côté de la conversation principale. (#61352, #61888, #61889, #61919, #62157)
  • Ajout de raccourcis d'annulation et de rétablissement configurables vers le compositeur d'invites non-Vim, y compris la restauration des pièces jointes et des collages volumineux. (#61954)
  • Ajout de codex exec --remote <ADDR> pour démarrer ou reprendre des sessions non interactives sur un serveur d'applications existant. (#61707)
  • Ajout de /rc et /remote pour gérer la télécommande locale et afficher les codes d'appairage des appareils à partir du TUI. (#62121)
  • Ajout d'une sélection et d'une création de ligne d'état MCP personnalisées via /statusline lorsque tui_extensions_statusline est activé. (#61979, #61988, #62037)

Corrections de bugs

  • Brouillons conservés, suivis en file d'attente et saisie interrompue avec leurs fils de discussion d'origine lors du changement ou de la reprise de sessions. (#61216)
  • Conservé les profils d'autorisation intacts lors du changement de répertoires de travail. (#61195)
  • Empêche les événements d'achèvement tardif d'annuler les approbations pour un tour plus récent. (#61801)
  • Modifications antérieures conservées dans les différences globales lors du pilotage d'un virage actif. (#61820)
  • Correction du défilement qui insérait des caractères parasites, des sauts de curseur du compositeur et des redessins en utilisant des dimensions de terminal obsolètes. (#62139, #62174, #62175)
  • Correction de la connexion MCP d'entreprise pour les fournisseurs d'identité qui émettent des jetons d'identification sans jetons d'actualisation. (#62129)

New Features

  • Added GPT-6.2 Sol and Astra to model catalogs, with Sol as the default catalog selection. (#62106)
  • Enabled the TUI workspace by default, with searchable document previews, image previews, and subagent transcripts alongside the main conversation. (#61352, #61888, #61889, #61919, #62157)
  • Added configurable undo and redo shortcuts to the non-Vim prompt composer, including restoration of attachments and large pastes. (#61954)
  • Added codex exec --remote <ADDR> to start or resume noninteractive sessions on an existing app server. (#61707)
  • Added /rc and /remote to manage local remote control and display device pairing codes from the TUI. (#62121)
  • Added custom MCP status line selection and authoring through /statusline when tui_extensions_statusline is enabled. (#61979, #61988, #62037)

Bug Fixes

  • Preserved drafts, queued follow-ups, and interrupted input with their original threads when switching or resuming sessions. (#61216)
  • Kept permission profiles intact when changing working directories. (#61195)
  • Prevented late completion events from cancelling approvals for a newer turn. (#61801)
  • Preserved earlier edits in aggregate diffs when steering an active turn. (#61820)
  • Fixed scrolling that inserted stray characters, composer caret jumps, and redraws using stale terminal dimensions. (#62139, #62174, #62175)
  • Fixed enterprise MCP sign-in for identity providers that issue ID tokens without refresh tokens. (#62129)

Chores

  • Updated source builds and release tooling to Rust 1.99.1. (#61205)
  • Updated XML dependencies and removed obsolete security advisory exceptions. (#62068)
