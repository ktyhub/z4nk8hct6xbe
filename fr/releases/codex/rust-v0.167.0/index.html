codex rust-v0.167.0

Nouvelles fonctionnalités

  • Ouvrez le centre de commande de l'agent avec codex agents --no-daemon. Le centre de commande et le sélecteur de session marquent désormais les résultats non lus (#58238, #58239, #58263, #58264).
  • Basculez entre les backends connectés à partir du sélecteur de session du terminal et conservez vos brouillons lors du changement (#58280, #58457).
  • Prévisualisez les pièces jointes d'images locales lors de la composition sur les terminaux pris en charge et ouvrez les images locales visualisées à partir des chemins de transcription clickable (#58261, #58446).
  • Recherchez les options de clé API et de fournisseur de cloud sous « Se connecter d'une autre manière ». Activez gcp_setup_wizard pour configurer Google Cloud Vertex AI avec les informations d'identification par défaut de l'application ou un fichier d'informations d'identification (#57857, #58427).
  • Activez les paramètres de proxy système macOS ou Windows à partir de /experimental (#58157).
  • Développez les détails du correctif directement dans la transcription lorsqu'une invite d'approbation est ouverte (#58281).

Corrections de bugs

  • Les discussions enregistrées restent visibles après avoir changé de fournisseur de modèle. Si une discussion ne peut pas reprendre, vous pouvez lire sa transcription et préparer une invite modifiable pour continuer dans une nouvelle discussion (#58202).
  • Ctrl+L efface l'affichage du terminal tout en gardant les messages précédents disponibles via Ctrl+T (#58266).
  • La suppression du texte qui expose un ! en tête conserve un brouillon ordinaire en mode chat (#58412).
  • Les invites d'approbation du réseau se ferment à la fin de leurs demandes. Demandes simultanées adressées au même point de terminaison, une à la fois (#58350, #58351).
  • Les longues conversations V3 en temps réel enregistrent les paroles terminées dans l'historique des discussions à mesure que la transcription s'agrandit (#58221).
  • Le compactage automatique du contexte prend désormais en compte les sorties conservées des réponses ayant échoué et des réponses avec des données d'utilisation de jeton manquantes (#58404). ##Documents
  • Le fichier README du serveur d'applications couvre les contraintes du réseau géré selon les règles de commande [permissions.network] et prompt-user qui nécessitent une nouvelle approbation humaine (#58045, #58182).
  • La compétence openai-docs recommande le remplacement documenté lors de la migration à partir d'un modèle obsolète (#58134).

codex rust-v0.167.0

New Features

  • Open the agent command center with codex agents --no-daemon. The command center and session picker now mark unread results (#58238, #58239, #58263, #58264).
  • Switch between connected backends from the terminal session picker and keep your drafts when switching (#58280, #58457).
  • Preview local image attachments while composing on supported terminals, and open viewed local images from clickable transcript paths (#58261, #58446).
  • Find API key and cloud provider options under “Sign in another way.” Enable gcp_setup_wizard to set up Google Cloud Vertex AI with Application Default Credentials or a credential file (#57857, #58427).
  • Opt into macOS or Windows system proxy settings from /experimental (#58157).
  • Expand patch details directly in the transcript while an approval prompt is open (#58281).

Bug Fixes

  • Saved chats stay visible after you switch model providers. If a chat can’t resume, you can read its transcript and prepare an editable prompt to continue in a new chat (#58202).
  • Ctrl+L clears the terminal display while keeping earlier messages available through Ctrl+T (#58266).
  • Deleting text that exposes a leading ! keeps an ordinary draft in chat mode (#58412).
  • Network approval prompts close when their requests end. Concurrent requests to the same endpoint prompt one at a time (#58350, #58351).
  • Long realtime V3 conversations save completed speech to chat history as the transcript grows (#58221).
  • Automatic context compaction now accounts for retained output from failed responses and responses with missing token usage data (#58404).

Documentation

  • The app-server README covers managed network constraints under [permissions.network] and prompt-user command rules that require fresh human approval (#58045, #58182).
  • The openai-docs skill recommends the documented replacement when migrating away from a deprecated model (#58134).

Chores

  • DotSlash manifests now reference the Cargo packages shipped with the release (#58717, #58757).
  • Linux musl builds use fewer allocator arenas to reduce idle memory after conversations unload (#58399).
