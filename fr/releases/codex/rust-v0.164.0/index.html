Nouvelles fonctionnalités

  • Enregistrez des invites et des commandes slash réutilisables dans dix emplacements /presets numérotés, avec un menu clavier pour un accès rapide. (#54380, #54381)
  • Définissez les profils de modèle, d'effort de raisonnement, de vitesse et d'autorisation directement avec les arguments /model et /permissions en ligne. (#54378, #54383)
  • Prévisualisez les images visualisées et générées dans la transcription plein écran sur les terminaux prenant en charge les graphiques Kitty ou Sixel. (#54216)
  • Authentifiez les connexions MCP d'entreprise à l'aide d'autorisations de compte Codex éligibles ou d'une connexion dédiée, y compris les OAuth clients nécessitant des secrets. (#55334, #55859, #56001)
  • Masquez les informations d'identification lors des commandes Bash à distance prises en charge et des sessions d'instantanés Zsh, y compris les informations d'identification des fournisseurs personnalisés. (#54309, #54432, #56049)
  • L'assistant de configuration d'Amazon Bedrock est désormais activé par défaut, avec l'entrée de clé API regroupée avec d'autres méthodes de connexion AWS lorsque les informations d'identification sont détectées. (#56033, #56023)

Corrections de bugs

  • Les échecs de compactage ne laissent plus de résumés partiels dans l'historique des conversations, et les échecs de compactage en arrière-plan retombent sans paniquer. (#53932, #55581)
  • La reprise des sessions recherche désormais les historiques compressés et restaure les paramètres de thread enregistrés au lieu de les remplacer par les valeurs par défaut globales. (#54008, #55923)
  • Les connexions Windows HTTPS et WebSocket gèrent désormais les défis d'authentification du proxy à l'aide des informations d'identification Négocier ou NTLM de l'utilisateur connecté. (#55994, #56000)
  • Les remplacements de configuration CLI sont conservés lorsque -c ou --config apparaît à plusieurs niveaux de sous-commandes. (#56022)
  • Les invites en file d'attente attendent désormais la résolution des sélections d'autorisations en attente avant de continuer. (#55682)
  • Le bac à sable renforcé vérifie les chemins de métadonnées des variantes de cas sur macOS et les liens symboliques remplaçables utilisés pour localiser les exécutables. (#54273, #55384)

codex rust-v0.164.0

New Features

  • Save reusable prompts and slash commands in ten numbered /presets slots, with a keyboard menu for quick access. (#54380, #54381)
  • Set model, reasoning effort, speed, and permission profiles directly with inline /model and /permissions arguments. (#54378, #54383)
  • Preview viewed and generated images in the fullscreen transcript on terminals supporting Kitty or Sixel graphics. (#54216)
  • Authenticate enterprise MCP connections using eligible Codex account grants or dedicated sign-in, including OAuth clients requiring secrets. (#55334, #55859, #56001)
  • Mask credentials during supported remote Bash commands and Zsh snapshot sessions, including credentials from custom providers. (#54309, #54432, #56049)
  • The Amazon Bedrock setup wizard is now enabled by default, with API key entry grouped alongside other AWS sign-in methods when credentials are detected. (#56033, #56023)

Bug Fixes

  • Failed compaction no longer leaves partial summaries in conversation history, and background compaction failures fall back without panicking. (#53932, #55581)
  • Resuming sessions now finds compressed histories and restores saved thread settings instead of replacing them with global defaults. (#54008, #55923)
  • Windows HTTPS and WebSocket connections now handle proxy authentication challenges using the signed-in user’s Negotiate or NTLM credentials. (#55994, #56000)
  • CLI configuration overrides are preserved when -c or --config appears at multiple subcommand levels. (#56022)
  • Queued prompts now wait for pending permission selections to resolve before continuing. (#55682)
  • Hardened sandbox checks for case-variant metadata paths on macOS and replaceable symlinks used to locate executables. (#54273, #55384)

Chores

  • Reduced disk usage by pruning unused installations, cleaning abandoned marketplace checkouts, and bounding daemon logs. (#53827, #55149, #55689, #55690, #55856)
  • Updated the embedded JavaScript runtime with safety checks for optimized Array.sort operations. (#54519)
