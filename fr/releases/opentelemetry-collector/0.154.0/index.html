Utilisateur final Changelog

🛑 Changements récents 🛑

  • cmd/builder : Le flag --skip-get-modules ne régénérera plus votre fichier go.mod. (#15390) Il s'agit principalement d'une correction de bug, car elle a conduit à un comportement indésirable qui n'était pas intentionnel dans le flux décrit dans le README. Désormais, lorsque vous exécutez --skip-get-modules, votre fichier go.mod ne sera véritablement pas touché par ocb, comme le prétend le journal d'informations.

💡 Améliorations 💡

  • pkg/config/configtls : ajoutez include_insecure_cipher_suites aux configurations pour activer les suites de chiffrement non sécurisées. Les suites de chiffrement non sécurisées sont désactivées par défaut pour des raisons de sécurité. (#13829)
  • pkg/confighttp : ajoutez le champ ExposedHeaders à CORSConfig pour permettre la définition de l'en-tête de réponse Access-Control-Expose-Headers. (#15119)

🧰 Corrections de bugs 🧰

  • cmd/mdatagen : Supprime la ligne supplémentaire dans le README.md entre le statut et la description (#15306)
  • pkg/exporterhelper : Correction de la panique du pointeur nul dans sending_queue::batch Unmarshal lorsque sending_queue::sizer est défini et que sending_queue::batch::enabled est faux. (#14687) Lorsque sending_queue::sizer a été réglé et sending_queue::batch::enabled: false effacé le lot Facultatif à Aucun, la branche sizer-inheritance dans queuebatch.Config.Unmarshal a déréférencé un nil Facultatif et a fait planter le collecteur au démarrage. La branche nécessite désormais également Batch.HasValue().

opentelemetry-collector v0.154.0

Images and binaries here: https://github.com/open-telemetry/opentelemetry-collector-releases/releases/tag/v0.154.0

End User Changelog

🛑 Breaking changes 🛑

  • cmd/builder: The --skip-get-modules flag will no longer regenerate your go.mod file. (#15390) This is mostly a bug fix, as it led to adverse behaviour that was unintended in the described flow in the README. Now when you run --skip-get-modules, your go.mod file will truly be untouched by ocb as the info log claims.

💡 Enhancements 💡

  • pkg/config/configtls: Add include_insecure_cipher_suites to configtls to enable insecure cipher suites. Insecure cipher suites are disabled by default for security. (#13829)
  • pkg/confighttp: Add ExposedHeaders field to CORSConfig to allow setting the Access-Control-Expose-Headers response header. (#15119)

🧰 Bug fixes 🧰

  • cmd/mdatagen: Removes the extra line in the README.md between status and description (#15306)
  • pkg/exporterhelper: Fix nil-pointer panic in sending_queue::batch Unmarshal when sending_queue::sizer is set and sending_queue::batch::enabled is false. (#14687) When sending_queue::sizer was set and sending_queue::batch::enabled: false cleared the batch Optional to None, the sizer-inheritance branch in queuebatch.Config.Unmarshal dereferenced a nil Optional and crashed the collector at startup. The branch now also requires Batch.HasValue().

API Changelog

💡 Enhancements 💡

  • cmd/mdatagen: Handle numeric validators in generated config structs (#14806) Supported validators include minimum, maximum, exclusiveMinimum and exclusiveMaximum.
  • pkg/config/configtls: Add include_insecure_cipher_suites to configtls to enable insecure cipher suites. Insecure cipher suites are disabled by default for security. (#13829)
  • pkg/confighttp: Add ExposedHeaders field to CORSConfig to allow setting the Access-Control-Expose-Headers response header. (#15119)
