ChatGPTNextWeb v2.15.3

Highlights

  • Model selection respects saved configuration — Selector and customization improvements (#5428, #5431, #5426) are paired with a hydration fix (#5444) addressing selections being forced back to gpt-3.5-turbo; recheck your default and custom models after upgrading.
  • Conversation titles can be regenerated safely — Manual title regeneration (#5430) gives users control over auto-generated titles, while #5522 prevents invalid assistant responses from overwriting an existing title.
  • Speech and media playback are built in — Text-to-speech (#5459) and audio/video playback (#5519) expand interaction beyond text; test these paths with your configured providers and deployed content.
  • Plugins and function calling are more reliable — Bundled plugins (#5508) reduce setup work, styling fixes (#5498) address plugin UI issues, and #5489 repairs OpenAI function-call handling; verify existing plugins and tool schemas before rollout.
  • Provider compatibility fixes reduce request failures — #5435 addresses CORS around Anthropic authentication_error responses, while #5304 fixes a missing-max_tokens edge case for vision models with nonstandard names—particularly relevant to custom endpoints and aliases.
  • WebDAV configuration rename requires migration — Replace the misspelled WHITE_WEBDEV_ENDPOINTS with WHITE_WEBDAV_ENDPOINTS and redeploy (#5463). Separately, #5462 removes the server-side prompts.json fetch, reducing SSR/build-time network dependencies.
