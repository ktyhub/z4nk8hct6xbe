écraser v0.87.0

MCP OAuth, performances et plus

Bon vendredi à tous ! Nous publions quelques fonctionnalités intéressantes pour que vous puissiez profiter de votre vibecoding du week-end. (Ou pas, restez dehors :sun_with_face: et revenez à Crush lundi ! :smiley:).

MCP OAuth

Ça y est, il est enfin là ! Certains d’entre vous le demandent depuis longtemps. Ceci est nécessaire pour que certains MCP fonctionnent. Vous voulez savoir comment le configurer ? [Reportez-vous à cette section dans le README] (https://github.com/charmbracelet/crush#mcp-oauth). Merci @joestump et son agent @joestump-agent pour cette contribution. Et bien sûr, notre @taciturnaxolotl préféré a également aidé.

Extension MCP des chaînes Claude

@joestump (et son agent) également ont ajouté une implémentation initiale pour prendre en charge l'[extension Claude Channels MCP] (https://code.claude.com/docs/en/channels-reference), ce qui signifie que les MCP peuvent désormais envoyer des notifications à Crush lorsque certains événements se produisent. Essayez ceci si vous êtes intéressé et dites-nous si cela fonctionne pour vous.

Invites MCP restaurées

Les invites MCP ont été involontairement désactivées dans une version précédente, mais elles ont maintenant été rajoutées !

Amélioration des performances du LSP

Une autre contribution intéressante a été faite par @TheJhyeFactor, qui a considérablement amélioré l'utilisation du processeur et de la mémoire lors de la gestion des serveurs LSP dans de grands référentiels ! Voir #3370 pour une explication plus approfondie des optimisations.

Amélioration des performances du mode Bang

@TheJhyeFactor a également amélioré les performances du streaming de sortie lors de l'exécution d'une commande en mode bang. Vérifiez # 3381 pour voir des analyses comparatives. ##/etc/crush/crush.json Vous avez bien lu ! Grâce à @Muttaqin86, vous pouvez désormais disposer d'une configuration Crush à l'échelle du système sur /etc/crush/crush.json. La motivation était d’améliorer la compatibilité avec NixOS.

Copilote fixe + GPT-5.6

Les trois modèles GPT-5.6 (Sol, Terra et Luna) sont désormais corrigés lors de l'exécution via GitHub Copilot. Félicitations à @nghiant03 pour cela ! C'était beaucoup, mais c'est vraiment amusant de voir à quel point la communauté est impliquée dans le développement de Crush. Continuez à écraser ! :tm: Charme ##Changelog

crush v0.87.0

MCP OAuth, performance and more

Happy Friday everybody!

We're releasing some nice features for you so you can enjoy your weekend vibecoding. (Or not, stay outside :sun_with_face: and return to Crush on Monday! :smiley:).

MCP OAuth

That's it, it's finally here! Some of you have been asking for this for long.

This is required for some MCPs to work. Want to know to it set it up? Refer to this section into the README.

Thank @joestump and his agent @joestump-agent for this contribution. And of course, our favorite @taciturnaxolotl also helped.

Claude Channels MCP extension

@joestump (and his agent) also added an initial implementation to support the Claude Channels MCP extension, which means MCPs can now send notifications to Crush when certain events happen.

Give this a try if you're interested, and let us know how well it works for you.

Restored MCP prompts

MCP prompts were unintentionally disabled in a previous release, but they were now added back!

LSP performance boost

Another cool contrib was made by @TheJhyeFactor, who vastly improved the CPU and memory usage on handling LSP servers in large repositories!

See #3370 for a more in-depth explanation of the optimizations.

Bang mode performance boost

@TheJhyeFactor also improved performance of output streaming when running command in bang mode.

Check #3381 to see some benchmarking.

/etc/crush/crush.json

You read it right! Thank to @Muttaqin86 you can now have a system-wide Crush configuration on /etc/crush/crush.json.

The motivation for this was improving compatibility with NixOS.

Fixed Copilot + GPT-5.6

All three GPT-5.6 models (Sol, Terra and Luna) are now fixed when running via GitHub Copilot. Kudos to @nghiant03 for this!

That was a lot, but it's really fun to how much the community is enganged with Crush dev.

Keep Crushing! :tm: Charm
