cherry-studio v1.7.0

Highlights

  • Agents and local API service — The agent implementation (#10096) now includes automatic database migrations (#10215), dedicated settings and session controls (#10668, #10773), and automatic API-server startup when agents exist (#10772). This removes manual service setup, but existing installations should back up agent data before upgrading and verify migrated agents and default models afterward.
  • Provider and model coverage — New integrations include Mistral (#10795), Hugging Face (#10966), NewAPI (#10696), Ling (#10863), and Intel OVMS with NPU OCR (#10570, #10737). Claude Haiku 4.5, GPT-5-Codex, Gemini 2.5 Image Flash, and MiniMax-M2 receive dedicated support or fixes (#10800, #10587, #10781, #10683, #10962), reducing provider-specific configuration and streaming failures.
  • Sampling and API-key behavior — Top-P now defaults to disabled in assistant settings (#10754), so prompts that previously relied on it may need explicit re-enabling. API keys now preserve spaces, with commas or newlines separating multiple keys (#10751), and keys rotate per request (#10776); reformat padded or space-separated key lists accordingly.
  • Knowledge and RAG reliability — Knowledge-base deletion and web-search failures are fixed (#10595), knowledge tool choice is supported (#10763), and citations guard against missing arrays (#10778). Removing the web-search RAG LRU path (#10631) should improve problematic retrieval flows, but may change caching and reuse behavior; benchmark repeated searches if latency matters.
  • Notes and mini apps — Notes gain image export (#10559), full-text search (#10640), and right-click creation (#10523). Mini apps gain search (#10609), reliable Cmd/Ctrl+F handling (#10641, #10783), and external-browser links under tab navigation (#10669), making them more practical for large archives and keyboard-driven workflows.
  • Runtime and integration surface — React moves to 19.2.0 (#10710), Electron to 38 (#10884), and AI SDK dependencies are refreshed (#10643). OpenAI imports migrate to @cherrystudio/openai (#10802), while MCPToolResponse is replaced by NormalToolResponse (#10303); custom code coupled to these internals should be updated or revalidated.
  • Breaking changes — None are listed.
