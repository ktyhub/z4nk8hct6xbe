<summary>Release Note</summary> Cherry Studio 2.1.7 - Mises à jour de la voix, du cloud et du modèle ✨ Nouvelles fonctionnalités - [Voix] Ajoutez Kokoro chinois-anglais TTS avec 103 voix pour Windows x64, Linux et macOS, et Qwen3-TTS pour Apple Silicon. Téléchargez des modèles depuis Paramètres > Modèles locaux avant la première utilisation. - [Voix] Afficher les spectres audio en direct dans la lecture vocale et les commandes de dictée. Restaurez le microphone après une dictée vide. - [Voix] Ajoutez une transcription vocale FunASR locale sur Windows, Linux et macOS. - [Cherry Cloud] Ajoutez un plan d'abonnement et une visibilité sur l'utilisation des quotas à l'édition globale, avec des descriptions de quotas gratuits et épuisés à durée limitée pour les modèles gérés. - [Cherry Cloud] Ajoutez un menu de compte compact ancré dans la barre latérale. L'avatar et le surnom ouvrent les paramètres d'informations personnelles ; L'apparence et la connexion restent dans le menu. - [Cherry Cloud] Préserver la connexion lors d'échecs de connexion temporaire ou d'actualisation. - [Automation] Orchestrez l'utilisation du navigateur et de l'ordinateur via un JavaScript persistant avec un retour d'exécution plus clair. - [Base de connaissances] Faites glisser les bases de connaissances entre les groupes et réorganisez les groupes ; parcourir les colonnes d’éléments dans l’ordre croissant, décroissant et par défaut. - [Image] Ajoutez des préréglages de format d'image GPT-Image-2 pour une sortie 16:9, 9:16, 16:10 et 4K. - [Modèles] Ajoutez la prise en charge de Gemini 4 Argon avec des niveaux de réflexion et une continuation automatique des sorties longues. - [Modèles] Ajoutez la reconnaissance de modèles Muse Spark Open avec des capacités multimodales et des contrôles de raisonnement. - [Recherche] Ajoutez DuckDuckGo en tant que fournisseur de recherche Web par mots clés gratuit. Aucune clé API requise. - [Outils] Les résultats de l'outil prévisualisent désormais les liens d'image et affichent les liens Web clickable. - [Erreurs] Afficher des notifications d'erreur exploitables avec des diagnostics lisibles, des détails extensibles et des actions de récupération pour les conversations, les vérifications des fournisseurs et les échecs MCP. - [Chat] Les messages de suivi en file d'attente commencent à être réduits. CliCochez l'en-tête pour développer ou réduire. - [Chat] Passez la souris sur les conversations pour voir le nom complet, la durée de l'activité et les détails de l'espace de travail. - [Notes] Recherchez les langues à blocs de code par nom. 🐛 Corrections de bugs - [Pièces jointes] Correction des fichiers texte à extension non reconnue (par exemple, .lrmx) qui ne sont pas lus comme du texte. - [OCR] Identifiez quel chemin OCR a échoué lors de l'envoi d'images à des modèles sans vision, avec des conseils pour chaque type d'échec. - [Fenêtre] Correction de la fermeture de la fenêtre principale sous Windows/Linux masquant la fenêtre lorsque l'icône de la barre d'état n'est pas disponible, ne laissant aucun moyen de restaurer ou de quitter. - [Messages] Préservez l'état de divulgation et suivez le raisonnement diffusé dans l'affichage des messages. - [Compositeur] Suivez automatiquement la direction du texte d'invite ; conserver les noms de fichiers avec un point de début ; accepter n’importe quel type de fichier sur la surface de l’agent. - [Fichiers] Ajouter des actions de menu contextuel de fichier ; alignez les liens de fichiers et les icônes avec le texte en ligne. - [MCP] Connectez-vous aux serveurs MCP distants qui rejettent la sonde de version avec des erreurs 5xx ; confirmer l’état de santé avant de se reconnecter. - [Modèles] Accepter les jetons de pagination de liste de modèles Gemini nuls ; améliorer la découverte du modèle Gemini et l'actualisation des métadonnées. -[Tray] Utilisez un GUID de barre d'état Windows stable pour les installations portables. - [Voix] Correction du texte sautant à haute voix dans les blocs de code et le code en ligne. - [Agents] Autoriser les utilisateurs à désactiver l'intégration via la configuration declining. - [Traduction] Conservez les boutons de dictée et de copie inactifs à côté du texte saisi sans ajouter de ligne de barre d'outils supplémentaire. - [Utilisation de l'ordinateur] Correction de la sortie manquante de l'outil d'automatisation pour les agents Claude et ajout d'une pagination structurée de l'arborescence d'accessibilité pour empêcher l'omission d'observations surdimensionnées. - [Paramètres] Restaurez les barres de défilement des paramètres et les mises en page cohérentes, clarifiez les actions d'autorisation d'utilisation de l'ordinateur et corrigez le Cherry Studio 2.1.7 - Voice, Cloud, and Model Updates

✨ New Features

  • [Voice] Add Kokoro Chinese-English TTS with 103 voices for Windows x64, Linux and macOS, and Qwen3-TTS for Apple Silicon. Download models from Settings > Local Models before first use.
  • [Voice] Show live audio spectra in speech playback and dictation controls. Restore the microphone after empty dictation.
  • [Voice] Add local FunASR speech transcription on Windows, Linux and macOS.
  • [Cherry Cloud] Add subscription plan and quota usage visibility to the Global edition, with limited-time-free and exhausted-quota descriptions for managed models.
  • [Cherry Cloud] Add a compact anchored sidebar account menu. Avatar and nickname open Personal Information settings; Appearance and Login stay in the menu.
  • [Cherry Cloud] Preserve login during temporary connection or refresh failures.
  • [Automation] Orchestrate Browser and Computer Use through persistent JavaScript with clearer execution feedback.
  • [Knowledge Base] Drag knowledge bases between groups and reorder groups; cycle item columns through ascending, descending and default ordering.
  • [Image] Add GPT-Image-2 aspect ratio presets for 16:9, 9:16, 16:10, and 4K output.
  • [Models] Add Gemini 4 Argon support with thinking levels and automatic long-output continuation.
  • [Models] Add Muse Spark Open model recognition with multimodal capabilities and reasoning controls.
  • [Search] Add DuckDuckGo as a free keyword web search provider. No API key required.
  • [Tools] Tool results now preview image links and display clickable web links.
  • [Errors] Show actionable error notifications with readable diagnoses, expandable details, and recovery actions for conversations, provider checks, and MCP failures.
  • [Chat] Queued follow-up messages start collapsed. Click the header to expand or collapse.
  • [Chat] Hover over conversations to see full name, activity time, and workspace details.
  • [Notes] Search code-block languages by name.

🐛 Bug Fixes

  • [Attachments] Fix unrecognized-extension text files (e.g., .lrmx) not being read as text.
  • [OCR] Identify which OCR path failed when sending images to non-vision models, with guidance for each failure type.
  • [Window] Fix main window closing on Windows/Linux hiding the window when the tray icon is unavailable, leaving no way to restore or quit.
  • [Messages] Preserve disclosure state and follow streamed reasoning in message display.
  • [Composer] Automatically follow prompt text direction; keep leading-dot file names; accept any file type on the agent surface.
  • [Files] Add file context menu actions; align file links and icons with inline text.
  • [MCP] Connect to remote MCP servers that reject the version probe with 5xx errors; confirm health before reconnects.
  • [Models] Accept null Gemini model list pagination tokens; improve Gemini model discovery and metadata refresh.
  • [Tray] Use a stable Windows tray GUID for portable installs.
  • [Voice] Fixed read-aloud skipping text in code blocks and inline code.
  • [Agents] Allow users to turn off onboarding by declining setup.
  • [Translation] Keep idle dictation and copy buttons beside the input text without adding an extra toolbar row.
  • [Computer Use] Fixed missing automation tool output for Claude agents and added structured accessibility-tree pagination to prevent oversized observations from being omitted.
  • [Settings] Restore settings scrollbars and consistent layouts, clarify Computer Use permission actions, and fix clipped content, MCP tab order and unnecessary Usage heatmap overflow.
