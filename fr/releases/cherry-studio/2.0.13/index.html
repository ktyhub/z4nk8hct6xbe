<summary>Anglais</summary> Cherry Studio 2.0.13 - Nouvelles fonctionnalités, correctifs et améliorations ✨ Nouvelles fonctionnalités - [Modèles] Ajoutez la prise en charge de GPT-6 Astra avec des limites de contexte, des contrôles de raisonnement, un mode rapide, une recherche Web native, une tarification échelonnée et l'icône officielle du modèle. - [Modèles] Ajoutez TokenDance en tant que fournisseur de modèles intégré avec autorisation de clé API basée sur un navigateur. - [Tâches planifiées] Les préréglages quotidiens, hebdomadaires et hebdomadaires prennent désormais en charge plusieurs fois par jour (par exemple 09h00 et 18h00). - [Chat] Affichez les titres des sujets et des sessions, changez de branche depuis l'en-tête et exportez les branches individuelles au format Markdown. - [Compétences] Ajoutez des filtres de source de compétences installées et un commutateur de disposition à une/double colonne dans les paramètres de compétences. - [Panneau rapide] Les actions de gestion restent désormais dans un pied de page accessible dans les invites, les compétences, le MCP, les notes, la base de connaissances et la personnalisation de la barre d'outils. - [Composer] Ajoutez un raccourci configurable Ctrl+I / Cmd+I pour concentrer la saisie. - [Exportation d'images] L'exportation d'images de messages utilise désormais le compositeur de Chromium pour une sortie au pixel près correspondant à ce que vous voyez à l'écran. - [Traduire] Rendu de la sortie en streaming avec un formatage Markdown riche. 🐛 Corrections de bugs - [Modèles] Correction des fournisseurs de modèles personnalisés qui rejettent les en-têtes d'attribution automatique de Cherry Studio. - [Modèles] Correction des requêtes Moonshot Kimi K2.5+ qui échouent lorsque les paramètres d'échantillonnage personnalisés sont activés. - [Modèles] Correction des requêtes Kimi K3 qui échouaient lorsqu'un effort de raisonnement non pris en charge était sélectionné. - [Modèles] Retrait du fournisseur Yi (01.AI) suite à l'arrêt de son service. - [Modèles] Les profils migrés depuis la v1 conservent désormais l'accès à tous les fournisseurs et modèles, quelle que soit l'édition installée. - [Chat] Correction d'un sujet échouant définitivement avec une erreur 400 après un appel d'outil lorsque le fournisseur renvoie un identifiant d'élément non standard. - [Chat] Correction du basculement entre les réponses multi-modèles pendant qu'une réponse est en streaming. - [Chat] Correction des erreurs normales d'authentification du chat qui ne parvenaient pas à établir un lien avec les paramètres du fournisseur après des tentatives automatiques. - [Chat] Les citations de recherche Web natives renvoyées par les fournisseurs sont désormais affichées dans les réponses du chat. - [Chat] Les sessions d'agent terminées affichent désormais l'utilisation de jetons indisponibles au lieu d'un zéro trompeur. - [Chat] Les échecs d'authentification du certificat de l'agent client affichent désormais des conseils de récupération proxy et SSL. - [Chat] Les échecs de connexion à Claude Code Agent sont désormais liés aux paramètres du fournisseur nécessaires à la récupération. - [Chat] Ajouter une action de récupération des paramètres du fournisseur aux erreurs HTTP 400 génériques. - [Chat] Correction du routage des citations de messages vers la mauvaise fenêtre. - [Tâches planifiées] Correction du journal d'exécution des tâches qui perdait son lien « afficher la session » lorsqu'une exécution planifiée d'un agent échouait, expirait ou était annulée. - [Agent] Correction des agents sans tâches disparaissant de la liste des agents lorsque les sessions sont affichées à droite. - [Agent] Correction des échecs de l'outil Bash étiquetés comme des erreurs au lieu de la sortie de la commande. - [Agent] Correction des appels d'outils afin que les arguments réparés et rejoués conservent leur forme JSON attendue. - [Agent] Restaurez la protection contre les boucles de répétition de commandes de Claude Code lorsque RTK réécrit les commandes Bash. - [Agent] Empêche les agents de modifier les fichiers SQLite de données utilisateur de Cherry Studio via des outils natifs. - Les échecs du processus [Agent] Claude Code affichent désormais une cause exploitable et une référence de diagnostic. - [Agent] L'indicateur d'utilisation du contexte avance désormais en direct pendant une tâche au lieu de seulement à la fin. - [DeepSeek] Les sessions Web DeepSeek Harness démarrent désormais correctement lorsque le runtime nécessite son URL authentifiée par jeton. - [Pi] Reprendre les tâches Pi après des réponses de longueur limitées par le contexte avec une tentative de compactage et de nouvelle tentative limitée. - [OpenCode] Les titres de conversation automatiques OpenCode Go préservent désormais l'identité de la session. - [Contexte] Correction du sélecteur de modèle de compression de contexte afin que les utilisateurs puissent revenir à « Suivre le modèle actuel ». - [Paramètres] Correction de la liste des modèles de fournisseur gelant l'application lorsqu'un fournisseur dispose de plusieurs modèles. - [Paramètres] Correction des paramètres de l'Assistant interrompant la sauvegarde automatique avec des valeurs de jetons Max non sécurisées. - [Paramètres] L'intégration de l'édition chinoise utilise désormais à nouveau la connexion CherryIN par défaut. - [Paramètres] AMD GPU Cloud n'affiche plus les messages promotionnels « gratuits » ou de crédit quotidien. - [Quick Assistant] Correction des actions rapides de sélection intégrées pour appeler les outils MCP lorsqu'un quickAssistant avec MCP est configuré. - [Traduire] Correction du bouton de copie affichant ses commentaires sur le mauvais volet. - [Traduire] de fichier de sauvegarde » trompeuse lors de la restauration d'une sauvegarde créée par une version plus récente. - [Sauvegarde] Correction de la sauvegarde, de la restauration, de la gestion et du autre proxy. - [Mini applications] Correction de la recherche de mini applications qui ne parvenait pas à trouver les applications par leurs noms d'affichage traduits. - [Mini applications] Supprimez les info-bulles des clés d'autorisation brutes qui affichaient des chaînes non traduites. - [Notes] Correction des champs de note et de renommage de dossier se fermant avant que les utilisateurs Cherry Studio 2.0.13 - New Features, Fixes, and Improvements

✨ New Features

  • [Models] Add GPT-6 Astra support with context limits, reasoning controls, Fast mode, native web search, tiered pricing, and the official model icon.
  • [Models] Add TokenDance as a built-in model provider with browser-based API key authorization.
  • [Scheduled Tasks] Daily, weekdays, and weekly presets now support multiple times per day (e.g. 09:00 and 18:00).
  • [Chat] Show topic and session titles, switch branches from the header, and export individual branches as Markdown.
  • [Skills] Add installed-skill source filters and a single/double-column layout switch in Skills settings.
  • [Quick Panel] Management actions now stay in an accessible footer across prompts, skills, MCP, Notes, Knowledge Base, and toolbar customization.
  • [Composer] Add a configurable Ctrl+I / Cmd+I shortcut to focus the input.
  • [Image Export] Message image export now uses Chromium's compositor for pixel-perfect output matching what you see on screen.
  • [Translate] Render streamed output with rich Markdown formatting.

🐛 Bug Fixes

  • [Models] Fix custom model providers that reject Cherry Studio's automatic attribution headers.
  • [Models] Fix Moonshot Kimi K2.5+ requests failing when custom sampling settings are enabled.
  • [Models] Fix Kimi K3 requests failing when an unsupported reasoning effort was selected.
  • [Models] Retired the Yi (01.AI) provider following its service shutdown.
  • [Models] Profiles migrated from v1 now retain access to all providers and models regardless of the installed edition.
  • [Chat] Fix a topic permanently failing with a 400 error after a tool call when the provider returns a non-standard item id.
  • [Chat] Fix switching between multi-model answers while a response is streaming.
  • [Chat] Fix normal chat authentication errors failing to link to provider settings after automatic retries.
  • [Chat] Native web search citations returned by providers are now displayed in chat responses.
  • [Chat] Completed Agent sessions now show unavailable token usage instead of a misleading zero.
  • [Chat] Agent client-certificate authentication failures now show proxy and SSL recovery guidance.
  • [Chat] Claude Code Agent sign-in failures now link to the provider settings needed for recovery.
  • [Chat] Add a provider settings recovery action to generic HTTP 400 errors.
  • [Chat] Fix message quotes routing to the wrong window.
  • [Scheduled Tasks] Fixed the task run log losing its “view session” link when a scheduled agent run failed, timed out, or was cancelled.
  • [Agent] Fix taskless agents disappearing from the agent list when sessions are displayed on the right.
  • [Agent] Fix Bash tool failures labeled as errors instead of command output.
  • [Agent] Fix tool calls so repaired and replayed arguments keep their expected JSON shape.
  • [Agent] Restore Claude Code's repeat-command loop guard when RTK rewrites Bash commands.
  • [Agent] Prevent agents from modifying Cherry Studio user-data SQLite files through native tools.
  • [Agent] Claude Code process failures now show an actionable cause and diagnostic reference.
  • [Agent] The context-usage indicator now advances live during a task instead of only at completion.
  • [DeepSeek] DeepSeek Harness Web sessions now start correctly when the runtime requires its token-authenticated URL.
  • [Pi] Resume Pi tasks after context-clamped length responses with a bounded compact-and-retry attempt.
  • [OpenCode] OpenCode Go automatic conversation titles now preserve session identity.
  • [Context] Fixed the context compression model selector so users can switch back to “Follow current model”.
  • [Settings] Fix the provider model list freezing the app when a provider has many models.
  • [Settings] Fix Assistant settings breaking auto-save with unsafe Max tokens values.
  • [Settings] China-edition onboarding now uses CherryIN login by default again.
  • [Settings] AMD GPU Cloud no longer shows promotional “Free” or daily-credit messaging.
  • [Quick Assistant] Fix built-in selection quick actions to call MCP tools when a quickAssistant with MCP is configured.
  • [Translate] Fixed the copy button showing its feedback on the wrong pane.
  • [Translate] Fixed translation history stars opening details instead of toggling when activated with Enter or Space.
  • [Web Search] Keep valid Querit results when individual items omit optional metadata.
  • [Word Export] Word export now renders four-space-indented code blocks, numbered lists, image alt text, strikethrough, and fixes empty blockquote errors.
  • [Markdown] Horizontal scrollbars are now visible on overflowing content inside markdown.
  • [Browser MCP] Prevent hidden or inactive built-in browser pages from playing audible media.
  • [Backup] Fix misleading “Backup file format error” when restoring a backup created by a newer version.
  • [Backup] Fixed Qiniu Cloud S3 backup, restore, management, and retention cleanup when using regional endpoints.
  • [Region] Region-dependent routing now falls back to global endpoints when IP region detection fails instead of treating failure as mainland China.
  • [Region] Fix region detection reusing an in-flight request from a different proxy.
  • [Mini Apps] Fixed Mini Apps search failing to find apps by their translated display names.
  • [Mini Apps] Remove raw permission key tooltips that showed untranslated strings.
  • [Notes] Fixed note and folder rename fields closing before users could enter a new name.
  • [PDF Preview] Fixed PDF page input retaining an out-of-range number when submitting.
  • [Cherry Cloud] Bring Cherry Studio to the foreground after sign-in completes.
  • [Portable] Fix Windows portable deep links opening a second app instance that can lose packaged resources.
  • [Windows] Fix garbled localized default application names in the Open with menu.
  • [macOS] Repair macOS keychain signing.

💄 Improvements

  • [Image Generation] Disable automatic retries to avoid duplicate billable requests.
  • [Image Generation] Probe edit-only image models via edit mode.
  • [Agent Channels] Begin processing incoming messages after a one-second batching delay.

⚡ Performance

  • [Code Editor] CodeMirror theme catalog is now loaded only when a code editor is opened.
  • [HTML Artifacts] HTML artifact previews skip full-element layout sweeps for scrollable content.

Cherry Studio 2.0.13 - 新功能、修复与改进

✨ 新功能

  • [模型] 新增 GPT-6 Astra 支持，包括上下文限制、推理控制、快速模式、原生联网搜索、分层定价和官方模型图标。
  • [模型] 新增 TokenDance 内置模型服务商，支持浏览器 API 密钥授权。
  • [定时任务] 每天、工作日和每周预设现在支持每天多个时间点（如 09:00 和 18:00）。
  • [对话] 显示话题和会话标题，从标题栏切换分支，并将单个分支导出为 Markdown。
  • [技能] 技能设置中新增已安装技能来源过滤和单/双列布局切换。
  • [快捷面板] 管理操作现在固定在可访问的页脚，涵盖提示词、技能、MCP、笔记、知识库和工具栏自定义。
  • [输入框] 新增可配置的 Ctrl+I / Cmd+I 快捷键聚焦输入框。
  • [图片导出] 对话消息图片导出现在使用 Chromium 合成器，输出像素完美匹配屏幕显示。
