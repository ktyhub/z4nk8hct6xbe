<summary>Anglais</summary> Cherry Studio 2.1.0 - System Doctor, contrôle du navigateur et transformation Office ✨ Nouvelles fonctionnalités - [Docteur] Ajoutez System Doctor avec diagnostic IA, vérifications du système, correctifs guidés, exportation de diagnostics et commentaires. Les vérifications couvrent l'installation, les autorisations, le stockage, les fournisseurs, MCP, les outils gérés et les erreurs récentes. Diagnostiquez les discussions individuelles ou les sessions d'agent séparément des rapports complets du système ; l'ouverture des commentaires ou l'exportation ne démarre pas un contrôle de santé. - [Navigateur] Les agents et les assistants de chat peuvent utiliser le navigateur intégré, avec un pointeur animé affichant les actions de l'agent. Les agents peuvent rechercher des éléments de page, les récupérer après les mises à jour des pages, inspecter l'activité de la console et du réseau et utiliser les outils WebMCP du site Web. Prend également en charge la recherche dans l'historique de navigation, l'importation des données du navigateur et la suppression de l'historique ou du cache séparé. - [Office] Ajoutez la compétence Office-Transform : les agents peuvent extraire des plages de feuilles de calcul, des paragraphes de documents, des pages PDF et des formes de diapositives dans de nouveaux fichiers. - [Sélection] Activez « Sélectionner une région » pour sélectionner une plage de feuille de calcul, un paragraphe Word, une page PDF ou une diapositive et la citer comme référence structurelle précise. - [Recherche Web] Ajoutez Serply en tant que fournisseur de recherche Web. - [Modèles] Ajoutez le modèle Flash DeepSeek V4.1 avec contrôle de l'effort de raisonnement et prise en charge de la recherche sur le Web. - [Agent] Les agents peuvent désactiver l'attribution des commits Claude Code dans Paramètres → Général. - [Barre latérale] Épinglez les applications, les mini-applications, les agents, les assistants, les bases de connaissances, les sujets, les sessions d'agent, les fichiers et les outils Code CLI comme raccourcis. - [Chat] Ajoutez des menus contextuels de lien de conversation à ouvrir dans un navigateur intégré ou externe. - [Historique] Ajoutez Ctrl+A/Cmd+A tout sélectionner, la sélection de plage Shift-click et un indicateur de sélection partielle. - Les connexions des appareils [Mobile] sont désormais visibles pour tous les utilisateurs disposant d'une carte de téléchargement d'application mobile localisée. - [Corbeille] La suppression de sujets, d'agents, d'assistants ou de fichiers les déplace désormais vers Paramètres → Données → Corbeille pour restauration ou suppression permanente. - [Markdown] Les blocs de code LaTeX affichent désormais les aperçus des formules par défaut. - [Markdown] Les chemins d'accès aux fichiers et dossiers locaux dans les réponses de l'assistant sont désormais clickable. - [Journaux] Ajoutez un paramètre de conservation des journaux (7/14/30/90 jours) avec nettoyage automatique. 🐛 Corrections de bugs - [Code Block] Correction des modifications enregistrées dans un mauvais bloc de code ou perdues ; la barre d'outils reste visible lors du défilement. - [Composer] Correction du collage silencieux qui ne faisait rien lorsque le fichier ne pouvait pas être lu. - [Composer] Préserve le focus d'entrée lors de l'envoi de messages. - [Liste des conversations] Afficher plus développe désormais toutes les conversations restantes. - [Historique] Gardez l'historique ouvert après la suppression de conversations. -[Markdown] Empêche les messages bruts de clignoter lors d'un chargement paresseux. - [Markdown] Correction du rendu mathématique de l'affichage sur les lignes vides. - [Windows] Correction des avertissements répétés « fsync(dir) failed » dans le journal. - [Modèles] Activer la recherche sur le Web pour les modèles LMStudio/Ollama compatibles avec les outils. - [Modèles] Répertoriez les modèles LM Studio à partir de /api/v0/models. - [Fournisseur] Limiter la sortie de DeepSeek V4 à 384 000 jetons ; corriger les limites du GLM-5.3 et du MiMo V2.5. - [DSH] Lancez DSH avec Bun fourni ; conserver les en-têtes de session OpenCode. - [DSH] Échec rapide sur la maison DSH mise à niveau incompatible. - [Erreur] Classifier les échecs de transport Chromium net::ERR_* ; préserver les messages structurés d’échec du fournisseur. - [Image] Restaurer la compatibilité des images de référence HDR ; correction du retournement de rotation de l'image. - [Migration] Conservez l'enregistrement du serveur MCP mal formé en cas d'abandon de la migration v2. - [Raccourcis] Avertir lorsque le raccourci entre en collision avec le raccourci du processus principal. - [Chat] Restaurer le suivi du bas après l'envoi ; préserver l’état de la barre latérale lors du changement d’onglet. - [Chat] Afficher la barre de défilement multi-modèles au survol ; empêcher le rebond du défilement. - [Connaissances] Afficher les barres de défilement du lecteur de fichiers. - [Smooth Stream] Vider le texte mis en mémoire tampon à la fin. - [Claude Code] Traitez les liens symboliques pendants comme des fuites d'espace de travail ; préserver le bus de session de bureau Linux. - Cherry Studio 2.1.0 - System Doctor, Browser Control, and Office Transform

✨ New Features

  • [Doctor] Add System Doctor with AI diagnosis, system checks, guided fixes, diagnostic export, and feedback. Checks cover installation, permissions, storage, providers, MCP, managed tools, and recent errors. Diagnose individual chats or Agent sessions separately from full system reports; opening feedback or export does not start a health check.
  • [Browser] Agents and chat assistants can use the built-in browser, with an animated pointer showing Agent actions. Agents can find page elements, recover them after page updates, inspect console and network activity, and use website WebMCP tools. Also supports browsing history search, browser data import, and separate history or cache clearing.
  • [Office] Add the office-transform skill: agents can extract worksheet ranges, document paragraphs, PDF pages, and slide shapes into new files.
  • [Selection] Turn on “Select region” to pick a worksheet range, Word paragraph, PDF page, or slide and quote it as a precise structural reference.
  • [Web Search] Add Serply as a web search provider.
  • [Models] Add DeepSeek V4.1 Flash model with reasoning effort control and web search support.
  • [Agent] Agents can opt out of Claude Code commit attribution in Settings → General.
  • [Sidebar] Pin Apps, Mini Apps, Agents, Assistants, Knowledge Bases, Topics, Agent Sessions, Files, and Code CLI tools as shortcuts.
  • [Chat] Add conversation link context menus for opening in built-in or external browser.
  • [History] Add Ctrl+A/Cmd+A select-all, Shift-click range selection, and partial-selection indicator.
  • [Mobile] Device Connections now visible to all users with a localized mobile app download card.
  • [Trash] Deleting topics, agents, assistants, or files now moves them to Settings → Data → Recycle Bin for restore or permanent deletion.
  • [Markdown] LaTeX code blocks now show formula previews by default.
  • [Markdown] Bare local file and folder paths in assistant responses are now clickable.
  • [Logs] Add log retention setting (7/14/30/90 days) with automatic cleanup.

Cherry Studio 2.1.0 - 系统诊断、浏览器控制与 Office 转换

✨ 新功能

  • [诊断] 新增系统诊断，支持 AI 诊断、系统检查、引导修复、导出诊断信息和问题反馈，涵盖安装、权限、存储、服务商、MCP、托管工具及最近错误。可单独诊断对话或智能体会话，与全系统报告分离；打开反馈或导出不会自动启动健康检查。
  • [浏览器] 智能体和对话助手均可使用内置浏览器，并以动画指针展示智能体操作。智能体支持查找页面元素、在页面更新后恢复元素、检查控制台和网络活动，以及调用网站的 WebMCP 工具；同时支持搜索浏览历史、导入浏览器数据和单独清理历史或缓存。
  • [Office] 新增 office-transform 技能：智能体可将工作表范围、文档段落、PDF 页面和幻灯片形状提取为新文件。
  • [选择] 开启”选择区域”可选取工作表范围、Word 段落、PDF 页面或幻灯片，作为精确的结构化引用。
  • [网络搜索] 新增 Serply 网络搜索服务商。
  • [模型] 新增 DeepSeek V4.1 Flash 模型，支持推理力度控制和网络搜索。
  • [智能体] 智能体可在设置 → 通用中关闭 Claude Code 提交署名。
  • [侧边栏] 可将应用、小程序、智能体、助手、知识库、话题、智能体会话、文件和代码 CLI 工具固定为快捷方式。
