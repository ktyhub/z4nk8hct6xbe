orque v1.4.249

Configuration plus facile, plus de contrôle sur les discussions et des espaces de travail plus ordonnés ✨

  • 🎛️ Choisissez Chat ou Terminal dès le début : L'intégration vous permet désormais de choisir Chat UI ou Terminal, puis de choisir un agent et d'installer les compétences pour cette configuration.
  • 💬 Gardez le contrôle des conversations : Préservez les entrées de chat en cas de livraison et d'arrêt incertains, choisissez si l'envoi déplace la position de défilement et décidez quand les agents de chat inactifs s'arrêtent ou les laissent fonctionner.
  • 🗂️ Gardez les projets en ordre : L'ajout d'un projet maintient les arbres de travail découverts cachés, tandis que la création et le clonage gèrent de manière cohérente les dossiers parents liés par des liens symboliques.
  • 📝 ** Personnalisez la lecture et l'édition : ** Définissez la vue Markdown par défaut, insérez éventuellement une nouvelle ligne finale lors de l'enregistrement et ajustez la largeur du chat à partir des en-têtes du volet.
  • 📱 Un accueil téléphonique plus clair : L'application téléphonique mise à jour sépare le flux, l'utilisation, les automatisations et les paramètres, affiche davantage d'utilisation des agents et nomme les conversations récentes.
  • 🧩 Petits correctifs dans le travail quotidien : Conservez la position de défilement du terminal lors de la saisie, ouvrez les liens de fichiers dans leur espace de travail, affichez Mermaid dans les commentaires PR et fermez les divisions flottantes du navigateur à partir de leur propre barre d'outils.

Faits saillants

  • Configuration et compétences : Choisissez Chat ou Terminal lors de l'intégration, utilisez le sélecteur d'agent et l'étape de thème mis à jour, et installez les compétences Chat pour le fournisseur sélectionné sur cet ordinateur. Les projets vides nouvellement ajoutés peuvent ouvrir l'agent Chat choisi lorsque cet itinéraire est pris en charge.
  • Comportement de chat : Les entrées et les suivis en file d'attente sont conservés jusqu'à la livraison incertaine et l'arrêt. De nouveaux paramètres contrôlent la position de défilement lors de l’envoi et lorsque les agents de chat inactifs s’arrêtent. Les images de discussion chargées restent visibles sur les commutateurs de défilement et d’espace de travail, et le compactage Pi conserve les envois jusqu’à la fin.
  • Choix d'agent : Les comptes Claude gérés conservent les choix ultérieurs de /model et d'effort lorsque les valeurs par défaut n'ont pas changé. La solution de repli de Claude est affichée sans modifier les choix de modèles enregistrés ; L'effort OpenCode suit le modèle sélectionné et Claude Chat ajoute l'effort Ultracode.
  • Projets et navigation : L'ajout d'un projet permet de masquer les arbres de travail découverts. La création et le clonage de projets résolvent systématiquement les parents liés symboliquement ; L'ordre manuel de l'espace de travail et la saisie pour effectuer une recherche dans le sélecteur d'agent de nouvel espace de travail reçoivent des correctifs.
  • Éditeur et navigateur : Choisissez la vue Markdown par défaut, activez Insérer une nouvelle ligne finale lors de l'enregistrement, conservez l'apparence HTML du chat dans les aperçus de fichiers et fermez une division de navigateur flottante sans fermer le terminal à côté.
  • Téléphone : L'application mise à jour ajoute des onglets d'accueil, une utilisation pour plus d'agents et des noms de conversation dans Jump back in. Elle améliore également la saisie dans le terminal, les contrôles d'effort, les aperçus HTML et le comportement de thème/navigation Android.
  • Automatisation et notifications : Les automatisations utilisent le sélecteur d'agent partagé, acceptent les arguments de modèle/de réflexion Pi et s'actualisent lorsque les projets changent. Les exécutions interrompues de l'automatisation du terminal sont enregistrées comme ayant échoué, les alertes de bureau reconnues sont effacées et les notifications d'achèvement d'OpenCode gèrent OSC 7501.

Notes de compatibilité et de mise à niveau

  • Choix de configuration existants : Les nouveaux choix d'intégration utilisent les préférences de surface et d'agent existantes. Cette version ne réinitialise pas l'agent par défaut de tout le monde et ne fait pas basculer chaque espace de travail existant vers Chat. Un espace de travail avec des onglets existants les conserve ; le chemin Chat du nouveau projet dépend d’un environnement d’exécution et d’un agent pris en charge.
  • Paramètres de discussion : Le défilement lors de l'envoi et l'arrêt de l'agent inactif sont configurables. Choisissez Jamais si vous souhaitez que les agents de chat inactifs continuent de fonctionner ; l’arrêt d’un agent inactif est distinct de la suppression de la conversation.
  • Comptes Claude gérés : Les valeurs par défaut inchangées cessent d'écraser les choix de compte ultérieurs après la synchronisation des paramètres. Cela ne récupère pas les choix écrasés par une version plus ancienne et les clés par défaut modifiées s'appliquent toujours.
  • Serveurs couplés : Les améliorations apportées aux liens de fichiers entre serveurs couplés utilisent la nouvelle fonctionnalité lorsqu'elle est disponible ; les anciens serveurs conservent leur chemin d'accès existant. Il n'y a pas de nouvelle version minimale du serveur pour les modifications de configuration. Les limitations du problème GitHub avec les anciens serveurs restent ci-dessous.
  • Modifications du téléphone : L'interface utilisateur native du téléphone et les correctifs Android nécessitent une application Orca Mobile mise à jour ainsi qu'un ordinateur de bureau ou un serveur compatible. Les modifications mobiles sont incluses dans Orca Mobile 0.0.64 ; la mise à jour du bureau à elle seule n’installe pas une version native du téléphone.
  • Panneau d'orchestration : Le panneau expérimental et ses paramètres sont à nouveau temporairement désactivés. Les modifications de la messagerie d’orchestration sont distinctes de la disponibilité de ce panneau.

Problèmes connus

Configuration de Chat sans agent par défaut : Avec l'interface utilisateur de Chat activée et l'agent par défaut désactivé dans Paramètres, le bouton Installer les compétences du Guide de configuration peut rester désactivé sans explication. Choisissez un agent par défaut, tel que Claude, avant l'installation.

Historique du shell après un redémarrage à froid : Certains volets du shell Mac peuvent rouvrir sans afficher leur sortie précédente après un redémarrage complet de l'application et du terminal. Cette classe de défaillance a également été observée sur v1.4.248 ; la cause reste non résolue. Cette version ne prétend pas résoudre ce problème.

Problèmes GitHub sur les anciens serveurs couplés : L'ouverture d'un numéro via un référentiel ou une URL peut rendre la modification du titre, de l'étiquette et du responsable indisponible. Problème de téléphone Fermer/Réouvrir peut également refuser un ancien serveur ou intermédiaire. Ouvert sur GitHub reste disponible.

Stockage et performances des discussions enregistrées : Le compactage de l'historique en direct reste suspendu, afin que le stockage puisse augmenter à mesure que les conversations se poursuivent. Cette version ne prétend pas supprimer toutes les sources de blocages de chat. Les modifications de hook réduisent le travail des sous-processus, mais la latence de l'ensemble de l'application, les améliorations du processeur et du tas n'ont pas été mesurées.

Longs délais de mise à jour : Avec un délai de 14 ou 30 jours, une version peut quitter le flux de mise à jour avant de devenir éligible. Aucun et Skip Delay Once restent disponibles.

Remplacements de commandes de plugin : Un plugin remplaçant une commande intégrée peut toujours se terminer après qu'Orca a utilisé la commande normale à la place, provoquant que l'action se produise deux fois.

orca v1.4.249

Easier setup, more control over chats & tidier workspaces ✨

  • 🎛️ Choose Chat or Terminal from the start: Onboarding now lets you pick Chat UI or Terminal, then choose an agent and install the skills for that setup.
  • 💬 Keep control of conversations: Preserve chat inputs through uncertain delivery and Stop, choose whether sending moves the scroll position, and decide when idle chat agents stop—or keep them running.
  • 🗂️ Keep projects tidy: Adding a project keeps discovered worktrees hidden, while create and clone handle symlinked parent folders consistently.
  • 📝 Make reading and editing your own: Set the default Markdown view, optionally insert a final newline on save, and adjust chat width from pane headers.
  • 📱 A clearer phone Home: The updated phone app separates Feed, Usage, Automations and Settings, shows more agent usage, and names recent conversations.
  • 🧩 Small fixes across daily work: Keep terminal scroll position on input, open file links in their workspace, render Mermaid in PR comments, and close floating browser splits from their own toolbar.

Highlights

  • Setup & skills: Pick Chat or Terminal during onboarding, use the updated agent picker and theme step, and install Chat skills for the selected provider on this computer. Empty newly added projects can open the chosen Chat agent when that route is supported.
  • Chat behavior: Inputs and queued follow-ups are retained through uncertain delivery and Stop. New settings control scroll position when sending and when idle chat agents stop. Loaded chat images stay visible across scrolling and workspace switches, and Pi compaction holds sends until it finishes.
  • Agent choices: Managed Claude accounts keep later /model and effort choices when the defaults have not changed. Claude fallback is shown without changing saved model choices; OpenCode effort follows the selected model, and Claude chat adds Ultracode effort.
  • Projects & navigation: Adding a project keeps discovered worktrees hidden. Project creation and cloning resolve symlinked parents consistently; manual workspace order and type-to-search in the new-workspace agent picker receive fixes.
  • Editor & browser: Choose the default Markdown view, enable Insert Final Newline on save, preserve chat HTML appearance in file previews, and close a floating browser split without closing the terminal beside it.
  • Phone: The updated app adds Home tabs, usage for more agents and conversation names in Jump back in. It also improves terminal input, effort controls, HTML previews and Android theme/navigation behavior.
  • Automation & notifications: Automations use the shared agent picker, accept Pi model/thinking arguments and refresh when projects change. Interrupted terminal automation runs are recorded as failed, acknowledged desktop alerts clear, and OpenCode completion notifications handle OSC 7501.

Compatibility & upgrade notes

  • Existing setup choices: The new onboarding choices use existing surface and agent preferences. This release does not reset everyone's default agent or switch every existing workspace to Chat. A workspace with existing tabs keeps them; the new-project Chat path depends on a supported runtime and agent.
  • Chat settings: Scroll-on-send and idle-agent stopping are configurable. Choose Never if you want idle chat agents to remain running; stopping an idle agent is separate from deleting the conversation.
  • Managed Claude accounts: Unchanged defaults stop overwriting later account choices after settings synchronization. This does not recover choices overwritten by an older build, and changed default keys still apply.
  • Paired servers: Improvements to paired-server file links use the new capability when available; older servers retain their existing path. There is no new minimum server version for the setup changes. GitHub issue limitations with older servers remain below.
  • Phone changes: Native phone UI and Android fixes require an updated Orca Mobile app as well as a compatible desktop or server. The mobile changes are included in Orca Mobile 0.0.64; updating desktop alone does not install a native phone release.
  • Orchestration panel: The experimental panel and its setting are temporarily disabled again. Orchestration messaging changes are separate from availability of that panel.

Known issues

Chat setup with no default agent: With Chat UI enabled and the default agent cleared in Settings, Setup Guide's Install skills button can remain disabled without an explanation. Choose a default agent, such as Claude, before installing.

Shell history after a cold restart: Some Mac shell panes can reopen without showing their previous output after a full app and terminal restart. This class of failure was also observed on v1.4.248; the cause remains unresolved. This release does not claim to fix it.

GitHub issues on older paired servers: Opening an issue through a repository or URL can leave title, label and assignee editing unavailable. Phone issue Close/Reopen can also refuse an older server or intermediary. Open on GitHub remains available.

Saved chat storage & performance: Live-history compaction remains paused, so storage can grow as conversations continue. This release does not claim to remove every source of chat stalls. Hook changes reduce subprocess work, but whole-app latency, CPU and heap improvements were not measured.

Long update delays: With a 14- or 30-day delay, a release can leave the update feed before it becomes eligible. None and Skip Delay Once remain available.

Plugin command replacements: A plugin replacing a built-in command can still finish after Orca has used the normal command instead, causing the action to happen twice.
