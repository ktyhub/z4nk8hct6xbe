orque v1.4.243

Extensions Chrome dans le navigateur d'Orca, prise en charge de l'iPhone Duo et conversion d'une session d'agent de terminal en direct en interface de chat 🧩

Cette version apporte les extensions Chrome au navigateur d'Orca en mode expérimental, permet à une conversation de se poursuivre dans Chat une fois que vous quittez son agent dans le terminal et affiche vos arbres de travail locaux plus tôt après un redémarrage. Il ajoute également la prise en charge de l'iPhone Duo pliable, des menus compacts de style natif, des thèmes clairs et sombres sur le téléphone et des correctifs pour les terminaux Windows, les hôtes SSH et les mises à jour.

La version courte

  • Extensions Chrome (expérimentales) : Ajoutez des extensions du Chrome Web Store avec Ajouter à Orca, afin que les gestionnaires de mots de passe comme Bitwarden et 1Password puissent remplir les connexions dans le navigateur d'Orca. Désactivé par défaut.
  • Convertissez une session d'agent de terminal en direct en une interface de chat : Une fois que vous quittez Claude ou Codex dans un terminal, la même conversation peut continuer dans Chat pendant que l'onglet du terminal reste ouvert. Les discussions de Claude conservent également leur choix d'approbation enregistré lors des modifications de modèle, et la fermeture d'une discussion qui fonctionne toujours demande en premier.
  • Arbres de travail plus tôt après un redémarrage : Les arbres de travail locaux se chargent avant la restauration des terminaux, et la barre latérale indique que la découverte est toujours en cours au lieu d'afficher une liste vide.
  • Terminaux plus stables : Les terminaux Windows conservent leur historique malgré les changements de largeur, les terminaux en veille se réveillent dans le dossier que vous avez laissé, le bash intégré de macOS maintient le suivi des commandes en ordre après un changement d'interruption DEBUG et la copie depuis pi sur un hôte distant atteint votre clipboard.
  • Orchestration : Choisissez l'intervalle de battement de cœur des travailleurs ou désactivez les battements de cœur, et réduisez l'utilisation du processeur en empêchant les travailleurs installés d'interroger les commandes.
  • Polissez là où ça compte : Menus compacts de style natif, mise en surbrillance Markdown de style VS Code avec des titres collants et vérifications de mise à jour via votre proxy de paramètres.
  • Corrections de la communauté : Quitter et arrêter toutes les sessions, les mathématiques dans les discussions, la copie de l'URL distante avec des plages de lignes, la mise en surbrillance IME dans les terminaux, fnm sous Windows et les traductions japonaises et chinoises fonctionnent toutes mieux. Mises à jour sur le téléphone et sur le Web : Les téléphones bénéficient de thèmes clairs et sombres, d'une prise en charge de l'iPhone Duo pliable, de fichiers PDF dans Quick Look et de boutons de copie dans les discussions. De nombreux écrans de téléphone suivent désormais les règles du bureau pour les discussions, le contrôle de source et les terminaux, et la saisie et le défilement dans les longues discussions restent rapides.

Notes de compatibilité et de mise à niveau

  • Nouvel hôte de terminal : Les nouveaux terminaux démarrent sur un nouvel hôte de terminal, donc les correctifs de terminal de cette version s'appliquent, y compris la poursuite d'une conversation après la sortie de son agent de terminal. Les terminaux déjà ouverts avant la mise à jour continuent de fonctionner et restent attachés sur l'hôte précédent jusqu'à ce que vous les fermiez.
  • Extensions de navigateur (expérimentales) : activez Paramètres → Expérimental → Extensions de navigateur, redémarrez, puis ouvrez le Chrome Web Store dans un onglet du navigateur Orca. Les extensions s'exécutent uniquement dans les profils de navigateur local. Les bloqueurs de publicités s'installent mais ne bloquent pas encore, et certaines extensions, telles que Tampermonkey, ne fonctionnent pas.
  • Battements de cœur du travailleur : Les battements de cœur restent activés toutes les 5 minutes par défaut. Les modifications dans Paramètres → Orchestration de l'agent s'appliquent aux travailleurs nouvellement envoyés ; les travailleurs déjà en activité gardent leur brief et les hôtes plus âgés gardent 5 minutes.
  • Navigation du sous-agent Claude : L'œil qui marquait le sous-agent que vous visualisez a disparu. La ligne de sous-agent affichée utilise la mise en surbrillance normale de la ligne actuelle.

orca v1.4.243

Chrome extensions in Orca’s browser, iPhone Duo support, and Convert a terminal agent session live into a chat ui 🧩

This release brings Chrome extensions to Orca’s browser under experimental, lets a conversation continue in Chat once you quit its agent in the terminal, and shows your local worktrees sooner after a restart. It also adds support for the folding iPhone Duo, compact native-style menus, light and dark themes on the phone, and fixes for Windows terminals, SSH hosts and updates.

The short version

  • Chrome extensions (experimental): Add extensions from the Chrome Web Store with Add to Orca, so password managers like Bitwarden and 1Password can fill logins in Orca’s browser. Off by default.
  • Convert a terminal agent session live into a chat ui: Once you quit Claude or Codex in a terminal, the same conversation can continue in Chat while the terminal tab stays open. Claude chats also keep their saved approval choice across model changes, and closing a chat that’s still working asks first.
  • Worktrees sooner after a restart: Local worktrees load before terminals restore, and the sidebar says discovery is still running instead of showing an empty list.
  • Steadier terminals: Windows terminals keep their history through width changes, slept terminals wake in the folder you left, macOS’s built-in bash keeps command tracking in order after a DEBUG trap change, and copying from pi on a remote host reaches your clipboard.
  • Orchestration: Choose the worker heartbeat interval or turn heartbeats off, and reduce CPU use by stopping settled workers from polling for commands.
  • Polish where it counts: Compact native-style menus, VS Code–style Markdown highlighting with sticky headings, and update checks through your Settings proxy.
  • Fixes from the community: Quit and Stop All Sessions, math in chats, Copy Remote URL with line ranges, IME highlighting in terminals, fnm on Windows, and Japanese and Chinese translations all work better.

Phone & web updates: Phones get light and dark themes, support for the folding iPhone Duo, PDFs in Quick Look and copy buttons in chats. Many phone screens now follow desktop’s rules for chats, Source Control and terminals, and typing and scrolling in long chats stay fast.

Compatibility & upgrade notes

  • Fresh terminal host: New terminals start on a fresh terminal host so this release’s terminal fixes apply, including continuing a chat after its terminal agent exits. Terminals already open before you update keep running, and stay attached, on the previous host until you close them.
  • Browser extensions (experimental): Turn on Settings → Experimental → Browser extensions, restart, then open the Chrome Web Store in an Orca browser tab. Extensions run in local browser profiles only. Ad blockers install but don’t block yet, and some extensions, such as Tampermonkey, don’t work.
  • Worker heartbeats: Heartbeats stay on every 5 minutes by default. Changes in Settings → Agent Orchestration apply to newly dispatched workers; workers already running keep their brief, and older hosts keep 5 minutes.
  • Claude subagent navigation: The eye that marked the subagent you’re viewing is gone. The viewed subagent row uses the normal current-row highlight.
