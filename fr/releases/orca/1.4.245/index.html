orque v1.4.245

Une utilisation plus rapide d'Orca, des plugins et de l'ordinateur en arrière-plan ⚡

  • ⚡ Un Orca plus rapide : Lancez-vous en douceur avec des centaines de discussions, avec moins de décalage lorsque vous tapez et changez d'onglet.
  • 🧩 Personnalisez Orca avec des thèmes d'icônes, une coloration syntaxique et des éditeurs personnalisés.
  • 🖱️ Continuez à travailler pendant que les agents utilisent Chrome, Blender et d'autres applications Mac en arrière-plan.
  • 🎙️ Dictez sur votre téléphone et voyez vos mots pendant que vous parlez.
  • 💬 Essayez la nouvelle interface utilisateur de chat : Recherchez « interface utilisateur de chat » dans les paramètres pour l'activer, puis cliquez à droite sur click sur un onglet pour basculer en direct entre l'interface utilisateur de chat et TUI.

Faits saillants

  • Un Orca plus rapide : Application rapide avec des centaines de discussions. La saisie reste plus réactive et les discussions masquées effectuent moins de travail lorsque vous utilisez d'autres onglets.
  • Plugins : Ajoutez des thèmes d'icônes, une coloration syntaxique et des éditeurs personnalisés depuis Paramètres → Plugins. La publication communautaire arrive bientôt, vous pourrez donc partager vos propres plugins.
  • Utilisation de l'ordinateur en arrière-plan sur Mac : Laissez les agents travailler dans Chrome, Blender et d'autres applications tout en continuant à utiliser votre souris et votre clavier. Le navigateur intégré à l'application d'Orca fonctionne déjà en arrière-plan ; maintenant, l’utilisation de l’ordinateur aussi. Certaines actions nécessitent encore la mise en avant de l'application.
  • Chats : Profitez d'une interface utilisateur de chat très soignée, envoyez à nouveau après l'arrêt et prévisualisez les liens dans le chat. Recherchez « Chat UI » dans Paramètres pour l'activer, puis cliquez avec le bouton droit sur click sur un onglet pour basculer en direct entre Chat UI et TUI.
  • Terminaux : définissez une limite de terminaux en cours d'exécution pour chaque ordinateur dans Paramètres → Terminal → Avancé.
  • WSL : Les distributions arrêtées restent arrêtées jusqu'à ce que vous choisissiez Démarrer. Les terminaux mémorisent leur dossier.
  • Navigateur : Appuyez sur Cmd+Opt+B sur Mac pour diviser le navigateur. Envoyez des commentaires d'annotation plus courts, désormais avec des images collées.
  • Espaces de travail : Le nom de votre espace de travail redevient son nom de branche. Les actions de contrôle de code source obtiennent des contrôles de modèle et d'effort.
  • Téléphone : Consultez la dictée pendant que vous parlez et lisez un code, des tableaux et des diagrammes plus clairs.

Notes de compatibilité et de mise à niveau

  • Nouvel hôte de terminal : Cette version démarre un nouvel hôte de terminal pour les nouveaux terminaux. Les terminaux déjà ouverts avant la mise à jour continuent de s'exécuter sur l'hôte précédent et restent attachés. Le nouveau paramètre de limite de terminal en cours d'exécution nécessite le nouvel hôte, tout comme les correctifs tels que le correctif de démarrage ble.sh et les vérifications de processus plus légères sur macOS. Celles-ci s'appliquent aux terminaux que vous ouvrez après la mise à jour.
  • Les plugins sont activés par défaut : L'installation d'un plugin, y compris à partir d'un lien orca://plugins, n'ouvre qu'un écran de révision en premier. Les plugins qui exécutent du code demandent votre consentement avant de s'installer et, une fois approuvés, ils s'exécutent avec un accès complet à votre ordinateur.
  • Limite de terminaux en cours d'exécution : La valeur par défaut suit désormais chaque ordinateur : la moitié de sa limite de terminaux système, jusqu'à 4 096, ou 256 comme auparavant lorsqu'Orca ne peut pas lire cette limite. Une valeur que vous définissez dans Paramètres ou avec une variable d'environnement est prioritaire. Le relever ou l’abaisser ne ferme jamais les terminaux en cours d’exécution. Un serveur distant exécutant un ancien Orca continue de fonctionner, mais la limite ne peut pas y être modifiée jusqu'à ce qu'il soit mis à jour.
  • Nom des discussions : Les discussions sont désormais nommées par défaut par leur propre agent et leur propre compte. Un agent de nommage, une commande personnalisée ou des arguments que vous avez enregistrés auparavant continuent de fonctionner, et le choix de l'agent de nommage a été déplacé sous Avancé dans Paramètres → Chat → Dénomination du chat.
  • Historique du Codex entre les comptes : Un nouveau commutateur, Paramètres → Agents → Partager l'historique du Codex entre les comptes, est activé par défaut et conserve le comportement actuel. Une fois activé, l'historique des comptes gérés par Orca s'affiche désormais également dans votre propre ~/.codex lorsque vous revenez aux paramètres par défaut du système. Le désactiver arrête les nouveaux partages et ne supprime rien. Sur un hôte SSH ou WSL exécutant un ancien Orca, le commutateur reste désactivé jusqu'à ce que cet hôte soit mis à jour.
  • Codex sur macOS et Linux : Orca démarre désormais le Codex avec sa fonction de collage désactivée, donc les invites saisies à partir d'un téléphone ou d'un autre client sont envoyées au lieu de rester dans le compositeur. Les vraies pâtes arrivent toujours sous forme de pâtes.
  • Utilisation d'un ordinateur sur Mac : Les agents agissent désormais en arrière-plan par défaut. Les agents peuvent toujours demander l'ancien mode de premier plan avec --restore-window, dont les applications Chromium et Electron ont encore besoin.
  • Annotations du navigateur : Envoyer et copier donne désormais aux agents un bref résumé par note. Cochez Inclure les détails de la page dans le menu Envoyer pour obtenir l'ancienne sortie complète ; le choix dure pour ce volet de navigateur.
  • Noms des branches de l'espace de travail : Un nom que vous saisissez pour un nouvel espace de travail est à nouveau utilisé comme branche, même lorsque l'option Renommer automatiquement la branche du travail est activée. Le renommage automatique remplace uniquement les noms inventés par Orca.
  • Automatisations : Les agents démarrés par une automatisation ignorent l'invite de mise à jour de démarrage de leur CLI, de sorte que l'invite ne peut pas avaler la tâche. Les agents que vous démarrez vous-même restent inchangés.
  • Actions de contrôle de source : Les indicateurs de modèle et d'effort enregistrés dans les arguments d'une action sont déplacés vers les nouveaux contrôles de modèle et d'effort lors du chargement d'Orca ; les autres arguments restent tels quels. Un téléphone ou un serveur distant sur un Orca plus ancien peut lancer ces actions avec un modèle ou un effort différent jusqu'à ce qu'il soit mis à jour.
  • Nouveaux raccourcis : Cmd/Ctrl+Shift+X ouvre les plugins (en dehors des champs de texte) et Cmd+Opt+B sur macOS ouvre un onglet de navigateur divisé à droite. Cmd+Opt+B peut être modifié dans Paramètres → Clavier.
  • Limitation connue, déclassement : Si vous revenez à v1.4.244, les choix personnalisés de modèle et d'effort sur les actions Source Control AI sont réinitialisés aux valeurs par défaut de l'agent, et une nouvelle mise à jour ne les ramènera pas.

orca v1.4.245

A faster Orca, plugins & background computer use ⚡

  • ⚡ A faster Orca: Launch smoothly with hundreds of chats, with less lag as you type and switch tabs.
  • 🧩 Customize Orca with icon themes, syntax highlighting and custom editors.
  • 🖱️ Keep working while agents use Chrome, Blender and other Mac apps in the background.
  • 🎙️ Dictate on your phone and see your words as you speak.
  • 💬 Try the new Chat UI: Search for “Chat UI” in Settings to turn it on, then right-click a tab to switch live between Chat UI and TUI.

Highlights

  • A faster Orca: Fast app with hundreds of chats. Typing stays more responsive, and hidden chats do less work while you use other tabs.
  • Plugins: Add icon themes, syntax highlighting and custom editors from Settings → Plugins. Community publishing is coming soon, so you’ll be able to share your own plugins.
  • Background computer use on Mac: Let agents work in Chrome, Blender and other apps while you keep using your mouse and keyboard. Orca’s in-app browser already works in the background; now computer use does too. Some actions still need the app brought forward.
  • Chats: Enjoy a very polished Chat UI, send again after Stop, and preview links in chat. Search for “Chat UI” in Settings to turn it on, and right-click a tab to switch live between Chat UI and TUI.
  • Terminals: Set a running terminal limit for each computer in Settings → Terminal → Advanced.
  • WSL: Stopped distros stay stopped until you choose Start. Terminals remember their folder.
  • Browser: Press Cmd+Opt+B on Mac for a browser split. Send shorter annotation feedback, now with pasted images.
  • Workspaces: Your workspace name becomes its branch name again. Source Control actions get Model and Effort controls.
  • Phone: See dictation as you speak, and read clearer code, tables and diagrams.

Compatibility & upgrade notes

  • New terminal host: This release starts a fresh terminal host for new terminals. Terminals already open before the update keep running on the previous host and stay attached. The new running terminal limit setting needs the new host, and so do fixes such as the ble.sh startup fix and lighter process checks on macOS. Those apply to terminals you open after updating.
  • Plugins are on by default: Installing a plugin, including from an orca://plugins link, only opens a review screen first. Plugins that run code ask for your consent before they install, and once approved they run with full access to your computer.
  • Running terminal limit: The default now follows each computer: half of its system terminal limit, up to 4096, or 256 as before when Orca can’t read that limit. A value you set in Settings or with an environment variable takes priority. Raising or lowering it never closes running terminals. A remote server running an older Orca keeps working, but the limit can’t be changed there until it updates.
  • Chat naming: Chats are now named by their own agent and account by default. A naming agent, custom command or arguments you saved before keep working, and the naming agent choice moved under Advanced in Settings → Chat → Chat naming.
  • Codex history across accounts: A new switch, Settings → Agents → Share Codex history across accounts, is on by default and keeps today’s behavior. With it on, history from Orca’s managed accounts now also shows up in your own ~/.codex when you switch back to system default. Turning it off stops new sharing and removes nothing. On an SSH or WSL host running an older Orca, the switch stays disabled until that host updates.
  • Codex on macOS and Linux: Orca now starts Codex with its paste guess turned off, so prompts typed from a phone or another client send instead of staying in the composer. Real pastes still arrive as pastes.
  • Computer use on a Mac: Agents now act in the background by default. Agents can still ask for the old foreground mode with --restore-window, which drags into Chromium and Electron apps still need.
  • Browser annotations: Send and Copy now give agents a short summary per note. Check Include page details in the Send menu to get the old full output; the choice lasts for that browser pane.
  • Workspace branch names: A name you type for a new workspace is used as its branch again, even when Auto-rename branch from work is on. Auto-rename only replaces names Orca made up.
  • Automations: Agents started by an automation skip their CLI’s startup update prompt, so the prompt can’t swallow the task. Agents you start yourself are unchanged.
  • Source Control actions: Model and effort flags saved in an action’s Arguments move into the new Model and Effort controls when Orca loads; other Arguments stay as they are. A phone or remote server on an older Orca may launch these actions with a different model or effort until it updates.
  • New shortcuts: Cmd/Ctrl+Shift+X opens Plugins (outside text fields), and Cmd+Opt+B on macOS opens a browser tab in a split to the right. Cmd+Opt+B can be changed in Settings → Keyboard.
  • Known limitation, downgrading: If you go back to v1.4.244, custom model and effort choices on Source Control AI actions reset to the agent’s defaults, and updating again won’t bring them back.
