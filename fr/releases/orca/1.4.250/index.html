orque v1.4.250

Nous avons fait deux sorties aujourd'hui ! N'oubliez pas de consulter les [v1.4.249 release note] (https://github.com/stablyai/orca/releases/tag/v1.4.249), qui incluent une configuration plus facile du chat ou du terminal, plus de contrôle sur les conversations et un téléphone d'accueil repensé.

Utilisation réduite de la mémoire du terminal, modifications de discussion plus claires et gestionnaire de mots de passe compatible Chrome ✨

  • ⚡ Utilisation réduite de la mémoire du terminal : Arrêtez de lire et d'analyser à plusieurs reprises les fichiers de polices pour les ligatures des terminaux, corrigeant une source d'utilisation élevée de la mémoire et lancez des plantages dans les sessions avec de nombreux terminaux.
  • ⚡ Changement plus rapide des arbres de travail : Les améliorations des performances accélèrent le basculement entre les arbres de travail.
  • 📝 Découvrez ce que les agents ont modifié : Les tours de discussion affichent les fichiers modifiés et le nombre de lignes, avec des correctifs disponibles en ligne sur ordinateur et téléphone.
  • 🔐 Gestionnaire de mots de passe compatible Chrome : Activez dans Paramètres → Navigateur pour enregistrer, remplir, importer des mots de passe Chrome et gérer les connexions, cryptées localement avec le stockage sécurisé de votre système d'exploitation.
  • 💬 Chat UI suit votre agent : Les tours longs et gourmands en outils restent connectés dans Chat UI, et les nouvelles discussions suivent la configuration du modèle de votre agent, sauf si vous choisissez un modèle.
  • 🖥️ Terminaux et hôtes plus fiables : Empêchez les textes de séquence d'échappement parasites après des écarts de sortie du terminal et rendez les serveurs de serveur couplés et les sondages d'utilisation disponibles sur les hôtes sans tête.
  • 📱 Meilleure continuité téléphonique : Envoyez une conversation avec Cmd/Ctrl+Entrée et gardez les appareils couplés en suivant les onglets qu'ils ouvrent.

Faits saillants

  • Performances : La commutation des arbres de travail est plus rapide. Les ligatures de terminaux n'analysent plus une police entière pour chaque terminal. Dans le test Windows du PR avec Commit Mono, 32 terminaux ont été relancés sans le précédent crash de mémoire insuffisante ; les résultats dépendent des polices et de la charge de travail. La fermeture d'un outil lors d'un long tour d'agent évite également d'analyser tous les autres outils en direct.
  • Chat : Les modifications réussies de Claude et du Codex apparaissent sous forme de résumés de fichiers modifiés dans la conversation, avec les détails du correctif chargés lors de la sélection. L'interface utilisateur de chat n'interrompt plus le tour d'un agent par ailleurs sain lorsqu'il dépasse 128 entrées de texte ou d'outil en direct. Les discussions du Codex affichent les durées d'attente demandées et prennent en charge la pause, la reprise et l'effacement des objectifs.
  • Navigateur : Enregistrez et remplissez les connexions dans le navigateur d'Orca et gérez-les dans les paramètres du navigateur. Les mots de passe utilisent un cryptage basé sur le système d'exploitation ; le coffre-fort est indisponible lorsque le stockage sécurisé n'est pas disponible.
  • Terminal et hôtes distants : La récupération du flux du terminal évite d'imprimer des séquences d'échappement partielles après des écarts de sortie. Les hôtes sans tête démarrent les services nécessaires aux serveurs couplés et aux interrogations d'utilisation.
  • Espace de travail et intégration : choisissez l'interface utilisateur de chat lors de l'intégration, masquez la liste de contrôle d'intégration, recherchez les arbres de travail découverts cachés en dehors du regroupement de projets et utilisez l'interface améliorée de nettoyage de l'espace de travail inactif.

Notes de compatibilité et de mise à niveau

  • Ligatures terminales : Les ligatures communes restent disponibles. Les ligatures spécifiques aux polices en dehors de la liste intégrée ne peuvent plus se joindre au moteur de rendu GPU.
  • Mots de passe du navigateur : Le coffre-fort est disponible dans le navigateur de bureau, y compris les pages de l'espace de travail local et SSH ; les pages de serveurs couplés en streaming et le Web client n'ont pas de coffre-fort. Un cryptage sécurisé du système d’exploitation est requis.
  • Paramètres par défaut du modèle de discussion : Une nouvelle discussion sans choix de modèle explicite utilise la configuration de l'agent. La valeur par défaut affichée peut être obsolète jusqu'à ce que l'agent démarre et signale son modèle.
  • Récupération de terminal : Les flux d'exécution à distance conservent leur comportement de récupération existant.

orca v1.4.250

We did two releases today! Be sure to check out the v1.4.249 release notes, which include easier Chat or Terminal setup, more control over conversations, and a redesigned phone Home.

Lower terminal memory use, clearer chat changes & a Chrome-compatible password manager ✨

  • ⚡ Lower terminal memory use: Stop repeatedly reading and parsing font files for terminal ligatures, fixing a source of high memory use and launch crashes in sessions with many terminals.
  • ⚡ Faster worktree switching: Performance improvements make switching between worktrees faster.
  • 📝 See what agents changed: Chat turns show changed files and line counts, with patches available inline on desktop and phone.
  • 🔐 Chrome-compatible password manager: Enable in Settings → Browser to save, fill, import Chrome passwords, and manage logins, encrypted locally with your OS’s secure storage.
  • 💬 Chat UI keeps up with your agent: Long, tool-heavy turns stay connected in Chat UI, and new chats follow your agent’s own model configuration unless you choose a model.
  • 🖥️ More reliable terminals and hosts: Prevent stray escape-sequence text after terminal output gaps, and make paired-server workers and usage polling available on headless hosts.
  • 📱 Better phone continuity: Send chat with Cmd/Ctrl+Enter and keep paired devices following the tabs they open.

Highlights

  • Performance: Worktree switching is faster. Terminal ligatures no longer parse an entire font for every terminal. In the PR’s Windows test with Commit Mono, 32 terminals relaunched without the previous out-of-memory crash; results depend on fonts and workload. Closing a tool in a long agent turn also avoids scanning every other live tool.
  • Chat: Successful Claude and Codex edits appear as changed-file summaries in the conversation, with patch details loaded on selection. Chat UI no longer interrupts an otherwise healthy agent turn when it exceeds 128 live text or tool entries. Codex chats show requested wait durations and support goal pause, resume and clear.
  • Browser: Save and fill logins in Orca’s browser and manage them in browser settings. Passwords use OS-backed encryption; the vault is unavailable when secure storage is unavailable.
  • Terminal & remote hosts: Terminal stream recovery avoids printing partial escape sequences after output gaps. Headless hosts start the services needed for paired-server workers and usage polling.
  • Workspace & onboarding: Choose Chat UI during onboarding, hide the onboarding checklist, find hidden discovered worktrees outside project grouping, and use the improved inactive workspace cleanup interface.

Compatibility & upgrade notes

  • Terminal ligatures: Common ligatures remain available. Font-specific ligatures outside the built-in list may no longer join with the GPU renderer.
  • Browser passwords: The vault is available in the desktop browser, including local and SSH workspace pages; streamed paired-server pages and the web client do not have a vault. Secure OS encryption is required.
  • Chat model defaults: A new chat without an explicit model choice uses the agent’s configuration. The displayed default can be stale until the agent starts and reports its model.
  • Terminal recovery: Remote-runtime streams retain their existing recovery behavior.
