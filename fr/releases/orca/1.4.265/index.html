orque v1.4.265

Version précédente : 1.4.264 — Les commandes de discussion trouvent leur espace de travail, permettant ainsi au navigateur de fonctionner avec la bonne discussion.

Présentation d'Orca Bots (bêta) <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="20" height="20" valign="middle" />

Les robots Orca fonctionnent comme des coéquipiers de premier ordre : chaque session d'agent géré obtient ses outils et son identité, les robots peuvent partager au nom du propriétaire, ils suivent les fils de discussion Slack et les déclencheurs Gmail de manière plus fiable, et leur connexion est plus claire et plus sûre.

  • <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="20" height="20" valign="middle" /> Chaque session de bot obtient ses outils et son identité : Les sessions d'agent géré ne sont plus limitées à Claude et Codex ; chacun commence avec les outils et l’identité dont il a besoin.
  • 🔗 Les robots peuvent partager, tout comme le propriétaire : Les appelants de l'agent CLI peuvent utiliser le partage de la même manière que le propriétaire.
  • 💬 Les fils de discussion Slack montrent ce que fait un robot : Un fil de discussion reflète désormais ce sur quoi il travaille à son tour, et les réponses longues arrivent entières au lieu d'être découpées.
  • 📬 Les déclencheurs Gmail correspondent au véritable expéditeur : Les déclencheurs correspondent à l'adresse réelle de l'expéditeur, et non à un nom d'affichage qui peut différer.
  • 🛡️ Avertissements d'accès plus clairs : La boîte de dialogue de confirmation d'accès indique désormais ce que vous autorisez avant de connecter un bot.

Faits saillants

Bots, connecteurs et accès. Connectez un bot via un sélecteur de connecteurs plus rapide avec des icônes de catégorie, une boîte de dialogue de connexion Slack réduite qui montre comment mentionner le bot une fois qu'il est installé et un avertissement de contrôle d'accès plus clair. Les autres conversations sont répertoriées à titre de référence uniquement dans le contexte d'un agent, afin qu'un robot reste concentré sur celle pour laquelle il a été interrogé. Les alertes de fin et les rapports d'arrêt des travailleurs contiennent la réponse ajoutée par une lecture de transcription, et les agents sont informés du type de courrier à définir, y compris via --on. Un bureau plus léger pour les discussions et les terminaux occupés. Les longues bandes d'onglets affichent uniquement la région visible, la session enregistre les entrées modifiées, les nouveaux messages passent pendant que d'autres discussions sont diffusées et une boucle de défilement du terminal qui pourrait geler la fenêtre est corrigée. Envoyer pendant que d'autres discussions sont diffusées. Le travail d'envoi d'une nouvelle discussion a la priorité sur les écritures en continu en arrière-plan. Les compositeurs masqués cessent également d'écouter chaque frappe, et les discussions fermées libèrent des lignes d'état dont elles n'ont plus besoin. Ces changements réduisent le travail concurrent lorsque plusieurs conversations sont actives. Lisez le statut sans perdre le fil. Développez les lignes d'activité pour plus de détails ou ouvrez la propre vue d'un sous-agent. Le texte avant une question reste visible une fois le tour plié, les diagrammes conservés survivent aux changements d'espace de travail et de nombreux messages antérieurs ayant échoué proposent de réessayer. Utilisez l'agent sur le bon hôte. L'installation de Claude et Codex suit l'hôte sur lequel le chat s'exécute. Une installation personnelle existante est prioritaire ; Les copies gérées d’Orca sont également disponibles sur ses terminaux. Les contrôles de compte à distance et les affichages d'utilisation reçoivent également des correctifs. Choisissez les mises à jour automatiques du bureau. Activez Mises à jour automatiques dans Paramètres → Général → À propos pour permettre à Orca de télécharger, d'installer et de relancer en utilisant votre cadence, votre canal et votre délai de mise à jour. Par défaut, il est désactivé. L'installation automatique attend si elle met fin à un terminal en cours ou en cours de lancement, si un déplacement WSL est actif ou si l'état de la fenêtre ne peut pas être enregistré. Compatibilité téléphonique. Les modifications téléphoniques répertoriées ci-dessous sont des modifications sources incluses dans les limites de cette version. L'installation de cette mise à jour de bureau n'installe pas de mise à jour d'application mobile ; ces fonctionnalités nécessitent la version mobile correspondante.

orca v1.4.265

Previous release: 1.4.264 — Chat commands find their workspace, keeping browser work with the right chat.

Introducing Orca Bots (Beta) <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="20" height="20" valign="middle" />

Orca Bots work like first-class teammates: every managed agent session gets its tools and identity, bots can share on the owner's behalf, they follow Slack threads and Gmail triggers more reliably, and connecting them is clearer and safer.

  • <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="20" height="20" valign="middle" /> Every bot session gets its tools and identity: Managed agent sessions are no longer limited to Claude and Codex; each one starts with the tools and identity it needs.
  • 🔗 Bots can share, just like the owner: Agent CLI callers can use Sharing the same way the owner does.
  • 💬 Slack threads show what a bot is doing: A thread now reflects what its turn is working on, and long answers arrive whole instead of cut up.
  • 📬 Gmail triggers match the real sender: Triggers match the sender's actual address, not a display name that can differ.
  • 🛡️ Clearer access warnings: The access confirm dialog now spells out what you are allowing before you connect a bot.

Highlights

Bots, connectors and access. Connect a bot through a faster connector picker with category icons, a trimmed Slack connect dialog that shows how to mention the bot once it is installed, and a clearer access-control warning. Other conversations are listed for reference only in an agent's context, so a bot stays focused on the one it was asked about. Finish alerts and worker stop reports carry the reply a transcript read adds, and agents are told which mail type to set, including over --on.

A lighter desktop for busy chats and terminals. Long tab strips render only the visible region, session saves write changed entries, new messages get through while other chats stream, and a terminal scroll loop that could freeze the window is fixed.

Send while other chats stream. A new chat’s sending work gets priority over background streaming writes. Hidden composers also stop listening to every keystroke, and closed chats release status rows they no longer need. These changes reduce competing work when several conversations are active.

Read status without losing the thread. Expand activity rows for details or open a subagent’s own view. Text before a question remains visible after the turn folds, retained diagrams survive workspace switches, and failed loads of earlier messages offer Retry.

Use the agent on the right host. Claude and Codex installation follows the host where the chat runs. An existing personal installation takes precedence; Orca’s managed copies are available to its terminals too. Remote account controls and usage displays also receive fixes.

Choose automatic desktop updates. Enable Automatic updates in Settings → General → About to let Orca download, install and relaunch using your update cadence, channel and delay. It defaults to off. Automatic installation waits if it would terminate a live or launching in-process terminal, a WSL move is active, or window state cannot be saved.

Phone compatibility. The phone changes listed below are source changes included in this release boundary. Installing this desktop update does not install a mobile app update; those features require the corresponding mobile build.
