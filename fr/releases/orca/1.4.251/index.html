orque v1.4.251

Chats téléphoniques plus riches, ajouts au chat depuis n'importe où et terminaux plus stables ✨

  • 📱 Beaucoup plus de discussions au téléphone : Revenez à un message précédent, continuez une réponse interrompue, épinglez le plan de l'agent au-dessus du compositeur, collez des images et du texte long, gérez l'objectif d'une discussion et consultez l'utilisation du contexte, les brouillons non envoyés étant conservés lors du redémarrage de l'application.
  • 📎 Ajoutez n'importe quoi au chat : Envoyez une sélection à partir d'un fichier, d'un aperçu Markdown ou d'un terminal à n'importe quel agent de l'espace de travail, ou démarrez un nouvel agent avec.
  • 🔁 Les discussions reprennent après un redémarrage : Les nouvelles installations reprennent automatiquement les discussions fonctionnelles après la fermeture ou la mise à jour d'Orca, et la reprise est plus fiable pour tous ceux qui l'utilisent.
  • 🤖 Les travailleurs peuvent démarrer leurs propres travailleurs : Les travailleurs imbriqués sont autorisés par défaut, les travailleurs terminés peuvent continuer à envoyer des messages à leur coordinateur et l'arrêt d'un travailleur arrête ses assistants.
  • ⚡ Travail quotidien plus rapide : Le lancement évite une deuxième capture du shell de connexion, le contrôle de source et la barre d'onglets effectuent un travail moins répété et les longues discussions restent réactives.
  • 🖥️ Terminaux plus stables : Les terminaux se reconnectent après une reconnexion du démon, survivent à une application occupée et les nouveaux canevas GPU ne clignotent plus vides.
  • 🗂️ Organisation de projet plus simple : Réduisez ou développez tous les projets, créez un arbre de travail enfant à partir du menu contextuel et actualisez les groupes de projets du dossier.

Faits saillants

  • Chat : Ajoutez un fichier, un aperçu Markdown ou une sélection de terminal à un chat. Les messages d'agent utilisent des cartes d'une seule ligne sur le bureau et le téléphone, les discussions natives apparaissent dans les messages récents et la recherche de titre Cmd+J, et Cmd/Ctrl+Entrée sur un compositeur vide dirige le premier message en file d'attente. Les discussions de Claude maintiennent l'effort modifiable après la première réponse et effacent le statut bloqué "besoin d'autorisation" lorsque Claude met fin à la demande elle-même. Les discussions du Codex affichent /usage et les noms des tâches des sous-agents.
  • Téléphone : Rembobinez et poursuivez les discussions, épinglez le plan, collez des images et du texte long, définissez et gérez des objectifs, consultez l'anneau d'utilisation du contexte, suivez les tâches en arrière-plan, copiez ou partagez des images, copiez les chemins de fichiers, choisissez où les liens s'ouvrent et connectez-vous à partir d'une discussion déconnectée.
  • Orchestration : Les travailleurs peuvent démarrer leurs propres travailleurs, continuer à envoyer des messages à leur coordinateur une fois qu'ils ont terminé et arrêter leurs assistants lorsqu'ils sont arrêtés. Mail attend un brouillon que vous tapez, y compris dans OpenCode et après un redémarrage.
  • Performances : Le démarrage, les badges de conflit de contrôle de source et les comparaisons de branches, la barre d'onglets, la détection de connexion au navigateur, les apparitions du terminal Pi et les images du catalogue de plugins effectuent tous un travail moins répété. Les longues discussions ne réanalysent plus l’intégralité de leur historique à chaque mise à jour de statut. Les discussions avec les agents ACP cessent également de conserver les enregistrements d'outils et de messages terminés pendant toute la durée de la discussion.
  • Terminaux et hôtes distants : Les terminaux se rattachent après une reconnexion du démon et conservent leur lien malgré un gel du processus principal. SSH explique quand la configuration du serveur d'un hôte s'arrête pour une cause connue et arrête de redémarrer un serveur qui ne cesse de planter. Les actions du serveur reconnectent un serveur déconnecté.

Notes de compatibilité et de mise à niveau

  • Profondeur de travailleur imbriqué : La valeur par défaut est désormais de 4. Les profils existants définis sur 1 passent à 4 lors de la mise à niveau ; vous pouvez le redéfinir dans Paramètres, et Orca conserve ce choix.
  • Reprendre les discussions de travail après le redémarrage : Activé par défaut pour les nouvelles installations uniquement. Les utilisateurs existants conservent leur choix enregistré et les profils existants qui n'ont jamais choisi restent désactivés.
  • Statut d'autorisation de Claude : La suppression d'un statut "nécessite une autorisation" auquel Claude a mis fin lui-même nécessite Claude 2.1.118 ou une version ultérieure. Orca installe un hook Claude géré supplémentaire pour cela ; les anciennes versions de Claude conservent le comportement précédent.
  • Mises à jour macOS : Les Mac dont la version minimale de macOS est inférieure à une version restent sur leur dernière version compatible et reçoivent un avis unique. Le minimum est toujours macOS 12, donc rien ne change pour l'instant.
  • Menu de l'interface utilisateur de chat : "Fork Agent Session…" n'est plus dans le menu de l'interface utilisateur de chat. Les terminaux le gardent.

orca v1.4.251

Richer phone chats, add-to-chat from anywhere & steadier terminals ✨

  • 📱 Much more chat on the phone: Rewind to an earlier message, continue a stopped reply, pin the agent's plan above the composer, paste images and long text, manage a chat's goal and see context usage, with unsent drafts kept across an app restart.
  • 📎 Add anything to chat: Send a selection from a file, a Markdown preview or a terminal to any agent in the workspace, or start a new agent with it.
  • 🔁 Chats pick up after a restart: New installs resume working chats automatically after Orca quits or updates, and resuming is more reliable for everyone who has it on.
  • 🤖 Workers can start their own workers: Nested workers are allowed by default, finished workers can keep messaging their coordinator, and stopping a worker stops its helpers.
  • ⚡ Faster everyday work: Launch skips a second login-shell capture, source control and the tab bar do less repeated work, and long chats stay responsive.
  • 🖥️ Steadier terminals: Terminals re-attach after a daemon reconnect, survive a busy app, and new GPU canvases no longer flash blank.
  • 🗂️ Easier project organization: Collapse or expand all projects, create a child worktree from the context menu and refresh folder project groups.

Highlights

  • Chat: Add a file, Markdown preview or terminal selection to a chat. Agent messages use one-line cards on desktop and phone, native chats appear in Cmd+J recents and title search, and Cmd/Ctrl+Enter on an empty composer steers the first queued message. Claude chats keep effort changeable after the first reply and clear a stuck "needs permission" status when Claude ends the request itself. Codex chats show /usage and subagent task names.
  • Phone: Rewind and continue chats, pin the plan, paste images and long text, set and manage goals, see the context usage ring, follow background tasks, copy or share images, copy file paths, choose where links open, and sign in from a signed-out chat.
  • Orchestration: Workers can start their own workers, keep messaging their coordinator after they finish, and stop their helpers when stopped. Mail waits for a draft you are typing, including in OpenCode and after a restart.
  • Performance: Startup, source control conflict badges and branch compares, the tab bar, browser login detection, Pi terminal spawns and plugin catalog images all do less repeated work. Long chats no longer rescan their whole history on every status update. Chats with ACP agents also stop holding on to finished tool and message records for the chat's whole life.
  • Terminals & remote hosts: Terminals re-attach after a daemon reconnect and keep their link through a main-process freeze. SSH explains when a host's server setup stops on a known cause and stops restarting a server that keeps crashing. Server actions reconnect a disconnected server.

Compatibility & upgrade notes

  • Nested worker depth: The default is now 4. Existing profiles set to 1 move to 4 on upgrade; you can set it back in Settings, and Orca keeps that choice.
  • Resume working chats after restart: On by default for new installs only. Existing users keep their saved choice, and existing profiles that never chose stay off.
  • Claude permission status: Clearing a "needs permission" status that Claude ended itself needs Claude 2.1.118 or later. Orca installs one more managed Claude hook for it; older Claude versions keep the previous behavior.
  • macOS updates: Macs below a release's minimum macOS stay on their last compatible build and get a one-time notice. The minimum is still macOS 12, so nothing changes yet.
  • Chat UI menu: "Fork Agent Session…" is no longer in Chat UI's menu. Terminals keep it.
