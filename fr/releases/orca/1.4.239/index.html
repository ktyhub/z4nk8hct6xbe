orque v1.4.239

Deux versions aujourd'hui ! Découvrez également les v1.4.238 release note. Cette version a apporté des modifications non enregistrées partagées dans les espaces de travail, des discussions d'agent plus riches et une configuration de compte à distance, un navigateur plus performant et des commandes téléphoniques plus fluides.

Votre espace de travail, travailler ensemble 🐳

Configurez les compétences d'agent dans un seul click, séparez les sessions de navigateur entre les projets et passez plus facilement du chat au terminal. Cette version renforce également l'essentiel : les fichiers partagés restent synchronisés, les sessions SSH se rétablissent de manière plus fiable et les interactions téléphoniques semblent plus prévisibles.

La version courte

  • Compétences, prêtes partout où vous travaillez : Installez les compétences d'Orca dans un click à partir des écrans de configuration, et installez-les ou mettez-les à jour sur des serveurs couplés et des hôtes SSH avec le propre programme d'installation d'Orca.
  • Un navigateur adapté à vos projets : Choisissez des profils partagés, par dépôt ou par espace de travail pour les nouveaux onglets. Séparez les connexions aux applications locales, utilisez un menu contextuel de page familier et obtenez des explications plus claires lorsqu'une page ne peut pas se charger.
  • Conversations d'agent plus fluides : Divisez-vous en une nouvelle discussion à côté de votre conversation actuelle, continuez avec un agent de terminal à partir de l'en-tête du volet et conservez intacts les messages en file d'attente et les multiples pièces jointes d'images.
  • Modifications plus sûres, travail en arrière-plan plus silencieux : Les vues des fichiers partagés restent à jour après annulation et suppression. Les fichiers non UTF-8 demandent avant la conversion, la surveillance des fichiers récupère après des ralentissements et Orca surveille moins de fichiers sans rapport.
  • Travail à distance avec un retour en arrière : Récupérez les serveurs SSH gérés pris en charge à partir d'un verrou obsolète dans les paramètres, restaurez les terminaux après la connexion par mot de passe et conservez le lien d'accès SSH d'un serveur couplé lors des redémarrages.
  • Mieux depuis votre téléphone : Appuyer sur une notification ouvre l'agent qui l'a envoyée, les onglets de discussion de l'agent peuvent démarrer la dictée, les commandes de copie du terminal atteignent le téléphone clipboard et le défilement Android maintient le clavier à l'écart.
  • Peaufinage quotidien, dans toutes les langues : Meilleure saisie en coréen, rendu des terminaux bengali et autres indiens, traductions plus complètes, sélecteurs d'utilisateurs Jira et liens de commentaires PR qui accèdent directement à l'éditeur. Mises à jour du téléphone : La mise à jour d'Orca sur l'ordinateur qui dessert votre téléphone met à jour l'interface servie. Les améliorations natives du téléchargement, de la progression et de la navigation nécessitent une application téléphonique native mise à jour.

Notes de compatibilité et de mise à niveau

  • Profils de navigateur : Choisissez Paramètres → Navigateur → Profil pour les nouveaux onglets. Partagé reste la valeur par défaut ; Les profils par dépôt et par espace de travail s'appliquent aux nouveaux onglets. Les pages de serveurs couplés utilisent les propres profils du serveur.
  • Chat natif (expérimental) : Mettez à jour les hôtes couplés et SSH aux côtés d'Orca pour les derniers correctifs de chat et de lancement. La disponibilité du chat vérifie désormais le temps d'exécution du chat séparément du terminal CLI, y compris les configurations Antigravity prises en charge.
  • Récupération SSH : Le serveur de récupération… est disponible pour les hôtes Linux SSH gérés pris en charge signalant un refus de verrouillage obsolète. Il vérifie le verrou et vous demande de confirmer qu'aucune autre machine partageant cette maison n'exécute Orca avant de l'effacer. Les téléphones vous dirigent vers les paramètres du bureau.
  • Travail préparatoire expérimental : Le travail préparatoire du propriétaire de la mise en page reste désactivé. Les actions de lancement de groupe vide et la bascule d'état de l'espace de travail enfant ont été annulées avant la publication.

orca v1.4.239

Two releases today! Check out the v1.4.238 release notes too. That release brought shared unsaved edits across workspaces, richer agent chats and remote account setup, a more capable browser, and smoother phone controls.

Your workspace, working together 🐳

Set up agent skills in one click, keep browser sessions separate between projects, and move more easily between chat and terminal. This release also strengthens the essentials: shared files stay in sync, SSH sessions recover more reliably, and phone interactions feel more predictable.

The short version

  • Skills, ready wherever you work: Install Orca’s skills in one click from setup screens, and install or update them on paired servers and SSH hosts with Orca’s own installer.
  • A browser that fits your projects: Choose shared, per-repo or per-workspace profiles for new tabs. Keep local app logins separate, use a familiar page context menu, and get clearer explanations when a page cannot load.
  • More fluid agent conversations: Split into a fresh chat beside your current one, continue with a terminal agent from the pane header, and keep queued messages and multiple image attachments intact.
  • Safer edits, quieter background work: Shared file views stay current after undo and discard. Non-UTF-8 files ask before conversion, file watching recovers after slowdowns, and Orca watches fewer unrelated files.
  • Remote work with a way back: Recover supported managed SSH servers from a stale lock in Settings, restore terminals after password sign-in, and keep a paired server’s SSH access link through restarts.
  • Better from your phone: Tapping a notification opens the agent that sent it, agent chat tabs can start dictation, terminal copy commands reach the phone clipboard, and Android scrolling keeps the keyboard out of the way.
  • Everyday polish, across languages: Better Korean input, Bengali and other Indic terminal rendering, more complete translations, Jira user pickers, and PR comment links that jump straight to the editor.

Phone updates: Updating Orca on the computer serving your phone updates the served interface. Native download, progress and navigation improvements require an updated native phone app.

Compatibility & upgrade notes

  • Browser profiles: Choose Settings → Browser → Profile for new tabs. Shared remains the default; per-repo and per-workspace profiles apply to new tabs. Paired-server pages use the server’s own profiles.
  • Native chat (experimental): Update paired and SSH hosts alongside Orca for the latest chat and launch fixes. Chat availability now checks the chat runtime separately from the terminal CLI, including supported Antigravity setups.
  • SSH recovery: Recover server… is available for supported managed Linux SSH hosts reporting a stale-lock refusal. It checks the lock and asks you to confirm that no other machine sharing that home is running Orca before clearing it. Phones point you to desktop Settings.
  • Experimental groundwork: The layout-owner groundwork remains disabled. The empty-group launch actions and child-workspace status toggle were reverted before release.
