orque v1.4.242

Plus léger en mémoire, Claude sous-agents à click, et des serveurs distants qui se souviennent 🪄

Cette version est plus légère en termes de mémoire, avec une utilisation moindre de la mémoire dans l'hôte du terminal et les connexions WSL, ainsi qu'une utilisation moindre du processeur inactif dans les terminaux. Il vous permet également d'ouvrir les sous-agents Claude directement à partir de la barre latérale, de demander aux discussions Codex en mode Demander avant de modifier et d'aider les serveurs couplés, les hôtes SSH et WSL à garder un œil sur vous et à expliquer les échecs. Cette version corrige également des problèmes sous Windows, Linux et macOS.

La version courte

  • Ouvrir les sous-agents Claude depuis la barre latérale : Click une ligne de sous-agent Claude dans la barre latérale ou le tableau de bord pour ouvrir sa transcription dans le même terminal, puis click le parent pour revenir en arrière. Un œil marque celui que vous regardez.
  • Chats qui demandent en premier : Les chats Codex en mode Demander demandent désormais avant de modifier votre espace de travail, les terminaux Claude distants sur des serveurs couplés peuvent continuer dans Chat et les chats qui ne peuvent pas démarrer vous expliquent pourquoi.
  • Les agents reprennent tels que vous les avez quittés : Les sessions Claude reprises conservent leur niveau d'effort et lancent des indicateurs, le Codex conserve la dernière autorisation que vous lui avez donnée et l'historique de session trouve les discussions dans davantage de dossiers et sur des serveurs.
  • Serveurs distants qui se souviennent : Les serveurs couplés gardent vos onglets lors des redémarrages, les onglets fermés restent fermés, les hôtes WSL arrêtent de se réassocier après chaque redémarrage et les échecs SSH indiquent ce qui n'a pas fonctionné.
  • Plus léger en mémoire : Les terminaux utilisent beaucoup moins de processeur inactif, l'hôte du terminal utilise moins de mémoire lors de son prochain redémarrage, les connexions WSL ont besoin de beaucoup moins de mémoire et le panneau de ressources correspond désormais au moniteur d'activité sur macOS.
  • Corrections de la communauté : Chemins de lancement Windows espacés, saisie coréenne, DST dans les automatisations, focus-follows-mouse, déplacement d'onglets et packages Linux fonctionnent tous mieux. Mises à jour sur le téléphone et sur le Web : Les téléphones expliquent désormais un ordinateur inaccessible au lieu de tourner indéfiniment, et les réponses en streaming et les longues discussions sur le Web se redessinent moins. Les programmes de terminal qui posent une question au terminal continuent également de fonctionner pendant qu'un téléphone regarde à la taille d'un ordinateur de bureau.

Notes de compatibilité et de mise à niveau

  • ** Discussions Codex en mode Demande : ** Demander s'exécute désormais en lecture seule et demande avant les modifications de l'espace de travail ; Approuver pour moi et Accès complet restent inchangés, et les travaux déjà en cours conservent leur octroi. Les discussions sur un serveur couplé conservent l'ancien comportement jusqu'à ce que ce serveur soit mis à jour.
  • Navigation du sous-agent Claude : Activée par défaut avec les hooks d'état Claude. Orca charge son plugin uniquement dans les volets Orca et ajoute un raccourci, le premier sans Ctrl+Alt+G, H ou V, vers keybindings.json dans chaque dossier Claude qu'il utilise. Désactivez-le dans Paramètres → Agents → Navigation sous-agent Claude pour supprimer ce raccourci. Les sessions Claude déjà en cours ont besoin d'un nouveau lancement.
  • Serveurs couplés : Le déplacement d'un volet dans un nouvel onglet et la poursuite d'un terminal Claude distant dans Chat nécessitent que le serveur exécute cette version. Sur les serveurs plus anciens, le déplacement reste dans cette fenêtre uniquement, comme auparavant, et Continuer dans l'interface utilisateur du chat s'affiche désactivé avec un indice de mise à jour.
  • Changement de compte Claude : Le changement de compte propose désormais également de redémarrer les sessions en cours d'exécution dans votre dossier Claude par défaut du système lorsque ce dossier est connecté à l'ancien compte. La boîte de dialogue regroupe les sessions entre celles de l’ancien compte, les autres et celles qu’elle ne peut pas déplacer.
  • Hôtes WSL : Les connexions au serveur d'un hôte WSL passent désormais par bash et reviennent à Node lorsque bash est manquant ou trop ancien. Cela ne nécessite aucune mise à jour du serveur et fonctionne avec n'importe quelle version du serveur.

orca v1.4.242

Lighter on memory, Claude subagents a click away, and remote servers that remember 🪄

This release is lighter on memory, with lower memory use in the terminal host and WSL connections, plus less idle CPU use in terminals. It also lets you open Claude subagents straight from the sidebar, makes Codex chats in Ask mode ask before editing, and helps paired servers, SSH and WSL hosts keep your tabs and explain failures. This release also fixes problems across Windows, Linux and macOS.

The short version

  • Open Claude subagents from the sidebar: Click a Claude subagent row in the sidebar or dashboard to open its transcript in the same terminal, then click the parent to go back. An eye marks the one you’re viewing.
  • Chats that ask first: Codex chats in Ask mode now ask before editing your workspace, remote Claude terminals on paired servers can continue in Chat, and chats that can’t start tell you why.
  • Agents resume as you left them: Resumed Claude sessions keep their effort level and launch flags, Codex keeps the permission you last gave it, and Session History finds chats in more folders and on servers.
  • Remote servers that remember: Paired servers keep your tabs across restarts, closed tabs stay closed, WSL hosts stop re-pairing after each restart, and SSH failures say what actually went wrong.
  • Lighter on memory: Terminals use far less idle CPU, the terminal host uses less memory once it next restarts, WSL connections need much less memory, and the resource panel now matches Activity Monitor on macOS.
  • Fixes from the community: Spaced Windows launcher paths, Korean input, DST in automations, focus-follows-mouse, tab dragging and Linux packages all work better.

Phone & web updates: Phones now explain an unreachable computer instead of spinning forever, and streaming replies and long web chats redraw less. Terminal programs that ask the terminal a question also keep working while a phone watches at desktop size.

Compatibility & upgrade notes

  • Codex chats in Ask mode: Ask now runs read-only and asks before workspace edits; Approve for me and Full access are unchanged, and work already running keeps its grant. Chats on a paired server keep the old behavior until that server is updated.
  • Claude subagent navigation: On by default with Claude status hooks. Orca loads its plugin only into Orca panes and adds one shortcut, the first free of Ctrl+Alt+G, H or V, to keybindings.json in each Claude folder it uses. Turn it off in Settings → Agents → Claude subagent navigation to remove that shortcut. Claude sessions already running need a fresh launch.
  • Paired servers: Moving a pane into a new tab and continuing a remote Claude terminal in Chat need the server to run this release. On older servers the move stays in this window only, as before, and Continue in Chat UI shows disabled with an update hint.
  • Claude account switching: Switching accounts now also offers to restart sessions running in your System default Claude folder when that folder is signed in to the old account. The dialog groups sessions into those on the old account, others, and ones it can’t move.
  • WSL hosts: Connections to a WSL host’s server now go through bash and fall back to Node when bash is missing or too old. This needs no server update and works with any server version.
