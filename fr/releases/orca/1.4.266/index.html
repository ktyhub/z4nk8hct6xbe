orque v1.4.266

Version précédente : 1.4.265 : Orca Bots en tant que coéquipiers de première classe, avec un bureau plus léger pour les discussions chargées.

Présentation d'Orca Bots (bêta) <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="36" height="36" valign="middle" />

Les robots Orca fonctionnent comme des coéquipiers de premier ordre : chaque session d'agent géré obtient ses outils et son identité, les robots peuvent partager au nom du propriétaire, ils suivent les fils de discussion Slack et les déclencheurs Gmail de manière plus fiable, et leur connexion est plus claire et plus sûre.

  • <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="28" height="28" valign="middle" /> Chaque session de bot obtient ses outils et son identité : Les sessions d'agent géré ne sont plus limitées à Claude et Codex ; chacun commence avec les outils et l’identité dont il a besoin.
  • 🔗 Les robots peuvent partager, tout comme le propriétaire : Les appelants de l'agent CLI peuvent utiliser le partage de la même manière que le propriétaire.
  • 💬 Les fils de discussion Slack montrent ce que fait un robot : Un fil de discussion reflète désormais ce sur quoi il travaille à son tour, et les réponses longues arrivent entières au lieu d'être découpées.
  • 📬 Les déclencheurs Gmail correspondent au véritable expéditeur : Les déclencheurs correspondent à l'adresse réelle de l'expéditeur, et non à un nom d'affichage qui peut différer.
  • 🛡️ Avertissements d'accès plus clairs : La boîte de dialogue de confirmation d'accès indique désormais ce que vous autorisez avant de connecter un bot. Nous avons expédié deux versions aujourd'hui. Découvrez également la version précédente, 1.4.265.

Connectez-vous à Antigravity à votre façon

Les discussions antigravité peuvent désormais se connecter avec une clé Gemini API ou Google Agent Platform (ADC), et les nouvelles discussions s'exécutent sur une agy connectée, de sorte que la discussion, le quota et le compte choisi sont tous d'accord. Un plus grand nombre d'agents fonctionnent également immédiatement : Orca installe ses propres copies lorsqu'un hôte n'en a pas.

  • 🔑 Clé Gemini API ou Google Agent Platform : Choisissez comment un chat Antigravity se connecte et voyez le même compte dans le chat et le quota.
  • 📦 Plus d'agents, prêts à l'emploi : Orca installe ses propres OpenCode, Cursor, Copilot, Grok, Kimi Code et OMP lorsqu'un hôte n'en a pas, et propose des mises à jour CLI pour chaque agent de chat natif.
  • 🛡️ Antigravité plus stable sur chaque plate-forme : Les mises à jour automatiques restent désactivées pour les lancements d'hôtes, la découverte de Windows et le timing de hook sont corrigés et le réviseur décide de l'utilisation de l'outil.
  • 🖼️ Aperçus d'images : Les images récemment collées et déposées affichent un aperçu, et les aperçus d'images du Codex CLI fonctionnent.
  • 📱 Un téléphone plus convivial : Les cloches non lues sur les lignes d'agent et les onglets de session, la version Orca de votre hôte avec les étapes de mise à jour, et fini les compteurs sans fin sur les ordinateurs de bureau qu'il ne peut pas atteindre.

Faits saillants

Bots, commentaires et barre latérale. Réorganisez les robots et les projets dans la barre latérale, écrivez des commentaires d'éléments plus longs dans un compositeur empilé, parcourez les éléments sans le quitter et répondez à une question ouverte directement depuis sa carte dans Activité. La barre latérale réduite des Bots est plus claire et les mentions de Slack dans le chat des agents s'affichent sous forme de noms. ** Discussions plus silencieuses et plus calmes. ** Les tours silencieux terminés masquent leur barre Travaillé pour avec un léger fondu, et la reprise au redémarrage est un petit toast au lieu d'une boîte de dialogue. Les onglets du terminal conservent leur nom après leur fermeture et à leur reprise. Construit pour les serveurs couplés. Ouvrez les liens d'hôte local à partir de SSH et des hôtes couplés dans le navigateur Orca de cet hôte, lisez la vidéo et l'audio dans les aperçus HTML à distance, et lisez et modifiez les commutateurs de notification d'un serveur à partir d'un client couplé. Les serveurs sans tête arrêtent de publier les mises à jour qu'ils ne peuvent pas effectuer. Plus léger sur votre ordinateur. Les sauvegardes de session conservent les entrées inchangées identiques, le travail sur l'état de l'hôte s'effectue uniquement pour les hôtes qui ont changé et les outils Windows se lancent à partir de chemins System32 absolus. Linux ouvre un trousseau de clés sans mot de passe avant de revenir en arrière, et les installations .deb reconditionnées ne sont plus transmises à dpkg. Compatibilité téléphonique. Les modifications téléphoniques répertoriées ci-dessous sont des modifications sources incluses dans les limites de cette version. L'installation de cette mise à jour de bureau n'installe pas de mise à jour d'application mobile ; ces fonctionnalités nécessitent la version mobile correspondante.

orca v1.4.266

Previous release: 1.4.265: Orca Bots as first-class teammates, with a lighter desktop for busy chats.

Introducing Orca Bots (Beta) <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="36" height="36" valign="middle" />

Orca Bots work like first-class teammates: every managed agent session gets its tools and identity, bots can share on the owner's behalf, they follow Slack threads and Gmail triggers more reliably, and connecting them is clearer and safer.

  • <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="28" height="28" valign="middle" /> Every bot session gets its tools and identity: Managed agent sessions are no longer limited to Claude and Codex; each one starts with the tools and identity it needs.
  • 🔗 Bots can share, just like the owner: Agent CLI callers can use Sharing the same way the owner does.
  • 💬 Slack threads show what a bot is doing: A thread now reflects what its turn is working on, and long answers arrive whole instead of cut up.
  • 📬 Gmail triggers match the real sender: Triggers match the sender's actual address, not a display name that can differ.
  • 🛡️ Clearer access warnings: The access confirm dialog now spells out what you are allowing before you connect a bot.

We shipped two releases today. Check out the previous release, 1.4.265 too.

Sign in to Antigravity your way

Antigravity chats can now sign in with a Gemini API key or Google Agent Platform (ADC), and new chats run on a signed-in agy so chat, quota and the picked account all agree. More agents also work out of the box: Orca installs its own copies when a host has none.

  • 🔑 Gemini API key or Google Agent Platform: Choose how an Antigravity chat signs in, and see the same account in chat and quota.
  • 📦 More agents, ready to use: Orca installs its own OpenCode, Cursor, Copilot, Grok, Kimi Code and OMP when a host has none, and offers CLI updates for every native-chat agent.
  • 🛡️ Steadier Antigravity on every platform: Auto-updates stay off for host launches, Windows discovery and hook timing are fixed, and the reviewer decides on tool use.
  • 🖼️ Image previews: Recent pasted and dropped images show a preview, and Codex CLI image previews work.
  • 📱 A friendlier phone: Unread bells on agent rows and session tabs, your host's Orca version with update steps, and no more endless spinners on desktops it cannot reach.

Highlights

Bots, comments and the sidebar. Reorder Bots and Projects in the sidebar, write longer item comments in a stacked composer, step through items without leaving it, and reply to an open question straight from its card in Activity. The collapsed Bots sidebar is clearer, and Slack mentions in agent chat show as names.

Quieter, calmer chats. Finished quiet turns hide their Worked for bar with a gentle fade, and resume-on-restart is a small toast instead of a dialog. Terminal tabs keep their name after they close and on resume.

Built for paired servers. Open localhost links from SSH and paired hosts in that host's Orca browser, play video and audio in remote HTML previews, and read and change a server's notification switches from a paired client. Headless servers stop advertising updates they cannot perform.

Lighter on your machine. Session saves keep unchanged entries identical, host status work happens only for hosts that changed, and Windows tools launch from absolute System32 paths. Linux opens a password-less keyring before falling back, and repackaged .deb installs are no longer handed to dpkg.

Phone compatibility. The phone changes listed below are source changes included in this release boundary. Installing this desktop update does not install a mobile app update; those features require the corresponding mobile build.
