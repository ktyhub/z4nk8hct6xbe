orque v1.4.269

Après 1.4.268, voici le prochain tour d'Orca. Les robots apprennent huit agents supplémentaires et l'application téléphonique rattrape le bureau.

Bots sur huit agents supplémentaires, un téléphone plus complet et un Mac plus silencieux ✨

Les robots peuvent désormais fonctionner sur Kiro, Kimi Code, Auggie, Gemini CLI, Kilo Code, MiMo Code, Droid et Goose, Chat ouvre directement plus d'agents et l'application téléphonique peut répondre, approuver et configurer presque tout ce que le bureau peut faire.

  • 🤖 Exécutez des robots sur plus d'agents : Les robots peuvent fonctionner sur Kiro, Kimi Code, Auggie, Gemini CLI, Kilo Code, MiMo Code, Droid et Goose. Le chat peut également ouvrir Kiro, Auggie et Goose, et les chats Kiro exécutent vos propres hooks.
  • 📱 Faites plus depuis votre téléphone : Répondez aux questions d'un agent et aux cartes de configuration Google ou Composio depuis son chat, examinez les approbations des outils et les demandes d'accès dans Besoins de vous, gérez les outils et les webhooks d'un agent, démarrez une nouvelle discussion à partir de + et parcourez les fils de discussion et les éléments d'un groupe. Ceux-ci ont besoin de la version mobile correspondante.
  • 🔐 Antigravity, à votre façon : Les utilisateurs de comptes Google peuvent choisir la connexion Google intégrée à Orca ou l'agent agy, et agy a sa propre connexion dans les paramètres.
  • 💤 Un Mac plus silencieux lorsqu'il est inactif : Les terminaux Mac inactifs utilisent moins de CPU et le travail Git démarre sur le processus de travail en arrière-plan sur macOS et Linux.
  • 🧭 Chats plus clairs : Les messages plus anciens affichent les dates du calendrier, le CV apparaît dans une file d'attente en pause et les chats de Claude dont les paramètres bloquent l'accès complet le disent et choisissent le mode autorisé le plus proche.

Les robots Orca fonctionnent comme des coéquipiers de première classe : ils fonctionnent désormais avec beaucoup plus d'agents, travaillent main dans la main dans des salles de groupe et envoient des résultats que vous pouvez réellement ouvrir.

  • <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="28" height="28" valign="middle" /> Huit agents supplémentaires derrière vos robots : Kiro, Kimi Code, Auggie, Gemini CLI, Kilo Code, MiMo Code, Droid et Goose rejoignent les agents sur lesquels un bot peut s'exécuter.
  • Les liens affichent la progression pendant que les robots les publient, et vous pouvez rejeter une demande d'accès directement depuis sa boîte de dialogue Accorder l'accès.
  • 🤝 Transferts dans les salles de groupe : Lorsqu'un robot nomme un autre membre comme @Name dans sa réponse, ce membre prend le tour.
  • 📎 Résultats que vous pouvez ouvrir : Les robots partagent un lien, attachent le fichier ou donnent le contenu au lieu d'un chemin sur leur propre ordinateur, et les chemins locaux dans les messages Slack deviennent des étiquettes lisibles.
  • 🧩 Un dossier de compétences par bot : Les propres compétences d'un bot se trouvent dans un dossier neutre en termes d'agent que chaque agent sur lequel il s'exécute peut utiliser.

orca v1.4.269

Following 1.4.268, here is the next round of Orca. Bots learn eight more agents, and the phone app catches up with the desktop.

Bots on eight more agents, a fuller phone & a quieter Mac ✨

Bots can now run on Kiro, Kimi Code, Auggie, Gemini CLI, Kilo Code, MiMo Code, Droid and Goose, Chat opens more agents directly, and the phone app can answer, approve and set up almost everything the desktop can.

  • 🤖 Run bots on more agents: Bots can run on Kiro, Kimi Code, Auggie, Gemini CLI, Kilo Code, MiMo Code, Droid and Goose. Chat can open Kiro, Auggie and Goose too, and Kiro chats run your own hooks.
  • 📱 Do more from your phone: Answer an agent's questions and Google or Composio setup cards from its chat, review tool approvals and access requests in Needs you, manage an agent's tools and webhooks, start a new chat from +, and browse a group's threads and items. These need the matching mobile build.
  • 🔐 Antigravity, your way: Google account users can pick Orca's built-in Google sign-in or the agy agent, and agy has its own Sign in in Settings.
  • 💤 A quieter Mac when idle: Idle Mac terminals use less CPU, and Git work starts on the background process worker on macOS and Linux.
  • 🧭 Clearer chats: Older messages show calendar dates, Resume stands out in a paused queue, and Claude chats that settings block from Full access say so and pick the closest allowed mode.

About Orca Bots (Beta) <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="36" height="36" valign="middle" />

Orca Bots work like first-class teammates: they now run on many more agents, hand work to each other in group rooms, and send results you can actually open.

  • <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="28" height="28" valign="middle" /> Eight more agents behind your bots: Kiro, Kimi Code, Auggie, Gemini CLI, Kilo Code, MiMo Code, Droid and Goose join the agents a bot can run on.
  • Links show progress while Bots publish them, and you can reject an access request right from its Give access dialog.
  • 🤝 Hand-offs in group rooms: When a bot names another member as @Name in its reply, that member picks up the turn.
  • 📎 Results you can open: Bots share a link, attach the file or give the content instead of a path on their own computer, and local paths in Slack messages become readable labels.
  • 🧩 One skills folder per bot: A bot's own skills live in one agent-neutral folder that every agent it runs on can use.
