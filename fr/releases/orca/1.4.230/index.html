orque v1.4.230

Merci beaucoup d'utiliser Orca et pour votre soutien continu ! ❤️

La version courte

  • Chat natif (expérimental) : Utilisez Antigravity dans le chat, choisissez les agents qui s'ouvrent en tant que chat et installez un agent manquant à partir du chat lui-même. Collez les fichiers copiés sous forme de pièces jointes, d'images de file d'attente et obtenez des commentaires plus clairs pendant que les pièces jointes et les actions de file d'attente sont en attente.
  • Comptes et agents : Après avoir changé de compte Claude, redémarrez les sessions en cours sur le nouveau compte. Supprimez les environnements d'exécution d'agent téléchargés dans les paramètres et modifiez ou supprimez les commentaires linéaires via l'Orca CLI.
  • Téléphone : Modifiez les messages en file d'attente sur place, suivez les exécutions de l'outil avec des cartes de type bureau et consultez immédiatement votre conversation lorsque vous reprenez l'historique. Les téléphones en mode paysage placent les onglets de session dans la barre supérieure et les tâches indiquent clairement le bureau que vous utilisez.
  • SSH et espaces de travail distants : La déconnexion reste déconnectée, les espaces de travail en veille restent en veille et les onglets fermés restent fermés après la reconnexion. Des messages plus clairs de mise à jour du serveur et de réappairage vous aident à récupérer une connexion.
  • Peaufinage quotidien : Les raccourcis de commande rapide suivent la division ciblée, les aperçus des onglets attendent le délai de survol complet et les en-têtes de fichiers proposent la révélation dans le Finder. Le nettoyage de l'espace de travail protège mieux les projets ayant le même chemin sur d'autres machines.

Notes de compatibilité et de mise à niveau

Chat natif (expérimental) : Certaines fonctionnalités de chat nécessitent la prise en charge de l'hôte distant. Gardez l'hôte à jour aux côtés d'Orca pour utiliser les dernières fonctionnalités. La commande orca sur les hôtes SSH : Les hôtes existants conservent les préférences de contrôle CLI explicitement enregistrées ; une préférence non définie est migrée vers désactivée. Pour autoriser les commandes sur un hôte SSH connecté à ouvrir et contrôler les onglets du navigateur Orca de ce bureau pour les espaces de travail de cet hôte, activez Autoriser l'orca CLI de cet hôte à contrôler Orca sous Paramètres → Hôtes SSH → modifier l'hôte → Connexion avancée.

orca v1.4.230

Thank you so much for using Orca and for your continued support! ❤️

The short version

  • Native chat (experimental): Use Antigravity in chat, choose which agents open as chats, and install a missing agent from the chat itself. Paste copied files as attachments, queue images, and see clearer feedback while attachments and queue actions are pending.
  • Accounts & agents: After switching Claude accounts, restart running sessions on the new account. Remove downloaded agent runtimes from Settings, and edit or delete Linear comments through the Orca CLI.
  • Phone: Edit queued messages in place, follow tool runs with desktop-style cards, and see your conversation immediately when resuming from history. Landscape phones put session tabs in the top bar, and Tasks makes clear which desktop you’re using.
  • SSH & remote workspaces: Disconnect stays disconnected, sleeping workspaces stay asleep, and closed tabs stay closed after reconnecting. Clearer server update and re-pairing messages help you recover a connection.
  • Everyday polish: Quick Command shortcuts follow the focused split, tab previews wait for the full hover delay, and file headers offer Reveal in Finder. Workspace cleanup better protects same-path projects on other machines.

Compatibility & upgrade notes

Native chat (experimental): Some chat features require support from the remote host. Keep the host updated alongside Orca to use the latest capabilities.

The orca command on SSH hosts: Existing hosts retain explicitly saved CLI control preferences; an unset preference is migrated to off. To allow commands on a connected SSH host to open and control this desktop’s Orca browser tabs for that host’s workspaces, enable Allow this host’s orca CLI to control Orca under Settings → SSH Hosts → edit the host → Advanced Connection.
