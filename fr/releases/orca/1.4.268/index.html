Nous avons expédié plus d'une version aujourd'hui. Découvrez également 1.4.267 et 1.4.266.

Des robots sur plus d'agents, un Slack plus riche et un Orca plus rapide ✨

Les robots peuvent désormais fonctionner sur Cursor, GitHub Copilot et Hermes, Slack obtient la planification et les canevas, et Orca fait moins de travail en arrière-plan, donc cela semble plus rapide.

  • 🤖 Exécuter des robots sur plus d'agents : Les robots peuvent s'exécuter sur Cursor, GitHub Copilot et Hermes, et les robots OpenCode 2.x obtiennent leurs instructions permanentes. Les nouveaux robots reçoivent une carte d'identité et Soul & Memory a des éditeurs repensés.
  • 🖼️ Envoyer des images et des fichiers : Joignez des images et des fichiers dans les discussions de robots, les discussions de groupe et les commentaires d'articles, y compris à un robot sur un ordinateur couplé. Les images d’une requête Slack parviennent à l’agent sous forme d’images.
  • 💬 Plus de Slack : orca slack post --at planifie une publication pour plus tard, et les nouvelles commandes pin, canvas, list et scheduled couvrent les épingles, les canevas et les listes. La connexion à Slack prend le jeton copié sans clicks supplémentaires et les mentions lues sous forme de noms.
  • ⚡ Un Orca plus léger et plus fluide : Les animations s'exécutent à nouveau de manière fluide au lieu d'environ une fois par seconde, les spinners et les impulsions dessinent moins d'images, les lectures d'informations d'identification quittent le thread principal et les profils de tas automatiques ont disparu. Orca suggère également de nettoyer les espaces de travail lorsque le disque est presque plein.
  • 🧭 Travailleurs et chats plus fiables : Les chats interrompus par un crash ou un redémarrage peuvent continuer, le rapport final d'un travailleur réveille l'agent qui l'a démarré et les noms des travailleurs dans le chat ouvrent le travailleur. Le chat reçoit également des correctifs Antigravity, Claude, Codex et Droid.
  • 🌐 Annoter les pages sur les hôtes distants : Les annotations du navigateur fonctionnent désormais également sur les hôtes distants.

Les robots Orca fonctionnent comme des coéquipiers de premier ordre : chaque session d'agent géré obtient ses outils et son identité, les robots peuvent partager au nom du propriétaire, ils suivent les fils de discussion Slack et les déclencheurs Gmail de manière plus fiable, et leur connexion est plus claire et plus sûre.

orca v1.4.268

We shipped more than one release today. Check out 1.4.267 and 1.4.266 too.

Bots on more agents, richer Slack & a faster Orca ✨

Bots can now run on Cursor, GitHub Copilot and Hermes, Slack gets scheduling and canvases, and Orca does less work in the background so it feels quicker.

  • 🤖 Run bots on more agents: Bots can run on Cursor, GitHub Copilot and Hermes, and OpenCode 2.x bots get their standing instructions. New bots get an identity card, and Soul & Memory have redesigned editors.
  • 🖼️ Send images and files: Attach images and files in bot chats, group chats and item comments, including to a bot on a paired computer. Images on a Slack request reach the agent as images.
  • 💬 More from Slack: orca slack post --at schedules a post for later, and new pin, canvas, list and scheduled commands cover pins, canvases and lists. Connecting Slack takes the copied token without extra clicks, and mentions read as names.
  • ⚡ A lighter, smoother Orca: Animations run smoothly again instead of about once a second, spinners and pulses draw fewer frames, credential reads move off the main thread, and automatic heap profiles are gone. Orca also suggests cleaning up workspaces when the disk is almost full.
  • 🧭 More reliable workers and chats: Chats cut by a crash or restart can continue, a worker's final report wakes the agent that started it, and worker names in chat open the worker. Chat also gets Antigravity, Claude, Codex and Droid fixes.
  • 🌐 Annotate pages on remote hosts: Browser annotations now work on remote hosts too.

Orca Bots work like first-class teammates: every managed agent session gets its tools and identity, bots can share on the owner's behalf, they follow Slack threads and Gmail triggers more reliably, and connecting them is clearer and safer.
