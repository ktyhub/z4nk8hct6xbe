orque v1.4.229

Merci beaucoup d'utiliser Orca et pour votre soutien continu ! ❤️

La version courte

  • Chat natif (expérimental) : Examinez les modifications détaillées en ligne, développez les diagrammes pour effectuer un panoramique et un zoom, partagez des visuels de chat avec un click et consultez les objectifs de Claude et l'utilisation du contexte du Codex. Les réponses au clavier, un séparateur non lu et Copier sur sélection facilitent la navigation dans les longues conversations.
  • Compétences partagées : L'installation de compétences partagées prend désormais en charge 20 agents supplémentaires, avec une découverte WSL plus large et des emplacements d'installation appropriés pour des outils tels que Kiro, Qoder et CodeBuddy.
  • Téléphone : Les filtres, le regroupement et le tri de l'espace de travail suivent désormais les choix partagés du bureau. Appuyez longuement pour accéder aux problèmes et aux notes liés, travaillez avec les espaces de travail du serveur et les pages du navigateur, ou poursuivez une discussion prise en charge dans une nouvelle conversation de terminal.
  • SSH et terminaux distants : Les correctifs de reconnexion préservent les volets divisés, l'ordre de collage et les groupes de projets de serveur géré. Les agents endormis reprennent leurs conversations et la suppression du projet d’une machine laisse tranquille son homologue au même chemin.
  • Espaces de travail et peaufinage quotidien : Ouvrez un site Web à partir de Cmd/Ctrl+J, surveillez la progression de la validation lors de la création d'un arbre de travail et nettoyez les espaces de travail avec une confirmation explicite avant d'arrêter l'exécution des agents.
  • Planification Jira : Basculez entre les listes de tickets et les tableaux, concentrez-vous sur le sprint en cours, réutilisez les favoris JQL et Jira enregistrés et démarrez des espaces de travail depuis un ordinateur ou un téléphone. Vos agents peuvent également lire et mettre à jour les tickets Jira via l'Orca CLI.

Problèmes connus

Pour permettre aux agents de gérer les espaces de travail ou de contrôler le navigateur de bureau, activez Autoriser l'orca CLI de cet hôte à contrôler Orca sous Paramètres → Hôtes SSH → modifier l'hôte → Connexion avancée.

orca v1.4.229

Thank you so much for using Orca and for your continued support! ❤️

The short version

  • Native chat (experimental): Review turn-by-turn edits inline, expand diagrams to pan and zoom, share chat visuals with a click, and see Claude goals and Codex context usage. Keyboard answers, an unread divider and Copy on Select make long conversations easier to navigate.
  • Shared skills: Shared-skill installation now supports 20 additional agents, with broader WSL discovery and the right install locations for tools such as Kiro, Qoder and CodeBuddy.
  • Phone: Workspace filters, grouping and sorting now follow the desktop’s shared choices. Long-press for linked issues and notes, work with server workspaces and browser pages, or continue a supported chat in a new terminal conversation.
  • SSH and remote terminals: Reconnect fixes preserve split panes, paste order and managed-server project groups. Sleeping agents resume their conversations, and removing one machine’s project leaves its same-path counterpart alone.
  • Workspaces and everyday polish: Open a website from Cmd/Ctrl+J, watch checkout progress as a worktree is created, and clean up workspaces with an explicit confirmation before stopping running agents.
  • Jira planning: Switch between issue lists and boards, focus on the current sprint, reuse saved JQL and Jira favourites, and start workspaces from desktop or phone. Your agents can read and update Jira tickets through the Orca CLI, too.

Known issues

Native chat (experimental): Features that depend on a remote host are available when that host supports them. Update the host alongside Orca to get the latest capabilities.

The orca command on SSH hosts: Existing hosts keep their saved Orca CLI control preference. To let agents there manage workspaces or control the desktop browser, turn on Allow this host’s orca CLI to control Orca under Settings → SSH Hosts → edit the host → Advanced Connection.
