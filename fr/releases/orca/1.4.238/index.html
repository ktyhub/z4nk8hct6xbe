orque v1.4.238

Un travail plus connecté, des modifications plus sécurisées 🐳

Cette version facilite le déplacement entre les agents, les fichiers, les navigateurs et les machines distantes. Les onglets du même fichier partagent désormais les modifications non enregistrées, les discussions natives reprennent les tours effectués ailleurs et le téléphone bénéficie de gestes de terminal plus fiables et de contrôles d'onglets plus riches.

La version courte

  • Vos modifications restent ensemble : Les onglets du même fichier partagent le texte non enregistré dans les espaces de travail. L'examen des conflits constate que le texte en direct, la suppression de l'espace de travail répertorie les fichiers non enregistrés et les modifications obsolètes de Markdown ou de bloc-notes n'écrasent plus les travaux plus récents.
  • Des discussions qui suivent : Le Codex et Pi affichent les tours effectués en dehors du chat. Les pâtes longues peuvent devenir des pièces jointes de texte, les questions du Codex reçoivent des cartes de réponses et OMP gagne l'envoi d'images et des cartes de révision de plan exploitables.
  • Plus de contrôle sur les agents : Choisissez un chat ou un terminal lors de la création d'un espace de travail, définissez ce choix pour votre agent par défaut, ajoutez des comptes Claude et Codex sur les serveurs distants pris en charge et installez des compétences partagées pour 11 agents supplémentaires.
  • Un navigateur plus performant : Un nouvel onglet compatible avec l'espace de travail, des suggestions dans la barre d'adresse, les autorisations de site mémorisées, l'apparence et le zoom par site et la progression du chargement des pages sur ordinateur et téléphone.
  • Une expérience téléphonique plus fluide : Consultez l'activité de l'agent dans les onglets, renommez en appuyant deux fois, faites défiler les messages de discussion précédents, sélectionnez le texte du terminal plus naturellement et revenez à la position de lecture de votre terminal après la reprise.
  • Meilleures visibilité et récupération : Inspectez les terminaux locaux dans Resource Manager, utilisez SSH simple lorsque le déplacement d'un hôte vers un serveur Orca est bloqué et conservez les couplages via les mises à jour et la récupération des serveurs gérés.
  • Peaufinage quotidien : Portugais brésilien, sélection de la langue lors de l'intégration, versions de versions consultables, progression plus claire de l'analyse de l'historique et Résolution avec l'IA pour les fusions, les rebases et les sélections en pause, même une fois les conflits de fichiers résolus. Mises à jour du téléphone : La mise à jour d'Orca sur l'ordinateur qui dessert votre téléphone met à jour l'interface servie. La nouvelle entrée Accueil → Nouvel espace de travail et les correctifs de dictée iOS native nécessitent une application téléphonique native mise à jour ; l'entrée de l'écran d'accueil est livrée avec la prochaine version de l'application.

Notes de compatibilité et de mise à niveau

  • Comptes distants : Mettez à jour le serveur couplé pour le nouveau flux Claude et Codex Ajouter un compte. Les serveurs Windows et les hôtes plus anciens conservent le guide orca account add. Les informations d'identification restent sur le serveur ; la réauthentification à distance d'un compte existant est en dehors de ce changement.
  • Chat natif (expérimental) : Mettez à jour les hôtes couplés et SSH aux côtés d'Orca pour les derniers correctifs de chat. Les vérifications de version de l'agent acceptent désormais les versions plus récentes et les versions préliminaires qui répondent au minimum requis ; une ancienne version connue affiche des conseils de mise à jour.
  • Resource Manager : La nouvelle vue PTY couvre les terminaux locaux. La fin d'un terminal nécessite la prise en charge de l'hôte pour vérifier la session sélectionnée ; les hôtes plus anciens refusent la résiliation non contrôlée.
  • Fichiers HTML : L'ouverture du HTML en aperçu par défaut a été annulée pour cette version.
  • Travail de base expérimental : Les modifications du propriétaire de la mise en page et de la barre latérale répertoriées ci-dessous restent désactivées. Les nouveaux contrôles facultatifs d’écriture d’agent n’ont aucun appelant existant activé.

orca v1.4.238

More connected work, safer edits 🐳

This release makes it easier to move between agents, files, browsers and remote machines. Tabs of the same file now share unsaved edits, native chats pick up turns made elsewhere, and the phone gets more dependable terminal gestures and richer tab controls.

The short version

  • Your edits stay together: Tabs of the same file share unsaved text across workspaces. Conflict review sees that live text, workspace deletion lists unsaved files, and stale Markdown or notebook edits no longer overwrite newer work.
  • Chats that keep up: Codex and Pi show turns made outside the chat. Long pastes can become text attachments, Codex questions get answer cards, and OMP gains image sending and actionable plan-review cards.
  • More control over agents: Pick chat or terminal when creating a workspace, set that choice for your default agent, add Claude and Codex accounts on supported remote servers, and install shared skills for 11 more agents.
  • A more capable browser: A workspace-aware new tab, address-bar suggestions, remembered site permissions, per-site appearance and zoom, and page-loading progress on desktop and phone.
  • A smoother phone experience: See agent activity in tabs, rename with a double-tap, scroll back through earlier chat messages, select terminal text more naturally, and return to your terminal reading position after resuming.
  • Better visibility and recovery: Inspect local terminals in Resource Manager, use plain SSH when a host’s move to an Orca server is blocked, and keep pairings through managed-server updates and recovery.
  • Everyday polish: Brazilian Portuguese, language selection during onboarding, searchable release builds, clearer history-scan progress, and Resolve with AI for paused merges, rebases and cherry-picks—even after file conflicts are fixed.

Phone updates: Updating Orca on the computer serving your phone updates the served interface. The new Home → New Workspace entry and native iOS dictation fixes require an updated native phone app; the home-screen entry ships with the next app build.

Compatibility & upgrade notes

  • Remote accounts: Update the paired server for the new Claude and Codex Add Account flow. Windows servers and older hosts retain the orca account add guidance. Credentials stay on the server; remote re-authentication of an existing account is outside this change.
  • Native chat (experimental): Update paired and SSH hosts alongside Orca for the latest chat fixes. Agent version checks now accept newer releases and prereleases that meet the required minimum; a known older version shows update guidance.
  • Resource Manager: The new PTYs view covers local terminals. Ending a terminal requires host support for verifying the selected session; older hosts refuse unchecked termination.
  • HTML files: Opening HTML in preview by default was reverted for this release.
  • Experimental groundwork: Layout-owner and sidebar changes listed below remain disabled. The new optional agent-write controls have no existing callers enabled.
