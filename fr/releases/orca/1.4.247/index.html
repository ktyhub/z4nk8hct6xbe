orque v1.4.247

Interface utilisateur de chat améliorée, avis téléphoniques plus riches et plus de façons de vous approprier Orca ✨

  • 🔄 Continuer après la réinitialisation des limites d'utilisation : Un paramètre facultatif reprend automatiquement votre conversation lorsque sa limite d'utilisation est réinitialisée.
  • 📱 Des critiques plus riches sur votre téléphone : Parcourez les commits de branche, passez d'un fichier à l'autre dans les différences et lisez ou ajoutez des commentaires de révision de demande d'extraction à côté du code.
  • 🎨 Faites vôtre Orca : Découvrez plus de thèmes, prévisualisez les polices dans leurs propres polices de caractères et importez les fichiers de configuration Ghostty ou Kitty.
  • 🧩 Plugins plus puissants : Créez des éditeurs personnalisés, des éléments et des panneaux d'état en direct, et connectez les plugins aux invites, lancements et actions de l'espace de travail des agents.
  • 🤝 Activité d'agent plus claire : Les travailleurs en cours d'exécution restent visibles une fois que leur coordinateur a terminé, avec un changement de compte plus facile et des cartes de transfert plus claires.
  • ⚡ Travail quotidien plus fluide : Moins de redessins et d'animations hors écran inutiles, des réponses enregistrées plus fiables et des correctifs pour les espaces de travail, les terminaux et les aperçus de l'émulateur.
  • 💬 Interface utilisateur de chat améliorée : Choisissez Chat ou CLI pour chaque agent dans les paramètres de l'interface utilisateur de chat, conservez les brouillons lorsque vous continuez à partir d'un terminal et voyez clairement le mode d'autorisation sélectionné.

Faits saillants

  • Chat UI : Choisissez Chat ou CLI pour chaque agent directement dans les paramètres de Chat UI. Les choix d'autorisation restent visibles, les contrôles de modèle et d'effort restent utilisables pendant que les options s'actualisent, et la concentration du compositeur maintient les superpositions ouvertes en place.
  • Continuité de la conversation : Conservez le texte non envoyé lorsque vous passez d'un terminal au chat, et conservez les réponses reçues et les résultats de l'outil pendant que l'enregistrement est occupé. Activez la poursuite automatique pour reprendre une discussion après la réinitialisation de sa limite d'utilisation.
  • Contrôle de source téléphonique : Examinez chaque validation de branche sur sa propre page, passez d'un fichier à l'autre, repliez le contexte de comparaison et lisez ou ajoutez des commentaires de révision à côté du code. L'onglet pull-request se concentre sur ce qui bloque la fusion, avec des actions suivantes plus claires et des actualisations automatiques.
  • Thèmes et polices : Recherchez les thèmes GitHub, VS Code et de catalogue dans les contrôles d'apparence. Prévisualisez chaque police dans sa propre police, importez des thèmes Ghostty avec des paires clair/sombre et introduisez également les fichiers de configuration Kitty.
  • Plugins : Créez des éditeurs personnalisés qui conservent les modifications en attente via des sauvegardes et des rechargements, des éléments de barre d'état en direct et des panneaux de composants avec un conteneur de mise en page Box. Les hooks connectent les plugins aux lancements d'agents, aux invites, aux appels d'outils, aux envois de terminaux et à la création d'espace de travail ; des outils de capture d'écran et de test aident à vérifier le résultat.
  • Agents et orchestration : Les travailleurs en cours d'exécution restent dans la liste des agents une fois que leur coordinateur a terminé. Les cartes de transfert facilitent le suivi du travail délégué, et les sélecteurs de comptes Codex et Claude sont plus simples à utiliser.
  • Travail et espaces de travail à distance : Prévisualisez le code HTML distant en dehors des espaces de travail enregistrés, recherchez les projets dans les distributions WSL arrêtées après un redémarrage et voyez plus clairement la progression de Git. Les arbres de travail enfants restent dans le projet de l'appelant, les racines des dossiers restent visibles et les liens de branche ouvrent la demande d'extraction actuelle.
  • Réactivité et fiabilité : Les animations hors écran s'arrêtent, les modifications de paramètres non liées entraînent moins de redessins de différences et les modèles d'éditeur inutilisés sont publiés. Les correctifs du terminal empêchent le texte d'échappement parasite, tandis que les aperçus de l'émulateur offrent des commentaires de connexion et de démarrage plus clairs.

Notes de compatibilité et de mise à niveau

  • Chat ou CLI par agent : L'interface utilisateur du chat n'est plus expérimentale. Les contrôles de lancement partagés sont également disponibles dans Paramètres → Chat UI, afin que vous puissiez choisir la surface ouverte par chaque agent.
  • La poursuite automatique est facultative : Activez-la si vous souhaitez qu'une discussion à utilisation limitée se poursuive automatiquement après la réinitialisation de la limite.
  • Comportement d'envoi par téléphone : Le téléphone suit le paramètre d'envoi de l'ordinateur de bureau couplé. Mettez à jour Orca Mobile ainsi que votre ordinateur de bureau ou votre serveur pour obtenir les modifications mobiles.
  • Panneau d'orchestration : Le panneau d'orchestration expérimental est désactivé pendant que son décalage à l'échelle de l'application est corrigé. Les commandes d'orchestration continuent de fonctionner.

Problèmes connus

Stockage de discussion enregistré : L'historique des discussions peut continuer à utiliser davantage d'espace disque à mesure que les conversations se développent ; le compactage automatique du stockage n'est pas inclus dans cette version.

Remplacements de commandes de plugin : Un plugin remplaçant une commande intégrée peut toujours se terminer après qu'Orca a utilisé la commande normale à la place, provoquant que l'action se produise deux fois.

orca v1.4.247

Improved Chat UI, richer phone reviews & more ways to make Orca yours ✨

  • 🔄 Continue after usage limits reset: An optional setting resumes your chat automatically when its usage limit resets.
  • 📱 Richer reviews on your phone: Browse branch commits, jump between files in diffs, and read or add pull-request review comments alongside the code.
  • 🎨 Make Orca yours: Discover more themes, preview fonts in their own typefaces, and import Ghostty or Kitty configuration files.
  • 🧩 More powerful plugins: Build custom editors, live status items and panels, and connect plugins to agent prompts, launches and workspace actions.
  • 🤝 Clearer agent activity: Running workers stay visible after their coordinator finishes, with easier account switching and clearer hand-off cards.
  • ⚡ Smoother everyday work: Fewer unnecessary redraws and offscreen animations, more reliable saved replies, and fixes for workspaces, terminals and emulator previews.
  • 💬 Improved Chat UI: Choose Chat or CLI for each agent in Chat UI settings, keep drafts when continuing from a terminal, and see your selected permission mode clearly.

Highlights

  • Chat UI: Choose Chat or CLI for each agent directly in Chat UI settings. Permission choices stay visible, model and effort controls remain usable while options refresh, and focusing the composer keeps open overlays in place.
  • Conversation continuity: Keep unsent text when moving from a terminal into chat, and preserve received replies and tool results while saving is busy. Turn on automatic continuation to resume a chat after its usage limit resets.
  • Phone source control: Review each branch commit on its own page, jump between files, fold diff context, and read or add review comments alongside the code. The pull-request tab focuses on what blocks the merge, with clearer next actions and automatic refreshes.
  • Themes & fonts: Find GitHub, VS Code and catalog themes in the appearance controls. Preview each font in its own typeface, import Ghostty themes with light/dark pairs, and bring in Kitty configuration files too.
  • Plugins: Create custom editors that keep pending edits through saves and reloads, live status bar items, and component panels with a Box layout container. Hooks connect plugins to agent launches, prompts, tool calls, terminal sends and workspace creation; screenshot and testing tools help check the result.
  • Agents & orchestration: Running workers remain in the Agents list after their coordinator finishes. Hand-off cards make delegated work easier to follow, and Codex and Claude account switchers are simpler to use.
  • Remote work & workspaces: Preview remote HTML outside registered workspaces, find projects in stopped WSL distros after a restart, and see clearer Git progress. Child worktrees stay in the caller’s project, folder roots remain visible, and branch links open the current pull request.
  • Responsiveness & reliability: Offscreen animations pause, unrelated settings changes cause fewer diff redraws, and unused editor models are released. Terminal fixes prevent stray escape text, while emulator previews offer clearer connection and startup feedback.

Compatibility & upgrade notes

  • Chat or CLI per agent: Chat UI is out of Experimental. Shared launch controls are also available in Settings → Chat UI, so you can choose which surface each agent opens.
  • Automatic continuation is optional: Enable it if you want a usage-limited chat to continue automatically after the limit resets.
  • Phone Send behavior: The phone follows the paired desktop’s send setting. Update Orca Mobile as well as your desktop or server to get the mobile changes.
  • Orchestration panel: The experimental Orchestration panel is disabled while its app-wide lag is addressed. Orchestration commands continue to work.

Known issues

Saved chat storage: Chat history can continue to use more disk space as conversations grow; automatic storage compaction is not included in this release.

Plugin command replacements: A plugin replacing a built-in command can still finish after Orca has used the normal command instead, causing the action to happen twice.
