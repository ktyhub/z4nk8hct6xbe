orque v1.4.237

100 000 étoiles. Merci! ⭐🐳

Orca vient de franchir 100 000 étoiles sur GitHub ! Chaque rapport de bug, demande d'extraction, flux de travail partagé et recommandation nous a aidés à arriver ici. Merci d'avoir construit avec Orca et d'avoir aidé à façonner ce qui va suivre. ❤️ Pour célébrer, cette version apporte une expérience téléphonique plus performante, des conversations d'agent plus fiables et des correctifs qui permettent à votre travail de se dérouler sur les postes de travail et les machines distantes.

La version courte

  • Plus de choses à faire depuis votre téléphone : Créez et modifiez des notes, enregistrez Markdown sur des hôtes sans tête, suivez les liens de fichiers relatifs et consultez les images intégrées. Les brouillons de terminaux tamponnés peuvent désormais également survivre à la navigation dans l’espace de travail.
  • Chats auxquels vous pouvez revenir : Les chats du Codex rouvrent correctement après une annulation, Claude conserve son contexte rembobiné lors des restaurations d'Orca et les captures d'écran restent avec la conversation. Le sélecteur de compétences du Codex reflète désormais les compétences réellement chargées par le Codex. - Votre travail reste protégé : La suppression suspend l'enregistrement automatique du même fichier dans les espaces de travail. Les vues Markdown et CSV en lecture seule protègent vos modifications non enregistrées, et les nouveaux documents Markdown non préparés s'ouvrent directement dans l'éditeur enrichi.
  • Voix au-delà du bureau : La dictée téléphonique fonctionne à nouveau via les hôtes orca serve sans tête, avec une commande CLI pour configurer la clé OpenAI de l'hôte.
  • Travail à distance plus fluide : Reconnectez les onglets de terminal cachés après un redémarrage, conservez les connexions du navigateur lorsque les hôtes s'associent à nouveau et recherchez les configurations SSH avec des milliers d'hôtes sans geler l'interface.
  • Petits détails, meilleure fluidité : Les onglets du téléphone suivent l'ordre du bureau, les dispositions en paysage affichent le titre de la session, les commandes du clavier conservent leur hauteur et les balayages de sécurité de l'arbre de travail ignorent les espaces de travail inchangés. Mises à jour du téléphone : La mise à jour d'Orca sur l'ordinateur qui dessert votre téléphone met également à jour l'interface desservie par le téléphone. Les versions de terminal persistantes nécessitent en outre un shell mobile mis à jour.

Notes de compatibilité et de mise à niveau

  • Chat natif (expérimental) : Mettez à jour les hôtes couplés et SSH aux côtés d'Orca pour obtenir les derniers correctifs de chat. La sélection exacte des fichiers de compétences Codex est disponible sur ordinateur avec un hôte prenant en charge ; les sélections de téléphone et les hôtes plus anciens conservent les noms de compétences en texte brut. Envoyez une compétence sous forme de nouveau message pour que le Codex l'applique au début d'un tour.
  • Dictée sans tête : Enregistrez la clé OpenAI sur l'hôte effectuant la transcription avec orca speech openai-key set (lit la clé depuis stdin). Les hôtes orca serve de l'application installée sur Linux et macOS peuvent également utiliser le dispositif de reconnaissance intégré sur l'appareil ; Les serveurs Windows, SSH et WSL gérés utilisent des modèles cloud.
  • Choix de lancement CLI : Les choix explicites de --surface nécessitent un hôte d'exécution mis à jour. L'omission de l'option conserve vos valeurs par défaut existantes.

orca v1.4.237

100,000 stars. Thank you! ⭐🐳

Orca just crossed 100,000 stars on GitHub! Every bug report, pull request, shared workflow and recommendation has helped us get here. Thank you for building with Orca and helping shape what comes next. ❤️

To celebrate, this release brings a more capable phone experience, more dependable agent conversations, and fixes that keep your work moving across desktops and remote machines.

The short version

  • More done from your phone: Create and edit notes, save Markdown on headless hosts, follow relative file links, and see embedded images. Buffered terminal drafts can now survive workspace navigation, too.
  • Chats you can come back to: Codex chats reopen correctly after undo, Claude keeps its rewound context across Orca rollbacks, and screenshots stay with the conversation. Codex’s skill picker now reflects the skills Codex actually loaded.
  • Your work stays protected: Discard pauses autosave of the same file across workspaces. Read-only Markdown and CSV views protect your unsaved edits, and new, unstaged Markdown documents open straight into the rich editor.
  • Voice beyond the desktop: Phone dictation works again through headless orca serve hosts, with a CLI command to configure the host’s OpenAI key.
  • Smoother remote work: Reconnect hidden terminal tabs after a restart, keep browser logins when hosts pair again, and search SSH configurations with thousands of hosts without freezing the interface.
  • Small details, better flow: Phone tabs follow desktop order, landscape layouts show the session title, keyboard controls keep their height, and worktree safety sweeps skip unchanged workspaces.

Phone updates: Updating Orca on the computer serving your phone also updates the phone’s served interface. Persistent terminal drafts additionally require an updated mobile shell.

Compatibility & upgrade notes

  • Native chat (experimental): Update paired and SSH hosts alongside Orca to get the latest chat fixes. Exact Codex skill-file selection is available on desktop with a supporting host; phone selections and older hosts retain plain-text skill names. Send a skill as a new message for Codex to apply it at the start of a turn.
  • Headless dictation: Save the OpenAI key on the host doing the transcription with orca speech openai-key set (reads the key from stdin). Installed-app orca serve hosts on Linux and macOS can also use the bundled on-device recognizer; Windows, managed SSH and WSL servers use cloud models.
  • CLI launch choice: Explicit --surface choices require an updated execution host. Omitting the option keeps your existing defaults.
