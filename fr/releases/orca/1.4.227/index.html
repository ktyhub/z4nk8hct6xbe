orque v1.4.227

Merci beaucoup d'utiliser Orca et pour votre soutien continu ! ❤️

La version courte

  • Les discussions natives ont leur propre mode d'autorisation. Choisissez les autorisations pour chaque nouvelle discussion Claude ou Codex dans Paramètres → Chat → Comportement ; les discussions existantes conservent le mode qu’elles utilisaient déjà et le changement de modèle ne le réinitialise plus.
  • Les sessions de chat natives sont plus faciles à poursuivre. Vous pouvez reprendre des conversations de terminal importantes dans une nouvelle conversation native, récupérer des discussions dont le seul travail s'est exécuté en arrière-plan après un redémarrage et voir avec précision tous les fournisseurs de chat pris en charge dans l'historique de session.
  • Les comptes Claude et la configuration du chat Codex sont plus fluides. Les comptes Claude utilisent à nouveau des dossiers séparés, le lien de connexion peut être copié, les chats Codex nécessitent la version 0.136.0 ou ultérieure, et Codex Ultrafast est disponible comme choix de vitesse.
  • L'automatisation du navigateur restitue votre clavier de manière fiable. Les commandes du navigateur de l'agent ciblent la page souhaitée et les fenêtres contextuelles du navigateur se comportent davantage comme Chrome.
  • Aussi : le nettoyage de l'arbre de travail est plus sûr, les notifications de lecture macOS disparaissent du Centre de notifications, les longues discussions se chargent mieux sur les téléphones et les lectures froides de l'historique des sessions évitent les réindexations inutiles.

orca v1.4.227

Thank you so much for using Orca and for your continued support! ❤️

The short version

  • Native chats have their own permission mode. Choose permissions for each new Claude or Codex chat from Settings → Chat → Behavior; existing chats keep the mode they were already using, and changing models no longer resets it.
  • Native chat sessions are easier to continue. You can resume large terminal conversations in a new native chat, recover chats whose only work ran in the background after a restart, and see every supported chat provider accurately in Session History.
  • Claude accounts and Codex chat setup are smoother. Claude accounts again use separate folders, the sign-in link can be copied, Codex chats require version 0.136.0 or later, and Codex Ultrafast is available as a speed choice.
  • Browser automation gives your keyboard back reliably. Agent browser commands target the intended page, and browser popups behave more like Chrome.
  • Also: worktree cleanup is safer, read macOS notifications disappear from Notification Center, long chats load better on phones, and cold session-history reads avoid unnecessary reindexing.
