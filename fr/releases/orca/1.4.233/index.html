orque v1.4.233

Merci beaucoup d'utiliser Orca et pour votre soutien continu ! ❤️ Nous avons expédié deux versions aujourd'hui ! Si vous l'avez manqué, consultez également les v1.4.232 release notes. Les points forts incluent les autorisations d'agent Manuel/Auto/Yolo, OpenCode 2 dans le chat natif, un meilleur compositeur de téléphone avec des pièces jointes et des compétences en ligne, une récupération SSH plus fluide et une application plus petite avec des mises à jour Mac plus rapides. Mises à jour du téléphone : La mise à jour d'Orca sur votre bureau met également à jour l'application sur votre téléphone connecté : le téléphone la charge directement depuis votre bureau.

La version courte

  • SSH et espaces de travail distants : La connexion à un hôte SSH fonctionne lorsqu'aucune machine ne peut télécharger Node.js, avec un miroir à un click dont Orca se souvient et réessaye. Les anciens hôtes Windows (Windows 10 1809 et Server 2019) peuvent exécuter le serveur d'Orca et les tunnels sont récupérés lorsqu'un port est détenu par une ancienne connexion SSH.
  • Serveurs distants dans Paramètres : Les serveurs Orca distants sont une liste au lieu de six sections, et les hôtes SSH peuvent être supprimés en bloc et rester supprimés. Orca vous indique quand le même serveur a été enregistré deux fois, et l'ajout d'un serveur que vous avez déjà enregistré le met à jour à la place.
  • Téléphone : La création d'un espace de travail à partir du téléphone est beaucoup plus rapide, la liste des espaces de travail reste en phase avec le bureau et les icônes des onglets de session conservent leur taille à côté des titres longs.
  • Éditeur : Orca refuse d'enregistrer les modifications apportées à un fichier sur le disque que vous n'avez pas vues, et Recharger et Annuler se comportent ensuite de manière prévisible.
  • Tous les jours : Les projets portant le même nom sur différentes machines conservent des noms courts et indiquent sur quelle machine ils se trouvent. Les conversations enregistrées depuis longtemps utilisent beaucoup moins de mémoire lorsqu'Orca les analyse pour rechercher l'historique des sessions.

orca v1.4.233

Thank you so much for using Orca and for your continued support! ❤️

We shipped two releases today! If you missed it, check out the v1.4.232 release notes too. Highlights include Manual / Auto / Yolo agent permissions, OpenCode 2 in native chat, a better phone composer with file attachments and inline skills, smoother SSH recovery, and a smaller app with faster Mac updates.

Phone updates: Updating Orca on your desktop also updates the app on your connected phone—the phone loads it directly from your desktop.

The short version

  • SSH & remote workspaces: Connecting to an SSH host works when neither machine can download Node.js, with a one-click mirror Orca remembers and retries. Older Windows hosts (Windows 10 1809 and Server 2019) can run Orca's server, and tunnels recover when a port is held by an old SSH connection.
  • Remote servers in Settings: Remote Orca Servers is one list instead of six sections, and SSH hosts can be removed in bulk and stay removed. Orca tells you when the same server was saved twice, and adding a server you already saved updates it instead.
  • Phone: Creating a workspace from the phone is much faster, the workspace list stays in step with the desktop, and session tab icons keep their size beside long titles.
  • Editor: Orca refuses to save over changes made to a file on disk that you haven't seen, and Reload and Undo behave predictably afterwards.
  • Everyday polish: Projects with the same name on different machines keep short names and show which machine they're on. Long saved conversations use far less memory when Orca scans them for Session History.
