homme des cavernes v4.1.0

Caveman 4.1.0 est une version de maintenance : corrections de bugs sur compress, OpenCode, Hermes, Pi, le proxy et les hooks, un magasin de récupération qui ne se remplit plus et arrête la compression, et quelques petits commutateurs demandés par les gens. caveman-compress refuse désormais un fichier contenant une clé ou un jeton et s'installe à nouveau à partir des centres de compétences.

Action nécessaire

  • forward_headers sous un bloc providers.<name> arrête désormais le démarrage du proxy. Avant, il était ignoré silencieusement : aucun en-tête n'était transmis et le seul symptôme était un 401 en amont. Configurez plutôt celui-ci en amont comme un montage compatible : compat.<name> avec base_url et forward_headers, plus wire_dialect: anthropic s'il parle le protocole Anthropic (voir docs/technical/configuration.md) (#1458).
  • caveman-compress refuse un fichier dont le texte contient un identifiant, comme un bloc de clé privée ou un cloud, un hôte Git ou un jeton modèle API. La compression envoie le fichier à votre fournisseur de modèles, alors déplacez d'abord le secret dans une variable d'environnement ou un gestionnaire de secrets. L'erreur nomme la ligne, jamais le secret. Les espaces réservés comme sk-... ou $OPENAI_API_KEY sont toujours compressés (#1471).

Modifié

  • Les anciens descripteurs de récupération peuvent désormais expirer. Le magasin de récupération conservait chaque original compressé pour toujours, il s'est donc rempli et la compression s'est arrêtée (#1370). Lorsqu'une écriture dépasse le plafond du magasin, elle libère désormais de la place : les objets tapés des sessions inactives depuis 14 jours (archivés) ou 30 jours (n'importe lequel) sont expirés, les plus anciens en premier, jusqu'à ce que le magasin soit à 80 %. La récupération d’un handle expiré répond à cave_expired_recovery, et chaque expiration est enregistrée dans proxy.log. Les récupérations de blob n’expirent jamais (#1481).

Nouveau

  • caveman-proxy recovery-store status|check|repair pour un ccr.db endommagé. Un magasin endommagé refuse désormais les écritures au lieu de rester corrompu lors des mises à niveau ; les lectures continuent de fonctionner. Réparer copie uniquement les lignes dont les octets correspondent toujours à leur hachage et déplace les fichiers endommagés de côté sans les toucher. caveman status et caveman doctor le pointent (#1369, #1481).
  • Désactivez le rappel par invite avec CAVEMAN_REINFORCE=0, ou "reinforce": false dans ~/.config/caveman/config.json ou .caveman.json d'un dépôt. L'ensemble de règles complet est toujours envoyé au début de la session (#1468).
  • --hook-node node permet aux hooks installés de trouver Node via PATH au moment de l'exécution au lieu d'épingler le chemin d'installation au moment de l'installation, pour les personnes qui changent de version de Node (#1452). La valeur par défaut est inchangée, car les applications démarrées en dehors d'un terminal ne voient pas le PATH du shell.
  • L'installateur revient à Bun lorsque Node est absent. Node reste en premier (#570, #1344 par @cyrus-za).
  • caveman learn scanne les sessions Pi et honore PI_CODING_AGENT_DIR / PI_CODING_AGENT_SESSION_DIR (#1317 par @tranducquy0).
  • caveman mem peut restaurer une mémoire à une valeur antérieure, et supersede --stdin prend des remplacements trop volumineux pour une ligne de commande (#1386 par @PARTHDESHMUKH2005). Le client vérifie d'abord que le binaire installé prend en charge --stdin, donc un binaire plus ancien ne peut plus stocker le texte littéral --stdin comme fait.

Corrigé

compresse d'homme des cavernes

  • Le centre de compétences d'Hermès a bloqué l'installation avec un verdict DANGEREUX que --force ne peut pas contourner. Chaque résultat était une fausse correspondance et le texte correspondant est réécrit avec un comportement identique (#1464).
  • Les sauvegardes sont saisies sur le chemin complet du fichier, donc les CLAUDE.md de deux projets ne partagent plus un seul emplacement de sauvegarde. Une exécution qui s'arrête avant l'écriture supprime son fichier de sauvegarde et de transfert, de sorte que l'exécution suivante n'est pas abandonnée.
  • La validation refuse désormais les commentaires ajoutés après le corps (#1433). L'invite conserve le verbe qui porte une instruction (#1434). Frontmatter reste local sur les deux passes (#1359 par @leninworld). La ponctuation finale sur les URL et les chemins n'échoue plus à la validation (#1356 par @Pharex38). Les fichiers de points d'informations d'identification et les fichiers de points nus comme .env sont refusés par leur nom (#1357 par @Pharex38, #1363). OpenCode
  • OpenCode 2 : le plugin Shrink est généré pour le API que le majeur installé charge réellement (#1445). OPENCODE_CONFIG_DIR est à l'honneur partout (#1441). Les sessions supprimées sont traitées (#1444) et le répertoire du projet de l'hôte est transmis (#1443).
  • La sonde déjà installée de l'installateur lit correctement JSONC settings.json, et le plugin honore un repo defaultMode: "off" (#1430, #1431 par @Quinnod345). Hermès
  • caveman enable hermes écrit YAML qui analyse toujours (#1405). Il lit la propriété par valeur, donc une configuration reformatée reste la propriété (#1410). Il honore l'adhésion à plugins.enabled / plugins.disabled (#1442, #1446 par @Ha1baraA11). Pi (@caveman-ai/pi 0.3.2)
  • Le contexte par invite est envoyé sous forme de message, de sorte que le cache d'invite du fournisseur survit à chaque invite (#1364, #1376 par @worldofgeese).
  • Les sorties d'outils inférieures à 4 Ko ne sont plus remplacées par un handle de récupération (#1365, #1378 par @danieldutu). caveman_retrieve avec une requête dit maintenant qu'il renvoie un extrait (#1368, #1377 par @danieldutu).
  • Le modèle virtuel router/auto de Pi n'avertit plus qu'il est non routable (#1449). La route de compatibilité est vérifiée pour une URL de base OpenAI sans /v1 (#1325 par @szsunyuan). Proxy, statistiques et coût
  • Les requêtes Claude Code qui déclarent l'outil de conseiller sont à nouveau tarifées, au lieu de chaque requête affichant un coût « Inconnu » (#1465). Les réponses anthropiques en continu lisent leurs qualificatifs de résultat au bon endroit (#1453).
  • Un flux Codex terminé fermé par le client conserve son nombre de jetons (#1397, #1398 par @Ha1baraA11).
  • caveman start lit le mode de niveau supérieur du proxy, pas un middleware.mode imbriqué (#1457).
  • Une compatibilité en amont bloquée par le garde SSRF répond désormais à cave_upstream_blocked et enregistre l'hôte ainsi que le correctif CAVE_SSRF_ALLOWLIST, au lieu d'un 502 générique (#1440).
  • caveman stats n'expire plus sur les grands magasins : les résumés de cache par requête sont déplacés vers leur propre table, migrés en arrière-plan (#1371, #1481). En cas d'expiration du délai, il nomme la taille de la base de données et suggère --days 7.
  • Runtime natif : les écritures CCR ne réanalysent plus l'ensemble du magasin, ce qui, dans les grandes maisons, faisait que les requêtes natives épuisent leur budget de 250 ms et se ferment à vide (#1279). Des chemins native.sock trop longs sont signalés (#1399, #1402 par @Ha1baraA11).
  • Les octets de récupération qui ne correspondent pas à leur handle sont refusés (#1373 par @zsltg). La limite de page du magasin de récupération s'applique à chaque connexion et ses écritures sont sérialisées (#1374, #1375 par @zsltg). Les fenêtres de statistiques sont indexées (#1372 par @zsltg). Les identifiants de modèle ARN Bedrock conservent leur barre oblique codée (#1345 par @AlSh007). Une réponse middleware n'est pas marquée au-delà de la limite à un quart de celle-ci (#1367 par @AlSh007). L'effort Kimi K3 est cartographié (#1306 par @ysntony). Les résultats caveman_retrieve du plugin wrap ne sont plus recompressés (#1432).
  • L'actualisation du token Claude OAuth est relayée via le proxy. Les broches Gemini acheminées API-key auth au lieu de quitter 41.
  • Le catalogue de prix a été revérifié par rapport aux pages des fournisseurs (aucun prix n'a changé). Vertex gemini-2.5-pro et gemini-2.5-flash ont été supprimés : Google a tous deux retiré son service le 20/10/2026, et ces demandes s'affichent désormais comme non tarifées plutôt que mal tarifées (#1473). Crochets et installateur
  • La configuration de Statusline conserve le littéral $ dans les chemins CLAUDE_CONFIG_DIR (#1400, #1401 par @Ha1baraA11). Les entrées de hook gérées sont comparées en ignorant l'ordre des clés, donc doctor --fix arrête de combattre une entrée réorganisée (#1437, #1420 par @jamestrandung).   • ENABLE_TOOL_SEARCH est par défaut "true" pour correspondre au code Claude (#1362 par @AliReza99). Moteur, rétrécissement et apprentissage
  • Les tuyaux échappés restent à l'intérieur des cellules du tableau Markdown (#1456 par @kevin9327). Les entiers supérieurs à 2^53 restent en dehors de la plage numérique (#1332 par @AlSh007). Les notes d'élision sont placées de manière stable (#1343 par @CHLIN0). La sortie du terminal séparé par CR n’est plus tronquée.
  • caveman-shrink ignore les entrées de liste nulles au lieu de quitter (#1435, #1436 par @shaikn6) et lit les outils Anthropic input_schema (#1331 par @AlSh007).
  • caveman learn arrête de signaler le contexte injecté par l'homme des cavernes sous forme de texte que vous avez collé (#1459) et sépare les CV froids du taux de désabonnement du cache (#1419 par @jamestrandung). Versions d'agent

caveman v4.1.0

Highlights

  • Proxy config migration required — forward_headers under providers.<name> now blocks startup instead of being silently ignored. Move that upstream to compat.<name> with base_url and forward_headers, adding wire_dialect: anthropic for Anthropic-compatible APIs (#1458).
  • Compression rejects credentials — caveman-compress now refuses files containing private keys or cloud, Git host, or model API tokens because their contents are sent to your model provider. Move secrets into environment variables or a secret manager; placeholders such as $OPENAI_API_KEY remain valid, and errors identify only the offending line (#1471).
  • Recovery storage is bounded and repairable — typed recovery handles expire oldest-first after 14 days for archived sessions or 30 days for any session when the store exceeds its cap, reclaiming space down to 80%; blob recoveries never expire. Expired handles return cave_expired_recovery. For damaged ccr.db files, caveman-proxy recovery-store status|check|repair validates hashes and repairs intact rows without discarding damaged originals (#1369, #1481).
  • Large stores no longer stall requests and stats — cache digests move to a dedicated table with background migration, native writes avoid whole-store rescans that could exhaust the 250 ms request budget, and caveman stats timeouts now report database size and suggest --days 7 (#1279, #1371, #1481).
  • Agent integrations preserve caching and report costs correctly — Pi sends per-prompt context as a message to preserve provider prompt caching and leaves tool outputs under 4 KB inline; OpenCode 2 generates its shrink plugin for the installed API major and honors OPENCODE_CONFIG_DIR consistently (#1364, #1365, #1445, #1441). Claude Code advisor requests are priced again, while retired Vertex gemini-2.5-pro and gemini-2.5-flash requests now appear unpriced rather than mispriced (#1465, #1473).
  • Security and runtime flexibility improve — the MCP adapter requires @modelcontextprotocol/sdk 1.32.0 or newer and reports outdated installations (#1466). Installers fall back to Bun when Node is unavailable, while --hook-node node optionally resolves Node through runtime PATH; the default install-time pinning remains unchanged (#570, #1344, #1452).

Caveman 4.1.0 is a maintenance release: bug fixes across compress, OpenCode, Hermes, Pi, the proxy and the hooks, a recovery store that no longer fills up and stops compressing, and a few small switches people asked for. caveman-compress now refuses a file with a key or token in it, and installs from skill hubs again.

Action needed

  • forward_headers under a providers.<name> block now stops the proxy from starting. Before, it was silently ignored: no headers were forwarded and the only symptom was an upstream 401. Configure that upstream as a compat mount instead: compat.<name> with base_url and forward_headers, plus wire_dialect: anthropic if it speaks the Anthropic protocol (see docs/technical/configuration.md) (#1458).
  • caveman-compress refuses a file whose text holds a credential, such as a private key block or a cloud, Git host or model API token. Compression sends the file to your model provider, so move the secret into an env var or secret manager first. The error names the line, never the secret. Placeholders like sk-... or $OPENAI_API_KEY still compress (#1471).

Changed

  • Old recovery handles can now expire. The recovery store used to keep every compressed original forever, so it filled up and compression stopped (#1370). When a write would exceed the store's cap, it now frees room: typed objects of sessions idle 14 days (archived) or 30 days (any) are expired, oldest first, until the store is at 80%. Retrieving an expired handle answers cave_expired_recovery, and each expiry is logged in proxy.log. Blob recoveries never expire (#1481).

New

  • caveman-proxy recovery-store status|check|repair for a damaged ccr.db. A damaged store now refuses writes instead of staying corrupt across upgrades; reads keep working. Repair copies only rows whose bytes still match their hash, and moves the damaged files aside untouched. caveman status and caveman doctor point at it (#1369, #1481).

  • Turn off the per-prompt reminder with CAVEMAN_REINFORCE=0, or "reinforce": false in ~/.config/caveman/config.json or a repo's .caveman.json. The full ruleset is still sent at session start (#1468).

  • --hook-node node makes installed hooks find Node through PATH at run time instead of pinning the install-time path, for people who switch Node versions (#1452). The default is unchanged, because apps started outside a terminal don't see the shell's PATH.

  • The installer falls back to Bun when Node is absent. Node stays first (#570, #1344 by @cyrus-za).

  • caveman learn scans Pi sessions, and honors PI_CODING_AGENT_DIR / PI_CODING_AGENT_SESSION_DIR (#1317 by @tranducquy0).

  • caveman mem can revert a memory to an earlier value, and supersede --stdin takes replacements too large for a command line (#1386 by @PARTHDESHMUKH2005). The client checks that the installed binary supports --stdin first, so an older binary can no longer store the literal text --stdin as the fact.

Fixed

caveman-compress

  • Hermes' skill hub blocked the install with a DANGEROUS verdict that --force can't override. Every finding was a false match, and the matched text is respelled with identical behavior (#1464).
  • Backups are keyed on the file's full path, so two projects' CLAUDE.md no longer share one backup slot. A run that dies before writing removes its backup and staging file, so the next run doesn't abort.
  • Validation now refuses commentary appended after the body (#1433). The prompt keeps the verb that carries an instruction (#1434). Frontmatter stays local on both passes (#1359 by @leninworld). Trailing punctuation on URLs and paths no longer fails validation (#1356 by @Pharex38). Credential dotfiles and bare dotfiles like .env are refused by name (#1357 by @Pharex38, #1363).

OpenCode

  • OpenCode 2: the shrink plugin is generated for the API the installed major actually loads (#1445). OPENCODE_CONFIG_DIR is honored everywhere (#1441). Deleted sessions are acted on (#1444), and the host's project directory is passed through (#1443).
  • The installer's already-installed probe reads JSONC settings.json correctly, and the plugin honors a repo defaultMode: "off" (#1430, #1431 by @Quinnod345).

Hermes

  • caveman enable hermes writes YAML that still parses (#1405). It reads ownership by value, so a reformatted config stays owned (#1410). It honors plugins.enabled / plugins.disabled membership (#1442, #1446 by @Ha1baraA11).

Pi (@caveman-ai/pi 0.3.2)

  • Per-prompt context is sent as a message, so the provider's prompt cache survives each prompt (#1364, #1376 by @worldofgeese).
  • Tool outputs under 4 KB are no longer replaced by a retrieval handle (#1365, #1378 by @danieldutu). caveman_retrieve with a query now says it returns an excerpt (#1368, #1377 by @danieldutu).
  • Pi's virtual router/auto model no longer warns that it is unroutable (#1449). The compat route is verified for an OpenAI base URL without /v1 (#1325 by @szsunyuan).

Proxy, stats and cost

  • Claude Code requests that declare the advisor tool are priced again, instead of every request showing "Unknown" cost (#1465). Streaming Anthropic responses read their outcome qualifiers from the right place (#1453).
  • A completed Codex stream closed by the client keeps its token counts (#1397, #1398 by @Ha1baraA11).
  • caveman start reads the proxy's top-level mode, not a nested middleware.mode (#1457).
  • A compat upstream blocked by the SSRF guard now answers cave_upstream_blocked and logs the host plus the CAVE_SSRF_ALLOWLIST fix, instead of a generic 502 (#1440).
  • caveman stats no longer times out on large stores: per-request cache digests moved to their own table, migrated in the background (#1371, #1481). On a timeout it names the database size and suggests --days 7.
  • Native runtime: CCR writes no longer re-scan the whole store, which in large homes made native requests run out their 250 ms budget and close empty (#1279). Overlong native.sock paths are reported (#1399, #1402 by @Ha1baraA11).
  • Recovery bytes that don't match their handle are refused (#1373 by @zsltg). The recovery store's page cap applies on every connection, and its writes are serialized (#1374, #1375 by @zsltg). Stats windows are indexed (#1372 by @zsltg). Bedrock ARN model ids keep their encoded slash (#1345 by @AlSh007). A middleware response is not marked over the limit at a quarter of it (#1367 by @AlSh007). Kimi K3 effort is mapped (#1306 by @ysntony). The wrap plugin's caveman_retrieve results are no longer recompressed (#1432).
  • Claude OAuth token refresh is relayed through the proxy. Routed Gemini pins API-key auth instead of exiting 41.
  • The pricing catalog was re-verified against vendor pages (no price changed). Vertex gemini-2.5-pro and gemini-2.5-flash were removed: Google retired both on 2026-10-20, and those requests now show as unpriced rather than mispriced (#1473).

Hooks and installer

  • Statusline setup keeps literal $ in CLAUDE_CONFIG_DIR paths (#1400, #1401 by @Ha1baraA11). Managed hook entries are compared ignoring key order, so doctor --fix stops fighting a reordered entry (#1437, #1420 by @jamestrandung). Uninstall no longer deletes a settings.json.bak it didn't create (#1330 by @AlSh007).
  • Codex PostCompact hook output is valid (#1467 by @mauhpr). Cursor stops always injecting skill files from AGENTS.md (#1411 by @minhhung2556). Hook downloads are bounded and pinned to HTTPS (#1269 by @tejgokani).
  • ENABLE_TOOL_SEARCH defaults to "true" to match Claude Code (#1362 by @AliReza99).

Engine, shrink and learn

  • Escaped pipes stay inside Markdown table cells (#1456 by @kevin9327). Integers above 2^53 stay off the numeric range track (#1332 by @AlSh007). Elision notes are placed stably (#1343 by @CHLIN0). CR-separated terminal output is no longer truncated.
  • caveman-shrink skips null list entries instead of exiting (#1435, #1436 by @shaikn6), and reads Anthropic input_schema tools (#1331 by @AlSh007).
  • caveman learn stops reporting caveman's own injected context as text you pasted (#1459), and separates cold resumes from cache churn (#1419 by @jamestrandung).

Agent versions

  • Tested agent versions move up: Codex 0.166.0, Claude Code 2.1.318, Gemini CLI 0.67.0, OpenCode 1.19.5, Qwen Code 0.26.8, Kilo 7.8.27, OpenClaw 2026.11.1 and Hermes 0.23.0, each passing the repo's conformance run (#1474, with #1416 by @szsunyuan and #1451 by @anirudhqwerty). Pi stays at 1.0.4 for now; Pi 1.5.0 needs compatibility work (#1225).

Maintenance

  • Security: klauspost/compress v1.20.3 (GO-2026-6865), golang.org/x/net v0.62.0 (GO-2026-6860, GO-2026-6866), and a patched Go toolchain. @caveman-ai/middleware's MCP adapter now requires @modelcontextprotocol/sdk 1.32.0 or newer (GHSA-6prh-2h8m-c8cw), and says so when it finds an older one (#1466 by @sudip28122812-creator). filelock is patched, and the broken litellm releases are excluded (#1379 by @szsunyuan).
  • Dependency bumps: npm dev group (#1479), golang image, pip group.
  • Binaries: bin-v4.1.0. CLI: @caveman-ai/cli 4.1.0. Pi: @caveman-ai/pi 0.3.2.

Packages

  • Signed binaries, module index and container: bin-v4.1.0
  • npm CLI: @caveman-ai/cli@4.1.0
  • npm Pi extension: @caveman-ai/pi@0.3.2
  • npm middleware: @caveman-ai/middleware@1.1.0
  • PyPI middleware: caveman-middleware==1.0.1
