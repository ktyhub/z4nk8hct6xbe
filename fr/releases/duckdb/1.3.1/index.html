duckdb v1.3.1

Il s'agit d'une version de correction de bugs pour divers problèmes découverts après la publication de 1.3.0 "Ossivalis". Il n'y a pas de nouvelles fonctionnalités majeures, juste des corrections de bugs. Les fichiers de base de données créés par les versions de DuckDB depuis v0.9 peuvent être lus par cette version.

duckdb v1.3.1
