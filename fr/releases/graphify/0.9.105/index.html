graphique v0.9.105

graphique 0.9.105

  • Correction : les répertoires watch ignorés (node_modules, .git, sortie de build) sont supprimés de l'arborescence de surveillance Linux, donc un grand projet n'enregistre plus des dizaines de milliers de surveillances inotify gaspillées et risque ENOSPC ; l'observateur récursif non Linux est inchangé et se déclenche toujours à chaque changement réel (#5074, #5091, merci @Deepjyoti-Sarmah).
  • Correction : cpp une chaîne d'appel de membre acheminée via des champs de classe déclarés dans d'autres en-têtes (client.actions->Execute(), avec la valeur ., le pointeur brut -> et les récepteurs unique_ptr/shared_ptr à argument unique) se résout en membre du type de champ à travers l'ensemble d'inclusion, fermée à un type et un membre uniques et fermée par échec dans le cas contraire ; un local typé dont la classe se trouve dans un autre dépôt est garé pour la fusion entre dépôts (#5098, merci @xRedLeader).
  • Correction : markdown une étendue de code nommant une classe d'espace de noms \ majuscule (\Foo\Bar, App\API) ou un appel de méthode qualifié par type (Type::member()) est conservée comme mention de symbole au lieu d'être supprimée, tandis qu'un non-appel Type::CONST/Type::class reste supprimé (#5093, merci @Adityakk9031).
  • Correction : ts/js un appel via une demande de baril CommonJS déstructuré (const { Thing } = require('./barrel') où le baril réexporte Thing) se résout en déclaration réelle en suivant les exportations du baril, au lieu de laisser tomber le bord (#5034, #5104, merci @qq2514568380).
  • Correction : wiki le balayage orphelin plie les slugs avec casefold (et non lower), donc deux noms d'articles qui entrent en collision uniquement sous une casse Unicode complète (Straße/STRASSE, Σ/ς) conservent chacun leur propre fichier au lieu d'en supprimer un en tant qu'orphelin ; un fichier écrit lors de cette exécution n'est jamais balayé (#5087, #5102, merci @nothariharan).
  • Correctif : les hyperedges build sont conservés entiers sur un graphify update incrémentiel : ils sont lus à partir de l'emplacement de graphique imbriqué qu'un écrivain uniquement JSON utilise, et après un élagage de la source supprimée, un hyperedge supprime uniquement ses membres supprimés (et lui-même uniquement lorsqu'il n'en reste aucun), au lieu de perdre ou de laisser silencieusement les hyperedges pendants (#5081, #5103, merci @nothariharan).
  • Correction : cache une entrée de cache sémantique dégradée (sous-production) n'épingle plus le corpus : après que le Shrink Guard voit une réextraction revenir plus petite que le graphe stocké, l'entrée est estampillée partial donc la prochaine exécution la redistribue au lieu de rejouer le résultat dégradé pour toujours (#5083, #5101, merci @nothariharan).
  • Correctif : affecté graphify affected <file> amorce les nœuds membres imbriqués du fichier (une méthode à l'intérieur d'une classe) de manière transitive, pas seulement un saut, donc l'analyse d'impact ne sous-estime plus les appelants qui se lient à un membre imbriqué (#5094, merci @Adityakk9031).
  • Correction : tree build_tree dérive la racine du répertoire commun des fichiers parents, donc une arborescence à fichier unique ou à répertoire unique n'est plus auto-imbriquée sous le fichier lui-même (#5092, merci @Adityakk9031).
  • Correction : requête une étiquette dont le nom se trouve derrière un qualificatif de schéma ou d'espace de noms (public.sweep_widget_state(), fmt.Println) est mise en correspondance sur sa queue par l'ensemble de la requête et classée au-dessus des niveaux par jeton, elle n'est donc plus concurrencée par les nœuds de collision à jeton unique et supprimée des graines (#5080, #5095, merci @sunhouy).
  • Correction : détecter qu'une vérification d'obsolescence incrémentielle hache un fichier dont le tampon atterrit dans la fenêtre d'inclinaison de l'horloge de chaque côté de son mtime, donc une réécriture de même tick qui ne bouge pas mtime est toujours interceptée au lieu d'être servie périmée (#5090, merci @sunhouy).
  • Correction : path graphify path A B refuse un point de terminaison dont les mots n'apparaissent nulle part dans le graphique (sortie introuvable) au lieu de renvoyer une route trompeuse construite à partir de jetons qui se chevauchent vaguement (#5085, merci @sunhouy).
  • Correction : csharp, un appel de méthode d'extension classique (x.Foo() où Foo est déclaré static ... Foo(this X x, ...)) se lie à la déclaration de la méthode d'extension via une passe additive qui s'exécute après la répartition nominale, fermée à un espace de noms visible, un type this correspondant et une méthode applicable unique ; une méthode d'instance du même nom gagne, une extension statique sans extension ou une extension non importée n'obtient aucun avantage et l'ambiguïté échoue (#4828, #4849, merci @Deepjyoti-Sarmah).
  • Correction : markdown une mention de fonction libre nue et non qualifiée en prose (token, pas de () et pas d'espace de noms) se lie à une fonction du même nom uniquement lorsque son fichier de définition (ou un autre symbole de celui-ci) est cité dans la chaîne de sections du titre, au lieu de correspondre à tout appelable du même nom dans le corpus ; les liens de style référence ([text][label]) sont résolus sur le site d'utilisation (#4804, #4806, merci @madanlalit).
  • Correction : export la protection anti-rétrécissement du to_json ne compte plus les sources sémantiques qui ont été remplacées lors de la réextraction ou élaguées en tant que suppressions comme "perdues", donc un graphify update légitime n'est pas refusé ; un véritable psy inexpliqué est toujours refusé (#5107, merci @khkar).
  • Correction : construire un nœud dont file_type ou confidence arrive sous forme de valeur structurée (liste/dict) à partir d'une passe LLM à la dérive ne fait plus planter les contrôles d'adhésion de validation/construction : la validation le fait apparaître comme une erreur de schéma, et la construction le plie en concept/INFERRED sans fabriquer de score (#5088, merci @sdivyanshu90).
  • Correction : llm un document divisible sous la majuscule de caractère dont la sortie du modèle est tronquée est promu en tranche complète et divisé en deux (et réessayé) au lieu d'être conservé comme résultat partiel tronqué ; une unité non séparable ou code/binaire échoue toujours à la fermeture (#5072, #5078, merci @aadilrizwan).
  • Feat : llm les extra_headers d'un fournisseur personnalisé compatible OpenAI sont transmis au client en tant que default_headers, limités à ce fournisseur et avec tout en-tête Authorization supprimé afin qu'il ne puisse pas remplacer les informations d'identification configurées (#3680, #4783, merci @jaimemartinez).
  • Perf : extraire les intermédiaires de graphe entier (le mémo d'analyse sur le one-shot CLI, les listes de travail build/cluster/export) sont libérés dès qu'ils sont consommés, réduisant ainsi le pic de mémoire sur un grand corpus ; la sortie du graphique est identique en octets (#5063, merci @TPAteeq).
  • Correction : skillgen l'invite du sous-agent claw/kiro/pi indique désormais au travailleur d'écrire son morceau dans CHUNK_PATH, donc un morceau de répartition sur disque n'est plus renvoyé en ligne et perdu à l'étape de fusion (#5040, merci @connhodendatabase).
  • Correctif : deps le plancher pypdf est élevé à 6.21.4 dans les extras pdf et all pour récupérer ses correctifs de sécurité (#5015, merci @yotamleo). Le schéma du cache AST passe à 42 ; les caches chauds réexécutent les extractions C++, Markdown et C# concernées.

graphify v0.9.105

graphify 0.9.105

  • Fix: watch ignored directories (node_modules, .git, build output) are pruned from the Linux watch tree, so a large project no longer registers tens of thousands of wasted inotify watches and risks ENOSPC; the non-Linux recursive watcher is unchanged and still fires on every real change (#5074, #5091, thanks @Deepjyoti-Sarmah).

  • Fix: cpp a member-call chain routed through class fields declared in other headers (client.actions->Execute(), with value ., raw-pointer -> and single-arg unique_ptr/shared_ptr receivers) resolves to the field type's member across the include set, gated to a unique type and member and fail-closed otherwise; a typed local whose class is in another repo is parked for the cross-repo merge (#5098, thanks @xRedLeader).

  • Fix: markdown a code span naming an uppercase \-namespace class (\Foo\Bar, App\API) or a type-qualified method call (Type::member()) is kept as a symbol mention instead of being dropped, while a non-call Type::CONST/Type::class stays dropped (#5093, thanks @Adityakk9031).

  • Fix: ts/js a call through a destructured CommonJS barrel require (const { Thing } = require('./barrel') where the barrel re-exports Thing) resolves to the real declaration by following the barrel's exports, instead of dropping the edge (#5034, #5104, thanks @qq2514568380).

  • Fix: wiki the orphan sweep folds slugs with casefold (not lower), so two article names that collide only under full Unicode case-folding (Straße/STRASSE, Σ/ς) each keep their own file instead of one being deleted as an orphan; a file written this run is never swept (#5087, #5102, thanks @nothariharan).

  • Fix: build hyperedges are kept whole across an incremental graphify update: they are read from the nested graph slot a JSON-only writer uses, and after a deleted-source prune a hyperedge drops only its removed members (and itself only when none remain), instead of silently losing or leaving dangling hyperedges (#5081, #5103, thanks @nothariharan).

  • Fix: cache a degraded (under-producing) semantic cache entry no longer pins the corpus: after the shrink guard sees a re-extraction come back smaller than the stored graph, the entry is stamped partial so the next run re-dispatches it instead of replaying the degraded result forever (#5083, #5101, thanks @nothariharan).

  • Fix: affected graphify affected <file> seeds the file's nested member nodes (a method inside a class) transitively, not just one hop, so impact analysis no longer under-reports callers that bind to a nested member (#5094, thanks @Adityakk9031).

  • Fix: tree build_tree derives the common directory root from file parents, so a single-file or single-directory tree is no longer self-nested under the file itself (#5092, thanks @Adityakk9031).

  • Fix: query a label whose name is behind a schema or namespace qualifier (public.sweep_widget_state(), fmt.Println) is matched on its tail by the whole query and ranked above the per-token tiers, so it is no longer out-competed by single-token collision nodes and dropped from the seeds (#5080, #5095, thanks @sunhouy).

  • Fix: detect an incremental staleness check hashes a file whose stamp lands within the clock-skew window on either side of its mtime, so a same-tick rewrite that does not move mtime is still caught instead of being served stale (#5090, thanks @sunhouy).

  • Fix: path graphify path A B refuses an endpoint whose words appear nowhere in the graph (exit not-found) instead of returning a misleading route built from loosely-overlapping tokens (#5085, thanks @sunhouy).

  • Fix: csharp a classic extension-method call (x.Foo() where Foo is declared static ... Foo(this X x, ...)) binds to the extension method's declaration through an additive pass that runs after nominal dispatch, gated to a visible namespace, a matching this type and a unique applicable method; an instance method of the same name wins, a non-extension static or an unimported extension gets no edge, and ambiguity fails closed (#4828, #4849, thanks @Deepjyoti-Sarmah).

  • Fix: markdown a bare, unqualified free-function mention in prose (token, no () and no namespace) binds to a same-named function only when its defining file (or another symbol from it) is cited within the heading's section chain, instead of matching any same-named callable in the corpus; reference-style links ([text][label]) resolve at the use site (#4804, #4806, thanks @madanlalit).

  • Fix: export the to_json shrink guard no longer counts semantic sources that were replaced on re-extract or pruned as deletions as "lost", so a legitimate graphify update is not refused; a genuine unexplained shrink is still refused (#5107, thanks @khkar).

  • Fix: build a node whose file_type or confidence arrives as a structured value (list/dict) from a drifting LLM pass no longer crashes the validate/build membership checks: validation surfaces it as a schema error, and the build folds it to concept/INFERRED without fabricating a score (#5088, thanks @sdivyanshu90).

  • Fix: llm a splittable document below the character cap whose model output truncates is promoted to a full-range slice and bisected (and retried) instead of being kept as a truncated partial result; a non-splittable or code/binary unit still fails closed (#5072, #5078, thanks @aadilrizwan).

  • Feat: llm a custom OpenAI-compatible provider's extra_headers are forwarded to the client as default_headers, scoped to that provider and with any Authorization header dropped so it cannot override the configured credential (#3680, #4783, thanks @jaimemartinez).

  • Perf: extract whole-graph intermediates (the parse memo on the one-shot CLI, build/cluster/export working lists) are freed as soon as they are consumed, cutting peak memory on a large corpus; graph output is byte-identical (#5063, thanks @TPAteeq).

  • Fix: skillgen the claw/kiro/pi subagent prompt now tells the worker to write its chunk to CHUNK_PATH, so a disk-dispatch chunk is no longer returned inline and lost at the merge step (#5040, thanks @connhodendatabase).

  • Fix: deps the pypdf floor is raised to 6.21.4 in the pdf and all extras to pick up its security fixes (#5015, thanks @yotamleo).

The AST cache schema is bumped to 42; warm caches re-run the affected C++, Markdown and C# extractions.
