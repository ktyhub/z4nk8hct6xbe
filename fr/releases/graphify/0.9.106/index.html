graphique v0.9.106

graphique 0.9.106

  • Correctif : install requires-python est limité à >=3.10,<3.15, donc uv tool install graphifyy (et pip) sur une nouvelle machine ne sélectionne plus Python 3.15 — pour lequel tree-sitter n'a pas de roue — et échoue ensuite avec une version source qui nécessite un compilateur C (No such file or directory: 'cc'). uv sélectionne désormais par défaut un interpréteur doté d'une roue (3.14), sans indicateur --python et sans compilateur nécessaire. La ligne Ubuntu/Debian README qui demandait python3.12 (absente sur Debian 12 et Ubuntu 22.04) est remplacée par le programme d'installation uv ou une simple ligne python3/pipx (#5134).
  • Correction : cpp une déclaration directe de classe/struct simple se replie dans sa définition unique exactement qualifiée lorsqu'un fichier atteint l'autre via des inclusions exactes inconditionnelles, et une déclaration de membre sans paramètre se replie dans sa définition hors ligne éprouvée en faisant correspondre le type de retour et les qualificatifs ; les surcharges, les modèles, les déclarations conditionnelles et les inclusions non prouvées restent séparés (#5117, merci @xRedLeader).
  • Correction : cpp un appel de membre est résolu via un alias de type étendu (using Alias = ns::Type;) et via des champs/méthodes hérités, et un type pointee déclaré en avant est complété sur le site d'utilisation ; les récepteurs ambigus, virtuels ou hérités du diamant échouent à la fermeture (#5118, merci @xRedLeader).
  • Correction : cpp un membre de modèle hors ligne conserve son propriétaire de modèle principal éprouvé, et les appels à l'intérieur d'un initialiseur ou d'une liste d'arguments protégés par #if sont récupérés à partir de vues de branche préservant les octets (limitées, fermées en cas d'entrée mal formée/dépassant le budget) ; les récepteurs dépendants restent non résolus (#5115, merci @xRedLeader).
  • Correction : python une annotation en indice pointé (mod.MyBox[Foo]) compte sa valeur une fois comme type au lieu de également comme son propre argument générique, donc la fausse référence generic_arg ne remplace plus le vrai bord parameter_type/return_type (#5113, merci @rohit-jsfreaky).
  • Correction : ts/js un appel via une importation d'espace de noms ESM (import * as ns from './m'; ns.f()), une demande de module entier CommonJS (const m = require('./m'); m.f()) ou un TS import = require se résout en la déclaration réelle ; échec de fermeture sur un module inconnu, un nom non exporté ou un baril ambigu (#5114, #5129, merci @mohitdixit02).
  • Correction : llm une entrée FileSlice précalculée est préservée via extract_corpus_parallel au lieu de planter ou de tamponner un parent partiel comme complet ; une tranche qui ne couvre qu'une partie de son fichier marque le partiel parent pour la réexpédition (#5106, #5128, merci @aadilrizwan).
  • Correction : requête BFS parcourt les niveaux dans un ordre fixe et indépendant du hachage, donc les lignes de bord d'une requête (et qui survivent au budget du jeton) ne varient plus avec PYTHONHASHSEED (#5109, #5112, merci @rohit-jsfreaky).
  • Feat : query --no-doc-demotion (et la clé rc demote_docs / MCP arg) désactive la pondération logicielle source-over-docs pour un corpus docs-first ; les corpus de code ne sont pas affectés par défaut (#5084, #5116, merci @mohitdixit02).
  • Perf : résolution _collision_aware indexe les identifiants des frères et sœurs salés une fois au lieu de réanalyser tous les nœuds à chaque utilisation, réduisant ainsi le temps de résolution sur les grands corpus à forte collision (octet de sortie du graphique identique) (#5108, #5111, merci @rohit-jsfreaky).
  • Correction : manifester un pom.xml en utilisant un xmlns préfixé, entre guillemets simples ou espacé conserve son package Maven et ses nœuds de dépendance au lieu de les perdre ; un espace de noms étranger n'est pas compté deux fois (#5126, merci @sdivyanshu90).
  • Correctif : merge-graphs graphify merge-graphs indique combien de nœuds externes ont été unifiés dans les dépôts au lieu de les absorber silencieusement ; le résultat de la fusion est inchangé (#5127, merci @igorpugatschev).
  • Correction : diagnostics diagnose_extraction ne plante plus sur un conteneur nodes mal formé (nul ou scalaire) ; l'extraction mal formée est toujours visible via l'erreur de construction (#5125, merci @sdivyanshu90).
  • Correction : html le graphique interactif ne dessine plus une région hyperedge sur les membres masqués par une bascule de communauté ; une région disparaît une fois que moins de deux de ses membres restent visibles (#5122, merci @Yi-111-a). Le schéma du cache AST passe à 43 ; les caches chauds réexécutent les extractions Python et C++ concernées.

graphify v0.9.106

graphify 0.9.106

  • Fix: install requires-python is capped to >=3.10,<3.15, so uv tool install graphifyy (and pip) on a fresh machine no longer selects Python 3.15 — for which tree-sitter has no wheel — and then fails with a source build that needs a C compiler (No such file or directory: 'cc'). uv now picks a wheel-having interpreter (3.14) by default, with no --python flag and no compiler needed. The Ubuntu/Debian README line that asked for python3.12 (absent on Debian 12 and Ubuntu 22.04) is replaced with the uv installer or a plain python3/pipx line (#5134).
  • Fix: cpp a plain class/struct forward declaration folds into its unique exactly-qualified definition when one file reaches the other through unconditional exact quoted includes, and a parameterless member declaration folds into its proven out-of-line definition by matching return type and qualifiers; overloads, templates, conditional declarations and unproven includes stay separate (#5117, thanks @xRedLeader).
  • Fix: cpp a member call resolves through a scoped type alias (using Alias = ns::Type;) and through inherited fields/methods, and a forward-declared pointee type is completed at the use site; ambiguous, virtual or diamond-inherited receivers fail closed (#5118, thanks @xRedLeader).
  • Fix: cpp an out-of-line template member keeps its proven primary-template owner, and calls inside a #if-guarded initializer or argument list are recovered from byte-preserving branch views (bounded, fail-closed on malformed/over-budget input); dependent receivers stay unresolved (#5115, thanks @xRedLeader).
  • Fix: python a dotted subscript annotation (mod.MyBox[Foo]) counts its value once as the type instead of also as its own generic argument, so the false generic_arg reference no longer replaces the real parameter_type/return_type edge (#5113, thanks @rohit-jsfreaky).
  • Fix: ts/js a call through an ESM namespace import (import * as ns from './m'; ns.f()), a CommonJS whole-module require (const m = require('./m'); m.f()), or a TS import = require resolves to the real declaration; fail-closed on an unknown module, a non-exported name, or an ambiguous barrel (#5114, #5129, thanks @mohitdixit02).
  • Fix: llm a precomputed FileSlice input is preserved through extract_corpus_parallel instead of crashing or stamping a partial parent complete; a slice that covers only part of its file marks the parent partial for re-dispatch (#5106, #5128, thanks @aadilrizwan).
  • Fix: query BFS walks levels in a fixed, hash-independent order, so a query's edge lines (and which survive the token budget) no longer vary with PYTHONHASHSEED (#5109, #5112, thanks @rohit-jsfreaky).
  • Feat: query --no-doc-demotion (and the demote_docs rc key / MCP arg) disables the source-over-docs soft weight for a docs-first corpus; code corpora are unaffected by default (#5084, #5116, thanks @mohitdixit02).
  • Perf: resolution _collision_aware indexes salted sibling ids once instead of rescanning all nodes per use, cutting resolution time on large collision-heavy corpora (graph output byte-identical) (#5108, #5111, thanks @rohit-jsfreaky).
  • Fix: manifest a pom.xml using a prefixed, single-quoted or spaced xmlns keeps its Maven package and dependency nodes instead of losing them; a foreign namespace is not double-counted (#5126, thanks @sdivyanshu90).
  • Fix: merge-graphs graphify merge-graphs reports how many external nodes were unified across repos instead of silently absorbing them; the merge result is unchanged (#5127, thanks @igorpugatschev).
  • Fix: diagnostics diagnose_extraction no longer crashes on a malformed nodes container (null or scalar); the malformed extraction is still surfaced through the build error (#5125, thanks @sdivyanshu90).
  • Fix: html the interactive graph no longer draws a hyperedge region over members hidden by a community toggle; a region vanishes once fewer than two of its members stay visible (#5122, thanks @Yi-111-a).

The AST cache schema is bumped to 43; warm caches re-run the affected Python and C++ extractions.
