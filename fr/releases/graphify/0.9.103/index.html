graphique v0.9.103

graphique 0.9.103

Une large version d'exactitude, de performances et de robustesse pour les extracteurs, la résolution, les hooks, les chemins de requête et de mise à jour, l'installation et le runbook de compétences.

Extracteurs

  • C# : les directives du préprocesseur et les branches #if qui font dérailler le tree-sitter sont effacées avant l'analyse (préservation de la longueur des octets), de sorte qu'une directive ne ferme plus une classe plus tôt et supprime les membres ou les appels ultérieurs.
  • Solidité : les appels de bibliothèque (Lib.f(), y compris les importations avec alias) et emit/revert/require nommant un événement ou une erreur déclaré sont désormais liés au membre qu'ils nomment, liés à un type et un membre visibles uniques.
  • YAML : une séquence de fusion << donne la priorité d'ancrage précédente pour une clé dupliquée, correspondant à la spécification et à PyYAML.
  • Markdown : une étendue de code écrite sous la forme d'un espace de noms de barre oblique inverse (\Foo\Bar) ou d'un membre qualifié de type (Type::member) se résout en nœud réel ; une mention en pointillés dont le nom de méthode est un langage intégré n'est plus supprimée.
  • Python : un appel nommé intégré (raise NotImplementedError(...)) ne se lie plus à une classe du même nom dans un autre module à moins d'être importé.

Résolution

  • Un appel à l'intérieur d'un def _main() de niveau supérieur est attribué à _main, et non au main public avec lequel il entre en collision après la normalisation de l'identifiant, sans attribuer à tort la référence de type d'un membre de la classe.

Crochets

  • Un fichier dont le contenu est inchangé n'est pas à nouveau signalé comme obsolète par mtime (le hachage d'extraction est vérifié par rapport au manifeste).
  • Un Grep dédié est tenu au portail d'orientation stricte ; une lecture de fichier Bash (cat/head/sed -n) d'un fichier de code dans le projet obtient le coup de pouce de lecture ; une recherche dont chaque cible est en dehors du projet n'émet aucun indice de projet ; le budget de nudge est rétabli après un compactage Claude Code ; et l'ancre de niveau supérieur continue de fonctionner lorsque CDPATH est exporté.

Performances

  • Mémoire de pointe inférieure en charge, résolution et extraction ; un repointage inter-fichiers #3252 plus rapide ; et la passe de réconciliation de surveillance résout la propriété AST une fois par fichier au lieu de relire chaque en-tête par nœud – le tout avec une sortie graphique identique.

Mise à jour / build / cache

  • graphify update réextrait uniquement les fichiers dont le contenu a changé (identique à une reconstruction complète) ; une demande incrémentielle contestée est enregistrée au lieu d'être abandonnée. La protection contre l'écriture de build ne compte plus les replis fantômes/dédoublons intentionnels comme des abandons ; les clés de cache conservent leur écrin écrit.

Requête/arborescence

  • Les nœuds sources sont classés au-dessus des tests et des documents (un poids doux) avec des réponses classées en premier ; query lit query_budget/query_depth à partir de .graphifyrc et gagne --depth. export tree limite les enfants du répertoire tout en rapportant les totaux complets.

Installation / sécurité des threads

  • La compétence du projet Pi est écrite dans .pi/skills ; la désinstallation supprime l'enregistrement global des compétences qu'il a écrit. La racine de l'analyse ambiante est conservée dans un ContextVar afin que les appelants de bibliothèque simultanés extrayant différentes racines ne se heurtent pas. Le schéma du cache AST est repoussé à l'état actuel. les caches chauds réexécutent les extractions concernées. graphify v0.9.103

graphify 0.9.103

A broad correctness, performance and robustness release across the extractors, resolution, hooks, the query and update paths, install and the skill runbook.

Extractors

  • C#: preprocessor directives and #if branches that derail tree-sitter are blanked before parsing (byte-length preserving), so a directive no longer closes a class early and drops later members or calls.
  • Solidity: library calls (Lib.f(), including aliased imports) and emit/revert/require naming a declared event or error now link to the member they name, gated to a unique visible type and member.
  • YAML: a << merge sequence gives the earlier anchor precedence for a duplicated key, matching the spec and PyYAML.
  • Markdown: a code span written as a backslash namespace (\Foo\Bar) or a type-qualified member (Type::member) resolves to the real node; a dotted mention whose method name is a language builtin is no longer dropped.
  • Python: a bare builtin-named call (raise NotImplementedError(...)) no longer binds to a same-named class in another module unless imported.

Resolution

  • A call inside a top-level def _main() is attributed to _main, not the public main it collides with after id normalization, without misattributing a class member's type reference.

Hooks

  • A file unchanged in content is not re-flagged stale by mtime (the extraction hash is checked against the manifest).
  • A dedicated Grep is held to the strict orientation gate; a Bash file read (cat/head/sed -n) of an in-project code file gets the read nudge; a search whose every target is outside the project emits no project hint; the nudge budget is restored after a Claude Code compaction; and the toplevel anchor keeps working when CDPATH is exported.

Performance

  • Lower peak memory in load, resolution and extraction; a faster #3252 cross-file repoint; and the watch reconcile pass resolves AST ownership once per file instead of re-reading each header per node — all with identical graph output.

Update / build / cache

  • graphify update re-extracts only the files whose content changed (identical to a full rebuild); a contended incremental request is recorded instead of dropped. The build write guard no longer counts intentional ghost/dedup folds as drops; cache keys keep their written case.

Query / tree

  • Source nodes rank above tests and docs (a soft weight) with file-first answers; query reads query_budget/query_depth from .graphifyrc and gains --depth. export tree caps directory children while reporting full totals.

Install / thread-safety

  • The Pi project skill is written to .pi/skills; uninstall removes the global skill registration it wrote. The ambient scan root is held in a ContextVar so concurrent library callers extracting different roots do not clobber each other.

The AST cache schema is bumped to 39; warm caches re-run the affected extractions.
