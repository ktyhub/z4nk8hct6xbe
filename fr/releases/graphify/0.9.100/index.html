graphique v0.9.100

0.9.100 (2026-11-01)

  • Correction : ids un type et une fonction dont les noms ne diffèrent que dans le cas où (Foo la classe, foo la fonction) obtiennent des identifiants de nœud distincts au lieu d'entrer en collision (ce qui a laissé tomber un nœud et créé une fausse boucle automatique) (#4904, #4908, merci @bercedev).
  • Correction : php un accès Scope::MEMBER dans un initialiseur au niveau de la classe (une valeur const, une propriété par défaut ou un paramètre/constructeur promu par défaut) émet un bord references_constant ; self::/static::/parent:: sont ignorés et les portées inconnues ne contiennent pas de stub (#4648, #4895, merci @Jitendarmahara).
  • Correctif : hooks La sortie git rev-parse est décodée en UTF-8, donc un arbre de travail lié sous un chemin non-ASCII se résout correctement sous Windows au lieu de mojibake (#4903, merci @LukeTheoJohnson).
  • Correction : analyser sur un graphique contenant uniquement du code, la raison de la question sur le nœud isolé indique "des bords manquants possibles" plutôt que de faire référence à des lacunes dans la documentation qui ne peuvent pas s'appliquer (#4887, merci @oleksii-tumanov).
  • Perf : resolve les bords de référence sont indexés une fois par source, donc la résolution d'importation JS/TS ne parcourt plus chaque bord par importation (sortie inchangée) (#4909, #4913, merci @Deepjyoti-Sarmah).
  • Docs : compétence la compétence indique désormais quand un graphique mérite d'être construit, sur tous les hôtes générés, tout en préservant l'invariant "si l'utilisateur a invoqué /graphify, faites-le comme demandé" (#4829, #4906, merci @TanmayShah29).
  • Correction : deps le video majuscule supplémentaire PyAV en dessous de 19 (av>=11,<19), car PyAV 19 a supprimé l'argument metadata_errors selon lequel le chuchotement plus rapide passe sans condition lors de l'ouverture de l'audio ; sans le capuchon, une nouvelle installation sur Python 3.12+ n'a pas réussi à transcrire (#4842, merci @SyedFahad7).
  • Correctif : r setClass/setRefClass L'héritage S4/R5 déclaré avec contains= émet désormais un bord d'héritage (auparavant, seul le inherit= de R6Class était reconnu) (#4902, merci @ayushcodes10).
  • Correction : elixir un simple appel de fonction se résout en une fonction dans le propre module de l'appelant avant les autres modules, au lieu de se lier à la dernière définition du même nom parcourue (#4900, merci @ayushcodes10).
  • Correction : dart une clause mixin on A, B résout chaque contrainte de superclasse, pas seulement la première (#4899, merci @ayushcodes10).
  • Correction : fortran le extends(base) d'un type dérivé émet un bord hérité, aligne Fortran avec les autres extracteurs POO (#4897, merci @ayushcodes10).
  • Correction : scala un extension (x: T) def m est limité à son type de récepteur T (un bord method à T) au lieu de fuir vers la portée du fichier (#2044, #4856, merci @divakantpandey).
  • Correction : terraform un nœud porte sa portée d'origine afin que les identifiants restent stables lorsqu'un répertoire de projet mis en cache est déplacé, au lieu de rediriger la portée du nouveau chemin (#4858, #4861, merci @yUm1k4).
  • Correction : extrait (JVM) Les importations Java et Kotlin, extends/implements et les appels de membres sont résolus dans les fichiers et dans les deux langues lorsqu'un FQN écrit nomme exactement un type source (#4874, #4879, merci @Deepjyoti-Sarmah).
  • Correction : export un rendu chemin/explication/wiki répertorie toutes les relations parallèles entre deux nœuds (via edge_datas), et une écriture brute --no-cluster marque le graphe multigraph afin que les arêtes parallèles survivent au rechargement (#4794, merci @ensell-yes).
  • Correctif : export une sauvegarde partielle ou échouée est signalée comme aucune sauvegarde et réessayée lors de l'exécution suivante, au lieu d'être enregistrée comme un faux succès (#3769, #4834, merci @barlowa124).
  • Correction : affecté graphify affected (et query --seed) résolvent les mêmes formes de référence path::Symbol et de référence en pointillés que explain accepte, en réutilisant le résolveur d'explication, et sortent non nul (3 ambigus / 4 non trouvés) sur une graine qui ne se résout pas (#4792, #4797, merci @dupeisen).
  • Correction : install graphify uninstall supprime la compétence utilisateur de chaque plate-forme (13 ont été laissées pour compte) et la commande globale kilo ; et graphify kilo uninstall supprime le side-car references/ de la compétence kilo (#4782, #4789, merci @bercedev).
  • Feat : llm le backend Claude met en cache son invite système (stable et volumineuse) avec cache_control, en comptant les jetons mis en cache dans input_tokens, et GRAPHIFY_CLAUDE_PROMPT_CACHE=0 le désactive pour les passerelles qui rejettent cache_control (#4835, #4855, #4880, merci @Jvxoq et @1akashkalita).
  • Correction : invite la description du format d'identifiant de nœud dans l'invite d'extraction correspond à ce que ids.py produit réellement (caractères de mots conservés, lettres/chiffres non-ASCII conservés, ASCII minuscules) au lieu du libellé périmé "[a-z0-9_] uniquement" (#4432, #4799, merci @dupeisen).
  • Docs : comment ça marche le nombre de langues prises en charge est mis à jour (environ 40 : 33 grammaires arborescentes plus 7 analyseurs intégrés) et le Pass 3 est décrit comme exécutant le backend LLM configuré, pas Claude uniquement (#4873, merci @SyedFahad7).

graphify v0.9.100

0.9.100 (2026-11-01)

  • Fix: ids a type and a function whose names differ only in case (Foo the class, foo the function) get distinct node ids instead of colliding (which dropped one node and minted a bogus self-loop) (#4904, #4908, thanks @bercedev).
  • Fix: php a Scope::MEMBER access in a class-level initializer (a const value, a property default, or a parameter/promoted-constructor default) emits a references_constant edge; self::/static::/parent:: are skipped and unknown scopes mint no stub (#4648, #4895, thanks @Jitendarmahara).
  • Fix: hooks git rev-parse output is decoded as UTF-8, so a linked worktree under a non-ASCII path resolves correctly on Windows instead of mojibake (#4903, thanks @LukeTheoJohnson).
  • Fix: analyze on a code-only graph the isolated-node question reason says "possible missing edges" rather than referencing documentation gaps that cannot apply (#4887, thanks @oleksii-tumanov).
  • Perf: resolve reference edges are indexed by source once, so JS/TS import resolution no longer re-walks every edge per import (output unchanged) (#4909, #4913, thanks @Deepjyoti-Sarmah).
  • Docs: skill the skill now says when a graph is worth building, across all generated hosts, while preserving the "if the user invoked /graphify, do it as asked" invariant (#4829, #4906, thanks @TanmayShah29).
  • Fix: deps the video extra caps PyAV below 19 (av>=11,<19), because PyAV 19 removed the metadata_errors argument that faster-whisper passes unconditionally when opening audio; without the cap a fresh install on Python 3.12+ failed to transcribe (#4842, thanks @SyedFahad7).
  • Fix: r setClass/setRefClass S4/R5 inheritance declared with contains= now emits an inherits edge (previously only R6Class's inherit= was recognised) (#4902, thanks @ayushcodes10).
  • Fix: elixir a bare function call resolves to a function in the caller's own module before other modules, instead of binding to the last-walked same-named definition (#4900, thanks @ayushcodes10).
  • Fix: dart a mixin on A, B clause resolves every superclass constraint, not just the first (#4899, thanks @ayushcodes10).
  • Fix: fortran a derived type's extends(base) emits an inherits edge, bringing Fortran in line with the other OOP extractors (#4897, thanks @ayushcodes10).
  • Fix: scala an extension (x: T) def m is scoped to its receiver type T (a method edge to T) instead of leaking to file scope (#2044, #4856, thanks @divakantpandey).
  • Fix: terraform a node carries its original scope so ids stay stable when a cached project directory is moved, instead of re-deriving the scope from the new path (#4858, #4861, thanks @yUm1k4).
  • Fix: extract (JVM) Java and Kotlin imports, extends/implements and member calls resolve across files and across the two languages when a written FQN names exactly one sourced type (#4874, #4879, thanks @Deepjyoti-Sarmah).
  • Fix: export a path/explain/wiki rendering lists every parallel relation between two nodes (via edge_datas), and a raw --no-cluster write marks the graph multigraph so parallel edges survive reload (#4794, thanks @ensell-yes).
  • Fix: export a partial or failed backup is reported as no backup and retried on the next run, instead of being recorded as a false success (#3769, #4834, thanks @barlowa124).
  • Fix: affected graphify affected (and query --seed) resolve the same path::Symbol and dotted reference forms explain accepts, reusing explain's resolver, and exit non-zero (3 ambiguous / 4 not-found) on a seed that does not resolve (#4792, #4797, thanks @dupeisen).
  • Fix: install graphify uninstall removes every platform's user-scope skill (13 were left behind) and the kilo global command; and graphify kilo uninstall removes the kilo skill's references/ sidecar (#4782, #4789, thanks @bercedev).
  • Feat: llm the Claude backend caches its (stable, large) system prompt with cache_control, counting the cached tokens back into input_tokens, and GRAPHIFY_CLAUDE_PROMPT_CACHE=0 disables it for gateways that reject cache_control (#4835, #4855, #4880, thanks @Jvxoq and @1akashkalita).
  • Fix: prompt the node-id format description in the extraction prompt matches what ids.py actually produces (word characters kept, non-ASCII letters/digits preserved, ASCII lowercased) instead of the stale "[a-z0-9_] only" wording (#4432, #4799, thanks @dupeisen).
  • Docs: how-it-works the supported-language count is updated (about 40: 33 tree-sitter grammars plus 7 built-in parsers) and Pass 3 is described as running the configured LLM backend, not Claude only (#4873, thanks @SyedFahad7).
