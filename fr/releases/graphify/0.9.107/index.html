graphique v0.9.107

  • Correction : cpp une déclaration de membre pliée sans paramètre (bar()) enregistre son implémentation dans definition_file comme un chemin ancré à la même racine que source_file, au lieu d'un parcours ../ relatif à la racine cache/out. La réconciliation sans argument ajoutée dans 0.9.106 stockait le formulaire de preuve interne _cpp_source_key, que _norm_source_file ne peut pas réancrer (il relativise uniquement les chemins absolus), de sorte qu'un corpus hors arbre a obtenu un definition_file mutilé. La fusion frère decl/def a déjà stocké le source_file brut pour cette raison ; les deux chemins s’accordent désormais. La preuve du chemin d'inclusion utilise toujours la forme clé.
  • Correction : llm une tranche dont le délai d'attente ou le dépassement de contexte est reconnu et abandonné (elle ne peut pas être divisée davantage, ou la profondeur de nouvelle tentative est épuisée) marque désormais son fichier comme partiel, donc un document dont la tranche de queue a expiré n'est plus mis en cache et estampillé complet de ses autres tranches ; il est remis en file d'attente lors de la prochaine exécution tandis que les résultats des fichiers frères sont conservés (#5099, merci @khrisshie).
  • Correction : php une analyse du chemin de route s'arrête au propre argument de la fermeture, donc $app->get('/users', function () { ... }) conserve GET /users au lieu de lire un argument de chaîne de fin après la fermeture comme route ; un chemin légitime avant la fermeture est inchangé (#5135, merci @mppyxx).
  • Correction : ids deux déclarations au niveau module du même type dans un fichier dont les noms diffèrent uniquement par les traits de soulignement de début/fin (function _save(){} et function save(){ return _save() }) sont encore deux nœuds au lieu d'un, et l'appel entre eux est un véritable bord save -> _save au lieu d'un auto-appel save -> save fabriqué ; la déclaration qui apparaît en premier conserve l'identifiant brut et l'autre est salée. Affecte JS, TS, C, C++, PHP, Ruby, Kotlin, Swift et Lua (#2810, merci @khrisshie).
  • Correction : les méthodes php d'une classe, d'un trait, d'une interface ou d'une énumération dont les noms ne diffèrent que par un _ de début/fin (_x() / x()) sont des nœuds séparés au lieu que l'un avale l'autre : un nom public garde son identifiant et les autres sont salés, comme dans Python, C#, JS/TS et Solidity, donc $this->x() et $b->x() atteignent x() à la place. d'être perdu et $this->_x() ne ressemble plus à un auto-appel (#5137, merci @khrisshie).
  • Correction : les membres java d'une classe dont les noms diffèrent uniquement par un _ de début/fin (_name / name) ou seulement par la casse (run / Run, que Java traite comme distincts) obtiennent des identifiants de nœuds séparés au lieu que l'un avale l'autre ; un nom public garde son identifiant et les jumeaux sont salés, comme dans les autres langues, donc les appels à chacun se résolvent correctement (#5151, merci @rohit-jsfreaky).
  • Correctif : test le test d'identification Terraform du cache copié accepte un pool de tâches qui n'a pas pu démarrer sous la pression des ressources (il revient au mode séquentiel et avertit), au lieu d'affirmer que le pool démarre toujours ; un pool véritablement cassé échoue toujours au test (# 5136, merci @mppyxx).
  • Correction : php/js un appel via un membre d'espace de noms ESM (import * as ns; ns.handler()) ou un module entier nécessite une résolution uniquement lorsque la cible est réellement appelable, donc un membre d'espace de noms qui nomme une exportation non appelable (un objet littéral, une constante) n'obtient plus un bord d'appel parasite (#5144, merci @ayushcodes10).
  • Perf : interroger le chemin de lecture (requête/explication/chemin/affecté et chargement du graphe MCP) n'importe plus tous les extracteurs de langue, réduisant ainsi le coût d'importation des commandes en lecture seule ; la sortie du graphique est inchangée (merci @rohit-jsfreaky).
  • Perf : extraire le pool de nœuds de calcul AST est dimensionné en fonction de la quantité de travail non mis en cache (un nœud de calcul pour ~ 500 Ko de source non mise en cache, limité au nombre de processeurs et de fichiers) lorsqu'aucun nombre de nœuds de calcul n'est défini, de sorte que les petites builds incrémentielles arrêtent de créer un pool complet ; la sortie est invariante au nombre de travailleurs (merci @rohit-jsfreaky).
  • Modification : cloud les surfaces OSS (README, texte d'aide/d'installation de CLI, les documents traduits dans les 31 paramètres régionaux et la compétence d'agent) pointent désormais vers le plan gratuit sans carte sur app.graphify.com/signup, au lieu d'un "essai de 14 jours" sur /login (l'essai est réservé aux forfaits payants et nécessite une carte, donc l'ancienne copie confondait les deux). Les liens portent des UTM utm_campaign=oss étiquetés par surface, de sorte qu'une inscription peut être attribuée à son origine.
  • Changement : cloud le nudge post-build du CLI est contextuel. Il est uniquement TTY (jamais dans CI ou dans le pipeline d'agent), respecte GRAPHIFY_NO_TIPS/GRAPHIFY_NO_CTA et s'affiche sur les builds 1, 5 et 20 puis reste silencieux pour de bon. Lorsqu'un graphique local atteint 25 000 nœuds, le seuil par dépôt du forfait gratuit, le coup de pouce passe à une ligne spécifique à l'échelle (étiquetée utm_content=scale) qui vend Graphify Pro et renvoie aux tarifs avec l'essai de 14 jours, au lieu de l'inscription gratuite : un dépôt de cette taille ne correspond plus au forfait gratuit, donc le pointer vers le forfait gratuit atterrirait directement sur la limite. Le schéma du cache AST passe à 44 ; les caches chauds réexécutent les extractions C++, PHP, Java et ID au niveau du module concernées.

graphify v0.9.107

  • Fix: cpp a folded parameterless member declaration (bar()) records its implementation in definition_file as a path anchored to the same root as source_file, instead of a ../-walk relative to the cache/out root. The zero-argument reconciliation added in 0.9.106 stored the internal _cpp_source_key proof form, which _norm_source_file cannot re-anchor (it only relativizes absolute paths), so an out-of-tree corpus got a mangled definition_file. The sibling decl/def merge already stored the raw source_file for this reason; both paths now agree. The include-path proof still uses the key form.
  • Fix: llm a slice whose timeout or context overflow is recognised and given up on (it cannot be split further, or the retry depth is exhausted) now marks its file partial, so a document whose tail slice timed out is no longer cached and stamped complete from its other slices; it is re-queued on the next run while sibling files' results are kept (#5099, thanks @khrisshie).
  • Fix: php a route path scan stops at the closure's own argument, so $app->get('/users', function () { ... }) keeps GET /users instead of reading a trailing string argument after the closure as the route; a legitimate path before the closure is unchanged (#5135, thanks @mppyxx).
  • Fix: ids two module-level declarations of the same kind in one file whose names differ only by leading/trailing underscores (function _save(){} and function save(){ return _save() }) are two nodes again instead of one, and the call between them is a real save -> _save edge instead of a fabricated save -> save self-call; the declaration that appears first keeps the plain id and the other is salted. Affects JS, TS, C, C++, PHP, Ruby, Kotlin, Swift and Lua (#2810, thanks @khrisshie).
  • Fix: php methods of one class, trait, interface or enum whose names differ only by a leading/trailing _ (_x() / x()) are separate nodes instead of one swallowing the other: the one public name keeps its id and the others are salted, as in Python, C#, JS/TS and Solidity, so $this->x() and $b->x() reach x() instead of being lost and $this->_x() no longer looks like a self-call (#5137, thanks @khrisshie).
  • Fix: java members of one class whose names differ only by a leading/trailing _ (_name / name) or only by case (run / Run, which Java treats as distinct) get separate node ids instead of one swallowing the other; a public name keeps its id and the twins are salted, as in the other languages, so calls to each resolve correctly (#5151, thanks @rohit-jsfreaky).
  • Fix: test the copied-cache terraform id test accepts a worker pool that could not start under resource pressure (it falls back to sequential and warns), instead of asserting the pool always starts; a genuinely broken pool still fails the test (#5136, thanks @mppyxx).
  • Fix: php/js a call through an ESM namespace member (import * as ns; ns.handler()) or whole-module require resolves only when the target is actually callable, so a namespace member that names a non-callable export (an object literal, a constant) no longer gets a spurious call edge (#5144, thanks @ayushcodes10).
  • Perf: query the read path (query/explain/path/affected and the MCP graph load) no longer imports every language extractor, cutting import cost on read-only commands; graph output is unchanged (thanks @rohit-jsfreaky).
  • Perf: extract the AST worker pool is sized by the amount of uncached work (one worker per ~500 KB of uncached source, capped at CPU count and file count) when no worker count is set, so small incremental builds stop spinning up a full pool; output is invariant to worker count (thanks @rohit-jsfreaky).
  • Change: cloud the OSS surfaces (README, CLI help/install text, the translated docs in all 31 locales, and the agent skill) now point at the free plan with no card at app.graphify.com/signup, instead of a "14-day trial" at /login (the trial is paid-plans-only and needs a card, so the old copy conflated the two). Links carry utm_campaign=oss UTMs tagged per surface, so a signup can be attributed to where it came from.
  • Change: cloud the post-build CLI nudge is contextual. It is TTY-only (never in CI or the agent pipeline), respects GRAPHIFY_NO_TIPS/GRAPHIFY_NO_CTA, and shows on builds 1, 5 and 20 then stays quiet for good. When a local graph reaches 25k nodes, the free plan's per-repo cut-off, the nudge switches to a scale-specific line (tagged utm_content=scale) that sells Graphify Pro and links to pricing with the 14-day trial, instead of the free signup: a repo that size no longer fits the free plan, so pointing it at the free plan would land straight on the limit. The AST cache schema is bumped to 44; warm caches re-run the affected C++, PHP, Java and module-level-id extractions.
