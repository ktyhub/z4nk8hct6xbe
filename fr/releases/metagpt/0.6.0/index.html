MétaGPT v0.6.0

Faits saillants de la version

Statistiques numériques

  • Un grand nombre de commits : augmenté de ~1 300 à ~2 000
  • Couverture des tests considérablement améliorée : de ~30 % à 80 %+

Facilité d'utilisation

  • Exemple de simplification : Désormais, seules 7 lignes de code sont nécessaires pour mettre en œuvre un débat électoral général. Exemples de débats simplifiés et de bases de connaissances
  • Asynchrone pur : les appels LLM API sont transformés en asynchrones purs, supprimant tout le code de synchronisation

Mise à jour du framework

  • Code intégré pour prendre en charge la démo Huggingface et AgentStore
  • Ajout de la sérialisation et de la désérialisation des objets importants
  • Prise en charge [récupération de point d'arrêt] (https://docs.deepwisdom.ai/main/en/guide/in_depth_guides/breakpoint_recovery.html)
  • Tous les types modifiés pour se baser sur pydantic v2. Afin de rester assez simple, toutes les variables privées sont remplacées par des variables publiques.
  • Déplacement de la plupart des logiques de ActionOutput vers ActionNode

Mise à jour du fournisseur LLM

  • Package OpenAI mis à niveau vers v1.6.0
  • LLM pris en charge ou optimisés : Gemini, ZhipuAI, [Ollama et autres Open LLM] (https://docs.deepwisdom.ai/main/en/guide/tutorials/integration_with_open_llm.html) etc.

Autre mise à jour

  • Suppression d'une partie OpenInterpreter et StableDiffusion du code
  • Ajout de la stratégie ToT
  • Processus d'installation optimisé : vous pouvez désormais utiliser pip install -e .[dev] / pip install -e .[test] pour installer le package correspondant au scénario

MetaGPT v0.6.0

Highlights

  • Fully asynchronous LLM interface — BaseLLM.ask and BaseLLM.ask_code are removed; migrate callers to await BaseLLM.aask(...) and await BaseLLM.aask_code(...). Custom LLM wrappers must also implement the asynchronous interface.
  • Configuration and naming migrations — Rename OPENAI_API_BASE to OPENAI_BASE_URL in config.yaml, replace BaseGPTAPI with BaseLLM, and update Role._rc references to Role.rc before upgrading.
  • Pydantic v2-based object model — Important objects now inherit from Pydantic v2, with serialization/deserialization support (#590) and breakpoint recovery. Private attributes are now public, and much of ActionOutput moved into ActionNode; review code that depends on internal fields or output behavior.
  • More cloud and local LLM providers — Gemini (#595) and Ollama (#603) join the supported backends, alongside optimized ZhipuAI and other open-model integrations. The OpenAI package is upgraded to v1.6.0 with corresponding LangChain compatibility updates (#605), so validate custom provider adapters against the new client.
  • Removed integrations — OpenInterpreter and StableDiffusion code is no longer bundled. Applications relying on those built-ins need an external replacement or a vendored copy.
  • Experimental Tree-of-Thoughts and simpler setup — ToT strategy support is available experimentally (#643), while pip install -e .[dev] and pip install -e .[test] now install scenario-specific dependencies. Treat ToT as exploratory rather than a stable production guarantee.

Release Highlights

Numerical statistics

  • Huge number of commits: increased from ~1300 to ~2000
  • Significantly improved test coverage: from ~30% to 80%+

Ease of use

  • Example simplification: Now only 7 lines of code are needed to implement a general election debate. Simplified debate and knowledge base related examples
  • Pure asynchronous: LLM API calls are changed to pure asynchronous, removing all synchronization code

Framework update

  • Integrated code to support Huggingface demo and AgentStore
  • Added serialization and deserialization of important objects
  • Supported breakpoint recovery
  • All types modified to base on pydantic v2. In order to keep it simple enough, all private variables are changed to public
  • Moved most logic of ActionOutput to ActionNode

LLM provider update

  • OpenAI package upgraded to v1.6.0
  • Supported or optimized LLMs: Gemini, ZhipuAI, Ollama, and other Open LLMs etc.

Other update

  • Removed OpenInterpreter and StableDiffusion part of the code
  • Added ToT strategy
  • Installation process optimized: now you can use pip install -e .[dev] / pip install -e .[test] to install the package corresponding to the scenario

What's Changed

Backwards Incompatible Changes

  • IMPORTANT: In accordance with OpenAI's official specifications, the OPENAI_API_BASE has been renamed to OPENAI_BASE_URL in config.yaml
  • The underlying abstraction has been renamed from BaseGPTAPI to BaseLLM, making it more generic and capable of supporting API / UI / local interfaces.
  • Role._rc -> Role.rc
  • Removed BaseLLM.ask and BaseLLM.ask_code, maintained the asynchronous BaseLLM.aask and BaseLLM.aask_code only

Features

  • Github related: Add pre-commit code format check and corrected the format #587 #594 by @voidking
  • Optimized example, used purely asynchronous api call, integrated code to support Huggingface and AgentStore, upgraded OpenAI package, built up test suite #589 #671 by @geekan @better629 @seehi @iorisa @shenchucheng @Stitch-z @Justin-ZL @voidking @garylin2099
  • Based important objects to pydantic BaseModel, added serialization and deserialization #590 by @better629
  • Supported Google Gemini as underlying LLM #595 by @better629
  • Github related: Provided issue and pr template #598 by @better629
  • Supported Ollama as underlying LLM #603 by @better629
  • Enabled MetaGPT to be used as a dependency for web applications, such as https://huggingface.co/spaces/deepwisdom/MetaGPT. #621 by @shenchucheng
  • Experimental implementation of ToT strategy #643 by @stellaHSR

Bugfixes and improvements

  • Fixed QaEngineer missing test_round #600 by @better629
  • Upgraded langchain to be compatible with openai new version #605 by @seehi
