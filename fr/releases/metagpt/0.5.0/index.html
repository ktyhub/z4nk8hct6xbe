MétaGPT v0.5.0

Faits saillants de la version

Globalement

  1. Support multilingue (expérimental) : prend désormais en charge le chinois et l'anglais, et théoriquement d'autres langues.
  2. Prise en charge de plusieurs langages de programmation (expérimental) : La prise en charge de divers langages de programmation est désormais disponible, permettant la génération naturelle de projets JavaScript. Cependant, il est à noter que GPT-4-turbo a des capacités nettement plus puissantes dans Python et qu'il existe une marge d'amélioration considérable avec d'autres langages de programmation.
  3. Développement incrémentiel (expérimental) : il est désormais possible d'augmenter progressivement les exigences et les corrections de bugs, permettant une optimisation supplémentaire du dépôt généré.
  4. Support CLI : Vous pouvez désormais utiliser metagpt "make a 2048 game" pour laisser Metagpt écrire le logiciel directement dans la ligne de commande. Plus de fonctionnalités peuvent être débloquées avec metagpt --help.
  5. Prise en charge PIP : pip install metagpt est désormais disponible pour l'installation et l'utilisation de métagpt, permettant un accès direct à la version en ligne de commande de métagpt.
  6. Révision améliorée du code : le code généré subit désormais une révision de code plus complète, ce qui améliore considérablement la qualité du code.
  7. Gestion de fichiers avec Git : un espace de travail de documentation indépendant avec un historique Git complet est désormais utilisé pour enregistrer les modifications du code historique.
  8. Mécanisme de messagerie optimisé : mémoire de rôle privatisée, fournissant un mécanisme de messagerie inter-rôles qui prend en charge la diffusion, la messagerie de groupe et la messagerie privée.

Ce qui a changé

Modifications rétrocompatibles

  • Supprimez Role.recv et Role.handle. La logique correspondante est déplacée dans Role._observe -Role._publish_message ->Role.publish_message -Team.start_project ->Team.run_project. Étant donné que nous soutenons le développement incrémental, nous utilisons « exécuter » pour faire référence à l'exécution d'un projet en général, par opposition à « démarrer » un projet à partir de zéro. Nous expliquerons le développement incrémental et le nouveau mécanisme de messagerie sur le site de documentation, restez connectés !

MetaGPT v0.5.0

Release Highlights

Overall

  1. Multilingual Support (Experimental): Now supports both Chinese and English, and theoretically other languages.
  2. Multiple Programming Languages Support (Experimental): Support for various programming languages is now available, allowing for the natural generation of JavaScript projects. However, it's noted that GPT-4-turbo has significantly stronger capabilities in Python, and there is considerable room for improvement with other programming languages.
  3. Incremental Development (Experimental): It's now possible to incrementally raise requirements and bug fixes, allowing for further optimization of the generated repo.
  4. CLI Support: You can now use metagpt "make a 2048 game" to let metagpt write software directly in the command line. More features can be unlocked with metagpt --help.
  5. PIP Support: pip install metagpt is now available for installing and using metagpt, enabling direct access to the command-line version of metagpt.
  6. Enhanced Code Review: The generated code now undergoes a more comprehensive code review, which significantly improves code quality.
  7. File Management with Git: An independent documentation workspace with a complete git history is now used to record changes in historical code.
  8. Optimized Messaging Mechanism: Privatized Role memory, providing an inter-Role messaging mechanism that supports broadcasting, group messaging, and private messaging.

What's Changed

Backwards Incompatible Changes

  • Remove Role.recv and Role.handle. Corresponding logic is moved into Role._observe
  • Role._publish_message -> Role.publish_message
  • Team.start_project -> Team.run_project. Given we support incremental development, we use "run" to refer to project execution in general, as opposed to "starting" a project from scratch

We will explain incremental development and the new messaging mechanism on the documentation site, stay tuned!

Features

  • IMPORTANT: Multilingual support (experimental), multiple programming languages support (experimental), incremental development (experimental), CLI support, pip support, enhanced code review, documentation mechanism, optimized messaging mechanism by @iorisa @geekan #552 . Check out the highlights above for details.
