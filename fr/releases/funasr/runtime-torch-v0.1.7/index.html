FunASR runtime-torch-v0.1.7

Version de maintenance du runtime autonome de Torch.

  • Conservez les horodatages Paraformer d'enregistrement court indépendants du remplissage dans des lots de longueurs mixtes (# 3871).
  • Ignorer les entrées de mots clés vides et tronquer les termes contextuels/Seaco longs à la largeur d'intégration de dix caractères exportée (#3882).
  • Préserver les abréviations des terminaux et les limites des mots de transcription riche (#3869 et correctif d'espacement des segments existant).
  • Tester les installations réelles de roues et de distribution de sources sur Python 3.10 et 3.12.

Installer dans un environnement dédié : python -m pip install funasr-torch==0.1.7. Nom d'importation : funasr_torch. Les scripts de serveur racine funasr, autonome funasr-onnx et Python WebSocket sont des livrables distincts.

Validation : 118 tests de source locale ciblés ; cinq régressions installées pour chaque roue/sdist locale ; package hébergé et tests installés ; les dix modules d'exécution liés par hachage aux preuves réelles existantes du montage synthétique L20Z. Les résultats existants ont été réutilisés et non réexécutés. Il ne s'agit pas d'une nouvelle évaluation de la précision ou des performances ASR pré-entraînée, d'une suite complète de modèles ou d'une mise à niveau automatique du service de production. Voir le PR source pour la provenance du contrôle négatif et du montage de test.

Les deux charges utiles et SHA256SUMS sont les artefacts CI principaux finaux acceptés. La version racine de FunASR reste la dernière version du référentiel.

FunASR runtime-torch-v0.1.7

Highlights

  • Paraformer timestamp alignment in mixed-length batches — #3871 decouples short-recording timestamps from batch padding, so dynamic batching no longer smears pad frames into alignment for shorter utterances. If you batch variable-length audio in production, expect corrected word/token offsets — and re-check any downstream consumer that may have been tuned against the old offsets.

  • Hotword and contextual term hygiene — #3882 makes the runtime ignore empty hotword entries and clamp Contextual/Seaco terms to the exported ten-character embedding width instead of letting oversized terms break or misalign the bias path. Watch out: terms longer than ten characters are silently truncated, so long custom vocabulary needs shortening or splitting to keep its intended biasing effect.

  • Rich-transcription word boundaries — #3869, together with the existing segment-spacing fix, preserves terminal abbreviations and word boundaries, improving punctuation/casing and caption segmentation. Matters most if you emit subtitles or structured transcripts — compare output on abbreviation-heavy audio before rollout.

  • Packaging and Python support — Wheels and sdists are now installed and regression-tested on Python 3.10 and 3.12; install into a dedicated env with python -m pip install funasr-torch==0.1.7 and import as funasr_torch. This is only the standalone Torch runtime: root funasr, funasr-onnx, and the WebSocket server scripts ship separately, so don't treat it as a drop-in replacement for those. Verify the payloads against the published SHA256SUMS CI artifacts.

  • Scope of validation — 118 scoped source tests plus five installed regressions per wheel/sdist, with all ten runtime modules hash-bound to prior L20Z synthetic-fixture evidence that was reused, not rerun. Editorially: this is a maintenance release, not a fresh accuracy/performance evaluation or full model suite, and there's no automatic production-service upgrade — bring your own benchmarks before calling it a quality improvement.

  • Compatibility — No breaking changes in this release.

Standalone Torch runtime maintenance release.

  • Keep short-recording Paraformer timestamps independent of padding in mixed-length batches (#3871).
  • Ignore empty hotword entries and truncate long Contextual/Seaco terms to the exported ten-character embedding width (#3882).
  • Preserve terminal abbreviations and rich-transcription word boundaries (#3869 and existing segment-spacing fix).
  • Test actual wheel and source-distribution installations on Python 3.10 and 3.12.

Install in a dedicated environment: python -m pip install funasr-torch==0.1.7. Import name: funasr_torch. Root funasr, standalone funasr-onnx, and Python WebSocket server scripts are separate deliverables.

Validation: 118 scoped local source tests; five installed regressions for each local wheel/sdist; hosted package and installed tests; all ten runtime modules bound by hash to existing real L20Z synthetic-fixture evidence. Existing results were reused, not rerun. This is not a new pretrained ASR accuracy or performance evaluation, full model suite, or automatic production-service upgrade. See the source PR for negative-control and test-fixture provenance.

The two payloads and SHA256SUMS are the accepted final-main CI artifacts. The root FunASR release remains the repository's latest release.
