##1.21.2

07 janvier 2026

CHANGEMENTS :

  • auth/oci : passer le plugin à v0.20.1
  • noyau : version Bump Go vers 1.25.5
  • packaging : les images de conteneurs sont désormais exportées à l'aide d'une présentation d'image OCI compressée.
  • packaging : les images de conteneurs UBI sont désormais construites sur l'image minimale UBI 10.
  • secrets/azure : Mise à jour du plugin vers v0.25.1+ent. Améliore la gestion des nouvelles tentatives lors de la création d’applications Azure et du principal de service afin de réduire les échecs transitoires.
  • Stockage : mettez à niveau la bibliothèque aerospike client vers la v8. AMÉLIORATIONS :
  • noyau : vérifier la file d'attente du gestionnaire de rotation toutes les 5 secondes au lieu de 10 secondes pour améliorer la réactivité
  • go : mise à jour vers golang/x/crypto vers v0.45.0 pour résoudre GHSA-f6x5-jh6r-wrfv, GHSA-j5w8-q4qc-rx2x, GO-2025-4134 et GO-2025-4135.
  • rotation : assurez-vous que les rotations pour les chemins partagés s'exécutent uniquement sur le nœud actif du cluster principal. Assurez-vous que les rotations pour les chemins locaux s’exécutent sur le nœud actif local du cluster.
  • sdk/rotation : empêche les tentatives de rotation sur le stockage en lecture seule.
  • secrets-sync (entreprise) : Ajout de la prise en charge d'un indicateur booléen force_delete (par défaut : false). Lorsqu'il est défini sur true, cet indicateur permet la suppression d'une destination même si ses associations ne peuvent pas être désynchronisées. Cette option doit être utilisée uniquement comme mécanisme de suppression de dernier recours, car tous les secrets déjà synchronisés avec le fournisseur externe resteront orphelins et nécessiteront un nettoyage manuel.
  • secrets/pki : évitez de charger les informations sur l'émetteur plusieurs fois par signature de certificat feuille. CORRECTIONS DE BOGUES :
  • core/activitylog (enterprise) : résolvez un problème de stabilité dans lequel Vault Enterprise pouvait rencontrer une panique lors du report de l'activité de facturation de fin de mois.
  • http : ignorez l'analyse de la limite JSON sur l'écouteur de cluster.
  • Quotas : Vault protège désormais les plugins avec des opérations ResolveRole contre la panique lors de la création de quotas.
  • réplication (entreprise) : correction d'une panique rare due à une course lors de l'activation d'un secondaire avec le stockage Consul.
  • rotation : Correction d'un bug où un secondaire de performances paniquerait si une écriture était effectuée sur un montage local.
  • secret-sync (entreprise) : amélioration de la gestion des erreurs de désynchronisation en traitant les cas où la destination n'existe plus comme un succès.
  • secrets-sync (entreprise) : correction d'un bug où la suppression de la dernière version du secret KV-V2 entraînait la suppression complète du secret externe associé. La tâche de synchronisation implémente désormais un mécanisme de secours de version pour rechercher et synchroniser la version active disponible la plus élevée, garantissant ainsi la continuité et empêchant la suppression involontaire de la ressource secrète externe.
  • secrets-sync (entreprise) : correction d'un problème où les secrets n'étaient pas correctement désynchronisés après les modifications de la configuration de destination.
  • secrets-sync (entreprise) : correction d'un problème où la suppression du magasin de synchronisation pouvait être tentée lorsque la synchronisation était désactivée.
  • ui/pki : Correction de la gestion des valeurs contenant des virgules dans les champs de liste comme crl_distribution_points.

vault v1.21.2

1.21.2

January 07, 2026

CHANGES:

  • auth/oci: bump plugin to v0.20.1
  • core: Bump Go version to 1.25.5
  • packaging: Container images are now exported using a compressed OCI image layout.
  • packaging: UBI container images are now built on the UBI 10 minimal image.
  • secrets/azure: Update plugin to v0.25.1+ent. Improves retry handling during Azure application and service principal creation to reduce transient failures.
  • storage: Upgrade aerospike client library to v8.

IMPROVEMENTS:

  • core: check rotation manager queue every 5 seconds instead of 10 seconds to improve responsiveness
  • go: update to golang/x/crypto to v0.45.0 to resolve GHSA-f6x5-jh6r-wrfv, GHSA-j5w8-q4qc-rx2x, GO-2025-4134 and GO-2025-4135.
  • rotation: Ensure rotations for shared paths only execute on the Primary cluster's active node. Ensure rotations for local paths execute on the cluster-local active node.
  • sdk/rotation: Prevent rotation attempts on read-only storage.
  • secrets-sync (enterprise): Added support for a boolean force_delete flag (default: false). When set to true, this flag allows deletion of a destination even if its associations cannot be unsynced. This option should be used only as a last-resort deletion mechanism, as any secrets already synced to the external provider will remain orphaned and require manual cleanup.
  • secrets/pki: Avoid loading issuer information multiple times per leaf certificate signing.

BUG FIXES:

  • core/activitylog (enterprise): Resolve a stability issue where Vault Enterprise could encounter a panic during month-end billing activity rollover.
  • http: skip JSON limit parsing on cluster listener.
  • quotas: Vault now protects plugins with ResolveRole operations from panicking on quota creation.
  • replication (enterprise): fix rare panic due to race when enabling a secondary with Consul storage.
  • rotation: Fix a bug where a performance secondary would panic if a write was made to a local mount.
  • secret-sync (enterprise): Improved unsync error handling by treating cases where the destination no longer exists as successful.
  • secrets-sync (enterprise): Corrected a bug where the deletion of the latest KV-V2 secret version caused the associated external secret to be deleted entirely. The sync job now implements a version fallback mechanism to find and sync the highest available active version, ensuring continuity and preventing the unintended deletion of the external secret resource.
  • secrets-sync (enterprise): Fix issue where secrets were not properly un-synced after destination config changes.
  • secrets-sync (enterprise): Fix issue where sync store deletion could be attempted when sync is disabled.
  • ui/pki: Fix handling of values that contain commas in list fields like crl_distribution_points.
