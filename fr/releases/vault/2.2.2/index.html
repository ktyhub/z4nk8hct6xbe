coffre-fort v2.2.2

12 novembre 2026

SÉCURITÉ :

  • core/acl : renforce l'évaluation explicite des règles de refus en faisant correspondre les chemins demandés sans tenir compte de la casse. CHANGEMENTS :
  • auth/alicloud : mettre à jour le plugin vers v0.24.1
  • auth/cf : Mettre à jour le plugin vers v0.24.1
  • auth/jwt : mettre à jour le plugin vers v0.27.2
  • auth/kerberos : mettre à jour le plugin vers v0.18.1
  • auth/oci : mettre à jour le plugin vers v0.22.1
  • noyau : version Bump Go vers 1.27.4
  • core/acl : correction d'un problème où les règles de politique de refus explicites n'étaient pas appliquées aux variantes de cas du chemin refusé. Les règles de refus explicites correspondent désormais également au chemin demandé sans tenir compte de la casse, sous réserve de la spécificité habituelle des règles. Par exemple, un refus sur secret/data/example refuse désormais également les demandes adressées à secret/data/EXAMPLE.
  • base de données/couchbase : mise à jour du plugin vers v0.17.1
  • base de données/elasticsearch : mise à jour du plugin vers v0.21.1
  • base de données/mongodbatlas : mise à jour du plugin vers v0.18.1
  • base de données/redis : mise à jour du plugin vers v0.9.1
  • base de données/flocon de neige : mise à jour du plugin vers v0.17.1
  • proxy/agent : les plugins ou intégrations personnalisés qui renvoient du HTML interactif via un agent ou un proxy ne s'afficheront plus de manière interactive dans un navigateur.
  • secrets/alicloud : mettre à jour le plugin vers v0.23.1
  • secrets/azure : Mettre à jour le plugin vers v0.28.5+ent
  • secrets/keymgmt : mettre à jour le plugin vers v0.20.2+ent
  • secrets/mongodbatlas : mise à jour du plugin vers v0.18.1
  • secrets/terraform : mise à jour du plugin vers v0.15.1 AMÉLIORATIONS :
  • core : inclure l'ID de l'espace de noms dans les journaux d'échec de la configuration du montage
  • noyau : mettez à jour github.com/go-jose/go-jose/v4 vers v4.1.6 et golang.org/x/net vers v0.62.0
  • ui : affiche "Jamais" comme dernière rotation de Vault sur la page d'informations d'identification du rôle LDAP lorsqu'un rôle statique n'a pas subi de rotation, au lieu d'une date en année 0001. CORRECTIONS DE BOGUES :
  • Transit (entreprise) : correction d'un bug de cache qui entraînait l'écriture de valeurs auto_rotate_period non nulles dans le cache avec des clés gérées
  • agent/pki-external-ca (entreprise) : correction de la réémission prématurée du certificat lors de la réauthentification automatique afin que le renouvellement du certificat respecte percent_renew_before_expiry au lieu d'être déclenché par les mises à jour des jetons.
  • audit : correction d'un bug où Vault renvoyait HTTP 500 lorsqu'une réponse volumineuse (par exemple, une requête PKI ?help=1) ne pouvait pas être écrite sur un périphérique d'audit syslog en raison de la limite de taille de socket de datagramme du système d'exploitation Unix (EMSGSIZE / ENOBUFS). Le récepteur Syslog divise désormais les charges utiles d’audit surdimensionnées en morceaux de taille sûre et réessaye de remplir temporairement les tampons de socket.
  • audit : corrige une panique qui peut survenir lorsque le courtier d'audit n'est pas initialisé lors du démontage.
  • auth/approle : rejetez les SecretID expirés lors de la connexion au lieu de compter sur un nettoyage périodique.
  • auth/spiffe (entreprise) : correction d'un problème où les jetons renouvelables n'étaient pas renouvelés
  • core (entreprise) : correction d'une panique et d'une création partielle d'espace de noms lorsque le montage du registre de l'agent racine n'est pas disponible
  • noyau/recensement (entreprise) : correction de la jauge de recensement previous_month_complete indiquant 0 au cours du premier mois après la date de début de facturation, de sorte que le décompte final client du cycle de facturation précédent soit signalé.
  • core/plugin : correction d'un problème où le moteur de secrets externes et les plugins d'authentification restaient en lecture seule après un échec de chargement lors du démarrage ou des descellement. Les opérateurs peuvent désormais restaurer le binaire ou l'enregistrement manquant et recharger le plug-in pour reprendre les écritures sans redémarrer Vault.
  • core : correction d'un problème où la correspondance du chemin de stratégie pouvait être incohérente pour les demandes qui ne diffèrent que par une barre oblique finale.
  • Identité : utilisez le résolveur de conflits de rapport uniquement lors du rechargement en mode sensible à la casse, pour éviter de collecter des doublons après la descellement.
  • pki-external-ca : Correction de la suppression prématurée des enregistrements de certificat révoqués lors du rangement ; les commandes révoquées sont désormais conservées jusqu'à la date NotAfter du certificat plutôt que jusqu'à l'expiration de la commande ACME
  • secrets/azure : continuez le nettoyage permanent de l'application lorsque l'application active est déjà absente, ce qui permet des tentatives de nettoyage ultérieures pour réessayer la purge.
  • secrets/azure : réessayez les erreurs Microsoft Graph 403/404 transitoires lors de l'ajout de principaux de service nouvellement créés aux groupes Azure.
  • secrets/kv : correction d'un problème dans KV v1 où l'écriture d'un chemin secret contenant des barres obliques consécutives entraînait le renvoi de "/" par les opérations de liste en tant qu'entrée de répertoire, produisant une boucle infinie dans le fil d'Ariane de l'interface utilisateur de Vault.
  • tpm : tpm auth respecte désormais l'option InsecureSkipVerify
  • ui : corrigez la page de présentation de la base de données pour répertorier les rôles dynamiques et statiques et autoriser la génération d'informations d'identification, et restaurer l'onglet Rôles pour les utilisateurs disposant uniquement d'autorisations de rôle statique.
  • ui : corrige la pagination sur la table de la liste des entités
  • Proxy Vault : prend en charge la méthode tpm dans le bloc auto_auth pour faire correspondre la parité avec l'agent.

vault v2.2.2

November 12, 2026

SECURITY:

  • core/acl: Harden explicit deny rule evaluation by matching requested paths case-insensitively.

CHANGES:

  • auth/alicloud: Update plugin to v0.24.1
  • auth/cf: Update plugin to v0.24.1
  • auth/jwt: Update plugin to v0.27.2
  • auth/kerberos: Update plugin to v0.18.1
  • auth/oci: Update plugin to v0.22.1
  • core: Bump Go version to 1.27.4
  • core/acl: Fix an issue where explicit deny policy rules were not enforced against case variants of the denied path. Explicit deny rules now also match the requested path case-insensitively, subject to the usual rule specificity. For example, a deny on secret/data/example now also denies requests to secret/data/EXAMPLE.
  • database/couchbase: Update plugin to v0.17.1
  • database/elasticsearch: Update plugin to v0.21.1
  • database/mongodbatlas: Update plugin to v0.18.1
  • database/redis: Update plugin to v0.9.1
  • database/snowflake: Update plugin to v0.17.1
  • proxy/agent: Custom plugins or integrations that return interactive HTML through Agent or Proxy will no longer render interactively in a browser.
  • secrets/alicloud: Update plugin to v0.23.1
  • secrets/azure: Update plugin to v0.28.5+ent
  • secrets/keymgmt: Update plugin to v0.20.2+ent
  • secrets/mongodbatlas: Update plugin to v0.18.1
  • secrets/terraform: Update plugin to v0.15.1

IMPROVEMENTS:

  • core: Include the namespace ID in mount setup failure logs
  • core: Update github.com/go-jose/go-jose/v4 to v4.1.6 and golang.org/x/net to v0.62.0
  • ui: Show "Never" as the last Vault rotation on the LDAP role credentials page when a static role has not been rotated, instead of a date in year 0001.

BUG FIXES:

  • Transit (enterprise): Fix cache bug that led to non-zero auto_rotate_period values being written to the cache with managed keys
  • agent/pki-external-ca (enterprise): Fix premature certificate reissuance on auto-auth re-authentication so certificate renewal respects percent_renew_before_expiry instead of being triggered by token updates.
  • audit: Fixed a bug where Vault returned HTTP 500 when a large response (e.g. a PKI ?help=1 request) could not be written to a syslog audit device due to the OS Unix datagram socket size limit (EMSGSIZE / ENOBUFS). The syslog sink now splits oversized audit payloads into safe-sized chunks and retries transiently full socket buffers.
  • audit: Fixes a panic that can occur when audit broker not initialized during teardown.
  • auth/approle: Reject expired SecretIDs during login instead of relying on periodic tidy cleanup.
  • auth/spiffe (enterprise): Fix an issue where renewable tokens were not being renewed
  • core (enterprise): Fix a panic and partial namespace creation when the root agent-registry mount is unavailable
  • core/census (enterprise): Fix the previous_month_complete census gauge reporting 0 in the first month after the billing start date auto-rolls, so the previous billing cycle's final client count is reported.
  • core/plugin: Fix an issue where external secrets engine and auth plugins remained read-only after failing to load during startup or unseal. Operators can now restore the missing binary or registration and reload the plugin to resume writes without restarting Vault.
  • core: Fix an issue where policy path matching could be inconsistent for requests that differ only by a trailing slash.
  • identity: Use the reporting conflict resolver only while reloading in case-sensitive mode, to avoid collecting duplicates after unseal.
  • pki-external-ca: Fix premature deletion of revoked certificate records during tidy; revoked orders are now retained until the certificate's NotAfter date rather than the ACME order expiry
  • secrets/azure: Continue permanent application cleanup when the active application is already absent, allowing later cleanup attempts to retry the purge.
  • secrets/azure: Retry transient Microsoft Graph 403/404 errors when adding newly created service principals to Azure groups.
  • secrets/kv: Fixed an issue in KV v1 where writing a secret path containing consecutive slashes caused list operations to return "/" as a directory entry, producing an infinite loop in the Vault UI breadcrumb.
  • tpm: tpm auth now respects the InsecureSkipVerify option
  • ui: Fix the database overview page to list both dynamic and static roles and allow credential generation, and restore the Roles tab for users with only static-role permissions
  • ui: fixes pagination on entities list table
  • vault proxy: Support tpm method in the auto_auth block to match parity with agent.
