sim v0.9.37

Features

  • feat(access-control): govern access requests per permission item (#9483)
  • feat(docs): rebuild documentation with the shared Sim design system (#9459)
  • feat(extension): open typed sim/ links through the Sim link resolver (#9486)
  • feat(sim-links): organization Sim links (go links) with sim/<name> redirects (#9484)
  • feat(library): Best AI Agents for Automated Data Reports in 2026: 4 Tools Compared (#9472)
  • feat(library): Best AI Agent Platforms for Slack and Discord: 4 Cross-Channel Options Compared (#9473)
  • feat(library): Best AI Agents for Internal Knowledge Search Across Docs and Tools (#9471)
  • feat(extension): bring Sim chat and page context to Chrome (#9454)
  • feat(mcp): type mcp block replies from declared output schemas (#9466)
  • feat(workflows): let a synchronous run continue in the background after a wait timeout (#9464)
  • feat(library): Best AI Agent Builders for Automated Daily Email Digests (#9442)
  • feat(library): Best AI Agents for Meeting Notes and Follow-Ups: 6 Options Compared (#9443)
  • feat(search): unify organization search and reviewed assistant actions (#9428)
  • feat(files): page, search, look up and roll up workspace files over the session API (#9435)
  • feat(db): seal account tokens by default and backfill them during migrate (#9425)

Improvements

  • improvement(sim-links): cleanup and simplify pass on the resource layout (#9492)
  • improvement(sim-links): use the shared resource table layout (#9491)
  • improvement(sim-links): show each link's destination favicon (#9489)
  • improvement(auth): unify sign-in and access pages (#9461)
  • improvement(comparisons): lead the OpenAI AgentKit page with the Agent Builder shutdown migration (#9460)
  • improvement(sandbox): pause idle chat workbenches instead of keeping them running (#9452)
  • perf(knowledge): reconcile a completed listing in one pass over its windows (#9449)
  • perf(admin): read dashboard ledger usage one bounded scan per entity (#9448)
  • perf(db): serve workspace usage drill-downs index-only on usage_log (#9447)
  • perf(audit-logs): read a listing narrowed only by time through per-workspace keyset scans (#9450)
  • perf(outbox): resume each retention batch where the previous run's batch ended (#9446)
  • perf(file-search): probe each backfill page's revisions by primary key (#9445)
  • perf(audit-logs): index organization-level rows and read them as two keyset parts (#9437)
  • perf(files): page the Files browser and resolve files without listing the workspace (#9436)
  • perf(db): index a workspace's live files in upload order (#9434)
  • perf(db): cut hot-path database work and close copilot cleanup gaps (#9419)

Bug Fixes

  • fix(docs): simplify selection and verify media interactions (#9493)
  • fix(search): accept Fireflies data-array responses (#9490)
  • fix(integrations): align connection header actions (#9487)

  • fix(mcp): honor json schema openness in mcp output shapes (#9476)

  • fix(executor): bound condition loops and reject unnamed variable assignments (#9463)
  • fix(search): unify navigation and preserve action review history (#9467)

  • fix(search): inline action review and unify account menus (#9451)
  • fix(workflows): refuse new placements of sunset blocks in workflow edits (#9456)
  • fix(billing): correct the Pi sizing note on E2B's resource maximums (#9455)
  • fix(billing): price Pi sandboxes at their build resources (#9453)
  • fix(audit-logs): list an organization's audit log through its single scope predicate again (#9438)
  • fix(cleanup): keep shared chat files, sweep inline images by prefix, and make room refetches wait (#9433)
