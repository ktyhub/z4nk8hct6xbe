#JecgBoot v3.8.2

Journal de mise à niveau

Cette mise à niveau se concentre sur l'amélioration de la fonction en ligne, en ajoutant des capacités de création automatique de tables IA, de données de test IA et de génération automatique de rapports IA, améliorant considérablement l'efficacité du traitement des données ; dans le même temps, le générateur de code est entièrement amélioré pour prendre en charge les boutons personnalisés et la génération de code améliorée JS. De plus, des fonctions pratiques telles que la gestion des versions d'APP, la personnalisation de la page d'accueil des autorisations et un nouveau système de notification et d'annonce ont été ajoutées. Veuillez noter que cette mise à niveau implique des ajustements à la structure de la base de données. Assurez-vous de sauvegarder vos données, de les tester et de les vérifier à l'avance pour garantir une mise à niveau fluide.

JeecgBoot v3.8.2

Highlights

  • AI-assisted Online development — Online 3.8.2-GA adds AI-generated tables, mock test data, and reports. Review generated schemas, SQL, permissions, and tenant boundaries before promoting them to production.

  • Report controls and SQL Server reliability — Online reports now support permission enforcement and tenant isolation, while advanced queries support multi-select filtering. The pagination fix ensures SQL Server OFFSET … ROWS FETCH NEXT queries include ordering, preventing errors in unsorted reports.

  • More complete code generation — The generator now supports custom buttons and JavaScript enhancements, and generated menu SQL includes component names. Verify regenerated routes and component mappings; fixes for ERP master/detail refreshes and linked-record creation also reduce data-integrity surprises (#8163, #8575, #8532).

  • XXL-JOB migration required — The starter/executor version mismatch that left scheduled jobs unfinished is fixed (#8621), but XXL-JOB 2.4.0+ removes the previous sharding-parameter retrieval method. Audit custom jobs and update shard handling before upgrading.

  • Dependency and database changes — MyBatis-Plus moves to 3.5.12, JSqlParser to 4.9, JimuReport to 2.1.1, and JimuBI to 2.1.0. This release also changes database structures: back up first, apply the supplied migration/initialization scripts, and regression-test custom SQL across Oracle, SQL Server, and PostgreSQL.

  • Security and deployment fixes — The horizontal privilege-escalation vulnerability in password changes is addressed (#8567), and Swagger operation mismatches are fixed (#8665). Validate both before rollout; new single-instance and microservice Docker Compose scripts, plus a pgvector service, simplify fresh deployments.

升级日志

本次升级重点增强了Online在线功能，新增AI智能建表、AI测试数据和AI报表自动生成能力，大幅提升数据处理效率；同时全面强化代码生成器，支持自定义按钮和JS增强代码生成。此外，新增APP版本管理、权限首页自定义和全新通知公告系统等实用功能。请注意，本次升级涉及数据库结构调整，请务必提前做好数据备份和测试验证，确保平稳升级。
