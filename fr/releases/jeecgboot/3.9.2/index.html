JeecgBoot v3.9.2

Highlights

  • Low-code v2.0 ships as Claude Code Skills — A separate repo, jeecgboot/skills, is released alongside 3.9.2. Six JeecgBoot skills (jeecg-codegen, jeecg-onlform, jeecg-onlreport, jeecg-desform, jeecg-onlchart, jeecg-bpmn) plus three JimuReport skills (jimureport, jimubi-bigscreen, jimubi-dashboard) let you generate CRUD (Java + Vue3 + SQL), forms, reports, BPMN XML and 1920×1080 screens from natural language; jeecg-desform and jimureport even accept screenshots as input. Requires Python 3.12+ and Claude Code, with Claude / DeepSeek-v4 / MiniMax 2.7 backends. The shift that matters: Online forms and flow nodes become natively callable "business capabilities," so teams no longer hand-write Tools to expose low-code artifacts to AI.

  • Breaking: AI starter renamed and Langchain4j jumped to 1.12.2 — jeecg-boot-starter-chatgpt is now jeecg-boot-starter-ai, so any module declaring the old Maven coordinate must be updated before compiling. The Langchain4j 1.12.2 upgrade adds Agent Skills metadata auto-selection (models pick business capabilities automatically instead of blind prompt tuning) and adds deepseek-v4 compatibility (#9585). Watch model-specific API requirements when upgrading: qwen3.5-plus needs incremental_output enabled (#9446), qwen-vl-ocr needs extra config (#8 / #9359 family), and PR #9539 handles Tongyi Qianwen rejecting null message content.

  • Online becomes extensible and AI-readable — The Online frontend source is fully open-sourced, a new Online chart module adds configurable visualization panels, and a published Online form Schema spec gives AI a stable metadata contract to reason over. Data-model additions: LongText (#9366) plus link_table / link_table_field for Vue3 one-to-many related records and cross-table field references, dictionary-tree support in sub-tables (#7633), and external-link forms for anonymous fill/edit. Long-standing performance complaints are targeted directly (config lag QQYUN-14177, slow open, small-screen field positioning). For adopters this is the main reason to upgrade if you were blocked on二次开发 or on representing hierarchical/relational data in Online.

  • AiFlow graduates from chatbot to visual Agent orchestration — New variable read/write, memory read/write, loop-variable and structured-JSON-output nodes, prompt-table binding on LLM nodes, file-upload start nodes, and a search-engine node plus web search for the AI assistant. Post-publish read-only node inspection and fixed HTTP request timeout handling (#9533) make flows safer to run in production. Combined with tool/AI-app whitelisting and cross-tenant isolation, this is what turns AiFlow into a platform you can actually delegate multi-step work to, rather than a demo.

  • Security hardening makes 3.9.2 a mandatory upgrade for multi-tenant deployments — High-severity fixes cover AI poster SSRF (#9579, rejects loopback/link-local), attachment path traversal (#9519, path normalization + sandbox enforcement), AiragApp cross-tenant write (#9462), token privilege escalation via getUserSectionInfoByToken (#9518), RCE (#9335), and JDBC URL injection from an incomplete blacklist/missing datasource endpoint permission (#9468). MCP and sensitive underlying tools now require permission checks (#9483, #9464). If you expose AI endpoints to tenants, audit which ones were reachable before patching — several of these were direct cross-tenant data paths.

  • Frontend on-demand loading cuts first paint and enables in-page AI — antd (via unplugin-vue-components), unplugin-icons, Jvxetable/Vxetable, TinyMCE, JEasyCron, codemirror and the chat module are all lazy-loaded; login registration/QR/forgot-password components and AppSearch no longer hit the initial bundle. JCronValidator and custom basicForm components moved out of the global load. One caveat worth flagging to your team: after the Jvxetable conversion, internal self-references are disallowed or the page will hang — check custom tables before rollout (#9452 also addressed Online styles leaking into the host project).

升级日志

v3.9.2 是 JeecgBoot 自 AI 路线开启以来最重的一次版本大升级。 低代码再进化，正式迈入 v2.0 时代——从「拖拉拽」到「一句自然语言」，全线 Skills 加持，一句话即可搭建业务，手工配置成为历史！低代码不再只是「拖拖拽拽生成 CRUD」，一句话创建大屏、一句话搭建 OA 审批、一句话生成整个系统，已在 JeecgBoot 成为现实！本次升级还全面打磨低代码开发体验，涵盖表单、图表、大屏、安全与前端性能的系统性优化，同步开放 Online 前端源码，并新增 Online 图表大模块。

✨ 本次发布的"高度"

1. Skills：让 AI 真正成为你的开发搭档
  • Claude Code Skills 接入低代码：代码生成、Online 表单、报表、大屏、流程全面对接 Claude Skills，无需手动操作代码生成器——AI 一句话生成代码、一句话生成整个系统、一句话创建 Online 表单、一句话创建 Online 报表、一句话设计大屏、一句话配置字典、创建菜单并完成授权，全部触手可及。
2. AI 应用大优化
  • Chat2BI / Chart2BI 对接 Online 表单：一句话生成分页表格、报表与图表配置，数据分析链路全程打通。
  • AI 流程编排能力大爆发：新增变量读写、记忆检索、循环变量、结构化 JSON 输出、提示词表关联、文件上传起点节点等，AiFlow 已进化为一套完整的可视化 Agent 编排平台。
  • AI 应用工具白名单 + 跨租户隔离：能力开放与权限管控并举，SaaS 多租户安全边界筑牢。
  • 配套上线 AI 助手联网搜索 与 AI 流程搜索引擎节点，让 AI 流程既能「会用工具」，也能「会查资料」。
  • Langchain4j 1.12.2升级：Java AI 应用能力边界重新定义——AI 助手不再依赖人工提示词盲调接口，也支持 Skills 元数据自动选择并调用业务能力。
3. AI多模态生产力（图 / 音 / 视频 / 换衣）
  • 真实的 AI 生成 音频 / 视频 / 图片，不再是 Demo
  • AI 换衣 同时输出图片与视频
  • 谷歌生图模型、本地语音合成、混图示例 全部到位
  • 模型矩阵补齐：VLLM / Xinference / LMStudio / qwen-vl-ocr / qwen3.5-plus / 通义千问 / 千帆
4. Online 三件套（表单 / 报表 / 图表）一次性优化
  • Online 模块前端源码完全开源，AI 时代用户可自由灵活扩展，二次开发无门槛
  • 新增 Online 图表大模块，快速配置图表面板，为用户提供更多可视化选择
  • 新增 LongText 字段类型 与 link_table / link_table_field 类型（Vue3 一对多关联记录、跨表字段引用）
  • 子表支持分类字典树与自定义字典树，层级数据配置更灵活
  • 解决多年顽疾：Online 配置卡顿（QQYUN-14177）、Online 打开慢、小屏字段定位不可见 等体验痛点全面修复
  • 新增 Online 表单 Schema 规范文档，为 AI 深度理解 Online 元数据夯实基础
5. 全面按需加载，前端瘦身
  • antd / unplugin-icons / Jvxetable / Vxetable / TinyMCE / JEasyCron / codemirror / 聊天模块 全部按需加载
  • 首屏体积与加载速度显著下降，为 AI 助手在线入驻业务页面铺平道路
6. 安全加固
  • AI 海报 SSRF（#9579）、AI 附件路径遍历（#9519）、AiragApp 跨租户写入（#9462）、Token 越权（#9518）、RCE #9335 等多个高危漏洞集中修复
  • 给 MCP / 底层敏感工具 全面加上权限校验

🎯 低代码 v2.0 时代，意味着什么？

Skills 让低代码平台沉淀的表单、流程、报表、大屏，自动成为 AI 可直接调用的业务能力——无需手写 Tool、无需二次开发，自然语言即可驱动全套业务流程自动化执行，甚至一句话生成整个系统。

| 维度 | v3.9.1 及以前（拖拉拽时代） | v3.9.2（一句话时代） | |---|---|---| | 低代码定位 | 表单 / 流程 /代码生成 / 报表和大屏设计 | AI Native 的业务能力出口 | | 交互方式 | 拖拉拽 + 手工配置 | 一句自然语言，搞定一切 | | 业务搭建 | 手动拖组件、配字段、设流程 | 一句话设计表单，画流程 / 报表 / 大屏 / 菜单 | | AI 用法 | 完全手工搭建：手动配表单、画流程、建关联、配菜单、逐步授权 | AI 一句话搭表单、画流程、绑关联、建菜单、完成授权，一条龙搞定 | | 业务接入 AI | 需二次开发手写 Tool | Online 表单 / 流程节点 = 天然 Skill | | 多模态 | 仅文本 | 文本 / 图像 / 音频 / 视频 /Skills 全模态覆盖 | | 安全 | 漏洞分散修复 | 专项漏洞修复 + 权限管控 + 租户隔离加固 |
