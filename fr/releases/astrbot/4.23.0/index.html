#AstrBot v4.23.0

  • Journal de mise à jour (chinois simplifié)
  • Changelog(anglais) <a id="chinois"></a>

Ce qui a changé

Nouveau

  • Prend en charge la lecture de fichiers (lecture), l'écriture (écriture), l'édition (édition), la recherche Grep (ripgrep) et l'espace de travail isolé par session pour les capacités d'utilisation de l'ordinateur. (#7402)
  • L'adaptateur de compte personnel WeChat prend en charge l'analyse des messages de référence. (#7380)
  • Ajout de l'outil de recherche Web Brave Search et suppression de l'ancienne implémentation de recherche Web par défaut. (#6847)
  • Ajout de la prise en charge de l'adaptateur de plate-forme Mattermost. (#7369)
  • Ajout du fournisseur de reclassement NVIDIA. (#7227)
  • Ajout du fournisseur LongCat LLM. (#7360)
  • Ajout de la prise en charge des modes d'entrée audio OpenAI et Gemini et résolution des problèmes liés à l'enregistrement ChatUI. (#7378)
  • La plateforme Discord ajoute une nouvelle configuration de filtrage des messages des Bots, vous permettant de contrôler si vous souhaitez recevoir des messages d'autres Bots. (#6505)
  • Ajout de la capacité de LLM à guider les appels d'outils répétés afin de réduire la situation dans laquelle le modèle tombe dans des appels d'outils répétés. (#7388)
  • Le API officiel de QQ ajoute un mécanisme de nouvelle tentative pour le téléchargement de fichiers afin d'améliorer la stabilité de l'envoi de fichiers. (#7430)

Optimisation

  • Reconstruire le style ChatUI, le rendu des messages et l'expérience de saisie pour améliorer la maintenabilité globale et la cohérence des interactions de l'interface de chat. (#7485)
  • Fusionnez les outils liés à Cron dans un outil de gestion unifié et ajoutez des fonctionnalités d'édition de tâches Cron. (#7445)
  • Reconstruire la logique de gestion des outils intégrés pour améliorer la maintenance de l'enregistrement et de l'appel des outils intégrés d'AstrBot. (#7418)
  • Suppression de la plupart des commandes intégrées basse fréquence et intégration des fonctions de commande, déplacement de ces commandes vers le plug-in builtin-command-extension et mise à jour de la documentation. (#7478)
  • Suppression de l'implémentation de recherche Web par défaut et remplacement par un nouveau lien vers un outil de recherche. (#7416)
  • Suppression des dépendances lxml et beautifulsoup4 pour réduire la taille de l'installation et la complexité des dépendances. (#7449)
  • Ajout de la vérification de la configuration MCP stdio pour réduire les échecs de démarrage et les coûts de dépannage causés par des configurations non valides. (#7477)
  • Docker Activez no-new-privileges dans la configuration en cours pour améliorer la sécurité par défaut du conteneur. (validation)
  • Réduisez la fréquence d'interrogation de l'état du serveur MCP et réduisez la surcharge des requêtes en arrière-plan. (#7399)
  • Les commandes d'aide ignorent les commandes internes valides telles que dashboard_update pour réduire le bruit de la liste d'aide. (validation)
  • Correction de l'exemple d'épissage de chemin dans le document pour empêcher les documents de stockage de développement de plug-ins d'induire les utilisateurs en erreur. (#7448)
  • Constantes de plate-forme Matrix complétées, icônes de plate-forme et documentation associée. (#7368)

Correction

  • Correction d'un problème où le fournisseur STT ou TTS peut toujours être utilisé lorsqu'il est désactivé dans la configuration. (#7363)
  • Correction du problème de sortie du modèle vide Gemini déclenchant accidentellement le traitement des erreurs. (#7377)
  • Correction d'un problème où le champ id non pris en charge dans Gemini FunctionResponse provoquait l'échec de la requête. (#7386)
  • Correction d'un problème où FunctionCallingConfig est toujours transmis lorsque seuls les outils natifs sont présents. (#7407)
  • Correction d'un problème où les assertions de résultats d'outils étaient incohérentes avec les seuils dynamiques. (validation)
  • Correction du problème de compatibilité du format de retour de Bailian Rerank pour différents points de terminaison d'URL. (#7250)
  • Correction du problème de nettoyage incomplet du processus de fermeture officiel du WebSocket de QQ. (#7395)
  • Correction du problème de récupération d'interrogation après une anomalie du réseau Telegram et ajout de tests associés. (#7468)
  • Correction du problème où le segment final d'un long message Telegram était trop long. (#7432)
  • Correction du problème où Telegram sendMessageDraft envoyait un texte vide provoquant une erreur 400 pour vider l'écran. (#7398)
  • Correction du problème où le gestionnaire de plug-in n'est pas dans star_map, provoquant KeyError lorsque Telegram collecte des commandes. (#7405)
  • Correction du problème où la commande Discord Slash ne différait pas dans le temps, provoquant 10062 Unknown interaction. (#7474)
  • Correction du message d'avertissement lorsque l'adaptateur de compte personnel WeChat manque de jeton de contexte. (validation)
  • Correction du problème de group_icl_enable n'utilisant pas la configuration de liaison UMO lors du traitement des messages. (#7397)
  • Correction du problème où le chemin du module de l'outil de fonction du plug-in est incohérent avec le chemin du module principal du plug-in. (#7462)
  • Correction de la prise en charge de la logique de vérification de version du plug-in pour les versions préliminaires. (validation)
  • Correction du problème où les caractères non-ASCII sont échappés dans la réponse de l'exécution de la commande Shell JSON. (#7475)
  • Correction d'un problème où le chargement des dépendances du plug-in du bureau Windows était dangereux ou échouait. (#7446)
  • Correction du problème où faiss était importé prématurément pendant la phase de démarrage, entraînant l'échec du démarrage de certains environnements. (#7400)
  • Correction du rendu en mode sombre de WebUI et de plusieurs problèmes d'interaction. (#7173)
  • Correction des constantes manquantes du projet ChatUI et ajout de cas de test associés. (#7414)
  • Correction du problème de saut des boutons flottants lors du changement de page. (#7214)
  • Correction du problème d'absence de la dépendance de la page de gestion des boîtes de dialogue MessageList.vue, entraînant l'échec de la construction du tableau de bord de l'environnement Linux. (validation)
  • Correction du problème d'affichage provoqué par l'icône d'appel d'outil utilisant l'icône manquante du sous-ensemble MDI. (validation)
  • Correction du problème d'utilisation du type de defineStore dans la boutique Dashboard. (#7490)
  • Correction d'une erreur de nom d'image Docker dans le fichier de composition. (#7488) <a id="anglais"></a>

AstrBot v4.23.0

Highlights

  • Session-isolated local file tools — Computer Use gains file read, write, edit, ripgrep-backed search, and per-session workspaces (#7402), allowing agents to inspect and modify project files without sharing session state. Scope granted workspaces carefully to data the agent is permitted to change.

  • Web search migration — Brave Search replaces the old default web-search implementation (#6847, #7416). Update tool bindings, prompts, and workflows that call the removed implementation directly; existing search configurations should not be assumed to carry over unchanged.

  • Built-in command relocation — Many low-frequency built-in commands move to the builtin_commands_extension plugin (#7478). Install that extension if you depend on the affected commands, and update scripts or documentation that still treat them as core features.

  • Multimodal and platform expansion — OpenAI and Gemini gain audio input (#7378), while LongCat and NVIDIA Rerank add model and ranking options (#7360, #7227). Mattermost support arrives (#7369), Weixin OC gains reply-message parsing (#7380), and Discord can optionally accept messages from other bots (#6505)—useful for bot-to-bot workflows, but potentially loop-prone without filtering.

  • Tool-calling reliability and configuration changes — LLM guidance reduces repeated tool-call loops (#7388), and Cron tools are consolidated into an editable management tool (#7445). Disabled STT/TTS providers now return None instead of still being resolved (#7363), so integrations should handle missing providers explicitly; native-only tool configurations also stop receiving FunctionCallingConfig (#7407).

  • Deployment and plugin compatibility — Removing lxml and beautifulsoup4 (#7449) means plugins importing them directly must declare their own dependencies. MCP stdio configurations are validated earlier (#7477), while fixes address faiss startup imports and Windows plugin dependency loading (#7400, #7446). Docker now enables no-new-privileges (68a195e12), which may affect custom images relying on setuid-based privilege escalation.
