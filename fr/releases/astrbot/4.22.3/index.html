#AstrBot v4.22.3

  • Journal de mise à jour (chinois simplifié)
  • Changelog(anglais) <a id="chinois"></a>

Ce qui a changé

Nouveau

  • Ajout du fournisseur vllm_rerank pour prendre en charge rerank_api_suffix configurable, qui peut s'adapter de manière flexible aux différents chemins API. (#7278)
  • Adaptez la prise en charge de l'extraction de l'utilisation des jetons de llama.cpp pour améliorer les statistiques des jetons et les capacités d'analyse de la facturation. (#7358)
  • WebUI regroupe les fichiers de travail de Monaco Editor pour éviter les échecs de téléchargement depuis CDN. (#7249)
  • Tout nouveau panneau de statistiques de présentation des modèles/plateformes. (#7152)

Optimisation

  • Optimisez le traitement des messages OpenAI, si la liste content est vide, définissez-la sur None et réduisez le taux d'exceptions sous contenu vide. (#6551)
  • Optimisez la mise en page et le style des pages du fournisseur pour améliorer la cohérence globale de la mise en page des paramètres. (#7248)
  • Lorsque l'utilisateur est connecté, la page d'accueil sautera directement, réduisant ainsi les étapes pour accéder à nouveau à la page de connexion. (validation)

Correction

  • Correction du problème où le programme d'exécution MCP sous Windows n'héritait pas de l'intégralité des variables d'environnement système, provoquant une exception de démarrage. (#7054)
  • Correction d'un problème où des extraits de réflexion Gemini étaient divulgués vers des liens de message visibles par l'utilisateur. (#7196)
  • Correction de l'erreur 400 Invalid argument provoquée par l'exigence de format function_response sous Gemini (OpenAI compatible avec API). (#7216
  • Correction des invites d'erreur et des problèmes de récupération lorsque l'initialisation de la base de connaissances échoue. (#7243)
  • Correction de la compatibilité de Bailian Rerank avec les anciens et les nouveaux formats de réponse pour éviter les échecs d'analyse. (#7217)
  • L'image Docker complète la dépendance de l'encodeur AMR et résout le problème du transcodage audio manquant dans certains scénarios de déploiement. (#7247)
  • Correction du problème d'indisponibilité du proxy SOCKS5 causé par l'absence de dépendance pysocks dans l'installation de pip. (#7221)
  • Réparez la logique de traitement de cached_tokens dans _extract_usage pour éviter toute confusion dans les statistiques des jetons. (#6719)
  • Améliorez la protection contre les déconnexions SSE, envoyez activement des battements de cœur sous transmission compressée et réduisez les déconnexions accidentelles de WebChat. (#7003)
  • Correction de l'erreur 400 provoquée par un message d'assistant vide sous le strict API. (#7202)
  • Ajout de la réparation des dépendances qrcode pour la fonction de code QR manquante et restauration de la fonction de génération de code QR. (validation)
  • Correction du problème d'expérience interactive du composant d'entrée numérique du configurateur pour éviter les écarts de traitement dans des scénarios d'entrée anormaux. (#7153)
  • Correction de Record.path étant traité incorrectement comme un champ obligatoire sous Pydantic v2. (#7048) <a id="anglais"></a>

AstrBot v4.22.3

Highlights

  • Token accounting for self-hosted stacks — llama.cpp now emits token usage (#7358) and _extract_usage stops mangling cached_tokens (#6719), so billing/cost analytics finally reflect real prompt-cache behavior. If you meter local inference, expect usage numbers to shift — recalibrate dashboards or budget alerts built on the old, noisier counts.

  • Gemini behavior changes — thinking parts are stripped from user-facing message chains (#7196): a privacy/UX win, but anything downstream that consumed reasoning fragments will no longer see them. In the same vein, function_response payloads are reshaped to satisfy Gemini's schema, removing 400 Invalid argument on tool-result turns (#7216).

  • Strict-API payload hygiene — empty OpenAI content lists are normalized to None (#6551) and empty assistant messages are filtered before dispatch (#7202), eliminating the zero-content 400s strict endpoints throw. Custom providers that assumed an empty list would be passed should verify they now handle None.

  • Rerack deployment flexibility — vllm_rerank gains a configurable rerank_api_suffix (#7278), so non-default API paths no longer require a fork, and Bailian rerank parses both legacy and current response formats (#7217) — a safe upgrade for anyone still pinned to the older shape.

  • Dependency and deployment repairs — Docker images bundle an AMR encoder (#7247), pip installs pull pysocks so SOCKS5 proxies actually work (#7221), and the missing qrcode dep restores QR generation (commit 5886c437). Windows MCP runners inherit full system env vars (#7054), fixing launches that failed when tooling lived in PATH.

  • WebUI and plugin-author fixes — Monaco workers are bundled locally (#7249), so code editing survives CDN outages; a new model/platform stats dashboard (#7152) and provider-page restyle (#7248) ship alongside SSE heartbeats under compression to cut WebChat false disconnects (#7003). For plugin developers: Record.path is no longer wrongly required under Pydantic v2 (#7048), and Discord/Misskey hot reload was fixed by correcting client_self_id misuse (#7331).

No breaking changes are noted in this release.

What's Changed

新增

  • 新增 vllm_rerank 提供商支持可配置的 rerank_api_suffix，可灵活适配不同 API 路径。（#7278）
  • 适配 llama.cpp 的 token 用量提取支持，增强 token 统计与计费分析能力。（#7358）
  • WebUI 捆绑 Monaco Editor 的 worker 文件，防止从 CDN 下载失败。（#7249）
  • 全新的模型/平台总览统计面板。（#7152）

优化

  • 优化 OpenAI 消息处理，若 content 列表为空时将其置为 None，并降低空内容下的异常率。（#6551）
  • 优化 provider page 布局与样式，提升整体设置页面排版一致性。（#7248）
  • 用户已登录时将直接跳转欢迎页，减少再次进入登录页的步骤。（commit）

修复

  • 修复 Windows 下 MCP runner 未继承完整系统环境变量导致启动异常的问题。（#7054）
  • 修复 Gemini 思考片段泄露到用户可见消息链路的问题。（#7196）
  • 修复 Gemini(OpenAI 兼容 API) 下，function_response 格式要求导致的 400 Invalid argument 错误。（#7216
  • 修复知识库初始化失败时的错误提示与恢复问题。（#7243）
  • 修复 Bailian Rerank 对新旧响应格式兼容性，避免解析失败。（#7217）
  • Docker 镜像补充 AMR 编码器依赖，修复部分部署场景下的音频转码缺失问题。（#7247）
  • 修复 pip 安装缺少 pysocks 依赖导致的 SOCKS5 代理不可用问题。（#7221）
  • 修复 cached_tokens 在 _extract_usage 中的处理逻辑，避免 token 统计错乱。（#6719）
  • 增强 SSE 断开保护，压缩传输下主动发送心跳，减少 WebChat 误断连。（#7003）
  • 修复严格 API 下空 assistant 消息导致的 400 错误。（#7202）
  • 新增二维码功能缺失的 qrcode 依赖修复，恢复二维码生成功能。（commit）
  • 修复配置器数字输入组件的交互体验问题，避免异常输入场景下的处理偏差。（#7153）
  • 修复 Record.path 在 Pydantic v2 下被错误视为必填字段的问题。（#7048）
