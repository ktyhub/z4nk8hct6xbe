AstrBot v4.25.2

Highlights

  • Streaming reliability & token accounting — Three streaming changes land together: smooth Markdown streaming (#8371) alters how replies render, #8244 stops delta=None chunks from crashing SDK to_dict() calls, and #8306 restores the trailing usage metadata that OpenAI streams were dropping. If you derive cost or token metrics from streamed responses, previously undercounted usage will now be reported accurately — expect a visible jump in totals after upgrading.
  • RAG ingestion gets structure-aware — A Markdown-aware chunker (#8151) now respects headings and document structure instead of splitting blindly, and RST/AsciiDoc knowledge uploads are fixed (#8255). Developers with existing structured corpora should re-index: chunk boundaries — and therefore retrieval quality — will change, so benchmark your RAG answers post-upgrade.
  • Vision routing behavior changes — Image requests are now routed to the vision fallback (#8089), and quoted images are no longer double-processed by the multimodal primary provider when no dedicated caption provider is configured (#8401). This affects how image inputs are interpreted and billed; verify any pipeline that relied on the primary model handling images directly.
  • Plugin runtime isolation — A single failing plugin no longer leaves stale state that breaks reloads of all other plugins (#8441), joined by a type guard for plugin metadata repo values (#8207) and a fix for marketplace/local plugin name mismatches (#8276). Workarounds for reload-after-crash can go; plugin authors should confirm declared names match marketplace entries so identity lookups keep working.
  • Provider and platform compatibility — Anthropic tool_choice schema conversion is corrected (#8328), Xiaomi and Xiaomi Token Plan providers are added (#7744), Mimo voice-design and reasoning payload bugs are fixed (#8326, #8327), and a macOS SQLAlchemy incompatibility is resolved (#7724). Workarounds for broken tool forcing on Anthropic or a broken macOS install can now be removed.
  • New ops and ChatUI tooling — Adds a dashboard password-change command (#8272), ChatUI command suggestions with custom wake words and hover hints (#8279, #8353), model capability icons (#8405), and a fix for broken ChatUI voice recording/upload (#8440). Mostly additive, but the suggestion wake words are configurable — check they don't collide with your own command prefixes.

No breaking changes are noted in this release.
