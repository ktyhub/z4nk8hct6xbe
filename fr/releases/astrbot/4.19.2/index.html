#AstrBot v4.19.2

Ce qui a changé

Nouveau

  • Adaptateur de plateforme KOOK intégré (#5658).
  • Ajout de la prise en charge des Emoji de pré-réaction Discord (#5609).
  • Ajout de la prise en charge de Telegram pour la sortie de streaming en temps réel sendMessageDraft API (#5726)
  • Prend en charge la capacité de suivi des messages lorsque l'agent est en cours d'exécution et les messages de suivi sont injectés dans l'agent en temps réel (#5484).
  • Intégrez DeerFlow Agent Runner et optimisez le streaming (#5581).
  • Ajout d'un nouveau shell, l'outil ipython qui contient des informations sur le système d'exploitation pour améliorer le taux de réussite des appels d'outils sous Windows (#5677).
  • Prise en charge du bac à sable pour Shipyard-neo - Prise en charge de l'auto-itération des compétences (#5028).
  • Ajout de la sélection du mode de transmission ChatUI WebSocket, OpenAPI Chat API prend en charge la connexion WebSocket (#5410).
  • Prise en charge du message de réponse d'erreur personnalisé et de la logique évasive de Persona (#5547).
  • Empaquetez les fichiers statiques WebUI dans Wheel et remplacez les journaux astrbot CLI par l'anglais (#5665).
  • Interface de chat améliorée et expérience mobile réactive (#5635).
  • Optimisation de la logique de gestion des échecs du plug-in et de l'expérience d'interaction avec les listes étendues (#5535).

Correction

  • Correction de la non-concordance des mots-clés des paramètres de délai d'attente d'initialisation MCP (#5743).
  • Correction de la condition de concurrence critique de l'outil MCP provoquant l'erreur « l'achèvement ne peut pas être analysé » (#5534).
  • Correction du problème de transmission transparente directe des URL non HTTPS dans l'adaptateur LINE (#5697).
  • Correction du problème de statut personnalisé instable de la barre latérale WebUI (#5670).
  • Correction du problème où l'adaptateur KOOK génère des journaux de débogage redondants lors de la réception de messages et de réponses de battement de cœur.
  • Correction d'un problème où la variable d'environnement DEMO_MODE n'était pas analysée correctement en tant que valeur booléenne (#5676).
  • Correction du problème selon lequel le sous-agent ne pouvait pas recevoir correctement le chemin de l'image locale (image de référence) (#5579).
  • Correction de la commande /model provoquant un comportement trompeur lors du passage à un autre modèle de fournisseur (#5578).
  • Correction d'un problème dans les enregistrements de conversation où le décalage du fuseau horaire UTC n'était pas géré, provoquant des exceptions d'horodatage (#5580).
  • Correction d'un problème où les statistiques de plate-forme en double provoquaient des exceptions lors de l'importation de sauvegardes (#5594).
  • Correction de la configuration max_agent_step n'étant pas appliquée aux agents enfants (#5608).
  • Correction du tri de la liste des plugins et de la logique de filtrage de recherche (#5559).
  • Correction du problème où l'environnement Node.js n'était pas requis lors de l'utilisation de uv sync.

  • Correction d'un échec d'importation de sauvegarde en raison d'entrées de statistiques de plate-forme en double (#5594).

AstrBot v4.19.2

What's Changed

新增

  • 集成 KOOK 平台适配器 (#5658)。
  • 新增 Discord pre-react Emoji 支持 (#5609)。
  • 新增 Telegram 支持 sendMessageDraft 流式实时输出 API (#5726)
  • 支持在 Agent 运行时进行消息跟进能力，跟进的消息实时注入给 Agent (#5484)。
  • 集成 DeerFlow Agent Runner 并优化流式处理 (#5581)。
  • 新增 shell, ipython tool 中包含操作系统信息，提高 windows 下 tool call 成功率 (#5677)。
  • Sandbox 支持 Shipyard-neo - 支持 Skills 自迭代 (#5028)。
  • 新增 ChatUI WebSocket 传输模式选择，OpenAPI Chat API 支持 WebSocket 连接 (#5410)。
  • 支持 Persona 自定义报错回复消息与兜底逻辑 (#5547)。
  • 将 WebUI 静态文件打包至 wheel，并将 astrbot CLI 日志替换为英文 (#5665)。
  • 增强聊天界面与移动端响应式体验 (#5635)。
  • 优化插件失败处理逻辑与扩展列表交互体验 (#5535)。

修复

  • 修复 MCP 初始化超时参数关键字不匹配的问题 (#5743)。
  • 修复 MCP 工具竞态条件导致"completion 无法解析"错误 (#5534)。
  • 修复 LINE 适配器中非 HTTPS URL 直接透传的问题 (#5697)。
  • 修复 WebUI 侧边栏自定义状态不稳定的问题 (#5670)。
  • 修复 KOOK 适配器收到消息和心跳响应时输出多余调试日志的问题。
  • 修复 DEMO_MODE 环境变量未正确解析为布尔值的问题 (#5676)。
  • 修复子 Agent 无法正确接收本地图片（参考图）路径的问题 (#5579)。
  • 修复 /model 命令切换至不同 Provider 模型时产生误导性行为的问题 (#5578)。
  • 修复对话记录中 UTC 时区偏移未处理导致时间戳异常的问题 (#5580)。
  • 修复备份导入时重复平台统计数据导致异常的问题 (#5594)。
  • 修复 max_agent_step 配置未应用到子 Agent 的问题 (#5608)。
  • 修复插件列表排序和搜索过滤逻辑 (#5559)。
  • 修复 uv sync 时未要求 Node.js 环境的问题。

What's Changed (EN)

New Features

  • Integrated KOOK platform adapter (#5658).
  • Integrated DeerFlow Agent Runner with optimized streaming support (#5581).
  • feat(telegram): supports sendMessageDraft API (#5726)
  • Integrated Neo skill self-iteration capability with full lifecycle management (candidate, release, deletion) via Shipyard Neo sandbox (#5028).
  • Added Discord pre-ack emoji support (#5609).
  • Added WebSocket transport mode selection for the chat interface (#5410).
  • Added OS information to tool descriptions with unit test coverage (#5677).
  • Added follow-up message handling in ToolLoopAgentRunner (#5484).
  • Added support for persona custom error reply messages with fallback logic (#5547).
  • Bundled WebUI static files into the wheel package and replaced astrbot CLI logs with English (#5665).
  • Optimized async IO performance and added benchmark coverage (#5737).
  • Refactored API key creation and added unit tests for open API routes.
  • Improved error messaging for AI execution failures in agent runners.
  • Enhanced chat interface and mobile responsiveness (#5635).
  • Improved plugin failure handling and extension list UX (#5535).

Bug Fixes

  • Fixed MCP initialization timeout keyword mismatch (#5743).
  • Fixed MCP tools race condition causing completion 无法解析 error (#5534).
  • Fixed LINE adapter allowing non-HTTPS URLs to pass through directly (#5697).
  • Fixed unstable sidebar customization state in WebUI (#5670).
  • Fixed excessive debug logging in KOOK adapter for received messages and heartbeat responses.
  • Fixed DEMO_MODE environment variable not being parsed correctly as a boolean (#5676).
  • Fixed sub-agent failing to correctly receive local image (reference image) paths (#5579).
  • Fixed misleading behavior of the /model command when switching to a model from a different provider (#5578).
  • Fixed unhandled UTC timezone offset causing incorrect timestamps in conversation records (#5580).
  • Fixed backup import failure due to duplicate platform stats entries (#5594).
  • Fixed max_agent_step config not being applied to sub-agents (#5608).
  • Fixed plugin list sorting and search filtering logic (#5559).
  • Fixed missing Node.js environment requirement during uv sync.
