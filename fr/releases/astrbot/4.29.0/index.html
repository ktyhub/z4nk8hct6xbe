#AstrBot v4.29.0

[4.29.0] - 2026-10-14

Cette version inclut toutes les modifications apportées à v4.29.0-beta.1 et v4.29.0-beta.2, ainsi que les modifications depuis v4.29.0-beta.2. La gamme complète de versions commence à v4.28.0.

Ajouts majeurs

  • Utilisation de l'ordinateur : ajout de la prise en charge du bac à sable spécifique au système d'exploitation pour l'environnement d'exécution local, disponible sur macOS avec Seatbelt et Linux avec bubblewrap uniquement. Veuillez vous référer à : https://docs.astrbot.app/use/astrbot-agent-sandbox.html (#9472)
  • ChatUI : ajout de l'historique des discussions et de la pagination des sessions dans la barre latérale, des brouillons d'entrée persistants, de la sélection de modèles par session et de la mise au point automatique des entrées lors du changement de projet. (#9667, #10279, #10247, #10301)
  • ChatUI : ajout de filtres de source de fournisseur et de groupes persistants à la sélection de modèles, ainsi que d'une recherche sur les pages Compétences et MCP. (#10084, #10217)
  • Les paramètres de conversion texte-image ont ** été déplacés de Paramètres vers Profils de configuration → Extensions ** et sont désormais configurés séparément pour chaque profil.
  • Les paramètres de l'administrateur et de la liste blanche ont été déplacés de Profils de configuration → Plateforme à Profils de configuration → Contrôle d'accès. (#10321)
  • WebUI : ajout d'un sélecteur de répertoire d'espace de travail et mise à jour de la progression du téléchargement dans l'application de bureau. (#10222, #10227, #10050)
  • Bureau : ajout d'effets de verre dépoli macOS à la barre latérale et à la barre supérieure de WebUI. (#10222, #10227, #10050)
  • Core : ajout de rappels de budget d'étape d'agent, limites héritées migrées, augmentation de la limite d'étape d'agent par défaut et attentes de session Shell prolongées. (#10131, #10133)
  • Core : Ajout de l'en-tête d'ID de conversation x-astrbot-conversation-id aux demandes du fournisseur. (#10218, #10237)
  • WebUI : ajout de raccourcis de paramètres de modèle à côté des modèles sélectionnés et dans les menus modèle/de secours. Les modifications sont enregistrées immédiatement pour chaque profil de configuration utilisant ce modèle. (#10321)
  • WebUI : ajout de la recherche dans le journal de la console et de la mise en surbrillance des mots clés, des badges sources pour les compétences, des aperçus d'images par étapes dans ChatUI et la mémorisation du dernier onglet Données et journaux ouvert. (#10327, #10339, #10376, #10251)
  • WebUI : Ajout de l'édition du profil de configuration dans un tiroir latéral depuis l'éditeur de bot. (#10310)
  • Docker : Inclus le astrbot CLI pour la réinitialisation du mot de passe à l'intérieur des conteneurs. (#10442)
  • Journaux : ajout d'un filtrage combiné par niveau, source, plugin, plate-forme et mot-clé, une option pour masquer les journaux de discussion des utilisateurs et des contrôles de taille de police de 8 à 16 px (12 px par défaut, par étapes de 2 px). Les sélecteurs de plugins affichent les noms d’affichage avec les identifiants comme sous-titres. (#10514)

Optimisations majeures

  • Rendu par lots des journaux de console, optimisation des boîtes de dialogue des fournisseurs et des mises à jour de trace, et suppression des travaux inutiles de session et de limite de débit. (#9990, #10007, #10270, #10273, #10274)

  • Docs : plugin chinois et anglais actualisé et guides d'IA intégrés avec flux de travail actuels, dépannage et captures d'écran localisées ; Mise à jour des instructions de configuration de Slack et Lark/Feishu. (#10487, #10353, #10400)
  • Journaux : ajout de métadonnées structurées de source, de plugin, de plate-forme et de catégorie pour le filtrage en mémoire. Les nouveaux journaux suivent automatiquement lorsqu'ils défilent vers le bas et préservent la position de lecture lors de l'affichage des entrées plus anciennes. (#10514)
  • Agent : déplacement du contexte de tâche planifiée par exécution après l'historique des conversations pour maintenir la stabilité de l'invite du système et préserver la réutilisation du cache d'invite. (#10549)

AstrBot v4.29.0

Highlights

  • OS-native sandboxing for Computer Use — Local agent execution can now be isolated with macOS Seatbelt or Linux bubblewrap (#9472), shrinking the blast radius of shell/file tool calls. Watch out: coverage is deliberately narrow (no Windows isolation), and when local isolation is unavailable the execution/file-access controls remain visible but unenforced (#10444–#10487) — don't assume you're sandboxed on unsupported hosts.

  • Configuration keys moved — budget upgrade time — Text-to-image rendering moves from Settings to Configuration Profiles → Extensions and is now isolated per profile (#10306); admin/whitelist moves from Profiles → Platform to Profiles → Access Control, and Platform is renamed Platforms & Messages (#10321); the Customize Sidebar feature is removed (#10480). Scripts or docs targeting old labels/paths will need updating, and users should expect to re-locate these settings after upgrading.

  • /reset and /new semantics restored — /reset again clears only the current conversation context while /new creates and switches to a fresh conversation, undoing a regression (#10118, #10003, #9983). Bot logic and user docs written against the recent (broken) behavior must be re-validated; persisted conversation deletion and history titles are fixed in the same pass.

  • Provider-facing wire changes — Provider requests now carry an x-astrbot-conversation-id header (#10218, #10237), letting custom/proxy endpoints correlate turns. The retired Gemini embedding default is replaced with gemini-embedding-001 (#10393) — re-check pinned configs — and full Anthropic tool parameter schemas (including refs and constraints) are preserved while non-object root schemas are now rejected (#10520).

  • Agent budgets and lifecycle tightened — Step-budget reminders arrive alongside a higher default agent step limit and migrated legacy limits (#10131, #10133), and stopping a session now genuinely halts background agent work and blocks late wakeups (#10323, #10347, #10474). Per-run scheduled-task context also moved after conversation history to keep the system prompt stable and preserve prompt-cache reuse (#10549) — a quiet latency/cost win for scheduled agents.

  • WebUI load and upload performance — Initial load drops via lazy-loaded VAD, Monaco, translations and ApexCharts plus gzip responses (#10413), and uploads are now resumable/chunked with bounded memory (#10123); desktop adds a workspace directory picker and update-download progress (#10222, #10227, #10050). Low adoption risk, but expect different asset-loading behavior on first use of the editor and charts.
