#AstrBot v4.15.0

Ce qui a changé

⚠️ Rappel aux utilisateurs de v4.14.8 : en raison du bug de la version v4.14.8, si vous n'utilisez pas l'application de bureau Electron AstrBot, vous serez redirigé par erreur vers la page des versions de Github via la boîte de dialogue WebUI. Une boîte de dialogue semblable à la suivante apparaît : <img width="400" height="710" alt="image" src="https://github.com/user-attachments/assets/e9a0e3e1-d41d-42c5-b36c-6b9efe298dac" /> Si tel est le cas, ne téléchargez pas et n'installez pas le package d'installation ci-dessous. Vous disposez de deux manières de procéder à la mise à niveau :

  1. Vous devrez peut-être redéployer manuellement AstrBot pour effectuer la mise à niveau. (Vous pouvez ignorer ce rappel si vous pouvez ouvrir la page de mise à jour pour passer à la nouvelle version)
  2. Téléchargez [ce fichier] (https://github.com/AstrBotDevs/AstrBot/releases/download/v4.15.0/AstrBot-v4.15.0-dashboard.zip), décompressez-le et placez-le dans le répertoire de données d'AstrBot, remplacez le répertoire dist, puis actualisez l'interface WebUI et cliquez à nouveau sur le bouton de mise à jour pour restaurer la boîte de dialogue de mise à jour d'origine.

Nouveau

  • Le robot intelligent d'entreprise WeChat prend en charge le push de messages actif et ajoute la prise en charge des vidéos, des fichiers et d'autres types de messages (#4999)
  • L'application d'entreprise WeChat prend en charge la diffusion active de messages et optimise le processus de traitement audio de l'application d'entreprise WeChat, du compte public WeChat et du service client WeChat (#4998)
  • L'adaptateur DingTalk prend en charge le push de message actif et ajoute la prise en charge des types de messages image, vidéo, audio et autres (#4986)
  • Ajout d'un bouton Supprimer dans la fenêtre pop-up de gestion de la personnalité (#4978)

Correction

  • Correction de problèmes liés à la déduplication de l'outil SubAgents (#4990)
  • Améliorer la logique de traitement des messages en streaming de WeCom AI Bot pour améliorer la stabilité de la segmentation et des réponses en streaming (#5000)
  • Stabilisez le comportement d'installation de pip dans le code source et l'environnement de packaging Electron, et corrigez le problème du déclenchement accidentel de la boîte de dialogue de saut lorsque vous cliquez sur le bouton de mise à jour WebUI dans des scènes non-Electron (#4996)
  • Correction d'un problème de collecte de données de certification lors de la création du backend du bureau (#4995)
  • Correction d'un problème d'exécution de l'installation de pip dans un runtime gelé (#4985)
  • Provisionner OpenSSL via vcpkg pour Windows ARM64, résoudre les problèmes de préparation de build associés

Optimisation

  • Mettre à jour la version dépendante de pydantic (#4980)
  • Ajuster la configuration CI de l'espace de noms GHCR

AstrBot v4.15.0

Highlights

  • Recover v4.14.8 before upgrading — The erroneous non-Electron WebUI redirect is fixed in #4996, but already-affected installations may still require manual recovery. If the update page cannot switch versions, replace data/dist with the extracted AstrBot-v4.15.0-dashboard.zip, refresh WebUI, and retry; do not install packages from the erroneous dialog.
  • Proactive messaging across enterprise channels — WeCom AI Bot gains outbound push plus video/file messages (#4999), WeCom app gains push and improved audio handling across WeCom, Official Account, and customer service (#4998), and DingTalk gains push plus image/video/audio support (#4986). Bots can now deliver alerts and background results without waiting for an inbound message.
  • More reliable orchestration and streaming — WeCom AI Bot streaming segmentation is hardened (#5000), subagent/persona tool management and deduplication are improved (#4990), persona deletion is exposed in the UI (#4978), and the HandoffTool.agent attribute crash is fixed (#5005). These changes target unstable streamed replies and failures during multi-agent handoffs.
  • Packaged-runtime dependency fixes — pip install execution is repaired for frozen runtimes (#4985), stabilized across source and Electron environments (#4996), and corrected alongside packaged SSL behavior (#5007); desktop backend certifi collection is also fixed (#4995). This matters for runtime plugin installation. Pydantic is updated (#4980), so custom model and validation code deserves a smoke test.
  • Desktop lifecycle and Windows ARM64 builds — Windows packaged-backend restart failures (#5009), in-app restart feedback and UI readiness (#5013), and Windows ARM64 OpenSSL provisioning through vcpkg are addressed. Restart flows should be more dependable, while ARM64 build preparation now includes the required OpenSSL dependency.
  • Breaking changes — None declared.

What's Changed

⚠️ 提醒 v4.14.8 用户：由于 v4.14.8 版本 Bug，若您未使用 Electron AstrBot 桌面应用，会被错误地通过 WebUI 对话框跳转到 Github Releases 页。 类似出现如下对话框： <img width="400" height="710" alt="image" src="https://github.com/user-attachments/assets/e9a0e3e1-d41d-42c5-b36c-6b9efe298dac" /> 如果是这种情况，不要下载和安装下面的安装包。您有两种升级方式：

  1. 您可能需要手动重新部署 AstrBot 才能升级。（如果可以打开更新页面切换新版本则可以忽略此提醒）
  2. 下载此文件，解压后放到 AstrBot 的 data 目录下，替换 dist 目录，然后刷新 WebUI 界面，重新点击更新按钮即可恢复原来的更新对话框。

新增

  • 企业微信智能机器人支持主动消息推送，并新增视频、文件等消息类型支持 (#4999)
  • 企业微信应用支持主动消息推送，并优化企微应用、微信公众号、微信客服的音频处理流程 (#4998)
  • 钉钉适配器支持主动消息推送，并新增图片、视频、音频等消息类型支持 (#4986)
  • 人格管理弹窗新增删除按钮 (#4978)

修复

  • 修复 SubAgents 工具去重相关问题 (#4990)
  • 改进 WeCom AI Bot 的流式消息处理逻辑，提升分段与流式回复稳定性 (#5000)
  • 稳定源码与 Electron 打包环境下的 pip 安装行为，并修复非 Electron 场景点击 WebUI 更新按钮时误触发跳转对话框的问题 (#4996)
  • 修复桌面端后端构建时 certifi 数据收集问题 (#4995)
  • 修复冻结运行时（frozen runtime）中的 pip install 执行问题 (#4985)
  • 为 Windows ARM64 通过 vcpkg 预置 OpenSSL，修复相关构建准备问题

优化

  • 更新 pydantic 依赖版本 (#4980)
  • 调整 GHCR namespace 的 CI 配置

What's Changed (EN)

New Features

  • Enhanced persona tool management and improved UI localization for subagent orchestration (#4990)
  • Added proactive message push for WeCom AI Bot, with support for video, file, and more message types (#4999)
  • Added proactive message push for WeCom app, and improved audio handling for WeCom app, WeChat Official Account, and WeCom customer service (#4998)
  • Enhanced Dingtalk adapter with proactive push and support for image, video, and audio message types (#4986)
  • Added a delete button to the persona management dialog for better usability (#4978)

Fixes

  • Improved streaming message handling in WeCom AI Bot for better segmented and streaming reply stability (#5000)
  • Stabilized pip installation behavior in source and Electron packaged environments, and fixed the unexpected redirect dialog when clicking WebUI update in non-Electron mode (#4996)
  • Fixed certifi data collection in desktop backend build (#4995)
  • Fixed pip install execution in frozen runtime (#4985)
  • Prepared OpenSSL via vcpkg for Windows ARM64 build flow

Improvements

  • Updated pydantic dependency version (#4980)
  • Updated CI configuration for GHCR namespace
