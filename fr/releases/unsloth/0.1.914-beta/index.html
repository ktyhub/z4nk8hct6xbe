paresseux v0.1.914-beta

Unsloth propose désormais des thèmes Glass et davantage d'options de personnalisation pour les arrière-plans, les salutations et les discussions. Cette version apporte également une génération plus rapide, davantage d'options de formation multi-GPU et une formation CPU dans Unsloth.

<img width="800" alt="thème du verre peu paresseux" src="https://github.com/user-attachments/assets/bc38677f-9e49-4b46-b0ac-f16522541a57" />

Faits saillants

  • Nouveaux thèmes Glass avec 5 thèmes, transparence + verre macOS natif
  • Personnalisation avec des messages d'accueil personnalisés, des contrôles d'arrière-plan et des polices de code
  • Les benchmarks contextuels DeepSeek-V4.1 512K montrent que les GGUF d'Unsloth se classent les plus forts sur Terminal Bench, DeepSWE et AutomationBench. Analyse
  • Navigation par chat pour prévisualiser, ajouter des favoris et passer d'un tour précédent à l'autre
  • Formation de texte CPU directement depuis la page Train

Faites-le vôtre

  • Choisissez parmi cinq styles de verre avec une force réglable et des menus de verre en option, avec ou sans image d'arrière-plan.
  • Unsloth Desktop sur Mac prend en charge le verre natif, permettant à votre bureau de s'afficher à travers la fenêtre.
  • Ajustez la taille et la position de l'arrière-plan, et choisissez où il apparaît dans vos discussions.
  • Ajoutez votre propre message d'accueil avec du texte, une icône ou une image, ou masquez-le entièrement.
  • Personnalisez les polices de code, les numéros de ligne, le retour à la ligne et les ligatures avec un aperçu en direct.
  • Utilisez le thème Trick or Treat toute l'année sans les extras saisonniers.

Chat

  • Prévisualisez les messages précédents, marquez les tours et parcourez de longues conversations avec le nouveau navigateur de discussion.
  • Collez le contenu formaté au format Markdown, y compris les liens, les listes et les tableaux de feuilles de calcul.
  • Les messages arabes, persans, hébreux et ourdou s'affichent de droite à gauche tandis que le code conserve sa direction d'origine.
  • Les longues discussions restent plus réactives pendant que les réponses sont diffusées et que vous faites défiler.
  • Les connexions MCP sont récupérées après un redémarrage du serveur.
  • Les agents de codage peuvent suivre les instructions des fichiers du dossier de travail de votre projet.

Performances et médias

  • Les modèles Llama et Qwen3 à GPU unique pris en charge génèrent plus rapidement dans le backend Transformers d'Unsloth sur les GPU NVIDIA avec Linux ou WSL. Dans notre test A100, le Qwen3-8B 4 bits a atteint 99.1 jetons/s, contre 25.7, soit une accélération de 3,9x.
  • SDXL restitue désormais avec un budget VRAM de 4 Gio, testé sur les GPU T4 et L4.
  • Recherchez plus rapidement de grandes collections de documents grâce à un nouvel index pour RAG.
  • Enregistrez les images générées au format PNG plus rapidement sans modifier la sortie.
  • Les modèles vidéo réutilisent les poids INT8 mis en cache pour des chargements répétés plus rapides.
  • Wan2.2 A14B utilise moins de mémoire système lors de la création de poids INT8 pour la génération déchargée.
  • Ajustez les forces LoRA de l'image sans recharger les fichiers d'adaptateur.
  • Transcrivez l'audio jusqu'à quatre heures avec audio.cpp, sous réserve des limites de téléchargement et de stockage.

## Mac

  • Essayez Fast Verify expérimental pour une génération plus rapide avec les modèles de décodage spéculatif MLX pris en charge. Les réponses peuvent différer légèrement.
  • Le streaming MLX passe moins de temps à traiter le texte à mesure que les réponses augmentent.
  • Unsloth utilise désormais la police système Mac par défaut.

Formation

  • Affinez les modèles de texte sur le CPU à partir de la page Train lorsqu'aucun GPU n'est disponible.
  • Les installations de chat uniquement peuvent ajouter une formation sur le processeur via Install Training.
  • Affinez les modèles de vision audio tels que Gemma 3n et Gemma 4 en utilisant l'audio et les images ensemble dans le même ensemble de données.
  • Chargez les modèles non quantifiés pris en charge plus grands qu'un seul GPU en chargeant uniquement les couches de pipeline attribuées à chaque GPU.
  • Configurez les combinaisons prises en charge de parallélisme de données, de tenseur, de pipeline et de contexte avec UNSLOTH_PARALLEL.
  • Réduisez la mémoire d'activation MLP pendant l'entraînement avec unsloth.tile_mlp(model).
  • Envoyez des images aux modèles de vision via les commandes de chat et d'inférence CLI.

unsloth v0.1.914-beta

Unsloth now has Glass themes and more customization options for backgrounds, greetings and chats. This release also brings faster generation, more multi-GPU training options and CPU training in Unsloth.

<img width="800" alt="unsloth glass theme" src="https://github.com/user-attachments/assets/bc38677f-9e49-4b46-b0ac-f16522541a57" />

Highlights

  • New Glass themes with 5 themes, transparency + native macOS glass
  • Customization with custom greetings, background controls and code fonts
  • DeepSeek-V4.1 512K context benchmarks show Unsloth's GGUFs rank strongest across Terminal Bench, DeepSWE and AutomationBench. Analysis
  • Chat navigation to preview, bookmark and jump between earlier turns
  • CPU text training directly from the Train page

Make it yours

  • Choose from five Glass styles with adjustable strength and optional glass menus, with or without a background image.
  • Unsloth Desktop on Mac supports native glass, letting your desktop show through the window.
  • Adjust background size and position, and choose where it appears across your chats.
  • Add your own greeting with text, an icon or an image, or hide it entirely.
  • Customize code fonts, line numbers, word wrapping and ligatures with a live preview.
  • Use the Trick or Treat theme year-round without the seasonal extras.

Chat

  • Preview earlier messages, bookmark turns and jump through long conversations with the new chat navigator.
  • Paste formatted content as Markdown, including links, lists and spreadsheet tables.
  • Arabic, Persian, Hebrew and Urdu messages display right to left while code keeps its original direction.
  • Long chats stay more responsive while replies stream and you scroll.
  • MCP connections recover after a server restart.
  • Coding agents can follow instructions from files in your project's working folder.

Performance and media

  • Supported single-GPU Llama and Qwen3 models generate faster in Unsloth's Transformers backend on NVIDIA GPUs with Linux or WSL. In our A100 test, 4-bit Qwen3-8B reached 99.1 tokens/s, up from 25.7, a 3.9x speedup.
  • SDXL now renders under a 4 GiB VRAM budget, tested on T4 and L4 GPUs.
  • Search large document collections faster with a new index for RAG.
  • Save generated images as PNG faster without changing the output.
  • Video models reuse cached INT8 weights for faster repeat loads.
  • Wan2.2 A14B uses less system memory when building INT8 weights for offloaded generation.
  • Adjust image LoRA strengths without reloading adapter files.
  • Transcribe audio up to four hours long with audio.cpp, subject to upload and storage limits.

Mac

  • Try experimental Fast Verify for faster generation with supported MLX speculative decoding models. Replies may differ slightly.
  • MLX streaming spends less time processing text as replies grow.
  • Unsloth now uses the Mac system font by default.

Training

  • Fine-tune text models on CPU from the Train page when no GPU is available.
  • Chat-only installs can add CPU training through Install Training.
  • Fine-tune audio vision models such as Gemma 3n and Gemma 4 using audio and images together in the same dataset.
  • Load supported non-quantized models larger than a single GPU by loading only each GPU's assigned pipeline layers.
  • Configure supported combinations of data, tensor, pipeline and context parallelism with UNSLOTH_PARALLEL.
  • Reduce MLP activation memory during training with unsloth.tile_mlp(model).
  • Send images to vision models through CLI chat and inference commands.
