paresseux v0.1.912-beta

Halloween 👻 est là. Jusqu'en octobre, une ligne Trick or Treat dans la barre latérale ouvre onze thèmes d'Halloween, des salutations effrayantes et quelques araignées et chauves-souris.

Cette version accélère également le premier lancement, les appels d'outils Linux et le chargement du modèle, et entraîne les tâches de réglage fin compatibles avec multi-LoRA.

Faits saillants

  • Trick or Treat : 🎃 nouveaux thèmes d'Halloween - jusqu'au 1er novembre
  • Faster Unsloth : premier lancement 2 fois plus rapide, plus accélérations pour les appels d'outils, les listes de modèles, la préparation des ensembles de données et les chargements MiniMax-H3
  • Lot multi-LoRA : jusqu'à 4 tâches de réglage fin compatibles en file d'attente s'entraînent ensemble
  • Réflexion SGLang + compactage automatique : La reprise et la sortie JSON fonctionnent désormais également sur vLLM et SGLang
  • Commutateur d'utilisation du navigateur : laissez les modèles contrôler le navigateur intégré à partir de sa nouvelle page à onglet

Optimisations

  • Le programme d'installation précompile désormais les fichiers Python, le premier lancement est donc environ 2 fois plus rapide.
  • Sous Linux, les appels aux outils démarrent en 1 à 2 ms au lieu de 84 à 174 ms avec un process serveur de 2 Go.
  • Avec 497 modèles mis en cache, la liste des modèles utilise environ un tiers du temps CPU qu'elle utilisait.
  • La préparation d'un ensemble de données de discussion de 1 000 lignes pour Gemma 3 4B a nécessité des 1.75 au lieu des 6.6 dans notre test.
  • MiniMax-H3 chargé en 49 s au lieu de 61 s sur un Linux A100.

Multi-LoRA + API

Lorsque plusieurs tâches compatibles attendent dans la file d'attente de réglage fin, Unsloth les entraîne désormais ensemble, chacune avec son propre adaptateur LoRA sur un modèle de base partagé.

  • Les tâches envoyées pendant que le GPU est occupé sont mises en file d'attente dans l'ordre et chacune peut être annulée indépendamment.
  • Chargez le nom fine_tuned_model d'un travail pour discuter avec son adaptateur formé.
  • Les requêtes /v1/videos sont désormais mises en file d'attente pendant le rendu d'un clip, et les requêtes /v1/images/generations correspondantes sont regroupées.

Comment ça marche

  • Les nouveaux noyaux Triton exécutent la couche de base une fois par lot, tandis que chaque adaptateur apprend uniquement à partir de ses propres jetons avec son propre taux de perte et d'apprentissage.
  • Avec 4 adaptateurs, le passage avant et arrière d'une couche 4 096 x 4 096 s'est déroulé 1,52 fois plus rapidement qu'un adaptateur à la fois (A100, bf16, rang 16).

Chat + outils

  • Les modèles locaux ignorent les appels d'outils qui atteignent la limite de sortie, de sorte qu'un cat > app.py à moitié écrit ne peut pas écraser un fichier.
  • Avant, les réécritures de coupure réduisaient un fichier de test de 175 lignes à seulement 6 lignes sur un RTX 3090.
  • Les modèles Thinking tels que Qwen3 et DeepSeek R1 affichent désormais leur raisonnement et la bascule Think sur SGLang.
  • Avec le compactage automatique activé, les longues discussions SGLang abandonnent leurs tours les plus anciens et continuent de répondre.
  • Sur vLLM et SGLang, vous pouvez reprendre une réponse coupée à Max Tokens et demander JSON avec response_format.

Navigateur + Bureau

  • La nouvelle page à onglet du navigateur comporte un commutateur Utilisation du navigateur qui permet aux modèles de contrôler le navigateur.
  • Sur Desktop, un agent de navigation travaillant pour une discussion temporaire n'ajoute plus de pages à votre historique.
  • Sur macOS avec Safari 18.4 ou version antérieure, les onglets du navigateur du bureau et leurs boutons de fermeture fonctionnent à nouveau.
  • Déconnexion est désormais dans le menu utilisateur d'Unsloth Desktop.

Des bonbons ou un sort

La ligne Trick or Treat… se trouve au-dessus de Plus dans la barre latérale et ouvre un menu Halloween.

  • Choisissez l'un des onze thèmes, tels que Pumpkin, Coven et Ghost Ship, chacun avec un mode clair et sombre.
  • Activez Salutations effrayantes et de nouvelles discussions s'ouvrent avec une ligne d'Halloween et un paresseux.
  • Avec Araignées et chauves-souris activées, les thèmes d'Halloween font apparaître d'étranges araignées et chauves-souris traversant la fenêtre.
  • Vous ne savez pas quel thème ? Un bonbon ou un sort ! en choisit un au hasard. Unsloth revient à la normale à minuit le 1er novembre, ou immédiatement avec Supprimer maintenant.

Formation

  • Gemma 4 E2B et E4B conservent désormais le texte de réflexion d'un ensemble de données dans l'entraînement au lieu de le supprimer.
  • Les nouvelles configurations de formation par chat activent le regroupement de séquences et les achèvements d'assistants là où le modèle et les données les prennent en charge.
  • Les ensembles de données locaux JSON et JSONL se chargent même lorsque les lignes ultérieures ajoutent de nouvelles clés.

unsloth v0.1.912-beta

Halloween 👻 is here. Through October, a Trick or treat row in the sidebar opens eleven Halloween themes, spooky greetings and a few spiders and bats.

This release also speeds up the first launch, Linux tool calls and model loading, and trains compatible fine-tuning jobs together with multi-LoRA.

Highlights

  • Trick or treat: 🎃 new Halloween themes - until Nov 1
  • Faster Unsloth: 2x faster first launch, plus speedups for tool calls, model lists, dataset prep and MiniMax-H3 loads
  • Multi-LoRA batching: up to 4 compatible queued fine-tuning jobs train together
  • SGLang thinking + auto-compact: Resume and JSON output now work on vLLM and SGLang too
  • Browser use switch: let models control the built-in browser from its new tab page

Optimizations

  • Setup now precompiles Python files, so the first launch is about 2x faster.
  • On Linux, tool calls start in 1 to 2 ms instead of 84 to 174 ms with a 2 GB server process.
  • With 497 cached models, the model list uses about a third of the CPU time it did.
  • Preparing a 1,000-row chat dataset for Gemma 3 4B took 1.75 s instead of 6.6 s in our test.
  • MiniMax-H3 loaded in 49 s instead of 61 s on a Linux A100.

Multi-LoRA + API

When several compatible jobs wait in the fine-tuning queue, Unsloth now trains them together, each with its own LoRA adapter on a shared base model.

  • Jobs sent while the GPU is busy queue up in order, and each can be cancelled on its own.
  • Load a job's fine_tuned_model name to chat with its trained adapter.
  • /v1/videos requests now queue while a clip renders, and matching /v1/images/generations requests are batched.

How it works

  • New Triton kernels run the base layer once per batch, while each adapter learns only from its own tokens with its own loss and learning rate.
  • With 4 adapters, a 4096x4096 layer's forward and backward pass ran 1.52x faster than one adapter at a time (A100, bf16, rank 16).

Chat + tools

  • Local models skip tool calls that hit the output limit, so a half-written cat > app.py can't overwrite a file.
  • Before, cut-off rewrites shrank a 175-line test file to as few as 6 lines on an RTX 3090.
  • Thinking models such as Qwen3 and DeepSeek R1 now show their reasoning and the Think toggle on SGLang.
  • With Auto-compact on, long SGLang chats drop their oldest turns and keep answering.
  • On vLLM and SGLang, you can resume a reply cut off at Max Tokens and request JSON with response_format.

Browser + Desktop

  • The browser's new tab page has a Browser use switch that lets models control the browser.
  • On Desktop, a browser agent working for a temporary chat no longer adds pages to your history.
  • On macOS with Safari 18.4 or earlier, Desktop browser tabs and their close buttons work again.
  • Log out is now in the Unsloth Desktop user menu.

Trick or treat

The Trick or treat… row sits above More in the sidebar and opens a Halloween menu.

  • Pick one of eleven themes, such as Pumpkin, Coven and Ghost Ship, each with a light and dark mode.
  • Turn on Spooky greetings and new chats open with a Halloween line and sloth.
  • With Spiders and bats on, Halloween themes get the odd spider and bats crossing the window.
  • Not sure which theme? Trick or treat! picks one at random.

Unsloth returns to normal at midnight on November 1, or right away with Remove now.

Training

  • Gemma 4 E2B and E4B now keep a dataset's thinking text in training instead of dropping it.
  • New chat training setups turn on sequence packing and Assistant completions where the model and data support them.
  • Local JSON and JSONL datasets load even when later rows add new keys.
