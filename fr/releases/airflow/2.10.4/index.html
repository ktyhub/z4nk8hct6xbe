Changements importants

TaskInstance priority_weight est plafonnée dans des plages d'entiers signés de 32 bits (#43611)

Certains moteurs de base de données sont limités à des valeurs entières de 32 bits. Comme certains utilisateurs ont signalé des erreurs dans poids reporté à des valeurs négatives, nous avons décidé de limiter la valeur à l'entier de 32 bits. Même si en interne dans python des valeurs plus petites ou plus grandes jusqu'à 64 bits sont prises en charge, priority_weight est plafonné et stockant uniquement les valeurs de -2147483648 à 2147483647.

airflow 2.10.4

Highlights

  • priority_weight clamped to 32-bit range — PR #43611 caps stored priority_weight to [-2147483648, 2147483647] because several DB backends cannot hold 64-bit integers; values that previously rolled over into negatives now clamp instead. Python still computes internally at 64-bit, but what gets persisted and queried is bounded — relevant if you rely on large weights for queue prioritization.

  • Dynamic mapped task fixes — #44300 and #44319 correct stats after automatic retries and stop grouping TaskInstance stats by try_number, while #43591 fixes the Try Selector on mapped index 0. If you depend on mapped-task metrics or UI retry selection, these paths were previously producing wrong counts and broken selectors.

  • trigger_rule="always" disallowed in mapped tasks — #43810 and #44751 block always (including TriggerRule.ALWAYS) inside dynamic mappings and task-generated mappings in bare tasks. Because always bypasses dependency semantics that conflict with mapped expansion, existing DAGs using it will now be rejected — audit your mapped tasks before upgrading.

  • Stuck queued tasks re-queued — #44158 (with #43520) re-queues TaskInstances left stranded in queued, addressing a scheduler edge case where tasks never progressed. Worth watching if you have historically seen tasks hang in the queue.

  • Connection form and API cleanups — #44442 (via #40421) finally allows removing fields from the Connection form; #43901 corrects the mime-type in the OpenAPI spec; #44167 suppresses false-positive warnings when scanning for sensitive values. Useful if you maintain custom connection UIs or generate clients from the API spec.

  • Inlet/outlet event deprecation — #43922 raises a deprecation warning when accessing inlet/outlet events through str; data-aware or lineage code that reads events in string form should begin migrating now. Related: #43659 fixes the venv numpy example to require ≥1.26 so it works on Python 3.12.

No breaking changes in this release.

Significant Changes

TaskInstance priority_weight is capped in 32-bit signed integer ranges (#43611)

Some database engines are limited to 32-bit integer values. As some users reported errors in weight rolled-over to negative values, we decided to cap the value to the 32-bit integer. Even if internally in python smaller or larger values to 64 bit are supported, priority_weight is capped and only storing values from -2147483648 to 2147483647.

  • Fix wrong display of multi-line messages in the log after filtering (#44457)
  • Allow "/" in metrics validator (#42934) (#44515)
  • Fix gantt flickering (#44488) (#44517)
  • Fix problem with inability to remove fields from Connection form (#40421) (#44442)
  • Check pool_slots on partial task import instead of execution (#39724) (#42693)
  • Avoid grouping task instance stats by try_number for dynamic mapped tasks (#44300) (#44319)
  • Re-queue task when they are stuck in queued (#43520) (#44158)
  • Suppress the warnings where we check for sensitive values (#44148) (#44167)
  • Fix get_task_instance_try_details to return appropriate schema (#43830) (#44133)
  • Log message source details are grouped (#43681) (#44070)
  • Fix duplication of Task tries in the UI (#43891) (#43950)
  • Add correct mime-type in OpenAPI spec (#43879) (#43901)
  • Disable extra links button if link is null or empty (#43844) (#43851)
  • Disable XCom list ordering by execution_date (#43680) (#43696)
  • Fix venv numpy example which needs to be 1.26 at least to be working in Python 3.12 (#43659)
  • Fix Try Selector in Mapped Tasks also on Index 0 (#43590) (#43591)
  • Prevent using trigger_rule="always" in a dynamic mapped task (#43810)
  • Prevent using trigger_rule=TriggerRule.ALWAYS in a task-generated mapping within bare tasks (#44751)

Doc Only Changes

  • Update XCom docs around containers/helm (#44570) (#44573)

Miscellaneous

  • Raise deprecation warning when accessing inlet or outlet events through str (#43922)
