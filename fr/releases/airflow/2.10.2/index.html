airflow 2.10.2

Highlights

  • Dataset scheduling reliability — DAG-to-dataset and dataset-alias references are stored as (type, URI/name) instead of whole objects, avoiding parse failures with custom unhashable subclasses (#41987, #42055). Aliases now retain every outlet_events[alias].add(...) call instead of only the last dataset (#42189, #42247); reparse affected DAGs and validate dataset-triggered scheduling after upgrading.
  • DAG processing and diagnostics — AirflowTaskTimeout is now persisted and displayed like an import error (#42064, #42078), making dagbag_import_timeout failures visible instead of leaving DAGs mysteriously absent. The 2.10.1 DAG-folder stale-detection change is reverted after false stale/DAG-disappearance reports (#42220, #42217); verify reparsing when changing AIRFLOW__CORE__DAGS_FOLDER.
  • XCom and API data fidelity — camelCasing no longer rewrites keys inside XCom values, extra, or renderedTemplates (#42182, #42187, #42206, #42208), while valid falsy values such as false, 0, and "" render correctly instead of as null (#42199, #42213). Update API clients that relied on the previously transformed keys.
  • UI and trigger-form fixes — Task-instance/DAG-run links from list views and details-tab log URLs are corrected (#42138, #42143, #42104, #42114), and require_confirmation_dag_change now correctly governs pause/resume confirmations (#42063, #42211). String Params support textarea input through format="multiline" (#40414, #42139).
  • Upgrade and CLI migration — universal-pathlib is constrained below 0.2.4 because that release breaks local-path integration (#42101); regenerate environments locked to 0.2.4. airflow tasks list --tree and its public helpers are deprecated for removal in Airflow 3 (#41965); migrate automation to airflow dags show.
  • Breaking changes — None.

Significant Changes

No significant changes.

Bug Fixes

  • Revert "Fix: DAGs are not marked as stale if the dags folder change" (#42220, #42217)
  • Add missing open telemetry span and correct scheduled slots documentation (#41985)
  • Fix require_confirmation_dag_change (#42063) (#42211)
  • Only treat null/undefined as falsy when rendering XComEntry (#42199) (#42213)
  • Add extra and renderedTemplates as keys to skip camelCasing (#42206) (#42208)
  • Do not camelcase xcom entries (#42182) (#42187)
  • Fix task_instance and dag_run links from list views (#42138) (#42143)
  • Support multi-line input for Params of type string in trigger UI form (#40414) (#42139)
  • Fix details tab log url detection (#42104) (#42114)
  • Add new type of exception to catch timeout (#42064) (#42078)
  • Rewrite how DAG to dataset / dataset alias are stored (#41987) (#42055)
  • Allow dataset alias to add more than one dataset events (#42189) (#42247)

Miscellaneous

  • Limit universal-pathlib below 0.2.4 as it breaks our integration (#42101)
  • Auto-fix default deferrable with LibCST (#42089)
  • Deprecate --tree flag for tasks list cli command (#41965)

Doc Only Changes

  • Update security_model.rst to clear unauthenticated endpoints exceptions (#42085)
  • Add note about dataclasses and attrs to XComs page (#42056)
  • Improve docs on markdown docs in DAGs (#42013)
  • Add warning that listeners can be dangerous (#41968)
