airflow 2.10.1

Highlights

  • Deferrable triggers finally report real state — #41834 makes triggers completed with end_from_trigger=True record end_date and duration, so deferred tasks stop looking perpetually "running" and expose meaningful terminal timing; paired with #41485, which adds a WebEncoder for the trigger page so detail views no longer 500 on non-JSON-serializable values. If you drive SLAs or duration metrics off deferred sensors/operators, the numbers will shift after upgrade — re-baseline dashboards.
  • Custom executors and older auth stacks get explicit guards — #41927 adds a backward-compatibility check for executors that don't subclass BaseExecutor, catching a common extension pattern before it fails at runtime, and #41809 restores compatibility with FAB provider versions <1.3.0. Note these are guards rather than fixes, so an already-broken executor won't be repaired. Also watch #41569, which drops Debian bullseye from the docs (doc-only, but a signal to plan your base-image upgrade), offset by a new Keycloak auth example in #41791.
  • Fewer spurious task and DAG failures — #41810 stops LocalTaskJob from failing on heartbeat errors, so transient scheduler/worker blips no longer kill healthy tasks; #41829 stops DAGs being marked stale when only the dags folder changes, and #41874 fixes missing-file checks for example DAGs. Operationally this means fewer false incident pages and needless re-parses, especially on volatile or network-mounted dags folders.
  • universal-pathlib XCom backend is easier to adopt and safer — #41943 lowers the minimum universal-pathlib to 0.2.2, relaxing a pin that blocked some environments, while #41938 hardens the backend against None components in XCom paths and #41605 fixes UI rendering when XCom values are INT/FLOAT/BOOL/NULL. Expect previously invisible None-laden keys and scalar XComs to surface correctly in the UI — validate any downstream code that assumed string-only XComs.
  • UI security, tracing and telemetry cleanup — #41680 sanitizes URLs in extra links and #41783 adds rel attributes to hyperlinks in task logs, closing injection/referrer-leak vectors; audit custom extra_links that previously passed unsanitized URLs. #41535 fixes an incorrect try-number subtraction that produced invalid OpenTelemetry span IDs (relevant if you correlate Airflow traces), #41900 changes Scarf usage reporting to major+minor versions with bucketed counters (beacon timing will differ), and webpack is bumped to 5.94.0 in #41879 with no expected runtime impact.
  • Breaking changes — None in 2.10.1.
