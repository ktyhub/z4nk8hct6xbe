airflow 3.0.4

Highlights

  • Forced task termination — BaseOperator.on_kill now runs when TaskSDK tasks are killed externally, and DAG Processor failure callbacks fire on the same path (#53832, #53143). Cleanup and alerting therefore cover manual termination and worker-level kills; test these hooks with forced kills, not only normal failures.

  • Scheduler and API-server resilience — Fixes remove an intermittent scheduler heartbeat DetachedInstanceError (#53858) and prevent large log reads from exhausting API-server memory (#53167). Log retrieval is now streamed, making inspection of high-volume task logs less likely to take down the control plane.

  • Remote logging and private TLS — Logging providers can load metadata-database connections through the API Server when secrets backends do not supply them (#53761), while API-server clients gain self-signed certificate support (#53793). This restores connection-backed remote logging and enables private-PKI deployments without relying solely on instance credentials.

  • Connection editing and exceptions — Connection updates now preserve passwords and extras instead of silently dropping sensitive fields (#53973), and connection exception behavior is aligned between Airflow 2.x and 3.x (#53093). Audit automation that matched exact exception classes, especially credential-rotation workflows.

  • Compatibility-sensitive behavior — start_from_trigger is unconditionally disabled because it does not work in Airflow 3 (#53750), and NaN and infinities now serialize as strings to produce valid JSON (#53844). Remove reliance on trigger-started execution and update custom clients that assumed numeric special-float values.

  • SDK migration and Python packaging — Importing Connection from Airflow models now emits a deprecation notice in favor of the SDK (#53621). Separately, requires-python loses its upper bound and ~= syntax (#52984, #52987), so keep using the 3.0.4 constraints file rather than allowing newer Python versions to outpace provider support.

No breaking changes are declared.
