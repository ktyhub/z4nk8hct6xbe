angular v22.3.0

Highlights

  • Stronger template validation — Unknown property bindings on explicit ng-template elements are now reported, and colon-prefixed attribute/property names are rejected. Fix these diagnostics before upgrading CI to avoid surfacing previously hidden template mistakes.
  • Stricter control-flow typing — Invalid @let usages and tracking functions no longer cascade into misleading compiler errors, while non-iterable @for expressions are no longer suppressed. Invalid loop inputs should be corrected rather than relied on to fail silently.
  • CSS unit checks — The compiler CLI now detects numeric values for CSS properties that require units, catching styles that browsers would otherwise reject.
  • Preprocessor workflow support — The preprocessor gains a serve tool and synchronous WASM execution (#71313), making local compilation workflows more complete and easier to integrate with development tooling.
  • Better compiler and preprocessor parity — @defer validation, host directives, diagnostics, query emission order, decorator handling, and declaration emission are increasingly aligned with ngtsc; tooling users should expect more consistent errors and generated code.
  • Compatibility — No breaking changes announced.
