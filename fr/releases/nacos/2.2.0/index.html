nacos 2.2.0

Cette version est une version importante qui inclut des changements importants. Le premier changement important consiste à supprimer les anciens codes redondants concernant la dénomination 1.x et à double écrire les codes relatifs. Après modification, la version 2.2.0 ne pourra pas être mise à niveau à partir du serveur Nacos 1.X, mais uniquement à partir d'au moins la version 2.0.0. Les modifications n'affecteront pas l'adaptation à la demande 1.X client, ​​les utilisateurs peuvent toujours utiliser 1.X client avec la version 2.2.0. Le deuxième changement important est l'ajout de plusieurs plugins :

  • plugin de source de données, ajouté par le projet Asoc 2022 pour prendre en charge d'autres bases de données.
  • plugin d'environnement personnalisé, ajouté par la communauté pour gérer les configurations du serveur Nacos, telles que le décryptage du mot de passe de la base de données.
  • plugin de limite de connexion, qui a été remanié à partir de l'ancien module de limite, pour étendre davantage de capacités afin de protéger le serveur Nacos sous haute pression. Le troisième changement important consiste à améliorer les fonctionnalités bêta Tracing plugin et batch register, ce qui les rend plus faciles à utiliser. Détails voir :

nacos 2.2.0

This version is an important version which include some large changes.

The first important change is remove the old redundant codes about 1.x naming and double write relative codes. After changed, The 2.2.0 version will can't upgraded from Nacos 1.X server, only can upgraded from at least version 2.0.0. The changes will not effect the adapt for 1.X client request, users can still use 1.X client with 2.2.0 version.

The second important change is adding several plugins:

  • datasource plugin, which added by Asoc 2022 project to support other DBs.
  • custom environment plugin, which added by community to handle configurations of Nacos server, such as decrypt database password.
  • connection limit plugin, which refactored from old limit module, to extend more abilities to protect Nacos server under high pressure.

The third important change is to enhance the beta feature Tracing plugin and batch register, which make them more easy to use.
