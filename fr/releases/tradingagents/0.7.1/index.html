Agents de trading v0.7.1

Les décisions ne sont notées qu'à la clôture finale et sont réglées pendant les longues vacances de marché, la date non complétée d'un modèle ne lit plus les dépôts effectués après la date d'exécution et corrige les portefeuilles, les prix, les déclarations SEC, les rapports, les paramètres Azure et Claude.

Mise à niveau depuis 0.7.0

  • Les images Docker n'incluent plus .env.enterprise. Pour Azure OpenAI dans Docker, placez ses clés dans .env.

Corrigé

  • Une date à laquelle un modèle passe sans remplissage de zéros, telle que 2024-7-5, est lue comme cette date. Il pourrait être comparé à un dépôt effectué après la date d'exécution, et SEC EDGAR a ensuite signifié ce dépôt. (#1488)
  • Une décision n'est plus notée sur la barre d'une séance en cours de négociation, et une décision prise avant une fermeture du marché de plus d'une semaine, comme un jour férié national, est réglée une fois la négociation reprise au lieu de rester en attente. (#1548, #1539)
  • Un backtest signale les échecs de sa dernière passe de règlement, et deux lancées dans la même seconde ne partagent plus une même exécution. (#1557, #1549)
  • Un avoir coté sous l'orthographe d'un courtier (BTCUSDT, 700.HK) est apparié à l'instrument analysé, et un numéro de portefeuille non fini est refusé au chargement du fichier. (#1556, #1509)
  • Les prix conservent leurs chiffres significatifs : une clôture en sous-cents ne s'imprime plus comme 0.00, et une paire de devises conserve ses pips. (#1567)
  • Les déclarations SEC EDGAR répertorient une ligne par période, de sorte qu'un modèle ne lit plus un chiffre par rapport au mauvais trimestre sur une longue histoire, et un chiffre inférieur à un million ne s'imprime plus comme 0. (#1517, #1589)
  • L'enregistrement d'un rapport dans un dossier utilisé auparavant supprime les sections de l'exécution précédente. (#1566)
  • Une fenêtre de date qui se termine avant de commencer est renvoyée au modèle au lieu de ne renvoyer aucune donnée. (#1595)
  • Une fréquence de relevé autre qu'annuelle ou trimestrielle est renvoyée au modèle au lieu de recevoir des chiffres annuels sous ce mot. (#1593)
  • Les leçons les plus récentes de la mémoire et la rotation des entrées suivent les dates de décision, de sorte qu'un remplissage de dates plus anciennes ne les déplace plus. (#1603)
  • Les cotes du marché des prédictions proches de 0 % ou 100 % indiquent leur distance à deux chiffres significatifs. (#1598)
  • Azure OpenAI reçoit max_tokens et un point de terminaison configuré. (#1584, #1600)
  • Le paramètre d'effort de Claude est décidé correctement pour les ID de modèle datés tels que claude-sonnet-4-20250514. (#1585)
  • Le CLI vérifie un ticker avec la même règle que l'exécution, donc XAUUSD+ est accepté et .. est refusé à l'invite. (#1604)
  • Les images Docker n'incluent plus les fichiers .env d'aucun dossier.
  • Les tests qui ont échoué sous Windows et macOS pour des raisons de plate-forme sont corrigés. (#1506, #1485, #1541)

TradingAgents v0.7.1

Highlights

  • Docker environment migration — Images no longer bundle .env files, including .env.enterprise. Supply configuration at runtime; Azure OpenAI users must move keys into .env rather than relying on the previously bundled enterprise file. Deployments that depended on those files may otherwise start without credentials.
  • Prevention of future-filing leakage — Unpadded model dates such as 2024-7-5 are interpreted correctly, avoiding comparisons that could admit EDGAR filings made after the run date (#1488). Historical analyses now enforce the intended information cutoff instead of silently incorporating later data.
  • Final-close scoring and holiday settlement — Decisions no longer score against a session’s still-changing bar, and decisions spanning market closures longer than a week settle when trading resumes rather than remaining pending indefinitely (#1548, #1539). This makes backtest outcomes more consistent with real trading sessions and extended holidays.
  • Backtest isolation and clearer failures — Concurrent runs started in the same second no longer share an identity, and failures from the final settlement pass are reported (#1557, #1549). Reusing a report directory also removes sections left by an earlier run (#1566), reducing cross-run contamination and making failed evaluations easier to diagnose.
  • More accurate financial data and portfolios — SEC statements now use one row per period and preserve figures below one million, while prices retain sub-cent and FX-pip precision (#1517, #1589, #1567). Broker-specific holdings such as BTCUSDT and 700.HK match analyzed instruments, and non-finite portfolio values are rejected during loading (#1556, #1509), preventing silent mismatches and invalid-state propagation.
  • Provider and validation fixes — Azure OpenAI now receives the configured endpoint and max_tokens, while Claude effort selection recognizes dated model IDs (#1584, #1600, #1585). Invalid date windows and unsupported statement frequencies return to the model for correction instead of producing empty or mislabeled results (#1595, #1593); CLI ticker validation now matches runtime rules (#1604).

Decisions are scored only on final closes and settle across long market holidays, a model's unpadded date no longer reads filings made after the run date, and fixes to portfolios, prices, SEC statements, reports, Azure and Claude settings.

Upgrading from 0.7.0

  • Docker images no longer include .env.enterprise. For Azure OpenAI in Docker, put its keys in .env.

Fixed

  • A date a model passes without zero padding, such as 2024-7-5, is read as that date. It could compare as later than a filing made after the run date, and SEC EDGAR then served that filing. (#1488)
  • A decision is no longer scored on the bar of a session still trading, and one made before a market closure longer than a week, such as a national holiday, settles once trading resumes instead of staying pending. (#1548, #1539)
  • A backtest reports the failures of its last settlement pass, and two started in the same second no longer share one run. (#1557, #1549)
  • A holding listed under a broker's spelling (BTCUSDT, 700.HK) is matched to the instrument analyzed, and a portfolio number that is not finite is refused when the file loads. (#1556, #1509)
  • Prices keep their significant digits: a sub-cent close no longer prints as 0.00, and a currency pair keeps its pips. (#1567)
  • SEC EDGAR statements list one row per period, so a model no longer reads a figure against the wrong quarter across a long history, and a figure under one million no longer prints as 0. (#1517, #1589)
  • Saving a report to a folder used before removes the earlier run's sections. (#1566)
  • A date window that ends before it starts is sent back to the model instead of returning no data. (#1595)
  • A statement frequency other than annual or quarterly is sent back to the model instead of being served annual figures under that word. (#1593)
  • The memory's most recent lessons, and the entries rotation keeps, follow decision dates, so a backfill of older dates no longer displaces them. (#1603)
  • Prediction-market odds near 0% or 100% show their distance from it to two significant digits. (#1598)
  • Azure OpenAI receives max_tokens and a configured endpoint. (#1584, #1600)
  • Claude's effort setting is decided correctly for dated model IDs such as claude-sonnet-4-20250514. (#1585)
  • The CLI checks a ticker with the same rule as the run, so XAUUSD+ is accepted and .. is refused at the prompt. (#1604)
  • Docker images no longer include .env files from any folder.
  • Tests that failed on Windows and macOS for platform reasons are fixed. (#1506, #1485, #1541)
