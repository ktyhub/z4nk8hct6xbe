ktransformateurs v0.6.4

KTransformers v0.6.4 : paramètres complets de bout en bout hautes performances et réglage fin LoRA

KTransformers v0.6.4 est une mise à niveau majeure du chemin de réglage fin KT pour les grands modèles MoE clairsemés. Cette version étend KT SFT du réglage précis des paramètres complets de bout en bout à LoRA, tout en améliorant le débit d'entraînement hétérogène CPU-GPU BF16 et l'efficacité de la mémoire sur la RAM hôte et la VRAM GPU.

🚀 Points forts

  • Paramètres complets de bout en bout et LoRA SFT : entraînez de grands modèles MoE clairsemés avec des configurations Full Fine-Tuning, LoRA ou hybrides via le flux de travail familier de LLaMA-Factory.
  • Débit de formation élevé : lors d'exécutions de formation réelles de bout en bout (et non dans des tests de noyau isolés), les KTransformers ont atteint environ 400 jetons/s avec Full-FT et 600 jetons/s avec LoRA sur Qwen3-30B-A3B en utilisant 2 × processeurs AMD EPYC 9355 et 2 × GPU RTX 5090. Une configuration LoRA distincte utilisant un RTX 4090 et un processeur compatible AMX a supporté plus de 700 jetons/s. Les points de contrôle qui en ont résulté ont également montré des gains évidents en matière de validation des réglages fins de bout en bout.
  • DeepSeek V4 sur les GPU Ampere : les replis d'attention BF16 et un chemin FP8 MoE Marlin étendent la prise en charge de DeepSeek V4 Flash aux GPU sans cœurs Tensor FP8 natifs.
  • Compatibilité et accélération RAWINT4 : compatibilité plus large en termes de poids emballé, chargement expert AVX-VNNI-256 et chemin de pré-remplissage Kimi K2 plus rapide.
  • Backend expérimental Intel iGPU : nouvelle prise en charge de l'inférence GPTQ INT4 MoE basée sur SYCL pour les GPU intégrés Intel.

📌 Paramètres complets, LoRA et SFT hybride

Cette version complète le workflow de formation hétérogène KT CPU-GPU pour les grands modèles MoE clairsemés :

  • Full Fine-Tuning met à jour les poids experts du processeur gérés par KT ainsi que les paramètres réguliers d'entraînement du modèle.
  • LoRA couvre les couches linéaires régulières, les routeurs et les portes, ainsi que les experts MoE fusionnés.
  • Entraînement hybride permet d'entraîner ensemble les paramètres Full-FT et LoRA.
  • Une formation fiable en plusieurs étapes prend en charge l'accumulation de gradients, les points de contrôle d'activation, l'exécution distribuée, les mises à jour de l'optimiseur et le profilage. Le nouveau parcours de formation cible principalement la formation experte en CPU BF16 KT. 👉 Implémentation principale : ktransformers PR #2094

📌 GPU DeepSeek V4 et Ampere

L'intégration sglang-kt fournie ajoute une prise en charge plus large de DeepSeek V4 Flash et FP8 MoE sur les GPU Ampere :

  • Cache KV BF16 et solutions de secours pour les GPU sans cœurs Tensor FP8 natifs.
  • Prise en charge FP8 MoE Marlin pour les experts GPU, le préremplissage GPU et les mises à jour dynamiques des experts.
  • Correctifs de stabilité pour la planification d'entrées longues, le démarrage AMXINT4/8 et la déquantification à l'échelle FP16 FE8M0. Modifications associées :
  • [Inférence Flash DeepSeek V4 sur les GPU Ampere] (https://github.com/kvcache-ai/sglang/pull/58)
  • [Correction du dimensionnement du pool de jetons SWA V4] (https://github.com/kvcache-ai/sglang/pull/60)
  • Correction de la gestion des paramètres AMXINT4/8 SwiGLU
  • [FP8 MoE Marlin pour GPU Expert et GPU Prefill] (https://github.com/kvcache-ai/sglang/pull/62)
  • [Déquantification à l'échelle Marlin FP16 FE8M0] (https://github.com/kvcache-ai/sglang/pull/63)

📌 Compatibilité RAWINT4 et accélération du pré-remplissage

KTransformers v0.6.4 améliore le chemin RAWINT4 CPU Expert avec :

  • Prise en charge des points de contrôle de tenseurs compressés qui stockent les poids INT4 emballés dans int32.
  • Chargement RAWINT4 par expert sur les systèmes AVX-VNNI-256.
  • Un chemin de multiplication matricielle bloqué pour un pré-remplissage plus rapide du Kimi K2 RAWINT4, tout en conservant le chemin de décodage existant pour les séquences courtes. Modifications associées :
  • Normaliser les poids RAWINT4 compressés
  • [Chargement RAWINT4 AVX-VNNI-256 par expert] (https://github.com/kvcache-ai/ktransformers/pull/2092)
  • Expédition mat-mat pré-remplie K2 RAWINT4

📌 Backend expérimental Intel iGPU SYCL

Cette version introduit un backend SYCL expérimental pour l'inférence GPTQ INT4 MoE sur les GPU intégrés Intel. La compatibilité et les performances dépendent du GPU Intel, du pilote, de la chaîne d'outils SYCL et de la configuration du modèle. 👉 [Backend Intel iGPU SYCL GPTQ INT4 MoE] (https://github.com/kvcache-ai/ktransformers/pull/2089)

🔐 Sécurité

Le planificateur balance_serve lie désormais son point de terminaison ZMQ ROUTER à 127.0.0.1 au lieu de toutes les interfaces réseau, réduisant ainsi l'exposition à la désérialisation de pickle à distance non authentifiée.

  • Correctif de sécurité PR #2091
  • GHSA-83vp-v6wg-x93x

📦Installation

KT SFT

pip install "ktransformers[sft]"

KT SFT continue d'utiliser l'entrée de formation LLaMA-Factory et le flux de travail YAML.

Inférence KT

Installer à partir de la source

git clone https://github.com/kvcache-ai/ktransformers.git
cd ktransformers
git submodule update --init --recursive
cd kt-kernel && ./install.sh
cd .. && ./install.sh

CUDA 12.0 ou plus récent est requis. Les backends individuels peuvent avoir des exigences supplémentaires en matière de CPU ISA, d'architecture GPU, de pilote ou de compilateur.

ktransformers v0.6.4

KTransformers v0.6.4: High-Performance End-to-End Full-Parameter and LoRA Fine-Tuning

KTransformers v0.6.4 is a major upgrade to the KT fine-tuning path for large sparse MoE models. This release extends KT SFT from end-to-end Full-Parameter Fine-Tuning to LoRA, while improving BF16 CPU-GPU heterogeneous training throughput and memory efficiency across host RAM and GPU VRAM.

🚀 Core Highlights

  • End-to-end Full-Parameter and LoRA SFT: train large sparse MoE models with Full Fine-Tuning, LoRA, or Hybrid configurations through the familiar LLaMA-Factory workflow.
  • High training throughput: in real end-to-end training runs—not isolated kernel benchmarks—KTransformers reached approximately 400 tokens/s with Full-FT and 600 tokens/s with LoRA on Qwen3-30B-A3B using 2× AMD EPYC 9355 CPUs and 2× RTX 5090 GPUs. A separate LoRA setup using one RTX 4090 and an AMX-enabled CPU sustained more than 700 tokens/s. The resulting checkpoints also showed clear gains in end-to-end fine-tuning validation.
  • DeepSeek V4 on Ampere GPUs: BF16 attention fallbacks and an FP8 MoE Marlin path expand DeepSeek V4 Flash support to GPUs without native FP8 Tensor Cores.
  • RAWINT4 compatibility and acceleration: broader packed-weight compatibility, AVX-VNNI-256 expert loading, and a faster Kimi K2 prefill path.
  • Experimental Intel iGPU backend: new SYCL-based GPTQ INT4 MoE inference support for Intel integrated GPUs.

📌 Full-Parameter, LoRA, and Hybrid SFT

This release completes the KT CPU-GPU heterogeneous training workflow for large sparse MoE models:

  • Full Fine-Tuning updates KT-managed CPU expert weights together with the model's regular trainable parameters.
  • LoRA covers regular linear layers, routers and gates, and fused MoE experts.
  • Hybrid training allows Full-FT and LoRA parameters to be trained together.
  • Reliable multi-step training supports gradient accumulation, activation checkpointing, distributed execution, optimizer updates, and profiling.

The new training path primarily targets BF16 KT CPU expert training.

👉 Main implementation: ktransformers PR #2094

📌 DeepSeek V4 and Ampere GPUs

The bundled sglang-kt integration adds broader DeepSeek V4 Flash and FP8 MoE support on Ampere GPUs:

  • BF16 KV-cache and attention fallbacks for GPUs without native FP8 Tensor Cores.
  • FP8 MoE Marlin support for GPU Experts, GPU Prefill, and dynamic expert updates.
  • Stability fixes for long-input scheduling, AMXINT4/8 startup, and FP16 FE8M0 scale dequantization.

Related changes:

  • DeepSeek V4 Flash inference on Ampere GPUs
  • Fix V4 SWA token-pool sizing
  • Fix AMXINT4/8 SwiGLU parameter handling
  • FP8 MoE Marlin for GPU Expert and GPU Prefill
  • FP16 FE8M0 Marlin scale dequantization

📌 RAWINT4 Compatibility and Prefill Acceleration

KTransformers v0.6.4 improves the RAWINT4 CPU Expert path with:

  • Support for compressed-tensors checkpoints that store packed INT4 weights in int32.
  • Per-expert RAWINT4 loading on AVX-VNNI-256 systems.
  • A blocked matrix-multiplication path for faster Kimi K2 RAWINT4 prefill, while keeping the existing decode path for short sequences.

Related changes:

  • Normalize compressed RAWINT4 weights
  • AVX-VNNI-256 per-expert RAWINT4 loading
  • K2 RAWINT4 prefill mat-mat dispatch

📌 Experimental Intel iGPU SYCL Backend

This release introduces an experimental SYCL backend for GPTQ INT4 MoE inference on Intel integrated GPUs. Compatibility and performance depend on the Intel GPU, driver, SYCL toolchain, and model configuration.

👉 Intel iGPU SYCL GPTQ INT4 MoE backend

🔐 Security

The balance_serve scheduler now binds its ZMQ ROUTER endpoint to 127.0.0.1 instead of all network interfaces, reducing exposure to unauthenticated remote pickle deserialization.

  • Security fix PR #2091
  • GHSA-83vp-v6wg-x93x
