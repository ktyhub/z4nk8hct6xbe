ragflow v0.25.1

Résumé

Améliorations

  • Refactorisation et unification du API : normalise les API Web selon les conventions RESTful sur tous les points de terminaison, unifiant les flux de création et d'indexation de documents tout en maintenant la compatibilité ascendante.
  • Optimisations de l'analyse : ajoute le backend PDF [OpenDataLoader] (https://github.com/opendataloader-project/opendataloader-pdf). #14097
  • Introduit le chargement paresseux et l'analyse fragmentée pour les PDF volumineux (> 50 pages), réduisant considérablement l'empreinte mémoire. #14385

Source de données

Permet de synchroniser les fichiers supprimés dans Bitbucket, Gmail, Google Drive et Airtable.

Prise en charge du modèle

  • DeepSeek v4

Fournisseurs de modèles

-UCloud

Corrections de bugs

  • Problèmes de visibilité des métadonnées lors des mises à niveau de v0.24.0 vers v0.25.0.
  • Sortie de chat en double.

ragflow v0.25.1

Summary

Improvements

  • API refactoring and unification: Standardizes web APIs to RESTful conventions across all endpoints, unifying document creation and indexing flows while maintaining backward compatibility.
  • Parsing optimizations: Adds OpenDataLoader PDF backend. #14097
  • Introduces lazy loading and chunked parsing for large PDFs (>50 pages), significantly reducing memory footprint. #14385

Data source

Enables synchronizing deleted files in Bitbucket, Gmail, Google Drive, and Airtable.

Model support

  • DeepSeek v4

Model providers

  • UCloud

Bug fixes

  • Metadata visibility issues during v0.24.0 to v0.25.0 upgrades.
  • Duplicate chat output.
