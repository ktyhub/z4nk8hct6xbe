#ragflow v1.0.0

Après trois release candidates, nous sommes heureux d'annoncer la sortie officielle du RAGFlow 1.0, désormais prêt pour la production. Construite sur une réécriture complète dans Go, cette version réduit considérablement les frais de déploiement et d'exécution et introduit une toute nouvelle expérience de chat agent. Nous encourageons tous les utilisateurs à effectuer une mise à niveau pour améliorer la stabilité, les performances et la réponse aux questions.

Faits saillants

  • Réécrit en Go pour un déploiement plus léger : les images du Docker sont environ 10 fois plus petites et le démarrage est environ 10 fois plus rapide.
  • Une simultanéité environ 100 fois supérieure, avec des améliorations substantielles de la latence des requêtes, de l'utilisation de la mémoire et de la vitesse d'analyse des documents.
  • Tout nouveau chat agent : permet un raisonnement en plusieurs étapes et des réponses à des questions complexes grâce à la récupération itérative, aux appels d'outils et à l'évaluation de la suffisance des preuves.

Chat et agents

  • Ajout du mode Agentic Chat, remplaçant les niveaux de réflexion précédents Faible, Moyen, Élevé et Ultra.
  • Introduction du modèle de décision Jev dans la boucle d'appel d'outils d'agent pour déterminer si les preuves disponibles sont suffisantes pour répondre à une question.
  • Ajout de la prise en charge du modèle de décision Jev dans le composant d'agent Categorize.
  • Ajout du stockage et de l'affichage des invites, de l'utilisation des jetons et du temps d'exécution dans l'historique des discussions.

Ingestion et récupération de documents

  • Unifié les 12 analyseurs de documents intégrés avec les analyseurs de pipeline.
  • Ajout de la prise en charge de plusieurs versions DSL du pipeline d'ingestion.

Architecture et déploiement

  • Migration de la file d'attente de messages de Redis vers NATS.
  • Adoption de Kvrocks pour le stockage du cache et des points de contrôle.
  • Ajout d'images Docker pour l'architecture arm64.
  • Réimplémentation du RAGFlow CLI en Go.

Stabilité

  • Correction de plusieurs bogues critiques signalés par la communauté et de problèmes identifiés lors de la phase de version candidate, améliorant encore la stabilité de l'exécution.

Repères

  • Atteint une précision de 91 % sur le test de réponse aux questions multi-sauts FRAMES à l'aide de RAGFlow Agentic Chat avec MiniMax M3.

Mise à niveau

  • Depuis v1.0.0-rc1, rc2 ou rc3 : les données existantes sont entièrement compatibles. Vous pouvez mettre à niveau directement.
  • Depuis le v0.27.2 : vous pouvez passer directement au v1.0.0. La migration des données s'exécute automatiquement au démarrage du conteneur RAGFlow Docker.
  • À partir des versions antérieures à v0.27.2 : suivez le guide de migration pour effectuer les mises à niveau intermédiaires requises avant de passer à v1.0.0.
  • Sauvegardez toutes les données avant la mise à niveau. La migration des données du v0.27.2 vers le v1.0.0 est irréversible. Si la migration échoue, restaurez la sauvegarde complète avant la mise à niveau avant de réessayer.

Compatibilité et limites

  • Les alias API obsolètes ne sont plus pris en charge.
  • Le Python SDK n'est pas affecté.
  • DeepDoc prend actuellement en charge uniquement les environnements CPU.

Références relatives

  • Guide de sauvegarde et de mise à niveau : https://ragflow.io/docs/migration_overview
  • Suppression des API : https://ragflow.io/docs/http_api_reference#removed-api-aliases

ragflow v1.0.0

After three release candidates, we are pleased to announce the official release of RAGFlow 1.0, now ready for production. Built on a complete rewrite in Go, this release significantly reduces deployment and runtime overhead and introduces an all-new Agentic Chat experience. We encourage all users to upgrade for improved stability, performance, and question answering.

Highlights

  • Rewritten in Go for lighter deployment: Docker images are approximately 10× smaller, and startup is approximately 10× faster.
  • Approximately 100× greater concurrency, with substantial improvements in query latency, memory usage, and document parsing speed.
  • All-new Agentic Chat: Enables multi-step reasoning and answers to complex questions through iterative retrieval, tool calls, and evidence sufficiency assessment.

Chat and Agents

  • Added Agentic Chat mode, replacing the previous Low, Medium, High, and Ultra thinking levels.
  • Introduced the Jev decision model into the agent tool-calling loop to determine whether the available evidence is sufficient to answer a question.
  • Added support for the Jev decision model in the Categorize agent component.
  • Added storage and display of prompts, token usage, and execution time in chat history.

Document Ingestion and Retrieval

  • Unified the 12 built-in document parsers with the pipeline parsers.
  • Added support for multiple ingestion pipeline DSL versions.

Architecture and Deployment

  • Migrated the message queue from Redis to NATS.
  • Adopted Kvrocks for cache and checkpoint storage.
  • Added Docker images for the arm64 architecture.
  • Reimplemented the RAGFlow CLI in Go.

Stability

  • Fixed multiple critical bugs reported by the community and issues identified during the release candidate phase, further improving runtime stability.

Benchmarks

  • Achieved 91% accuracy on the FRAMES multi-hop question-answering benchmark using RAGFlow Agentic Chat with MiniMax M3.

Upgrading

  • From v1.0.0-rc1, rc2, or rc3: Existing data is fully compatible. You can upgrade directly.
  • From v0.27.2: You can upgrade directly to v1.0.0. Data migration runs automatically when the RAGFlow Docker container starts.
  • From versions earlier than v0.27.2: Follow the migration guide to complete the required intermediate upgrades before upgrading to v1.0.0.
  • Back up all data before upgrading. Data migration from v0.27.2 to v1.0.0 is irreversible. If migration fails, restore the complete pre-upgrade backup before trying again.

Compatibility and Limitations

  • Deprecated API aliases are no longer supported.
  • The Python SDK is unaffected.
  • DeepDoc currently supports CPU environments only.

Relative references

  • Backup and upgrade guide: https://ragflow.io/docs/migration_overview
  • Removed APIs: https://ragflow.io/docs/http_api_reference#removed-api-aliases
