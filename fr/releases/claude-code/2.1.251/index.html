claude-code v2.1.251

Correctif Publié28 août 2026 Sourceanthropics/claude-code Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

code-claude v2.1.251

Qu'est-ce qui a changé

  • Ajout des événements hook PreModelSwitch et PostModelSwitch (bloquer, confirmer ou annoter un commutateur de modèle) ; Les hooks de reprise SessionStart reçoivent désormais l'obsolescence de la session et le coût estimé de la remise en cache.
  • Ajout de la diffusion en direct des appels et des résultats d'un sous-agent de premier plan vers la télécommande clients (les sous-agents d'arrière-plan, par défaut, affichent toujours l'état uniquement)
  • Ajout d'une barre de limite de dépenses à /usage et d'un champ de ligne d'état rate_limits.spend_limit pour les développeurs derrière une passerelle d'applications Claude avec des limites de dépenses
  • Ajout d'une ligne de cache d'invite par session à /cost (taux de réussite, échecs, jetons remis en cache, chaud/froid) et un objet prompt_cache correspondant pour les scripts de ligne d'état
  • Ajout de attach, logs, stop, respawn et rm à claude --help ; le message --resume pour une session en arrière-plan en cours d'exécution nomme désormais la commande claude attach <id> exacte
  • Correction des outils de fichiers (Lecture, Écriture, Édition) suite à un lien symbolique échangé à l'intérieur du répertoire de travail après la vérification des autorisations, qui pouvaient lire ou écrire en dehors de l'emplacement approuvé
  • Correction des commandes de plugin déclarées dans une entrée du marché pouvant pointer en dehors du répertoire du plugin ; ces chemins sont maintenant rejetés avec une erreur de parcours
  • Correction des paramètres du projet permettant d'activer le traçage bêta détaillé ou la journalisation brute du corps API, ainsi qu'un point de terminaison de traçage bêta de moindre portée contournant un collecteur OTLP épinglé par des paramètres gérés ou une application hôte.
  • Correction de l'outil Workflow lisant (et citant dans les erreurs) un scriptPath en dehors de ce que la session peut lire avant l'exécution de la vérification des autorisations
  • Correction de Grep et Glob n'appliquant pas les règles de refus Read(...) aux fichiers atteints via un chemin de recherche lié symboliquement
  • Correction des conversations bloquées sur les erreurs "les blocs de contenu texte doivent être non vides" après un tour où le modèle ne produisait que de la réflexion
  • Correction du premier lancement sur une nouvelle installation démarrant en mode par défaut au lieu du mode automatique pour les comptes dont le démarrage par défaut est le mode automatique
  • Correction des requêtes Opus 5 échouant avec « l'effort… n'est pas pris en charge lorsque la pensée est désactivée » lorsque l'effort était xhigh/max et que la pensée était désactivée ; l'effort est maintenant envoyé comme high dans ce cas
  • Correction de la réponse à un message que Claude Desktop a envoyé à partir d'une autre session : SendMessage à cet identifiant de session est désormais transmis via Claude Desktop au lieu d'échouer avec "inaccessible".
  • Correction du décalage TUI avec de nombreux sous-agents parallèles : les ticks de progression par seconde remplacent désormais leur prédécesseur au lieu de s'accumuler dans la transcription.
  • Correction des équipes d'agents : la réponse finale d'un coéquipier n'atteignait pas le chef d'équipe - elle arrivait désormais dans la notification d'inactivité au lieu d'un avis "disponible" sans contenu
  • Correction des sous-agents en arrière-plan incapables de répondre à un message provenant d'un agent frère ou parent sans nom (from était le type d'agent, qui n'est pas une adresse)
  • Correction des paramètres gérés disableAutoMode arrivant en milieu de session ne replaçant pas une session en mode automatique déjà en cours en mode par défaut
  • Correction d'une astuce "passer à Opus 1M pour 5x plus de contexte" qui apparaissait même lorsque le modèle Opus actuel dispose déjà d'une fenêtre contextuelle 1M
  • Correction des sessions de passerelle d'applications Claude traitant un profil Anthropic stocké (par exemple une connexion à la console) comme actif : le listant dans /status et réessayant la passerelle 401 avec lui, bien que les requêtes ne l'utilisent jamais
  • Correction des sessions cloud indiquant à Claude que le modèle avait changé alors que l'hôte ne faisait que définir le modèle initial de la session
  • Correction du contrôle à distance signalant un échec lorsque la politique d'une organisation le désactive ; il affiche désormais un seul avis silencieux à la place
  • Correction de /mcp reconnect sur la télécommande affichant une erreur générique de détails retenus au lieu du véritable remède lorsqu'un serveur était désactivé dans une autre session
  • Correction de --input-format stream-json : les appels de l'outil d'assistance injectés par client envoyés sans identifiant de message étaient fusionnés dans le premier et leurs résultats étaient perdus, y compris lors de la reprise d'anciennes sessions.
  • Correction des transcriptions de session écrasées silencieusement lorsqu'un changement de répertoire déplaçait une session sur une transcription existante de même ID
  • Correction des sessions en arrière-plan et de leurs sous-agents incapables de modifier les fichiers dans un arbre de travail git créé avec git worktree add
  • Correction de sessions en arrière-plan démarrant parfois sans aucune compétence en matière de plugin (et restant ainsi) lorsqu'un autre processus Claude Code actualisait le marché des plugins au même moment
  • Correction de la sélection de texte dans une session en arrière-plan ouverte dans tmux via SSH : il se copie désormais dans le tampon tmux comme une session de premier plan au lieu de revenir à OSC 52
  • Correction du blocage indéfini des sessions SDK et cloud lorsque l'accusé de réception d'une liaison d'un serveur MCP SDK était perdu ; l'attente expire maintenant après 70 secondes et marque uniquement l'échec du serveur
  • Correction du programme d'exécution auto-hébergé qui laissait les processus de l'outil Bash d'une session bloquée s'exécuter après l'arrêt forcé de la session.
  • Correction de /usage-credits pour les membres Team et Enterprise dont l'administrateur a défini la limite de crédit d'utilisation de l'organisation à 0 $ : il propose désormais de demander à l'administrateur au lieu de dire qu'un plafond a été atteint.
  • Correction de --worktree --tmux avec un numéro de demande de fusion sur une origine gitlab.com en essayant d'abord une récupération de style GitHub condamnée au lieu de récupérer directement la référence GitLab
  • Correction de l'échec de Ctrl+G avec "Emacs se ferme de manière inattendue" dans les sessions en arrière-plan pour les éditeurs qui ouvrent /dev/tty, tels que emacs -nw et micro.
  • Correction d'une entrée additionalDirectories contenant un démarrage en panne d'octet nul ou une interruption des mises à jour des paramètres de /add-dir et versions ultérieures lorsqu'elle provenait d'un hôte, d'un IDE ou d'un hook SDK ; c'est maintenant ignoré
  • Correction du raccourci de copie du menu du serveur MCP : il indique désormais comment l'URL de connexion a été copiée au lieu de toujours revendiquer le succès
  • Correction du rendu du texte italique (comme la ligne de récapitulation de la session) sous forme de blocs en surbrillance dans l'écran GNU et dans les sessions tmux utilisant un terminal de type screen
  • Correction du texte d'aide claude mcp add --header et claude mcp add-json nommant les mauvais transports
  • Correction de claude ultrareview et /ultrareview attendant 30 minutes complètes lorsque la session cloud ne démarre pas ; ils s'arrêtent maintenant plus tôt et signalent la raison
  • Correction de l'autorisation Bash qui vérifie les commandes d'approbation automatique qui attribuent une expression arithmétique à une variable shell entière (par exemple OPTIND=1/0, RANDOM=2+2) ; ceux-ci demandent désormais approbation
  • Correction des sessions en arrière-plan (←, /background, --bg) perdant une passerelle Vertex/Bedrock (ANTHROPIC_*_BASE_URL + CLAUDE_CODE_SKIP_*_AUTH) exportée dans le shell, donc chaque requête échouait
  • Correction de claude --bg --model fable sur les forfaits Max qui s'arrêtaient pour demander des crédits d'utilisation alors que la session interactive sur le même compte avait toujours l'allocation Fable
  • Correction de l'offre unique « faire du mode automatique votre mode par défaut » apparaissant dans les sessions sans surveillance (par exemple, les volets des coéquipiers de l'agent-équipe), où une pression parasite sur une touche pouvait l'accepter sans être lu.
  • Correction de l'invite d'approbation des paramètres gérés réapparaissant après une nouvelle connexion à la même passerelle d'applications Claude lorsque les paramètres sont inchangés
  • Correction des /bug et /share désactivés signalant que /feedback était désactivé ; les conseils, /help et les messages de refus ne suggèrent plus /feedback lorsqu'une stratégie d'organisation ou une variable d'environnement le désactive
  • Correction de la création d'une session cloud conseillant la configuration du GitHub après un échec transitoire de connexion au GitHub - le message indique désormais de réessayer à la place
  • Amélioration de l'utilisation du processeur pendant les tours dans les sessions interactives en supprimant les rendus redondants de l'interface utilisateur
  • Taille d'installation améliorée : le binaire natif est environ 5 Mo plus petit
  • Sessions cloud améliorées : lorsque le proxy réseau de la session abandonne une connexion lors d'une commande Bash, le résultat de l'outil nomme désormais l'hôte et la raison au lieu de simplement "réinitialisation de la connexion".
  • Amélioration de /schedule pour expliquer que les serveurs MCP configurés dans Claude Code ne peuvent pas être attachés aux routines cloud, au lieu d'un simple message "Pas de connecteurs MCP"
  • Cadrage amélioré des messages de vos propres sous-agents : Claude est informé que l'expéditeur est un travailleur à l'intérieur de cette session, et non une session Claude sans rapport.
  • Amélioration de l'espace réservé à l'invite pour lire "Message @name…" lors de l'affichage d'un sous-agent en arrière-plan ou d'une transcription fork ouverte à partir du panneau de sous-agent ou de /tasks.
  • Amélioration de la désinfection des noms de serveur MCP dans les messages d'erreur, les menus et les résultats de commandes
  • Amélioration du démarrage de la session Amazon Bedrock sous CLAUDE_CODE_PROVIDER_MANAGED_BY_HOST (par exemple Claude Desktop) : une session dotée d'un ID de modèle ou d'un ARN Bedrock n'attend plus la découverte du profil d'inférence
  • Amélioration de la boîte de dialogue d'approbation des paramètres gérés pour répertorier uniquement les paramètres modifiés depuis votre dernière approbation
  • Amélioration des nouvelles tentatives lorsque l'appel à l'outil du modèle est mal formé : la sortie interrompue est désormais supprimée du contexte de nouvelle tentative, y compris sur Bedrock, Vertex et Foundry.
  • Modification de /radio pour qu'il soit disponible sur Bedrock, Vertex AI, Foundry et Claude Platform sur AWS, et lorsque la télémétrie est désactivée
  • Modification de Claude dans Chrome afin que les actions du navigateur passent toujours par les contrôles d'autorisation de Claude Code, y compris dans les sessions avec télémétrie désactivée, qui utilisaient auparavant les propres invites de l'extension Chrome
  • Modification de CLAUDE_CODE_SUBAGENT_MODEL pour définir le modèle de sous-agent par défaut plutôt que de tout remplacer : le model: d'une définition d'agent et un modèle explicite par apparition ont désormais la priorité sur lui.
  • Modification de la bande-annonce de validation par défaut en Co-Authored-By: Claude Code lorsque le modèle actif n'est pas un modèle Claude reconnu (par exemple, modèles tiers derrière un ANTHROPIC_BASE_URL personnalisé)
  • Modification du modèle par défaut pour les abonnements Entreprise basés sur des sièges vers Opus 5, correspondant à d'autres forfaits premium
  • Modification de /effort pour enregistrer votre niveau d'effort par défaut par modèle, afin que chaque modèle conserve son propre paramètre lorsque vous changez
  • Modification des analyses pour qu'elles ne soient plus désactivées avant la connexion uniquement parce que les paramètres gérés forcent la connexion à la passerelle (ou ne peuvent pas être lus) ; ils restent désactivés une fois connectés à la passerelle ou via DISABLE_TELEMETRY
  • Modification du badge PR de pied de page sur Bedrock, Vertex et Foundry, et lorsque la télémétrie est désactivée, pour appeler directement le GitHub API (via gh auth token, GH_TOKEN ou GITHUB_TOKEN) au lieu de gh pr view
  • Modification de la façon dont les fichiers de sortie des commandes Bash sont créés et relus lorsque les commandes sont exécutées dans le bac à sable, afin qu'une commande en bac à sable ne puisse pas les rediriger ou les remplacer.
  • Modification des suggestions d'installation du plugin/LSP et de l'offre par défaut du mode automatique pour attendre que vous ayez envoyé ou effacé ce que vous tapez, afin que la touche Entrée qui envoie votre invite ne puisse pas y répondre.
  • Modification des paramètres gérés par le serveur qui mettent fin au sandbox TLS, acheminent le trafic du sandbox via votre propre proxy, injectent des informations d'identification ou affaiblissent l'isolation du sandbox pour exiger une approbation avant de s'appliquer.
  • Modification de ANTHROPIC_CUSTOM_HEADERS à partir des paramètres gérés ou du projet pour exiger une approbation lorsqu'il définit un en-tête d'informations d'identification, d'organisation/locataire, de routage ou de comportement API (par exemple, Authorization, Host)
  • Modification de .claude/settings.json env au niveau du projet pour ne plus définir CLAUDE_CONFIG_DIR, CLAUDE_CODE_TMPDIR ou TMPDIR/TMP/TEMP ; définissez-les plutôt dans votre shell, votre utilisateur ou vos paramètres gérés
  • Suppression de la coloration syntaxique pour six langages rarement utilisés (1c, gml, isbl, mathematica, maxima, sqf) ; le binaire est 2.5 Mo plus petit
  • [VSCode] Correction du bouton "Bedrock, Foundry ou Vertex" de l'écran de connexion ouvrant les documents en haut de la page au lieu de la section de configuration du fournisseur tiers
  • [VSCode] Modification de la bannière du contrôle à distance en une pilule de pied de page (affichée lorsque le contrôle à distance est activé ou en panne) qui ouvre la session sur claude.ai/code ; allumez-le ou éteignez-le avec /remote-control

claude-code v2.1.251

What's changed

  • Added PreModelSwitch and PostModelSwitch hook events (block, confirm, or annotate a model switch); SessionStart resume hooks now receive session staleness and the estimated re-cache cost
  • Added live streaming of a foreground subagent's tool calls and results to Remote Control clients (background subagents, the default, still show status only)
  • Added a Spend limit bar to /usage and a rate_limits.spend_limit status line field for developers behind a Claude apps gateway with spend limits
  • Added a per-session prompt-cache line to /cost (hit ratio, misses, tokens re-cached, warm/cold) and a matching prompt_cache object for status line scripts
  • Added attach, logs, stop, respawn, and rm to claude --help; the --resume message for a running background session now names the exact claude attach <id> command
  • Fixed file tools (Read, Write, Edit) following a symlink swapped inside the working directory after the permission check, which could read or write outside the approved location
  • Fixed plugin commands declared in a marketplace entry being able to point outside the plugin directory; such paths are now rejected with a path-traversal error
  • Fixed project settings being able to enable detailed beta tracing or raw API body logging, and a lower-scope beta tracing endpoint bypassing an OTLP collector pinned by managed settings or a host app
  • Fixed the Workflow tool reading (and quoting in errors) a scriptPath outside what the session may read before the permission check ran
  • Fixed Grep and Glob not applying Read(...) deny rules to files reached through a symlinked search path
  • Fixed conversations getting stuck on "text content blocks must be non-empty" errors after a turn where the model produced only thinking
  • Fixed the first launch on a fresh install starting in default mode instead of auto mode for accounts whose startup default is auto mode
  • Fixed Opus 5 requests failing with "effort … is not supported when thinking is disabled" when effort was xhigh/max and thinking was turned off; effort is now sent as high in that case
  • Fixed replying to a message Claude Desktop delivered from another session: SendMessage to that session id now delivers through Claude Desktop instead of failing with "not reachable"
  • Fixed TUI lag with many parallel subagents: per-second progress ticks now replace their predecessor instead of piling up in the transcript
  • Fixed agent teams: a teammate's final answer not reaching the team lead — it now arrives in the idle notification instead of a content-free "available" notice
  • Fixed background subagents being unable to reply to a message from an unnamed sibling or parent agent (from was the agent type, which is not an address)
  • Fixed managed-settings disableAutoMode arriving mid-session not moving an already-running auto-mode session back to default mode
  • Fixed a "switch to Opus 1M for 5x more context" tip that appeared even when the current Opus model already has a 1M context window
  • Fixed Claude apps gateway sessions treating a stored Anthropic profile (e.g. a Console sign-in) as active: listing it in /status and retrying gateway 401s with it, though requests never use it
  • Fixed cloud sessions telling Claude the model had changed when the host was only setting the session's initial model
  • Fixed Remote Control reporting a failure when an organization's policy disables it; it now shows a single quiet notice instead
  • Fixed /mcp reconnect on Remote Control showing a generic withheld-detail error instead of the real remedy when a server was disabled in another session
  • Fixed --input-format stream-json: client-injected assistant tool calls sent without a message id were merged into the first one and their results lost, including when resuming older sessions
  • Fixed session transcripts being silently overwritten when a directory change relocated a session onto an existing same-ID transcript
  • Fixed background sessions and their subagents being unable to edit files inside a git worktree they created with git worktree add
  • Fixed background sessions occasionally starting without any plugin skills (and staying that way) when another Claude Code process was refreshing the plugin marketplace at the same moment
  • Fixed selecting text in an opened background session inside tmux over SSH: it now copies to the tmux buffer like a foreground session instead of falling back to OSC 52
  • Fixed SDK and cloud sessions hanging indefinitely when an SDK MCP server's handshake acknowledgment was lost; the wait now times out after 70 seconds and marks only that server failed
  • Fixed self-hosted runner leaving a stuck session's Bash tool processes running after the session was force-stopped
  • Fixed /usage-credits for Team and Enterprise members whose admin set the org's usage-credit limit to $0: it now offers to ask the admin instead of saying a cap was reached
  • Fixed --worktree --tmux with a merge-request number on a gitlab.com origin trying a doomed GitHub-style fetch first instead of fetching the GitLab ref directly
  • Fixed Ctrl+G failing with "Emacs quit unexpectedly" in background sessions for editors that open /dev/tty, such as emacs -nw and micro
  • Fixed an additionalDirectories entry containing a null byte crashing startup, or breaking /add-dir and later settings updates when it came from an SDK host, IDE, or hook; it is now skipped
  • Fixed the MCP server menu's copy shortcut: it now says how the sign-in URL was copied instead of always claiming success
  • Fixed italic text (such as the session recap line) rendering as highlighted blocks in GNU screen and in tmux sessions using a screen terminal type
  • Fixed claude mcp add --header and claude mcp add-json help text naming the wrong transports
  • Fixed claude ultrareview and /ultrareview waiting the full 30 minutes when the cloud session fails to start; they now stop early and report the reason
  • Fixed Bash permission checks auto-approving commands that assign an arithmetic expression to an integer shell variable (e.g. OPTIND=1/0, RANDOM=2+2); these now prompt for approval
  • Fixed backgrounded sessions (←, /background, --bg) losing a Vertex/Bedrock gateway (ANTHROPIC_*_BASE_URL + CLAUDE_CODE_SKIP_*_AUTH) exported in the shell, so every request failed
  • Fixed claude --bg --model fable on Max plans stopping to ask for usage credits while the interactive session on the same account still had Fable allowance
  • Fixed the one-time "make auto mode your default" offer appearing in unattended sessions (e.g. agent-team teammate panes), where a stray keypress could accept it unread
  • Fixed the managed-settings approval prompt re-appearing after signing in again to the same Claude apps gateway when the settings are unchanged
  • Fixed disabled /bug and /share reporting that /feedback was disabled; tips, /help, and refusal messages no longer suggest /feedback when an org policy or env var turns it off
  • Fixed cloud session creation advising GitHub setup after a transient GitHub connection failure — the message now says to retry instead
  • Improved CPU usage during turns in interactive sessions by cutting redundant UI re-renders
  • Improved install size: the native binary is about 5 MB smaller
  • Improved cloud sessions: when the session's network proxy drops a connection during a Bash command, the tool result now names the host and reason instead of only "connection reset"
  • Improved /schedule to explain that MCP servers configured in Claude Code can't be attached to cloud routines, instead of a bare "No MCP connectors" message
  • Improved framing of messages from your own subagents: Claude is told the sender is a worker inside this session, not an unrelated Claude session
  • Improved the prompt placeholder to read "Message @name…" while viewing a background subagent or fork transcript opened from the subagent panel or /tasks
  • Improved sanitization of MCP server names in error messages, menus, and command results
  • Improved Amazon Bedrock session start under CLAUDE_CODE_PROVIDER_MANAGED_BY_HOST (e.g. Claude Desktop): a session given a Bedrock model ID or ARN no longer waits for inference-profile discovery
  • Improved the managed settings approval dialog to list only the settings that changed since you last approved them
  • Improved retry when the model's tool call is malformed: the broken output is now dropped from the retry context, including on Bedrock, Vertex, and Foundry
  • Changed /radio to be available on Bedrock, Vertex AI, Foundry, and Claude Platform on AWS, and when telemetry is disabled
  • Changed Claude in Chrome so browser actions always go through Claude Code's permission checks, including in sessions with telemetry disabled, which previously used the Chrome extension's own prompts
  • Changed CLAUDE_CODE_SUBAGENT_MODEL to set the default subagent model rather than override everything: an agent definition's model: and an explicit per-spawn model now take precedence over it
  • Changed the default commit trailer to Co-Authored-By: Claude Code when the active model isn't a recognized Claude model (e.g. third-party models behind a custom ANTHROPIC_BASE_URL)
  • Changed the default model for seat-based Enterprise subscriptions to Opus 5, matching other premium plans
  • Changed /effort to save your default effort level per model, so each model keeps its own setting when you switch
  • Changed analytics to no longer turn off before sign-in solely because managed settings force gateway login (or cannot be read); they stay off once signed in to the gateway or via DISABLE_TELEMETRY
  • Changed the footer PR badge on Bedrock, Vertex, and Foundry, and when telemetry is off, to call the GitHub API directly (via gh auth token, GH_TOKEN, or GITHUB_TOKEN) instead of gh pr view
  • Changed how Bash command output files are created and read back when commands run in the sandbox, so a sandboxed command cannot redirect or replace them
  • Changed plugin/LSP install suggestions and the auto-mode default offer to wait until you've sent or cleared what you're typing, so the Enter that sends your prompt can't answer them
  • Changed server-managed settings that terminate sandbox TLS, route sandbox traffic through your own proxy, inject credentials, or weaken sandbox isolation to require approval before they apply
  • Changed ANTHROPIC_CUSTOM_HEADERS from managed or project settings to require approval when it sets a credential, org/tenant, routing, or API-behavior header (e.g. Authorization, Host)
  • Changed project-level .claude/settings.json env to no longer set CLAUDE_CONFIG_DIR, CLAUDE_CODE_TMPDIR, or TMPDIR/TMP/TEMP; set them in your shell, user, or managed settings instead
  • Removed syntax highlighting for six rarely used languages (1c, gml, isbl, mathematica, maxima, sqf); the binary is 2.5 MB smaller
  • [VSCode] Fixed the sign-in screen's "Bedrock, Foundry, or Vertex" button opening the docs at the top of the page instead of the third-party provider setup section
  • [VSCode] Changed the Remote Control banner to a footer pill (shown while Remote Control is on or has failed) that opens the session on claude.ai/code; turn it on or off with /remote-control
