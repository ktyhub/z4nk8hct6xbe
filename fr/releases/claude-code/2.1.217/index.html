code-claude v2.1.217

Qu'est-ce qui a changé

  • Ajout de la saisie semi-automatique du shortcode emoji dans la saisie d'invite : tapez :heart: pour insérer ❤️, ou :hea pour les suggestions - désactivez-le avec le paramètre emojiCompletionEnabled
  • Ajout d'avertissements lorsque les écritures de transcription échouent (par exemple, disque plein) ou lorsque la sauvegarde de session est désactivée en raison d'une variable d'environnement héritée, au lieu de perdre les transcriptions silencieusement
  • Correction d'une fuite de mémoire où les sorties tronquées de l'outil MCP conservaient le résultat complet non tronqué en mémoire pour le reste de la session.
  • Correction des échecs de mise à jour automatique de Windows qui pouvaient laisser claude.exe manquant ; les mises à jour ayant échoué restaurent désormais automatiquement l'exécutable préservé
  • Correction de l'isolation des sessions en arrière-plan ne canonisant pas les répertoires de travail liés par des liens symboliques, ce qui pouvait permettre aux sessions d'échapper à leur dossier d'espace de travail
  • Correction du compactage automatique ne se déclenchant jamais pour Claude Opus 4.8 sur Bedrock et /compact échouant une fois au-delà de la limite
  • Correction des paramètres d'entreprise mTLS, TLS-verify, OAuth et proxy ignorés dans les sessions Claude Desktop
  • Correction de l'annonce de démarrage du mode lecteur d'écran étant coupée par le premier rendu d'invite, et la ligne d'état de réflexion étant restituée toutes les quelques secondes pour mettre à jour le temps écoulé et le nombre de jetons
  • Correction des paramètres gérés qui font que OTEL_EXPORTER_OTLP_ENDPOINT ne régit pas tous les signaux : les remplacements spécifiques aux signaux de portée inférieure ne redirigent plus la télémétrie loin du point de terminaison géré.
  • Correction de l'échec de --resume/--continue et /resume avec une TypeError lorsqu'une transcription a une entrée de pièce jointe mal formée
  • Correction des sessions de contrôle à distance n'affichant pas une invite d'autorisation ou une boîte de dialogue en attente aux téléspectateurs connectés après son apparition
  • Correction des shells en arrière-plan devenant parfois impossible à arrêter après qu'une session soit envoyée en arrière-plan (/background ou ←) ou lorsque la session se termine sur une machine très chargée, plus visible sous Windows
  • Correction d'une valeur de premier plan des chemins CLAUDE.md ou SKILL.md avec de nombreux groupes d'accolades tuant ou bloquant le CLI au démarrage - l'expansion des accolades est désormais limitée au budget
  • Correction de l'aperçu de la transcription aligné contre la zone de saisie lors de la connexion à une session en arrière-plan de démarrage ; il laisse désormais le même espace d'une ligne que la mise en page en direct, de sorte que la transcription ne change plus lorsque la session prend le relais
  • Amélioration des liens de badge PR de pied de page pour devenir des hyperliens clickables même lorsque la prise en charge du terminal ne peut pas être détectée (par exemple via ssh/tmux) ; configurer FORCE_HYPERLINK=0 pour se désinscrire
  • Modification de l'avertissement d'expiration de connexion pour qu'il apparaisse 3 jours avant l'expiration au lieu de 5.
  • Plafond de la suggestion de suggestion de plugin de conception frontale à 3 impressions à vie au lieu de répéter indéfiniment
  • Ajout d'un plafond pour les sous-agents exécutés simultanément (20 par défaut, remplacement par CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS) afin qu'un message ne puisse pas déployer des agents en arrière-plan illimités.
  • Modification des sous-agents pour ne plus générer de sous-agents imbriqués par défaut ; définissez CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH pour permettre une imbrication plus profonde
  • Correction de --max-budget-usd n'arrêtant pas les sous-agents en arrière-plan : une fois le plafond atteint, les nouvelles apparitions sont refusées et les agents en arrière-plan en cours d'exécution sont arrêtés.

claude-code v2.1.217

What's changed

  • Added emoji shortcode autocomplete in the prompt input: type :heart: to insert ❤️, or :hea for suggestions — disable with the emojiCompletionEnabled setting
  • Added warnings when transcript writes are failing (e.g. disk full) or when session saving is off due to an inherited environment variable, instead of losing transcripts silently
  • Fixed a memory leak where truncated MCP tool outputs kept the full untruncated result in memory for the rest of the session
  • Fixed Windows auto-update failures that could leave claude.exe missing; failed updates now restore the preserved executable automatically
  • Fixed background session isolation not canonicalizing symlinked working directories, which could let sessions escape their workspace folder
  • Fixed auto-compact never triggering for Claude Opus 4.8 on Bedrock and /compact failing once over the limit
  • Fixed corporate mTLS, TLS-verify, OAuth scope, and proxy settings being ignored in Claude Desktop sessions
  • Fixed screen reader mode's startup announcement being cut off by the first prompt render, and the thinking status row re-rendering every few seconds to update elapsed time and token counts
  • Fixed managed settings that set OTEL_EXPORTER_OTLP_ENDPOINT not governing all signals — lower-scope signal-specific overrides no longer redirect telemetry away from the managed endpoint
  • Fixed --resume/--continue and /resume failing with a TypeError when a transcript has a malformed attachment entry
  • Fixed Remote Control sessions not showing a pending permission prompt or dialog to viewers that connected after it appeared
  • Fixed background shells sometimes becoming impossible to stop after a session is sent to the background (/background or ←) or when the session exits on a heavily loaded machine, most visible on Windows
  • Fixed a CLAUDE.md or SKILL.md paths frontmatter value with many brace groups OOM-killing or stalling the CLI at startup — brace expansion is now budget-bounded
  • Fixed the transcript preview sitting flush against the input area when attaching to a starting background session; it now leaves the same one-line gap as the live layout, so the transcript no longer shifts when the session takes over
  • Improved footer PR badge links to be clickable hyperlinks even when terminal support can't be detected (e.g. over ssh/tmux); set FORCE_HYPERLINK=0 to opt out
  • Changed the login-expiry warning to appear 3 days before expiry instead of 5
  • Capped the frontend-design plugin suggestion tip at 3 lifetime impressions instead of repeating indefinitely
  • Added a cap on concurrently-running subagents (default 20, override with CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS) so one message can't fan out unbounded background agents
  • Changed subagents to no longer spawn nested subagents by default; set CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH to allow deeper nesting
  • Fixed --max-budget-usd not stopping background subagents: once the cap is reached, new spawns are denied and running background agents are halted
