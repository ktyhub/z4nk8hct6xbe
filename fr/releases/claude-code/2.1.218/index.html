code-claude v2.1.218

Qu'est-ce qui a changé

  • Modification de /code-review pour qu'il s'exécute en tant que sous-agent en arrière-plan, afin que le travail de révision ne remplisse plus votre conversation et conserve les commandes slash empilées comme cible de révision.
  • Ajout d'annonces de lecteur d'écran concernant le texte supprimé pour les suppressions de mots et de lignes (Option+Delete, Ctrl+W, Cmd+Backspace, Ctrl+U, Ctrl+K) en mode --ax-screen-reader
  • Correction des chemins Windows avec des segments préfixés par \u (comme C:\Users\unicorn) corrompus en caractères CJK dans les entrées de l'outil, ce qui rendait ces fichiers inaccessibles
  • Correction de la touche fléchée gauche annulant la conversation sans annulation : appuyer juste après l'édition demande maintenant de confirmer, et Esc dans la vue de l'agent revient à la conversation en arrière-plan
  • Ajout du statut HTTP et du texte d'erreur à claude mcp list et /mcp lorsqu'un serveur ne parvient pas à se connecter, ainsi qu'un avertissement pour les valeurs de configuration MCP avec des espaces de début ou de fin masqués.
  • Correction du collage multiligne se réduisant en une seule ligne avec j à la place des nouvelles lignes dans les terminaux qui codent les nouvelles lignes collées sous la forme Ctrl+J
  • Correction de /context signalant l'utilisation de jetons pré-compacts périmés après le compactage à partir du sélecteur de messages.
  • Correction de l'échec de /ultrareview sur les arguments descriptifs tels que "examiner mes modifications d'authentification" — ils exécutent désormais une révision de votre branche actuelle avec le texte appliqué comme note aux résultats.
  • Correction de /code-review ultra exécutant silencieusement une révision locale dans des sessions non interactives — il lance désormais la révision dans le cloud
  • Correction des dépenses de passerelle pour tarifer les ARN de profil d'inférence d'application Bedrock et d'autres ID de modèle en amont mappés par configuration aux tarifs du modèle configuré
  • Correction de Mojibake lorsqu'une longue sélection IDE était tronquée au milieu d'un emoji, et d'un cas où une erreur de l'exécuteur d'outil pouvait être supprimée silencieusement
  • Correction d'une course au démontage du moteur qui pouvait démarrer et abandonner un virage fantôme, et les entrées poussées après la fermeture étaient systématiquement rejetées.
  • Correction de faux messages "[Demande interrompue par l'utilisateur]" après des appels d'outil interrompus et d'un bloc tool_use non apparié laissé dans la transcription lorsqu'un outil abandonnait en cours de réponse
  • Correction de VoiceOver lisant "nouvelle ligne" au lieu de faire écho à l'espace tapé à la fin de l'entrée en mode --ax-screen-reader
  • Correction du plugin et des panneaux de paramètres ne déplaçant pas le curseur du terminal vers la ligne ciblée, afin que les lecteurs d'écran et les loupes puissent suivre la navigation par touches fléchées
  • Correction de crashs (pile d'appels maximale dépassée) lorsqu'une arborescence de répertoires surveillés profondément imbriquée était supprimée ou déplacée, et lors du rendu d'arborescences d'interface utilisateur profondément imbriquées
  • Correction des événements de demande d'extraction étant parfois perdus lorsqu'une session se terminait immédiatement après la création ou la liaison d'un PR
  • Correction de l'échec de la vérification du profil de l'assistant de configuration de Bedrock pour les profils assumant un rôle dans les régions AWS partitionnées et sur les réseaux proxy uniquement.
  • Correction de rares mesures de durée de tour négatives ou incorrectes après un réglage de l'horloge système en chronométrant les tours avec une horloge monotone
  • Correction de l'avis de démarrage « Les serveurs N MCP ont besoin d'une authentification » surcomptant les connecteurs claude.ai qui ne sont pas connectés dans claude.ai
  • Correction des entrées d'historique d'invite étant supprimées ou dupliquées lorsque les écritures de l'historique ont échoué ou échoué.
  • Correction d'une boucle de nouvelle tentative qui renvoyait des requêtes identiques vouées à l'échec après une erreur de débordement de contexte avec un budget de réflexion important ; L'arrière-plan Ctrl+B applique désormais les mêmes majuscules d'arrière-plan que les autres chemins
  • Correction des hooks de premier plan de l'agent s'exécutant à partir de dossiers untrust : les hooks nécessitent désormais que le propre dossier du fichier de l'agent ait accepté l'espace de travail trust
  • Correction de la perte de la lignée des sessions fork après le compactage dans les sessions sans tête et SDK
  • Correction d'une session reprise qui échouait à chaque tour, ou qui plantait à la reprise, lorsque son historique contenait une pièce jointe delta mal formée.
  • Amélioration du retour d'erreur /ultrareview afin que Claude puisse corriger un argument invalide au lieu de le réessayer inchangé
  • Mode automatique amélioré : les vérifications de chemin dangereux-rm, background-& et suspect-Windows-path n'ouvrent plus les boîtes de dialogue d'autorisation ; le classificateur en mode automatique les juge à la place
  • Amélioration des restrictions des commandes sandbox pour les interactions IDE
  • Boîtes de dialogue trust améliorées pour nommer la racine du référentiel couverte par la subvention
  • Modification de /deep-research pour qu'il démarre uniquement lorsqu'il est invoqué manuellement ; Claude ne le lance plus tout seul
  • Modification du mode plan avec auto pour ne plus demander de commandes Bash que l'analyseur statique ne peut pas prouver en lecture seule ; le classificateur en mode automatique les juge à la place
  • Ajout d'une annonce lorsque le mode rapide change suite au changement de modèle via /config model=<x> ou la télécommande
  • Modification des paramètres gérés par le serveur afin que les fonctionnalités et les coûts inoffensifs ne déclenchent plus l'invite d'approbation des paramètres.
  • Modification des fichiers de démarque d'agent pour rejeter les noms d'agent contenant :, qui est réservé à l'espace de noms des plugins.
  • Modification des compétences avec context: fork pour qu'elles s'exécutent en arrière-plan par défaut ; se désinscrire par compétence avec background: false
  • Ajout de yes/no/on/off/1/0 (insensible à la casse) comme valeurs acceptées pour les booléens de compétence et de plugin, aux côtés de true/false
  • Correction des sessions à distance qui continuaient à envoyer des battements de cœur après le remplacement de leur travailleur, ce qui laissait les processus de bureau et IDE de longue durée réessayer une demande rejetée toutes les quelques secondes pour toujours

claude-code v2.1.218

What's changed

  • Changed /code-review to run as a background subagent, so review work no longer fills your conversation and keeps stacked slash commands as its review target
  • Added screen-reader announcements of deleted text for word and line deletions (Option+Delete, Ctrl+W, Cmd+Backspace, Ctrl+U, Ctrl+K) in --ax-screen-reader mode
  • Fixed Windows paths with \u-prefixed segments (like C:\Users\unicorn) being corrupted into CJK characters in tool inputs, which made those files inaccessible
  • Fixed the left arrow key discarding the conversation with no undo: presses right after editing now ask to confirm, and Esc in the agent view returns to the conversation it backgrounded
  • Added HTTP status and error text to claude mcp list and /mcp when a server fails to connect, and a warning for MCP config values with hidden leading or trailing whitespace
  • Fixed multi-line paste collapsing into one line with j in place of newlines in terminals that encode pasted newlines as Ctrl+J
  • Fixed /context reporting stale pre-compact token usage after compacting from the message picker
  • Fixed /ultrareview failing on descriptive arguments like "review my auth changes" — they now run a review of your current branch with the text applied as a note to the findings
  • Fixed /code-review ultra silently running a local review in non-interactive sessions — it now launches the cloud review
  • Fixed gateway spend metering to price Bedrock application-inference-profile ARNs and other config-mapped upstream model IDs at the configured model's rates
  • Fixed mojibake when a long IDE selection was truncated mid-emoji, and a case where a tool executor error could be silently dropped
  • Fixed an engine teardown race that could start and abandon a phantom turn, and made input pushed after close consistently rejected
  • Fixed spurious "[Request interrupted by user]" messages after interrupted tool calls, and an unpaired tool_use block left in the transcript when a tool aborted mid-response
  • Fixed VoiceOver reading "new line" instead of echoing the typed space at the end of the input in --ax-screen-reader mode
  • Fixed plugin and settings panels not moving the terminal cursor to the focused row, so screen readers and magnifiers can follow arrow-key navigation
  • Fixed crashes (maximum call stack exceeded) when a deeply nested watched directory tree was deleted or moved, and when rendering deeply nested UI trees
  • Fixed pull request events occasionally being lost when a session exited immediately after creating or linking a PR
  • Fixed the Bedrock setup wizard failing profile verification for assume-role profiles in partitioned AWS regions and on proxy-only networks
  • Fixed rare negative or incorrect turn duration measurements after a system clock adjustment by timing turns with a monotonic clock
  • Fixed the "N MCP servers need authentication" startup notice over-counting claude.ai connectors that aren't connected in claude.ai
  • Fixed prompt history entries being dropped or duplicated when history writes raced or failed
  • Fixed a retry loop that re-sent identical doomed requests after a context-overflow error with a large thinking budget; Ctrl+B backgrounding now applies the same background-shell caps as other paths
  • Fixed agent frontmatter hooks running from untrusted folders: hooks now require the agent file's own folder to have accepted workspace trust
  • Fixed fork-session lineage being lost after compaction in headless and SDK sessions
  • Fixed a resumed session failing every turn, or crashing on resume, when its history held a malformed delta attachment
  • Improved /ultrareview error feedback so Claude can correct an invalid argument instead of retrying it unchanged
  • Improved auto mode: the dangerous-rm, background-&, and suspicious-Windows-path checks no longer open permission dialogs; the auto-mode classifier adjudicates them instead
  • Improved sandbox command restrictions for IDE interactions
  • Improved trust dialogs to name the repository root the grant covers
  • Changed /deep-research to start only when invoked manually; Claude no longer launches it on its own
  • Changed plan mode with auto to no longer prompt for Bash commands the static analyzer can't prove read-only; the auto-mode classifier judges them instead
  • Added an announcement when fast mode changes as a result of switching models via /config model=<x> or Remote Control
  • Changed server-managed settings so benign feature and cost toggles no longer trigger the settings-approval prompt
  • Changed agent markdown files to reject agent names containing :, which is reserved for plugin namespacing
  • Changed skills with context: fork to run in the background by default; opt out per skill with background: false
  • Added yes/no/on/off/1/0 (case-insensitive) as accepted values for skill and plugin frontmatter booleans, alongside true/false
  • Fixed remote sessions continuing to send heartbeats after their worker was replaced, which left long-lived desktop and IDE processes retrying a rejected request every few seconds forever
