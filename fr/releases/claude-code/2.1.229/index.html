claude-code v2.1.229

code-claude v2.1.229

Qu'est-ce qui a changé

  • claude remote-control --continue documenté pour reprendre la session de contrôle à distance la plus récente
  • Ajout de la prise en charge du hook Claude Code fourni par le serveur pour les sessions d'exécution auto-hébergées, correspondant au comportement de l'environnement géré
  • Ajout de pings keepalive SSE aux réponses de streaming de la passerelle pendant de longues pauses de réflexion, empêchant les déconnexions d'inactivité sur les amonts de Vertex et Bedrock
  • Ajout des sources command du marché des plugins : une commande locale (par exemple un IDE) imprime le répertoire du plugin, qui est re-résolu à chaque session et appliqué sans redémarrage ; mode: "link" l'utilise sur place
  • ListAgents marque désormais les sessions de contrôle à distance déconnectées comme offline et étiquette vos sessions cloud comme cloud
  • Correction des réponses longues disparaissant partiellement lors du streaming et étant imprimées deux fois dans le terminal
  • Correction d'un crash de l'écran d'erreur (y compris sur --resume de la session affectée) lorsqu'un appel d'outil avait une valeur glob, file_path ou command autre qu'une chaîne.
  • Correction d'un crash de RangeError lorsqu'une barre de progression ou un tableau de démarques s'affichait dans une fenêtre de terminal très étroite (pouvait également planter claude --continue/--resume au démarrage)
  • Correction d'un crash sous Windows lorsqu'un appel d'outil ou un message faisait référence à un fichier par un chemin de longueur étendue (\\?\) ou UNC
  • Correction du mode automatique échouant à chaque appel d'outil pour les utilisateurs qui désactivent l'en-tête d'attribution via CLAUDE_CODE_ATTRIBUTION_HEADER (connexions directes Anthropic API)
  • Correction de /model rejetant Sonnet/Opus 1M pour les abonnés claude.ai utilisant une passerelle ANTHROPIC_BASE_URL personnalisée
  • Correction de MCP OAuth avec des serveurs d'autorisation strictes en utilisant 127.0.0.1 au lieu de localhost dans l'URI de redirection
  • Correction de la télécommande clients affichant une roulette de travail bloquée après une commande slash tapée dans le terminal de l'ordinateur portable
  • Correction du workflow Claude Code Review généré par /install-github-app se terminant sans publier sa révision sur la pull request
  • Correction de blocages de l'interface utilisateur de plusieurs secondes après la modification d'un fichier contenant des milliers de diagnostics IDE alors que l'extension IDE est connectée
  • Correction des commandes uniques claude plugin laissant un fichier d'activité parasite qui pourrait empêcher le nettoyage des versions de plugin obsolètes
  • Correction des flux de travail dynamiques dans les conteneurs limités en CPU en utilisant le nombre de cœurs de la machine hôte au lieu de la limite de CPU du conteneur
  • Correction d'une fuite de gestion de l'observateur de fichiers après le remplacement de fichiers atomiques et d'une erreur non détectée sous Windows lorsque l'observateur de tâches planifiées échouait sur un réseau ou un système de fichiers virtuel.
  • Correction des sessions SDK et --input-format stream-json obtenant une erreur 400 API lorsqu'un message contenant uniquement des espaces était soumis
  • Correction des conversations dont les messages à eux seuls dépassent la limite de requêtes de 32 Mo du API en réessayant le compactage lorsqu'aucune image ou document ne peut être supprimé ; ils échouent maintenant une fois avec un message clair
  • Correction de l'exportation OpenTelemetry des sessions Claude Desktop rejetée par la passerelle gérée par Desktop lorsque cette passerelle est également le point de terminaison de télémétrie.
  • Correction du programme d'exécution auto-hébergé et d'autres sessions à distance se terminant au démarrage lorsque managed-mcp.json est déployé et que le serveur fournit des serveurs MCP ; ces serveurs sont désormais ignorés avec un avertissement
  • Correction de la préparation du référentiel d'exécution auto-hébergé bloquée par une invite Git Credential Manager ; git échoue désormais rapidement lorsque les informations d'identification sont manquantes
  • Amélioration de la diffusion du flux de travail pour échelonner les agents frères et sœurs de même préfixe afin que les agents suivants lisent le préfixe d'invite mis en cache au lieu de le repayer (CLAUDE_CODE_WORKFLOW_PREFIX_STAGGER_MS=0 est désactivé)
  • Amélioration des erreurs « l'invite est trop longue » pour expliquer pourquoi le compactage automatique n'a pas pu récupérer au lieu de simplement suggérer /compact
  • Bac à sable amélioré : les littéraux IPv6 dans les listes de domaines réseau sont désormais entre crochets ([::1]:443) et les orthographes ambiguës sont appliquées et signalées par /doctor.
  • Mise à jour de /login pour répéter l'avertissement de remplacement de CLAUDE_CODE_OAUTH_TOKEN après une connexion réussie
  • Modification de /commit-push-pr afin que les commandes git/gh avec des indicateurs dangereux (--force, --amend, --no-verify, etc.) ne soient plus automatiquement approuvées
  • Modification du démarrage de Windows du programme d'exécution auto-hébergé pour exiger un --base-dir explicite ; il n'y a pas de répertoire de paiement par défaut sous Windows
  • [VSCode] "Signaler un problème" et /bug ouvrent désormais la boîte de dialogue de commentaires intégrée au lieu d'un lien d'enquête retiré.
  • [VSCode] Redimensionnement du panneau de questions secondaires /btw en faisant glisser sa limite, dans les mises en page latérales et empilées.
  • [VSCode] Ajout de groupes de sessions dans la barre latérale — droit-click pour créer, renommer ou supprimer ; Cmd/Ctrl- ou Shift-click pour déplacer plusieurs sessions à la fois

claude-code v2.1.229

What's changed

  • Documented claude remote-control --continue for resuming the most recent Remote Control session
  • Added server-supplied Claude Code hook support for self-hosted runner sessions, matching managed-environment behavior
  • Added SSE keepalive pings to gateway streaming responses during long thinking pauses, preventing idle-timeout disconnects on Vertex and Bedrock upstreams
  • Added plugin marketplace command sources: a local command (e.g. an IDE) prints the plugin directory, which is re-resolved each session and applied without a restart; mode: "link" uses it in place
  • ListAgents now marks disconnected Remote Control sessions as offline and labels your cloud sessions as cloud
  • Fixed long responses partly disappearing while streaming and being printed twice in the terminal
  • Fixed a crash to the error screen (including on --resume of the affected session) when a tool call had a non-string glob, file_path, or command value
  • Fixed a RangeError crash when a progress bar or markdown table rendered in a very narrow terminal window (could also crash claude --continue/--resume at startup)
  • Fixed a crash on Windows when a tool call or message referenced a file by an extended-length (\\?\) or UNC path
  • Fixed auto mode failing on every tool call for users who disable the attribution header via CLAUDE_CODE_ATTRIBUTION_HEADER (direct Anthropic API connections)
  • Fixed /model rejecting Sonnet/Opus 1M for claude.ai subscribers using a custom ANTHROPIC_BASE_URL gateway
  • Fixed MCP OAuth with strict authorization servers by using 127.0.0.1 instead of localhost in the redirect URI
  • Fixed Remote Control clients showing a stuck working spinner after a slash command typed in the laptop terminal
  • Fixed the Claude Code Review workflow generated by /install-github-app completing without posting its review on the pull request
  • Fixed multi-second UI stalls after editing a file with thousands of IDE diagnostics while the IDE extension is connected
  • Fixed one-shot claude plugin commands leaving a stray liveness file that could prevent cleanup of outdated plugin versions
  • Fixed dynamic workflows inside CPU-limited containers using the host machine's core count instead of the container's CPU limit
  • Fixed a file-watcher handle leak after atomic file replacements, and an uncaught error on Windows when the scheduled-tasks watcher failed on a network or virtual filesystem
  • Fixed SDK and --input-format stream-json sessions getting a 400 API error when a whitespace-only message was submitted
  • Fixed conversations whose messages alone exceed the API's 32 MB request limit retrying compaction when no images or documents can be stripped; they now fail once with a clear message
  • Fixed OpenTelemetry export from Claude Desktop sessions being rejected by the Desktop-managed gateway when that gateway is also the telemetry endpoint
  • Fixed self-hosted runner and other remote sessions exiting at startup when managed-mcp.json is deployed and the server delivers MCP servers; those servers are now skipped with a warning
  • Fixed self-hosted runner repository preparation hanging on a Git Credential Manager prompt; git now fails fast when credentials are missing
  • Improved workflow fan-outs to stagger same-prefix sibling agents so subsequent agents read the cached prompt prefix instead of re-paying it (CLAUDE_CODE_WORKFLOW_PREFIX_STAGGER_MS=0 disables)
  • Improved "prompt is too long" errors to explain why automatic compaction could not recover instead of only suggesting /compact
  • Improved sandbox: IPv6 literals in network domain lists are now bracketed ([::1]:443), and ambiguous spellings are enforced fail-closed and flagged by /doctor
  • Updated /login to repeat the CLAUDE_CODE_OAUTH_TOKEN override warning after a successful login
  • Changed /commit-push-pr so git/gh commands with dangerous flags (--force, --amend, --no-verify, etc.) are no longer auto-approved
  • Changed self-hosted runner Windows startup to require an explicit --base-dir; there is no default checkout directory on Windows
  • [VSCode] "Report a problem" and /bug now open the built-in feedback dialog instead of a retired survey link
  • [VSCode] Made the /btw side-question panel resizable by dragging its boundary, in both side-docked and stacked layouts
  • [VSCode] Added session groups in the sidebar — right-click to create, rename, or delete; Cmd/Ctrl- or Shift-click to move several sessions at once
