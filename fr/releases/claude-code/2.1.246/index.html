claude-code v2.1.246

code-claude v2.1.246

Qu'est-ce qui a changé

  • Ajout d'un avertissement de démarrage pour les règles d'autorisation Bash avec un caractère générique avant la sous-commande (par exemple Bash(git * main)), car elles correspondent également aux options insérées avant la sous-commande.
  • Ajout d'un onglet de mode automatique à /permissions pour afficher et modifier les règles du classificateur en mode automatique
  • Ajout de l'heure d'achèvement du tour à la ligne de durée de fin de tour, par ex. ✻ Sautéed for 23s · done 6:05 PM
  • Correction du mode plein écran affichant une transcription vierge après avoir redimensionné le terminal et sauté vers le bas jusqu'à la prochaine pression sur une touche
  • Correction d'un ralentissement important de la transcription lorsqu'un diff contenait une très longue ligne (par exemple une chaîne base64) ; ces lignes sont désormais tronquées avec un marqueur
  • Correction du défilement erratique en plein écran lorsqu'il est positionné sur un message précédent, y compris le saut vers le bas restant bloqué au milieu de la transcription
  • Correction des sessions en arrière-plan qui ne s'ouvraient pas après 45 secondes lorsque le répertoire de démarrage de Claude Code avait été supprimé, que la machine était en veille ou que l'hôte était lent à démarrer les processus.
  • Correction de l'échec de l'ouverture des sessions en arrière-plan avec "Impossible de démarrer le service en arrière-plan… EACCES" lorsqu'un autre processus Claude Code réinstallait le package npm à ce moment-là
  • Correction du rendu des démarques étant désactivé pour un message entier lorsque ses 500 premiers caractères ne contenaient aucune démarque, et pour les listes +/N) et les en-têtes de texte
  • Correction des appels à l'outil MCP interrompus par un message entrant dans les sessions sans tête/à distance étant signalés au modèle comme "terminés sans sortie" au lieu d'une erreur interrompue explicite
  • Correction des arguments de l'outil MCP envoyés sous forme de chaînes JSON lorsque le schéma du paramètre est vide ({}), au lieu de leur type réel
  • Correction d'une commande interrompue en cours d'exécution, affichant "Commande shell Ran 1" sans aucun signe qu'elle a été coupée.
  • Correction de l'appui sur ← ou de l'exécution de /background pendant un flux de travail dynamique redémarrant ses sous-agents terminés ; il demande maintenant en premier et indique combien de sous-agents redémarreraient
  • Correction de l'ouverture d'une session qui vient de démarrer dans claude agents alors que son travailleur était encore en train de démarrer (courant sous Windows), en l'arrêtant avec "a été arrêté alors que la réapparition était en vol".
  • Correction de claude agents répertoriant deux fois une session nommée en arrière-plan ; la mise en arrière-plan de la même conversation numérote désormais la nouvelle ligne (par exemple my-session (2))
  • Correction du balayage de rétention en arrière-plan supprimant les arbres de travail git sous .claude/worktrees/ que vous avez créés vous-même lorsqu'un ancien enregistrement de session en arrière-plan les pointait
  • Correction des appels d'outils en mode automatique refusés comme "temporairement indisponibles" sur de très grandes sessions en augmentant le délai de contrôle de sécurité avec la taille de l'invite
  • Correction du cache du plugin créant des répertoires en double nommés SHA pour le même plugin
  • Correction des compétences du plugin dont le frontmatter name inclut déjà le préfixe <plugin>: le montrant doublé dans le menu slash (par exemple /plugin:plugin:skill)
  • Correction de l'échec de claude plugin update pour un plugin installé étant donné son nom brut (seul le nom complet fonctionnait)
  • Correction de l'échec de l'installation du plugin lorsque plugin.json était enregistré avec une marque d'ordre d'octet (BOM) UTF-8
  • Correction de /reload-plugins signalant 0 compétence pour les plugins qui définissent des compétences sous skills/*/SKILL.md
  • Correction des messages d'erreur de hook affichant un ${CLAUDE_PLUGIN_ROOT} littéral au lieu du chemin du plugin résolu
  • Correction de /rename remplaçant la couleur de bordure d'invite du thème (y compris le promptBorder d'un thème personnalisé) par le cyan par défaut ; la bordure conserve désormais la couleur de votre thème sauf si vous en choisissez une avec /color
  • Correction des couleurs de différences de thème personnalisé (diffAdded/diffRemoved et leurs variantes grisées) étant ignorées dans les différences et l'aperçu /theme
  • Correction d'une liaison keybindings.json avec un nom d'action inconnu, amortissant silencieusement cette clé ; il est maintenant ignoré afin que la liaison par défaut continue de fonctionner et qu'un avertissement soit enregistré sous --debug
  • Correction de la carte thermique d'activité /stats affichant l'activité de chaque jour à une cellule (le décompte du dimanche sous le lundi) dans les fuseaux horaires à l'est de UTC
  • Correction de /fork à partir d'une session déjà bifurquée ou en arrière-plan démarrant la nouvelle session avec une conversation vide
  • Correction des invites commençant par /-- (par exemple, commentaires Lean doc) étant rejetées comme commande slash inconnue au lieu d'être envoyées à Claude
  • Correction du sélecteur de fichiers @ restant ouvert après que le texte tapé ne corresponde plus à un chemin réel
  • Correction du coût et de la durée de la ligne d'état réinitialisés à zéro après avoir accédé à la vue des agents et inversement
  • Correction du mode plein écran déplaçant le focus du clavier sur le contrôle sous le pointeur lorsque vous clickez la fenêtre du terminal uniquement pour la remettre au point
  • Correction de l'échec de l'achèvement du chemin lorsque le jeton d'achèvement ou le répertoire de travail contenait un octet nul
  • Windows/macOS : correction des sessions sans tête ne nettoyant pas les entrées obsolètes dans ~/.claude/sessions laissées par les sessions qui se sont terminées de manière sale
  • Correction de l'arrêt de l'interface utilisateur avec une erreur de rendu lors du premier appel d'outil lorsqu'un point de terminaison tiers compatible Anthropic (ANTHROPIC_BASE_URL) diffuse un bloc tool_use sans id.
  • Correction de l'outil d'écriture signalant "Mémoire insuffisante" ou se figeant pendant une longue période après avoir écrasé un très gros fichier existant, même si le fichier avait été écrit
  • Correction de claude plugin install <name> quittant silencieusement (ou suspendu dans un terminal) au lieu de signaler une erreur lorsque ~/.claude/plugins/known_marketplaces.json est vide ou corrompu
  • Correction des sessions reprises échouant à chaque tour avec un 400 lorsque l'historique enregistré contient des blocs d'outils que l'Anthropic API n'accepte pas (généralement écrits par un proxy tiers API)
  • Correction de l'échec de curl -fsSL https://claude.ai/install.sh | bash avec "Le mode brut n'est pas pris en charge" pour certains utilisateurs Team/Enterprise avec des paramètres gérés par le serveur.
  • Correction des sessions qui se terminaient en mode plan et reprenaient en dehors du mode plan dans l'extension VS Code et dans claude -p --continue/--resume avec un outil d'invite d'autorisation, lorsqu'aucun mode d'autorisation n'était défini
  • Correction du hook Notification qui ne se déclenchait pas pendant que l'invite d'autorisation du bac à sable "Demande réseau en dehors du bac à sable" était en attente.
  • Correction des contrôles d'autorisation Bash pour toujours exiger l'approbation des commandes mal formées avec un opérateur && ou || pendant
  • Correction des sessions --strict-mcp-config invitant à approuver les serveurs .mcp.json qu'elles ne chargeraient jamais, ce qui laissait les sessions en arrière-plan en attente au démarrage
  • Correction des requêtes de télémétrie et de métriques vers Anthropic portant la clé API configurée pour une passerelle tierce (ANTHROPIC_BASE_URL) ; un identifiant n'est désormais envoyé qu'à son propre hôte
  • Correction d'une erreur API visible à la première invite après une inactivité lorsque apiKeyHelper renvoie des JWT de courte durée : un jeton mis en cache expiré est désormais actualisé avant l'envoi, et les erreurs d'authentification 401/403 réessayent silencieusement
  • Correction de l'augmentation de la mémoire avec la durée de la session dans les vues de transcription plein écran et Ctrl+O : chaque ligne de message rendue ne conserve plus une copie complète des recherches d'outils à l'échelle de la transcription.
  • Correction des exécutions /ultrareview et des sessions cloud lancées en même temps à partir d'un référentiel (par exemple à partir de plusieurs arbres de travail) commençant parfois par les modifications non validées d'un autre lancement
  • Correction du nombre de progression des tâches (par exemple 3/5) affiché pour les sessions cloud en arrière-plan telles que /autofix-pr manquant occasionnellement une tâche
  • Correction des sessions de contrôle à distance conservant leur nom d'espace réservé dans claude.ai et l'application Claude jusqu'à la deuxième invite ; le titre généré automatiquement apparaît désormais après la première invite
  • Correction des outils MCP marqués requiresUserInteraction proposant toujours "Oui, et ne demandez plus" dans leur invite d'autorisation ; l'option a écrit une règle d'autorisation, l'outil a ensuite ignoré
  • Correction du runner auto-hébergé mettant fin à ses sessions en direct ou quittant lorsqu'une réponse à un sondage de travail est mal formée (par exemple, la page HTML d'un proxy interceptant) ; il relance maintenant le sondage
  • /cd amélioré : les paramètres de projet, les hooks, les serveurs .mcp.json (derrière l'invite d'approbation habituelle), les compétences et les agents du nouveau répertoire prennent désormais effet juste après le déplacement au lieu de sur --resume
  • Amélioration de la latence de l'outil Bash sur les shells bash en rejouant les fonctions d'instantané sans sous-shell base64 par fonction
  • Résultats de sous-agent améliorés : un sous-agent qui s'arrête à sa limite maxTurns renvoie désormais sa sortie marquée comme partielle, avec une suggestion pour la continuer via SendMessage, au lieu d'apparaître terminé
  • Sessions non interactives améliorées (-p, SDK, sessions cloud) pour poursuivre automatiquement une réponse interrompue en cours de flux par une erreur de serveur, une perte de connexion ou un blocage au lieu de se terminer par une erreur
  • Amélioration de l'attribution de la télémétrie d'utilisation à votre organisation pour les sessions de fédération d'identité de charge de travail, les événements envoyés pendant l'exécution de apiKeyHelper au démarrage et après l'expiration d'un jeton de connexion en cas d'inactivité.
  • Modification de /code-review pour que Claude puisse également le démarrer seul sur Bedrock, Vertex AI et Foundry, via la passerelle des applications Claude, et lorsque la télémétrie ou le trafic non essentiel est désactivé
  • /goal : modification des sessions inactives pour démarrer au maximum trois enregistrements sur un travail en arrière-plan de longue durée par objectif ; votre prochain message en autorise trois autres
  • Modification de claude install et claude update pour reporter une invite de consentement en attente de paramètres gérés à la prochaine session interactive au lieu de demander une invite à mi-commande.
  • Modification des événements du plugin OpenTelemetry pour les plugins synchronisés depuis claude.ai : plugin_id_hash reflète désormais le véritable marché du plugin, et enabled_via est admin-install pour les plugins installés par l'administrateur
  • Correction de la configuration du système de fichiers du bac à sable de commande ne respectant pas --setting-sources

Anglais original / English original

claude-code v2.1.246

What's changed

  • Added a startup warning for Bash allow rules with a wildcard before the subcommand (e.g. Bash(git * main)), since they also match options inserted before the subcommand
  • Added an Auto mode tab to /permissions for viewing and editing auto mode classifier rules
  • Added the turn's completion time to the end-of-turn duration line, e.g. ✻ Sautéed for 23s · done 6:05 PM
  • Fixed fullscreen mode showing a blank transcript after resizing the terminal and jumping to the bottom until the next keypress
  • Fixed a severe transcript slowdown when a diff contained a very long single line (e.g. a base64 string); such lines now render truncated with a marker
  • Fixed erratic fullscreen scrolling when positioned at an earlier message, including jump-to-bottom getting stuck mid-transcript
  • Fixed background sessions failing to open after 45 seconds when Claude Code's starting directory had been deleted, the machine had slept, or the host is slow to start processes
  • Fixed background sessions failing to open with "Couldn't start the background service … EACCES" when another Claude Code process was re-installing the npm package at that moment
  • Fixed markdown rendering being disabled for a whole message when its first 500 characters contained no markdown, and for +/N) lists and setext headings
  • Fixed MCP tool calls interrupted by an incoming message in headless/remote sessions being reported to the model as "completed with no output" instead of an explicit interrupted error
  • Fixed MCP tool arguments being sent as JSON strings when the parameter's schema is empty ({}), instead of their real type
  • Fixed a command interrupted mid-run showing as "Ran 1 shell command" with no sign it was cut
  • Fixed pressing ← or running /background during a dynamic workflow restarting its finished subagents; it now asks first and says how many subagents would restart
  • Fixed opening a just-started session in claude agents while its worker was still booting (common on Windows) stopping it with "was stopped while the respawn was in flight"
  • Fixed claude agents listing a backgrounded named session twice; backgrounding the same conversation again now numbers the new row (e.g. my-session (2))
  • Fixed the background retention sweep removing git worktrees under .claude/worktrees/ that you created yourself when an old background-session record pointed at them
  • Fixed auto mode tool calls being denied as "temporarily unavailable" on very large sessions by scaling the safety-check deadline with prompt size
  • Fixed the plugin cache creating duplicate SHA-named directories for the same plugin
  • Fixed plugin skills whose frontmatter name already includes the <plugin>: prefix showing it doubled in the slash menu (e.g. /plugin:plugin:skill)
  • Fixed claude plugin update failing for an installed plugin given its bare name (only the fully-qualified name worked)
  • Fixed plugin installation failing when plugin.json was saved with a UTF-8 byte-order mark (BOM)
  • Fixed /reload-plugins reporting 0 skills for plugins that define skills under skills/*/SKILL.md
  • Fixed hook error messages showing a literal ${CLAUDE_PLUGIN_ROOT} instead of the resolved plugin path
  • Fixed /rename replacing the theme's prompt border color (including a custom theme's promptBorder) with the default cyan; the border now keeps your theme's color unless you pick one with /color
  • Fixed custom theme diff colors (diffAdded/diffRemoved and their dimmed variants) being ignored in diffs and the /theme preview
  • Fixed a keybindings.json binding with an unknown action name silently deadening that key; it is now skipped so the default binding keeps working, and a warning is logged under --debug
  • Fixed /stats activity heatmap showing each day's activity one cell off (Sunday's count under Monday) in timezones east of UTC
  • Fixed /fork from an already-forked or backgrounded session starting the new session with an empty conversation
  • Fixed prompts beginning with /-- (e.g. Lean doc comments) being rejected as an unknown slash command instead of being sent to Claude
  • Fixed the @ file picker staying open after the typed text stopped matching a real path
  • Fixed the status line's cost and duration resetting to zero after navigating to the agents view and back
  • Fixed fullscreen mode moving keyboard focus onto the control under the pointer when you clicked the terminal window only to bring it back into focus
  • Fixed path completion failing when the completion token or working directory contained a null byte
  • Windows/macOS: Fixed headless sessions not cleaning up stale entries in ~/.claude/sessions left by sessions that exited uncleanly
  • Fixed the UI stopping with a render error on the first tool call when a third-party Anthropic-compatible endpoint (ANTHROPIC_BASE_URL) streams a tool_use block without an id
  • Fixed the Write tool reporting "Out of memory" or freezing for a long time after overwriting a very large existing file, even though the file had been written
  • Fixed claude plugin install <name> exiting silently (or hanging in a terminal) instead of reporting an error when ~/.claude/plugins/known_marketplaces.json is empty or corrupted
  • Fixed resumed sessions failing every turn with a 400 when the saved history contains tool blocks the Anthropic API does not accept (typically written by a third-party API proxy)
  • Fixed curl -fsSL https://claude.ai/install.sh | bash failing with "Raw mode is not supported" for some Team/Enterprise users with server-managed settings
  • Fixed sessions that ended in plan mode resuming outside plan mode in the VS Code extension, and in claude -p --continue/--resume with a permission prompt tool, when no permission mode was set
  • Fixed the Notification hook not firing while the sandbox "Network request outside of sandbox" permission prompt is waiting
  • Fixed Bash permission checks to always require approval for malformed commands with a dangling && or || operator
  • Fixed --strict-mcp-config sessions prompting to approve .mcp.json servers they would never load, which left background sessions waiting at startup
  • Fixed telemetry and metrics requests to Anthropic carrying the API key configured for a third-party gateway (ANTHROPIC_BASE_URL); a credential is now only sent to its own host
  • Fixed a visible API error on the first prompt after idle when apiKeyHelper returns short-lived JWTs: an expired cached token is now refreshed before sending, and 401/403 auth errors retry quietly
  • Fixed memory growing with session length in the fullscreen and Ctrl+O transcript views: each rendered message row no longer retains a full copy of the transcript-wide tool lookups
  • Fixed /ultrareview runs and cloud sessions launched at the same time from one repository (e.g. from several worktrees) sometimes starting with another launch's uncommitted changes
  • Fixed the task progress count (e.g. 3/5) shown for background cloud sessions such as /autofix-pr occasionally missing a task
  • Fixed Remote Control sessions keeping their placeholder name in claude.ai and the Claude app until the second prompt; the auto-generated title now appears after the first prompt
  • Fixed MCP tools marked requiresUserInteraction still offering "Yes, and don't ask again" in their permission prompt; the option wrote an allow rule the tool then ignored
  • Fixed the self-hosted runner ending its live sessions or exiting when a work-poll response is malformed (e.g. an intercepting proxy's HTML page); it now retries the poll
  • Improved /cd: the new directory's project settings, hooks, .mcp.json servers (behind the usual approval prompt), skills, and agents now take effect right after the move instead of on --resume
  • Improved Bash tool latency on bash shells by replaying snapshot functions without a base64 subshell per function
  • Improved subagent results: a subagent that stops at its maxTurns limit now returns its output marked as partial, with a hint to continue it via SendMessage, instead of appearing finished
  • Improved non-interactive sessions (-p, SDK, cloud sessions) to automatically continue a response cut off mid-stream by a server error, connection loss, or stall instead of ending with an error
  • Improved attribution of usage telemetry to your organization for workload identity federation sessions, events sent while apiKeyHelper runs at startup, and after a login token expired while idle
  • Changed /code-review so Claude can also start it on its own on Bedrock, Vertex AI, and Foundry, through the Claude apps gateway, and when telemetry or non-essential traffic is disabled
  • /goal: Changed idle sessions to start at most three check-ins on long-running background work per goal; your next message allows three more
  • Changed claude install and claude update to defer a pending managed-settings consent prompt to the next interactive session instead of prompting mid-command
  • Changed OpenTelemetry plugin events for plugins synced from claude.ai: plugin_id_hash now reflects the plugin's real marketplace, and enabled_via is admin-install for admin-installed plugins
  • Fixed the command sandbox's filesystem configuration not respecting --setting-sources
