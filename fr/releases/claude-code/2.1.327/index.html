  • [VSCode] Amélioration de la vitesse lorsque Claude effectue plusieurs modifications d'affilée : les modifications en file d'attente partagent une attente pour de nouveaux problèmes ; un problème peut être signalé lors d'une modification ultérieure
  • [VSCode] Amélioration de la vitesse de recherche des fichiers @-mention dans les grands espaces de travail lorsque rg est sur votre PATH ; les résultats sont désormais classés comme dans le terminal, avec moins de tolérance pour les fautes de frappe
