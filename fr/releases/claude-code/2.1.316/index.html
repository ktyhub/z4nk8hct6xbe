claude-code v2.1.316

code-claude v2.1.316

Qu'est-ce qui a changé

  • Ajout de CLAUDE_CODE_DISABLE_ULTRATHINK, qui désactive le mot-clé ultrathink
  • Ajout de budgets de groupe mutualisés à la passerelle des applications Claude : un budget mensuel que les membres d'un groupe partagent, en plus de la limite de chaque membre, définie avec pooled_budget sur l'administrateur des limites de dépenses API
  • Ajout de CLAUDE_CODE_DISABLE_LOOPED_CROSS_CERT_DROP pour conserver les certifications croisées du système qui se certifient mutuellement en boucle, pour les serveurs dont l'autorité de certification privée en a besoin.
  • Ajout de CLAUDE_CODE_SUBAGENT_EFFORT pour définir le niveau d'effort auquel les sous-agents s'exécutent lorsque rien d'autre n'en nomme un, au lieu d'hériter du niveau d'effort de la session.
  • Ajout de managed.policy_mode: layered à la passerelle des applications Claude : chaque politique qui correspond à un développeur s'applique, chacune fusionnée avec celles répertoriées en dessous, pas seulement la première
  • Ajout de guardrail.input_tagging sur la passerelle des applications Claude Bedrock en amont, qui encapsule les invites dans les balises d'entrée dont le filtre d'attaques d'invite d'un garde-corps Amazon Bedrock a besoin ; all_messages_and_system marque également l'invite du système
  • Mode rapide obsolète pour Opus 4.8 à compter du 30 octobre 2026 ; il sera supprimé le 30 novembre 2026. Après suppression, les requêtes en mode rapide sur l'Opus 4.8 renvoient une erreur et ne reviennent pas au standard Opus 4.8. Migrez vers Opus 5.5 pour conserver l'accélération
  • Correction des commandes shell qui restent en cours d'exécution sur macOS et Linux lorsque Claude Code se termine tout seul, par exemple lorsque les informations d'identification sont refusées ou qu'une session cloud est archivée
  • Correction des alias bash avec des sauts de ligne dans leur valeur (sauf dans Git Bash) et des fonctions dont les noms commencent par un tiret, étant tronqués ou perdus dans le shell de l'outil Bash
  • Correction des scripts bash démarrés à partir de l'outil Bash s'arrêtant après leur première commande lors de l'exportation de SHELLOPTS
  • Correction des hooks PowerShell ne bloquant pas sur le code de sortie 2 lorsque la commande commence par un transtypage de type, param, using ou un attribut
  • Correction de certaines requêtes réseau bloquées lorsqu'une réponse compressée était coupée ou corrompue
  • Correction de sonnet, opus et haiku sur Vertex AI et Amazon Bedrock affichant une erreur en cours de session au lieu de passer à un modèle plus ancien lorsque le plus récent n'est pas encore disponible pour le compte ou la région.
  • Correction de la passerelle des applications Claude ne vérifiant pas les noms de chaque modèle et demande par rapport à availableModels, deniedModels et models ; une requête qui nomme un modèle bloqué obtient désormais un 400 nommant le champ
  • Correction de claude auth login refusant de s'exécuter lorsque les paramètres gérés nécessitent une passerelle d'applications Claude ; dans un terminal, il affiche maintenant la connexion à la passerelle
  • Correction des sessions --restricted téléchargeant des fichiers depuis l'extérieur des répertoires de travail lorsqu'une règle d'autorisation de lecture les couvrait
  • Correction des invites contenant des caractères invisibles nécessitant une seconde Entrée pour être envoyées ; les invites simples sont désormais envoyées nettoyées lors de la première entrée, et les commandes attendent toujours d'être révisées
  • Correction des sous-agents qui héritaient du modèle d'un sous-agent parent se déplaçant vers le modèle principal lorsqu'un travail en arrière-plan ou un message les réveillait
  • Correction d'une liste autoMode.allow gérée sans que "$defaults" ne récupère les exceptions intégrées du --settings d'une application hôte, une première règle ajoutée dans /permissions ou /auto-mode-setup
  • Correction des sessions cloud et des tâches planifiées dans le cloud qui n'étaient pas marquées comme ayant échoué lorsque le mode automatique arrêtait un tour car le serveur ne renvoyait aucun verdict de sécurité.
  • Correction de la sortie de texte claude -p qui n'indiquait parfois pas pourquoi le mode automatique arrêtait un tour alors qu'un agent en arrière-plan était toujours en cours d'exécution
  • Correction de CLAUDE_CODE_AUTO_MODE_SERVER=1 étant ignoré dans les sessions démarrées par une application hôte (telle que Claude Desktop) derrière un proxy ou une passerelle LLM avec les bêtas expérimentaux désactivés
  • Correction des scripts du plugin MCP headersHelper recevant un CLAUDE_PLUGIN_ROOT et une URL de serveur corrompus lorsqu'une variable d'environnement nommée par identifiant était définie sur une valeur de commutateur telle que 1
  • Correction de la requête de contrôle SDK register_repo_root ne chargeant pas le CLAUDE.md d'un répertoire en dehors du répertoire de travail (avec CLAUDE_CODE_ADDITIONAL_DIRECTORIES_CLAUDE_MD=1)
  • Correction de l'outil Artefact affichant ? pour les règles d'accès à la base de données d'artefacts au niveau self, et ne citant pas ces règles lorsqu'il refuse une republication qui les supprimerait
  • Correction de /model <id> n'avertissant pas lorsque le modèle n'est pas reconnu par cette version et le compactage automatique supposera une fenêtre contextuelle de 200 Ko
  • Correction de l'indice « Garder de l'espace pour parler » utilisant ses trois affichages en une seule session et affichant une touche vide lorsque le push-to-talk n'est pas lié.
  • Correction de Grep et Glob ne revenant jamais lorsque le processus de recherche est arrêté à l'expiration du délai mais ne se termine pas, vu sous Windows
  • Correction d'un cas rare où la reprise d'une conversation ne rétablissait pas son plan, lorsque /clear ou /resume avait été exécuté alors qu'une partie de cette conversation était encore en cours de sauvegarde
  • Correction de la configuration de première exécution supprimant les mots des notes de sécurité et l'explication de la configuration du terminal dans les terminaux étroits
  • Correction de la carte d'enquête Enterprise prenant un 1 ou un 0 tapé après une courte pause ; une réponse dactylographiée nécessite maintenant Entrée
  • Coureur auto-hébergé : Correction d'un message envoyé pendant que Claude travaillait et qui recevait une réponse après un Stop, une fois le processus de la session remplacé
  • Exécuteur auto-hébergé : correction du commutateur marche/arrêt d'un serveur MCP qui était parfois perdu lorsqu'une session était déplacée vers une nouvelle machine
  • Windows : correction de l'outil Bash qui perdait vos alias et fonctions dans Git Bash lorsque le fichier rc définit errexit et pipefail et que seuls les alias winpty, ou aucun, sont définis
  • /code-review amélioré lancé depuis l'onglet Code dans Claude Desktop ou sur le Web : les sessions cloud et claude remote-control affichent désormais la carte des résultats, et non une liste en texte brut
  • /diff amélioré sur les grands référentiels : chaque actualisation exécute généralement une commande git de moins pour le référentiel complet, et les actualisations sont espacées lorsque git est lent
  • Amélioration des messages affichés lorsque /ultrareview, une session cloud ou un agent cloud ne trouve aucun distant GitHub : ils disent désormais de créer un référentiel sur https://github.com/new, et /ultrareview ne suggère plus une commande gh que gh rejette
  • Amélioration des erreurs de certificat SSL pour nommer les causes probables, parmi lesquelles un serveur qui oublie un certificat intermédiaire et le correctif pour chacune
  • Modification du mode automatique afin qu'une liste autoMode.allow sans "$defaults" ne supprime plus la règle intégrée sur les invites de tâches planifiées
  • Modification des paramètres gérés par le serveur pour les connexions Team et Enterprise : les paramètres extraits du API d'Anthropic s'appliquent désormais sans invite d'approbation, et une copie stockée qui ne vérifie pas est refusée.
  • [VSCode] Ajout de la connexion à une passerelle d'applications Claude à partir du panneau de discussion, sans terminal nécessaire
  • [VSCode] Modification de ultrathink pour qu'il exécute son tour avec l'effort de xhigh et s'affiche dans un arc-en-ciel dans la boîte de discussion, comme dans le terminal
  • [VSCode] Correction du curseur Effort, du commutateur Ultracode et du nom du modèle manquants lorsque le paramètre du modèle comporte la balise [1m], telle que opus[1m].
  • [VSCode] Correction de l'historique des questions secondaires du /btw enregistré qui était supprimé trop tôt alors qu'un fichier de paramètres contenait des erreurs.
  • [VSCode] Correction d'une conversation revenant en mode Auto après un rechargement ou un redémarrage lorsque son plan était approuvé avec "Oui, et approuver manuellement les modifications"
  • [Sessions cloud] Ajout d'une fiche de formulaire aux sessions cloud, afin que vous puissiez remplir ou supprimer un formulaire demandé par un serveur MCP au lieu que la demande soit annulée sans que vous la voyiez
  • [Sessions Cloud] Ajout d'une ligne « Rattrapage… » qui s'affiche pendant qu'une session Cloud ou Remote Control à laquelle vous revenez met toujours ses messages à jour
  • [Sessions cloud] Modification des secrets réseau afin que les membres de l'entreprise puissent les ajouter et les supprimer sur leurs propres environnements cloud, au lieu de simplement les afficher.
  • [Sessions cloud] Amélioration du volet Modifications pour les sessions cloud : la note sur ce que la liste laisse de côté est désormais un badge à côté du nom de la branche, et non une ligne au-dessus de la différence.
  • [Sessions Cloud] Correction de la recherche de fichiers dans le volet Fichiers d'une session cloud affichant les dossiers sous forme de chemins ../.. après que Claude ait changé de répertoire ; les résultats montrent maintenant leur chemin depuis la racine du projet
  • [Claude Tag] Correction du refus de Claude de modifier ou d'ajouter un canevas qu'il avait créé dans une chaîne Slack, à partir de cette chaîne, une fois que le canevas était également partagé sur une autre chaîne ou un DM.
  • [Claude Tag] Correction des réponses non taguées qui restaient sans réponse dans un fil de discussion Slack Connect lorsque les deux organisations avaient installé Claude et que Slack envoyait la réponse à l'application de l'autre organisation.
  • [Claude Tag] Correction de la liste de contrôle de l'état en direct d'une tâche planifiée dans le cloud dans Slack qui restait à moitié terminée ; une exécution peut désormais modifier les messages de niveau supérieur qu'elle a publiés au cours de cette exécution
  • [Claude Tag] Modification du passage automatique de la réponse d'une chaîne Slack à un choix « Comment Claude participe » sur la page de configuration de la chaîne et dans les paramètres d'administration de Claude Tag
  • [Code Review] Ajout d'une carte de résultats par gravité à la page d'analyse de Code Review, affichant les résultats totaux de la période, un graphique quotidien empilé par gravité et le nombre de chaque gravité.

Anglais original / English original

claude-code v2.1.316

What's changed

  • Added CLAUDE_CODE_DISABLE_ULTRATHINK, which turns the ultrathink keyword off
  • Added pooled group budgets to the Claude apps gateway: one monthly budget that a group's members share, on top of each member's own limit, set with pooled_budget on the spend limits admin API
  • Added CLAUDE_CODE_DISABLE_LOOPED_CROSS_CERT_DROP to keep system cross-certificates that certify each other in a loop, for servers whose private CA needs one
  • Added CLAUDE_CODE_SUBAGENT_EFFORT to set the effort level subagents run at when nothing else names one, instead of inheriting the session's
  • Added managed.policy_mode: layered to the Claude apps gateway: every policy that matches a developer applies, each merged over the ones listed below it, not only the first
  • Added guardrail.input_tagging on Claude apps gateway Bedrock upstreams, which wraps prompts in the input tags that an Amazon Bedrock guardrail's prompt attacks filter needs; all_messages_and_system also tags the system prompt
  • Deprecated fast mode for Opus 4.8 as of October 30, 2026; it will be removed on November 30, 2026. After removal, fast mode requests on Opus 4.8 return an error and do not fall back to standard Opus 4.8. Migrate to Opus 5.5 to keep the speedup
  • Fixed shell commands being left running on macOS and Linux when Claude Code exits by itself, for example when credentials are refused or a cloud session is archived
  • Fixed bash aliases with line breaks in their value (except in Git Bash), and functions whose names start with a dash, being garbled or lost in the Bash tool's shell
  • Fixed bash scripts started from the Bash tool stopping after their first command when SHELLOPTS is exported
  • Fixed PowerShell hooks not blocking on exit code 2 when the command begins with a type cast, param, using or an attribute
  • Fixed some network requests hanging when a compressed response was cut off or corrupted
  • Fixed sonnet, opus and haiku on Vertex AI and Amazon Bedrock showing an error mid-session instead of switching to an older model when the newest is not yet available to the account or region
  • Fixed the Claude apps gateway not checking every model a request names against availableModels, deniedModels and models; a request that names a blocked model now gets a 400 naming the field
  • Fixed claude auth login refusing to run where managed settings require a Claude apps gateway; in a terminal it now shows the gateway sign-in
  • Fixed --restricted sessions uploading files from outside the working directories when a Read allow rule covered them
  • Fixed prompts containing invisible characters needing a second Enter to send; plain prompts now send cleaned on the first Enter, and commands still wait for review
  • Fixed sub-agents that inherited a parent sub-agent's model moving to the main model when a background job or message woke them
  • Fixed a managed autoMode.allow list without "$defaults" getting the built-in exceptions back from a host app's --settings, a first rule added in /permissions, or /auto-mode-setup
  • Fixed cloud sessions and cloud scheduled tasks not being marked as failed when auto mode stopped a turn because the server returned no safety verdict
  • Fixed claude -p text output sometimes not saying why auto mode stopped a turn when a background agent was still running
  • Fixed CLAUDE_CODE_AUTO_MODE_SERVER=1 being ignored in sessions started by a host application (such as Claude Desktop) behind a proxy or LLM gateway with experimental betas turned off
  • Fixed plugin MCP headersHelper scripts receiving a corrupted CLAUDE_PLUGIN_ROOT and server URL when a credential-named environment variable was set to a switch value such as 1
  • Fixed the SDK register_repo_root control request not loading the CLAUDE.md of a directory outside the working directory (with CLAUDE_CODE_ADDITIONAL_DIRECTORIES_CLAUDE_MD=1)
  • Fixed the Artifact tool showing ? for artifact database access rules at the self level, and not quoting those rules back when it refuses a republish that would drop them
  • Fixed /model <id> not warning when the model isn't recognized by this version and auto-compact will assume a 200K context window
  • Fixed the "hold space to speak" hint using up its three showings in one session, and showing an empty key when push-to-talk is unbound
  • Fixed Grep and Glob never returning when the search process is killed at the timeout but does not exit, seen on Windows
  • Fixed a rare case where resuming a conversation did not restore its plan, when /clear or /resume had been run while part of that conversation was still being saved
  • Fixed first-run setup dropping words from the security notes and the terminal-setup explanation in narrow terminals
  • Fixed the Enterprise survey card taking a typed 1 or 0 after a short pause; a typed answer now needs Enter
  • Self-hosted runner: Fixed a message sent while Claude was working being answered after a Stop, once the session's process had been replaced
  • Self-hosted runner: Fixed an MCP server's on/off switch sometimes being lost when a session moved to a new machine
  • Windows: Fixed the Bash tool losing your aliases and functions in Git Bash when the rc file sets errexit and pipefail and only winpty aliases, or none, are defined
  • Improved /code-review started from the Code tab in Claude Desktop or on the web: cloud and claude remote-control sessions now show the findings card, not a plain-text list
  • Improved /diff on large repositories: each refresh usually runs one fewer full-repository git command, and refreshes are spaced out when git is slow
  • Improved the messages shown when /ultrareview, a cloud session or a cloud agent finds no GitHub remote: they now say to create a repository at https://github.com/new, and /ultrareview no longer suggests a gh command that gh rejects
  • Improved SSL certificate errors to name the likely causes, among them a server that leaves out an intermediate certificate, and the fix for each
  • Changed auto mode so that an autoMode.allow list without "$defaults" no longer removes the built-in rule on scheduled-task prompts
  • Changed server-managed settings for Team and Enterprise logins: settings fetched from Anthropic's API now apply without an approval prompt, and a stored copy that doesn't verify is refused
  • [VSCode] Added sign-in to a Claude apps gateway from the chat panel, with no terminal needed
  • [VSCode] Changed ultrathink to run its turn at xhigh effort and show in a rainbow in the chat box, as in the terminal
  • [VSCode] Fixed the missing Effort slider, Ultracode switch and model name when the model setting has the [1m] tag, such as opus[1m]
  • [VSCode] Fixed saved /btw side-question history being deleted too early while a settings file has errors
  • [VSCode] Fixed a conversation coming back in Auto mode after a reload or restart when its plan was approved with "Yes, and manually approve edits"
  • [Cloud sessions] Added a form card to cloud sessions, so you can fill in or decline a form an MCP server asks for instead of the request being canceled without you seeing it
  • [Cloud sessions] Added a "Catching up…" line that shows while a cloud or Remote Control session you switch back to is still bringing its messages up to date
  • [Cloud sessions] Changed network secrets so Enterprise members can add and delete them on their own cloud environments, instead of only viewing them
  • [Cloud sessions] Improved the Changes pane for cloud sessions: the note about what the list leaves out is now a badge beside the branch name, not a row above the diff
  • [Cloud sessions] Fixed file search in a cloud session's Files pane showing folders as ../.. paths after Claude changed directory; results now show their path from the project's root
  • [Claude Tag] Fixed Claude refusing to edit or append to a canvas it made in a Slack channel, from that channel, once the canvas was also shared to another channel or a DM
  • [Claude Tag] Fixed untagged replies going unanswered in a Slack Connect thread when both organizations have installed Claude and Slack delivered the reply to the other organization's app
  • [Claude Tag] Fixed a cloud scheduled task's live status checklist in Slack staying half-done; a run can now edit the top-level messages it posted during that run
  • [Claude Tag] Changed a Slack channel's Respond automatically switch to a "How Claude participates" choice on the channel's Configure page and in Claude Tag admin settings
  • [Code Review] Added a findings-by-severity card to the Code Review analytics page, showing the period's total findings, a daily chart stacked by severity, and each severity's count
