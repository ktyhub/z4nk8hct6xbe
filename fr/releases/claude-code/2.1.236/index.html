claude-code v2.1.236

code-claude v2.1.236

Qu'est-ce qui a changé

  • Ajout de la variable d'environnement ANTHROPIC_DEFAULT_MODEL : définit le modèle sur lequel les nouvelles sessions démarrent, tandis qu'un choix /model le remplace toujours et persiste lors des redémarrages (contrairement à ANTHROPIC_MODEL)
  • Ajout de notify_when_idle à SendMessage inter-session : demandez à une autre session Claude Code sur cette machine d'envoyer une notification lors de sa prochaine inactivité - opt-in, one-shot, pas d'interrogation (macOS et Linux)
  • Sandbox : sur macOS, les règles de refus de lecture génériques (par exemple **/.env) ont désormais la priorité dans les régions de lecture autorisées, couvrent le contenu des répertoires correspondant et ne peuvent pas être contournées en renommant le fichier refusé.
  • Correction de la copie de clipboard, de la gestion en arrière-plan, des sessions en arrière-plan et de la rupture des journaux MCP locaux après la suppression du répertoire dans lequel une session était basculée (depuis 2.1.229)
  • Correction du rendu plein écran qui échouait définitivement après un seul démarrage raté : il revient désormais au moteur de rendu classique au lieu de se fermer à chaque lancement ultérieur.
  • Correction du rendu du sélecteur /model plus haut que le terminal : il affiche désormais uniquement autant de modèles que la fenêtre le permet, le reste étant accessible en faisant défiler
  • Correction des appels SendMessage étant rejetés lorsqu'une balise de fermeture mal formée laissait le texte du message dans le champ récapitulatif
  • Correction des rejets de promesses non gérés lorsqu'un sous-processus ne démarre pas, par exemple powershell.exe sur WSL avec l'interopérabilité Windows désactivée (régression dans 2.1.234)
  • Correction du mode plein écran qui n'affichait parfois pas un message nouvellement envoyé jusqu'à la prochaine mise à jour après le redimensionnement du terminal
  • Correction d'une bande vide qui pouvait rester au-dessus de l'invite après avoir effacé une invite multiligne, et les volets ne se repeignaient pas après avoir redimensionné le terminal en mode plein écran.
  • Correction de l'invite d'approbation des paramètres gérés qui n'apparaissait parfois pas au démarrage tout en capturant la première pression sur une touche comme approbation
  • Correction des titres des onglets du terminal sautant dans tmux (intégration iTerm tmux) : le titre est désormais écrit uniquement lorsque son texte change au lieu de s'animer toutes les 960 ms
  • Correction d'une erreur peu claire lorsque la liste des environnements cloud revenait vide ou mal formée
  • Correction de l'invite de crédits de première utilisation de Fable 5 sélectionnant automatiquement le modèle de secours après 60 secondes sans réponse lors de l'utilisation de la télécommande.
  • Correction des astuces de spinner n'apparaissant jamais, avec une erreur d'arrière-plan répétée, lorsque la récompense du pass invité mise en cache dans ~/.claude.json était mal formée
  • Correction du rechargement à chaud des compétences dans les sessions SDK/VS Code générant une erreur à chaque changement de compétences après la suppression du répertoire de travail de la session (2.1.229+)
  • Correction des sessions de coureur auto-hébergées libérées en cas d'inactivité, de retrait ou d'expiration du délai de démarrage, reprenant occasionnellement sur un autre coureur avant la fin du hook post-session.
  • Correction du rendu inégal des yeux et des pieds de la mascotte Clawd dans iTerm2 pour certaines tailles de police
  • Correction des récapitulatifs occasionnels de sessions incontrôlables : le texte de récapitulation (automatique et /recap) est désormais limité à 400 caractères, coupé à la limite d'un mot.
  • Performances de démarrage améliorées : le compteur de sessions est désormais écrit en arrière-plan
  • Mode automatique amélioré : les règles d'autorisation Monitor sont désormais mises de côté lorsque le mode automatique est actif, de sorte que les commandes Monitor sont examinées de la même manière que les commandes Bash.
  • Mode automatique amélioré sur Bedrock, Vertex AI et Foundry, et lorsque la télémétrie est désactivée : le classificateur utilise désormais les mêmes paramètres par défaut que sur le Claude API, y compris la classification par gravité
  • Mode automatique amélioré : la vérification de l'état de git ne peut plus être trompée par le paramètre status.showUntrackedFiles=no d'un dépôt pour signaler une arborescence propre
  • Modification du sélecteur /model pour mettre en surbrillance uniquement le nom du modèle le plus récent, de sorte que la surbrillance marque la nouvelle version plutôt qu'un sous-ensemble arbitraire de la liste.
  • /goal : une session inactive dont l'objectif est garé derrière un travail en arrière-plan de longue durée s'enregistre désormais automatiquement après 30 minutes (puis 1h, 2h) au lieu d'attendre votre retour
  • /usage affiche désormais la ligne de dépenses en crédits d'utilisation pour les membres Team et Enterprise, et affiche une ligne plafonnée à 0 % avant que quoi que ce soit ne soit dépensé.
  • SIGTERM en mode print/SDK n'enregistre plus un tour interrompu ou un refus d'outil synthétique avant de sortir ; les commandes en cours d'exécution sont toujours terminées et le processus se termine toujours avec le code 143
  • Appuyer sur Entrée sur une faute de frappe dans une commande barre oblique ou sur une commande indisponible dans cette session le signale désormais au lieu d'exécuter la correspondance floue la plus proche ; les préfixes et les alias fonctionnent toujours
  • La télécommande marque désormais une session hors ligne en quelques secondes lorsque le CLI se ferme ou que son terminal se ferme
  • SendMessage refuse désormais d'envoyer d'autres messages à une session dès qu'une rafale rapid dépasse ce que la boîte de réception de cette session accepte, au lieu de signaler leur envoi alors qu'ils ont été abandonnés.
  • Alignement de la puce du titre de la session sur la bordure d'invite avec le bord droit du pied de page
  • Les éléments de pied de page alignés à droite (indicateur d'objectif, état de session, état de l'agent en arrière-plan) et les notifications tronquées partagent désormais une marge droite cohérente avec le reste de la zone d'invite.
  • [VSCode] Ajout de la prise en charge d'un lecteur d'écran pour la transcription : annonces en direct pour les réponses, les demandes d'autorisation, les erreurs et les changements de statut, ainsi qu'une navigation par cap par tour.

claude-code v2.1.236

What's changed

  • Added ANTHROPIC_DEFAULT_MODEL environment variable: sets the model new sessions start on, while a /model pick still overrides it and persists across restarts (unlike ANTHROPIC_MODEL)
  • Added notify_when_idle to cross-session SendMessage: ask another Claude Code session on this machine to send one notice when it next goes idle — opt-in, one-shot, no polling (macOS and Linux)
  • Sandbox: on macOS, wildcard read-deny rules (e.g. **/.env) now take precedence inside allowed read regions, cover matched directories' contents, and can't be bypassed by renaming the denied file
  • Fixed clipboard copy, background housekeeping, background sessions, and local MCP logs breaking after the directory a session had switched into was removed (since 2.1.229)
  • Fixed the fullscreen renderer failing permanently after a single failed start: it now falls back to the classic renderer instead of exiting on every subsequent launch
  • Fixed the /model picker rendering taller than the terminal: it now shows only as many models as fit the window, with the rest reachable by scrolling
  • Fixed SendMessage calls being rejected when a malformed closing tag left the message text inside the summary field
  • Fixed unhandled promise rejections when a subprocess fails to start, for example powershell.exe on WSL with Windows interop disabled (regression in 2.1.234)
  • Fixed fullscreen mode sometimes not showing a newly sent message until the next update after the terminal was resized
  • Fixed a blank band that could remain above the prompt after clearing a multi-line prompt, and panes not repainting after resizing the terminal away and back, in fullscreen mode
  • Fixed the managed-settings approval prompt sometimes not appearing at startup while still capturing the first keypress as approval
  • Fixed terminal tab titles jumping in tmux (iTerm tmux integration): the title is now written only when its text changes instead of animating every 960ms
  • Fixed an unclear error when the cloud environments list came back empty or malformed
  • Fixed the Fable 5 first-time usage-credits prompt auto-selecting the fallback model after 60 seconds with no answer when using Remote Control
  • Fixed spinner tips never appearing, with a repeated background error, when the cached guest-pass reward in ~/.claude.json was malformed
  • Fixed skills hot-reload in SDK/VS Code sessions raising an error on every skills change after the session's working directory was deleted (2.1.229+)
  • Fixed self-hosted runner sessions released on idle, retire, or startup timeout occasionally resuming on another runner before the post-session hook had finished
  • Fixed the Clawd mascot's eyes and feet rendering unevenly in iTerm2 at some font sizes
  • Fixed occasional runaway session recaps: recap text (automatic and /recap) is now capped at 400 characters, cut at a word boundary
  • Improved startup performance: the session counter is now written in the background
  • Improved auto mode: Monitor allow rules are now set aside while auto mode is active, so Monitor commands are reviewed the same way Bash commands are
  • Improved auto mode on Bedrock, Vertex AI, and Foundry, and when telemetry is disabled: the classifier now uses the same defaults as on the Claude API, including severity-scored classification
  • Improved auto mode: the git status check can no longer be fooled by a repo's status.showUntrackedFiles=no setting into reporting a clean tree
  • Changed the /model picker to highlight only the newest model's name, so the highlight marks the new release rather than an arbitrary subset of the list
  • /goal: an idle session whose goal is parked behind long-running background work now checks in automatically after 30 minutes (then 1h, 2h) instead of waiting for you to return
  • /usage now shows the usage-credits spend row for Team and Enterprise members, and shows a capped row at 0% before anything is spent
  • SIGTERM in print/SDK mode no longer records an interrupted turn or synthetic tool denials before exiting; running commands are still terminated and the process still exits with code 143
  • Pressing Enter on a slash-command typo or a command unavailable in this session now reports it instead of running the closest fuzzy match; prefixes and aliases still run
  • Remote Control now marks a session offline within seconds when the CLI exits or its terminal closes
  • SendMessage now refuses further messages to a session up front once a rapid burst would exceed what that session's inbox accepts, instead of reporting them sent while they were dropped
  • Aligned the session title chip on the prompt border with the footer's right edge
  • Right-aligned footer items (goal indicator, session state, background agent status) and truncated notices now share a consistent right margin with the rest of the prompt area
  • [VSCode] Added screen reader support for the transcript: live announcements for replies, permission requests, errors, and status changes, plus per-turn heading navigation
