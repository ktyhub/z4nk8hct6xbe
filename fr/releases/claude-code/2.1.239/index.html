claude-code v2.1.239

Correctif Publié21 août 2026 Sourceanthropics/claude-code Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

code-claude v2.1.239

Qu'est-ce qui a changé

  • Les estimations de coûts (/cost, ligne de statut, --max-budget-usd) incluent désormais la prime d'inférence 1.1 × uniquement aux États-Unis pour les espaces de travail de résidence de données.
  • Ajout de l'offre unique de rendu plein écran sur Bedrock, Vertex, Foundry et d'autres configurations précédemment exclues ; les nouvelles installations démarrent maintenant en plein écran
  • Ajout de /claude-api upgrade pour migrer les projets Python de anthropic 0.x vers 1.x, et mise à jour de la référence Python de la compétence pour 1.x (les délais d'attente utilisent anthropic.Timeout, pas httpx.Timeout)
  • Sessions cloud : les plugins synchronisés depuis claude.ai s'affichent désormais sous le nom de name@synced, fonctionnent avec claude plugin enable/disable <name>@synced et ne remplacent jamais un plugin du même nom que vous avez installé
  • Builds Alpine/musl : les modules complémentaires de collage d'images natifs, clipboard et de capture audio se chargent désormais (les binaires construits par musl au lieu de ceux glibc refusés par le runtime)
  • Le message de limite d'utilisation affiché lorsque votre limite de dépenses mensuelle est déjà utilisée indique désormais également quand votre session ou votre limite hebdomadaire est réinitialisée.
  • Correction du streaming Bedrock derrière les proxys qui supprimaient l'en-tête Content-Type de réponse, ce qui doublait silencieusement les appels API facturés en réexécutant chaque tour sans streaming
  • Correction du code Claude bloqué au démarrage derrière un proxy HTTPS lors de l'utilisation de Bedrock avec un profil SSO et awsAuthRefresh — la pré-vérification des informations d'identification honore désormais HTTPS_PROXY
  • Correction d'un crash dump brut lors du démarrage de Claude Code à partir d'un répertoire qui n'existe plus ; il imprime maintenant un message clair
  • Correction des appels d'édition et d'écriture s'arrêtant pendant environ 5 secondes dans les terminaux JetBrains IDE lorsque le plugin Claude Code est connecté
  • Correction d'une course où appuyer sur Echap avec une invite en file d'attente pouvait permettre au prochain tour de se terminer plus tôt, laissant la session inactive pendant que Claude travaillait encore et permettant à un utilisateur ultérieur de répéter les actions.
  • Correction de WebFetch conservant le contenu des pages expirées en mémoire pendant toute la session au lieu des 15 minutes prévues
  • Correction des sessions cloud (Claude Code sur les applications Web, de bureau et mobiles) reprenant hors du mode plan après un redémarrage d'un travailleur inactif
  • Correction des formulaires d'élicitation MCP plus hauts que le terminal étant affichés en mode plein écran : le formulaire s'adapte désormais à la fenêtre, avec des champs cachés accessibles par défilement et Accept/Decline toujours visible
  • Correction des serveurs MCP distants qui échouaient après un 5xx transitoire lors d'une reconnexion à mi-session dans les sessions cloud ou via SDK setMcpServers()
  • Correction des titres de session personnalisés disparaissant de /resume après l'écriture de plus de ~64 Ko de conversation après le changement de nom.
  • Correction de claude -c/reprise des sessions à partir d'un répertoire différent dont le chemin ne différait que par des caractères comme _, - ou .
  • Correction de /resume et de la vue des agents affichant une session comme récemment modifiée (et la réorganisant) lorsque seul son fichier était touché ou simplement rouvert
  • Correction de /resume en mode tous projets vous indiquant de placer cd dans un répertoire supprimé (par exemple un arbre de travail supprimé) ; ces sessions reprennent désormais dans le répertoire courant
  • Correction des résultats étendus de l'outil de rendu du thème dark-ansi en mode plein écran avec un texte de la même couleur que l'arrière-plan
  • Correction de l'invite du moteur de rendu plein écran réapparaissant à chaque lancement alors qu'il était impossible d'y répondre ; il s'arrête maintenant après avoir été diffusé sur trois lancements
  • Correction des modèles .worktreeinclude commençant par **/ ne correspondant silencieusement à rien lorsque la cible vivait dans un répertoire gitignored
  • Correction des agents, compétences et commandes dont le fichier .md commence par une nomenclature UTF-8 ignorée en silence
  • Correction de /insights faisant écho aux balises littérales <message> dans sa réponse sur certains modèles
  • Correction du marché metadata.pluginRoot n'ayant aucun effet : les noms de sources de plugins nus sont désormais résolus en dessous comme le décrit la documentation.
  • Correction du mouvement de la souris dans les terminaux basés sur un navigateur en insérant du texte comme "35;150;7M" dans l'invite lorsqu'un rapport de souris arrivait réparti sur plusieurs écritures
  • Correction des remplacements de thème personnalisé pour les couleurs du badge d'état d'effort/ultracode étant ignorées
  • Correction de la fragmentation de la trace OpenTelemetry : les exécutions d'outils différées par un hook PreToolUse reprennent désormais dans la trace du tour d'origine au lieu de démarrer une nouvelle trace
  • Correction du mode vim dans la vue agent : Escape passe désormais en mode NORMAL et conserve votre texte au lieu d'effacer l'invite
  • Correction du raccourci clavier selection:copy supprimant silencieusement une sélection de texte qui avait été étendue avec les touches Maj+Flèche.
  • Correction de l'astuce de démarrage du /voice apparaissant toujours après l'activation de la dictée vocale via le paramètre voice.enabled
  • Correction de l'achèvement de l'onglet en mode shell (!) supprimant le ./ d'un chemin ./script, ce qui laissait une commande que le shell ne pouvait pas exécuter
  • Correction du mode plein écran répondant à une invite d'autorisation ou en appuyant sur un bouton lorsque vous cliquez la fenêtre du terminal uniquement pour la remettre au point
  • Correction des panneaux de commandes slash (par exemple /config, /model) en mode plein écran couvrant les derniers messages ; la conversation reste désormais épinglée au-dessus du panneau
  • Correction de la boîte de dialogue détaillée de /workflows débordant du terminal et perdant son en-tête hors écran lorsqu'elle était ouverte alors que Claude répondait toujours
  • Correction du bac à sable Linux rendant illisible un .git/config.worktree inexistant, ce qui cassait chaque commande git en bac à sable dans les dépôts avec l'ensemble extensions.worktreeConfig
  • Correction des hooks échouant avec "posix_spawn ENOENT" après la suppression du répertoire de travail de la session ; ils s'exécutent désormais à partir de la racine du projet ou du répertoire personnel
  • Correction de claudeMdExcludes n'excluant pas un fichier .claude/rules avec lien symbolique lorsque le modèle nomme le répertoire de règles ou le lien symbolique plutôt que sa cible
  • Correction de la synchronisation incontrôlée des titres de session avec Remote Control lorsque deux processus Claude Code partageaient l'état d'un travail en arrière-plan (régression 2.1.232) ; les mises à jour des titres sont désormais dédupliquées et limitées en débit
  • Correction des sessions dont le titre commence par / étant inadressables par SendMessage et affichées comme "(sans titre)" dans ListAgents
  • Correction de Ctrl+W, Ctrl+U, Ctrl+K, Option+Backspace, Option+D et vim df/dt laissant un espace réservé [Pasted text #N] cassé lorsque le curseur était à l'intérieur.
  • Correction des entrées masquées (style mot de passe) telles que le champ du code de connexion permettant à leur texte d'être recollé avec Ctrl+Y ailleurs ou enregistré dans l'historique des invites lorsqu'il est effacé avec un double Échap.
  • Correction de Ctrl+Retour arrière supprimant un caractère au lieu d'un mot dans les champs de recherche
  • Correction d'une demande rejetée par une vérification de politique d'organisation renvoyée avant que le rejet ne soit affiché
  • Amélioration du rappel affiché après le compactage afin que les arguments d'origine d'une compétence ne soient pas réexécutés en tant que nouvelle requête.
  • Les chemins de fichiers longs sur les lignes d'utilisation des outils sont désormais tronqués au milieu pour rester sur une seule ligne.
  • Les sessions à distance continuent d'envoyer des keep-alives pendant qu'un long hook SessionStart ou Setup s'exécute, de sorte que le conteneur ne soit pas inactif à mi-hook
  • /goal : répétez les enregistrements sur le travail en arrière-plan de longue durée maintenant (30 min, puis 1 h, puis toutes les 2 h) au lieu de répéter toutes les 30 minutes
  • /goal : reprendre une session depuis le sélecteur claude --resume restaure désormais son objectif actif
  • ListAgents indique désormais à une session son propre nom (celui que les pairs utilisent pour lui envoyer un message), et SendMessage à votre propre nom l'indique au lieu de "aucun agent nommé…"
  • ListAgents et /list-agents répertorient désormais vos coéquipiers en direct (auparavant, seuls les sous-agents et autres sessions apparaissaient, donc un coéquipier joignable semblait absent)
  • keybindingFlavor: "readline" correspond désormais également à Bash pour les clés de mots : Alt+F et Ctrl/Option+→ s'arrêtent à la fin du mot, Alt+D le supprime (Ctrl+Y le colle) et la ponctuation sépare les mots.
  • Le mode de nouvelle tentative persistante (CLAUDE_CODE_RETRY_WATCHDOG) échoue désormais immédiatement en cas d'erreur de limite de dépenses de l'organisation et d'épuisement des crédits au lieu d'attendre indéfiniment une réinitialisation.
  • Claude dans Chrome : /clear ferme désormais le groupe d'onglets Chrome de la session, et les groupes vides sont fermés sur /resume et à la sortie de Claude Code
  • Sessions à distance : les images téléchargées depuis un mobile incluent désormais leur chemin de fichier enregistré, afin que Claude puisse les copier dans les fichiers qu'il crée
  • Claude Code sur le web : les requêtes de Bash et d'autres outils vers des hôtes anthropic.com non-API (par exemple www, docs) passent désormais par le proxy réseau de la session, donc les domaines autorisés de votre environnement s'appliquent
  • Télécommande : message plus clair et libellé claude doctor lorsque la télécommande n'est pas activée pour votre compte
  • Windows : la messagerie intersessions est désormais disponible, afin que les sessions Claude Code sur vos machines puissent s'envoyer des messages avec SendMessage et se retrouver avec ListAgents, comme sur macOS et Linux
  • [VSCode] "Afficher l'utilisation" dans la bannière de limite d'utilisation est désormais intégré au texte d'avertissement au lieu de flotter au milieu de la bannière

claude-code v2.1.239

What's changed

  • Cost estimates (/cost, status line, --max-budget-usd) now include the 1.1× US-only-inference premium for data-residency workspaces
  • Added the one-time fullscreen renderer offer on Bedrock, Vertex, Foundry and other previously excluded setups; new installs there now start in fullscreen
  • Added /claude-api upgrade to migrate Python projects from anthropic 0.x to 1.x, and updated the skill's Python reference for 1.x (timeouts use anthropic.Timeout, not httpx.Timeout)
  • Cloud sessions: plugins synced from claude.ai now show as name@synced, work with claude plugin enable/disable <name>@synced, and never override a same-named plugin you installed
  • Alpine/musl builds: native image paste, clipboard, and audio-capture add-ons now load (musl-built binaries instead of glibc ones refused by the runtime)
  • The usage-limit message shown when your monthly spend limit is already used up now also says when your session or weekly limit resets
  • Fixed Bedrock streaming behind proxies that strip the response Content-Type header, which silently doubled billed API calls by re-running every turn non-streaming
  • Fixed Claude Code hanging at startup behind an HTTPS proxy when using Bedrock with an SSO profile and awsAuthRefresh — the credential pre-check now honors HTTPS_PROXY
  • Fixed a raw crash dump when starting Claude Code from a directory that no longer exists; it now prints a clear message
  • Fixed Edit and Write calls pausing for about 5 seconds in JetBrains IDE terminals when the Claude Code plugin is connected
  • Fixed a race where pressing Esc with a prompt queued could let the next turn finish early, leaving the session idle while Claude was still working and letting a later resubmit repeat actions
  • Fixed WebFetch retaining expired page content in memory for the whole session instead of the intended 15 minutes
  • Fixed cloud sessions (Claude Code on the web, desktop and mobile apps) resuming out of plan mode after an idle worker restart
  • Fixed MCP elicitation forms taller than the terminal being clipped in fullscreen mode: the form now fits the window, with hidden fields reachable by scrolling and Accept/Decline always visible
  • Fixed remote MCP servers staying failed after a transient 5xx on a mid-session reconnect in cloud sessions or via SDK setMcpServers()
  • Fixed custom session titles disappearing from /resume after more than ~64 KB of conversation was written following the rename
  • Fixed claude -c/resume picking up sessions from a different directory whose path differed only by characters like _, -, or .
  • Fixed /resume and the agents view showing a session as recently changed (and reordering it) when only its file was touched or it was merely reopened
  • Fixed /resume in all-projects mode telling you to cd into a deleted directory (e.g. a removed worktree); such sessions now resume in the current directory
  • Fixed the dark-ansi theme rendering expanded tool results in fullscreen mode with text the same color as the background
  • Fixed the fullscreen renderer prompt reappearing on every launch when it could never be answered; it now stops after being shown on three launches
  • Fixed .worktreeinclude patterns starting with **/ silently matching nothing when the target lived in a gitignored directory
  • Fixed agents, skills, and commands whose .md file starts with a UTF-8 BOM being silently ignored
  • Fixed /insights echoing literal <message> tags in its response on some models
  • Fixed marketplace metadata.pluginRoot having no effect: bare plugin source names now resolve under it as the docs describe
  • Fixed mouse movement in browser-based terminals inserting text like "35;150;7M" into the prompt when a mouse report arrived split across writes
  • Fixed custom theme overrides for the effort/ultracode status badge colors being ignored
  • Fixed OpenTelemetry trace fragmentation: tool executions deferred by a PreToolUse hook now resume in the original turn's trace instead of starting a new trace
  • Fixed vim mode in the agent view: Escape now switches to NORMAL mode and keeps your text instead of clearing the prompt
  • Fixed the selection:copy keybinding silently dropping a text selection that had been extended with Shift+Arrow keys
  • Fixed the /voice startup tip still appearing after voice dictation was enabled via the voice.enabled setting
  • Fixed shell-mode (!) Tab completion dropping the ./ from a ./script path, which left a command the shell couldn't run
  • Fixed fullscreen mode answering a permission prompt or pressing a button when you clicked the terminal window only to bring it back into focus
  • Fixed slash-command panels (e.g. /config, /model) in fullscreen mode covering the latest messages; the conversation now stays pinned above the panel
  • Fixed the /workflows detail dialog overflowing the terminal and losing its header off-screen when opened while Claude is still responding
  • Fixed the Linux sandbox making a nonexistent .git/config.worktree unreadable, which broke every sandboxed git command in repos with extensions.worktreeConfig set
  • Fixed hooks failing with "posix_spawn ENOENT" after the session's working directory was deleted; they now run from the project root or home directory instead
  • Fixed claudeMdExcludes not excluding a symlinked .claude/rules file when the pattern names the rules directory or the symlink rather than its target
  • Fixed runaway session-title syncing to Remote Control when two Claude Code processes shared one background job's state (2.1.232 regression); title updates are now deduplicated and rate-limited
  • Fixed sessions whose title starts with / being unaddressable by SendMessage and shown as "(untitled)" in ListAgents
  • Fixed Ctrl+W, Ctrl+U, Ctrl+K, Option+Backspace, Option+D and vim df/dt leaving a broken [Pasted text #N] placeholder when the cursor was inside it
  • Fixed masked (password-style) inputs such as the login code field letting their text be pasted back with Ctrl+Y elsewhere or saved to prompt history when cleared with double Esc
  • Fixed Ctrl+Backspace deleting one character instead of a word in search boxes
  • Fixed a request rejected by an organization policy check being re-sent before the rejection was shown
  • Improved the reminder shown after compaction so a skill's original arguments are not re-run as a new request
  • Long file paths on tool-use rows now truncate in the middle to stay on one line
  • Remote sessions keep sending keep-alives while a long SessionStart or Setup hook runs, so the container is not idle-reaped mid-hook
  • /goal: repeat check-ins on long-running background work now back off (30 min, then 1 h, then every 2 h) instead of repeating every 30 minutes
  • /goal: resuming a session from the claude --resume picker now restores its active goal
  • ListAgents now tells a session its own name (the one peers use to message it), and SendMessage to your own name says so instead of "no agent named …"
  • ListAgents and /list-agents now list your live teammates (previously only subagents and other sessions appeared, so a reachable teammate looked absent)
  • keybindingFlavor: "readline" now also matches Bash for word keys: Alt+F and Ctrl/Option+→ stop at the end of the word, Alt+D deletes to it (Ctrl+Y pastes it back), and punctuation separates words
  • Persistent retry mode (CLAUDE_CODE_RETRY_WATCHDOG) now fails immediately on organization spend-limit and out-of-credits errors instead of waiting indefinitely for a reset
  • Claude in Chrome: /clear now closes the session's Chrome tab group, and empty groups are closed on /resume and when Claude Code exits
  • Remote sessions: images uploaded from mobile now include their saved file path, so Claude can copy them into files it creates
  • Claude Code on the web: requests from Bash and other tools to non-API anthropic.com hosts (e.g. www, docs) now go through the session's network proxy, so your environment's allowed domains apply
  • Remote Control: clearer message and claude doctor wording when Remote Control isn't enabled for your account
  • Windows: cross-session messaging is now available, so Claude Code sessions across your machines can message each other with SendMessage and find each other with ListAgents, as on macOS and Linux
  • [VSCode] "View usage" in the usage-limit banner now sits inline with the warning text instead of floating mid-banner
