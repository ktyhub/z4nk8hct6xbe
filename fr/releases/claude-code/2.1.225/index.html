claude-code v2.1.225

Correctif Publié8 août 2026 Sourceanthropics/claude-code Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

code-claude v2.1.225

Qu'est-ce qui a changé

  • Ajout de la prise en charge de la limite de dépenses de la passerelle à l'avertissement d'utilisation de Claude Code ; le message de limite atteinte nomme désormais le plafond, son heure de réinitialisation et le message de l'opérateur (nécessite la passerelle sur 2.1.225)
  • Ajout d'une invite d'espace de travail trust à claude agents pour les répertoires untrusted, correspondant au comportement de claude
  • Correction d'un 401 transitoire remplaçant un CLAUDE_CODE_OAUTH_TOKEN de longue durée par le jeton de courte durée d'une connexion stockée, interrompant les sessions sans tête jusqu'au redémarrage
  • Correction des serveurs MCP OAuth sur macOS échouant par intermittence avec une rafale d'erreurs 401, comme s'ils n'avaient jamais été authentifiés, après l'expiration du délai de lecture d'un trousseau
  • Correction du mode automatique comptant un refus de filtre de sécurité de sa propre vérification d'autorisation dans la limite de blocs consécutifs ; l'action est toujours refusée, mais il est maintenant demandé au modèle de continuer plutôt que de réessayer
  • Correction des messages inter-sessions restant parqués sans préavis ni expiration dans les sessions sans tête et pendant le démarrage
  • Correction de l'historique des conversations lors de la reprise de la session de contrôle à distance après le compactage de très grandes conversations
  • Correction du survol d'une session dans un autre projet dans la liste des agents en modifiant le répertoire dans lequel l'agent suivant démarre
  • Correction de l'enregistrement de claude self-hosted-runner puis de l'échec à chaque session lorsque --base-dir ne peut pas être créé ou écrit ; il se termine maintenant au démarrage avec une erreur claire
  • Correction de Claude Code sur les sessions Web signalées à tort comme bloquées, renvoyant un retard d'événements croissant à chaque reconnexion
  • Contrôle à distance amélioré : les photos jointes depuis l'application Claude sont désormais affichées directement à Claude au lieu d'être lues à partir du disque avec un appel d'outil séparé
  • [VSCode] Correction de la vue Focus repliant la dernière liste de tâches, le contexte d'une question en attente et les réponses réglées ; les plis réservés à la réflexion affichent « Pensée pour Ns » et se ré-effondrent une fois leur tour terminé
  • SendMessage peut désormais démarrer une conversation avec vos sessions de contrôle à distance sur d'autres machines par leur nom (ListAgents les affiche comme name [ref]), au lieu de répondre uniquement après qu'ils vous ont envoyé un premier message.
  • SendMessage : un destinataire de contrôle à distance que vous avez déjà confirmé n'est jamais remplacé par une session du même nom sur cette machine lorsque sa propre liste n'a pas pu être vérifiée

claude-code v2.1.225

What's changed

  • Added gateway spend-limit support to Claude Code's usage warning; the limit-reached message now names the cap, its reset time, and the operator's message (requires the gateway on 2.1.225)
  • Added a workspace trust prompt to claude agents for untrusted directories, matching the behavior of claude
  • Fixed a transient 401 replacing a long-lived CLAUDE_CODE_OAUTH_TOKEN with a stored login's short-lived token, breaking headless sessions until restart
  • Fixed MCP OAuth servers on macOS intermittently failing with a burst of 401 errors, as if never authenticated, after a keychain read timed out
  • Fixed auto mode counting a safety-filter refusal of its own permission check toward the consecutive-block limit; the action is still denied, but the model is now told to move on rather than retry
  • Fixed cross-session messages staying parked without a notice or expiry in headless sessions and during startup
  • Fixed conversation history breaking on Remote Control session resume after very large conversations were compacted
  • Fixed hovering over a session in another project in the agents list changing the directory the next agent starts in
  • Fixed claude self-hosted-runner registering and then failing every session when --base-dir cannot be created or written; it now exits at startup with a clear error
  • Fixed Claude Code on the web sessions being misreported as stuck, re-sending a growing event backlog on every reconnect
  • Improved Remote Control: photos attached from the Claude app are now shown to Claude directly instead of being read from disk with a separate tool call
  • [VSCode] Fixed Focus view folding away the latest to-do list, a pending question's context, and settled answers; thinking-only folds show "Thought for Ns" and re-collapse when their turn completes
  • SendMessage can now start a conversation with your Remote Control sessions on other machines by name (ListAgents shows them as name [ref]), instead of only replying after they message you first
  • SendMessage: a Remote Control recipient you already confirmed is never swapped for a same-named session on this machine when its own list couldn't be checked
