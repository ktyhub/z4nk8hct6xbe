claude-code v2.1.224

code-claude v2.1.224

Qu'est-ce qui a changé

  • Ajout d'environnements auto-hébergés : claude self-hosted-runner transforme vos propres machines ou conteneurs en un endroit où les sessions Web, mobiles et de bureau de Claude Code peuvent s'exécuter, sur les forfaits Team et Enterprise.
  • Ajout de la source du plugin archive : installez des plugins à partir d'un zip via HTTPS sans git ni npm, avec épinglage SHA-256 en option
  • Ajout d'une étape d'annulation et de confirmation lors de la suppression d'un collage indisponible modifie le texte d'une commande
  • Ajout de la variable d'environnement ANTHROPIC_BEDROCK_REGION_PREFIX pour Bedrock afin de préférer un profil d'inférence inter-régions spécifique à celui dérivé de AWS_REGION.
  • Ajout des paramètres crossSessionInbound et dialogExpiry : les messages intersessions envoyés à une session exécutée avec des autorisations contournées sont conservés pour votre approbation et les messages vers d'autres sessions sont automatiquement livrés.
  • Ajout d'options de masquage des informations d'identification du bac à sable : extract et onExtractNoMatch pour les valeurs d'environnement structurées, decode: "jwt" avec maskClaims pour le masquage compatible JWT et awsPairs/sigv4 pour la re-signature AWS SigV4 ; ceux-ci nécessitent network.tlsTerminate et sont honorés uniquement à partir des paramètres utilisateur, gérés ou --settings
  • Ajout du cross-session SendMessage : les sessions Claude Code peuvent désormais s'envoyer des messages, sur n'importe laquelle de vos machines, avec ListAgents pour les découvrir (macOS et Linux)
  • Correction des chemins de projet longs (> 200 caractères) se résolvant vers le répertoire de session d'un autre projet sous un préfixe filtré partagé ; liste de sessions, renommer, fork, supprimer et /resume ne croisent plus les projets
  • Correction de SendMessage signalant "Message envoyé" lorsque l'écriture dans la boîte de réception d'un coéquipier avait effectivement échoué ; les livraisons échouées sont désormais signalées comme des erreurs
  • Correction du système de fichiers sandbox refusant les entrées écrites avec une barre oblique finale (par exemple denyRead: "~/.aws/") pouvant être contournées silencieusement sous Linux et macOS
  • Correction des détails de violation du bac à sable n'apparaissant jamais dans les résultats de l'outil Bash ; Claude voit maintenant quel fichier ou accès au réseau a été refusé et pourquoi
  • Correction des outils MCP qui se connectent à mi-tour étant différés pour la recherche d'outils sans que leurs noms soient annoncés au modèle
  • Correction des enregistrements d'installation du plugin étant corrompus silencieusement lorsque le même plugin est installé dans plusieurs projets
  • Correction du contenu de collage rappelé ou restauré, attachant occasionnellement des données erronées ou perdant silencieusement du texte lorsque la pâte avait vieilli ou que les numéros d'espace réservé entraient en collision.
  • Correction de la copie sur sélection sur Wayland n'atteignant parfois pas le tableau clip ; les deux sélections n'écrivent plus de course
  • Correction du partage de transcription de l'enquête de feedback qui échouait silencieusement lors de longues sessions ; un partage échoué affiche désormais une erreur au lieu d'un message de réussite
  • Correction du démarrage automatique de la télécommande qui échouait par intermittence avec "Échec de la récupération des informations d'identification à distance" lors d'un démarrage à froid avec un jeton de connexion périmé.
  • Correction de la télécommande et des SDK clients affichant un message vide "(pas de contenu)" après /clear et d'autres commandes sans sortie
  • Correction d'une session de contrôle à distance recréée après l'expiration de sa session serveur en téléchargeant l'historique des conversations locales précédentes dans la nouvelle session
  • Mode plein écran amélioré pour conserver l'historique complet de pré-compactage en défilement lors de compactages répétés, au lieu de seulement l'intervalle le plus récent
  • Contrôle à distance amélioré : les clients Web et mobiles connectés voient désormais la progression du compactage et la limite post-compactage au lieu d'une pause silencieuse ; Les réinitialisations /clear se propagent désormais aux clients attachés
  • Contrôle à distance amélioré : les échecs de connexion affichent désormais un indicateur d'échec persistant avec des détails et un raccourci de reconnexion, au lieu d'un simple toast de 8 secondes
  • Suppression de la limite d'apparition de 200 sous-agents par session ; les sessions de longue durée ne refusent plus les nouveaux agents (les limites de concurrence et de profondeur s'appliquent toujours)
  • Paramètres gérés modifiés : la demande d'approbation ne réapparaît plus après une reconnexion ou un changement d'organisation lorsque les paramètres de l'organisation sont inchangés.
  • Modification du partage de transcription de l'enquête de rétroaction : avec votre consentement, il télécharge désormais également les paramètres du modèle de la dernière demande : l'invite système (qui inclut vos instructions CLAUDE.md), les définitions d'outils et les paramètres du modèle. Les secrets sont expurgés comme auparavant, et ces champs sont supprimés en premier si le partage est trop volumineux
  • Modification de la description de l'outil Bash pour toujours noter que le résultat de la commande est affiché pour le modèle, et de manière non fiable pour l'utilisateur.
  • Modification des numéros d'espace réservé de collage rappelés pour les renuméroter une fois acceptés dans l'entrée
  • Modification du contrôle à distance pour archiver la session de serveur obsolète au lieu de laisser une session morte répertoriée lorsqu'une nouvelle session est créée après le compactage ou /resume
  • [VSCode] Correction de l'extension affichant la télécommande comme connectée après l'échec de la connexion
  • Correction d'une reprise de session reconnectant silencieusement le contrôle à distance après que l'utilisateur l'ait éteint (hôtes --resume, SDK et extension VS Code)
  • [VSCode] Correction des sessions n'honorant pas remoteControlAtStartup lorsqu'elles sont explicitement activées

claude-code v2.1.224

What's changed

  • Added self-hosted environments: claude self-hosted-runner turns your own machines or containers into a place Claude Code web, mobile, and desktop sessions can run, on Team and Enterprise plans
  • Added archive plugin source: install plugins from a zip over HTTPS without git or npm, with optional SHA-256 pinning
  • Added a cancel-and-confirm step when removing an unavailable paste changes a command's text
  • Added ANTHROPIC_BEDROCK_REGION_PREFIX env var for Bedrock to prefer a specific cross-region inference profile over the AWS_REGION-derived one
  • Added crossSessionInbound and dialogExpiry settings: cross-session messages sent to a session running with bypassed permissions are held for your approval, and messages to other sessions auto-deliver
  • Added sandbox credential-masking options: extract and onExtractNoMatch for structured env values, decode: "jwt" with maskClaims for JWT-aware masking, and awsPairs/sigv4 for AWS SigV4 re-signing; these need network.tlsTerminate and are honored only from user, managed, or --settings settings
  • Added cross-session SendMessage: Claude Code sessions can now message each other, on any of your machines, with ListAgents to discover them (macOS and Linux)
  • Fixed long (>200 char) project paths resolving to another project's session directory under a shared sanitized prefix; session list, rename, fork, delete and /resume no longer cross projects
  • Fixed SendMessage reporting "Message sent" when the write to a teammate's inbox had actually failed; failed deliveries are now reported as errors
  • Fixed sandbox filesystem deny entries written with a trailing slash (e.g. denyRead: "~/.aws/") being silently bypassable on Linux and macOS
  • Fixed sandbox violation details never appearing in Bash tool results; Claude now sees which file or network access was denied and why
  • Fixed MCP tools that connect mid-turn being deferred for tool search without their names announced to the model
  • Fixed plugin install records being silently corrupted when the same plugin is installed in multiple projects
  • Fixed recalled or restored paste content occasionally attaching wrong data or silently losing text when the paste had aged out or placeholder numbers collided
  • Fixed copy-on-select on Wayland sometimes not reaching the clipboard; the two selection writes no longer race
  • Fixed the feedback survey's transcript share silently failing on long sessions; a failed share now shows an error instead of a success message
  • Fixed Remote Control auto-start intermittently failing with "Remote credentials fetch failed" on a cold start with a stale login token
  • Fixed Remote Control and SDK clients showing a blank "(no content)" message after /clear and other output-less commands
  • Fixed a Remote Control session recreated after its server session expired uploading prior local conversation history into the new session
  • Improved fullscreen mode to keep the full pre-compaction history in scrollback across repeated compactions, instead of only the most recent interval
  • Improved Remote Control: attached web and mobile clients now see compaction progress and the post-compaction boundary instead of a silent pause; /clear resets now propagate to attached clients
  • Improved Remote Control: connection failures now show a persistent failure indicator with details and a reconnect shortcut, instead of only an 8-second toast
  • Removed the 200-subagent-per-session spawn cap; long-running sessions no longer refuse new agents (concurrency and depth limits still apply)
  • Changed managed settings: the approval prompt no longer re-appears after re-login or org switching when the organization's settings are unchanged
  • Changed the feedback-survey transcript share: with your consent it now also uploads the last request's model settings — the system prompt (which includes your CLAUDE.md instructions), tool definitions, and model parameters. Secrets are redacted as before, and these fields are dropped first if the share is too large
  • Changed the Bash tool description to always note that command output is displayed to the model, not reliably to the user
  • Changed recalled paste placeholder numbers to renumber when accepted into the input
  • Changed Remote Control to archive the stale server session instead of leaving a dead one listed when a fresh session is minted after compaction or /resume
  • [VSCode] Fixed the extension showing Remote Control as connected after the connection failed
  • Fixed a session resume silently reconnecting Remote Control after the user turned it off (--resume, SDK hosts, and the VS Code extension)
  • [VSCode] Fixed sessions not honoring remoteControlAtStartup when explicitly enabled
