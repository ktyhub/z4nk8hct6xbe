claude-code v2.1.221

code-claude v2.1.221

Qu'est-ce qui a changé

  • [VSCode] Ajout de la vue Focus : une bascule dans le menu de discussion qui masque l'activité de l'outil derrière un résumé extensible par tour avec un indicateur d'outil en cours d'exécution, basculé avec Ctrl+Alt+F ou la commande "Claude Code : Basculer la vue Focus".
  • Ajout de mode: "mask" pour les fichiers d'informations d'identification sandbox sous Linux et WSL — les commandes sandbox lisent une copie sentinelle (le fichier entier, ou uniquement les étendues capturées par une expression régulière extract) tandis que le proxy sandbox remplace la valeur réelle en sortie ; sur macOS, le masquage des fichiers revient à deny
  • Ajout d'avertissements à claude plugin validate lorsqu'un nom de place de marché ou de plugin serait rejeté par la synchronisation de place de marché gérée de Claude Desktop
  • Ajout d'une sous-commande prompt-audit à la compétence claude-api pour l'audit des invites et des descriptions d'outils pour les modèles écrits pour des modèles plus anciens.
  • Correction d'un contournement de vérification des autorisations de l'outil Bash où zsh pouvait exécuter des commandes cachées dans les conditions d'expression régulière [[ ]] ; les commandes concernées demandent désormais l'autorisation
  • Correction de l'autorisation PowerShell qui vérifie les chemins de mauvaise gestion contenant des guillemets sous Windows ; de tels chemins demandent désormais approbation
  • Correction de la bascule de réflexion n'ayant aucun effet pour le reste d'une session commençant par une réflexion ; la désactivation d'un serveur MCP en cours de connexion ne revient plus silencieusement
  • Correction des serveurs MCP de --mcp-config n'étant pas connectés avant le premier passage en mode impression (-p), ce qui faisait que le modèle émettait des appels d'outils sous forme de texte littéral
  • Correction des fichiers mentionnés @ étant supprimés silencieusement lorsque vous appuyez sur Echap pour retirer une invite et la soumettre à nouveau
  • Correction d'un crash lors de la préparation des requêtes API pour les outils MCP SDK nommés d'après les propriétés d'objet intégrées telles que constructor
  • Correction de l'échec de WebSearch avec une erreur 400 lors de l'effort xhigh/max lorsque la réflexion est désactivée
  • Correction des téléchargements volumineux en sandbox échouant avec des erreurs TLS via le proxy sandbox
  • Correction du message de limite de dépenses d'équipe et d'entreprise attribuant à tort la limite mensuelle de l'organisation au lieu de votre limite de dépenses individuelle.
  • Correction de l'authentification Bedrock avec les profils nommés AWS SSO échouant dans les sessions gérées par le bureau sur les machines Windows qui définissaient une variable d'environnement HOME parasite.
  • Correction de CLAUDE_CODE_RESUME_INTERRUPTED_TURN=0 ne désactivant pas la reprise automatique des tours interrompus ; les fausses valeurs sont désormais honorées
  • Correction d'une rare course au réveil où deux processus Claude Code pouvaient tous deux actualiser le même connecteur MCP ou le même jeton WIF OAuth en même temps, forçant une ré-authentification
  • Correction du renommage d'une session depuis Claude Code Desktop ou claude.ai ne mettant pas à jour le nom de session du CLI ; les noms de session de chaque surface de renommage sont désormais nettoyés
  • Correction des compétences fournies par les plugins et les organisations nommées d'après des éléments intégrés au terminal uniquement (par exemple /help, /feedback) étant ininvocables dans les sessions non interactives
  • Correction de la notification "Plugins modifiés" qui persistait après le rechargement des plugins au lieu d'être effacés
  • Correction du mode Vim : le registre Yank survit désormais aux boîtes de dialogue, à la recherche d'historique et à la vue de transcription au lieu d'être vidé silencieusement
  • Correction du mode Vim : l'annulation d'une invite vide active désormais la confirmation "appuyez à nouveau sur ←" avant de revenir à la vue de l'agent.
  • Recherche d'outils améliorée sur Google Vertex AI : réactivée pour Claude 4.5-generation et les modèles plus récents
  • Mode automatique amélioré : les vérifications d'autorisation pour les appels d'outils parallèles sont désormais efficaces dans le cache, et le changement de mode pendant qu'une vérification est en attente invite de manière fiable au lieu d'appliquer le résultat obsolète.
  • Réduction des coûts de mise en cache des invites pour les vérifications d'autorisation en mode automatique en réutilisant le préfixe de conversation mis en cache dans les décisions
  • Panneau de statistiques amélioré pour compter les jetons de cache dans ses totaux de jetons, avec une répartition par entrée, sortie, lecture du cache et écriture du cache
  • Amélioration des messages d'erreur /ultrareview lorsqu'un repo ne partage aucun historique avec sa base : une extraction sans branche est désormais refusée d'avance avec conseil pour en créer une, et les indices de refus ne suggèrent plus git fetch --unshallow sur les clones déjà terminés
  • Démarrage Windows amélioré : les temps de création des processus sont désormais lus via un appel kernel32 natif au lieu de générer PowerShell, de sorte que les outils de sécurité des points de terminaison qui déclenchent powershell.exe ne demandent plus
  • Modification des sessions en arrière-plan pour valider et pousser pour préserver le travail, ouvrir un brouillon de PR uniquement lorsque la tâche l'exige, suivre vos instructions git CLAUDE.md et terminer toujours en signalant où se trouve le travail
  • Modification de /plugin install pour actualiser un catalogue de marché obsolète et réessayer avant de signaler un plugin introuvable
  • Modification des plugins installés depuis /plugin pour s'activer immédiatement en cas de sécurité, au lieu de toujours nécessiter /reload-plugins
  • Modification des plugins pour accepter "." comme chemin skills, et l'erreur de validation SKILL.md au niveau racine suggère désormais d'utiliser la racine du plugin
  • Modification de /status pour afficher le type de session : interactive, ou un travail en arrière-plan attached ou unattended
  • Modification de la saisie semi-automatique des emoji pour accepter les codes courts alternatifs courants tels que :thumbsup:, :thumbsdown: et :love:
  • Modification des sessions avec /fork pour créer leur propre arbre de travail au lieu de travailler dans la caisse de la session d'origine
  • Modification de Claude dans Chrome pour fermer les onglets du navigateur qu'il ouvre une fois qu'il n'en a plus besoin
  • Modification du mode rapide pour signaler sur le flux lorsque les crédits d'utilisation sont épuisés en milieu de session, au lieu d'échouer silencieusement
  • Moniteur modifié : une montre qui se ferme sans produire de sortie l'indique désormais au lieu de signaler "flux terminé".
  • Modification de la validation du champ Gateway model : les valeurs non-string sont rejetées avec un 400 au lieu d'être transmises
  • Suppression de l'avis répété « Mode d'autorisation modifié alors que l'appel du classificateur en mode automatique était en file d'attente » des invites d'approbation

claude-code v2.1.221

What's changed

  • [VSCode] Added Focus view: a chat-menu toggle that hides tool activity behind an expandable per-turn summary with a live running-tool indicator, toggled with Ctrl+Alt+F or the "Claude Code: Toggle Focus view" command
  • Added mode: "mask" for sandbox credential files on Linux and WSL — sandboxed commands read a sentinel copy (the whole file, or just the spans captured by an extract regex) while the sandbox proxy substitutes the real value on egress; on macOS file masking falls back to deny
  • Added warnings to claude plugin validate when a marketplace or plugin name would be rejected by Claude Desktop's managed marketplace sync
  • Added a prompt-audit subcommand to the claude-api skill for auditing prompts and tool descriptions for patterns written for older models
  • Fixed a Bash tool permission-check bypass where zsh could execute hidden commands in [[ ]] regex conditionals; affected commands now prompt for permission
  • Fixed PowerShell permission checks mishandling paths containing quote characters on Windows; such paths now prompt for approval
  • Fixed the thinking toggle having no effect for the rest of a session that started with thinking off; disabling an MCP server mid-connect no longer silently reverts
  • Fixed MCP servers from --mcp-config not being connected before the first turn in print mode (-p), which made the model emit tool calls as literal text
  • Fixed @-mentioned files being silently dropped when pressing Esc to retract a prompt and resubmitting it
  • Fixed a crash when preparing API requests for SDK MCP tools named after built-in object properties such as constructor
  • Fixed WebSearch failing with a 400 error at effort xhigh/max when thinking is disabled
  • Fixed sandboxed large uploads failing with TLS errors through the sandbox proxy
  • Fixed Team and Enterprise spend-limit message incorrectly blaming the org's monthly limit instead of your individual spend limit
  • Fixed Bedrock authentication with AWS SSO named profiles failing in desktop-managed sessions on Windows machines that set a stray HOME environment variable
  • Fixed CLAUDE_CODE_RESUME_INTERRUPTED_TURN=0 not disabling interrupted-turn auto-resume; falsy values are now honored
  • Fixed a rare wake-from-sleep race where two Claude Code processes could both refresh the same MCP connector or WIF OAuth token at once, forcing re-authentication
  • Fixed renaming a session from Claude Code Desktop or claude.ai not updating the CLI's session name; session names from every rename surface are now sanitized
  • Fixed plugin- and org-delivered skills named after terminal-only built-ins (e.g. /help, /feedback) being un-invocable in non-interactive sessions
  • Fixed the "Plugins changed" notification lingering after plugins were reloaded instead of clearing
  • Fixed Vim mode: the yank register now survives dialogs, history search, and the transcript view instead of being silently emptied
  • Fixed Vim mode: undoing back to an empty prompt now arms the "press ← again" confirm before returning to the agent view
  • Improved tool search on Google Vertex AI: re-enabled for Claude 4.5-generation and newer models
  • Improved auto mode: permission checks for parallel tool calls are now cache-efficient, and switching modes while a check is pending reliably prompts instead of applying the stale result
  • Reduced prompt-cache costs for auto-mode permission checks by reusing the cached conversation prefix across decisions
  • Improved Stats panel to count cache tokens in its token totals, with a breakdown by input, output, cache read, and cache write
  • Improved /ultrareview error messages when a repo shares no history with its base: a checkout with no branches is now refused up front with advice to create one, and refusal hints no longer suggest git fetch --unshallow on clones that are already complete
  • Improved Windows startup: process creation times are now read via a native kernel32 call instead of spawning PowerShell, so endpoint security tools that gate powershell.exe no longer prompt
  • Changed background sessions to commit and push to preserve work, open a draft PR only when the task calls for one, follow your CLAUDE.md git instructions, and always end by reporting where the work lives
  • Changed /plugin install to refresh a stale marketplace catalog and retry before reporting a plugin not found
  • Changed plugins installed from /plugin to activate immediately when safe, instead of always requiring /reload-plugins
  • Changed plugins to accept "." as a skills path, and the root-level SKILL.md validation error now suggests using the plugin root
  • Changed /status to show the session kind: interactive, or a background job that is attached or unattended
  • Changed emoji autocomplete to accept common alternate shortcodes like :thumbsup:, :thumbsdown:, and :love:
  • Changed sessions forked with /fork to create a new worktree of their own instead of working in the original session's checkout
  • Changed Claude in Chrome to close the browser tabs it opens once it no longer needs them
  • Changed fast mode to report on the stream when usage credits run out mid-session, instead of failing silently
  • Changed Monitor: a watch that exits without producing any output now says so instead of reporting "stream ended"
  • Changed the Gateway model field validation: non-string values are rejected with a 400 instead of being forwarded
  • Removed the repeated "Permission mode changed while the auto-mode classifier call was queued" notice from approval prompts
