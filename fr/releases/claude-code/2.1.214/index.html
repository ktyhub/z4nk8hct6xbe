claude-code v2.1.214

code-claude v2.1.214

Qu'est-ce qui a changé

  • Correction de dir/** à segment unique permettant des règles telles que Edit(src/**) approuvant automatiquement les écritures dans les répertoires dir/ imbriqués n'importe où dans l'arborescence au lieu de seulement <cwd>/dir
  • Correction d'un contournement de vérification des autorisations affectant les commandes exécutées dans les sessions Windows PowerShell 5.1
  • Correction des contrôles d'autorisation Bash qui échouaient lors de la fermeture des formulaires de redirection de descripteur de fichier que bash analyse différemment de l'analyseur d'autorisations
  • Correction des contrôles d'autorisation Bash qui jugeaient mal les commandes très longues - les commandes de plus de 10 000 caractères demandent désormais toujours au lieu de s'exécuter automatiquement
  • Correction des contrôles d'autorisation Bash traitant les indices et modificateurs de variables zsh dans les comparaisons [[ ]] comme du texte inerte - ces commandes demandent désormais approbation
  • Correction des contrôles d'autorisation Bash pour ne plus approuver automatiquement certaines commandes help et man qui pourraient exécuter des options non sécurisées, des substitutions de commandes ou des chemins de barre oblique inverse
  • Correction des invites d'autorisation sur les sessions à distance qui pouvaient se poursuivre avant la boîte de dialogue de confirmation locale
  • Ajout de l'outil EndConversation : Claude peut mettre fin à des sessions avec des utilisateurs très abusifs ou des tentatives de jailbreak, comme sur claude.ai depuis 2025 — voir https://www.anthropic.com/research/end-subset-conversations
  • Ajout d'un battement de coeur de progression périodique pour les appels d'outils de longue durée qui étaient auparavant silencieux
  • Ajout d'un horodatage ISO modified au premier plan du fichier mémoire
  • Ajout des attributs message.uuid, client_request_id et tool_source aux événements du journal OpenTelemetry pour la corrélation au niveau des messages et la provenance des outils.
  • Ajout de CLAUDE_CODE_OTEL_CONTENT_MAX_LENGTH pour configurer la limite de troncature de 60 Ko sur les attributs de contenu OpenTelemetry
  • Ajout d'un effort de raisonnement à la charge utile subagentStatusLine, afin que les lignes d'agent personnalisées puissent restituer le modèle et l'effort
  • Ajout d'invites d'autorisation pour les commandes docker (y compris le shim Podman docker) portant des indicateurs de redirection de démon (--url, --connection, --identity et mode distant de Podman) qui s'exécutaient auparavant sans un
  • Correction d'un crash lorsqu'une fonctionnalité GrowthBook est évaluée à null, et d'un bug où une charge utile d'indicateur mal formée pouvait effacer les indicateurs de fonctionnalité mis en cache
  • Correction de l'outil Bash tuant la session Claude lorsqu'un modèle pkill -f correspondait accidentellement au propre processus du CLI (Linux)
  • Correction d'une croissance de mémoire illimitée lorsque --settings pointe vers un fichier de périphérique ou un fichier de plusieurs Go ; Les fichiers de paramètres surdimensionnés (> 2 Mio) échouent désormais au démarrage avec une erreur claire
  • Correction de l'échec des tours de streaming avec "Le socket est fermé" derrière les proxys d'entreprise sous Windows
  • Correction de la troncature de sortie du flux json à la sortie pour les consommateurs SDK/pipeline à lecture lente ; le drain de sortie évolue désormais avec les octets en file d'attente au lieu d'un plafond plat de 2 secondes
  • Correction des tâches planifiées refusant leur propre invite configurée comme entrée non rusted - l'invite déclenchée est désormais transmise en tant que tâche assignée à la session.
  • Correction des commandes de l'outil PowerShell suspendues jusqu'à l'expiration du délai lorsqu'un processus enfant attendait une entrée standard (Windows)
  • Correction des scripts Python sous l'outil PowerShell qui plantaient avec UnicodeDecodeError lors de la lecture de données non UTF-8 à partir d'une entrée standard (Windows)
  • Correction des scripts Python exécutés via l'outil PowerShell qui plantaient avec UnicodeEncodeError sur une sortie non-ASCII et des messages d'erreur PowerShell 7 contenant des séquences d'échappement ANSI brutes (Windows)
  • Correction de l'outil PowerShell signalant where.exe, fc.exe et diff.exe comme erreurs lorsqu'ils renvoient une réponse négative valide (Windows)
  • Correction de > et >> sous l'outil PowerShell sous Windows PowerShell 5.1 écrivant des fichiers UTF-16LE que d'autres outils ne pouvaient pas lire en UTF-8
  • Correction d'un démon d'arrière-plan déplacé supprimant le socket de contrôle de son successeur à l'arrêt, ce qui obligeait le prochain client à tuer le démon de remplacement sain.
  • Correction des sessions en arrière-plan garées avec ← ou /background et laissées inactives, gardant le démon en arrière-plan et un processus de travail en vie indéfiniment
  • Correction des sessions en arrière-plan terminées, impossibles à supprimer via claude rm ou la vue agent une fois le service en arrière-plan devenu inactif
  • Correction des sessions en arrière-plan envoyées à partir d'un dossier non-git étant impossible à supprimer de la vue des agents
  • Correction de la réouverture d'une session en arrière-plan arrêtée qui ne parvenait pas à restaurer sa conversation enregistrée lorsqu'un dossier illisible existe dans le magasin de session
  • Correction du déclenchement de la notification push "session prête" du contrôle à distance pour les sessions où le contrôle à distance n'était pas explicitement activé
  • Correction du blocage de /install-github-app et du menu de paramètres /mcp dans les sessions avec vue agent - ils sont désormais refusés uniquement dans les sessions en arrière-plan sans terminal connecté.
  • Correction des plugins activés via le flag --settings CLI ne se chargeant pas (régression depuis v2.1.181)
  • Correction des indicateurs de fonctionnalité devenant obsolètes lors de sessions de longue durée après la rotation du jeton OAuth
  • Correction de /ultrareview refusant de s'exécuter dans les dépôts sans base de fusion — il propose désormais de revoir tous les fichiers suivis
  • Correction du blocage silencieux de claude update et claude doctor et de la section de diagnostic du système /status devenant vide lorsqu'un chemin de configuration du shell est un répertoire.
  • Correction des valeurs de mémoire de premier plan étant tronquées silencieusement sur un # en ligne lorsque les fichiers de mémoire sont enregistrés
  • Coût de session fixe et double comptage de télémétrie de jeton sur les flux qui émettent plusieurs trames message_delta cumulées
  • Correction d'un faux avertissement « vérifiez votre réseau » qui apparaissait pendant que le conseiller réfléchissait
  • Correction des hooks avec le code de sortie 2 ne bloquant pas comme indiqué lorsque la sortie standard JSON du hook échoue à la validation du schéma
  • Correction des événements de journal OTel émis en dehors du contexte asynchrone du tour manquant le contexte de trace de l'intervalle d'interaction
  • Correction d'erreurs transitoires MCP lors de l'actualisation des invites/ressources, effaçant les commandes et les ressources slash du serveur
  • Amélioration de l'erreur claude rc workspace-trust dans le répertoire personnel pour indiquer que trust n'est jamais enregistré et pour suggérer de l'exécuter à partir d'un répertoire de projet.
  • Modification des conditions du crochet if: à segment unique dir/** pour correspondre uniquement au <cwd>/dir ; écrivez **/dir/** pour une correspondance de toute profondeur. Les règles d'autorisation deny/ask conservent leur correspondance quelle que soit la profondeur.
  • Modification des commandes file en utilisant -m/--magic-file ou -f/--files-from pour exiger une autorisation au lieu d'être automatiquement autorisée en lecture seule.
  • Modification du regroupement de connexions persistantes pour le désactiver après une erreur de connexion obsolète, donc réessayez d'ouvrir un nouveau socket
  • Modification des hooks SessionStart pour signaler la source "fork" lorsqu'une session commence comme un fork au lieu de "resume"

claude-code v2.1.214

What's changed

  • Fixed single-segment dir/** allow rules like Edit(src/**) auto-approving writes to nested dir/ directories anywhere in the tree instead of only <cwd>/dir
  • Fixed a permission-check bypass affecting commands run in Windows PowerShell 5.1 sessions
  • Fixed Bash permission checks to fail closed on file-descriptor redirect forms that bash parses differently than the permission analyzer
  • Fixed Bash permission checks misjudging very long commands — commands over 10,000 characters now always prompt instead of running automatically
  • Fixed Bash permission checks treating zsh variable subscripts and modifiers in [[ ]] comparisons as inert text — these commands now prompt for approval
  • Fixed Bash permission checks to no longer auto-approve certain help and man commands that could run unsafe options, command substitutions, or backslash paths
  • Fixed permission prompts on remote sessions that could proceed before the local confirmation dialog
  • Added the EndConversation tool: Claude can end sessions with highly abusive users or jailbreak attempts, as on claude.ai since 2025 — see https://www.anthropic.com/research/end-subset-conversations
  • Added a periodic progress heartbeat for long-running tool calls that previously went silent
  • Added an ISO modified timestamp to memory file frontmatter
  • Added message.uuid, client_request_id, and tool_source attributes to OpenTelemetry log events for message-level correlation and tool provenance
  • Added CLAUDE_CODE_OTEL_CONTENT_MAX_LENGTH to configure the 60 KB truncation limit on OpenTelemetry content attributes
  • Added reasoning effort to the subagentStatusLine payload, so custom agent rows can render model and effort
  • Added permission prompts for docker commands (including the Podman docker shim) carrying daemon-redirect flags (--url, --connection, --identity, and Podman's remote mode) that previously ran without one
  • Fixed a crash when a GrowthBook feature evaluates to null, and a bug where a malformed flag payload could wipe the cached feature flags
  • Fixed Bash tool killing the Claude session when a pkill -f pattern accidentally matched the CLI's own process (Linux)
  • Fixed unbounded memory growth when --settings points at a device file or multi-GB file; oversized (>2 MiB) settings files now fail at startup with a clear error
  • Fixed streaming turns failing with "Socket is closed" behind corporate proxies on Windows
  • Fixed stream-json output truncation at exit for slow-reading SDK/pipeline consumers; the exit drain now scales with queued bytes instead of a flat 2s cap
  • Fixed scheduled tasks refusing their own configured prompt as untrusted input — the fired prompt is now delivered as the session's assigned task
  • Fixed PowerShell tool commands hanging until timeout when a child process waited on standard input (Windows)
  • Fixed Python scripts under the PowerShell tool crashing with UnicodeDecodeError when reading non-UTF-8 data from standard input (Windows)
  • Fixed Python scripts run via the PowerShell tool crashing with UnicodeEncodeError on non-ASCII output, and PowerShell 7 error messages containing raw ANSI escape sequences (Windows)
  • Fixed the PowerShell tool reporting where.exe, fc.exe, and diff.exe as errors when they return a valid negative answer (Windows)
  • Fixed > and >> under the PowerShell tool on Windows PowerShell 5.1 writing UTF-16LE files that other tools couldn't read as UTF-8
  • Fixed a displaced background daemon deleting its successor's control socket on shutdown, which made the next client kill the healthy replacement daemon
  • Fixed background sessions parked with ← or /background and left idle keeping the background daemon and a worker process alive indefinitely
  • Fixed completed background sessions being impossible to remove via claude rm or the agent view once the background service had gone idle
  • Fixed background sessions dispatched from a non-git folder being impossible to delete from the agents view
  • Fixed reopening a stopped background session failing to restore its saved conversation when an unreadable folder exists in the session store
  • Fixed the Remote Control "session ready" push notification firing for sessions where Remote Control was not explicitly enabled
  • Fixed /install-github-app and the /mcp settings menu being blocked in agent-view sessions — they're now refused only in background sessions with no terminal attached
  • Fixed plugins enabled via the --settings CLI flag not loading (regression since v2.1.181)
  • Fixed feature flags going stale in long-running sessions after the OAuth token rotates
  • Fixed /ultrareview refusing to run in repos with no merge base — it now offers to review all tracked files
  • Fixed claude update and claude doctor hanging silently, and the /status System diagnostics section going blank, when a shell-config path is a directory
  • Fixed memory frontmatter values being silently truncated at an inline # when memory files are saved
  • Fixed session cost and token telemetry double-counting on streams that emit multiple cumulative message_delta frames
  • Fixed a spurious "check your network" warning that appeared while the advisor was thinking
  • Fixed hooks with exit code 2 not blocking as documented when the hook's stdout JSON fails schema validation
  • Fixed OTel log events emitted outside the turn's async context missing the interaction span's trace context
  • Fixed MCP transient errors during prompts/resources refresh clearing the server's slash commands and resources
  • Improved the claude rc workspace-trust error in the home directory to say trust there is never saved and to suggest running from a project directory
  • Changed single-segment dir/** hook if: conditions to match only <cwd>/dir; write **/dir/** for any-depth matching. deny/ask permission rules keep their any-depth match.
  • Changed file commands using -m/--magic-file or -f/--files-from to require permission instead of being auto-allowed as read-only
  • Changed keep-alive connection pooling to disable after a stale-connection error, so retries open a fresh socket
  • Changed SessionStart hooks to report source "fork" when a session begins as a fork instead of "resume"
