claude-code v2.1.301

code-claude v2.1.301

Qu'est-ce qui a changé

  • Ajout de CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS afin que le mode de nouvelle tentative sans surveillance (CLAUDE_CODE_RETRY_WATCHDOG) mette fin à une requête à une limite d'utilisation qui se réinitialise trop loin au lieu d'attendre
  • Ajout du guidage de traçage OpenTelemetry à la compétence claude-api, y compris la configuration des destinations de trace avec le ant CLI
  • Ajout du mouvement % en mode vim : sautez vers le support correspondant, seul ou avec d/c/y
  • Ajout de rows au Input d'un mod : un champ de texte de plusieurs lignes dans le terminal, où Enter soumet et Shift+Entrée ou une barre oblique inverse avant que Enter ne démarre une nouvelle ligne
  • Ajout des événements classifier_verdict et permission_mode aux événements OpenTelemetry tool_decision, afin que les décisions du classificateur en mode automatique puissent être distinguées des règles d'autorisation
  • Ajout des événements classifier_category aux événements OpenTelemetry tool_decision, nommant la règle intégrée à laquelle correspond un bloc classificateur, lorsque OTEL_LOG_TOOL_DETAILS=1
  • Correction de l'arrêt de la suppression d'un arbre de travail créé par un hook WorktreeCreate sans demander quand il peut contenir des validations non poussées
  • Correction de l'erreur d'alias de modèle fable (et best) sur l'Anthropic API lorsque le dernier modèle Fable n'est pas disponible pour votre organisation : Claude Code réessaye désormais une fois sur le modèle Fable précédent
  • Correction d'une erreur trompeuse « Veuillez exécuter /login » lorsqu'un disque plein empêche l'actualisation de la connexion ; l'erreur nomme maintenant le disque et dit de supprimer les fichiers
  • Correction de Grep et Glob ne signalant aucune correspondance lorsque le programme de recherche échouait de manière inattendue avant de renvoyer des résultats ; ils renvoient maintenant une erreur indiquant que la recherche a échoué
  • Correction des agents de flux de travail sautant parfois leur étape et l'exécution signalant toujours un succès, après avoir lu le harnais, notez que le texte de leur tâche ne comporte aucune autorité utilisateur.
  • Correction des mises à jour d'artefacts refusées lorsqu'un hook PreToolUse couvre l'édition ou l'écriture ; Claude édite maintenant le fichier puis le republie au lieu de le modifier lors de l'appel de publication
  • Correction des compétences et des commandes avec des noms d'arguments très nombreux ou très longs qui bloquaient pendant quelques secondes lorsqu'elles étaient invoquées ; seuls les 64 premiers noms, chacun comportant jusqu'à 64 caractères, sont désormais renseignés
  • Correction des compétences, commandes et hooks utilisant de très grandes quantités de mémoire lorsque leurs arguments remplissent de nombreux espaces réservés
  • Correction des caractères parasites tels que >0q couvrant l'invite du dossier trust et >4m avant l'invite du shell à la sortie, dans les terminaux construits sur VTE plus anciens que 0.53 tels que le terminal MATE sur RHEL 8
  • Correction du texte GOK parasite apparaissant dans l'invite au démarrage dans certaines versions d'iTerm2
  • Correction du passage à un modèle dont le nom contient application-inference-profile exécutant votre commande awsAuthRefresh et retardant les hooks de changement de modèle lorsque le fournisseur n'est pas Bedrock
  • Correction des délais d'expiration de l'actualisation de connexion et des déconnexions inattendues après la sortie d'une courte commande telle que claude auth status ou claude plugin list au milieu d'une actualisation de jeton.
  • Correction d'un appel d'outil interrompu par un message envoyé à mi-tour lors de sa vérification d'autorisation étant signalé au modèle comme rejeté par l'utilisateur
  • Correction d'un cas où le passage à un modèle avec une fenêtre contextuelle plus petite pouvait dépenser des crédits d'utilisation sur un résumé du modèle précédent sans demander au préalable
  • Correction des conversations compactées encore et encore, sur un modèle que vous n'aviez pas choisi, derrière une passerelle LLM dont les réponses nomment un modèle différent de celui demandé
  • Correction du mode vim restant parfois en INSERT après Escape sur une machine lente ou occupée
  • Correction de Esc rejetant une réponse AskUserQuestion tapée en mode vim : le champ de texte libre prend désormais en charge le mode vim NORMAL, et Esc s'annule uniquement à partir de NORMAL.
  • Correction de l'outil de lecture lisant les fichiers binaires tels que .xlsm, .parquet, .epub et .heic sous forme de texte
  • Correction d'un tableau Markdown avec seulement une ligne d'en-tête ne dessinant rien lorsqu'elle était trop large pour le terminal, y compris dans les plans sur la carte d'approbation du plan
  • Correction de la compétence /claude-api indiquant que les points de terminaison à clé externe CMEK ne sont pas disponibles sur la plateforme Claude sur AWS
  • Correction des compétences n'étant plus répertoriées sur le modèle après avoir utilisé /rewind
  • Correction de la ligne de compactage dans une session reprise proposant ctrl+o pour l'historique qui n'est pas chargé ; il indique maintenant où les messages précédents sont enregistrés et s'affiche également en plein écran
  • Correction de l'indice "nouvelle tâche ? /effacer pour enregistrer les jetons" qui revenait juste après avoir interrompu une réponse
  • Correction de l'invite d'autorisation pour la décision ask d'un plugin ou d'un hook de compétence n'affichant pas de quel plugin ou compétence le hook provient
  • Correction de /diff ne remarquant pas un choix de cerises en conflit ou un retour dans les référentiels reftables lorsqu'une de ses vérifications git expirait ou échouait
  • Correction des scripts de workflow demandant l'autorisation ou étant refusés lors de la lecture, de la modification ou de la réexécution après un Bash cd dans la même session
  • Correction du texte grisé sur le thème ANSI sombre et les terminaux à 16 couleurs : pâle à l'intérieur des cases remplies, pas pâle sous les surlignages de sélection et de recherche, et descriptions de liste grisées comme tout autre texte secondaire
  • Correction du $.model.fork d'un mod renvoyant nothing-to-fork lorsqu'il était appelé avant la fin de la première réponse d'un nouveau processus Claude Code, comme dans les exécutions et les sessions cloud de claude -p
  • Mode plein écran : correction de /compact et compactage automatique, gelant brièvement l'interface utilisateur pendant que la transcription visible est reconstruite
  • Exécuteur auto-hébergé : correction des sessions démarrées à partir de Slack, incapables de trouver ou d'attacher un référentiel lorsque les paramètres gérés restreignent les serveurs MCP ; utilisez deniedMcpServers pour garder ces outils désactivés
  • Exécuteur auto-hébergé : correction des sessions signalées comme ayant une branche source supprimée, et non réessayées, lorsqu'une configuration sans rapport ou un échec de session citait le libellé de référence manquante de git.
  • Exécuteur auto-hébergé : correction du journal promettant une nouvelle tentative d'une version de session échouée ou déclined pour une session qui se termine ; les échecs répétés affichent désormais un décompte
  • Windows : correction des commandes PowerShell en arrière-plan arrêtées, manquant la ligne de fermeture [killed] dans leur fichier de sortie
  • Amélioration du passage à un modèle avec une fenêtre contextuelle plus petite : une conversation trop longue pour le nouveau modèle est désormais résumée en premier par le modèle précédent
  • Amélioration des performances de rendu pendant le fonctionnement d'un sous-agent de longue durée : sa trace de progression est désormais mise à jour de manière incrémentielle au lieu d'être retraitée intégralement à chaque rendu.
  • Artefacts améliorés : les pages écrites par Claude peignent désormais la bande au-dessus d'un en-tête collant, donc le texte défilé n'y apparaît plus dans les applications mobiles
  • Mods améliorés : dans VS Code et dans les applications de bureau et mobiles, un arbre dessiné au-dessus de la boîte de dialogue de question peut désormais contenir Markdown et jusqu'à 48 lignes ; le terminal conserve 12 lignes simples
  • Modification du gestionnaire .catch d'un hook de mod pour qu'il s'exécute uniquement lorsque le hook est lancé ou expire ; les événements déclenchés sous les propres appels du hook ignorent désormais ce hook sans demander à son .catch
  • Modification du $.env.set d'un mod pour qu'il soit résolu avec {} une fois que la variable est définie ou non, ou avec { deny } indiquant pourquoi lorsque l'écriture n'est pas effectuée.
  • [VSCode] Ajout du rendu mathématique LaTeX dans les réponses de Claude, y compris les blocs $$ et \[ … \] multilignes et les mathématiques en ligne $…$ et \(…\)
  • [VSCode] Ajout d'un lien "Obtenir plus d'utilisation" à la bannière de limite d'utilisation pour les forfaits Pro et Max dans les panneaux VS Code et JetBrains
  • [VSCode] Correction d'une conversation qui plante ou gèle le panneau étant rouvert à chaque rechargement
  • [VSCode] Correction du ralentissement du panneau de discussion lors d'une longue réflexion : il ne réanalyse plus l'intégralité du texte de réflexion à chaque mise à jour
  • [VSCode] Correction des diagnostics affichant "[object Object]" au lieu du code de règle (par exemple MD013) pour certains serveurs de langue
  • [VSCode] Correction du module audio de dictée natif en cours de chargement, pour vérifier l'autorisation du microphone, là où la dictée n'est pas proposée (connexions non-claude.ai, fenêtres distantes)

claude-code v2.1.301

What's changed

  • Added CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS so unattended retry mode (CLAUDE_CODE_RETRY_WATCHDOG) ends a request at a usage limit that resets too far away instead of waiting
  • Added OpenTelemetry tracing guidance to the claude-api skill, including setting up trace destinations with the ant CLI
  • Added the % motion to vim mode: jump to the matching bracket, alone or with d/c/y
  • Added rows to a mod's Input: a text field of several lines in the terminal, where Enter submits and Shift+Enter or a backslash before Enter starts a new line
  • Added classifier_verdict and permission_mode to OpenTelemetry tool_decision events, so auto mode classifier decisions can be told apart from permission rules
  • Added classifier_category to OpenTelemetry tool_decision events, naming the built-in rule a classifier block matched, when OTEL_LOG_TOOL_DETAILS=1
  • Fixed quitting removing a worktree made by a WorktreeCreate hook without asking when it may hold unpushed commits
  • Fixed the fable (and best) model alias erroring on the Anthropic API when the newest Fable model is not available to your organization: Claude Code now retries once on the previous Fable model
  • Fixed a misleading "Please run /login" error when a full disk keeps the login from being refreshed; the error now names the disk and says to delete files
  • Fixed Grep and Glob reporting no matches when the search program failed unexpectedly before returning any results; they now return an error saying the search failed
  • Fixed workflow agents sometimes skipping their step, and the run still reporting success, after reading the harness note that their task text carries no user authority
  • Fixed artifact updates being refused where a PreToolUse hook covers Edit or Write; Claude now edits the file and then republishes instead of changing it in the publish call
  • Fixed skills and commands with very many or very long argument names stalling for seconds when invoked; only the first 64 names, each up to 64 characters, are now filled in
  • Fixed skills, commands and hooks using very large amounts of memory when their arguments fill many placeholders
  • Fixed stray characters such as >0q covering the folder trust prompt, and >4m before the shell prompt at exit, in terminals built on VTE older than 0.53 such as MATE Terminal on RHEL 8
  • Fixed stray GOK text appearing in the prompt at startup in some versions of iTerm2
  • Fixed switching to a model whose name contains application-inference-profile running your awsAuthRefresh command and delaying model-switch hooks when the provider is not Bedrock
  • Fixed sign-in refresh timeouts and unexpected sign-outs after a short command such as claude auth status or claude plugin list exited in the middle of a token refresh
  • Fixed a tool call cut off by a message sent mid-turn during its permission check being reported to the model as rejected by the user
  • Fixed a case where switching to a model with a smaller context window could spend usage credits on a summary by the previous model without asking first
  • Fixed conversations being compacted over and over, on a model you didn't pick, behind an LLM gateway whose responses name a different model than the one requested
  • Fixed vim mode sometimes staying in INSERT after Escape on a slow or busy machine
  • Fixed Esc discarding a typed AskUserQuestion answer in vim mode: the free-text field now supports vim NORMAL mode, and Esc cancels only from NORMAL
  • Fixed the Read tool reading binary files such as .xlsm, .parquet, .epub and .heic as text
  • Fixed a Markdown table with only a header row drawing nothing when too wide for the terminal, including in plans on the plan approval card
  • Fixed the /claude-api skill saying CMEK external-key endpoints aren't available on Claude Platform on AWS
  • Fixed skills no longer being listed to the model after using /rewind
  • Fixed the compaction row in a resumed session offering ctrl+o for history that is not loaded; it now says where the earlier messages are saved, and also shows in fullscreen
  • Fixed the "new task? /clear to save tokens" hint coming back right after you interrupt a response
  • Fixed the permission prompt for a plugin or skill hook's ask decision not showing which plugin or skill the hook comes from
  • Fixed /diff not noticing a conflicted cherry-pick or revert in reftable repositories when one of its git checks timed out or failed
  • Fixed workflow scripts asking for permission or being refused when read, edited or re-run after a Bash cd in the same session
  • Fixed dim text on the dark ANSI theme and 16-color terminals: faint inside filled boxes, not faint under selection and search highlights, and list descriptions dimmed like other secondary text
  • Fixed a mod's $.model.fork returning nothing-to-fork when called before the first response of a new Claude Code process had finished, as in claude -p runs and cloud sessions
  • Fullscreen mode: Fixed /compact and auto-compact briefly freezing the UI while the visible transcript is rebuilt
  • Self-hosted runner: Fixed sessions started from Slack being unable to find or attach a repository when managed settings restrict MCP servers; use deniedMcpServers to keep those tools off
  • Self-hosted runner: Fixed sessions being reported as having a deleted source branch, and not retried, when an unrelated setup or session failure quoted git's missing-ref wording
  • Self-hosted runner: Fixed the log promising a retry of a failed or declined session release for a session that is ending; repeated failures now show a count
  • Windows: Fixed stopped background PowerShell commands missing the closing [killed] line in their output file
  • Improved switching to a model with a smaller context window: a conversation too long for the new model is now summarized by the previous model first
  • Improved rendering performance while a long-running subagent works: its progress trail now updates incrementally instead of being reprocessed in full on every render
  • Improved artifacts: pages Claude writes now paint the band above a sticky header, so scrolled text no longer shows there in the mobile apps
  • Improved mods: in VS Code and the desktop and mobile apps, a tree drawn above the question dialog can now hold Markdown and up to 48 rows; the terminal keeps 12 plain rows
  • Changed a mod hook's .catch handler to run only when the hook throws or times out; events raised beneath the hook's own calls now skip that hook without asking its .catch
  • Changed a mod's $.env.set to resolve with {} once the variable is set or unset, or with { deny } saying why when the write is not made
  • [VSCode] Added LaTeX math rendering in Claude's responses, including $$ and multi-line \[ … \] blocks and inline $…$ and \(…\) math
  • [VSCode] Added a "Get more usage" link to the usage-limit banner for Pro and Max plans in the VS Code and JetBrains panels
  • [VSCode] Fixed a conversation that crashes or freezes the panel being reopened on every reload
  • [VSCode] Fixed the chat panel slowing down during long thinking: it no longer re-parses the whole thinking text on every update
  • [VSCode] Fixed diagnostics showing "[object Object]" instead of the rule code (e.g. MD013) for some language servers
  • [VSCode] Fixed the native dictation audio module being loaded, to check microphone permission, where dictation is not offered (non-claude.ai sign-ins, remote windows)
