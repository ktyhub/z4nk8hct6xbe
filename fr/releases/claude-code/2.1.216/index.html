claude-code v2.1.216

code-claude v2.1.216

Qu'est-ce qui a changé

  • Ajout du paramètre sandbox.filesystem.disabled pour ignorer l'isolation du système de fichiers tout en gardant le contrôle de sortie du réseau
  • Correction d'un ralentissement dans les longues sessions où le coût de normalisation des messages augmentait quadratiquement avec le nombre de tours, provoquant des blocages de plusieurs secondes et des reprises lentes.
  • Correction du refus des commandes en mode automatique avec des erreurs de classificateur "HTTP 401" après l'expiration du jeton OAuth ou une rotation en cours de session
  • Correction de AskUserQuestion indiquant à Claude de continuer même lorsque votre réponse lui demandait d'attendre ou d'expliquer en premier — les réponses en texte libre ont désormais une formulation neutre
  • Correction de Claude Code sur le Web qui posait à nouveau la même question et abandonnait votre réponse après que la session soit restée inactive pendant quelques minutes
  • Correction des @-mentions n'attachant rien silencieusement après les hooks de modification de fichier, la répétition de points vim des opérateurs c et le collage, la ligne d'état s'exécutant deux fois lors de la reprise et le sélecteur de reprise se bloque en cas d'échec
  • Correction des sessions d'agent en arrière-plan revenant à l'agent par défaut : l'invite de l'agent et les restrictions d'outils sont désormais restaurées.
  • Correction des sous-agents isolés de l'arbre de travail redirigeant git vers la caisse partagée via git -C, --git-dir ou GIT_DIR/GIT_WORK_TREE
  • Correction des sessions d'arbre de travail atterrissant dans l'arbre de travail restant d'un autre projet lorsque le répertoire de travail ne correspondait pas au projet sélectionné
  • Correction des sessions en arrière-plan dont l'arbre de travail n'a pas de référentiel git et qui ne peuvent pas être supprimés.
  • Correction de claude daemon stop --any mettant potentiellement fin à un processus non lié via un fichier de verrouillage de démon hérité obsolète
  • Correction de Esc-Esc à une invite d'inactivité n'ouvrant pas le sélecteur de rembobinage lors de sessions de longue durée avec des tâches en arrière-plan
  • Correction de l'autorisation de la commande Bash vérifiant les instructions composées avec des redirections dans les listes ou négations &&
  • Correction du fait d'appuyer deux fois sur Ctrl+X dans la liste des agents, l'échec de la suppression d'une session et les sessions supprimées réapparaissant lorsque leur travailleur en arrière-plan était décédé
  • Correction des sous-agents en arrière-plan annulés lorsqu'un message hautement prioritaire arrive pendant leur fenêtre de démarrage
  • Correction des erreurs de souris et de focus dans le terminal lorsqu'un éditeur GUI de /memory, /plan, /keybindings ou Ctrl+G est ouvert ; /memory n'attend plus la fermeture de l'éditeur
  • Correction du bouclage Claude-in-Chrome 403 lors de la reconnexion lorsque le jeton OAuth de la session n'a pas la portée requise
  • Correction des sauvegardes de flux de travail et des écritures de tâches planifiées suite à un lien symbolique sur .claude, ce qui pouvait rediriger les écritures en dehors du projet
  • Correction de la réauthentification MCP révoquant les informations d'identification de travail avant la réussite de la nouvelle connexion, et le message de reconnexion nécessite une authentification dans les sessions en arrière-plan pointant vers une commande inutilisable
  • Correction des commandes en lecture seule sur Windows accédant aux chemins réseau sans invite d'autorisation
  • Correction de l'analyse des commandes Bash des caractères non-ASCII pour correspondre aux limites réelles des mots shell
  • Correction de la validation des autorisations de l'outil PowerShell pour les commandes contenant des caractères Unicode invisibles
  • Correction des boîtes de dialogue en mode plein écran s'étendant au-delà du bord droit de leur panneau
  • Correction de la liste des paramètres du /config en mode plein écran cli en plaçant son pied de page d'indice de clavier
  • Correction de l'habillage du pied de page en mode transcription (Ctrl+O) sur les terminaux de moins de 104 colonnes
  • Correction du point de terminaison des métriques Prometheus (OTEL_METRICS_EXPORTER=prometheus) émettant des lignes # UNIT invalides
  • Correction des compétences et commandes modifiées au cours d'une session n'apparaissant pas dans le menu slash jusqu'au redémarrage
  • Correction des compétences de plugin avec un champ frontal name perdant leur préfixe de plugin dans la saisie semi-automatique de la commande slash
  • Correction des refus d'autorisation signalés par la télémétrie : les demandes d'invite d'autorisation ayant échoué ne comptent plus comme des rejets de l'utilisateur, et les interruptions de l'utilisateur sont désormais signalées comme des abandons de l'utilisateur au lieu de rejets.
  • Amélioration de la confirmation /fork à une seule ligne avec le nom de la nouvelle session, l'identifiant claude attach et une note lorsque la copie partage votre paiement
  • Amélioration de la validation des arguments des commandes git et gh dans l'outil PowerShell
  • Amélioration de l'erreur de diff trop grande /ultrareview pour afficher les limites configurées, la taille de diff mesurée et les fichiers contributeurs les plus volumineux.
  • Amélioration du message vide-diff /code-review ultra pour nommer la référence de base exacte et suggérer de passer une base explicite
  • Amélioration de l'invite d'ajustement de la limite de dépenses pour afficher la raison du serveur lorsqu'une modification de la limite de dépenses est rejetée.
  • /context affiche désormais un avertissement explicite lorsque la conversation dépasse la fenêtre contextuelle, et un /compact défaillant s'affiche comme une erreur
  • /rewind ne restaure ou ne supprime plus les fichiers via des liens symboliques ou des liens physiques sur les chemins suivis et indique le nombre de chemins ignorés
  • Sessions en arrière-plan : /mcp et /install-github-app garent désormais une requête "besoin d'entrée" dans la vue agent lorsqu'aucun client n'est attaché
  • Mise à jour de la compétence de visualisation de données intégrée : réorganisation de la palette de graphiques par défaut et correction des instructions suggérant des étiquettes directes pour les graphiques à quatre séries.
  • [VSCode] Correction du rendu du texte de droite à gauche (arabe, hébreu, persan) dans le mauvais ordre lorsqu'il est mélangé avec de l'anglais ou du code
  • Correction des sessions cloud supprimant le message en vol lorsque le conteneur de la session redémarre à mi-tour - le tour interrompu se réexécute désormais à la reprise au lieu de laisser la session sans réponse

claude-code v2.1.216

What's changed

  • Added sandbox.filesystem.disabled setting to skip filesystem isolation while keeping network egress control
  • Fixed a slowdown in long sessions where message normalization cost grew quadratically with the number of turns, causing multi-second stalls and slow resumes
  • Fixed auto mode denying commands with "HTTP 401" classifier errors after the OAuth token expired or rotated mid-session
  • Fixed AskUserQuestion telling Claude to continue even when your answer asked it to wait or explain first — free-text answers now get neutral wording
  • Fixed Claude Code on the web re-asking the same question and dropping your answer after the session sat idle for a few minutes
  • Fixed @-mentions silently attaching nothing after file-modifying hooks, vim dot-repeat of c-operators and paste, statusline running twice on resume, and resume-picker hangs on failure
  • Fixed resumed background agent sessions reverting to the default agent: the agent's prompt and tool restrictions are now restored
  • Fixed worktree-isolated subagents redirecting git into the shared checkout via git -C, --git-dir, or GIT_DIR/GIT_WORK_TREE
  • Fixed worktree sessions landing in another project's leftover worktree when the working directory did not match the selected project
  • Fixed background sessions whose worktree has no git repository being undeletable
  • Fixed claude daemon stop --any potentially terminating an unrelated process via a stale legacy daemon lockfile
  • Fixed Esc-Esc at an idle prompt not opening the rewind picker in long-running sessions with background tasks
  • Fixed Bash command permission checking for compound statements with redirects inside && lists or negations
  • Fixed pressing Ctrl+X twice in the agent list failing to delete a session, and deleted sessions reappearing when their background worker had died
  • Fixed background subagents getting cancelled when a high-priority message arrives during their startup window
  • Fixed mouse and focus garbage in the terminal while a GUI editor from /memory, /plan, /keybindings, or Ctrl+G is open; /memory no longer waits for the editor to close
  • Fixed Claude-in-Chrome 403-looping on reconnect when the session's OAuth token lacks a required scope
  • Fixed workflow saves and scheduled-task writes following a symlink at .claude, which could redirect writes outside the project
  • Fixed MCP re-authenticate revoking working credentials before the new sign-in succeeds, and the reconnect needs-auth message in background sessions pointing at an unusable command
  • Fixed read-only commands on Windows accessing network paths without a permission prompt
  • Fixed Bash command parsing of non-ASCII characters to match real shell word boundaries
  • Fixed PowerShell tool permission validation of commands containing invisible Unicode characters
  • Fixed dialogs in fullscreen mode stretching past the right-hand edge of their panel
  • Fixed the /config settings list in fullscreen mode clipping its keyboard-hint footer
  • Fixed the transcript-mode (Ctrl+O) footer hint wrapping on terminals narrower than 104 columns
  • Fixed the Prometheus metrics endpoint (OTEL_METRICS_EXPORTER=prometheus) emitting invalid # UNIT lines
  • Fixed skills and commands changed during a session not appearing in the slash menu until restart
  • Fixed plugin skills with a name frontmatter field losing their plugin prefix in slash-command autocomplete
  • Fixed telemetry misreporting permission denials: failed permission-prompt requests no longer count as user rejections, and user interrupts are now reported as user aborts instead of rejections
  • Improved the /fork confirmation to one line with the new session's name, claude attach id, and a note when the copy shares your checkout
  • Improved validation of git and gh command arguments in the PowerShell tool
  • Improved the /ultrareview diff-too-large error to show configured limits, measured diff size, and largest contributing files
  • Improved /code-review ultra empty-diff message to name the exact base ref and suggest passing an explicit base
  • Improved the spend limit adjustment prompt to show the server's reason when a spend limit change is rejected
  • /context now shows an explicit warning when the conversation exceeds the context window, and a failed /compact displays as an error
  • /rewind no longer restores or deletes files through symlinks or hard links at tracked paths and reports how many paths it skipped
  • Background sessions: /mcp and /install-github-app now park a "needs input" request in the agent view when no client is attached
  • Updated the bundled dataviz skill: reordered the default chart palette and fixed guidance that suggested direct labels for four-series charts
  • [VSCode] Fixed right-to-left text (Arabic, Hebrew, Persian) rendering in the wrong order when mixed with English or code
  • Fixed cloud sessions dropping the in-flight message when the session's container restarts mid-turn — the interrupted turn now re-runs on resume instead of leaving the session unresponsive
