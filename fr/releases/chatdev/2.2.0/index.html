ChatDev v2.2.0

Highlights

  • OpenClaw orchestration — Backend workflows can now invoke OpenClaw agent teams and coordinate them dynamically (#584), letting developers combine ChatDev workflows with an external agent stack. Validate OpenClaw connectivity and permissions before routing production workflows through it.
  • Official Python SDK — ChatDev workflows and agent capabilities are now accessible programmatically (#586), enabling scripted runs and service-side automation without UI interaction. Pin the SDK version in automation pipelines to keep workflow behavior reproducible.
  • Filesystem-backed Agent Skills — Agent nodes can now use skills stored on disk (#559), making reusable agent behavior easier to version alongside workflow configuration. Check filesystem paths and permissions when sharing skills across containers or developer machines.
  • New workflow and chat capabilities — The general_problem_solving_team provides a reusable starting point for open-ended problem-solving workflows (#558), while persistent, fullscreen chat improves inspection of long-running sessions (#577, #583). Custom UI integrations should retest navigation and scrolling after the fixes in #576 and #580.
  • Setup and runtime reliability — Optional Docker-based local development (#536), improved Windows Makefile/sync compatibility (#530), and a corrected Gemini endpoint in .env.example (#552) reduce onboarding friction. WebSocket and frontend-lag fixes (#525, #553) target unstable sessions; teams using non-default embedding models should verify the hardcoded-dimension fix (#582).
  • Breaking changes — None are announced in this release.

Key Updates:

OpenClaw Integration

ChatDev now provides full support for OpenClaw within its backend workflows, enabling seamless invocation of agent teams and dynamic orchestration of workflows.

ChatDev Python SDK

The official ChatDev Python SDK has been released, allowing developers to programmatically access ChatDev workflows and utilize agent capabilities.
