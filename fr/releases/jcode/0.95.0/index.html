jcode v0.95.0

Faits saillants

  • Les modèles OpenCode Go, notamment grok-4.7 et gpt-6-luna, sont désormais acheminés via les réponses API
  • Les hooks exposent l'utilisation du jeton de fin de tour, et turn_start/turn_end se déclenchent désormais pour les tours d'exécution jcode en un seul coup
  • /agents prend en charge les remplacements de modèle de travailleur par session

Améliorations

  • /resume peut s'ouvrir sur le projet en cours lorsque display.resume_project_scope est activé
  • Swarm gagne un chien de garde en cas de blocage des travailleurs et une exécution sans tête - les sessions de socket peuvent rejoindre les essaims
  • L'assistant de la barre de menu macOS utilise une identité de signature stable, dessine l'icône de streaming en vert et peut être désactivé avec [menubar] activé = false
  • Les images en ligne s'adaptent à leur zone réservée et le widget d'informations épouse son contenu
  • L'évaluation des risques de commande inspecte désormais les commandes à l'intérieur de $(...), les backticks et les heredocs
  • Les instances privées lancées par SDK ne se mettent plus à jour automatiquement en cours de session et génèrent des erreurs de connexion plus courtes et plus précises.

Correctifs

  • Les raccourcis Ctrl/Alt/Cmd fonctionnent sur la source d'entrée coréenne 2-Set
  • Le protocole du clavier du terminal et les modes TUI sont restaurés lorsque jcode sort sur un signal
  • Les reprises automatiques de limite de débit et de reconnexion du fournisseur sont limitées au lieu de réessayer indéfiniment
  • Les flux OpenAI récupèrent plus rapidement des blocages et l'actualisation du jeton OAuth ne se bloque plus
  • Les appels d'outils émis sous forme de texte de balisage DSML/invoke sont récupérés au lieu d'être perdus
  • Le raisonnement de Kimi via OpenRouter ne perd plus le texte des instantanés non cumulatifs
  • Les sessions reprises corrigent une route d'informations d'identification obsolète afin que les travailleurs de l'essaim héritent de la route en direct.
  • Les captures d'écran utilisées sur ordinateur conservées dans les transcriptions sont de taille limitée
  • L'outil de navigation réutilise les sessions persistantes sur macOS sans ouvrir de fenêtres répétées
  • Un seul assistant de barre de menus s'exécute lorsque jcode est démarré avec un HOME remplacé
  • L'attribution des membres Swarm et les avis de redémarrage sont corrects changelog complet : https://github.com/1jehuang/jcode/compare/v0.94.0...v0.95.0

Anglais original / English original

jcode v0.95.0

Highlights

  • OpenCode Go models, including grok-4.7 and gpt-6-luna, now route over the Responses API
  • Hooks expose turn-end token usage, and turn_start/turn_end now fire for one-shot jcode run turns
  • /agents supports per-session worker model overrides

Improvements

  • /resume can open scoped to the current project when display.resume_project_scope is enabled
  • Swarm gains a stalled-worker watchdog, and headless run --socket sessions can join swarms
  • The macOS menu bar helper uses a stable signing identity, draws the streaming icon green, and can be turned off with [menubar] enabled = false
  • Inline images fit their reserved box and the info widget hugs its content
  • Command risk assessment now inspects commands inside $(...), backticks, and heredocs
  • SDK-launched private instances no longer auto-update mid-session and give shorter, more accurate connect errors

Fixes

  • Ctrl/Alt/Cmd shortcuts work on the Korean 2-Set input source
  • The terminal keyboard protocol and TUI modes are restored when jcode exits on a signal
  • Rate-limit and provider reconnect auto-resumes are bounded instead of retrying indefinitely
  • OpenAI streams recover faster from stalls and OAuth token refresh no longer hangs
  • Tool calls emitted as DSML/invoke markup text are recovered instead of lost
  • Kimi reasoning via OpenRouter no longer loses text from non-cumulative snapshots
  • Resumed sessions heal a stale credential route so swarm workers inherit the live one
  • Computer-use screenshots kept in transcripts are bounded in size
  • The browser tool reuses persistent sessions on macOS without opening repeated windows
  • Only one menu bar helper runs when jcode is started with an overridden HOME
  • Swarm member attribution and restart notices are correct

Full changelog: https://github.com/1jehuang/jcode/compare/v0.94.0...v0.95.0
