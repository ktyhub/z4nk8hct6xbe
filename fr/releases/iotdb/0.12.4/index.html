#iotdb v0.12.4

Nouvelles fonctionnalités

  • [IOTDB-1823] groupe par multi-niveau

Améliorations

  • [IOTDB-2027] Annulation d'une entrée invalide après un échec d'écriture WAL
  • [IOTDB-2061] Ajoutez le paramètre de sous-requête simultanée maximum, lisez les données par lots pour limiter les E/S maximales et ajoutez la configuration de la taille maximale du tampon mis en cache.
  • [IOTDB-2065] publiera bientôt TsFileSequenceReader lorsqu'il ne sera plus utilisé
  • [IOTDB-2072] Supprimez TVListAllocator pour réduire le coût de la mémoire TVList
  • [IOTDB-2101] Réduisez l'empreinte mémoire de QueryDataSource
  • [IOTDB-2102] Poussez l'opérateur de limite vers chaque lecteur
  • [IOTDB-2123] Accélérer le processus de récupération
  • mettre à jour le guide de l'utilisateur pour cpp-cpi et désactiver la compilation de nodejs dans cpp-cli
  • Ignorer trop de journaux WAL BufferOverflow

Corrections de bugs

  • [IOTDB-1408] L'instruction avec 'as' ne s'exécute pas correctement dans les scènes à chemins multiples
  • [IOTDB-2023] Correction des bugs de sérialisation et de désérialisation des filtres
  • [IOTDB-2025] Correction incorrecte du nombre de nœuds et de périphériques dans le cluster
  • [IOTDB-2031] Correction du résultat incorrect de la requête descendante avec filtre de valeur dans le cluster
  • [IOTDB-2032] Correction du résultat incorrect d'une requête descendante avec plusieurs partitions de temps
  • [IOTDB-2039] Correction des données redondantes après un trop grand nombre d'exceptions de fichiers ouverts lors du compactage
  • [IOTDB-2047] Correction de NPE lorsque memControl est désactivé et insère une valeur TEXT dans une série non-TEXTE
  • [IOTDB-2058] Correction de la requête bloquée sans bug dans les threads de sous-requête
  • [IOTDB-2063] Correction du bug d'implémentation de MinTimeDescAggregationResult
  • [IOTDB-2064] Correction du NPE causé par map serde
  • [IOTDB-2068] Correction du compresseur GZIP répondant à l'exception ArrayIndexOutOfBoundsException
  • [IOTDB-2124] la condition de filtrage ne prend pas effet pour la dernière requête du cluster
  • [IOTDB-2138] Correction de la perte de données après la récupération d'IoOTDB
  • [IOTDB-2140] Correction d'une fusion avec NullPointerException
  • [IOTDB-2152] PyClient : remplacez __eq__() de TSDataType, TSEncoding et Compressor pour éviter un comportement de comparaison inattendu
  • [IOTDB-2160] Correction des fuites de références entre nœuds de requête groupby de cluster
  • [ISSUE-3335] Correction du bug du mode start-cli.sh -e qui ne peut pas fonctionner avec les caractères génériques *
  • Correction d'une fuite de mémoire : remplacez RandomDeleteCache par Caffine CacheLoader
  • Correction de la connexion refusée lors de l'utilisation de la session lorsque les utilisateurs oublient de définir l'adresse IP de client

Anglais original / English original

iotdb v0.12.4

New Features

  • [IOTDB-1823] group by multi level

Improvements

  • [IOTDB-2027] Rollback invalid entry after WAL writing failure
  • [IOTDB-2061] Add max concurrent sub query parameter, read data in batches to limit max IO and add max cached buffer size configuration
  • [IOTDB-2065] release TsFileSequenceReader soon when it is no longer used
  • [IOTDB-2072] Remove TVListAllocator to reduce the TVList mem cost
  • [IOTDB-2101] Reduce the memory footprint of QueryDataSource
  • [IOTDB-2102] Push limit operator down to each reader
  • [IOTDB-2123] Accelerate recovery process
  • update user guide for cpp-cpi and disable compiling nodejs in cpp-cli
  • Ignore too many WAL BufferOverflow log

Bug Fixes

  • [IOTDB-1408] Statement with 'as' executes incorrectly in mutil-path scenes
  • [IOTDB-2023] Fix serializing and deserializing bugs of Filters
  • [IOTDB-2025] Fix count nodes and devices incorrectly in cluster
  • [IOTDB-2031] Fix incorrect result of descending query with value filter in cluster
  • [IOTDB-2032] Fix incorrect result of descending query with multiple time partitions
  • [IOTDB-2039] Fix data redundant after too many open files exception occurs during compaction
  • [IOTDB-2047] Fix NPE when memControl is disabled and insert TEXT value to a non-TEXT series
  • [IOTDB-2058] Fix Query is blocked without sub-query-threads exist bug
  • [IOTDB-2063] Fix MinTimeDescAggregationResult implementation bug
  • [IOTDB-2064] Fix the NPE caused by map serde
  • [IOTDB-2068] Fix GZIP compressor meets ArrayIndexOutOfBoundsException
  • [IOTDB-2124] the filtering condition does not take efffect for last query in cluster
  • [IOTDB-2138] Fix data loss after IoTDB recover
  • [IOTDB-2140] Fix merge throw NullPointerException
  • [IOTDB-2152] PyClient: Override __eq__() of TSDataType, TSEncoding and Compressor to avoid unexpected comparation behaviour
  • [IOTDB-2160] Fix cluster groupby query cross-node reference leaks
  • [ISSUE-3335] Fix the bug of start-cli.sh -e mode can't work with wild card *
  • fix memory leak: replace RandomDeleteCache with Caffine CacheLoader
  • Fix connection refused using session when users forget to set client ip
