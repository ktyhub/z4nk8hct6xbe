#iotdb v1.3.2

Fonctionnalités et améliorations

  • Module de stockage : Amélioration des performances de l'interface insertRecords pour l'écriture
  • Module de requête : ajout d'une nouvelle instruction Explain Analyze (surveillant le temps passé sur chaque étape d'une seule exécution SQL)
  • Module de requête : ajout d'un nouveau cadre UDAF (User-Defined Aggregate Function)
  • Module de requête : nouvelles fonctions MaxBy/MinBy ajoutées, prenant en charge la récupération des valeurs maximales/minimales ainsi que les horodatages correspondants
  • Module de requête : amélioration des performances des requêtes de filtrage de valeurs
  • Synchronisation des données : la correspondance de chemin prend en charge le modèle de chemin
  • Synchronisation des données : prend en charge la synchronisation des métadonnées (y compris les séries chronologiques et les attributs, autorisations, etc.)
  • Traitement de flux : ajout de l'instruction Alter Pipe, prenant en charge les mises à jour à chaud des plugins pour les tâches Pipe
  • Module système : les statistiques du nombre de points de données du système incluent désormais des statistiques pour les données importées en chargeant TsFile.
  • Scripts et outils : ajout d'un nouvel outil de sauvegarde de mise à niveau locale (sauvegarde des données originales via des liens physiques)
  • Scripts et outils : nouveaux scripts d'exportation de données/importation de données ajoutés, prenant en charge l'exportation de données aux formats CSV, TsFile ou instructions SQL.
  • Scripts et outils : l'environnement Windows prend désormais en charge la distinction de ConfigNode, DataNode et Cli par nom de fenêtre ...

Bogues

  • Optimisez le message d'erreur lorsqu'une NullPointerException (NPE) se produit en raison d'un délai d'attente lors de la suppression d'une base de données.
  • Ajoutez des journaux pour notifyLeaderReady, notifyLeaderChanged et le processus de travail.
  • Ajout d'une gestion de compatibilité pour les données erronées existantes lors de la fusion de fichiers.
  • Correction du problème de blocage provoqué par le vidage des fichiers vides lors de l'interrogation.
  • Correction du problème où Ratis ne répond plus lors des opérations de lecture, d'écriture et de suppression.
  • Correction du bug simultané dans les opérations de chargement et de fusion.
  • Correction du problème où le taux de compression du système est enregistré sous la forme d'un nombre négatif dans le fichier pour certains scénarios.
  • Correction du problème ConcurrentModificationException lors de l'estimation de la mémoire pour les tâches de fusion.
  • Correction des blocages potentiels pouvant survenir lors de l'écriture, de la création automatique et de la suppression simultanée de bases de données. ...

iotdb v1.3.2

Features & Improvements

  • Storage Module: Performance improvement in the insertRecords interface for writing
  • Query Module: New Explain Analyze statement added (monitoring the time spent on each stage of a single SQL execution)
  • Query Module: New UDAF (User-Defined Aggregate Function) framework added
  • Query Module: New MaxBy/MinBy functions added, supporting the retrieval of maximum/minimum values along with the corresponding timestamps
  • Query Module: Performance improvement in value filtering queries
  • Data Synchronization: Path matching supports path pattern
  • Data Synchronization: Supports metadata synchronization (including time series and related attributes, permissions, etc.)
  • Stream Processing: Added Alter Pipe statement, supporting hot updates of plugins for Pipe tasks
  • System Module: System data point count statistics now include statistics for data imported by loading TsFile
  • Scripts and Tools: New local upgrade backup tool added (backing up original data through hard links)
  • Scripts and Tools: New export-data/import-data scripts added, supporting data export in CSV, TsFile formats or SQL statements
  • Scripts and Tools: Windows environment now supports distinguishing ConfigNode, DataNode, and Cli by window name ...

Bugs

  • Optimize the error message when a NullPointerException (NPE) occurs due to a timeout when dropping a database.
  • Add logs for notifyLeaderReady, notifyLeaderChanged, and procedure worker.
  • Add compatibility handling for existing erroneous data during file merging.
  • Fix the deadlock issue caused by flushing empty files during querying.
  • Fix the issue where Ratis becomes unresponsive during read, write, and delete operations.
  • Fix the concurrent bug in load and merge operations.
  • Fix the issue where the system's compression ratio is recorded as a negative number in the file for certain scenarios.
  • Fix the ConcurrentModificationException issue during memory estimation for merge tasks.
  • Fix potential deadlocks that may occur when writing, automatically creating, and deleting databases concurrently. ...
