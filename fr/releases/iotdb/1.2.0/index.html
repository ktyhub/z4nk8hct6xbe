#iotdb v1.2.0

Nouvelle fonctionnalité

  • [IOTDB-5567] ajoute SQL pour interroger seriesslotid et timeslotid
  • [IOTDB-5631] Ajout d'une fonction d'agrégation intégrée nommée time_duration
  • [IOTDB-5636] Ajouter un arrondi comme fonction scalaire intégrée
  • [IOTDB-5637] Ajouter substr comme fonction scalaire intégrée
  • [IOTDB-5638] Cas de support lorsque la syntaxe dans IoTDB
  • [IOTDB-5643] Ajout de REPLACE en tant que fonction scalaire intégrée
  • [IOTDB-5683] Prise en charge du mode de fonction d'agrégation pour les requêtes
  • [IOTDB-5711] Python API devrait prendre en charge la connexion de plusieurs nœuds
  • [IOTDB-5752] Python Client prend en charge la redirection d'écriture
  • [IOTDB-5765] Ordre de prise en charge par expression
  • [IOTDB-5771] ajoute un encodeur SPRINTZ et RLBE et un compresseur LZMA2
  • [IOTDB-5924] Ajouter la suppression de SessionPool API
  • [IOTDB-5950] Prise en charge du modèle de schéma dynamique
  • [IOTDB-5951] Prise en charge de l'affichage des séries temporelles/périphériques avec une chaîne spécifique contenue dans le chemin
  • [IOTDB-5955] Prise en charge de la création de séries temporelles à l'aide d'un modèle de schéma dans la session API

Améliorations

  • [IOTDB-5630] Faire de la fonction une fonction intégrée
  • [IOTDB-5689] Fermez Isink lorsque ISourceHandle est fermé
  • [IOTDB-5715] Améliorer les performances de l'ordre des requêtes par description temporelle
  • [IOTDB-5763] Optimiser l'estimation de la mémoire pour les opérations INTO
  • [IOTDB-5887] Optimiser les performances de construction de PathPatternTree sans caractères génériques
  • [IOTDB-5888] Les journaux TTL ne prenaient pas en compte la précision de l'horodatage
  • [IOTDB-5896] Échec de l'exécution de l'instruction de suppression
  • [IOTDB-5908] Ajouter plus de métriques de requête
  • [IOTDB-5911] L'outil print-iotdb-data-dir ne peut pas fonctionner
  • [IOTDB-5914] Supprimer le journal de débogage redondant dans la session
  • [IOTDB-5919] Afficher les variables ajoute une variable timestamp_precision
  • [IOTDB-5926] Optimiser la mise en œuvre des métriques
  • [IOTDB-5929] Activer la stratégie d'héritage DataPartition
  • [IOTDB-5943] Évitez d'appeler RPC pour SimpleQueryTerminator lorsque le point de terminaison est une adresse locale.
  • [IOTDB-5944] Le suiveur n'a pas besoin de mettre à jour le dernier cache lors de l'utilisation d'IoT_consensus
  • [IOTDB-5945] Ajouter un cache pour éviter d'initialiser un objet ID de périphérique dupliqué lors du processus d'écriture
  • [IOTDB-5946] Optimiser la mise en œuvre de la tablette dans Go client
  • [IOTDB-5949] Prise en charge de l'affichage des séries temporelles avec filtre de type de données
  • [IOTDB-5952] Prise en charge de la stratégie FIFO dans DataNodeSchemaCache
  • [IOTDB-6022] Les WAL s'accumulent lorsque l'iotconsensus multi-réplique est écrit avec une simultanéité élevée

Corrections de bugs

  • [IOTDB-5604] NPE lors de l'exécution d'Agg + aligner par requête de périphérique sans DataRegion attribué
  • [IOTDB-5619] requête de groupe par balises NPE
  • [IOTDB-5644] Résultat inattendu lorsqu'il n'y a pas d'expressions de sélection après analyse dans la requête
  • [IOTDB-5657] La limite ne prend pas effet lors de la dernière requête

  • [IOTDB-5716] Dépendance incorrecte lorsque le pipeline consommeOneByOneOperator

  • [IOTDB-5735] Le résultat de l'ajout de la fonction distincte à l'alignement par périphérique est incorrect
  • [IOTDB-5755] Correction du problème selon lequel 123w ne peut pas être utilisé dans l'identifiant
  • [IOTDB-5756] NPE lorsque le prédicat est NotEqualExpression et que l'une des sous-expressions n'existe pas
  • [IOTDB-5757] Exception non prise en charge lors d'une utilisation comme ' s3 || false' où même le type de s3 est booléen
  • [IOTDB-5760] La requête est bloquée en raison d'un manque de mémoire
  • [IOTDB-5764] Impossible de spécifier correctement l'alias lorsque la clause FROM contient plusieurs suffixes de chemin
  • [IOTDB-5769] Le décalage ne prend pas effet dans certains cas particuliers
  • [IOTDB-5774] La syntaxe selon laquelle les nœuds de chemin commencent ou se terminent par un caractère générique pour une correspondance floue n'est pas prise en charge.
  • [IOTDB-5784] Résultat incorrect lors d'une requête avec décalage push-down et filtre temporel
  • [IOTDB-5815] NPE lors de l'utilisation d'UDF pour interroger
  • [IOTDB-5837] Exceptions pour la sélection de l'utilisation d'espaces réservés
  • [IOTDB-5851] L'utilisation de la clause limit dans la requête show devices lancera NPE
  • [IOTDB-5858] La métrique n'affiche pas le taux de réussite de schemaCache
  • [IOTDB-5861] La dernière requête est incomplète
  • [IOTDB-5889] TTL Impossible de supprimer les fichiers ts expirés
  • [IOTDB-5897] NullPointerException lors du compactage
  • [IOTDB-5905] Certains points de données de séries temporelles alignés sont perdus après le vidage
  • [IOTDB-5934] Optimiser la stratégie de partition de cluster
  • [IOTDB-5953] Le paramètre de contrôle de la mémoire LastCache ne prend pas effet
  • [IOTDB-5963] Parfois, nous pouvons obtenir des résultats de requête dans le désordre
  • [IOTDB-6016] Coût du numéro de fichier de publication après une tâche de compactage croisé

iotdb v1.2.0

New Feature

  • [IOTDB-5567] add SQL for querying seriesslotid and timeslotid
  • [IOTDB-5631] Add a built-in aggregation functions named time_duration
  • [IOTDB-5636] Add round as built-in scalar function
  • [IOTDB-5637] Add substr as built-in scalar function
  • [IOTDB-5638] Support case when syntax in IoTDB
  • [IOTDB-5643] Add REPLACE as a built-in scalar function
  • [IOTDB-5683] Support aggregation function Mode for query
  • [IOTDB-5711] Python API should support connecting multiple nodes
  • [IOTDB-5752] Python Client supports write redirection
  • [IOTDB-5765] Support Order By Expression
  • [IOTDB-5771] add SPRINTZ and RLBE encodor and LZMA2 compressor
  • [IOTDB-5924] Add SessionPool deletion API
  • [IOTDB-5950] Support Dynamic Schema Template
  • [IOTDB-5951] Support show timeseries/device with specific string contained in path
  • [IOTDB-5955] Support create timeseries using schema template in Session API

Improvements

  • [IOTDB-5630] Make function cast a built-in function
  • [IOTDB-5689] Close Isink when ISourceHandle is closed
  • [IOTDB-5715] Improve the performance of query order by time desc
  • [IOTDB-5763] Optimize the memory estimate for INTO operations
  • [IOTDB-5887] Optimize the construction performance of PathPatternTree without wildcards
  • [IOTDB-5888] TTL logs didn' t consider timestamp precision
  • [IOTDB-5896] Failed to execute delete statement
  • [IOTDB-5908] Add more query metrics
  • [IOTDB-5911] print-iotdb-data-dir tool cannot work
  • [IOTDB-5914] Remove redundant debug log in Session
  • [IOTDB-5919] show variables add a variable timestamp_precision
  • [IOTDB-5926] Optimize metric implementation
  • [IOTDB-5929] Enable DataPartition inherit policy
  • [IOTDB-5943] Avoid rpc invoking for SimpleQueryTerminator when endpoint is local address
  • [IOTDB-5944] Follower doesn' t need to update last cache when using IoT_consensus
  • [IOTDB-5945] Add a cache to avoid initialize duplicated device id object in write process
  • [IOTDB-5946] Optimize the implement of tablet in Go client
  • [IOTDB-5949] Support show timeseries with datatype filter
  • [IOTDB-5952] Support FIFO strategy in DataNodeSchemaCache
  • [IOTDB-6022] The WAL piles up when multi-replica iotconsensus is written at high concurrency

Bug Fixes

  • [IOTDB-5604] NPE when execute Agg + align by device query without assigned DataRegion
  • [IOTDB-5619] group by tags query NPE
  • [IOTDB-5644] Unexpected result when there are no select expressions after analyzed in query
  • [IOTDB-5657] Limit does not take effect in last query
  • [IOTDB-5700] UDF query did not clean temp file after the query is finished
  • [IOTDB-5716] Wrong dependency when pipeline consumeOneByOneOperator
  • [IOTDB-5717] Incorrect result when querying with limit push-downing & order by time desc
  • [IOTDB-5722] Wrong default execution branch in PlanVisitor
  • [IOTDB-5735] The result of adding the distinct function to the align by device is incorrect
  • [IOTDB-5755] Fix the problem that 123w can not be used in Identifier
  • [IOTDB-5756] NPE when where predicate is NotEqualExpression and one of subExpression is not exist
  • [IOTDB-5757] Not Supported Exception when use like ' s3 || false' in where even Type of s3 is Boolean
  • [IOTDB-5760] Query is blocked because of no memory
  • [IOTDB-5764] Cannot specify alias successfully when the FROM clause contains multiple path suffixes
  • [IOTDB-5769] Offset doesn' t take effect in some special case
  • [IOTDB-5774] The syntax that path nodes start or end with a wildcard to fuzzy match is not supported
  • [IOTDB-5784] Incorrect result when querying with offset push-down and time filter
  • [IOTDB-5815] NPE when using UDF to query
  • [IOTDB-5837] Exceptions for select into using placeholders
  • [IOTDB-5851] Using limit clause in show devices query will throw NPE
  • [IOTDB-5858] Metric doesn' t display the schemaCache hit ratio
  • [IOTDB-5861] Last quey is incomplete
  • [IOTDB-5889] TTL Cannot delete expired tsfiles
  • [IOTDB-5897] NullPointerException In compaction
  • [IOTDB-5905] Some aligned timeseries data point lost after flush
  • [IOTDB-5934] Optimize cluster partition policy
  • [IOTDB-5953] LastCache memory control param does not take effect
  • [IOTDB-5963] Sometimes we may get out-of-order query result
  • [IOTDB-6016] Release file num cost after cross compaction task

New Contributors

  • @EliasMei made their first contribution in https://github.com/apache/iotdb/pull/9291
  • @nikam14 made their first contribution in https://github.com/apache/iotdb/pull/9368
  • @riverbuilding made their first contribution in https://github.com/apache/iotdb/pull/9379
  • @lichenyu20 made their first contribution in https://github.com/apache/iotdb/pull/9458
