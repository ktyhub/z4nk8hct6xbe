#iotdb v0.12.1

Corrections de bugs

  • [GITHUB-3373] Supprimez la connexion leader en cache interrompue et optimisez la méthode insertRecords en session
  • [IOTDB-1433] Correction d'un bug dans getMetadataAndEndOffset lors de l'interrogation d'un périphérique inexistant
  • [IOTDB-1432] données de perte de compactage au niveau correctif
  • [IOTDB-1427] Correction du verrouillage de compactage avec requête
  • [IOTDB-1420] Correction d'un bug ttl de compactage
  • [IOTDB-1419] Supprimez clearCompactionStatus redondant, corrigez le compactage continu qui ne prend pas effet lors de l'activation de Partition.
  • [IOTDB-1415] Correction du MOO causé par ChunkCache
  • [IOTDB-1414] NPE s'est produit lors de l'appel de la méthode getStorageGroupNodeByPath() en utilisant un chemin inexistant
  • [IOTDB-1412] Message d'exception peu clair émis lors de l'exécution d'un InsertTabletPlan vide
  • [IOTDB-1411] La correction de thriftMaxFrameSize et thriftDefaultBufferSize n'est pas effective
  • [IOTDB-1398] Ne sélectionnez pas les fichiers unseq lorsqu'il existe d'anciens fichiers unseq non compactés.
  • [IOTDB-1390] Correction d'un bug de données de perte de compactage non suivi
  • [IOTDB-1384] Correction du groupe par bug
  • [ISSUE-3378] Correction de NPE lors de la suppression du dossier de mise à niveau ; Correction de certaines statistiques manquantes de pageHeader mises à jour
  • [GITHUB-3339] Essayez de corriger le blocage sg
  • [GITHUB-3329] Correction de la mise à niveau NPE et DeadLock
  • [GITHUB-3319] L'outil de mise à niveau ne peut pas fermer le lecteur de fichiers.
  • [IOTDB-1212] Correctif Le message d'erreur donné n'est pas correct lors de l'exécution de select sin(non_existence) à partir de root.sg1.d1
  • [IOTDB-1219] Correction d'un problème potentiel de NPE dans le module UDF
  • [IOTDB-1286] Correction de 4 points de fuite de mémoire C++
  • [IOTDB-1294] Correction de l'opération de suppression devenue invalide après le compactage
  • [IOTDB-1313] Correction de la perte de précision temporelle lors de l'importation d'un fichier CSV avec un format d'horodatage non pris en charge
  • [IOTDB-1316] L'outil importCsv doit continuer l'insertion si une partie de l'insertion a échoué
  • [IOTDB-1317] Le rattrapage du journal de correction échouait toujours en raison de la non-vérification de l'index de correspondance du suiveur.
  • [IOTDB-1323] Le correctif renvoie un message de réussite lorsque RuntimeException est rencontré pendant le processus d'insertion
  • [IOTDB-1325] Correction de l'exception StackOverflow dans la requête de groupe par mois naturel
  • [IOTDB-1330] Correction du bug de chargement du fichier tsfile lorsque le fichier tsfile de la partition multi-multi n'a qu'une seule page
  • [IOTDB-1348] Correction du dernier plan ne fonctionnant pas en mode cluster
  • [IOTDB-1376] Le correctif BatchProcessException n'était pas correctement géré dans BaseApplier
  • [ISSUE-3277] Correction du TotalSeriesNumber dans MManager compté deux fois lors de la récupération
  • [ISSUE-3116] Correction d'un bug lors de l'utilisation de l'unité de mois naturel dans l'intervalle de temps en groupe par requête
  • [ISSUE-3309] Correction de InsertRecordsOfOneDevice qui fonctionne trop lentement
  • Correction de l'index du plan qui est toujours nul lors de l'utilisation de l'interface insertRecords pour exécuter le cluster
  • Ajouter un contrôle d'autorité pour que les utilisateurs créent des séries temporelles à l'aide de l'interfaceexecuteBatch sans le privilège
  • Correction de versionInfo NPE lors de la mise à niveau de la requête 0.11 tsfile
  • L'outil de mise à niveau ne peut pas charger l'ancien fichier ts si la partition de temps est activée dans 0.11.
  • Correction de l'importation csv qui lance ArrayOutOfIndexError lorsque la dernière valeur d'une ligne est nulle.
  • L'outil de mise à niveau ne peut pas fermer le lecteur de fichiers

Améliorations

  • [GITHUB-3399] Modifiez la taille du tableau primitif par défaut à 32
  • [IOTDB-1387] Prise en charge sans clause Null ALL dans l'alignement par périphérique, filtre automatiquement RowRecord si une colonne qu'il contient est nulle ou si toutes les colonnes sont nulles
  • [IOTDB-1385] Extraire le super utilisateur vers la configuration
  • [IOTDB-1315] ExportCsvTool devrait prendre en charge l'horodatage yyyy-MM-dd'T'HH:mm:ss.SSSZ
  • [IOTDB-1339] optimise TimeoutChangeableTSnappyFramedTransport
  • [IOTDB-1356] Séparez unseq_file_num_in_each_level de la sélection du fichier candidat dans le compactage unseq
  • [IOTDB-1357] Le compactage utilise la stratégie de fusion d'ajout de fragments lorsque le fragment est déjà suffisamment grand
  • [IOTDB-1380] Fermez automatiquement l'ensemble de données lorsqu'il n'y a plus de données
  • Optimiser le leader de synchronisation pour la méta

Nouvelles fonctionnalités

  • [GITHUB-3389] TTL peut être défini sur n'importe quel chemin
  • [GITHUB-3387] Ajouter le paramètre compaction_interval=10000ms
  • [IOTDB-1190] Prise en charge complète des caractères d'URL HTTP définis dans le chemin de la série temporelle
  • [IOTDB-1321][IOTDB-1322] Filtrer automatiquement RowRecord si une colonne qu'il contient est nulle ou si toutes les colonnes sont nulles
  • [IOTDB-1357] Le compactage utilise la stratégie de fusion d'ajout de fragments lorsque le fragment est déjà volumineux
  • [ISSUE-3089] Permettre aux groupes de stockage d'avoir un nom avec un trait d'union

Modifications diverses

  • [GITHUB-3346] mise à niveau de netty et demande d'exclusion pour le contrôle de l'exécuteur
  • [IOTDB-1259] mise à niveau de libthrift de 0.12.0/0.13.0 vers 0.14.1
  • Décommentez les configurations les moins utilisées
  • Activer la configuration concurrent_writing_time_partition

iotdb v0.12.1

Bug Fixes

  • [GITHUB-3373] Remove the broken cached leader connection & optimize the insertRecords method in session
  • [IOTDB-1433] Fix bug in getMetadataAndEndOffset when querying non-exist device
  • [IOTDB-1432] fix level compaction loss data
  • [IOTDB-1427] Fix compaction lock with query
  • [IOTDB-1420] Fix compaction ttl bug
  • [IOTDB-1419] Remove redundant clearCompactionStatus, fix continuous compaction doesn't take effect when enablePartition
  • [IOTDB-1415] Fix OOM caused by ChunkCache
  • [IOTDB-1414] NPE occurred when call getStorageGroupNodeByPath() method using not exist path
  • [IOTDB-1412] Unclear exception message thrown when executing empty InsertTabletPlan
  • [IOTDB-1411] Fix thriftMaxFrameSize and thriftDefaultBufferSize does not in effect
  • [IOTDB-1398] Do not select unseq files when there are uncompacted old unseq files
  • [IOTDB-1390] Fix unseq compaction loss data bug
  • [IOTDB-1384] Fix group by bug
  • [ISSUE-3378] Fix NPE when clear upgrade folder; Fix some upgraded pageHeader missing statistics
  • [GITHUB-3339] Try to fix sg dead lock
  • [GITHUB-3329] Fix upgrade NPE and DeadLock
  • [GITHUB-3319] Fix upgrade tool cannot close file reader
  • [IOTDB-1212] Fix The given error message is not right when executing select sin(non_existence) from root.sg1.d1
  • [IOTDB-1219] Fix a potential NPE issue in UDF module
  • [IOTDB-1286] Fix 4 C++ mem-leak points
  • [IOTDB-1294] Fix delete operation become invalid after compaction
  • [IOTDB-1313] Fix lossing time precision when import csv with unsupported timestamp format
  • [IOTDB-1316] The importCsv tool should continue inserting if a part of insertion failed
  • [IOTDB-1317] Fix log CatchUp always failed due to not check the follower's match index
  • [IOTDB-1323] Fix return a success message when encounter RuntimeException during the insertion process
  • [IOTDB-1325] Fix StackOverflow Exception in group by natural month query
  • [IOTDB-1330] Fix the load tsfile bug when the cross multi partition's tsfile only have one page
  • [IOTDB-1348] Fix Last plan not work in cluster mode
  • [IOTDB-1376] Fix BatchProcessException was not correctly handled in BaseApplier
  • [ISSUE-3277] Fix TotalSeriesNumber in MManager counted twice when recovering
  • [ISSUE-3116] Fix bug when using natural month unit in time interval in group by query
  • [ISSUE-3309] Fix InsertRecordsOfOneDevice runs too slow
  • Fix the plan index is always zero when using insertRecords interface to run the cluster
  • Add authority check for users create timeseries using executeBatch interface without the privilege
  • Fix versionInfo NPE when query upgrading 0.11 tsfile
  • Fix upgrade tool cannot load old tsfile if time partition enabled in 0.11
  • Fix import csv throw ArrayOutOfIndexError when the last value in a line is null
  • Fix upgrade tool cannot close file reader

Improvements

  • [GITHUB-3399] Change the default primitive array size to 32
  • [IOTDB-1387] Support Without Null ALL in align by device clause, Filter RowRecord automatically if any column in it is null or all columns are null
  • [IOTDB-1385] Extract the super user to the configuration
  • [IOTDB-1315] ExportCsvTool should support timestamp yyyy-MM-dd'T'HH:mm:ss.SSSZ
  • [IOTDB-1339] optimize TimeoutChangeableTSnappyFramedTransport
  • [IOTDB-1356] Separate unseq_file_num_in_each_level from selecting candidate file in unseq compaction
  • [IOTDB-1357] Compaction use append chunk merge strategy when chunk is already large enough
  • [IOTDB-1380] Automatically close the dataset while there is no more data
  • Optimize sync leader for meta

New Features

  • [GITHUB-3389] TTL can be set to any path
  • [GITHUB-3387] Add parameter compaction_interval=10000ms
  • [IOTDB-1190] Fully support HTTP URL char set in timeseries path
  • [IOTDB-1321][IOTDB-1322] Filter RowRecord automatically if any column in it is null or all columns are null
  • [IOTDB-1357] Compaction use append chunk merge strategy when chunk is already large
  • [ISSUE-3089] Make it possible for storage groups to have name with hyphen

Miscellaneous changes

  • [GITHUB-3346] upgrade netty and claim exclusion for enforcer check
  • [IOTDB-1259] upgrade libthrift from 0.12.0/0.13.0 to 0.14.1
  • Uncomment the less used configurations
  • Enable the configration concurrent_writing_time_partition
