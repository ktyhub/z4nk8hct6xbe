ComfyUI v0.36.0

Highlights

  • Generic loops land (CORE-14) — PR #16227 introduces first-class loop control flow in graphs, the headline capability of this release. Two follow-ups harden it: #16347 declares loop boundaries in node schema and marks the executionList input strictly internal (custom node authors should not wire it directly), and #16345 fixes heterogeneous list items being dropped across iterations. If you build loop-aware custom nodes, expect to adjust to the new schema contract.
  • Video pipelines go first-class — New Video Concatenate node (#16267, unit tests fixed in #16271) joins Bria's Video Eraser and image-edit nodes (#16264), BFL's Flux Video Edit (#16259), and Pruna's P‑Video‑2 text-/image-to-video nodes (#16315). adopters assembling multi-clip or generative-video workflows now have far more native building blocks instead of external post-processing.
  • Model coverage widens across depth, audio, and VAEs — Marigold v2 depth estimation arrives with matching blueprints (#16232, #16318); Yue2 music generation is added with longer song durations and AMD fixes plus more ABC controls (#16250, #16292, #16293); MiniMax-H3 VAE optimizations cut VRAM use (#16187, #16332); and llama rope kernels now cover more models (#16351, #16326). Practical takeaway: notable memory and speed wins on consumer GPUs, especially for large latent models.
  • Partner node migrations require action — Tripo moves to its v3 API, adds Smart Segment and retires dead widgets (#16201), while Gemini-LLM ships GeminiNodeV3 and deprecates V2 (#16287); Gemini 3.8 Flash is also added (#16195). These are the real breaking changes in the release — existing graphs using Tripo widgets or the V2 Gemini node will need rewiring, so budget migration time before upgrading.
  • AMD/ROCm on Windows gets a push — The AMD Windows VA quota is bumped to 4TB (#16199), the stale ROCm triton arch gate is dropped in quant_ops (#16211), and manual-install instructions are refreshed (#16217). Better headroom for large models on Windows AMD, though the 4TB figure is a configuration ceiling — it does not guarantee a given workload will actually fit.
  • Behavioral and internal shifts to watch — ImageColorSpace gains a linear value (#16247); Add Noise no longer perturbs the alpha channel (#15626); the frontend package moves to 1.52.7 (#16275); and the asset subsystem splits records from content with structured event logging (#16295, #16306, #16096) as --enable-assets testing is temporarily disabled (#16334). Expect subtle output differences in color/noise pipelines and check any tooling that consumes the old asset-record shape.
