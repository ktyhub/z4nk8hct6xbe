ComfyUI v0.43.0

Highlights

  • MOSS-Image moves from "supported" to tunable — This release gives the newly-supported MOSS-Image family real production controls: RoPE scaling (#17172), color-depth control (#17206), edit LoRAs (#17296), and attention-bias conditioning plus image-strength knobs for edits (#17320), with a model-specific merge node (#17349) and slightly lower peak memory (#17338). If you wrote MOSS off as a smoke-test when it first landed, this is the version to re-evaluate.

  • Large-model memory and throughput work lands incrementally — Aimed at constrained GPUs: adaptive tree MTP for Qwen 3.x (#17273), Comfy-Aimdo 0.6.0 with part I of dynamic VRAM KV caches (#17274), synchronized graph cleanups in model prefetch (#17178), and offload-stream syncing before pin stealing (#17297). Expect lower peak VRAM and faster long-generation decoding; note these are explicitly "part I/III" changes, so treat them as a foundation and watch for follow-up PRs that complete the behavior.

  • Partner Nodes expand — but two quiet infra fixes matter more than the new nodes — Hosted nodes multiply (Kling 4.0 #17364, FLUX 3 Max #17202 and 2K/4K FLUX 3 Video #17200, Ideogram SVG #17298, HeyGen voice cloning #17043, three new Bria nodes #17289). For adopters, the higher-value changes are the client now respecting proxy environment variables (#17346) and partner sign-in token renewal (#16943) — decisive if you're behind a corporate proxy or have hit silent API-node auth failures.

  • Several fixes change generated outputs — regenerate your baselines — FIBO 2.0 RoPE scaling switched to NTK-aware (#17290) and its T2I negative-prompt handling was corrected (#17285); Gemma 4 31B global attention was fixed to k_eq_v with 4 global KV heads (#17220); top-p sampling threshold was corrected (#17221); PyTorch attention was enabled in the VAE on AMD (#17271) but suppressed for head dims above 256 on gfx11 (#17323). Saved workflows tuned against the old behavior may shift in framing or prompt adherence, so do a quick regression pass.

  • New core nodes and tightening repo boundaries — Additions include a Pad Image node with mirror padding and pad-to-multiple (#17224), a Branch node (#16383), ACEScg support in color-space conversion/advanced EXR save (#17023, CORE-657), the Flux2 VAE fused and stripped via comfy-kitchen (#17196), and the optional local agent loading through comfy-agent's v1 host (#17241). Meanwhile comfy is being narrowed to model-related code (#17307) with architecture boundaries documented in AGENTS.md (#17331), and Pillow now has a declared minimum version (#17249) — custom-node authors should re-check imports and refresh their environment.

  • Breaking changes — None in this release.
