ComfyUI v0.44.0

Highlights

  • MiniMax H3 and PH3 support — Native support now covers the H3 latent upscaler, Sol-H3-VAE, context windows, and PH3Image (#17412, #17411, #17425, #17506). H3 pipelines can use these components directly, while context-window support enables longer workflows without custom integration code.
  • Video tools expand, with one migration to watch — Flux Video Upscale V2 gains 1080p, 2K, and 4K targets (#17394); Pruna adds P-Video Upscale (#17443); and MiniMax adds recast, extend, reframe, insert, lip-sync, and camera-control nodes (#17424). WaveSpeed’s FlashVSR and image-upscale nodes move to Comfy Router (#17319), so verify saved workflows after upgrading.
  • More control over video delivery — Video saving now supports ProRes and configurable chroma subsampling (#17463), with explicit validation of subsampling values (#17501). Delivery pipelines can choose encoding and color sampling directly, while invalid settings are rejected before reaching the encoder.
  • VAE precision becomes configurable — The new VAE Compute Dtype node (#17450) lets workflows tune memory usage, speed, and precision. Fixes address an LTX 2.5 decoder crash (#17487) and fp8_e4m3fn_fast falling back to bf16 under dynamic VRAM (#16941), so existing low-precision workflows may now execute differently.
  • Lower sampling overhead and richer job metadata — Single-condition paths skip concatenation (#17413, #17414), and identical tensors no longer require torch.equal checks (#17439), removing unnecessary tensor work. Job-detail responses now include execution_meta (#17397), giving API clients additional execution information.
  • Compatibility — Seedance 1.x partner video nodes are deprecated (#17507), so migrate workflows using them before removal. The proposed defaults for local_web_sso and partner_node_token were reverted (#17490, #17514), leaving authentication behavior unchanged. No breaking changes.
