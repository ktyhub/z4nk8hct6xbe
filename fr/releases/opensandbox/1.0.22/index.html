OpenSandbox docker/execd/v1.0.22

Quoi de neuf

⚠️ Modifications radicales

  • Les sessions de réseau privé échouent lors de la fermeture au démarrage. Les sessions share_net: false explicites nécessitent désormais que execd épingle la charge de travail NetNS/UserNS et renvoie 503 réessayable en cas d'échec ; les sessions en réseau partagé restent inchangées. (#1397)

✨Caractéristiques

  • L'arrière-plan s'exécute dans des sessions isolées. run accepte background: true et renvoie un handle JSON ; le nouveau statut runs/{runId} et les points de terminaison .../logs prennent en charge l'interrogation. Les exécutions en vol bloquent le GC inactif. (#1456)
  • Visionneuses PTY en lecture seule. L'option ?mode=viewer permet à plusieurs clients de regarder une session PTY en cours aux côtés du détenteur exclusif, avec relecture + sortie en direct et isolation contre-pression. (#1420)
  • attach(sessionId) dans les cinq SDK. Reconstruit un handle de session entièrement fonctionnel à partir d'un identifiant nu, par ex. après un redémarrage du travailleur ; SessionState fait désormais écho aux paramètres de création. (#1295)
  • Sonde de disponibilité uid_mode. execd sonde setpriv/userns indépendamment et renvoie 503 NOT_SUPPORTED pour les modes indisponibles au lieu d'échouer toute isolation. (#1320)

🐛 Corrections de bugs

  • Cycle de vie de charge de travail fermé en cas d'échec pour les sessions isolées (sécurité). Une porte native bloque la commande sandbox jusqu'à ce qu'execd vérifie l'identité de la charge de travail ; les sessions sont terminées si la comptabilité du cycle de vie est perdue. (#1388 #1392)
  • execd config env ne fuit plus dans les sessions bwrap (sécurité). EXECD_ACCESS_TOKEN, JUPYTER_*, EXECD_ISOLATION_CONFIG sont toujours supprimés, même s'ils sont sur la liste autorisée. (#1314)
  • Correction du blocage d'exécution de Jupyter sous les consommateurs lents — plus de blocages permanents lors d'une sortie en rafale. (#1464)
  • Bash → sh repli pour PTY, session bash et API isolés, y compris la citation correcte du tiret/cendre export -p sur les images sans bash. (#1359 #1361 #1367)
  • Purge de l'autorité de certification mitmproxy obsolète au démarrage de la sortie — corrige les échecs HTTPS après le co-redémarrage du conteneur de pod. (#1371)
  • Corruption du flux SSE éliminée — Course de goroutine ping et fuite d'erreur de proxy corrigées (taux d'échec e2e nocturne d'environ 64 %). (#1216)

📦 Divers

  • Augments de dépendance CVE : grpc v1.82.1, x/crypto v0.52.0, x/net v0.55.0, postcss 8.5.11. (#1385 #1250)
  • En-têtes de licence Apache 2.0 ajoutés à 21 fichiers. (#1313)

OpenSandbox docker/execd/v1.0.22

Highlights

  • Breaking: private-network isolation now fails closed — Explicit share_net: false sessions require successful NetNS/UserNS bind-pinning; execd returns a retryable 503 when setup fails. Review orchestration retry handling and isolation capabilities before upgrading; shared-network sessions are unaffected. (#1397)

  • Background execution and run observability — Set run.background: true to receive a JSON run handle, then poll runs/{runId} and its /logs endpoint. In-flight runs are excluded from idle garbage collection, enabling long-running workloads without losing status or output. (#1456)

  • Reattachable sessions across all five SDKs — attach(sessionId) reconstructs a fully functional handle from an ID, including after worker restarts, while SessionState echoes creation parameters for stateful recovery. (#1295)

  • Read-only PTY viewing and more portable shell execution — Opt into ?mode=viewer to let multiple clients replay and follow a PTY alongside its exclusive holder, with backpressure isolated between viewers. PTY, bash-session, and isolated APIs now fall back from Bash to sh, including correct dash/ash export -p handling on bash-less images. (#1420 #1359 #1361 #1367)

  • Isolation failures are narrower, security boundaries are stronger — Independent setpriv/userns probes return 503 NOT_SUPPORTED only for unavailable uid_mode options. Native workload-identity gates and lifecycle checks terminate isolated sessions if accounting is lost, and execd credentials/config variables are stripped from bwrap sessions even when allow-listed. (#1320 #1388 #1392 #1314)

  • Reliability fixes for output-heavy and restarted workloads — Slow Jupyter consumers no longer deadlock bursty execution, SSE output avoids corruption from ping races and proxy errors, and egress startup purges stale mitmproxy CAs to prevent HTTPS failures after pod-container co-restarts. Dependency updates address known CVE exposure. (#1464 #1216 #1371 #1385 #1250)

What's New

⚠️ Breaking Changes

  • Private-network sessions fail closed at startup. Explicit share_net: false sessions now require execd to bind-pin the workload NetNS/UserNS and return retryable 503 on failure; shared-network sessions are unchanged. (#1397)

✨ Features

  • Background runs in isolated sessions. run accepts background: true and returns a JSON handle; new runs/{runId} status and .../logs endpoints support polling. In-flight runs block idle GC. (#1456)

  • Read-only PTY viewers. Opt-in ?mode=viewer lets multiple clients watch a running PTY session alongside the exclusive holder, with replay + live output and backpressure isolation. (#1420)

  • attach(sessionId) in all five SDKs. Rebuilds a fully functional session handle from a bare id, e.g. after a worker restart; SessionState now echoes creation params. (#1295)

  • uid_mode availability probing. execd probes setpriv/userns independently and returns 503 NOT_SUPPORTED for unavailable modes instead of failing all isolation. (#1320)

🐛 Bug Fixes

  • Fail-closed workload lifecycle for isolated sessions (security). A native gate blocks the sandbox command until execd verifies workload identity; sessions are terminated if lifecycle accounting is lost. (#1388 #1392)

  • execd config env no longer leaks into bwrap sessions (security). EXECD_ACCESS_TOKEN, JUPYTER_*, EXECD_ISOLATION_CONFIG are always stripped, even if allow-listed. (#1314)

  • Fixed Jupyter execution deadlock under slow consumers — no more permanent hangs during bursty output. (#1464)

  • Bash → sh fallback for PTY, bash-session, and isolated APIs, including correct dash/ash export -p quoting on bash-less images. (#1359 #1361 #1367)

  • Stale mitmproxy CA purge on egress startup — fixes HTTPS failures after pod-container co-restart. (#1371)

  • SSE stream corruption eliminated — ping goroutine race and proxy error leak fixed (~64% nightly e2e failure rate). (#1216)

📦 Misc

  • CVE dependency bumps: grpc v1.82.1, x/crypto v0.52.0, x/net v0.55.0, postcss 8.5.11. (#1385 #1250)
  • Apache 2.0 license headers added to 21 files. (#1313)
