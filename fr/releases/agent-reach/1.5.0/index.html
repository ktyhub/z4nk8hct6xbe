#Agent-Reach v1.5.0

Quelle est cette version ?

Agent Reach a été mis à niveau de « Collection d'outils » vers « Couche de capacités » : Chaque plate-forme = liste préférée + liste backend ordonnée alternative. La méthode d'accès la plus stable à l'heure actuelle est sélectionnée, installée et vérifiée pour vous grâce à des tests réels - vous n'aurez pas à vous soucier du remplacement des méthodes d'accès. Toutes les sélections de cette version sont basées sur des tests réels sur machine effectués en 2026-06 (32 tests de bout en bout).

Modifications du routage de la plate-forme

| Plateforme | La route actuelle | |------|--------------| | Xiaohongshu | OpenCLI (bureau, réutilisation de l'état de connexion du navigateur sans configuration) ▸ xiaohongshu-mcp (serveur, scan du code) ▸ xhs-cli (disponible en stock, l'amont a été arrêté) | | Reddit | OuvrirCLI ▸ rdt-cli. Calibre honnête : Reddit n'a pas de chemin de configuration zéro (l'interface anonyme a été complètement bloquée et le système d'approbation officiel API est requis), et vous devez vous connecter | | Gare B | bili-cli (Recherche/Populaire/Détails, pas besoin de se connecter) ▸ OpenCLI (Sous-titres) ▸ Recherchez API pour le savoir. yt-dlp a quitté le site B (complètement intercepté par le contrôle des risques 412, la dernière version + proxy + cookie testés sont invalides) ; yt-dlp continue de servir YouTube | | Twitter | twitter-cli Gatekeeper (stable en mesure réelle)▸ Alternative OpenCLI, détection et nouvelle tentative |

Le médecin est devenu un véritable examen physique

  • Exécute réellement la détection des commandes au lieu de simplement examiner l'existence des fichiers - peut identifier "installé mais cassé" (typique : le lien venv est rompu après la mise à niveau du système Python) et fournir des prescriptions de réinstallation qui peuvent être directement copiées
  • Signaler quel chemin est actuellement utilisé par chaque plate-forme multi-backend (active_backend de doctor --json)
  • L'effondrement d'un canal ne fera plus échouer l'examen physique dans son intégralité.

Stockage OpenCLI (backend de bureau)

agent-reach install --channels opencli : npm s'installe automatiquement, cliquez une fois sur le magasin d'extensions Chrome (modèle de sécurité Chrome, ne peut pas être cliqué au nom de). Réutilisez le statut de connexion de votre navigateur - vous pouvez l'utiliser directement après avoir parcouru Xiaohongshu ou vous être connecté à Reddit. Nécessite un ordinateur de bureau + Chrome, le serveur est automatiquement ignoré.

Expérience d'installation et de mise à jour

  • Installation en une phrase : 帮我安装 Agent Reach：https://raw.githubusercontent.com/Panniantong/agent-reach/main/docs/install.md
  • Mettre à jour une phrase : 帮我更新 Agent Reach：https://raw.githubusercontent.com/Panniantong/agent-reach/main/docs/update.md (ontologie + outils amont + compétences à rattraper d'un coup)
  • Réécriture des compétences : "Recherche à l'échelle du réseau" et "Aidez-moi à rechercher" sont déclenchés de manière fiable ; une fois que l'agent a terminé un gros travail, il vérifiera la version. S'il y a une nouvelle version, il fera un rappel à la fin (pas d'interruption, pas de harcèlement répété)
  • Correctif check-update : ne demande plus par erreur "mettre à jour" lorsque la version locale est antérieure à la dernière version (pour éviter une rétrogradation)

Qualité

  • Test 107 → 162 (Couverture complète du contrat/scénario de lien rompu/matrice de priorités backend/comparaison de versions)
  • Après trois séries d'examens contradictoires (les 12 résultats ont été corrigés) : des problèmes tels que le blocage du routage Twitter, les invites de rétrogradation de la montre, les commutateurs de proxy morts, etc. qui pourraient vraiment nuire aux utilisateurs ont été résolus.
  • Réussite des 32 tests de machine réelle de bout en bout sur 13 canaux

Remerciements

En amont nouvellement inclus : OpenCLI (@jackwener), xiaohongshu-mcp (@xpzouying).

Anglais original / English original

Agent-Reach v1.5.0

Highlights

  • Platforms become ordered backend lists — v1.5.0 reframes each integration as a capability layer: every platform now resolves to a primary + fallback backend chain that the project pre-selects, installs, and health-checks based on 32 real-device E2E tests (2026-06). For adopters this is the release's whole point — backend churn (a CLI going stale, an API locking down) is absorbed by routing instead of by your code, so you keep calling the same platform. The payoff is largest on Xiaohongshu and Reddit, where the chains are deepest.

  • Bilibili drops yt-dlp; Reddit has no zero-config path — yt-dlp is out for B站 after 412 risk-control blocked it even with proxies and cookies; use bili-cli (search/trending/detail, no login), OpenCLI for subtitles, then the search API fallback — yt-dlp still serves YouTube. On Reddit, anonymous endpoints are dead and the official API is approval-gated, so a logged-in session is mandatory; on Xiaohongshu the primary route is desktop OpenCLI reusing browser cookies, with xiaohongshu-mcp (QR) as the server option and xhs-cli kept only as a stale fallback. Watch the desktop-vs-server split: zero-config on a workstation is not zero-config on a headless box.

  • doctor now probes instead of just stat-ing files — It executes real commands, so "installed but broken" (the classic venv broken by a system Python upgrade) is detected with a copy-pasteable reinstall command, and doctor --json exposes active_backend per multi-backend platform. Failures are isolated per channel rather than aborting the whole check. Operationally: run doctor --json first after upgrading to see which route you are actually on, and let the prescriptions fix broken installs instead of reinstalling blind.

  • OpenCLI onboarding is mostly automated — agent-reach install --channels opencli npm-installs the backend; the one manual step is a single Chrome extension-store click, which Chrome's security model forbids automating. It inherits your existing browser login state, so a prior Xiaohongshu session or Reddit login makes it work immediately; servers skip it automatically. If you run agent-reach headless, plan on the server-side backends instead.

  • Install/update flow and skill triggers — One-line prompts (docs/install.md, docs/update.md) now pull the core, upstream tools, and skills in one pass; the rewritten skill reliably fires on "全网调研"/"帮我调研" and surfaces only a non-intrusive version hint at the end of large tasks. check-update no longer falsely nags when the local build is ahead of the latest release, preventing accidental downgrades — relevant if you track main or pinned builds.

  • Quality and regression coverage back the reshuffle — Tests grew from 107 to 162, covering contracts, broken-link scenarios, the backend-priority matrix, and version comparison; three adversarial review rounds closed 12 findings including real user-facing bugs (Twitter route suppression, watch downgrade messaging, dead proxy switches). All 13 channels / 32 E2E checks pass — the signal that the routing rewrite is safe to adopt rather than a cosmetic refactor.

No breaking changes were reported.

这一版是什么

Agent Reach 从「工具集合」升级为「能力层」:每个平台 = 首选 + 备选的有序后端列表,当下最稳的接入方式替你实测选好、装好、体检好——接入方式换代,你无感。本版全部选型基于 2026-06 真机实测(32 项端到端测试)。

平台路由变化

| 平台 | 现在的路 | |------|---------| | 小红书 | OpenCLI(桌面,复用浏览器登录态零配置)▸ xiaohongshu-mcp(服务器,扫码)▸ xhs-cli(存量备选,上游已停更) | | Reddit | OpenCLI ▸ rdt-cli。诚实口径:Reddit 没有零配置路径(匿名接口已被全面封锁、官方 API 审批制),必须登录态 | | B站 | bili-cli(搜索/热门/详情,无需登录)▸ OpenCLI(字幕)▸ 搜索 API 兜底。yt-dlp 退出 B站(被 412 风控全面拦截,实测最新版+代理+Cookie 均无效);yt-dlp 继续服务 YouTube | | Twitter | twitter-cli 守门(实测稳定)▸ OpenCLI 备选,探测加重试 |

doctor 成了真体检

  • 真跑命令探测,而不是只看文件存在——能识别「装了但坏了」(典型:系统 Python 升级后 venv 断链),并给出可直接复制的重装处方
  • 报告每个多后端平台当前在用哪条路(doctor --json 的 active_backend)
  • 一个渠道崩了不再拖垮整个体检

收纳 OpenCLI(桌面后端)

agent-reach install --channels opencli:npm 自动装,Chrome 扩展商店点一次(Chrome 安全模型,无法代点)。复用你浏览器的登录态——刷过小红书、登过 Reddit 就直接能用。需要桌面 + Chrome,服务器自动跳过。

安装与更新体验

  • 安装一句话:帮我安装 Agent Reach：https://raw.githubusercontent.com/Panniantong/agent-reach/main/docs/install.md
  • 更新一句话:帮我更新 Agent Reach：https://raw.githubusercontent.com/Panniantong/agent-reach/main/docs/update.md(本体+上游工具+skill 一次跟上)
  • skill 重写:「全网调研」「帮我调研」可靠触发;agent 干完大活会顺手查版本,有新版在收尾时提示一句(不打断、不重复唠叨)
  • check-update 修复:本地版本领先于最新 release 时不再误提示"更新"(避免降级)

质量

  • 测试 107 → 162(契约/断链场景/后端优先级矩阵/版本比较全覆盖)
  • 经三轮对抗性 review(12 项发现全部修复):修掉了 Twitter 路由屏蔽、watch 降级提示、死代理开关等会真实伤到用户的问题
  • 13 渠道 32 项真机端到端实测全通过

致谢

新收纳的上游:OpenCLI(@jackwener)、xiaohongshu-mcp(@xpzouying)。
