#claude-mem v15.1.0

claude-mem 15.1.0

Faits saillants

  • Nouveau visualiseur My Work (React, données en direct). Le visualiseur localhost de http://localhost:37777 est remplacé par le visualiseur React My Work sur les données des travailleurs en direct : une carte par demande humaine, des indicateurs de progression, des objectifs du propriétaire, l'alignement des objectifs, la vitesse d'expédition et l'histoire de construction (#5010).
  • Mon travail est toujours en ligne. Les mises à jour apparaissent au fur et à mesure de leur arrivée ; le bouton "Afficher les mises à jour" a disparu. L'en-tête indique désormais "claude-mem", renvoie vers la visionneuse Classic sur /viewer et affiche un bouton étoiles GitHub. Un tiroir de requêtes ouvert ne se rouvre plus tout seul lorsque sa requête revient au flux (#5056).
  • Demander un regroupement et un examen de la progression. L'histoire de construction reste sous son plafond et la mise à jour de l'histoire est informée de l'espace dont elle dispose (#5053, #5054) ; l'échec de l'actualisation de chaque agent est affiché ; les sous-agents terminés s'affichent comme terminés et un sous-agent peut être marqué comme terminé à partir de sa carte d'agent ; Les arrêts du sous-agent Claude Code sont enregistrés.

Serveur

  • Injection sémantique par invite en mode serveur (#5004).
  • Le modèle d'intégration configuré est intégré à l'image Docker (#5003).

MCP

  • Transport HTTP de bouclage opt-in avec espaces de travail par session (#5028).

Correctifs

  • Observateur : le raisonnement dispose de son propre budget et les réponses coupées sont rapportées (#5033).
  • Recherche : les chronologies non filtrées sont limitées à leur projet d'ancrage (#5013).
  • Worker : les écritures de bouclage d'origine croisée vers /api/import sont rejetées (#5025) ; Les charges utiles d'édition portant de nouveaux indicateurs scalaires continuent d'être supprimées (#5027).
  • Rédaction : clés secrètes AWS sous noms de clés minuscules, blocs de clés privées PGP et clés PKCS#8 chiffrées (#5014, #5017).
  • Sécurité : le texte d'invite privé reste en dehors des objectifs.
  • Smart-read : lecture de la sortie de la sonde tree-sitter lorsque Bun renvoie un Buffer (#5024), alias de type Go (#5020), méthodes d'extension Swift (#5016), symboles se terminant à la colonne 0 (#5015).
  • Crochets : last_assistant_message mappé dans l'adaptateur brut (#5011).
  • Agent Runner : le codex et Gemini installés par NPM sont trouvés et démarrés. ### Tests
  • Suite divisée en voies rapides et d'intégration ; tests lents, défaillants et source-grep coupés (#5032).

claude-mem v15.1.0

claude-mem 15.1.0

Highlights

  • New My Work viewer (React, live data). The localhost viewer at http://localhost:37777 is replaced by the React My Work viewer on live worker data: one card per human request, progress meters, owner goals, goal alignment, shipping velocity and the build story (#5010).
  • My Work is always live. Updates appear as they arrive; the "Show updates" button is gone. The header now reads "claude-mem", links to the Classic viewer at /viewer, and shows a GitHub stars button. An open request drawer no longer reopens by itself when its request returns to the feed (#5056).
  • Request grouping and progress review. The build story stays under its cap and the story update is told how much room it has (#5053, #5054); every agent's refresh failure is shown; finished subagents show as finished, and a subagent can be marked finished from its agent card; Claude Code subagent stops are recorded.

Server

  • Per-prompt semantic injection in server mode (#5004).
  • The configured embedding model is baked into the Docker image (#5003).

MCP

  • Opt-in loopback HTTP transport with per-session workspaces (#5028).

Fixes

  • Observer: reasoning gets its own budget and cut-off replies are reported (#5033).
  • Search: unfiltered timelines are scoped to their anchor project (#5013).
  • Worker: cross-origin loopback writes to /api/import are rejected (#5025); Edit payloads carrying new scalar flags keep being trimmed (#5027).
  • Redaction: AWS secret keys under lowercase key names, PGP private key blocks and encrypted PKCS#8 keys (#5014, #5017).
  • Security: private prompt text stays out of Goals.
  • Smart-read: tree-sitter probe output read when Bun returns a Buffer (#5024), Go type aliases (#5020), Swift extension methods (#5016), symbols ending at column 0 (#5015).
  • Hooks: last_assistant_message mapped in the raw adapter (#5011).
  • Agent runner: npm-installed codex and gemini are found and started.

Tests

  • Suite split into fast and integration lanes; slow, failing and source-grep tests cut (#5032).
