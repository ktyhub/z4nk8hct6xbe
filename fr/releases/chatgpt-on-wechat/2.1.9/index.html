chatgpt-sur-wechat 2.1.9

🌐 anglais | 中文

Il s'agit d'une version améliorée de la [version multi-agents 2.1.8] (https://docs.cowagent.ai/releases/v2.1.8), qui s'appuie sur une série d'améliorations et de correctifs concernant la collaboration multi-agents, les capacités de modèle et l'intégration des canaux.

🤝 Expérience multi-agents

Perfectionnez davantage l'utilisation d'équipes multi-agents :

  • Sélection de session multi-agent : le sélecteur multi-agent en session ajoute un marqueur d'agent principal qui sépare clairement l'agent principal des membres, tout en simplifiant la vue dans les configurations à agent unique.
  • Correction de collaboration : correction d'échecs lors de la délégation de tâches d'agents non principaux dans les discussions de groupe multi-agents, identifiant désormais correctement les agents membres.
  • Rendu d'image d'agent membre : correction des images générées par des agents autres que ceux par défaut qui ne parvenaient pas à s'afficher sur la console Web et le bureau client.
  • Entrée de discussion de groupe : la page Équipe du bureau ajoute une entrée de discussion de groupe, afin que vous puissiez démarrer une session de groupe directement à partir d'une équipe d'agents.
<img src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/agent-group-chat-picker.png" alt="Chat de groupe multi-agents" width="800" />

📡 Correctifs d'intégration des chaînes

Correction de problèmes clés le long du chemin de démarrage/arrêt du canal de la console pour une intégration plus stable des canaux :

  • Correction d'intégration des canaux de bureau : correction des canaux qui ne parvenaient pas à démarrer dans le bureau client.
  • Correction d'arrêt de canal : correction d'une recherche app_module perdue pendant le flux d'arrêt de canal qui provoquait des erreurs de déconnexion (une régression introduite par #3141).
  • Reconnexion du canal QQ : correction du canal QQ qui ne se reconnectait pas après une déconnexion silencieuse de WebSocket ; il se reconnecte désormais automatiquement.

🤖 Capacités du modèle

  • Configuration de la liste de modèles : les fournisseurs de modèles peuvent désormais configurer une liste de modèles, en définissant le nom du modèle, le type de modèle, la fenêtre contextuelle, la sortie maximale, etc. Merci @alanyz106 (#3146)
<img src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/model-catalog-config.png" alt="Configuration de la liste de modèles" width="800" />
  • Modèles de repli multiples : lorsque le modèle principal échoue, CowAgent essaie désormais à son tour une chaîne de repli ordonnée, remplaçant le modèle de repli unique précédent. Merci @alanyz106 (#3125)
<img src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/model-fallback-chain.png" alt="Plusieurs modèles de secours" width="800" />
  • Correction des informations d'identification de secours : correction de la résolution des informations d'identification lors du repli, qui résout désormais les informations d'identification par le fournisseur réellement acheminées plutôt que par la configuration globale. Merci @alanyz106 (#3142)
  • Nouveaux modèles d'image : ajout de gpt-image-2.5-flare et gpt-image-2.5-sunburst. Merci @cowagent (#3140)

🛠 Améliorations et correctifs

  • Tolérance de fichier de configuration : tolérez une nomenclature UTF-8 dans config.json et arrêtez l'interrogation 401 de pré-connexion pour éviter les demandes non valides avant la connexion.
  • Corrections de génération d'images :
    • Correction du crash de Baidu Ernie IMAGE_CREATE lorsqu'il n'est pas pris en charge, renvoyant désormais un message d'erreur à la place (Merci @c020627 #3144).
    • Correction des tentatives de réponse à mi-parcours qui ne se répétaient pas correctement dans la logique d'envoi (Merci @c020627 #3151).
  • Correction vocale : correction du transcodage vocal Silk en décodant d'abord Silk en un wav autonome, puis en ré-encodant en mp3, en évitant d'écraser le fichier source (Merci @c020627 #3149).
  • Classification des URL des médias : déterminez le type de média à partir du chemin de l'URL résolu, en corrigeant les liens multimédias mal classés (Merci @c020627 #3150).
  • Baidu Translate : correction de Baidu Translate ne signalant pas l'erreur API après l'échec de toutes les tentatives (Merci @c020627 #3147).
  • Détection de commandes en arrière-plan : limitez run_in_background aux processus de longue durée, empêchant ainsi les tâches d'être marquées comme terminées trop tôt.
  • Troncation de sortie de l'outil : signalez correctement la raison de la troncature basée sur les octets lorsque les lignes conservées sont partiellement tronquées (Merci @c020627 #3137).
  • Mise en page Web mobile : amélioration de la mise en page de la console sur mobile.
  • Desktop client : correction du menu de l'équipe multi-agents qui ne s'affichait pas.

📦 Comment mettre à niveau

  • Déploiement source : exécutez cow update pour une mise à niveau d'un click, ou extrayez le dernier code et redémarrez. Consultez le [guide de mise à niveau] (https://docs.cowagent.ai/guide/upgrade).
  • Desktop client : recherchez les mises à jour et mettez à jour avec un click dans le client, ​​ou obtenez la dernière version à partir de la [page de téléchargement] (https://cowagent.ai/download/).

Anglais original / English original

chatgpt-on-wechat 2.1.9

Highlights

  • Ordered fallback with correct credentials — Failed primary requests now traverse a configured fallback chain instead of stopping after one alternate (#3125). Credentials resolve against the provider actually selected (#3142), which is critical for mixed-provider deployments; verify fallback order and provider credentials after upgrading.
  • Provider-managed model metadata — Providers can define model names, types, context windows, and output limits (#3146), allowing teams to encode actual model capabilities rather than rely on generic defaults. This release also adds gpt-image-2.5-flare and gpt-image-2.5-sunburst (#3140); confirm provider support before selecting them.
  • More reliable multi-Agent workflows — Non-lead Agents can now delegate in group chats, and images from non-default Agents render correctly in Web and desktop clients. The desktop Team page adds direct group-chat access, reducing friction for team sessions.
  • Channel lifecycle repairs — Desktop channels start correctly again, the stop flow no longer loses its app_module lookup following the #3141 regression, and QQ automatically reconnects after silent WebSocket disconnects. Long-running channel deployments should require fewer manual restarts.
  • Safer media and background execution — Unsupported Ernie IMAGE_CREATE calls return an error instead of crashing (#3144), Midjourney retries correctly re-enter the send logic (#3151), and Silk conversion uses an intermediate WAV to avoid overwriting the source (#3149). Media classification now follows the resolved URL path (#3150), while run_in_background is restricted to long-running processes, preventing premature task completion.
  • Compatibility — No breaking changes.

🌐 English | 中文

This is a refinement release for the 2.1.8 multi-Agent version, building on it with a series of improvements and fixes across multi-Agent collaboration, model capabilities, and channel integration.

🤝 Multi-Agent Experience

Further polish around using multi-Agent teams:

  • Multi-Agent session selection: the in-session multi-Agent selector adds a lead-Agent marker that clearly separates the lead Agent from members, while simplifying the view in single-Agent setups.
  • Collaboration fix: fixed failures when delegating tasks from non-lead Agents in multi-Agent group chats, now correctly identifying member Agents.
  • Member Agent image rendering: fixed images generated by non-default Agents failing to render on the Web console and desktop client.
  • Group-chat entry: the desktop Team page adds a group-chat entry, so you can start a group session directly from an Agent team.
<img src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/agent-group-chat-picker.png" alt="Multi-Agent group chat" width="800" />

📡 Channel Integration Fixes

Fixed key issues along the console's channel start/stop path for more stable channel integration:

  • Desktop channel integration fix: fixed channels failing to start in the desktop client.
  • Channel stop fix: fixed a lost app_module lookup during the channel stop flow that caused disconnect errors (a regression introduced by #3141).
  • QQ channel reconnection: fixed the QQ channel not reconnecting after a silent WebSocket disconnect; it now reconnects automatically.

🤖 Model Capabilities

  • Model list configuration: model providers can now configure a model list, setting the model name, model type, context window, max output, and more. Thanks @alanyz106 (#3146)
<img src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/model-catalog-config.png" alt="Model list configuration" width="800" />
  • Multiple fallback models: when the primary model fails, CowAgent now tries an ordered fallback chain in turn, replacing the previous single fallback model. Thanks @alanyz106 (#3125)
<img src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/model-fallback-chain.png" alt="Multiple fallback models" width="800" />
  • Fallback credential fix: fixed credential resolution during fallback, which now resolves credentials by the provider actually routed to rather than the global configuration. Thanks @alanyz106 (#3142)
  • New image models: added gpt-image-2.5-flare and gpt-image-2.5-sunburst. Thanks @cowagent (#3140)

🛠 Improvements & Fixes

  • Config file tolerance: tolerate a UTF-8 BOM in config.json, and stop the pre-login 401 polling to avoid invalid requests before sign-in.
  • Image generation fixes:
    • fixed Baidu Ernie IMAGE_CREATE crashing when unsupported, now returning an error message instead (Thanks @c020627 #3144).
    • fixed Midjourney reply retries not recursing into the send logic correctly (Thanks @c020627 #3151).
  • Voice fix: fixed silk voice transcoding by first decoding silk into a standalone wav and then re-encoding to mp3, avoiding overwriting the source file (Thanks @c020627 #3149).
  • Media URL classification: determine media type from the resolved URL path, fixing misclassified media links (Thanks @c020627 #3150).
  • Baidu Translate: fixed Baidu Translate not reporting the API error after all retries failed (Thanks @c020627 #3147).
  • Background command detection: restrict run_in_background to long-running processes, preventing tasks from being marked complete too early.
  • Tool output truncation: report the byte-based truncation reason correctly when kept lines are partially truncated (Thanks @c020627 #3137).
  • Web mobile layout: improved the console layout on mobile.
  • Desktop client: fixed the multi-Agent team menu not showing.

📦 How to Upgrade

  • Source deployment: run cow update for a one-click upgrade, or pull the latest code and restart. See the upgrade guide.
  • Desktop client: check for updates and update with one click inside the client, or get the latest version from the download page.
