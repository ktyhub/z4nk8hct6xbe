🧬 Auto-évolution

CowAgent introduit Self-Evolution, permettant à l'agent d'aller au-delà d'une seule tâche et de continuer à s'améliorer grâce à une collaboration quotidienne avec vous :

  • Révision automatique après inactivité : une fois qu'une conversation reste inactive, l'agent l'examine en arrière-plan pour résoudre les problèmes liés à une compétence exposée en cours d'utilisation, créer de nouvelles compétences réutilisables, assurer le suivi des tâches inachevées et enregistrer des informations importantes dans la mémoire et la base de connaissances.
  • Silencieux par défaut, notifier à la demande : il signale ce qu'il a modifié uniquement lorsqu'il a réellement effectué une modification, et reste silencieux dans le cas contraire.
  • Sûr et réversible : Chaque révision est préalablement sauvegardée et peut être annulée à tout moment. Les compétences intégrées sont protégées et toutes les lectures et écritures restent dans l'espace de travail

Activé par défaut pour les nouvelles installations. Les utilisateurs existants peuvent l'activer avec un seul click dans la console Web sous Paramètres → Configuration de l'agent.

💬 Mises à niveau de la console Web

L'expérience de chat de la console Web bénéficie de plusieurs améliorations :

  • Gestion des messages : modifiez, supprimez et régénérez les messages des utilisateurs et des robots ; les blocs de code incluent désormais des étiquettes de langue et un bouton de copie one-click
  • Sessions parallèles : exécutez plusieurs sessions en même temps sans interférence, avec une reprise automatique de la diffusion en direct lorsque vous revenez à une session.
  • Affinements : faites glisser et déposez des fichiers n'importe où dans la vue de discussion ; passer automatiquement à une session frère après avoir supprimé la session active

chatgpt-on-wechat 2.1.1

Highlights

  • Self-Evolution ships on by default — New installs get an agent that, once a conversation goes idle, reviews it in the background to repair skills that misbehaved, mint reusable new skills, chase unfinished tasks, and persist findings into memory and the knowledge base. It stays silent unless something actually changed, every review is snapshotted beforehand with full undo, built-in skills are protected, and all reads/writes are confined to the workspace. The key adoption detail: existing installs keep the old behavior until you opt in via Web Console → Settings → Agent Config, so decide deliberately whether to flip it on during rollout.

  • Web Console chat becomes genuinely editable and parallel — #2865 adds edit/delete/regenerate on both user and bot messages, language-tagged code blocks with one-click copy, and simultaneous sessions whose live streaming auto-resumes when you switch back. Files can be dropped anywhere in the chat view, and deleting the active session falls back to a sibling. Worth testing if your workflow assumed a single stream: two sessions now run independently and resume rather than restart.

  • MCP unblocked on Windows and made concurrent — #2859 fixes stdio transport failing on Windows and exposes the server timeout as configurable via mcp.json, which matters if tools were silently timing out. The sse and streamable-http transports now handle concurrent calls across sessions, so multi-tool chains no longer serialize. Windows users on older configs should revisit their mcp.json timeout values after upgrading.

  • Model lineup shifts without a migration — #2855 promotes MiniMax-M3 to the default while keeping the M2.7 series as an option; pin M2.7 explicitly if you need output parity. Qwen3.7-plus adds multi-modal conversations, #2857 lets the Web Console select and persist an ASR (speech recognition) model, and the one-line installer streamlines the menu and adds Xiaomi MiMo. Watch for changed behavior in prompts that never named a model.

  • Runtime and deployment hardening — Python 3.13 install/dependency issues are fixed, streaming replies can now actually be interrupted (a long-standing cancellation bug), cow status reports the current project path, and channel ordering follows the UI language with improved auto fallback. Security-wise, #2863 narrows the credential-file block to just ~/.cow/.env so other directories are untouched, and the WeChat Official Account now rejects webhook requests when wechatmp_token is empty — set a token before upgrading if you relied on an unauthenticated MP webhook. Source deployments can cow update (or pull and restart).

  • Breaking changes — None formally declared in 2.1.1.

🌐 English | 中文

🧬 Self-Evolution

CowAgent introduces Self-Evolution, letting the agent go beyond completing a single task and keep improving through everyday collaboration with you:

  • Automatic review after idle: Once a conversation goes idle, the agent reviews it in the background to fix problems a skill exposed in use, create reusable new skills, follow up on unfinished tasks, and record important information into memory and the knowledge base
  • Silent by default, notify on demand: It reports what it changed only when it actually made a change, and stays silent otherwise
  • Safe and reversible: Every review is backed up beforehand and can be undone at any time. Built-in skills are protected, and all reads and writes stay within the workspace

Enabled by default for new installs. Existing users can turn it on with a single click in the Web Console under Settings → Agent Config.

<img width="750" src="https://cdn.jsdelivr.net/gh/zhayujie/cowagent-assets@main/screenshots/en/web-console-evolution-demo.png" alt="Self-Evolution conversation example" />

Documentation: Self-Evolution

💬 Web Console Upgrades

The Web Console chat experience gets several enhancements:

  • Message management: Edit, delete, and regenerate both user and bot messages; code blocks now include language labels and a one-click copy button
  • Parallel sessions: Run multiple sessions at the same time without interference, with live streaming automatically resumed when you switch back to a session
  • Refinements: Drag and drop files anywhere in the chat view; automatically switch to a sibling session after deleting the active one

Thanks @core-power (#2865)

🧩 Cross-platform MCP Enhancements

  • Windows compatibility fix: Fixed stdio communication failing on Windows, and made the server timeout configurable via mcp.json
  • Concurrent calls: The sse and streamable-http transports now support concurrent calls across sessions for faster multi-tool responses

Thanks @xliu123321 (#2859)

Documentation: MCP Tools

🤖 New Models & Improvements

  • MiniMax-M3: Added and set as the default model, with the M2.7 series kept as an option. Thanks @octo-patch (#2855)
  • Qwen3.7-plus: Added support for multi-modal conversations
  • Selectable ASR model: The Web Console can now select and persist the ASR (speech recognition) model. Thanks @nightwhite (#2857)
  • Simplified install menu: The one-line install script streamlines the model menu and adds the Xiaomi MiMo option

Documentation: Models Overview

🛠 Improvements & Fixes

  • Python 3.13 support: Fixed installation and dependency compatibility on Python 3.13
  • Internationalization: The channel list is now ordered by the interface language; refined the automatic language fallback under auto mode
  • More reliable cancellation: Fixed cases where a streaming reply could not be interrupted
  • CLI: cow status now shows the current project path
  • Hardened deployment security: The credential-file block is narrowed to ~/.cow/.env so other directories are no longer affected (Thanks @orbisai0security #2863); the WeChat Official Account now rejects webhook requests when wechatmp_token is empty
  • Group task board plugin: Added the group task board plugin source. Thanks @Wyh-max-star (#2853)

📦 Upgrade

Source-code deployments can run cow update for a one-click upgrade, or pull the latest code and restart manually. See the Upgrade Guide for details.
