feindre 13.18

Ce qui a changé

  • Ajoutez le codec feign-jdk-json pour le JDK Simple JSON API (JEP 540) et corrigez la fusion automatique de Dependabot par @velo dans https://github.com/OpenFeign/feign/pull/3620
  • Exclure les champs statiques des cartes de requêtes de champs par @hutiefang76 dans https://github.com/OpenFeign/feign/pull/3613
  • Traitez les valeurs HeaderMap d'exécution comme des littéraux par @hutiefang76 dans https://github.com/OpenFeign/feign/pull/3612
  • docs : correction de fautes de frappe dans la documentation de @hamidzr dans https://github.com/OpenFeign/feign/pull/3659
  • Lit le jeu de caractères de réponse après d'autres paramètres Content-Type par @hutiefang76 dans https://github.com/OpenFeign/feign/pull/3628
  • Lire les paramètres de jeu de caractères cités et en casse mixte dans FormEncoder par @kdelay dans https://github.com/OpenFeign/feign/pull/3611
  • Document indiquant que Logger reflète la demande de Feign, et non la demande électronique de @ChrisJr404 dans https://github.com/OpenFeign/feign/pull/3544
  • Appliquez les extensions @Param sur les champs et les getters QueryMap POJO par @havefunatcode dans https://github.com/OpenFeign/feign/pull/3658
  • Ajoutez des balises d'hôte cible et d'observation de port opt-in par @henriquejsza dans https://github.com/OpenFeign/feign/pull/3546
  • feign-kotlin : ajoutez WebClient non bloquant AsyncClient et améliorez la prise en charge des coroutines par @ggoowlgns dans https://github.com/OpenFeign/feign/pull/3645
  • sauter privé et varier : * réponses dans HttpCacheInterceptor par @alhudz dans https://github.com/OpenFeign/feign/pull/3610
  • Appliquer les délais d'attente du corps de réponse Java 11 par @goutamadwant dans https://github.com/OpenFeign/feign/pull/3462
  • feindre-mock : autoriser la correspondance des en-têtes de requête par sous-ensemble par @lxcxjxhx dans https://github.com/OpenFeign/feign/pull/3661
  • Correction du remplacement des fragments d'URI et préservation des échappements de cible par @hutiefang76 dans https://github.com/OpenFeign/feign/pull/3633
  • Honore l'indicateur de caractère réservé pour les valeurs URI non échappées par @hutiefang76 dans https://github.com/OpenFeign/feign/pull/3627
  • Préserver l'ordre des valeurs d'en-tête de réponse Java11 et les doublons par @hutiefang76 dans https://github.com/OpenFeign/feign/pull/3638
  • Préserver les valeurs littérales des requêtes et développer les paramètres du tableau par @hutiefang76 dans https://github.com/OpenFeign/feign/pull/3624
  • Reconnaître les schémas d'URI HTTP sans tenir compte du cas par @wozhenbang2004 dans https://github.com/OpenFeign/feign/pull/3665
  • Honorer zéro connexion et lire les délais d'attente dans Java11 client par @hutiefang76 dans https://github.com/OpenFeign/feign/pull/3637
  • Restaurez les tentatives Apache HTTP4 pour les requêtes idempotentes sans corps par @hutiefang76 dans https://github.com/OpenFeign/feign/pull/3634
  • Complète les contrats à terme asynchrones client lorsque le délégué lance une erreur de @hutiefang76 dans https://github.com/OpenFeign/feign/pull/3630
  • Partage l'analyse du jeu de caractères prenant en compte les citations avec les encodeurs de formulaire par @hutiefang76 dans https://github.com/OpenFeign/feign/pull/3674
  • Réutilisez les connexions persistantes DefaultClient lorsque les corps fragmentés ne sont pas lus jusqu'à la fin par @velo dans https://github.com/OpenFeign/feign/pull/3673

feign 13.18

What's Changed

  • Add feign-jdk-json codec for the JDK Simple JSON API (JEP 540) and fix Dependabot auto-merge by @velo in https://github.com/OpenFeign/feign/pull/3620
  • Exclude static fields from field query maps by @hutiefang76 in https://github.com/OpenFeign/feign/pull/3613
  • Treat runtime HeaderMap values as literals by @hutiefang76 in https://github.com/OpenFeign/feign/pull/3612
  • docs: fix typos in documentation by @hamidzr in https://github.com/OpenFeign/feign/pull/3659
  • Reads response charset after other Content-Type parameters by @hutiefang76 in https://github.com/OpenFeign/feign/pull/3628
  • Read quoted and mixed-case charset parameters in FormEncoder by @kdelay in https://github.com/OpenFeign/feign/pull/3611
  • Document that Logger reflects Feign's Request, not the wire request by @ChrisJr404 in https://github.com/OpenFeign/feign/pull/3544
  • Apply @Param expanders on QueryMap POJO fields and getters by @havefunatcode in https://github.com/OpenFeign/feign/pull/3658
  • Add opt-in target host and port observation tags by @henriquejsza in https://github.com/OpenFeign/feign/pull/3546
  • feign-kotlin: add non-blocking WebClient AsyncClient and improve coroutine support by @ggoowlgns in https://github.com/OpenFeign/feign/pull/3645
  • skip private and Vary: * responses in HttpCacheInterceptor by @alhudz in https://github.com/OpenFeign/feign/pull/3610
  • Enforce Java 11 response body timeouts by @goutamadwant in https://github.com/OpenFeign/feign/pull/3462
  • feign-mock: allow matching request headers by subset by @lxcxjxhx in https://github.com/OpenFeign/feign/pull/3661
  • Fix URI fragment replacement and preserve target escapes by @hutiefang76 in https://github.com/OpenFeign/feign/pull/3633
  • Honors reserved-character flag for unescaped URI values by @hutiefang76 in https://github.com/OpenFeign/feign/pull/3627
  • Preserve Java11 response header value order and duplicates by @hutiefang76 in https://github.com/OpenFeign/feign/pull/3638
  • Preserve literal query values and expand array parameters by @hutiefang76 in https://github.com/OpenFeign/feign/pull/3624
  • Recognize HTTP URI schemes without regard to case by @wozhenbang2004 in https://github.com/OpenFeign/feign/pull/3665
  • Honor zero connect and read timeouts in the Java11 client by @hutiefang76 in https://github.com/OpenFeign/feign/pull/3637
  • Restore Apache HTTP4 retries for bodyless idempotent requests by @hutiefang76 in https://github.com/OpenFeign/feign/pull/3634
  • Completes async client futures when the delegate throws Error by @hutiefang76 in https://github.com/OpenFeign/feign/pull/3630
  • Shares quote-aware charset parsing with form encoders by @hutiefang76 in https://github.com/OpenFeign/feign/pull/3674
  • Reuse DefaultClient keep-alive connections when chunked bodies are not read to the end by @velo in https://github.com/OpenFeign/feign/pull/3673
