Ce qui a changé

Fonctionnalité

  • Prise en charge du rythme cardiaque pour le triple protocole par @icodening dans https://github.com/apache/dubbo/pull/12955
  • Prise en charge de Jboss @Form par @suncairong163 dans https://github.com/apache/dubbo/pull/13201
  • Découverte du service de prise en charge de registres multiples par @zhengkaifor dans https://github.com/apache/dubbo/pull/13137

Correction de bugs

  • Libérez ByteBuf lorsque le handle onData n'a pas réussi à empêcher une fuite de mémoire par @finefuture dans https://github.com/apache/dubbo/pull/13102
  • Correction du triple exécuteur de flux client par @finefuture dans https://github.com/apache/dubbo/pull/13178
  • Correction de RejectException par @finefuture dans https://github.com/apache/dubbo/pull/12950
  • Définir la valeur par défaut pour le protocole d'acceptation au repos par @sick-cat dans https://github.com/apache/dubbo/pull/13199
  • Correction des mauvais types de retour pour StubMethodDescriptor par @namelessssssssssss dans https://github.com/apache/dubbo/pull/13223
  • Correction de l'impossibilité de recevoir le cadre de départ par @AlbumenJ dans https://github.com/apache/dubbo/pull/13228
  • Correction du remplacement de méthode triple par @AlbumenJ dans https://github.com/apache/dubbo/pull/13224
  • Supprimez le verrouillage de synchronisation pour la cible à ressort paresseux pour éviter le blocage mort par @AlbumenJ dans https://github.com/apache/dubbo/pull/13220
  • Correction du changement de MigrationRule lors du chargement de la valeur par défaut du consommateur par @AlbumenJ dans https://github.com/apache/dubbo/pull/13237
  • Correction de l'en-tête minuscule dans le protocole de repos par @sick-cat dans https://github.com/apache/dubbo/pull/13247
  • Correction de la désérialisation de Jackson, pas d'échec sur les propriétés inconnues par @sick-cat dans https://github.com/apache/dubbo/pull/13249
  • Correction des paramètres de clé de service lors de la suppression de l'écouteur d'instance de service par @AlbumenJ dans https://github.com/apache/dubbo/pull/13272
  • Correction du remplacement de MappingListener dans ServiceDiscoveryRegistry par @AlbumenJ dans https://github.com/apache/dubbo/pull/13277

What's Changed

Feature

  • Support heartbeat for triple protocol by @icodening in https://github.com/apache/dubbo/pull/12955
  • Jboss @Form support by @suncairong163 in https://github.com/apache/dubbo/pull/13201
  • Multiple Registry support Service Discovery by @zhengkaifor in https://github.com/apache/dubbo/pull/13137

Bugfix

  • Release ByteBuf when handle onData failed to prevent memory leak by @finefuture in https://github.com/apache/dubbo/pull/13102
  • Fix triple client stream executor by @finefuture in https://github.com/apache/dubbo/pull/13178
  • Fix RejectException by @finefuture in https://github.com/apache/dubbo/pull/12950
  • Set default value for accept in rest protocol by @sick-cat in https://github.com/apache/dubbo/pull/13199
  • Fix wrong returnTypes for StubMethodDescriptor by @namelessssssssssss in https://github.com/apache/dubbo/pull/13223
  • Fix unable to receive go away frame by @AlbumenJ in https://github.com/apache/dubbo/pull/13228
  • Fix triple method override by @AlbumenJ in https://github.com/apache/dubbo/pull/13224
  • Remove sync lock for lazy spring target to prevent dead lock by @AlbumenJ in https://github.com/apache/dubbo/pull/13220
  • Fix MigrationRule changing when load consumer default value by @AlbumenJ in https://github.com/apache/dubbo/pull/13237
  • Fix lowerCase header in rest protocol by @sick-cat in https://github.com/apache/dubbo/pull/13247
  • Fix jackson deserialization, not fail on unknown properties by @sick-cat in https://github.com/apache/dubbo/pull/13249
  • Fix service key params when remove service instance listener by @AlbumenJ in https://github.com/apache/dubbo/pull/13272
  • Fix MappingListener override in ServiceDiscoveryRegistry by @AlbumenJ in https://github.com/apache/dubbo/pull/13277
