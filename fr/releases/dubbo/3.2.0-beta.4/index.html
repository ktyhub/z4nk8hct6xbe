Ce qui a changé

Fonctionnalité

  • Ajout du support bytebuddy par @icodening dans https://github.com/apache/dubbo/pull/11117
  • Ajouter une métrique de limite de délai d'attente par @jojocodeX dans https://github.com/apache/dubbo/pull/11244
  • Le compteur Jvm ajoute l'étiquette du nom de l'application par @songxiaosheng dans https://github.com/apache/dubbo/pull/11255
  • Ajoutez le préfixe Dubbo (dubbo.provider) aux métriques du fournisseur Dubbo par @fomeiherz dans https://github.com/apache/dubbo/pull/11295
  • Ajout de métriques pour le total des demandes ayant échoué par @jojocodeX dans https://github.com/apache/dubbo/pull/11315
  • Ajoutez la logique d'observation xdsroute par @MentosL dans https://github.com/apache/dubbo/pull/11309
  • Faire fonctionner le routeur xds par @AlbumenJ dans https://github.com/apache/dubbo/pull/11319
  • Changez le nom selon la convention de dénomination par @fomeiherz dans https://github.com/apache/dubbo/pull/11327

Correction de bugs

  • Correction du jeton qui ne fonctionne pas dans le protocole de repos par @ShenFeng312 dans https://github.com/apache/dubbo/pull/11144
  • Améliorer la mise à jour de la découverte du service nacos par @AlbumenJ dans https://github.com/apache/dubbo/pull/11239
  • Refactoriser nacos à mettre à jour par @AlbumenJ dans https://github.com/apache/dubbo/pull/11313
  • Fonctionnalité/modification de l'abonnement xds par @aamingaa dans https://github.com/apache/dubbo/pull/10885
  • Correction native de la configuration de réflexion par @CrazyHZM dans https://github.com/apache/dubbo/pull/11263
  • Correction de la configuration impossible à sérialiser par @AlbumenJ dans https://github.com/apache/dubbo/pull/11267
  • Mettre à jour l'annotation IPv6 et filtrer les IPv6 invalides par @HHoflittlefish777 dans https://github.com/apache/dubbo/pull/11266
  • Le correctif des invocateurs a changé lors du changement de chaîne de routeur par @AlbumenJ dans https://github.com/apache/dubbo/pull/11248
  • Correction des lds observés par @aamingaa dans https://github.com/apache/dubbo/pull/11300
  • Prise en charge de fastjson2 en cas natif par @CrazyHZM dans https://github.com/apache/dubbo/pull/11325
  • Ne supprimez pas le fichier de verrouillage lorsque le verrou est détenu par un autre par @schneiderlin dans https://github.com/apache/dubbo/pull/11324
  • Correction de la duplication des clés de métriques par @jojocodeX dans https://github.com/apache/dubbo/pull/11349
  • Correction de l'exception de déploiement de l'écouteur par @aamingaa dans https://github.com/apache/dubbo/pull/11351

Optimisation des performances

  • Optimize ConcurrentHashMap#computeIfAbsent a un problème de performances dans jdk1.8 par @mxsm dans https://github.com/apache/dubbo/pull/11326

What's Changed

Feature

  • Add bytebuddy support by @icodening in https://github.com/apache/dubbo/pull/11117
  • Add timeout limit metric by @jojocodeX in https://github.com/apache/dubbo/pull/11244
  • Jvm meter add application name label by @songxiaosheng in https://github.com/apache/dubbo/pull/11255
  • Add dubbo prefix(dubbo.provider) to dubbo provider metrics by @fomeiherz in https://github.com/apache/dubbo/pull/11295

  • Add xdsroute observe logic by @MentosL in https://github.com/apache/dubbo/pull/11309

  • Enhance nacos service discovery update by @AlbumenJ in https://github.com/apache/dubbo/pull/11239
  • Refactor nacos to update by @AlbumenJ in https://github.com/apache/dubbo/pull/11313
  • Feature/modify xds subscribe by @aamingaa in https://github.com/apache/dubbo/pull/10885
  • Fix native about reflect config by @CrazyHZM in https://github.com/apache/dubbo/pull/11263
  • Fix config unable to serialize by @AlbumenJ in https://github.com/apache/dubbo/pull/11267
  • Update IPv6 annotation and filter invalid IPv6 by @HHoflittlefish777 in https://github.com/apache/dubbo/pull/11266
  • Fix invokers has changed when router chain switch by @AlbumenJ in https://github.com/apache/dubbo/pull/11248
  • Fix lds observe by @aamingaa in https://github.com/apache/dubbo/pull/11300
  • Support fastjson2 in native case by @CrazyHZM in https://github.com/apache/dubbo/pull/11325
  • Don't delete lock file when lock is held by other by @schneiderlin in https://github.com/apache/dubbo/pull/11324
  • Fix metrics key duplication by @jojocodeX in https://github.com/apache/dubbo/pull/11349
  • Fix deploy listener exception by @aamingaa in https://github.com/apache/dubbo/pull/11351

Performance Optimization

  • Optimize ConcurrentHashMap#computeIfAbsent have performance problem in jdk1.8 by @mxsm in https://github.com/apache/dubbo/pull/11326
