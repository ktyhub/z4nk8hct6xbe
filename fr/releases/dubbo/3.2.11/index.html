Ce qui a changé

Amélioration

  • L'annotation DubboService prend en charge la sérialisation personnalisée par @zhaoyunxing92 dans https://github.com/apache/dubbo/pull/13553
  • Prise en charge du code d'état de réponse Resteasy par @suncairong163 dans https://github.com/apache/dubbo/pull/13586
  • Prise en charge des paramètres de personnalisation pour l'enregistrement au niveau de l'interface par @finefuture dans https://github.com/apache/dubbo/pull/13304

Correction de bugs

  • Correction du décodage des caractères chinois dans le protocole rest par @MajaChen dans https://github.com/apache/dubbo/pull/13617
  • Correction du nom d'erreur du fichier de cache MultipleRegistry par @shaowYe dans https://github.com/apache/dubbo/pull/13633
  • Correction du verrouillage du sémaphore AbortPolicyWithReport non libéré par @CycleMaker dans https://github.com/apache/dubbo/pull/13609
  • Correction du problème de journal MergeableClusterInvoker par @namelessssssssssss dans https://github.com/apache/dubbo/pull/13593
  • Correction d'un problème de copie approfondie de la classe protobuf par @namelessssssssssss dans https://github.com/apache/dubbo/pull/13597
  • Correction du remplacement de MethodKeyRt et de l'amélioration de l'erreur par @AlbumenJ dans https://github.com/apache/dubbo/pull/13580
  • Correction du blocage de publication retardé par @AlbumenJ dans https://github.com/apache/dubbo/pull/13583
  • Correction du remplacement de dubbo.tag par consumer.tag dans NacosRegistry par @namelessssssssssss dans https://github.com/apache/dubbo/pull/13592
  • Correction du problème de génération de StubMethodDescriptor par @namelessssssssssss dans https://github.com/apache/dubbo/pull/13582
  • Correction du problème du proto package et du java_package par @namelessssssssssss dans https://github.com/apache/dubbo/pull/13559
  • Correction d'une exception déjà complète par @icodening dans https://github.com/apache/dubbo/pull/13546
  • Correction du lien dubbo-go et du langage rust par @baerwang dans https://github.com/apache/dubbo/pull/13558
  • Correction de la dépendance de connexion de la démo native par @CrazyHZM dans https://github.com/apache/dubbo/pull/13551
  • Correction d'une fuite de mémoire dans le service de repos et libération du ByteBuf du champ NettyHttpRequest par @G-XD dans https://github.com/apache/dubbo/pull/13514

What's Changed

Enhancement

  • DubboService annotation support custom serialization by @zhaoyunxing92 in https://github.com/apache/dubbo/pull/13553
  • Support resteasy response status code by @suncairong163 in https://github.com/apache/dubbo/pull/13586
  • Support customize parameters for interface-level registration by @finefuture in https://github.com/apache/dubbo/pull/13304

Bugfix

  • Fix Chinese character decoding in rest protocol by @MajaChen in https://github.com/apache/dubbo/pull/13617
  • Fix MultipleRegistry cache file error name by @shaowYe in https://github.com/apache/dubbo/pull/13633
  • Fix AbortPolicyWithReport Semaphore lock not released by @CycleMaker in https://github.com/apache/dubbo/pull/13609
  • Fix MergeableClusterInvoker log issue by @namelessssssssssss in https://github.com/apache/dubbo/pull/13593
  • Fix protobuf class deep copy issue by @namelessssssssssss in https://github.com/apache/dubbo/pull/13597
  • Fix MethodKeyRt override and error enhance by @AlbumenJ in https://github.com/apache/dubbo/pull/13580
  • Fix delay publish deadlock by @AlbumenJ in https://github.com/apache/dubbo/pull/13583
  • Fix dubbo.tag override by consumer.tag in NacosRegistry by @namelessssssssssss in https://github.com/apache/dubbo/pull/13592
  • Fix StubMethodDescriptor generate issue by @namelessssssssssss in https://github.com/apache/dubbo/pull/13582
  • Fix proto package and java_package issue by @namelessssssssssss in https://github.com/apache/dubbo/pull/13559
  • Fix complete already exception by @icodening in https://github.com/apache/dubbo/pull/13546
  • Fix dubbo-go link and rust language by @baerwang in https://github.com/apache/dubbo/pull/13558
  • Fix native demo logback dependency by @CrazyHZM in https://github.com/apache/dubbo/pull/13551
