What's Changed

Feature

  • Add tracing starters && Add zipkin auto configuration by @conghuhu in https://github.com/apache/dubbo/pull/12013
  • QoS Support anonymous command allow list by @AlbumenJ in https://github.com/apache/dubbo/pull/12082

  • Support offline notify by @AlbumenJ in https://github.com/apache/dubbo/pull/12211
