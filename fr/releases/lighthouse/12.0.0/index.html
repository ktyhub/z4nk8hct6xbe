Changements notables

Suppression de la catégorie PWA

Conformément aux [Critères d'installation mis à jour de Chrome] (https://developer.chrome.com/blog/update-install-criteria), Lighthouse [a supprimé la catégorie PWA] (https://github.com/GoogleChrome/lighthouse/pull/15455). Pour les futurs tests PWA, les utilisateurs seront invités à utiliser la [documentation PWA mise à jour] (https://developer.chrome.com/docs/devtools/progressive-web-apps/).

Réorganisation des catégories SEO

La catégorie SEO a été mise à jour pour refléter les priorités de la recherche Google en 2024. A ce titre, plusieurs audits ont été supprimés ou déplacés vers d'autres catégories :

  • L'audit is-crawlable est désormais suffisamment pondéré pour échouer à lui seul dans la catégorie SEO. (#15933)
  • Les audits viewport et font-size ne sont plus des priorités pour le SEO, mais restent importants pour l'UX en général ils ont donc été déplacés dans la catégorie des meilleures pratiques. (#15930)
  • L'audit plugins n'est plus une priorité pour le SEO et a été supprimé. (#15928)
  • L'audit tap-targets n'est plus une priorité en SEO et a été remplacé par l'audit target-size en accessibilité. (#15906)

Dépréciation globale des économies

La valeur overallSavingsMs sur les audits de diagnostic de performances est obsolète (#15902). Nous vous recommandons d'utiliser metricSavings.LCP ou metricSavings.FCP pour comprendre les économies métriques estimées des diagnostics de performances.

🆕 Nouveaux audits

  • Les contrôles Axe aria-conditional-attr, aria-deprecated-role et aria-prohibited-attr ont été ajoutés à la catégorie d'accessibilité du phare. (#15963)
  • L'audit redirects-http a été ramené, mais ne vérifiera passivement une redirection http -> https que si l'URL fournie se trouve sur http (#13548)

Autres modifications d'audit

  • L'audit layout-shifts-elements est supprimé. Des informations améliorées sur les changements de disposition peuvent être trouvées dans l’audit layout-shifts. (#15931)
  • L'audit no-unload-listeners est supprimé. Les écouteurs de déchargement sont obsolètes et sont toujours signalés dans les audits deprecations et bf-cache. (#15874)
  • L'audit duplicate-id-active est supprimé car le contrôle Axe correspondant est obsolète. (#15900)
  • Les audits uses-rel-preload et preload-fonts ont été déplacés vers la configuration expérimentale. Les conseils de préchargement sont toujours en attente et ces audits étaient déjà dans un état désactivé. (#15876)

Full Changelog

We expect this release to ship in the DevTools of Chrome 126, and to PageSpeed Insights within 2 weeks.

Notable Changes

PWA Category Removal

As per Chrome’s updated Installability Criteria, Lighthouse has removed the PWA category. For future PWA testing, users will be directed to use the updated PWA documentation.

SEO Category Reorganization

The SEO category has been updated to reflect the priorities of Google search in 2024. As such, several audits have been removed or moved to other categories:

  • The is-crawlable audit is now weighted high enough to fail the SEO category on its own. (#15933)
  • The viewport and font-size audits are no longer priorities for SEO, but are still important for UX in general so they have been moved to the best practices category. (#15930)
  • The plugins audit is no longer a priority for SEO and has been removed. (#15928)
  • The tap-targets audit is no longer a priority for SEO and has been replaced with the target-size audit in accessibility. (#15906)

Overall Savings Deprecation

The overallSavingsMs value on performance diagnostic audits has been deprecated (#15902). We recommend using metricSavings.LCP or metricSavings.FCP to understand the estimated metric savings of performance diagnostics.

🆕 New Audits

  • The aria-conditional-attr, aria-deprecated-role and aria-prohibited-attr Axe checks have been added to the Lighthouse accessibility category. (#15963)
  • The redirects-http audit has been brought back, but will only passively check for a http -> https redirect if the provided URL happens to be on http (#13548)

Other Audit Changes

  • The layout-shifts-elements audit is removed. Improved layout shift information can be found in the layout-shifts audit. (#15931)
  • The no-unload-listeners audit is removed. Unload listeners are deprecated and are still flagged in the deprecations and bf-cache audits. (#15874)
  • The duplicate-id-active audit is removed because it's corresponding Axe check is deprecated. (#15900)
  • The uses-rel-preload and preload-fonts audits have been moved to the experimental config. Preload advice is still on hold and these audits were already in a disabled state. (#15876)
