ChuanhuChatGPT 20230614

Highlights

  • New OpenAI models — Adds gpt-3.5-16k, gpt-3.5-turbo-0613, gpt-4-0613 and gpt-4-32k-0613 (@GaiZhenbiao). The -0613 snapshots let you pin to stable revisions, and the 16k/32k windows unlock much larger documents — but revisit token budgeting and cost assumptions before rollout, since longer contexts change embedding/chunk sizing and pricing.
  • Gradio 3.33.1 + rewritten markdown pipeline — Frontend and backend markdown rendering were rewritten together (@Keldos-Li, @GaiZhenbiao). Streaming output, code blocks and copy buttons now flow through gradio's renderer, so expect visible layout/style changes and re-test any custom CSS or UI automation tied to the old DOM.
  • LaTeX config removed, KaTeX built in — The old LaTeX-rendering config options are gone; math now uses gradio's KaTeX support (@Keldos-Li). This is a real migration point: any LaTeX-specific keys in your config become inert, and math fidelity now tracks gradio's KaTeX instead of your own setup.
  • Search back to DuckDuckGo — Web search switched back to duckduckgo (@GaiZhenbiao). If you had tuned prompts or workflows around a different provider (or DDG's prior behavior), re-validate retrieval quality and rate limits.
  • Indexing and encoding fixes — Repairs index-build failures on some files, xlsx indexing, and unreadable Chinese-encoded history (@GaiZhenbiao, @MZhao-ouo); re-index affected documents to recover them. Embedding generation is also more stable and httpx logs are muted, cleaning up noisy deployments.
  • Formatting correctness — Fixes code blocks overflowing, misaligning or showing wrong colors, and user input losing original formatting (@Keldos-Li). Note the custom copy-code button is removed in favor of gradio's built-in one, and HTML was moved out of presets — check any preset overrides that relied on it.
