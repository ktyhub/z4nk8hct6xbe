shardingsphere 5.3.0

Mineure Publié8 janv. 2023 Sourceapache/shardingsphere Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

sphère de partage 5.3.0

API Modifications

  1. DistSQL : Refactoriser la syntaxe API, veuillez vous référer au manuel d'utilisation
  2. Proxy : modifiez le style de configuration de la règle globale, supprimez le point d'exclamation
  3. Proxy : Autoriser le démarrage sans configuration, activer le compte root/root par défaut lorsqu'il n'y a pas de configuration d'autorité
  4. Proxy : supprimez le fichier logback.xml par défaut et utilisez l'initialisation API.
  5. JDBC : supprimez la configuration Spring et utilisez plutôt la configuration Driver + YAML

Améliorations

  1. DistSQL : Nouvelle syntaxe REFRESH DATABASE METADATA, actualiser les métadonnées de la base de données logique
  2. Noyau : prend en charge les métadonnées de la base de données DistSQL REFRESH pour charger la configuration à partir du centre de gouvernance et reconstruire MetaDataContext.
  3. Prise en charge du niveau d'isolation des transactions postgresql/openGauss
  4. Mise à l'échelle : augmentez la fréquence de mise à jour de la progression des tâches d'inventaire
  5. Mise à l'échelle : prise en charge du contrôle de cohérence DATA_MATCH, reprise du point d'arrêt
  6. Mise à l'échelle : prise en charge du travail de vérification de cohérence via DistSQL
  7. Mise à l'échelle : renommez la colonne sharding_total_count en job_item_count dans la réponse DistSQL de la liste de tâches
  8. Mise à l'échelle : ajoutez une colonne de partitionnement dans la tâche SQL incrémentielle pour éviter le routage de diffusion
  9. Mise à l'échelle : la colonne Sharding peut être mise à jour lors de la génération de SQL
  10. Mise à l'échelle : améliorez le lecteur de valeur de colonne pour la vérification de la cohérence DATA_MATCH
  11. DistSQL : chiffrement de l'optimisation de la syntaxe DistSQL, prise en charge de l'algorithme de requête
  12. DistSQL : ajouter une vérification de la valeur des propriétés lors de l'ENREGISTREMENT DE L'UNITÉ DE STOCKAGE
  13. DistSQL : supprimez les algorithmes inutiles en même temps lorsque DROP RULE
  14. DistSQL : EXPORTER LA CONFIGURATION DE LA BASE DE DONNÉES prend en charge les tables de diffusion
  15. DistSQL : REGISTER STORAGE UNIT prend en charge des sources de données hétérogènes
  16. Chiffrer : prise en charge de la fonctionnalité Chiffrer LIKE
  17. Démarrez automatiquement les transactions distribuées lors de l'exécution d'instructions DML sur plusieurs fragments
  18. Noyau : prend en charge client \d pour PostgreSQL et openGauss
  19. Noyau : prise en charge de la sélection par groupe, de l'instruction triée par lorsque la colonne contient des valeurs nulles
  20. Noyau : prise en charge de l'analyse de la clause RETURNING de PostgreSQL/openGauss Insert
  21. Noyau : amélioration des performances de SQL HINT
  22. Noyau : prend en charge le cas mysql lors de l'analyse de l'instruction Then
  23. Noyau : prise en charge de la passerelle de base de données hétérogène au niveau de la source de données
  24. (Expérimental) Sharding : ajouter un plugin de cache de partitionnement
  25. Proxy : prend en charge davantage de formats datetime PostgreSQL
  26. Proxy : prend en charge MySQL COM_RESET_CONNECTION
  27. Mise à l'échelle : améliorez MySQLBinlogEventType.valueOf pour prendre en charge le type d'événement inconnu
  28. Noyau : cas de support pour la fédération

Correction de bugs

  1. Mise à l'échelle : correction du nœud de barrière créé lors de la suppression du travail
  2. Mise à l'échelle : la correction d'une partie de la valeur des colonnes peut être ignorée lors du contrôle de cohérence DATA_MATCH
  3. Mise à l'échelle : correction des paramètres d'URL jdbc qui ne sont pas mis à jour lors du contrôle de cohérence
  4. Mise à l'échelle : correction de l'algorithme de partitionnement des tables, le type INLINE est sensible à la casse
  5. Mise à l'échelle : la correction d'une tâche incrémentielle sur MySQL nécessite l'autorisation de la base de données système mysql
  6. Proxy : corrigez le NPE lors de l'exécution de Select SQL sans nœud de stockage
  7. Proxy : prend en charge la vérification des autorisations DATABASE_PERMITTED dans les scénarios de monodiffusion
  8. Noyau : corrigez la valeur incorrecte de l'identifiant du travailleur dans Afficher les nœuds de calcul
  9. Noyau : correction d'une erreur de route lorsque le nombre de sources de données lisibles et les configurations de poids de l'algorithme de poids ne sont pas égaux
  10. Noyau : correction de plusieurs groupes de fractionnement en lecture-écriture faisant référence au même nom d'équilibreur de charge et problème d'échec de l'équilibreur de charge
  11. Noyau : le correctif ne peut pas désactiver et activer le problème du nœud de calcul
  12. JDBC : la source de données corrigée est fermée en mode cluster ShardingSphereDriver en cas de problème de démarrage
  13. Noyau : correction d'un résultat de réécriture erroné lorsqu'une partie du nom de table logique de la table de liaison est cohérente avec le nom réel de la table et que certaines sont incohérentes
  14. Noyau : correction d'une exception de démarrage lors de l'utilisation de SpringBoot sans configurer de règles
  15. Encrypt : correction de l'exception de pointeur nul lorsque la valeur de chiffrement est nulle
  16. Noyau : correction de l'analyse Oracle qui ne prend pas en charge le type spécifié par varchar2
  17. Noyau : correction d'une erreur de jugement du drapeau de série dans la transaction
  18. Noyau : correction d'une erreur de récupération du curseur causée par le changement wasNull
  19. Noyau : correction d'une erreur de modification de la règle de transaction lors de l'actualisation des métadonnées
  20. Encrypt : correction de l'exception EncryptRule convertie en TransparentRule qui se produit lorsque l'instruction de procédure d'appel est exécutée dans le scénario Encrypt.
  21. Chiffrer : correction de l'exception provoquée par ExpressionProjection dans la projection abrégée
  22. Proxy : Correction du décodage incorrect de la valeur négative du proxy PostgreSQL int2
  23. Proxy : prise en charge de PostgreSQL/openGauss décrivant l'insertion d'une clause de retour
  24. Proxy : le correctif gsql 3.0 peut être bloqué lors de la connexion du proxy
  25. Proxy : les paramètres de correction sont manqués lors de la vérification de SQL dans le backend du proxy
  26. Proxy : activez le proxy MySQL pour encoder les gros paquets
  27. Noyau : correction du commentaire d'analyse Oracle sans erreur d'espacement
  28. DistSQL : correction de l'affichage de la table de création pour la table de chiffrement

Refactoriser

  1. Mise à l'échelle : inversez le nom de la table et le nom de la colonne lors de la génération de SQL s'il s'agit d'un mot-clé SQL
  2. Mise à l'échelle : améliorer la gestion des échecs de tâches incrémentales
  3. Noyau : ajustement du nœud du centre de gouvernance, bosse unifiée pour souligner

Anglais original / English original

shardingsphere 5.3.0

API Changes

  1. DistSQL: Refactor syntax API, please refer to the user manual
  2. Proxy: Change the configuration style of global rule, remove the exclamation mark
  3. Proxy: Allow zero-configuration startup, enable the default account root/root when there is no Authority configuration
  4. Proxy: Remove the default logback.xml and use API initialization
  5. JDBC: Remove the Spring configuration and use Driver + YAML configuration instead

Enhancements

  1. DistSQL: New syntax REFRESH DATABASE METADATA, refresh logic database metadata
  2. Kernel: Support DistSQL REFRESH DATABASE METADATA to load configuration from the governance center and rebuild MetaDataContext
  3. Support postgresql/openGauss setting transaction isolation level
  4. Scaling: Increase inventory task progress update frequency
  5. Scaling: DATA_MATCH consistency check support breakpoint resume
  6. Scaling: Support drop consistency check job via DistSQL
  7. Scaling: Rename column from sharding_total_count to job_item_count in job list DistSQL response
  8. Scaling: Add sharding column in incremental task SQL to avoid broadcast routing
  9. Scaling: Sharding column could be updated when generating SQL
  10. Scaling: Improve column value reader for DATA_MATCH consistency check
  11. DistSQL: Encrypt DistSQL syntax optimization, support like query algorithm
  12. DistSQL: Add properties value check when REGISTER STORAGE UNIT
  13. DistSQL: Remove useless algorithms at the same time when DROP RULE
  14. DistSQL: EXPORT DATABASE CONFIGURATION supports broadcast tables
  15. DistSQL: REGISTER STORAGE UNIT supports heterogeneous data sources
  16. Encrypt: Support Encrypt LIKE feature
  17. Automatically start distributed transactions when executing DML statements across multiple shards
  18. Kernel: Support client \d for PostgreSQL and openGauss
  19. Kernel: Support select group by, order by statement when column contains null values
  20. Kernel: Support parse RETURNING clause of PostgreSQL/openGauss Insert
  21. Kernel: SQL HINT performance improvement
  22. Kernel: Support mysql case when then statement parse
  23. Kernel: Supporting data source level heterogeneous database gateway
  24. (Experimental) Sharding: Add sharding cache plugin
  25. Proxy: Support more PostgreSQL datetime formats
  26. Proxy: Support MySQL COM_RESET_CONNECTION
  27. Scaling: Improve MySQLBinlogEventType.valueOf to support unknown event type
  28. Kernel: Support case when for federation

Bug Fix

  1. Scaling: Fix barrier node created at job deletion
  2. Scaling: Fix part of columns value might be ignored in DATA_MATCH consistency check
  3. Scaling: Fix jdbc url parameters are not updated in consistency check
  4. Scaling: Fix tables sharding algorithm type INLINE is case-sensitive
  5. Scaling: Fix incremental task on MySQL require mysql system database permission
  6. Proxy: Fix the NPE when executing select SQL without storage node
  7. Proxy: Support DATABASE_PERMITTED permission verification in unicast scenarios
  8. Kernel: Fix the wrong value of worker-id in show compute nodes
  9. Kernel: Fix route error when the number of readable data sources and weight configurations of the Weight algorithm are not equal
  10. Kernel: Fix multiple groups of readwrite-splitting refer to the same load balancer name, and the load balancer fails problem
  11. Kernel: Fix can not disable and enable compute node problem
  12. JDBC: Fix data source is closed in ShardingSphereDriver cluster mode when startup problem
  13. Kernel: Fix wrong rewrite result when part of logical table name of the binding table is consistent with the actual table name, and some are inconsistent
  14. Kernel: Fix startup exception when use SpringBoot without configuring rules
  15. Encrypt: Fix null pointer exception when Encrypt value is null
  16. Kernel: Fix oracle parsing does not support varchar2 specified type
  17. Kernel: Fix serial flag judgment error within the transaction
  18. Kernel: Fix cursor fetch error caused by wasNull change
  19. Kernel: Fix alter transaction rule error when refresh metadata
  20. Encrypt: Fix EncryptRule cast to TransparentRule exception that occurs when the call procedure statement is executed in the Encrypt scenario
  21. Encrypt: Fix exception which caused by ExpressionProjection in shorthand projection
  22. Proxy: Fix PostgreSQL Proxy int2 negative value decoding incorrect
  23. Proxy: PostgreSQL/openGauss support describe insert returning clause
  24. Proxy: Fix gsql 3.0 may be stuck when connecting Proxy
  25. Proxy: Fix parameters are missed when checking SQL in Proxy backend
  26. Proxy: Enable MySQL Proxy to encode large packets
  27. Kernel: Fix oracle parse comment without whitespace error
  28. DistSQL: Fix show create table for encrypt table

Refactor

  1. Scaling: Reverse table name and column name when generating SQL if it's SQL keyword
  2. Scaling: Improve increamental task failure handling
  3. Kernel: Governance center node adjustment, unified hump to underscore

Change Log
