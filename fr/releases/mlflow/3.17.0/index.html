mlflow v3.17.0

MLflow 3.17.0 comprend plusieurs fonctionnalités et améliorations majeures.

Nouvelles fonctionnalités majeures

  • Jev Decisions Across Evaluation, Gateway, and Tracing : utilisez des modèles TypeSafe dans les marqueurs intégrés et les juges personnalisés avec des commentaires booléens ou catégoriques dactylographiés. (#26100, @B-Step62)
  • Autorisations précises pour les ressources partagées : contrôlez l'accès aux types de ressources contenues, y compris les exécutions, les traces et les versions, avec des autorisations génériques et un DENY explicite. (#26157, @rrrkharse)
  • Analyses plus rapides pour les grands ensembles de données de trace : réduisez la surcharge des requêtes d'analyse SQL grâce aux résumés quotidiens facultatifs et au repli des requêtes brutes. (#25991, @HumairAK)
  • Résultats d'évaluation plus clairs : associez les métriques d'évaluation globales du modèle journalisé à l'ensemble de données géré qui les a produites. (#25927, @joshuawong-db)
  • Améliorations de l'assistant pour les serveurs partagés : conservez les conversations enregistrées limitées à l'utilisateur connecté et réinitialisez la session active lorsque les comptes changent. (#26009, @kriscon-db)

Mise à niveau de la base de données : Les serveurs basés sur SQL nécessitent une mise à niveau de schéma coordonnée avec tous les enregistreurs arrêtés et une sauvegarde restaurable, même lorsque les cumuls quotidiens restent désactivés. Exécutez mlflow db upgrade <database-url> avant de redémarrer toutes les répliques sur la nouvelle version de MLflow. Les mises à niveau progressives de versions mixtes ne sont pas prises en charge. Suivez les [instructions de mise à niveau de la base de données] (https://mlflow.org/docs/latest/self-hosting/architecture/backend-store/#upgrading-a-database-with-trace-analytics-data).

mlflow v3.17.0

MLflow 3.17.0 includes several major features and improvements.

Major New Features

  • Jev Decisions Across Evaluation, Gateway, and Tracing: Use TypeSafe models in built-in scorers and custom judges with typed Boolean or categorical feedback. (#26100, @B-Step62)
  • Fine-Grained Permissions for Shared Resources: Control access to contained resource types, including runs, traces, and versions, with wildcard grants and explicit DENY. (#26157, @rrrkharse)
  • Faster Analytics for Large Trace Datasets: Reduce SQL analytics query overhead with opt-in daily summaries and raw-query fallback. (#25991, @HumairAK)
  • Clearer Evaluation Results: Associate aggregate logged-model evaluation metrics with the managed dataset that produced them. (#25927, @joshuawong-db)
  • Assistant Improvements for Shared Servers: Keep saved conversations scoped to the signed-in user and reset the active session when accounts change. (#26009, @kriscon-db)

Database upgrade: SQL-backed servers require a coordinated schema upgrade with all writers stopped and a restorable backup, even when daily rollups remain disabled. Run mlflow db upgrade <database-url> before restarting all replicas on the new MLflow version. Mixed-version rolling upgrades are not supported. Follow the database upgrade instructions.
