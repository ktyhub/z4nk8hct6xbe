mlflow v3.16.0

MLflow 3.16.0 comprend plusieurs fonctionnalités et améliorations majeures

Nouvelles fonctionnalités majeures

  • 🎨 Vues de trace personnalisées : concevez votre propre interface utilisateur de trace en anglais simple : décrivez la vue souhaitée et MLflow Assistant la construit pour vous, en présentant exactement les champs qui vous intéressent, sans fichiers de configuration ni code personnalisé. Enregistrez, nommez et réutilisez les vues par expérience afin que toute votre équipe partage le même objectif sur vos traces.
  • 🔭 Expérience de trace repensée (maintenant par défaut) : L'explorateur de traces a été entièrement reconstruit et constitue désormais la valeur par défaut : une densité de lignes plus stricte, une navigation plus propre et une vue arborescente repensée. Réorganisez les colonnes, ajoutez des colonnes personnalisées configurables à partir de n'importe quelle balise de trace ou champ de métadonnées, et recherchez des conversations à plusieurs tours en ligne via le regroupement de sessions.
  • 🔗 Liens Span : Les spans sont rarement autonomes. MLflow 3.16.0 ajoute des liens de travée de première classe afin que les relations entre les travées (une étape de récupération, un appel d'outil, une trace en aval) soient capturées et navigables. Enregistrez les liens dans votre SDK et l'explorateur de traces les affiche dans un onglet Liens dédié pour accéder directement à l'étendue de destination.

mlflow v3.16.0

MLflow 3.16.0 includes several major features and improvements

Major New Features

  • 🎨 Custom Trace Views: Design your own trace UI in plain English — describe the view you want and the MLflow Assistant builds it for you, laying out exactly the fields you care about with no config files or custom code. Save, name, and reuse views per experiment so your whole team shares the same lens on your traces.
  • 🔭 Redesigned Trace Experience (now default): The trace explorer has been rebuilt from the ground up and is now the default — tighter row density, cleaner navigation, and a redesigned span-tree view. Reorder columns, add configurable custom columns from any trace tag or metadata field, and find multi-turn conversations inline via session grouping.
  • 🔗 Span Links: Spans rarely stand alone. MLflow 3.16.0 adds first-class span links so relationships between spans — a retrieval step, a tool call, a downstream trace — are captured and navigable. Record links in your SDK and the trace explorer surfaces them in a dedicated Links tab to jump straight to the destination span.
