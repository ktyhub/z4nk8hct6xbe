Baleine-code v0.8.53

Cette version renomme le projet en CodeWhale. L'héritage Les binaires deepseek et deepseek-tui continuent d'être expédiés cales de dépréciation uniquement pour la compatibilité pendant v0.8.x ; ils impriment un avertissement sur une ligne et transfert vers codewhale / codewhale-tui. Ils seront supprimés dans v0.9.0. L'ancien package npm deepseek-tui est obsolète et ne reçoit aucune autre version. Voir docs/REBRAND.md pour l'histoire complète de la migration.

Installer

Recommandé — npm (une commande, les deux binaires)

npm install -g codewhale

Le wrapper télécharge les deux binaires de cette version et les place dans le même répertoire.

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v ~/.deepseek:/home/codewhale/.deepseek \
  ghcr.io/hmbown/codewhale:v0.8.53

L'image contient le répartiteur codewhale et le runtime codewhale-tui (plus les anciennes cales deepseek/deepseek-tui pendant la transition). La balise latest est également mise à jour lors de la sortie.

Cargaison (Linux / macOS)

cargo install codewhale-cli codewhale-tui --locked

Les deux caisses sont requises : codewhale-cli produit le répartiteur codewhale et codewhale-tui produit le runtime interactif auquel le répartiteur délègue. L'installation d'un seul binaire échouera au moment de l'exécution avec une erreur MISSING_COMPANION_BINARY.

Téléchargement manuel — archives de la plateforme (recommandé)

Chaque archive ci-dessous contient à la fois le répartiteur codewhale et le runtime codewhale-tui, ainsi qu'un script d'installation : | Plateforme | Archives | Script d'installation | |---|---|---| | Linuxx64 | codewhale-linux-x64.tar.gz | install.sh | | LinuxARM64 | codewhale-linux-arm64.tar.gz | install.sh | | Linux RISC-V | codewhale-linux-riscv64.tar.gz | install.sh | | macOS x64 | codewhale-macos-x64.tar.gz | install.sh | | MacOS BRAS | codewhale-macos-arm64.tar.gz | install.sh | | Windows x64 (installateur) | CodeWhaleSetup.exe | Configuration du NSIS | | Windowsx64 | codewhale-windows-x64.zip | install.bat | | Windows x64 (portable) | codewhale-windows-x64-portable.zip | — | Unix (Linux/MacOS) :

tar xzf codewhale-<platform>.tar.gz
cd codewhale-<platform>
./install.sh

Fenêtres :

  • Pour le chemin du programme d'installation, exécutez CodeWhaleSetup.exe ; il installe les deux binaires sous %LOCALAPPDATA%\Programs\CodeWhale\bin et ajoute ce répertoire au PATH de l'utilisateur actuel.
  • Extrait codewhale-windows-x64.zip
  • Exécutez install.bat (copie dans %USERPROFILE%\bin)
  • Ajoutez %USERPROFILE%\bin à votre CHEMIN L'archive Windows portable ignore le script d'installation : extrayez et exécutez à partir de n'importe quel répertoire. Le programme d'installation NSIS n'est actuellement pas signé et peut déclencher Windows SmartScreen jusqu'à ce qu'un certificat de signature soit connecté au pipeline de publication. Des binaires individuels sont également joints ci-dessous pour les scripts et le wrapper npm. Les anciens actifs deepseek-* et deepseek-tui-* sont des cales de dépréciation de compatibilité uniquement pour v0.8.x afin que les invocations deepseek update existantes sur v0.8.40 continuent de fonctionner ; ils transmettent aux binaires canoniques. L'ancien package npm deepseek-tui est obsolète et n'est pas republié.

Codewhale v0.8.53

Highlights

  • Project rename without an immediate cutover — Canonical commands and packages are now codewhale and codewhale-tui; existing deepseek automation, including deepseek update from v0.8.40, continues through forwarding shims. npm users should switch to codewhale because deepseek-tui receives no further releases; the documented Docker setup still uses DEEPSEEK_API_KEY and ~/.deepseek.
  • Install both binaries together — npm and platform archives bundle the dispatcher and TUI, while Cargo users must install both codewhale-cli and codewhale-tui or hit MISSING_COMPANION_BINARY. Keep them in the same directory, verify downloads with the published SHA-256 manifests, and note that the Windows NSIS installer is unsigned and may trigger SmartScreen.
  • Provider routing and authentication cleanup — Hugging Face routing/docs are included alongside provider persistence, scoped /logout, provider-picker key replacement, and MiMo auth cleanup ported from #2714, #2715, #2717, and #2718. Review session automation against the scoped logout behavior rather than assuming /logout always ends every provider session.
  • Custom paths for OpenAI-compatible endpoints — Configurable path_suffix support from #2558 lets requests target gateways or proxies requiring an additional URL path segment. Configure it explicitly and verify the composed request URL when migrating existing endpoint definitions.
  • More accurate model and tool context — Model-family classification from #2525 makes family-specific handling more consistent; validate any custom model configuration after upgrading. Shell-prompt guidance is hidden when shell execution is disabled (#2638), preventing the UI from advertising unavailable capabilities.
  • No breaking changes in v0.8.53 — Legacy compatibility lasts through v0.8.x; migrate before the shims are removed in v0.9.0.

This release renames the project to CodeWhale. The legacy deepseek and deepseek-tui binaries continue to ship as compatibility-only deprecation shims during v0.8.x; they print a one-line warning and forward to codewhale / codewhale-tui. They will be removed in v0.9.0. The legacy npm package deepseek-tui is deprecated and receives no further releases. See docs/REBRAND.md for the full migration story.

Install

Recommended — npm (one command, both binaries)

npm install -g codewhale

The wrapper downloads both binaries from this Release and places them in the same directory.

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v ~/.deepseek:/home/codewhale/.deepseek \
  ghcr.io/hmbown/codewhale:v0.8.53

The image ships the codewhale dispatcher and codewhale-tui runtime (plus the legacy deepseek / deepseek-tui shims during the transition). The latest tag is also updated on release.

Cargo (Linux / macOS)

cargo install codewhale-cli codewhale-tui --locked

Both crates are required — codewhale-cli produces the codewhale dispatcher and codewhale-tui produces the interactive runtime that the dispatcher delegates to. Installing only one binary will fail at runtime with a MISSING_COMPANION_BINARY error.

Manual download — platform archives (recommended)

Each archive below contains both the codewhale dispatcher and codewhale-tui runtime, plus an install script:

| Platform | Archive | Install script | |---|---|---| | Linux x64 | codewhale-linux-x64.tar.gz | install.sh | | Linux ARM64 | codewhale-linux-arm64.tar.gz | install.sh | | Linux RISC-V | codewhale-linux-riscv64.tar.gz | install.sh | | macOS x64 | codewhale-macos-x64.tar.gz | install.sh | | macOS ARM | codewhale-macos-arm64.tar.gz | install.sh | | Windows x64 (installer) | CodeWhaleSetup.exe | NSIS setup | | Windows x64 | codewhale-windows-x64.zip | install.bat | | Windows x64 (portable) | codewhale-windows-x64-portable.zip | — |

Unix (Linux / macOS):

tar xzf codewhale-<platform>.tar.gz
cd codewhale-<platform>
./install.sh

Windows:

  • For the installer path, run CodeWhaleSetup.exe; it installs both binaries under %LOCALAPPDATA%\Programs\CodeWhale\bin and adds that directory to the current-user PATH.
  • Extract codewhale-windows-x64.zip
  • Run install.bat (copies to %USERPROFILE%\bin)
  • Add %USERPROFILE%\bin to your PATH

The portable Windows archive skips the install script — extract and run from any directory. The NSIS installer is currently unsigned and may trigger Windows SmartScreen until a signing certificate is wired into the release pipeline.

Individual binaries are also attached below for scripting and the npm wrapper. Legacy deepseek-* and deepseek-tui-* assets are compatibility-only deprecation shims for v0.8.x so that existing deepseek update invocations on v0.8.40 keep working; they forward to the canonical binaries. The legacy npm package deepseek-tui is deprecated and is not republished.

Verify (recommended)

Download the checksum manifests from this Release and verify:

# Linux — archive bundles
sha256sum -c codewhale-bundles-sha256.txt

# Linux — individual binaries
sha256sum -c codewhale-artifacts-sha256.txt

# macOS
shasum -a 256 -c codewhale-bundles-sha256.txt
shasum -a 256 -c codewhale-artifacts-sha256.txt

The legacy deepseek-artifacts-sha256.txt is also attached for backward compatibility and contains the same hashes as the canonical manifest.
