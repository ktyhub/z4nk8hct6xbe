#pulsar v4.1.1

2025-09-27

Mises à jour de la bibliothèque

  • [fix][sec] Mise à niveau de Netty vers 4.1.127.Final pour résoudre les CVE (#24717)
  • [améliorer][construire] Mettre à niveau Lombok vers 1.18.42 pour prendre entièrement en charge JDK25 (#24763)
  • [améliorer][construire] Mettre à niveau Apache Parent POM vers la version 35 (#24742)
  • [améliorer][construire] Mettre à niveau Mockito, AssertJ et ByteBuddy pour prendre entièrement en charge JDK25 (#24764)
  • [améliorer][construire] Mettre à niveau SpotBugs vers une version prenant en charge JDK25 (#24768)
  • [feat][misc] mise à niveau de la version d'oxia vers 0.6.2 (#24689)
  • [améliorer][io] Mise à niveau vers Debezium 3.2.2 (#24712)

Courtier

  • [fix][broker] L'abonnement Key_Shared ne délivre pas toujours les messages de la file d'attente de relecture après qu'un consommateur se déconnecte et laisse un retard (#24736)
  • [fix][broker] Assurez-vous que le consommateur du mode persistant KeyShared respecte les plages assignées (#24730)
  • [fix][broker] La première entrée sera ignorée si l'ouverture de NonDurableCursor alors que le grand livre tronqué ajoute la première entrée. (#24738)
  • [fix][broker] Le correctif ne peut pas arrêter le courtier correctement par l'administrateur api (#24731)
  • [fix][broker] Correction d'une fuite de mémoire lorsque les métriques sont mises à jour dans un thread autre que FastThreadLocalThread (#24719)
  • [fix][broker] Empêcher les échecs de recyclage inattendus dans le rappel de lecture du répartiteur (#24741)
  • [fix][broker]Correction du problème de mauvaise version du magasin de métadonnées jamais récupéré en cas de réponse importante de ZK (#24580)
  • [fix][ml]Correction de l'exception EOFException après l'activation du déchargement des sujets (#24753)
  • [fix][broker] Corrige NPE et annote les valeurs de retour nullables pour ManagedCursorContainer (#24706)
  • [fix][broker]Dispatcher a effectué un tri inutile pour les consommateurs récemmentjoints et a imprimé des journaux d'erreurs bruyants (#24634)
  • [fix][broker]Correction de la lecture incorrecte des seuils de déchargement au niveau de l'espace de noms (#24696)
  • [fix][ml] Le backlog négatif et les positions confirmées n'existent pas et le message est perdu lors de l'occupation simultanée du propriétaire du sujet (#24722)
  • [améliorer][broker] S'il y a un blocage dans le service, la sonde doit renvoyer un échec car le service peut être indisponible (#23634)
  • [améliorer][broker] Autoriser la suppression des sujets persistants vides quelle que soit la politique de rétention (#24733)
  • [améliorer][broker] PIP-402 : empêcher éventuellement la journalisation du rôle/originalPrincipal (#23386)
  • [améliorer][broker] Réduire l'analyse inutile des MessageMetadata en mettant en cache l'instance analysée dans le cache du courtier (#24682)
  • [améliorer][ml] Améliorer les performances d'insertion du cache en supprimant la vérification de l'existence car elle est déjà couverte par putIfAbsent (#24699)

Client

  • [fix][client] Évitez de recyclercling le même ConcurrentBitSetRecyclable entre différents threads (#24725)
  • [fix][client] Correction de la mise à l'échelle automatique de la file d'attente du récepteur sans limite de mémoire (#24743)
  • [fix][client]TopicListWatcher n'est pas fermé lors de l'appel de la méthode PatternMultiTopicsConsumerImpl.closeAsync() (#24698)
  • [correction] [client] restauration du comportement de nouvelle tentative de TopicListWatcher (#24752)
  • [fix][client] Exclure io.prometheus:simpleclient_caffeine des dépendances côté client (#24761)
  • [améliorer][client] PIP-407 Ajouter un nouveau message avec schéma et transactions (#23942)

Pulsar IO et fonctions Pulsar

  • [fix][io] Améliorer la logique de vidage du décalage de la source Kafka Connect (#24654)
  • [feat][fn] Repli sur l'utilisation de STATE_STORAGE_SERVICE_URL dans PulsarMetadataStateStoreProviderImpl.init (#24721)

Autres

  • [fix][misc] Correction de la violation du contrat compareTo pour NamespaceBundleStats, TimeAverageMessageData et ResourceUnitRanking (#24772)
  • [correctif] Exclure le dépôt commons-lang du comptable (#24749)

Tests et CI

  • [fix][test] Flaky-test : BrokerServiceTest.testShutDownWithMaxConcurrentUnload (#24769)
  • [fix][broker] Correction du test unitaire testServiceConfigurationRetentionPolicy (#24756)
  • [fix][broker]Correction de la mauvaise logique du test PartitionCreationTest.testCreateMissedPartitions (#24683)
  • [améliorer][build] Désactiver l'échec de la compilation javadoc (#24594)
  • [fix][ci] Correction de CI pour Java 25 incluant la mise à niveau de l'extension Gradle Deelocity Maven (#24767) Pour la liste complète, consultez le changelog complet.

pulsar v4.1.1

2025-09-27

Library updates

  • [fix][sec] Upgrade Netty to 4.1.127.Final to address CVEs (#24717)
  • [improve][build] Upgrade Lombok to 1.18.42 to fully support JDK25 (#24763)
  • [improve][build] Upgrade Apache Parent POM to version 35 (#24742)
  • [improve][build] Upgrade Mockito, AssertJ and ByteBuddy to fully support JDK25 (#24764)
  • [improve][build] Upgrade SpotBugs to a version that supports JDK25 (#24768)
  • [feat][misc] upgrade oxia version to 0.6.2 (#24689)
  • [improve][io] Upgrade to Debezium 3.2.2 (#24712)

Broker

  • [fix][broker] Key_Shared subscription doesn't always deliver messages from the replay queue after a consumer disconnects and leaves a backlog (#24736)
  • [fix][broker] Ensure KeyShared sticky mode consumer respects assigned ranges (#24730)
  • [fix][broker] First entry will be skipped if opening NonDurableCursor while trimmed ledger is adding first entry. (#24738)
  • [fix][broker] Fix cannot shutdown broker gracefully by admin api (#24731)
  • [fix][broker] Fix memory leak when metrics are updated in a thread other than FastThreadLocalThread (#24719)
  • [fix][broker] Prevent unexpected recycle failure in dispatcher's read callback (#24741)
  • [fix][broker]Fix never recovered metadata store bad version issue if received a large response from ZK (#24580)
  • [fix][ml]Fix EOFException after enabled topics offloading (#24753)
  • [fix][broker] Fix NPE and annotate nullable return values for ManagedCursorContainer (#24706)
  • [fix][broker]Dispatcher did unnecessary sort for recentlyJoinedConsumers and printed noisy error logs (#24634)
  • [fix][broker]Fix dirty reading of namespace level offload thresholds (#24696)
  • [fix][ml] Negative backlog & acked positions does not exist & message lost when concurrently occupying topic owner (#24722)
  • [improve][broker] If there is a deadlock in the service, the probe should return a failure because the service may be unavailable (#23634)
  • [improve][broker] Allow deletion of empty persistent topics regardless of retention policy (#24733)
  • [improve][broker] PIP-402: Optionally prevent role/originalPrincipal logging (#23386)
  • [improve][broker] Reduce unnecessary MessageMetadata parsing by caching the parsed instance in the broker cache (#24682)
  • [improve][ml] Improve cache insert performance by removing exists check since it's already covered by putIfAbsent (#24699)

Client

  • [fix][client] Avoid recycling the same ConcurrentBitSetRecyclable among different threads (#24725)
  • [fix][client] Fix receiver queue auto-scale without memory limit (#24743)
  • [fix][client]TopicListWatcher not closed when calling PatternMultiTopicsConsumerImpl.closeAsync() method (#24698)
  • [fix][client] rollback TopicListWatcher retry behavior (#24752)
  • [fix][client] Exclude io.prometheus:simpleclient_caffeine from client-side dependencies (#24761)
  • [improve][client] PIP-407 Add newMessage with schema and transactions (#23942)

Pulsar IO and Pulsar Functions

  • [fix][io] Improve Kafka Connect source offset flushing logic (#24654)
  • [feat][fn] Fallback to using STATE_STORAGE_SERVICE_URL in PulsarMetadataStateStoreProviderImpl.init (#24721)

Others

  • [fix][misc] Fix compareTo contract violation for NamespaceBundleStats, TimeAverageMessageData and ResourceUnitRanking (#24772)
  • [fix] Exclude commons-lang dep from bookkeeper (#24749)

Tests & CI

  • [fix][test] Flaky-test: BrokerServiceTest.testShutDownWithMaxConcurrentUnload (#24769)
  • [fix][broker] Fix testServiceConfigurationRetentionPolicy unit test (#24756)
  • [fix][broker]Fix the wrong logic of the test PartitionCreationTest.testCreateMissedPartitions (#24683)
  • [improve][build] Disable javadoc build failure (#24594)
  • [fix][ci] Fix CI for Java 25 including upgrade of Gradle Develocity Maven extension (#24767)

For the complete list, check the full changelog.
