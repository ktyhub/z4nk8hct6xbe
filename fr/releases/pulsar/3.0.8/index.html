#pulsar v3.0.8

2024-12-02

Mises à jour de la bibliothèque

  • [fix][sec] Mise à niveau de Zookeeper vers 3.9.3 pour résoudre le CVE-2024-51504 (#23581)
  • [fix][sec] Mise à niveau vers Netty 4.1.115.Final pour résoudre le CVE-2024-47535 (#23596)
  • [améliorer][misc] Mettre à niveau la jetée vers 9.4.56.v20240826 (#23405)

Courtier

  • [fix][broker] Évitez les registres orphelins dans BucketDelayedDeliveryTracker (#22802)
  • [fix][broker] Le courtier ne parvient pas à créer un sous-marin non durable si le sujet est clôturé (#23579)
  • [fix][broker] Continuer la fermeture même lorsque l'exécuteur est arrêté (#22599)
  • [fix][broker] Correction de la vérification de la stratégie AvgShedder (#23156)
  • [fix][broker] Correction actuellement des tentatives de client jusqu'à l'expiration du délai d'opération si le sujet n'existe pas (#23530)
  • [fix][broker] Correction de l'échec de TokenAuthenticatedProducerConsumerTest (#23602)
  • [réparer][courtier] Réparer la perte de propriété (#23515)
  • [fix][broker] Correction d'une condition de concurrence provoquant une suppression répétée du sujet (#23522)
  • [fix][broker] Augmente la taille de readBuffer pour bookkeeper.DLOutputStream (#23548)
  • [fix][broker] Les sujets n'ont pas pu être supprimés après la suppression du cluster de l'ensemble de clusters répliqués et ont provoqué un MOO (#23360).
  • [fix][broker] corrige le résultat de recherche nul au démarrage des courtiers (#23642)
  • [fix][broker] normaliser le chemin (#23438)
  • [améliorer][broker] Ajouter un journal pour suivre le problème lorsque handleGetTopicsOfNamespace (#23434)
  • [améliorer][broker] Fermez TopicPoliciesService pour permettre l'arrêt progressif du courtier Pulsar (#22589)
  • [améliorer][broker] Découpler la métrique pulsar_storage_backlog_age_seconds avec la vérification du backlogQuota (#23619)
  • [améliorer][broker] Ne pas utiliser le pool forkjoin par défaut pour supprimer les sujets partitionnés (#22598)
  • [améliorer][broker] Exclure les sujets système de la limitation du taux de publication et de répartition au niveau de l'espace de noms (#23589)
  • [améliorer][broker] Faire en sorte que la commande d'initialisation des métadonnées du cluster prenne en charge le chemin de configuration des métadonnées (#23269)
  • [améliorer][broker] Faire en sorte que la commande de démontage des métadonnées du cluster prenne en charge le chemin de configuration des métadonnées (#23520)
  • [améliorer][broker] PIP-392 : ajouter une configuration pour permettre un hachage cohérent afin de sélectionner le consommateur actif pour le sujet partitionné (#23584)
  • [améliorer][broker] Prise en charge du nettoyage replication cluster et allowed cluster lors du démontage des métadonnées du cluster (#23561)
  • [améliorer] [broker] remplacer HashMap par l'implémentation interne ConcurrentLongLongPairHashMap dans Negative Ack Tracker. (#23582)

Client

  • [fix][admin] La recherche de correctif obtient un résultat nul si elle utilise un proxy (#23556)
  • [fix][client] Fix Reader.hasMessageAvailable renvoie une valeur incorrecte après une recherche par horodatage avec startMessageIdInclusive (#23502)
  • [fix][client] Correction du blocage de NegativeAcksTracker (#23651)
  • [fix][client] Correction de l'arrêt du producteur/consommateur pour se reconnecter ou Pub/Sub en raison d'une condition de concurrence critique du thread IO (#23499)
  • [fix][client] Correction d'une condition de concurrence provoquant le blocage de doReconsumeLater lors de l'échec de la création de retryLetterProducer (#23560)
  • [fix][client] Correction du javadoc pour ConsumerBuilder.isAckReceiptEnabled (#23452)
  • [fix][client] Correction d'un problème où une chaîne de certificat ne pouvait pas être utilisée dans l'authentification TLS (#23644)
  • [fix][client] Initialisation de l'authentification client à l'aide des paramètres d'authentification configurés (#23610)
  • [fix][client] Rendre la dépendance protobuf-java facultative dans les bibliothèques java client (#23632)
  • [fix][client] Empêcher l'intégration des fichiers de classe protobuf-java dans pulsar-client-admin et pulsar-client-all (#23468)
  • [fix][client] Le maxPendingMessages partitionedProducer est toujours 0 (#23593)
  • [fix][client] Utiliser un exécuteur dédié pour les requêtes dans BinaryProtoLookupService (#23378) (#23461)
  • [fix][client] corrige l'utilisation de la mémoire de incomingMessageSize et client qui est négative (#23624)
  • [fix][client] corrige la méthode beforeConsume() précédemment atteinte avec l'écouteur de message (#23578)
  • [améliorer][admin] Imprimer le journal des erreurs si la réponse http de la gestion échoue (#23563)
  • [améliorer][client] Améliorer la gestion des erreurs pour les abonnements inexistants lors de la création du consommateur (#23254)
  • [améliorer][client] Augmenter la connexion Java client par défautMaxIdleSeconds à 60 secondes (#23430)
  • [améliorer][client] Réduire les dépendances non ombrées et les avertissements d'ombrage dans les modules Java client ombrés (#23647)

Fonctions Pulsar IO et Pulsar

  • [fix][fn] messages d'accusé de réception pour la fonction fenêtre lorsque son résultat est nul (#23618)
  • [fix][sql][branch-3.0] Correction de la compatibilité des décimales longues dans Trino 368. (#23419)
  • [fix][sql][branch-3.0] Correction de la configuration d'ombrage pour presto-pulsar
  • [améliorer][io] Prise en charge de la position d'abonnement à la mise à jour pour le connecteur d'évier (#23538)
  • [améliorer][io] Mise à niveau de la version Spring vers 6.1.13 dans les connecteurs IO (#23459)

Autres

  • [correctif] Méthode restaurée comme obsolète dans AbstractMetadataStore (#21950)
  • [fix][misc] Conflit de classe lors du processus d'ombrage jetcd-core-shaded (#23641)
  • [fix][misc] Impossible de connecter un métastore etcd avec les versions récentes en raison d'un problème de partitionnement jetc-core (#23604)
  • [fix][ml] Le grand livre géré devrait récupérer après l'échec du grand livre ouvert (#23368)
  • [fix][proxy] Le consommateur de modèle de correctif ne fonctionne pas lors de l'utilisation du proxy (#23489)
  • [fix][standalone] supprime correctement le znode d'enregistrement du bookmaker (#23497)
  • [améliorer] Améliorer la logique pour activer la détection des fuites du Netty (#23613)
  • [améliorer] Utiliser un tampon unique pour les métriques en cas d'utilisation non dangereuse (#23612)
  • [fix][ws] Implémentation des fonctions de données d'en-tête http manquantes dans AuthenticationDataSubscription (#23638)
  • [améliorer][ml] Évitez les verrouillages imbriqués répétitifs pour isMessageDeleted dans ManagedCursorImpl (#23609)
  • [améliorer][décharger] Utiliser l'URI du système de fichiers comme chemin de stockage (#23591)
  • Activation de DNS retryOnTimeout avec TCP dans DnsNameResolver (#23590)

Tests et CI

  • [cleanup][build] ignore la génération de pom.xml.versionsBackup (#23639)
  • [fix][build] Ajout d'un support de base pour vscode-java et Eclipse IDE (#23448)
  • [fix][build] Correction de l'erreur "L'encodage des éléments n'est pas autorisé ici" dans pom.xml (#23655)
  • [fix][test] Adresse irrégulière GetPartitionMetadataMultiBrokerTest (#23456)
  • [fix][test] Correction de DeadLetterTopicTest.testDeadLetterTopicWithInitialSubscriptionAndMultiConsumers (#23552)
  • [fix][test] Correction de SimpleProducerConsumerTest.testMultiTopicsConsumerImplPauseForManualSubscription (#23546)
  • [fix][test] Correction de GetPartitionMetadataMultiBrokerTest.testCompatibilityDifferentBrokersForNonPersistentTopic (#23259)
  • [fix][test] Correction du test irrégulier ManagedLedgerTest.testDeleteCurrentLedgerWhenItIsClosed (#23437)
  • [fix][test][branch-3.0] Correction de PrecisTopicPublishRateThrottleTest qui s'est cassé après les modifications de #23589
  • [fix][test][branch-3.0] Correction d'un problème de sélection dans 2f6c1a3 où l'importation de nettoyage était manquante
  • [améliorer][construire] Nécessite Java 17 pour créer la branche Pulsar-3.0 (#22875)
  • [améliorer][construire] Mettre à jour maven-wrapper (mvnw) vers la version stable récente 3.3.2 (#23410)
  • [improve][build][branch-3.0] Mise à niveau de docker-maven-plugin vers 0.45.1
  • [améliorer][test] Ajout de tests de propriétés de message pour les messages batch et non-batch (#23473)
  • [améliorer][test] Réduire le temps d'exécution de OneWayReplicatorUsingGlobalZKTest.testRemoveCluster (#23633) Pour la liste complète, consultez le changelog complet.

pulsar v3.0.8

2024-12-02

Library updates

  • [fix][sec] Upgrade Zookeeper to 3.9.3 to address CVE-2024-51504 (#23581)
  • [fix][sec] Upgrade to Netty 4.1.115.Final to address CVE-2024-47535 (#23596)
  • [improve][misc] Upgrade Jetty to 9.4.56.v20240826 (#23405)

Broker

  • [fix][broker] Avoid orphan ledgers in BucketDelayedDeliveryTracker (#22802)
  • [fix][broker] Broker is failing to create non-durable sub if topic is fenced (#23579)
  • [fix][broker] Continue closing even when executor is shut down (#22599)
  • [fix][broker] Fix AvgShedder strategy check (#23156)
  • [fix][broker] Fix currently client retries until operation timeout if the topic does not exist (#23530)
  • [fix][broker] Fix failed TokenAuthenticatedProducerConsumerTest (#23602)
  • [fix][broker] Fix ownership loss (#23515)
  • [fix][broker] Fix race-condition causing repeated delete topic (#23522)
  • [fix][broker] Increase readBuffer size for bookkeeper.DLOutputStream (#23548)
  • [fix][broker] Topics failed to delete after remove cluster from replicated clusters set and caused OOM (#23360)
  • [fix][broker] fix null lookup result when brokers are starting (#23642)
  • [fix][broker] normalize path (#23438)
  • [improve][broker] Add log to track issue when handleGetTopicsOfNamespace (#23434)
  • [improve][broker] Close TopicPoliciesService to allow Pulsar broker graceful shutdown (#22589)
  • [improve][broker] Decouple pulsar_storage_backlog_age_seconds metric with backlogQuota check (#23619)
  • [improve][broker] Don't use forkjoin pool by default for deleting partitioned topics (#22598)
  • [improve][broker] Exclude system topics from namespace level publish and dispatch rate limiting (#23589)
  • [improve][broker] Make cluster metadata init command support metadata config path (#23269)
  • [improve][broker] Make cluster metadata teardown command support metadata config path (#23520)
  • [improve][broker] PIP-392: Add configuration to enable consistent hashing to select active consumer for partitioned topic (#23584)
  • [improve][broker] Support cleanup replication cluster and allowed cluster when cluster metadata teardown (#23561)
  • [improve][broker] replace HashMap with inner implementation ConcurrentLongLongPairHashMap in Negative Ack Tracker. (#23582)

Client

  • [fix][admin] Fix lookup get a null result if uses proxy (#23556)
  • [fix][client] Fix Reader.hasMessageAvailable return wrong value after seeking by timestamp with startMessageIdInclusive (#23502)
  • [fix][client] Fix deadlock of NegativeAcksTracker (#23651)
  • [fix][client] Fix producer/consumer stop to reconnect or Pub/Sub due to IO thread race-condition (#23499)
  • [fix][client] Fix race-condition causing doReconsumeLater to hang when creating retryLetterProducer has failed (#23560)
  • [fix][client] Fix the javadoc for ConsumerBuilder.isAckReceiptEnabled (#23452)
  • [fix][client] Fixed an issue where a cert chain could not be used in TLS authentication (#23644)
  • [fix][client] Initializing client-authentication using configured auth params (#23610)
  • [fix][client] Make protobuf-java dependency optional in java client libraries (#23632)
  • [fix][client] Prevent embedding protobuf-java class files in pulsar-client-admin and pulsar-client-all (#23468)
  • [fix][client] The partitionedProducer maxPendingMessages always is 0 (#23593)
  • [fix][client] Use dedicated executor for requests in BinaryProtoLookupService (#23378) (#23461)
  • [fix][client] fix incomingMessageSize and client memory usage is negative (#23624)
  • [fix][client] fix the beforeConsume() method earlier hit with message listener (#23578)
  • [improve][admin] Print error log if handle http response fails (#23563)
  • [improve][client] Enhance error handling for non-exist subscription in consumer creation (#23254)
  • [improve][client] Increase default Java client connectionMaxIdleSeconds to 60 seconds (#23430)
  • [improve][client] Reduce unshaded dependencies and shading warnings in shaded Java client modules (#23647)

Pulsar IO and Pulsar Functions

  • [fix][fn] ack messages for window function when its result is null (#23618)
  • [fix][sql][branch-3.0] Fix long decimal compatibility in Trino 368. (#23419)
  • [fix][sql][branch-3.0] Fix shading configuration for presto-pulsar
  • [improve][io] Support update subscription position for sink connector (#23538)
  • [improve][io] Upgrade Spring version to 6.1.13 in IO Connectors (#23459)

Others

  • [fix] Restored method as deprecated in AbstractMetadataStore (#21950)
  • [fix][misc] Class conflict during jetcd-core-shaded shading process (#23641)
  • [fix][misc] Unable to connect an etcd metastore with recent releases due to jetc-core sharding problem (#23604)
  • [fix][ml] Managed ledger should recover after open ledger failed (#23368)
  • [fix][proxy] Fix pattern consumer does not work when using Proxy (#23489)
  • [fix][standalone] correctly delete bookie registration znode (#23497)
  • [improve] Improve logic for enabling Netty leak detection (#23613)
  • [improve] Use single buffer for metrics when noUnsafe use (#23612)
  • [fix][ws] Implement missing http header data functions in AuthenticationDataSubscription (#23638)
  • [improve][ml] Avoid repetitive nested lock for isMessageDeleted in ManagedCursorImpl (#23609)
  • [improve][offload] Use filesystemURI as the storage path (#23591)
  • Enabling DNS retryOnTimeout with TCP in DnsNameResolver (#23590)

Tests & CI

  • [cleanup][build] skip generating pom.xml.versionsBackup (#23639)
  • [fix][build] Add basic support for vscode-java and Eclipse IDE (#23448)
  • [fix][build] Fix error "Element encoding is not allowed here" in pom.xml (#23655)
  • [fix][test] Address flaky GetPartitionMetadataMultiBrokerTest (#23456)
  • [fix][test] Fix DeadLetterTopicTest.testDeadLetterTopicWithInitialSubscriptionAndMultiConsumers (#23552)
  • [fix][test] Fix SimpleProducerConsumerTest.testMultiTopicsConsumerImplPauseForManualSubscription (#23546)
  • [fix][test] Fix flaky GetPartitionMetadataMultiBrokerTest.testCompatibilityDifferentBrokersForNonPersistentTopic (#23259)
  • [fix][test] Fix flaky test ManagedLedgerTest.testDeleteCurrentLedgerWhenItIsClosed (#23437)
  • [fix][test][branch-3.0] Fix PrecisTopicPublishRateThrottleTest that broke after #23589 changes
  • [fix][test][branch-3.0] Fix cherry-picking issue in 2f6c1a3 where Cleanup import was missing
  • [improve][build] Require Java 17 for building Pulsar branch-3.0 (#22875)
  • [improve][build] Update maven-wrapper (mvnw) to recent stable version 3.3.2 (#23410)
  • [improve][build][branch-3.0] Upgrade docker-maven-plugin to 0.45.1
  • [improve][test] Added message properties tests for batch and non-batch messages (#23473)
  • [improve][test] Reduce OneWayReplicatorUsingGlobalZKTest.testRemoveCluster execution time (#23633)

For the complete list, check the full changelog.
