#pulsar v4.0.0

2024-10-21

Modifications apportées à la version 4.0.0 depuis le début de la préparation de la version 3.3.0. Pour la liste complète, consultez la liste complète changelog et la liste PR complète. Quoi de neuf dans Apache Pulsar 4.0 ? couvre des sujets tels que :

  • Mise en œuvre améliorée de l'abonnement Key_Shared
  • Runtime sécurisé Docker basé sur Alpine Linux et Java 21 * Contrôles de qualité de service améliorés pour les déploiements multi-tenants
  • Limitation de débit comme base de la gestion des ressources multi-locataires
  • Chemins de mise à niveau des versions précédentes
  • Compatibilité Client et importance de la mise à niveau de Java clients pour résoudre le problème CVE-2024-47561.
