#pulsar v4.0.10

2026-04-27

Avis de mise à niveau

Cette version met à niveau Jetty de 9.4.x vers 12.1.8 pour résoudre plusieurs CVE de haute gravité dans Jetty 9.4.x (#25534). Pour obtenir des informations générales et des discussions, consultez le [fil de discussion de la liste de développement] (https://lists.apache.org/thread/2mcnfn7f0nq3zww3ph2wf41cbh6xcsjj).

La mise à niveau introduit les modifications majeures suivantes :

  1. Changement d'interface AdditionalServlet. L'interface org.apache.pulsar.broker.web.plugin.servlet.AdditionalServlet a été couplée directement à la classe Jetty 9 org.eclipse.jetty.servlet.ServletHolder. Ce couplage a été supprimé, les implémentations externes de ce plugin API doivent donc être mises à jour.

  2. L'authentification Athenz nécessite Java 17+. pulsar-client-auth-athenz dépend désormais de Jetty et nécessite donc Java 17+. Le Pulsar Client et le Pulsar Admin client restent eux-mêmes compatibles Java 8+.

  3. Déplacement de la classe du fournisseur de métriques Prometheus. Les classes de fournisseur de métriques Prometheus par défaut pour BookKeeper et ZooKeeper ont été remplacées car les valeurs par défaut précédentes dépendaient de Jetty 9.4.x. Si vous utilisez le fichier de configuration par défaut précédent dans votre déploiement, mettez à jour les paramètres suivants :

    | Fichier de configuration | Paramètre | Ancienne valeur | Nouvelle valeur | | --- | --- | --- | --- | | bookkeeper.conf | statsProviderClass | org.apache.bookkeeper.stats.prometheus.PrometheusMetricsProvider | org.apache.pulsar.metrics.prometheus.bookkeeper.PrometheusMetricsProvider | | zookeeper.conf | metricsProvider.className | org.apache.zookeeper.metrics.prometheus.PrometheusMetricsProvider | org.apache.pulsar.metrics.prometheus.zookeeper.PrometheusMetricsProvider |

Les utilisateurs de la charte Apache Pulsar Helm antérieure à la version 4.6.0 devront définir la clé bookie.configData.statsProviderClass sur org.apache.pulsar.metrics.prometheus.bookkeeper.PrometheusMetricsProvider :

bookie:
  configData:
    statsProviderClass: "org.apache.pulsar.metrics.prometheus.bookkeeper.PrometheusMetricsProvider"

pulsar v4.0.10

2026-04-27

Upgrade notice

This release upgrades Jetty from 9.4.x to 12.1.8 to address several high-severity CVEs in Jetty 9.4.x (#25534). For background and discussion, see the dev list thread.

The upgrade introduces the following breaking changes:

  1. AdditionalServlet interface change. The org.apache.pulsar.broker.web.plugin.servlet.AdditionalServlet interface was coupled directly to the Jetty 9 org.eclipse.jetty.servlet.ServletHolder class. This coupling has been removed, so external implementations of this plugin API need to be updated.

  2. Athenz authentication requires Java 17+. pulsar-client-auth-athenz now depends on Jetty and therefore requires Java 17+. The Pulsar Client and Pulsar Admin client themselves remain Java 8+ compatible.

  3. Prometheus metrics provider class relocation. The default Prometheus metrics provider classes for BookKeeper and ZooKeeper have been replaced because the previous defaults depended on Jetty 9.4.x. If you are using the previous default configuration file in your deployment, update the following settings:

    | Config file | Setting | Old value | New value | | --- | --- | --- | --- | | bookkeeper.conf | statsProviderClass | org.apache.bookkeeper.stats.prometheus.PrometheusMetricsProvider | org.apache.pulsar.metrics.prometheus.bookkeeper.PrometheusMetricsProvider | | zookeeper.conf | metricsProvider.className | org.apache.zookeeper.metrics.prometheus.PrometheusMetricsProvider | org.apache.pulsar.metrics.prometheus.zookeeper.PrometheusMetricsProvider |

Users of the Apache Pulsar Helm chart prior to version 4.6.0 will need to set the bookie.configData.statsProviderClass key to org.apache.pulsar.metrics.prometheus.bookkeeper.PrometheusMetricsProvider:

bookie:
  configData:
    statsProviderClass: "org.apache.pulsar.metrics.prometheus.bookkeeper.PrometheusMetricsProvider"
