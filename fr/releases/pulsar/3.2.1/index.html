#pulsar v3.2.1

Courtier

  • Ajouter systématiquement une autorisation à grain fin à REST API #22202
  • Ajouter une autorisation fine à l'administrateur de rétention API #22163
  • Imprimer le non-journal en cas d'échec de la suppression du sujet partitionné #22153
  • Correction du courtier ne démarrant pas lorsque les deux transactions et Extensible Load Manager sont activés #22139
  • Renvoie getOwnerAsync sans attendre le courtier source lors de l'attribution et de la libération et gère le changement de rôle lors de l'initialisation du rôle #22112
  • Mettez en cache le rédacteur interne lorsqu'il est envoyé au sujet système. #22099
  • L'activation du traitement par lots provoque des messages non accusés de réception négatifs en raison de la concurrence d'accusé de réception et de livraison #22090
  • Prise en charge de l'exécution du conteneur docker avec gid != 0 #22081
  • Ajouter un journal d'erreurs pour résoudre l'échec du démarrage du registre du courtier #22065
  • Définir explicitement le seuil de compactage du sujet ServiceUnitStateChannel, améliorer getOwnerAsync et corriger d'autres bugs #22064
  • Correction d'une collision de hachage lors de l'utilisation d'un nom de consommateur se terminant par un nombre #22053
  • Nettoyez les valeurs avant de vous connecter au script apply-config-from-env.py #22044
  • Le correctif ne permet pas d'abonner un sujet partitionné avec une expression rationnelle correspondant au suffixe #22025
  • Ne pas conserver les données dans la rubrique système #22022
  • Abonnement bloqué en raison de l'appel de l'administrateur API analyseSubscriptionBacklog #22019
  • N'essayez pas d'ouvrir ML lorsque la méta du sujet n'existe pas et n'espérez pas en créer une nouvelle #22004
  • Ne pas imprimer de journal d'erreurs lorsque vous répondez à HTTP-404 lors de l'appel de l'administrateur API et que le sujet n'existe pas #21995
  • Ne fermez pas le socket si la recherche a échoué en raison de LockBusyException #21993
  • Prise en charge de la configuration dynamique d'autoSkipNonRecoverableData dans PersistentMessageExpiryMonitor #21991
  • Ajouter un délai d'attente pour la lecture du contrôle de santé #21990
  • Correction d'une erreur de suppression de schéma lors de la suppression d'un sujet partitionné avec de nombreuses partitions et schémas #21977
  • Différer les contrôles de propriété si le propriétaire est inactif (ExtensibleLoadManager) #21811
  • Correction de la perte de données de compactage/réplication lors de l'expiration des messages #21865
  • Ignorer le chargement des packages NAR s'ils ne sont pas configurés #21867
  • Améliorer le message d'erreur NamespaceUnloadStrategy #21880
  • Ne pas reconduire les registres vides en raison de l'inactivité #21893
  • Faire expirer les messages en fonction de l'heure de fermeture du grand livre pour éviter le décalage d'horloge client #21940
  • Correction du lecteur bloqué lors de la lecture à partir d'un sujet compacté avec désactivation du mode lecture compact #21969

Client

  • Correction d'un problème de consommation multi-sujets pouvant recevoir d'anciens messages après une recherche #21945
  • Correction de ConsumerBuilderImpl#subscribe silencieux bloqué lors de l'utilisation de pulsar-client:3.0.x avec des annotations jackson avant 2.12.0 #21985

Fonctions Pulsar IO et Pulsar

  • [FN] Ajouter une configuration pour les sources d'URL du package de connecteurs et de fonctions #22184
  • [FN] Ajout d'un argument "exception" manquant à certains log.error #22140
  • [FN] Empêcher putstate d'utiliser des valeurs vides #22127
  • [FN] Optimiser le démarrage de Function Worker par un chargement paresseux et un accès direct au zip/bytecode #22122
  • [FN] Empêcher la création d'une table d'état à partir des appels API pour les instances non existantes #22107
  • [FN] Utiliser le service PackageManagement unifié pour télécharger les packages #21955 ###CLI
  • [Admin] Expose le seuil de déchargement en secondes à l'administrateur #22101
  • [CLI] Correction du bug lorsque la taille spécifiée pour la rétention était définie avec -T #22150
  • [CLI] Erreur lorsque --destinationBroker est défini lorsque --bundle est vide #21879

Autres

  • [MISC] Ajouter une vérification de la valeur du temps d'entrée #22023
  • [Proxy] Ajouter une vérification pour brokerServiceURL qui ne prend pas encore en charge plusieurs uri #21972
  • [TX] Récupérer la position précédente par grand livre géré #22024
  • [ML] Correction du mécanisme de nouvelle tentative de suppression des registres pour invalider #21869
  • [ML] Filtrer les entrées supprimées avant de lire les entrées du grand livre #21739

Mises à jour de la bibliothèque

  • Mettez à niveau Jetty vers 9.4.54.v20240208 pour répondre au CVE-2024-22201 #22144
  • mise à niveau de commons-compress vers 1.26.0 #22086
  • Mise à niveau de la dépendance BookKeeper vers 4.16.4 #21983

pulsar v3.2.1

Broker

  • Consistently add fine-grain authorization to REST API #22202
  • Add fine-grain authorization to retention admin API #22163
  • Print non log when delete partitioned topic failed #22153
  • Fix broker not starting when both transactions and the Extensible Load Manager are enabled #22139
  • Return getOwnerAsync without waiting on source broker upon Assigning and Releasing and handle role change during role init #22112
  • Cache the internal writer when sent to system topic. #22099
  • Enabling batch causes negative unackedMessages due to ack and delivery concurrency #22090
  • Support running docker container with gid != 0 #22081
  • Add an error log to troubleshoot the failure of starting broker registry #22065
  • Set ServiceUnitStateChannel topic compaction threshold explicitly, improve getOwnerAsync, and fix other bugs #22064
  • Fix hash collision when using a consumer name that ends with a number #22053
  • Sanitize values before logging in apply-config-from-env.py script #22044
  • Fix can not subscribe partitioned topic with a suffix-matched regexp #22025
  • Do not retain the data in the system topic #22022
  • Subscription stuck due to called Admin API analyzeSubscriptionBacklog #22019
  • Do not try to open ML when the topic meta does not exist and do not expect to create a new one #22004
  • Do not print an Error log when responding to HTTP-404 when calling Admin API and the topic does not exist #21995
  • Do not close the socket if lookup failed due to LockBusyException #21993
  • Support setting autoSkipNonRecoverableData dynamically in PersistentMessageExpiryMonitor #21991
  • Add timeout for health check read #21990
  • Fix schema deletion error when deleting a partitioned topic with many partitions and schema #21977
  • Defer the ownership checks if the owner is inactive (ExtensibleLoadManager) #21811
  • Fix compaction/replication data loss when expire messages #21865
  • Skip loading the NAR packages if not configured #21867
  • Improve NamespaceUnloadStrategy error message #21880
  • Don't rollover empty ledgers based on inactivity #21893
  • Expire messages according to ledger close time to avoid client clock skew #21940
  • Fix reader stuck when read from compacted topic with read compact mode disable #21969

Client

  • Fix multi-topics consumer could receive old messages after seek #21945
  • Fix ConsumerBuilderImpl#subscribe silent stuck when using pulsar-client:3.0.x with jackson-annotations prior to 2.12.0 #21985

Pulsar IO and Pulsar Functions

  • [FN] Add configuration for connector & functions package url sources #22184
  • [FN] Add missing "exception" argument to some log.error #22140
  • [FN] Prevent putstate uses empty values #22127
  • [FN] Optimize Function Worker startup by lazy loading and direct zip/bytecode access #22122
  • [FN] Prevent create state table from API calls for non-exists instances #22107
  • [FN] Use unified PackageManagement service to download packages #21955

CLI

  • [Admin] Expose the offload threshold in seconds to the admin #22101
  • [CLI] Fix the bug when set-retention specified size with -T #22150
  • [CLI] Error out when --destinationBroker is set when --bundle is empty #21879

Others

  • [MISC] Add a check for the input time value #22023
  • [Proxy] Add a check for brokerServiceURL that does not support multi uri yet #21972
  • [TX] Get previous position by managed ledger #22024
  • [ML] Fix retry mechanism of deleting ledgers to invalidate #21869
  • [ML] Filter out deleted entries before read entries from ledger #21739

Library updates

  • Upgrade Jetty to 9.4.54.v20240208 to address CVE-2024-22201 #22144
  • pgrade commons-compress to 1.26.0 #22086
  • Upgrade BookKeeper dependency to 4.16.4 #21983

A special thanks to the following contributors who contributed to Pulsar 3.2.1: mattisonchao, lhotari, poorbarcode, Technoboy-, jiangpengcheng, dragosvictor, freeznet, liangyepianzhou, heesung-sn, zymap, massakam, thetumbled, BewareMyPower, chenhongSZ, Shawyeok, hangc0276, 315157973, coderzc, dao-jun.
