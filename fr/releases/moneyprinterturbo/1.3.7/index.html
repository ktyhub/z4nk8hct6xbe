<h2 id="fr-v1.3.7">Points forts</h2>
  • Ajout de sous-titres mot par mot et d'une animation printanière contextuelle, avec des commandes indépendantes pour le mode d'affichage et l'animation dans la WebUI.
  • Ajout d'une sélection de musique de fond prédéfinie avec aperçu audio dans le navigateur, afin que vous puissiez l'écouter avant de générer une vidéo.
  • Ajout de pauses natives aux scripts avec Azure TTS V1 (Edge TTS) : utilisez [pause: 2s] ou [停顿: 2s] pour insérer du silence tout en gardant la narration et les sous-titres alignés.
  • Ajout des fournisseurs Kokoro et VoxCPM TTS. Kokoro prend en charge un service auto-hébergé compatible OpenAI et charge automatiquement la liste vocale du serveur.
  • Ajout de Claude Code en tant que fournisseur LLM utilisant un abonnement Claude authentifié, avec des fichiers de déploiement Docker dédiés ; a également ajouté le fournisseur de route API compatible OpenAI.
  • Amélioration de la génération vidéo Shengsuan Cloud avec découverte de modèles spécifiques au compte, devis et confirmation explicite des coûts, ainsi que des recommandations de nombre clip basées sur la durée de la narration.
  • Réduction de la sélection répétée de matériaux dans les vidéos générées dans la même tâche lors de l'utilisation de Pexels, Pixabay, Coverr ou de fichiers locaux. La réutilisation des matériaux est signalée lorsque le pool disponible est insuffisant.
  • Ajout d'un paramètre d'audience YouTube « Conçu pour les enfants » à la publication Upload-Post.
  • Ajout de la localisation azerbaïdjanaise WebUI et des traductions mises à jour pour les nouveaux paramètres et invites.

Correctifs et améliorations

  • Rendu amélioré des animations de sous-titres, notamment une mise à l'échelle synchronisée des images de sous-titres et des masques de transparence pour éviter les contours noirs lorsque les sous-titres apparaissent.
  • Découverte vocale et gestion audio renforcées de Kokoro : conservez la voix sélectionnée lorsque le service est indisponible et validez l'audio généré avant de remplacer les fichiers existants.
  • Ajout de la validation des balises de pause et de la synchronisation améliorée de la narration/sous-titres multi-segments ; les morceaux de parole invalides arrêtent désormais la génération plutôt que de produire silencieusement une narration incomplète.
  • Géré les débits vocaux non finis tels que NaN et l'infini de manière plus sûre.
  • Correction de la vérification du port du script de lancement WebUI lorsque le chemin du projet contient des espaces, et correction des importations et des chemins de référentiel dans le notebook Colab.
  • Ajout de messages de journal périodiques pendant l'exécution de la concaténation FFmpeg, ce qui facilite le diagnostic des traitements de longue durée.
  • Nettoyage étendu du cache matériel pour récupérer les fichiers temporaires laissés par les écritures interrompues.
  • Mise à jour de l'assistant d'agent pour prendre en charge openai_image et reconnaître claude_code comme fournisseur LLM sans clé.
  • Synchronisation de la liste vocale Edge TTS documentée avec le catalogue intégré et clarification de l'emplacement du package Windows one-click dans la version Assets.

## Notes d'utilisation et de mise à niveau

  • Les sous-titres par défaut restent affichage des phrases sans animation. La synchronisation mot par mot fonctionne mieux avec Azure TTS V1 (Edge TTS) ou Whisper ; les fournisseurs sans horodatage au niveau des mots peuvent afficher des phrases ou des phrases entières à la place.
  • Les balises de pause de script sont prises en charge uniquement avec Azure TTS V1 (Edge TTS), avec des pauses individuelles de 0.1 à 10 secondes.
  • Kokoro nécessite un service TTS compatible fonctionnant séparément. Claude Code nécessite son CLI et une authentification d'abonnement ; la sélection de l’un ou l’autre fournisseur n’installe ni n’authentifie automatiquement le service sous-jacent.
  • Le paramètre d'audience YouTube est une déclaration explicite de l'utilisateur et non une classification automatique du contenu. La valeur par défaut est non conçu pour les enfants ; vérifiez le paramètre avant de télécharger.
  • L'allocation de matériaux par lots réduit la réutilisation au sein d'une seule tâche ; cela ne garantit pas des images uniques lorsqu'il y a trop peu de clips sources et ne modifie pas le comportement d'allocation des fournisseurs de matériel d'IA payants.

MoneyPrinterTurbo v1.3.7

Highlights

  • Word-by-word subtitles with spring animation — #1313 adds independent WebUI toggles for subtitle display mode and pop-in animation. Defaults stay sentence-level with no animation, so upgrading needs no config change — but don't assume word-accurate timing everywhere: it depends on word-level timestamps from Azure TTS V1 (Edge TTS) or Whisper, while other providers fall back to phrases or whole sentences.
  • Native script pauses — #1330 introduces [pause: 2s] / [停顿: 2s] (0.1–10s, Edge TTS V1 only) that inserts silence while keeping narration and subtitles aligned. Behavioral change to watch: invalid pause tags and speech chunks now abort generation instead of silently producing incomplete narration, so scripts that were previously "tolerated" will fail loudly.
  • Kokoro and VoxCPM TTS providers — #1325 (Kokoro) and #1343 (VoxCPM) broaden the voice backends; Kokoro targets a self-hosted OpenAI-compatible service and auto-loads its voice list. Watch out: selecting a provider does not install or authenticate it — you run the service yourself — though hardening now preserves your chosen voice when the server is unreachable and validates audio before overwriting files.
  • Claude Code and API Route LLM providers — #1319 enables Claude Code via an authenticated Claude subscription (keyless, with dedicated Docker files), and #1354 adds an OpenAI-compatible API Route provider. You still must install the CLI and authenticate yourself; provider selection is not auto-setup. The agent helper (#1352/#1353) now treats claude_code as keyless and supports openai_image.
  • Generation cost and material consistency — #1328 brings Shengsuan Cloud account-specific model discovery, quotes with explicit cost confirmation, and clip-count recommendations tied to narration length, so you see the bill before rendering. #1340 reduces repeated Pexels/Pixabay/Coverr/local footage within one batch and warns when the pool is thin — but it guarantees no uniqueness with scarce clips and leaves paid AI material providers' allocation unchanged.
  • Publishing and preview controls — #1314 adds preset background music with in-browser preview so you can hear the track before generating. The YouTube "Made for kids" setting (bfd7612) is an explicit user declaration defaulting to "not made for kids," not automatic content classification — review it before uploading.

No breaking changes.

<h2 id="en-v1.3.7">Highlights</h2>
  • Added word-by-word subtitles and a pop-up spring animation, with independent controls for display mode and animation in the WebUI.
  • Added preset background music selection with in-browser audio preview, so you can listen before generating a video.
  • Added native pauses to scripts with Azure TTS V1 (Edge TTS): use [pause: 2s] or [停顿: 2s] to insert silence while keeping narration and subtitles aligned.
  • Added Kokoro and VoxCPM TTS providers. Kokoro supports a self-hosted OpenAI-compatible service and automatically loads the server's voice list.
  • Added Claude Code as an LLM provider using an authenticated Claude subscription, with dedicated Docker deployment files; also added the OpenAI-compatible API Route provider.
  • Improved Shengsuan Cloud video generation with account-specific model discovery, quotes and explicit cost confirmation, plus clip-count recommendations based on narration duration.
  • Reduced repeated material selection across videos generated in the same task when using Pexels, Pixabay, Coverr, or local files. Material reuse is reported when the available pool is insufficient.
  • Added a YouTube “Made for kids” audience setting to Upload-Post publishing.
  • Added Azerbaijani WebUI localization and updated translations for the new settings and prompts.

Fixes and Improvements

  • Improved subtitle animation rendering, including synchronized scaling of subtitle images and transparency masks to avoid black outlines when subtitles appear.
  • Hardened Kokoro voice discovery and audio handling: retain the selected voice when the service is unavailable and validate generated audio before replacing existing files.
  • Added pause-tag validation and improved multi-segment narration/subtitle synchronization; invalid speech chunks now stop generation rather than silently producing incomplete narration.
  • Handled non-finite voice rates such as NaN and infinity more safely.
  • Fixed the WebUI launch script's port check when the project path contains spaces, and corrected imports and repository paths in the Colab notebook.
  • Added periodic log messages while FFmpeg concatenation is running, making long-running processing easier to diagnose.
  • Extended material cache cleanup to reclaim temporary files left behind by interrupted writes.
  • Updated the agent helper to support openai_image and recognize claude_code as a keyless LLM provider.
  • Synced the documented Edge TTS voice list with the built-in catalog and clarified where to find the Windows one-click package in release Assets.

Usage and Upgrade Notes

  • Subtitle defaults remain sentence display with no animation. Word-by-word timing works best with Azure TTS V1 (Edge TTS) or Whisper; providers without word-level timestamps may display phrases or whole sentences instead.
  • Script pause tags are supported only with Azure TTS V1 (Edge TTS), with individual pauses from 0.1 to 10 seconds.
  • Kokoro requires a separately running compatible TTS service. Claude Code requires its CLI and subscription authentication; selecting either provider does not install or authenticate the underlying service automatically.
  • The YouTube audience setting is an explicit user declaration, not automatic content classification. It defaults to not made for kids; review the setting before uploading.
  • Batch material allocation reduces reuse within a single task; it does not guarantee unique footage when there are too few source clips and does not change paid AI material providers' allocation behavior.
