lobehub v2.3.2

Sortie v2.3.2

À partir du PR #22430 : https://github.com/lobehub/lobehub/pull/22430

Résumé

Source de contribution : assistée par l'IA

🚀 Sortie LobeHub (20261106)

Date de sortie : 6 novembre 2026
Depuis v2.3.1 : 127 PR fusionnés · 11 contributeurs

Le travail quotidien devient plus facile à organiser et à annuler : les tâches reçoivent des étiquettes et une corbeille, les canaux se comportent comme de vraies conversations et des vues MCP interactives s'ouvrent directement dans le chat.

✨ Points forts

  • Étiquettes de tâches — Étiquetez les tâches, filtrez par étiquette et regroupez les vues par étiquette, à partir de l'interface utilisateur Web, des outils d'agent ou du CLI. (#22176, #22175)
  • Annuler pour les actions de tâches par lots : les actions par lots s'appliquent instantanément avec une annulation et les tâches supprimées sont envoyées dans une corbeille. (#22167)
  • Applications MCP dans les conversations : les vues interactives des applications MCP s'affichent dans la conversation. (#21231)
  • Chaînes dans la liste des messages — Les conversations s'ouvrent sous forme de chaînes, les messages apparaissent dès que vous les envoyez, les membres mentionnés sont avertis et @mentionner quelqu'un en dehors d'une chaîne les invite. (#22205, #22325, #22222, #22294)
  • GitHub Copilot CLI en tant qu'agent hétérogène — Exécutez le copilot CLI aux côtés des agents locaux existants. Le Codex obtient également des questions natives et une sélection de vitesse en fonction de ce que la machine prend en charge. (#22195, #22287, #22264)
  • Appareils cloud gérés — Connectez-en un à lh connect --managed, suivez ses phases dans la liste des appareils et laissez-le se réveiller avant que le travail ne soit réparti. (#22269, #22275, #22274, #22276)
  • Entrée de chat plus riche — Faites glisser les documents de l'agent dans l'entrée, @mentionnez les agents et les compétences du marché et choisissez le mode de conversion du texte collé. (#22104, #22194, #22183)
  • Liste de contrôle de configuration du projet — Les nouveaux projets répertorient leurs étapes de base et proposent des connexions lorsque vous en avez besoin. (#22279)

🏗️ Produit de base et architecture

Tâches et objectifs

  • Recherchez du texte dans la page de détail de la tâche avec Mod+F et recherchez des descriptions de tâches et des instructions à partir de la recherche globale. (#22267, #22256)
  • Archiver les objectifs et filtrer la liste d'objectifs par Archivé ; Les objectifs atteints peuvent être archivés sans signature et sont étiquetés Terminé. (#22172, #22259)
  • Le membre responsable peut changer pendant l'exécution d'une tâche, et le bouton Archiver reste utilisable une fois l'exécution d'une tâche terminée. (#22181, #22321)
  • L'attribution groupée à l'agent est regroupée et confirmée avant d'attribuer un agent privé. (#22300)

Chat et agents

  • Le texte collé est envoyé textuellement au lieu d'être reformaté en démarque. (#22189)
  • Les téléchargements du compositeur restent dans leur conversation et un message d'accueil refusé reste dans le compositeur. (#22329, #22280)
  • Les sujets transférés continuent dans le répertoire de travail source. (#22238)
  • Les exécutions de groupe montrent la progression par membre pour les tâches parallèles. (#22282)
  • Les outils encore en cours d'exécution lorsque vous arrêtez une exécution sont marqués comme abandonnés. (#22330)
  • Le transport Pi RPC prend désormais en charge les événements Pi 1.x et les images des résultats des outils provenant des exécutions d'appareils distants peuvent être prévisualisées. (#22324, #22211)

Modèles et génération

  • Les modèles d'images GPT peuvent générer des GIF animés. (#22306)
  • La réflexion DeepSeek V4 est désactivée pour la sortie structurée Anthropic. (#22369)

📱 Plateformes / Intégrations

  • Linéaire : importez les problèmes qui n'appartiennent à aucun projet, consultez le nombre total de problèmes dans le sélecteur d'importation, incluez éventuellement les problèmes archivés et exécutez des cycles de synchronisation des règles en une seule requête. (#22301, #22258, #22340, #22263)
  • Bots : l'espace réservé au traitement est désactivé par défaut avec une bascule sur chaque plate-forme, et les nouveaux robots démarrent avec les réactions de statut désactivées. (#21981, #22182)
  • Bots : les robots indiquent à l'expéditeur qu'ils n'ont pas d'autorisation lorsque la stratégie de groupe est désactivée, et le test de connexion Discord signale un robot désinstallé, une intention désactivée ou une incompatibilité d'ID d'application. (#22187, #22178)
  • Bureau : changez d'onglet avec Ctrl+numéro, avec la commutation rapid corrigée. (#22225)
  • Éditeur de page : l'en-tête indique qui d'autre se trouve sur une page en direct, et la limite de caractères par page s'applique également aux pages collaboratives. (#22174, #22277)

🖥️ CLI & Expérience utilisateur

  • Nouveau groupe de commandes lh connector pour les connecteurs MCP. (#22193)
  • lh whoami affiche la portée signalée par le serveur et les pages lh doc list dans les documents plus anciens. (#22254, #21720)
  • lh gen image permet au serveur de choisir le modèle par défaut. (#22197) - lh des agents locaux utilise la connexion au bureau et nomme lh login lorsqu'il est manquant. (#22114)
  • Les onglets du navigateur sont intitulés après la page ou l'élément ouvert. (#22228)

🔧 Outillage

  • De nouveaux worktrees sont créés sous ~/.lobehub/worktrees. (#22203)
  • Les téléchargements Canary de bureau ayant échoué peuvent désormais être récupérés. (#22312)

🔒 Fiabilité et mise à niveau

  • Fiabilité : une rafale de réhébergements d'images ne bloque plus le pool de bases de données et les sondes de stockage de fichiers s'exécutent en dehors des transactions de base de données. (#22290, #22385)
  • Fiabilité : une discussion qui échoue avant son premier octet renvoie une erreur structurée. (#22314)
  • Fiabilité : l'affirmation du gestionnaire d'objectifs ne se remet plus en file d'attente pour toujours, et les exécutions simultanées mortes depuis longtemps cessent de ré-avertir. (#22209, #22208)
  • Auto-hébergement : cette version inclut les migrations 0200–0205, qui s'exécutent automatiquement au démarrage. Ils ajoutent channels.config, goals.archived_at, project_sites.last_seen_at, des tables d'étiquettes de tâches, des liens d'invitation à un espace de travail réutilisables et des tables d'évaluation LobeBench. 0204 rend également workspace_invitations.expires_at nullable et ajoute une vérification indiquant que les invitations non réutilisables expirent. Effectuez votre sauvegarde habituelle de base de données avant la mise à niveau. (#22173, #22171, #22175, #22278, #22245, #22157)

lobehub v2.3.2

Release v2.3.2

From PR #22430: https://github.com/lobehub/lobehub/pull/22430

Summary

Contribution source: AI-assisted

🚀 LobeHub Release (20261106)

Release Date: November 6, 2026
Since v2.3.1: 127 merged PRs · 11 contributors

Everyday work gets easier to organize and easier to undo: tasks gain labels and a recycle bin, channels behave like real conversations, and interactive MCP views open right inside the chat.

✨ Highlights

  • Task labels — Label tasks, filter by label and group views by label, from the Web UI, Agent tools or the CLI. (#22176, #22175)
  • Undo for batch task actions — Batch actions apply instantly with an undo, and deleted tasks go to a recycle bin. (#22167)
  • MCP Apps in conversations — Interactive views from MCP Apps render inside the conversation. (#21231)
  • Channels in the message list — Conversations open as channels, messages appear as soon as you send them, mentioned members get notified, and @mentioning someone outside a channel invites them. (#22205, #22325, #22222, #22294)
  • GitHub Copilot CLI as a heterogeneous Agent — Run Copilot CLI alongside the existing local Agents. Codex also gains native questions and Speed selection based on what the machine supports. (#22195, #22287, #22264)
  • Managed cloud devices — Connect one with lh connect --managed, follow its phases in the device list, and let it wake before work is dispatched. (#22269, #22275, #22274, #22276)
  • Richer chat input — Drag Agent documents into the input, @mention Agents and Skills from the marketplace, and choose how pasted text converts. (#22104, #22194, #22183)
  • Project setup checklist — New projects list their basic steps and offer connections when you need them. (#22279)

🏗️ Core Product & Architecture

Tasks and Goals

  • Find text in the task detail page with Mod+F, and search task descriptions and instructions from global search. (#22267, #22256)
  • Archive goals and filter the goal list by Archived; completed goals can be archived without a sign-off and are labeled Completed. (#22172, #22259)
  • The member assignee can change while a task runs, and the Archive button stays usable once a task stops running. (#22181, #22321)
  • Bulk Assign to Agent is grouped and confirms before assigning a private Agent. (#22300)

Chat and Agents

  • Pasted text is sent verbatim instead of being reformatted as markdown. (#22189)
  • Composer uploads stay with their conversation, and a refused Home message stays in the composer. (#22329, #22280)
  • Forwarded topics continue in the source working directory. (#22238)
  • Group runs show per-member progress for parallel tasks. (#22282)
  • Tools still running when you stop a run are marked as aborted. (#22330)
  • The Pi RPC transport now supports Pi 1.x events, and tool-result images from remote device runs can be previewed. (#22324, #22211)

Models and Generation

  • GPT Image models can output animated GIFs. (#22306)
  • DeepSeek V4 thinking is disabled for Anthropic structured output. (#22369)

📱 Platforms / Integrations

  • Linear: import issues that belong to no project, see the total issue count in the import picker, optionally include archived issues, and run rule sync rounds in one request. (#22301, #22258, #22340, #22263)
  • Bots: the processing placeholder is off by default with a toggle on every platform, and new bots start with status reactions off. (#21981, #22182)
  • Bots: bots tell the sender they lack permission when group policy is disabled, and Discord test connection flags an uninstalled bot, a disabled intent or an app ID mismatch. (#22187, #22178)
  • Desktop: switch tabs with Ctrl+number, with rapid switching fixed. (#22225)
  • Page editor: the header shows who else is on a live page, and the per-page character limit also applies to collaborative pages. (#22174, #22277)

🖥️ CLI & User Experience

  • New lh connector command group for MCP connectors. (#22193)
  • lh whoami shows the server-reported scope, and lh doc list pages through older documents. (#22254, #21720)
  • lh gen image lets the server pick the default model. (#22197)
  • Local Agents' lh uses the desktop sign-in and names lh login when it is missing. (#22114)
  • Browser tabs are titled after the open page or item. (#22228)

🔧 Tooling

  • New worktrees are created under ~/.lobehub/worktrees. (#22203)
  • Failed desktop canary uploads can now be recovered. (#22312)

🔒 Reliability & Upgrade

  • Reliability: a burst of image rehosts no longer deadlocks the database pool, and file storage probes run outside database transactions. (#22290, #22385)
  • Reliability: a chat that fails before its first byte returns a structured error. (#22314)
  • Reliability: the goal manager claim no longer re-queues itself forever, and long-dead concurrent runs stop re-warning. (#22209, #22208)
  • Self-hosting: this release ships migrations 0200–0205, which run automatically on startup. They add channels.config, goals.archived_at, project_sites.last_seen_at, task label tables, reusable workspace invitation links and LobeBench evaluation tables. 0204 also makes workspace_invitations.expires_at nullable and adds a check that non-reusable invitations keep an expiry. Take your usual database backup before upgrading. (#22173, #22171, #22175, #22278, #22245, #22157)

👥 Contributors

Huge thanks to 11 contributors who shipped 127 merged PRs this cycle.
