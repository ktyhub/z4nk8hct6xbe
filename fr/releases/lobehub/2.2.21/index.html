🚀 Sortie LobeHub (20261029)

Date de sortie : 29 octobre 2026
Depuis v2.2.20 : 616 PR fusionnés · 16 contributeurs

Les projets deviennent le lieu où se déroule le travail : les conversations, les canaux, les tâches et l'acceptation y vivent - tandis que les robots apprennent quand s'exprimer, les objectifs bénéficient d'une boucle de révision complète et les ressources deviennent des documents.

✨ Points forts

  • Projets en tant qu'espaces de travail — Exécutez des conversations et des tâches au sein d'un projet, avec un compositeur d'accueil du projet, des paramètres de membres et de bibliothèques, un agent principal échangeable, des sujets regroupés par agent et filtrés par statut et appareil, des projets à glisser pour réorganiser et des canaux regroupés à l'intérieur des projets. (#21370, #21345, #21344, #21483, #21382, #21398, #21490, #21752)
  • Canaux multi-agents — Les agents collaborent dans des canaux, chaque canal hérite de l'appareil et du répertoire de son agent, et les paramètres de canal repensés conservent le style de réponse et les emoji par canal. (#21545, #21782, #21658, #21757)
  • Bot wake — Les robots décident quand répondre en fonction de leurs tâches, peuvent d'abord accuser réception et répondre dans un fil de discussion, se réveiller lors des modifications qui les @-mentionnent, rester en dehors des fils de discussion multipartites et le choix de ne pas répondre s'affiche comme son propre état. Disponible sur Discord, Slack et Feishu/Lark. (#21585, #21726, #21719, #21756, #21728, #21727, #21825)
  • Espace de travail des objectifs : une page d'objectifs multi-agents, des arborescences d'options de décision, un rapport de livraison à examiner avant l'approbation, une copie des objectifs entre les étendues personnelles et celles de l'espace de travail et des graphiques de métriques North Star. (#21221, #21560, #21773, #21665, #21126)
  • Docs et Favoris — Les ressources sont restructurées dans Docs avec des options d'affichage de la barre latérale et un rendu d'artefacts ; épinglez n’importe quelle page dans une section Favoris de la barre latérale. (#21373, #21548, #21572)
  • Canvas — Artefacts HTML multi-fichiers rendus avec des éléments lobe-*, mise en évidence du code, un bouton de partage explicite et publication Canvas/HTML CLI unifiée. (#21326, #21506, #21589, #21671)
  • Éditeur 7.0 — Alertes, graphiques et notes de bas de page dans les documents et le menu barre oblique, ainsi qu'une table des matières de page de style Notion. (#21799, #21826, #21321)
  • Intégration linéaire — Connectez Linear via OAuth et synchronisez les problèmes Linear dans les tâches du projet. (#21036, #21723)

🏗️ Agent principal et architecture

  • Les sous-agents s'exécutent en arrière-plan et fournissent leurs résultats sous forme de messages. (#20862)
  • Modèles de décision via OpenRouter et les décisions natives API d'OpenAI, configurables par canal et dans les paramètres du modèle de service repensés, ainsi que le modèle de vérificateur. (#20836, #21359, #21788, #21480, #21774)
  • Nouveaux fournisseurs et modèles : Magpie, TypeSafe, MiniMax M3.1 Flash et tout point de terminaison fal avec sa liste de modèles d'image/vidéo. (#21644, #21444, #21216, #21238)
  • Le compactage du contexte est proposé pour les requêtes surdimensionnées et l'historique est conservé en cas d'échec du résumé du compactage. (#21504, #21590)
  • Les sessions Stdio MCP restent actives lors des appels d'outils et affichent des erreurs de démarrage exploitables ; MCP négocie les versions modernes du protocole HTTP. (#21031, #21110, #21743)
  • Recherche de messages filtrés, recherche d'objectifs et lh recall. (#21188)
  • Les grands routeurs de serveur, les services et les modèles de bases de données sont divisés en modules ciblés, et de nombreux magasins client sont passés à @lobechat/replica pour des peintures obsolètes plus rapides. (#21085, #21132, #21145, #21200, #21118)

📱 Plateformes / Intégrations

  • OpenAPI : groupes de discussion sur /api/v1/chat-groups, exécutez une tâche maintenant et lisez ses exécutions sur /api/v1/tasks/{id}/runs, ainsi que les points de terminaison des paramètres de notification. (#21280, #21470, #21538)
  • IM : pièces jointes aux messages téléchargées, images de discussion visibles par le modèle dans les lectures de messages et réponses Discord qui @-mentionnent des personnes. (#21581, #21758, #21736)
  • Agents externes : téléchargement de fichiers/images dans le menu +, Claude Code voit les connecteurs claude.ai et les exécutions liées au périphérique reprennent lors d'une nouvelle tentative au lieu d'effacer le tour. (#21794, #21294, #21494)
  • Bureau : notification du système d'exploitation lorsqu'un membre de l'espace de travail vous mentionne et URL des liens survolés dans la barre d'état. (#21436, #21291)
  • Mobile : les surfaces de bureau arrivent sur le Web mobile. (#21503)
  • CLI : lh gen json, lh gen decide, lh read <url>, lh notification, slugs d'espace de travail pour --workspace, un WebSocket reconnectable à la place de SSE et l'outil de navigation sur les appareils lh connect. (#21413, #21835, #21514, #21539, #21540, #20501, #21422)
  • SDK : Assistants OAuth pour les applications natives et un fournisseur accessToken. (#21435)

🖥️ Expérience utilisateur

  • L'acceptation gagne la portée de l'espace de travail, la liaison du projet, les preuves du terminal et le transfert des commentaires à l'agent d'origine. (#21432, #21392, #21734, #21619)
  • La mémoire remplace la page de contextes par des pages d'entités construites sur des données de mémoire réelles. (#21347)
  • Recherchez dans le sujet avec Mod+F, survolez la prélecture des pages du sujet et une corbeille d'espace de travail. (#21530, #21724, #21537) - Avatars générés pour les agents, les personnes et les espaces de travail sans un, ainsi qu'un mur de badges pour la liste des agents. (#21778, #21632, #21786, #21815)
  • Les connecteurs s'ouvrent sous forme de liste → pages de détail, avec un paramètre d'espace de travail pour savoir qui les gère. (#21684, #21653)
  • Copie plus claire de l'interface utilisateur chinoise avec erreurs de traduction corrigées. (#21505)

🔒 Sécurité et fiabilité

  • Sécurité : Rotation des clés JWKS pour l'authentification. (#21431)
  • Sécurité : les webhooks de mémoire nécessitent une configuration d'authentification et les informations d'identification du point de terminaison du fournisseur sont isolées. (#21254, #21255)
  • Sécurité : @modelcontextprotocol/sdk mis à jour pour un avis de sécurité, les installations OAuth MCP du marché sont autorisées et les journaux MCP rédigent les métadonnées sensibles. (#21351, #21367, #21423)
  • Sécurité : le formulaire d'identification sécurisé ne peut plus être approuvé à partir des surfaces de notification. (#20580)
  • Fiabilité : les sessions Web restent actives grâce à l'actualisation de session différée. (#21707)
  • Fiabilité : La récupération sécurisée SSRF diffuse les corps de réponse au lieu de les mettre en mémoire tampon. (#21701)
  • Auto-hébergement : cette version inclut plusieurs migrations de bases de données (favoris, synchronisation linéaire, cycle de vie des canaux, sites de projet et rôles de membre) ; ils s'exécutent automatiquement au démarrage. (#21792, #21722, #21691, #21290)

Commit Message

🚀 LobeHub Release (20261029)

Release Date: October 29, 2026
Since v2.2.20: 616 merged PRs · 16 contributors

Projects become the place where work happens — conversations, channels, tasks and acceptance live inside them — while bots learn when to speak up, goals gain a full review loop, and Resources become Docs.

✨ Highlights

  • Projects as workspaces — Run conversations and tasks inside a project, with a project home composer, members and libraries settings, a swappable main agent, topics grouped by agent and filtered by status and device, drag-to-reorder projects, and channels grouped inside projects. (#21370, #21345, #21344, #21483, #21382, #21398, #21490, #21752)
  • Multi-agent channels — Agents collaborate in channels, each channel inherits its Agent's device and directory, and the redesigned channel settings keep reply style and emoji per channel. (#21545, #21782, #21658, #21757)
  • Bot wake — Bots decide when to reply based on their duties, can acknowledge first and answer in a thread, wake on edits that @-mention them, stay out of multi-party threads, and the choice not to reply renders as its own state. Available on Discord, Slack and Feishu / Lark. (#21585, #21726, #21719, #21756, #21728, #21727, #21825)
  • Goals workspace — A cross-agent goals page, decision option trees, a delivery report to review before sign-off, copying goals between personal and workspace scopes, and north-star metric charts. (#21221, #21560, #21773, #21665, #21126)
  • Docs and Favorites — Resources are restructured into Docs with sidebar view options and artifact rendering; pin any page to a sidebar Favorites section. (#21373, #21548, #21572)
  • Canvas — Multi-file HTML artifacts rendered with lobe-* elements, code highlighting, an explicit share button, and unified Canvas/HTML CLI publishing. (#21326, #21506, #21589, #21671)
  • Editor 7.0 — Alerts, charts and footnotes in documents and the slash menu, plus a Notion-style page table of contents. (#21799, #21826, #21321)
  • Linear integration — Connect Linear via OAuth and sync Linear issues into project tasks. (#21036, #21723)

🏗️ Core Agent & Architecture

  • Sub-agents run in the background and deliver their results as messages. (#20862)
  • Decision models via OpenRouter and OpenAI's native Decisions API, configurable per channel and in the redesigned Service Model settings, along with the verifier model. (#20836, #21359, #21788, #21480, #21774)
  • New providers and models: Magpie, TypeSafe, MiniMax M3.1 Flash, and any fal endpoint with its image/video model list. (#21644, #21444, #21216, #21238)
  • Context compaction is offered for oversized requests, and history is kept when the compaction summary fails. (#21504, #21590)
  • Stdio MCP sessions stay alive across tool calls and show actionable startup errors; MCP negotiates modern HTTP protocol versions. (#21031, #21110, #21743)
  • Filtered message search, goal search and lh recall. (#21188)
  • Large server routers, services and database models split into focused modules, and many client stores moved onto @lobechat/replica for faster stale-first paints. (#21085, #21132, #21145, #21200, #21118)

📱 Platforms / Integrations

  • OpenAPI: chat groups at /api/v1/chat-groups, run a task now and read its runs at /api/v1/tasks/{id}/runs, and notification settings endpoints. (#21280, #21470, #21538)
  • IM: uploaded message attachments, chat images visible to the model in message reads, and Discord replies that actually @-mention people. (#21581, #21758, #21736)
  • External agents: file/image upload in the + menu, Claude Code sees claude.ai connectors, and device-bound runs resume on retry instead of wiping the turn. (#21794, #21294, #21494)
  • Desktop: OS notification when a workspace member mentions you, and hovered link URLs in the status bar. (#21436, #21291)
  • Mobile: desktop surfaces come to the mobile web. (#21503)
  • CLI: lh gen json, lh gen decide, lh read <url>, lh notification, workspace slugs for --workspace, a reconnectable WebSocket in place of SSE, and the browser tool on lh connect devices. (#21413, #21835, #21514, #21539, #21540, #20501, #21422)
  • SDK: OAuth helpers for native apps and an accessToken provider. (#21435)

🖥️ User Experience

  • Acceptance gains workspace scope, project binding, terminal evidence and feedback hand-off to the original agent. (#21432, #21392, #21734, #21619)
  • Memory replaces the contexts page with entity pages built on real memory data. (#21347)
  • Find in topic with Mod+F, hover prefetch of topic pages, and a workspace recycle bin. (#21530, #21724, #21537)
  • Generated avatars for agents, people and workspaces without one, and an agent list badge wall. (#21778, #21632, #21786, #21815)
  • Connectors open as list → detail pages, with a workspace setting for who manages them. (#21684, #21653)
  • Clearer Chinese UI copy with mistranslations corrected. (#21505)

🔒 Security & Reliability

  • Security: JWKS key rotation for auth. (#21431)
  • Security: memory webhooks require authentication configuration, and provider endpoint credentials are isolated. (#21254, #21255)
  • Security: @modelcontextprotocol/sdk updated for a security advisory, marketplace OAuth MCP installations are authorized, and MCP logs redact sensitive metadata. (#21351, #21367, #21423)
  • Security: the secure credential form can no longer be approved from notification surfaces. (#20580)
  • Reliability: web sessions stay alive with deferred session refresh. (#21707)
  • Reliability: SSRF-safe fetch streams response bodies instead of buffering them. (#21701)
  • Self-hosting: this release ships several database migrations (favorites, Linear sync, channel lifecycle, project sites and member roles); they run automatically on startup. (#21792, #21722, #21691, #21290)
