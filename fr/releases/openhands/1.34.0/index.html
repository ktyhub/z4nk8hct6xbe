note d'installation de macOS

L'application n'est pas encore signée avec un identifiant de développeur Apple, donc macOS peut appeler un version téléchargée "endommagée" — c'est la quarantaine Gatekeeper, pas un mauvais fichier. Après avoir déplacé l'application vers Applications, effacez le drapeau une fois, puis ouvrez-la normalement :

xattr -dr com.apple.quarantine "/Applications/OpenHands Agent Canvas.app"

La signature + la notarisation sont suivies dans OpenHands/OpenHands#16774.

OpenHands v1.34.0

Highlights

  • Per-conversation Docker runtime — #18436 gives each conversation its own Docker runtime and adds a Settings → Runtime page to choose defaults. This is the headline capability: concurrent sessions no longer share one sandbox, so isolation is stronger and you can target different runtime images per task. Watch the resource cost (more containers per active conversation) and note that runtime selection is now conversation-scoped rather than global.
  • Compatibility floor raised to agent-server 1.57.0 — #18983 lifts minimumAgentServer; self-hosted installs pinned to an older agent-server will fail compatibility checks after upgrading, so bump the server first. The same maintenance line ships @openhands/extensions 0.36.0 and automation 1.26.0 (#18993) — refresh lockfiles accordingly.
  • Session API key moved off the command line — #16420 passes the static-server session key via env instead of argv. Good security hygiene: the key no longer shows up in ps output or process tooling, but any custom launcher that read it from argv must be updated to use the environment variable.
  • Automation KV survives session-key rotation — #18307 pins the automation KV secret so rotating session keys no longer makes stored KV data unreadable. If your automations persist state in KV, this is a data-durability fix worth verifying post-upgrade — previously a routine rotation could silently orphan that state.
  • Markdown and dependency security hardening — #17156 stops untrusted markdown from injecting rel="opener" or an arbitrary target (a reverse-tabnabbing vector in chat/transcript rendering), backed by DOMPurify and shell-quote bumps (#18990). Related correctness fixes: #18817 stops percent-encoded repo labels being decoded twice, and #18290 prevents raw i18n templates leaking on titleless ACP tool calls.
  • macOS installs trip Gatekeeper — v1.34.0 is not yet signed/notarized (#16774), so macOS may flag the download as "damaged." After copying to Applications, clear quarantine once with xattr -dr com.apple.quarantine "/Applications/OpenHands Agent Canvas.app" — relevant if you're distributing builds to macOS testers or automating installs.

No breaking changes.
