openclaude v0.34.0

0.34.0 (2026-11-02)

Features

  • add Keenable as an explicit web search backend (#2435) (e61e913)
  • add OrcaRouter gateway descriptor (#2125) (7b83353)
  • aimlapi: add opt-in MCP plugin with safe credential refresh (#2469) (42b108d)
  • attachments: make TODO reminders configurable (#2214) (23115eb)
  • ctx: add --save to /set-context-window to persist overrides (#2475) (beecf58)
  • ctx: show context-window source and active compaction triggers (#2473) (354ce5f), closes #2299
  • ctx: show why the last compaction happened (#2474) (d0b464e)
  • gateway: add Merge Gateway provider (#2317) (a13ed45)
  • gemini-vertex: native env routing and tool-id safety (2/3) (#1614) (c56c68f)
  • i18n: add Traditional Chinese (zh-HK) locale support (#2193) (cdb28e0)
  • integrations: add Runcrate as an OpenAI-compatible gateway (#2434) (3a8e12b)
  • minimax: default to M3.1 Flash and refresh text suggestions (#2297) (8be7274)
  • sdk: let a v2 session carry its own environment (#2268) (7ac848c)
  • skills: load skills from ~/.agents/skills and opt-in ~/.claude/skills (#2258) (#2283) (8ee936c)
  • web-fetch: add opt-in AI/ML API Toolbox scraping with restored test state (#2468) (f235c83)
  • web-search: add AI/ML API Toolbox with safe error reporting (#2465) (649c224)

Bug Fixes

  • add missing statement terminators flagged by CodeQL (#2448) (099cd50)
  • address AI code-quality findings in mcp remove, updater, Windows paths, and SDK packaging test (#2472) (e0d2bd9)
  • address remaining code-scanning alert sites (#2461) (eeff78a)

  • clarify declarations and redundant comparisons (#2441) (51f50e9)

  • clear resumed chat state and escape tool file paths (#2466) (072a921)
  • cli: keep standalone --model over saved provider profile model (#2471) (972cb0b)
  • complete full checks and repair baseline test failures (#2286) (0e9170f)
  • encode JSX apostrophes for CodeQL tokenization (#2455) (ec6bc3f)
  • fall back to global disabledMcpServers when project has none configured (#1935) (66cb795)
  • git: honor discovery ceilings in worktree fixtures (#2408) (6c8d22a)
  • hooks: reject unsupported command hook args (#2398) (cb4a72b)
  • ide: propagate VSIX download stream errors (#2443) (391c660)
  • launcher: tolerate missing bin helpers on distro installs (#2255) (#2256) (0e441ba)

  • ollama: send think=false by default so hybrid-reasoning models actually stop thinking (c884a88)
  • openai-shim: recover <tool_call> text tool calls on Ollama streams (#2476) (cd66554)
  • opencode: promote bare Codex alias launches to Codex backend (#2066) (#2171) (c860143)
  • plugins: suppress hooks throughout sparse clones (#2426) (2dddbb3)
  • provider: match MiniMax and Venice base URLs by hostname, not substring (#2099) (cdd6af6)

  • resolve eight reported AI quality findings (#2463) (977cb53)
  • sdk: surface the authenticate tool for a needs-auth MCP server (#2295) (4533f03)
  • sdk: wire options.hooks callbacks into the in-process hook executor (#2244) (5ef7183)

  • shell: honor an abort that lands before the listener is attached (#2321) (1c42a10)
  • simplify redundant UI conditions (#2449) (9876d04)

  • smart-routing: stop overriding sub-agent models chosen by agentRouting (#2310) (ec39d80)
  • stabilize settings writes and enable fork PR scans (#2290) (a0c5c7d)
  • stop tab-input crashes and other 0.34.0 regressions (#2479) (87cbb5c)
