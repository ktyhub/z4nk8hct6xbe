#sglang v0.5.10

Faits saillants

  • Graphique CUDA par morceaux activé par défaut : La capture de graphique CUDA par morceaux est désormais le mode d'exécution par défaut, réduisant la surcharge de mémoire et améliorant le débit pour les modèles avec des modèles de flux de contrôle complexes : #16331
  • Elastic EP pour une tolérance aux pannes partielles : intégrez Elastic NIXL-EP dans SGLang, permettant une tolérance aux pannes partielles pour les déploiements DeepSeek MoE : lorsqu'un GPU tombe en panne, le système redis rend hommage aux poids experts et continue de fonctionner sans redémarrage complet : #19248, #17374, #12068 blog
  • Tampon de transfert GPU pour la désagrégation PD : rassemble les tranches de tête dispersées dans la mémoire contiguë pour un transfert RDMA en masse, réduisant ainsi le nombre de requêtes RDMA sur les modèles GQA d'environ 1 000 fois. TPS/GPU sur une grande simultanéité augmenté d'environ 5x avec Prefill TP4+Decode DEP4 sur Qwen3.5 : #19890
  • HiSparse for Sparse Attention : intégrez le backend d'attention clairsemée HiSparse pour une inférence efficace sur un contexte long avec un calcul réduit grâce à une attention consciente de la parcimonie : #20343
  • Mise à jour SGlang-Diffusion :
    • Prise en charge des modèles : LTX-2, Hunyuan3D-2, Helios
    • Améliorations des performances sur l'image Qwen, l'image Z augmentée de 1,5x
    • Nouvelle plateforme : macOS
    • Nouvelle fonctionnalité : améliorez les performances du backend des diffuseurs en intégrant toutes les optimisations de Cache-DiT
    • COMPÉTENCES : n'hésitez pas à explorer les compétences sélectionnées pour développer et optimiser la diffusion du sglang !
  • Prise en charge du noyau FlashInfer MXFP8 : intégrez les noyaux FlashInfer mxfp8 pour les opérations GEMM et MoE, permettant une inférence FP8 de précision mixte avec une plus grande précision grâce à la microscaling pour les charges de travail RL et générales : #19537
  • Mise à niveau des transformateurs 5.3.0 : mise à niveau majeure des transformateurs 4.57.1 vers 5.3.0, déverrouillant la prise en charge des dernières architectures de modèles et fonctionnalités de HuggingFace. Le modèle GLM-5 est désormais pris en charge dans cette image au lieu de l'image personnalisée : #17784
  • Optimisation DeepSeek V3.2 / GLM-5 : GLM-5 exécutable sur la branche principale (avec transformateurs mis à niveau). Noyau Triton fusionné pour la récupération du cache KV de pré-remplissage, indexeur de magasin de fusibles NSA pour le cache K, noyaux DSA de pré-remplissage/décodage TRT-LLM par défaut sur SM100/SM103 et IndexCache pour un débit amélioré de plus de 10 % sur les charges de travail élevées : #19319, #19148, #20062, #21914, #21405
  • Optimisation Qwen3.5 GDN/KDA : transposez la disposition de l'état d'attention linéaire de [N, HV, K, V] à [N, HV, V, K] et fusionnez les opérations de fractionnement/remodelage/cat dans la projection GDN avec le noyau Triton, plus la prise en charge du noyau de décodage CuTeDSL KDA pour des performances Qwen3.5 améliorées : #20283, #21019, #21203
  • Prise en charge de LoRA pour les couches MoE : ajoutez la prise en charge du réglage précis de LoRA pour les couches de mélange d'experts avec des noyaux d'alignement JIT, des noyaux Triton fusionnés, la prise en charge de TP, la prise en charge de graphiques CUDA et la détection automatique des modules cibles LoRA — permettant un réglage efficace basé sur un adaptateur sur les modèles MoE comme DeepSeek : #19710, #19711, #14105, #21439, #21647.
  • Prefill Context Parallel for MHA (Qwen3) : activez le parallélisme de contexte pendant le pré-remplissage pour les modèles d'attention multi-têtes comme Qwen3 MoE, en distribuant de longues séquences sur les GPU pour réduire la mémoire par GPU et accélérer le pré-remplissage : #18233
  • Prise en charge de la bibliothèque officielle Flash Attention 4 : mise à niveau vers le package officiel FlashAttention 4, apportant les dernières optimisations d'attention et la prise en charge du GPU Blackwell : #20303
  • Skip-Softmax Attention pour les noyaux FlashInfer TRT-LLM : Réduisez la surcharge de calcul dans les couches d'attention en ignorant la normalisation softmax redondante : #19089
  • Décodage spéculatif avec le backend FA4 : activez le décodage spéculatif pour le backend d'attention FA4, combinant l'inférence spéculative avec l'attention flash de nouvelle génération pour une génération plus rapide : #21080
  • MM Attention FA4 par défaut sur SM100 : L'attention multimodale utilise désormais FA4 par défaut sur le matériel Blackwell pour des performances VLM améliorées : #21595
  • Backend de modélisation de transformateurs plus puissant : backend de transformateurs amélioré avec prise en charge complète de TP, PP, MoE, VLM et compatibilité torch.compile : #19163
  • sglang-kernel 0.4.1 : version majeure du paquet du noyau avec paquet renommé (sgl-kernel → sglang-kernel), noyaux consolidés et nettoyage des opérations obsolètes : #20440, #22009
  • Backend MLX natif pour Apple Silicon : ajoutez un backend d'exécution MLX natif permettant à SGLang d'exécuter l'inférence directement sur les Mac Apple Silicon sans CUDA : #20342

sglang v0.5.10

Highlights

  • Piecewise CUDA Graph Enabled by Default: Piecewise CUDA graph capture is now the default execution mode, reducing memory overhead and improving throughput for models with complex control flow patterns: #16331

  • Elastic EP for Partial Failure Tolerance: Integrate Elastic NIXL-EP into SGLang, enabling partial failure tolerance for DeepSeek MoE deployments — when a GPU fails, the system redistributes expert weights and continues serving without full restart: #19248, #17374, #12068 blog

  • GPU Staging Buffer for PD Disaggregation: Gathers scattered head slices into contiguous memory for bulk RDMA transfer, reducing RDMA request count on GQA models by ~1000x. TPS/GPU on large concurrency increased by ~5x with Prefill TP4+Decode DEP4 on Qwen3.5: #19890

  • HiSparse for Sparse Attention: Integrate HiSparse sparse attention backend for efficient long-context inference with reduced compute through sparsity-aware attention: #20343

  • SGLang-Diffusion Update:

    • Model support: LTX-2, Hunyuan3D-2, Helios
    • Performance improvements on Qwen-image, Z-image increased by 1.5x
    • New platform: macOS
    • New feature: enhance the performance of diffusers backend by integrating all optimization from Cache-DiT
    • SKILLs: feel free to explore the curated skill for developing and optimizing sglang-diffusion!

  • FlashInfer MXFP8 Kernel Support: Integrate FlashInfer mxfp8 kernels for GEMM and MoE operations, enabling mixed-precision FP8 inference with higher accuracy through microscaling for RL and general workloads: #19537

  • Transformers 5.3.0 Upgrade: Major upgrade from transformers 4.57.1 to 5.3.0, unlocking support for the latest model architectures and features from HuggingFace. GLM-5 model is now supported in this image instead of the custom built image: #17784

  • DeepSeek V3.2 / GLM-5 Optimization: GLM-5 runnable on main branch (with upgraded transformers). Fused Triton kernel for prefill KV cache fetching, NSA fuse store indexer for K cache, TRT-LLM prefill/decode DSA kernels as default on SM100/SM103, and IndexCache for improved throughput by more than 10% on high workloads: #19319, #19148, #20062, #21914, #21405

  • Qwen3.5 GDN/KDA Optimization: Transpose linear attention state layout from [N, HV, K, V] to [N, HV, V, K] and fuse split/reshape/cat ops in GDN projection with Triton kernel, plus CuTeDSL KDA decode kernel support for improved Qwen3.5 performance: #20283, #21019, #21203

  • LoRA Support for MoE Layers: Add LoRA fine-tuning support for Mixture-of-Experts layers with JIT alignment kernels, fused Triton kernels, TP support, CUDA graph support, and auto-detection of LoRA target modules — enabling efficient adapter-based tuning on MoE models like DeepSeek: #19710, #19711, #14105, #21439, #21647

  • Prefill Context Parallel for MHA (Qwen3): Enable context parallelism during prefill for multi-head attention models like Qwen3 MoE, distributing long sequences across GPUs to reduce per-GPU memory and accelerate prefill: #18233

  • Flash Attention 4 Official Library Support: Upgrade to the official FlashAttention 4 package, bringing the latest attention optimizations and Blackwell GPU support: #20303

  • Skip-Softmax Attention for FlashInfer TRT-LLM Kernels: Reduce computation overhead in attention layers by skipping redundant softmax normalization: #19089

  • Speculative Decoding with FA4 Backend: Enable speculative decoding for the FA4 attention backend, combining speculative inference with next-generation flash attention for faster generation: #21080

  • MM Attention FA4 Default on SM100: Multi-modal attention now uses FA4 by default on Blackwell hardware for improved VLM performance: #21595

  • Stronger Transformers Modeling Backend: Enhanced transformers backend with full TP, PP, MoE, VLM support, and torch.compile compatibility: #19163

  • sglang-kernel 0.4.1: Major kernel package release with renamed package (sgl-kernel → sglang-kernel), consolidated kernels, and cleanup of deprecated ops: #20440, #22009

  • Native MLX Backend for Apple Silicon: Add native MLX execution backend enabling SGLang to run inference directly on Apple Silicon Macs without CUDA: #20342
