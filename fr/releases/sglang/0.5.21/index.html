Principales fonctionnalités

  • Les instances PD peuvent basculer entre le pré-remplissage et le décodage à la volée, aucun redémarrage n'est nécessaire (#28403).
  • Le cache de préfixes s'exécute désormais par défaut sur un noyau Rust (#39627).
  • DeepSeek-V4.1 obtient un premier jeton 22 % plus rapide sur les invites longues (#40352).
  • Kimi K3 obtient un débit de préremplissage 20.6 % plus élevé dans la diffusion PD (#40045).
  • GLM-5.3-Flash fonctionne désormais sur AMD MI355X, avec décodage spéculatif FP8 / MXFP4 MoE et MTP (#38546, #39341, #39778).
  • Des résultats plus précis sous PP, DP attention et CP, avec une communication de couche désormais gérée par SGLang (guide, #41557).
  • Les nouvelles décisions API (/v1/decisions) transforment un LLM/VLM en un classificateur et un marqueur à faible latence (docs, #41208).
  • Le score API (/v1/score) note tous les candidats en une seule requête (#38965, #41188).
  • Exécutez MiniMax-H3 avec SGLang Diffusion dans ComfyUI (#35990).

Dernières modifications et notes de mise à niveau

  • L'arborescence de base unifiée utilise le noyau Rust par défaut. Configurations dans lesquelles le noyau Rust ne prend pas en charge le retour automatique au Python ; définissez SGLANG_UNIFIED_RADIX_TREE_CORE_BACKEND=python pour forcer le noyau Python partout : #39627
  • La finalisation fusionnée FlashInfer MoE est désactivée par défaut pour des raisons de précision numérique. Cela coûte une certaine latence W4A4 MoE ; définissez SGLANG_FLASHINFER_MOE_FUSED_FINALIZE=1 pour restaurer la finalisation atomique fusionnée : #40105
  • Le décodage PD diffère désormais par défaut la sortie de KV en cas d'abandon sur les backends Mooncake et NIXL, en conservant les pages jusqu'à ce que chaque classement de pré-remplissage soit confirmé (délai d'expiration de 30 s, SGLANG_DISAGGREGATION_DEFERRED_DECODE_KV_RELEASE_TIMEOUT). Configurez SGLANG_DISAGGREGATION_DEFERRED_DECODE_KV_RELEASE=False pour restaurer la version immédiate : #41023
  • Les modèles de discussion fournis par la demande sont rejetés. Une clé chat_template à l'intérieur de chat_template_kwargs sur /v1/chat/completions ou /v1/tokenize renvoie désormais une erreur à moins que le serveur ne démarre par --trust-request-chat-template ; les autres chat_template_kwargs sont inchangés : #28135
  • Les points de terminaison, variables d'environnement et alias obsolètes sont supprimés. Utilisez /model_info au lieu de /get_weight_version et /weight_version, /v1/loads au lieu de /get_load et POST /hicache/storage-backend/clear au lieu de /clear_hicache_storage_backend. Les alias SGLANG_NSA_* cèdent la place à SGLANG_DSA_*, SGLANG_ENABLE_SPEC_V2 a disparu, --elastic-ep-rejoin devient --elastic-ep-join-mode recover, --kv-cache-dtype fp4_e2m1 devient fp4_mx_block16 et python -m sglang.bench_offline_throughput / sglang.bench_one_batch passent à sglang.benchmark.offline_throughput / sglang.benchmark.one_batch : #40795
  • Les implémentations de cache de base héritées sont supprimées. L'arbre de base expérimental C++ (SGLANG_EXPERIMENTAL_CPP_RADIX_TREE) a disparu (#40775), et SGLANG_ENABLE_UNIFIED_RADIX_TREE ne fait plus rien, bien qu'il affiche toujours un avertissement de dépréciation (#40780). Le code important SWARadixCache, MambaRadixCache ou HiRadixCache doit être déplacé vers UnifiedRadixCache : #40313, #40787
  • Les processeurs logit personnalisés doivent renvoyer des logits de forme complète. Un CustomLogitProcessor qui renvoyait une forme réduite telle que (1, vocab) et s'appuyait sur la diffusion augmente désormais au moment du décodage. Les processeurs intégrés ne sont pas affectés : #39234
  • Les mises à jour de poids RL s'exécutent au cours d'une session. update_weights_from_tensor et update_weights_from_distributed doivent être appelés entre begin_weight_update() et end_weight_update(). UpdateWeightsFromTensorReqInput.disable_draft_model est remplacé par selector="target", et ChecksumInfo.parallelism_info est désormais une liste avec une entrée par rôle : #40777
  • Les getters à états parallèles sont obsolètes. Ils ne sont plus réexportés depuis sglang.srt.distributed ; lire les groupes via get_parallel() (par exemple get_parallel().tp_group) ou importer directement depuis parallel_state : #40342, #40344, #40707
  • Les images Ascend A2 (910b) ne sont plus publiées. Les images de sortie et de nuit sont expédiées pour A3 et 950 (A5) uniquement, sur CANN 9.1.0 avec Python 3.12 : #40524

Breaking Changes & Upgrade Notes

  • The unified radix tree uses the Rust core by default. Configurations the Rust core does not support fall back to Python automatically; set SGLANG_UNIFIED_RADIX_TREE_CORE_BACKEND=python to force the Python core everywhere: #39627
  • FlashInfer MoE fused finalize is off by default for numerical accuracy. This costs some W4A4 MoE latency; set SGLANG_FLASHINFER_MOE_FUSED_FINALIZE=1 to restore the fused atomic finalize: #40105
  • PD decode now defers KV release on abort by default on the Mooncake and NIXL backends, holding pages until every prefill rank acks (30 s timeout, SGLANG_DISAGGREGATION_DEFERRED_DECODE_KV_RELEASE_TIMEOUT). Set SGLANG_DISAGGREGATION_DEFERRED_DECODE_KV_RELEASE=False to restore immediate release: #41023
  • Request-supplied chat templates are rejected. A chat_template key inside chat_template_kwargs on /v1/chat/completions or /v1/tokenize now returns an error unless the server starts with --trust-request-chat-template; other chat_template_kwargs are unchanged: #28135
  • Deprecated endpoints, env vars, and aliases are removed. Use /model_info instead of /get_weight_version and /weight_version, /v1/loads instead of /get_load, and POST /hicache/storage-backend/clear instead of /clear_hicache_storage_backend. SGLANG_NSA_* aliases give way to SGLANG_DSA_*, SGLANG_ENABLE_SPEC_V2 is gone, --elastic-ep-rejoin becomes --elastic-ep-join-mode recover, --kv-cache-dtype fp4_e2m1 becomes fp4_mx_block16, and python -m sglang.bench_offline_throughput / sglang.bench_one_batch move to sglang.benchmark.offline_throughput / sglang.benchmark.one_batch: #40795
  • Legacy radix cache implementations are removed. The experimental C++ radix tree (SGLANG_EXPERIMENTAL_CPP_RADIX_TREE) is gone (#40775), and SGLANG_ENABLE_UNIFIED_RADIX_TREE no longer does anything, though it still prints a deprecation warning (#40780). Code importing SWARadixCache, MambaRadixCache, or HiRadixCache must move to UnifiedRadixCache: #40313, #40787
  • Custom logit processors must return full-shape logits. A CustomLogitProcessor that returned a reduced shape such as (1, vocab) and relied on broadcasting now raises at decode time. The built-in processors are unaffected: #39234
  • RL weight updates run inside a session. update_weights_from_tensor and update_weights_from_distributed must be called between begin_weight_update() and end_weight_update(). UpdateWeightsFromTensorReqInput.disable_draft_model is replaced by selector="target", and ChecksumInfo.parallelism_info is now a list with one entry per role: #40777
  • Parallel-state getters are deprecated. They are no longer re-exported from sglang.srt.distributed; read groups through get_parallel() (for example get_parallel().tp_group) or import from parallel_state directly: #40342, #40344, #40707
  • Ascend A2 (910b) images are no longer published. Release and nightly images ship for A3 and 950 (A5) only, on CANN 9.1.0 with Python 3.12: #40524
