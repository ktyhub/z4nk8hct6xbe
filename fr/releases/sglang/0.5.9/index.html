#sglang v0.5.9

Faits saillants

  • Chevauchement du chargement de poids LoRA avec calcul : chevauchement du chargement de poids LoRA avec le calcul pendant l'inférence, réduisant le TTFT d'environ 78 % et le TPOT de ~34.88 % sur les grands adaptateurs : #15512
  • Intégration du noyau TRT-LLM NSA pour DeepSeek V3.2 : intégration des noyaux DSA TRT-LLM pour Native Sparse Attention, augmentant les performances de DeepSeek V3.2 de 3 à 5 fois sur les plates-formes Blackwell avec trtllm pour --nsa-prefill-backend et --nsa-decode-backend (avec une légère baisse de précision) : #16758, #17662, #18389
  • Flashinfer All-to-All MoE Dispatcher : Ajoutez le répartiteur Flashinfer All-to-All MoE pour une communication efficace par parallélisme expert, permettant un routage optimisé dans les modèles MoE : #14668
  • Prise en charge FA4 (FP4 Attention) pour l'encodeur multimodal : introduction du backend d'attention FP4 et de la fonction d'attention de longueur variable pour les encodeurs multimodaux, permettant une inférence de moindre précision pour les modèles de langage de vision : #13539
  • Point de terminaison API compatible Anthropic : ajoutez la compatibilité native Anthropic API à SGLang, permettant une intégration directe avec les outils et clients conçus pour le format Anthropic API : #18630
  • Optimisations avancées SGLang-Diffusion : améliorations prêtes pour la production, notamment le partitionnement de séquence au niveau des jetons, le décodage VAE parallèle, les noyaux fusionnés, la prise en charge de Nunchaku et FP8 et plusieurs nouveaux modèles dans le plugin ComfyUI : blog
  • Correction d'un bug critique Spec V2 : Correction d'un bug hors index causé par le garbage collection de la torche dans le décodage spéculatif v2, améliorant la fiabilité de la vérification spéculative : #18958
  • Déploiement de DeepSeek sur GB300 NVL72 : travail d'optimisation pour l'inférence de contexte long à l'aide de la désagrégation pré-remplissage-décodage et d'autres fonctionnalités SGLang sur la dernière plate-forme GB300 de NVIDIA : blog
  • Modifier la version AITER vers 0.1.10.post3 : Prise en charge du pré-remplissage/décodage/cache KV FP8
  • Recherche de validation de version dans docs.sglang.io : trouvez facilement la première version officielle qui inclut un PR ou un commit donné, rationalisant ainsi le suivi des versions pour les utilisateurs et les développeurs : #18450, lien

sglang v0.5.9

Highlights

  • LoRA Weight Loading Overlap with Computation: Overlap LoRA weight loading with computation during inference, reducing TTFT by ~78% and TPOT by ~34.88% on large adaptors: #15512

  • TRT-LLM NSA Kernel Integration for DeepSeek V3.2: Integrate TRT-LLM DSA kernels for Native Sparse Attention, boosting DeepSeek V3.2 performance by 3x-5x on Blackwell platforms with trtllm for both --nsa-prefill-backend and --nsa-decode-backend (with minor accuracy drop): #16758, #17662, #18389

  • Flashinfer All-to-All MoE Dispatcher: Add the Flashinfer all-to-all MoE dispatcher for efficient expert parallelism communication, enabling optimized routing in MoE models: #14668

  • FA4 (FP4 Attention) Support for Multimodal Encoder: Introduce FP4 attention backend and variable-length attention function for multimodal encoders, enabling lower-precision inference for vision-language models: #13539

  • Anthropic Compatible API Endpoint: Add native Anthropic API compatibility to SGLang, allowing direct integration with tools and clients built for the Anthropic API format: #18630

  • SGLang-Diffusion Advanced Optimizations: Production-ready improvements including token-level sequence sharding, parallel VAE decoding, fused kernels, Nunchaku and FP8 support, and multiple new models in the ComfyUI plugin: blog

  • Spec V2 Critical bug fix: Fix out-of-index bug caused by torch garbage collection in speculative decoding v2, improving reliability of speculative verification: #18958

  • Deploying DeepSeek on GB300 NVL72: Optimization work for long-context inference using prefill-decode disaggregation and other SGLang features on NVIDIA's latest GB300 platform: blog

  • Bump AITER version to 0.1.10.post3: Support FP8 Prefill/Decode/KV Cache

  • Commit-to-Version Lookup in docs.sglang.io: Easily find the earliest official version that includes a given PR or commit, streamlining release tracking for users and developers: #18450, link
