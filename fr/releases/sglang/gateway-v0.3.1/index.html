🚀 SMG v0.3.1 sorti !

Nous sommes ravis d'annoncer SMG v0.3.1 – une version révolutionnaire avec une amélioration des performances de 10 à 12 fois et une réduction de 99 % de la mémoire dans le routage prenant en compte le cache, ainsi qu'une sécurité de niveau entreprise !

🌲 Radix Tree / Routage basé sur le cache : 10 à 12 fois plus rapide + 99 % de mémoire en moins ⚡

Refonte complète de l'optimisation de notre moteur de routage sensible au cache avec des performances et des gains de mémoire époustouflants :

Améliorations des performances

  • Notre routage prenant en compte le cache peut désormais gérer plus de 216 000 insertions de cache par seconde (contre 18 900 auparavant), avec une latence passant de 52.9 microsecondes à seulement 4.6 microsecondes par opération.
  • Pour la correspondance de préfixes sur 10 000 entrées d'arborescence, le débit est passé de 41 000 à 124 000 opérations par seconde.
  • Sous charge simultanée avec 64 threads, le système traite 474 000 opérations par seconde, soit une amélioration de 7,9 fois par rapport aux 59 000 opérations/s précédentes.

Traitement des données

  • Les opérations INSERT traitent désormais 440 Mo/s (contre 38 Mo/s),
  • Les opérations MATCH gèrent 253 Mo/s (au lieu de 83 Mo/s).

Améliorations de la mémoire :

  • ~99 % de réduction de mémoire par nœud d'arborescence :
  • Avant : ~180 Ko par nœud (configuration par défaut de DashMap sur les machines à 170 cœurs)
  • Après : ~1.4 Ko par nœud Résultat : déployez 100 fois plus d'entrées de cache dans la même empreinte mémoire ! Pour un déploiement typique avec 10 000 préfixes mis en cache, l'utilisation de la mémoire passe de ~1.8 Go à seulement ~14 Mo, libérant ainsi des ressources pour les charges de travail d'inférence réelles. Impact : le routage prenant en compte le cache est désormais 10 à 12 fois plus rapide et utilise 99 % de mémoire en moins. Ceci est essentiel pour les déploiements multi-tenants à grande échelle.

🔐 Authentification JWT/OIDC

Sécurité de niveau production pour les plans de contrôle API avec prise en charge native des fournisseurs OIDC standard du secteur : Google, Azure, Oracle, GitHub, et plus encore. Protégez la gestion du tokenizer, l'enregistrement des travailleurs et les points de terminaison d'administration avec l'infrastructure d'authentification d'entreprise que vous utilisez déjà. Essentiel pour les déploiements en entreprise : intégrez de manière transparente SMG à vos systèmes de gestion des identités et des accès existants.

📊Classification API Prise en charge

Prise en charge native des charges de travail de classification ! Déployez et servez des modèles de classification parallèlement à votre parc d'inférences existant avec des étapes de pipeline et des types de protocoles dédiés.

✨ Fonctionnalités supplémentaires

  • PrefixHash Load Balancing : nouvelle politique d'équilibrage de charge KV prenant en compte le cache et utilisant le hachage de préfixe pour améliorer les taux de réussite du cache dans les environnements multi-locataires.
  • Analyseur Nemotron Nano V3
  • Métriques d'âge des demandes en vol : suivez l'âge des demandes en vol pour une meilleure observabilité et une meilleure surveillance des SLA.

sglang gateway-v0.3.1

🚀 SMG v0.3.1 Released!

We're excited to announce SMG v0.3.1 – a game-changing release with 10-12x performance improvement and 99% memory reduction in cache-aware routing, plus enterprise-grade security!

🌲 Radix Tree / Cache-Aware Routing: 10-12x Faster + 99% Less Memory ⚡

Complete optimization overhaul of our cache-aware routing engine with stunning performance and memory gains:

Performance Improvements

  • Our cache-aware routing can now handle over 216,000 cache insertions per second (up from 18,900), with latency dropping from 52.9 microseconds to just 4.6 microseconds per operation.
  • For prefix matching across 10,000 tree entries, throughput jumped from 41,000 to 124,000 operations per second.
  • Under concurrent load with 64 threads, the system processes 474,000 operations per second – a 7.9x improvement over the previous 59,000 ops/sec.

Data processing

  • INSERT operations now process 440 MB/s (up from 38 MB/s),
  • MATCH operations handle 253 MB/s (up from 83 MB/s).

Memory Improvements:

  • ~99% memory reduction per tree node:
  • Before: ~180 KB per node (DashMap default config on 170-core machines)
  • After: ~1.4 KB per node Result: Deploy 100x more cache entries in the same memory footprint! For a typical deployment with 10,000 cached prefixes, memory usage drops from ~1.8 GB to just ~14 MB – freeing up resources for actual inference workloads. Impact: Cache-aware routing is now 10-12x faster and uses 99% less memory. This is critical for large-scale multi-tenant deployments.

🔐 JWT/OIDC Authentication

Production-grade security for control plane APIs with native support for industry-standard OIDC providers: Google, Azure, Oracle, GitHub, and more. Protect tokenizer management, worker registration, and admin endpoints with enterprise authentication infrastructure you already use. Critical for enterprise deployments – seamlessly integrate SMG into your existing identity and access management systems.

📊 Classification API Support

Native support for classification workloads! Deploy and serve classification models alongside your existing inference fleet with dedicated pipeline stages and protocol types.

✨ Additional Features

  • PrefixHash Load Balancing: New KV cache-aware load balancing policy using prefix hashing for improved cache hit rates in multi-tenant environments.
  • Nemotron Nano V3 Parser
  • In-Flight Request Age Metrics: Track request age in-flight for better observability and SLA monitoring.

🛠️ Enhancements

Developer Experience:

  • Organized CLI arguments into logical groups
  • Shortened logging targets (sgl_model_gateway → smg)
  • Comprehensive embedding correctness tests against HuggingFace
  • Auto-generate protobuf files during wheel build

Reliability:

  • Fix IGW routing for external OpenAI workers
  • Work around orphan process problems
  • Prevent potential hangs in subprocess handling
  • Use 504 Gateway Timeout for upstream timeouts (proper HTTP semantics)

🐛 Bug Fixes

  • Fixed embedding worker health check crash
  • Fixed tokenizer to match transformers special token handling
  • Fixed age bucket rendering issue
  • Fixed non-PD router HTTP header whitelist
  • Fixed duplicate classify prefix in response ID
  • Fixed WASM test errors on machines with many cores

⚡ Built for speed. Engineered for scale. Production-proven.
