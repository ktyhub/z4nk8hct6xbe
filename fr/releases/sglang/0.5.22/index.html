Quoi de neuf

  • DeepSeek-V4.1 obtient un débit jusqu'à 2,3 fois plus élevé par GPU sur H200 et fonctionne désormais sur AMD MI350X/MI355X avec un débit jusqu'à 1,9 fois supérieur à celui de DSpark (#41251, #41308).
  • Qwen3.8-Flash-Next décode 12 % plus rapidement sur le B200 et GLM-5.3-Flash avec DFlash 10 % plus rapidement sur le B300 (#42175, #42489).
  • MiMo-V2.6-Pro obtient un débit de décodage de 1,85x avec DFlash sur B300 (#41886).
  • Les modèles se chargent 10 fois plus rapidement avec le nouveau chargeur InstantTensor (#40453).
  • La désagrégation PD permet d'obtenir jusqu'à 27 % de débit en plus et la moitié du TTFT p95 sur les charges de travail à invite longue (#40703).
  • HiSparse prend désormais en charge EAGLE et MTP pour le service en contexte long avec le cache KV dans la mémoire CPU (#37771).
  • GLM-5.2 et GLM-5.3 peuvent désormais combiner le parallélisme de contexte de décodage avec MTP, avec un décodage jusqu'à 2,1 fois plus rapide sur GLM-5.3 (#43735).
  • SGLang fonctionne désormais sur les Mac Apple Silicon avec le backend standard PyTorch, aux côtés de MLX (#36780).
  • MiniMax-H3 et Qwen-Image 2.1 fonctionnent désormais dans ComfyUI avec SGLang Diffusion, qui charge également les points de contrôle GGUF et LoRA communautaires (#43504, #43581, #42556, #39523, #42174).
  • Correctif important : les modèles linéaires hybrides pouvaient reprendre à partir de mauvais états mamba lorsque le décodage spéculatif et la sortie structurée étaient utilisés ensemble. Merci à @Wirick et Baseten de l'avoir trouvé (#43029).

Pour mettre à niveau

SGLang nécessite désormais Python 3.11 ou une version plus récente.

uv pip install --prerelease=allow sglang==0.5.22

Dernières modifications et notes de mise à niveau

  • SGLang nécessite Python 3.11 ou plus récent. Sur Python 3.10, pip install sglang n'échoue pas ; il correspond à la dernière version prenant en charge 3.10. Passez à Python 3.11+ (par exemple à partir du système Ubuntu 22.04 Python) pour obtenir cette version et les versions ultérieures : #43021
  • --enable-dp-attention est obsolète ; utilisez --attn-dp-size N. --dp-size ne compte désormais que les répliques de modèles. L'ancien --dp-size N --enable-dp-attention se résout toujours en --attn-dp-size N avec un avertissement ; la combinaison de répliques avec attention DP, ou la transmission des deux orthographes, est rejetée au démarrage : #41818. Sous le parallélisme du contexte DeepSeek, --dp-size N signifie toujours attention DP mais avertit désormais et sera rejeté après le 31/12/2026 : #42348
  • --disaggregation-decode-host-receive-threshold inverse son encodage. 1 (la nouvelle valeur par défaut) désactive la réception sur l'hôte et 0 signifie désormais toujours recevoir sur l'hôte. Les configurations qui ont réussi 0 pour le désactiver doivent réussir 1 : #43407
  • ChunkCache est supprimé. Avec --disable-radix-cache, les modèles hybrides-SWA et Mamba à pleine attention exécutent UnifiedRadixCache en mode désactivé et les modèles purement SWA exécutent PureSWARadixCache (#43198, #43199, #43200, #42354, #43201). Les sessions de streaming démarrent désormais uniquement sur UnifiedRadixCache ; Les caches pure-SWA, FlexKV et d'arborescence de plugins échouent au démarrage avec une erreur "non vérifié" (#42295), et la recherche de faisceau rejette également les modèles Mamba avec --disable-radix-cache (#42354)
  • Le backend du graphique CUDA de pré-remplissage tc_piecewise est supprimé. La transmission de --cuda-graph-backend-prefill tc_piecewise ou d'un paramètre tc_compiler génère désormais une erreur ; CUDA conserve breakable comme backend de graphique de pré-remplissage par défaut, et les autres plates-formes n'utilisent par défaut aucun graphique de pré-remplissage : #42287
  • Variables d'environnement renommées et retirées. SGLANG_AITER_MLA_DCP_DECODE_BACKEND devient SGLANG_AITER_MLA_DECODE_BACKEND et sa valeur par défaut passe de gluon à asm (#34537) ; SGLANG_OPT_SWA_RELEASE_LEAF_LOCK_AFTER_WINDOW devient SGLANG_OPT_RELEASE_PREFILL_SWA (#42657) ; les anciens noms continuent de fonctionner avec un avertissement de dépréciation. SGLANG_DSPARK_FAST_SAMPLING, SGLANG_DSPARK_FOLDED_SAMPLING et SGLANG_DSPARK_OPT_FUSED_GREEDY_MARKOV sont obsolètes et ne font plus rien (#43622, #43668), et SGLANG_TRITON_PREFILL_TRUNCATION_ALIGN_SIZE est obsolète : #43444
  • Les réponses du chat OpenAI ont changé de trois petites manières. tool_choice: "none" n'affiche plus les schémas d'outils pour les modèles DeepSeek (#43006), un champ tool_calls absent est omis au lieu d'être renvoyé sous la forme null (#43027), et un flux conserve un horodatage created pendant toute sa durée de vie : #43026
  • --enable-layernorm-sp est rejeté avec le parallélisme du pipeline. Il a échoué lors du premier pré-remplissage avant : #43458
  • Pour les auteurs de modèles et de plugins : ModelRunner.tp_group est supprimé ; lisez get_parallel().tp_group dans la portée dans laquelle le code s'exécute (#41817). Les attributs de placement non lus tels que model.tp_size ont disparu ; lire get_parallel() (#41812). Un modèle qui déclare les limites des étapes et s'exécute sous le parallélisme du pipeline doit transmettre sa déclaration d'étape partagée (stage_facts) à make_layers / make_pp_layers : #43460

What's new

  • DeepSeek-V4.1 gets up to 2.3x more throughput per GPU on H200, and now runs on AMD MI350X / MI355X with up to 1.9x throughput from DSpark (#41251, #41308).
  • Qwen3.8-Flash-Next decodes 12% faster on B200, and GLM-5.3-Flash with DFlash 10% faster on B300 (#42175, #42489).
  • MiMo-V2.6-Pro gets 1.85x decode throughput with DFlash on B300 (#41886).
  • Models load 10x faster with the new InstantTensor loader (#40453).
  • PD disaggregation gets up to 27% more throughput and half the p95 TTFT on long-prompt workloads (#40703).
  • HiSparse now supports EAGLE and MTP for long-context serving with the KV cache in CPU memory (#37771).
  • GLM-5.2 and GLM-5.3 can now combine decode context parallelism with MTP, with up to 2.1x faster decoding on GLM-5.3 (#43735).
  • SGLang now runs on Apple Silicon Macs with the standard PyTorch backend, alongside MLX (#36780).
  • MiniMax-H3 and Qwen-Image 2.1 now run in ComfyUI with SGLang Diffusion, which also loads community GGUF checkpoints and LoRAs (#43504, #43581, #42556, #39523, #42174).
  • Important fix: Hybrid linear models could resume from wrong mamba states when speculative decoding and structured output were used together. Thanks to @Wirick and Baseten for finding it (#43029).

Breaking Changes & Upgrade Notes

  • SGLang requires Python 3.11 or newer. On Python 3.10, pip install sglang does not fail; it resolves to the last release that supported 3.10. Move to Python 3.11+ (for example off the Ubuntu 22.04 system Python) to get this and later releases: #43021
  • --enable-dp-attention is deprecated; use --attn-dp-size N. --dp-size now counts model replicas only. The old --dp-size N --enable-dp-attention still resolves to --attn-dp-size N with a warning; combining replicas with attention DP, or passing both spellings, is rejected at startup: #41818. Under DeepSeek context parallelism, --dp-size N still means attention DP but now warns and will be rejected after 2026-12-31: #42348
  • --disaggregation-decode-host-receive-threshold flips its encoding. 1 (the new default) disables host receive and 0 now means always receive on host. Configurations that passed 0 to disable it must pass 1: #43407
  • ChunkCache is removed. With --disable-radix-cache, full-attention, hybrid-SWA and Mamba models run UnifiedRadixCache in disabled mode and pure-SWA models run PureSWARadixCache (#43198, #43199, #43200, #42354, #43201). Streaming sessions now start only on UnifiedRadixCache; pure-SWA, FlexKV and plugin tree caches fail at startup with a "not verified" error (#42295), and beam search rejects Mamba models with --disable-radix-cache too (#42354)
  • The tc_piecewise prefill CUDA graph backend is removed. Passing --cuda-graph-backend-prefill tc_piecewise or a tc_compiler setting now raises an error; CUDA keeps breakable as the default prefill graph backend, and other platforms default to no prefill graph: #42287
  • Renamed and retired environment variables. SGLANG_AITER_MLA_DCP_DECODE_BACKEND becomes SGLANG_AITER_MLA_DECODE_BACKEND and its default changes from gluon to asm (#34537); SGLANG_OPT_SWA_RELEASE_LEAF_LOCK_AFTER_WINDOW becomes SGLANG_OPT_RELEASE_PREFILL_SWA (#42657); the old names keep working with a deprecation warning. SGLANG_DSPARK_FAST_SAMPLING, SGLANG_DSPARK_FOLDED_SAMPLING and SGLANG_DSPARK_OPT_FUSED_GREEDY_MARKOV are deprecated and no longer do anything (#43622, #43668), and SGLANG_TRITON_PREFILL_TRUNCATION_ALIGN_SIZE is deprecated: #43444
  • OpenAI chat responses changed in three small ways. tool_choice: "none" no longer shows tool schemas to DeepSeek models (#43006), an absent tool_calls field is omitted instead of returned as null (#43027), and a stream keeps one created timestamp for its whole lifetime: #43026
  • --enable-layernorm-sp is rejected with pipeline parallelism. It failed on the first prefill before: #43458
  • For model and plugin authors: ModelRunner.tp_group is removed; read get_parallel().tp_group in the scope the code runs in (#41817). Unread placement attributes such as model.tp_size are gone; read get_parallel() (#41812). A model that declares stage boundaries and runs under pipeline parallelism must pass its shared stage declaration (stage_facts) to make_layers / make_pp_layers: #43460
