#sglang v0.5.15

Faits saillants

GLM-5.2 NVFP4, réglé pour la production : Nous avons pris le temps ce cycle pour régler le GLM-5.2 NVFP4 sur Blackwell pour un service de production optimisé. Il fonctionne désormais à 500+ tok/s/utilisateur sur 8x B300, 450 sur 4x GB300 (bs=1). Exécutez GLM-5.2 avec notre livre de recettes.

  • Spec V2 par défaut : planification sans surcharge via l'extension de brouillon DSA graphable CUDA, synchronisations D2H/H2D abandonnées, opérations de métadonnées fusionnées. +11 % de TPS de bout en bout (#29413, #29343, #29166, #29077).
  • IndexShare MTP : réutilise le top-k de l'indexeur à travers les étapes de brouillon, jusqu'à 1,9 fois moins cher par étape de brouillon dans un contexte long (#29959, #29787, #29654).
  • TopK V2 : fusionne la sélection top-k avec la transformation page-table, durée d'exécution k jusqu'à 2048 (#30274, #26788).
  • Fusion du prologue de l'indexeur : 12 noyaux à 4, décodage ~8 % plus rapide à bs=1 (#27705).
  • GEMM : routeur JIT spécialisé en forme GEMM + CuteDSL BF16 GEMM pour Blackwell (#21531, #30117).
  • Réglage automatique FlashInfer : couvre désormais les graphiques de modèle brouillon (#29595). Prise en charge d'un nouveau modèle : Hunyuan 3 (Hy3), modèle de raisonnement hiérarchique (texte HRM), NVIDIA LocateAnything-3B, Baidu Unlimited-OCR, JoyEcho multi-shot A/V, plus prise en charge de Qwen3.6 NVFP4. Recherche Web native (Exa) : prise en charge intégrée de web_search soutenue par Exa (#29342). Breakable CUDA Graph activé par défaut : Breakable CUDA Graph est désormais le chemin de capture par défaut, réduisant ainsi la surcharge de lancement du noyau par étape (#29458) ; La prise en charge complète de CUDA Graph pour la phase de pré-remplissage est considérée comme expérimentale (#27988). Noyaux à attention linéaire (KDA / GDN) : nouveau backend de pré-remplissage FlashKDA pour l'attention linéaire KDA de sécurité (#29472), plus décodage en sortie tampon ReplaySSM uniquement pour l'attention linéaire (#28451). FlashInfer A2A pour MoE routé : ajoute FlashInfer tout-à-tout avec le coureur MoE flashinfer_trtllm_routed (#22394). Optimisation DeepSeek-V4 :
  • Optimise l'allocation du pool d'états C128 à l'aide du pool d'états de requête (#28612).
  • Le pré-remplissage clairsemé FlashMLA est désormais activé par défaut pour DeepSeek-V4, atteignant un gain de débit > 10 % sur un contexte long. (#29775).
  • Prise en charge de l'indexeur non paginé pour le pré-remplissage de contexte long, avec un gain de débit e2e > 5 %. ([#29619] (https://github.com/sgl-project/sglang/pull/29619)). Decode Context Parallelism : décode le parallélisme de contexte pour les modèles MLA, y compris les séries DeepSeek V3 et Kimi K2 (#14194). Mises à niveau des dépendances : transformers est remplacé par 5.12.1 (#29393) ; tvm-ffi / sgl-deep-gemm / tilelang mis à niveau (#29554). et . Voir le [Livre de recettes DeepSeek-V4] (https://docs.sglang.io/cookbook/autoregressive/DeepSeek/DeepSeek-V4).

sglang v0.5.15

Highlights

GLM-5.2 NVFP4, tuned for production: We took time this cycle to tune GLM-5.2 NVFP4 on Blackwell for optimized production serving. It now runs at 500+ tok/s/user on 8x B300, 450 on 4x GB300 (bs=1). Run GLM-5.2 with our cookbook.

  • Spec V2 by default: zero-overhead scheduling via CUDA-graphable DSA draft-extend, dropped D2H/H2D syncs, fused metadata ops. +11% end-to-end TPS (#29413, #29343, #29166, #29077).
  • IndexShare MTP: reuses the indexer top-k across draft steps, up to 1.9x lower draft-step cost at long context (#29959, #29787, #29654).
  • TopK V2: fuses top-k selection with the page-table transform, runtime k up to 2048 (#30274, #26788).
  • Indexer prologue fusion: 12 kernels to 4, ~8% faster decode at bs=1 (#27705).
  • GEMM: shape-specialized JIT router GEMM + CuteDSL BF16 GEMM for Blackwell (#21531, #30117).
  • FlashInfer autotune: now covers draft-model graphs (#29595).

New Model Support: Hunyuan 3 (Hy3), Hierarchical Reasoning Model (HRM-Text), NVIDIA LocateAnything-3B, Baidu Unlimited-OCR, JoyEcho multi-shot A/V, plus Qwen3.6 NVFP4 support.

Native web search (Exa): Built-in web_search support backed by Exa (#29342).

Breakable CUDA Graph on by default: Breakable CUDA Graph is now the default capture path, reducing per-step kernel-launch overhead (#29458); full CUDA Graph support for the prefill phase lands as experimental (#27988).

Linear-attention kernels (KDA / GDN): New FlashKDA prefill backend for safe-gate KDA linear attention (#29472), plus ReplaySSM buffered output-only decode for linear attention (#28451).

FlashInfer A2A for routed MoE: Adds FlashInfer all-to-all with the flashinfer_trtllm_routed MoE runner (#22394).

DeepSeek-V4 Optimization:

  • Optimizes C128 state-pool allocation using the request state pool (#28612).
  • FlashMLA sparse prefill is now enabled by default for DeepSeek-V4, reaching >10% throghput gain on long context. (#29775).
  • Non paged indexer support for long context prefill, with >5% e2e throughput gain.(#29619).

Decode Context Parallelism: decode context parallelism lands for MLA models, including DeepSeek V3 and Kimi K2 series (#14194).

Dependency upgrades: transformers bumped to 5.12.1 (#29393); tvm-ffi / sgl-deep-gemm / tilelang upgraded (#29554). and . See the DeepSeek-V4 cookbook.
