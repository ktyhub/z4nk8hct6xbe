AutoGPT autogpt-platform-beta-v0.6.11

Highlights

  • Claude 4 model options — Claude 4 Sonnet and Opus are now available on the platform (#10018), expanding model choices for agent workflows. Benchmark cost and latency before switching existing agents, since model selection materially affects both.
  • Execution reliability and observability — The executor now stays running and retries message consumption (#9999), reducing disruption from transient consumption failures. Webhook-triggered executions are included in GraphExecution queries (#9984), and termination correctly updates execution state (#9952), making run history and stop behavior more dependable.
  • Graph performance — Graph creation and updates (#10025) and query indexes (#10038) are optimized, reducing overhead when editing large graphs or repeatedly querying execution data.
  • Integration and block robustness — Twitter and Todoist blocks are disabled when OAuth is unconfigured (#9954), making missing setup explicit rather than a runtime surprise. UserIntegrations parsing now tolerates missing/None values (#9994), GitHub block URL handling is fixed (#9989), and AddMemoryBlock JSON serialization failures are resolved (#10013).
  • Diagnostics and frontend behavior — SendWebRequestBlock and Exa now provide clearer errors (#10009, #10020), while WebSocket toasts, loading spinners, and page titles improve operational feedback (#9949, #9993, #9995). Marketplace publishers must now select a category (#10031), and the restored “See runs” action (#9970) makes listing executions accessible again.
  • Breaking changes — None listed.
