AutoGPT autogpt-platform-beta-v0.6.67

Highlights

  • Organization/workspace tenancy — #12670 adds tenancy schema, authentication, APIs, migration, and frontend support. Treat this as a data-model migration: validate workspace-scoped API calls and bot organization resolution after upgrading. Expect stricter personal-org uniqueness (#13552) and corrected development environment org lookups (#13564).

  • Adapter contract changes — #13505 replaces the shared adapter base with separate Socket and Webhook bases and reduces shared-core coupling. Custom adapters must migrate to the appropriate base and adopt the extracted attachment, mention, history, and chunking helpers from #13506.

  • Slack and Telegram bot support — Slack gains webhook/Events API integration and multi-workspace OAuth installation (#13508, #13514). Telegram joins the chat bus with streaming draft-style reply previews (#13561, #13565). Check LaunchDarkly per-platform visibility before rollout (#13563), alongside Slack exposure in settings and analytics (#13509).

  • Preview and batch-bot automation — Active previews now redeploy automatically when their PR updates (#13485), reducing stale review environments. Batch-bot backfills, rollup processing, and head matching changed (#13512, #13536, #13538), while the merge gate now uses a GitHub App identity (#13521); automation owners should review App permissions and gate behavior.

  • Revid credentials are no longer bundled — #13507 removes the built-in Revid credential. Configure a user-provided API key for affected workflows; deployments relying on the previous shared credential will stop working until updated.

  • SDK MCP tool availability changes — #13548 stops registering baseline-only TodoWrite on the SDK server. Clients must not assume this tool is available by default and should update tool discovery or conditional invocation accordingly.
