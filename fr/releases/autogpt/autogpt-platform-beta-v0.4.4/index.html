AutoGPT autogpt-platform-beta-v0.4.4

Highlights

  • Public API and marketplace execution — #9272 introduces an external API for driving AutoGPT programmatically, while #9267 lets users execute store-published agents without owning them. Together these turn the marketplace from a browse/install catalog into an invokable runtime: expect to design around auth and quota boundaries, and to test ownership-gated access explicitly, since "publicly executable" is now a first-class graph state rather than an edge case.

  • /store* → /marketplace* route rename — #9119 changes the URL namespace across the app. Any hardcoded links, bookmarks, webhooks, or client-side route constants will break on upgrade; update integrations and add redirects for old paths. This is the most likely source of broken deep links for adopters and is easy to miss if you only test in-app navigation.

  • Block-set churn — breaking for existing graphs — #9337 removes TwitterUnblockUserBlock and TwitterBlockUserBlock outright, and #9158 splits CodeExecutionBlock into InstantiationBlock and StepExecutionBlock. Grep serialized graph JSON for the old block ids and re-author affected graphs before migration. The additions are substantial: GitHub checks/statuses (#9271), Mem0 memory (#9285), Linear (#9269), multimedia/file and video blocks (#9320), and a username+password credential type that restores email and Reddit blocks (#9113).

  • Credits become first-class execution state — Auto-top-up (#9278) plus the PAYG top-up flow (#9050) and monthly top-ups now retargeting the balance (#9295) change billing behavior, while #9217 adds graph/node/execution ids to CreditTransaction rows so spend can be attributed per step and #9340 makes credit-spend failures fail the block instead of passing silently. Watch for graphs that previously treated credits as best-effort — they will now surface hard errors; the new billing portal entry point (#9264) is where users manage this.

  • Ollama setup gets simpler — #9287 and #9288 drop the requirement to configure an Ollama API key and remove the related onboarding steps; #9351 adds ollama_host to AIConversationBlock so you can target a custom endpoint. Self-hosted LLM setups are easier to bootstrap, but any automation that used "Ollama credentials present" as a readiness signal should be updated.

  • Frontend and dependency hardening — #9226 adds TypeScript type checking to the frontend, so stricter CI and possible new type errors are part of the upgrade; combine this with the Next.js security bump 14.2.20 → 14.2.21 (#9243) and the large production/dev dependency update batches. #9352 also adds default-value support in oneOf fields, which can change schema-driven form behavior, and #9138 fixes broken connections when copy-pasting agents — worth re-testing clone workflows.
