AutoGPT autogpt-platform-beta-v0.6.66

Highlights

  • Runtime upgrade to Node 24 LTS — (#13492) Self-hosters and CI pipelines must move to Node 24 before pulling this tag: the toolchain and locally built artifacts now target the 24.x line, so 20.x environments will hit engine checks or produce mismatched native builds. Treat this as a prerequisite migration step, not optional maintenance.

  • Security hardening in classic — (#13422, #13423) Outbound request handling now validates URLs and blocks SSRF vectors, and litellm is capped below the compromised 1.82.7 release. Anyone pinned to litellm ≥1.82.7 must roll back; the SSRF fix may reject previously accepted internal or redirect URLs, so audit custom integrations that call user-supplied endpoints before upgrading.

  • Discord file uploads land in AutoPilot — (#13427, #13464, #13470, #13424) You can finally attach files to AutoPilot turns from Discord, but the implementation details matter: uploads are session-scoped (readable only within the originating session) and must be referenced via read_workspace_file, not a host path. Output text blocks are also split so messages no longer run together — relevant if you parse bot replies.

  • New layout sidebar ships behind a flag — (#13365, #13474, #13479, #13493) The redesigned navigation and artifacts UI is opt-in via feature flag, with a separate flag still gating the copilot task-progress bar (#13476). The tour sidebar is now ungated (#13493) and the new chrome is hidden on unauthenticated pages (#13479) — expect a mixed UI until you deliberately flip the flags; anonymous visitors see no change.

  • Bot monetization and batch operations — (#13477, #13465) Bot turns are now subject to subscription paywall enforcement and rate limiting, so free-tier or unmetered automations will start seeing turns rejected — the main behavioral change for existing bot users. The new /batch, /batch-remove, and /batch-merge commands (#13465) let you deploy bot fleets in one shot; consolidate repeated per-bot deploy calls into these commands.

  • State and execution correctness — (#12673, #13438, #13482, #12899, #13452) Several long-running pain points are fixed: classic preserves action history across task continuations (#12673), encrypted reasoning items are replayed so OpenAI tool loops survive (#13438), save-and-run executes the freshly saved graph instead of a stale version (#13482), connect_integration no longer hallucinates the wrong provider (#12899), and cancelled streams stop leaking their pending buffer while emitting an SSE drain hint (#13452). Remove any workarounds you built for these behaviors.
