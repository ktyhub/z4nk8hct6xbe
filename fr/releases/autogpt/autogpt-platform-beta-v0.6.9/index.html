AutoGPT autogpt-platform-beta-v0.6.9

Highlights

  • Fault-tolerant execution recovery — #9903 lets a replacement executor resume interrupted or unacknowledged runs from persisted RUNNING/QUEUED node executions instead of restarting the graph; runs may remain nonterminal until recovery. Custom executor integrations must account for the removal of GraphExecutionEntry.start_node_execs, and side-effecting nodes should remain retry-safe.
  • Nested credentials, stricter graph saves — #9862 extends Graph.credentials_input_schema to subgraphs and propagates node_credentials_input_map through AgentExecutionBlock and queued nodes, making Library agents with nested credential-dependent blocks usable. #9858 rejects saves with unset discriminator fields, such as model choice, so update imported or custom graph JSON before publishing.
  • User-wide execution limits — #9901/#9902 block execution at zero balance and make node-execution counts global per user rather than per agent; #9921 continues usage accounting for aborted or broken runs. Revisit quota assumptions and balance monitoring: consumption by one agent now reduces the allowance available to a user’s other agents.
  • Late-execution monitoring — #9914 adds a scheduled check with a configurable lateness threshold that reports overdue executions to Sentry; #9925 immediately alerts when that check job itself fails. Tune the threshold to your workload and verify alert routing. #9919 also restores Scheduler.get_execution_schedules.
  • Cloud-only Turnstile enforcement — #9847 adds Cloudflare Turnstile to login, signup, and password reset when BEHAVE_AS=CLOUD, verified server-side through /api/turnstile/verify. Configure NEXT_PUBLIC_CLOUDFLARE_TURNSTILE_SITE_KEY and CLOUDFLARE_TURNSTILE_SECRET_KEY, and update authentication E2E tests for the challenge; BEHAVE_AS=LOCAL deployments remain unaffected.
  • Google Sheets disabled in production — #9906 disables the Google Sheets OAuth scopes in production following OAuth review. Production workflows using the Sheets block should be migrated or disabled until a compliant support path ships; this is an availability regression, not merely dependency cleanup.
