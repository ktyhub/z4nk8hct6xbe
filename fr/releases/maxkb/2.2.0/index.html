MaxKo v2.2.0

Release Note pour MaxKB v2.2.0 Community Edition

Dans MaxKB v2.2.0 Community Edition, concernant les Applications : les applications d'orchestration avancées ont ajouté des nœuds de boucle, des nœuds de reconnaissance d'intention, des nœuds texte-vidéo et des nœuds image-vidéo. Les applications simples prennent désormais en charge les fonctions MCP et d'appel d'outils, et disposent de nouvelles capacités de génération d'invites. Pour les Outils : MaxKB a lancé un tout nouveau magasin d'outils, permettant aux utilisateurs de sélectionner directement les outils requis sans auto-développement. En termes de Modèles : MaxKB a ajouté la prise en charge des modèles Texte-vers-Vidéo et Image-vers-Vidéo d'Alibaba Cloud BaiLian et Volcano Engine.
Pour le X-Pack Enhancement Package : MaxKB prend en charge les paramètres de méthode de connexion par défaut, permettant aux administrateurs de personnaliser les canaux de connexion par défaut du système (par exemple, connexion par mot de passe de compte, connexion tierce, etc.) en fonction des besoins de l'entreprise ; il prend également en charge depuis peu le paramètre permettant d'activer la vérification captcha après N tentatives de connexion infructueuses.

Nouvelles fonctionnalités

  • Outils : Ajout d'un magasin d'outils ;
  • Applications : ajout d'un nœud de boucle, d'un nœud d'arrêt et d'un nœud de continuation ;
  • Applications : ajout d'un nœud de reconnaissance d'intention ;
  • Applications : ajout d'un nœud texte-vidéo ;
  • Applications : ajout d'un nœud image-vidéo ;
  • Applications : les applications simples prennent désormais en charge les fonctions MCP et d'appel d'outils ;
  • Applications : ajout de la prise en charge de la génération d'invites ;
  • Applications : ajout du paramètre de commutateur « Output MCP/Tool Execution Process » ;
  • Applications : les nœuds d'affectation de variables prennent désormais en charge le type de données bool lors de l'attribution de valeurs ;
  • Applications : les informations de configuration MCP prennent en charge l'analyse des variables ;
  • Applications : les utilisateurs de conversation prennent en charge le paramètre permettant d'activer la vérification captcha après un nombre spécifié de tentatives infructueuses de connexion au compte (X-Pack) ;
  • Base de connaissances : prend en charge les paramètres pour les modèles qui gèrent les tâches de génération de questions ;
  • Modèles : le fournisseur Alibaba Cloud BaiLian a ajouté la prise en charge des modèles Text-to-Video et Image-to-Video ;
  • Modèles : le fournisseur de Volcano Engine a ajouté la prise en charge des modèles texte-vidéo et image-vidéo ;
  • Modèles : les modèles de reconnaissance vocale prennent en charge les paramètres de modèle ;
  • Connexion : ajout du paramètre de méthode de connexion par défaut (X-Pack) ;
  • Connexion : ajout d'un paramètre pour activer la vérification captcha après un nombre spécifié de tentatives de connexion utilisateur infructueuses (X-Pack) ;
  • Connexion : mise à niveau du captcha de connexion vers un mécanisme d'authentification avec fonctionnalité d'isolation des utilisateurs.

Optimisations des fonctionnalités

  • Page Q&A : Ajout d'une opération de raccourci "Retour en bas" ;
  • Base de connaissances : la liste de questions prend en charge le paramètre d'option « Afficher 1 000 éléments » ;
  • Applications : optimisation du style d'affichage de « Ajouter un composant » pour les applications d'orchestration avancées ;
  • Applications : optimisation des descriptions des invites système et des invites utilisateur ;
  • Gestion des ressources : Ajout de la prise en charge du filtrage par type dans les options de filtrage de la liste de ressources (X-Pack).

Corrections de bugs

  • Base de connaissances : Correction du problème où l'exportation d'une base de connaissances expirait et signalait une erreur lorsque la base de connaissances contenait une grande quantité de données (#3995) ;
  • Applications : Correction du problème où le processus de réflexion n'était pas renvoyé lors de l'utilisation de l'interface de l'application API pour les conversations (#4084) ;
  • Applications : Correction du problème où l'ordre d'affichage des méthodes de connexion dans les restrictions d'accès n'était pas trié par catégorie (#4049) ;
  • Applications : Correction du problème où le paramètre d'option "Limite de questions par Client" dans les Restrictions d'accès ne prenait pas effet (#4042) ;
  • Page Q&A : Correction du problème où le bouton d'envoi n'était pas affiché sur certains navigateurs du système iOS ;
  • Page Q&A : Correction du problème où l'actualisation du navigateur sur la page Q&A ouvrait la page de liste des applications après avoir défini les paramètres de l'interface des questions dans les paramètres de l'application (#4076) ;
  • Page Q&A : Correction du problème où le style de police du processus de réflexion était incorrect (#2792) ;
  • Modèles : Correction du problème où les paramètres du modèle de synthèse vocale du fournisseur Silicon Flow ne prenaient pas effet.

Anglais original / English original

MaxKB v2.2.0

Highlights

  • More controllable workflows — Loop, Break, Continue, and Intent Recognition nodes let advanced applications iterate, terminate cleanly, and route conversations by intent. Test loop termination paths before deploying long-running workflows.
  • MCP and tools in Simple Applications — Simple Applications now support MCP, tool calling, and prompt generation; MCP configuration also accepts variables, and variable assignment supports booleans. This reduces the need to graduate to advanced orchestration, but runtime variable resolution should be validated across environments.
  • Video generation and execution traces — Text-to-Video and Image-to-Video nodes work with new Alibaba Cloud Bailian and Volcano Engine models. Verify provider model IDs, credentials, and quotas; enable the “Output MCP/Tool Execution Process” switch only when clients should receive execution details.
  • API and reliability fixes — Conversation APIs again return the thinking process (#4084), “Question Limit per Client” is enforced (#4042), login methods sort correctly (#4049), Q&A refreshes retain the application view (#4076), and large knowledge-base exports avoid the reported timeout (#3995). Retest API response handling and client-side rate-limit behavior.
  • Enterprise login controls (X-Pack) — Administrators can choose the default login method and trigger captcha after a configurable number of failures; captcha verification is now user-isolated. Review thresholds and test account-password and third-party login flows after upgrading.
  • Breaking changes — None reported.

Release Notes for MaxKB v2.2.0 Community Edition

In MaxKB v2.2.0 Community Edition, regarding Applications: Advanced Orchestration Applications have added Loop Nodes, Intent Recognition Nodes, Text-to-Video Nodes, and Image-to-Video Nodes. Simple Applications now support MCP and tool calling functions, and have newly added prompt generation capabilities. For Tools: MaxKB has launched a brand-new Tool Store, allowing users to select required tools directly without self-development. In terms of Models: MaxKB has added support for Text-to-Video and Image-to-Video models from Alibaba Cloud BaiLian and Volcano Engine.

For the X-Pack Enhancement Package: MaxKB supports default login method settings, enabling administrators to customize the system’s default login channels (e.g., account-password login, third-party login, etc.) based on enterprise needs; it also newly supports setting to enable captcha verification after N failed login attempts.

New Features

  • Tools: Added Tool Store;
  • Applications: Added Loop Node, Break Node, and Continue Node;
  • Applications: Added Intent Recognition Node;
  • Applications: Added Text-to-Video Node;
  • Applications: Added Image-to-Video Node;
  • Applications: Simple Applications now support MCP and tool calling functions;
  • Applications: Added support for prompt generation;
  • Applications: Added "Output MCP/Tool Execution Process" switch setting;
  • Applications: Variable Assignment Nodes now support the bool data type when assigning values;
  • Applications: MCP configuration information supports variable parsing;
  • Applications: Conversation users support the setting to enable captcha verification after a specified number of failed account login attempts (X-Pack);
  • Knowledge Base: Supports parameter settings for models that handle question generation tasks;
  • Models: Alibaba Cloud BaiLian provider has added support for Text-to-Video and Image-to-Video models;
  • Models: Volcano Engine provider has added support for Text-to-Video and Image-to-Video models;
  • Models: Speech Recognition Models support model parameter settings;
  • Login: Added default login method setting (X-Pack);
  • Login: Added setting to enable captcha verification after a specified number of failed user login attempts (X-Pack);
  • Login: Upgraded the login captcha to an authentication mechanism with user isolation functionality.

Feature Optimizations

  • Q&A Page: Added a "Back to Bottom" shortcut operation;
  • Knowledge Base: The question list supports the "Show 1000 Items" option setting;
  • Applications: Optimized the display style of "Add Component" for Advanced Orchestration Applications;
  • Applications: Optimized the descriptions of system prompts and user prompts;
  • Resource Management: Added support for filtering by type in the resource list filter options (X-Pack).

Bug Fixes

  • Knowledge Base: Fixed the issue where exporting a knowledge base would time out and report an error when the knowledge base contains a large amount of data (#3995);
  • Applications: Fixed the issue where the thinking process was not returned when using the application API interface for conversations (#4084);
  • Applications: Fixed the issue where the display order of login methods in Access Restrictions was not sorted by category (#4049);
  • Applications: Fixed the issue where the "Question Limit per Client" option setting in Access Restrictions did not take effect (#4042);
  • Q&A Page: Fixed the issue where the send button was not displayed on some browsers in the iOS system;
  • Q&A Page: Fixed the issue where refreshing the browser on the Q&A page would open the application list page after setting the question interface parameters in the application settings (#4076);
  • Q&A Page: Fixed the issue where the font style of the thinking process was incorrect (#2792);
  • Models: Fixed the issue where the parameter settings for the speech synthesis model from the Silicon Flow provider did not take effect.
