MaxKo v2.6.0

Nouvelles fonctionnalités

  • Agent : ajout d'une capacité d'activation de déclencheur ;
  • Agent (X-Pack) : période de validité des paramètres pris en charge pour les clés d'agent API ;
  • Agent : ajout des attributs Adresse IP et Source à la liste des journaux de conversation ;
  • Agent : prise en charge de la définition de politiques de nettoyage indépendantes pour les fichiers téléchargés dans les journaux de conversation ;
  • Outils : Ajout de la capacité d'activation du déclencheur ;
  • Outils : Ajout de la fonction pour afficher les enregistrements d'exécution ;
  • Outils partagés (X-Pack) : Ajout de la fonction permettant d'afficher les enregistrements d'exécution ;
  • Déclencheurs : Ajout d'une fonction de gestion des déclencheurs pour le rôle d'administrateur de l'espace de travail ;
  • Base de connaissances : la base de connaissances générale, la base de connaissances du site Web et la base de connaissances Lark prennent toutes en charge la conversion directe vers la base de connaissances Workflow ;
  • Base de connaissances : Ajout de la prise en charge de l'exportation par lots de documents dans la liste des documents ;
  • Gestion du système (X-Pack) : période de validité des paramètres pris en charge pour les clés système API.

Optimisations des fonctionnalités

  • Agent : ajustement de la position du bouton Aller à la conversation dans le panneau Agent ;
  • Agent : ajout d'un paramètre Current Moment pour la valeur par défaut des paramètres de type de date saisis par les utilisateurs ; après réglage, le paramètre obtient dynamiquement l'heure actuelle sur la page Q&A ;
  • Modèles : ajout de la prise en charge de la saisie du paramètre API URL pour les modèles vidéo et les modèles de reconnaissance vocale d'Alibaba Cloud BaiLian ;
  • Modèles : les modèles vectoriels du fournisseur Volcano Engine prennent en charge l'amarrage avec des modèles vectoriels multimodaux ;
  • Modèles : les modèles de reconnaissance vocale du fournisseur Volcano Engine prennent en charge la méthode d'accueil de reconnaissance vocale pour les fichiers audio ;
  • Modèles : Ajout de la prise en charge de la définition du paramètre Type de réponse (par exemple, response_format=b64_json) dans les paramètres de modèle des modèles de génération d'images du fournisseur OpenAI ; #4538
  • Système : copie internationalisée optimisée et interfaces utilisateur partielles.

Corrections de bugs

  • Agent : correction du problème où les champs Nombre de segments référencés et Titre du segment + Contenu manquaient lors de l'exportation des journaux de conversation ;
  • Agent : Correction du problème où le processus d'appel n'était pas affiché si un outil dans les compétences n'avait pas de paramètres d'entrée lorsque le modèle d'IA appelait l'outil ;
  • Agent : Correction du problème de contenu de réponse IA désordonné lorsqu'un sous-agent dans un corps de boucle avait également un nœud de boucle (#4654) ;
  • Agent : Correction du problème où le contenu de la réponse de l'IA ne défilait pas automatiquement vers le bas pendant le débogage de l'agent (#4660) ;
  • Authentification de connexion (X-Pack) : Correction du problème où le nombre de tentatives de connexion infructueuses pour l'affichage du captcha ne pouvait pas être défini sur 0 ;
  • Modèles : Correction du problème où le modèle de reconnaissance vocale slm d'iFlytek Spark ne pouvait pas convertir la parole en texte ;
  • Modèles : Correction de l'erreur lors de la modification du modèle iat d'iFlytek Spark ;
  • Dossiers : Correction du problème où les utilisateurs disposant uniquement des autorisations d'affichage des dossiers pouvaient toujours créer des sous-dossiers (#4688).

MaxKB v2.6.0

Highlights

  • Trigger-driven automation — Agents and tools can now be activated through triggers, with workspace administrators able to manage them. This enables event-driven workflows across both capabilities; review administrator permissions before exposing trigger controls broadly.

  • Knowledge-base reuse and bulk export — General, web-site, and Lark knowledge bases can convert directly into workflow knowledge bases, while document lists support batch exports. Teams can reuse existing knowledge in workflows without rebuilding sources and move content at scale.

  • API-key lifecycle controls (X-Pack) — Agent and system API keys now support validity periods. This enables time-bounded credentials for integrations; review automated jobs and service accounts that depend on long-lived keys before enforcing expiration policies.

  • Broader model compatibility — Alibaba Cloud BaiLian video and speech-recognition models accept custom API URLs, Volcano Engine vector models support multimodal models, and OpenAI image generation supports response_format=b64_json (#4538). Verify downstream parsing when switching image responses to base64.

  • Better agent diagnostics and permissions — Tool execution records are now viewable, conversation logs include IP/source metadata, and exports restore referenced-segment fields. Nested loop replies (#4654) and folder creation by view-only users (#4688) are fixed; retest custom loops and accounts that previously relied on excessive folder permissions.

  • Breaking changes — None listed in this release.

New Features

  • Agent: Added trigger activation capability;
  • Agent (X-Pack): Supported setting validity period for Agent API Keys;
  • Agent: Added IP Address and Source attributes to the conversation log list;
  • Agent: Supported setting independent cleanup policies for uploaded files in conversation logs;
  • Tools: Added trigger activation capability;
  • Tools: Added the function to view execution records;
  • Shared Tools (X-Pack): Added the function to view execution records;
  • Triggers: Added trigger management function for the workspace administrator role;
  • Knowledge Base: General Knowledge Base, Web Site Knowledge Base, and Lark Knowledge Base all support direct conversion to Workflow Knowledge Base;
  • Knowledge Base: Added support for batch exporting documents in the document list;
  • System Management (X-Pack): Supported setting validity period for system API Keys.

Feature Optimizations

  • Agent: Adjusted the position of the Go to Conversation button to the Agent panel;
  • Agent: Added a Current Moment setting for the default value of date-type parameters entered by users; after setting, the parameter dynamically obtains the current time on the Q&A page;
  • Models: Added support for entering the API URL parameter for video models and speech recognition models of Alibaba Cloud BaiLian;
  • Models: Vector models of the Volcano Engine provider support docking with multimodal vector models;
  • Models: Speech recognition models of the Volcano Engine provider support the docking method of speech recognition for audio files;
  • Models: Added support for setting the Response Type parameter (e.g., response_format=b64_json) in the model parameters of image generation models of the OpenAI provider; #4538
  • System: Optimized internationalized copy and partial UI interfaces.

Bug Fixes

  • Agent: Fixed the issue where the Referenced Segment Count and Segment Title + Content fields were missing when exporting conversation logs;
  • Agent: Fixed the issue where the calling process was not displayed if a tool in skills had no input parameters when the AI model called the tool;
  • Agent: Fixed the issue of disordered AI reply content when a sub-agent in a loop body also had a loop node (#4654);
  • Agent: Fixed the issue where AI reply content did not automatically scroll to the bottom during Agent debugging (#4660);
  • Login Authentication (X-Pack): Fixed the issue where the number of failed login attempts for displaying captcha could not be set to 0;
  • Models: Fixed the issue where the slm speech recognition model of iFlytek Spark could not convert speech to text;
  • Models: Fixed the error when editing the iat model of iFlytek Spark;
  • Folders: Fixed the issue where users with only folder view permissions could still create subfolders (#4688).
