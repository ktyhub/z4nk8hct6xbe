MaxKo v2.1.0

Release Note

Nouvelles fonctionnalités

  • Outils : Ajout de la fonction de gestion des outils MCP.
  • Applications : ajout de paramètres d'outils pour les nœuds de conversation IA ; une fois que les utilisateurs ont sélectionné un outil personnalisé, le modèle peut décider indépendamment s'il doit appeler l'outil configuré.
  • Applications : les paramètres des nœuds de collection de formulaires prennent désormais en charge la référence de variable.
  • Applications : ajout de zones de texte multilignes, de téléchargement de fichiers et de composants de boîte à sélection multiple sur une seule ligne pour former des nœuds de collection.
  • Applications (X-Pack) : l'accès aux applications prend désormais en charge la connexion aux robots intelligents WeChat Work, permettant aux utilisateurs d'établir une liaison efficace entre les capacités d'IA et l'écosystème de bureau WeChat Work.
  • Applications (X-Pack) : Ajout de l'option "Afficher les enregistrements de l'historique" dans les paramètres d'affichage.
  • Page Q&A : Prise en charge de l'exportation des enregistrements de conversation en cours aux formats d'image PDF et PNG sur la page Q&A.
  • Base de connaissances : ajout de l'option de paramètre « Autoriser le téléchargement dans les sources de connaissances » pour les documents de la base de connaissances générale et de la base de connaissances Lark.
  • Autorisation des ressources : ajout d'une fonction d'autorisation au niveau des ressources, prenant en charge l'autorisation des ressources principales telles que les applications, les bases de connaissances, les outils et les modèles pour les utilisateurs spécifiés.
  • Autorisation des ressources : lors de l'autorisation de ressources par utilisateur dans la gestion du système, différentes autorisations peuvent être définies pour chaque ressource.
  • Modèles : ajout de la prise en charge des modèles de reclassement et des modèles de reconnaissance vocale au fournisseur vLLM.
  • Modèles : ajout de la prise en charge des modèles de reconnaissance vocale pour le fournisseur Tencent Hunyuan.
  • Modèles : Ajout de la prise en charge des grands modèles de parole chinoise aux modèles de reconnaissance vocale du fournisseur iFlytek Spark.
  • Modèles : Ajout de la prise en charge des modèles qwen-omni-turbo, qwen2.5-omni-7b et ASR aux modèles de reconnaissance vocale du fournisseur Alibaba Cloud BaiLian.
  • Modèles : ajout de la prise en charge de la méthode de connexion API version V2 au fournisseur Baidu Qianfan Large Model.

Améliorations

  • Applications : Ajout de la fonction d'interrogation par utilisateur dans la liste des journaux de conversation.
  • Applications (X-Pack) : Une fois qu'une application est connectée à Lark, le contenu de la réponse de l'IA est affiché au format Markdown.
  • Page Q&A : crée automatiquement une nouvelle conversation par défaut lors de l'accès à la page Q&A.
  • Page Q&A : optimisation du problème où une question par défaut est automatiquement générée lors du téléchargement de fichiers ou d'images.
  • Outils : Ajout d'une invite de confirmation secondaire lorsque cliclique sur le bouton "Fermer" ou "Annuler" lors de la création ou de la modification d'un outil.
  • Connexion : les utilisateurs doivent modifier leur mot de passe par défaut avant de continuer à utiliser le système après s'être connectés avec celui-ci.

Corrections de bugs

  • Applications : correction du problème où les nœuds MCP dans les applications d'orchestration avancées n'étaient pas internationalisés.
  • Applications : Correction du problème où les variables de session ne pouvaient pas être lues lorsqu'elles étaient utilisées après les nœuds de collecte de formulaire.
  • Page Q&A (X-Pack) : Correction du problème où le logo de l'application personnalisée n'était pas affiché dans l'onglet du navigateur.
  • Page Q&A (X-Pack) : Correction du problème où les informations d'authentification existantes restaient valides lors du changement de méthode d'authentification d'identité de l'application dans la fonction "Restriction d'accès".
  • Page Q&A : Correction du problème où le style d'affichage du contenu était perturbé lorsque clicliquait sur le bouton "Réduire" dans la zone de navigation de gauche.
  • Page Q&A : Correction du problème où une invite "paramètre manquant" apparaissait lorsqu'un utilisateur de conversation posait une question après s'être reconnecté.
  • Page Q&A : Correction du problème où les enregistrements de conversation n'étaient pas affichés dans la zone d'enregistrement de conversation lors du chargement des données d'enregistrement historique.
  • Page Q&A : Correction du problème où le téléchargement d'un fichier vide provoquait des erreurs d'extraction.
  • Page Q&A : Correction du problème où les balises s'affichaient anormalement lorsque le contenu des questions rapides était trop long.
  • Base de connaissances : Correction du problème où la zone de saisie sur l'interface de test d'impact était affichée de manière incomplète lorsque le système n'avait aucune autorisation de licence.
  • Base de connaissances : Correction du problème où il n'y avait pas de confirmation secondaire lorsque clicliquez sur le bouton "Retour" lors du téléchargement du document vers la base de connaissances.
  • Base de connaissances : Correction du problème où les résultats de recherche étaient incorrects lors de la recherche par contenu de segment dans les détails du segment de la base de connaissances.
  • Base de connaissances : correction du problème où le même segment pouvait être associé plusieurs fois à la même question.
  • Base de connaissances : correction du problème où le nombre de « Nombre de segments associés » était incorrect dans la liste de questions.
  • Modèles : Correction du problème où les modèles de la liste "Tous les modèles" n'étaient pas affichés par ordre décroissant d'heure de création.
  • Autorisation des ressources : correction du problème où les utilisateurs disposant uniquement de l'autorisation d'affichage de la base de connaissances pouvaient ajouter des segments dans les journaux de conversation.
  • Dossiers : Correction du problème où clicliquez sur le bouton "Retour" dans les détails des ressources des applications et des bases de connaissances revenait toujours au répertoire racine.
  • Utilisateurs de conversation (X-Pack) : Correction du problème où les mots de passe des utilisateurs n'étaient pas synchronisés lors de la synchronisation des utilisateurs du système.
  • Utilisateurs de conversation (X-Pack) : Correction du problème où un nouvel utilisateur de conversation pouvait être créé avec succès même sans définir de groupe d'utilisateurs.

Anglais original / English original

MaxKB v2.1.0

Highlights

  • MCP becomes a first-class, model-invoked tool — MCP tool management plus new tool settings on AI conversation nodes let the model decide autonomously whether to call a configured tool, rather than following a fixed graph. This is the move from deterministic orchestration to agent-style tool use; the fix for un-translated MCP nodes in advanced orchestration signals the two approaches coexist for now, so expect some UI rough edges.
  • Resource-level RBAC arrives, with a permission hole closed — Applications, knowledge bases, tools, and models can now be granted to specific users with per-resource permission levels. A companion fix stops users holding only "view" permission on a knowledge base from adding segments through conversation logs — audit this if you depended on view-only restrictions actually being enforced.
  • Speech and reranking expand across providers, Qianfan adds a V2 path — vLLM gains reranking and speech recognition, BaiLian adds qwen-omni-turbo / qwen2.5-omni-7b plus ASR, Hunyuan and iFlytek Spark gain speech models, and Baidu Qianfan supports API Version V2 connections. If you were working around missing ASR or reranking in a chosen provider, a native option may now exist — but the Qianfan V2 method likely needs a connection-config update rather than being a transparent swap.
  • Default-password enforcement is a behavioral change — Users logging in with the default password must change it before continuing. Factor this into automated deployments, demos, and test harnesses that seed accounts with default credentials, since scripts will now hit an interstitial instead of proceeding straight into the app.
  • Form collection nodes become usable as workflow steps — Parameters accept variable references and new components (multi-line text, file upload, single-line multi-select), and a fix restores session-variable reads after a form node. Together these make forms a real data-gathering step in longer conversations instead of a dead end where downstream state broke.
  • Q&A export and conversation lifecycle cleanup — Conversations can be exported to PDF and PNG, entering the Q&A page now auto-creates a conversation, and fixes address historical records not rendering, "missing parameter" prompts after re-login, and empty-file upload errors. Net result is a cleaner default UX, but re-authentication and history-loading flows are the areas to regression-test.

No breaking changes are listed in this release.

Release Notes

New Features

  • Tools: Added the MCP tool management function.
  • Applications: Added tool settings for AI conversation nodes; after users select a custom tool, the model can independently decide whether to call the configured tool.
  • Applications: Parameters of form collection nodes now support variable reference.
  • Applications: Added multi-line text boxes, file upload, and single-line multi-select box components to form collection nodes.
  • Applications (X-Pack): Application access now supports connection to WeChat Work intelligent robots, enabling users to achieve efficient linkage between AI capabilities and the WeChat Work office ecosystem.
  • Applications (X-Pack): Added the "Show History Records" option in display settings.
  • Q&A Page: Supported exporting current conversation records as PDF and PNG image formats on the Q&A page.
  • Knowledge Base: Added the "Allow Download in Knowledge Sources" setting option for documents in the general knowledge base and Lark knowledge base.
  • Resource Authorization: Added resource-level authorization function, supporting the authorization of core resources such as applications, knowledge bases, tools, and models to specified users.
  • Resource Authorization: When authorizing resources by user in system management, different permissions can be set for each resource.
  • Models: Added support for reranking models and speech recognition models to the vLLM provider.
  • Models: Added support for speech recognition models to the Tencent Hunyuan provider.
  • Models: Added support for Chinese speech large models to the speech recognition models of the iFlytek Spark provider.
  • Models: Added support for qwen-omni-turbo, qwen2.5-omni-7b, and ASR models to the speech recognition models of the Alibaba Cloud BaiLian provider.
  • Models: Added support for the API Version V2 connection method to the Baidu Qianfan Large Model provider.

Enhancements

  • Applications: Added the function of querying by user in the conversation log list.
  • Applications (X-Pack): After an application is connected to Lark, AI response content is displayed in Markdown format.
  • Q&A Page: Automatically creates a new conversation by default when entering the Q&A page.
  • Q&A Page: Optimized the issue where a default question is automatically generated when uploading files or images.
  • Tools: Added a secondary confirmation prompt when clicking the "Close" or "Cancel" button while creating or editing a tool.
  • Login: Users must change their default password before continuing to use the system after logging in with it.

Bug Fixes

  • Applications: Fixed the issue where MCP nodes in advanced orchestration applications were not internationalized.
  • Applications: Fixed the issue where session variables could not be read when used after form collection nodes.
  • Q&A Page (X-Pack): Fixed the issue where the custom application Logo was not displayed in the browser tab.
  • Q&A Page (X-Pack): Fixed the issue where existing authentication information remained valid when switching the application's identity authentication method in the "Access Restriction" function.
  • Q&A Page: Fixed the issue where the content display style was messed up when clicking the "Collapse" button in the left navigation area.
  • Q&A Page: Fixed the issue where a "missing parameter" prompt appeared when a conversation user asked a question after re-logging in.
  • Q&A Page: Fixed the issue where conversation records were not displayed in the conversation record area when loading historical record data.
  • Q&A Page: Fixed the issue where uploading an empty file caused extraction errors.
  • Q&A Page: Fixed the issue where tags were displayed abnormally when the content of quick questions was too long.
  • Knowledge Base: Fixed the issue where the input box on the hit test interface was displayed incompletely when the system had no License authorization.
  • Knowledge Base: Fixed the issue where there was no secondary confirmation when clicking the "Back" button during document upload to the knowledge base.
  • Knowledge Base: Fixed the issue where search results were incorrect when searching by segment content in the knowledge base segment details.
  • Knowledge Base: Fixed the issue where the same segment could be associated with the same question multiple times.
  • Knowledge Base: Fixed the issue where the "Number of Associated Segments" count was incorrect in the question list.
  • Models: Fixed the issue where models in the "All Models" list were not displayed in descending order of creation time.
  • Resource Authorization: Fixed the issue where users with only knowledge base view permission could add segments in conversation logs.
  • Folders: Fixed the issue where clicking the "Back" button in the resource details of applications and knowledge bases always returned to the root directory.
  • Conversation Users (X-Pack): Fixed the issue where user passwords were not synchronized when synchronizing system users.
  • Conversation Users (X-Pack): Fixed the issue where a new conversation user could be created successfully even without setting a user group.
