MaxKo v2.10.0-lts

Nouvelles fonctionnalités

  • Page d'accueil : ajout de statistiques sur la page d'accueil de l'espace de travail, permettant aux administrateurs de visualiser toutes les ressources de l'espace de travail, les tendances de surveillance des opérations et les classements d'utilisation des ressources.
  • Base de connaissances : ajout d'une bibliothèque de terminologie personnalisable ; les termes personnalisés sont prioritaires lors de la segmentation et de la récupération des mots du document (#5031).
  • Agent : prise en charge complète des entrées multimodales pour les nœuds AI Conversation (#5276).
  • Agent : les paramètres de saisie utilisateur peuvent être affichés en ligne directement dans les zones de saisie pour la configuration.
  • Agent : configuration des conditions de visibilité disponible pour les paramètres des nœuds de saisie utilisateur et de collecte de formulaires afin de réaliser la liaison entre les champs.
  • Système : prise en charge des packs de langue personnalisés ; les fichiers de paramètres régionaux personnalisés peuvent être placés sous /opt/maxkb/local/locales dans le conteneur MaxKB, et les langues personnalisées deviennent sélectionnables après le redémarrage du service (#5120).

Optimisations des fonctionnalités

  • Page Q&A : Masquer les paramètres de saisie de l'utilisateur lors du démarrage d'une nouvelle conversation (#5298).
  • Agent : affiche le nom du nœud actuellement en cours d'exécution à côté des réponses de l'IA sur la page Q&R (#5092).
  • Agent : Ajout d'une bascule de visibilité pour les paramètres à l'intérieur des nœuds de collection de formulaires.
  • Agent : Ajout du paramètre de sortie Result List for Direct Reply pour les nœuds multi-rappels.
  • Base de connaissances : Gelez les boutons d'opération dans le coin supérieur droit pendant l'aperçu de la segmentation du document (#965).
  • Base de connaissances : affichez le contenu segmenté au format Markdown lors de l'aperçu de la segmentation.
  • Modèles : le fournisseur MiniMax prend désormais en charge les modèles texte-image, texte-vidéo et image-vidéo.
  • Modèles : Alibaba Cloud Bailian a ajouté la prise en charge du modèle d'intégration multimodal (#5142).
  • Modèles : Alibaba Cloud Bailian prend en charge le modèle image-vidéo Wan2.7 (#5232).
  • Modèles : la configuration des paramètres est disponible pour le reclassement des modèles de tous les fournisseurs.
  • Gestion des rôles (X-Pack) : divisez l'autorisation de création d'agent et l'autorisation de copie en bits d'autorisation indépendants (#5284).

Corrections de bugs

  • Vulnérabilité de sécurité : correction de la vulnérabilité RCE post-authentification causée par le contournement des autorisations MCP dans MaxKB.
  • Base de connaissances : Correction de l'échec du téléchargement de documents dans la base de connaissances du flux de travail sans autorisation de flux de travail correspondante (#5296).
  • Agent : Correction d'un affichage anormal pour la disposition mobile intégrée, la disposition des fenêtres flottantes et le style de page partagée (#6130).
  • Agent : Correction d'un problème où tous les graphiques ECharts étaient écrasés par le premier graphique après l'actualisation de la page lorsque plusieurs graphiques sont générés dans une seule conversation.
  • Agent : Correction des fichiers téléchargés disparaissant après l'actualisation de la page une fois la conversation terminée dans l'agent avancé (#5253).
  • Agent : Correction des journaux de conversation exportés affichant uniquement le nom d'utilisateur au lieu du nom complet, ce qui empêchait la correspondance des utilisateurs.
  • Base de connaissances partagée (X-Pack) : Correction du résultat vide après l'importation pour créer une base de connaissances partagée (#5274).
  • Gestion des utilisateurs : Correction d'une erreur de validation lorsque l'administrateur réinitialise les mots de passe des utilisateurs (#5301).
  • Connexion système (X-Pack) : Correction des journaux d'opérations manquants lors de la connexion d'un utilisateur tiers.

MaxKB v2.10.0-lts

Highlights

  • Security: post-auth RCE via MCP permission bypass — The headline reason to upgrade. An authenticated user could bypass MCP permission checks to achieve remote code execution, so any deployment exposing MCP-enabled agents should treat v2.10.0-lts as mandatory, not optional. Given how narrow the "post-auth" qualifier is, don't assume a trusted-user-only perimeter protects you.

  • Multimodal agents become end-to-end — AI Conversation nodes now accept full multimodal input (#5276), so agents can consume images/video rather than text alone. That pairs with provider expansion: MiniMax gains text-to-image, text-to-video and image-to-video; Bailian adds multimodal embeddings (#5142) and Wan2.7 image-to-video (#5232). Developers can now build multimodal pipelines without external services — but note that reranking models across all providers also gain parameter configuration, so existing reranker setups should be re-tuned rather than left at defaults.

  • Retrieval quality: customizable terminology library — Custom terms are prioritized during word segmentation and retrieval (#5031). This is the most meaningful accuracy lever here for domain-heavy knowledge bases (medical, legal, internal product names) that generic tokenization tends to mangle. To actually benefit, seed the glossary before re-indexing — existing indexes won't retroactively honor the new terms.

  • Permission model split (X-Pack) — Agent creation and copy permissions are now separate bits (#5284). This is a quiet behavioral change with governance consequences: a role that previously copied agents may implicitly have carried creation capability, and vice versa. Audit custom roles and role assignments after upgrade rather than assuming they carry over unchanged — this is the closest thing in the release to a soft breaking change for permission configurations.

  • Custom language packs (#5120) — Locale files dropped into /opt/maxkb/local/locales inside the container become selectable after a service restart. Useful for i18n forks, but operationally fragile: that path is container-local, so mount it as a volume or bake it into the image, or your custom language vanishes on the next container replacement.

  • Agent debugging and conditional forms — The running node's name now appears alongside AI responses on the Q&A page (#5092), and user-input/form nodes gain visibility conditions, field linkage, and a per-parameter visibility toggle. Combined with the new Result List for Direct Reply output on multi-recall nodes, this materially improves both building multi-step conditional forms and tracing which node produced a given result — worth adopting if you maintain complex agent graphs.

No formally documented breaking changes in this release.

New Features

  • Homepage: Added workspace homepage statistics, enabling administrators to overview all workspace resources, operation monitoring trends and resource usage rankings.
  • Knowledge Base: Added customizable terminology library; custom terms are prioritized during document word segmentation and retrieval (#5031).
  • Agent: Full multimodal input support for AI Conversation nodes (#5276).
  • Agent: User input parameters can be displayed inline directly within input boxes for configuration.
  • Agent: Visibility condition configuration available for parameters of user input and form collection nodes to realize linkage between fields.
  • System: Support for custom language packs; custom locale files can be placed under /opt/maxkb/local/locales inside MaxKB container, and custom languages become selectable after service restart (#5120).

Feature Optimizations

  • Q&A Page: Hide user input parameters when starting a new conversation (#5298).
  • Agent: Display the name of currently running node alongside AI responses on Q&A page (#5092).
  • Agent: Added visibility toggle for parameters inside form collection nodes.
  • Agent: Added output parameter Result List for Direct Reply for multi-recall nodes.
  • Knowledge Base: Freeze operation buttons at top-right corner during document segmentation preview (#965).
  • Knowledge Base: Render segmented content in Markdown format on segmentation preview.
  • Models: MiniMax provider newly supports text-to-image, text-to-video and image-to-video models.
  • Models: Alibaba Cloud Bailian added multimodal embedding model support (#5142).
  • Models: Alibaba Cloud Bailian supports Wan2.7 image-to-video model (#5232).
  • Models: Parameter configuration is available for reranking models of all providers.
  • Role Management (X-Pack): Split agent creation permission and copy permission into independent permission bits (#5284).

Bug Fixes

  • Security Vulnerability: Fixed post-authentication RCE vulnerability caused by MCP permission bypass in MaxKB.
  • Knowledge Base: Fixed failure to upload documents in workflow knowledge base without corresponding workflow authorization (#5296).
  • Agent: Fixed abnormal display for embedded mobile layout, floating window layout and shared page style (#6130).
  • Agent: Fixed issue where all ECharts charts get overwritten by the first chart after page refresh when multiple charts are generated in one conversation.
  • Agent: Fixed uploaded files disappearing after page refresh once conversation ends in advanced agent (#5253).
  • Agent: Fixed exported conversation logs only showing username instead of full name, hindering user matching.
  • Shared Knowledge Base (X-Pack): Fixed empty result after importing to create shared knowledge base (#5274).
  • User Management: Fixed validation error when admin resets user passwords (#5301).
  • System Login (X-Pack): Fixed missing operation logs upon third-party user login.
