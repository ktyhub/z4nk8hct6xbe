QwenPaw v1.0.2

✨ Ajouté

Noyau

  • Plugins : Installez les extensions à partir du dossier plugins/ de votre espace de travail (#3101, #3131, #3132).
  • copaw task : Exécutez des tâches ponctuelles depuis le terminal sans serveur Web (#3031).
  • /model dans le chat : changez de modèle, répertoriez ce qui est disponible, réinitialisez les paramètres par défaut et inspectez un modèle, sans ouvrir les paramètres (#3133). Modèles et fournisseurs
  • SiliconFlow : points de terminaison chinois et internationaux prêts à l'emploi pour le API compatible OpenAI de SiliconFlow (#2886).
  • CoPaw Local : modèles compatibles image et vidéo, paramètres plus riches dans la console, téléchargements et détection de fonctionnalités plus fiables sous Windows (#3021, #3087, #3140). Sécurité
  • Secrets enregistrés de manière plus sûre : les clés API et les valeurs similaires sont cryptées sur le disque ; dans la mesure du possible, la clé de cryptage reste dans le trousseau du système d'exploitation (#3025). Console et interface utilisateur
  • Historique des entrées de chat : parcourez les lignes utilisateur précédentes avec les touches fléchées (#2466).
  • Recherche de chat : recherchez le texte du message dans les sessions (#2842).
  • Sessions épinglées : épinglez les fils de discussion pour qu'ils restent en haut de la liste (#3137).
  • Chat par agent : restaurez le dernier chat ouvert lorsque vous changez d'agent (#3155).
  • Visual polish : icônes pour les outils intégrés et logos des fournisseurs à côté des modèles (#3061, #3130). Compétences et outils
  • Commandes de compétences : /skills affiche ce qui est activé pour le canal ; tapez /<skill name> pour ouvrir une compétence ou exécutez-la avec votre message (#3150).
  • Tags pour les compétences du pool : Organisez le pool partagé avec des tags (#2837, #3069).
  • Découverte d'outils MCP : interrogez chaque serveur MCP connecté pour connaître ses noms d'outils, ses descriptions et ses paramètres via HTTP API (#3149). Chaînes
  • QQ : envoyez des fichiers et des contenus multimédias riches de manière cohérente quels que soient les types de messages (#3012).
  • WeCom : les messages entrants conservent le contexte de citation/réponse afin que l'agent voie ce qui a été référencé (#3024).

🔄 Modifié

  • Sélecteur de fuseau horaire : les noms de région suivent la langue de l'interface utilisateur sélectionnée (#2497).
  • Tailles de fichiers : tailles lisibles par l'homme partout dans la console (#2808).
  • Démarrage de la console : des pages de paramètres plus lourdes se chargent à la demande afin que le premier écran s'ouvre plus rapidement (#3122).
  • Grandes listes de compétences : défilement et interaction plus fluides lorsque vous possédez de nombreuses compétences de pool (#3141, #3158).
  • Tests de connexion au fournisseur : les messages d'état apparaissent dans votre langue (#2913).
  • Code d'erreur : codes d'erreur plus cohérents sur tous les canaux, API et CLI (#3110).

🐛 Corrigé

Chaînes

  • iMessage : les discussions privées respectent désormais votre politique de DM et votre liste d'autorisation de la même manière que les autres chaînes (#2491).
  • Discord : les réponses longues de l'assistant ne brisent plus les blocs de code Markdown à mi-clôture (#2976).
  • Feishu : La reconnexion et l'exécution de plusieurs agents ne déclenchent plus de verrous partagés ou de boucles d'événements mélangées (#3095, #3145). Outils et compétences
  • MCP : la fermeture ou la reconnexion des clients après le rechargement ne provoque plus une utilisation incontrôlable du processeur (#3106).
  • Automatisation du navigateur : Clicking éléments lorsque des doublons existent ciblent le bon ; la documentation explique plus clairement les sélecteurs (#3023).
  • Outil Shell : les commandes avec du texte entre guillemets conservent leurs sauts de ligne intacts (#3070).
  • Compétences : les métadonnées de compétences corrompues ou non-objets ne bloquent plus l'analyse des exigences (#3072).

QwenPaw v1.0.2

✨ Added

Core

  • Plugins: Install extensions from your workspace plugins/ folder (#3101, #3131, #3132).
  • copaw task: Run one-off jobs from the terminal with no web server (#3031).
  • /model in chat: Switch models, list what is available, reset to the default, and inspect a model—without opening Settings (#3133).

Models and providers

  • SiliconFlow: Ready-to-use China and International endpoints for SiliconFlow’s OpenAI-compatible API (#2886).
  • CoPaw Local: Image and video capable models, richer settings in the console, and more reliable downloads and capability detection on Windows (#3021, #3087, #3140).

Security

  • Safer saved secrets: API keys and similar values are encrypted on disk; where possible the encryption key stays in the OS keychain (#3025).

Console and UI

  • Chat input history: Browse previous user lines with the arrow keys (#2466).
  • Chat search: Search message text across sessions (#2842).
  • Pinned sessions: Pin threads so they stay at the top of the list (#3137).
  • Per-agent chat: Restore the last open chat when you switch agents (#3155).
  • Visual polish: Icons for built-in tools and provider logos next to models (#3061, #3130).

Skills and Tools

  • Skill commands: /skills shows what is enabled for the channel; type /<skill name> to open a skill or run it with your message (#3150).
  • Tags for pool skills: Organize the shared pool with tags (#2837, #3069).
  • MCP tool discovery: Query each connected MCP server for its tool names, descriptions, and parameters over the HTTP API (#3149).

Channels

  • QQ: Send files and rich media consistently across message types (#3012).
  • WeCom: Incoming messages keep quote/reply context so the agent sees what was referenced (#3024).

🔄 Changed

  • Timezone picker: Region names follow your selected UI language (#2497).
  • File sizes: Human-readable sizes everywhere in the console (#2808).
  • Console startup: Heavier settings pages load on demand so the first screen opens faster (#3122).
  • Large skill lists: Smoother scrolling and interaction when you have many pool skills (#3141, #3158).
  • Provider connection tests: Status messages appear in your language (#2913).
  • Error Code: More consistent error codes across channels, APIs, and CLI (#3110).

🐛 Fixed

Channels

  • iMessage: Private chats now respect your DM policy and allowlist the same way as other channels (#2491).
  • Discord: Long assistant replies no longer break Markdown code blocks mid-fence (#2976).
  • Feishu: Reconnecting and running several agents no longer trips over shared locks or mixed-up event loops (#3095, #3145).

Tools and skills

  • MCP: Closing or reconnecting clients after reload no longer causes runaway CPU usage (#3106).
  • Browser automation: Clicking elements when duplicates exist targets the right one; the docs explain selectors more clearly (#3023).
  • Shell tool: Commands with quoted text keep their line breaks intact (#3070).
  • Skills: Corrupt or non-object skill metadata no longer crashes requirement parsing (#3072).
