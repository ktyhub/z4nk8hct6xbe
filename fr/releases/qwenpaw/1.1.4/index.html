QwenPaw v1.1.4

✨ Ajouté

Système d'agent

  • Refactor de mémoire et de contexte : refactorisez le module de mémoire à long terme avec des backends enfichables, un résumé automatique de la mémoire tous les N tours de conversation, une récupération automatique de la mémoire et une nouvelle interface de gestion de contexte (#3548)
  • Mode Plan : mode de planification structurée activé – utilisez /plan pour créer des plans de tâches étape par étape que l'agent suit, avec un panneau de plan en direct dans la console (#3686, #3787) Fournisseurs
  • Modèles DeepSeek V4 : ajout de DeepSeek V4 Flash et V4 Pro en tant que modèles intégrés (#3797) Sécurité
  • Contrôles d'évasion de shell configurables : activez ou désactivez les règles de détection d'évasion de shell individuelles à partir de la page des paramètres de sécurité, avec un marquage du type de risque par vérification (#3694, #3715, #3781).
  • Liste blanche des hôtes Auth-Bypass : liste allow_no_auth_hosts configurable pour l'accès au API sans authentification, avec validation IP et avertissements de sécurité dans la console (#3739) Outils
  • Paramètres de lancement du navigateur : transmettez des indicateurs Chromium personnalisés et un chemin d'exécutable de navigateur personnalisé à browser_use (#3556).
  • Shell Command Timeout : délai d'expiration par défaut configurable pour execute_shell_command par agent (#3732) Console et interface utilisateur
  • Affectation de modèle par agent : attribuez un modèle LLM spécifique à chaque agent depuis Paramètres → Agents (#3599)
  • Bouton d'affichage de session : action "Afficher" sur le tableau Sessions pour accéder directement à la session de chat correspondante (#3615)
  • Menu contextuel de session Right-Click : Right-click sur les éléments de la session de chat pour des actions rapides d'ouverture, de renommage, d'épinglage/désépinglage et de suppression (#3770) Chaînes
  • SIP Voice Channel : nouveau canal téléphonique SIP avec backends double mode — pyVoIP pour le développement et LiveKit pour la production (#3449)
  • Reconnaissance vocale DingTalk : utilisez la reconnaissance vocale intégrée de DingTalk au lieu de télécharger et de transcoder l'audio localement (#3681).
  • Menu de commande Telegram : exposez /model et /stop dans le menu de commande du robot Telegram pour pouvoir être découvert (#3714)
  • Prise en charge des messages cités QQ : analysez les métadonnées de réponse/citation et injectez le texte cité et les pièces jointes dans les demandes d'agent (#3735)
  • Messages DingTalk Markdown : envoyez des réponses plus courtes sous forme de démarque DingTalk Open API pour un rendu de message plus riche (#3771)
  • Type de message DingTalk Cron : type de message indépendant pour les envois planifiés/cron, permettant des messages de type carte pour cron tout en utilisant le markdown pour le chat interactif (#3778)
  • Assistant interactif WeChat : Assistant interactif configure_weixin dans le flux de configuration du canal CLI (#3699)

🔄 Modifié

  • Tool Guard Approval System : Tool-guard refactorisé avec cartes d'approbation interactives dans la console, routage d'approbation inter-sessions (approuver les appels d'outils de sous-agents depuis la session principale), niveaux d'exécution configurables (Strict/Smart/Auto/Off), commande REST API et /approval CLI (#3656, #3737)
  • Enregistrement dynamique du plug-in : remplacement du registre du module hôte généré au moment de la construction par un enregistrement basé sur l'exécution import.meta.glob (#3676, #3692, #3696)
  • Améliorations de la version Docker : Déplacement de l'initialisation de config.json de la création d'image vers le point d'entrée du conteneur pour les déploiements montés sur volume, et remplacement de pip par uv pour des installations de packages plus rapides (#3698, #3723, #3769).
  • Agent Language Sync : les nouveaux agents héritent désormais de la langue de l'interface utilisateur de la console (#3720).
  • Persistance de la sélection de l'agent : l'état de sélection de l'agent a persisté dans localStorage afin qu'il survive aux redémarrages du navigateur (#3772).
  • Tampon d'utilisation des jetons : enregistrement asynchrone de l'utilisation des jetons en mémoire tampon avec vidage périodique du disque (#3766)

🐛 Corrigé

  • Encodage d'URL de fichier : encodage en pourcentage des caractères non-ASCII dans les URL file:// pour corriger les échecs d'envoi de fichiers sous Windows et les chemins avec des caractères CJK (#3625)

  • Statistiques d'agent : correction d'un crash de page dû à des importations incorrectes de bibliothèques de graphiques et à des statistiques non actualisées lors du changement d'agent (#3724, #3743) Fournisseurs
  • Avertissement de modèle en double : affiche un avertissement localisé lors de l'ajout d'un ID de modèle qui existe déjà (#3773)
  • Bloc de fichiers Anthropic : convertissez les blocs de fichiers non pris en charge en espaces réservés de texte dans l'historique au format Anthropic pour éviter les erreurs API (#3786) Emballage
  • Discord.py Conda-Unpack : Ajout de discord.py à la liste de réinstallation de conda-unpack pour corriger la corruption du chemin Windows (#3730)

📝Documentation

  • Volume de sauvegarde Docker : Ajout de la documentation sur le montage du volume Docker pour la sauvegarde et la restauration (#3736)
  • Chiffres de sauvegarde : Chiffres de la documentation de sauvegarde mis à jour (#3678)

🧪 Tests et CI

  • Tests unitaires d'agent : ajout de tests unitaires pour les modules hooks, de mémoire et d'utilitaires (#3630)

QwenPaw v1.1.4

Highlights

  • Long-running agent context — Memory now supports pluggable backends, automatic summarization every N turns, retrieval, and a context-management interface (#3548). Opt-in /plan mode adds executable step plans with a live console panel (#3686, #3787). Teams adopting custom memory should review the new interface, since retrieval and summarization change which history reaches the model.

  • Approval and security policies need review — Tool guard now offers Strict/Smart/Auto/Off execution levels, console approval cards, cross-session approval for sub-agent calls, and REST//approval automation (#3656, #3737). Audit these levels before upgrading; keep allow_no_auth_hosts narrowly scoped (#3739), and track disabled shell-evasion rules as intentional policy changes (#3694, #3715, #3781).

  • Per-agent model routing — DeepSeek V4 Flash and Pro are built in (#3797), and individual agents can now be assigned specific models (#3599). This enables cost/capability routing without separate deployments, but validate prompts and stored history when switching providers—especially where file blocks require conversion for Anthropic-formatted requests (#3786).

  • Plugins and containers initialize differently — Plugin registration moved from generated build-time modules to runtime import.meta.glob discovery (#3676, #3692, #3696), so test custom plugin packaging at runtime. Docker now initializes config.json at container entrypoint and installs packages with uv (#3698, #3723, #3769); volume-mounted deployments must support writable configuration at startup.

  • Token metrics are eventually consistent — Usage recording is now buffered and periodically flushed to disk (#3766). This reduces write overhead, but dashboards may lag and recent counters can be lost after an abrupt shutdown; monitoring and audit logic should account for that window.

  • Compatibility — No breaking changes are declared.

✨ Added

Agent System

  • Memory & Context refactor: Refactor long-term memory module with pluggable backends, automatic memory summarization every N conversation turns, automatic memory retrieval, and a new context management interface (#3548)
  • Plan Mode: Opt-in structured planning mode — use /plan to create step-by-step task plans that the agent follows, with a live plan panel in the console (#3686, #3787)

Providers

  • DeepSeek V4 Models: Added DeepSeek V4 Flash and V4 Pro as built-in models (#3797)

Security

  • Configurable Shell Evasion Checks: Toggle individual shell evasion detection rules on or off from the Security settings page, with per-check risk-type tagging (#3694, #3715, #3781)
  • Auth-Bypass Host Whitelist: Configurable allow_no_auth_hosts list for API access without authentication, with IP validation and security warnings in the console (#3739)

Tools

  • Browser Launch Parameters: Pass custom Chromium flags and a custom browser executable path to browser_use (#3556)
  • Shell Command Timeout: Configurable default timeout for execute_shell_command per agent (#3732)

Console & UI

  • Per-Agent Model Assignment: Assign a specific LLM model to each agent from Settings → Agents (#3599)
  • Session View Button: "View" action on the Sessions table to jump directly into the corresponding chat session (#3615)
  • Session Right-Click Context Menu: Right-click on chat session items for quick open, rename, pin/unpin, and delete actions (#3770)

Channels

  • SIP Voice Channel: New SIP phone channel with dual-mode backends — pyVoIP for development and LiveKit for production (#3449)
  • DingTalk Voice Recognition: Use DingTalk's built-in voice recognition instead of downloading and transcoding audio locally (#3681)
  • Telegram Command Menu: Expose /model and /stop in the Telegram bot's command menu for discoverability (#3714)
  • QQ Quoted Message Support: Parse reply/quote metadata and inject quoted text and attachments into agent requests (#3735)
  • DingTalk Markdown Messages: Send shorter replies as DingTalk Open API markdown for richer message rendering (#3771)
  • DingTalk Cron Message Type: Independent message type for scheduled/cron sends, allowing card-style messages for cron while using markdown for interactive chat (#3778)
  • WeChat Interactive Wizard: Interactive configure_weixin wizard in the CLI channel setup flow (#3699)

🔄 Changed

  • Tool Guard Approval System: Refactored tool-guard with interactive approval cards in the console, cross-session approval routing (approve sub-agent tool calls from the main session), configurable execution levels (Strict/Smart/Auto/Off), REST API and /approval CLI command (#3656, #3737)
  • Dynamic Plugin Registration: Replaced the build-time generated host module registry with runtime import.meta.glob-based registration (#3676, #3692, #3696)
  • Docker Build Improvements: Moved config.json initialization from image build to container entrypoint for volume-mounted deployments, and replaced pip with uv for faster package installs (#3698, #3723, #3769)
  • Agent Language Sync: New agents now inherit the console UI language (#3720)
  • Agent Selection Persistence: Agent selection state persisted in localStorage so it survives browser restarts (#3772)
  • Token Usage Buffering: Asynchronous buffered token usage recording with periodic disk flush (#3766)

🐛 Fixed

Channels

  • Filter Tool Messages: Respect filter_tool_messages setting for in-progress content events (#3660)
  • File URL Encoding: Percent-encode non-ASCII characters in file:// URLs to fix file send failures on Windows and paths with CJK characters (#3625)
  • WeChat Send Response: Fixed WeChat send_text failing on empty or non-dict API responses (#3685)
  • WeChat Icon Mapping: Fixed wechat channel key not mapping to the correct WeChat icon in chat history sidebar (#3691)
  • WeChat QR Login Timeout: Extended WeChat QR-status polling timeout to 60 seconds with retry on read timeout during login (#3700)

Console & UI

  • Agent Stats: Fixed page crash from incorrect chart library imports and stats not refreshing when switching agents (#3724, #3743)

Providers

  • Duplicate Model Warning: Show a localized warning when adding a model ID that already exists (#3773)
  • Anthropic File Block: Convert unsupported file blocks to text placeholders in Anthropic-formatted history to prevent API errors (#3786)

Packaging

  • Discord.py Conda-Unpack: Added discord.py to conda-unpack reinstall list to fix Windows path corruption (#3730)

📝 Documentation

  • Memory-Evolving & Proactive Agent: Added dedicated documentation pages for memory-evolving and proactive agent features (#3755, #3764)
  • Agent Team Practice Guide: Added a comprehensive practice guide for Agent Team collaboration (#3784)
  • ACP Integration: Restructured and polished ACP integration documentation, with in-UI documentation link (#3741)
  • Docker Backup Volume: Added Docker volume mount documentation for backup & restore (#3736)
  • Backup Figures: Updated backup documentation figures (#3678)

🧪 Testing & CI

  • Agent Unit Tests: Added unit tests for hooks, memory, and utils modules (#3630)
