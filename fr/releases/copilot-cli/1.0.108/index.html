copilote-cli v1.0.108

2026-11-09

  • Ajoutez sandbox.userPolicy.filesystem.enumeratePaths dans settings.json pour les subventions de répertoire Windows énumérant uniquement
  • Ajoutez des commandes /index et activez l'indexation tgrep partagée gérée par défaut pour les référentiels éligibles
  • Les pièces jointes PDF sur Grok 4.7 et Grok 4.6 reviennent aux références de fichiers au lieu d'échouer.
  • Avec le bac à sable activé, un serveur MCP local en cours d'exécution est désormais redémarré après /cd, il suit donc les chemins refusés du nouveau répertoire au lieu de conserver ceux du répertoire quitté par la session.
  • Une pièce jointe envoyée via le SDK qui pointe vers un canal, un socket ou un périphérique nommé est désormais étiquetée comme une erreur au lieu de bloquer le tour jusqu'à ce que quelque chose écrive dans le canal.
  • Les outils de canevas indiquent désormais au modèle quels ID d'instance open_canvas accepte, au lieu de les appeler sous forme libre.
  • /model répertorie désormais les modèles lorsque Copilot répond à la demande de liste de modèles avec 421 Misdirected Request, par exemple après un changement de plan, en résolvant le point de terminaison de votre compte comme le font déjà les tours de discussion au lieu d'afficher "Erreur de chargement de la liste de modèles".
  • Les demandes adressées aux fournisseurs de chat-achèvements compatibles OpenAI n'incluent plus de champ de message interne sur les messages de compétences et d'outils.
  • Ctrl+C arrête désormais un /compact en cours d'exécution, comme le fait Esc Esc, au lieu de simplement armer l'indice de sortie et de quitter le CLI lors d'une deuxième pression.
  • L'aide de /config n'affiche plus les backticks littéraux ou n'utilise plus un modèle en dehors de la liste des modèles comme exemple.
  • Votre paramètre defaultMode s'applique désormais lorsque vous fermez le sélecteur de session de démarrage alors que la session est encore en train de charger son modèle, au lieu que la session reste dans son mode précédent.
  • Une entrée DisabledSkills, skills.disable et skills.enable correspondent désormais à un nom de compétence dans n'importe quelle casse, comme le fait l'invocation de la compétence, au lieu de ne rien faire en silence lorsque la casse est différente.
  • Créer ou reprendre une session SDK, ou remplacer ses outils, par deux outils personnalisés du même nom est désormais une erreur. Avant, le modèle se voyait proposer la première définition tandis que certains SDK exécutaient le gestionnaire de la dernière.
  • Copilot ne plante plus avec une exception non gérée au démarrage lorsqu'il ne peut pas enregistrer son horodatage de premier lancement, par exemple parce que le disque contenant le répertoire personnel de Copilot est plein. L'échec est enregistré et le démarrage continue.
  • La boîte de démarrage ne suggère plus /init dans un dossier où vous avez exécuté /init suppress, dans un référentiel contenant déjà des instructions Copilot ou en dehors d'un référentiel git.
  • copilot help config nomme désormais les fichiers d'instructions .claude/rules et les paramètres du référentiel .claude/settings.json que lit le CLI.
  • L'entrée d'aide du copilote indique désormais que esc esc arrête également un /compact en cours d'exécution, et qu'en mode shell, un seul esc ou ctrl+c sur une invite vide quitte le mode shell.
  • /help décrit désormais correctement ctrl+d (se ferme uniquement sur une invite vide, sinon supprime le caractère suivant) et ctrl+z sous Windows, et répertorie ctrl+j, ctrl+v, ctrl+y et les touches de saisie vocale.
  • Les limites d'aide du copilote cite désormais l'invite de limite de débit telle que les sessions locales l'affichent, "Passer en mode Copilot Fusion ?", au lieu de "Passer en mode automatique ?"
  • l'aide du copilote mcp indique désormais que le .github/mcp.json d'un répertoire est ignoré lorsque le même répertoire a un .mcp.json, au lieu d'impliquer que les deux fichiers sont fusionnés
  • La surveillance de l'aide du copilote décrit désormais la métrique github.copilot.sandbox.operation.count comme comptant chaque décision du bac à sable par type, et pas seulement les changements de posture dédupliqués.
  • Coller à nouveau un chemin d'image après avoir effacé son étiquette [image: ...] avec Ctrl+U, Ctrl+K, Ctrl+W ou un rappel d'historique avec la flèche vers le haut attache à nouveau l'image au lieu d'insérer le chemin simple.
  • Retour arrière, une touche fléchée, Ctrl+U ou Maj+Entrée enfoncée juste après un collage agit désormais après le texte collé plutôt que sur le texte devant lui.
  • Choisir un type de serveur MCP par son numéro dans le formulaire d'ajout ou de modification déplace désormais le focus vers le champ suivant pour ce type.
  • /permissions default dans Autopilot demande désormais à nouveau comment gérer les autorisations à l'invite suivante, comme le fait /permissions manual, au lieu de laisser Autopilot refuser chaque demande d'outil.
  • Un /ask ou un /btw en file d'attente qui s'exécute alors qu'une autre réponse secondaire est ouverte montre désormais qu'il est toujours en train de réfléchir, au lieu d'afficher la réponse précédente comme sa propre réponse terminée pour que Ctrl+Y la copie.
  • copilot --resume <name> et /resume <name> recherchent désormais une session dont le nom a un accent précomposé ou décomposé, quelle que soit l'orthographe avec laquelle la session a été enregistrée.
  • Dans /search, Up, Down et Enter ramènent une seule correspondance à l'écran après avoir fait défiler l'écran, et un terminal plus court ne laisse plus la correspondance actuelle hors de l'écran.
  • L'aide de /security-review indique désormais qu'elle examine les différences de branche lorsque l'arborescence de travail est propre, et pas seulement les modifications planifiées et non planifiées.
  • Les séquences d'échappement dans les titres des points de contrôle, les noms de fichiers, les chemins d'accueil du Copilot et les noms d'agents générés ne restylent plus les informations /session ou l'assistant /agent.
  • Les valeurs longues dans /session info, telles que les chemins des fichiers journaux et de session, sont désormais placées sous leur propre colonne au lieu de revenir sous l'étiquette.
  • Le passage à une autre session ne remplace plus occasionnellement le modèle de cette session par Auto pendant le rechargement de la liste des modèles.
  • L'utilisation de /share n'implique plus que /share exporte seul un fichier markdown ; il montre qu'un chemin nu doit contenir /, . ou ~.
  • Un chemin ou une route URL dans une invite, telle que /docs/setup.md, ne charge plus une compétence nommée d'après son premier segment (docs) comme si vous aviez invoqué cette compétence.
  • Les sous-commandes de /pr, /lsp, /skills, /plugin, /user et /collect-debug-logs correspondent désormais dans n'importe quelle casse, donc /lsp TEST my-server exécute le test au lieu d'afficher le texte d'utilisation.
  • L'aide pour /experimental et /theme marque désormais /experimental on|off et /theme <mode> comme obsolètes et pointe vers /settings, et /mcp disable n'est plus décrit comme temporaire : il est enregistré au fil des sessions.
  • Un hook d'invite du référentiel sessionStart qui exécute /clear <prompt> ou /new démarre désormais une nouvelle session au lieu d'en démarrer une autre à chaque session qu'il crée.
  • La durée affichée sur un sous-agent ne compte plus le temps passé par son outil aux appels d'autorisation.
  • L'aide de /subagents ne promet plus de modèle de sous-agent par défaut. Il indique maintenant que la commande configure le modèle et les paramètres de chaque sous-agent et active ou désactive les sous-agents.
  • Les caractères de tabulation dans les réponses, les messages d'erreur, les noms d'agents et autres textes sont désormais affichés sous forme d'espaces au lieu d'être supprimés, de sorte que les mots séparés par des tabulations ne s'assemblent plus.
  • La durée affichée sur un appel d'outil ne compte plus le temps passé à son invite d'autorisation, et elle ne s'écoule pas lorsque l'invite est ouverte.
  • Les choix de canal /update indiquent désormais que choisir stable ou prerelease l'enregistre également comme canal de mise à jour pour les mises à jour futures.
  • Préserver les entrées en file d'attente derrière un collage lors du redimensionnement du terminal
  • L'importation de mémoire signale des étendues de référentiel mal formées sans fausse erreur d'hôte non prise en charge.
  • Afficher un avertissement lorsque les compétences configurées d'un agent personnalisé sélectionné sont manquantes ou ne peuvent pas être chargées
  • Inclure les événements de démarrage, de reprise et de changement de modèle de session dans la sortie -p --output-format json
  • Gardez les agents intégrés sélectionnés avec --agent actif lors de l'ouverture de /agent ou de l'actualisation des agents disponibles
  • Les sessions interactives CLI transmettent littéralement les valeurs de l'environnement du serveur MCP local ; utilisez ${NAME} pour référencer une variable d'environnement hôte
  • Autoriser la recherche de code sémantique pour trouver les référentiels renommés lorsque la caisse utilise toujours l'ancien nom
  • Utilisez Ctrl+T pour afficher et masquer le raisonnement du premier passage lorsque Fusion est sélectionné via un profil de routage
  • Gardez la correspondance sélectionnée en vue lors de l'ouverture de /search ou /find au lieu de passer au bas de la conversation.
  • Autoriser le système à se mettre en veille à nouveau après la fin d'un rechargement MCP en arrière-plan lors de l'utilisation de /keep-alive occupé.
  • Gardez l'indice de plan du pied de page visible lorsqu'un plan non vide est disponible
  • Le pilote automatique interactif attend votre réponse aux demandes de saisie et de consentement MCP au lieu de les supprimer automatiquement
  • /mcp activate respecte désormais les paramètres du référentiel qui désactivent un serveur MCP
  • Renommer les fichiers avec l'outil de correctif réussit désormais sans nécessiter de modification de leur contenu
  • Les différences de fichiers dans la transcription concise affichent les séquences d'échappement du terminal sous forme de caractères visibles et préservent les couleurs de ligne ajoutées et supprimées.
  • Réduisez l'utilisation du processeur lors des builds dans de grands arbres de travail lorsque les serveurs de langue surveillent les modifications de fichiers
  • Les exécutions sans tête signalent désormais une erreur lors de la reprise d'une session utilisée par un autre processus Copilot, en gardant son historique intact.
  • Les règles de refus MCP bloquent désormais un outil nommé de la manière dont son serveur MCP l'annonce (par exemple server(weather.lookup)), pas seulement son nom épuré, même avec --allow-all-tools
  • Sous Linux, les serveurs de langage ne sont plus informés que les fichiers d'un répertoire ont été supprimés lorsque le répertoire est renommé et redevenu directement.
  • Sous Linux, les serveurs de langue sont désormais informés lorsqu'un répertoire est renommé (les anciens fichiers supprimés, les nouveaux créés) tandis que d'autres répertoires de l'espace de travail sont créés et supprimés, comme lors de l'installation d'un package.
  • Un canevas qui était ouvert lors de la reprise d'une session est désormais restauré même si son extension redémarre pendant la réouverture du canevas, au lieu de rester indisponible.
  • Lorsqu'un hook preToolUse pose des questions sur plusieurs appels d'outils parallèles, chaque appel reçoit à nouveau sa propre confirmation : répondre Non avec retour à l'un ne refuse plus les autres sans demander.
  • Joindre un document PDF ou Office vide n'échoue plus l'activation des modèles qui lisent les documents de manière native ; le fichier vide est transmis comme référence de fichier à la place.
  • Connectez-vous à un serveur /voice déjà en cours d'exécution même lorsque son fichier PID est manquant
  • /limites non définies efface désormais les plafonds de crédit de l'IA de session pour les demandes ultérieures
  • /plugin install à partir d'un référentiel, d'une URL ou d'un chemin local affiche désormais le même avertissement de dépréciation que copilot plugin install imprime.
  • Les mises à jour automatiques ne sont plus ignorées lors d'un lancement lorsque la connexion prend plus d'une seconde environ
  • /changelog <version> peut récupérer les release note pour les versions non fournies avec le CLI
  • Un tour qui se termine alors que le journal des événements de session ne peut pas être écrit se termine désormais par session.idle, donc sendAndWait n'expire plus lors d'un tour terminé.
  • Les outils grep et glob renvoient désormais les correspondances trouvées lorsqu'un fichier ou un répertoire sous le chemin de recherche ne peut pas être lu, avec une note nommant ce qui a été ignoré, au lieu d'échouer uniquement avec l'erreur d'autorisation.
  • Appliquer les modifications de l'effort de raisonnement effectuées lors d'un appel d'outil à la prochaine demande de modèle sur les modèles pris en charge, sans attendre une autre invite
  • Depuis 1.0.104, les appels du juge des autorisations assistées sont envoyés sous forme de demandes d'agent et ne comptent plus comme des demandes premium distinctes.
  • Répondez aux questions sur le comportement du Copilot CLI à partir de la propre documentation de cette version et indiquez clairement quand la documentation ne couvre pas une question.
  • Conservez les sorties de commandes réussies et les différences de fichiers réduites en mode de transcription concise jusqu'à ce qu'elles soient développées, tout en gardant les détails de sortie et d'échec en cours d'exécution visibles.
  • Afficher les erreurs de validation du formulaire MCP à côté des entrées, cibler le premier champ invalide et améliorer les étiquettes du lecteur d'écran et le positionnement du curseur
  • Depuis 1.0.106, le pilote automatique avec autorisations assistées ne s'arrête plus pour les invites d'autorisation ; l'agent tente une autre approche et signale les actions qu'il n'a pas pu entreprendre
  • Les affectations de plugins gérées avec l'état "defaultEnabled" installent et activent désormais les plugins par défaut tout en préservant les remplacements de l'utilisateur.

copilot-cli v1.0.108

2026-11-09

  • Add sandbox.userPolicy.filesystem.enumeratePaths in settings.json for Windows enumerate-only directory grants
  • Add /index commands and enable managed shared tgrep indexing by default for eligible repositories
  • PDF attachments on Grok 4.7 and Grok 4.6 fall back to file references instead of failing the turn
  • With the sandbox on, a running local MCP server is now restarted after /cd, so it follows the new directory's denied paths instead of keeping those of the directory the session left.
  • A file attachment sent through the SDK that points at a named pipe, socket or device is now tagged as an error instead of stalling the turn until something writes to the pipe.
  • The canvas tools now tell the model which instance IDs open_canvas accepts, instead of calling them free-form.
  • /model now lists models when Copilot answers the model list request with 421 Misdirected Request, for example after a plan change, by re-resolving your account's endpoint as chat turns already do instead of showing "Error loading model list".
  • Requests to OpenAI-compatible chat-completions providers no longer include an internal message field on skill and tool messages.
  • Ctrl+C now stops a running /compact, as Esc Esc does, instead of only arming the exit hint and quitting the CLI on a second press.
  • The /config help no longer shows literal backticks or uses a model outside the model list as its example.
  • Your defaultMode setting now applies when you close the startup session picker while the session is still loading its model, instead of the session staying in its previous mode.
  • A disabledSkills entry, skills.disable and skills.enable now match a skill name in any letter case, as invoking the skill does, instead of silently doing nothing when the case differs.
  • Creating or resuming an SDK session, or replacing its tools, with two custom tools of the same name is now an error. Before, the model was offered the first definition while some SDKs ran the handler of the last one.
  • Copilot no longer crashes with an unhandled exception at startup when it cannot save its first-launch timestamp, for example because the disk holding the Copilot home directory is full. The failure is logged and startup continues.
  • The Getting started box no longer suggests /init in a folder where you ran /init suppress, in a repository that already has Copilot instructions, or outside a git repository.
  • copilot help config now names the .claude/rules instruction files and the .claude/settings.json repository settings the CLI reads.
  • copilot help input now says that esc esc also stops a running /compact, and that in shell mode a single esc or ctrl+c on an empty prompt leaves shell mode
  • /help now describes ctrl+d (exits only on an empty prompt, otherwise deletes the next character) and ctrl+z on Windows correctly, and lists ctrl+j, ctrl+v, ctrl+y and the voice input keys.
  • copilot help limits now quotes the rate-limit prompt as local sessions show it, "Switch to Copilot Fusion mode?", instead of "Switch to auto mode?".
  • copilot help mcp now says that a directory's .github/mcp.json is ignored when the same directory has a .mcp.json, instead of implying the two files are merged
  • copilot help monitoring now describes the github.copilot.sandbox.operation.count metric as counting every sandbox decision by kind, not only deduplicated posture changes.
  • Pasting an image path again after clearing its [image: ...] label with Ctrl+U, Ctrl+K, Ctrl+W or an Up-arrow history recall attaches the image again instead of inserting the plain path.
  • Backspace, an arrow key, Ctrl+U or Shift+Enter pressed right after a paste now acts after the pasted text instead of on the text in front of it.
  • Picking an MCP server type by its number in the add or edit form now moves focus to the next field for that type.
  • /permissions default in Autopilot now asks again how to handle permissions on the next prompt, as /permissions manual does, instead of leaving Autopilot to deny every tool request.
  • A queued /ask or /btw that runs while another side answer is open now shows that it is still thinking, instead of showing the previous answer as its own finished answer for Ctrl+Y to copy.
  • copilot --resume <name> and /resume <name> now find a session whose name has an accent typed precomposed or decomposed, whichever spelling the session was saved with.
  • In /search, Up, Down and Enter bring a single match back into view after you scroll away, and a shorter terminal no longer leaves the current match off screen.
  • /security-review help now says it reviews the branch diff when the working tree is clean, not only staged and unstaged changes
  • Escape sequences in checkpoint titles, file names, Copilot home paths and generated agent names no longer restyle /session info or the /agent wizard.
  • Long values in /session info, such as the log and session file paths, now wrap under their own column instead of back under the label
  • Switching to another session no longer occasionally replaces that session's model with Auto while the model list reloads.
  • /share usage no longer implies that /share alone exports a markdown file; it shows that a bare path must contain /, . or ~.
  • A path or URL route in a prompt, such as /docs/setup.md, no longer loads a skill named after its first segment (docs) as if you had invoked that skill.
  • Subcommands of /pr, /lsp, /skills, /plugin, /user and /collect-debug-logs now match in any letter case, so /lsp TEST my-server runs the test instead of showing usage text.
  • Help for /experimental and /theme now marks /experimental on|off and /theme <mode> as deprecated and points at /settings, and /mcp disable is no longer described as temporary: it is saved across sessions.
  • A repository sessionStart prompt hook that runs /clear <prompt> or /new now starts one new session instead of starting another one in every session it creates.
  • The duration shown on a sub-agent no longer counts the time its tool calls spent at permission prompts.
  • The /subagents help no longer promises a default subagent model. It now says the command configures each subagent's model and settings and turns subagents on or off.
  • Tab characters in replies, error messages, agent names and other text are now shown as spaces instead of being dropped, so tab-separated words no longer run together.
  • The duration shown on a tool call no longer counts the time spent at its permission prompt, and it does not tick while the prompt is open.
  • The /update channel choices now say that picking stable or prerelease also saves it as your update channel for future updates.
  • Preserve input queued behind a paste when resizing the terminal
  • Memory import reports malformed repository scopes without a false unsupported host error
  • Show a warning when a selected custom agent's configured skills are missing or cannot be loaded
  • Include session start, resume, and model-change events in -p --output-format json output
  • Keep built-in agents selected with --agent active when opening /agent or refreshing available agents
  • Interactive CLI sessions pass local MCP server environment values literally; use ${NAME} to reference a host environment variable
  • Allow semantic code search to find renamed repositories when the checkout still uses the old name
  • Use Ctrl+T to show and hide First Pass reasoning when Fusion is selected through a routing profile
  • Keep the selected match in view when opening /search or /find instead of jumping to the bottom of the conversation.
  • Allow the system to sleep again after a background MCP reload finishes when using /keep-alive busy.
  • Keep the footer's plan hint visible when a nonempty plan is available
  • Interactive Autopilot waits for your response to MCP input and consent requests instead of automatically declining them
  • /mcp enable now respects repository settings that disable an MCP server
  • Renaming files with the patch tool now succeeds without requiring changes to their contents
  • File diffs in the concise transcript show terminal escape sequences as visible characters and preserve added and removed line colors
  • Reduce CPU usage during builds in large worktrees when language servers watch for file changes
  • Headless runs now report an error when resuming a session in use by another Copilot process, keeping its history intact.
  • MCP deny rules now block a tool named the way its MCP server advertises it (for example server(weather.lookup)), not only its sanitized name, even with --allow-all-tools
  • On Linux, language servers are no longer told that the files in a directory were deleted when the directory is renamed away and straight back.
  • On Linux, language servers are now told when a directory is renamed (the old files deleted, the new ones created) while other directories in the workspace are being created and removed, such as during a package install.
  • A canvas that was open when a session was resumed is now restored even if its extension restarts while the canvas is being reopened, instead of staying unavailable.
  • When a preToolUse hook asks about several parallel tool calls, each call gets its own confirmation again: answering No with feedback to one no longer denies the others without asking.
  • Attaching an empty PDF or Office document no longer fails the turn on models that read documents natively; the empty file is passed as a file reference instead.
  • Connect to an already running /voice server even when its PID file is missing
  • /limits unset now clears session AI credit caps for subsequent requests
  • /plugin install from a repository, URL or local path now shows the same deprecation warning that copilot plugin install prints.
  • Automatic updates are no longer skipped for a launch when signing in takes more than about a second
  • /changelog <version> can retrieve release notes for versions not bundled with the CLI
  • A turn that ends while the session event log cannot be written now still ends with session.idle, so sendAndWait no longer times out on a turn that completed.
  • The grep and glob tools now return the matches they found when a file or directory under the search path cannot be read, with a note naming what was skipped, instead of failing with only the permission error.
  • Apply reasoning effort changes made during a tool call to the next model request on supported models, without waiting for another prompt
  • Since 1.0.104, Assisted Permissions judge calls are sent as agent requests and no longer count as separate premium requests
  • Answer questions about Copilot CLI behavior from this build's own documentation and clearly say when docs do not cover a question.
  • Keep successful command output and file diffs collapsed in concise transcript mode until expanded, while keeping running output and failure details visible.
  • Show MCP form validation errors beside inputs, focus the first invalid field, and improve screen-reader labels and cursor positioning
  • Since 1.0.106, Autopilot with Assisted Permissions no longer stops for permission prompts; the agent tries another approach and reports the actions it could not take
  • Managed plugin assignments with state "defaultEnabled" now install and activate plugins by default while preserving user overrides.
