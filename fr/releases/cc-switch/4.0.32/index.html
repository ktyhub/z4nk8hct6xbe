cc-switch v4.0.32

interrupteur cc v4.0.32

#Commutateur CC v4.0.32 Cette version ajoute Télécharger automatiquement les mises à jour en arrière-plan : Après avoir activé "Télécharger automatiquement les mises à jour" dans "Paramètres → À propos", la nouvelle version sera téléchargée et vérifiée en arrière-plan. Une invite apparaîtra dans le coin inférieur droit vous demandant si vous souhaitez l'installer. Il ne redémarrera pas sans confirmation. "Paramètres → Réseau" a ajouté la Détection IP, qui vous permet d'afficher l'adresse IP et la région de sortie lorsque CC Switch est accessible via un proxy global, un proxy temporaire ou le réseau actuel. De plus, nous avons résolu des problèmes tels que lorsque Codex poursuit une ancienne session via des fournisseurs de routage et de commutation, le système en amont renvoie d'abord 200, puis signale « Impossible de déchiffrer », entraînant l'abandon de l'intégralité du cycle ; Le Codex demande le rapport 422 lors de la connexion à Mistral AI via le routage ou l'agrégation ; après le crash d'une opération à l'intérieur de CC Switch, le bac devient vide et le fournisseur ne peut pas être changé avant le redémarrage ; les outils installés avec mise affichent deux enregistrements d'installation sur la page "Application". Ajouter

Téléchargez automatiquement les mises à jour en arrière-plan

"Paramètres → À propos" ajoute le commutateur "Télécharger automatiquement les mises à jour", qui est désactivé par défaut et peut être défini individuellement pour chaque appareil.

  • Une fois allumé, CC Switch le vérifiera une minute après son démarrage, puis toutes les six heures. S'il existe une nouvelle version, elle sera téléchargée et vérifiée en arrière-plan.
  • Après le téléchargement, il vous sera demandé si vous souhaitez l'installer dans le coin inférieur droit de l'interface principale. L'installation redémarrera CC Switch et les requêtes passant par le routage local seront interrompues, vous devez donc cliquer sur « Installer et redémarrer » pour continuer ; cela sera indiqué dans l'invite lorsque le routage est activé.
  • Cliquer sur "Plus tard" ne vous demandera plus cette version. Le point rouge dans les paramètres, le bouton sur la page « À propos » et le nouveau « Redémarrer et mettre à jour vers vX » dans le menu de la barre d'état et le panneau de raccourcis peuvent toujours être installés.
  • Le package d'installation deb/rpm de la version portable et Linux ne peut pas être installé automatiquement. Le commutateur sera grisé et la raison sera expliquée.

Détection IP

"Paramètres → Réseau" ajoute une détection IP sous le proxy global (#9449, voir #9448 pour les exigences) : Sélectionnez le proxy global enregistré ou remplissez un proxy temporaire (utilisé uniquement pour cette détection, non enregistré). Après avoir cliqué sur "Détecter l'IP", l'IP de sortie, si les résultats des deux services de détection sont cohérents, et des informations telles que le pays ou la région, la ville, l'opérateur, etc. seront affichées. Lorsqu'il n'y a pas de proxy global, le proxy système ou la connexion directe est utilisé pour la détection ; lorsqu'un proxy est spécifié, la connexion directe ne sera pas utilisée si le proxy ne peut pas se connecter.

  • Exécuté uniquement après avoir cliqué, il visitera icanhazip.com, ipify.org et enverra l'adresse IP mesurée à ipwho.is pour interroger l'emplacement.
  • Ce qui est mesuré, c'est la sortie propre du CC Switch par cette ligne, qui n'est pas forcément égale à la sortie des clients comme Claude Code et Codex.

Autres

  • La carte de fournisseur inversé GitHub Copilot affiche le compte GitHub lié (#9228, pour les exigences, voir #9480) : auparavant, seule l'adresse du site Web officiel de GitHub Copilot était affichée et il était difficile de faire la distinction entre plusieurs comptes. S'il n'est pas lié, le compte par défaut du centre d'autorisation sera affiché. Lorsque la remarque est renseignée, la remarque est prioritaire.

Correction

  • Lorsque le Codex poursuit l'ancienne session via le fournisseur de commutation, le fournisseur de commutation en amont renvoie d'abord 200, puis signale "Le contenu de sortie de fonction crypté n'a pas pu être déchiffré ou décodé". Après que le Codex se soit reconnecté cinq fois, ce cycle est abandonné (#9476) : lorsque la demande contient l'enregistrement de pensées ou le contenu crypté généré par le fournisseur précédent, CC Switch attendra que l'amont démarre la sortie avant de le remettre. Codex, s'il est rejeté à ce moment-là, supprimez ces contenus et réessayez automatiquement dans la même entreprise, et la session peut continuer. Les demandes sans ce contenu seront renvoyées comme d'habitude.
  • Lorsque le Codex est connecté à Mistral AI via routage ou agrégation, la requête rapporte 422 extra_forbidden (#9507) : Le champ spécial Réponses porté par le Codex, les paramètres de réflexion automatiquement ajoutés pour le modèle DeepSeek / GLM sur Mistral, et le reasoning_content porté à chaque tour après utilisation de l'outil seront supprimés lorsqu'ils seront envoyés à api.mistral.ai. Les autres amonts ne sont pas concernés.
  • Après un crash d'une opération interne de CC Switch, le menu de la barre d'état devient vide, le fournisseur ne peut pas être changé et la connexion directe ne peut pas être rétablie en quittant. Il ne peut être redémarré que (#9472, #9483, voir #8058) : la base de données, les paramètres, l'écriture du fichier de configuration, le MCP, les mots d'invite, les prix, la sauvegarde et d'autres opérations peuvent désormais être restaurés après un crash, et les modifications inachevées au moment du crash seront annulées.
  • Lors de l'utilisation de Claude Code / Claude Desktop via GitHub Copilot, des modèles tels que Grok qui prennent uniquement en charge l'interface Responses dans Copilot ont signalé "non accessible via le point de terminaison /chat/completions" (#6954, #9473) : ce type de modèle utilise désormais l'interface Responses, et les modèles pris en charge par les deux interfaces restent inchangés.
  • Lorsque Antigravity sélectionne Orchestrator, toute utilisation est enregistrée sous le nom d'un modèle virtuel et le coût est de 0 (#9493, #9494) : désormais, le prix est basé sur le modèle réel utilisé à chaque étape, et le prix de Gemini 4 Hydrogen est ajouté. L'historique antigravité importé sera réanalysé et le coût sera compensé.
  • Après avoir activé « l'historique de session du Codex unifié » ou l'historique de migration, les sessions d'il y a quelques mois sont classées en premier dans codex resume (#3866, #9471) : lors de la réécriture des fichiers de session .jsonl ordinaires, l'heure de modification d'origine sera conservée et les fichiers compressés seront conservés. L'heure de modification modifiée ne sera pas restaurée.
  • Pour les fournisseurs supprimés dans Hermes, le bouton supprimer dans CC Switch est toujours gris (#4816, #9470) : Les fournisseurs qui n'existent plus dans Hermes peuvent désormais être modifiés et supprimés ; ils sont toujours verrouillés lorsque la configuration Hermes n'est pas lisible.
  • Lors de l'ajout d'un fournisseur OpenClaw à partir d'un préréglage, /model répertorie les modèles fournis avec le préréglage, pas le dernier enregistré dans le formulaire (#9474, voir #6729) : les modèles supprimés dans le formulaire ne réapparaîtront pas et les modèles nouvellement ajoutés pourront également être sélectionnés ; lors de l'enregistrement direct sans modifier le préréglage, tous les modèles prédéfinis seront enregistrés. La modification d'un fournisseur existant ne se synchronise pas encore, le #6729 est toujours suivi.
  • Outils installés avec mise, la page "Application" affiche deux enregistrements d'installation (l'un d'eux est marqué homebrew lorsque mise est installé avec Homebrew) (#9515) : le shim de mise compte désormais comme l'installation vers laquelle elle pointe réellement.
  • Lorsque la fenêtre est courte, le bouton de confirmation de la boîte de dialogue « Ouvrir le terminal » est expulsé de l'écran et ne peut pas être cliqué (#9478) : le contenu de la boîte de dialogue peut défiler indépendamment et le bouton est fixé en bas ; vous pouvez également ouvrir directement le terminal en appuyant sur Entrée dans la zone de saisie "Paramètres supplémentaires (facultatifs)".
  • Il manque un point dans l'état du taux de change sur la page d'utilisation et est lié à la description suivante (#9436).

cc-switch v4.0.32

Highlights

  • Automatic update downloads, manual installation — Enable the opt-in setting to check one minute after launch, then every six hours; updates are downloaded and verified in the background. Installation still requires confirmation and restarts CC Switch, interrupting requests through its local router. Portable and Linux deb/rpm builds cannot auto-install. “Later” suppresses the prompt for that version without removing the other update entry points.
  • Proxy-aware IP diagnostics (#9449) — Check the exit IP and geolocation for a saved global proxy or an unsaved temporary proxy. Results show agreement between two IP services, and a failed selected proxy does not fall back to direct access. Note that this measures CC Switch’s own route, not necessarily Claude Code’s or Codex’s traffic.
  • Reliable Codex provider routing (#9476, #9507) — If a new provider rejects encrypted content from a previous provider after starting a 200 response, CC Switch strips that content and retries once with the same provider. Requests to Mistral AI also omit Responses-only fields, model-specific thinking parameters, and stale reasoning_content, eliminating 422 extra_forbidden errors.
  • Copilot model compatibility and account visibility (#9473, #9228) — Models such as Grok that Copilot exposes only through Responses are routed to that endpoint instead of failing on /chat/completions. Provider cards now distinguish accounts using the bound GitHub identity or a custom note.
  • Crash recovery and accurate accounting (9472, #9483, #9494) — Database, settings, configuration, MCP, prompt, pricing, and backup operations can recover after an internal crash and roll back incomplete writes, preventing a broken tray and direct-connect state. Antigravity Orchestrator usage is now charged to the model used at each step, and imported history is reparsed to backfill costs.
  • Provider management fixes — Hermes providers deleted externally become editable and removable (#9470); new OpenClaw providers now register the models actually saved in the form (#9474), though editing existing providers still does not sync them. Codex history ordering is also corrected by preserving original .jsonl modification times (#9471).

No breaking changes.

CC Switch v4.0.32

本版本新增后台自动下载更新：在「设置 → 关于」打开「自动下载更新」后，新版本会在后台下载并校验好，右下角弹出提示问你是否安装，不会未经确认就重启。「设置 → 网络」新增 IP 检测，可以查看 CC Switch 经全局代理、临时代理或当前网络访问时的出口 IP 和所在地区。

另外修复了 Codex 经路由换供应商续接旧会话后，上游先回 200 再报「无法解密」导致整轮报废；Codex 经路由或聚合接 Mistral AI 时请求报 422；CC Switch 内部某个操作崩溃一次后，托盘变空、切不了供应商，直到重启；用 mise 装的工具在「应用」页显示两条安装记录等问题。

新增

后台自动下载更新

「设置 → 关于」新增「自动下载更新」开关，默认关闭，每台设备单独设置。

  • 打开后，CC Switch 启动一分钟后检查一次，之后每六小时检查一次，有新版本就在后台下载并校验。
  • 下载好后，主界面右下角会问你是否安装。安装会重启 CC Switch，正在经本地路由的请求会中断，所以一定要你点「安装并重启」才会进行；路由开着时提示里会写明这一点。
  • 点「稍后」只是不再为这个版本弹提示，设置里的红点、「关于」页的按钮，以及托盘菜单和快捷面板里新增的「重启并更新到 vX」仍然可以安装。
  • 便携版和 Linux 的 deb / rpm 安装包不能自动安装，开关会置灰并说明原因。

IP 检测

「设置 → 网络」在全局代理下方新增 IP 检测（#9449，需求见 #9448）：选已保存的全局代理或填一个临时代理（只用于这次检测，不保存），点「检测 IP」后会显示出口 IP、两个检测服务的结果是否一致，以及国家或地区、城市、运营商等信息。没设全局代理时，按系统代理或直连检测；指定了代理时，代理连不上不会改用直连。

  • 只在点击后运行，会访问 icanhazip.com、ipify.org，并把测得的 IP 发给 ipwho.is 查询位置。
  • 测的是 CC Switch 自己经这条线路的出口，不一定等于 Claude Code、Codex 等客户端的出口。

其他

  • GitHub Copilot 反代供应商卡片显示绑定的 GitHub 账号（#9228，需求见 #9480）：以前只显示 GitHub Copilot 的官网地址，多个账号时分不清。没绑定时显示授权中心的默认账号，填了备注时备注优先。

修复

  • Codex 经路由换供应商续接旧会话时，上游先回 200、再报「Encrypted function output content could not be decrypted or decoded」，Codex 重连五次后这一轮报废（#9476）：请求里带着上一家生成的思考记录或加密内容时，CC Switch 会先等上游开始输出再交给 Codex，这时被拒就去掉这些内容后在同一家自动重试一次，会话可以继续。不带这类内容的请求照常直接流式返回。
  • Codex 经路由或聚合接 Mistral AI 时，请求报 422 extra_forbidden（#9507）：Codex 带的 Responses 专用字段、为 Mistral 上的 DeepSeek / GLM 模型自动加的思考参数，以及用过工具之后每轮都带的 reasoning_content，发往 api.mistral.ai 时都会去掉。其他上游不受影响。
  • CC Switch 内部某个操作崩溃一次后，托盘菜单变空、切不了供应商，退出时也恢复不了直连，只能重启（#9472、#9483，见 #8058）：数据库、设置、配置文件写入、MCP、提示词、价格、备份等操作现在都能在崩溃后恢复，崩溃时没写完的改动会回滚。
  • 经 GitHub Copilot 用 Claude Code / Claude Desktop 时，Grok 这类在 Copilot 里只支持 Responses 接口的模型报「not accessible via the /chat/completions endpoint」（#6954、#9473）：这类模型现在改走 Responses 接口，两种接口都支持的模型不变。
  • Antigravity 选 Orchestrator 时，用量全部记在一个虚拟模型名下、费用为 0（#9493、#9494）：现在按每一步实际使用的模型计价，并新增 Gemini 4 Hydrogen 的价格。已导入的 Antigravity 历史会重新解析一次，补上费用。
  • 开启「统一 Codex 会话历史」或迁移历史后，几个月前的会话在 codex resume 里排到了最前面（#3866、#9471）：改写普通 .jsonl 会话文件时会保留原来的修改时间，压缩过的文件本来就会保留。已经被改乱的修改时间不会恢复。
  • 在 Hermes 里删掉的供应商，CC Switch 里删除按钮一直是灰的（#4816、#9470）：Hermes 里已经没有的供应商现在可以编辑和删除；读不到 Hermes 配置时仍然锁定。
  • 从预设新增 OpenClaw 供应商时，/model 里列的是预设自带的模型，不是表单里最后保存的（#9474，见 #6729）：在表单里删掉的模型不会再出现，新加的模型也能选；不改动预设直接保存时，会登记预设的全部模型。编辑已有供应商时还不会同步，#6729 仍在跟进。
  • 用 mise 安装的工具，「应用」页显示两条安装记录（mise 用 Homebrew 安装时其中一条标成 homebrew）（#9515）：mise 的 shim 现在算作它实际指向的那个安装。
  • 窗口较矮时，「打开终端」对话框的确认按钮被挤出屏幕，点不到（#9478）：对话框内容可以单独滚动，按钮固定在底部；在「附加参数（可选）」输入框里按回车也可以直接打开终端。
  • 用量页的汇率状态缺句号，和后面的说明连在一起（#9436）。
