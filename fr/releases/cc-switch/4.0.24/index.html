interrupteur cc v4.0.24

#Commutateur CC v4.0.24 Cette version ajoute le commutateur « Ouvrir automatiquement le navigateur lors de la connexion » dans le centre d'autorisation. Après l'avoir désactivé, vous ne pouvez copier que le lien de connexion pour vous connecter à votre compte, et vous pouvez l'ouvrir dans le navigateur de votre choix. Cela convient aux utilisateurs qui utilisent un environnement de navigateur indépendant pour chaque compte. De plus, des problèmes tels que le niveau de réflexion maximum réduit à xhigh lors de l'utilisation de GPT 6.1 Sol/Terra via Claude Code et Claude Desktop, les fournisseurs tiers ne s'affichant pas après la sélection d'un modèle prenant en charge la saisie PDF dans DeepSeek Harness, le commutateur CC sur WSL quittant après le démarrage, le niveau de réflexion n'étant pas envoyé après la réouverture du fournisseur de chat du Codex "Support Thinking Level", etc. Pour le contenu complet de la mise à jour de 4.0, veuillez consulter v4.0 Release Remarques. Ajouter

Vous ne pouvez copier le lien que lorsque vous vous connectez à votre compte

Dans le passé, lors de la connexion à un compte dans le centre d'autorisation, la page de connexion était toujours ouverte à l'aide du navigateur par défaut du système. Si vous utilisez des outils comme AdsPower pour ouvrir un environnement de navigateur distinct pour chaque compte, la connexion tombera dans le mauvais navigateur. Il existe désormais un commutateur « Ouvrir automatiquement le navigateur lors de la connexion » en haut du centre d'autorisation. Les connexions aux comptes Claude, ChatGPT, Copilot, xAI, Antigravity, Kimi et DeepSeek sont toutes contrôlées par celui-ci, y compris les connexions initiées dans le formulaire d'ajout de fournisseur. Après l'arrêt :

  • Cliquez sur Connexion pour copier le lien de connexion dans le presse-papiers, ouvrez-le dans le navigateur que vous souhaitez utiliser, connectez-vous et acceptez l'autorisation, CC Switch se mettra automatiquement à jour.
  • Les connexions nécessitant la saisie d'un code de vérification ne copieront plus automatiquement le code de vérification pour éviter de supprimer le lien dans le presse-papiers.
  • En attendant de vous connecter, vous pouvez cliquer sur « Copier le lien de connexion » pour le copier à nouveau. Le bouton pour ouvrir la page de connexion ne sera pas affiché. Sous Windows, Claude Code ouvrira le navigateur tout seul et CC Switch n'affichera le lien de connexion que lorsque le commutateur est éteint. Le commutateur est activé par défaut et est uniquement enregistré sur cet ordinateur et non synchronisé avec le cloud. Par défaut : A6API utilise le nouveau nom de domaine a6api.vip.

Correction

  • Lorsque Claude Code et Claude Desktop sont connectés en amont du format OpenAI et que le modèle est gpt-6.1-sol ou gpt-6.1-terra, l'équipement de réflexion maximum est réduit à xhigh et émis (#9122). Désormais dans GPT 5.6 et les versions ultérieures, les modèles sans suffixes ou avec les suffixes sol, terra, luna et astra conservent le maximum ; d'autres suffixes tels que pro, codex, mini, etc. sont toujours émis sous le nom xhigh.
  • Harnais DeepSeek Après avoir sélectionné un modèle prenant en charge la saisie PDF dans la liste des modèles extraits, tous les fournisseurs tiers ne sont pas affichés (#9116). Le type d’entrée de modèle de DeepSeek Harness reconnaît uniquement le texte et les images. L'écriture d'un PDF invalidera toute cette configuration. Maintenant, écrivez simplement du texte et des images.
  • CC Switch sur WSL se ferme directement après le démarrage et l'icône de la barre d'état "Autorisation refusée" est signalée (#9021, #9020). L'icône de la barre d'état Linux est modifiée pour être placée dans le répertoire de cache de l'application.
  • Une fois le fournisseur de chat du Codex fermé puis ouvert « Support Thinking Level », le niveau de réflexion sélectionné ne sera plus envoyé en amont (#8998, #8954). Les amonts comme le GitHub Copilot ne reçoivent donc aucun équipement de réflexion. Les fournisseurs qui ont été enregistrés auparavant reviendront à la normale sans réédition.
  • La carte « DeepSeek Official Login » de DeepSeek Harness indique « Connectez-vous avec le compte Claude » (#9058). Il s'agit maintenant de "Connectez-vous avec le compte DeepSeek".

cc-switch v4.0.24

Highlights

  • Browser-independent account login — The new local “automatically open browser on login” switch controls Claude, ChatGPT, Copilot, xAI, Antigravity, Kimi, and DeepSeek sign-in, including supplier-add flows. Disable it to copy an authorization URL and complete login in a separate browser environment; CAPTCHA codes are no longer auto-copied, preventing them from overwriting that URL. On Windows, Claude Code likewise emits a link instead of launching a browser. The setting is per-device and does not sync.
  • Preserved max reasoning for routed GPT models — #9122 fixes Claude Code and Claude Desktop downgrading max to xhigh when using gpt-6.1-sol or gpt-6.1-terra through OpenAI-format routers. GPT 5.6 and later now retain max without a suffix or with sol, terra, luna, or astra; pro, codex, mini, and other suffixes still map to xhigh.
  • DeepSeek Harness provider visibility restored — #9116 addresses a configuration failure triggered by selecting a PDF-capable model. Because Harness accepts only text and image inputs, CC Switch now writes only those capabilities; PDF input is intentionally omitted so one incompatible model no longer hides every third-party supplier.
  • Codex Chat reasoning settings repaired — #8998, following #8954, fixes reasoning levels disappearing after “support thinking levels” is disabled and re-enabled. Previously saved suppliers recover automatically—no re-editing or re-saving is required—and upstreams such as GitHub Copilot receive the selected level again.
  • WSL startup fixed — #9021 moves the Linux tray icon into the application cache directory, resolving the startup-time “Permission denied” failure reported in #9020. WSL users can launch CC Switch without applying a separate tray-icon permission workaround.
  • A6API preset endpoint updated — The built-in A6API preset now uses a6api.vip. Users who copied the previous endpoint into custom supplier configurations, allowlists, or proxies should check those references separately; changing the preset does not rewrite manually configured values.

No breaking changes.

CC Switch v4.0.24

本版本在授权中心加了「登录时自动打开浏览器」开关，关掉后登录账号只复制登录链接，由你自己选浏览器打开，适合每个账号用独立浏览器环境的用户。另外修复了 Claude Code、Claude Desktop 经路由用 GPT 6.1 Sol / Terra 时 max 思考档位被降成 xhigh、DeepSeek Harness 选了支持 PDF 输入的模型后第三方供应商全部不显示、WSL 上 CC Switch 启动就退出、Codex 的 Chat 供应商重开「支持思考等级」后思考档位发不出去等问题。4.0 完整的更新内容请见 v4.0 发布说明。

新增

登录账号时可以只复制链接

以前在授权中心登录账号，一律用系统默认浏览器打开登录页。用 AdsPower 这类工具给每个账号单独开浏览器环境的话，登录会落到错误的浏览器里。

现在授权中心顶部多了「登录时自动打开浏览器」开关，Claude、ChatGPT、Copilot、xAI、Antigravity、Kimi、DeepSeek 账号登录都受它控制，包括在添加供应商表单里发起的登录。关掉后：

  • 点登录只把登录链接复制到剪贴板，在你要用的浏览器里打开、登录并同意授权，CC Switch 会自动更新。
  • 需要输入验证码的登录不再自动复制验证码，免得把剪贴板里的链接顶掉。
  • 等待登录时可以点「复制登录链接」再复制一次，打开登录页的按钮不显示。

Windows 上 Claude Code 会自己打开浏览器，开关关掉时 CC Switch 会让它只输出登录链接。

开关默认打开，只记在这台电脑上，不随云同步。

预设： A6API 改用新域名 a6api.vip。

修复

  • Claude Code、Claude Desktop 经路由连 OpenAI 格式的上游、模型是 gpt-6.1-sol 或 gpt-6.1-terra 时，max 思考档位被降成 xhigh 发出（#9122）。现在 GPT 5.6 及以后的版本，不带后缀或带 sol、terra、luna、astra 后缀的模型都保留 max；pro、codex、mini 等其他后缀仍按 xhigh 发。
  • DeepSeek Harness 从拉取到的模型列表里选了支持 PDF 输入的模型后，第三方供应商全部不显示（#9116）。DeepSeek Harness 的模型输入类型只认文字和图片，写进去一个 PDF 就会让这一条配置整体失效。现在只写文字和图片。
  • WSL 上 CC Switch 启动后直接退出，报托盘图标「Permission denied」（#9021、#9020）。Linux 的托盘图标改为放在应用的缓存目录。
  • Codex 的 Chat 供应商关掉再打开「支持思考等级」后，选的思考档位不再发给上游（#8998、#8954）。GitHub Copilot 等上游因此收不到任何思考档位。以前保存过的供应商不用重新编辑，也会恢复正常。
  • DeepSeek Harness 的「DeepSeek 官方登录」卡片写着「用 Claude 账号登录」（#9058）。现在是「用 DeepSeek 账号登录」。

致谢

感谢 @gddg（WSL 托盘）、@guishiw（Codex 思考等级）、@iSanae233（DeepSeek 登录文案）的贡献。

感谢 @Xinyu-Li-1997、@clickwzy、@mhsbz、@ggbdpq 报告问题、提供复现信息和修复思路。

完整的技术细节请见 CHANGELOG。
