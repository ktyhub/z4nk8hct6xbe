11/23
v4.0.40 Correctif MT

本版本让 Grok Build 的官方卡可以绑定授权中心里的 xAI 账号，像 Claude、Codex 官方卡一样在多个 Grok 账号之间切换。插件页支持 Antigravity CLI；用量统计的供应商和模型列表加了缓存命中率；小米 MiMo 内置余额和 Token Plan 额度查询；授权中心的账号卡片跟随侧栏应用的顺序和隐藏设置。

 11/22
v4.0.39 Correctif MT

本版本以修复为主。API Key 输入框加了复制按钮；备份可以设置总大小上限，超过时从最旧的开始删；Claude Code 经 Codex OAuth 使用 GPT-6.2 Sol / Astra 时，系统提示的缓存命中率大幅提高。

 11/21
v4.0.38 Correctif MT

本版本以修复为主。一键导入链接现在可以导入 WorkBuddy 供应商；Linux 上也能在授权中心切换 Antigravity 账号；Antigravity 的会话列表不再混进空会话和内部子会话，会话阅读器能看到思考、工具调用和结果。

 11/20
v4.0.37 Correctif MT

本版本以修复为主。读不出来的供应商和 MCP 条目（比如由更新版本写入、经 WebDAV / S3 同步过来的）不再被当成空配置、下次保存时被默认值覆盖，而是单独列出来，可以删除；Pi 新增 Mistral AI 预设；韩语界面翻译整体改进。

 11/19
v4.0.36 Correctif MT

Cette version a une nouvelle page de plug-in. Vous pouvez installer, activer, mettre à jour et désinstaller des plug-ins pour Claude Code, Codex, Grok Build, MiniMax Code, OpenClaw et Pi dans CC Switch, et gérer le marché des plug-ins pour Claude Code, Codex et Grok Build. Les référentiels de compétences peuvent désormais lire les référentiels privés avec des jetons d'accès ; les fournisseurs acheminés localement peuvent fixer des multiplicateurs de frais ; et les chapitres du bureau Claude Code sont visibles dans la gestion de session.

 11/18
v4.0.35 Correctif MT

Cette version permet aux cartes Codex utilisant les comptes ChatGPT dans Claude Code / Claude Desktop d'utiliser GPT-6.2. L'objectif complet du Codex /goal peut être vu dans la gestion de session, et l'ID de la demande dans les détails de la demande peut être copié en un seul clic.

 11/17
v4.0.34 Correctif MT

本版本的技能仓库支持 GitLab、Gitea 和 Forgejo（包括自建实例和 Codeberg），不再只能添加 GitHub 上的仓库。会话管理里现在可以直接删除 Antigravity CLI 的会话；开启自动下载更新后，发现新版本会立刻开始下载。另外，WorkBuddy 手动添加的模型可以设置思考强度，S3 同步也可以像 WebDAV 一样清除本机保存的配置。

 11/16
v4.0.33 Correctif MT

本版本修复了从第三方供应商切回 Claude 官方后，已经开着的 Claude Code 会话仍把请求发给上一家、要重开会话才恢复的问题。套餐额度查询新增 Ollama Cloud；授权中心的 Antigravity 账号切换现在也支持 Windows。

 11/14
v4.0.32 Correctif MT

本版本新增后台自动下载更新：在「设置 → 关于」打开「自动下载更新」后，新版本会在后台下载并校验好，右下角弹出提示问你是否安装，不会未经确认就重启。「设置 → 网络」新增 IP 检测，可以查看 CC Switch 经全局代理、临时代理或当前网络访问时的出口 IP 和所在地区。

 11/12
v4.0.31 Correctif MT

本版本新增受管应用腾讯 WorkBuddy：自定义模型写进 WorkBuddy 自己的模型配置，在 WorkBuddy 里直接就能选；还能在多个 WorkBuddy 账号之间切换，切换前先看到每个号的套餐、剩余积分和到期时间。界面新增德语，README 也有了全部八种界面语言的版本。

 11/12
v4.0.30 Correctif MT

本版本新增隐私过滤器：在路由和聚合模式下，本地路由转发请求前可以把用户输入和系统提示里的个人信息和密钥替换成占位符，不让它们发到上游。默认关闭，开关在「设置 → 数据」。

 11/10
v4.0.29 Correctif MT

Cette version ajoute une nouvelle application gérée GitHub Copilot CLI : les fournisseurs possédant leur propre clé seront écrits dans les propres fournisseurs de Copilot.json. Utilisez /model dans copilot pour le sélectionner avec le modèle officiel sans passer par CC Switch. Les langues coréenne et russe ont été ajoutées à l'interface. Les sept langues ont été maintenues simultanément, et l'anglais n'est plus affiché aux endroits manquants.

Cette version traite principalement de la mise à jour incompatible du Codex du 8 novembre.

本版本让会话管理可以搜索消息正文，新增界面密度和界面缩放设置，模型定价表可以搜索，Grok Build 正在使用的供应商也能打开终端了。Skills 的已安装页重新排了版，供应商图标会跟随深浅色主题。另外修复了配置文件是软链接时被替换成普通文件或写入失败、取消请求后供应商卡在熔断恢复中直到重启、Codex 设置了自定义权限后 plan 模式报错、运行过的 Skill 被误报有更新、Skills 仓库显示 0 个…

v4.0.26 Correctif MT

Cette version permet au centre d'autorisation et aux fiches fournisseurs officielles d'afficher le plan d'abonnement de chaque compte. Le compte GitHub Copilot listera tous les quotas plafonnés ; le lien d'importation en un clic peut désormais également importer des fournisseurs de Claude Desktop, MiniMax Code, Kimi Code, DeepSeek Harness et Oh My Pi.

 11/02
v4.0.25 Correctif MT

本版本为 MCP 页面增加了连通性检查，可以一键检查所有已启用的 MCP 服务器能不能连上；Codex 经本地路由用官方账号时，可以在额度快用完前自动暂停官方请求，第三方模型照常可用。另外，用量页的汇率可以自动获取，Codex 供应商表单可以设置子代理并发上限，Claude Code 和 Claude Desktop 经路由或聚合时，模型菜单会写明每个模型来自哪个供应商、实际是哪个模型，会话管理里也能删除 Kimi Code 会话了。

 10/31
v4.0.23 Correctif MT

本版本让 Kimi Code、MiniMax Code、Oh My Pi 的供应商编辑器按应用自己的格式显示配置文件里这一家的部分；Claude Code、Claude Desktop 经路由连 OpenAI 格式和 Gemini 的上游时，客户端选的思考档位能发给更多模型，卡片上还可以选怎么发；授权中心可以一键刷新所有账号的额度；Antigravity、MiniMax Code 的用量记录有了耗时和首字时间。

v4.0.22 Correctif MT

本版本新增对 DeepSeek Harness 的支持，它是 CC Switch 管理的第 14 个应用：供应商一起写进它的 Web 和 Desktop 配置，MCP、Skills、提示词同步给它，会话可以浏览，「应用」页可以安装、升级、卸载；还可以在授权中心登录 DeepSeek 账号、查看余额，用量也会统计。Oh My Pi 的用量现在也会统计。

 10/26
v4.0.21 Correctif MT

本版本为 Claude Code 增加了多个官方订阅账号的切换：在授权中心添加几个 Claude 账号，每张官方卡选一个，切到哪张卡，Claude Code 就用哪个号；想几个号同时用，从卡片上「打开终端」，那个终端固定用卡片上的号。登录走 Claude Code 官方的流程，令牌只留在本机的 Claude Code 里，CC Switch 不上传、不刷新、不登出。绑了账号的卡片和授权中心都会显示每个号的套餐和剩余额度。
