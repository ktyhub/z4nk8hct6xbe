mflux v.0.24.0

##0.24.0

Sécurité

  • L'oreiller 13.0.0 ou plus récent est désormais requis. Il corrige un débordement de tas critique dans le décodage FlashPix JPEG (GHSA-5x8w-8jj5-q52h) et d'autres avis. (#935)
  • MFlux nécessite désormais Pillow 13 et Python 3.11 ou plus récent. Python 3.10 n'est plus pris en charge. Mettez à niveau vers Python 3.11 ou une version plus récente pour installer cette version. (#933)
  • Les commandes mflux ne plantent plus au démarrage avec Pillow 13 (ImportError: cannot import name '_IntegralLike' from 'numbers'). (#890)

Nouveaux modèles

  • Nouveau modèle : FIBO 2 de Bria (Fibo 2.0 Dev et Fibo 2.0 Edit Turbo) avec mflux-generate-fibo2 et mflux-generate-fibo2-edit. Texte à image à partir de légendes ou de courtes descriptions du JSON, édition d'une à cinq images avec masques optionnels, texte rendu, LoRA et quantification. (#924)
  • Nouveau modèle : Anima de circlestone-labs (Turbo, Aesthetic et Base) avec mflux-generate-anima. Il charge les fichiers ComfyUI de circlestone-labs/Anima et prend en charge kohya LoRA, -q 4 à 8, --compute-precision float16 et mflux-save. (#931)
  • Nouveau modèle : MOSS-Image-SFT d'OpenMOSS, avec mflux-generate-moss-image. Il fonctionne entièrement en MLX, y compris son encodeur de texte Qwen3.5-9B, et prend en charge la quantification et mflux-save. (#914)
  • mflux-generate-iris exécute Iris-3B, un modèle texte-image 3B qui génère les pixels directement (pas de VAE) : Turbo en 4 étapes (--model iris-3b, la valeur par défaut) et le modèle de base (--model iris-3b-base). (#899)

Amélioré

  • FIBO 2 : mflux-generate-fibo2 exécute également Edit Turbo, et les deux commandes FIBO 2 prennent --expand-prompt (écrit la légende JSON avec FIBO-vlm), --cfg-end et --step-cache-ratio, vérifie une légende JSON avant le chargement du modèle et décode le VAE dans des bandes de mémoire faible. (#934)
  • mflux-generate-moss-image prend désormais --lora et conserve les LoRA comme couches d'exécution, de sorte que les LoRA distillées par étapes conservent toutes leurs mises à jour. --model moss-image-base exécute MOSS-Image-Base. (#929)
  • mflux-generate-qwen-2.1 et mflux-generate-qwen-2.1-edit ont un nouveau drapeau --small-text-encoder. Il utilise Qwen3.5-0.8B et l'adaptateur zen-image-edit au lieu de Qwen3-VL-8B, et télécharge environ 2.1 Go au lieu de 17.5 Go. (#906)
  • FLUX 3, FLUX.2 Klein, ERNIE-Image, Z-Image, Lens et Ideogram 4 décodent désormais le VAE en bandes de rangées bf16. Le décodage nécessite environ 1.6 Go à 1024 × 1024 au lieu de 7 à 14 Go. --vae-tiling ne change plus les couleurs. --vae-full-precision utilise le décodage d'image complète antérieur. (#910)
  • mflux-generate-flux2 et mflux-generate-flux2-edit ont un nouveau drapeau --small-text-encoder pour FLUX.2-klein-4B. Il utilise Qwen3-0.6B et un adaptateur au lieu de l'encodeur de texte 4B, le modèle a donc besoin de moins de mémoire. (#896)
  • mflux-generate-flux2 et mflux-generate-flux2-edit ont un nouveau drapeau --small-decoder. Il décode les images FLUX.2 klein avec le petit décodeur VAE de Black Forest Labs, qui est plus rapide et nécessite moins de mémoire. (#897)
  • mflux-save --hf-symlink [USERNAME] ajoute une entrée de cache Hugging Face qui renvoie aux fichiers enregistrés, donc --model USERNAME/<folder> charge le modèle enregistré par identifiant de dépôt. Super simple, mflux-save --model Qwen/Qwen-Image-2.1 -q 5 fonctionne désormais avec la dénomination automatique - nécessite la variable d'environnement MFLUX_MODELS_DIR (#903)
  • Les dépôts FLUX 3 publiés par mflux-community sont désormais résolus par leur nom uniquement : ajout d'alias avec trait d'union (flux-3-image-klein, flux-3-image-klein-base) afin que les noms de dépôt déduisent le modèle de base correct au lieu de lever "Impossible de déduire base_model". (#909)

Corrigé

  • Points de contrôle Krea 2 enregistrés sur Hugging Face, comme les dépôts mflux-community/krea-2-*, désormais chargés par identifiant de dépôt ; ils ont téléchargé sans leur transformateur et ont échoué. Un fichier passé en tant que --model obtient désormais une erreur qui le dit sur Krea 2, FLUX, FLUX.2 et Z-Image. (#873)
  • FLUX.2 petit : --config-from-metadata n'active plus le petit encodeur de texte lorsqu'un side-car enregistre "small_text_encoder" sous forme de chaîne telle que "false" ; il signale une erreur à la place. (#905)
  • Correction du crash du préprocesseur Z-Image ControlNet mlsd sur OpenCV 5, et autorisation opencv-python 5. (#901)

Modifié

  • mflux-check valide les packages de modèles locaux MFlux et Safetensors sans téléchargement. Utilisez --fix pour restaurer les fragments MFlux manquants à partir d'un instantané de cache local compatible. (#877)

Documents

  • L'exemple pip dans docs/plugins.md installe désormais mflux-teacache. Avant, pip install mflux-<name> échouait dans un shell car le shell lit < et > comme redirection. (#886)
  • Ajout de mfluxible, un serveur HTTP API avec un harnais de navigateur, un outil MCP et des points de terminaison compatibles OpenAI, à la liste des applications communautaires dans le README. (#885)

Interne

  • CI exécute désormais les tâches de test et d'enregistrement des modèles sur les coureurs macos-15 de GitHub, avant le retrait de l'image macos-14 le 2 novembre 2026. (#887)
  • Les tests rapides FLUX 3 comparent désormais les transformateurs distillés et de base avec les tenseurs de référence fixes FP32 et BF16, y compris le conditionnement d'image et les règles de pas de temps. (#883)
  • Les contributeurs de FLUX 3 peuvent enregistrer les timings de phase, les pics MLX lors des réinitialisations et RSS, avec une ligne de base reproductible de 32 Go q4. (#894)

mflux v.0.24.0

0.24.0

Security

  • Pillow 13.0.0 or newer is now required. It fixes a critical heap overflow in FlashPix JPEG decoding (GHSA-5x8w-8jj5-q52h) and other advisories. (#935)
  • MFlux now requires Pillow 13 and Python 3.11 or newer. Python 3.10 is no longer supported. Upgrade to Python 3.11 or newer to install this version. (#933)
  • mflux commands no longer crash at startup with Pillow 13 (ImportError: cannot import name '_IntegralLike' from 'numbers'). (#890)

New models

  • New model: FIBO 2 from Bria (Fibo 2.0 Dev and Fibo 2.0 Edit Turbo) with mflux-generate-fibo2 and mflux-generate-fibo2-edit. Text-to-image from JSON captions or short descriptions, editing of one to five images with optional masks, rendered text, LoRA and quantization. (#924)
  • New model: Anima from circlestone-labs (Turbo, Aesthetic and Base) with mflux-generate-anima. It loads the ComfyUI files of circlestone-labs/Anima and supports kohya LoRAs, -q 4 to 8, --compute-precision float16 and mflux-save. (#931)
  • New model: MOSS-Image-SFT from OpenMOSS, with mflux-generate-moss-image. It runs fully in MLX, including its Qwen3.5-9B text encoder, and supports quantization and mflux-save. (#914)
  • mflux-generate-iris runs Iris-3B, a 3B text-to-image model that generates the pixels directly (no VAE): Turbo in 4 steps (--model iris-3b, the default) and the base model (--model iris-3b-base). (#899)

Improved

  • FIBO 2: mflux-generate-fibo2 also runs Edit Turbo, and both FIBO 2 commands take --expand-prompt (writes the JSON caption with FIBO-vlm), --cfg-end and --step-cache-ratio, check a JSON caption before the model loads and decode the VAE in low-memory strips. (#934)
  • mflux-generate-moss-image now takes --lora and keeps LoRAs as runtime layers, so step-distilled LoRAs keep all of their update. --model moss-image-base runs MOSS-Image-Base. (#929)
  • mflux-generate-qwen-2.1 and mflux-generate-qwen-2.1-edit have a new --small-text-encoder flag. It uses Qwen3.5-0.8B and the zen-image-edit adapter instead of Qwen3-VL-8B, and downloads about 2.1 GB instead of 17.5 GB. (#906)
  • FLUX 3, FLUX.2 Klein, ERNIE-Image, Z-Image, Lens and Ideogram 4 now decode the VAE in bf16 row strips. The decode needs approximately 1.6 GB at 1024×1024 instead of 7–14 GB. --vae-tiling no longer shifts the colours. --vae-full-precision uses the earlier full-image decode. (#910)
  • mflux-generate-flux2 and mflux-generate-flux2-edit have a new --small-text-encoder flag for FLUX.2-klein-4B. It uses Qwen3-0.6B and an adapter instead of the 4B text encoder, so the model needs less memory. (#896)
  • mflux-generate-flux2 and mflux-generate-flux2-edit have a new --small-decoder flag. It decodes FLUX.2 klein images with the small VAE decoder from Black Forest Labs, which is faster and needs less memory. (#897)
  • mflux-save --hf-symlink [USERNAME] adds a Hugging Face cache entry that links to the saved files, so --model USERNAME/<folder> loads the saved model by repo id. Super simple mflux-save --model Qwen/Qwen-Image-2.1 -q 5 now works with auto-naming - requires env var MFLUX_MODELS_DIR (#903)
  • Published mflux-community FLUX 3 repos now resolve by name alone: added hyphenated aliases (flux-3-image-klein, flux-3-image-klein-base) so repo names infer the correct base model instead of raising "Cannot infer base_model". (#909)

Fixed

  • Saved Krea 2 checkpoints on Hugging Face, like the mflux-community/krea-2-* repos, now load by repo id; they downloaded without their transformer and failed. A file passed as --model now gets an error that says so on Krea 2, FLUX, FLUX.2 and Z-Image. (#873)
  • FLUX.2 klein: --config-from-metadata no longer turns on the small text encoder when a sidecar records "small_text_encoder" as a string such as "false"; it reports an error instead. (#905)
  • Fix the Z-Image ControlNet mlsd preprocessor crashing on OpenCV 5, and allow opencv-python 5. (#901)

Changed

  • mflux-check validates local MFlux and Safetensors model packages without downloads. Use --fix to restore missing MFlux shards from a compatible local cache snapshot. (#877)

Docs

  • The pip example in docs/plugins.md now installs mflux-teacache. Before, pip install mflux-<name> failed in a shell because the shell reads < and > as redirection. (#886)
  • Added mfluxible, an HTTP API server with a browser harness, MCP tool and OpenAI-compatible endpoints, to the community applications list in the README. (#885)

Internal

  • CI now runs the test and model-registry jobs on GitHub's macos-15 runners, ahead of the macos-14 image's retirement on November 2, 2026. (#887)
  • FLUX 3 fast tests now compare distilled and Base transformers with fixed FP32 and BF16 reference tensors, including image conditioning and timestep rules. (#883)
  • FLUX 3 contributors can record phase timings, MLX peaks across resets and RSS, with a reproducible 32 GB q4 baseline. (#894)
