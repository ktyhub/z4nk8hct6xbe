agentscope v2.0.10

Highlights

  • New provider capabilities — Adds OpenAI Decisions API support for classifiers (#3174) and Qwen3.8 Omni Realtime support (#3196), giving developers native integrations for API-backed classification and real-time multimodal applications.
  • App configuration migration — Text-mode settings are now grouped under chat_config (#2570). Move programmatically constructed, persisted, or externally supplied text-mode fields into that object before upgrading, and update code that reads the previous top-level locations.
  • TTS contract and failure handling — TTSModelBase is now a true abstract base class (#2956), so custom subclasses must satisfy its abstract-method requirements and direct base-class instantiation is no longer valid. DashScope now honors per-call voice and speech instructions (#3002, #2990), propagates DashScope and CosyVoice callback errors (#2993, #3042), and wraps non-streaming chat audio in a valid WAV container (#3028). Synthesis failures should now reach application error handling instead of producing misleading output.
  • More reliable cross-provider tool calling — Ollama tool calls receive unique IDs (#3011), while argument-less Anthropic and OpenAI Responses calls stream as {} (#3008, #3229), preventing correlation failures and malformed empty payloads. Responses API stream errors now propagate (#3086), and refusal and reasoning text is preserved (#3136, #2916); review retry logic that previously relied on incomplete streams being accepted.
  • Higher-fidelity RAG ingestion — Word parsing preserves omitted table columns and embedded cell images (#2961, #3064); Excel preserves duplicate and blank headers plus native error cells (#2948, #3204); deferred PDF and PPTX errors are normalized (#2975, #3217). This reduces silent document-schema drift, but downstream mappings that assumed deduplicated headers or discarded table content should be retested.
  • Safer tools and clearer orchestration outcomes — Filesystem tools resolve symlinks before dangerous-path checks and unlink links without following their targets (#3033, #3006); empty edit targets are rejected (#2995); and injected state is omitted from inferred function schemas (#3090). Budget exhaustion no longer blocks structured output (#3027), while failed SOP steps and pipeline rounds now produce accurate outcomes (#3096, #2982), so monitoring may correctly report failures that were previously missed.
