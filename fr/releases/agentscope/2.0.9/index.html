agentscope v2.0.9

Correctif Publié28 sept. 2026 Sourceagentscope-ai/agentscope Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

champ d'application de l'agent v2.0.9

Mettre en surbrillance

  • Procédures opérationnelles standard (expérimentales) : Ajout du module agentscope.sop pour diviser une tâche en jalons ordonnés, chacun vérifié avant le démarrage du suivant, avec un état d'exécution qui peut être conservé et repris. Le service d'agent expose également les points de terminaison /sop pour stocker des procédures, démarrer des exécutions et réviser manuellement les étapes.
  • Team Pipeline : ajout d'une classe TeamPipeline dans laquelle un agent leader délègue des tâches aux agents membres, qui s'exécutent simultanément et rendent leurs résultats.
  • Plus de modèles vocaux en temps réel : ajout de modèles vocaux OpenAI Realtime, Gemini Live et xAI Grok à l'agent vocal en temps réel.
  • Interface utilisateur du terminal : introduction du module agentscope.tui, une interface de terminal plein écran pour discuter avec les agents et exécuter des sessions vocales en temps réel via launch_realtime_ui.
  • AskUser Tool : ajout de AskUser, un outil externe qui permet aux agents de poser des questions à choix multiples aux utilisateurs.
  • Modèle MiniMax et routage de modèles basé sur Jev : Ajout du modèle de discussion MiniMax (M3 par défaut) et d'un ModelRouterMiddleware soutenu par le nouveau module agentscope.classifier (avec prise en charge de Jev) qui sélectionne le modèle de discussion pour chaque réponse.
  • Outils de base de connaissances DingTalk : les agents sur les canaux DingTalk peuvent désormais effectuer des recherches dans les bases de connaissances DingTalk.
  • Contrôles d'autorisation Shell plus sûrs : détection renforcée des commandes en lecture seule afin que les utilisations destructrices de git, sed et tee n'ignorent plus la confirmation des autorisations.

agentscope v2.0.9

Highlight

  • Standard Operating Procedures (Experimental): Added the agentscope.sop module for splitting a task into ordered milestones, each verified before the next one starts, with run state that can be persisted and resumed. The agent service also exposes /sop endpoints to store procedures, start runs, and review steps by hand.
  • Team Pipeline: Added a TeamPipeline class where a leader agent delegates tasks to member agents, which run concurrently and hand their results back.
  • More Realtime Voice Models: Added OpenAI Realtime, Gemini Live, and xAI Grok Voice models to the realtime voice agent.
  • Terminal UI: Introduced the agentscope.tui module, a full-screen terminal interface for chatting with agents and running realtime voice sessions via launch_realtime_ui.
  • AskUser Tool: Added AskUser, an external tool that lets agents ask users multiple-choice questions.
  • MiniMax Model and Jev-based Model Routing: Added the MiniMax chat model (M3 by default), and a ModelRouterMiddleware backed by the new agentscope.classifier module (with Jev support) that picks the chat model for each reply.
  • DingTalk Knowledge Base Tools: Agents on DingTalk channels can now search DingTalk knowledge bases.
  • Safer Shell Permission Checks: Tightened read-only command detection so destructive git, sed, and tee usages no longer skip permission confirmation.
