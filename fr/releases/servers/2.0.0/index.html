Serveurs Python : changements pour clients

mcp-server-fetch, mcp-server-git et mcp-server-time n'ont pas de CHANGELOG, voici donc ce qui change pour un client dans 2026.10.19. Ils sont désormais construits sur le MCPServer de haut niveau du MCP Python SDK (#5175).

  • Outil inconnu : une erreur JSON-RPC -32602 (Unknown tool: <name>) dans les deux époques de protocole, comme l'exige la spécification. C'était auparavant un résultat isError.
  • Erreurs d'outil lire Error executing tool <name>: <message>. Les erreurs de validation d'argument utilisent désormais la formulation de pydantic. Les deux sont toujours des résultats isError.
  • Capacités : chaque serveur annonce désormais les capacités prompts et resources (avec listChanged: false). L'invite fetch de fetch est la seule entrée dans ces listes.
  • time : get_current_time et convert_time déclarent un outputSchema et renvoient structuredContent. Le contenu du texte est inchangé.
  • fetch : le description d'un résultat prompts/get est désormais toujours la description enregistrée de l'invite.
  • Nécessite mcp>=2.3,<3.

Python servers: changes for clients

mcp-server-fetch, mcp-server-git and mcp-server-time have no CHANGELOG, so here is what changes for a client in 2026.10.19. They are now built on the MCP Python SDK's high-level MCPServer (#5175).

  • Unknown tool: a JSON-RPC -32602 error (Unknown tool: <name>) in both protocol eras, as the spec requires. It used to be an isError result.
  • Tool errors read Error executing tool <name>: <message>. Argument-validation errors now use pydantic's wording. Both are still isError results.
  • Capabilities: each server now advertises prompts and resources capabilities (with listChanged: false). fetch's fetch prompt is the only entry in those lists.
  • time: get_current_time and convert_time declare an outputSchema and return structuredContent. The text content is unchanged.
  • fetch: a prompts/get result's description is now always the prompt's registered description.
  • Requires mcp>=2.3,<3.
