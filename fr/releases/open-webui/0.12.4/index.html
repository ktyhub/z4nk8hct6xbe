  • 🚫 Model import reports taken IDs. Importing models on the Workspace Models page now stops with an error at a model whose ID belongs to another user's model the importer cannot edit or, for non-admins, to a connection model, where that model was skipped without a message. #32866, Commit
  • 🎞️ Left-aligned PowerPoint titles. The PowerPoint preview now keeps titles and subtitles that the file aligns left on the left, where it centered them. #32876, Commit, #32873
  • 🫥 Multi-model hover previews. Sidebar hover previews of a chat with replies from several models now show one reply at full width, where every reply was squeezed into the card. Commit, #32858
  • 🐚 Launcher help in zsh. The examples in the Docker Compose launcher help now quote options with square brackets, so they also work when pasted into zsh. #32881, Commit, #32878
  • 🌡️ Context gauge uses model threshold. The context usage gauge now measures against the compaction threshold set on the model or in the default model parameters, the same one compaction uses, where it ignored a lower threshold on the model and showed a chat as far from compaction. With the Redis websocket manager and "retry_on_timeout" in "WEBSOCKET_REDIS_OPTIONS", an instance now accepts new browser connections again once Redis is back after its connection dropped, where since 0.12.3 every new connection could hang until the instance was restarted. #33009, Commit, #33008

Commit, Commit

Commit
