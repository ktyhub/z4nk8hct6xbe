  • 🛡️ Avis de sécurité : cette version contient des correctifs de sécurité. Nous recommandons fortement de mettre à jour tous les déploiements dès que possible pour disposer des derniers correctifs de sécurité en place. Ces correctifs ne sont pas répertoriés dans ce changelog ; nous publierons les avis de sécurité les concernant immédiatement après l'attribution du CVE. Avis
  • 🔃 Les nouveaux chats restent synchronisés. Un chat démarré depuis la page d'accueil continue de se synchroniser avec le serveur après sa création, de sorte que les fichiers supprimés des contrôles du chat ne reviennent plus après un rechargement et le propriétaire d'un chat partagé avec Autoriser les réponses obtient à nouveau une régénération sur les réponses des autres personnes. #33377, #33376
  • 📂 ** Chat temporaire sur les pages de dossier. ** Activer ou désactiver le chat temporaire sur la page d'un dossier, avec le bouton en haut ou avec "/temporary", vous maintient désormais sur la page du dossier, de sorte que le chat suivant est toujours enregistré dans le dossier et obtient son invite système, son modèle par défaut et ses connaissances. #33456, #33448
  • 🧵 Focus sur la réponse du fil de discussion. Choisir Répondre dans le fil de discussion sur un message de canal place désormais le curseur dans la zone de réponse du fil de discussion, également lorsque le panneau du fil de discussion est déjà ouvert. #33467, #33466
  • 🪟 Actions du message de fil de discussion visibles. Le survol du message supérieur dans un fil de discussion affiche désormais toute sa barre d'outils d'actions au lieu de couper sa moitié supérieure au bord du panneau. Commettre, #33472
  • 📞 Interruption des appels en temps réel. L'interruption du modèle pendant qu'il parle lors d'un appel vocal en temps réel ne met plus fin à l'ensemble de l'appel lorsque la position de lecture signalée ne correspond pas à l'audio. Commettre, #33550
  • 📶 Chats temporaires après reconnexion. Une réponse qui est toujours en cours d'écriture dans un chat temporaire continue désormais d'arriver après la coupure et le retour de la connexion, et une réponse qui n'a pas pu se terminer affiche "Connexion perdue. Veuillez réessayer." au lieu de charger pour toujours. Commettre
  • 🏠 Nouvelle initialisation du chat. L'ouverture ou le rechargement de la page d'accueil ou d'un dossier sélectionne désormais le modèle et applique à nouveau les paramètres d'URL du chat, au lieu de laisser le modèle vide et d'ignorer les paramètres du lien. Commettre
  • ✍️ Brouillons de discussion restaurés. Le brouillon de texte enregistré revient désormais à la saisie du message après le montage du nouvel éditeur de discussion, au lieu de disparaître lors de l'initialisation. S'engager
  • 🧩 Aperçus de code imbriqués. L'aperçu ouvre désormais les blocs de code dans les listes, les citations et les blocs de détails, afin que les exemples intégrés et les artefacts générés puissent être inspectés directement. Commettre
  • 🖼️ Image supprimée des applications photo. Les images déposées dans les discussions et les chaînes sont désormais reconnues à partir de leur contenu lorsque la source omet le type de fichier, y compris les photos glissées depuis macOS Photos, au lieu d'être traitées comme des fichiers génériques.   • 📏 Estimations d'utilisation du contexte en direct. open-webui v0.13.0

Added

  • 📑 Tabbed workspace. The Tabs button at the top of a chat now opens a workspace for files, multiple terminal sessions, artifacts, previews, voice calls and comments. Add tabs from the + menu, drag to reorder them, and create and save new files directly into the selected terminal. Keep the conversation and its working files together while coding, analyzing data or reviewing generated documents. Commit, Commit, Commit, Commit
  • 🖥️ Open Terminal Desktop tab for computer use. Open the Desktop tab from the + menu to view and control the desktop provided by your connected Open Terminal, with mouse, keyboard, clipboard and audio support where available. With a model that can call its desktop tools, you can follow computer-use workflows in the same desktop and step in yourself: operate graphical apps, inspect generated documents or handle a step that needs manual input. Requires an Open Terminal connection with desktop support enabled. Commit, Commit, Commit, Commit
  • 🌐 Browser tab for browser use and web app testing. Open websites and local development servers beside your chat, with navigation controls, multiple tabs and a mobile viewport. On a compatible Open Terminal connection, Chrome mode gives you and the model a shared browser session for browser automation: navigate sites, interact with forms and test the web apps the model builds. You can watch the work and interact with the page yourself; Proxy mode remains available for previews. Requires browser support on the selected terminal, and Chrome availability for browser-use tools. Commit, Commit, Commit
  • ↔️ Full-width tabs. On larger screens, expand the tabbed workspace to fill the chat area, with the main conversation kept as its own tab. Switch between the chat, code, browser and desktop with more room to work, or return to the side-by-side layout; your layout choice is remembered. Commit, Commit
  • 💻 Open WebUI Desktop 0.1.x. The separately installed app for macOS, Windows and Linux now focuses on setting up and running Open WebUI on your own computer, with optional llama.cpp local models. The 0.1.0–0.1.4 updates bring a slimmer interface, searchable settings, startup logs, optional automatic Desktop updates, start-to-tray controls and image copying and saving. They also improve screen sharing, knowledge folder uploads, Linux graphics and shortcuts, and NVIDIA/AMD local-model setup and updates. Use it for a managed local installation and local AI workflows. Desktop changelog, Download v0.1.4
  • 🌿 Git in the side panel. When the selected terminal's folder is a Git repository, a Git panel in the tabbed side panel now lets you review diffs, stage, discard and commit changes, manage branches and worktrees, push and pull, browse history and work with GitHub pull requests, and open files can show their changes with Show diff. Commit, Commit, Commit, Commit, Commit
  • ⚡ Live terminal updates. On terminals that support it, the Git panel, the list of open ports and the running processes and their output now update as soon as something changes instead of every few seconds. Commit, Commit
  • 💭 Side chats. Typing "/side" or "/btw" in a chat, or choosing Side chat in the side panel, now opens a temporary side conversation using the chat so far as context. Ask a quick question or explore an alternative without adding the detour to the main conversation; the side chat disappears when you close its tab. Available to administrators and users given the new Allow Side Chat permission, which is off by default. Commit, Commit, Commit
  • 💬 Comment threads. Administrators can now turn on Comments in Admin Settings > General or with "ENABLE_COMMENTS", which lets users leave comments with replies, reactions and mentions on the chats, notes, models, knowledge bases, prompts, skills and tools they can open, including on a selected passage of a chat message, which then stays highlighted in the reply, or of a note page, shown in a Comments tab in the chat's side panel, which "/comments" opens, and with comment counts in the workspace lists. Commit, Commit, Commit, Commit
  • 🔔 Notification inbox. A new Inbox in the sidebar collects comments on your items, replies to your comments, mentions in comments and channels, replies in channels, failed automation runs and upcoming calendar events with an unread count, and administrators can turn it off in Admin Settings > General or with "ENABLE_NOTIFICATIONS". Commit, Commit, #19539
  • 🧩 MCP Apps in chat. Tools from MCP servers that come with an interactive app now show that app right in the chat after they run, in a sandboxed frame that can only reach the sites the server declares, and every tool call the app wants to make waits for you to confirm it. Commit, Commit, #21040, #20915
  • ✨ Generate title from top bar. The rename field at the top of an open chat now has the same sparkle button as the sidebar, which generates a title from the conversation and saves it right away. #33382
  • 📐 Side panels on tablets. On screens from 768 pixels wide, such as tablets and narrow windows, channel threads and the pages list and chat in notes now open beside the content instead of over it, picking a terminal opens its files beside the chat as well, and the search dialog shows its preview there by default and remembers whether you turned it on or off at any window size. Commit, Commit
  • 📊 More PowerPoint charts. The PowerPoint preview now draws pie, doughnut and horizontal bar charts as well as values below zero, and shows "Chart preview unavailable" for charts it cannot draw. Commit, #32884
  • 🧊 3D model previews. GLB, glTF, STL, OBJ and PLY files in a terminal's file browser and in files shown in chat replies now open in a 3D viewer that you can rotate and zoom. Commit
  • 🔘 Switch tools on and off. Tools in Workspace > Tools now have an on and off switch for everyone who can edit them, and a tool that is switched off can no longer be picked or run in any chat, including chats where it was already selected. Commit
  • 🛠️ Tool creation from chat. Models with native function calling can now create a private Python tool in your workspace when you ask them to, for administrators and users allowed to create workspace tools, and it can be turned off per model under Tool Creation in the model editor's builtin tools. Commit
  • 🤝 Multi-model sub-agents. The model editor now lets you choose other models for a model to delegate work to, enabling multi-agent workflows such as assigning research, coding and review to different models. The parent model chooses among the configured models the user can access; previously, sub-agents always used the same model as the parent. Commit
  • 📏 Knowledge base file limits. Administrators can now cap how many files a knowledge base holds, how large each of its files may be and how many files go into it in one upload, for all knowledge bases in Admin Settings > Documents or with "KNOWLEDGE_MAX_FILE_COUNT", "KNOWLEDGE_MAX_FILE_SIZE" and "KNOWLEDGE_MAX_UPLOAD_COUNT", and a knowledge base's owner can set its own file count and size limits under Advanced when creating it or from Settings in its menu, while the global limits always apply. Commit, Commit, #33318, #24845
  • 📄 File sizes in previews. Opened terminal files now show their size in the file toolbar, so you can check a document or generated output without leaving its preview. Commit
  • 🗂️ Sort files by date added. The terminal file browser can now sort files by when they were added, next to name, size and date modified, on terminals that report creation times. Commit
  • ↕️ Move blocks in notes. Every paragraph, heading and other block in a note now has a handle beside it that you can drag to move the block, or click to move it up or down. Commit
  • 📋 Copy code in notes. Code blocks in notes now have a Copy button and use clearer syntax colors in light mode. Commit, Commit, #33455
  • ⏸️ Approvals shown in sidebar. Chats in the sidebar now show a "Waiting for approval" marker while a tool call in them waits for you to allow or deny it. Commit, Commit
  • 🏷️ Role prompt variable. System prompts, saved prompts and chat requests through the API can now use "{{USER_ROLE}}", which is replaced with the signed-in user's role, such as admin or user. #33441, #4765
  • ♿ Accessibility improvements. Screen reader users now hear a name for every window, form field, setting and icon button, including Admin Settings, Valves, filters and channel message actions, and keyboard users can answer tool approvals, dismiss notifications, open model details in Admin Analytics, sort Analytics and group member tables, resize the sidebar, open notebook cells for editing, use multi-select lists in Valves, pick a status emoji, choose tag and voice suggestions, open the sources of a web search, use the menus in the Search window, stay inside the full-size image viewer and side drawers until they close them and reach every event on the calendar. Closing a window opened from a menu now returns focus to the menu button, Tab cancels shortcut recording, task-list checkboxes are named by their text, and unselected Analytics tabs have better contrast in Accessibility Mode. Commit, Commit, Commit, Commit
  • 🔄 General improvements. Various improvements were implemented across the application to enhance performance, stability, and security.
  • 🌐 Translation updates. Translations for Portuguese (Brazil), Latvian, Azerbaijani, Basque, Bengali, Bosnian, Bulgarian, Cebuano, Croatian, Czech, Danish, Dutch, Estonian, Faroese, Filipino, Galician, German, Greek, Hebrew, Hungarian, Indonesian, Irish, Japanese, Korean, Lithuanian, Malay, Norwegian Bokmål, Persian, Polish, Punjabi, Romanian, Russian, Serbian, Slovak, Slovenian, Spanish (Spain), Tamil, Turkish, Turkmen, Ukrainian and Vietnamese were enhanced and expanded.

Fixed

  • 🛡️ Security Advisory: This release contains security fixes. We strongly recommend updating all deployments as soon as possible to have the latest security fixes in place. These fixes are not listed in this changelog; we will publish the security advisories for them immediately following CVE assignment. Advisories
  • 🔃 New chats stay in sync. A chat started from the home page keeps syncing with the server again after it is created, so files removed from the chat's Controls no longer come back after a reload and the owner of a chat shared with Allow replies gets Regenerate on other people's replies again. #33377, #33376
  • 📂 Temporary Chat on folder pages. Turning Temporary Chat on or off on a folder's page, with the button at the top or with "/temporary", now keeps you on the folder page, so the next chat is still saved in the folder and gets its system prompt, default model and knowledge. #33456, #33448
  • 🧵 Thread reply focus. Choosing Reply in Thread on a channel message now puts the cursor in the thread's reply box, also when the thread panel is already open. #33467, #33466
  • 🪟 Thread message actions visible. Hovering the top message in a channel thread now shows its whole actions toolbar instead of cutting off its top half at the edge of the panel. Commit, #33472
  • 📞 Interrupting realtime calls. Interrupting the model while it speaks in a realtime voice call no longer ends the whole call when the reported playback position does not match the audio. Commit, #33550
  • 📶 Temporary chats after reconnecting. A reply that is still being written in a temporary chat now keeps arriving after the connection drops and comes back, and a reply that could not finish shows "Connection lost. Please retry." instead of loading forever. Commit
  • 🏠 New chat initialization. Opening or reloading the home page or a folder now selects the model and applies chat URL parameters again, instead of leaving the model empty and ignoring the link’s settings. Commit
  • ✍️ Restored chat drafts. Saved draft text now returns to the message input after the new-chat editor mounts, instead of disappearing during initialization. Commit
  • 🧩 Nested code previews. Preview now opens code blocks inside lists, quotes and details blocks, so embedded examples and generated artifacts can be inspected directly. Commit
  • 🖼️ Image drops from photo apps. Images dropped into chats and channels are now recognized from their contents when the source omits the file type, including photos dragged from macOS Photos, instead of being treated as generic files. Commit
  • 📏 Live context usage estimates. The context indicator now accounts for output arriving after the latest reported token usage and avoids counting assistant text twice when it also appears in structured output, making it easier to track context-window usage during long agent runs. Commit
  • 🔌 Responses-backed API streaming. Clients using Open WebUI’s Chat Completions API now receive the expected streaming format even when the upstream model uses the Responses API, including text, reasoning, tool calls, token usage and completion reasons. Commit
  • 😀 Channel reaction names. Hovering a reaction on a channel message now shows who reacted when those names are available, instead of showing only the count. Commit
  • 📊 Analytics activity scrolling. The activity chart now tracks the element actually being scrolled, keeping its visible rows in sync when browsing longer activity lists. Commit
  • 🔑 Saved OAuth provider settings. OAuth providers now load their saved connection settings when Open WebUI starts. Admin Settings also explains that changes to provider connections require restarting every Open WebUI instance. Commit

Changed

  • ⚠️ Database Migrations: This release includes database schema changes; we strongly recommend backing up your database and all associated data before upgrading in production environments. If you are running a multi-worker, multi-server, or load-balanced deployment, all instances must be updated simultaneously, rolling updates are not supported and will cause application failures due to schema incompatibility.
  • 🎛️ Controls in the model menu. The chat files, valves, system prompt and advanced parameters moved from the Controls panel at the top of the chat to Controls in the model controls menu next to the message input, and the button at the top now opens the tabbed side panel. Commit, Commit
  • 🗺️ Overview in the chat menu. The chat Overview, the map of all messages and their branches, now opens as a full-screen window from Overview in the chat's menu instead of as a tab in Chat Controls. Commit
  • 🔁 Higher tool-call limit. A single response with native function calling can now run up to 1024 rounds of tool calls before it stops with "Tool-call limit reached", up from 256, and setting "CHAT_RESPONSE_MAX_TOOL_CALL_ITERATIONS" to 256 keeps the old limit. #33384
  • 🔓 No sub-agent limits by default. The sub-agent limits in Admin Settings and through "SUBAGENTS_MAX_CONCURRENT", "SUBAGENTS_MAX_ASYNC", "SUBAGENTS_MAX_ITERATIONS" and "SUBAGENTS_MAX_OUTPUT" now default to no limit, and leaving one empty means no limit, where they defaulted to 20 at once, 20 in the background, 30 tool loops each and 30000 characters of output. Commit
  • 🧠 Context compaction and prompt caching. When the same model handles the conversation and its compaction summary, eligible requests now reuse the conversation’s prompt structure so the provider can use its prompt cache. This can reduce the cost of summarizing long conversations and agent workflows; other requests retain the separate summary path. Commit
  • 💻 Desktop 0.1.x upgrade changes. Open WebUI Desktop no longer switches between remote servers, bundles Open Terminal, or provides the old Spotlight and global voice overlays. Existing remote-connection users should review Open WebUI Tether. The Open Terminal Desktop and Browser tabs described above use a separately configured Open Terminal connection. Desktop 0.1.0 release notes
  • 📭 File processing alerts removed. Personal notifications in Settings > Notifications no longer offer "Retrieval Content process failed", so notification webhooks no longer receive an alert when a file fails to process. Commit
