druide druide-0.14.1-incubating

Apache Druid 0.14.1-incubating est une petite version de correctif qui comprend une poignée de correctifs de bogues et de documentation provenant de 16 contributeurs.

Avis important

Cette version corrige un problème avec l'extension druid-datasketches avec les esquisses quantiles, mais en introduit un autre avec les esquisses thêta qui a été confirmé après la finalisation de la version, provoqué par #7320 et décrit dans #7607. Si vous utilisez des croquis thêta, nous vous recommandons ne de mettre à niveau vers cette version. Cela sera corrigé dans la prochaine version de Druid par #7619.

Corrections de bugs

  • utilisez les derniers croquis-core-0.13.1 #7320
  • Ajustez les impls BufferAggregator.get() pour renvoyer des copies #7464
  • DoublesSketchComplexMetricSerde : gère les chaînes vides. #7429
  • gérer les croquis vides #7526
  • Ajoute un serde rétrocompatible pour SeekableStreamStartSequenceNumbers. #7512
  • Prise en charge du superviseur Kafka pour l'adoption des tâches en cours d'exécution entre les versions #7212
  • Correction du topN d'extraction du temps avec un type de sortie non-STRING. #7257
  • Correction de deux problèmes avec la communication Coordinateur -> Overlord. #7412
  • refactoriser les agrégateurs druid-bloom-filter #7496
  • Correction de la vérification codée de taskId dans chatHandlerResource #7520
  • Correction d'un trop grand nombre d'objs de dalle de cache dentry #7508. #7509
  • Correction du cache au niveau des résultats pour les requêtes #7325
  • Correction de l'aplatissement des cartes Avro avec les clés Utf8 #7258
  • Écrivez un octet nul lors de l'indexation de dimensions numériques avec Hadoop #7020
  • La tâche d'ingestion Hadoop par lots ne fonctionne pas correctement avec la table de segments personnalisés #7492
  • Correction de l'exception de fusion de méta-aggregatorFactory #7504

Modifications de la documentation

  • Correction d'un lien brisé en raison d'une faute de frappe. #7513
  • Optimisation de certaines documents #6890
  • Mise à jour de la documentation de configuration Javascript Affinity #7441
  • Correction de la table des opérateurs de la documentation sur les expressions #7420
  • Correction des informations contradictoires dans le document de configuration #7299
  • Ajouter un lien vers la documentation manquante pour les opérations/http-compression.html #7110

Mise à jour depuis 0.14.0-incubating et versions antérieures

Ingestion de Kafka

La mise à jour depuis la version 0.13.0-incubating ou antérieure directement vers 0.14.1-incubating ne nécessitera pas de temps d'arrêt comme le chemin de migration vers 0.14.0-incubating en raison du problème décrit dans #6958, qui a été corrigé pour cette version dans #7212. De même, les mises à jour progressives à partir de la version 0.13.0-incubating et des versions antérieures devraient également fonctionner correctement en raison du #7512.

Ingestion parallèle native

La mise à jour de 0.13.0-incubating directement vers 0.14.1-incubating ne rencontrera pas de problèmes lors d'une mise à jour continue avec des versions mixtes de managers intermédiaires en raison des correctifs du #7520, comme cela pourrait être le cas lors de la mise à jour vers 0.14.0-incubating.

druid druid-0.14.1-incubating

Apache Druid 0.14.1-incubating is a small patch release that includes a handful of bug and documentation fixes from 16 contributors.

Important Notice

This release fixes an issue with druid-datasketches extension with quantile sketches, but introduces another one with theta sketches that was confirmed after the release was finalized, caused by #7320 and described in #7607. If you utilize theta sketches, we recommend not upgrading to this release. This will be fixed in the next release of Druid by #7619.

Bug Fixes

  • use latest sketches-core-0.13.1 #7320
  • Adjust BufferAggregator.get() impls to return copies #7464
  • DoublesSketchComplexMetricSerde: Handle empty strings. #7429
  • handle empty sketches #7526
  • Adds backwards-compatible serde for SeekableStreamStartSequenceNumbers. #7512
  • Support Kafka supervisor adopting running tasks between versions #7212
  • Fix time-extraction topN with non-STRING outputType. #7257
  • Fix two issues with Coordinator -> Overlord communication. #7412
  • refactor druid-bloom-filter aggregators #7496
  • Fix encoded taskId check in chatHandlerResource #7520
  • Fix too many dentry cache slab objs#7508. #7509
  • Fix result-level cache for queries #7325
  • Fix flattening Avro Maps with Utf8 keys #7258
  • Write null byte when indexing numeric dimensions with Hadoop #7020
  • Batch hadoop ingestion job doesn't work correctly with custom segments table #7492
  • Fix aggregatorFactory meta merge exception #7504

Documentation Changes

  • Fix broken link due to Typo. #7513
  • Some docs optimization #6890
  • Updated Javascript Affinity config docs #7441
  • fix expressions docs operator table #7420
  • Fix conflicting information in configuration doc #7299
  • Add missing doc link for operations/http-compression.html #7110

Updating from 0.14.0-incubating and earlier

Kafka Ingestion

Updating from version 0.13.0-incubating or earlier directly to 0.14.1-incubating will not require downtime like the migration path to 0.14.0-incubating due to the issue described in #6958, which has been fixed for this release in #7212. Likewise, rolling updates from version 0.13.0-incubating and earlier should also work properly due to #7512.

Native Parallel Ingestion

Updating from 0.13.0-incubating directly to 0.14.1-incubating will not encounter any issues during a rolling update with mixed versions of middle managers due to the fixes in #7520, as could be experienced when updating to 0.14.0-incubating.

Apache Druid (incubating) is an effort undergoing incubation at The Apache Software Foundation (ASF), sponsored by the Apache Incubator. Incubation is required of all newly accepted projects until a further review indicates that the infrastructure, communications, and decision making process have stabilized in a manner consistent with other successful ASF projects. While incubation status is not necessarily a reflection of the completeness or stability of the code, it does indicate that the project has yet to be fully endorsed by the ASF.
