pi v1.3.0

pi v1.3.0

Nouvelles fonctionnalités

  • Choisissez où /share télécharge : sessionShareDestination sélectionne auto, gist ou radius. Voir Sessions et contexte et Exporter ou partager une session.
  • Modifications du niveau de réflexion préservant le cache sur OpenAI GPT-6 : la modification du niveau de réflexion en cours de session avec une clé API conserve le cache d'invite.
  • Kimi Code over Chat Completions : les outils ajoutés en cours de conversation n'invalident plus le cache d'invite. Les remplacements d'URL de base models.json doivent désormais inclure /v1. Voir Fournisseurs.
  • Changement de modèle propre : la réflexion à partir d'un modèle précédent est abandonnée au lieu d'être présentée au nouveau modèle sous forme de texte.
  • Les sessions reprises conservent leurs outils actifs : --tools +name/-name s'applique par-dessus. Voir Outils.

Ajouté

  • La modification du niveau de réflexion en cours de session sur les modèles OpenAI GPT-6 (clé API) conserve désormais le cache d'invite (#10853)
  • Ajout du paramètre sessionShareDestination pour choisir les téléchargements automatiques, GitHub Gist ou Radius pour /share (#10870 par @vegarsti).

Modifié

  • Modification du fournisseur kimi-coding pour utiliser OpenAI Chat Completions sur https://api.kimi.com/coding/v1, le protocole utilisé par le code officiel Kimi client. K3, K3-256K et Kimi For Coding acceptent désormais les outils ajoutés en cours de conversation sans invalider le cache d'invite. Les remplacements models.json de l'URL de base kimi-coding doivent désormais inclure /v1 (#10720).
  • Modification du changement de modèle pour supprimer les blocs de réflexion des messages d'assistant précédents produits par un modèle différent, au lieu de les envoyer sous forme de texte brut. Le nouveau modèle considérait auparavant le raisonnement de l'ancien modèle comme faisant partie de ses réponses et pouvait commencer à écrire son propre raisonnement dans la réponse visible (#10995).

Corrigé

  • Épinglage des dépendances internes de Pi aux versions exactes pour empêcher les nouvelles installations de mélanger des packages incompatibles (#10865)
  • Correction des sessions reprises supprimant les outils activés pendant la session. La reprise restaure désormais les outils actifs de la session, avec les entrées --tools +name/-name qui leur sont appliquées, à moins que --tools avec les noms d'outils, --no-tools ou --no-builtin-tools ne sélectionne explicitement les outils (#10785).
  • Correction de l'arrêt d'un script en mode code ou de l'attente de sa date limite en attendant le retour d'un intégré non-interruptible sur Bun (#10748)
  • Correction des délais d'attente ou des abandons répétés du mode code en accumulant des travailleurs survivants ; l'admission limite désormais les travailleurs en direct à deux par session, en comptant les travailleurs annulés jusqu'à la sortie réelle (#10748)
  • Correction de --model choisissant un fournisseur par commande catalogue lorsque plusieurs fournisseurs proposent le match ; Pi préfère désormais le fournisseur disposant des informations d’identification et signale autrement l’ambiguïté. --models et enabledModels ajoutent un modèle pour chaque fournisseur qui le propose et avertissent de l'ambiguïté (#10160)
  • Correction des étiquettes de plage de lignes read pour les arguments de chaîne numérique ou nuls dans l'interface utilisateur, l'arborescence de session, les exportations HTML et les exemples (#9887)
  • Correction de l'échec de la construction de Nix Flake lorsqu'un fournisseur changeait de API : l'épingle du catalogue de modèles est désormais actualisée à partir du catalogue publié le plus récent lorsque ses groupes de modèles API diffèrent, et les versions épinglent le catalogue le plus récent et construisent avec lui avant le marquage (#10985)
  • Correction du package Nix plaçant son Node.js en premier sur PATH, ce qui faisait que les shells d'outils bash utilisaient le nœud de Pi au lieu du node/npm de l'utilisateur. Le nœud de Pi n'est désormais qu'une solution de secours (#10519)
  • Correction des modèles d'invite supprimant les arguments vides entre guillemets ("" ou ''), ce qui décalait les arguments de position ultérieurs et empêchait l'application des valeurs de position par défaut (#10867).
  • Correction de l'échec de la construction du package Nix lors de sa vérification d'installation car il attendait toujours chord et esbuild, dont Pi ne dépend plus
  • Correction de l'argument d'appel d'outil analysant la suppression des champs lorsqu'une chaîne contient un échappement \u non valide tel que \usepackage (#10868)
  • Correction des requêtes Anthropic et Bedrock Claude qui échouaient avec un 400 lorsqu'un résultat d'outil d'erreur contenait des images ; les images sont désormais envoyées après les résultats de l'outil du tour, donc le modèle les voit toujours (#10794)
  • Correction des modèles OpenCode Go Gemini échouant avec un 404 en déplaçant OpenCode Zen et OpenCode Go vers les points de terminaison opencode.ai/inference, et ajout de la prise en charge de Google Generative AI au fournisseur OpenCode Go
  • Correction de l'échec d'OpenCode Go MiniMax M2.7 avec "Le modèle ne prend pas en charge ce protocole" en utilisant les messages anthropiques API
  • Correction d'une nouvelle tentative automatique ne se déclenchant pas pour les erreurs de passerelle Unable to forward upstream stream (#10920)
  • Correction d'une nouvelle tentative automatique ne se déclenchant pas pour les erreurs The service is temporarily unavailable, ce qui faisait également échouer le compactage à la première tentative (#10965)
  • Correction des réponses compatibles OpenAI montrant une réflexion après la réponse lorsqu'un proxy tel que LiteLLM envoie le raisonnement et le contenu dans le même morceau de flux (#10926)
  • Correction des requêtes Gemini 4 Argon sur Google Vertex échouant avec "Le budget de réflexion n'est pas pris en charge" et son niveau de réflexion étant ignoré sur le Gemini API (#10890)
  • Correction des modèles Xiaomi MiMo échouant avec un 400 au niveau de réflexion minimal ; ils exposent désormais uniquement les niveaux off et high (#10818)
  • Correction de openai-codex/gpt-6.1-sol utilisant une fenêtre contextuelle de 272 Ko au lieu de la fenêtre de 500 Ko que le Codex fournit désormais (#10840)
  • Correction des appels d'outils dont les arguments finaux sont mal formés. JSON s'exécutant silencieusement avec uniquement les champs analysés avant l'erreur ; ils échouent désormais à la validation et montrent au modèle les arguments bruts qu'il a envoyés (#10897)
  • Correction de Claude Haiku 5.5 et Claude Opus 5 ne prenant pas en charge le niveau de réflexion off (#10753)
  • Correction du done() du ctx.ui.custom({ overlay: true }) d'une extension fermant la superposition la plus haute au lieu de la sienne, ce qui laissait la superposition terminée à l'écran et la boîte de dialogue d'une autre extension non résolue (#10648, #10999 par @masonc15)

Anglais original / English original

pi v1.3.0

New Features

  • Choose where /share uploads: sessionShareDestination selects auto, gist, or radius. See Sessions and context and Export or share a session.
  • Cache-preserving thinking level changes on OpenAI GPT-6: changing the thinking level mid-session with an API key keeps the prompt cache.
  • Kimi Code over Chat Completions: tools added mid-conversation no longer invalidate the prompt cache. models.json base URL overrides must now include /v1. See Providers.
  • Clean model switching: thinking from a previous model is dropped instead of being shown to the new model as text.
  • Resumed sessions keep their active tools: --tools +name/-name applies on top of them. See Tools.

Added

  • Changing the thinking level mid-session on OpenAI GPT-6 models (API key) now keeps the prompt cache (#10853)
  • Added the sessionShareDestination setting to choose automatic, GitHub gist, or Radius uploads for /share (#10870 by @vegarsti)

Changed

  • Changed the kimi-coding provider to use OpenAI Chat Completions at https://api.kimi.com/coding/v1, the protocol used by the official Kimi Code client. K3, K3-256K, and Kimi For Coding now accept tools added mid-conversation without invalidating the prompt cache. models.json overrides of the kimi-coding base URL must now include /v1 (#10720)
  • Changed model switching to drop thinking blocks from earlier assistant messages produced by a different model, instead of sending them as plain text. The new model previously saw the old model's reasoning as part of its replies and could start writing its own reasoning into the visible answer (#10995)

Fixed

  • Pinned internal Pi dependencies to exact release versions to prevent fresh installs from mixing incompatible packages (#10865)
  • Fixed resumed sessions dropping tools activated during the session. Resume now restores the session's active tools, with --tools +name/-name entries applied to them, unless --tools with tool names, --no-tools, or --no-builtin-tools selects tools explicitly (#10785)
  • Fixed stopping a codemode script or reaching its deadline waiting for a non-interruptible built-in to return on Bun (#10748)
  • Fixed repeated codemode timeouts or aborts accumulating surviving workers; admission now limits live workers to two across sessions, counting cancelled workers until actual exit (#10748)
  • Fixed --model choosing a provider by catalog order when several providers offer the match; Pi now prefers the provider with credentials and otherwise reports the ambiguity. --models and enabledModels add a model for each provider that offers it and warn about the ambiguity (#10160)
  • Fixed read line-range labels for numeric-string or null arguments in the TUI, session tree, HTML exports, and examples (#9887)
  • Fixed the Nix flake build failing when a provider switched APIs: the model catalog pin is now refreshed from the newest published catalog when its model API groups differ, and releases pin the newest catalog and build with it before tagging (#10985)
  • Fixed the Nix package putting its Node.js first on PATH, which made bash tool shells use Pi's Node instead of the user's node/npm. Pi's Node is now only a fallback (#10519)
  • Fixed prompt templates dropping empty quoted arguments ("" or ''), which shifted later positional arguments and prevented positional defaults from applying (#10867)
  • Fixed the Nix package build failing in its install check because it still expected chord and esbuild, which Pi no longer depends on
  • Fixed tool-call argument parsing dropping fields when a string contains an invalid \u escape such as \usepackage (#10868)
  • Fixed Anthropic and Bedrock Claude requests failing with a 400 when an error tool result contains images; the images are now sent after the tool results of the turn, so the model still sees them (#10794)
  • Fixed OpenCode Go Gemini models failing with a 404 by moving OpenCode Zen and OpenCode Go to the opencode.ai/inference endpoints, and added Google Generative AI support to the OpenCode Go provider
  • Fixed OpenCode Go MiniMax M2.7 failing with "Model does not support this protocol" by using the Anthropic Messages API
  • Fixed automatic retry not triggering for gateway Unable to forward upstream stream errors (#10920)
  • Fixed automatic retry not triggering for The service is temporarily unavailable errors, which also made compaction fail on the first attempt (#10965)
  • Fixed OpenAI-compatible responses showing thinking after the answer when a proxy such as LiteLLM sends reasoning and content in the same stream chunk (#10926)
  • Fixed Gemini 4 Argon requests on Google Vertex failing with "Thinking budget is not supported", and its thinking level being ignored on the Gemini API (#10890)
  • Fixed Xiaomi MiMo models failing with a 400 at the minimal thinking level; they now expose only the off and high levels (#10818)
  • Fixed openai-codex/gpt-6.1-sol using a 272K context window instead of the 500K window Codex now provides (#10840)
  • Fixed tool calls whose final arguments are malformed JSON silently running with only the fields parsed before the error; they now fail validation and show the model the raw arguments it sent (#10897)
  • Fixed Claude Haiku 5.5 and Claude Opus 5 not supporting the off thinking level (#10753)
  • Fixed done() of an extension's ctx.ui.custom({ overlay: true }) closing the topmost overlay instead of its own, which left the finished overlay on screen and another extension's dialog unresolved (#10648, #10999 by @masonc15)
