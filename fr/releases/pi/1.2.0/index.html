pi v1.2.0

Nouvelles fonctionnalités

  • Listes de modèles OpenRouter par clé : avec une clé OpenRouter, Pi répertorie uniquement les modèles que cette clé peut utiliser, avec la taille du contexte de la clé, la sortie maximale et les prix, y compris les points de terminaison régionaux définis dans models.json. Voir OpenRouter.
  • Schémas de configuration publiés : ajoutez $schema à settings.json, models.json, les raccourcis clavier et les thèmes pour la validation et l'achèvement de l'éditeur. Voir [Paramètres] (https://github.com/earendil-works/pi/blob/v1.2.0/packages/coding-agent/docs/settings.md), [Modèles] (https://github.com/earendil-works/pi/blob/v1.2.0/packages/coding-agent/docs/models.md), [Raccords de touches] (https://github.com/earendil-works/pi/blob/v1.2.0/packages/coding-agent/docs/keybindings.md) et [Thèmes] (https://github.com/earendil-works/pi/blob/v1.2.0/packages/coding-agent/docs/themes.md).
  • Clipboard copie sur des sessions distantes : PI_CLIPBOARD_OSC52=1 envoie le texte copié au clipboard d'un client distant lorsque Pi ne peut pas détecter la session distante, comme un multiplexeur connecté à partir d'une autre machine. Voir [Configuration du processus Pi] (https://github.com/earendil-works/pi/blob/v1.2.0/packages/coding-agent/docs/environment-variables.md#pi-process-configuration).
  • Améliorations du mode code : les déclarations d'outils affichent les contraintes d'entrée telles que l'entier, le minimum/maximum et la valeur par défaut, et les lignes du mode code affichent le temps écoulé et total. Voir [Mode Code] (https://github.com/earendil-works/pi/blob/v1.2.0/packages/coding-agent/docs/codemode.md).
  • before_agent_start pour les exécutions déclenchées par une extension : les exécutions démarrées par pi.sendMessage(..., { triggerTurn: true }) passent par la même configuration que les invites. Voir Événements et concurrence.

Modifications radicales

  • Publication de schémas de configuration générés pour les modèles, les paramètres, les raccourcis clavier et les thèmes sur https://pi.dev/schemas/*.schema.json. Le schéma du thème a été déplacé vers https://pi.dev/schemas/theme.schema.json ; les thèmes chargés au démarrage reçoivent désormais la même validation de schéma que les rechargements ultérieurs. Mettez à jour les références du thème $schema, définissez des couleurs réutilisables sous vars et supprimez les métadonnées non prises en charge (#9880, #10751 par @christianklotz).
  • Modification de before_agent_start pour qu'il se déclenche également pour les exécutions démarrées par pi.sendMessage(..., { triggerTurn: true }) au repos. BeforeAgentStartEvent est désormais une union sur messageType : les événements "user" portent prompt et images, et les événements "custom" portent le message de départ et aucun prompt. Les messages renvoyés par les gestionnaires sont ajoutés aux deux types d'exécution et les messages deliverAs: "nextTurn" en attente sont remis avec l'exécution de messages personnalisés. Les gestionnaires qui doivent agir uniquement sur les invites de l'utilisateur doivent vérifier event.messageType === "user" (#10267, #5581, #10739 par @davidbrai)
  • Modification de la session pour qu'elle soit considérée comme occupée au démarrage d'une exécution, y compris pendant les gestionnaires before_agent_start : ctx.isIdle() est faux, pi.sendMessage() se met en file d'attente dans l'exécution de démarrage au lieu de démarrer une deuxième exécution qui a échoué avec "L'agent est déjà en cours de traitement", pi.sendUserMessage() nécessite deliverAs, et un abandon demandé entre-temps abandonne l'exécution une fois qu'elle démarre (#10739 par @davidbrai)
  • Modification de pi mcp list --json pour signaler resources: true pour les serveurs offrant des ressources au lieu des comptes resources et resourceTemplates ; Pi ne répertorie plus les ressources lors de la connexion (#10526)

Ajouté

  • Ajout de reachesTools aux définitions d'outils, afin que les outils qui atteignent d'autres outils (tels que codemode et tool_search) déclarent quels outils un appel peut atteindre ; l'extension MCP l'utilise pour attendre les serveurs dont un appel a besoin et pour décider si un outil codemode ou tool_search de remplacement peut atteindre les outils MCP
  • Ajout de aliases aux espaces de noms d'outils ; describeNamespace() de codemode et l'option namespace de searchTools() les correspondent, et les espaces de noms MCP utilisent le nom du serveur
  • Ajout de listes de modèles OpenRouter par clé : avec une clé OpenRouter, Pi répertorie uniquement les modèles de discussion que la clé peut utiliser, avec la taille du contexte de la clé, la sortie maximale et les prix, y compris les garde-corps et les points de terminaison régionaux définis comme URL de base dans models.json. La liste est enregistrée et utilisée hors ligne (#10353, #10672 par @davidbrai).
  • Ajout de PI_CLIPBOARD_OSC52=1 pour envoyer le texte copié au terminal avec OSC 52 après l'écriture du clipboard local, afin que les copies atteignent le clipboard d'un client distant lorsque Pi ne peut pas détecter la session distante, comme la connexion d'un multiplexeur depuis une autre machine ou des démons IDE distants (#10826, #10835, #10114)
  • Ajout du temps écoulé pendant l'exécution d'un script en mode code et de sa durée totale une fois terminée dans la ligne de l'outil en mode code, comme les lignes bash (#10708).

Modifié

  • Modification du paramètre showHardwareCursor pour utiliser uniquement le curseur du terminal au lieu de dessiner également le curseur vidéo inverse de Pi
  • Modification des déclarations de l'outil de mode de code pour afficher les contraintes d'entrée telles que l'entier, le minimum/maximum, la longueur, le modèle et la valeur par défaut sous forme de balises @ sur les commentaires de propriété, afin que les scripts les voient sans que l'outil ne les répète dans les descriptions (#10707).
  • Modification des déclarations de mode de code des outils MCP pour épeler le type de résultat (content, structuredContent, isError) au lieu de faire référence à CallToolResult<T>, que describeTool(), searchTools() et ALL_TOOLS affichaient sans le définir ; la description du mode code n'inclut plus les types MCP partagés
  • Modification de serializeConversation() (compaction, résumés de branches, rapports de bogues) pour omettre les blocs de réflexion ; la pensée rejouée n'est souvent pas dans le contexte réel, donc l'inclure pourrait rendre une demande de résumé plus grande que le contexte qu'elle résume et échouer

Corrigé

  • Correction du mode code ignorant une ligne // @options: qui n'est pas la première ligne du script, qui exécutait le script sans le timeout_ms demandé ; l'appel échoue désormais avec une erreur avant l'exécution du script (#10631)
  • Correction des flux Mistral interrompus en milieu de génération (par exemple lors d'une longue réflexion) après l'expiration du délai de demande ; le délai d'attente s'applique désormais uniquement à l'attente des en-têtes de réponse (#10609)
  • Correction d'un AGENTS.md lié symboliquement dans un arbre de travail git imbriqué dans son référentiel principal, provoquant le chargement d'aucun fichier de contexte de projet (#10681)
  • Correction de la description de l'outil en mode code affirmant que chaque appel d'outil ayant échoué est rejeté ; un outil qui déclare qu'un schéma de sortie se résout également avec sa valeur en cas d'échec (par exemple bash avec une sortie différente de zéro)
  • Correction des exécutions démarrées par pi.sendMessage(..., { triggerTurn: true }) supprimant les sections d'invite système ajoutées dans before_agent_start après leur premier appel d'outil, ce qui modifiait l'invite à mi-exécution et cassait le cache d'invite du fournisseur deux fois par exécution (#10267, #10739 par @davidbrai).
  • Correction du mode code bloquant le processus pendant quelques secondes à quelques minutes après les scripts avec de nombreux appels text() ; joindre les éléments de sortie était quadratique (#10678)
  • Correction du mode d'impression (-p) quittant 0 sans avertissement lorsque la réponse finale était coupée à la limite du jeton de sortie du modèle ; il imprime maintenant le texte partiel, écrit un avertissement sur stderr et quitte 1 (#10799)
  • Correction des documents pi mcp login --help et CLI décrivant --timeout comme étant uniquement l'attente du navigateur ; cela limite toute la connexion (#10636)
  • Correction de ~ n'étant pas développé dans les entrées !pattern, +path et -path des paramètres extensions, skills, prompts et themes, donc les entrées comme !~/skills/pdf ne correspondaient à rien (#10765)
  • Correction des serveurs MCP avec des ressources n'enregistrant aucun outil jusqu'à ce que chaque ressource soit répertoriée ; Pi ne liste plus les ressources lors de la connexion, donc /mcp et pi mcp list montrent qu'un serveur propose des ressources au lieu de les compter (#10526)
  • Correction des appels de l'outil MCP échouant lorsque le serveur renvoie un contenu structuré qui n'est pas un objet (un tableau, null ou une primitive, comme le permet le MCP 2026-07-28) ; les déclarations de mode code des outils MCP sans schéma de sortie tapent désormais structuredContent comme unknown au lieu d'un objet (#10416)
  • Correction de l'échec de la lecture ou de l'écriture de auth.json sous Windows avec EPERM alors que le dossier de verrouillage précédent était toujours en cours de suppression ; Pi réessaye maintenant brièvement avant de signaler l'erreur (#10801)
  • Correction des modèles de routeurs OpenRouter tels que openrouter/auto affichant un coût de -1 000 000 $ par 1 million de jetons ; Les prix des espaces réservés négatifs d'OpenRouter sont désormais de 0 (#10672 par @davidbrai)
  • Correction des requêtes Anthropic qui échouaient lorsque le fournisseur rejetait l'ensemble d'outils strict pour la taille de la grammaire, le nombre d'outils ou les limites d'union ; Pi réessaye désormais une fois avec les outils préférés non stricts (#10409)
  • Correction de "Le fournisseur en amont a renvoyé une erreur" qui n'a pas été réessayé en tant qu'erreur de fournisseur transitoire (#10842)
  • Correction des superpositions plein écran ciblées bloquant le défilement de la transcription avec la molette de la souris (#10769)
  • Correction des réponses couleur du terminal fragmentées laissant fuir des valeurs hexadécimales dans l'invite et ouvrant l'éditeur externe (rapports associés : #10256, #10657)
  • Correction des images en ligne ne s'affichant pas dans Herdr depuis 1.1.0 (#10774 par @ogulcancelik)
  • Correction des raccourcis clavier qui nomment un symbole décalé, tel que + ou ctrl++, ne correspondant pas au protocole du clavier Kitty ou à modifierOtherKeys (#9880 par @christianklotz)
  • Correction de l'indicateur d'état de compactage intégré dans un éditeur personnalisé en utilisant les couleurs sourdes par défaut au lieu de la bordure de l'éditeur ou de la couleur du niveau de réflexion, comme le fait l'indicateur de travail (#10809, #10810 par @Jay-Madden).
  • Correction des appels à l'outil MCP qui étaient annulés ou expirés en attendant une actualisation OAuth toujours envoyée au serveur une fois l'actualisation terminée (#10598)
  • Correction de la connexion MCP OAuth acceptant une réponse d'autorisation avec un paramètre iss qui n'a pas pu être vérifié car aucune métadonnée du serveur d'autorisation n'a été découverte ; la connexion échoue désormais en raison d’une incompatibilité d’émetteur. Rapporté par @AizenvoltPrime
  • Correction d'un échec du mode code avec une erreur de pont cassé lorsque Pi s'exécute sous node --watch sur le nœud 24 ou 26 (#10725)

Supprimé

  • Suppression du serveur expérimental inédit, client, et de la pile de plugins (src/experimental, src/cli/experimental) ainsi que de ses exportations ./client et ./experimental/plugin uniquement source ; rien de tout cela ne faisait partie du package publié. Les packages @earendil-works/pi-client, @earendil-works/pi-protocol et @earendil-works/pi-server utilisés sont supprimés et ne sont plus publiés
  • Suppression de la dépendance sur @earendil-works/chord

pi v1.2.0

New Features

  • Per-key OpenRouter model lists: with an OpenRouter key, Pi lists only the models that key may use, with the key's context size, max output, and prices, including regional endpoints set in models.json. See OpenRouter.
  • Published configuration schemas: add $schema to settings.json, models.json, keybindings, and themes for editor validation and completion. See Settings, Models, Keybindings, and Themes.
  • Clipboard copies over remote sessions: PI_CLIPBOARD_OSC52=1 sends copied text to a remote client's clipboard when Pi cannot detect the remote session, such as a multiplexer attached from another machine. See Pi Process Configuration.
  • Codemode improvements: tool declarations show input constraints such as integer, minimum/maximum, and default, and codemode rows show elapsed and total time. See Codemode.
  • before_agent_start for extension-triggered runs: runs started by pi.sendMessage(..., { triggerTurn: true }) go through the same setup as prompts. See Events and concurrency.

Breaking Changes

  • Published generated configuration schemas for models, settings, keybindings, and themes at https://pi.dev/schemas/*.schema.json. The theme schema moved to https://pi.dev/schemas/theme.schema.json; themes loaded during startup now receive the same schema validation as later reloads. Update theme $schema references, define reusable colors under vars, and remove unsupported metadata (#9880, #10751 by @christianklotz)
  • Changed before_agent_start to also fire for runs started by pi.sendMessage(..., { triggerTurn: true }) while idle. BeforeAgentStartEvent is now a union on messageType: "user" events carry prompt and images, and "custom" events carry the starting message and no prompt. Messages returned by handlers are added to both kinds of run, and pending deliverAs: "nextTurn" messages are delivered with the custom-message run. Handlers that should act only on user prompts must check event.messageType === "user" (#10267, #5581, #10739 by @davidbrai)
  • Changed the session to count as busy while a run starts, including during before_agent_start handlers: ctx.isIdle() is false, pi.sendMessage() queues into the starting run instead of starting a second run that failed with "Agent is already processing", pi.sendUserMessage() requires deliverAs, and an abort requested meanwhile aborts the run once it starts (#10739 by @davidbrai)
  • Changed pi mcp list --json to report resources: true for servers that offer resources instead of resources and resourceTemplates counts; Pi no longer lists resources when connecting (#10526)

Added

  • Added reachesTools to tool definitions, so tools that reach other tools (such as codemode and tool_search) declare which tools a call may reach; the MCP extension uses it to wait for the servers a call needs and to decide whether a replacement codemode or tool_search tool can reach MCP tools
  • Added aliases to tool namespaces; codemode's describeNamespace() and the namespace option of searchTools() match them, and MCP namespaces use the server name
  • Added per-key OpenRouter model lists: with an OpenRouter key, Pi lists only the chat models that key may use, with the key's context size, max output, and prices, including guardrails and regional endpoints set as the base URL in models.json. The list is saved and used offline (#10353, #10672 by @davidbrai)
  • Added PI_CLIPBOARD_OSC52=1 to send copied text to the terminal with OSC 52 after the local clipboard write, so copies reach a remote client's clipboard when Pi cannot detect the remote session, such as multiplexer attaches from another machine or remote IDE daemons (#10826, #10835, #10114)
  • Added elapsed time while a codemode script runs and its total time once finished to the codemode tool row, like bash rows (#10708)

Changed

  • Changed the showHardwareCursor setting to use only the terminal cursor instead of also drawing Pi's reverse-video cursor
  • Changed codemode tool declarations to show input constraints such as integer, minimum/maximum, length, pattern, and default as @ tags on property comments, so scripts see them without the tool repeating them in descriptions (#10707)
  • Changed codemode declarations of MCP tools to spell out the result type (content, structuredContent, isError) instead of referring to CallToolResult<T>, which describeTool(), searchTools(), and ALL_TOOLS showed without defining it; the codemode description no longer includes the shared MCP types
  • Changed serializeConversation() (compaction, branch summaries, bug reports) to omit thinking blocks; replayed thinking is often not in the live context, so including it could make a summarization request larger than the context it summarizes and fail

Fixed

  • Fixed codemode ignoring a // @options: line that is not the first line of the script, which ran the script without the requested timeout_ms; the call now fails with an error before the script runs (#10631)
  • Fixed Mistral streams being aborted mid-generation (e.g. during long thinking) after the request timeout; the timeout now applies only to waiting for response headers (#10609)
  • Fixed a symlinked AGENTS.md in a git worktree nested inside its main repo causing no project context file to load (#10681)
  • Fixed the code mode tool description claiming every failed tool call rejects; a tool that declares an output schema resolves with its value on failure too (e.g. bash with a nonzero exit)
  • Fixed runs started by pi.sendMessage(..., { triggerTurn: true }) removing system prompt sections added in before_agent_start after their first tool call, which changed the prompt mid-run and broke the provider prompt cache twice per run (#10267, #10739 by @davidbrai)
  • Fixed codemode blocking the process for seconds to minutes after scripts with many text() calls; joining the output items was quadratic (#10678)
  • Fixed print mode (-p) exiting 0 without a warning when the final response was cut off at the model's output token limit; it now prints the partial text, writes a warning to stderr, and exits 1 (#10799)
  • Fixed pi mcp login --help and the CLI docs describing --timeout as only the wait for the browser; it limits the whole sign-in (#10636)
  • Fixed ~ not being expanded in !pattern, +path, and -path entries of the extensions, skills, prompts, and themes settings, so entries like !~/skills/pdf matched nothing (#10765)
  • Fixed MCP servers with resources registering no tools until every resource was listed; Pi no longer lists resources when connecting, so /mcp and pi mcp list show that a server offers resources instead of counting them (#10526)
  • Fixed MCP tool calls failing when the server returns structured content that is not an object (an array, null, or a primitive, as MCP 2026-07-28 allows); codemode declarations of MCP tools without an output schema now type structuredContent as unknown instead of an object (#10416)
  • Fixed reading or writing auth.json on Windows failing with EPERM when the previous lock folder was still being deleted; Pi now retries briefly before reporting the error (#10801)
  • Fixed OpenRouter router models such as openrouter/auto showing a cost of -$1,000,000 per 1M tokens; OpenRouter's negative placeholder prices are now 0 (#10672 by @davidbrai)
  • Fixed Anthropic requests failing when the provider rejects the strict tool set for grammar size, tool count, or union limits; Pi now retries once with preferred tools non-strict (#10409)
  • Fixed "The upstream provider returned an error" not being retried as a transient provider error (#10842)
  • Fixed focused fullscreen overlays blocking mouse-wheel scrolling of the transcript (#10769)
  • Fixed fragmented terminal color replies leaking hex values into the prompt and opening the external editor (related reports: #10256, #10657)
  • Fixed inline images not rendering in Herdr since 1.1.0 (#10774 by @ogulcancelik)
  • Fixed key bindings that name a shifted symbol, such as + or ctrl++, not matching under the Kitty keyboard protocol or modifyOtherKeys (#9880 by @christianklotz)
  • Fixed the compaction status indicator embedded in a custom editor using the default muted colors instead of the editor border or thinking-level color, as the working indicator does (#10809, #10810 by @Jay-Madden)
  • Fixed MCP tool calls that were cancelled or timed out while waiting for an OAuth refresh still being sent to the server once the refresh finished (#10598)
  • Fixed MCP OAuth sign-in accepting an authorization response with an iss parameter that could not be checked because no authorization server metadata was discovered; sign-in now fails with an issuer mismatch. Reported by @AizenvoltPrime
  • Fixed codemode failing with a broken bridge error when Pi runs under node --watch on Node 24 or 26 (#10725)

Removed

  • Removed the unreleased experimental server, client, and plugin stack (src/experimental, src/cli/experimental) and its source-only ./client and ./experimental/plugin exports; none of it was part of the published package. The @earendil-works/pi-client, @earendil-works/pi-protocol, and @earendil-works/pi-server packages it used are removed and no longer released
  • Removed the dependency on @earendil-works/chord
