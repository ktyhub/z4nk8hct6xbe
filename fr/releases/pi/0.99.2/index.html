pi v0.99.2

Nouvelles fonctionnalités

  • Les serveurs MCP restent à l'écart : les serveurs avec l'exposition par défaut codemode ne sont plus répertoriés dans la description codemode et ne bloquent plus la première invite. Ils apparaissent dans une courte section d'invite système et les scripts trouvent leurs outils avec searchTools() et describeNamespace(). Voir [Exposition de l'outil de contrôle] (https://github.com/earendil-works/pi/blob/v0.99.2/packages/coding-agent/docs/mcp.md#control-tool-exposure).
  • Plus d'options d'authentification MCP : oauth.clientName pour les serveurs qui n'acceptent que les OAuth clients connus et "auth": { "provider": "<provider>" } pour authentifier les serveurs HTTP avec le jeton /login d'un fournisseur. Voir Authentifier avec OAuth.
  • Fédération d'identité de charge de travail Anthropic à partir des variables d'environnement Anthropic SDK. Voir [Utiliser une clé API de l'environnement] (https://github.com/earendil-works/pi/blob/v0.99.2/packages/coding-agent/docs/providers.md#use-an-api-key-from-the-environment).
  • /reload active les outils nouvellement ajoutés au paramètre defaultTools. Voir Outils.

Ajouté

  • Ajout d'un champ description pour les serveurs MCP (pi mcp add --description), affiché avec le serveur dans l'invite système et utilisé pour classer ses outils dans la recherche d'outils, et un assistant en mode code describeNamespace(name) qui renvoie les instructions et les noms d'outils d'un espace de noms. describeNamespace() et searchTools() acceptent un espace de noms tel que mcp__dev-radius, mcp__dev_radius, dev-radius ou dev_radius.
  • Ajout d'un paramètre oauth.clientName pour les serveurs MCP (pi mcp add --oauth-client-name) pour modifier le nom client envoyé lors de l'enregistrement OAuth client, ​​pour les serveurs qui n'acceptent que les clients connus (#10226).
  • Ajout de "auth": { "provider": "<provider>" } pour les serveurs HTTP MCP afin d'envoyer le jeton /login actuel d'un fournisseur comme jeton de porteur au lieu d'utiliser MCP OAuth. Le jeton est lu à chaque demande, les actualisations du fournisseur s'appliquent donc. Autorisé uniquement dans le mcp.json global et à partir des extensions, et nécessite https sauf sur les hôtes de bouclage.
  • Ajout de la fédération d'identité de charge de travail Anthropic à partir des variables d'environnement ANTHROPIC_FEDERATION_RULE_ID, ANTHROPIC_ORGANIZATION_ID et ANTHROPIC_IDENTITY_TOKEN_FILE (voir Providers) (#10177, #10242 par @philfreo).
  • /reload active désormais les outils nouvellement ajoutés au paramètre defaultTools. Les outils supprimés restent activés, les outils désactivés pendant la session restent désactivés à moins qu'ils ne soient nouvellement ajoutés, et --tools, --no-tools et --no-builtin-tools remplacent toujours le paramètre (#10245).

Modifié

  • Les serveurs MCP avec l'exposition par défaut codemode n'apparaissent plus dans la description codemode ; les scripts les trouvent avec searchTools(). codemode-deferred est désormais un alias pour codemode. Utilisez l'exposition direct pour les outils que le modèle doit voir sans rechercher (#10212).
  • La description codemode n'inclut plus les outils différés, le nombre d'outils ou les instructions du serveur MCP, elle ne change donc plus lorsque les serveurs MCP se connectent ou modifient leurs outils. La description du tool_search ne répertorie plus les serveurs dont il peut charger les outils, pour la même raison. Les serveurs sont répertoriés à la place dans une section d'invite système mcp_servers avec un résumé d'une ligne, mis à jour au début de chaque invite ; une section modifiée est ajoutée à la conversation. Les scripts lisent les instructions du serveur avec describeNamespace() (#10212).
  • La première invite n'attend plus les serveurs MCP sans outils direct. Ils se connectent en arrière-plan et sont attendus lorsqu'un script en mode code les nomme, qu'un script recherche des outils ou que tool_search s'exécute (#10212).

Corrigé

  • Correction des nouvelles sessions ignorant par intermittence le modèle par défaut enregistré, ou avertissant qu'aucun modèle n'est disponible, lorsqu'il appartient à un fournisseur natif enregistré par extension avec un identifiant stocké (#9962, #10190 par @davidbrai).
  • Correction de l'URL de connexion /mcp qui n'était pas clickable lorsqu'elle s'étend sur plusieurs lignes, en l'émettant en tant que lien hypertexte de terminal avec une ligne Cmd/Ctrl+click to open comme /login (#10186).
  • Correction du mode de code image() acceptant des données base64 mal formées ou des types d'image non pris en charge, qui persistaient un bloc d'image non valide qui faisait échouer chaque demande ultérieure du fournisseur avec HTTP 400 (#10215).
  • Correction du mode code qui ne parvenait pas à démarrer son script à partir de l'exécutable Windows autonome (#10204).
  • Correction du ralentissement de la soumission des invites avec la durée de la session, car la résolution de la sélection de modèle de la session consultait le catalogue de modèles une fois par message de l'assistant (#10198).
  • Correction du ralentissement des recherches de modèles pour les fournisseurs disposant d'un catalogue pi.dev actualisé, car la fusion des modèles de catalogue distant prenait un temps quadratique.
  • Correction des exemples d'extension built-in-tool-renderer.ts et minimal-mode.ts supprimant les résumés et les directives des outils intégrés de l'invite système (#10072, #10193 par @christianklotz).
  • Correction de la détection de dépassement de contexte pour les erreurs Prompt exceeds max length du point de terminaison Z.AI CN (#10208).
  • Correction des requêtes Anthropic qui échouaient lorsqu'un schéma d'outil utilisait des mots-clés rejetés par l'utilisation stricte d'un outil Anthropic, tels que minimum/maximum ; ces outils sont désormais envoyés de manière non stricte (#9953).
  • Correction du fournisseur qui tente de se déclencher immédiatement lorsqu'un en-tête Retry-After contient une date non analysable ; ils utilisent désormais l'intervalle exponentiel (#9571).
  • Correction des commandes d'extension enregistrées sans nom de chaîne ni gestionnaire faisant planter pi lors de la saisie de / ; l'extension ne parvient désormais pas à se charger avec une erreur (#10054).
  • Correction des résultats réduits des outils codemode et MCP remplissant l'écran lorsque la sortie est une longue ligne, comme par exemple JSON minifié. Comme la sortie bash, l'aperçu est désormais limité aux lignes enveloppées au lieu des lignes logiques.
  • Correction de codemode.mode: "only" répertoriant read, bash, edit et write dans la liste d'outils de l'invite système bien que les requêtes déclarent uniquement codemode (#10192).
  • Correction des scripts de mode code appelant le mauvais outil MCP lorsque deux noms d'outils diffèrent uniquement dans - et _, tels que read-file et read_file. Comme dans le Codex, les noms d'outils et d'espaces de noms MCP remplacent désormais - par _ (mcp__my-server__x est désormais mcp__my_server__x), les outils en collision d'un serveur reçoivent tous un suffixe de hachage et les noms de serveur qui diffèrent uniquement en - et _ sont rejetés (#10239).

pi v0.99.2

New Features

  • MCP servers stay out of the way: servers with the default codemode exposure are no longer listed in the codemode description and no longer block the first prompt. They appear in a short system prompt section, and scripts find their tools with searchTools() and describeNamespace(). See Control tool exposure.
  • More MCP authentication options: oauth.clientName for servers that only accept known OAuth clients, and "auth": { "provider": "<provider>" } to authenticate HTTP servers with a provider's /login token. See Authenticate with OAuth.
  • Anthropic workload identity federation from the Anthropic SDK environment variables. See Use an API key from the environment.
  • /reload enables tools newly added to the defaultTools setting. See Tools.

Added

  • Added a description field for MCP servers (pi mcp add --description), shown with the server in the system prompt and used to rank its tools in tool search, and a describeNamespace(name) codemode helper that returns a namespace's instructions and tool names. describeNamespace() and searchTools() accept a namespace as mcp__dev-radius, mcp__dev_radius, dev-radius, or dev_radius.
  • Added an oauth.clientName setting for MCP servers (pi mcp add --oauth-client-name) to change the client name sent during OAuth client registration, for servers that only accept known clients (#10226).
  • Added "auth": { "provider": "<provider>" } for HTTP MCP servers to send a provider's current /login token as the bearer token instead of using MCP OAuth. The token is read on every request, so provider refreshes apply. Only allowed in the global mcp.json and from extensions, and requires https except on loopback hosts.
  • Added Anthropic workload identity federation from the ANTHROPIC_FEDERATION_RULE_ID, ANTHROPIC_ORGANIZATION_ID, and ANTHROPIC_IDENTITY_TOKEN_FILE environment variables (see Providers) (#10177, #10242 by @philfreo).
  • /reload now enables tools newly added to the defaultTools setting. Tools removed from it stay enabled, tools turned off during the session stay off unless newly added, and --tools, --no-tools, and --no-builtin-tools still override the setting (#10245).

Changed

  • MCP servers with the default codemode exposure no longer appear in the codemode description; scripts find them with searchTools(). codemode-deferred is now an alias for codemode. Use direct exposure for tools the model should see without searching (#10212).
  • The codemode description no longer includes deferred tools, tool counts, or MCP server instructions, so it no longer changes when MCP servers connect or change their tools. The tool_search description no longer lists the servers whose tools it can load, for the same reason. Servers are listed instead in an mcp_servers system prompt section with a one-line summary, updated at the start of each prompt; a changed section is appended to the conversation. Scripts read server instructions with describeNamespace() (#10212).
  • The first prompt no longer waits for MCP servers without direct tools. They connect in the background and are waited for when a codemode script names them, a script searches tools, or tool_search runs (#10212).

Fixed

  • Fixed new sessions intermittently ignoring the saved default model, or warning that no models are available, when it belongs to an extension-registered native provider with a stored credential (#9962, #10190 by @davidbrai).
  • Fixed the /mcp sign-in URL not being clickable when it wraps across lines, by emitting it as a terminal hyperlink with a Cmd/Ctrl+click to open line like /login (#10186).
  • Fixed codemode image() accepting malformed base64 data or unsupported image types, which persisted an invalid image block that made every later provider request fail with HTTP 400 (#10215).
  • Fixed codemode failing to start its script worker from the standalone Windows executable (#10204).
  • Fixed prompt submission slowing down with session length, because resolving the session's model selection looked up the model catalog once per assistant message (#10198).
  • Fixed model lookups slowing down for providers with a refreshed pi.dev catalog, because merging remote catalog models took quadratic time.
  • Fixed the built-in-tool-renderer.ts and minimal-mode.ts extension examples removing the built-in tools' summaries and guidelines from the system prompt (#10072, #10193 by @christianklotz).
  • Fixed context overflow detection for Z.AI CN endpoint Prompt exceeds max length errors (#10208).
  • Fixed Anthropic requests failing when a tool schema uses keywords Anthropic strict tool use rejects, such as minimum/maximum; such tools are now sent non-strict (#9953).
  • Fixed provider retries firing immediately when a Retry-After header contains an unparseable date; they now use exponential backoff (#9571).
  • Fixed extension commands registered without a string name or handler crashing pi when typing /; the extension now fails to load with an error instead (#10054).
  • Fixed collapsed codemode and MCP tool results filling the screen when the output is one long line, such as minified JSON. Like bash output, the preview is now limited to wrapped lines instead of logical lines.
  • Fixed codemode.mode: "only" listing read, bash, edit, and write in the system prompt's tool list although requests only declare codemode (#10192).
  • Fixed codemode scripts calling the wrong MCP tool when two tool names differ only in - and _, such as read-file and read_file. Like in Codex, MCP tool and namespace names now replace - with _ (mcp__my-server__x is now mcp__my_server__x), colliding tools of a server all get a hash suffix, and server names that differ only in - and _ are rejected (#10239).
