pi v1.4.0

Nouvelles fonctionnalités

  • Entrée d'image pour les classificateurs : le mode code models.classify() accepte images pour les modèles Jev de TypeSafe et Clef de Cloudflare sur typesafe, cloudflare-workers-ai et OpenRouter. Voir Utiliser des modèles de classificateur et Codemode.
  • Référence de configuration des modèles : chaque fournisseur, modèle, remplacement de modèle et champ de compatibilité de models.json, générés à partir de son schéma. Voir [Configuration des modèles] (https://github.com/earendil-works/pi/blob/v1.4.0/packages/coding-agent/docs/models-configuration.md).
  • Résumés sans plafond de sortie fixe : les résumés de compactage et de branchement utilisent la limite de sortie du modèle, donc un long raisonnement ne les fait plus échouer. Voir Compactage.
  • Codemode attend un travailleur libre : les scripts parallèles et les sous-agents en cours d'attente au lieu d'échouer, et PI_CODEMODE_MAX_WORKERS augmente la limite. Voir [Limites du mode code] (https://github.com/earendil-works/pi/blob/v1.4.0/packages/coding-agent/docs/codemode.md#limits).
  • Prise en charge du terminal Rex : hyperliens OSC 8, couleurs vraies et images en ligne.

Ajouté

  • Ajout d'une référence de configuration de modèles générée à partir du schéma models.json, répertoriant tous les champs de fournisseur, de modèle, de remplacement de modèle et de compatibilité (#10790).
  • Codemode models.classify() accepte désormais images pour les modèles Jev de TypeSafe et Clef de Cloudflare sur typesafe, cloudflare-workers-ai et OpenRouter, et répertorie Clef Omni et Jev 1.14 sur Workers AI.
  • compat au niveau du fournisseur dans models.json s'applique désormais également aux modèles de classificateurs, avec les champs System One imageInput et sendImageOptInHeader pour les proxys qui servent les classificateurs d'un autre service. Les modèles de classificateur d'extension acceptent également le compat.
  • Ajout de MiniMax-M3.1-Flash aux fournisseurs minimax et minimax-cn, avec des niveaux de réflexion bas jusqu'au maximum (#11121)
  • Ajout de la prise en charge du terminal Rex : hyperliens OSC 8, truecolor et images en ligne (#11131, #11150 par @petrroll, #11183 par @nihaals)

Modifié

  • Les en-têtes d'attribution du fournisseur proviennent désormais de l'identité client de pi-ai. Les gestionnaires before_provider_headers des extensions ne voient plus les en-têtes d'attribution OpenRouter, NVIDIA NIM et OpenCode ; renvoyer null pour un le supprime toujours. Les requêtes Cloudflare envoient le User-Agent détaillé de pi au lieu de pi-coding-agent, tout comme les vérifications de version GitHub pour les téléchargements d'outils, et les requêtes OpenCode envoient x-opencode-client chaque fois que l'attribution est activée, pas seulement avec une session.
  • generateSummary() et generateSummaryWithUsage() ignorent désormais leur paramètre reserveTokens. Les requêtes récapitulatives utilisent à la place la limite de sortie du modèle.
  • Modification du modèle Copilot GitHub par défaut de gpt-5.4, que Copilot a retiré, à gpt-6.1-sol.
  • Modification du modèle NVIDIA par défaut en nvidia/nemotron-3.5-super-vl-120b-a12b (#10910 par @cv)
  • Modification du modèle Xiaomi par défaut en mimo-v2.6-pro pour les fournisseurs xiaomi et Xiaomi Token Plan, puisque mimo-v2.5-pro a quitté le catalogue.
  • Grok 4.3 et Grok 4.5 sur le fournisseur xai proposent désormais le niveau de réflexion xhigh.
  • Connectez-vous avec ChatGPT : les erreurs de limite d'utilisation de l'espace de travail ChatGPT Business ne sont pas réessayées et demandent à l'utilisateur de demander à l'administrateur de son espace de travail d'augmenter la limite.

Corrigé

  • Correction du compactage et des résumés de branche qui échouaient avec "la génération atteignait le plafond du jeton" lorsque le raisonnement utilisait la majeure partie de la limite de sortie du résumé fixe. Les résumés utilisent désormais la limite de sortie du modèle et compaction.reserveTokens contrôle uniquement le moment où le compactage démarre (#9512, #9075).
  • Correction des descriptions manquantes de models.schema.json pour les champs de fournisseur et de modèle, de sorte que les éditeurs n'affichaient aucune indication pour eux (#10790)
  • Correction de l'échec de pi update avec « Le marqueur d'installation géré est manquant ou invalide » lorsque managed-install.json démarre avec une nomenclature UTF-8, que Windows PowerShell 5.1 ajoute lorsqu'il réécrit le fichier.
  • Correction de l'exportation HTML affichant des astérisques littéraux pour Markdown gras et italique à côté de la ponctuation CJK (#3353, #10154)
  • Correction du terminal restant en mode suivi de la souris, rapport de mise au point, clavier Kitty et écran alternatif lorsque pi se ferme sans son démontage normal du terminal, ce qui inonde l'invite du shell avec des séquences d'échappement (#11170)
  • Correction des dialogues d'extension simultanés select/confirm/input/editor et des composants custom() en ligne en mode interactif : un deuxième dialogue a remplacé le premier et la première promesse n'a jamais été réglée ; la fermeture de la boîte de dialogue visible affiche à nouveau la précédente (#11166, #9909)
  • Correction du collage dans le shell suspendu après avoir copié du texte dans pi et l'avoir suspendu avec Ctrl+Z sous Linux : le processus d'arrière-plan wl-copy/xclip/xsel qui continue de servir le clipboard a été suspendu avec pi (#11179)
  • Correction des scripts en mode code échouant immédiatement lorsque les deux travailleurs en mode code sont occupés, par exemple avec des appels en mode code parallèles ou des sous-agents en cours. Les scripts attendent désormais jusqu'à 60 secondes pour un travailleur libre, et PI_CODEMODE_MAX_WORKERS augmente la limite de deux travailleurs (#11184).
  • Correction des extensions qui ne se chargeaient pas lors de l'importation de @earendil-works/pi-ai/models (par exemple pour clampThinkingLevel) en exposant le sous-chemin via les alias du chargeur d'extension et les modules virtuels (#11156)
  • Correction des fichiers mcp.json qui commençaient par une nomenclature UTF-8 qui ne parvenait pas à être analysée, ce qui ignorait tous leurs serveurs MCP et faisait échouer pi mcp add/pi mcp remove (#11191)
  • Correction de /compact <instructions> ignorant les instructions lors de la synthèse du début d'un tour qui divise le compactage. Lorsque le tour divisé était le seul nouveau contenu depuis le dernier compactage, les instructions étaient entièrement ignorées (#11058)
  • Correction des reprises de sessions et de la navigation /tree laissant les outils d'extension inactifs lorsque la branche enregistrait ses outils avant leur enregistrement, comme les outils des extensions installées après le démarrage de la session. Les outils d'extension que la branche n'a jamais ajoutés ou supprimés sont désormais actifs sauf s'ils sont enregistrés auprès de defaultActive: false (#11062, #11075).
  • Correction des sessions interrompues après récupération d'une réponse coupée à la limite de sortie : l'appel à l'outil tronqué était omis mais ses résultats d'outil étaient conservés, donc les fournisseurs rejetaient chaque demande ultérieure (#11227, #11233 par @petrroll)
  • Correction de l'outil grep après RIPGREP_CONFIG_PATH, où des options telles que --fixed-strings transformaient silencieusement les recherches d'expressions régulières en recherches littérales. L'outil exécute désormais rg --no-config (#11203, #11230 par @petrroll).
  • Correction de la détection du shell Windows rejetant les alias de shell exécutables du Microsoft Store (#9504 par @petrroll)
  • Correction de la détection du shell Windows manquant PowerShell en dehors de PATH et de l'ancien lanceur WSL bash.exe lorsque Windows n'est pas installé dans C:\Windows. pi vérifie désormais %ProgramFiles%\PowerShell\7, %SystemRoot%\System32\WindowsPowerShell\v1.0 et %SystemRoot% (#9501 par @petrroll)
  • Correction des sessions Copilot GitHub avec des corps de requête volumineux, tels que de nombreuses images, échouant avec HTTP 413 failed to parse request au lieu de compacter et de réessayer (#11016 par @petrroll).
  • Correction du fournisseur openai-codex proposant gpt-5.5 et gpt-5.3-codex-spark, qui échouent toujours pour les comptes ChatGPT (#11173 par @lucasmeijer)
  • Correction de la sortie de l'outil contenant uniquement des espaces (par exemple un \r\n nu de bash) faisant échouer les achèvements OpenAI, les réponses OpenAI et les requêtes Google avec un 400 (#8720)
  • Correction des tentatives automatiques ne se déclenchant pas en cas d'échecs supplémentaires de la passerelle en amont, des erreurs stream disconnected before completion relayées par les proxys Codex CLI et des échecs transitoires d'actualisation du jeton Google Vertex OAuth, ainsi que des erreurs de nouvelle tentative en raison de chiffres dans les identifiants de requête ou du nombre d'octets (#10920, #11057, #10996)
  • Correction des modèles OpenAI Responses perdant le cache d'invite à chaque chargement d'outil différé après la suppression d'un outil (#10940)
  • Correction du prix du classificateur Cloudflare Workers AI : Clef Flash coûte 0.038 $ et Jev 0.042 $ par million de jetons d'entrée au lieu que Jev soit répertorié comme gratuit.
  • Correction d'un bloc d'affichage mathématique $$ non fermé avalant ou corrompant chaque table Markdown après lui (#11159)
  • Correction du rendu Markdown gras et italique à côté de la ponctuation CJK (#10730 par @theBucky)
  • Correction de la saisie semi-automatique du fichier @ ne renvoyant aucun résultat pour les requêtes contenant des métacaractères regex tels que [ ou ( (#10972)

Anglais original / English original

pi v1.4.0

New Features

  • Image input for classifiers: codemode models.classify() accepts images for TypeSafe's Jev and Cloudflare's Clef models on typesafe, cloudflare-workers-ai, and OpenRouter. See Use classifier models and Codemode.
  • Models Configuration reference: every provider, model, model override, and compatibility field of models.json, generated from its schema. See Models Configuration.
  • Summaries without a fixed output cap: compaction and branch summaries use the model's output limit, so long reasoning no longer makes them fail. See Compaction.
  • Codemode waits for a free worker: parallel scripts and in-process subagents queue instead of failing, and PI_CODEMODE_MAX_WORKERS raises the limit. See Codemode limits.
  • Rex terminal support: OSC 8 hyperlinks, truecolor, and inline images.

Added

  • Added a Models Configuration reference generated from the models.json schema, listing all provider, model, model override, and compatibility fields (#10790)
  • Codemode models.classify() now accepts images for TypeSafe's Jev and Cloudflare's Clef models on typesafe, cloudflare-workers-ai, and OpenRouter, and lists Clef Omni and Jev 1.14 on Workers AI.
  • Provider-level compat in models.json now also applies to classifier models, with the System One fields imageInput and sendImageOptInHeader for proxies that serve another service's classifiers. Extension classifier models accept compat too.
  • Added MiniMax-M3.1-Flash to the minimax and minimax-cn providers, with thinking levels low through max (#11121)
  • Added support for the Rex terminal: OSC 8 hyperlinks, truecolor, and inline images (#11131, #11150 by @petrroll, #11183 by @nihaals)

Changed

  • Provider attribution headers now come from pi-ai's client identity. Extensions' before_provider_headers handlers no longer see the OpenRouter, NVIDIA NIM, and OpenCode attribution headers; returning null for one still removes it. Cloudflare requests send pi's detailed User-Agent instead of pi-coding-agent, as do GitHub release checks for tool downloads, and OpenCode requests send x-opencode-client whenever attribution is enabled, not only with a session.
  • generateSummary() and generateSummaryWithUsage() now ignore their reserveTokens parameter. Summary requests use the model's output limit instead.
  • Changed the default GitHub Copilot model from gpt-5.4, which Copilot retired, to gpt-6.1-sol.
  • Changed the default NVIDIA model to nvidia/nemotron-3.5-super-vl-120b-a12b (#10910 by @cv)
  • Changed the default Xiaomi model to mimo-v2.6-pro for the xiaomi and Xiaomi Token Plan providers, since mimo-v2.5-pro left the catalog.
  • Grok 4.3 and Grok 4.5 on the xai provider now offer the xhigh thinking level.
  • Sign in with ChatGPT: ChatGPT Business workspace usage-limit errors are not retried and tell the user to ask their workspace admin to increase the limit.

Fixed

  • Fixed compaction and branch summaries failing with "generation hit the token cap" when reasoning used most of the fixed summary output limit. Summaries now use the model's output limit, and compaction.reserveTokens only controls when compaction starts (#9512, #9075).
  • Fixed models.schema.json missing descriptions for provider and model fields, so editors showed no hints for them (#10790)
  • Fixed pi update failing with "Managed install marker is missing or invalid" when managed-install.json starts with a UTF-8 BOM, which Windows PowerShell 5.1 adds when it rewrites the file.
  • Fixed HTML export showing literal asterisks for Markdown bold and italic next to CJK punctuation (#3353, #10154)
  • Fixed the terminal staying in mouse-tracking, focus-reporting, Kitty keyboard, and alternate-screen modes when pi exits without its normal terminal teardown, which flooded the shell prompt with escape sequences (#11170)
  • Fixed concurrent extension select/confirm/input/editor dialogs and inline custom() components in interactive mode: a second dialog replaced the first and the first promise never settled; closing the visible dialog now shows the previous one again (#11166, #9909)
  • Fixed pasting in the shell hanging after copying text in pi and suspending it with Ctrl+Z on Linux: the background wl-copy/xclip/xsel process that keeps serving the clipboard was suspended along with pi (#11179)
  • Fixed codemode scripts failing immediately when both codemode workers are busy, for example with parallel codemode calls or in-process subagents. Scripts now wait up to 60 seconds for a free worker, and PI_CODEMODE_MAX_WORKERS raises the limit of two workers (#11184)
  • Fixed extensions failing to load when importing @earendil-works/pi-ai/models (e.g. for clampThinkingLevel) by exposing the subpath through the extension loader aliases and virtual modules (#11156)
  • Fixed mcp.json files that start with a UTF-8 BOM failing to parse, which skipped all their MCP servers and made pi mcp add/pi mcp remove fail (#11191)
  • Fixed /compact <instructions> ignoring the instructions when summarizing the start of a turn that compaction splits. When the split turn was the only new content since the last compaction, the instructions were ignored entirely (#11058)
  • Fixed resumed sessions and /tree navigation leaving extension tools inactive when the branch recorded its tools before they were registered, such as tools from extensions installed after the session started. Extension tools the branch never added or removed are now active unless they are registered with defaultActive: false (#11062, #11075)
  • Fixed sessions breaking after recovery from a response cut off at the output limit: the truncated tool call was omitted but its tool results were kept, so providers rejected every later request (#11227, #11233 by @petrroll)
  • Fixed the grep tool following RIPGREP_CONFIG_PATH, where options such as --fixed-strings silently changed regex searches into literal ones. The tool now runs rg --no-config (#11203, #11230 by @petrroll)
  • Fixed Windows shell detection rejecting runnable Microsoft Store shell aliases (#9504 by @petrroll)
  • Fixed Windows shell detection missing PowerShell outside PATH and the legacy WSL bash.exe launcher when Windows is not installed in C:\Windows. pi now checks %ProgramFiles%\PowerShell\7, %SystemRoot%\System32\WindowsPowerShell\v1.0, and %SystemRoot% (#9501 by @petrroll)
  • Fixed GitHub Copilot sessions with large request bodies, such as many images, failing with HTTP 413 failed to parse request instead of compacting and retrying (#11016 by @petrroll)
  • Fixed the openai-codex provider offering gpt-5.5 and gpt-5.3-codex-spark, which always fail for ChatGPT accounts (#11173 by @lucasmeijer)
  • Fixed whitespace-only tool output (for example a bare \r\n from bash) making OpenAI Completions, OpenAI Responses, and Google requests fail with a 400 (#8720)
  • Fixed automatic retry not triggering for more gateway upstream failures, stream disconnected before completion errors relayed by Codex CLI proxies, and transient Google Vertex OAuth token refresh failures, and retrying errors because of digits inside request ids or byte counts (#10920, #11057, #10996)
  • Fixed OpenAI Responses models losing the prompt cache on every deferred tool load after a tool was removed (#10940)
  • Fixed Cloudflare Workers AI classifier pricing: Clef Flash costs $0.038 and Jev $0.042 per million input tokens instead of Jev being listed as free.
  • Fixed an unclosed $$ display-math block swallowing or corrupting every Markdown table after it (#11159)
  • Fixed Markdown bold and italic not rendering next to CJK punctuation (#10730 by @theBucky)
  • Fixed @ file autocomplete returning no results for queries containing regex metacharacters such as [ or ( (#10972)
