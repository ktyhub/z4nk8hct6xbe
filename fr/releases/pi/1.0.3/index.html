pi v1.0.3

Nouvelles fonctionnalités

  • Azure Foundry Chat Completions — Le fournisseur azure (renommé azure-openai-responses) sert désormais également les déploiements Foundry Chat Completions, à commencer par azure/deepseek-v4-pro. Voir Azure OpenAI.
  • Images en mode code enregistrées dans des fichiers — image() écrit également chaque image dans un fichier temporaire et nomme le chemin dans le résultat, afin que les tours ultérieurs puissent copier ou déplacer les images générées. Voir Générer des images.

Modifications radicales

  • Renommé le fournisseur Azure de azure-openai-responses en azure. Renommez la clé du fournisseur dans auth.json (ou exécutez à nouveau /login), dans models.json et dans settings.json (defaultProvider, modèles enabledModels et clés modelThinkingLevels). Les sessions qui utilisaient l'ancien fournisseur reviennent à un autre modèle lors de leur reprise et leur cache d'invites n'est pas réutilisé. Les variables d'environnement AZURE_OPENAI_* sont inchangées (#9714 par @jsanter27)

Ajouté

  • Ajout des déploiements Azure Foundry Chat Completions, en commençant par azure/deepseek-v4-pro (#9645, #9714 par @jsanter27)

Modifié

  • Codemode image() enregistre désormais également chaque image dans un fichier temporaire et nomme le chemin dans le résultat, afin que les tours ultérieurs puissent copier ou déplacer les images générées (#10310).
  • Les fichiers de sortie (texte intégral de la sortie de l'outil tronquée, ressources MCP binaires, images en mode code) sont désormais lisibles uniquement par l'utilisateur.
  • Home/End déplace désormais toujours le curseur de l'éditeur vers le début/la fin de la ligne ; transcription plein écran haut/bas déplacé vers Ctrl+Home/Ctrl+End, qui ne déplacent plus le curseur de l'éditeur (#10314)

Corrigé

  • Correction des connexions par abonnement telles que la connexion avec ChatGPT échouant avec refresh_token_invalidated après l'annulation d'une demande lors d'une actualisation du jeton OAuth
  • Correction de l'échec du mode code pour le reste d'une session après qu'une mise à jour globale de pnpm ait supprimé l'installation en cours et ajouté un indice de redémarrage lorsque des erreurs se produisent après la mise à jour ou la suppression de pi sur le disque (#10439)
  • Correction de sessions interactives signalant un crash de read EIO ou setRawMode EIO (et demandant d'exécuter /bug) lorsque le terminal s'éloignait, par ex. après avoir fermé la fenêtre ou repris un pi suspendu dans un terminal fermé

Anglais original / English original

pi v1.0.3

New Features

  • Azure Foundry Chat Completions — The azure provider (renamed from azure-openai-responses) now also serves Foundry Chat Completions deployments, starting with azure/deepseek-v4-pro. See Azure OpenAI.
  • Codemode images saved to files — image() also writes each image to a temp file and names the path in the result, so later turns can copy or move generated images. See Generate images.

Breaking Changes

  • Renamed the Azure provider from azure-openai-responses to azure. Rename the provider key in auth.json (or run /login again), in models.json, and in settings.json (defaultProvider, enabledModels patterns, and modelThinkingLevels keys). Sessions that used the old provider fall back to another model when resumed, and their prompt cache is not reused. The AZURE_OPENAI_* environment variables are unchanged (#9714 by @jsanter27)

Added

  • Added Azure Foundry Chat Completions deployments, starting with azure/deepseek-v4-pro (#9645, #9714 by @jsanter27)

Changed

  • Codemode image() now also saves each image to a temp file and names the path in the result, so later turns can copy or move generated images (#10310)
  • Output files (full text of truncated tool output, binary MCP resources, codemode images) are now readable only by the user
  • Home/End now always move the editor cursor to the line start/end; fullscreen transcript top/bottom moved to Ctrl+Home/Ctrl+End, which no longer move the editor cursor (#10314)

Fixed

  • Fixed subscription logins such as Sign in with ChatGPT failing with refresh_token_invalidated after a request was cancelled during an OAuth token refresh
  • Fixed codemode failing for the rest of a session after a pnpm global update removed the running install, and added a restart hint when errors occur after pi was updated or removed on disk (#10439)
  • Fixed interactive sessions reporting a read EIO or setRawMode EIO crash (and asking to run /bug) when the terminal went away, e.g. after closing the window or resuming a suspended pi in a closed terminal
