Versions 20 indexées · dernière v1.6.0 sur 20 nov. 2026

earendil-works/pi ↗

202620

11/20
v1.6.0 Mineure MT

GPT-6.2 Astra et GPT-6.2 Sol : les deux modèles sont disponibles sur les fournisseurs openai, azure et openai-codex, et GPT-6.2 Sol est désormais le modèle par défaut pour les trois. Voir Fournisseurs.

 11/10
v1.5.2 Correctif MT

Sessions de duplication dont le dossier a disparu : lorsque le dossier d'origine d'une session a été déplacé ou supprimé, vous pouvez désormais le transférer dans le dossier actuel au lieu de simplement continuer, de sorte que les reprises ultérieures ne demandent plus.

 11/09
v1.5.1 Correctif MT

Connexion et déconnexion du shell : utilisez la connexion pi auth et la déconnexion pi auth sans démarrer de session, avec la clé API et les options de connexion sans navigateur. Voir Commandes d'informations d'identification.

 11/02
v1.5.0 Mineure MT

Mise à jour de l'extension changelogs : voyez ce qui a changé dans les packages d'extension installés lors du prochain lancement après une mise à jour. Les auteurs de packages peuvent choisir le chemin changelog et réduireChangelog condense les notifications.

 10/21
v1.4.0 Mineure MT

Entrée d'image pour les classificateurs : codemode models.classify() accepte les images pour les modèles Jev de TypeSafe et Clef de Cloudflare sur typesafe, cloudflare-workers-ai et OpenRouter. Voir Utiliser des modèles de classificateur et Codemode.

 10/15
v1.3.0 Mineure MT

Choisissez où /share télécharge : sessionShareDestination sélectionne auto, gist ou radius. Voir Sessions et contexte et Exporter ou partager une session.

 10/12
v1.2.0 Mineure MT

Listes de modèles OpenRouter par clé : avec une clé OpenRouter, Pi répertorie uniquement les modèles que la clé peut utiliser, avec la taille du contexte de la clé, la sortie maximale et les prix, y compris les points de terminaison régionaux définis dans models.json. Voir OpenRouter.

 10/07
v1.1.0 Mineure MT

Rapports sur l'état du programme : les terminaux et les tableaux de bord d'agent prenant en charge OSC 7501 voient si Pi fonctionne, est bloqué lors d'une boîte de dialogue ou d'une connexion, est terminé ou a échoué. Voir Statut du programme.

 10/05
v1.0.4 Correctif MT

Modèles d'outils et --no-mcp : --tools et --exclude-tools acceptent des modèles, par exemple --tools read,codemode,'mcp__radius' ne conserve qu'un seul outil de serveur MCP.

 10/05
v1.0.3 Correctif MT

Azure Foundry Chat Completions — Le fournisseur Azure (renommé azure-openai-responses) sert désormais également les déploiements Foundry Chat Completions, à commencer par azure/deepseek-v4-pro. Consultez Azure OpenAI.

 10/04
v1.0.2 Correctif MT

Échantillonnage par niveau de réflexion — samplingParamsByThinkingLevel dans models.json définit les paramètres d'échantillonnage tels que la température et top_p pour chaque niveau de réflexion sur les API compatibles OpenAI.

 10/03
v1.0.1 Correctif MT

Nix flake — nix run github:earendil-works/pi/stable exécute la dernière version et nix profile add github:earendil-works/pi/stable l'installe. Voir Installer pi.

 10/01
v1.0.0 Majeure MT

Plein écran par défaut — La TUI s'exécute désormais en plein écran. Réglez tuiMode sur « normal » pour conserver le défilement normal du terminal. Voir Terminal et affichage.

 09/30
v0.99.2 Correctif MT

Les serveurs MCP restent à l'écart : les serveurs avec l'exposition en mode code par défaut ne sont plus répertoriés dans la description du mode code et ne bloquent plus la première invite.

 09/29
v0.99.1 Correctif MT

GPT-6.1 Sol — Disponible sur OpenAI, Azure OpenAI et OpenAI Codex, et désormais le modèle OpenAI Codex par défaut. Voir Sélectionner un modèle.

 09/29
v0.99.0 Mineure MT

Codemode et MCP — Connectez les serveurs MCP et laissez les modèles exécuter JavaScript qui appelle des outils en parallèle. Voir Serveurs MCP et Activer le mode code.

 09/22
v0.87.1 Correctif MT

Derniers modèles frontière — Utilisez Claude Opus 5.5, GPT-6 Sol et GPT-6 Luna via les fournisseurs pris en charge, notamment GitHub Copilot. Voir Choisir un modèle.

 09/21
v0.87.0 Mineure MT

Contexte de session canonique et limites d'extension — Modifiez le contexte du modèle sans réécrire l'historique et ajoutez des hooks de cycle de vie exploitables. Voir ContextEditEntry et événements d'extension.

 09/20
v0.86.1 Correctif MT

Fournisseur Meta Muse — Connectez-vous avec Meta en utilisant la méta /login ou utilisez META_API_KEY pour accéder aux modèles Muse Spark. Voir Meta (abonnement Muse).

 09/19
v0.86.0 Mineure MT

Réchauffement du cache d'invites : conservez les caches d'invites précieux en vie pendant les longues exécutions des outils et éventuellement en cas d'inactivité grâce à des actualisations tenant compte des coûts. Voir Réchauffement du cache.
