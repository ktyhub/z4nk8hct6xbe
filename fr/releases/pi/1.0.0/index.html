pi v1.0.0

Nouvelles fonctionnalités

  • Plein écran par défaut — La TUI s'exécute désormais en plein écran. Réglez tuiMode sur "regular" pour conserver le défilement normal du terminal. Voir [Terminal et affichage] (https://github.com/earendil-works/pi/blob/v1.0.0/packages/coding-agent/docs/settings.md#terminal-and-display).
  • Mode de code plus léger — Environ 40 % de jetons d'invite en moins et d'erreurs indiquant au modèle comment récupérer. Voir [Mode Code] (https://github.com/earendil-works/pi/blob/v1.0.0/packages/coding-agent/docs/codemode.md).
  • Génération d'images en mode code — Les scripts appellent models.generateImages() avec les informations d'identification de la session. Voir [Générer des images] (https://github.com/earendil-works/pi/blob/v1.0.0/packages/coding-agent/docs/codemode.md#generate-images) et [Utiliser des modèles d'image] (https://github.com/earendil-works/pi/blob/v1.0.0/packages/coding-agent/docs/models.md#use-image-models).
  • Radius dans /login — Connectez-vous avec Radius et configurez son serveur MCP en une seule étape. Voir Rayon.
  • Connexion au code de copie anthropique — Connectez-vous lorsque le navigateur s'exécute sur une autre machine. Voir Authentifier de manière interactive.
  • Renforcement MCP OAuth — Vérifications oauth.authServerMetadataUrl, RFC 9207 iss, informations d'identification par serveur et connexion renforcée qui conserve les étendues accordées. Voir Authentifier avec OAuth.
  • Démarrage silencieux uniquement en-tête — quietStartup: "header" conserve la version et les indications clés et masque le reste. Voir [Terminal et affichage] (https://github.com/earendil-works/pi/blob/v1.0.0/packages/coding-agent/docs/settings.md#terminal-and-display).

Ajouté

  • Ajout d'un paramètre oauth.authServerMetadataUrl pour les serveurs MCP qui annoncent un mauvais serveur d'autorisation OAuth ou aucun. Pi utilise le document de métadonnées configuré au lieu de la découverte (#10172).
  • Ajout de quietStartup: "header", qui conserve l'en-tête de démarrage avec la version et les indications clés, mais masque la ligne de portée du modèle et la liste des ressources chargées.
  • Ajout de models.generateImages() aux scripts en mode code. Il exécute des modèles d'image tels que ceux d'OpenRouter avec les informations d'identification de la session et renvoie des blocs d'image base64 que image() attache au résultat ; l'utilisation compte dans le coût de la session comme models.classify(). Les extensions peuvent appeler ctx.modelRegistry.generateImages(). Voir [Utiliser des modèles d'image] (https://github.com/earendil-works/pi/blob/v1.0.0/packages/coding-agent/docs/models.md#use-image-models).
  • Ajout d'une méthode de connexion par copie de code à Anthropic /login pour les configurations sans tête où le navigateur s'exécute sur une autre machine (#10194 par @lucasmeijer).

Modifié

  • Modification du mode TUI par défaut en plein écran. Réglez tuiMode sur "regular" ou transmettez --tui-mode regular pour conserver le défilement normal du terminal.
  • /login propose désormais « Connexion avec Radius » au niveau supérieur, comme dernière option, avec son statut. Après une connexion Radius, /login propose de configurer le serveur Radius MCP dans le mcp.json global avec "auth": { "provider": "radius" } et recharge. L'annulation d'une connexion revient au menu à partir duquel elle a été démarrée.
  • La page de documentation du fournisseur est renommée [Providers] (https://github.com/earendil-works/pi/blob/v1.0.0/packages/coding-agent/docs/providers.md), sa section « Cloud Providers » est désormais « Provider Specific Config » et documente en premier Radius.
  • Les informations d'identification MCP OAuth sont désormais stockées par nom de serveur et URL, de sorte que les serveurs MCP avec la même URL peuvent se connecter avec des comptes différents. Les informations d'identification stockées par URL uniquement sont transférées vers le premier serveur qui les utilise (#10252).
  • Le mode code coûte beaucoup moins de jetons d'invite : avec les outils par défaut et le mode code actifs, une requête GPT-5.6 passe d'environ 5 300 à 3 300 jetons. La description du codemode répertorie les scripts globaux sur une ligne chacun et pointe vers la nouvelle référence Codemode pour le models API, que le modèle lit lorsqu'il en a besoin. Les outils déclarés indiquent sur une seule ligne comment les scripts les appellent et à quoi l'appel est résolu, au lieu de répéter leur déclaration complète, et les instructions de mode de code de l'invite système et la section du serveur MCP sont plus courtes.
  • Les erreurs Codemode indiquent désormais comment récupérer : la lecture d'un outil ou d'un membre models qui n'existe pas nomme les correspondances proches (tools.Bash suggère tools.bash), models.classify() et models.generateImages() rejettent les arguments mal formés avec la forme attendue, un modèle inconnu pointe vers models.getAvailableOfType(), une valeur store() surdimensionnée explique à quoi sert le magasin, et un script qui génère des images sans les afficher reçoit une note. Les scripts qui recherchent un outil avec typeof tools.name doivent utiliser "name" in tools.
  • /login et /logout étiquetent désormais les fournisseurs sans informations d'identification comme « non configurés » au lieu de « non configurés ».
  • Les pages du navigateur OAuth affichent désormais le logo Pi en couleur.

Corrigé

  • Correction de la connexion MCP OAuth acceptant une réponse d'autorisation dont le paramètre iss nomme un autre serveur d'autorisation ; le code est désormais rejeté avant d'être échangé (RFC 9207).
  • Correction de l'échec de la connexion MCP OAuth avec Invalid scope lorsque la réponse du jeton contient "scope": "", et d'échecs similaires pour d'autres champs OAuth facultatifs vides ou null (#10266).
  • Correction de l'URL de connexion imprimée par /mcp login qui n'était pas clickable à la fin (#10186).
  • Correction de --provider sans que --model soit ignoré silencieusement et exécute le modèle par défaut d'un autre fournisseur ; il échoue désormais avec une erreur (#10236).
  • Correction des serveurs MCP qui demandent plus de portée (insufficient_scope) demandant une connexion encore et encore. La nouvelle connexion n'a demandé que les étendues manquantes, de sorte que le nouveau jeton a perdu l'accès au précédent ; il conserve désormais les étendues accordées.
  • Correction des messages utilisateur dans la transcription en conservant deux copies pleine largeur de chaque ligne rendue ; ils en gardent un, avec un rendu identique.
  • Correction de /login et /logout étiquetant chaque connexion OAuth, y compris Radius, comme un abonnement ; seuls les fournisseurs par abonnement disent « abonnement », les autres connexions OAuth disent « compte ».
  • Correction du rendu du logo d'en-tête de démarrage avec des lacunes dans Apple Terminal ; il affiche maintenant un "Pi" coloré avec la version à la place.
  • Correction des outils MCP différés chargés par tool_search qui étaient abandonnés à la reprise et /reload même lorsque leur serveur se reconnectait avant l'invite suivante, car la session restaurait ses outils avant la reconnexion des serveurs MCP.
  • Correction du thème système rendant les palettes pastel telles que Catppuccin Frappe beaucoup plus vives ; les couleurs de la palette conservent désormais leur chrominance (#10255, #10293 par @dgtlntv).
  • Correction de l'auto-complétion des commandes slash ne se déclenchant pas lorsque l'entrée commence par un espace (#10218 par @haoqixu).
  • Correction du saignement des couleurs après les sélections de la souris et de la recherche des surbrillances en mode plein écran lorsqu'un jeton stylisé se termine à la limite de surbrillance (#10169).
  • Correction de la mémoire conservée par message rendu dans la transcription ; un long message d'assistant conserve environ un cinquième du tas qu'il conservait auparavant.

Anglais original / English original

pi v1.0.0

New Features

  • Fullscreen by default — The TUI now runs fullscreen. Set tuiMode to "regular" to keep the terminal's normal scrollback. See Terminal and display.
  • Leaner codemode — About 40% fewer prompt tokens, and errors that tell the model how to recover. See Codemode.
  • Image generation in codemode — Scripts call models.generateImages() with the session's credentials. See Generate images and Use image models.
  • Radius in /login — Sign in with Radius and set up its MCP server in one step. See Radius.
  • Anthropic copy code login — Sign in when the browser runs on another machine. See Authenticate interactively.
  • MCP OAuth hardening — oauth.authServerMetadataUrl, RFC 9207 iss checks, credentials per server, and step-up sign-in that keeps granted scopes. See Authenticate with OAuth.
  • Header-only quiet startup — quietStartup: "header" keeps the version and key hints and hides the rest. See Terminal and display.

Added

  • Added an oauth.authServerMetadataUrl setting for MCP servers that advertise a wrong OAuth authorization server or none. Pi uses the configured metadata document instead of discovery (#10172).
  • Added quietStartup: "header", which keeps the startup header with version and key hints but hides the model scope line and loaded-resource listing.
  • Added models.generateImages() to codemode scripts. It runs image models such as OpenRouter's with the session's credentials and returns base64 image blocks that image() attaches to the result; usage counts toward the session cost like models.classify(). Extensions can call ctx.modelRegistry.generateImages(). See Use image models.
  • Added a copy code login method to Anthropic /login for headless setups where the browser runs on another machine (#10194 by @lucasmeijer).

Changed

  • Changed the default TUI mode to fullscreen. Set tuiMode to "regular" or pass --tui-mode regular to keep the terminal's normal scrollback.
  • /login now offers "Sign in with Radius" at the top level, as the last option, with its status. After a Radius sign-in, /login offers to configure the Radius MCP server in the global mcp.json with "auth": { "provider": "radius" } and reloads. Cancelling a login returns to the menu it was started from.
  • The provider docs page is renamed to Providers, its "Cloud Providers" section is now "Provider Specific Config", and it documents Radius first.
  • MCP OAuth credentials are now stored per server name and URL, so MCP servers with the same URL can sign in with different accounts. Credentials stored by URL alone move to the first server that uses them (#10252).
  • Codemode costs far fewer prompt tokens: with the default tools and codemode active, a GPT-5.6 request shrinks from about 5,300 to 3,300 tokens. The codemode description lists the script globals in one line each and points to the new Codemode reference for the models API, which the model reads when it needs it. Declared tools say in one line how scripts call them and what the call resolves to, instead of repeating their full declaration, and the system prompt's codemode guidance and MCP server section are shorter.
  • Codemode errors now say how to recover: reading a tool or models member that does not exist names the close matches (tools.Bash suggests tools.bash), models.classify() and models.generateImages() reject malformed arguments with the expected shape, an unknown model points to models.getAvailableOfType(), an oversized store() value explains what the store is for, and a script that generates images without showing them gets a note. Scripts that probed for a tool with typeof tools.name must use "name" in tools.
  • /login and /logout now label providers without credentials as "not configured" instead of "unconfigured".
  • OAuth browser pages now show the color Pi logo.

Fixed

  • Fixed MCP OAuth sign-in accepting an authorization response whose iss parameter names another authorization server; the code is now rejected before it is exchanged (RFC 9207).
  • Fixed MCP OAuth sign-in failing with Invalid scope when the token response contains "scope": "", and similar failures for other empty or null optional OAuth fields (#10266).
  • Fixed the sign-in URL printed by /mcp login not being clickable when it wraps (#10186).
  • Fixed --provider without --model being silently ignored and running the default model from another provider; it now fails with an error (#10236).
  • Fixed MCP servers that ask for more scope (insufficient_scope) requesting sign-in over and over. The new sign-in requested only the missing scopes, so the new token lost access the previous one had; it now keeps the granted scopes.
  • Fixed user messages in the transcript keeping two full-width copies of every rendered line; they keep one, with identical output.
  • Fixed /login and /logout labeling every OAuth sign-in, including Radius, as a subscription; only subscription-backed providers say "subscription", other OAuth sign-ins say "account".
  • Fixed the startup header logo rendering with gaps in Apple Terminal; it now shows a colored "Pi" with the version instead.
  • Fixed deferred MCP tools that tool_search loaded being dropped on resume and /reload even when their server reconnected before the next prompt, because the session restored its tools before the MCP servers reconnected.
  • Fixed the system theme making pastel palettes such as Catppuccin Frappe much more vivid; palette colors now keep their chroma (#10255, #10293 by @dgtlntv).
  • Fixed slash command autocompletion not triggering when the input starts with whitespace (#10218 by @haoqixu).
  • Fixed color bleeding past mouse selections and search highlights in fullscreen mode when a styled token ends at the highlight boundary (#10169).
  • Fixed memory retained per rendered message in the transcript; a long assistant message keeps about a fifth of the heap it kept before.
