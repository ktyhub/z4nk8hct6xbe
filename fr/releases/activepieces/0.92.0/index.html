activepieces 0.92.0

Highlights

  • Breaking changes: connection promotion and action contracts — Releases and project replacements now apply changed connections instead of reverting them (#14899), so review connection diffs before promoting. Airtable’s setup and record lookups changed (#15483), while Pinterest/Trello expanded their agent-facing actions (#15539); reconfigure affected nodes and re-test lookup mappings and action inputs.

  • Sandboxed code execution is more reliable and isolated — A new Deno sandbox (#14370) is complemented by per-run, ephemeral DENO_DIR handling and HOME forwarding in workers (#15559, #15556). Self-hosters should review SANDBOX_CODE_ONLY behavior (#15578), while transient build failures and sandbox startup errors are less likely to leave code steps permanently broken (#15382, #15557).

  • Agents gain routing and run-level observability — AI Router selects a route from a single question (#15707), and agents can now be built from a description in chat (#15667). Run inspection exposes the steps taken, triggering flow, and actual duration without leaving the Agents page (#15583, #15548, #15561), making unattended agent execution easier to diagnose.

  • MCP connectors get stronger access controls and audit trails — OpenID Connect can restrict connectors by email domain (#15604), while the Activity feed records what clients actually executed (#15240, #15241, #15243). Grant revocation now cuts off access immediately rather than after up to 15 minutes (#15181); verify IdP claims/domain mappings and update tests that assumed delayed enforcement.

  • Enterprise authentication expands beyond static API keys — Shopify adds Dev Dashboard client credentials (#15755), Bedrock accepts SSO/STS temporary credentials in both pieces and AI-provider configuration (#15746, #15745), Azure SQL adds Entra ID service-principal authentication (#15681), and Zendesk adds OAuth2 (#15672). Salesforce OAuth now correctly sends a PKCE challenge (#15662); provision least-privilege identities and account for credential expiration.

  • Execution correctness and data integrity fixes change operational behavior — Failed webhook authentication now creates a failed run and stops synchronous flows (#14954), so expect these attempts in dashboards and alerting. Retried subflow crashes keep the calling flow waiting (#15642), and table edits/deletions no longer corrupt other columns (#15764, #15709); re-test retry handling and verify affected table data after upgrading.
