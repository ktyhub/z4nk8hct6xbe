tinker-cookbook v0.3.0

v0.3.0

Benchmark evaluation framework, cloud storage backends, and structured training run stores.

Highlights

  • Benchmark evaluation framework — 21 benchmarks (12 stable, 9 experimental) with concurrency, resumability, trajectory storage, and pass@k support (#569)
  • Cloud storage — S3, GCS, and Azure backends via FsspecStorage for training logs, checkpoints, and eval results (#623)
  • Stores module — Typed TrainingRunStore and RunRegistry for structured access to training runs (#617)

New features

  • Pluggable quantization formats + GPU acceleration for weight export (#583)
  • True-Thinking Score (TTS) recipe (#578)
  • MXFP4 shard merge support for GPT-OSS models (#590)
  • Generalize SandboxFactory for non-Modal backends (#588)

Improvements

  • Dynamic max_tokens capping via context_window (#618)
  • Parallel evaluation in async training loop (#630)
  • Thread TrainingRunStore through all training loops (#620, #621, #627)
  • Cloud URI support for logging (#625, #628)
  • Public API exports for distillation and eval exceptions (#639)
  • Remove v0.3.0-deprecated parameters (#635)

Bug fixes

  • Fix grading bugs in IFEval, MATH-500, and GPQA benchmarks — IFEval +3.9pp, MATH-500 +3.2pp on Qwen3.5-35B-A3B (#643)
  • Guard against edge-case crashes in RL, preference, and xmux (#644)
  • Fix DPO training crash with odd batch size (#637)
  • Fix FP8 expert quantization for fused 3D expert tensors (#597)
  • Fix unembed_tokens merge for models with tied embeddings (#593)
  • Fix load_config_dict not forwarding trust_remote_code (#586)
  • Fix IncrementalReader locking and FsspecStorage flush re-upload (#629)

See the full CHANGELOG.md for details.
