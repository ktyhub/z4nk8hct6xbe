hyperframes v0.9.73

HyperFrames v0.9.73

Released on 2026-11-20.

Preview copies of long clips with sound finish again, so their footage no longer shows black. Saving history on a drive that stops answering no longer freezes the app, and sealed films show when their timeline arrives late.

Fixes

  • Studio: Paste refuses an element with an event handler or a script link (7b2c6dc1a, #8298).
  • Studio: The first edit of a film without ids no longer reloads the preview (99fcdfb5c, #8274).
  • Producer: Reserve each font's inline size before reading it (8ad346357, #8302).
  • Producer: Refuse a render whose mounts copy more than 100,000 elements (31959db98, #8295).
  • Studio: A timing drag moves the animation in place in a sealed preview (6cf81c668, #8163).
  • Media Use: Never write recipe files through links (be3d21807, #8257).
  • Studio: A host can own the live preview's load deadline, so a slow sealed film isn't an error (44d805c44, #8206).
  • Producer: Download at most 1,000 remote assets per compile, 8 at a time (c50ec09d2, #8290).
  • Producer: Pass the render's cancel to the compile's media, image and font downloads (edd1c90a4, #8289).
  • Share: A first share only lands on a review it created (1d5403525, #8282).
  • Core: Stop audio automation from crashing the preview renderer (e3896cf08, #8299).
  • Producer: A remote font embeds in the page instead of warning it is missing (2f23fbd36, #8297).
  • Studio Server: Saving history on a drive that stops answering no longer freezes the app (88c22a77f, #8294).
  • Player: A sealed film shows when its timeline arrives after the 8 s check (58de4c783, #8293).
  • Studio: A sealed audio group's undo reads the frame's reply only in its shape (3c735ad01, #8291).
  • CLI: Preview answers unknown paths with an inert refusal, not the Studio shell (4e3c96045, #8161).
  • Studio: A sealed resize of a layer whose GSAP keyframes animate its width saves (9b7be276a, #8288).
  • Studio: A sealed move, resize or turn takes GSAP's route when GSAP animates the layer (468ab907e, #8286).
  • Studio: A sealed resize, move or turn typed or made by the agent shows in the preview (89edb0af0, #8283).
  • Studio: Agent tools see the film in a sealed preview (c34df57ab, #8281).
  • Studio: A sealed crop lands where it was dragged (a755e3f58, #8279).
  • Core: A sub-composition's script re-run keeps the preview at its playhead (332720972, #8276).
  • Core: A redo in a sealed preview puts Studio's edit marks back in place (95a8a91b5, #8264).
  • Core: Split a rule's selector list once when rewriting svg id references (fbbbfe058, #8275).
  • Studio Server: Preview copies of long clips with sound finish again (07928702f, #8253).
  • Media Use: Remove only the temp folders media-use made, and never fail on cleanup (e16c681dc, #8267).
  • Core: Check svg id scopes against excluded roots in one ancestor walk (026bff07d, #8273).
  • Share: Ask before sharing from Studio and bind each action to the confirmed review (2c3427089, #8268).
  • Studio: A video with no size of its own keeps its file's size while a lighter copy plays (ce0932e04, #8233).
  • Studio: A sealed preview turns a rotated element live and saves the turn on its own route (fdc7d676c, #8271).
  • Studio: A sealed undo or redo of a keyframe edit re-runs in place instead of reloading (4fd96e353, #8272).
  • Studio: A sealed preview's timeline names each file by its project path (a8884522f, #8213).
  • Studio: A sealed preview's failed reload says only what the preview reported (f13969f13, #8194).
  • Engine: Bound the seek-index rebuild's temp copy (fab75fb91, #8269).

Docs & Examples

  • Render: Name the 100,000-element limit beside the mount limits (d6411daac, #8309).

Internal

  • Studio: A test chrome launch that fails with a non-error names what it holds (0ecb6671f, #8305).
