HyperFrames v0.9.82

Sorti le 2026-11-22. Un aperçu charge le plug-in de chemin de mouvement de GSAP à partir du dossier GSAP de la page ou de la copie de l'hôte, afin qu'il fonctionne sans réseau. Les aperçus scellés bénéficient de plus de correctifs, du son et du clavier aux mouvements dans les compositions imbriquées.

Correctifs

  • Producteur : Un rendu sert chaque GSAP livré par le CLI, ainsi que le sien lorsque le CDN est bloqué (8c9c94572, #8349).
  • Core : Le plugin de chemin de mouvement se charge à côté du propre GSAP de la page, jamais d'un CDN qu'il n'a pas nommé (80f45de33, #8523).
  • Producteur : Un film avec plusieurs clips d'une vidéo 4K ne gèle plus la sonde de rendu (4daeb78c3, #8284).
  • Studio : Un aperçu scellé ne conserve jamais le clavier, donc aucune touche signalée n'est utilisée (196eff39e, #8521).
  • Studio : La zone recadrée d'un calque retourné correspond aux limites de ses coins coupés (e5e360154, #8502).
  • Lecteur : Un film scellé est entendu lorsque son image ne démarre pas le son (87fddbc1a, #8495).
  • Core : Le balisage collé ou écrit ne contient jamais de source de composition provenant d'ailleurs (2425df5f4, #8520).
  • CLI : Les téléchargeurs de fichiers épinglés vérifient que le dossier cache est privé avant de le lire ou de l'écrire (675e3a876, #8486).
  • Studio : Collez et dupliquez la vérification du fichier qu'ils écrivent, après chaque modification (bd7a8402d, #8519).
  • CLI : Publier met à jour un projet validé uniquement lorsque cette machine a lié le dossier (886f609c4, #8487).
  • CLI : Imprime les noms des fichiers de projet dans les notes stderr du chèque sous forme d'échappements visibles (4202462ca, #8485).
  • Joueur : Une chronologie tardive de l'ancien film ne maintient plus un lecteur commuté prêt (c19d98d9a, #8500).
  • Core : Un mouvement scellé à l'intérieur d'une composition imbriquée montre où il a été déposé (ec9a3a8ef, #8517).
  • Studio Server : Une page contenant des milliers de balises de script ne bloque plus l'aperçu (0bc7963ff, #8518).
  • Producteur : L'erreur de manque de mémoire d'une étape de sonde conserve ses mots, elle est donc toujours lue en mémoire (258a3cf4e, #8513).
  • CLI : Cloudrun et lambda indiquent une erreur d'utilisation avant de charger leur cloud SDK (fbd1cd4bc, #8510).
  • Core : Une timeline dont les étiquettes ne vident plus la liste clip (5d4420fee, #8512).
  • Studio : Vitest se ferme lorsqu'un projet est ouvert dans le dossier de données de développement (b3d37f948, #8514).
  • Studio : La porte d'affichage indique une chronologie virtualisée par ses lignes montées, et non par ses clips (dd7799037, #8511).
  • Studio : Le contour d'un calque recadré est découpé à l'échelle du calque, scellé ou non (2b1495f7a, #8496).
  • Core : Un clip lointain dont la source est permutée apprend sa nouvelle longueur (4a47c33ea, #8509).
  • Studio Server : La prévisualisation d'une page contenant des milliers de fichiers multimédias ne bloque plus l'application (f03233ab4, #8505).
  • Producer : Un rendu qui s'arrête pendant la préparation nomme l'étape à laquelle il s'est arrêté (852611378, #8506).

hyperframes v0.9.82

HyperFrames v0.9.82

Released on 2026-11-22.

A preview loads GSAP's motion path plugin from the page's own GSAP folder or the host's copy, so it works with no network. Sealed previews get more fixes, from sound and the keyboard to moves inside nested compositions.

Fixes

  • Producer: A render serves every GSAP the CLI ships, and its own when the CDN is blocked (8c9c94572, #8349).
  • Core: The motion path plugin loads from beside the page's own GSAP, never a CDN it did not name (80f45de33, #8523).
  • Producer: A film with many clips of one 4K video no longer freezes the render probe (4daeb78c3, #8284).
  • Studio: A sealed preview never keeps the keyboard, so no key it reports is acted on (196eff39e, #8521).
  • Studio: A turned layer's cropped box is the bounds of its cut corners (e5e360154, #8502).
  • Player: A sealed film is heard when its frame may not start sound (87fddbc1a, #8495).
  • Core: Pasted or written markup never carries a composition source from elsewhere (2425df5f4, #8520).
  • CLI: Pinned-file downloaders check the cache folder is private before reading or writing it (675e3a876, #8486).
  • Studio: Paste and duplicate check the file they write, after every edit to it (bd7a8402d, #8519).
  • CLI: Publish updates a committed project only when this machine linked the folder (886f609c4, #8487).
  • CLI: Print project file names in check's stderr notes as visible escapes (4202462ca, #8485).
  • Player: A late timeline from the old film no longer keeps a switched player ready (c19d98d9a, #8500).
  • Core: A sealed move inside a nested composition shows where it was dropped (ec9a3a8ef, #8517).
  • Studio Server: A page with thousands of script tags no longer stalls the preview (0bc7963ff, #8518).
  • Producer: A probe step's out-of-memory error keeps its words, so it still reads as memory (258a3cf4e, #8513).
  • CLI: Cloudrun and lambda say a usage error before loading their cloud SDK (fbd1cd4bc, #8510).
  • Core: A timeline whose labels throw no longer empties the clip list (5d4420fee, #8512).
  • Studio: Vitest exits when a project is open in the dev data folder (b3d37f948, #8514).
  • Studio: The viewport gate tells a virtualized timeline by its mounted rows, not its clips (dd7799037, #8511).
  • Studio: A cropped layer's outline is cut at the layer's own scale, sealed or not (2b1495f7a, #8496).
  • Core: A far clip whose source is swapped learns its new length (4a47c33ea, #8509).
  • Studio Server: Previewing a page with thousands of media files no longer stalls the app (f03233ab4, #8505).
  • Producer: A render that stops while preparing names the step it stopped in (852611378, #8506).

Internal

  • CLI: The diagnostic test's ffmpeg stand-in answers the demuxer listing, writing no file (f38a4e367, #8515).
  • Studio: A failed walk in the viewport gate job names itself on the check (086948766, #8516).
  • CLI: The sign-in return test waits for each window's navigation instead of one second (20a91dd5f, #8507).
