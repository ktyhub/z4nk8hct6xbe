hyperframes v0.9.78

HyperFrames v0.9.78

Released on 2026-11-21.

Undo after an agent step now brings back the files it changed. A catalog gap report on Windows never puts a query your shell would run into a command, and renders sharing one capture proxy keep their connections.

Features

  • Engine: A late image's load time is logged when it arrives (e65b11e5c, #8372).

Fixes

  • CLI: Show control characters as text in notices that repeat a failure reason (c75860ddf, #8387).
  • Core: A Windows rename onto a folder that exists fails at once instead of waiting 1.3 s (7cb548e45, #8389).
  • Core: Show text direction marks and typed text as visible text in printed lines (f01d1f32b, #8384).
  • Studio Server: History keeps undo steps in order when file times and its clock disagree (63e700de1, #8383).
  • Core: A long text's name is cut at a word, not inside one (19587337f, #8388).
  • CLI: Check reports its own deadlines as check_deadline (d78e9a5f3, #8378).
  • CLI: Windows kills end only the process the CLI started, never a reused pid (93f2fcca4, #8382).
  • Player: Stop the preview reloading itself after a quick seek, and stalling at cuts on a slower connection (120689e3c, #8339).
  • CLI: Print check and validate setup commands on their own lines (88f7d4052, #8381).
  • Studio Server: The preview file check resolves links on volumes that refuse native realpath (40cc86252, #8377).
  • CLI: Print capture setup commands on their own lines (281f1a2a4, #8374).
  • Studio Server: An agent step waits for history's first copies, so undo brings old files back (fbbf5ee67, #8375).
  • Studio Server: History refusals carry a closed reason, so callers tell them from failures (d5881e8aa, #8376).
  • Studio Server: A timed-out history save says it may still land, so callers don't retry blindly (6b74cfa9f, #8300).
  • CLI: Read --json before the command name the same as after it (9a618b798, #8365).
  • CLI: Show control characters as text in capture, figma, usage and notice lines (7fcc4909b, #8366).
  • Studio: Adding or removing a text field keeps the spaces between words (e8f52dc86, #8369).
  • CLI: A received-files write waits out a held lock instead of failing on Windows (f74e1545c, #8367).
  • CLI: A stop reads the process tree from /proc on Linux, so load cannot hide a child (a2df08e49, #8363).
  • Engine: A capture proxy shared by many browsers no longer drops tunnels at 128 (5e16c18b1, #8362).
  • CLI: Show control characters as text in init, skills and render printed lines (8bc73a0bd, #8352).
  • CLI: Show control characters as text in more commands' printed lines (7a1163fc9, #8353).
  • Studio Server: A preview file request no longer waits on a silent drive on the event loop (7cb605c78, #8254).

Catalog

  • CLI: A catalog gap report hands back a line only when every shell reads the query as text (414557262, #8373).

Internal

  • CLI: The probe-cache snapshot test asks 16 times of an 8 s clip, not 40 of 20 s (c7a6c9315, #8390).
  • Lint: Linear scans are held to characters read and one coarse time bound (e0d844030, #8386).
  • Studio: The marquee-past-the-cap check waits as long as the frame takes to answer (b0d9f3615, #7757).
  • Studio Server: A held-file edit is checked for blocking waits, not wall-clock gaps (29a5003ee, #8236).
  • Studio Server: A held save proves it never sleeps the thread, not a 100 ms stall bound (ba81f6793, #8359).

Other Changes

  • CLI: The proxy fix and its Node.js 22.19 floor came out again before this release; they ship in v0.10.0 (296031974, #8311, 66156bf35, #8391).
