✨ Premier plan de design au monde : des modèles abordables pour tous

Allocation mensuelle généreuse. Explorez et affinez vos créations avec DeepSeek V4.1 Flash, GLM-5.3 Flash et MiMo 2.6 Flash. Commencez avec Go pour $8 pour votre premier mois, ou choisissez Plus ou supérieur pour jusqu'à $200 de crédits bonus. Accès API dans tout votre flux de travail. Tous les niveaux d'abonnement personnel prennent en charge les appels API. Utilisez votre clé OpenDesign API avec Codex, Claude Code, DSH, OpenCode, Hermes et d'autres agents IA. Crédits gratuits pour les nouveaux utilisateurs. Chaque nouvel utilisateur reçoit environ $0.50 en crédits gratuits pour essayer OpenDesign.

🐛 Corrigé

🧠 Agents, runtimes et diagnostics

  • Une exécution proprement terminée reste visiblement terminée. Un blocage au niveau de la tâche ne transforme plus la sortie d'un agent propre en une carte d'exécution ratée trompeuse ; les vrais crashs et les sorties ratées restent toujours des échecs. (#8350) Merci @itscheems.
  • Les bundles de support conservent les indices qui comptent. Les diagnostics contiennent désormais des preuves de l'état des démons pour la pression de la mémoire, la croissance de SQLite et les sorties impures, que vous exportiez depuis l'application ou avec od diagnostics export. (#8354) Merci @PerishCode.
  • Les preuves d'échec peuvent être collectées avant que la piste ne se refroidisse. Avec le consentement existant activé, les échecs d'agent et de livraison détectés sont limités à la file d'attente et les diagnostics rédigés automatiquement ; la désinscription arrête la collecte. (#8357) Merci @Siri-Ray.
  • Les exécutions en bac à sable OD Next sont nettoyées après elles-mêmes. La racine d'accès aux entrées d'exécution reste accessible en écriture pour le démontage du bac à sable au lieu de laisser une exécution bloquée lors du nettoyage. (#8024) Merci @arqueon.
  • Les échecs fatals de MCP indiquent ce qui s'est passé. Un processus stdio MCP écrit désormais son erreur fatale avant de se terminer, de sorte que le client dispose d'un diagnostic utilisable au lieu d'une disparition silencieuse. (#7340) Merci @lorenzozanee.

🖥️ Bureau et présentation

  • La mise à jour de l'application de bureau n'entraîne plus son propre arrêt. Le trafic du moteur de rendu est arrêté avant la fin du runtime packagé, ce qui rend le transfert de redémarrage plus sûr. (#8348) Merci @PerishCode.
  • Le bouton de sortie plein écran appartient au thème que vous avez choisi. Ses couleurs, son état de survol et le focus du clavier restent désormais lisibles dans les présentations claires et sombres. (#7272) Merci @dennytosp.
  • Une session macOS MCP peut devenir une fenêtre de bureau en place. L'ouverture de l'application après le démarrage de son exécution sans tête révèle désormais la fenêtre normale sans perdre la session locale. (#8398) Merci @PerishCode.

🏠 Accueil et campagnes

  • Le menu des types de tâches reste ouvert lorsque vous le demandez. Un click immédiatement après que Home ait choisi un type n'ouvre plus le sélecteur uniquement pour qu'il se ferme automatiquement. (#8386) Merci @Siri-Ray.
  • Une campagne valide reste présente malgré les interruptions ordinaires. Les changements de réseau, les courtes mises en veille et les changements d'onglets ne suppriment plus inutilement une campagne active ; le contenu mis en cache suit son calendrier de serveur connu lorsqu'il est hors ligne. (#8292) Merci @alchemistklk.

open-design open-design-v0.24.1

✨ World’s First Design Plan: Affordable models for everyone

Generous monthly allowance. Explore and refine your designs with DeepSeek V4.1 Flash, GLM-5.3 Flash and MiMo 2.6 Flash. Get started with Go for $8 for your first month, or choose Plus or above for up to $200 in bonus credits.

API access across your workflow. All personal subscription tiers support API calls. Use your OpenDesign API key with Codex, Claude Code, DSH, OpenCode, Hermes and other AI agents.

Free credits for new users. Every new user receives approximately $0.50 in free credits to try OpenDesign.

🐛 Fixed

🧠 Agents, runtimes and diagnostics

  • A cleanly finished run stays visibly finished. A task-level block no longer turns a clean agent exit into a misleading failed-run card; real crashes and failed exits still remain failures. (#8350) Thanks @itscheems.
  • Support bundles retain the clues that matter. Diagnostics now carry daemon health evidence for memory pressure, SQLite growth and unclean exits, whether you export from the app or with od diagnostics export. (#8354) Thanks @PerishCode.
  • Failure evidence can be collected before the trail goes cold. With existing consent enabled, detected Agent and delivery failures queue bounded, redacted diagnostics automatically; opting out stops collection. (#8357) Thanks @Siri-Ray.
  • OD Next sandboxed runs clean up after themselves. The run input access root remains writable for sandbox teardown instead of leaving a run stranded on cleanup. (#8024) Thanks @arqueon.
  • Fatal MCP failures say what happened. An MCP stdio process now writes its fatal error before it exits, so the client has a usable diagnostic instead of a silent disappearance. (#7340) Thanks @lorenzozanee.

🖥️ Desktop and presentation

  • Updating the desktop app no longer races its own shutdown. Renderer traffic is stopped before the packaged runtime retires, making the restart handoff safer. (#8348) Thanks @PerishCode.
  • The fullscreen exit button belongs to the theme you chose. Its colors, hover state and keyboard focus now remain readable in both light and dark presentations. (#7272) Thanks @dennytosp.
  • A macOS MCP session can become a desktop window in place. Opening the app after its headless runtime started now reveals the normal window without losing the local session. (#8398) Thanks @PerishCode.

🏠 Home and campaigns

  • The task-type menu stays open when you ask for it. A click immediately after Home chooses a type no longer opens the picker only for it to snap shut. (#8386) Thanks @Siri-Ray.
  • A valid campaign remains present through ordinary interruptions. Network changes, short sleeps and tab switches no longer unnecessarily remove an active campaign; cached content follows its known server schedule while offline. (#8292) Thanks @alchemistklk.
