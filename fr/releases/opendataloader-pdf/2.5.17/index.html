What's Changed

  • docs(skills): odl-fix uses the attachment, side-effect, and benchmark tools of odl-review by @bundolee in https://github.com/opendataloader-project/opendataloader-pdf/pull/837
  • chore: begin 2.5.17-SNAPSHOT by @github-actions[bot] in https://github.com/opendataloader-project/opendataloader-pdf/pull/839

  • chore(deps)!: bump pillow 12.3.0 -> 13.0.0 and the docling family by @bundolee in https://github.com/opendataloader-project/opendataloader-pdf/pull/841
  • chore(deps)!: bump filelock 3.32.7 -> 4.2.4 by @bundolee in https://github.com/opendataloader-project/opendataloader-pdf/pull/842
  • fix(struct-tree): leave out text in /Artifact sequences by @bundolee in https://github.com/opendataloader-project/opendataloader-pdf/pull/844
  • Add createIDTree method to build IDTree for StructTree in AutoTagging by @LonelyMidoriya in https://github.com/opendataloader-project/opendataloader-pdf/pull/832
  • fix(hybrid): keep backend page headers and footers for --include-header-footer by @bundolee in https://github.com/opendataloader-project/opendataloader-pdf/pull/847

  • feat(skills): add an issue triage and a contract harness to odl-fix by @bundolee in https://github.com/opendataloader-project/opendataloader-pdf/pull/849
  • fix(core): leave out U+0000 in the text output, as the other writers do by @bundolee in https://github.com/opendataloader-project/opendataloader-pdf/pull/850
  • fix(markdown): drop a struck list label and keep the strikethrough markup balanced by @bundolee in https://github.com/opendataloader-project/opendataloader-pdf/pull/853
  • test(hybrid): test the real chunk loop and the hybrid CLI options by @bundolee in https://github.com/opendataloader-project/opendataloader-pdf/pull/854
  • fix(markdown): escape a heading or list marker at the start of a list item by @bundolee in https://github.com/opendataloader-project/opendataloader-pdf/pull/852

  • fix(tagging): share one MCID only between text shows that follow each other in the element by @bundolee in https://github.com/opendataloader-project/opendataloader-pdf/pull/858
  • fix(markdown): write an image in a line of text at its place in the line by @bundolee in https://github.com/opendataloader-project/opendataloader-pdf/pull/861
  • feat(hybrid): start and stop the hybrid server from Python by @bundolee in https://github.com/opendataloader-project/opendataloader-pdf/pull/860
  • feat(skills): bounded review in odl-review by @bundolee in https://github.com/opendataloader-project/opendataloader-pdf/pull/863
  • feat(core): write URI links in Markdown and HTML with --include-links by @bundolee in https://github.com/opendataloader-project/opendataloader-pdf/pull/862
  • feat(hybrid): add --hybrid-availability-timeout for the availability check by @bundolee in https://github.com/opendataloader-project/opendataloader-pdf/pull/865
  • fix(tagging): tag text drawn as outlines with its OCR text by @hnc-jglee in https://github.com/opendataloader-project/opendataloader-pdf/pull/866
  • feat(hybrid): add --hybrid-triage-log to write the triage decision of each page by @bundolee in https://github.com/opendataloader-project/opendataloader-pdf/pull/867
  • docs: keep released options working and say when one can be removed by @bundolee in https://github.com/opendataloader-project/opendataloader-pdf/pull/868
  • fix(hybrid): tag the stream text the backend returned no element for by @hnc-jglee in https://github.com/opendataloader-project/opendataloader-pdf/pull/869
