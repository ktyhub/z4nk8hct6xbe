career-ops web-v0.18.0

Highlights

  • CV factuality checks — Tailoring now blocks bullets whose verbs drift from their source bullets (#6630), while new renderLint warnings expose content the renderer silently drops (#5943). Review these warnings before publishing; a clean-looking PDF can still omit or misstate source facts.
  • Template management in Config — The web UI now supports browsing CV and cover-letter templates, choosing a default, and duplicating, renaming, or deleting your own templates (#5945, #5961, #5962). Teams can manage variants without editing files directly, while deletion remains limited to user-owned templates.
  • Evaluation and prompt handling — Script-rendered job descriptions are read before the evaluate worker starts (#6604), and oversized agent prompts spill to a file instead of argv, avoiding platform argument-length failures (#6719, #6743). Stopped evaluations now appear as unscored review outcomes (#6496), so automation must not treat them as completed scores.
  • Apply-automation guardrails — The never-submit guard now recognizes Norwegian and Vietnamese submit wording, including Vietnamese labels inside forms (#6629, #6661), while Workday, iCIMS, and UKG are rejected before a browser opens (#6595). Workflows targeting those ATS platforms need a fallback; the localized blocks are intentional safety checks.
  • Pipeline and inbox semantics — Posting close dates are retained and displayed (#6597), conditional workplace-geography rules run before inbox admission (#6484), and weekly matches are ranked before pagination (#6783). Users may see fewer geography-ineligible candidates, one row per posting (#6602), and Lapsed statuses normalized to Discarded (#6598).
  • Breaking changes — None.
