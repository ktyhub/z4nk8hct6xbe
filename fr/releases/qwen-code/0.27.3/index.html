Fonctionnalités

  • Ajout de puces au-dessus du compositeur Web Shell pour les flux de travail en arrière-plan, les shells, les moniteurs et les agents locaux inachevés, remplaçant la pilule de tâches de la barre d'état. (#16813) par @qqqys
  • Ajout de la localisation en chinois pour les invites d'événement du canal GitHub dans les sessions liées aux relations publiques lorsque la langue de l'interface utilisateur du canal est le chinois, tandis que les autres langues restent l'anglais. (#16773) par @wenshao
  • MCP géré ne compte désormais que jusqu'à 32 sélections en direct, conserve les entrées supprimées pour la récupération, conserve la limite de 16 activées et limite les instantanés conservés à 96 entrées. (#15161) par @yiliang114
  • Ajout de SPI d'agent géré qui permettent aux applications d'intégration d'importer des révisions exactes de compétences ou d'extensions à partir de sources externes et de stocker les archives compilées dans un stockage privé. (#16882) par @doudouOUC
  • Permet aux mods de réécrire les lignes de réponse affichées dans le terminal OpenTUI via ui.render tout en préservant le texte du message stocké et la sortie /copy. (#16873) par @qqqys
  • Enregistre les états des demandes d'extraction à partir de listes minces et transmet leurs clés à la montre afin que les demandes d'extraction fermées puissent quitter correctement la rotation de la vue. (#16847) par @wenshao
  • Ajoute un canal dingtalk-webhook d'envoi uniquement qui publie des notifications et des résultats de tâches réussies sous forme de Markdown aux robots de groupe personnalisés DingTalk configurés. (#16802) par @jkxiao
  • Les listes de sessions de la barre latérale s'étendent désormais sur dix sessions par click, avec des étiquettes indiquant le nombre restant, au lieu de toutes les afficher en même temps. (#16830) par @wenshao
  • Les sessions gérées stockent désormais des ressources surdimensionnées et des journaux fermés compactés dans le stockage d'objets, préservant ainsi la récupération et les lectures normales. (#16868) par @doudouOUC
  • Ajoute des primitives de bus d'événements internes pour la boucle d'agent unifiée sans modifier le comportement actuel. (#16935) par @wenshao
  • Ajoute la configuration du webhook DingTalk dans Web Shell et permet aux tâches planifiées de sélectionner les destinations de canal enregistrées. (#16804) par @jkxiao
  • Permet aux hôtes d'intégration d'ajouter du contenu d'en-tête et par modèle au sélecteur de modèle du compositeur tout en préservant le comportement natif de la recherche, de la sélection et du clavier. (#16933) par @callmeYe
  • Ajoute l'option AgentLoopOptions.useEventBus pour exécuter la boucle d'agent partagée sur les gestionnaires de bus d'événements sans modifier le comportement observable. (#16938) par @wenshao
  • Le flux sandbox/verify approfondit désormais la vérification pour inclure le PR et l'historique de base nécessaires avant la vérification, améliorant ainsi la gestion des poussées forcées et des validations manquantes. (#16781) par @wenshao
  • feat(cli) : active la boucle de l'agent event-bus sur headless derrière un paramètre expérimental (#16994) par @wenshao
  • Lorsque experimental.unifiedAgentLoop est activé, les tours de modèle AgentCore s'exécutent désormais via la boucle d'agent partagée. (#16880) par @qqqys
  • feat(workflows) : autoriser les exécutions en arrière-plan demandées par le modèle dans les sessions ACP (#16876) par @qqqys
  • feat(core) : exécuter les lots d'outils d'AgentCore sur la boucle d'agent partagée (#17035) par @qqqys
  • exploit : liaison manuelle PR de session (commande /pr + boîte de dialogue Web Shell) (#16877) par @wenshao
  • Les lecteurs de journal des agents gérés résolvent désormais les enregistrements expulsés des packs de journaux, activant ainsi qwen.managed-agent.session-resources.deletion-enabled. (#17047) par @doudouOUC
  • Les sessions gérées stockent désormais de manière durable les réveils/en boucle à votre rythme dans le journal de session afin qu'ils survivent aux redémarrages et aux reprises. (#16835) par @wenshao

qwen-code v0.27.3

<!-- qwen-release-notes:v1 -->

Highlights

See the complete change list below.

Breaking Changes

No known breaking changes.

Complete Change List

Features

  • Added chips above the Web Shell composer for unfinished background workflows, shells, monitors, and local agents, replacing the status-bar task pill. (#16813) by @qqqys
  • Added Chinese localization for GitHub channel event prompts in PR-bound sessions when the channel UI language is Chinese, while other languages remain English. (#16773) by @wenshao
  • Managed MCP now counts only up to 32 live selections, retains removed entries for recovery, keeps the 16-enabled limit, and caps retained snapshots at 96 entries. (#15161) by @yiliang114
  • Added managed-agent SPIs that let embedding applications import exact Skill or extension revisions from external sources and store compiled archives in private storage. (#16882) by @doudouOUC
  • Enables Mods to rewrite displayed reply rows in the OpenTUI terminal via ui.render while preserving stored message text and /copy output. (#16873) by @qqqys
  • Records pull request states from slim listings and passes their keys to the watch so closed pull requests can leave view rotation correctly. (#16847) by @wenshao
  • Adds a sending-only dingtalk-webhook channel that posts notifications and successful task results as Markdown to configured DingTalk custom group robots. (#16802) by @jkxiao
  • Sidebar session lists now expand ten sessions per click, with labels showing remaining count, instead of showing all at once. (#16830) by @wenshao
  • Managed Sessions now store oversized resources and compacted closed journals in object storage, preserving recovery and normal reads. (#16868) by @doudouOUC
  • Adds internal event-bus primitives for the unified agent loop without changing current behavior. (#16935) by @wenshao
  • Adds DingTalk webhook configuration in Web Shell and lets Scheduled Tasks pick saved Channel destinations. (#16804) by @jkxiao
  • Lets embedding hosts add header and per-model content to the composer model picker while preserving native search, selection, and keyboard behavior. (#16933) by @callmeYe
  • Adds opt-in AgentLoopOptions.useEventBus to run the shared agent loop on event-bus handlers without changing observable behavior. (#16938) by @wenshao
  • The sandboxed /verify flow now deepens the checkout to include the PR and base history needed before verification, improving handling of force-pushes and missing commits. (#16781) by @wenshao
  • feat(cli): enable the event-bus agent loop on headless behind an experimental setting (#16994) by @wenshao
  • When experimental.unifiedAgentLoop is enabled, AgentCore model rounds now run through the shared agent loop. (#16880) by @qqqys
  • feat(workflows): allow model-requested background runs in ACP sessions (#16876) by @qqqys
  • feat(core): run AgentCore's tool batches on the shared agent loop (#17035) by @qqqys
  • feat: Manual session PR binding (/pr command + Web Shell dialog) (#16877) by @wenshao
  • Managed agent journal readers now resolve evicted records from journal packs, enabling qwen.managed-agent.session-resources.deletion-enabled. (#17047) by @doudouOUC
