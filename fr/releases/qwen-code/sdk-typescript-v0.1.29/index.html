Faits saillants

Le CLI 0.23.0 fourni comprend deux correctifs demandés dans #11022 :

  • La disponibilité de la mémoire gérée respecte désormais le paramètre memory.enableManagedAutoMemory (#6941). Les hôtes qui désactivent la mémoire automatique gérée ne voient plus les requêtes de mémorisation/rêve admises ni les instructions de mémoire gérée dans l'invite système ; les correctifs locaux peuvent être supprimés.
  • Le microcompaction déclenché par la taille efface désormais les anciens résultats de l'outil vers un filigrane faible (#8464), de sorte qu'il ne réécrit plus une autre partie du préfixe de conversation à chaque tour suivant. La réutilisation du cache d'invite du fournisseur est préservée lors de longues sessions gourmandes en outils, réduisant ainsi le coût des entrées mises en cache.

Highlights

The bundled CLI 0.23.0 includes two fixes requested in #11022:

  • Managed memory availability now respects the memory.enableManagedAutoMemory setting (#6941). Hosts that disable managed auto memory no longer see remember/dream requests admitted or managed-memory instructions in the system prompt; local patches can be removed.
  • Size-triggered microcompaction now clears old tool results toward a low watermark (#8464), so it no longer rewrites another part of the conversation prefix on every subsequent turn. Provider prompt-cache reuse is preserved across long tool-heavy sessions, reducing cached-input cost.
