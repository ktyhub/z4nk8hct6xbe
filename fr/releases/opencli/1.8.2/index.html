OpenCLI v1.8.2

Highlights

  • Adapter coverage explodes — Five new surfaces land in one release: Kimi (21 commands, #1804), Qoder IDE (19, #1803), Trae Solo (19, #1801), Trae CN desktop (#1743), and WeChat Video Channels / 视频号 publishing (#1806). This is the headline for adopters: if your workflow lives in one of these tools, you now get a first-class command set instead of hand-rolled DOM workarounds. Watch-out — these are brand-new, mostly first-time-contributor adapters, so selector fragility is the main risk; pin the version you validate against.
  • Chat assistants gain stateful operations — Grok gets delete/pin/unpin plus locale-independent selectors (#1798), Codex gets pin/unpin/archive/rename and a model-selector fix (#1799), Antigravity gets history/delete/mark-read and model switching (#1800), and ChatGPT web gains a model-switch command (#1739). These adapters move from read-only scraping into real session management, which unlocks conversation-curation automation — but destructive verbs (delete/archive) mean you should scope credentials and rehearse on throwaway accounts. The locale-independent selectors in #1798 are the quiet win: they stop Grok automation from breaking when the UI language changes.
  • Silent-failure fixes you'll actually feel — #1789 adds --remote-allow-origins=* to the Chromium launcher to satisfy the 142+ WebSocket origin check; without it, remote CDP sessions can fail after a browser upgrade with no clear error. Grok now falls back to Enter-key dispatch when the submit button never renders (#1808), and the extension scopes reusable-tab selection to owned group members (#1816) — both close cases where commands appeared to hang or acted on the wrong tab. Also note ChatGPT now ignores image placeholders and upload previews when detecting attachments (#1802), which changes what counts as "has media" and matters if your scripts branch on that state.
  • Sitemap authoring becomes a first-class workflow — #1820 surfaces sitemap context in the browser, #1822 ships schema v1.1 with 12 patches from the Twitter + Hacker News PoC, #1821/#1824 add a detailed schema reference and SKILL.md guidelines, and #1809 now requires network-first strategy evidence in new adapter PRs. Migration watch-out: #1826 relocates the global seed to a top-level sitemaps/ directory (seeded in #1823), so existing references to the old path need updating. #1829 also restores the smart-search skill — re-test it if your flows depended on it.
  • Content-platform correctness — Xiaohongshu/RedNote now attaches real topics via the inline # dropdown (#1779), returns signed note URLs for drill-down (#1805), and gains draft management with more reliable publishing (#1784); Douyin adds keyword video search (#1759) and fixes an illegal-title error on publish (#1740); Twitter adds batch follow/list lifecycle commands (#1761) but drops the global tweetPhoto from the hasMedia poll check (#1812). These target the failure modes that wreck unattended posting — topic tagging, media detection, title validation — all of which previously produced silently wrong output rather than a clean error.
  • Smaller operational fixes — Daemon status now distinguishes multi-profile state (#1593, closes #1575), WeChat URL normalization strips CJK typographic/smart quotes (#1807), the 12306 train-number regex accepts lowercase letters (#1734), YouTube's Videos tab handles the lockupViewModel fallback (#1733), and PubMed gains workflow presets with richer metadata (#1778). Individually minor, but #1593 and #1807 directly affect automation reliability: a status read that can't tell profiles apart, or a URL that keeps curly quotes, will send your flow down the wrong path.

No breaking changes.
