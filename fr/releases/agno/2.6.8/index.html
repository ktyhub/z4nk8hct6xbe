agno v2.6.8

#Changelog

Nouvelles fonctionnalités :

  • Antigravity : Ajout de la prise en charge propriétaire de l'Antigravity API de Google sous deux formes : AntigravityAgent (un BaseExternalAgent servi via AgentOS avec sessions/streaming/interface utilisateur natives) et AntigravityTools (un Toolkit qui permet à tout agent Agno de déléguer une sous-tâche à un bac à sable Antigravity géré).
  • Agents gérés Gemini : Ajout de la prise en charge de GeminiInteractions pour les agents gérés de Google – Deep Research (recherche autonome avec citations, streaming en arrière-plan avec reconnexion/CV last_event_id) et Antigravity (agent à usage général dans un bac à sable Linux géré). Nouveaux champs agent / agent_config / environment, forçage par agent de background et store et prise en charge de mcp_servers + file_search_store_names sur le chemin de l'agent.
  • Livre de recettes - Étiquetage des données : Ajout de cookbook/data_labeling/ avec 18 flux de travail autonomes couvrant le texte, l'image, l'audio, la vidéo, le document et les primitives d'étiquetage composées (LLM en tant que juge, examen de la qualité).
  • Cookbook - Slack HITL : Ajout d'une démo déterministe du commandant d'incident Slack HITL montrant des pauses structurées via tool_choice="required", l'écho user_input et une terminaison propre via stop_after_tool_call=True.

Améliorations :

  • Path Safety (Security) : Sécurité de chemin centralisée dans un nouveau module agno.utils.path_safety avec safe_join et safe_join_subpath. Renforcement des FileGenerationTools, SlackTools, Toolkit._check_path, agno.skills.utils.is_safe_path et FileTools.check_escape contre les attaques de traversée de chemin, d'échappement de lien symbolique, d'injection de caractères de contrôle, de Windows MagicDot et de normalisation Unicode. Introduction de PathSecurityError (FileGenerationSecurityError conservé comme alias de dépréciation). J'ai remplacé requires-python par >=3.9,<4.
  • Parallel MCP : ParallelMCPBackend envoie désormais User-Agent: agno/<version> à chaque requête afin que Parallel puisse attribuer le trafic à agno.
  • Evals Config : Suppression du champ available_models inutilisé de EvalsDomainConfig ; le AgentOSConfig.available_models de niveau supérieur est désormais la seule source prise en charge pour la liste déroulante de l'interface utilisateur Evals.
  • Chonkie : Mise à jour du code PIN de dépendance Chonkie (suite au #7869).
  • Livre de recettes : Renommé gemini-3-flash-preview en gemini-3.5-flash dans les livres de recettes Gemini Interactions.

Corrections de bugs :

  • Équipes AG-UI : Correction d'une faute de frappe (stream_steps → stream_events) qui obligeait les équipes fonctionnant via AG-UI à abandonner silencieusement tous les événements de streaming intermédiaires (cycle de vie, raisonnement, appels d'outils, délégations de membres) pendant environ 7 mois.
  • Slack Extra : Ajout de aiohttp>=3.7.3,<4 au supplément facultatif slack — AsyncWebClient importe aiohttp au chargement du module, donc pip install agno[slack] était interrompu pour toutes les opérations Slack.
  • Google Drive : apparition de l'indicateur Drive API incompleteSearch de GoogleDriveTools.search_files() afin que les appelants corpora="allDrives" puissent détecter quand Drive n'a pas recherché tous les lecteurs.
  • GeminiInteractions : Ajout d'un champ de relais generation_config pour les contrôles avancés (top_k, presence_penalty, etc.) et correction de la gestion de l'historique — lorsque previous_interaction_id est défini, seul le nouveau tour est envoyé plutôt que de rejouer l'historique complet. Exploite désormais l'état côté serveur.
  • Anthropic Server Tools : Préservation des blocs de contenu server_tool_use et d'exécution de code dans l'historique des messages afin que les flux d'outils serveur multi-tours ne s'interrompent plus d'un tour à l'autre.
  • Durcissement anthropique : Suite à ce qui précède : passage au littéral de type canonique redacted_thinking (le SDK rejette redacted_reasoning_content), accepté les deux orthographes lors de l'événement de démarrage du streaming, ajouté une protection contre la déduplication sur les blocs d'outils serveur aller-retour, rendu les échecs de coercition visibles via log_warning et contraint les éléments de résultat d'outil non bloquants au texte.
  • Erreurs Gemini : Les erreurs Gemini génériques incluent désormais le type d'exception lorsque str(error) est vide ou faible, préservant ainsi le contexte d'erreur sur invoke / invoke_stream / ainvoke / ainvoke_stream.
  • N1N : Ajout du mappage du fournisseur n1n manquant dans get_model() afin que les chemins de chaîne de modèle Agent(model="n1n:...") soient désormais résolus correctement.

agno v2.6.8

Changelog

New Features:

  • Antigravity: Added first-party support for Google's Antigravity API in two shapes — AntigravityAgent (a BaseExternalAgent served through AgentOS with native sessions/streaming/UI) and AntigravityTools (a Toolkit that lets any Agno agent delegate a sub-task to a managed Antigravity sandbox).
  • Gemini Managed Agents: Added GeminiInteractions support for Google's managed agents — Deep Research (autonomous research with citations, background streaming with reconnect/last_event_id resume) and Antigravity (general-purpose agent in a managed Linux sandbox). New agent / agent_config / environment fields, per-agent forcing of background and store, and support for mcp_servers + file_search_store_names on the agent path.
  • Cookbook - Data Labeling: Added cookbook/data_labeling/ with 18 self-contained workflows covering text, image, audio, video, document, and composed (LLM-as-judge, quality review) labeling primitives.
  • Cookbook - Slack HITL: Added a deterministic Slack HITL incident-commander demo showing structured pauses via tool_choice="required", user_input echo, and clean termination via stop_after_tool_call=True.

Improvements:

  • Path Safety (Security): Centralized path-safety into a new agno.utils.path_safety module with safe_join and safe_join_subpath. Hardened FileGenerationTools, SlackTools, Toolkit._check_path, agno.skills.utils.is_safe_path, and FileTools.check_escape against path traversal, symlink escape, control-char injection, Windows MagicDot, and Unicode normalization attacks. Introduced PathSecurityError (FileGenerationSecurityError kept as deprecation alias). Bumped requires-python to >=3.9,<4.
  • Parallel MCP: ParallelMCPBackend now sends User-Agent: agno/<version> on every request so Parallel can attribute traffic to agno.
  • Evals Config: Dropped the unused available_models field from EvalsDomainConfig; the top-level AgentOSConfig.available_models is now the only supported source for the Evals UI dropdown.
  • Chonkie: Updated chonkie dependency pin (follow-up to #7869).
  • Cookbook: Renamed gemini-3-flash-preview to gemini-3.5-flash across the Gemini Interactions cookbooks.

Bug Fixes:

  • AG-UI Teams: Fixed a typo (stream_steps → stream_events) that caused teams running via AG-UI to silently drop all intermediate streaming events (lifecycle, reasoning, tool calls, member delegations) for ~7 months.
  • Slack Extra: Added aiohttp>=3.7.3,<4 to the slack optional extra — AsyncWebClient imports aiohttp at module load, so pip install agno[slack] was broken for all Slack operations.
  • Google Drive: Surfaced the Drive API incompleteSearch flag from GoogleDriveTools.search_files() so corpora="allDrives" callers can detect when Drive did not search every drive.
  • GeminiInteractions: Added a generation_config passthrough field for advanced controls (top_k, presence_penalty, etc.) and fixed history handling — when previous_interaction_id is set, only the new turn is sent rather than replaying the full history. Now actually leverages server-side statefulness.
  • Anthropic Server Tools: Preserved server_tool_use and code-execution content blocks in message history so multi-turn server-tool flows no longer break across turns.
  • Anthropic Hardening: Follow-up to the above — switched to the canonical redacted_thinking type literal (the SDK rejects redacted_reasoning_content), accepted both spellings on the streaming start event, added a dedup guard on round-tripped server tool blocks, made coercion failures visible via log_warning, and coerced non-block tool-result items to text.
  • Gemini Errors: Generic Gemini errors now include the exception type when str(error) is empty or weak, preserving error context across invoke / invoke_stream / ainvoke / ainvoke_stream.
  • N1N: Added the missing n1n provider mapping in get_model() so Agent(model="n1n:...") model-string paths now resolve correctly.
