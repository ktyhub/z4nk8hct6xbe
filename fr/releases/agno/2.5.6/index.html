agno v2.5.6

#Changelog

Nouvelles fonctionnalités :

  • Authentification de l'application GitHub pour les sources de connaissances : ajoute la prise en charge de l'authentification avec GitHub en tant qu'application GitHub (app_id, installation_id, private_key) en plus des jetons d'accès personnels, avec mise en cache des jetons thread-safe et les deux variantes sync/async.
  • Téléchargement de fichiers : Ajout de la prise en charge de image/heic et image/heif aux points de terminaison de téléchargement de fichiers.
  • Approbations : Ajout d'un point de terminaison de statut d'approbation et d'une application continue de l'exécution contrôlée par l'administrateur.
  • Traces : Ajout de la prise en charge DSL du filtrage avancé dans Agent OS

Améliorations :

  • Google Tools : outils Google restructurés dans le sous-package agno.tools.google (from agno.tools.google import GmailTools). Les anciens chemins d'importation fonctionnent toujours avec une compatibilité ascendante.
  • Mode tâche d'équipe :
    • Améliore le streaming TeamMode.tasks pour fournir des données de tâches structurées pour le rendu frontend dans des événements tels que TeamTaskCreated et TeamTaskUpdated
    • Données de tâche structurées dans TaskStateUpdatedEvent : ajout du champ tasks: List[TaskData] contenant les détails complets de la tâche (identifiant, titre, description, statut, responsable, dépendances, résultat) et du champ complétion_summary.

Corrections de bugs :

  • Réponses OpenAI :
    • Correction de la condition de course aux sondages du magasin vectoriel où file_search renvoyait silencieusement des résultats vides en raison d'une éventuelle cohérence dans vector_stores.files.list d'OpenAI. API.
    • Ajout du support input_file à OpenAIResponses
  • Sentence Transformer Reranker : Correction d'une fuite de mémoire VRAM dans SentenceTransformerReranker causée par l'instanciation de CrossEncoder à chaque appel _rerank() au lieu d'être réutilisé.
  • Schéma JSON : Prise en charge étendue des types Literal dans la génération de schéma JSON

agno v2.5.6

Highlights

  • GitHub App authentication for knowledge sources — GitHubConfig now supports app_id, installation_id, and private_key alongside PATs, with thread-safe token caching and sync/async implementations. This is preferable for organization-owned repositories where PAT rotation and permission scoping are operational burdens. (#6831)

  • Google tools have a new canonical import path — migrate to from agno.tools.google import GmailTools; existing imports remain compatible. The same change adds FileTools.search_content and per-tool enable flags, letting integrations expose a smaller, more controlled tool surface. (#6833)

  • Team task events are ready for frontend rendering — TeamMode.tasks now includes structured task data in TeamTaskCreated, TeamTaskUpdated, and TaskStateUpdatedEvent, including IDs, status, assignees, dependencies, results, and completion_summary. UI consumers no longer need to reconstruct task state from free-form stream text. (#6718)

  • OpenAI Responses retrieval is more reliable — vector-store polling now accounts for eventual consistency, fixing cases where file_search silently returned empty results. OpenAIResponses also accepts input_file; document-backed workflows should validate retrieved content rather than treating a successful response as proof of retrieval. (#6806)

  • Agent OS tightens run-control semantics — the new approval-status endpoint and admin-gated continuation mean automation must account for administrator authorization when resuming pending runs. Separately, disabled features now return HTTP 503 instead of 404, so feature-detection and error-handling logic should distinguish “unavailable” from “not found.” (#6598, #6837)

  • More stable reranking and structured outputs — SentenceTransformerReranker now reuses its CrossEncoder rather than recreating it per call, eliminating cumulative VRAM growth in long-running services. JSON Schema generation also supports Literal, reducing the need for hand-written workarounds in constrained output schemas. (#6638, #6723)

No breaking changes.

Changelog

New Features:

  • GitHub App Authentication for Knowledge Sources: Adds support for authenticating with GitHub as a GitHub App (app_id, installation_id, private_key) in addition to personal access tokens, with thread-safe token caching and both sync/async variants.
  • File Upload: Added image/heic and image/heif support to file upload endpoints.
  • Approvals: Added approval status endpoint and admin-gated continue run enforcement.
  • Traces: Added advanced filtering DSL support in Agent OS

Improvements:

  • Google Tools: Restructured Google tools into agno.tools.google sub-package (from agno.tools.google import GmailTools). Old import paths still work with a backwards compatibility.
  • Team Task Mode:
    • Enhances TeamMode.tasks streaming to provide structured task data for frontend rendering in events like TeamTaskCreated and TeamTaskUpdated
    • Structured task data in TaskStateUpdatedEvent: Added tasks: List[TaskData] field containing full task details (id, title, description, status, assignee, dependencies, result) and completion_summary field

Bug Fixes:

  • OpenAI Responses:
    • Fixed vector store polling race condition where file_search silently returned empty results due to eventual consistency in OpenAI's vector_stores.files.list API.
    • Added input_file support to OpenAIResponses
  • Sentence Transformer Reranker: Fixed VRAM memory leak in SentenceTransformerReranker caused by CrossEncoder being instantiated on every _rerank() call instead of being reused.
  • JSON Schema: Extended support for Literal types in JSON schema generation
