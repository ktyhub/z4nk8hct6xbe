agno v2.7.3

#Changelog

Nouvelles fonctionnalités :

  • Valclé :
    • Ajout de ValkeyDb en tant que base de données en mémoire rapide pour les agents, les équipes et les flux de travail. Voir Documents
    • Ajout d'un magasin de vecteurs ValkeyDB avec recherche de vecteurs et de mots clés. Voir Documents
  • Outils Redmine : Ajout de RedmineTools pour gérer les problèmes, les commentaires et les journaux de temps dans Redmine, un outil de gestion de projet open source.
  • TokenLab : ajout de TokenLab en tant que nouveau fournisseur de modèles compatible OpenAI.

Améliorations :

  • Contexte de session : ignorez un appel de modèle redondant lors de l'enregistrement du contexte de session.
  • AG-UI : confirmation, saisie et retour humains étendus vers AG-UI.
  • Mémoire et profil utilisateur : mémoire plus fiable et extraction de profil des conversations.
  • Outils MCP :
    • Faites apparaître une erreur propre lorsqu'un serveur MCP devient inaccessible.
    • Outils de support qui répondent uniquement avec structuredContent.

Corrections de bugs :

  • DoclingReader : Accepte les chaînes de chemin de fichier local.
  • JSONReader : honorez chunk=False lors de la lecture de documents JSON.
  • Lecteur PDF :
    • Correction d'une interprétation incorrecte du numéro de page pour les fichiers PDF d'une seule page.
    • Essayez automatiquement un mot de passe vide pour les PDF cryptés.
  • Sorties structurées : analysez de manière fiable les réponses dont les valeurs de champ contiennent des accolades.
  • Outils de fichiers et de codage : conservez la recherche et la liste dans la racine configurée.
  • Antigravity : empêche les fichiers liés par un lien symbolique de quitter le répertoire de l'agent.
  • Cassandra : dérivez la dimension vectorielle de l'intégrateur configuré.
  • Mistral : ajoutez frequency_penalty, presence_penalty et stop, et conservez les paramètres de valeur nulle comme temperature=0.
  • YouTools : corrigez les échecs de recherche et ajoutez des filtres de région, de langue et de fraîcheur.
  • Mesures de workflow : incluez des métriques sur WorkflowCompletedEvent.
  • Timer : Correction de Timer.elapsed pour des opérations très rapides.

agno v2.7.3

Changelog

New Features:

  • Valkey:
    • Added ValkeyDb as a fast in-memory database for agents, teams, and workflows. See Docs
    • Added a ValkeyDB vector store with vector and keyword search. See Docs
  • Redmine Tools: Added RedmineTools to manage issues, comments, and time logs in Redmine, an open source project management tool.
  • TokenLab: Added TokenLab as a new OpenAI-compatible model provider.

Improvements:

  • Session Context: Skip a redundant model call when saving session context.
  • AG-UI: Extended human-in-the-loop confirmation, input, and feedback to AG-UI.
  • User Memory & Profile: More reliable memory and profile extraction from conversations.
  • MCP Tools:
    • Surface a clean error when an MCP server becomes unreachable.
    • Support tools that respond with only structuredContent.

Bug Fixes:

  • DoclingReader: Accept local file-path strings.
  • JSONReader: Honor chunk=False when reading JSON documents.
  • PDFReader:
    • Fix incorrect page number interpretation for single page pdf’s.
    • Auto-try a blank password for encrypted PDFs.
  • Structured Outputs: Reliably parse responses whose field values contain braces.
  • File & Coding Tools: Keep search and listing contained to the configured root.
  • Antigravity: Prevent symlinked files from escaping the agent directory.
  • Cassandra: Derive the vector dimension from the configured embedder.
  • Mistral: Add frequency_penalty, presence_penalty, and stop, and keep zero-valued params like temperature=0.
  • YouTools: Fix failing searches and add region, language, and freshness filters.
  • Workflow Metrics: Include metrics on WorkflowCompletedEvent.
  • Timer: Fix Timer.elapsed for very fast operations.
