agno v2.5.3

#Changelog

Nouvelles fonctionnalités :

  • Connaissance à distance : Ajout de points de terminaison pour prendre en charge la liste des contenus distants via API. Permet le téléchargement de contenu dans les compartiments S3 via AgentOS

Améliorations :

  • Lecteur PDF : Ajout du paramètre sanitize_content à BasePDFReader (activé par défaut) qui normalise l'extraction de texte PDF fragmenté – réduction des artefacts mot par ligne tout en préservant les sauts de paragraphe. Désactivez-le avec sanitize_content=False pour les PDF contenant du contenu structuré comme du code ou des tableaux.
  • PDF Reader : Ajout d'un paramètre sanitize_content à BasePDFReader qui normalise le texte PDF extrait en réduisant les séquences d'espaces excessives en espaces simples.

Corrections de bugs :

  • Knowledge Retriever : Correction du problème où knowledge_retriever était ignoré lorsque search_knowledge=True était activé.
  • Claude : Correction du double comptage des métriques de streaming input_tokens pour les modèles Anthropic
  • Recherche de connaissances : Correction des modèles d'inclusion/exclusion par rapport au nom de fichier pour l'analyse du répertoire
  • Raisonnement : correction de la duplication de reasoning_content entre les étapes de raisonnement.
  • Deepcopy sur Agent/Team/Workflow : correction de l'échec de deep_copy pour les équipes imbriquées en raison de champs de classe de données non init.
  • HITL : correction des gestionnaires de pause HITL supprimant silencieusement les modifications session_state dans les modules agent et team .
  • Workflow Parallel Steps : correction de la condition de concurrence critique sur run_context.output_schema en exécution parallèle.

agno v2.5.3

Changelog

New Features:

  • Remote Knowledge: Added endpoints to support listing of remote contents via API. Enables uploading of content in S3 buckets via AgentOS

Improvements:

  • PDF Reader: Added sanitize_content parameter to BasePDFReader (enabled by default) that normalizes fragmented PDF text extraction — collapsing word-per-line artifacts while preserving paragraph breaks. Disable with sanitize_content=False for PDFs containing structured content like code or tables.
  • PDF Reader: Added a sanitize_content parameter to BasePDFReader that normalizes extracted PDF text by collapsing excessive whitespace sequences into single spaces.

Bug Fixes:

  • Knowledge Retriever: Fix issue whereknowledge_retriever ignored when search_knowledge=True enabled.
  • Claude: Fixed streaming metrics double-count input_tokens for Anthropic models
  • Knowledge Search: Fixed match include/exclude patterns against filename for directory scanning
  • Reasoning: fixed reasoning_content duplication across reasoning steps.
  • Deepcopy on Agent/Team/Workflow: fixed deep_copy fails for nested teams due to non-init dataclass fields.
  • HITL: fixed HITL pause handlers silently dropping session_state changes in both agent and team modules.
  • Workflow Parallel Steps: fixed race condition on run_context.output_schema in Parallel execution.
