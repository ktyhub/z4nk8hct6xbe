#agno v3.2.1 #Changelog

Nouvelles fonctionnalités :

  • Compactages de session : GET /sessions/{session_id}/compactions répertorie les compactages d'une session sur SqliteDb et PostgresDb, le plus récent en premier, avec le nombre de messages chacun remplacé et le nombre de jetons avant et après.
  • Fichiers d'entreprise : les fichiers d'une tâche et les notes partagées peuvent désormais être lus sur le API avec GET /company/tasks/{task_id}/files et GET /company/notes, chacun avec une route /{path} pour lire un fichier. Voir livre de recettes.

Améliorations :

  • LinearTools, DiscordTools et ModelsLabTools : prenez maintenant un timeout (30 secondes par défaut, 120 pour ModelsLab) qui s'applique à chaque requête.
  • ExaTools : prend désormais include_text, exclude_text, user_location, moderation, highlights et subpages.
  • MCPTools : connect() renvoie désormais True lorsqu'il est connecté et False lorsqu'il ne l'est pas.
  • Qdrant : async_insert prend désormais batch_size, comme insert.
  • WebSearchTools et DuckDuckGoTools : les erreurs de recherche reviennent désormais sous la forme d'un résultat JSON.
  • Compétences : les instructions de compétences, les références et les sorties de script en chinois et dans d'autres langues non-ASCII atteignent désormais le modèle sous forme de caractères lisibles.
  • AntigravityTools et AntigravityAgent : désormais par défaut antigravity-preview-09-2026.
  • Slack : default_role donne aux membres Slack qui ne font pas partie de users= les autorisations d'un rôle géré. Chaque membre est toujours enregistré comme lui-même.

Corrections de bugs :

  • SQLTools : Un db_engine que vous transmettez est désormais toujours utilisé, même lorsque les champs de connexion sont également fournis, et run_sql_query renvoie désormais l'erreur de la base de données lors de l'échec de la lecture des lignes de résultat.
  • OpenRouter, Perplexity et Requesty : Les réponses utilisent désormais la propre limite de sortie du modèle lorsque max_tokens n'est pas défini, donc les réponses longues reviennent complètes.
  • OpenRouterResponses : les métriques d'exécution et de message incluent désormais le cost signalé par OpenRouter pour chaque requête.
  • Traces : GET /traces compte désormais les pages à partir de 1, comme les autres itinéraires de trace, et JsonDb et GcsJsonDb appliquent limit lorsqu'aucun page n'est donné.
  • WebSearchTools et DuckDuckGoTools : max_results=0 ne renvoie désormais aucun résultat et search_news applique le modifier.
  • ExaTools : livecrawl atteint désormais Exa, et les résumés et faits saillants d'Exa atteignent désormais le modèle.
  • PostgresDb : si la création d'une table échoue sur PostgresDb ou AsyncPostgresDb, la même instance de base de données la crée désormais lors du prochain appel une fois la cause corrigée.
  • MCPTools : Un connect() en échec ou annulé ferme désormais la connexion et tout serveur stdio qu'il a démarré.
  • Qdrant : insert(batch_size=...) envoie désormais des documents par lots de cette taille.
  • CodexAgent : les demandes d'autorisation et les questions natives fonctionnent désormais avec openai-codex 0.163.0 et versions ultérieures.
  • DaytonaTools : agno[daytona] installe désormais un Daytona SDK pris en charge par DaytonaTools (daytona<1), et l'erreur d'importation nomme cette version.
  • Mistral : agno[mistral] ignore désormais httpx2 2.16.1, donc MistralChat et MistralEmbedder importent proprement.
  • FileTools et Workspace : read_file renvoie désormais un fichier entier contenant exactement les lignes max_file_lines.
  • PageMarkdownChunking : les titres qui se terminent par un # littéral, comme C#, le conservent désormais dans le fil d'Ariane et dans la ligne de contexte de la page.
  • DocxReader et PPTXReader : les fichiers Word et PowerPoint lus à partir d'un flux temporaire, comme le UploadFile.file de FastAPI, renvoient désormais leur contenu.
  • ModelsLabTools : L'attente des médias générés s'arrête désormais à max_wait_time.
  • Sambanova : La valeur par défaut est désormais Meta-Llama-3.3-70B-Instruct, donc cela fonctionne sans définir id.
  • Slack : Super Agent démarre désormais sous AgentOS(authorization=...) sans users= ; les membres qui ne font pas partie de users= peuvent discuter et les actions nécessitant une autorisation sont refusées à moins que default_role ne l'accorde.

agno v3.2.1

Highlights

  • Session-compaction visibility — GET /sessions/{session_id}/compactions exposes compaction history for SqliteDb and PostgresDb, including replaced-message counts and token usage before and after. This gives operators concrete data for auditing context reduction and investigating unexpectedly shortened sessions (#11617).

  • Company files over the API — Task files and shared notes are now accessible through GET /company/tasks/{task_id}/files and GET /company/notes, with individual /{path} routes. Clients can retrieve company artifacts without requiring direct storage access (#11612).

  • Routed providers stop silently truncating output — OpenRouter, Perplexity, and Requesty now inherit the model’s output limit when max_tokens is unset instead of applying an implicit cap. Expect longer responses by default, and set explicit limits where cost or latency matters (#10723).

  • Slack authorization becomes role-aware — Super Agent can start under AgentOS(authorization=...) without users=. Unlisted members can chat while retaining their own identity; permission-gated actions require the permissions granted by default_role. Review role assignments before broadening Slack access (#11713).

  • Connection lifecycle is easier to control — MCPTools.connect() now returns a boolean result and cleans up connections and spawned stdio servers after failures or cancellation. Linear, Discord, and ModelsLab tools also accept request-wide timeouts—30 seconds by default, 120 seconds for ModelsLab (#11135, #11459).

  • Database failures are less silent — SQLTools now honors an explicitly supplied db_engine over connection fields and surfaces row-fetch errors instead of returning an empty result. Qdrant insertions correctly honor batch_size, while PostgreSQL table creation can recover on the same instance after a failed attempt is fixed (#11500, #11680, #11722, #11723).

No breaking changes.

Changelog

New Features:

  • Session Compactions: GET /sessions/{session_id}/compactions lists a session's compactions on SqliteDb and PostgresDb, newest first, with how many messages each replaced and the token count before and after.
  • Company Files: A Task's files and the shared notes can now be read over the API with GET /company/tasks/{task_id}/files and GET /company/notes, each with a /{path} route to read one file. See cookbook.

Improvements:

  • LinearTools, DiscordTools and ModelsLabTools: Now take a timeout (default 30 seconds, 120 for ModelsLab) that applies to every request.
  • ExaTools: Now takes include_text, exclude_text, user_location, moderation, highlights and subpages.
  • MCPTools: connect() now returns True when connected and False when not.
  • Qdrant: async_insert now takes batch_size, like insert.
  • WebSearchTools and DuckDuckGoTools: Search errors now come back as a JSON result.
  • Skills: Skill instructions, references and script output in Chinese and other non-ASCII languages now reach the model as readable characters.
  • AntigravityTools and AntigravityAgent: Now default to antigravity-preview-09-2026.
  • Slack: default_role gives Slack members not in users= the permissions of a managed role. Each member is still recorded as themselves.

Bug Fixes:

  • SQLTools: A db_engine you pass in is now always used, even when connection fields are also given, and run_sql_query now returns the database error when reading the result rows fails.
  • OpenRouter, Perplexity and Requesty: Responses now use the model's own output limit when max_tokens is not set, so long answers come back complete.
  • OpenRouterResponses: Run and message metrics now include the cost that OpenRouter reports for each request.
  • Traces: GET /traces now counts pages from 1, like the other trace routes, and JsonDb and GcsJsonDb apply limit when no page is given.
  • WebSearchTools and DuckDuckGoTools: max_results=0 now returns no results, and search_news applies the modifier.
  • ExaTools: livecrawl now reaches Exa, and Exa's summaries and highlights now reach the model.
  • PostgresDb: If creating a table fails on PostgresDb or AsyncPostgresDb, the same db instance now creates it on the next call once the cause is fixed.
  • MCPTools: A failed or cancelled connect() now closes the connection and any stdio server it started.
  • Qdrant: insert(batch_size=...) now sends documents in batches of that size.
  • CodexAgent: Native permission requests and questions now work with openai-codex 0.163.0 and newer.
  • DaytonaTools: agno[daytona] now installs a Daytona SDK that DaytonaTools supports (daytona<1), and the import error names that version.
  • Mistral: agno[mistral] now skips httpx2 2.16.1, so MistralChat and MistralEmbedder import cleanly.
  • FileTools and Workspace: read_file now returns a whole file that has exactly max_file_lines lines.
  • PageMarkdownChunking: Headings that end in a literal #, such as C#, now keep it in chunk breadcrumbs and in the page context line.
  • DocxReader and PPTXReader: Word and PowerPoint files read from a temporary stream, such as FastAPI's UploadFile.file, now return their content.
  • ModelsLabTools: Waiting for generated media now stops at max_wait_time.
  • Sambanova: Now defaults to Meta-Llama-3.3-70B-Instruct, so it works without setting id.
  • Slack: Super Agent now starts under AgentOS(authorization=...) without users=; members not in users= can chat, and actions that need a permission are refused unless default_role grants it.
