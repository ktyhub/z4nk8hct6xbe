agno v3.0.10

#Changelog

Nouvelles fonctionnalités :

  • Azure OpenAI Responses : ajout de AzureOpenAIResponses pour utiliser les réponses API avec les déploiements Azure OpenAI. Voir livre de recettes.
  • Elasticsearch : Ajout de la base de données vectorielles Elasticsearch avec recherche vectorielle, par mot-clé et hybride. Voir livre de recettes.
  • DocumentationMarkdown : Ajout d'un transform pour Knowledge.sync_pages qui convertit les composants Mintlify et Fumadocs en Markdown simple. Voir livre de recettes.

Améliorations :

  • MCPConfig : ajout de root_host, path et path_aliases pour servir MCP sur un nom d'hôte dédié ou un chemin de point de terminaison personnalisé.
  • Carte serveur MCP : /mcp/server-card renvoie désormais un JSON joliment imprimé.

Corrections de bugs :

  • Outils MCP : préservez AudioContent des résultats de l'outil MCP en tant qu'artefacts audio.
  • Slack : tentatives de déduplication d'événements par event_id au lieu de les supprimer.
  • Agents distants : RemoteAgent.role et RemoteTeam.role sont désormais des propriétés qui renvoient le rôle au lieu d'une méthode liée ; utilisez .role, pas .role().
  • Lecteurs : TextReader, MarkdownReader et FieldLabeledCSVReader acceptent désormais les flux de texte.
  • PPTXReader : lit le texte à l'intérieur de formes groupées.
  • JSONReader : async_read() utilise désormais le achunk() asynchrone de la stratégie de segmentation.
  • Chunking : conservez les nouvelles lignes et les tabulations lors du nettoyage du texte avant le segmentage.
  • CSVReader : async_read() conserve chaque ligne de données sur les pages avec RowChunking(skip_header=True).
  • SitemapReader : conservez intacts les noms de fichiers tels que myindex.html et poursuivez la découverte au-delà d'un plan de site .xml.gz non valide.
  • Outils et flux de travail : conservez les valeurs fausses telles que 0, False et [] dans les résultats de l'outil de synchronisation et les sorties des étapes du flux de travail Parallel.
  • agnoctl : agno connect lit et écrit désormais les configurations client au format UTF-8 (agnoctl 0.2.1).
  • DynamoDB : sérialisez les booléens en tant que valeurs natives BOOL.

Dernières modifications :

  • CodingTools : run_shell est désormais opt-in (enable_run_shell=True) et le mode restreint exécute les commandes sans shell.
  • PublicSurface : Avec authorization=True et PublicSurface(mcp=True), MCP n'accepte désormais que localhost par défaut ; ajoutez votre domaine à MCPConfig(allowed_hosts=[...]).

agno v3.0.10

Highlights

  • CodingTools run_shell is now opt-in (breaking) — Shell execution requires enable_run_shell=True, and restricted mode now runs commands without a shell entirely. This is deliberate RCE/operator-injection hardening (#10210, #10220), but any agent that previously depended on shell-based tools will silently lose that capability — audit your tool configs and pass the flag explicitly before upgrading.
  • Public MCP is localhost-only by default (breaking) — With authorization=True and PublicSurface(mcp=True), MCP now accepts only localhost connections; you must add your domain via MCPConfig(allowed_hosts=[...]) or legitimate remote clients will be rejected. This lands alongside the public-MCP/JWT REST auth detection fix (#10083), so watch it if you expose MCP behind a reverse proxy.
  • RemoteAgent.role / RemoteTeam.role are now properties (behavioral) — They return the role value directly instead of a bound method; call sites using .role() will now fail at runtime and must switch to .role (#10172). A small diff, but an easy one to miss until something breaks at execution time.
  • New backends: Azure OpenAI Responses and Elasticsearch — AzureOpenAIResponses brings the Responses API to Azure OpenAI deployments (#9841), and the new Elasticsearch vector DB supports vector, keyword, and hybrid search (#10018). Relevant if you're standardizing on Azure or need hybrid retrieval out of the box.
  • MCP routing and multimodal artifacts — MCPConfig gains root_host, path, and path_aliases for dedicated hostnames and custom endpoints (#10090); /mcp/server-card now returns pretty-printed JSON (#10084); and AudioContent from MCP tool results is preserved as audio artifacts (#10036). Together these make self-hosted MCP more deployable and keep multimodal tool output intact.
  • Falsy values and ingestion reliability — 0, False, and [] are now retained in sync tool results and Parallel workflow step outputs (#9948, #10208), so downstream logic sees real values instead of dropped ones. Readers accept text streams, JSONReader.async_read() honors the chunking strategy's achunk(), PPTXReader reads grouped shapes, CSV rows survive skip_header=True across pages, and sitemap discovery continues past invalid .xml.gz files.

Changelog

New Features:

  • Azure OpenAI Responses: Added AzureOpenAIResponses to use the Responses API with Azure OpenAI deployments. See cookbook.
  • Elasticsearch: Added Elasticsearch vector database with vector, keyword and hybrid search. See cookbook.
  • DocumentationMarkdown: Added a transform for Knowledge.sync_pages that converts Mintlify and Fumadocs components into plain Markdown. See cookbook.

Improvements:

  • MCPConfig: Added root_host, path and path_aliases to serve MCP on a dedicated hostname or a custom endpoint path.
  • MCP Server Card: /mcp/server-card now returns pretty-printed JSON.

Bug Fixes:

  • MCP Tools: Preserve AudioContent from MCP tool results as audio artifacts.
  • Slack: Deduplicate event retries by event_id instead of dropping them.
  • Remote Agents: RemoteAgent.role and RemoteTeam.role are now properties that return the role instead of a bound method; use .role, not .role().
  • Readers: TextReader, MarkdownReader and FieldLabeledCSVReader now accept text streams.
  • PPTXReader: Read text inside grouped shapes.
  • JSONReader: async_read() now uses the chunking strategy's async achunk().
  • Chunking: Preserve newlines and tabs when cleaning text before chunking.
  • CSVReader: async_read() keeps every data row across pages with RowChunking(skip_header=True).
  • SitemapReader: Keep filenames like myindex.html intact and continue discovery past an invalid .xml.gz sitemap.
  • Tools & Workflows: Keep falsy values like 0, False and [] in sync tool results and Parallel workflow step outputs.
  • agnoctl: agno connect now reads and writes client configs as UTF-8 (agnoctl 0.2.1).
  • DynamoDB: Serialize booleans as native BOOL values.

Breaking Changes:

  • CodingTools: run_shell is now opt-in (enable_run_shell=True), and restricted mode runs commands without a shell.
  • PublicSurface: With authorization=True and PublicSurface(mcp=True), MCP now accepts only localhost by default; add your domain to MCPConfig(allowed_hosts=[...]).
