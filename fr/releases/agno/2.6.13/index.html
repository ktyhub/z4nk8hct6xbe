agno v2.6.13

Highlights

  • Nested-agent observability — Sub-agent events from the context provider update tool now reach the parent run (#8348), allowing event consumers to observe nested execution instead of treating it as a black box.
  • Simpler AgentOS onboarding — The registry automatically discovers agents, teams, and workflows (#8269), reducing manual registration. The new Slack app manifest (#8327) also provides a reference configuration for connecting the AgentOS interface to Slack.
  • Socket-based human-in-the-loop workflows — Workflow HITL now supports sockets (#7749), giving approval and resume flows another transport option for socket-connected, event-driven clients.
  • More reliable document identity — Content hashes now include metadata (#8310), so upsert=False inserts of documents with identical text but different metadata no longer collapse. Review ingestion logic if you previously relied on text-only deduplication.
  • Tool-call and execution robustness — Schema generation now accepts Optional dataclass fields without declared types (#8329), while tool arguments retain whitespace (#8131), avoiding subtle mutation of string values. Refreshed MCPTools sessions are closed correctly (#8230), failed MultiMCP connections are cleaned up (#8163), and quoted Daytona shell paths reduce path-parsing failures (#8289).
  • Compatibility — No breaking changes are listed.

Changelog

New Features:

  • Sub-Agent Event Streaming: Sub-agent events from the context provider update tool now stream through to the parent run.
  • AgentOS Registry Auto-Population: The AgentOS registry now auto-populates from agents, teams, and workflows.
  • Workflows HITL over Sockets: Added socket support for human-in-the-loop workflows.
  • Slack App Manifest: Added a Slack app manifest for the AgentOS interface.

Bug Fixes:

  • JSON Schema: json_schema now handles Optional dataclass fields that have no declared type.
  • MCPTools Sessions: Refreshed MCPTools sessions are now closed in the call task.
  • Tool Arguments: Preserve whitespace in tool arguments.
  • Content Hashing: Metadata is now included in the content hash so upsert=False inserts of the same document no longer collapse.
  • MultiMCP: Clean up MultiMCP connection failures.
  • DaytonaTools: Quote shell paths in DaytonaTools.
