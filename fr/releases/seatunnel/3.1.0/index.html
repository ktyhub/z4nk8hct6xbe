##3.1.0Release Note

Il s'agit d'une autre version importante pour Apache SeaTunnel après la version 3.0.0 !

La version 3.1.0 comprend 395 PR et 11 nouveaux connecteurs, en mettant l'accent sur la stabilité du moteur Zeta et l'exactitude des données du connecteur V2. Il améliore également le déploiement, les opérations et la transformation des données pour rendre les tâches d'intégration des données de production plus fiables.

Merci à tous les contributeurs pour leur travail acharné sur cette mise à jour. Nous pensons que la version 3.1.0 apportera à la communauté une expérience d'intégration de données plus stable et plus fiable.

Faits saillants

  • Mode d'application natif du Kubernetes : déployez un maître dédié et un nombre fixe de travailleurs par tâche, avec un nettoyage automatique des ressources une fois la tâche terminée, offrant une isolation des ressources et une libération des ressources à la demande pour les tâches de traitement de données ponctuelles et les équipes exécutant des charges de travail par lots à grande échelle.
  • Version Java minimale augmentée à 11, avec prise en charge jusqu'à Java 17.

3.1.0 Release Note

This is another important release for Apache SeaTunnel following version 3.0.0!

Version 3.1.0 includes 395 PRs and 11 new connectors, with a focus on Zeta engine stability and Connector-V2 data correctness. It also improves deployment, operations, and data transformation to make production data integration jobs more reliable.

Thank you to all contributors for their hard work on this update. We believe version 3.1.0 will bring the community a more stable and reliable data integration experience.

Highlights

  • Native Kubernetes Application Mode: Deploy a dedicated Master and a fixed number of Workers per job, with automatic resource cleanup when the job finishes, providing resource isolation and on-demand resource release for one-off data processing jobs and teams running large-scale batch workloads.
  • Minimum Java version raised to 11, with support up to Java 17.
