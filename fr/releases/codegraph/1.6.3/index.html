codegraphe v1.6.3

[1.6.3] - 2026-11-17

Faits saillants

  • Neuf agents et éditeurs supplémentaires. codegraph install installe désormais IBM Bob, Factory Droid, Windsurf, Qwen Code, DeepSeek Harness, Grok Build, Kimi Code, le Qoder CLI et Pi.
  • Corrections de sécurité. Un dossier sensible tel que ~/.ssh ne peut plus être ouvert en tant que projet via un lien, une jonction ou une autre orthographe de son chemin, et le Node.js fourni est déplacé vers 24.22.1, qui corrige CVE-2026-111497.
  • Liens plus précis dans toutes les langues. Des centaines de correctifs aident les appels, les importations et les types à atteindre le code qu'ils signifient, surtout dans JavaScript et TypeScript, Go, C et C++, Rust, Python, C#, Java et Dart. Tauri, CodeIgniter 3, les services et plugins Drupal, le middleware Next.js et les gestionnaires MediatR sont désormais également couverts.
  • De meilleures réponses pour votre agent. codegraph_explore ne se bloque plus sur un grand projet, répond à un journal ou à un fichier collé en quelques secondes, trouve le code nommé en chinois, japonais ou coréen et son flux atteint chaque symbole nommé par votre requête.
  • Nouvelles commandes. codegraph cycles trouve les fichiers qui s'importent les uns les autres dans un cercle, codegraph implementations répertorie ce qui implémente un type, codegraph files --format package divise un monorepo par package et codegraph init --local-only garde .codegraph/ hors de git.
  • Un serveur d'arrière-plan plus stable. Une nouvelle session n'attend plus quelques minutes lorsque le serveur d'arrière-plan est bloqué, la mise à niveau pendant une session le fait passer à la nouvelle version, et codegraph sync et l'observateur de fichiers conservent les liens au fur et à mesure que les fichiers sont ajoutés, supprimés et restaurés.
  • Plus rapide et plus léger. Les commandes qui lisent uniquement l'index démarrent plus rapidement et l'indexation consomme moins de CPU et de mémoire, surtout sur les petits projets et en C et C++.
  • Mise à niveau : réindexez vos projets après cette version avec codegraph index. La plupart de ces correctifs sont écrits lors de l'indexation, et codegraph status et votre agent vous indiquent tous deux quand un index a été créé par une ancienne version.

Sécurité

  • Un dossier sensible comme ~/.ssh, /etc ou C:\Windows ne peut plus être utilisé comme projet via un lien ou une jonction, un nom différemment capitalisé, un chemin \\?\ ou un chemin vers un dossier manquant à l'intérieur de celui-ci. Avant, n'importe lequel d'entre eux permettait à la requête d'un agent de lire les fichiers qu'il contient. Merci @mixxer. (#2929)
  • Le serveur MCP n'utilise plus de dossier sensible tel que ~/.ssh ou /etc comme projet par défaut d'une session, qu'il provienne de l'espace de travail de l'agent, du dossier dans lequel il a démarré ou de --path. Avant, une session démarrait dans une session contenant un index répondu à partir des fichiers qu'il contenait. (#3012)
  • Le runtime Node.js fourni passe à 24.22.1, la version de sécurité d'octobre de Node, qui corrige CVE-2026-111497, une écriture hors limites de haute gravité dans son décodeur Brotli, et chaque version vérifie désormais le nœud qu'il regroupe par rapport aux sommes de contrôle publiées par nodejs.org. Il corrige également un crash de Windows lorsqu'une commande telle que codegraph sync se termine une fois son travail terminé. Merci @Ancienttwo et @IdealBoy709. (#2617, #2780)

Correctifs

Fenêtres

  • Sous Windows, la suppression du dossier vers lequel pointe un lien dans votre projet, comme une jonction vers une bibliothèque extérieure, n'oblige plus le serveur de CodeGraph à utiliser un cœur de processeur complet ou à arrêter de récupérer vos modifications. Merci @L0garithmic.
  • Sous Windows, un projet à la racine d'un lecteur, comme un lecteur réseau mappé tel que Z:\, un lecteur subst ou la racine d'un partage réseau, indexe désormais au lieu de refuser chaque fichier comme "Parcours de chemin bloqué". Merci @Kamilslaoui93.
  • Sous Windows, un dossier temporaire sur un lecteur qui n'existe pas, comme un disque débranché ou un lecteur RAM non monté, ne bloque plus chaque commande codegraph au démarrage.
  • Sous Windows, un arbre de travail git à l'intérieur de votre caisse principale, comme celui sous .claude/worktrees/, est maintenant reconnu quelle que soit la manière dont son chemin est écrit, comme avec la lettre de lecteur minuscule VS Code et le passage du curseur. Merci @nk33-dev.
  • L'installateur Windows, irm …/install.ps1 | iex, ne s'arrête plus avec "(403) Forbidden" une fois la limite de requêtes anonymes de GitHub épuisée, et une version définie sans son v, comme CODEGRAPH_VERSION=1.6.2, s'installe désormais. Merci @hiyochi.
  • Dans les fichiers JavaScript et TypeScript avec fin de ligne Windows (CRLF), une boutique exportée sur une ligne ultérieure, comme export default useStore;, voit désormais ses actions indexées, comme pour les fins de ligne Unix.
  • Sous Windows, un appel Swift écrit après try!, comme try! Settings.Defaults.load(), renvoie désormais à ce qu'il appelle, comme c'était déjà le cas sur macOS et Linux.

  • Dans Rust, une méthode appelée via une chaîne de champs, comme self.inner.config.port(), ou sur un littéral de structure est désormais liée à la méthode du type du dernier champ ou du littéral. Merci @Egrn et @danusha2345. (#2614)

Highlights

  • Nine more agents and editors. codegraph install now sets up IBM Bob, Factory Droid, Windsurf, Qwen Code, DeepSeek Harness, Grok Build, Kimi Code, the Qoder CLI and Pi.
  • Security fixes. A sensitive folder such as ~/.ssh can no longer be opened as a project through a link, a junction or another spelling of its path, and the bundled Node.js moves to 24.22.1, which fixes CVE-2026-111497.
  • More accurate links in every language. Hundreds of fixes help calls, imports and types reach the code they mean, most of all in JavaScript and TypeScript, Go, C and C++, Rust, Python, C#, Java and Dart. Tauri, CodeIgniter 3, Drupal services and plugins, Next.js middleware and MediatR handlers are now covered too.
  • Better answers for your agent. codegraph_explore no longer stalls on a large project, answers a pasted log or file in seconds, finds code named in Chinese, Japanese or Korean, and its Flow reaches every symbol your query names.
  • New commands. codegraph cycles finds files that import each other in a circle, codegraph implementations lists what implements a type, codegraph files --format package splits a monorepo by package, and codegraph init --local-only keeps .codegraph/ out of git.
  • A steadier background server. A new session no longer waits minutes when the background server is stuck, upgrading during a session switches it to the new version, and codegraph sync and the file watcher keep links right as files are added, deleted and restored.
  • Faster and lighter. Commands that only read the index start faster, and indexing takes less CPU and memory, most of all on small projects and on C and C++.
  • Upgrading: re-index your projects after this release with codegraph index. Most of these fixes are written while indexing, and codegraph status and your agent both tell you when an index was built by an older version.

Security

  • A sensitive folder like ~/.ssh, /etc or C:\Windows can no longer be used as a project through a link or junction, a differently capitalized name, a \\?\ path or a path to a missing folder inside one. Before, any of these let an agent's query read the files inside. Thanks @mixxer. (#2929)
