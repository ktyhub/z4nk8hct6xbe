Fonctionnalités

  • compression : décrivez quelle compression CCR a chuté, pas seulement de combien (#3635) (62d1cc0)
  • hooks : ajoutez Protect_messages, un veto strict sur la compression par message (#3772) (d17ac6a)
  • opencode : exclure les hôtes du routage du plug-in de transport (#3668) (0024b57)
  • proxy : laissez /transformations/feed omettre les corps des messages pour les interrogeurs utilisant uniquement des numéros (#3672) (46ac52d)
  • économies : comportent le coût exact de lecture du cache dans les cumuls d'historique (#3734) (1cb779e)
  • économies : affiche la base d'économies des nouveaux intrants à côté du chiffre du fil entier (#3485) (e92cccc)

  • sdk : prend en charge le remplacement de la configuration par appel dans compress() (#3370) (c3e8a1e)
  • wrap : prend en charge le contexte 1 min dans vscode claude (#3361) (fc5a09e)

headroom v0.39.0

0.39.0 (2026-09-25)

Features

  • compression: describe what CCR compression dropped, not just how much (#3635) (62d1cc0)
  • hooks: add protect_messages, a hard per-message compression veto (#3772) (d17ac6a)
  • opencode: exclude hosts from transport plugin routing (#3668) (0024b57)
  • proxy: let /transformations/feed omit message bodies for number-only pollers (#3672) (46ac52d)
  • savings: carry exact cache-read cost in history rollups (#3734) (1cb779e)
  • savings: show the new-input savings basis beside the whole-wire figure (#3485) (e92cccc)
  • savings: track lifetime output spend so a bill-share rate has a denominator (#3520) (c766bdb)
  • sdk: support per-call config override in compress() (#3370) (c3e8a1e)
  • wrap: support 1m context in vscode claude (#3361) (fc5a09e)

Bug Fixes

  • anthropic: reject ping-only SSE from buffered CCR (#3682) (000fefc)
  • anthropic: stop the spurious compaction warning and drop dead handler code (#3678) (6e71267)
  • backends/litellm: stop dropping image blocks from /v1/messages requests (#3753) (577336d)
  • binaries: fail closed when a download carries no sha256 pin (#3724) (26a2c49)
  • cache/google: tolerate timezone-aware cache expiry timestamps (#3210) (7ce2580)
  • cache: default CCR payload previews off; harden the log when they are on (#3728) (5cb87bc)
  • cache: never batch-compress already-forwarded small Responses outputs in cache mode (#3756) (ab62b9e)
  • cache: preserve cache_control schema properties (#3348) (b84c4c9)
  • cache: preserve the forwarded OpenAI chat prefix across turns (#3757) (deca575)
  • cache: stop prefix transforms from busting the provider cache (#3735) (a2bf5ed)
  • cache: stop skipping tool compaction on a pinned tools array (#3750) (a6a9cef)
  • cli: keep non-ASCII working directory names out of the init profile slug (#3718) (f3d95ee)
  • cli: report anonymous beacon status accurately in the banner, log, and /stats (#3533) (fa9edb3)
  • content_detector: detect CMTrace (SCCM/Intune) logs as BUILD_OUTPUT (#3712) (6feb1fb)
  • dashboard: separate rolling cache economics by owner (#3319) (a29162b), closes #960
  • docker: support OpenCode in native wrapper (#3547) (d90dadf)
  • fall back for non-admin Windows task installs (#3437) (b958509)
  • graph: fetch and extract the zip codebase-memory-mcp asset on Windows (#3730) (b776983)
  • grok: preserve xAI model context metadata (#3312) (#3315) (c81378c)
  • init: raise the ensure hook's timeout above cold-start latency (#3438) (9a11109)
  • install: apply managed env vars added after a deployment was installed (#3740) (a4cb2bc)
  • install: wait for the old process to stop before restarting (#3670) (11c7320)
  • kompress: bound the inference deadline to the request, not each block (#3693) (7f2766c)
  • kompress: keep the boolean connectives that hold a condition together (#3687) (bf290ba)
  • learn: treat an unreadable project memory dir as absent instead of crashing (#3710) (ff60d57)
  • mcp: accept an empty install ledger instead of failing mutations as malformed (#3235) (19ddfe1)
  • memory/graph: apply relation_type filter to both sides of a BOTH subgraph query (#3236) (1a6f941)
  • memory: fail closed for unresolved tools (#3655) (7c3cbc8)
  • memory: make extract_system_prompt concatenative, not first-match (#3644) (3f3cf19)
  • memory: tolerate None message content in inline memory parser (#3211) (5ccec67)
  • metrics: split rate-limited by source and label failures by provider (#3707) (5ff4ea1)
  • openclaw: declare transcriptSemantics and implement commitTurn (#3442) (a28dd4e)
  • perf: make budget checks constant-time (#3368) (ed08069)
  • perf: make rate limiter bucket checks constant-time (#3373) (a8bd9be)
  • preserve null and empty strings in lossless CSV compaction (#3665) (7ad9f80)
  • proxy: admit container host gateway on compress routes (#3715) (a8ae0a6)
  • proxy: bound request-log message payloads to the feed window; trim glibc too (#3717) (994a89f)
  • proxy: count a ceiling-stopped stream exactly instead of estimating its text (#3771) (b36e59a)
  • proxy: discard partial SSE tails during finalization (#3411) (6c0e817)
  • proxy: enforce configured TPM limits (#3350) (138736c)
  • proxy: fall back when forced Kompress is cold (#3381) (ca54c2a)
  • proxy: make the output shaper actually reduce output in the default mode (#3773) (c029298)
  • proxy: partition response cache by upstream (#3349) (dfdc725)
  • proxy: pin the validated address so DNS rebinding cannot move an upstream (#3731) (a102e05)
  • proxy: preserve Claude Code auto-mode protocol (#3784) (12c1579)
  • proxy: preserve empty transport error context (#3675) (ca02f28)
  • proxy: preserve OpenCode Headroom retrieve results (#3782) (c7ebaed)
  • proxy: protect Codex exec reads whose argument is a JavaScript object literal (#3737) (ecb5e5a)
  • proxy: reject Anthropic batch operations on Copilot (#3318) (871bbde)
  • proxy: repair client-side tool_search tool_reference blocks (#3443) (f12e3fb)
  • proxy: resolve Codex custom_tool_call names for Responses tool exclusion (#3755) (55c78de)
  • proxy: restrict urlopen SSL context ALPN to http/1.1 (#3567) (5baa439)
  • proxy: scope OpenAI rate limits by api-key (#3365) (b9e8462)
  • proxy: stamp x-headroom-* compression metrics on streaming responses (#3769) (2c4dc44)
  • remove deprecated Apache license classifier (#3566) (b2d9275)
  • savings: report negative savings instead of flooring them at zero (#3744) (1455f00)
  • sdk: enforce dormant public type tests (#3424) (95cbbb8)
  • sdk: preserve Anthropic image blocks in message conversion instead of dropping the turn (#3439) (63676e6)
  • sdk: preserve proxy authentication alongside provider credentials (#3450) (ca4b47a)
  • security: create credential files private instead of narrowing after write (#3215) (9b8cae8)
  • security: reject unauthenticated public proxy binds (#3316) (b0c19a2)
  • smart-crusher: disclose dropped scalar-array items with a retrievable ccr sentinel (#3692) (c1fc84a)
  • spreadsheet: stop .xls integer rendering fabricating digits above 2^53 (#3704) (e8a5109)
  • spreadsheet: stop inventing digits for .xls cells above 2**53 (#3700) (1a7c5bb)
  • tests: ask litellm for a model it prices instead of naming a retired one (#3722) (0ad5e68)
  • tool-search: detect every wire shape of client-side deferral (#3746) (665b73d)
  • tool-search: don't orphan deferred tools, and stop overstating the saving (#3739) (85f9e01)
  • tool-search: make the core-tools override authoritative and the warning recurrent (#3745) (a9757c9)
  • transforms: detect fixed-width command output as tabular and keep it out of Kompress (#3786) (6c9aef1)
  • transforms: stop embedded JSON pre-pass short-circuiting HTML extraction (#3620) (195910b)
  • transforms: stop routing timestamped log rows as grep matches (#3748) (d971f7c)
  • wrap: handle SIGHUP on the shared proxy paths, not just claude (#3331) (c4df2dd)
  • wrap: stop blocking the launch on the Serena pre-index (#3557) (df8ebdf)

Performance Improvements

  • cache: drop eager full-backend TTL sweep on every new-key store() (#3256) (2fed685)
  • cache: LRU-bound the compression-feedback tool-pattern map (#3342) (2d10b10)
  • memory: reindex FTS5 a page at a time instead of a record at a time (#3466) (3e36aef)
  • providers: cache Google/Cohere token counters across requests (#3273) (cc6a07c)
  • relevance: order BM25 query terms once, not once per document (#3468) (6880984)

Dependencies

  • bump dotenv from 17.4.2 to 18.0.1 in /sdk/typescript (#3765) (56edfbc)
  • bump ruff from 0.16.7 to 0.16.8 in the pip-minor-patch group (#3761) (b9ded1a)
  • bump the cargo-minor-patch group with 3 updates (#3762) (fbbe8b8)
  • bump the npm-minor-patch group across 2 directories with 19 updates (#3763) (54357ff)
  • bump the npm-minor-patch group across 3 directories with 9 updates (#3764) (6311332)

Code Refactoring

  • sdk: route _fetch through rawFetch instead of duplicating it (#3473) (b2b5847)
  • smart-crusher: drop the dead crush_object clone from the object path (#3705) (7221724)
