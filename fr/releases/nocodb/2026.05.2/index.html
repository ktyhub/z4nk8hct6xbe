Vue Gantt

<img width="2880" height="1570" alt="image" src="https://github.com/user-attachments/assets/c194cf78-7b4c-4c50-a782-523525bd9e04" /> **Gantt View** transforme n'importe quel tableau basé sur des dates en un calendrier de projet en direct : les enregistrements se transforment en barres déplaçables, les dépendances en flèches et les dates clés en losanges d'étape. Que vous planifiiez le lancement d'un produit, établissiez une feuille de route ou coordonniez les phases d'un projet, il montre ce qui s'exécute, quand et ce qui bloque quoi. Faites glisser pour replanifier, liez les tâches à partir de la poignée d'une barre et passez d'un sprint d'une semaine à une feuille de route de cinq ans. [En savoir plus sur la vue Gantt →](https://nocodb.com/docs/product-docs/views/view-types/gantt) ## Pages partagées <img width="2004" height="1520" alt="image" src="https://github.com/user-attachments/assets/9e57a046-ee17-46ea-a9ab-3e9fa1cb1c30" /> **Vous pouvez désormais partager publiquement une page NocoDocs** sous forme de lien en lecture seule que n'importe qui peut ouvrir dans un navigateur, aucun compte NocoDB n'est requis. Que vous partagiez des documents produit, un brief de projet ou un wiki interne, vous pouvez transférer un document directement de l'éditeur vers une URL partageable, ou l'intégrer ailleurs avec un extrait iframe. Désactivez la bascule pour révoquer le lien en quelques secondes. [En savoir plus sur le partage de documents →](https://nocodb.com/docs/noco-docs/share-document) ## Panneau latéral d'enregistrement étendu dans l'édition communautaire <img width="2622" height="1568" alt="image" src="https://github.com/user-attachments/assets/56d078c3-c44f-4ab0-902f-f6ffe275ceee" /> Le **Panneau latéral d'enregistrement étendu**, introduit dans 2026.05.1, est désormais livré dans Community Edition. L'ouverture d'un enregistrement l'ancre à droite de la grille au lieu d'un mode plein écran, afin que vos données restent visibles pendant que vous modifiez des champs, lisez des commentaires ou analysez l'historique des révisions. Il s'agit de la disposition de bureau par défaut dans toutes les éditions ; les vues publiques et partagées restent ouvertes en tant que modal centré. [En savoir plus sur l'enregistrement étendu →](https://nocodb.com/docs/product-docs/records/expand-record) ## Sécurité du compte - **Une session active par compte.** La connexion sur un nouvel appareil ou navigateur déconnecte la session précédente, quel que soit le chemin de connexion, y compris l'authentification unique. Activé par défaut dans toutes les éditions ; Les jetons API ne sont pas affectés. - **Workspace 2FA couvre désormais les propriétaires.** Les propriétaires ne sont plus exemptés de l'application de la 2FA à l'échelle de l'espace de travail. Ainsi, sur les espaces de travail d'entreprise qui nécessitent la 2FA, les propriétaires sont invités à s'inscrire avant de continuer. ## Améliorations et correctifs - **Recherchez et masquez les champs vides dans un enregistrement développé.** Dans un enregistrement développé, vous pouvez désormais rechercher n'importe quel champ ou valeur, ce qui est utile lorsque vous avez beaucoup de champs. Plus la possibilité de masquer également les champs vides. - **Filtres épinglés pour les champs de date.** Les champs Date, DateHeure, Heure de création et Heure de dernière modification peuvent désormais être épinglés à la barre d'outils sous forme de pilules compactes (date exacte, il y a jours, N derniers jours). - **Palettes de couleurs des graphiques du tableau de bord.** Sur les tableaux de bord Cloud, les widgets à barres, lignes, secteurs, beignets et nuages ​​​​de points bénéficient d'un sélecteur de palette, et les jauges disposent d'un sélecteur de couleurs complet pour les couleurs de la plage. - **Les touches fléchées parcourent les champs de formulaire numériques.** Les flèches haut et bas incrémentent et décrémentent désormais les champs Entier, Décimal et Pourcentage dans les formulaires, correspondant au comportement déjà utilisé par la devise. - **AutoNumber sur les tables vides.** L'ajout d'un champ AutoNumber à une table vide ne génère plus d'erreur ; la séquence s'initialise correctement. - **La coloration des lignes persiste dans tous les changements de vue.** La valeur d'une condition de couleur de ligne est désormais conservée lorsque vous changez de vue au lieu de la réinitialiser. - **Tables de jonction exclues de la limite de table.** Les tables de liens plusieurs-à-plusieurs masquées ne sont plus prises en compte dans la limite de table d'une base, rétablissant ainsi le nombre prévu de tables visibles par l'utilisateur. - **Les champs obligatoires masqués n'échouent plus silencieusement.** Le masquage d'un champ obligatoire (NON NULL) avertit désormais, le marque dans le menu Champs, développe automatiquement les champs masqués lors de l'ajout d'un enregistrement et affiche une erreur de sauvegarde claire au lieu de supprimer la ligne. - **Les champs de calendrier et de date respectent le fuseau horaire de la colonne.** Le glisser, le redimensionnement et l'affichage dans les vues du calendrier n'affichent plus le mauvais décalage pour les colonnes MySQL DateTime et configurées selon le fuseau horaire. ## Notes d'auto-hébergement - **Si vous utilisiez `NC_CONNECTION_ENCRYPT_KEY` et 2FA, veuillez lire.** Sur les instances exécutées avec `NC_CONNECTION_ENCRYPT_KEY` défini, TOTP a rencontré des problèmes lors de la vérification du code en raison de l'aller-retour de chiffrement/déchiffrement, provoquant l'échec de chaque vérification 2FA avec "Code de vérification invalide". Ceci est corrigé. Si vous utilisiez 2FA, vous devrez le désactiver et vous réinscrire. Notez que 2FA s’applique uniquement aux connexions basées sur l’e-mail et le mot de passe, pas au SSO. - **Accès au réseau privé pour les bases de données et les webhooks.** La protection SSRF est appliquée par défaut. Si votre instance se connecte à une base de données ou envoie des webhooks sur un réseau privé ou local, vous devrez peut-être vous inscrire avec les variables d'environnement appropriées (`NC_ALLOW_LOCAL_EXTERNAL_DBS`, `NC_WEBHOOK_ALLOW_PRIVATE_NETWORK` / `NC_ALLOW_LOCAL_HOOKS`), ou désactiver le filtrage SSRF globalement avec `NC_DISABLE_SSRF_PROTECTION`. NocoDB Cloud applique toujours la protection SSRF. - **Audit des dépendances de sécurité.** Cette version efface un grand nombre d'avis de sécurité de dépendance dans la pile (y compris `axios`, `next` et `mermaid`) sans modification des API publics. ------ ### Problèmes résolus - [**fermé**] 🐛 Bug : l'intégration d'iFrame ne fonctionne pas pour les noco-docs partagés [#13901](https://github.com/nocodb/nocodb/issues/13901) - [**fermé**] 🐛 Bug : Créer le connecteur nocodb:create renvoie 404 alors que l'appel direct v2 API réussit (auto-hébergé, PG 16) [#13881](https://github.com/nocodb/nocodb/issues/13881) - [**fermé**] 🐛 Bug : la vue Calendrier envoie le champ Date en tant que fuseau horaire datetime à moins que la saisie de la date ne soit ciblée, provoquant une sauvegarde de la veille en UTC+9 [#13880](https://github.com/nocodb/nocodb/issues/13880) - [**fermé**] 🐛 Bug : les champs numériques de la vue du formulaire ne sont pas mis à jour lors du défilement vers le haut/bas [#13861](https://github.com/nocodb/nocodb/issues/13861) - [**fermé**] 🐛 Bug : la saisie des données échoue silencieusement si l'enregistrement ne peut pas être stocké (valeur non nulle dans le champ caché) [#13838](https://github.com/nocodb/nocodb/issues/13838) - [**fermé**] 🐛 Bug : l'import échoue mais message "réussi..." Gantt View

<img width="2880" height="1570" alt="image" src="https://github.com/user-attachments/assets/c194cf78-7b4c-4c50-a782-523525bd9e04" />

Gantt View turns any date-based table into a live project schedule: records become draggable bars, dependencies become arrows, and key dates become milestone diamonds. Whether you're planning a product launch, mapping a roadmap, or coordinating project phases, it shows what runs when and what blocks what. Drag to reschedule, link tasks from a bar's handle, and zoom from a one-week sprint out to a five-year roadmap.

Learn more about Gantt View →

Shared Pages

<img width="2004" height="1520" alt="image" src="https://github.com/user-attachments/assets/9e57a046-ee17-46ea-a9ab-3e9fa1cb1c30" />

You can now publicly share a NocoDocs page as a read-only link that anyone can open in a browser, no NocoDB account required. Whether you're sharing product docs, a project brief, or an internal wiki, you can take a document straight from the editor to a shareable URL, or embed it elsewhere with an iframe snippet. Switch the toggle off to revoke the link in seconds.

Learn more about sharing documents →

Expanded Record Side Panel in Community Edition

<img width="2622" height="1568" alt="image" src="https://github.com/user-attachments/assets/56d078c3-c44f-4ab0-902f-f6ffe275ceee" />

The Expanded Record Side Panel, introduced in 2026.05.1, now ships in Community Edition. Opening a record docks it to the right of the grid instead of a full-screen modal, so your data stays in view while you edit fields, read comments, or scan revision history. It's the default desktop layout across all editions; public and shared views still open as a centered modal.

Learn more about the Expanded Record →

Account Security

  • One active session per account. Signing in on a new device or browser signs out the previous session, across every sign-in path including SSO. On by default in all editions; API tokens are unaffected.
  • Workspace 2FA now covers owners. Owners are no longer exempt from workspace-wide 2FA enforcement, so on Enterprise workspaces that require 2FA, owners are prompted to enroll before continuing.

Improvements & Fixes

  • Search and hide blank fields in an expanded record. In an expanded record you can now search for any field or value, useful when you have lots of fields. Plus the ability to hide blank fields too.
  • Pinned filters for date fields. Date, DateTime, Created time, and Last modified time fields can now be pinned to the toolbar as compact pills (exact date, days ago, past N days).
  • Dashboard chart color palettes. On Cloud dashboards, bar, line, pie, donut, and scatter widgets gain a palette picker, and gauges get a full color picker for range colors.
  • Arrow keys step numeric form fields. Up and Down arrows now increment and decrement Integer, Decimal, and Percent fields in forms, matching how Currency already behaved.
  • AutoNumber on empty tables. Adding an AutoNumber field to an empty table no longer throws an error; the sequence initializes correctly.
  • Row coloring persists across view switches. A row-color condition's value is now retained when you switch views instead of resetting.
  • Junction tables excluded from the table limit. Hidden many-to-many link tables are no longer counted toward a base's table limit, restoring the intended number of user-visible tables.
  • Hidden required fields no longer fail silently. Hiding a required (NOT NULL) field now warns, flags it in the Fields menu, auto-expands hidden fields when adding a record, and shows a clear save error instead of dropping the row.
  • Calendar and date fields respect the column timezone. Drag, resize, and display on Calendar views no longer show the wrong offset for MySQL DateTime and timezone-configured columns.

Self-Hosting Notes

  • If you were using NC_CONNECTION_ENCRYPT_KEY and 2FA, please do read. On instances running with NC_CONNECTION_ENCRYPT_KEY set, TOTP had issues while verifying the code due to the encrypt/decrypt round-trip, causing every 2FA verification to fail with "Invalid verification code". This is fixed. If you were using 2FA, you will need to disable and re-enroll. Note that 2FA only applies to email and password based logins, not to SSO.
  • Private-network access for databases and webhooks. SSRF protection is enforced by default. If your instance connects to a database or sends webhooks on a private or local network, you may need to opt in with the relevant environment variables (NC_ALLOW_LOCAL_EXTERNAL_DBS, NC_WEBHOOK_ALLOW_PRIVATE_NETWORK / NC_ALLOW_LOCAL_HOOKS), or disable SSRF filtering globally with NC_DISABLE_SSRF_PROTECTION. NocoDB Cloud always enforces SSRF protection.
  • Security dependency audit. This release clears a large batch of dependency security advisories across the stack (including axios, next, and mermaid) with no changes to public APIs.
