nocodb 2026.10.1

<img width="1865" height="1147" alt="Groupe 115" src="https://github.com/user-attachments/assets/1f72ed6f-1f2b-4f89-a033-66b572c6bd90" /> > ⚠️ **Les horodatages incluent les millisecondes.** Sur PostgreSQL et SQLite, les valeurs de date et d'heure dans les réponses API, les charges utiles des webhooks et les exportations CSV incluent désormais les millisecondes (`12:34:56.000+00:00`). Vérifiez les intégrations qui lisent les dates dans un format fixe. > **MCP répertorie tous les outils.** Le serveur MCP de `/mcp` répertorie désormais tous les outils. Si Windsurf ou VS Code Copilot affiche trop d'outils, connectez-le à nouveau avec l'URL `/mcp-discovery`. [En savoir plus](https://docs.nocodb.com/docs/mcp#clients-that-cap-the-tool-list) > **Les modifications du mot de passe déconnectent vos applications.** La modification de votre mot de passe supprime vos jetons API et déconnecte les applications que vous avez autorisées avec OAuth. [En savoir plus](https://nocodb.com/docs/product/account-settings/api-tokens#password-changes-delete-your-tokens) ## Améliorations - **Applications classiques sur téléphones** - Les applications classiques publiées s'adaptent aux écrans des téléphones, y compris la barre latérale, les barres d'outils, les formulaires d'enregistrement, les groupes de tableaux de bord et les widgets pivots. - **Regrouper par plusieurs types de champs** - Les pages de l'application classique sont regroupées par champs de liens, de formule, de recherche, de cumul et de nombre de liens, et les widgets de liste obtiennent un groupe par paramètre. [En savoir plus](https://docs.nocodb.com/docs/classic-apps/layouts/table#grid) - **Redimensionner les colonnes dans les applications classiques** - Faites glisser le bord d'une colonne dans un widget Liste pour le redimensionner. Les constructeurs gardent la largeur pour tout le monde. [En savoir plus](https://docs.nocodb.com/docs/classic-apps/layouts/table#list) - **Ouvrir les enregistrements à partir des widgets d'affichage** - Les widgets Calendrier, Chronologie et Gantt sur un tableau de bord peuvent ouvrir un enregistrement lorsque vous le click. [En savoir plus](https://docs.nocodb.com/docs/classic-apps/layouts/dashboard#configuring-widgets) - **Masquer les titres des widgets** - Les widgets de données, de graphiques et de chiffres dans une application classique ont un commutateur *Afficher le titre*. - **Visibilité des boutons par rôle** - Les boutons de page dans une application classique ne peuvent s'afficher qu'aux rôles que vous choisissez. [En savoir plus](https://docs.nocodb.com/docs/classic-apps/elements#buttons) - **Réorganiser les onglets de filtre utilisateur** - Les constructeurs font glisser les onglets de filtre utilisateur dans un nouvel ordre. [En savoir plus](https://docs.nocodb.com/docs/classic-apps/elements#user-filters) - **Trier la sélection unique par ordre d'options** - Un tri sur un champ à sélection unique peut suivre l'ordre de ses options au lieu de A à Z. [En savoir plus](https://docs.nocodb.com/docs/product/tables/table-operations/sort#sort-a-single-select-field-by-option-order) - **Déconnectez-vous des autres appareils** - *Compte* > *Sécurité* vous déconnecte partout, sauf le navigateur actuel sur NocoDB Cloud. [En savoir plus](https://docs.nocodb.com/docs/product/account-settings/authentication/sign-out-other-devices) - **Modèles sur l'accueil** - L'accueil et la page *Nouveau projet* affichent une galerie de modèles sur NocoDB Cloud, et les projets construits avec l'IA commencent par quelques exemples d'enregistrements. [En savoir plus](https://docs.nocodb.com/docs/product/projects/create-project#from-template) - **Grec** - NocoDB est désormais disponible en grec. [En savoir plus](https://docs.nocodb.com/docs/product/account-settings/language) - **Limites de taux MCP** - MCP a sa propre limite par compte. Un client qui le dépasse se voit indiquer combien de temps attendre. - **Applications connectées MCP** - La liste des applications connectées indique la dernière fois que chaque application a été utilisée. [En savoir plus](https://docs.nocodb.com/docs/mcp/connections#managing-and-removing-access) - **Écran de consentement OAuth** - L'écran de consentement indique où vous serez envoyé et vous avertit lorsqu'une application n'est pas vérifiée par NocoDB. - **Mises à jour en direct** - La galerie, le Kanban, la carte, les tableaux de bord et l'examen des enregistrements d'applications classiques sont actualisés lorsque les collaborateurs effectuent des modifications. ## Ce qui est corrigé - **Workflows et webhooks** - *Lors de la mise à jour de l'enregistrement* Les workflows et les webhooks de mise à jour s'exécutent lorsque les enregistrements sont liés ou dissociés via le API, un collage ou une modification de clé étrangère. [En savoir plus](https://docs.nocodb.com/docs/workflows/nodes/trigger-nodes/record-updated#how-it-works) - **Formules** - Les formules avec `?` à l'intérieur du texte sont évaluées, les valeurs des cases à cocher agissent comme 1 et 0 dans les formules PostgreSQL et les résultats XOR peuvent être filtrés. - **Filtres** - Les filtres *est vide* sur les cumuls fonctionnent et les filtres *j'aime* sur les champs utilisateur ne correspondent qu'aux noms. - **Liens** - Les champs un-à-un auto-liés affichent l'enregistrement lié et les projets dupliqués conservent leurs liens. - **Copie de données** - La duplication et l'importation d'un projet conserve les valeurs Long Text et JSON de plus de 100 000 caractères. - **Applications classiques** - Recherche dans le générateur, sélecteurs de liens dans les formulaires, étiquettes de chronologie, noms de page par défaut, champs de formulaire non masqués, barres de défilement de liste et couleurs de lignes conditionnelles se comportent comme prévu. - **Partage** - La boîte de dialogue *Partager* de l'application classique peut donner à un membre existant un rôle plus élevé, et une deuxième invitation maintient le premier lien d'invitation fonctionnel. - **Pièces jointes** - Les touches d'échappement et les touches fléchées fonctionnent dans l'aperçu des pièces jointes partout où elles s'ouvrent. - **Tables** - Une nouvelle table peut prendre le nom d'une table supprimée, même à proximité de la limite de longueur du nom de la base de données. - **SQL Server et Oracle** - Les tris qui répètent un travail de champ sur SQL Server, et sur Oracle, un champ numérique est converti en tri par formules décimales et textuelles. - **Chat AI** - Le chat fonctionne avec les intégrations Claude Opus 5.5, Sonnet 5.5 et Fable 5.1. - **Connexion** - L'oubli de votre mot de passe ne vous déconnecte plus et les erreurs de connexion affichent un message pour chaque cas. ## Notes d'auto-hébergement - **Première inscription** - Lors d'une nouvelle installation sous licence, le premier super-administrateur obtient l'espace de travail et l'organisation par défaut sans redémarrage. - **Actualisation de la licence** - *Actualiser* sur la page Licence, ou un redémarrage, active une licence qui apparaît comme en attente. [En savoir plus](https://docs.nocodb.com/docs/self-hosting/license-activation#refresh-license) - **Pièces jointes sécurisées** - Le réglage uniquement de `NC_ATTACHMENT_ACCESS_CONTROL_ENABLED=true` active désormais les pièces jointes sécurisées, donc `/download` et `/dl` arrêtent de servir des fichiers. Utilisez les URL signées renvoyées par les réponses des pièces jointes. [En savoir plus](https://docs.nocodb.com/docs/self-hosting/environment-variables#storage) - **Bases de données locales** - ClickHouse sur un réseau privé, et MySQL ou PostgreSQL sur un socket Unix, nécessitent `NC_ALLOW_LOCAL_EXTERNAL_DBS=true`. [En savoir plus](https://docs.nocodb.com/docs/self-hosting/environment-variables#product-configuration) - **Jetons MCP** - Les secrets des jetons MCP sont stockés hachés et affichés une seule fois. Les jetons déjà présents dans vos MCP clients continuent de fonctionner. - **Noms de table longs** - Les nouveaux noms de table SQL Server et Oracle sont limités à 125 caractères. - **Renforcement de la sécurité** - L'inscription, les invitations, OAuth, les vues partagées, les exportations de données, les connexions à la base de données et les secrets stockés sont renforcés et les dépendances sont corrigées. --- Pour plus de détails sur les fonctionnalités introduites dans 2026.10.0, consultez le [2026.10.0 changelog](https://docs.nocodb.com/docs/changelog/2026.10.0). - nocodb 2026.10.1

<img width="1865" height="1147" alt="Group 115" src="https://github.com/user-attachments/assets/1f72ed6f-1f2b-4f89-a033-66b572c6bd90" />

⚠️ Timestamps include milliseconds. On PostgreSQL and SQLite, date and time values in API responses, webhook payloads and CSV exports now include milliseconds (12:34:56.000+00:00). Check integrations that read dates in a fixed format.

MCP lists every tool. The MCP server at /mcp now lists every tool. If Windsurf or VS Code Copilot shows too many tools, connect it again with the /mcp-discovery URL. Learn more

Password changes sign out your apps. Changing your password deletes your API tokens and disconnects apps you authorized with OAuth. Learn more

Improvements

  • Classic apps on phones - Published classic apps fit phone screens, including the sidebar, toolbars, record forms, dashboard groups and pivot widgets.
  • Group by more field types - Classic app pages group by Links, Formula, Lookup, Rollup and link count fields, and List widgets get a group by setting. Learn more
  • Resize columns in classic apps - Drag a column edge in a List widget to resize it. Builders save the width for everyone. Learn more
  • Open records from view widgets - Calendar, Timeline and Gantt widgets on a dashboard can open a record when you click it. Learn more
  • Hide widget titles - Data, chart and number widgets in a classic app have a Show title switch.
  • Button visibility by role - Page buttons in a classic app can show only to the roles you choose. Learn more
  • Reorder user filter tabs - Builders drag user filter tabs into a new order. Learn more
  • Sort Single Select by option order - A sort on a Single Select field can follow the order of its options instead of A to Z. Learn more
  • Sign out of other devices - Account > Security signs you out everywhere except the current browser on NocoDB Cloud. Learn more
  • Templates on Home - Home and the New project page show a template gallery on NocoDB Cloud, and projects built with AI start with a few sample records. Learn more
  • Greek - NocoDB is now available in Greek. Learn more
  • MCP rate limits - MCP has its own limit per account. A client that goes over it is told how long to wait.
  • MCP connected apps - The list of connected apps shows when each app was last used. Learn more
  • OAuth consent screen - The consent screen shows where you will be sent and warns when an app is not verified by NocoDB.
  • Live updates - Gallery, Kanban, Map, dashboards and classic app record review refresh in place when collaborators edit.

What's Fixed

  • Workflows and webhooks - When record updated workflows and update webhooks run when records are linked or unlinked through the API, paste or a foreign key change. Learn more
  • Formulas - Formulas with ? inside text evaluate, Checkbox values act as 1 and 0 in PostgreSQL formulas, and XOR results can be filtered.
  • Filters - is blank filters on Rollups work, and like filters on User fields match names only.
  • Links - Self-linking one-to-one fields show the linked record, and duplicated projects keep their links.
  • Copying data - Duplicating and importing a project keeps Long Text and JSON values longer than 100,000 characters.
  • Classic apps - Search in the builder, link pickers in forms, Timeline labels, default page names, unhidden form fields, list scrollbars and conditional row colors behave as expected.
  • Sharing - The classic app Share dialog can give an existing member a higher role, and a second invite keeps the first invite link working.
  • Attachments - Escape and arrow keys work in the attachment preview everywhere it opens.
  • Tables - A new table can take a trashed table's name, even near the database name length limit.
  • SQL Server and Oracle - Sorts that repeat a field work on SQL Server, and on Oracle a Number field converts to Decimal and text formulas sort.
  • AI chat - Chat works with Claude Opus 5.5, Sonnet 5.5 and Fable 5.1 integrations.
  • Sign-in - Forgetting your password no longer signs you out, and sign-in errors show one message for every case.

Self-Hosting Notes

  • First sign-up - On a new licensed install, the first super admin gets the default workspace and organization without a restart.
  • License refresh - Refresh on the License page, or a restart, activates a license that shows as pending. Learn more
  • Secure attachments - Setting only NC_ATTACHMENT_ACCESS_CONTROL_ENABLED=true now turns on secure attachments, so /download and /dl stop serving files. Use the signed URLs that attachment responses return. Learn more
  • Local databases - ClickHouse on a private network, and MySQL or PostgreSQL over a Unix socket, need NC_ALLOW_LOCAL_EXTERNAL_DBS=true. Learn more
  • MCP tokens - MCP token secrets are stored hashed and shown only once. Tokens already in your MCP clients keep working.
  • Long table names - New SQL Server and Oracle table names are limited to 125 characters.
  • Security hardening - Sign-up, invitations, OAuth, shared views, data exports, database connections and stored secrets are hardened, and dependencies are patched.

For more details on the features introduced in 2026.10.0, see the 2026.10.0 changelog.
