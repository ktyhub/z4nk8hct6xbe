nocodb 2026.10.2

<img width="1865" height="1147" alt="2026.10.2 : Version de correction de bug" src="https://github.com/user-attachments/assets/df5a8f63-c53b-45e2-b664-e78df076595d" /> ## Ce qui est corrigé - **Champs et formules** - La modification d'un type de champ sur PostgreSQL conserve toutes les valeurs qui correspondent, le fait de renommer un champ met à jour les formules qui l'utilisent et une erreur mathématique n'efface que sa propre ligne. - **Filtres** - *Est-ce que l'un des* correspond à l'option de sélection exacte, les groupes de filtres vides sont supprimés et les filtres de date fonctionnent sur les recherches de formules de date et de cumuls. - **Plus de filtres** - Les filtres de date avec une valeur incorrecte sont rejetés lors de l'enregistrement et les filtres sur les liens entre bases s'appliquent aux personnes pouvant voir la table liée. - **Grille et enregistrements** - Échapper annule une modification de cellule, coller une valeur qui ne convient pas conserve l'ancienne et une modification crée une entrée de révision. - **Enregistrements développés** - Ctrl/Cmd+F utilise la recherche du navigateur lorsqu'un enregistrement est développé, et *Créer et lier* à partir d'un nouvel enregistrement crée l'enregistrement lié lorsque vous enregistrez. - **Saisie** - La première clé saisie avec un IME chinois ou japonais atteint la cellule et un lecteur de codes-barres dans le sélecteur de liens relie l'enregistrement numérisé. - **Dates et nombres** - Les dates antérieures à l'année 100 conservent leur année, les champs décimaux des bases de données externes utilisent l'échelle de la colonne et les jours de la semaine du calendrier suivent le langage de l'interface utilisateur. - **Texte enrichi** - Les blocs de texte et de code enrichis conservent leur contenu et leur indentation après l'enregistrement et le rechargement. [En savoir plus](/docs/product/tables/fields/field-types/text-based/rich-text) - **Commentaires** - Le texte entre crochets, tel que `Name <a@b.com>`, est conservé dans les commentaires. - **Liens** - *Créer et lier* sur un lien automatique dans le bon sens, et la suppression d'une table de la corbeille supprime ses champs de lien. - **Recherches** - Une recherche via un lien plusieurs-à-plusieurs conserve la valeur d'affichage des enregistrements liés, et les filtres sur les recherches imbriquées appliquent les propres conditions de la recherche. [En savoir plus](/docs/product/tables/fields/field-types/links-based/lookup#applying-filters) - **Bases de données externes** - Les colonnes générées par PostgreSQL sont en lecture seule, les cumuls DateTime MySQL affichent l'heure correcte et les liens vers une table avec une clé primaire composite sont rejetés avant que quoi que ce soit ne soit créé. - **Corbeille** - La suppression ou la restauration d'un enregistrement conserve la liste des enregistrements liés qui sont déjà dans la corbeille. [En savoir plus](/docs/product/projects/project-trash#restore-an-entry) - **Dupliquer** - La duplication d'un projet ou d'une table ignore les filtres sur les liens entre bases qu'il ne copie pas et fonctionne avec les valeurs par défaut des colonnes qui contiennent `?`. [En savoir plus](/docs/product/projects/actions-on-project#duplicate-project) - **Importations et exportations** - Les importations Excel conservent les noms des feuilles et les exportations écrivent les valeurs d'affichage des liens. - **Import CSV** - La fusion d'un CSV sur l'ID met à jour les enregistrements existants, et les webhooks et workflows des enregistrements importés voient leurs liens. - **Kanban** - Les tableaux avec plus de 25 piles affichent chaque pile après *Tout réduire*. [En savoir plus](/docs/product/tables/views/view-types/kanban#collapse-stack) - **Calendrier** : un calendrier cumulatif de dates affiche les enregistrements sous forme d'événements d'une journée entière. - **Applications classiques** - Un filtre de groupe de tableau de bord s'applique à chaque widget, les pages de formulaire envoient des *Réponses par e-mail*, les sélecteurs de personnes répertorient uniquement les personnes qui y ont accès et les pages de tableau affichent des séparateurs de numéros. - **Formulaires** : les formulaires nécessitant une connexion s'ouvrent après la connexion, sans boucle de redirection. - **Workflows** - L'envoi d'e-mails accepte une liste séparée par des virgules, l'historique d'exécution montre pourquoi une exécution a échoué avant sa première étape, les scripts sont exécutés avec l'intégration NocoAI et un workflow qui ne peut jamais s'exécuter n'est pas laissé en ligne. [En savoir plus](/docs/workflows/nodes/action-nodes/send-email) - **Webhooks** - L'exemple de charge utile affiche les champs de lien comme le font les charges utiles réelles. [En savoir plus](/docs/product/tables/table-operations/webhook/create-webhook#configuring-webhook) - **Table Sync** - Les synchronisations Coller-lien à partir d'une vue partagée protégée par mot de passe acceptent le mot de passe. [En savoir plus](/docs/product/sync/nocodb-sync#source) - **Sécurité** - Les vues partagées et les tableaux de bord partagés renvoient uniquement les champs qu'ils affichent, les formulaires écrivent uniquement leurs propres champs, les éditeurs ne voient plus les secrets stockés dans les étapes du flux de travail et les webhooks de flux de travail acceptent des corps de requête jusqu'à 1 Mo. - **Scripts** - `table.selectRecordsAsync({ recordIds })` renvoie uniquement les enregistrements demandés. [En savoir plus](/docs/workflows/scripts/api-reference/table#selectrecordsasync) - **Équipes** - L'ajout ou la suppression d'un membre de l'équipe met immédiatement à jour son rôle dans le projet. [En savoir plus](/docs/product/collaboration/teams#assign-roles-to-teams) - **Documents** : faire glisser une colonne dans un tableau de documents redimensionne ce tableau. - **Colonnes de la grille** - Faire glisser un en-tête de colonne enregistre une position unique pour chaque colonne. - **Téléphones et tablettes** - Appuyer sur le champ d'un bouton exécute son action et la barre latérale commence à être réduite sur les tablettes. - **Messages d'erreur** - Les erreurs du serveur s'affichent à nouveau sous forme de toasts et les actions SQL ayant échoué nomment le problème de connexion. - **Étiquette du plan** - La barre latérale affiche le bon plan une fois que vous vous êtes reconnecté. ## Notes d'auto-hébergement - **Groupes SCIM** - Les groupes d'Entra ID et Okta accordent le rôle d'espace de travail à leur équipe. [En savoir plus](/docs/product/account-settings/authentication/scim#group-provisioning) - **Licences airgappées** - *Actualiser la licence* renouvelle les licences airgappées. [En savoir plus](/docs/self-hosting/license-activation#refresh-license) - **MariaDB** - `REGEX_REPLACE` et `REGEX_EXTRACT` fonctionnent sur MariaDB, et MariaDB fonctionne comme base de données de métadonnées. [En savoir plus](/docs/product/tables/fields/field-types/formula/string-functions#regex_replace) - **Bases de données externes** - Une connexion super-administrateur laisse les connexions aux bases de données externes fermées jusqu'à ce qu'elles soient utilisées. - **Support chat** - `NC_DISABLE_SUPPORT_CHAT` empêche également le navigateur de charger le script de chat. [En savoir plus](/docs/self-hosting/environment-variables#support-chat) - **SSO** - La connexion via `NC_SSO=oidc` fonctionne à nouveau. Avec `NC_SSO=saml`, une connexion initiée par l'IdP redémarre une fois à partir de NocoDB, l'IdP doit donc renvoyer RelayState inchangé. [En savoir plus](/docs/self-hosting/environment-variables#authentication) - **Windows** - Les exportations CSV et de documents fonctionnent avec le stockage local sous Windows. - **Passerelles IA** - Les fonctionnalités IA fonctionnent avec des passerelles compatibles OpenAI qui renvoient JSON à l'intérieur des barrières de code. - **Écrites de liens plus rapides** - Sur Community Edition, les écritures avec des liens ne lisent plus chaque enregistrement lié. Les suppressions et les ajouts de liens sont plusieurs fois plus rapides, tandis que les insertions et les mises à jour avec des liens sont environ un tiers plus rapides. - **Fuseaux horaires** - Les formules de date fonctionnent lorsque PostgreSQL signale un ancien nom de fuseau horaire, tel que `Asia/Calcutta`. --- Pour les modifications apportées à la version précédente, consultez le [2026.10.1 changelog](/docs/changelog/2026.10.1). --- - What's Fixed

  • Fields and formulas - Changing a field type on PostgreSQL keeps every value that fits, renaming a field updates the formulas that use it, and a math error blanks only its own row.
  • Filters - Is any of matches the exact select option, empty filter groups are removed, and date filters work on lookups of date formulas and rollups.
  • More filters - Date filters with a wrong value are rejected on save, and filters on cross-base links apply for people who can see the linked table.
  • Grid and records - Escape cancels a cell edit, pasting a value that does not fit keeps the old one, and one edit makes one revision entry.
  • Expanded records - Ctrl/Cmd+F uses the browser's find while a record is expanded, and Create & Link from a new record creates the linked record when you save.
  • Typing - The first key typed with a Chinese or Japanese IME reaches the cell, and a barcode scanner in the link picker links the scanned record.
  • Dates and numbers - Dates before year 100 keep their year, Decimal fields from external databases use the column's scale, and Calendar weekdays follow the UI language.
  • Rich text - Rich text and code blocks keep their content and indentation after save and reload. Learn more
  • Comments - Text in angle brackets, such as Name <a@b.com>, is kept in comments.
  • Links - Create & Link on a self-link links the right way, and deleting a table from Trash removes its link fields.
  • Lookups - A Lookup through a many-to-many link keeps the display value of the linked records, and filters on nested Lookups apply the Lookup's own conditions. Learn more
  • External databases - PostgreSQL generated columns are read-only, MySQL DateTime rollups show the right time, and links to a table with a composite primary key are rejected before anything is created.
  • Trash - Deleting or restoring a record keeps its linked records that are already in Trash listed there. Learn more
  • Duplicate - Duplicating a project or table skips filters on cross-base links it does not copy, and works with column defaults that contain ?. Learn more
  • Imports and exports - Excel imports keep sheet names, and exports write link display values.
  • CSV import - Merging a CSV on Id updates existing records, and webhooks and workflows of imported records see their links.
  • Kanban - Boards with more than 25 stacks show every stack after Collapse all. Learn more
  • Calendar - A calendar on a date rollup shows records as all-day events.
  • Classic apps - A dashboard group filter applies to every widget, form pages send Email responses, people pickers list only people who have access, and table pages show number separators.
  • Forms - Forms that require sign-in open after sign-in, with no redirect loop.
  • Workflows - Send email accepts a comma-separated list, run history shows why a run failed before its first step, scripts run with the NocoAI integration, and a workflow that can never run is not left Live. Learn more
  • Webhooks - The sample payload shows link fields as real payloads do. Learn more
  • Table Sync - Paste-link syncs from a password-protected shared view accept the password. Learn more
  • Security - Shared views and shared dashboards return only the fields they show, forms write only their own fields, Editors no longer see secrets stored in workflow steps, and workflow webhooks accept request bodies up to 1 MB.
  • Scripts - table.selectRecordsAsync({ recordIds }) returns only the requested records. Learn more
  • Teams - Adding or removing a team member updates their project role right away. Learn more
  • Documents - Dragging a column in a document table resizes that table.
  • Grid columns - Dragging a column header saves a unique position for each column.
  • Phones and tablets - Tapping a Button field runs its action, and the sidebar starts collapsed on tablets.
  • Error messages - Server errors show as toasts again, and failed SQL actions name the connection problem.
  • Plan label - The sidebar shows the right plan after you sign in again.

Self-Hosting Notes

  • SCIM groups - Groups from Entra ID and Okta grant their team's workspace role. Learn more
  • Airgapped licenses - Refresh License renews airgapped licenses. Learn more
  • MariaDB - REGEX_REPLACE and REGEX_EXTRACT work on MariaDB, and MariaDB works as the metadata database. Learn more
  • External databases - A super admin sign-in leaves external database connections closed until they are used.
  • Support chat - NC_DISABLE_SUPPORT_CHAT also stops the browser from loading the chat script. Learn more
  • SSO - Sign-in through NC_SSO=oidc works again. With NC_SSO=saml, an IdP-initiated sign-in restarts once from NocoDB, so the IdP must return RelayState unchanged. Learn more
  • Windows - CSV and document exports work with local storage on Windows.
  • AI gateways - AI features work with OpenAI-compatible gateways that return JSON inside code fences.
  • Faster link writes - On Community Edition, writes with links no longer read every linked record again. Deletes and adding links are several times faster, and inserts and updates with links about a third faster.
  • Timezones - Date formulas work when PostgreSQL reports a legacy timezone name, such as Asia/Calcutta.

For the changes in the previous release, see the 2026.10.1 changelog.
