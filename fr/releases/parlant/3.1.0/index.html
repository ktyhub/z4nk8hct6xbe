parlant v3.1.0

  • Ajouter un point de terminaison /healthz

  • Ajouter EmcieService
  • Ajouter le service GLM
  • Ajouter le service Mistral
  • Ajouter le service OpenRouter
  • Ajouter l'intégration OpenTelemetry pour Meter, Logger et Tracer
  • Ajouter l'adaptateur Qdrant VectorDatabase
  • Ajouter le service Snowflake Cortex
  • Ajout de la possibilité de configurer et d'étendre l'objet d'application FastAPI
  • Ajouter des récupérateurs différés
  • Ajouter un mode de composition dynamique
  • Ajouter des réponses standardisées de suivi
  • Ajouter un niveau de criticité indicatif
  • Ajouter une ligne directrice sur les hooks on_match()
  • Ajouter une option de persistance pour les valeurs des variables contextuelles (magasin de variables)
  • Ajout de descriptions de lignes directrices
  • Autoriser l'abandon de la sélection de réponses prédéfinies et utiliser le brouillon directement, à l'aide d'un crochet
  • Autoriser le contrôle de la charge utile maximale des résultats de l'outil via une variable d'environnement
  • Permettre de contrôler la politique de performance perçue par agent
  • Autoriser les transitions de parcours d'un état d'outil à un autre
  • Autoriser la spécification d'identifiants personnalisés lors de la création d'agents via SDK et API
  • Autoriser la spécification d'identifiants personnalisés lors de la création de clients via SDK et API
  • Autoriser la spécification d'identifiants personnalisés lors de la création de directives, de parcours et de termes de glossaire via SDK et API
  • Exposer le conteneur IoC dans l'objet serveur
  • Prise en charge de l'ajout de champs canrep personnalisés aux directives et états de voyage correspondants
  • Prise en charge des correspondances de lignes directrices personnalisées basées sur le code

Modifié

  • Changement de NLPService par défaut en EmcieService
  • Amélioration de l'efficacité de la correspondance de l'état du parcours lorsque le premier état est un état d'outil
  • Renommez ContextualCorrelator en Tracer
  • Renommer LoadedContext en EngineContext
  • Prise en charge de l'URL proxy pour LiteLLM

Corrigé

  • Correction d'un bug critique avec annulation lors de l'analyse des réponses
  • Correction d'une erreur critique de calcul de similarité dans TransientVectorDatabase
  • Correction d'une évaluation supplémentaire inutile des parcours et des outils dans certains cas extrêmes
  • Amélioration de la cohérence de la sortie Gemini Flash 2.5 en utilisant une astuce d'appel de fonction au lieu de sorties structurées

parlant v3.1.0

[3.1.0] - 2026-01-05

Added

  • Add .current property for Server, Agent, and Customer in SDK
  • Add /healthz endpoint
  • Add API for CRUD operations on session metadata
  • Add EmcieService
  • Add GLM service
  • Add Mistral service
  • Add OpenRouter service
  • Add OpenTelemetry integration for Meter, Logger and Tracer
  • Add Qdrant VectorDatabase adapter
  • Add Snowflake Cortex service
  • Add ability to configure and extend the FastAPI app object
  • Add deferred retrievers
  • Add dynamic composition mode
  • Add follow-up canned responses
  • Add guideline criticality level
  • Add guideline on_match() hooks
  • Add persistence option for context variable values (variable store)
  • Added guideline descriptions
  • Allow bailing out of canned response selection and utilize the draft directly, using a hook
  • Allow controlling max tool result payload via environment variable
  • Allow controlling perceived performance policy per agent
  • Allow journey transitions from one tool state to another
  • Allow specifying custom IDs when creating agents via SDK and API
  • Allow specifying custom IDs when creating customers via SDK and API
  • Allow specifying custom IDs when creating guidelines, journeys, and glossary terms via SDK and API
  • Expose IoC container in server object
  • Support adding custom canrep fields to matched guidelines and journey states
  • Support code-based, custom guideline matchers

Changed

  • Changed default NLPService to EmcieService
  • Improved efficiency of journey state matching when first state is a tool state
  • Rename ContextualCorrelator to Tracer
  • Rename LoadedContext to EngineContext
  • Support proxy URL for LiteLLM

Fixed

  • Fix critical bug with cancellation during response analysis
  • Fix critical similarity calculation error in TransientVectorDatabase
  • Fix unnecessary extra evaluation of journeys and tools in some edge cases
  • Improved Gemini Flash 2.5 output consistency by using function call trick instead of structured outputs
