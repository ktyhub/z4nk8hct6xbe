oh-mon-pi v19.0.1

@oh-my-pi/pi-ai

Corrigé

  • Correction des images GIF échouant aux jugements Liquid AI avec HTTP 422 ; ils sont désormais envoyés au format PNG (#19757 par @alphastorm)
  • La solution de secours Anthropic strict-tool traite désormais un rejet de politique d'organisation Vertex de structured_outputs (allowedPartnerModelFeatures / "fonctionnalité non autorisée structured_outputs") comme un rejet d'outils stricts, réessaye une fois sans strict et épingle strictToolsDisabled (#19576) (#19655 par @koeria)
  • Les requêtes Kiro rejetées avec Input is too long. ou CONTENT_LENGTH_EXCEEDS_THRESHOLD peuvent désormais être récupérées via le compactage de la conversation (#19723 par @emotionbug).
  • Kiro en train de réfléchir désactive désormais le raisonnement au lieu d'exécuter l'effort par défaut du modèle ; les modèles qui ne peuvent pas désactiver le raisonnement utilisent leur effort le plus faible (#19722 par @emotionbug)
  • Kiro /usage affiche les crédits complémentaires achetés, et un compte dont les crédits du forfait sont dépensés continue de fonctionner tant qu'il reste des crédits complémentaires (#19724 par @emotionbug).
  • Les connexions Kiro Identity Center dans AWS GovCloud (US) répertorient désormais les profils dans us-gov-west-1 et us-gov-east-1 au lieu des régions commerciales, qui rejettent les jetons GovCloud (#19726 par @TechDufus)
  • Les erreurs de passerelle sans statut lisant stream interrupted réessayent maintenant comme stream was interrupted au lieu de terminer le tour (#19709).

@oh-my-pi/browser-relay

Corrigé

  • L'extension de relais de navigateur survit à un navigateur dont l'ensemble d'autorisations chargé est antérieur à l'autorisation downloads : le service worker continue de travailler sans couplage de téléchargement au lieu de planter avant même de se connecter (#19659 par @pavel-kalmykov)

@oh-my-pi/pi-catalogue

Ajouté

  • Ajout des modèles de juge d1.2 et d1.2-ultra de Liquid AI ; liquid est désormais par défaut d1.2 (#19753 par @alphastorm)
  • Ajout de gemini-4-neon à la liste groupée Antigravity CLI, avec les niveaux de pensée low/medium/high/xhigh proposés par agy (#19787 par @ataberkus).
  • Model.snapcompactShape ({ variant, frameSize? }) donne à un modèle sa propre forme de cadre snapcompact (#19591 par @ryanskidmore)

Corrigé

  • Les modèles Kiro découverts qui ne peuvent pas désactiver le raisonnement utilisent désormais leur effort le plus faible lorsque la pensée est désactivée (#19722 par @emotionbug).
  • Kiro accepte les ARN de profil AWS GovCloud (US) (arn:aws-us-gov:codewhisperer:…), qui étaient auparavant ignorés lors de la liste des profils (#19726 par @TechDufus).
  • Google Antigravity ne répertorie plus l'emplacement pour moniteur sonar du Gemini 4 Hydrogen ou ses SKU High/XHigh à plusieurs niveaux en tant que modèles distincts ; les SKU à plusieurs niveaux se regroupent en un seul modèle Gemini 4 Hydrogen (#19795 par @eggpeat)
  • Gemini 4 Neon sur Google Antigravity s'affiche désormais comme un modèle dont le niveau de réflexion (faible, moyen, élevé, xélevé) sélectionne le SKU correspondant, au lieu de quatre modèles distincts, et est au prix de 3 $/15 $ par million de jetons (0.15 mis en cache) au lieu de 0 $ (#19789 par @eggpeat).
  • Gemini 4 Neon se regroupe désormais en un seul modèle sur le Gemini CLI également, et sur le Gemini API et Vertex AI, il offre un niveau de réflexion très élevé et des sorties longues jusqu'à 262 144 jetons, avec son prix Gemini API de 3 $/15 $

@oh-my-pi/pi-coding-agent

Ajouté

  • /session affiche le chemin du répertoire local:// de la session, et /copy local le copie, créant d'abord le répertoire afin qu'il puisse être saisi avant que quoi que ce soit n'y soit écrit (#19778 par @farnoy)
  • snapcompactShape sur les modèles models.yml, modelOverrides et les modèles d'extension registerProvider définissent la forme du cadre snapcompact de ce modèle (#19591 par @ryanskidmore)

Corrigé

  • Correction des transcriptions de commandes PTY obtenant parfois une ligne vide où la fin d'une ligne \r\n était divisée en deux lectures de terminal.
  • Correction du composant intégré dirname du shell sous Windows ignorant les séparateurs et les préfixes de lecteur \ (dirname 'C:\a\b' imprimé .), ce qui cassait des scripts comme le lanceur code de VS Code (./Code.exe: No such file or directory)
  • Correction de la sortie bash minimisant l'omission sous Windows lorsqu'une commande est nommée par un chemin \ ou avec .exe ("C:\Program Files\Git\cmd\git.exe" status, git.exe log)
  • Correction des documents omp://tools fournis décrivant toujours l'outil ida supprimé ; tools/dsm.md documente désormais l'espace de noms dsm et les paramètres disassembler.* d'eval, et tools/read.md documente uniquement les lectures exécutables de métadonnées (#19608).
  • Correction des hôtes de terminal natifs tels que Tern plaçant l'extension au-dessus des widgets de l'éditeur et une ligne vide entre la ligne d'état et la barre d'état ; les widgets se trouvent désormais au-dessus de la ligne d'état (#19767)
  • Correction des mentions ^model dans les messages en file d'attente (->/=> pendant que l'agent est occupé, éléments ultérieurs d'une liste numérotée, RPC steer/follow_up, pilotage ACP) atteignant le modèle sous forme de texte littéral ^provider/model au lieu d'enregistrer son agent m<N> (#19683 par @a-glapinski)
  • Correction des mentions ^model dans les messages d'extension envoyés avec sendUserMessage({ deliverAs: "steer" | "followUp" | "aside" }) pendant que l'agent est en train d'atteindre le modèle sous forme de texte littéral (#19799 par @H4vC)
  • Correction de chaque message mis en file d'attente derrière une mention ^model non livré répétant l'avis "m<N> maintenant disponible" au modèle (#19799 par @H4vC).
  • Un manifeste de plugin avec une entrée extensions sans chaîne (par exemple un objet) ne bloque plus le chargement de l'extension avec ERR_INVALID_ARG_TYPE ; l'entrée est signalée comme introuvable et les entrées valides sont toujours chargées (#19674 par @koeria)
  • Correction de bash script.sh intégré résolvant BASH_SOURCE[0] en bash au lieu du chemin du script, ce qui empêchait les scripts de charger des fichiers hors d'eux-mêmes (#19792)
  • Correction de la découverte du modèle proxy ignorant les modalités d'entrée annoncées d'une passerelle et le plafond de jeton de sortie (#19754 par @zhyc9de).
  • Correction d'un fournisseur acheminé via une passerelle d'authentification (transport: pi-native dans models.yml) répertoriant toujours les modèles à partir du propre point de terminaison du fournisseur, y envoyant la clé de passerelle ; ces fournisseurs ignorent désormais la découverte de modèles du fournisseur et conservent leurs modèles groupés et mis en cache (#19646 par @ray8828)
  • Correction d'un faux marqueur "échec de cache" au premier tour après un compactage : le compactage réécrit le préfixe d'invite, de sorte que l'échec soit attendu et ne soit plus signalé (#19679 par @Petyok)
  • Correction de omp --resume <id> sous --mode rpc, --mode rpc-ui et --mode acp échouant au démarrage lorsque le répertoire de la session n'existe plus ; la session s'ouvre désormais là où elle est stockée, avec le répertoire de lancement comme répertoire de travail, sans demander s'il faut la déplacer (#19651 par @sjawhar)
  • Correction de l'extension du relais du navigateur qui mourait silencieusement dans un navigateur dont l'ensemble d'autorisations chargé est antérieur à l'autorisation downloads : il continue désormais de fonctionner sans couplage de téléchargement, et le relais signale un écart de suivi de téléchargement au lieu d'un non-trouvé générique (#19659 par @pavel-kalmykov).
  • Le partage d'une session dont les sous-agents signalent une progression plus rapide que les drains de la liaison montante ne se termine plus par "Le retard d'envoi de la collaboration a dépassé sa limite" lorsqu'un invité rejoint
  • Correction des itérations /loop et des continuations /goal se déclenchant environ 800 ms après un tour, ce qui permettait d'attendre des sous-agents ou des tâches en arrière-plan ; ils attendent maintenant la fin de l'exécution (#19781)
  • Correction de la recherche Web Codex et OpenAI API ignorant le niveau de réflexion du rôle web (openai-codex/gpt-6-luna:xhigh) ; le niveau atteint maintenant la demande sous la forme reasoning.effort (#19793)
  • Correction de l'examen du plan mesurant « Approuver et conserver le contexte » par rapport au modèle pré-plan au lieu du niveau choisi dans le curseur « Continuer avec », donc le passage à un niveau à contexte plus large le permet désormais (#19660)

oh-my-pi v19.0.1

@oh-my-pi/pi-ai

Fixed

  • Fixed GIF images failing Liquid AI judgments with HTTP 422; they are now sent as PNG (#19757 by @alphastorm)
  • Anthropic strict-tool fallback now treats a Vertex org-policy rejection of structured_outputs (allowedPartnerModelFeatures / "disallowed feature structured_outputs") as a strict-tools rejection, retries once without strict, and pins strictToolsDisabled (#19576) (#19655 by @koeria)
  • Kiro requests rejected with Input is too long. or CONTENT_LENGTH_EXCEEDS_THRESHOLD can now recover through conversation compaction (#19723 by @emotionbug)
  • Kiro thinking off now turns reasoning off instead of running the model's default effort; models that cannot disable reasoning use their lowest effort (#19722 by @emotionbug)
  • Kiro /usage shows purchased add-on credits, and an account whose plan credits are spent keeps serving while add-on credits remain (#19724 by @emotionbug)
  • Kiro Identity Center logins in AWS GovCloud (US) now list profiles in us-gov-west-1 and us-gov-east-1 instead of the commercial regions, which reject GovCloud tokens (#19726 by @TechDufus)
  • Statusless gateway errors reading stream interrupted now retry like stream was interrupted instead of ending the turn (#19709).

@oh-my-pi/browser-relay

Fixed

  • The browser relay extension survives a browser whose loaded permission set predates the downloads permission: the service worker keeps working without download pairing instead of crashing before it ever connects (#19659 by @pavel-kalmykov)

@oh-my-pi/pi-catalog

Added

  • Added Liquid AI's d1.2 and d1.2-ultra judge models; liquid now defaults to d1.2 (#19753 by @alphastorm)
  • Added gemini-4-neon to the bundled Antigravity CLI roster, with the low/medium/high/xhigh thought levels agy offers for it (#19787 by @ataberkus).
  • Model.snapcompactShape ({ variant, frameSize? }) gives a model its own snapcompact frame shape (#19591 by @ryanskidmore)

Fixed

  • Discovered Kiro models that cannot turn reasoning off now use their lowest supported effort when thinking is set to off (#19722 by @emotionbug)
  • Kiro accepts AWS GovCloud (US) profile ARNs (arn:aws-us-gov:codewhisperer:…), which were previously skipped during profile listing (#19726 by @TechDufus)
  • Google Antigravity no longer lists Gemini 4 Hydrogen's sonar monitor slot or its tiered High/XHigh SKUs as separate models; the tiered SKUs fold into the one Gemini 4 Hydrogen model (#19795 by @eggpeat)
  • Gemini 4 Neon on Google Antigravity now shows as one model whose thinking level (low, medium, high, xhigh) selects the matching SKU, instead of four separate models, and is priced at $3/$15 per million tokens ($0.15 cached) instead of $0 (#19789 by @eggpeat)
  • Gemini 4 Neon now collapses into one model on Gemini CLI too, and on the Gemini API and Vertex AI offers the xhigh thinking level and long outputs up to 262,144 tokens, with its $3/$15 Gemini API price

@oh-my-pi/pi-coding-agent

Added

  • /session shows the path of the session's local:// directory, and /copy local copies it, creating the directory first so it can be entered before anything was written there (#19778 by @farnoy)
  • snapcompactShape on models.yml models, modelOverrides and extension registerProvider models sets that model's snapcompact frame shape (#19591 by @ryanskidmore)

Fixed

  • Fixed PTY command transcripts sometimes gaining a blank line where a \r\n line ending was split across two terminal reads.
  • Fixed the shell's dirname builtin on Windows ignoring \ separators and drive prefixes (dirname 'C:\a\b' printed .), which broke scripts like VS Code's code launcher (./Code.exe: No such file or directory)
  • Fixed bash output minimizing being skipped on Windows when a command is named by a \ path or with .exe ("C:\Program Files\Git\cmd\git.exe" status, git.exe log)
  • Fixed the bundled omp://tools docs still describing the removed ida tool; tools/dsm.md now documents eval's dsm namespace and disassembler.* settings, and tools/read.md documents metadata-only executable reads (#19608)
  • Fixed native terminal hosts such as Tern placing extension aboveEditor widgets and a blank row between the status row and the tray; the widgets now sit above the status row (#19767)
  • Fixed ^model mentions in queued messages (->/=> while the agent is busy, later items of a numbered list, RPC steer/follow_up, ACP steering) reaching the model as literal ^provider/model text instead of registering their m<N> agent (#19683 by @a-glapinski)
  • Fixed ^model mentions in extension messages sent with sendUserMessage({ deliverAs: "steer" | "followUp" | "aside" }) while the agent is busy reaching the model as literal text (#19799 by @H4vC)
  • Fixed every message queued behind an undelivered ^model mention repeating the "m<N> now available" notice to the model (#19799 by @H4vC)
  • A plugin manifest with a non-string extensions entry (e.g. an object) no longer crashes extension loading with ERR_INVALID_ARG_TYPE; the entry is reported as not found and valid entries still load (#19674 by @koeria)
  • Fixed embedded bash script.sh resolving BASH_SOURCE[0] to bash instead of the script path, which broke scripts loading files beside themselves (#19792)
  • Fixed proxy model discovery ignoring a gateway's advertised input modalities and output-token cap (#19754 by @zhyc9de).
  • Fixed a provider routed through an auth gateway (transport: pi-native in models.yml) still listing models from the provider's own endpoint, sending the gateway key there; such providers now skip the provider's model discovery and keep their bundled and cached models (#19646 by @ray8828)
  • Fixed a spurious "cache miss" marker on the first turn after a compaction: compaction rewrites the prompt prefix, so that miss is expected and no longer flagged (#19679 by @Petyok)
  • Fixed omp --resume <id> under --mode rpc, --mode rpc-ui and --mode acp failing at start when the session's directory no longer exists; the session now opens where it is stored, with the launch directory as its working directory, without asking whether to move it (#19651 by @sjawhar)
  • Fixed the browser relay extension dying silently in a browser whose loaded permission set predates the downloads permission: it now keeps working without download pairing, and the relay reports a download tracking gap instead of a generic not-found (#19659 by @pavel-kalmykov)
  • Sharing a session whose subagents report progress faster than the uplink drains no longer ends with "collab send backlog exceeded its limit" while a guest joins
  • Fixed /loop iterations and /goal continuations firing ~800ms after a turn yields to wait on background subagents or jobs; they now wait until the run finishes (#19781)
  • Fixed Codex and OpenAI API web search ignoring the web role's thinking level (openai-codex/gpt-6-luna:xhigh); the level now reaches the request as reasoning.effort (#19793)
  • Fixed plan review measuring "Approve and keep context" against the pre-plan model instead of the tier chosen in the "continue with" slider, so switching to a larger-context tier now enables it (#19660)

@oh-my-pi/pi-natives

Fixed

  • Fixed omp freezing for seconds to minutes on WSL2 while saving sessions: Linux FileLock now locks a sidecar file instead of binding a socket, which takes about 10 ms per call there. Older omp versions still running do not see these locks, so restart them after updating (#19704 by @turgaybulut)

@oh-my-pi/snapcompact

Added

  • resolveShape() uses a model's configured snapcompactShape in place of its model-line default; an explicit variant still wins and billing still follows the model (#19591 by @ryanskidmore)

@oh-my-pi/omp-stats

Added

  • Added 2d and 3d range presets with hourly buckets to the stats dashboard time selector (#19766, #19774 by @thekitaev).

@oh-my-pi/pi-tui

Added

  • The native session sheet shows a Local report line (the session's local:// directory) as a copyable field beside the ID and file (#19778 by @farnoy)

Fixed

  • Fixed images from a previous session reappearing at the top-left of the screen after /new in herdr-app (#19749 by @jaredlyon)
  • Loop-stall diagnostics (ui.loop-blocked) no longer sample the JS thread while no TUI runs, such as in an external editor or after the session ends (#19703 by @will-bogusz)
  • Fixed the usage dashboard rendering exhausted or pressured usage rows without a quota bar (prepaid balances, spent quotas) as dim informational text; they now take the error or warning color their reported status calls for, and a spent quota with no measurable amount reads "exhausted" instead of "no data" (#19764)
