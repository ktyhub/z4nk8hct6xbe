@oh-my-pi/pi-coding-agent

Modifications radicales

  • Les règles d'expression régulière secrets.yml sont désormais des modèles Rust regex exécutés de manière native, en temps linéaire : les lookarounds et les références arrière ne sont plus pris en charge, et un groupe (?P<secret>…) marque la partie à rédiger (le texte qui l'entoure est le contexte qui reste) ; \d, \w et \s sont compatibles Unicode. Une règle regex qui ne compile pas arrête le démarrage avec une erreur nommant le fichier et l'entrée au lieu d'être ignorée. Migrez (?<=password=)\S+ vers password=(?P<secret>\S+) ; voir docs/secrets.md (#18965 par @H4vC)
  • Les espaces réservés secrets sont désormais constitués de quatre mots en chameau après le nom convivial, par ex. GitHubToken_correctHorseStapleBattery, sans délimiteurs $$, et la transcription montre la valeur réelle partout où le modèle en a écrit une. Les espaces réservés dans l'ancien formulaire $$NAME_HASH:CASE$$, dans les sessions enregistrées avant cette modification, restent du texte littéral, y compris dans les appels d'outils dans lesquels le modèle les copie ; démarrer une nouvelle session pour obtenir des espaces réservés de travail (#19014 par @H4vC)
  • Ce que le modèle écrit à partir des espaces réservés (réponses, réflexions, appels d'outils, résumés) est stocké sous forme écrite et rejouée à l'identique, gardant les signatures de réflexion et les caches d'invite valides ; La sortie du modèle qui contient toujours une valeur (écrite alors que la rédaction était désactivée ou avant la configuration du secret) est rédigée lors de la relecture. Les valeurs qu'une règle regex trouve plus tard ne réécrivent plus l'historique antérieur. Un friendlyName est montré au modèle tel qu'écrit et n'est supprimé que lorsqu'il énonce son propre secret (#19014 par @H4vC).
  • Les builds Nix avec withAppleFm = false ne compilent plus le pont Apple Foundation Models avec le Xcode de l'hôte (#18911)
  • Les builds Apple Silicon Nix incluent la prise en charge des Apple Foundation Models au lieu de se construire silencieusement sans cela (#16584 par @honsunrise)
  • ask sur les hôtes RPC sans boîte de dialogue de formulaire affiche désormais chaque invite avec les paragraphes, listes, blocs préformatés et tableaux entourant le formulaire au lieu de seulement la question (#18927).

Modifié

  • Suppression de l'invite système par défaut : les règles de choix d'outils pointent désormais uniquement vers read, edit et find ; le format de raisonnement, l'AST et les limites de sous-agents ont disparu (ast_edit/ast_grep indiquent leur préférence dans leurs propres résumés) ; le workflow, la livraison et les règles critiques sont plus courts et ne se répètent plus ; La note de Spotlight sur la façon dont les résultats des outils sont façonnés est une courte liste sous Tool I/O au lieu d'un paragraphe à la fin ; et xd:// les appareils sont répertoriés par leur nom nu
  • edit.modelVariants sélectionne désormais le modèle de modèle correspondant le plus long au lieu du premier, donc une clé spécifique comme openai/gpt-5 l'emporte sur gpt quel que soit l'ordre de configuration (#17835 par @DeprecatedLuke)
  • Les onglets du navigateur s'ouvrent dans le moteur WebKit sans tête d'omp au lieu de Chromium géré lorsque le moteur, ABKit, est installé (~/.o2/lib/abkit/ABHost, ABHost.exe sous Windows, l'emplacement que Tern utilise également ; ou le paramètre browser.webkitPath / PI_BROWSER_WEBKIT_PATH) : les pages voient une fenêtre visible et ciblée sans indicateur d'automatisation, et un onglet par défaut n'exécute aucun script omp dans la page (la console, les erreurs et le journal des requêtes proviennent du moteur ; route, géolocalisation/localisation/émulation hors ligne, vitals et reactEnable ajoutent le code de page uniquement lorsqu'ils sont appelés ; les corps de réponse n'y sont pas disponibles). Chromium ouvre toujours les onglets headed où le moteur n'envoie aucun visualiseur et prend le relais, expliquant pourquoi, lorsque le moteur ne peut pas démarrer ; app: "chromium" sélectionne Chromium pour une ouverture et app: "webkit" nécessite WebKit (avec headed: true, son onglet s'ouvre dans une fenêtre), et le paramètre browser.webkit ou PI_BROWSER_WEBKIT=0 le désactive. Sur macOS, le moteur comprend WebGL, WebGPU, la lecture vidéo et audio silencieuse, Web Audio, WebRTC, WebAuthn, des manettes de jeu et Web Share, et sa poignée de main TLS, ses paramètres HTTP/2 et ses en-têtes de requête sont ceux envoyés par Safari.
  • omp télécharge son moteur WebKit, ABKit, depuis build.stencil.so dans ~/.o2/lib/abkit (vérifié par rapport au SHA-256 de la build) pour app: "webkit" lorsqu'il est manquant, et avant Chrome pour les tests lorsqu'un open ne trouve aucun navigateur installé ; un téléchargement échoué laisse cela ouvert sur Chromium et explique pourquoi
  • La description de l'outil task répertorie désormais uniquement les règles de livraison (livraison automatique des résultats, wait, completed non vérifié) ; les références read proc://, write proc://<id>/kill, expiration du travail et write agent:// arrivent avec le premier résultat de génération de la session
  • Les documents sur les paramètres ask.timeout, README et RPC décrivent désormais l'outil ask comme un formulaire HTML qui soumet ses valeurs actuelles à l'expiration du délai, et non comme un sélecteur de questions qui sélectionne automatiquement une option.
  • La description de l'outil bash répertorie à nouveau les fonctions intégrées en cours du shell intégré, directement à partir du shell, de sorte qu'il suit chaque commutateur PI_DISABLE_* et la plate-forme
  • Les sélecteurs de read pour SQLite, les archives, les requêtes JSON, les exécutables, la vidéo et SVG, ainsi que la grammaire des sous-chemins de proc://, ssh:// et issue:///pr://, ne sont plus livrés avec chaque requête : le modèle les lit à la demande sur xd://read/sources et xd://read/urls, et ils restent en ligne lorsque read est éteint
  • /browser visible et /browser headless affichent et masquent désormais les fenêtres des onglets WebKit d'omp en même temps au lieu d'attendre la prochaine ouverture : là où le moteur livre sa visionneuse (macOS), chaque onglet obtient sa propre fenêtre que l'utilisateur peut également click, faire défiler et saisir, et headed: true ou browser.headless off conserve un onglet sur WebKit avec une fenêtre au lieu de l'envoyer à Chromium.   • Le texte d'une capture d'écran de navigateur est constitué d'une seule ligne (la taille vue par le modèle, la taille réelle du fichier lorsqu'il a été conservé et le facteur de coordonnées pour tab.clickAt) au lieu de quatre lignes avec des tailles et des formats en octets, et browser.open indique l'onglet, la page sur laquelle il a atterri lorsqu'il ne s'agit pas de l'URL demandée (en utilisant la comparaison d'URL normalisée de navigation) et le titre sur une seule ligne (#18776 par @will-bogusz)

  • Chaque serveur de langue confie désormais la surveillance des fichiers à omp (il s'agissait uniquement de TypeScript 7) ; définir watchFiles: false sur un serveur pour conserver son propre observateur
  • Une cellule JavaScript Eval défaillante imprime le message d'erreur et les propres images de la cellule, avec une ligne comptant les images cachées du runtime d'omp, de ses dépendances et du moteur, au lieu de la pile hôte complète ; les cadres de dépendance locaux du projet restent visibles, les piles mises en cache dont les en-têtes ne correspondent plus à l'erreur restent intactes, les rejets flottants conservent leur message actuel et leur indice d'attente manquant même avec une pile mise en cache, et print(e.stack) dans un catch affiche toujours chaque image (#18775 par @will-bogusz)
  • Le compactage Snapcompact résout la forme du cadre une fois lors de son contrôle en amont et la transmet à compact(), qui l'a redérivée avec le paramètre de forme auto ; le contrôle en amont analyse la transcription une fois au lieu de deux, s'exécute comme phase de boucle compaction.snapcompact et cède la place à la boucle d'événement avant le rendu (#15689, #18867 par @wolfiesch)

@oh-my-pi/pi-agent-core

Changed

@oh-my-pi/pi-ai

Added

  • Added the google-decisions judgment API for Google's Gemini Decisions API (gemini-decision-1), with text and image input (#19060 by @kevcube)
  • Added apiKey to successful OAuthAccessResolution results from oauth.accessById() and oauth.accessAll(): the key normal requests send for that account, which differs from accessToken for providers with structured credentials (#19030 by @Xytronix)
  • Added an optional exemptionAlias to ToolCallLoopGuard so transport calls can match the dispatched tool's name in exemptTools (#18860)

  • Added the nace-systemone judgment API for Nace's Drex decision models, which sends images as Drex's top-level images data URLs and replaces the base64 image, audio, video and PDF data URLs that Drex rejects in judged text with a description (#18950 by @alphastorm)

Fixed

  • Fixed a spent Codex account retrying every minute for days when its siblings were only refused the requested model: their short model-policy blocks no longer count as a sibling becoming available, so the usage-limit wait follows the spent account's reset and model fallback can take over (#17637, #19019 by @wolfiesch)
  • Auth-gateway client tokens (serve --clients) can no longer set who a request is from, who pays, or how the gateway reaches the provider: chat routes drop their request headers, userProfileId, initiatorOverride, metadata, serviceTier, cacheRetention and the other gateway-only options, while the gateway token keeps them (#19067 by @alphastorm)
  • Fixed the auth gateway's /v1/pi/stream dropping taskBudget, include and anthropicPrefixMismatchBehavior, which its other chat routes accept (#19067 by @alphastorm)
  • Fixed requests to Vertex AI Mistral partner models (mistral-medium-3, mistral-small-2503, codestral-2) failing because they were sent in Anthropic's request format (#19010, #19022 by @yuzu-octopus)
  • Added Gemini's xhigh thinking level, sent on the Gemini API and Vertex for models whose ladder exposes it (Gemini 4 Hydrogen).
  • Fixed omp failing to start with ENOTDIR: not a directory, stat '~/.aws/credentials' when ~/.aws is a file instead of a directory (#19083 by @iamshatter)

@oh-my-pi/pi-coding-agent

Breaking Changes

  • secrets.yml regex rules are now Rust regex patterns run natively, in linear time: lookarounds and backreferences are no longer supported, and a (?P<secret>…) group marks the part to redact (text around it is context that stays); \d, \w and \s are Unicode-aware. A regex rule that does not compile stops startup with an error naming the file and entry instead of being skipped. Migrate (?<=password=)\S+ to password=(?P<secret>\S+); see docs/secrets.md (#18965 by @H4vC)
  • Secret placeholders are now four camelCased words after the friendly name, e.g. GitHubToken_correctHorseStapleBattery, with no $$ delimiters, and the transcript shows the real value wherever the model wrote one. Placeholders in the old $$NAME_HASH:CASE$$ form, in sessions saved before this change, stay literal text, including in tool calls the model copies them into; start a new session to get working placeholders (#19014 by @H4vC)
  • What the model writes from placeholders (replies, thinking, tool calls, summaries) is stored as written and replayed byte-identical, keeping thinking signatures and prompt caches valid; model output that still holds a value (written while redaction was off, or before the secret was configured) is redacted on replay. Values a regex rule finds later no longer rewrite earlier history. A friendlyName is shown to the model as written and is dropped only when it spells out its own secret (#19014 by @H4vC)
  • Nix builds with withAppleFm = false no longer compile the Apple Foundation Models bridge with the host's Xcode (#18911)
  • Apple Silicon Nix builds include Apple Foundation Models support instead of silently building without it (#16584 by @honsunrise)
  • ask over RPC hosts without a form dialog now shows each prompt with the form's surrounding paragraphs, lists, preformatted blocks and tables instead of only the question (#18927)

Added

  • Added the Gemini Decision 1 judge (google/gemini-decision-1) for the judge role, and models.yml accepts the google-decisions API (#19060 by @kevcube)
  • ssh:// host listing, ssh:// autocomplete and /ssh list now include the Host aliases from ~/.ssh/config and /etc/ssh/ssh_config (following Include); ssh.json entries win on a name clash
  • Added find.verifyModel, a model selector whose judge answers only find's passage verification while filename and sketch ranking stay on the judge role (#19006 by @alphastorm)
  • Added omp bench --account to benchmark a specific stored OAuth account, and report rejected priority requests instead of silently benchmarking standard speed.
  • Text a browser or computer call types into a page or app, such as a password, no longer appears in plain text in an eval cell's status lines or the session file (#18981 by @will-bogusz)
  • Browser page-script observations in Tern and WebKit now mask password values, including values used as accessible names or descriptions (#18983 by @will-bogusz)
