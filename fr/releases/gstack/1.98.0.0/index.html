#gstack v1.98.0.0

gstack v1.98.0.0

Les nouvelles installations suivent désormais la version stable testée, deux compétences peu utilisées sont retirées et plusieurs services locaux ainsi que le couplage à distance du navigateur sont verrouillés.

Quoi de neuf

  • Un nouveau git clone plus ./setup suit désormais le canal stable, afin que les nouveaux utilisateurs obtiennent la version testée au lieu de chaque modification sur le canal principal ; les installations existantes et les extractions des contributeurs continuent de suivre main, et le programme d'installation imprime la commande pour basculer. Sur Capy, gstack se met désormais à jour avec la dernière version principale au moins une fois par jour, sauf si vous l'épinglez avec une raison #4091.
  • /autoplan a une porte d'adhésion (./setup --autoplan-gate ou gstack-config set autoplan_gate on) qui empêche la session de se terminer jusqu'à ce que chaque phase de planification ait publié son rapport et que l'étape d'approbation finale soit écrite [#4100] (https://github.com/garrytan/gstack/pull/4100).
  • /plan-eng-review n'est plus installé, car deux évaluations ont trouvé qu'il n'ajoutait rien par rapport à l'Opus 5.5 standard ; /autoplan exécute toujours sa phase de révision technique, et le prochain ./setup supprime l'ancienne entrée mais laisse seule une compétence que vous avez écrite sous ce nom #4108.
  • /investigate n'est plus installé, après une évaluation de 18 corrections de bugs réels, aucun gain n'en a été trouvé ; le ./setup suivant supprime l'ancienne entrée de la même manière #4110.

Correctifs

  • Sur Capy, une vérification d'installation de gstack qui s'exécute au milieu d'un /ship ou d'un examen ouvert ne met plus à niveau gstack en dessous, et le chemin de mise à niveau fonctionne désormais sans le binaire flock #4095.
  • La grille /plan-ceo-review ne juge plus une séance avant que Claude Code ait fini d'écrire sa transcription, donc une révision terminée n'est plus retenue par erreur #4102.
  • Le contrôle qui maintient la session d'une compétence jusqu'à ce que les étapes requises soient effectuées attend désormais également que Claude Code ait fini d'écrire la transcription, donc une exécution terminée n'est plus bloquée par erreur #4104.
  • Les attentes de gstack sur les demandes d'extraction vérifient désormais GitHub au plus une fois par minute et attendent les limites de taux, afin qu'elles cessent d'utiliser le quota partagé GitHub API [#4109] (https://github.com/garrytan/gstack/pull/4109).
  • /ship traite désormais l'interface utilisateur écrite sous forme de modèles Lit ou htm dans un fichier .ts ou .js comme interface, de sorte que ces modifications obtiennent la vérification de la conception au lieu de l'ignorer silencieusement #4112.
  • /autoplan reconnaît désormais la même interface utilisateur des modèles Lit et htm et des mots comme ligne, sélecteur et menu, de sorte que ces plans obtiennent une phase de conception, et une exécution rapide ne dit plus qu'il a fusionné une phase de conception qu'il a ignorée [#4121] (https://github.com/garrytan/gstack/pull/4121).
  • /make-pdf lit les images locales uniquement à partir du propre dossier du document et uniquement des fichiers d'images réels ; tout le reste s'affiche sous la forme d'un espace réservé visible "image bloquée" #4113.
  • Via le tunnel /pair-agent, un agent distant ne peut désormais ouvrir que des pages Web : il ne peut pas lire les fichiers locaux, choisir un chemin sur votre disque, ni faire en sorte que le navigateur y enregistre des captures d'écran #4116.
  • Le comité de conception et les services d'arrière-plan iOS QA répondent désormais uniquement aux demandes locales qui leur sont directement adressées, et les liens du comité de conception incluent désormais un secret privé dans l'URL [#4117] (https://github.com/garrytan/gstack/pull/4117).
  • /setup-gbrain ne transmet plus l'URL de votre base de données gbrain, qui contient son mot de passe, sur la ligne de commande où d'autres utilisateurs locaux pourraient le voir, et la vérification de rédaction de gstack détecte désormais davantage de types d'informations d'identification #4114.
  • L'installateur Capy ne charge plus le bunfig.toml ou le .env de votre projet pendant qu'il lit les versions Bun et Node du projet #4115.

Modifications pour les responsables

  • La comptabilité des révisions de /ship a reçu plusieurs correctifs : les révisions de suivi et les tours supplémentaires accordés par le propriétaire comptent désormais correctement, les modifications de version et de documents après une révision ne forcent plus un autre tour, un enregistrement de révision refusé indique désormais de quel commit il provient, et une conclusion de réviseur qui s'ouvre avec "Finding 1" conserve sa propre gravité #4089 #4093 #4096 #4099 #4101 #4106.
  • Une exécution de /ship transmise à un nouveau thread conserve un budget de dépenses, et un résultat CI effacé par la vérification à distance satisfait désormais à l'étape de test locale de /ship pour cet arbre exact #4088 #4098.
  • Les appareils de test ne font plus penser à /ship qu'un critique a été récupéré sur le réseau, et les tests du canal de mise à jour ne peuvent plus écrire la véritable configuration gstack d'un développeur #4105 #4094.
  • Les requêtes pull de thread d'agent indiquent désormais si elles ont eu leur étape de planification, et un dépôt peut l'exiger avant la fusion #4118.
  • Trois bugs de l'outil /ship sont corrigés : la répartition de la révision du deuxième modèle correspond au plan de révision, et les résultats de la vérification avant la fusion survivent à une réexécution de test uniquement et à une branche de base déplacée #4124.
  • Les points et les cibles de harnais génériques n'enregistrent plus le retrait /plan-eng-review, et ses anciens cas de tests payants ont chacun un destin enregistré #4111. Comparez v1.97.0.0...v1.98.0.0 · changelog complet

gstack v1.98.0.0

gstack v1.98.0.0

New installs now follow the tested stable release, two little-used skills are retired, and several local services and the browser's remote pairing are locked down.

What's new

  • A fresh git clone plus ./setup now follows the stable channel, so new users get the tested release instead of every change on main; existing installs and contributor checkouts keep following main, and setup prints the command to switch. On Capy, gstack now updates itself to the latest main at least once a day unless you pin it with a reason #4091.
  • /autoplan has an opt-in gate (./setup --autoplan-gate, or gstack-config set autoplan_gate on) that keeps the session from ending until every planning phase has published its report and the final approval step is written #4100.
  • /plan-eng-review is no longer installed, because two evals found it added nothing over plain Opus 5.5; /autoplan still runs its engineering review phase, and the next ./setup removes the old entry but leaves a skill you wrote under that name alone #4108.
  • /investigate is no longer installed, after an eval on 18 real bug fixes found no gain from it; the next ./setup removes the old entry the same way #4110.

Fixes

  • On Capy, a gstack install check that runs in the middle of an open /ship or review no longer upgrades gstack underneath it, and the upgrade path now works without the flock binary #4095.
  • The /plan-ceo-review gate no longer judges a session before Claude Code has finished writing its transcript, so a finished review is no longer held by mistake #4102.
  • The check that holds a skill's session until its required steps are done now also waits for Claude Code to finish writing the transcript, so a finished run is no longer blocked by mistake #4104.
  • gstack's waits on pull requests now check GitHub at most once a minute and wait out rate limits, so they stop using up the shared GitHub API quota #4109.
  • /ship now treats UI written as Lit or htm templates inside a .ts or .js file as frontend, so those changes get the design check instead of skipping it silently #4112.
  • /autoplan now recognizes the same Lit and htm template UI and words like row, picker and menu, so those plans get a Design phase, and a quick run no longer says it merged a Design phase it skipped #4121.
  • /make-pdf reads local images only from the document's own folder and only real image files; anything else renders as a visible "image blocked" placeholder #4113.
  • Over the /pair-agent tunnel, a remote agent can now only open web pages: it can't read local files, pick a path on your disk, or make the browser save screenshots there #4116.
  • The design board and iOS QA background services now answer only local requests made directly to them, and design board links now include a private secret in the URL #4117.
  • /setup-gbrain no longer passes your gbrain database URL, which holds its password, on the command line where other local users could see it, and gstack's redaction check now catches more kinds of credentials #4114.
  • The Capy installer no longer loads your project's bunfig.toml or .env while it reads the project's Bun and Node versions #4115.

Changes for maintainers

  • /ship's review bookkeeping got several fixes: follow-up reviews and owner-granted extra rounds now count correctly, version and docs edits after a review no longer force another round, a refused review record now says which commit it came from, and a reviewer finding that opens with "Finding 1" keeps its own severity #4089 #4093 #4096 #4099 #4101 #4106.
  • A /ship run handed to a new thread keeps one spending budget, and a CI result cleared by the remote check now satisfies /ship's local test step for that exact tree #4088 #4098.
  • Test fixtures no longer make /ship think a reviewer fetched from the network, and the update-channel tests can no longer write a developer's real gstack config #4105 #4094.
  • Agent-thread pull requests now show whether they had their planning step, and a repo can require it before merge #4118.
  • Three /ship tooling bugs are fixed: the second-model review dispatch matches the review plan, and pre-merge check results survive a test-only rerun and a moved base branch #4124.
  • The dots and generic harness targets no longer register the retired /plan-eng-review, and its old paid test cases each have a recorded fate #4111.
