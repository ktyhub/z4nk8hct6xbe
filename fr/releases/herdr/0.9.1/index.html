herdr v0.9.1

Correctif Publié16 sept. 2026 Sourceherdrdev/herdr Anglais original

Cette page est traduite automatiquement. Le texte anglais original fait foi.

troupeau v0.9.1

Ajouté

  • Contrôlez les agents, les volets, les espaces de travail et les arbres de travail sur les machines SSH enregistrées avec herdr --machine <label-or-id>. Les commandes utilisent la session enregistrée de la machine sans avoir besoin d'une fenêtre Herdr ouverte. Mettez à jour Herdr sur les deux machines pour utiliser le transfert CLI ; les commandes à distance ayant échoué ne reviennent jamais à Local. (#3918)
  • Connectez-vous aux hôtes Windows SSH depuis Linux, macOS ou Windows. L'installation interactive peut installer ou mettre à jour le package Windows complet après confirmation ; les reconnexions en arrière-plan n'installent jamais de mises à jour. (#3651, #3701, #3661, #3687, merci @JJLiebig)
  • Modifiez les noms, les filtres et recherchez le texte au niveau du curseur plutôt qu'à la fin. Les entrées Herdr prennent désormais en charge le mouvement des caractères et des mots, Début/Fin, la suppression et les raccourcis Ctrl+A/E/K/U/W/Y familiers, y compris le texte Unicode. (#1803, #3698, merci @markjaquith)
  • Ajout de la détection Letta Code et de la restauration native des conversations, y compris les conversations par défaut. Son intégration expérimentale est installée via herdr integration install letta, et non via la liste d'intégration des paramètres ou l'intégration JSON API. (#3106, #3107, merci @just-cameron)
  • Maintenez Ctrl sur un lien pour le mettre en surbrillance avant de l'ouvrir. Les URL enveloppées et les liens OSC 8 restent clickable même lorsque leur début ou leur fin se trouve en dehors de la fenêtre d'affichage. (#1282)
  • Les règles des jetons de la barre latérale peuvent désormais masquer les jetons correspondants et leurs séparateurs avec hide = true ; les lignes disparaissent lorsqu'il ne reste plus de jetons. (#3925)

Modifié

  • La navigation au clavier de l'espace de travail couvre désormais les machines connectées dans l'ordre de la barre latérale, avec une surbrillance visible avant que Entrée ne change de machine. Les groupes de machines et d'arbres de travail réduits restent navigables sans envoyer accidentellement d'actions à la mauvaise machine. (#3754)
  • Le transfert expérimental en direct peut désormais transférer plus de 64 volets lorsque le serveur d'envoi inclut cette mise à jour. Un serveur en cours d'exécution plus ancien a toujours son ancienne limite pour la première mise à niveau ; cela ne modifie pas l’ordre d’installation des mises à jour et ne rend pas le transfert en direct non expérimental. (#3393, #3411, merci @kataokatsuki)
  • Sous Linux et macOS, les observateurs de terminal qui cessent d'accepter la sortie sont déconnectés après 30 secondes sans progression de l'écriture. Leur volet et les autres clients continuent de fonctionner ; un flux interrompu peut se terminer sans un enregistrement final de clôture. (#3612)
  • Le nettoyage du terminal Windows réinitialise désormais explicitement les modes de rapport de la souris. Le rapport de détachement Git Bash autonome restant dans le numéro 3748 fait toujours l'objet d'une enquête ; ne considérez pas cette version comme un correctif confirmé pour ce rapport. (#4055, merci @JJLiebig)

Corrigé

  • La saisie à distance, la commutation et l'interaction contextuelle ne renvoient plus l'intégralité de l'écran du volet pour de petites modifications. Les sessions SSH occupées utilisent moins de bande passante et les clients connectés inactifs évitent les travaux de redessinage inutiles. (#3769, #3745, #3822)
  • Une machine SSH bloquée n'éloigne plus le client du Local. CliLe fait de cliquer sur un espace de travail ou un agent local annule le commutateur distant inachevé et un espace de travail distant récupéré s'actualise sans sélection aller-retour. Les écrans obsolètes d’avant une reconnexion ne sont pas réutilisés. (#3903, #3842)
  • Les connexions SSH inactives utilisent moins de CPU sans perdre la sortie finale. Les échecs de connexion répétés s'annulent au lieu de reconnecter rapidly, et les ponts inactifs pris en charge sont nettoyés sans arrêter les volets distants. (#3728, #4083)
  • Les grosses pâtes ne déconnectent plus le client avec une erreur de file d'attente de sortie. (#3833)
  • La configuration SSH affiche désormais les instructions d'authentification et les erreurs utiles, y compris les URL de connexion Tailscale et les échecs de clé d'hôte, plutôt que de sembler se bloquer ou de signaler uniquement une connexion perdue. machine add accepte également les options avant la cible SSH. (#3606, #3731, #3883)
  • Les groupes de machines et d'arbres de travail se réduisent correctement sans modifier l'espace de travail sélectionné. La barre latérale respecte les espaces entre les lignes de l'espace de travail, reste stable pendant le redimensionnement et révèle les espaces de travail nouvellement ciblés. (#3778, #3738, #3817)
  • La liste des agents conserve sa position de défilement lors des changements de machine. Les filtres de l'espace de travail actuel et de l'onglet actuel distinguent les ID identiques sur différentes machines. (#3937, #4101, #3732, merci @minatoaquaMK2)
  • L'activation de la machine en arrière-plan ne redimensionne plus le volet ciblé d'un autre client. Les titres des fenêtres suivent la vue de chaque client plutôt que la sélection d'un autre client. (#3744, #4091, #4130, merci @JJLiebig)
  • agent focus et pane move --focus déplacent désormais les clients attachés vers le volet demandé. Se déplacer sans focus ne laisse plus un client suite à un onglet supprimé ou à des changements de focus ultérieurs sans rapport. (#3760, #4153, #4171, merci @minatoaquaMK2)
  • La création d'un arbre de travail concentre à nouveau son nouvel espace de travail. Les suppressions d'arbres de travail ayant partiellement échoué peuvent être réessayées, et les arbres de travail avec des sous-modules offrent un choix explicite de suppression forcée plutôt que d'échouer sans action de récupération. (#3766, #3314, #1797)
  • Les bannières d'erreur temporaires d'action d'arbre de travail expirent au lieu de rester indéfiniment à l'écran. (#1827, #4063, merci @JJLiebig)
  • Le dernier onglet reste entièrement visible lorsque la bande d'onglets déborde, et le navigateur de session dessine à nouveau les branches d'arbre connectées. (#4151, #3843)
  • Les étiquettes de la barre latérale et des onglets masquées restent lisibles sur les thèmes sombres, y compris le terminal Windows. (#2692, #4062, merci @JJLiebig)
  • Les sélections du mode glisser et copier de la souris restent actives pendant que la sortie se poursuit, même lorsqu'une partie de la sélection se trouve en dehors de la fenêtre. La copie utilise le texte actuel dans la plage sélectionnée. La repeinture de la sélection évite également de créer un retard dans les mouvements de la souris. (#3841, #3895)
  • Les sélections Double-click restent visibles avec la copie automatique désactivée. Maintenir le deuxième click et le faire glisser s'étend par mots entiers, et la sélection de jetons s'arrête à la ponctuation CJK. Les couleurs de sélection d'hôte restent visibles sur les fonds transparents. (#3847, #1836, #3706, #3798)
  • Le défilement ne combine plus d'instantanés de terminal incompatibles ou ne laisse plus de lignes obsolètes dans les applications plein écran telles que Neovim. Les lectures de l'historique sur écran alternatif préservent le contenu dans les en-têtes et les barres de défilement changeants. (#3900, #3329, #3979)
  • Les graphismes Local Kitty conservent leur transport direct après la première image. Les fenêtres contextuelles et les notifications masquent uniquement les emplacements d'images qui se chevauchent ; les images découvertes restent visibles. (#3785, #4081)
  • Les coordonnées de la souris pixel fonctionnent indépendamment du rendu de l'image et utilisent la taille de cellule entière du terminal, empêchant les clicks de dériver sur l'écran. (#3295, #4140, merci @JJLiebig)
  • Les touches de fonction F1 à F12 sont reconnues dans les rapports du clavier Kitty, et F1 à F4 fonctionnent également avec les rapports paramétrés provenant de terminaux tels que le pied. (#1809, #2378, #4067, merci @ashokDevs et @JJLiebig)
  • Les rapports avec touches de contrôle WezTerm conservent désormais Entrée, Retour arrière, Tabulation et Échap. L’entrée Cmd/Super-modified atteint les applications du volet avec son modificateur intact. La saisie modifiée reste compatible avec les volets qui n'ont pas demandé un codage de clé amélioré. (#3589, #3710, #4103, #4110, merci @minatoaquaMK2)
  • Les rapports de souris répartis sur des lectures retardées ne divulguent plus leurs octets de fin dans l'entrée du volet. Les Clients réaffirment les rapports de la souris après la reconnexion du terminal. (#3911, #4079, merci @JJLiebig)
  • Les sessions enregistrées qui ne peuvent pas être chargées sont conservées avant leur remplacement, plutôt que écrasées silencieusement. Les copies de récupération sont conservées dans session-backups/ ; une préservation ratée laisse l’original intact. (#4125)
  • La suppression d'une session nécessite désormais son nom exact, y compris la casse, sur les systèmes de fichiers insensibles à la casse. Les noms commençant par un trait d'union peuvent être passés après --. (#3819, #4233, #3220, merci @minatoaquaMK2)
  • Les serveurs macOS nouvellement démarrés conservent l'accès à la recherche d'utilisateurs et au DNS lors de la déconnexion. Les serveurs concernés existants nécessitent un redémarrage complet de la session ; le transfert en direct ne peut pas réparer leur contexte de service hérité. (#4100)
  • La découverte des processus Linux reste réactive face aux agents WSL bloqués et évite d'analyser à plusieurs reprises une arborescence de processus en constante évolution. (#2179, #3621, #3674, merci @dark2momo et @caner-akca)
  • Les notifications du bureau Linux identifient Herdr comme source. (#3638)
  • pane split sans cible divise désormais le volet appelant lorsqu'il est invoqué dans Herdr, plutôt que dans le volet ciblé d'un autre client. Les cibles explicites conservent leur comportement existant. (#4123)
  • Les noms d'agents actifs survivent à l'incertitude temporaire de détection des processus au lieu de laisser un agent actif inaccessible par son nom. (#3225, #3574, merci @caner-akca)
  • Les invites du Codex Windows sont soumises de manière fiable après le texte collé au lieu de perdre Entrée, y compris les invites longues. (#3187, #3961, merci @JJLiebig)
  • OpenCode V2 signale l'état du cycle de vie à partir du volet affichant la conversation, afin que les serveurs partagés ne mélangent pas les volets. Les tours terminés et interrompus reviennent au repos, tandis que les autorisations en attente, les formulaires et les exécutions échouées restent bloqués. La V1 reste prise en charge ; redémarrez OpenCode après avoir installé l'intégration mise à jour. (#3757, merci @markjaquith)
  • Le Codex continue de fonctionner avec des titres statiques, des animations désactivées et des suivis en file d'attente. Les scintillements du compositeur et l'ancien texte de confirmation ne font plus apparaître un volet inactif bloqué. (#4092, #4099, #3988, merci @minatoaquaMK2)
  • Le spinner d'activité Unicode de Claude Code et la bordure de travail de Pi sont reconnus correctement. La détection du lanceur Cline et les rapports d'état d'inactivité sont plus fiables. (#3949, #3629, #2396)
  • Pi enregistre les chemins de session natifs sous Windows. Les processus OMP imbriqués ne remplacent plus la session avec reprise du volet parent et les cales Windows Kimi npm sont reconnues. (#3726, #2593, #3994, #3317, #4053, merci @JJLiebig)
  • Grok met à jour sa référence de restauration après /new, et ses hooks compatibles Claude importés n'écrasent plus cette référence. Réinstallez l'intégration Claude pour adopter la correspondance de crochets plus étroite. (#2681, #4018)
  • Les mises à jour de configuration d'intégration préservent les fichiers existants en cas d'échec des écritures. L'installation d'Hermes préserve également le YAML valide lorsque les plugins activés utilisent une liste en ligne. (#3970, #3839, #4056, merci @JJLiebig)
  • Les écritures du registre des plugins préservent les liens symboliques. Les plugins continuent d'utiliser le binaire compatible du serveur en cours d'exécution après une mise à jour de client uniquement, et la navigation manuelle dans le volet émet à nouveau des événements de focus. (#3922, #3824, #4077)
  • Les fichiers de configuration contenant une nomenclature UTF-8 sont chargés et enregistrés correctement. La configuration par défaut place ui.accent dans le tableau de droite. (#3678, #3962, #2697, merci @JJLiebig)
  • Les entrées Windows locales et SSH préservent les combinaisons Alt, Ctrl+S et le texte du clavier amélioré au lieu de supprimer des touches ou d'insérer des déchets. La saisie à distance par touche morte n'ajoute plus de caractère de base supplémentaire. (#3702, #3910, #3932, #3948, #4133, #4148, merci @JJLiebig)
  • La capture de la souris Windows préserve les coordonnées SGR, y compris la colonne 95 passée, et la rattachement restaure les rapports de la souris. Les anciens rapports de souris SSH ne produisent plus de caractères fantômes et ne bloquent plus les saisies ultérieures. (#4155, #3735, #4080, merci @JJLiebig)
  • Les connexions Git Bash SSH honorent les alias d'hôte de la configuration SSH de l'utilisateur. (#3947, #4054, merci @JJLiebig)
  • Les volets du mode de connexion Windows respectent le shell configuré et maintiennent à jour les rapports du répertoire de travail PowerShell. Les chemins de lancement des volets utilisent une casse de répertoire cohérente. (#1445, #4060, #4065, #4199, merci @JJLiebig)

herdr v0.9.1

Added

  • Control agents, panes, workspaces, and worktrees on saved SSH machines with herdr --machine <label-or-id>. Commands use the saved machine's session without needing an open Herdr window. Update Herdr on both machines to use CLI forwarding; failed remote commands never fall back to Local. (#3918)
  • Connect to Windows SSH hosts from Linux, macOS, or Windows. Interactive setup can install or update the complete Windows package after confirmation; background reconnects never install updates. (#3651, #3701, #3661, #3687, thanks @JJLiebig)
  • Edit names, filters, and search text at the cursor instead of only at the end. Herdr inputs now support character and word movement, Home/End, deletion, and familiar Ctrl+A/E/K/U/W/Y shortcuts, including Unicode text. (#1803, #3698, thanks @markjaquith)
  • Added Letta Code detection and native conversation restore, including default conversations. Its experimental integration is installed through herdr integration install letta, not the Settings integration list or JSON integration API. (#3106, #3107, thanks @just-cameron)
  • Hold Ctrl over a link to highlight it before opening it. Wrapped URLs and OSC 8 links remain clickable even when their beginning or end is outside the viewport. (#1282)
  • Sidebar token rules can now hide matching tokens and their separators with hide = true; rows disappear when no tokens remain. (#3925)

Changed

  • Workspace keyboard navigation now spans connected machines in sidebar order, with a visible highlight before Enter switches machines. Collapsed machine and worktree groups remain navigable without accidentally sending actions to the wrong machine. (#3754)
  • Experimental live handoff can now transfer more than 64 panes when the sending server includes this update. An older running server still has its old limit for the first upgrade; this does not change update installation order or make live handoff non-experimental. (#3393, #3411, thanks @kataokatsuki)
  • On Linux and macOS, terminal observers that stop accepting output are disconnected after 30 seconds without write progress. Their pane and other clients keep running; an interrupted stream may end without a final close record. (#3612)
  • Windows terminal cleanup now explicitly resets mouse-reporting modes. The remaining standalone Git Bash detach report in #3748 is still under investigation; do not treat this release as a confirmed fix for that report. (#4055, thanks @JJLiebig)

Fixed

  • Remote typing, switching, and popup interaction no longer resend the entire pane screen for small changes. Busy SSH sessions use less bandwidth, and idle attached clients avoid unnecessary redraw work. (#3769, #3745, #3822)
  • A stalled SSH machine no longer traps the client away from Local. Clicking a local workspace or agent cancels the unfinished remote switch, and a recovered remote workspace refreshes without an away-and-back selection. Stale screens from before a reconnect are not reused. (#3903, #3842)
  • Idle SSH connections use less CPU without losing final output. Repeated connection failures back off instead of reconnecting rapidly, and supported idle bridges clean up without stopping remote panes. (#3728, #4083)
  • Large pastes no longer disconnect the client with an output-queue error. (#3833)
  • SSH setup now shows authentication instructions and useful errors, including Tailscale login URLs and host-key failures, rather than appearing to hang or only reporting a lost connection. machine add also accepts options before the SSH target. (#3606, #3731, #3883)
  • Machine and worktree groups collapse correctly without changing the selected workspace. The sidebar respects workspace row gaps, stays stable during resizing, and reveals newly focused workspaces. (#3778, #3738, #3817)
  • The agent list keeps its scroll position when switching machines. Current-workspace and current-tab filters distinguish identical IDs on different machines. (#3937, #4101, #3732, thanks @minatoaquaMK2)
  • Background machine activation no longer resizes another client's focused pane. Window titles follow each client's own view rather than another client's selection. (#3744, #4091, #4130, thanks @JJLiebig)
  • agent focus and pane move --focus now move attached clients to the requested pane. Moving without focus no longer leaves a client following a deleted tab or later unrelated focus changes. (#3760, #4153, #4171, thanks @minatoaquaMK2)
  • Creating a worktree focuses its new workspace again. Partially failed worktree removals can be retried, and worktrees with submodules offer an explicit forced-removal choice rather than failing without a recovery action. (#3766, #3314, #1797)
  • Temporary worktree-action error banners expire instead of remaining on screen indefinitely. (#1827, #4063, thanks @JJLiebig)
  • The last tab remains fully visible when the tab strip overflows, and the session navigator once again draws connected tree branches. (#4151, #3843)
  • Muted sidebar and tab labels remain readable on dark themes, including Windows Terminal. (#2692, #4062, thanks @JJLiebig)
  • Mouse drag and copy-mode selections stay active while output continues, even when part of the selection is outside the viewport. Copying uses the current text in the selected range. Selection repainting also avoids building up a backlog of mouse movements. (#3841, #3895)
  • Double-click selections remain visible with automatic copy disabled. Holding the second click and dragging extends by whole words, and token selection stops at CJK punctuation. Host selection colors remain visible on transparent backgrounds. (#3847, #1836, #3706, #3798)
  • Scrolling no longer combines mismatched terminal snapshots or leaves stale wrapped rows in fullscreen applications such as Neovim. Alternate-screen history reads preserve content across changing headers and scrollbars. (#3900, #3329, #3979)
  • Local Kitty graphics keep their direct transport after the first image. Popups and notifications hide only overlapping image placements; uncovered images remain visible. (#3785, #4081)
  • Pixel mouse coordinates work independently of image rendering and use the terminal's integer cell size, preventing clicks from drifting across the screen. (#3295, #4140, thanks @JJLiebig)
  • Function keys F1–F12 are recognized in Kitty keyboard reports, and F1–F4 also work with parameterized reports from terminals such as foot. (#1809, #2378, #4067, thanks @ashokDevs and @JJLiebig)
  • WezTerm control-key reports now preserve Enter, Backspace, Tab, and Escape. Cmd/Super-modified input reaches pane applications with its modifier intact. Modified Enter stays compatible with panes that have not requested enhanced key encoding. (#3589, #3710, #4103, #4110, thanks @minatoaquaMK2)
  • Mouse reports split across delayed reads no longer leak their trailing bytes into pane input. Clients reassert mouse reporting after terminal reconnects. (#3911, #4079, thanks @JJLiebig)
  • Saved sessions that cannot be loaded are preserved before replacement, rather than silently overwritten. Recovery copies are kept in session-backups/; failed preservation leaves the original untouched. (#4125)
  • Deleting a session now requires its exact name, including case, on case-insensitive filesystems. Names beginning with a hyphen can be passed after --. (#3819, #4233, #3220, thanks @minatoaquaMK2)
  • Newly started macOS servers retain access to user lookup and DNS across logout. Existing affected servers need a full session restart; live handoff cannot repair their inherited service context. (#4100)
  • Linux process discovery stays responsive around stuck WSL agents and avoids repeatedly scanning an ever-growing process tree. (#2179, #3621, #3674, thanks @dark2momo and @caner-akca)
  • Linux desktop notifications identify Herdr as their source. (#3638)
  • pane split without a target now splits the calling pane when invoked inside Herdr, rather than another client's focused pane. Explicit targets keep their existing behavior. (#4123)
  • Live agent names survive temporary process-detection uncertainty instead of leaving an active agent unreachable by name. (#3225, #3574, thanks @caner-akca)
  • Windows Codex prompts reliably submit after pasted text instead of losing Enter, including long prompts. (#3187, #3961, thanks @JJLiebig)
  • OpenCode V2 reports lifecycle state from the pane displaying the conversation, so shared servers do not mix up panes. Completed and interrupted turns return to idle, while pending permissions, forms, and failed executions remain blocked. V1 remains supported; restart OpenCode after installing the updated integration. (#3757, thanks @markjaquith)
  • Codex stays working with static titles, animations disabled, and queued follow-ups. Composer sparkles and old confirmation text no longer make an idle pane appear blocked. (#4092, #4099, #3988, thanks @minatoaquaMK2)
  • Claude Code's Unicode activity spinner and Pi's working border are recognized correctly. Cline launcher detection and idle-state reporting are more reliable. (#3949, #3629, #2396)
  • Pi records native session paths on Windows. Nested OMP processes no longer replace the parent pane's resumable session, and Windows Kimi npm shims are recognized. (#3726, #2593, #3994, #3317, #4053, thanks @JJLiebig)
  • Grok updates its restore reference after /new, and its imported Claude-compatible hooks no longer overwrite that reference. Reinstall the Claude integration to adopt the narrower hook matching. (#2681, #4018)
  • Integration configuration updates preserve existing files when writes fail. Hermes installation also preserves valid YAML when enabled plugins use an inline list. (#3970, #3839, #4056, thanks @JJLiebig)
  • Plugin registry writes preserve symlinks. Plugins keep using the running server's compatible binary after a client-only update, and manual pane navigation emits focus events again. (#3922, #3824, #4077)
  • Config files containing a UTF-8 BOM load and save correctly. The default config places ui.accent in the right table. (#3678, #3962, #2697, thanks @JJLiebig)
  • Windows local and SSH input preserves Alt combinations, Ctrl+S, and enhanced keyboard text instead of dropping keys or inserting garbage. Remote dead-key input no longer adds an extra base character. (#3702, #3910, #3932, #3948, #4133, #4148, thanks @JJLiebig)
  • Windows mouse capture preserves SGR coordinates, including past column 95, and reattaching restores mouse reporting. Legacy SSH mouse reports no longer produce phantom characters or block subsequent input. (#4155, #3735, #4080, thanks @JJLiebig)
  • Git Bash SSH connections honor host aliases from the user's SSH config. (#3947, #4054, thanks @JJLiebig)
  • Windows login-mode panes honor the configured shell and keep PowerShell working-directory reports current. Pane launch paths use consistent directory casing. (#1445, #4060, #4065, #4199, thanks @JJLiebig)
