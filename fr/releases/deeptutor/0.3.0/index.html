🚀 DeepTutor v0.3.0 Release Note

Date de sortie : 6 janvier 2026 Nous sommes ravis d'annoncer DeepTutor v0.3.0 ! Cette version se concentre sur les améliorations de l'expérience des développeurs, l'automatisation CI/CD et le déploiement local simplifié.

✨ Points forts

🏗️ Architecture unifiée de PromptManager

Un refactor majeur consolide tous les chargements d'invites sur plus de 10 modules d'agent dans un singleton PromptManager centralisé :

  • Mise en cache globale avec invalidation au niveau du module pour des performances améliorées
  • Chaîne de secours linguistique (zh → en, en → zh) pour une prise en charge transparente d'i18n
  • Conformité ISO 639-1 — tous les répertoires d'invites cn/ renommés en zh/
  • Code d'agent simplifié en supprimant les méthodes _load_prompts redondantes et les caches au niveau des classes

DeepTutor v0.3.0

Highlights

  • Centralized PromptManager — All prompt loading across 10+ agent modules now routes through a singleton get_prompt_manager() with module-level cache invalidation and a bidirectional zh → en / en → zh fallback chain. This kills duplicated loader logic, but if you ship custom prompts you must rename every cn/ directory to zh/ (ISO 639-1) and stop relying on the deleted _load_prompts methods and _PROMPT_CACHE class attributes — direct callers will break on upgrade.
  • Breaking removals to migrate around — PromptLoader is no longer exported from solve/__init__.py, src/agents/solve/utils/prompt_loader.py is deleted, and BaseAgent's use_prompt_loader parameter is gone. Downstream code using these hooks needs to move to get_prompt_manager() from src/core; this is the real migration cost of v0.3.0, not the Docker image.
  • Config API for frontends — New GET /api/v1/config/agents exposes agent metadata for data-driven UI configuration. Useful if you are building a custom client: the agent list no longer has to be hardcoded on the frontend.
  • Pre-built GHCR image — ghcr.io/hkuds/deeptutor:latest reduces setup to one docker run (ports 8001/3782, --env-file .env, a data bind mount). Convenient for local evaluation; pin a version tag instead of latest in any production or reproducible pipeline since CI now republishes that tag automatically.
  • CI/CD automation — Added tests.yml, docker-publish.yml (auto-publishes to GHCR), and dependabot.yml (pip, npm, GitHub Actions, Docker). Expect dependency and base-image bumps to arrive as automated PRs — worth gating merges on the new test workflow rather than rubber-stamping them.
  • Local-first LLM settings (with a caveat) — The settings page is narrowed to Ollama (default) and LM Studio, framed as a privacy-first, self-hosted move with cloud providers dropped. But the merged PR list tells a conflicting story: #28 adds support for newer OpenAI models and #34 adds "Dynamic LLM Provider Support (Local & Cloud)." Treat cloud support as contested and verify the runtime behavior before relying on either path.

🚀 DeepTutor v0.3.0 Release Notes

Release Date: January 6, 2026

We're excited to announce DeepTutor v0.3.0! This release focuses on developer experience improvements, CI/CD automation, and simplified local deployment.

✨ Highlights

🏗️ Unified PromptManager Architecture

A major refactor consolidates all prompt loading across 10+ agent modules into a centralized PromptManager singleton:

  • Global caching with module-level invalidation for improved performance
  • Language fallback chain (zh → en, en → zh) for seamless i18n support
  • ISO 639-1 compliance — all cn/ prompt directories renamed to zh/
  • Simplified agent code by removing redundant _load_prompts methods and class-level caches

🤖 GitHub Actions & CI/CD

Introducing automated workflows for better code quality and easier deployment:

| Workflow | Description | |:---|:---| | dependabot.yml | Automatic dependency updates (pip, npm, GitHub Actions, Docker) | | tests.yml | Automated testing on push/PR | | docker-publish.yml | Auto-publish Docker images to GHCR |

🐳 Pre-built Docker Images

Deploy in ~30 seconds using our pre-built image from GitHub Container Registry:

docker run -d --name deeptutor
-p 8001:8001 -p 3782:3782
--env-file .env
-v $(pwd)/data:/app/data
ghcr.io/hkuds/deeptutor:latest### 🏠 Local-First LLM Configuration

Simplified settings page now focuses exclusively on local LLM providers:

  • ✅ Ollama (default)
  • ✅ LM Studio
  • ❌ Removed cloud providers (OpenAI, Gemini, Azure, etc.)

This aligns with DeepTutor's vision for privacy-first, self-hosted AI tutoring.

Core Infrastructure

  • Added src/core/prompt_manager.py with singleton PromptManager
  • Export get_prompt_manager() from src/core/__init__.py
  • Added /api/v1/config/agents endpoint for data-driven frontend configuration
