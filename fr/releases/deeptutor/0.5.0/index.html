DeepTutor v0.5.0 Release Note

Date de sortie : 2026.01.15 Nous sommes ravis d'annoncer DeepTutor v0.5.0 ! Cette version offre une configuration de service unifiée, une sélection flexible de pipeline RAG ​​et des améliorations majeures de l'interface utilisateur/UX sur plusieurs modules.

Mise à jour de stabilité : Cette version corrige plusieurs problèmes de configuration et de stabilité de l'environnement. Nous recommandons à tous les utilisateurs de télécharger la dernière version ! Pensez à mettre à jour votre fichier .env ! [!ASTUCE] Appel à problèmes : Nous apprécions vos commentaires ! Si vous rencontrez des bugs ou avez des demandes de fonctionnalités, veuillez [ouvrir un problème] (https://github.com/HKUDS/DeepTutor/issues) ! Si vous souhaitez soumettre un PR, veuillez consulter notre [Guide de contribution] (https://github.com/HKUDS/DeepTutor/blob/main/CONTRIBUTING.md).

Résumé rapide

  • Configuration — Logique de configuration refactorisée pour une configuration LLM/Embedding plus fluide. Les secrets du backend restent cachés du frontend. Ajout de plus de fournisseurs de recherche.
  • RAG Pipelines — Sélectionnez différents pipelines par Ko : LlamaIndex (direct), LightRAG (graphique), RAG-Anything (graphique multimodal).
  • Question Gen — Architecture BaseAgent unifiée avec une interface utilisateur plus intuitive.
  • Accueil : enregistrez l'historique des discussions dans les blocs-notes.
  • Barre latérale — Réorganisation par glisser-déposer + étiquette personnalisable en haut à gauche.
  • Divers — Diverses corrections de bugs et améliorations de stabilité.

✨ Points forts

Système de configuration unifié

Gestion de configuration entièrement repensée pour les services LLM, Embedding, TTS et Search : Principales caractéristiques :

  • Secrets basés sur l'environnement : stockez les clés sensibles API dans .env tout en gérant les configurations dans l'interface utilisateur
  • Syntaxe {"use_env": "VAR_NAME"} : référencez les variables d'environnement sans les exposer dans le frontend
  • Configuration active par service : chaque service (LLM, Embedding, TTS, Search) conserve sa propre configuration active
  • Changement transparent de fournisseur : ajoutez de nouveaux fournisseurs dans le frontend sans toucher aux secrets du backend Nouveaux fournisseurs de recherche : | Fournisseur | Descriptif | |:---|:---| | Tavily | Recherche native IA API | | Examen | Moteur de recherche neuronal | | Jina | Recherche Web basée sur les lecteurs | | Serpent | Google SERPAPI |

Sélection de pipelines RAG

Choisissez le pipeline RAG optimal pour chaque base de connaissances en fonction de vos exigences de vitesse/qualité : | Pipeline | Type d'index | Idéal pour | Vitesse | |:---|:---|:---|:---| | Indice Lama | Vecteur (direct) | Installation rapide, documents simples | Le plus rapide | | LightRAG ​​| Graphique des connaissances | Documents généraux, riches en texte | Rapide | | RAG-N'importe quoi | Graphique multimodal | Articles académiques, manuels avec figures/équations | Complètement |

Refonte de la génération de questions

Refonte du module de génération de questions avec une architecture d'agent unifiée : Modifications du back-end :

  • Migré vers le modèle BaseAgent cohérent avec les autres modules
  • Nouveaux agents spécialisés : RetrieveAgent, GenerateAgent, RelevanceAnalyzer
  • Génération en un seul passage avec classification de pertinence (pas de boucles de validation itératives)
  • Analyse JSON améliorée avec extraction de bloc de code markdown Améliorations du front-end :
  • Tableau de bord de progression en temps réel avec indicateurs d'étape
  • Tiroir de journaux pour le processus de génération de débogage
  • Disposition plus propre de la carte de questions avec soumission des réponses
  • Intégration "Ajouter au bloc-notes"

Améliorations de la page d'accueil

Enregistrer le chat dans le bloc-notes :

  • Nouveau bouton "Enregistrer dans le bloc-notes" dans l'interface de chat
  • Formate automatiquement la conversation en démarque
  • Préserve les requêtes des utilisateurs et les réponses de l'assistant avec les étiquettes de rôle

Personnalisation de la barre latérale

Navigation par glisser-déposer :

  • Réorganisez les éléments de la barre latérale au sein des groupes en les faisant glisser
  • Retour visuel lors des opérations de traînée
  • Ordre persistant enregistré dans les paramètres utilisateur Description personnalisable :
  • Click pour modifier l'étiquette de description de la barre latérale
  • Personnalisez l'identité de votre espace de travail

DeepTutor v0.5.0

Highlights

  • Unified service configuration — LLM, Embedding, TTS, and Search now have independent active configurations managed through the rebuilt settings UI and unified API. Store credentials in .env and reference them with {"use_env":"VAR_NAME"} to keep secrets out of the frontend; refresh your .env during upgrade so provider bindings resolve correctly.
  • Per-knowledge-base RAG pipelines — Knowledge-base creation/upload now supports LlamaIndex direct vector indexing, LightRAG knowledge graphs, and RAG-Anything multimodal graphs for figures and equations (#129; LlamaIndex implementation #98). Pipeline selection is an indexing decision, not merely a query-time setting—choose based on document type and speed-versus-retrieval-quality requirements.
  • Pluggable search and LLM providers — Tavily, Exa, Jina, and Serper join the web-search backend (#95), alongside enhanced Azure OpenAI support (#87) and a standardized LLM error framework (#118). Each provider is opt-in and requires its corresponding environment credentials and configuration.
  • Simpler question-generation execution — Question Generation now uses BaseAgent with specialized RetrieveAgent, GenerateAgent, and RelevanceAnalyzer components. Removing iterative validation loops makes generation single-pass and faster, but there is no repeated correction stage; the new progress dashboard, log drawer, and markdown-aware JSON parsing improve visibility and parser resilience.
  • Notebook and workspace workflows — Chats can be saved as role-labeled Markdown notebooks, generated questions can be added directly to notebooks, and sidebar items support persistent drag-and-drop ordering plus an editable workspace description.
  • Breaking changes — None explicitly announced.

DeepTutor v0.5.0 Release Notes

Release Date: 2026.01.15

We're thrilled to announce DeepTutor v0.5.0! This release delivers unified service configuration, flexible RAG pipeline selection, and major UI/UX improvements across multiple modules.

Stability Update: This release fixes multiple environment configuration and stability issues. We recommend all users to pull the latest version! Remember to update your .env file!

[!TIP] Call for Issues: We welcome your feedback! If you encounter any bugs or have feature requests, please open an issue! If you would like to submit a PR, please check out our Contributing Guide.

Quick Summary

  • Configuration — Refactored config logic for smoother LLM/Embedding setup. Backend secrets stay hidden from frontend. Added more search providers.
  • RAG Pipelines — Select different pipelines per KB: LlamaIndex (direct), LightRAG (graph), RAG-Anything (multimodal graph).
  • Question Gen — Unified BaseAgent architecture with more intuitive UI.
  • Home — Save chat history to notebooks.
  • Sidebar — Drag-and-drop reordering + customizable top-left label.
  • Misc — Various bug fixes and stability improvements.

✨ Highlights

Unified Configuration System

Completely redesigned configuration management for LLM, Embedding, TTS, and Search services:

Key Features:

  • Environment-based secrets: Store sensitive API keys in .env while managing configurations in the UI
  • {"use_env": "VAR_NAME"} syntax: Reference environment variables without exposing them in the frontend
  • Per-service active config: Each service (LLM, Embedding, TTS, Search) maintains its own active configuration
  • Seamless provider switching: Add new providers in the frontend without touching backend secrets

New Search Providers: | Provider | Description | |:---|:---| | Tavily | AI-native search API | | Exa | Neural search engine | | Jina | Reader-based web search | | Serper | Google SERP API |

RAG Pipeline Selection

Choose the optimal RAG pipeline for each knowledge base based on your speed/quality requirements:

| Pipeline | Index Type | Best For | Speed | |:---|:---|:---|:---| | LlamaIndex | Vector (Direct) | Quick setup, simple documents | Fastest | | LightRAG | Knowledge Graph | General documents, text-heavy | Fast | | RAG-Anything | Multimodal Graph | Academic papers, textbooks with figures/equations | Thorough |

Question Generation Overhaul

Refactored the Question Generation module with unified agent architecture:

Backend Changes:

  • Migrated to BaseAgent pattern consistent with other modules
  • New specialized agents: RetrieveAgent, GenerateAgent, RelevanceAnalyzer
  • Single-pass generation with relevance classification (no iterative validation loops)
  • Improved JSON parsing with markdown code block extraction

Frontend Improvements:

  • Real-time progress dashboard with stage indicators
  • Log drawer for debugging generation process
  • Cleaner question card layout with answer submission
  • "Add to Notebook" integration

Home Page Enhancements

Save Chat to Notebook:

  • New "Save to Notebook" button in chat interface
  • Automatically formats conversation as markdown
  • Preserves user queries and assistant responses with role labels

Sidebar Customization

Drag-and-Drop Navigation:

  • Reorder sidebar items within groups by dragging
  • Visual feedback during drag operations
  • Persistent order saved to user settings

Customizable Description:

  • Click to edit the sidebar description label
  • Personalize your workspace identity

  • Added src/api/routers/config.py — Unified REST API for all service configs
  • Refactored web search to support multiple providers (src/services/search/)
  • Enhanced error handling with LLM error framework

RAG System

  • Implemented pure LightRAGPipeline with complete initialization
  • Added pipeline selection during KB create/upload (PR #129)

Question Generation

Frontend Updates
