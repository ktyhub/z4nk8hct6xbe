🚀 DeepTutor v1.0.0-beta1 Release Note

Date de sortie : 2026.04.04 Nous sommes ravis d'annoncer DeepTutor v1.0.0-beta1 — la première version bêta de la toute nouvelle architecture DeepTutor. Il s'agit d'une réécriture de fond qui transforme DeepTutor d'un tuteur RAG monolithique en une plate-forme d'apprentissage native d'agent avec un modèle de plugin à deux couches (Outils + Capacités), trois points d'entrée unifiés (CLI / WebSocket / Python SDK) et un shell d'application Web entièrement reconstruit. Trouvez plus de surprises par vous-même !

⚠️ Avis bêta : Il s'agit de la bêta 1 de v1.0.0. L'architecture de base est stable, mais certaines interactions d'interface utilisateur et workflows de cas extrêmes peuvent encore contenir des bogues. Nous apprécions votre patience et apprécions les rapports de bogues via [Problèmes] (https://github.com/HKUDS/DeepTutor/issues). 📌 Remarque sur la base de connaissances : Dans cette version, le pipeline RAG a été simplifié en LlamaIndex uniquement. Les pipelines LightRAG et RAG-Anything ainsi que le contenu de leur base de connaissances associée ont été temporairement supprimés pour se concentrer sur la stabilité. Ils seront réintroduits dans les prochaines versions. [!ASTUCE] Appel à commentaires : Il est conscient que certaines des anciennes fonctionnalités ne sont pas incluses dans la version la plus récente. Si vous avez des commentaires utiles, rencontrez des bugs ou avez des demandes de fonctionnalités, veuillez [ouvrir un problème] (https://github.com/HKUDS/DeepTutor/issues) ! Les PR sont également les bienvenus — consultez notre [Guide de contribution] (https://github.com/HKUDS/DeepTutor/blob/main/CONTRIBUTING.md). Résumé rapide

  • Architecture — Réécriture complète de src/ vers deeptutor/ + deeptutor_cli/ avec un runtime natif d'agent (outils + capacités).
  • Points d'entrée — Trois points d'entrée unifiés : CLI autonome (deeptutor), WebSocket API (/api/v1/ws) et façade Python SDK.
  • Capacités — Cinq capacités intégrées : chat, deep_solve, deep_question, deep_research, math_animator.
  • Outils — Sept outils appelables LLM : rag, web_search, code_execution, reason, brainstorm, paper_search, geogebra_analysis.
  • Application Web — Application Next.js reconstruite avec des groupes d'itinéraires d'espace de travail/utilitaires, de nouvelles pages Playground, Co-Writer, Agents et Guide.
  • TutorBot — Agent bot multicanal prenant en charge 12 plateformes de messagerie.
  • Infra — Persistance de session basée sur SQLite, temps d'exécution, contrôle du trafic LLM au niveau du fournisseur et télémétrie.

✨ Points forts

🏗️ Agent-Native Runtime (outils + capacités)

Introduction d'un modèle de plugin à deux couches qui dissocie l'exécution des outils des flux de travail des agents de haut niveau :

  • Contrats principaux : ToolProtocol, CapabilityProtocol, UnifiedContext, StreamEvent et StreamBus — la base de toute exécution du runtime.
  • ChatOrchestrator : Coordinateur central avec deux registres :
    • ToolRegistry — découverte d'outils, exportation de schéma de style OpenAI et exécution.
    • CapabilityRegistry — routage des capacités, gestion des manifestes et streaming adapté aux étapes.

🖥️ Points d'entrée unifiés : CLI / WebSocket / Python SDK

Trois points d'entrée partagent un seul environnement d'exécution ChatOrchestrator : | Point d'entrée | Descriptif | |:---|:---| | CLI (deeptutor) | CLI basé sur un typeur avec sous-commandes : run, chat, bot, kb, memory, session, notebook, plugin, config, provider, serve | | WebSocket (/api/v1/ws) | Point de terminaison unifié avec cycle de vie des tours : start_turn, subscribe_turn, subscribe_session, resume_from, cancel_turn | | Python SDK (deeptutor.app.facade) | Façade programmatique pour les intégrations de style SDK |

DeepTutor v1.0.0-beta.1

Highlights

  • Rewrite-level migration — This is not an in-place upgrade: src/ is replaced by deeptutor/ and deeptutor_cli/, the package is renamed from ai-tutor to deeptutor, and dependencies are split into cli.txt, server.txt, dev.txt, math-animator.txt, and tutorbot.txt. Update imports and installation scripts, and plan a state migration because runtime data now lives under data/user/workspace/....
  • Capability-first agent runtime — ChatOrchestrator routes chat, deep_solve, deep_question, deep_research, and math_animator through tool and capability registries, shared by the CLI, /api/v1/ws, and deeptutor.app.facade. chat is now the default, so integrations must explicitly select deep capabilities. WebSocket clients gain resumable and cancellable turns plus session subscriptions.
  • RAG reduced to LlamaIndex — LightRAG and RAG-Anything, along with their related knowledge-base content, are temporarily removed. Retrieval-dependent workflows must move to LlamaIndex and revalidate existing knowledge-base configuration; projects requiring the removed pipelines should pin the previous release until they return.
  • New web surface, removed deep links — The rebuilt Next.js app consolidates deep workflows under /playground and adds /guide, /co-writer, and /agents; legacy routes including /solver, /question, /research, /ideagen, /notebook, and /history are gone. Update bookmarks, UI automation, and integrations accordingly. The architecture is declared stable, but beta UI interactions and edge-case workflows still warrant caution.
  • TutorBot brings agents into messaging tools — TutorBot adds memory, subagents, team collaboration, scheduled tasks, and shell, filesystem, web, MCP, and message tools across messaging-platform integrations. This enables bots inside existing communication workflows, but its broad executable toolset makes reviewing tool exposure and scheduled-job behavior essential before deployment.
  • Code execution and provider hardening — AST-based import and call guards with configurable allowlists tighten generated-Python execution (PR #196); treat these as an additional safety layer rather than a replacement for sandboxing. Provider-level circuit breakers, retries, error-rate tracking, and telemetry (PR #183) make failures more observable and contained, while OpenRouter joins the search-provider options (PR #194).

🚀 DeepTutor v1.0.0-beta1 Release Notes

Release Date: 2026.04.04

We're thrilled to announce DeepTutor v1.0.0-beta1 — the first beta of the brand new DeepTutor architecture. This is a ground-up rewrite that transforms DeepTutor from a monolithic RAG tutor into an agent-native learning platform with a two-layer plugin model (Tools + Capabilities), three unified entry points (CLI / WebSocket / Python SDK), and a completely rebuilt web application shell. Find more surprises by your own!

⚠️ Beta Notice: This is beta 1 of v1.0.0. The core architecture is stable, but some UI interactions and edge-case workflows may still contain bugs. We appreciate your patience and welcome bug reports via Issues.

📌 Knowledge Base Note: In this release, the RAG pipeline has been simplified to LlamaIndex only. LightRAG and RAG-Anything pipelines along with their related knowledge base content have been temporarily removed to focus on stability. They will be re-introduced in upcoming releases.

[!TIP] Call for Feedback: It is aware that some of the old features are not included in the newest version. If you have any helpful comments, encounter any bugs or have any feature requests, please open an issue! PRs are also welcome — see our Contributing Guide.
