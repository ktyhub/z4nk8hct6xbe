dubbo-go v3.3.1

##3.3.1

Résumé

Cette version introduit des améliorations majeures du protocole Triple, des améliorations des centres de configuration et de registre (Nacos, Apollo, Zookeeper) et une refactorisation approfondie des modules de base pour améliorer la stabilité et les performances. Cette version met également à jour la compatibilité avec Go 1.24.

Nouvelles fonctionnalités

  • Prise en charge des caractères génériques de groupe et de version pour une correspondance exacte de l'interface. #3080
  • Prise en charge de l'injection de dubbo.tag dans les métadonnées du service. #3069
  • Exposer les API liés au routeur. #3066
  • Mettre à jour la prise en charge de la version Go vers Go 1.24 et supprimer l'utilisation obsolète de rand.seed. #3046
  • Introduire un outil de formatage des importations et l'intégrer dans les contrôles CI. #3019
  • Ajouter une capacité de rechargement à chaud de la configuration. #2992
  • Support exécutant simultanément des serveurs HTTP/2 et HTTP/3. #2972
  • Ajouter l'option WithInterface pour l'initialisation de client. #2946
  • Ajouter la prise en charge des outils pour générer la documentation OpenAPI pour les services Triple. #2951
  • Ajouter la prise en charge expérimentale de HTTP/3 pour le protocole Triple. #2916
  • Refonte des TLS API et ajout d'une nouvelle configuration TLS pour le protocole triple. #2852 #2891
  • Support Mode non-IDL dans la nouvelle implémentation Triple. #2858
  • Ajouter la prise en charge d'Apollo en tant que centre de configuration. #2857
  • Prise en charge du décodage du Hessian à partir du flux pour améliorer les performances de la transmission de gros paquets. #2841
  • Ajouter la prise en charge des appels génériques pour le nouveau protocole Triple. #2818

Corrections de bugs

  • Empêcher la panique lors de la récupération des métadonnées des fournisseurs Java. #3092

  • Correction du chargement de la configuration du fournisseur dans dubbo.Load(). #2941
  • Correction des problèmes de transmission des pièces jointes du serveur vers client dans le protocole triple. #2928 #2854

dubbo-go v3.3.1

3.3.1

Summary

This release introduces major enhancements to the Triple protocol, improvements to configuration and registry centers (Nacos, Apollo, Zookeeper), and extensive refactoring of core modules to improve stability and performance. This version also updates compatibility to Go 1.24.

New Features

  • Support group and version wildcards for exact interface matching. #3080
  • Support injecting dubbo.tag into service metadata. #3069
  • Expose Router-related APIs. #3066
  • Update Go version support to Go 1.24 and remove deprecated rand.seed usage. #3046
  • Introduce an imports formatter tool and integrate it into CI checks. #3019
  • Add configuration hot-reloading capability. #2992
  • Support running HTTP/2 and HTTP/3 servers simultaneously. #2972
  • Add WithInterface option for client initialization. #2946
  • Add tooling support to generate OpenAPI documentation for Triple services. #2951
  • Add experimental HTTP/3 support for the Triple protocol. #2916
  • Redesign TLS APIs and add new TLS configuration for Triple protocol. #2852 #2891
  • Support Non-IDL mode in the new Triple implementation. #2858
  • Add support for Apollo as a configuration center. #2857
  • Support decoding Hessian from stream to improve performance for large packet transmission. #2841
  • Add generic call support for the new Triple protocol. #2818

Bug Fixes

  • Fix Nacos deregistration failure during shutdown. #3108
  • Prevent panic when retrieving metadata from Java providers. #3092
  • Adjust log level from Error to Warn when application parameters are empty in Tag Router. #3035
  • Fix nil pointer dereference in multiple modules. #3071
  • Resolve URL parameter loss in SetParams method. #3022
  • Handle cluster extension creation failures instead of panicking. #3021 #3064
  • Fix incorrect log rotation paths to prevent file loss. #3014
  • Correct counter decrement logic on error. #3013
  • Fix metadata retrieval failures caused by meta-v errors and empty remote storage parameters. #2952 #2953
  • Fix provider configuration loading in dubbo.Load(). #2941
  • Fix attachment passing issues from server to client in Triple protocol. #2928 #2854
  • Fix Nacos weight configuration not taking effect. #2937
  • Reduce latency in Zookeeper client node perception. #2930
  • Fix read prefix EOF errors in the communication layer. #2912
  • Fix Nacos instance overwrite issues. #2882
  • Resolve logical infinite loop issues. #2879
  • Fix Nacos subscription issues where newly registered services were not detected. #2859
  • Fix Nacos weight option configuration logic. #2843
  • Fix error propagation in marshalRequest. #2817
  • Fix Context Attachment error handling in Triple streaming calls. #2810

Code Enhancements

  • Refactor: Config Decoupling. Decoupled dependencies from config package to resolve circular dependencies across registry, filter, and TLS modules.
  • Optimize performance by precompiling regex patterns. #3067
  • Improve Weighted RoundRobin by adding lastUpdate field to state storage. #3053
  • Fix multiple package imports in Triple code generation. #3052
  • Address memory leaks related to goroutine management, file handles, and extension caches. #3023
  • Refactor logger module and add comprehensive unit tests. #2838 #2993
  • Rewrite Makefile to improve build consistency and developer experience. #2975
  • Use errgroup to improve error handling during graceful shutdown. #2973
  • Replace deprecated CAS operations with CompareAndSwap. #2962
  • Harden Triple openServer error handling for configuration errors. #2945
  • Add timeout control for graceful shutdown in Triple protocol. #2943
  • Migrate interface{} to any throughout the codebase for Go 1.18+ compatibility. #2848

Observability

  • Add logging for the service registration lifecycle. #3043
  • Align trace scope names with OpenTelemetry specifications. #3041
  • Add Insecure option to tracing configuration. #3028
  • Upgrade OpenTelemetry dependencies to v1.21.0. #2971

Documentation & CI

  • Add make check-fmt command to CI pipeline. #3055
  • Update README contact info and fix invalid links in README_CN. #3020
  • Integrate imports formatter and License header checks into CI. #2961 #2957
  • Resolve various SonarQube/SonarCloud false positives and AI bot warnings. #2902
