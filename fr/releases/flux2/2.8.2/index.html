Faits saillants

Flux v2.8.2 est une version de correctif contenant divers correctifs. Les utilisateurs sont encouragés à effectuer une mise à niveau pour la meilleure expérience. ℹ️ Veuillez suivre la Procédure de mise à niveau pour Flux v2.7+ pour une mise à niveau en douceur de Flux v2.6 vers la dernière version. Correctifs :

  • Correction de la mise en file d'attente des nouvelles demandes de rapprochement pour les événements sur les objets Flux source lorsqu'ils réconcilient déjà la révision présente dans l'événement de surveillance (kustomize-controller, helm-controller)
  • Correction du bug des modèles Go du séparateur YAML --- concaténé à apiVersion: en mettant à jour vers Helm 4.1.3 (contrôleur de barre)
  • Correction des HelmReleases annulés qui restaient bloqués lorsqu'ils n'avaient pas de stratégie de nouvelle tentative configurée en introduisant une nouvelle porte de fonctionnalité DefaultToRetryOnFailure qui améliore l'expérience lorsque le CancelHealthCheckOnNewRevision est activé (contrôleur de barre)
  • Correction de la portée d'authentification pour Azure Container Registry afin d'utiliser la portée spécifique à ACR (contrôleur source, contrôleur image-réflecteur)
  • Correction d'un déni de service (DoS) potentiel lors des poignées de main TLS (CVE-2026-27138) en construisant tous les contrôleurs avec Go 1.26.1

flux2 v2.8.2

Highlights

Flux v2.8.2 is a patch release that comes with various fixes. Users are encouraged to upgrade for the best experience.

ℹ️ Please follow the Upgrade Procedure for Flux v2.7+ for a smooth upgrade from Flux v2.6 to the latest version.

Fixes:

  • Fix enqueuing new reconciliation requests for events on source Flux objects when they are already reconciling the revision present in the watch event (kustomize-controller, helm-controller)
  • Fix the Go templates bug of YAML separator --- getting concatenated to apiVersion: by updating to Helm 4.1.3 (helm-controller)
  • Fix canceled HelmReleases getting stuck when they don't have a retry strategy configured by introducing a new feature gate DefaultToRetryOnFailure that improves the experience when the CancelHealthCheckOnNewRevision is enabled (helm-controller)
  • Fix the auth scope for Azure Container Registry to use the ACR-specific scope (source-controller, image-reflector-controller)
  • Fix potential Denial of Service (DoS) during TLS handshakes (CVE-2026-27138) by building all controllers with Go 1.26.1
