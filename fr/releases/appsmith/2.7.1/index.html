appsmith v2.7.1

⚠️ Notes de mise à niveau importantes

  • Liste autorisée intégrée : APPSMITH_ALLOWED_FRAME_ANCESTORS doit être une liste d'expressions sources CSP frame-ancestors. Une valeur enregistrée qui n'est pas sous cette forme est servie comme 'self' après le prochain redémarrage. L’enregistrement du paramètre rejette une valeur non valide. (#42622)
  • Noms de page Git : Git ne validera pas d'application tant qu'un nom de page n'est pas un segment de chemin unique. Renommez d'abord cette page. Créer ou renommer une page sous un tel nom est rejeté. (#42633) Si vous effectuez une mise à niveau à partir d'une version antérieure à v2.7.0
  • Helm chart : si vous définissez des touches probes, les touches que vous n'avez pas définies prennent désormais les nouvelles valeurs par défaut (période de 10 s, timeout de 5 s). Si vous avez réglé failureThreshold pour l'ancienne période des années 60, réglez également periodSeconds: 60. Les valeurs de sonde qui ne sont pas des entiers positifs échouent désormais à helm install et helm upgrade. Les numéros cités tels que "5" fonctionnent toujours. (#42571)
  • navigateTo sur un nom de page qui n'existe plus échoue désormais avec "Entrez une URL ou un nom de page valide", même lorsqu'une valeur de paramètre contient un point. Avant, il ouvrait le nom sous forme d'adresse Web, telle que https://OldPage?file=report.pdf. Un hôte à un mot tel que intranet avec un paramètre en pointillés échoue désormais également. Utilisez plutôt une URL complète. (#42513)

🔐 Sécurité

  • Les téléchargements de tableaux CSV ne permettent plus à une cellule de s'exécuter comme une formule de feuille de calcul. La cellule est enregistrée sous forme de texte. Les téléchargements Excel sont inchangés. (#42569)
  • Changer qui peut utiliser une source de données lors de la validation des actions nécessite désormais l'autorisation de créer des actions sur cette source de données. La création ou la mise à jour d’une seule action nécessitait déjà cela. (#42601)
  • Le paramètre frame-ancestors accepte uniquement les expressions source CSP. Une valeur enregistrée non valide est transmise sous la forme 'self'. (#42622)
  • Git écrit et supprime dans le référentiel de cette application. Un nom de page doit être un segment de chemin unique. (#42633)
  • La mise à jour de la carte des dépendances d'une page nécessite désormais l'autorisation de modifier cette page. (#42642)

🛠️ Fiabilité

  • La connexion par code d'autorisation OAuth2 utilise désormais le certificat auto-signé de la source de données pour l'échange de jetons. Auparavant, cette étape ignorait le paramètre et la connexion échouait lorsque l'URL du jeton utilisait un certificat privé. (#42605)
  • L'importation d'une application ne supprime plus une nouvelle source de données ou bibliothèque JS lorsque plusieurs sont créées en même temps. (#42612)
  • MCP conserve une requête mise à jour sur sa propre intégration. Il ne déplace plus la requête vers une source de données d'un type différent. (#42620)
  • MCP n'ajoute pas de valeurs aux requêtes sur Redshift ou Snowflake, car ces sources de données ne lient pas de paramètres. (#42617)

✨ Nouvelles fonctionnalités et améliorations

  • La boîte de dialogue de téléchargement Filepicker suit le langage HTML de l'application. Une langue non prise en charge ou vide reste en anglais. (#42572)
  • Le SQL structuré MCP peut regrouper les dates par jour, semaine, mois, trimestre ou année sur PostgreSQL et Redshift, renvoyer jusqu'à six agrégats et sélectionner des lignes distinctes. (#42608)
  • Le SQL structuré MCP peut joindre des tables et utiliser CASE et WITH. (#42619)
  • MCP peut copier une requête SQL ou REST stockée vers une autre page ou vers une autre application. Le texte de la requête reste sur le serveur. (#42624)
  • MCP peut créer une requête par courrier électronique sur une source de données SMTP existante. Le JavaScript construit par MCP peut formater une date et écrire une entrée de journal. (#42638)

🎨 Améliorations de l'interface utilisateur et des widgets

  • L'entrée monétaire ajoute le rouble biélorusse (BYN), le bolivar vénézuélien (VES) et le kwacha zambien (ZMW). Les anciens codes BYR, VEF et ZMK restent dans la liste. (#42445)
  • Un groupe de boutons avec un seul bouton conserve son rayon de coin à chaque coin. (#42250)
  • Les contrôles Bouton Icône et Vidéo dans une cellule de tableau mesurent à nouveau 30 pixels de haut, sans remplissage vertical supplémentaire, de sorte que le nombre de lignes sélectionné s'adapte toujours. (#42615)
  • Appuyer sur Entrée dans un formulaire JSON comportant un champ de texte et aucun bouton de soumission ne recharge plus la page. Le bouton Soumettre fonctionne comme avant. (#42607)
  • Dans un formulaire JSON, les boutons Rayon de bordure et Ombre de boîte mettent en surbrillance l'option enregistrée. (#42292)
  • Paramètres d'administration → Branding ne propose plus de SVG pour le logo de l'instance. PNG et JPG sont acceptés, ce que le serveur autorise. (#42637)

appsmith v2.7.1

Highlights

  • Breaking: embed allowlist and Git page-name gates — Two new validation rules can change behavior before you touch any application code. APPSMITH_ALLOWED_FRAME_ANCESTORS is now parsed strictly as CSP frame-ancestors source expressions; a previously saved value in any other form is silently served as 'self' after the next restart, so legitimate third-party embeds can break without an error at save time ([#42622]). Separately, Git will refuse to commit an app while any page name is not a single path segment, and creating or renaming a page to such a name is rejected outright ([#42633]). Audit page names and the saved embed value before upgrading — both failures are hard stops, not warnings.

  • Breaking: navigateTo resolution and Helm probe defaults — Upgrading from pre-2.7.0 changes two runtime behaviors. navigateTo to a missing page name no longer falls back to opening it as a URL: even a dotted parameter like navigateTo("OldPage?file=report.pdf") or a one-word host such as intranet now fails with "Enter a valid URL or page name," so callers that relied on implicit URL coercion must pass a full URL ([#42513]). The Helm chart now fills unset probes keys with a 10 s period and 5 s timeout, and any non-positive-integer value fails helm install/helm upgrade; if you had tuned failureThreshold against the old 60 s cadence, also set periodSeconds: 60 (quoted numbers like "5" still parse) ([#42571]).

  • Security posture: formula injection and permission boundaries tightened — CSV exports now write cell values as text, closing a spreadsheet-formula injection path (Excel exports are unchanged) ([#42569]). The authorization model gains three checks: changing datasource usage while validating actions now requires create-action permission on that datasource ([#42601]), editing a page's dependency map requires edit permission on that page ([#42642]), and Git reads/writes/deletes are confined to the app's own repository ([#42633]). Expect tighter failures in automation that previously relied on implicit access; these are intentional privilege escalations being closed, not regressions.

  • MCP becomes an actual analytics surface, not just a query runner — Structured SQL gains date bucketing by day/week/month/quarter/year on PostgreSQL and Redshift, up to six aggregates, DISTINCT, and joins with CASE/WITH ([#42608], [#42619]). MCP can also copy a stored SQL or REST query to another page or app without exposing the query text, create email queries on existing SMTP datasources, and generate JavaScript that formats dates or writes logs ([#42624], [#42638]). Net effect: more of the data-shaping work can stay inside MCP instead of being rebuilt in JS.

  • Reliability: auth, import, and MCP correctness — OAuth2 authorization-code token exchange now honors the datasource's self-signed certificate, fixing login for private-CA token URLs that previously failed ([#42605]). Importing an app no longer drops concurrently created datasources or JS libraries ([#42612]). MCP keeps an updated query on its own integration rather than moving it onto a different datasource type ([#42620]), and stops injecting parameter values for Redshift and Snowflake, which do not bind parameters ([#42617]) — behavior that matters if you assumed MCP-bound values were safe there.

  • UI polish with one migration hook — Bug-fix level changes remove visual/input regressions rather than add capability: BYN, VES, and ZMW join the Currency Input list while legacy codes remain ([#42445]); single-button Button Groups keep their corner radius ([#42250]); Table-cell Icon Button/Video controls return to 30 px so the configured row count fits ([#42615]); Enter in a single-field JSON Form with no Submit button no longer reloads the page ([#42607]); and saved Border radius/Box shadow options now highlight correctly ([#42292]). The one action item: Admin Settings → Branding no longer offers SVG logos and accepts only PNG/JPG ([#42637]) — convert SVG assets before upgrading.

⚠️ Important Upgrade Notes

  • Embed allowlist: APPSMITH_ALLOWED_FRAME_ANCESTORS must be a list of CSP frame-ancestors source expressions. A saved value that is not in that form is served as 'self' after the next restart. Saving the setting rejects an invalid value. (#42622)
  • Git page names: Git will not commit an app while any page name is not a single path segment. Rename that page first. Creating or renaming a page to such a name is rejected. (#42633)

If you are upgrading from a version before v2.7.0

  • Helm chart: if you set some probes keys, the keys you did not set now take the new defaults (10 s period, 5 s timeout). If you tuned failureThreshold for the old 60 s period, also set periodSeconds: 60. Probe values that are not positive integers now fail helm install and helm upgrade. Quoted numbers such as "5" still work. (#42571)
  • navigateTo to a page name that no longer exists now fails with "Enter a valid URL or page name", even when a parameter value contains a dot. Before, it opened the name as a web address, such as https://OldPage?file=report.pdf. A one-word host such as intranet with a dotted parameter now fails too. Use a full URL instead. (#42513)

🔐 Security

  • Table CSV downloads no longer let a cell run as a spreadsheet formula. The cell is saved as text. Excel downloads are unchanged. (#42569)
  • Changing who can use a datasource while validating actions now requires permission to create actions on that datasource. Creating or updating a single action already required this. (#42601)
  • The frame-ancestors setting accepts only CSP source expressions. An invalid saved value is served as 'self'. (#42622)
  • Git writes and deletes stay inside that app's repository. A page name must be a single path segment. (#42633)
  • Updating a page's dependency map now requires permission to edit that page. (#42642)

🛠️ Reliability

  • OAuth2 authorization-code login now uses the datasource's self-signed certificate for the token exchange. Before, that step ignored the setting, and login failed when the token URL used a private certificate. (#42605)
  • Importing an app no longer drops a new datasource or JS library when several are created at the same time. (#42612)
  • MCP keeps an updated query on its own integration. It no longer moves the query onto a datasource of a different type. (#42620)
  • MCP does not add values to queries on Redshift or Snowflake, because those datasources do not bind parameters. (#42617)

✨ New Features & Enhancements

  • The Filepicker upload dialog follows the app's HTML language. An unsupported or empty language stays in English. (#42572)
  • MCP structured SQL can bucket dates by day, week, month, quarter, or year on PostgreSQL and Redshift, return up to six aggregates, and select distinct rows. (#42608)
  • MCP structured SQL can join tables and use CASE and WITH. (#42619)
  • MCP can copy a stored SQL or REST query to another page, or to another app. The query text stays on the server. (#42624)
  • MCP can create an email query on an existing SMTP datasource. MCP-built JavaScript can format a date and write a log entry. (#42638)

🎨 UI & Widget Improvements

  • Currency Input adds the Belarusian ruble (BYN), the Venezuelan bolívar (VES), and the Zambian kwacha (ZMW). The older codes BYR, VEF, and ZMK stay in the list. (#42445)
  • A Button Group with one button keeps its corner radius on every corner. (#42250)
  • Icon Button and Video controls in a Table cell are 30px tall again, with no extra vertical padding, so the selected number of rows still fits. (#42615)
  • Pressing Enter in a JSON Form that has one text field and no submit button no longer reloads the page. The Submit button works as before. (#42607)
  • In a JSON Form, the button Border radius and Box shadow controls highlight the option that is saved. (#42292)
  • Admin Settings → Branding no longer offers SVG for the instance logo. PNG and JPG are accepted, which is what the server allows. (#42637)
