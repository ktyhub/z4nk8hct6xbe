#hermès-agent v2026.6.5

Agent Hermès v0.16.0 (v2026.6.5)

Date de sortie : 5 juin 2026 Depuis v0.15.2 : 874 commits · 542 PR fusionnés · 1 962 fichiers modifiés · 205 216 insertions · 46 217 suppressions · 399 numéros fermés (2 P0, 62 P1, 16 marqués de sécurité) · 170 contributeurs de la communauté (y compris les co-auteurs)

The Surface Release. Hermès vous rencontre partout où vous travaillez. Une toute nouvelle application de bureau native, construite sur 100 PR et 159 commits en une seule semaine, vous offre Hermes comme une véritable application macOS/Linux/Windows : installation en un seul click, mise à jour automatique dans l'application, glisser-déposer des fichiers dans le chat, un sélecteur de modèle en ligne dans la barre d'état, des sessions multiprofils simultanées, une traduction complète en chinois simplifié et la possibilité de se connecter à une passerelle Hermes distante via OAuth ou nom d'utilisateur/mot de passe. Parallèlement, le tableau de bord Web s'est enrichi d'un panneau d'administration complet basé sur un navigateur (catalogue MCP, canaux de messagerie, informations d'identification, webhooks, mémoire, connexion OIDC / nom d'utilisateur-mot de passe enfichable), et la première installation a obtenu un chemin de « configuration rapide via Nous Portal » qui vous permet de passer de l'installation au premier message en quelques secondes. L'ensemble de compétences par défaut a été réduit à ce dont vous avez réellement besoin, NVIDIA/compétences a rejoint les robinets du hub de compétences trusted, le sélecteur de modèle est désormais consultable de manière floue partout (ordinateur de bureau, Web, TUI, CLI) et /undo vous permet enfin de reprendre les N derniers tours. 2 fermetures P0 et 62 P1 sont accompagnées, plus un tour de sécurité (broche Starlette CVE-2026-48710, durcissement hors boucle SSRF, suppression des informations d'identification du sous-processus).

✨ Points forts

  • Hermes Desktop — une véritable application native, pas un wrapper de terminal — C'est le titre. Il existe désormais une application apps/desktop/ Electron qui s'installe comme n'importe quelle autre application de bureau sur macOS, Linux et Windows, se met à jour depuis l'intérieur de l'application et vous offre une interface graphique raffinée pour tout ce que fait Hermes. Vous obtenez une fenêtre de discussion appropriée avec streaming, une liste de sessions que vous pouvez archiver et rechercher, glisser-déposer des fichiers n'importe où dans la zone de discussion, un collage d'image clipboard, une palette de commandes Cmd+K et un sélecteur de modèle directement dans la barre d'état. Si vous avez dit à vos amis « c'est un agent CLI » et que vous avez regardé leurs yeux s'écarquiller, vous pouvez désormais leur envoyer simplement un installateur. Rien de tout cela n’existait il y a une semaine. (#20059, #35607, #37099, #37379, #38631 — @OutThisLife, @jquesnelle, @ethernet8023, @austinpickett, @benbarclay)
  • Exécutez l'application de bureau sur un Hermes distant — connectez-vous avec OAuth ou nom d'utilisateur/mot de passe — L'application de bureau n'a pas besoin d'exécuter Hermes localement. Pointez-le vers une passerelle Hermes distante (votre homelab, une boîte hébergée, le serveur d'un coéquipier) et il se connecte via un WebSocket sécurisé, en s'authentifiant avec OAuth ou un nom d'utilisateur/mot de passe - pas de manipulation des indicateurs --insecure ou des jetons de session copiés à la main. Chaque profil peut cibler son propre hôte distant et vous pouvez exécuter des sessions simultanées sur plusieurs profils dans une seule fenêtre avec des liens @session inter-profils. La version pratique : votre ordinateur portable exécute une interface graphique fine, l'agent lourd s'exécute partout où votre API touche et calcule en direct. (#37888, #38851, #39330, #39778 — @benbarclay, @OutThisLife, @teknium1)
  • Le tableau de bord Web est désormais un panneau d'administration complet — configurez tout depuis le navigateur — Le tableau de bord est passé de « afficher vos sessions » à une surface d'administration complète. Il existe une page Canaux qui configure chaque plate-forme de messagerie de passerelle (Telegram, Discord, Slack, etc.) à partir du navigateur, un panneau d'administration pour le catalogue MCP avec des bascules d'activation/désactivation, la gestion des informations d'identification, la création de webhook et de hook, la configuration de la mémoire, les contrôles de passerelle et une page Système avec vérification avant mise à jour et partage de débogage one-click. Vous n'avez plus besoin de vous connecter via SSH et de modifier config.yaml pour connecter un nouveau canal de messagerie ou un nouveau serveur MCP : tout est maintenant point-and-click. (#36704, #36736, #37211, #38205, #38600 — @teknium1)
  • Hermes Desktop parle chinois simplifié — 简体中文 complet dans l'interface graphique de chat — L'application de bureau propose désormais une traduction complète en chinois simplifié (简体中文) sur chaque surface de l'interface utilisateur : la fenêtre de discussion elle-même, la barre latérale, les paramètres, le centre de commande, le cron, la messagerie, les profils, les compétences, les agents, etc. L'anglais reste la langue par défaut ; changez de langue dans les paramètres d'apparence et le choix persiste dans votre configuration (display.language). Il est construit sur une couche i18n correctement typée, donc ajouter plus de langues à partir d'ici est simple. (#38241 — @JimLiu)
  • Ensemble de compétences par défaut plus léger – Hermes ne livre que ce dont vous avez réellement besoin – L'ensemble de compétences groupé a été délibérément réduit. Les compétences qui étaient redondantes ou mortes ont disparu (spotify — remplacé par les 7 outils du plugin Spotify natif ; linear — remplacé par hermes mcp install linear ; kanban-codex-lane, debugging-hermes-tui-commands, un orphelin domain obsolète et plusieurs marqueurs de catégorie vides). Les compétences plus lourdes ou de niche sont passées de groupées à facultatives (l'ensemble créatif Baoyu, dspy, subagent-driven-development, minecraft-modpack-server, pokemon-player, hermes-s6-container-supervision) – toujours à un hermes skills install, mais non chargé par défaut. Et une nouvelle porte de pertinence environments: maintient les compétences spécifiques au contexte (kanban, docker/s6) hors de l'index de compétences pour les utilisateurs qui ne les utiliseront jamais, tout en les chargeant sur demande explicite. Le résultat : une liste de compétences par défaut plus petite et plus précise, moins de bruit dans le sélecteur et une invite plus légère. Le conservateur peut désormais également supprimer les compétences intégrées inutilisées (pas seulement celles créées par l'agent), avec un suivi de l'utilisation pour chaque compétence. (#39028, #36701, #36228 — @teknium1)
  • NVIDIA/skills est désormais un robinet de compétences trusted intégré — NVIDIA/skills rejoint OpenAI, Anthropic et HuggingFace en tant que robinet trusted par défaut dans le Skills Hub — détectable, consultable, consultable et mis à jour automatiquement via le même pipeline. Les compétences vérifiées de NVIDIA pour CUDA-X, AIQ, cuOpt et le reste de leur pile de produits sont accessibles en une seule installation, avec de véritables étiquettes de catégorie du side-car skills.sh.json du référentiel. (#34333 — @teknium1)
  • Configuration rapide via Nous Portal — de l'installation au premier message en quelques secondes — La première configuration a été réduite à deux chemins clairs : la configuration rapide (connectez-vous avec Nous Portal, obtenez un sélecteur de modèle, commencez à discuter immédiatement) ou la configuration complète (l'assistant détaillé pour les utilisateurs expérimentés). hermes portal est désormais l'alias lisible par l'homme qui exécute le flux Nous complet à configuration rapide. Le menu de première exécution explique la différence en ligne afin que les nouveaux arrivants ne devinent pas. L'objectif : un tout nouvel utilisateur ne devrait pas avoir besoin de lire des documents pour envoyer son premier message. (#35723, #36227, #38449, #38465 — @teknium1, @kshitijk4poor)
  • Sélecteur de modèle flou, partout — tapez quelques lettres, trouvez votre modèle — Le sélecteur de modèle effectue désormais une recherche floue dans l'application de bureau, le tableau de bord Web, TUI et CLI. Surfaces de type « v4fl » et deepseek-v4-flash ; les fournisseurs multi-points de terminaison sont regroupés sous une seule ligne au lieu d'encombrer la liste de doublons, et chaque ligne comporte une description afin que vous sachiez ce que vous choisissez. Le catalogue est actualisé toutes les heures au lieu de quotidiennement, de sorte que les nouveaux modèles apparaissent le jour même de leur lancement. Nouvelle fenêtre : deepseek-v4-flash, MiniMax-M3 avec contexte 1M, qwen3.7-plus. (#36928, #35227, #35756, #35659, #36214 — @kshitijk4poor, @teknium1)
  • /undo [N] — reprendre les N derniers tours — Vous avez dit une mauvaise chose ou envoyé l'agent sur une mauvaise voie ? /undo sauvegarde N tours d'utilisateur, préremplit votre dernier message afin que vous puissiez le modifier et le renvoyer, et supprime automatiquement les tours intermédiaires. Il fonctionne dans le CLI, le TUI et sur toutes les plateformes de messagerie (Telegram, Discord, etc.) avec une parité totale. Ferme une demande de longue date (#21910). (#36229, #36699 — @teknium1)
  • Choisissez votre interface par défaut — cli ou tui — Vous pouvez désormais définir si hermes chat vous place par défaut dans le CLI classique ou dans l'Ink TUI, avec un indicateur --cli pour remplacer par invocation. Le TUI dispose également d'une seule commande /model unifiée et d'une superposition de sessions pour basculer entre les sessions en direct. Utilisez l'interface que vous aimez réellement. Hermes Agent v0.16.0 (v2026.6.5)

Release Date: June 5, 2026 Since v0.15.2: 874 commits · 542 merged PRs · 1,962 files changed · 205,216 insertions · 46,217 deletions · 399 issues closed (2 P0, 62 P1, 16 security-tagged) · 170 community contributors (including co-authors)

The Surface Release. Hermes meets you wherever you work. A brand-new native desktop app — built across 100 PRs and 159 commits in a single week — gives you Hermes as a real macOS/Linux/Windows application: one-click install, in-app self-update, drag-and-drop files into chat, an inline model picker in the status bar, concurrent multi-profile sessions, a full Simplified Chinese translation, and the ability to connect to a remote Hermes gateway over OAuth or username/password. Alongside it, the web dashboard grew a full browser-based administration panel (MCP catalog, messaging channels, credentials, webhooks, memory, pluggable OIDC / username-password login), and first-time setup got a "Quick Setup via Nous Portal" path that gets you from install to first message in seconds. The default skill set was trimmed to what you actually need, NVIDIA/skills joined the trusted Skills Hub taps, the model picker is now fuzzy-searchable everywhere (desktop, web, TUI, CLI), and /undo finally lets you take back the last N turns. 2 P0 and 62 P1 closures ride along, plus a security round (CVE-2026-48710 Starlette pin, SSRF off-loop hardening, subprocess credential stripping).

✨ Highlights

  • Hermes Desktop — a real native app, not a terminal wrapper — This is the headline. There's now a apps/desktop/ Electron application that installs like any other desktop app on macOS, Linux, and Windows, updates itself in place from inside the app, and gives you a polished GUI for everything Hermes does. You get a proper chat window with streaming, a session list you can archive and search, drag-and-drop files anywhere in the chat area, clipboard image paste, a Cmd+K command palette, and a model picker right in the status bar. If you've been telling friends "it's a CLI agent" and watching their eyes glaze over — now you can just send them an installer. None of this existed a week ago. (#20059, #35607, #37099, #37379, #38631 — @OutThisLife, @jquesnelle, @ethernet8023, @austinpickett, @benbarclay)

  • Run the desktop app against a remote Hermes — sign in with OAuth or username/password — The desktop app doesn't have to run Hermes locally. Point it at a remote Hermes gateway (your homelab, a hosted box, a teammate's server) and it connects over a secure WebSocket, authenticating with OAuth or a username/password login — no fiddling with --insecure flags or hand-copied session tokens. Each profile can target its own remote host, and you can run concurrent sessions across multiple profiles in one window with cross-profile @session links. The practical version: your laptop runs a thin GUI, the heavy agent runs wherever your API keys and compute live. (#37888, #38851, #39330, #39778 — @benbarclay, @OutThisLife, @teknium1)

  • The web dashboard is now a full admin panel — configure everything from the browser — The dashboard grew from "view your sessions" into a complete administration surface. There's a Channels page that sets up every gateway messaging platform (Telegram, Discord, Slack, etc.) from the browser, an admin panel for the MCP catalog with enable/disable toggles, credential management, webhook and hook creation, memory configuration, gateway controls, and a System page with check-before-update and one-click Debug Share. You no longer have to SSH in and edit config.yaml to wire up a new messaging channel or MCP server — it's all point-and-click now. (#36704, #36736, #37211, #38205, #38600 — @teknium1)

  • Hermes Desktop speaks Simplified Chinese — full 简体中文 in the chat GUI — The desktop app now ships a complete Simplified Chinese (简体中文) translation across every UI surface — the chat window itself, sidebar, settings, command center, cron, messaging, profiles, skills, agents, the lot. English stays the default; switch language in Appearance settings and the choice persists to your config (display.language). It's built on a proper typed i18n layer, so adding more languages from here is straightforward. (#38241 — @JimLiu)

  • Leaner default skill set — Hermes ships only what you actually need — The bundled skill set got a deliberate trim. Skills that were redundant or dead are gone (spotify — superseded by the native Spotify plugin's 7 tools; linear — superseded by hermes mcp install linear; kanban-codex-lane, debugging-hermes-tui-commands, a stale domain orphan, and several empty category markers). Heavier or niche skills moved from bundled to optional (the Baoyu creative set, dspy, subagent-driven-development, minecraft-modpack-server, pokemon-player, hermes-s6-container-supervision) — still one hermes skills install away, just not loaded by default. And a new environments: relevance gate keeps context-specific skills (kanban, docker/s6) out of the skills index for users who'll never use them, while still loading them on explicit request. The result: a smaller, sharper default skill list, less noise in the picker, and a lighter prompt. The curator can now prune unused built-in skills too (not just agent-created ones), with usage tracked for every skill. (#39028, #36701, #36228 — @teknium1)

  • NVIDIA/skills is now a built-in trusted skills tap — NVIDIA/skills joins OpenAI, Anthropic, and HuggingFace as a default trusted tap in the Skills Hub — discoverable, browsable, searchable, and auto-updating through the same pipeline. NVIDIA's verified skills for CUDA-X, AIQ, cuOpt and the rest of their product stack are one install away, with real category labels from the repo's skills.sh.json sidecar. (#34333 — @teknium1)

  • Quick Setup via Nous Portal — from install to first message in seconds — First-time setup was thinned down to two clear paths: Quick Setup (sign in with Nous Portal, get a model picker, start chatting immediately) or Full Setup (the detailed wizard for power users). hermes portal is now the human-readable alias that runs the full quick-setup Nous flow. The first-run menu explains the difference inline so newcomers aren't guessing. The goal: a brand-new user shouldn't need to read docs to send their first message. (#35723, #36227, #38449, #38465 — @teknium1, @kshitijk4poor)

  • Fuzzy model picker, everywhere — type a few letters, find your model — The model picker now does fuzzy search across the desktop app, web dashboard, TUI, and CLI. Type "v4fl" and deepseek-v4-flash surfaces; multi-endpoint providers are grouped under one row instead of cluttering the list with duplicates, and each row carries a description so you know what you're picking. The catalog refreshes hourly instead of daily, so new models show up the same day they launch. New this window: deepseek-v4-flash, MiniMax-M3 with 1M context, qwen3.7-plus. (#36928, #35227, #35756, #35659, #36214 — @kshitijk4poor, @teknium1)

  • /undo [N] — take back the last N turns — Said the wrong thing, or sent the agent down a bad path? /undo backs up N user turns, prefills your last message so you can edit and resend, and soft-deletes the turns in between. It works in the CLI, the TUI, and across messaging platforms (Telegram, Discord, etc.) with full parity. Closes a long-standing request (#21910). (#36229, #36699 — @teknium1)

  • Choose your default interface — cli or tui — You can now set whether hermes chat drops you into the classic CLI or the Ink TUI by default, with a --cli flag to override per-invocation.
