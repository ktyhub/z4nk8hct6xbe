#hermès-agent v2026.3.28

Agent Hermès v0.5.0 (v2026.3.28)

Date de sortie : 28 mars 2026

La version renforcée : fournisseur Hugging Face, révision des commandes /model, sujets de discussion privée Telegram, modal natif SDK, hooks de cycle de vie des plugins, application de l'utilisation des outils pour les modèles GPT, Nix Flake, plus de 50 correctifs de sécurité et de fiabilité et un audit complet de la chaîne d'approvisionnement.

✨ Points forts

  • Nous Portal prend désormais en charge plus de 400 modèles — Le portail d'inférence Nous Research s'est considérablement développé, permettant aux utilisateurs d'Hermes Agent d'accéder à plus de 400 modèles via un point de terminaison de fournisseur unique.
  • Hugging Face en tant que fournisseur d'inférence de première classe — Intégration complète avec HF Inference API, y compris un sélecteur de modèle agent sélectionné qui correspond aux analogues d'OpenRouter, une sonde de point de terminaison /models en direct et un flux d'assistant de configuration (#3419, #3440)
  • Sujets de discussion privée Telegram — Conversations basées sur des projets avec liaison de compétences fonctionnelles par sujet, permettant des flux de travail isolés au sein d'une seule discussion Telegram (#3163)
  • Backend modal natif SDK — Remplacement de la dépendance swe-rex par le modal natif SDK (Sandbox.create.aio + exec.aio), éliminant les tunnels et simplifiant le backend du terminal modal (#3538)
  • Hooks de cycle de vie du plugin activés — Les hooks pre_llm_call, post_llm_call, on_session_start et on_session_end se déclenchent désormais dans la boucle d'agent et CLI/gateway, complétant le système de hook du plugin (#3542)
  • Fiabilité améliorée du modèle OpenAI — Ajout de GPT_TOOL_USE_GUIDANCE pour empêcher les modèles GPT de décrire les actions prévues au lieu d'effectuer des appels d'outils, ainsi que la suppression automatique des avertissements budgétaires obsolètes de l'historique des conversations qui obligeaient les modèles à éviter les outils d'un tour à l'autre (#3528).
  • Nix flake — Version complète d'uv2nix, module NixOS avec mode conteneur persistant, clés de configuration générées automatiquement à partir de la source Python et suffixes PATH pour la convivialité des agents (#20, #3274, #3061) par @alt-glitch
  • Renforcement de la chaîne d'approvisionnement — Suppression de la dépendance litellm compromise, épinglage de toutes les plages de versions de dépendance, régénération de uv.lock avec des hachages, ajout des PR d'analyse du flux de travail CI pour les modèles d'attaque de la chaîne d'approvisionnement et suppression des dépôts pour corriger les CVE (#2796, #2810, #2812, #2816, #3073)
  • Correction des limites de sortie anthropiques — Remplacement du max_tokens 16K codé en dur par des limites de sortie natives par modèle (128K pour l'Opus 4.6, 64K pour le Sonnet 4.6), correction de la "Réponse tronquée" et de l'épuisement du budget de réflexion sur le API anthropique direct (#3426, #3444)

hermes-agent v2026.3.28

Hermes Agent v0.5.0 (v2026.3.28)

Release Date: March 28, 2026

The hardening release — Hugging Face provider, /model command overhaul, Telegram Private Chat Topics, native Modal SDK, plugin lifecycle hooks, tool-use enforcement for GPT models, Nix flake, 50+ security and reliability fixes, and a comprehensive supply chain audit.

✨ Highlights

  • Nous Portal now supports 400+ models — The Nous Research inference portal has expanded dramatically, giving Hermes Agent users access to over 400 models through a single provider endpoint

  • Hugging Face as a first-class inference provider — Full integration with HF Inference API including curated agentic model picker that maps to OpenRouter analogues, live /models endpoint probe, and setup wizard flow (#3419, #3440)

  • Telegram Private Chat Topics — Project-based conversations with functional skill binding per topic, enabling isolated workflows within a single Telegram chat (#3163)

  • Native Modal SDK backend — Replaced swe-rex dependency with native Modal SDK (Sandbox.create.aio + exec.aio), eliminating tunnels and simplifying the Modal terminal backend (#3538)

  • Plugin lifecycle hooks activated — pre_llm_call, post_llm_call, on_session_start, and on_session_end hooks now fire in the agent loop and CLI/gateway, completing the plugin hook system (#3542)

  • Improved OpenAI Model Reliability — Added GPT_TOOL_USE_GUIDANCE to prevent GPT models from describing intended actions instead of making tool calls, plus automatic stripping of stale budget warnings from conversation history that caused models to avoid tools across turns (#3528)

  • Nix flake — Full uv2nix build, NixOS module with persistent container mode, auto-generated config keys from Python source, and suffix PATHs for agent-friendliness (#20, #3274, #3061) by @alt-glitch

  • Supply chain hardening — Removed compromised litellm dependency, pinned all dependency version ranges, regenerated uv.lock with hashes, added CI workflow scanning PRs for supply chain attack patterns, and bumped deps to fix CVEs (#2796, #2810, #2812, #2816, #3073)

  • Anthropic output limits fix — Replaced hardcoded 16K max_tokens with per-model native output limits (128K for Opus 4.6, 64K for Sonnet 4.6), fixing "Response truncated" and thinking-budget exhaustion on direct Anthropic API (#3426, #3444)
