#hermès-agent v2026.8.31

Agent Hermès v0.21.0 (v2026.8.31)

Date de sortie : 31 août 2026 Depuis v0.20.0 : ~5 800 commits · ~2 475 PR fusionnés · ~5 680 fichiers modifiés · ~869 000 insertions · ~135 000 suppressions · ~2 100 problèmes résolus · 760+ contributeurs

La sortie du Panthéon. v0.20.0 a fait d'Hermès le héraut : il a parlé et il a transmis la nouvelle à d'autres agents. Dans v0.21.0, les dieux se rassemblent. Le mode Bot est intégré à l'application de bureau : une société d'agents nommés avec leurs propres visages et des discussions de groupe, où vos robots parlent entre eux (et avec vous) comme une équipe, pas une boîte à outils. Autour de cette colonne vertébrale : les tâches cron ont gagné en mémoire et en continuité afin que les agents planifiés apprennent réellement entre les exécutions, les sous-agents peuvent être pilotés en direct en cours de vol, la surface MCP est devenue un véritable centre de commande et l'agent peut désormais piloter le propre navigateur du bureau. Cette version regroupe tout, depuis les balises de correctif d'infrastructure v0.20.1 à v0.20.6 – ces fenêtres sont entièrement documentées ici.

✨ Points forts

  • Mode Bot — vos agents deviennent une société intégrée — Le mode Bot est désormais une partie intégrée par défaut de l'application de bureau : chaque profil d'agent reçoit un nom, un visage d'avatar déterministe (avec des commandes de randomisation/verrouillage) et une place dans une liste partagée. Créez des discussions de groupe de style Discord où plusieurs robots et vous parlez dans une seule pièce, @-mentionnez n'importe quel robot du compositeur et donnez des noms et des images aux pièces. Avant, « multi-agents » signifiait plomberie ; maintenant, cela ressemble à une application de chat remplie de collègues. (#87886, #88243, #89386, #96726 — @teknium1, @OutThisLife, @dokterdok)
  • hermes peer — DM de bot à robot entre vos agents — N'importe quel agent Hermes peut désormais envoyer des messages à n'importe quel autre par identifiant, via des profils et des passerelles, depuis le CLI ou depuis une conversation. Demandez à votre robot de recherche de transmettre les résultats à votre robot de codage et obtenez la réponse là où vous pourrez la lire. Les réponses arrivent dans le Bot Chat canonique de chaque agent, de sorte que les conversations entre les agents sont durables et inspectables, et non déclenchées et oubliées. (#88725, #88178, #91487 — @teknium1)
  • Tâches Cron qui se souviennent — Les tâches planifiées ont cessé d'être des poissons rouges. Les agents Cron chargent et mettent désormais à jour la mémoire persistante comme tous les autres agents, continuity=true transfère la sortie de chaque exécution dans la suivante (afin qu'un moniteur puisse effectuer une déduplication par rapport à ce qu'il a déjà signalé), chaque tâche reçoit un bloc-notes durable, les tâches en mode moniteur ignorent complètement le LLM lorsque rien n'a changé, et la sortie cron peut atterrir dans le Bot Chat canonique d'un bot - où le bot répond réellement. Votre travail de briefing de 9 heures sait désormais ce qu'il vous a dit hier. (#91447, #80774, #81139, #81138, #91487 — @teknium1, @smwbev)
  • ** Dirigez vos sous-agents pendant qu'ils courent ** — delegate_task a obtenu une orchestration en direct : listez les enfants qui courent, dirigez-en un en plein vol avec une correction de cap, ou arrêtez-le plus tôt et conservez le résultat partiel. Ajoutez en option une validation de schéma JSON sur les sorties enfants, le coût par délégation apparaît dans les résultats et des valeurs par défaut élevées (250 itérations, 10 enfants simultanés) - la délégation est passée du feu et de la prière au travail parallèle réellement géré. (#85232, #81144, #81142, #86506, #86745 — @teknium1)
  • Le centre de commande MCP — Les serveurs MCP et le catalogue ont fusionné en une seule page de bureau cohérente avec une importation « coller n'importe quoi » par glisser-déposer, des vérifications de santé en arrière-plan qui vous incitent à vous réauthentifier avant l'échec d'un appel d'outil, une superposition de coût/utilisation de la flotte affichant les estimations des jetons de schéma et l'utilisation sur 30 jours par serveur, et des liens profonds hermes:// qui installent un serveur MCP avec confirmation explicite. La gestion de vingt serveurs MCP était autrefois une archéologie des fichiers de configuration ; maintenant c'est un tableau de bord. (#87525, #87572, #87576, #87579, #87581 — @teknium1)
  • Une vague de puissance CLI — Ctrl+P ouvre une palette de commandes floues, le sélecteur /model filtre au fur et à mesure que vous tapez, /status affiche le mode de raisonnement, les approbations en attente et l'utilisation du contexte, et la barre d'état peut afficher en direct le pourcentage d'accès au cache, la latence et les jetons/s avec des bascules par champ. De plus : un arrêt d'urgence global, l'épinglage/déverrouillage de session, des espaces réservés de composition rotatifs orientés tâches - et des animaux de terminal de niveau Ghostty, car un compagnon doit avoir un compagnon. (#90730, #90717, #90745, #98250, #98282, #97666 — @teknium1 et travail communautaire récupéré)
  • L'agent pilote le navigateur du bureau — Le navigateur intégré à l'application n'est plus une fenêtre que l'agent ne peut que regarder : Hermes navigue désormais, clicks et le lit directement, et les pages peuvent être affichées dans le navigateur de votre système avec des menus contextuels de liens complets. Demandez-lui de parcourir un site de documentation ou de déboguer une application Web et regardez-le se produire dans votre propre application. (#90197, #89366 – @OutThisLife, @ethernet8023)
  • Six nouveaux fournisseurs et une vague de catalogue de modèles — Le méta-modèle API (Muse Spark) arrive en tant que fournisseur intégré, aux côtés de CommandCode, Tencent TokenPlan, Nebius Token Factory, Ramp Router et Actual Computer. Les catalogues ont récupéré GLM-5.3-Flash, qwen3.8-max/flash, Gemini 3.7 Flash, MiniMax M3 gratuit et Nemotron 3.5 Lightning – et model_overrides vous permet de corriger la fenêtre contextuelle de n'importe quel modèle ou de vous fixer le prix sans attendre une version. (#88565, #88308, #97917, #97916, #97915, #85560 — @teknium1 et communauté)
  • Renforcement de la sécurité à tous les niveaux — Les fichiers d'instructions d'agent protégés (AGENTS.md, compétences, magasins de mémoire) nécessitent désormais toujours une approbation en écriture afin qu'un agent injecté rapidement ne puisse pas réécrire silencieusement ses propres ordres permanents. Une opération de rédaction approfondie a comblé les fuites de secrets concernant les erreurs de terminal, les lectures de fichiers .env, les points de contrôle et les journaux ACP ; le système d'approbation a appris les commandes destructrices de Windows ; et les autorisations macOS survivent enfin aux mises à jour via une identité de signature TCC stable. (#81152, #80965, #84428, #95091 — @teknium1 et communauté)

Hermes Agent v0.21.0 (v2026.8.31)

Release Date: August 31, 2026 Since v0.20.0: ~5,800 commits · ~2,475 merged PRs · ~5,680 files changed · ~869,000 insertions · ~135,000 deletions · ~2,100 issues closed · 760+ contributors

The Pantheon Release. v0.20.0 made Hermes the herald — he spoke, and he carried word to other agents. In v0.21.0 the gods assemble. Bot Mode ships built into the desktop app: a society of named agents with their own faces and group chats, where your bots talk to each other — and to you — like a team, not a toolbox. Around that spine: cron jobs gained memory and continuity so scheduled agents actually learn between runs, subagents can be steered live mid-flight, the MCP surface became a real command center, and the agent can now drive the desktop's own browser. This release rolls up everything from the v0.20.1–v0.20.6 infrastructure patch tags — those windows are fully documented here.

✨ Highlights

  • Bot Mode — your agents become a society, built in — Bot Mode is now a bundled, default-on part of the desktop app: every agent profile gets a name, a deterministic avatar face (with randomize/lock controls), and a place in a shared roster. Create Discord-style group chats where multiple bots and you talk in one room, @-mention any bot from the composer, and give rooms names and pictures. Before, "multi-agent" meant plumbing; now it looks like a chat app full of coworkers. (#87886, #88243, #89386, #96726 — @teknium1, @OutThisLife, @dokterdok)

  • hermes peer — bot-to-bot DMs between your agents — Any Hermes agent can now message any other by handle, across profiles and gateways, from the CLI or from inside a conversation. Ask your research bot to hand findings to your coding bot and get the reply back where you can read it. Replies land in each agent's canonical Bot Chat, so conversations between agents are durable and inspectable, not fire-and-forget. (#88725, #88178, #91487 — @teknium1)

  • Cron jobs that remember — Scheduled jobs stopped being goldfish. Cron agents now load and update persistent memory like every other agent, continuity=true carries each run's output into the next (so a monitor can dedupe against what it already reported), every job gets a durable notepad scratchpad, monitor-mode jobs skip the LLM entirely when nothing changed, and cron output can land in a bot's canonical Bot Chat — where the bot actually responds. Your 9am briefing job now knows what it told you yesterday. (#91447, #80774, #81139, #81138, #91487 — @teknium1, @smwbev)

  • Steer your subagents while they run — delegate_task gained live orchestration: list running children, steer one mid-flight with a course correction, or stop it early and keep the partial result. Add optional JSON-schema validation on child outputs, per-delegation cost surfaced in results, and raised defaults (250 iterations, 10 concurrent children) — delegation went from fire-and-pray to actually managed parallel work. (#85232, #81144, #81142, #86506, #86745 — @teknium1)

  • The MCP command center — MCP servers and the catalog merged into one coherent desktop page with drag-in "paste anything" import, background health checks that nudge you to re-auth before a tool call fails, a fleet cost/usage overlay showing schema token estimates and 30-day usage per server, and hermes:// deep links that install an MCP server with explicit confirmation. Managing twenty MCP servers used to be config-file archaeology; now it's a dashboard. (#87525, #87572, #87576, #87579, #87581 — @teknium1)

  • A CLI power wave — Ctrl+P opens a fuzzy command palette, the /model picker filters as you type, /status shows reasoning mode, pending approvals, and context usage, and the status bar can display live cache-hit %, latency, and tokens/sec with per-field toggles. Plus: a global emergency stop, session pin/unpin, rotating task-oriented composer placeholders — and Ghostty-level terminal pets, because a companion should have a companion. (#90730, #90717, #90745, #98250, #98282, #97666 — @teknium1, and salvaged community work)

  • The agent drives the desktop's browser — The in-app browser stopped being a window the agent could only look at: Hermes now navigates, clicks, and reads it directly, and pages can be popped out to your system browser with full link context menus. Ask it to walk a docs site or debug a web app and watch it happen inside your own app. (#90197, #89366 — @OutThisLife, @ethernet8023)

  • Six new providers and a model catalog wave — Meta Model API (Muse Spark) arrives as a built-in provider, alongside CommandCode, Tencent TokenPlan, Nebius Token Factory, Ramp Router, and Actual Computer. The catalogs picked up GLM-5.3-Flash, qwen3.8-max/flash, Gemini 3.7 Flash, MiniMax M3 free, and Nemotron 3.5 Lightning — and model_overrides lets you patch any model's context window or pricing yourself without waiting on a release. (#88565, #88308, #97917, #97916, #97915, #85560 — @teknium1 and community)

  • Security hardening across the board — Protected agent-instruction files (AGENTS.md, skills, memory stores) now always require write approval so a prompt-injected agent can't quietly rewrite its own standing orders. A deep redaction sweep closed secret-leak gaps across terminal errors, .env file reads, checkpoints, and ACP logs; the approval system learned Windows destructive commands; and macOS permission grants finally survive updates via a stable TCC signing identity. (#81152, #80965, #84428, #95091 — @teknium1 and community)
