#hermès-agent v2026.3.12

Agent Hermès v0.2.0 (v2026.3.12)

Date de sortie : 12 mars 2026

Première version étiquetée depuis v0.1.0 (la fondation pré-publique initiale). En un peu plus de deux semaines, Hermes Agent est passé d'un petit projet interne à une plateforme d'agent IA complète, grâce à une explosion de contributions de la communauté. Cette version couvre 216 demandes de tirage fusionnées provenant de 63 contributeurs, résolvant 119 problèmes.

✨ Points forts

  • Passerelle de messagerie multiplateforme — Plateformes Telegram, Discord, Slack, WhatsApp, Signal, Email (IMAP/SMTP) et Home Assistant avec gestion de session unifiée, pièces jointes multimédias et configuration d'outils par plateforme.
  • MCP (Model Context Protocol) Client — Prise en charge native de MCP avec transports stdio et HTTP, reconnexion, découverte de ressources/invites et échantillonnage (requêtes LLM lancées par le serveur). (#291 — @0xbyt4, #301, #753)
  • Écosystème de compétences : plus de 70 compétences groupées et facultatives dans plus de 15 catégories avec un centre de compétences pour la découverte de la communauté, l'activation/la désactivation par plateforme, l'activation conditionnelle basée sur la disponibilité des outils et la validation des prérequis. (#743 — @teyrebaz33, #785 — @teyrebaz33)
  • Routeur de fournisseur centralisé — Unifié call_llm()/async_call_llm() API remplace la logique de fournisseur dispersée à travers la vision, la synthèse, la compression et la sauvegarde de trajectoire. Tous les consommateurs auxiliaires sont acheminés via un chemin de code unique avec résolution automatique des informations d'identification. (#1003)
  • Serveur ACP — Intégration des éditeurs VS Code, Zed et JetBrains via la norme Agent Communication Protocol. (#949)
  • CLI Skin/Theme Engine — Personnalisation visuelle basée sur les données : bannières, icônes, couleurs, image de marque. 7 skins intégrés + skins YAML personnalisés.
  • Git Worktree Isolation — hermes -w lance des sessions d'agent isolées dans les arbres de travail git pour un travail parallèle en toute sécurité sur le même dépôt. (#654)
  • Points de contrôle et restauration du système de fichiers — Instantanés automatiques avant les opérations destructrices avec /rollback à restaurer. (#824)
  • 3 289 tests — D'une couverture de tests proche de zéro à une suite de tests complète couvrant l'agent, la passerelle, les outils, cron et CLI.

hermes-agent v2026.3.12

Hermes Agent v0.2.0 (v2026.3.12)

Release Date: March 12, 2026

First tagged release since v0.1.0 (the initial pre-public foundation). In just over two weeks, Hermes Agent went from a small internal project to a full-featured AI agent platform — thanks to an explosion of community contributions. This release covers 216 merged pull requests from 63 contributors, resolving 119 issues.

✨ Highlights

  • Multi-Platform Messaging Gateway — Telegram, Discord, Slack, WhatsApp, Signal, Email (IMAP/SMTP), and Home Assistant platforms with unified session management, media attachments, and per-platform tool configuration.

  • MCP (Model Context Protocol) Client — Native MCP support with stdio and HTTP transports, reconnection, resource/prompt discovery, and sampling (server-initiated LLM requests). (#291 — @0xbyt4, #301, #753)

  • Skills Ecosystem — 70+ bundled and optional skills across 15+ categories with a Skills Hub for community discovery, per-platform enable/disable, conditional activation based on tool availability, and prerequisite validation. (#743 — @teyrebaz33, #785 — @teyrebaz33)

  • Centralized Provider Router — Unified call_llm()/async_call_llm() API replaces scattered provider logic across vision, summarization, compression, and trajectory saving. All auxiliary consumers route through a single code path with automatic credential resolution. (#1003)

  • ACP Server — VS Code, Zed, and JetBrains editor integration via the Agent Communication Protocol standard. (#949)

  • CLI Skin/Theme Engine — Data-driven visual customization: banners, spinners, colors, branding. 7 built-in skins + custom YAML skins.

  • Git Worktree Isolation — hermes -w launches isolated agent sessions in git worktrees for safe parallel work on the same repo. (#654)

  • Filesystem Checkpoints & Rollback — Automatic snapshots before destructive operations with /rollback to restore. (#824)

  • 3,289 Tests — From near-zero test coverage to a comprehensive test suite covering agent, gateway, tools, cron, and CLI.
