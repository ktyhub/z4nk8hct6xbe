Agent Hermès v0.14.0 (v2026.5.16)

Date de sortie : 16 mai 2026 Depuis v0.13.0 : 808 commits · 633 PR fusionnés · 1393 fichiers modifiés · 165 061 insertions · 545 numéros fermés (12 P0, 50 P1) · 215 contributeurs de la communauté (y compris les co-auteurs)

La version Foundation – Hermes s'installe et s'exécute n'importe où, est livré avec les éléments que vous souhaitez réellement utiliser et arrête de livrer les éléments que vous n'utilisez pas. xAI Grok débarque en tant que fournisseur SuperGrok OAuth avec grok-4.3 placé dans une fenêtre contextuelle de 1 M. Un nouveau proxy local compatible OpenAI transforme n'importe quel fournisseur Hermes authentifié par OAuth (Claude Pro, ChatGPT Pro, SuperGrok) en un point de terminaison que Codex / Aider / Cline / Continue peut atteindre. x_search devient un outil de recherche X (Twitter) de première classe avec l'authentification par clé OAuth-ou-API. La pile Microsoft Teams est câblée de bout en bout (authentification graphique + écouteur webhook + exécution du pipeline + livraison sortante). Une vague de déballage rend les installations considérablement plus légères : les backends lourds s'installent désormais paresseusement lors de la première utilisation, les extras [all] suppriment tout ce qui est couvert par les deps paresseux et une installation à plusieurs niveaux retombe lorsqu'une roue rejette sur votre plate-forme. pip install hermes-agent fonctionne à partir de PyPI. La vague de démarrage à froid réduit d'environ 19 secondes le lancement du hermes. Les appels CDP du navigateur sont 180 fois plus rapides. Deux nouvelles plates-formes de messagerie (LINE + SimpleX Chat) portent le total à 22. Mise en cache des invites Claude d'une heure entre sessions, /handoff qui transfère réellement les sessions en direct, interface utilisateur de bouton natif pour clarify sur Telegram et Discord, remplissage de l'historique des canaux Discord, diagnostics sémantiques LSP à chaque écriture, un video_generate enfichable unifié, un backend de pilote cua computer_use qui fonctionne enfin avec les fournisseurs non anthropiques, URL clickables dans n'importe quel terminal, intégration du registre Zed ACP via uvx, version bêta native de Windows, 9 nouvelles compétences facultatives, routeur OpenRouter Pareto Code, étreintes de visage/compétences en tant que tap par défaut du trusted. 12 fermetures P0 + 50 P1.

✨ Points forts

  • xAI Grok via SuperGrok OAuth — et grok-4.3 passe à une fenêtre contextuelle de 1 M — Si vous payez pour SuperGrok, vous pouvez désormais utiliser Grok dans Hermes en vous connectant avec votre compte xAI — pas de clé API, pas de facturation séparée. Le transfert transfère également grok-4.3 vers une fenêtre contextuelle de jeton de 1 million, afin que vous puissiez déposer des bases de code entières ou des corpus de recherche dans une seule invite. Comprend une gestion appropriée des erreurs de droit et une page de documentation SSH vers tunnel lorsque vous êtes connecté en SSH dans une boîte distante et que vous devez terminer le flux OAuth. (#26534, #26664, #26644, #26592)
  • Proxy local compatible OpenAI pour les fournisseurs OAuth — Exécutez hermes proxy et vous obtenez un point de terminaison http://localhost:port qui parle OpenAI API mais est soutenu par le fournisseur OAuth auquel vous êtes connecté — Claude Pro, ChatGPT Pro, SuperGrok. Désormais, tout outil qui attend un point de terminaison compatible OpenAI (Codex CLI, Aider, Cline, Continue, vos scripts personnalisés) fonctionne simplement avec votre abonnement existant, aucune clé API n'est requise. Un abonnement, chaque outil. (#25969)
  • x_search — outil de recherche X (Twitter) de première classe — L'agent peut désormais rechercher X directement sans installer de compétence ni configurer une intégration personnalisée. Recherchez dans la chronologie, trouvez des fils de discussion, publiez des publications spécifiques, directement depuis le chat. Authentifiez-vous avec votre connexion X OAuth ou une clé API, selon celle dont vous disposez. (#26763)
  • Microsoft Teams — de bout en bout — Hermes peut désormais lire les messages de Teams et les publier. La pile complète Microsoft Graph est réunie : la fondation auth + client, ​​un écouteur webhook qui reçoit les événements Teams, un runtime de plugin de pipeline et une livraison sortante. Connectez le bot une fois, puis discutez avec votre agent depuis n'importe quel canal, DM ou groupe Teams. (récupérations de #21408–#21411) (#21922, #21969, #22007, #22024)
  • Vague de déballage – installations plus légères, moins d'utilisations – Un pip install hermes-agent propre utilisé pour tout extraire : chaque adaptateur de messagerie SDK, chaque SDK de génération d'image, chaque fournisseur de voix/TTS, que vous les utilisiez ou non. Les extras [all] suppriment tout ce qui est couvert par les dépôts paresseux, l'installateur revient d'un niveau à l'autre lorsqu'une roue ne correspond pas à votre plate-forme, et un vérificateur consultatif de la chaîne d'approvisionnement analyse chaque installation à la recherche de versions dangereuses. Installations plus rapides, empreinte disque réduite, moins de vulnérabilités transitives. (#24220, #24515, #25014, #25038, #25766, #21818)

La roue est livrée avec le pack Ink TUI et le lanceur d'obus, de sorte que l'expérience complète sort de la boîte. (récupération de #26350) (#26593, #26148)

Démarrez une session /new et la première réponse revient plus rapidement et à moindre coût car le cache est encore chaud depuis votre dernière session. L'examen de la mémoire en arrière-plan touche également le cache, de sorte qu'il ne paie pas le prix fort à chaque tour. (#23828, #25434, #24778)
  • Évaluations browser_console 180 fois plus rapides — Lorsque l'agent utilise l'outil de navigation pour inspecter une page ou exécuter JavaScript, ces appels partagent désormais une connexion persistante à Chrome au lieu de lancer une nouvelle session DevTools à chaque fois. La différence est énorme : des choses qui prenaient auparavant quelques secondes par appel reviennent en millisecondes. Les interactions avec les pages du monde réel semblent instantanées. (#23226)

En cours de débogage, passez d'un modèle rapide à un modèle à raisonnement approfondi, ou passez une session entre des profils pour différentes parties d'une tâche. (#23395)
  • Interface utilisateur des boutons natifs pour clarify sur Telegram et Discord — Lorsque l'agent utilise l'outil clarify pour vous poser une question à choix multiples, il affiche désormais de vrais boutons natifs de la plate-forme sur Telegram et Discord au lieu de vous demander de retaper le numéro d'option. Hermes Agent v0.14.0 (v2026.5.16)

Release Date: May 16, 2026 Since v0.13.0: 808 commits · 633 merged PRs · 1393 files changed · 165,061 insertions · 545 issues closed (12 P0, 50 P1) · 215 community contributors (including co-authors)

The Foundation Release — Hermes installs and runs anywhere, ships with the things you actually want to use, and stops shipping the things you don't. xAI Grok lands as a SuperGrok OAuth provider with grok-4.3 bumped to a 1M context window. A new OpenAI-compatible local proxy turns any OAuth-authed Hermes provider — Claude Pro, ChatGPT Pro, SuperGrok — into an endpoint that Codex / Aider / Cline / Continue can hit. x_search lands as a first-class X (Twitter) search tool with OAuth-or-API-key auth. The Microsoft Teams stack is wired end-to-end (Graph auth + webhook listener + pipeline runtime + outbound delivery). A debloating wave makes installs dramatically lighter — heavyweight backends now lazy-install on first use, the [all] extras drop everything covered by lazy-deps, and a tiered install falls back when a wheel rejects on your platform. pip install hermes-agent works from PyPI. The cold-start wave shaves ~19 seconds off hermes launch. Browser CDP calls are 180x faster. Two new messaging platforms (LINE + SimpleX Chat) bring the total to 22. Cross-session 1-hour Claude prompt caching, /handoff that actually transfers sessions live, native button UI for clarify on Telegram and Discord, Discord channel history backfill, LSP semantic diagnostics on every write, a unified pluggable video_generate, a computer_use cua-driver backend that finally works with non-Anthropic providers, clickable URLs in any terminal, Zed ACP Registry integration via uvx, native Windows beta, 9 new optional skills, OpenRouter Pareto Code router, huggingface/skills as a trusted default tap. 12 P0 + 50 P1 closures.

✨ Highlights

  • xAI Grok via SuperGrok OAuth — and grok-4.3 jumps to a 1M context window — If you pay for SuperGrok, you can now use Grok inside Hermes by signing in with your xAI account — no API key, no separate billing. The wire-through also bumps grok-4.3 to a 1M token context window, so you can drop whole codebases or research corpora into a single prompt. Includes proper handling for entitlement errors and an SSH-to-tunnel docs page for when you're SSH'd into a remote box and need to complete the OAuth flow. (#26534, #26664, #26644, #26592)

  • OpenAI-compatible local proxy for OAuth providers — Run hermes proxy and you get a http://localhost:port endpoint that speaks the OpenAI API but is backed by whichever OAuth provider you're signed into — Claude Pro, ChatGPT Pro, SuperGrok. Now any tool that expects an OpenAI-compatible endpoint (Codex CLI, Aider, Cline, Continue, your custom scripts) just works with your existing subscription, no API key required. One subscription, every tool. (#25969)

  • x_search — first-class X (Twitter) search tool — The agent can now search X directly without installing a skill or wiring up a custom integration. Search the timeline, find threads, surface specific posts — straight from the chat. Auth with either your X OAuth login or an API key, whichever you have. (#26763)

  • Microsoft Teams — end-to-end — Hermes can now read messages from Teams and post back. The full Microsoft Graph stack lands together: auth + client foundation, a webhook listener that receives Teams events, a pipeline plugin runtime, and outbound delivery.
