open_clip v4.2.2

La première version 4.x sur PyPI, et elle ajoute des modèles audio-texte officiels NaFlex CLAP pré-entraînés. Il déplace également la formation vers une nouvelle pile et ajoute plusieurs familles de modèles. Les numéros de version 4.x antérieurs étaient uniquement des versions de développement. L'inférence image-texte pré-entraînée est destinée à rester compatible, mais les scripts de formation et les intégrations en aval doivent être révisés. Consultez le guide de migration. Pour rester sur 3.x, exécutez pip install 'open_clip_torch<4'.

Faits saillants

  • NaFlex CLAP : cinq modèles d'audio-texte Apache 2.0 (paramètres 27 M à 340 M) qui acceptent des fichiers audio de longueur variable, formés sur LAION-Audio-XL : XXS, XS, S, M, L
  • NaFlex CLIP : tours d'images à résolution variable et à aspect variable avec traitement par lots à budget symbolique
  • NaFlex GenLIP / GenLAP : sous-titres génératifs d'images et d'audio avec attention préfixe-LM (configurations d'entraînement, pas encore de poids pré-entraînés)
  • Tours de texte modernes : options RoPE, SwiGLU/ReLU² et RMSNorm, texte de longueur variable par lot et tours Hugging Face ModernBERT
  • MaMMUT et CoCa v2 : MaMMUT avec les poids LAION publiés, ainsi que les configurations coca2_* corrigées
  • Pile de formation : wrappers TrainingTask, lots basés sur des dicts, stratégies FSDP2 (--fsdp), torch.compile et regroupement de longueurs
  • Chargement plus sûr des points de contrôle : tous les chargements de points de contrôle utilisent weights_only=True et les poids OpenAI se chargent désormais à partir du Hugging Face Hub au lieu des archives JIT

Notes de mise à niveau

  • PyPI nécessite désormais torch>=2.6 (au lieu de >=2.0)
  • Le --precision par défaut est désormais amp_bf16 (auparavant amp), et le --loss-dist-impl de SigLIP est désormais par défaut gather.
  • --horovod, --torchscript et --trace sont supprimés
  • load_openai_model, list_openai_models, build_model_from_openai_state_dict et trace_model sont supprimés ; utiliser create_model_from_pretrained(..., pretrained='openai') pour les poids OpenAI
  • Les chargeurs de données émettent désormais des lots de dict, et le code de formation devrait transmettre un TrainingTask au lieu d'un modèle séparé et d'une perte.
  • python -m open_clip_train.legacy_main reste disponible comme chemin de compatibilité pour les anciens scripts de formation image-texte Consultez le guide de migration pour connaître la liste complète des modifications.

open_clip v4.2.2

The first 4.x release on PyPI, and it adds official pretrained NaFlex CLAP audio-text models. It also moves training to a new stack and adds several model families. Earlier 4.x version numbers were development versions only.

Pretrained image-text inference is intended to remain compatible, but training scripts and downstream integrations need review. See the migration guide. To stay on 3.x, run pip install 'open_clip_torch<4'.

Highlights

  • NaFlex CLAP: five Apache 2.0 audio-text models (27M to 340M parameters) that take variable-length audio, trained on LAION-Audio-XL: XXS, XS, S, M, L
  • NaFlex CLIP: variable-resolution and variable-aspect image towers with token-budget batching
  • NaFlex GenLIP / GenLAP: generative image and audio captioning with prefix-LM attention (training configs, no pretrained weights yet)
  • Modern text towers: RoPE, SwiGLU/ReLU², and RMSNorm options, per-batch variable-length text, and Hugging Face ModernBERT towers
  • MaMMUT and CoCa v2: MaMMUT with the released LAION weights, plus corrected coca2_* configs
  • Training stack: TrainingTask wrappers, dict-based batches, FSDP2 (--fsdp), torch.compile strategies, and length bucketing
  • Safer checkpoint loading: all checkpoint loads use weights_only=True, and OpenAI weights now load from the Hugging Face Hub instead of JIT archives

Upgrade notes

  • PyPI now requires torch>=2.6 (was >=2.0)
  • The default --precision is now amp_bf16 (was amp), and SigLIP's --loss-dist-impl now defaults to gather
  • --horovod, --torchscript, and --trace are removed
  • load_openai_model, list_openai_models, build_model_from_openai_state_dict, and trace_model are removed; use create_model_from_pretrained(..., pretrained='openai') for OpenAI weights
  • Dataloaders now emit dict batches, and training code should pass a TrainingTask instead of a separate model and loss
  • python -m open_clip_train.legacy_main remains available as a compatibility path for older image-text training scripts

See the migration guide for the full list of changes.
