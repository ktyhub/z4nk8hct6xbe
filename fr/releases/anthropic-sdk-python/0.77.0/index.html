anthropic-sdk-python v0.77.0

Highlights

  • Structured Outputs in Messages — The Messages API now supports schema-constrained responses. Pass the schema through output_config rather than output_format; existing Structured Outputs requests must be migrated to the new request shape.

  • Request-shape migration — Replace top-level output_format usage with output_config in client code and wrappers. This changes the serialized API payload, so tests or middleware that inspect request bodies need updating.

  • Safer beta-header handling — The SDK no longer sends the Structured Outputs beta header when output_format is absent (#1121), preventing unrelated Messages requests from being marked as beta usage.

  • Extended JSON serialization — A custom client-side JSON encoder supports additional Python types, reducing serialization failures for non-native JSON values. Validate how application-specific objects are encoded before relying on this behavior.

  • Compatibility repair — A class that introduced an unintended breaking change was removed (#1333), restoring compatibility for code affected by its introduction.
