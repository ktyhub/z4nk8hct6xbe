Points forts

  • OmniVoice GGUF utilise les GPU AMD, Intel et NVIDIA via Vulkan sous Windows et Linux, et les GPU Intel Arc exécutent OmniVoice
  • L'installation revient à une version de processeur plus petite lorsque les téléchargements PyTorch échouent, et l'application revient au processeur lorsque le GPU échoue
  • Windows charge les modèles un fichier à la fois, et un crash moteur en nomme la cause et propose un redémarrage sur le processeur
  • Le clonage vocal dots.tts fonctionne sous Windows via audio.cpp, sans configuration Python
  • Convert peut conserver votre livraison et prend des vidéos ; Le doublage exporte d'abord les sous-titres et déplace les lignes entre les enceintes

OmniVoice utilise désormais votre GPU AMD, Intel ou NVIDIA, et VoiceStudio devient beaucoup plus difficile à casser. OmniVoice GGUF fonctionne sur n'importe quel GPU Vulkan sous Windows et Linux, dimensionne son modèle en fonction de votre carte et peut rester chargé entre les requêtes (opt-in, Paramètres → Performances), et les GPU Intel Arc exécutent également OmniVoice. En cas de problème, l'application continue désormais : l'installation propose une version de processeur beaucoup plus petite lorsque le téléchargement de PyTorch continue d'échouer, réessaye les téléchargements bloqués et VoiceStudio passe au processeur avec une notification en cas de panne du GPU. Sous Windows, les modèles chargent un fichier à la fois pour éviter un crash au premier lancement, et un crash du moteur nomme la bibliothèque derrière et propose un redémarrage sur le processeur.

Cette version apporte également le clonage vocal dots.tts sur Windows sans configuration Python, Convert qui conserve votre diffusion et prend la vidéo, un doublage qui exporte d'abord les sous-titres et déplace les lignes entre les haut-parleurs, une commande de terminal voicestudio, des mises à jour en arrière-plan, une nouvelle fenêtre d'installation macOS et des centaines de correctifs pour le doublage, la configuration, les livres audio et les applications téléphoniques.

La nouvelle fenêtre d'installation de macOS (#4001).

Mise à jour depuis 0.5.7 : Effectuez la mise à jour intégrée à l'application proposée par 0.5.7 ou installez-la par-dessus votre application existante ; les voix, les projets et les décors sont conservés. Lors du premier lancement, le runtime local met à jour ses packages, y compris la mise à jour de sécurité PyTorch 2.10 (#3884)

Mise à jour à partir d'un 0.5.8 bêta : Rien à faire : le canal Bêta avance automatiquement sur 0.5.8. Pour ne plus recevoir de versions bêta, passez à Stable dans Paramètres → Mises à jour → Mettre à jour le canal.

Exécutant à partir des sources : La démo Gradio et la formation du modèle ne sont plus installées par défaut ; ajoutez le ui ou le train supplémentaire si vous les utilisez (#4027)

VoiceStudio v0.5.8

Highlights

  • OmniVoice GGUF goes cross-vendor on Vulkan — The GGUF path now runs on any Vulkan GPU on Windows and Linux, covering AMD, Intel and NVIDIA cards plus Intel Arc, with model sizing per card and an opt-in resident runtime (Settings → Performance) that skips the reload before every generation (#3965, #3654). Release installers now bundle omnivoice.cpp's tts-server so resident mode survives outside dev builds, falling back to per-request loading when unavailable (#4005), and a Self-test in Settings → Models names the Vulkan device it actually ran on — the quickest way to verify a driver setup before chasing generation bugs (#3993).
  • Failure paths became fallbacks — Setup offers a much smaller CPU build when the PyTorch download keeps failing (#3846) and retries stalled downloads; a startup GPU probe switches to CPU with a notice if the GPU fails (#3845). On Windows, models load one file at a time to avoid first-launch crashes, and engine crashes now name the offending library and offer Restart on CPU. Crash reports include what was running and free memory (#3844), turning anonymous OOMs into diagnosable ones.
  • Source builds drop Gradio and training from the default install — The migration item for anyone running from source: Gradio and WebDataset are no longer installed by default (~81 MB lighter), and the demo and training paths now require the ui and train extras (#4027). Add those explicitly if your workflow uses them. Expect a one-time in-place package update on first launch when coming from 0.5.7, including the PyTorch 2.10 security update (#3884).
  • dots.tts cloning reaches Windows without Python — Voice cloning runs through the audio.cpp runtime, so Windows users skip the Python setup that previously gated the feature. The runtime moves to v0.9.4, but installed Breeze-TTS-2, dots.tts and Sortformer models keep working without a re-download, and the previous runtime continues serving them until you install the update (#3129).
  • Convert and dubbing preserve more source material — Convert voice can keep the original delivery video, returning picture and background when they can be preserved and converted audio plus an explanation when they can't (#3750). Dubbing now exports subtitles first, moves lines between speakers, and can speak the original transcript in the source language to bypass translation entirely (#3747).
  • CLI and quieter updates — A new voicestudio terminal command exposes voices, speech, transcription, dubbing and models with tab completion, auto-starting the app in the background when needed (#3828). Updates download in the background and install on quit with a title-bar progress pill, Restart/Retry controls and a prompt when work is running (#3928), so long sessions aren't interrupted mid-task.

No breaking changes for existing installs.
