photocraft v0.13.0

[!NOTE] FreeBSD aarch64 est supprimé de cette version. Nous avons dû supprimer des versions et nous ne pouvons pas créer cet objectif dans la limite CI de 5 heures pour aucune des applications Craft, nous le supprimons donc pour le moment. Il s'agit d'un bloqueur connu, signalé pour un futur correctif dans storytold/craft-common-actions#39. FreeBSD x86_64 et toutes les autres plateformes sont incluses.

[!NOTE] FreeBSD aarch64 is dropped from this release. We had to cut releases, and we cannot build this target within the 5-hour CI limit for any of the Craft apps, so we are dropping it for now.
