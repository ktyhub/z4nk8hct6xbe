  • Maintenant c'est fait : Content-Aware Move avec un aperçu grossier puis exact pour les grandes sélections ; forme Densité/Plume et masque Densité/Plume dans Propriétés ; Rééchantillonnage de l'exportation en tant que voisin le plus proche ; appareils pour fichiers volumineux (20 MP, 150 couches, 2 Go PSD, 4 Go PSB) ; Warp Text s'ouvre avec la déformation du calque et un aperçu en direct ; tests de ciblage masque/canal avec outil de retouche ; modificateurs de sélection enfoncés avant le glissement.
  • Déplacé vers le haut : Zoom Alt+molette (manquant → partiel) ; l'aperçu du trait en direct couvre désormais le tampon de motif, la gomme d'arrière-plan et le remplacement de couleur ; Les filtres intelligents mappent 41 filtres sur PSD (au lieu de 14) ; les options d'outils et les pinceaux par outil persistent lors des redémarrages.
  • Paramètres qui ne font rien : 24 sur 171 (au lieu de 25 sur 169).
  • Performance : aucun changement par rapport à la référence du 05/10/2026 (3 dans les limites du budget, 22 au-dessus). Scénarios ajoutés P20, P62 et P63 (2 Go PSD, 4 à 5 Go PSB, 3.1 GP New Document), pas encore exécutés.
  • Étages du Corpus : inchangé. FreeBSD aarch64 n'est pas dans cette version : le pipeline de versions partagées l'a supprimé pour chaque application Craft jusqu'à ce qu'elle soit construite dans le temps (storytold/craft-common-actions#40). FreeBSD x86_64 est inclus.

photocraft v0.12.0

Scorecard since v0.11.1

From docs/scorecard.md (done / partial / missing):

| Area | v0.11.1 | v0.12.0 | |---|---|---| | Tools | 33 / 11 / 0 | 36 / 8 / 0 | | File compatibility | 7 / 14 / 6 | 9 / 12 / 6 | | Type | 4 / 3 / 2 | 5 / 3 / 1 | | Workspace and UI | 13 / 6 / 4 | 13 / 7 / 3 | | Open bugs | 29 / 2 / 1 | 31 / 1 / 0 |

  • Now done: Content-Aware Move with a coarse-then-exact preview for large selections; shape Density/Feather and mask Density/Feather in Properties; Export As Nearest Neighbor resample; large-file fixtures (20 MP, 150 layers, 2 GB PSD, 4 GB PSB); Warp Text opens with the layer's warp and previews live; retouch-tool mask/channel targeting tests; selection modifiers pressed before the drag.
  • Moved up: Alt+wheel zoom (missing → partial); live stroke preview now covers Pattern Stamp, Background Eraser and Color Replacement; Smart Filters map 41 filters to PSD (was 14); tool options and per-tool brushes persist across restarts.
  • Settings that do nothing: 24 of 171 (was 25 of 169).
  • Performance: no change to the 2026-10-05 baseline (3 within budget, 22 over). Added scenarios P20, P62 and P63 (2 GB PSD, 4–5 GB PSB, 3.1 GP New Document), not run yet.
  • Corpus floors: unchanged.

FreeBSD aarch64 is not in this release: the shared release pipeline dropped it for every Craft app until it builds in time (storytold/craft-common-actions#40). FreeBSD x86_64 is included.
