#AionUi v2.1.53

Faits saillants

Slack comme canal de discussion

  • Slack n'est plus « à venir » : configurez un jeton de robot et un jeton de niveau application dans Paramètres → Canaux, testez la connexion, choisissez un modèle et gérez quels utilisateurs Slack sont autorisés à parler à votre agent.

Claude et Codex exécutent désormais votre propre installation

  • AionUi envoyait ses propres copies épinglées de Claude et du codex, donc la même invite pouvait se comporter différemment dans AionUi que dans votre terminal – de manière invisible. Les deux exécutent maintenant l'installation que vous avez déjà, de la même manière qu'Antigravity l'a toujours fait, et AionUi vous indique quand votre version diffère de celle par rapport à laquelle cette version a été vérifiée.

Panneau de configuration source, deuxième tour

  • Le panneau est restructuré en sections pliables avec des séparateurs à glisser pour redimensionner et un double click-to-reset, en suivant de près la barre latérale VS Code.
  • La section Modifications bénéficie d'une bascule d'affichage arborescence/liste.
  • Les référentiels sont désormais découverts un niveau en dessous des racines de votre espace de travail, de sorte que les projets multi-dépôts sont récupérés sans configuration manuelle.

Copier le chemin depuis l'explorateur

  • Faites un clic droit sur click sur n'importe quel fichier ou dossier dans l'explorateur de projet pour copier son chemin relatif, ou (sur le bureau) son chemin absolu.

Corrections de bugs

  • Correction d'un écran entièrement blanc sur les versions de bureau packagées, la bascule WebUI et la version Web, causée par une mauvaise division fournisseur-morceaux.
  • Sur les fenêtres étroites, clicliquer sur un fichier dans l'arborescence d'une conversation de projet ouvre désormais réellement l'aperçu. - cli Cliquer avec le bouton droit sur un dossier et choisir "Ajouter au chat" produit désormais une puce et envoie le dossier à l'agent, au lieu de simplement afficher un toast de réussite.
  • Le bouton Copier sur une réponse de l'IA copie désormais tout le tour. Les réponses entrelacées d'appels d'outils ou de réflexions avaient tout perdu avant le dernier segment de texte.
  • Les images à chemin relatif dans les aperçus de démarque du projet ne s'affichent plus cassées.
  • La navigation dans les fichiers de compétences fonctionne désormais dans WebUI, et pas seulement sur le bureau.
  • Antigravity apparaît à nouveau dans la liste déroulante Agent de l'assistant éditeur, et son champ Agent affiche le nom au lieu d'un identifiant brut.
  • Un abonnement à la surveillance de fichiers qui a échoué (hors ligne ou fermeture d'un socket juste après la reconnexion) est désormais réessayé, au lieu de laisser ce dossier obsolète pour toujours.

Mises à jour du moteur (AionCore v0.1.62 → v0.1.63)

  • Les agents exécutant un travail en arrière-plan (un workflow, un shell d'arrière-plan, un sous-agent d'arrière-plan) ne sont plus tués par l'analyseur inactif alors qu'ils sont encore en plein vol.
  • Les agents reçoivent désormais le chemin absolu réel de votre projet au lieu d'un chemin plié.

Remarque

  • La migration unique des paramètres de thème de l'ère Fork a été supprimée. Les thèmes créés avant le système de thèmes actuel ne sont plus automatiquement repris.

AionUi v2.1.53

Highlights

Slack as a Chat Channel

  • Slack moves out of "coming soon": configure a Bot Token and App-Level Token in Settings → Channels, test the connection, pick a model, and manage which Slack users are authorized to talk to your agent.

Claude and Codex Now Run Your Own Install

  • AionUi used to ship its own pinned copies of claude and codex, so the same prompt could behave differently in AionUi than in your terminal — invisibly. Both now run the install you already have, the same way Antigravity always has, and AionUi tells you when your version differs from the one this release was verified against.

Source Control Panel, Round Two

  • The panel is restructured into collapsible sections with drag-to-resize dividers and double-click-to-reset, closely following the VS Code sidebar.
  • The Changes section gains a tree / list view toggle.
  • Repositories are now discovered one level down from your workspace roots, so multi-repo projects are picked up without manual setup.

Copy Path from the Explorer

  • Right-click any file or folder in the project Explorer to copy its relative path, or (on desktop) its absolute path.

Bug Fixes

  • Fixed a full white screen on packaged desktop builds, the WebUI toggle, and the web build — caused by a bad vendor-chunk split.
  • On narrow windows, clicking a file in a project conversation's tree now actually opens the preview.
  • Right-clicking a folder and choosing "Add to chat" now produces a chip and actually sends the folder to the agent, instead of just showing a success toast.
  • The copy button on an AI reply now copies the whole turn. Replies interleaved with tool calls or thinking previously lost everything before the last text segment.
  • Relative-path images in project markdown previews no longer render broken.
  • Browsing skill files now works in WebUI, not just on desktop.
  • Antigravity shows up in the assistant editor's Agent dropdown again, and its Agent field shows the name instead of a raw id.
  • A file-watch subscription that failed (offline, or a socket closing right after reconnect) is now retried, instead of silently leaving that folder stale forever.

Engine updates (AionCore v0.1.62 → v0.1.63)

  • Agents running background work — a workflow, a background shell, a background subagent — are no longer killed by the idle scanner while still mid-flight.
  • Agents now receive the real-case absolute path of your project instead of a case-folded one.

Note

  • The one-time migration of fork-era theme settings has been removed. Themes created before the current theme system are no longer carried over automatically.
