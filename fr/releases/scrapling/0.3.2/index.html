Scrapling v0.3.2

Release Note pour v0.3.2

🚀 Nouveautés

  • Dépendances facultatives du récupérateur : tous les récupérateurs font désormais partie de groupes de dépendances facultatifs, réduisant ainsi la taille du package principal. Ainsi, le module de base scrapling est désormais uniquement l'analyseur, et pour utiliser les récupérateurs ou les options de ligne de commande, vous devez faire : pip install "scrapling[fetchers]". Consultez les instructions d'installation détaillées à partir de [ici] (https://scrapling.readthedocs.io/en/latest/#installation)
  • Configuration par page dans les sessions : les classes de session pour les récupérateurs de navigateur prennent désormais en charge la configuration individuelle par page dans les sessions. Tous les paramètres au niveau de la récupération sont désormais validés comme ceux au niveau de la session. Plus de détails sur le site de documentation ici <br>Exemple : 
    with StealthySession(headless=True, solve_cloudflare=True) as session:    page = session.fetch('https://nopecha.com/demo/cloudflare', google_search=False)
  • Frécupérateurs améliorés basés sur le navigateur
    • Une nouvelle option pour contrôler s'il faut attendre que l'exécution de JavaScript se termine en pages ou non (elle est activée par défaut maintenant, comme avant) 
      with DynamicSession(headless=True, disable_resources=False, network_idle=True) as session:   page = session.fetch('https://quotes.toscrape.com/', load_dom=False)
    • Le mode Furtif est désormais plus fiable dans DynamicFetcher et ses classes de session.
    • DynamicFetcher et StealthyFetcher utilisent désormais moins de ressources (recherche et fermeture automatiques de l'onglet par défaut ouvert par les contextes persistants dans Playwright API)
    • Correction d'un bug logique vital dans la rotation des pages des récupérateurs basés sur le navigateur - les pages précédentes sont désormais remplacées par de nouvelles. (Les onglets réutilisés en rotation sont peut-être contaminés par les paramètres précédents utilisés dessus)
    • StealthyFetcher et ses cours en session sont désormais légèrement plus rapides (5%)
  • Propriété .body améliorée : renvoie désormais le contenu transmis tel quel sans traitement, permettant le téléchargement de fichiers et le traitement des requêtes non HTML. Ci-dessous un exemple de téléchargement d'une photo : 
    from scrapling.fetchers import Fetcherpage = Fetcher.get('https://raw.githubusercontent.com/D4Vinci/Scrapling/main/images/poster.png')with open(file='poster.png', mode='wb') as f:   f.write(page.body)

🐛 Corrections de bugs

  • Problèmes d'encodage résolus : Correction de plusieurs problèmes d'encodage survenus avec certains sites Web en mode analyseur, mcp et commandes d'extraction (résout également les numéros 80 et 81)
  • Analyse plus rapide : en raison de nombreux changements ici et là, la bibliothèque est désormais plus rapide, et cela se reflète dans les tests de performance mis à jour.

🔨 Divers

  • Benchmarks mis à jour : benchmarks de performances actualisés pour comparer les améliorations de vitesse actuelles aux dernières versions de bibliothèques similaires
  • Refactorisation d'une grande partie du code et remplacement du code mort par de meilleures implémentations : moins de code, code plus propre, maintenance plus facile
  • Vidéo YouTube ajoutée : contenu vidéo inclus pour la documentation MCP.
  • Un nouveau modèle de problèmes : nouveau modèle simple pour les utilisateurs qui ne peuvent pas utiliser les modèles actuels.
  • Optimisation du workflow CI : le workflow de tests ignore désormais les exécutions lorsque seuls les fichiers de documentation ou non-code sont modifiés.
  • Dépendances mises à jour : ajout de diverses dépendances aux dernières versions.
  • Améliorations du style de code : application de nouvelles règles de ruff à tous les fichiers.
  • Hooks de pré-commit : configuration de pré-commit mise à jour.

🎯 Derniers changements

  • Suppression du paramètre max_pages de la synchronisation StealthySession pour correspondre à DynamicSession (cela n'a aucun sens de l'avoir dans la version sync) 🙏 Un merci spécial à notre communauté Discord pour tous les tests et commentaires continus

Scrapling v0.3.2

Release Notes for v0.3.2

🚀 New Stuff

  • Optional fetcher dependencies: All fetchers are now part of optional dependency groups, reducing core package size. So the base scrapling module is now the parser only, and to use the fetchers or the commandline options, you have to do: pip install "scrapling[fetchers]". Check out the detailed installation instructions from here

  • Per-page configuration in sessions: Session classes for browser fetchers now support individual configuration per page in sessions. All fetch-level parameters are now validated like session-level ones. More details on the documentation website here <br>Example:

    with StealthySession(headless=True, solve_cloudflare=True) as session:
    page = session.fetch('https://nopecha.com/demo/cloudflare', google_search=False)

  • Improved browser-based fetchers

    • A new option to control whether to wait for JavaScript execution to finish in pages or not (it's enabled by default now, as it was before) 
      with DynamicSession(headless=True, disable_resources=False, network_idle=True) as session:   page = session.fetch('https://quotes.toscrape.com/', load_dom=False)
    • The Stealth mode is now more reliable in DynamicFetcher and its session classes.
    • Both DynamicFetcher and StealthyFetcher are now using fewer resources (Automatically finding and closing the default tab opened by Persistent contexts in Playwright API)
    • Fixed a vital logic bug in browser-based fetchers' pages rotation - previous pages are now replaced with fresh ones. (Tabs that get reused in rotation are possibly contaminated from previous settings used on them)
    • StealthyFetcher and its session classes are now slightly faster (5%)

  • Enhanced .body property: Now returns the passed content as-is without processing, enabling file downloads and handling non-HTML requests. Below is an example of downloading a photo:

    from scrapling.fetchers import Fetcher

page = Fetcher.get('https://raw.githubusercontent.com/D4Vinci/Scrapling/main/images/poster.png')
with open(file='poster.png', mode='wb') as f:
   f.write(page.body)

🐛 Bug Fixes

  • Encoding issues resolved: Fixed multiple encoding problems that happened with some websites in parser, mcp mode, and extract commands (Also solves #80 and #81)
  • Faster parsing: Due to many changes here and there, the library is now faster, and it's reflected in the updated benchmarks

🔨 Misc

  • Updated benchmarks: Refreshed performance benchmarks to compare the current speed improvements to the latest versions of similar libraries
  • Refactored a lot of the code and replaced dead code with better implementations: Fewer code, cleaner code, easier maintenance
  • Added YouTube video: Included video content for MCP documentation.
  • A new issues template: Easy new template for users who can't use the current templates.
  • CI workflow optimization: Tests workflow now skips runs when only documentation or non-code files are changed.
  • Updated dependencies: Bumped up various dependencies to the latest versions.
  • Code style improvements: Applied new ruff rules across all files.
  • Pre-commit hooks: Updated pre-commit configuration.

🎯 Breaking Changes

  • Removed max_pages parameter from sync StealthySession to match DynamicSession (it's meaningless to have in the sync version)

🙏 Special thanks to our Discord community for all the continuous testing and feedback
