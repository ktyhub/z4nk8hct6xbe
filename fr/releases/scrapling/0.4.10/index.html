Scrapling v0.4.10

Une nouvelle mise à jour avec une toute nouvelle intégration de Scrapy et un lot de correctifs communautaires 🎉

[!NOTE] Suivez-nous sur X pour des trucs et astuces quotidiens

🚀 Nouveautés et changements dans la qualité de vie

  • Ajout d'une intégration Scrapy afin que vous puissiez utiliser l'analyse API de Scrapling dans vos projets Scrapy existants sans les réécrire. Mettez le décorateur scrapling_response sur n'importe quel rappel d'araignée, et la réponse qu'il reçoit devient un Scrapling Response pendant que Scrapy continue de gérer l'exploration (Vérifiez la [docs] (https://scrapling.readthedocs.io/en/latest/integrations/scrapy/)) :

    import scrapy
from scrapling.integrations.scrapy import scrapling_response


class QuotesSpider(scrapy.Spider):
    name = "quotes"
    start_urls = ["https://quotes.toscrape.com"]

    @scrapling_response
    def parse(self, response):  # `response` is now a Scrapling Response
        first_quote = response.find_by_text("The world as we have created it", partial=True)
        for quote in [first_quote, *first_quote.find_similar()]:
            yield {"text": quote.get_all_text(strip=True)}

  • Le serveur MCP peut désormais utiliser un navigateur personnalisé compatible avec Chromium pour tous les outils basés sur un navigateur. Définissez-le une fois avec scrapling mcp --executable-path "/path/to/chromium" ou la variable d'environnement SCRAPLING_EXECUTABLE_PATH, ou par requête avec l'argument executable_path, par @samrusani dans #360 (Résout #347)

  • Mise à jour de tous les navigateurs et empreintes digitales. Exécutez scrapling install --force après la mise à jour pour les actualiser.

🐛 Corrections de bugs

  • Correction du texte tronqué (mojibake) provenant des récupérateurs de navigateur sur les sites Web non UTF-8 par @yehudalevy-collab dans #365 (Corrections #364).
  • Correction de LinkExtractor ne filtrant pas les extensions de fichiers composés comme .tar.gz par @renbkna dans #359 (Corrections #349).
  • Correction des analyses en pause perdant leurs requêtes en vol aux points de contrôle, donc la reprise ne les ignore plus par @yetval dans #358.
  • Correction des robots calculant les mauvais délais d'exploration à partir des directives robots.txt Request-rate via la mise à niveau Protego, avec des tests alignés par @Disaster-Terminator dans #355.

Documents

  • Clarification de la manière dont init_script interagit avec le contexte d'exécution isolé de Patchright en mode furtif par @mturac dans #353 (Résout #350).
  • Ajout de la méthode d'installation skills.sh pour la compétence d'agent par @ob-aion dans #363.

Scrapling v0.4.10

Highlights

  • Scrapy integration — Apply @scrapling_response to existing spider callbacks to receive a Scrapling Response with APIs such as find_by_text() and find_similar(), while Scrapy continues handling crawling. Adoption is incremental: decorate only the callbacks that need richer parsing.
  • Custom Chromium for MCP — Browser-backed MCP tools can target a Chromium-compatible executable globally with --executable-path or SCRAPLING_EXECUTABLE_PATH, or per request with executable_path (#360). This supports controlled browser builds without changing application code.
  • Required browser-asset refresh — Browsers and fingerprints were updated; run scrapling install --force after upgrading to avoid continuing with stale assets. For stealth-mode users, also review the clarified interaction between init_script and Patchright’s isolated execution context (#353) before relying on page-global script side effects.
  • Crawl scheduling and resume accuracy — Checkpoint restores now preserve in-flight requests instead of silently skipping them (#358), and the Protego upgrade corrects crawl delays derived from robots.txt Request-rate directives (#355). Resumed crawls and politeness timings may therefore differ from previous behavior.
  • Parsing and content correctness — Browser fetchers now decode non-UTF-8 pages correctly, preventing mojibake from contaminating extracted data (#365). LinkExtractor also excludes compound extensions such as .tar.gz (#359), reducing unintended archive downloads.
  • Compatibility — No breaking changes.

A new update with a brand-new Scrapy integration and a batch of community fixes 🎉

[!NOTE] Follow us on X for daily tips and tricks

🚀 New Stuff and quality of life changes

  • Added a Scrapy integration so you can use Scrapling's parsing API inside your existing Scrapy projects without rewriting them. Put the scrapling_response decorator on any spider callback, and the response it receives becomes a Scrapling Response while Scrapy keeps handling the crawling (Check the docs):

    import scrapy
from scrapling.integrations.scrapy import scrapling_response


class QuotesSpider(scrapy.Spider):
    name = "quotes"
    start_urls = ["https://quotes.toscrape.com"]

    @scrapling_response
    def parse(self, response):  # `response` is now a Scrapling Response
        first_quote = response.find_by_text("The world as we have created it", partial=True)
        for quote in [first_quote, *first_quote.find_similar()]:
            yield {"text": quote.get_all_text(strip=True)}

  • The MCP server can now use a custom Chromium-compatible browser for all browser-based tools. Set it once with scrapling mcp --executable-path "/path/to/chromium" or the SCRAPLING_EXECUTABLE_PATH environment variable, or per request with the executable_path argument, by @samrusani in #360 (Solves #347)

  • Updated all browsers and fingerprints. Run scrapling install --force after updating to refresh them.

🐛 Bug Fixes

  • Fixed garbled text (mojibake) from browser fetchers on non-UTF-8 websites by @yehudalevy-collab in #365 (Fixes #364).
  • Fixed LinkExtractor not filtering compound file extensions like .tar.gz by @renbkna in #359 (Fixes #349).
  • Fixed paused crawls losing their in-flight requests from checkpoints, so resuming no longer skips them by @yetval in #358.
  • Fixed spiders calculating wrong crawl delays from robots.txt Request-rate directives through the Protego upgrade, with tests aligned by @Disaster-Terminator in #355.

Docs

  • Clarified how init_script interacts with Patchright's isolated execution context in stealth mode by @mturac in #353 (Solves #350).
  • Added the skills.sh install method for the agent skill by @ob-aion in #363.
