Faits saillants

  • Exécution du nœud corrigé requis : OpenClaw nécessite désormais le nœud 24.22.1+ sur la ligne 24 ou 26.12.1+ sur la ligne 26, qui rejettent les chaînes TLS signées avec les clés de certificat compromises abordées dans les versions de sécurité Node.js d'octobre 2026. Les images Docker expédient le nœud 24.22.1, les installateurs sélectionnent les environnements d'exécution corrigés et openclaw update refuse les conseils de récupération avant l'installation sur un nœud plus ancien au lieu d'interrompre l'installation en cours.
