openclaw v2026.10.9

##2026.10.9

Faits saillants

  • Corriger les dépendances d'exécution vulnérables : fast-uri 4.2.3 rejette les schémas d'URI et les hôtes mal formés lors de la validation du schéma MCP, les collections Zod surdimensionnées sont rejetées dès le début dans A2UI et l'application intégrée Discord SDK, l'analyse des expéditeurs IMAP utilise nodemailer 10.1.4 afin que les expéditeurs usurpés ne puissent pas passer la porte du jeton de l'expéditeur, et Microsoft Teams utilise le nœud MSAL corrigé 7.1.1. (#187294) Merci @RomneyDa.
  • Appliquez tools.fs.workspaceOnly aux outils créés par Gateway, de sorte que les modifications déléguées nécessitent toujours une approbation et que les outils multimédias restent à l'intérieur de l'espace de travail. (#185094) Merci @eleqtrizit, @RomneyDa et @shakkernerd.
  • Conservez les informations d'identification en direct hors de l'inspection MCP CLI et masquez les secrets Google OAuth client dans les journaux. (#180321, #180308, #183193) Merci @brandon-julio-t, @wr-web, @LeizhenZhang et @RomneyDa.
  • Sécuriser les restaurations de mise à jour ayant échoué : les restaurations de la source Git préservent les modifications de l'opérateur au lieu de réinitialiser la récupération, et les restaurations npm réessayent les refus temporaires de Windows et signalent le mouvement exact qui restaure une installation amorçable au lieu de bloquer la racine du package. (#185201, #184887, #185160, #184889) Merci @wr-web, @syxscott, @LiuwqGit, @shakkernerd et @RomneyDa.
  • Récupérez les bases de données d'agent intactes et les index de texte intégral obsolètes après les modifications du tokenizer SQLite, y compris les instantanés de mise à jour. (#176234, #176220, #176833, #181206) Merci @ndakota79 et @RomneyDa.
  • Réparez les mises à jour complètes de la publication après un remontage tout en conservant le lanceur d'origine et l'assistant de récupération scellé. (#186557, #186527) Merci @ericcaiwx-star, @sennyhoney et @RomneyDa.
  • Migrez de grandes archives de transcriptions sans dépasser les limites de chaînes Node.js. (#170853, #170847) Merci @iamonlv426 et @RomneyDa.
  • Autorisez les agents à récupérer après un disque plein une fois que l'espace devient disponible, sans nécessiter de redémarrage. (#176902) Merci @RomneyDa.

Modifications

Cette version de maintenance se concentre sur les correctifs de dépendance de sécurité, la récupération, la préservation des données et les correctifs de fiabilité.

Correctifs

  • Résolvez les messages de pilotage des médias locaux dans le Codex à partir du propre espace de travail de la session au lieu de l'espace de travail par défaut de l'agent. (#181528) Merci @RomneyDa.
  • Signalez un nettoyage de processus incertain à partir de commandes mises en mémoire tampon, telles que les fournisseurs vocaux locaux CLI, au lieu de le présenter comme un échec de commande ordinaire. (#184270, #184237) Merci @shakkernerd et @RomneyDa.
  • Maintenez actives les connexions de nœuds réapprouvées en publiant l'approbation avec ses faits de couplage validés avant la reprise de la demande. Merci @RomneyDa.
  • Récupérer les passerelles arrêtées lorsque l'activation du service ne peut pas être vérifiée ; conserver le comportement de récupération intact dans le tri Windows. (#172784, #181577, #181698) Merci @SMF12138 et @RomneyDa.
  • Évitez de désinstaller un service Gateway lors d'un arrêt passif de macOS lorsqu'aucun service n'est installé. (#181257) Merci @shakkernerd, @LiuwqGit, @eleqtrizit, @syxscott et @RomneyDa.
  • Récupérez les environnements d'exécution du nœud CLI lors de son lancement à partir de la racine du système de fichiers, y compris les tâches de lancement. (#178112, #177739) Merci @downingkeys et @RomneyDa.
  • Démarrez de nouvelles sessions ACP dans le répertoire de travail demandé au lieu de l'espace de travail par défaut. (#176852, #123557) Merci @yinx65588-boop, @crappier et @RomneyDa.
  • Empêcher les actualisations de modèles qui se chevauchent en cas d'échec des demandes. (#179144) Merci @RomneyDa.
  • Honorez un port SSH explicite 22 dans openclaw gateway probe --ssh au lieu du port configuré de l'alias. (#171092) Merci @zhangguiping-xydt, @obviyus et @RomneyDa.
  • Conservez les métadonnées des compétences telles que les icônes et les pages d'accueil lorsqu'une valeur de métadonnées YAML en ligne comporte un commentaire final. (#171224) Merci @zhangguiping-xydt, @Takhoffman et @RomneyDa.
  • Afficher les options ignorées par le fournisseur dans le texte openclaw infer video generate et la sortie JSON. (#171172) Merci @ly85206559, @obviyus et @RomneyDa.

openclaw v2026.10.9

2026.10.9

Highlights

  • Patch vulnerable runtime dependencies: fast-uri 4.2.3 rejects malformed URI schemes and hosts in MCP schema validation, oversized Zod collections are rejected early in A2UI and the Discord embedded app SDK, IMAP sender parsing uses nodemailer 10.1.4 so spoofed senders cannot pass the sender token gate, and Microsoft Teams uses patched MSAL Node 7.1.1. (#187294) Thanks @RomneyDa.
  • Apply tools.fs.workspaceOnly to Gateway-built tools, so delegate changes still require approval and media tools stay inside the workspace. (#185094) Thanks @eleqtrizit, @RomneyDa, and @shakkernerd.
  • Keep live credentials out of MCP CLI inspection and mask Google OAuth client secrets in logs. (#180321, #180308, #183193) Thanks @brandon-julio-t, @wr-web, @LeizhenZhang, and @RomneyDa.
  • Make failed update rollbacks safe: Git-source rollbacks preserve operator edits instead of resetting the checkout, and npm rollbacks retry transient Windows denials and report the exact move that restores a bootable install instead of stranding the package root. (#185201, #184887, #185160, #184889) Thanks @wr-web, @syxscott, @LiuwqGit, @shakkernerd, and @RomneyDa.
  • Recover intact agent databases and stale full-text indexes after SQLite tokenizer changes, including update snapshots. (#176234, #176220, #176833, #181206) Thanks @ndakota79 and @RomneyDa.
  • Repair publication-complete updates after a remount while retaining the original launcher and sealed recovery helper. (#186557, #186527) Thanks @ericcaiwx-star, @sennyhoney, and @RomneyDa.
  • Migrate large transcript archives without exceeding Node.js string limits. (#170853, #170847) Thanks @iamonlv426 and @RomneyDa.
  • Allow agents to recover after a full disk once space becomes available, without requiring a restart. (#176902) Thanks @RomneyDa.

Changes

This maintenance release focuses on security dependency patches, recovery, data preservation, and reliability fixes.

Fixes

  • Resolve local media in Codex steering messages from the session's own workspace instead of the agent's default workspace. (#181528) Thanks @RomneyDa.
  • Report uncertain process cleanup from buffered commands, such as local CLI speech providers, instead of presenting it as an ordinary command failure. (#184270, #184237) Thanks @shakkernerd and @RomneyDa.
  • Keep reapproved node connections alive by publishing the approval with its committed pairing facts before the request resumes. Thanks @RomneyDa.
  • Recover stopped Gateways when service activation cannot be verified; retain untouched-recovery behavior in Windows triage. (#172784, #181577, #181698) Thanks @SMF12138 and @RomneyDa.
  • Avoid uninstalling a Gateway service during a passive macOS stop when no service is installed. (#181257) Thanks @shakkernerd, @LiuwqGit, @eleqtrizit, @syxscott, and @RomneyDa.
  • Recover CLI Node runtimes when launched from the filesystem root, including launchd jobs. (#178112, #177739) Thanks @downingkeys and @RomneyDa.
  • Start new ACP sessions in the requested working directory instead of the default workspace. (#176852, #123557) Thanks @yinx65588-boop, @crappier, and @RomneyDa.
  • Prevent overlapping model refreshes from failing requests. (#179144) Thanks @RomneyDa.
  • Honor an explicit SSH port 22 in openclaw gateway probe --ssh instead of the alias's configured port. (#171092) Thanks @zhangguiping-xydt, @obviyus, and @RomneyDa.
  • Keep skill metadata such as icons and homepages when an inline YAML metadata value has a trailing comment. (#171224) Thanks @zhangguiping-xydt, @Takhoffman, and @RomneyDa.
  • Show provider-ignored options in openclaw infer video generate text and JSON output. (#171172) Thanks @ly85206559, @obviyus, and @RomneyDa.
