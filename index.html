Method

How STAGS collects, normalises and publishes release notes.

View →
01 Collect A scheduled job queries the GitHub Releases API for every tracked repository, skipping drafts, empty bodies and pre-releases unless configured otherwise.
02 Normalise Each release is reduced to a stable record: project, semantic version, publish date, release channel and a one-line summary extracted from the body.
03 Publish Notes are stored as Markdown in the repository and rendered as static pages on every push, so the site stays fast and every entry has a stable URL.
