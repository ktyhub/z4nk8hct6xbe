Método

Como a STAGS coleta, normaliza e publica release notes.

Ver →
01 Coletar Um trabalho agendado consulta o GitHub Releases API para cada repositório rastreado, ignorando rascunhos, corpos vazios e pré-lançamentos, a menos que seja configurado de outra forma.
02 Normalizar Cada lançamento é reduzido a um registro estável: projeto, versão semântica, data de publicação, canal de lançamento e um resumo de uma linha extraído do corpo.
03 Publicar As notas são armazenadas como Markdown no repositório e renderizadas como páginas estáticas em cada push, para que o site permaneça rápido e cada entrada tenha um URL estável.
