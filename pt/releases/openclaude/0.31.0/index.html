openclaude v0.31.0

0.31.0 (2026-09-22)

Features

  • launcher: support --max-old-space-size-percentage (#2219) (055e5d5)
  • providers: add Command Code hybrid gateway (#2196) (5b9daef)
  • query: configure idle timeout (#2233) (876fb79)
  • skills: add verify for revocations and eyebrow drift checks (#2215) (eb3c590)
  • skills: enforce registry revocations.json on install (#2187) (0ea8eef)
  • web-search: add Ollama backend (#2234) (70d97fd)
  • zai: add GLM-5.3-Flash Coding Plan support (#2185) (aceacf0)

Bug Fixes

  • agent: forward subagent permission prompts to parent session (#2235) (a07b06c)
  • api: validate API_TIMEOUT_MS in the native Anthropic clients (#2169) (35d7edc)
  • bg: clean up old completed session artifacts (#2167) (70fe2de)
  • chrome: launch the packaged CLI entrypoint in npm installs (#2146) (bfb44ff)
  • ci: restore main validation (#2236) (5fb5abb)
  • ctx: let explicit overrides beat discovered context windows (#2082) (3451187), closes #2081
  • frontmatter: anchor the closing --- to the start of a line (#2027) (cbbe10f)
  • hooks: preserve compound Bash commands on Windows (#2217) (0c2043f)
  • identify OpenCode Go requests (#2203) (3609d75)
  • image: allow large/metadata-less screenshots through on resize failure (#1964) (#1970) (2e687df)
  • mcp: resolve server names by own-property, not the prototype chain (#1983) (c3930ca)
  • openai-shim: request streaming usage from compatible local providers (#2144) (decad0e)
  • plugins: keep Windows marketplace cache on copy ENOENT (#2220) (e2b021d)
  • profiles: apply context limit to all profile models (#2201) (0b68e57)
  • sdk: preserve async generator session context (#2204) (0abfca3)
  • xai: validate OAuth state before settling callbacks (#2228) (d16318a)

Performance Improvements

  • bg: avoid full scans for exact session IDs (#2166) (55e9b24)
