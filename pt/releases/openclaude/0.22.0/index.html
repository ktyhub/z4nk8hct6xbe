openclaude v0.22.0

0.22.0 (2026-07-06)

Features

  • lsp: expose captured diagnostics (#1813) (5b1db55)
  • report: render task reports as markdown (#1826) (8182a46)
  • resume: group branched sessions in picker (#1824) (166d0ce)
  • ux: honest feedback pass — visible retries, statusline truncation marker, hint grace period (#1862) (77c0a0d)

Bug Fixes

  • api: quiet expected side-task aborts (#1868) (62fa7d4)
  • bash: share parser analysis across checks (#1735) (cd1cf3c)
  • bash: surface rolled-output file path on non-zero exit (#1359) (#1392) (0c9b814)
  • bash: use indexOf instead of lastIndexOf for multi-flag shell prefix (#1851) (68fcb91)
  • bound profiler performance entries (#1865) (ad796e0)
  • build: shim jsxDEV when bundling production React — TUI rendered nothing (#1863) (203f055)
  • clipboard: use .NET Clipboard.GetImage() for Windows raw bitmap paste (#1855) (2ac20c7)
  • codex: make Codex alias lookup prototype-safe (#1833) (d03b6a8)
  • format: show sub-second durations with one decimal instead of "0s" (#1820) (784d9a9)
  • gitdiff: count in-hunk lines that start with ++ or -- in raw diff stats (#1843) (069febb)
  • governance controls for memory and git attribution (#1806) (00b8c15)
  • lsp: suppress empty diagnostic deliveries (#1859) (9700bd3)
  • memory: prevent reported idle retention paths (#1856) (354feb4)
  • memory: recover from autocompact overflow failures (#1858) (cd13a61)
  • memoryscan: abort remaining workers when one throws on iterator … (#1836) (b73a879)
  • model: resolve [1m]-tagged aliases when 1M context is disabled (#1822) (e6019d3)
  • openai-shim: recover stalled provider streams (#1817) (67227cf)
  • openai-shim: strip store when baseUrl points at Mistral (#1047) (deb4176), closes #739
  • openai-shim: wire stream controller abort (#1828) (bb61d84)
  • permissions: make legacy tool-name alias lookup prototype-safe (#1847) (b9b5685)
  • plugins: match reserved-marketplace git URL owner by host, not substring (#1840) (17f4a5b)
  • query: clean up lifecycle tool tracking (#1845) (d1530c2)
  • query: configure hard max and abort reasons (#1850) (5226fb9)
