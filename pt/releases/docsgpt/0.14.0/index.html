DocsGPT 0.14.0

Highlights

  • Agentic retrieval and answering — The agent-retriever workflow and logging stack (#1648), ReActAgent refactor (#1721), and agent-assisted answering/search (#1693) enable multi-step, tool-driven retrieval instead of relying solely on one-shot generation. API clients should verify thought parameter handling for /api/answer after the fix in #1734.
  • Extensible tools and providers — Tool calls are now tracked (#1630), invalid tool names are handled (#1625), and tool results are shortened for cleaner output (#1774). New Brave (#1684), ntfy (#1692), and ReadWebpage (#1792) tools expand agent capabilities; Novita support (#1689) and the Azure OpenAI signature fix (#1702) broaden provider options. Retest custom integrations after the LLM-handler refactor (#1824).
  • Reusable agents and access control — Webhooks (#1755), sharing and pinning (#1775, #1801), documentation agents (#1806), and image upload/retrieval (#1849) make agents more suitable for team and external workflows. JWT authentication and token management (#1701), alongside analytics and feedback (#1647), add identity and usage visibility; review permissions and webhook payload exposure before enabling these broadly.
  • Knowledge-base maintenance and rendering — Chunks can now be inspected, added, and deleted (#1624), giving developers direct control over retrieval context—but mutations can change answer quality and citations. Upload refactoring (#1621), filesystem abstraction (#1742), attachment storage changes (#1768), and non-ASCII filename handling (#1838) improve ingestion robustness, while Mermaid integration (#1732) supports diagram-rich documentation.
  • Deployment and widget compatibility — The React widget moves to 0.5.1 with source display (#1637, #1809); update any pinned widget assets. Docker fixes address .env loading, volumes/users, and OPENAI_BASE_URL plus Ollama connectivity (#1700, #1790, #1791), while Arm builds and Windows setup broaden deployment options (#1615, #1729). Retest custom frontend and provider code after major dependency upgrades, including react-redux 9 (#1524) and google-genai 1.x (#1652).
  • Breaking changes — None announced in this changelog.
