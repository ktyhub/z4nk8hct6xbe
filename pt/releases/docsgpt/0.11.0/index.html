DocsGPT 0.11.0

Highlights

  • Database model migration — PRs #1062 and #1118 ("Migrating database to new model") are the one change that demands operator action: back up your data and run the migration before starting the new backend, or existing conversations/sources may be unreadable. This is effectively a breaking upgrade for existing deployments; fresh installs are fine, but budget a maintenance window and do not reuse an old DB volume unmodified.

  • Milvus becomes a first-class vector backend — #1045 lands Milvus support in main alongside the existing stores, so teams already running Milvus can reuse that infrastructure instead of provisioning a separate one. Note the client libraries also moved in this release — qdrant-client 1.9→1.11 (#1081) and Elasticsearch 8.12→8.15.1 (#1067, #1144) — so verify your retriever/index behavior against the new client versions.

  • React Widget overhaul — The embeddable widget is the single most-changed surface: new size options including a large preset (#1084, #1107), a Next.js compatibility fix (#1088), upgraded options (#1089), stream-endpoint sync with error handling (#1092), feedback collection (#1117), scroll fixes during streaming (#1113), and a deprecated dependency replaced (#1111). If you embed it, pin your version and re-test — several props and behaviors shifted, and the docs were reworked in #1093.

  • Streaming and source delivery — #1087 fixes a streaming bug specific to newly created conversation IDs, and #1140 adds streamed sources so citations arrive alongside the answer rather than trickling in afterward. The conversation sources UI was reworked (#1075), shared conversations now hydrate their sources (#1120), and remote sources can be synced (#1152). Better perceived latency, but anyone parsing the response stream should re-check their handling of the new source payload.

  • OpenAPI-compliant endpoints and easier proxying — #1154 adds OpenAPI-spec-compliant endpoints and #1040 introduces a reusable frontend API client, while #1112 simplifies proxying and #1044 corrects the delete-all HTTP method type. This makes generated clients and programmatic integration far more practical — a good moment to regenerate hand-written clients and confirm whether older endpoint shapes have been deprecated.

  • New observability and ingestion paths — Logging (#1110) plus an Analytics/Logs dashboard (#1116) finally give operators visibility that was previously missing, and CSV upload (#1109) with an upgraded unstructured (#1064) broaden supported formats. Watch the dependency churn: remark-gfm was bumped to 4.0.0 then reverted (#1071, #1085, #1086) over react-markdown incompatibility, and Redux Toolkit jumped to 2.2.7 (#1069) and LangChain to 0.2.10 (#1133) — validate that custom theming and builds still pass.
