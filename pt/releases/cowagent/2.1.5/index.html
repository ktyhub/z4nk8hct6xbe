🗂 Espaço de trabalho e visualização de arquivos

A página de bate-papo ganha uma visão visual do espaço de trabalho: documentos, páginas da web e imagens que o Agente produz podem ser visualizados no local. Tanto o console Web quanto o desktop client suportam isso.

  • Navegação no espaço de trabalho: navegue pelos arquivos no diretório do espaço de trabalho no painel, com pesquisa e download para local.
  • Visualização do arquivo: páginas HTML, documentos e imagens são abertos diretamente no painel lateral, e os caminhos dos arquivos em uma resposta são renderizados como cartões clickable.
  • Referências de arquivo: arraste um arquivo do espaço de trabalho para a conversa ou use @ na caixa de entrada para fazer referência a arquivos e diretórios e colocá-los no contexto.

🔧 Melhorias nas ferramentas principais

Uma passagem sistemática pelas ferramentas de pesquisa, leitura, gravação, edição e shell de arquivos, fortalecendo as habilidades de manipulação e codificação de arquivos do Agente.

  • Nova ferramenta de pesquisa de arquivos: search_files pesquisa o espaço de trabalho por conteúdo ou por nome de arquivo, apoiado por ripgrep por padrão — notavelmente mais rápido em diretórios grandes. Obrigado @Maaayhan (#2982)
  • Saída de leitura numerada de linha: a saída read agora sempre carrega números de linha, tornando mais fácil localizar e citar linhas específicas.
  • Edições mais precisas: edit não reescreve mais o recuo circundante em uma correspondência difusa e não chega mais à ocorrência errada quando o texto se repete; substituir tudo foi adicionado; um arquivo modificado fora do Agente agora é sinalizado.
  • Verificações de sintaxe em tempo de gravação: write / edit validam o formato dos arquivos estruturados antes da gravação e analisam os arquivos de origem para relatar erros de sintaxe ao Agente.
  • Comandos em segundo plano: bash pode executar um comando em segundo plano, para trabalhos de longa duração, como iniciar um serviço ou seguir logs; o tempo limite padrão para comandos em primeiro plano foi aumentado.
  • O cancelamento entra em vigor imediatamente: clicking parar ou executar /cancel encerra o comando que está sendo executado no momento.

🧠 Gerenciamento de Contexto

  • Compactação de contexto: o novo comando /compact resume e compacta o contexto da conversa sob demanda, reduzindo efetivamente o uso de token.

CowAgent 2.1.5

Highlights

  • Security fixes are the upgrade priority — Closes a prompt-injection chain that could rewrite MCP configuration, execute arbitrary commands, and steal keys (#2968), plus an edit bypass exposing ~/.cow/.env. This is especially important when processing untrusted repositories or web content.
  • File tools are faster and less error-prone — New ripgrep-backed search_files supports filename and content searches (#2982). read always includes line numbers; edit preserves indentation, avoids incorrect repeated-text matches, adds replace-all, and detects external modifications. write/edit validate structured formats and report source syntax errors. Automation parsing raw read output should account for line-number prefixes.
  • Workspace artifacts can now drive follow-up work — Web and desktop clients support workspace browsing, search, downloads, inline HTML/document/image previews, and clickable file-path cards. Dragging files or referencing files and directories with @ injects them into context, connecting generated artifacts directly to subsequent prompts; use broad directory references selectively to avoid unnecessary context consumption.
  • Context and prompt handling are more explicit — /compact manually summarizes and compresses session context, /clear consistently clears the current session with /context clear retained as an alias, and the larger default window delays automatic trimming. One-click Web prompt expansion now supports custom templates (#2989); review expanded instructions because they can materially change task scope and token usage.
  • Runtime and desktop behavior deserve a configuration check — bash gains background execution, a higher default foreground timeout, and immediate cancellation through Stop or /cancel. Previously ignored tools.bash.timeout and tools.bash.safety_mode settings now apply (#2986), so existing configurations may change command behavior after upgrading. Desktop fixes also deliver the correct macOS arm64 backend, bundled Windows ripgrep, and an approximately 1 MB on-demand Feishu SDK (#2988).
  • Compatibility — No breaking changes are listed.

🗂 Workspace & File Preview

The chat page gains a visual view of the workspace: documents, web pages, and images the Agent produces can be previewed in place. Both the Web console and the desktop client support it.

  • Workspace browsing: browse the files under the workspace directory from the panel, with search and download to local.
  • File preview: HTML pages, documents, and images open directly in the side panel, and file paths in a reply are rendered as clickable cards.
  • File references: drag a workspace file into the conversation, or use @ in the input box to reference files and directories and pull them into the context.

🔧 Core Tool Improvements

A systematic pass over file search, read, write, edit, and shell tools, strengthening the Agent's file handling and coding abilities.

  • New file search tool: search_files searches the workspace by content or by file name, backed by ripgrep by default — markedly faster on large directories. Thanks @Maaayhan (#2982)
  • Line-numbered read output: read output now always carries line numbers, making it easier to locate and cite specific lines.
  • More accurate edits: edit no longer rewrites the surrounding indentation on a fuzzy match, and no longer lands on the wrong occurrence when the text repeats; replace-all was added; a file modified outside the Agent is now flagged.
  • Write-time syntax checks: write / edit validate the format of structured files before writing, and parse source files to report syntax errors back to the Agent.
  • Background commands: bash can run a command in the background, for long-running work such as starting a service or following logs; the default timeout for foreground commands was raised.
  • Cancellation takes effect immediately: clicking stop or running /cancel terminates the command that is currently running.

Docs: File Search

🧠 Context Management

  • Context compaction: the new /compact command summarizes and compacts the conversation context on demand, effectively cutting token usage.
  • Unified commands: /clear now uniformly clears the current session's context, with /context clear kept as an alias.
  • Larger default window: the default context limit was raised, so long conversations start trimming later.

Docs: Context Management

🖥 Desktop Client

  • Native on Mac: fixed the macOS arm64 installer carrying an x64 backend, substantially speeding up the main process and the browser tool on Apple Silicon machines.
  • Feishu channel added: fixed the Feishu channel missing from the client. The Feishu SDK is now a trimmed dependency (about 1 MB) downloaded on demand the first time the channel is enabled. Thanks @EvanProgramming (#2988)
  • Update prompt: the update dialog for a given version only opens automatically once.
  • Bundled search backend: the Windows client ships with ripgrep, so file search works out of the box.

Download: CowAgent Desktop

Docs: Desktop Client

✨ One-Click Prompt Optimization

The Web input box can now expand what you typed into a more complete and explicit instruction, and the optimization rules support custom templates. Thanks @sufan721 (#2989)

🔒 Security Hardening

  • MCP and file-write hardening: fixed an attack chain exploitable through prompt injection — malicious content could lead the Agent into rewriting the MCP config, and from there run arbitrary commands and steal keys. Thanks @Correctover (#2968)
  • Credential file protection: fixed the edit tool bypassing credential protection to read and write ~/.cow/.env.

🛠 Improvements & Fixes

  • bash config honored: fixed tools.bash.timeout and tools.bash.safety_mode in config.json being ignored. Thanks @EvanProgramming (#2986)
  • Memory workspace path: fixed the workspace path being resolved incorrectly in the global memory config. Thanks @Maaayhan (#2992)
  • Conversation history protection: fixed memory index self-repair that could clear conversation history along with it.
  • Session deletion: fixed a reply still in flight writing a deleted session back into the list.
  • Browser launch: fixed launching a duplicate instance when the browser was already running.
  • Accurate tool results: fixed misleading failures from several tools — exit codes from grep / find judged wrong, browser scripts falsely reported as syntax errors, relative image paths failing to resolve — reducing pointless retries.

📦 How to Upgrade

  • Source deployment: run cow update for a one-click upgrade, or pull the latest code and restart. See the upgrade guide.
  • Desktop client: check for updates and update with one click inside the client, or get the latest version from the download page.
