headroom v0.39.0

0.39.0 (2026-09-25)

Features

  • compression: describe what CCR compression dropped, not just how much (#3635) (62d1cc0)
  • hooks: add protect_messages, a hard per-message compression veto (#3772) (d17ac6a)
  • opencode: exclude hosts from transport plugin routing (#3668) (0024b57)
  • proxy: let /transformations/feed omit message bodies for number-only pollers (#3672) (46ac52d)
  • savings: carry exact cache-read cost in history rollups (#3734) (1cb779e)
  • savings: show the new-input savings basis beside the whole-wire figure (#3485) (e92cccc)
  • savings: track lifetime output spend so a bill-share rate has a denominator (#3520) (c766bdb)
  • sdk: support per-call config override in compress() (#3370) (c3e8a1e)
  • wrap: support 1m context in vscode claude (#3361) (fc5a09e)
