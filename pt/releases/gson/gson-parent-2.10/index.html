Mudanças mais importantes

  • Suporte para serialização e desserialização de registros Java, em Java ≥ 16. (#2201)

  • Adicionar métodos de visualização JsonArray.asList e JsonObject.asMap (#2225)

  • Corrigido TypeAdapterRuntimeTypeWrapper não detectando TreeTypeAdapter e FutureTypeAdapter reflexivos (#1787)

  • Melhore JsonReader.skipValue() (#2062)

  • Realize conversão numérica para adaptadores de tipo numérico primitivo (#2158)

  • Adicione sobrecargas Gson.fromJson(..., TypeToken) (#1700)

  • Corrigir alterações no GsonBuilder que afetam instâncias Gson existentes (#1815)

  • Torne os métodos de conversão JsonElement mais consistentes e corrija o javadoc (#2178)

  • Lance UnsupportedOperationException quando JsonWriter.jsonValue não for compatível (#1651)

  • Proibir JsonObject Entry.setValue(null) (#2167)

  • Corrigido TypeAdapter.toJson lançando AssertionError para IOException personalizado (#2172)

  • Converter nulo em JsonNull para JsonArray.set (#2170)

  • Corrigido o uso de nullSafe. (#1555)

  • Valide argumentos TypeToken.getParameterized (#2166)

  • Correção nº 1702: Gson.toJson cria CharSequence que não implementa toString (#1703)

  • Prefira o adaptador existente para chamadas Gson.getAdapter simultâneas (#2153)

  • Melhore ArrayTypeAdapter para Object[] (#1716)

  • Melhore o desempenho do AppendableWriter (#1706)

Most important changes

  • Support for serializing and deserializing Java records, on Java ≥ 16. (#2201)

  • Add JsonArray.asList and JsonObject.asMap view methods (#2225)

  • Fix TypeAdapterRuntimeTypeWrapper not detecting reflective TreeTypeAdapter and FutureTypeAdapter (#1787)

  • Improve JsonReader.skipValue() (#2062)

  • Perform numeric conversion for primitive numeric type adapters (#2158)

  • Add Gson.fromJson(..., TypeToken) overloads (#1700)

  • Fix changes to GsonBuilder affecting existing Gson instances (#1815)

  • Make JsonElement conversion methods more consistent and fix javadoc (#2178)

  • Throw UnsupportedOperationException when JsonWriter.jsonValue is not supported (#1651)

  • Disallow JsonObject Entry.setValue(null) (#2167)

  • Fix TypeAdapter.toJson throwing AssertionError for custom IOException (#2172)

  • Convert null to JsonNull for JsonArray.set (#2170)

  • Fixed nullSafe usage. (#1555)

  • Validate TypeToken.getParameterized arguments (#2166)

  • Fix #1702: Gson.toJson creates CharSequence which does not implement toString (#1703)

  • Prefer existing adapter for concurrent Gson.getAdapter calls (#2153)

  • Improve ArrayTypeAdapter for Object[] (#1716)

  • Improve AppendableWriter performance (#1706)
