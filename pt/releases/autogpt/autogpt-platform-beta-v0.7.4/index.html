AutoGPT autogpt-platform-beta-v0.7.4

Highlights

  • Connections become first-class and account-aware — A coordinated set of changes (#14078, #14081, #14082, #14086, #14103, #14150) reworks AI connections: you can now choose the connection each new chat starts on, see which ChatGPT account a connection runs as, and — critically — server-defined connections are now enforced server-side rather than being client hints. Plans can mark a connection excluded/locked, provider failures are attributed to the engine actually executing them, and chats can be handed off elsewhere when a plan runs out. If you build on connections, expect to revisit selection logic and error attribution rather than assuming a single implicit connection.

  • Codex moves to HTTP; bundled CLI removed — #14195 drops the ~391 MB bundled Codex CLI in favor of HTTP-based execution. This materially shrinks the deployment/container footprint and startup cost, but it changes the dependency model: Codex flows now require a reachable service instead of a local binary. Watch network policies, timeouts, and any code that assumed an on-disk CLI.

  • Integrations scoped per expert; library agents installable as workflows — #14215 moves integrations to per-expert scope and surfaces them in the UI, #14297 lets you install your own library agents as expert workflows, and #13634 adds GitHub notification management blocks. The practical shift is toward distributing reusable, expert-specific toolsets instead of global wiring; #14120 reframes the Integrations page to match. Review any setup that relied on globally-available integrations.

  • Billing endpoints hardened, cached, and rate-limited — #14223 closes unauthenticated credit/subscription API calls (a security fix worth prioritizing), #14231 adds a per-user rate limit on the subscription status endpoint, and #14229 caches redundant active-subscription lookups. Clients that poll these endpoints aggressively will see lower latency but new throttling — check your retry/backoff behavior.

  • Fast/Thinking mode removed — #14083 deletes the Fast/Thinking mode control and its surrounding plumbing entirely. Any code or UI that branched on that mode needs updating; execution now follows a single path, so audit anything that depended on the mode flag for behavior or routing.

  • Reliability and maintenance — Async Redis clients are now event-loop-safe (#14259) with pytest async loop scope aligned (#14267), reducing flaky restarts and test failures. Also relevant: skill descriptions can reach 1,024 chars (#14024), Claude Code's system prompt is disabled (#14163), block docs generation no longer clobbers prose on rename (#14262), and knip is added to surface unused files/exports/dependencies (#14269).
