AutoGPT autogpt-platform-beta-v0.6.39

Highlights

  • Human-in-the-loop becomes production-ready — #11380 introduces the review/approval block, #11455 adds a graph-level Safe Mode toggle to gate HITL checkpoints per run, and #11509 fixes execution-context validation that had been breaking HITL runs (with tests re-enabled). Approval workflows were previously shaky; this is the release to revisit them, but re-validate any graphs authored against the old context behavior.
  • Headless control via the external API — #11463 exposes store search and tool usage as external routes, and #11472 moves integration management behind the external API. This is the real story for platform adopters: you can now discover blocks and wire integrations from your own backend instead of driving the UI, making embedded/automated AutoGPT deployments practical. Expect this surface to grow.
  • Chat toolchain slimmed to two tools — #11464 collapses the chat tool system down to just two tools. Though filed as an enhancement, this is the change most likely to break custom tool setups — anything that assumed the larger tool set needs an audit. Treat it as a behavioral change, not just cleanup.
  • Schema-correct database access — #11462 migrates every query_raw call to query_raw_with_schema. If you maintain custom blocks issuing raw SQL, mirror this migration: typed schemas make result parsing predictable, and staying on the old path leaves your blocks inconsistent with core and vulnerable to parsing surprises.
  • File selection and credential-scope shifts — #11311 adds a Google Drive Picker field for scoped file selection, while #11484 removes Google Sheets API scopes from block inputs. The scope removal is a permissions change: if your flows leaned on those broad grants, audit and re-authorize the affected integrations rather than assuming existing tokens still cover them.
  • Correctness fixes that alter runtime behavior — #11515 makes the HTTP block return response objects on non-2xx instead of failing silently, #11507 prunes empty values from node inputs, and #11478/#11477 preserve edges and customized_name metadata during copy/save. These eliminate silent data loss, but downstream blocks that counted on empty-string inputs or thrown HTTP errors will see different data — run a regression pass on existing graphs.

No breaking changes were formally declared in this release.
