AutoGPT autogpt-platform-beta-v0.6.36

Highlights

  • Chat becomes a first-class surface — This release lands the full chat stack: backend (#11230) and a complete messaging UI (#11290), with access gated to authenticated users and per-chat agent-run limits (#11330), plus a fix for duplicate messages (#11332). For adopters this is more than a new tab — it signals a shift from one-shot graph runs toward stateful, conversational execution. Expect to wire auth into any chat-enabled deployment and to keep an eye on message deduplication and run quotas under load.
  • Cron scheduling ships in the new builder — Recurring execution is now native via cron-based scheduling with input and credential support (#11312), and apscheduler is bumped to the DST-fixed 3.11.1 (#11294). The dependency bump is easy to overlook but matters: timezone/DST edge cases in scheduled runs are a common source of silent drift, so this is a correctness improvement worth verifying against any cron expressions you already had.
  • Credentials and inputs move to execution time — A dynamic input dialog lets runs collect inputs and credentials on demand (#11301), and input validation gains backwards-compatible Set operations (#11197). Practically, this means secrets no longer have to be baked into graph definitions — but it also introduces a new interactive step in previously unattended flows, so test scheduled/automated runs that can't answer a prompt.
  • Admin impersonation via header-based auth — Admins can now impersonate users using header-based authentication (#11298). The capability itself is useful for support and debugging, but the mechanism is security-sensitive: if your deployment sits behind a proxy, confirm it strips or overwrites client-supplied auth headers, otherwise the impersonation header becomes a trust-boundary risk.
  • Deprecated LLM models removed — migration script provided — Legacy model entries are dropped and a migration script is included (#11331). Treat this as the one action-required item: run the migration before upgrading or graphs referencing retired models will break. This is the change most likely to bite existing installs.
  • Builder and execution reliability cleanups — Undo/redo with keyboard shortcuts in the flow builder (#11307), correct rendering of all output types in custom nodes (#11258), tightened graph-execution permission checks (#11323), and republishing rate-limited messages to the back of the queue instead of blocking it (#11326) — alongside an agent-version fetch fix when active_version_id is set (#11291). These don't add features, but they remove friction in day-to-day graph authoring and make execution under rate limits and permissions far more predictable.
