AutoGPT autogpt-platform-beta-v0.6.46

Highlights

  • Persistent CoPilot workspaces — CoPilot now has user-scoped file storage (#11867), so files can survive across sessions instead of behaving as temporary session data. Whisper-powered speech-to-text (#11871) and improved focus restoration (#11893) also make voice-driven workflows more practical.
  • Recovery for long-running CoPilot sessions — Redis-backed SSE reconnection (#11877) lets clients reconnect to ongoing operations after a transient disconnect. Deployments should verify Redis availability and multi-instance connectivity to benefit reliably.
  • More capable sub-agents and marketplace tools — Two-phase library-agent discovery (#11889), customize_agent (#11943), and richer discovery/graph schemas (#11916, #11920) make marketplace agents easier to find, configure, and invoke as sub-agents. Unknown input fields are now validated, so malformed tool calls fail earlier instead of reaching execution.
  • More robust context management — Context-window handling and LLM continuation have been repaired (#11936), compaction is consolidated behind compress_context() (#11937), and fallback compaction now uses the correct message representation (#11922). Long-running agents should see fewer truncation and continuation errors; custom integrations touching compaction should target the new shared helper.
  • Model and credential migration required — Deprecated Claude 3.7 Sonnet references are removed (#11841); saved agents or integrations using that model must be migrated to a supported model. Graph execution also filters credentials by scope (#11881) and uses credential discriminators during matching (#11908), so under-scoped or ambiguous credentials that previously worked may no longer be selectable.
  • Security and runtime hardening — This release fixes reflected XSS in the OAuth callback (#11963), Redis connection leaks in ws_api (#11869), and scheduler database access through DatabaseManager (#11941). Block initialization also gains retry/error handling (#11946), improving recovery from transient startup failures.
