AutoGPT autogpt-platform-beta-v0.6.37

Highlights

  • Real-time notifications — #11297 adds WebSocket-based notifications, with onboarding coverage in #11335, enabling server-initiated UI updates. Consumers should implement reconnect/backoff handling and tolerate duplicate delivery; socket events should not be treated as a durable replacement for persisted state.
  • Builder authoring and save safety — Drag-and-drop, copy/paste, and custom-node context menus (#11341, #11339, #11342) expand the new builder’s workflow capabilities. Copied blocks now receive unique IDs (#11344), while consolidated graph-save logic (#11367) prevents duplicate event listeners, reducing the risk of ID collisions and repeated saves.
  • Frontend state architecture — The Supabase + Zustand integration (#11333) changes the frontend’s shared state/data flow for faster updates. Custom components should follow the new store conventions and verify consistency across navigation and refreshes rather than maintaining competing local state.
  • Admin analytics and impersonation — A new execution-analytics admin endpoint (#11327) includes a feature-flag bypass, and admin impersonation now works for server-rendered requests (#11343). Re-test authorization for both the bypass and impersonation paths, since they are privileged access routes.
  • Authentication and CORS configuration — CORS allowed origins now support regex (#11336), enabling pattern-based deployment configuration; anchor expressions carefully to avoid overly broad matches. Turnstile has been removed (#11387) and post-auth redirect conflicts fixed (#11382), so custom login flows should be checked for assumptions about challenge tokens and redirect handling.
  • Breaking changes — None declared in this release.
