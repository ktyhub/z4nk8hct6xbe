AutoGPT autogpt-platform-beta-v0.11.3

Highlights

  • Security fixes land with advisories still pending — Several privately reported issues are patched here, but the advisories only go public after production rollout, so treat this upgrade as urgent and watch the disclosure feed. The hardening is broad: webhook stored secrets are validated as text and preset-trigger signatures checked with timestamps (#16722, #16760), v1 API-key validation is rate-limited before the Scrypt step (#15059), OAuth sign-up requires a provider-verified email (#16445), bash_exec sandboxes get isolated PID/IPC namespaces (#14905), and bans now match every spelling of an address (#16764). Webhook integrators should re-check secret encoding and signature timestamps after upgrading.
  • Broader model and execution surface — Gemini 4 "Hydrogen" (#16792) and "Carbon" (#16741) join the model roster, so agents can target the newest Google models without config surgery. More consequentially, #13050 adds remote Local PC execution targets and #15384 lays native mobile server foundations — together they let you keep workload execution on hardware you control. The mobile piece is groundwork, not yet a shipping mobile server.
  • Apple and Microsoft sign-in widen the IdP matrix — Native and browser Sign in with Apple (#16683) plus Microsoft setup across Entra apps and Vercel (#16787) add identity options. Watch #16445: OAuth registration now succeeds only with a provider-verified email, which can break flows that previously accepted unverified identities.
  • Billing and metering are corrected — review your invoices — Billing state is isolated across account switches (#14226), ClaudeCodeBlock E2B sandbox usage is charged by walltime (#16469), and usage-priced blocks launched from AutoPilot are billed like workflow runs (#16761). Wallet balances are re-read after runs and chat turns (#16531), NO_TIER accounts on a card-less trial can finally buy a plan (#16709), and run_agent now reports "subscription required" instead of a generic failure (#16536). Expect cost attribution to shift for AutoPilot and sandbox-heavy workloads.
  • Account erasure matures into a compliance tool — Erasure no longer needs the confirmation email (erase-account --no-email, #16768) and is open to every user (#16793); it now sweeps bucket folders (#16767), pre-April-2026 AutoPilot transcripts (#16769), and PostHog persons, with rerunnable cleanup and crash-lease recovery (#16763, #16766). Docs (#16794) spell out what deliberately survives in Stripe, cost records, and handed-over agents — read them before promising users full deletion.
  • Reliability fixes worth pinning — Memory recall stops pulling embeddings out of FalkorDB reads (#15842) and walks each BFS origin once (#15843), easing graph-load; workspace downloads are streamed with continuous profiling and admin-only cache metrics (#16727); schedules stored with a one-second grace no longer skip runs (#16800). Also note #16775 (edits that would exceed the file size limit are refused) and #16539 (explicit fallback messaging when a site blocks the browser or web_fetch) — both change observable agent behavior.

No breaking changes are explicitly called out in this release.
