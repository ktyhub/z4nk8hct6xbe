AutoGPT autogpt-platform-beta-v0.6.62

Highlights

  • Deprecated LLM models retired with family-aware migration — #13089 retires deprecated models and maps them to the closest surviving model family, so agents pinned to old IDs will silently start running on a successor. Audit hardcoded model identifiers and verify the family mapping before upgrading; related model work includes #13177 teaching LlmModel OpenRouter Anthropic aliases and #13171 setting Haiku 4.5 as the dry-run sim default. This is the most migration-sensitive change in the release.
  • Orchestrator dry-run unblocked end-to-end — #13180 finally makes the dry-run path work using the canonical model plus SDK auth, backed by #13171, #13177 and #13188 (EXTENDED_THINKING now emits the final answer only). For anyone developing against the orchestrator, this turns a previously broken local test loop into a usable harness — but expect output shape to change under EXTENDED_THINKING, which now suppresses intermediate reasoning.
  • Native Copilot scheduling lands behind kill-switches — #13190 adds first-class scheduling for Copilot turn followups, with a unified Scheduled page and LaunchDarkly kill-switches (#13202), cache invalidation across all four affected query keys (#13204), and the Autopilot pill now counting only Copilot follow-ups (#13212). Watch out: #13187 disallows the ScheduleWakeup SDK built-in, so custom code calling it directly must move to the new native scheduling path.
  • Self-distilled skills registry injected into Copilot — #13195 introduces a skills registry whose index is injected into Copilot's context, enabling on-demand retrieval of distilled skills; paired with #13167 hiding builder-blocked MCP tools so the SDK can't auto-deny them. This changes which tools and skills a Copilot run can see — verify agents that relied on blocked tools being surfaced.
  • Credential and MCP setup UX overhauled — #13088 unifies credential handling across card, prompt, session store and popup recovery; #13207 fixes stale-credential firing, the OAuth popup-close race and adds Connected/Reconnect states; #13185 strips null credential fields before validation. The net effect is stricter validation plus new recovery paths — integrations that previously slipped null fields through may now fail validation, so re-check saved credentials after upgrading.
  • Security patch plus new sharing and search — #13104 bumps Next.js from 15.4.11 to 15.5.18 as a security upgrade; treat this as a required update. On the feature side, #13081 adds public share links for agent chat results and #13139 gates chat search behind the CHAT_SEARCH flag. Public links make any shared chat reachable by whoever holds the URL, so confirm that exposure is acceptable for your data.
