AutoGPT v0.6.44

Highlights

  • Claude Code execution — New ClaudeCodeBlock runs tasks via Claude Code inside an E2B sandbox (#11761), adding an isolated coding-agent execution option; adopters of this block need E2B-backed sandbox infrastructure.
  • Interactive agent generation — External Agent Generator integration (#11819) and clarification-question UI (#11833) let generation pause for missing requirements. Frontends and automations should support this clarification round-trip rather than assuming one-shot generation.
  • Long-running execution resilience — Tool results persist across SSE disconnects (#11856), heartbeats prevent execution timeouts (#11855), and auto-polling detects completion (#11866). Context management also preserves tool_call/tool_response pairs during compaction (#11848, #11863), reducing lost results and malformed chat history.
  • Finer execution controls — Node-specific auto-approval and safety prompts (#11810) allow policies to be scoped per node; disabled blocks are enforced on execution endpoints (#11839) and excluded from chat search/indexing (#11854). Audit node policies after upgrading to avoid unexpected prompts or unavailable blocks.
  • Capacity and telemetry changes — Higher max_agent_runs and max_agent_schedules limits (#11865) provide more headroom but may affect quota assumptions. Chat telemetry adds PostHog and OpenRouter tracing (#11828), removes Langfuse tracing (#11829), and initializes PostHog only on cloud (#11843); self-hosted deployments should update observability dependencies accordingly.
  • Breaking changes — None declared.
