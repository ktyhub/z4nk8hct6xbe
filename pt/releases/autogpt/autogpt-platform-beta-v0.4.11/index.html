AutoGPT autogpt-platform-beta-v0.4.11

Highlights

  • Library v2 agent management — Agents and presets (#9258) plus the Agent Runs page (#9051) make reusable configurations and execution history part of the new Library experience. The corrected api.listLibraryAgents() return contract (#9498) means typed clients should refresh API typings and review call sites that accommodated the previous behavior.
  • Notification service becomes runtime infrastructure — Schema/query migrations (#9445), service startup tests (#9464), email delivery (#9469), credit notifications (#9488), and setup detection (#9497) establish notifications as a separate dependency. Verify email-service configuration in every environment rather than assuming the UI alone enables delivery.
  • Dead-letter handling for failed messages — #9501 moves failed notification messages into a dead-letter queue, isolating problem messages from normal processing. Add queue monitoring and a retry/replay procedure instead of relying on in-path retries.
  • Native JSON storage migration — #9475 converts JSON-encoded string columns into native JSON. Audit custom SQL, ORM mappings, and ingestion code for string-based assumptions; this changes the storage contract even where application-facing behavior appears unchanged.
  • RabbitMQ reset for dev-branch upgrades — Existing RabbitMQ containers must be deleted and recreated by Docker Comppose to resolve the documented misconfiguration. Treat this as a required local-environment migration before starting the upgraded stack.
  • Breaking changes — None declared; the native-JSON migration and RabbitMQ reset are the main upgrade-sensitive changes.
