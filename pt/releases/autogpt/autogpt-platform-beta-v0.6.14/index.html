AutoGPT autogpt-platform-beta-v0.6.14

Highlights

  • Triggered agents land — with repair work that matters for adopters — #10167 adds triggered-agent support to the platform/library, but the real signal is the follow-up: #10230 fixes library breakage for manually-setup triggered agents, and #10220 splits and fixes the update_library_agent endpoint. If you script library management or automate agent setup, audit those calls before upgrading — the endpoint was restructured. #10229 also corrects the agent block input value key, so re-verify triggered-agent block wiring after the update.

  • Frontend data fetching is rebuilt around React Query — The biggest architectural shift for platform contributors: #10190 introduces React Query, #10194 adds DevTools and ESLint rules, #10209 configures orval, and #10200 ships a custom OpenAPI generator. #10189 adds a graph_id path parameter specifically so auto-generated clients work off the OpenAPI spec. Net effect: the client is moving to generated, typed API hooks with real cache management; older ad-hoc fetching patterns are effectively on the way out, so expect refactoring work if you maintain frontend integrations.

  • Uploads gain malware scanning; caching gets explicit — #10232 adds ClamAV anti-virus scanning on file upload — a security win, but operationally it means uploads now depend on a ClamAV service being reachable, so self-hosters need to provision it. #10160 adds cache-control headers, a quiet change that matters if you front the platform with a CDN or reverse proxy.

  • Block execution behavior shifts in subtle ways — #10203 enables automatic type conversion on nested input schema mismatches: fewer noisy failures, but inputs that previously errored may now be silently coerced, which is worth watching in complex graphs. #10198 improves SmartDecisionBlock and AIStructuredResponseGeneratorBlock, #10197 fixes broken Apollo blocks, and #10199 enables cloud Apollo integration cost tracking — Apollo users should expect different cost accounting and re-test their flows. #10191 also changes the Schedule Task default to "daily," so newly created schedules behave differently.

  • Design system expands with visual-regression coverage — #10196 adds a new Input component and #10241 a Link component, backed by docs for color tokens (#10186), Button (#10192), and skeletons (#10240). #10235 sets up Chromatic, giving UI changes automated visual-regression checks. Low risk for backend users, but frontend contributors should align with the new component APIs.

No formally declared breaking changes in this release.
