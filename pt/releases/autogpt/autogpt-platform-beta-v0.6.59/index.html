AutoGPT autogpt-platform-beta-v0.6.59

Highlights

  • New users default to NO_TIER — PR #12981 flips the signup default from PRO, so fresh accounts no longer inherit Pro entitlements. Combined with #12969 dropping the BetaUserCredit monthly refill and #12968 removing four earn-credits onboarding items, the free-tier credit economics are materially leaner. If your entitlement checks or onboarding flows assume a free user starts as PRO or receives a recurring grant, audit them before rollout.
  • Settings v2 billing is live on Stripe — #12942 ships the unified subscription + automation-credits page, wired to Checkout in #12978 with yearly plans in #13004. Watch #13003: Pro→Max upgrades now bill immediately with payment-failure rollback, and #12959 reserves TOP_UP strictly for real Stripe checkouts (refunds go through grant_credits) — any code that synthesizes TOP_UP transactions will break. #12947 also surfaces clearer 422s on currency mismatch, and #12952 gates the credits-add popup behind ENABLE_PLATFORM_PAYMENT.
  • Tier limits become first-class for builders — #12780 adds per-workspace file storage caps by tier, exposed to agents via the new get_platform_info tool (#13000) and enforced through the DB-manager path (#12992). SDK consumers also get dynamic max_budget_usd with a baseline budget hint (#13002). Hard-coded budget or storage assumptions will now behave tier-dependently.
  • Cost controls fail closed — #12990 makes the platform abort when Redis is unavailable, closing a USD-cap bypass — a deliberate availability-vs-safety tradeoff that will surface as hard failures during Redis outages. #13009 additionally persists activity-status LLM cost to PlatformCostLog, so expect cost rows where none existed before.
  • Copilot stream and thread handling hardened — #12948 bundles chat-stream stability fixes (PK dedup, race conditions, compaction, error/chip handling) and #12950 moves the executor to the foreground, changing latency and failure semantics for callers. #12995 adopts mentioned Discord threads while #12994 suppresses bot setup prompts in unrelated threads, and #12992 re-prompts on thinking-only finishes.
  • No breaking changes — None formally; the shifts above are behavioral and additive rather than API-breaking.
