AutoGPT autogpt-platform-beta-v0.6.57

Highlights

  • Model defaults and routing — Kimi K2.6 is now the fast-tier default for baseline and SDK, Grok 4.20 is available via OpenRouter, and copilot Sonnet moves to 4.6 (#12871, #12878, #12620, #12799). Per-user LaunchDarkly routing adds rollout control, but fallback is disabled to fix production CLI rejection; check pinned model IDs and fallback-dependent tests (#12881, #12802).
  • Billing and usage economics — Stripe Checkout adds subscription tiers, paid-to-paid downgrades are deferred behind a cancel-pending flow, and 13 paid blocks are registered with a documented credit/microdollar wallet boundary (#12727, #12865, #12876). Real OpenRouter costs now drive rate limits and vendor-aware SDK/simulator accounting; public limit reporting remains percentage-only, so dashboards should not expose raw dollar limits from it (#12864, #12873, #12878).
  • Copilot streaming and context — Baseline streaming now includes extended_thinking, a render flag, web search, persisted reasoning, and TodoWrite, while multiple compactions per turn are supported (#12870, #12873, #12853, #12879, #12834). Stream consumers should handle new event types and contexts that can compact mid-turn.
  • Session reliability and follow-ups — Messages sent while a session is busy can be queued through the UI, run_sub_session, and AutoPilot (#12841, #12737). Idempotent appends, completion-time lock release, and Stop+resend recovery address duplicate or stuck sessions; bash_exec now allows longer timeouts (#12814, #12867, #12862).
  • Resume and agent operations — Transcript context extraction is unified, --resume is mode-gated, and gap-fill is compaction-aware, but forward pagination was reverted for a blank-chat visibility guarantee; test CLI resume paths rather than relying on pagination (#12804, #12831). Scheduled agents now surface in the library and copilot briefings, and the Agent Briefing Panel reports monthly spend (#12818, #12764, #12854).
  • Breaking changes — None announced.
