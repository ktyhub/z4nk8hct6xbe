AutoGPT autogpt-platform-beta-v0.6.19

Highlights

  • Durable, retriable execution — This release is dominated by a reliability rewrite of the agent executor (#10516, #10518, #10526, #10529). RPC calls to the DB manager are now durable, graph/node execution is retriable with a user-visible failure status, and execution stats updates are crash-safe (#10529). Practical upshot: transient DB disconnects no longer poison in-flight runs, and traffic to the REST/DB services is suppressed when the DB is down (#10522). Watch the ordering change in #10541 — node output and status persistence now land in a different sequence, so anything reading execution state mid-run should not assume atomic status/output writes. #10528 adds a timeout guard on credit transactions, so billing operations can no longer hang the executor indefinitely.

  • LLM model churn (migration required) — #10512 adds new models, but #10508 removes deprecated ones and #10510 drops grok-beta outright. This is a genuine breaking change: any agent, template, or credential config pinned to a removed model ID will fail at execution time, so audit your graph definitions and remap to supported models before upgrading. The removals in #10535 (unused functions/imports) add minor cleanup but no runtime API impact.

  • Firecrawl integration for scraping/extraction — #10494 introduces a Firecrawl block for web scraping and structured data extraction. For developers this is a first-class way to ingest web content into an agent without wiring a scraper yourself; expect it to pair naturally with the marketplace/agent-builder workflows. Be aware it adds a new external service dependency — you'll need a Firecrawl API key and should account for its rate limits and egress in self-hosted deployments.

  • Ayrshare social channels expand, but credentials are decoupled — YouTube (#10505) and Instagram (#10504) support is enabled, widening the social-posting surface to two more networks. Counterintuitively, #10538 simultaneously removes Ayrshare from the execution and credentials manager — a sign the integration is being refactored away from the central credential path. If you rely on Ayrshare credentials, plan to re-verify the connection path rather than assuming a seamless upgrade, and test both new channels end-to-end before trusting them in production.

  • Validation and stop semantics shift server-side — #10556 defers graph validation to the backend, removing client-side checks; errors will now surface from the API rather than the UI, which changes error timing and shapes for anything automating graph creation (including your E2E assertions). Relatedly, #10542 stops node evaluation from being prematurely killed when a graph is stopped — a behavioral fix that means "stop" no longer guarantees every in-flight node halts instantly. #10514 fixes loop creation issues, so loop-heavy graphs should be re-tested.

  • Self-hosting: CAPTCHA is now cloud-only (#10543) — CAPTCHA is gated to cloud environments only, so self-hosted instances stop seeing it. That simplifies local/on-prem auth flows but means self-hosted deployments must supply their own bot protection if they expose the UI publicly. On the UI side, #10479/#10515 refactor the publish-agent modal and #10530 adds a reusable infinite-scroll component for consistent pagination — useful if you build on the frontend, though mostly non-breaking.
