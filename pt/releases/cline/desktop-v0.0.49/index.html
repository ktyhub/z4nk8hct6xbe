cline desktop-v0.0.49

  • Um novo botão Alterações no cabeçalho da sessão mostra a contagem de linhas da sessão e abre um painel listando os arquivos alterados no último turno ou em toda a sessão, com uma comparação de cada um. Quando um turno termina, um resumo abaixo dele lista os arquivos que foram alterados; click para abrir o painel naquele turno
  • Um painel de arquivos do projeto (botão de pasta no cabeçalho da sessão) mostra uma árvore de arquivos ao lado da conversa, com um visualizador com guias somente leitura, letras de status do git e um marcador nos arquivos que a sessão alterou. Os arquivos editados pelo agente recebem uma alternância Arquivo/Diferença. Funciona em ambientes locais e SSH
  • Um painel de terminal integrado é aberto na parte inferior da janela (alterne com Ctrl+crase)
  • Status da solicitação pull movido da barra acima do compositor para um botão de cabeçalho. Seu menu mostra o título do PR, o status da mesclagem e as verificações (falhando nas verificações primeiro) e permite que você abra o PR no GitHub, crie um PR, copie o nome da filial ou atualize
  • Uma nova página de configurações de Modelos Locais gerencia os modelos Ollama e LM Studio: orientação de configuração, detalhes e armazenamento do modelo, e um chip compositor mostrando quanta memória o modelo carregado usa
  • Atalhos de teclado são configuráveis em Configurações (também acessíveis no aplicativo e nos menus de Ajuda). Parar pode exigir segurar o atalho, 1 segundo por padrão no macOS, por isso é mais difícil sair acidentalmente
  • Comandos de barra e menções @file aparecem como chips no compositor e nas mensagens enviadas
  • Se o Hub falhar ao iniciar, o aplicativo agora mostrará uma tela de inicialização com diagnósticos de Repetir e Exportar, em vez de falhar em todas as ações com "endpoint de backend de desktop não pronto"
  • As configurações gerais mostram o status do Hub e possuem um botão Reiniciar Hub
  • Abrir uma tarefa que já está em execução em outro aplicativo Cline agora é anexado a essa execução em vez de iniciar uma segunda que não pôde ser interrompida. Solicitações que estavam aguardando um aplicativo fechado no meio da tarefa agora falham com uma mensagem clara em vez de serem interrompidas
  • Sessões com uma transcrição muito grande (mais de 8 MB) podem ser retomadas. Antes, a transcrição era enviada duas vezes ao Hub, ultrapassando o limite de tamanho da mensagem
  • Linhas longas no arquivo e nos visualizadores de diferenças são quebradas, e as linhas sempre ocupam toda a largura quando roladas
  • Novos bate-papos na nuvem começam em seu modelo Cline ou ClinePass local. Se a Cloud não oferecer esse modelo, os assinantes do ClinePass receberão um modelo ClinePass e todos os demais receberão Claude Sonnet 5.5
  • Uma chave Cline API colada agora substitui um login antigo do navegador em vez de ser ignorada. Os campos de configurações do provedor são empilhados corretamente no painel lateral estreito
  • A opção de classificação Sessões/Projetos na barra lateral é lembrada nas reinicializações
  • Em desktops Linux sem bandeja (GNOME padrão no Fedora ou Debian), fechar a janela fecha o aplicativo em vez de deixá-lo rodando sem ter como sair
  • Mensagens internas destinadas apenas ao modelo não aparecem mais na transcrição e os títulos das sessões ao vivo não mostram mais o wrapper user_input bruto
  • O status do cronograma permanece atual e as execuções com falha mostram o erro completo
  • A verificação de alterações não gera mais milhares de processos git em espaços de trabalho com muitos arquivos não rastreados
  • Ambientes SSH atrás de um alias ProxyJump agora se conectam
  • O botão Reiniciar do sistema de atualização fica abaixo do texto da mensagem
  • Um turno cuja conexão cai após o modelo ter transmitido apenas o raciocínio agora é repetido em vez de encerrar a execução
  • As solicitações de modelo são repetidas no máximo 3 vezes em vez de 5
  • Kimi K3 agora obtém o raciocínio max para Extra High e Max, em vez de uma configuração xhigh que ele rejeita
  • As chaves Gemini API (o provedor gemini) não enviam mais a Pesquisa Google nativa. As chaves de nível gratuito falharam em todos os turnos com um erro de cota 429 no Gemini 3+ e no Gemini 2.x todas as ferramentas Cline foram descartadas
  • A compactação automática não é mais executada para modelos com limite de contexto desconhecido e não é mais executada novamente a cada poucas chamadas de ferramenta após a primeira compactação
  • ask_question: o modelo continua após você escolher uma opção, respostas vazias são rejeitadas e uma resposta com apenas um anexo conta
  • run_commands com uma lista de comandos vazia agora retorna um erro em vez de um sucesso silencioso. No PowerShell, a ferramenta informa ao modelo como funciona a citação escaping e para confirmar primeiro as exclusões recursivas
  • Atualizado o catálogo de modelos. Adiciona os provedores Liquid Inference e Munito AI e descarta CrofAI, iFlow e Llama. A lista gratuita Cline adiciona Reflection Beam, Nemotron 3.5 Lightning e Laguna S 2.1 e descarta Mimo V2.6 Flash e Muse Spark 1.3 Contributor. ClinePass agora usa como padrão Kimi K3.1 Pro e adiciona MiniMax M3.1 Flash e DeepSeek V4.1 Flash 1017. Os modelos padrão mudam para 56 outros provedores, principalmente para Kimi K3.1 Pro, MiniMax M3.1 Flash ou DeepSeek V4.1 Flash 1017 Changelog completo: https://github.com/cline/cline/compare/desktop-v0.0.48...desktop-v0.0.49

cline desktop-v0.0.49

  • A new Changes button in the session header shows the session's line counts and opens a pane listing the files changed in the last turn or across the whole session, with a diff of each. When a turn finishes, a summary under it lists the files it changed; click it to open the pane on that turn
  • A project files panel (folder button in the session header) shows a file tree beside the conversation, with a read-only tabbed viewer, git status letters, and a marker on files the session changed. Files the agent edited get a File/Diff toggle. Works on local and SSH environments
  • An integrated terminal panel opens at the bottom of the window (toggle with Ctrl+backtick)
  • Pull request status moved from the bar above the composer into a header button. Its menu shows the PR title, merge status and checks (failing checks first), and lets you open the PR on GitHub, create a PR, copy the branch name, or refresh
  • A new Local Models settings page manages Ollama and LM Studio models: setup guidance, model details and storage, and a composer chip showing how much memory the loaded model uses
  • Keybindings are configurable in Settings (also reachable from the app and Help menus). Quit can require holding the shortcut, 1 second by default on macOS, so it's harder to quit by accident
  • Slash commands and @file mentions show as chips in the composer and in sent messages
  • If the Hub fails to start, the app now shows a startup screen with Retry and Export diagnostics, instead of failing every action with "desktop backend endpoint not ready"
  • General settings shows the Hub's status and has a Restart Hub button
  • Opening a task that's already running in another Cline app now attaches to that run instead of starting a second one that couldn't be stopped. Requests that were waiting on an app that closed mid-task now fail with a clear message instead of hanging
  • Sessions with a very large transcript (over about 8 MB) can be resumed again. Before, the transcript was sent to the Hub twice, which went over its message size limit
  • Long lines in the file and diff viewers wrap, and rows always span the full width when scrolled
  • New Cloud chats start on your local Cline or ClinePass model. If Cloud doesn't offer that model, ClinePass subscribers get a ClinePass model and everyone else gets Claude Sonnet 5.5
  • A pasted Cline API key now replaces an old browser sign-in instead of being ignored. Provider settings fields stack properly in the narrow side panel
  • The Sessions/Projects sort choice in the sidebar is remembered across restarts
  • On Linux desktops without a tray (stock GNOME on Fedora or Debian), closing the window quits the app instead of leaving it running with no way to quit
  • Internal messages meant only for the model no longer show in the transcript, and live session titles no longer show the raw user_input wrapper
  • Schedule status stays current and failed runs show the full error
  • Checking for changes no longer spawns thousands of git processes in workspaces with many untracked files
  • SSH environments behind a ProxyJump alias now connect
  • The update toast's Restart button sits under the message text
  • A turn whose connection drops after the model has streamed only reasoning is now retried instead of ending the run
  • Model requests retry at most 3 times instead of 5
  • Kimi K3 now gets max reasoning for Extra High and Max, instead of an xhigh setting it rejects
  • Gemini API keys (the gemini provider) no longer send native Google Search. Free-tier keys failed every turn with a 429 quota error on Gemini 3+, and on Gemini 2.x every Cline tool was dropped
  • Auto-compaction no longer runs for models with an unknown context limit, and it no longer runs again every few tool calls after the first compaction
  • ask_question: the model keeps going after you pick an option, empty answers are rejected, and an answer with only an attachment counts
  • run_commands with an empty command list now returns an error instead of a silent success. On PowerShell, the tool tells the model how quote escaping works and to confirm recursive deletes first
  • Refreshed the model catalog. Adds the Liquid Inference and Munito AI providers and drops CrofAI, iFlow and Llama. The Cline free list adds Reflection Beam, Nemotron 3.5 Lightning and Laguna S 2.1 and drops Mimo V2.6 Flash and Muse Spark 1.3 Contributor. ClinePass now defaults to Kimi K3.1 Pro and adds MiniMax M3.1 Flash and DeepSeek V4.1 Flash 1017. Default models change for 56 other providers, mostly to Kimi K3.1 Pro, MiniMax M3.1 Flash or DeepSeek V4.1 Flash 1017
