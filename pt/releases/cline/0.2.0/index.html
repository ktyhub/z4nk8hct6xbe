cline sdk/sdk/v0.2.0

  • Iniciar uma sessão que já tem uma execução em andamento agora é reconectada à sessão ao vivo em vez de substituir seu tempo de execução. Antes, a execução original continuava, mas não podia ser alcançada, e suas gravações de transcrição aconteciam em um instantâneo obsoleto. Um início que inclui um aviso enquanto uma execução está em andamento é rejeitado
  • O hub registra cada client que registrou capacidade para uma sessão, incluindo clients que ingressam em uma tarefa que já está em execução, e envia cada solicitação para o primeiro ainda conectado. Se não sobrar nada, a solicitação falha rapidamente com uma mensagem na qual o usuário pode agir, em vez de esperar para sempre
  • Um turno cuja conexão cai após o modelo ter transmitido apenas o raciocínio é agora tentado novamente e o raciocínio parcial é descartado. Turnos com chamadas de texto, mídia ou ferramenta nunca são repetidos
  • As solicitações de modelo são repetidas no máximo 3 vezes após a primeira tentativa (em vez de 5). As tentativas fracassadas são registradas nos rastreamentos do Langfuse e as solicitações canceladas não são mais relatadas como erros do Langfuse
  • AI SDK atualizado para ai 7.0.136 / @ai-sdk/provider-utils 5.0.58. O raciocínio max agora chega ao provedor: o gateway não o transforma mais em xhigh, e Kimi K3 ganha max para Extra High e Max. As voltas antrópicas vazias ainda são repetidas, apesar das novas partes personalizadas do fluxo anthropic.*
  • O provedor gemini não envia mais a Pesquisa Google nativa. No Gemini 3+, as chaves de nível gratuito falharam em todos os turnos com um erro de cota de 429, e no Gemini 2.x derrubou todas as ferramentas Cline. Vertex mantém pesquisa nativa
  • A compactação automática não é mais executada quando o limite de entrada do modelo é desconhecido. A compactação manual e de recuperação de transbordamento ainda funciona
  • Após a primeira compactação, a estimativa de tamanho agora utiliza as mensagens conforme elas são realmente enviadas, com os resultados da ferramenta truncados. Antes, ele superestimava cerca de 7x e a compactação era executada novamente a cada poucas chamadas de ferramenta
  • O Checkpoint compara o conteúdo do arquivo com um único processo git cat-file --batch em vez de até dois processos git show por arquivo. Espaços de trabalho com muitos arquivos não rastreados usados para gerar milhares de processos git
  • Os controles remotos SSH funcionam por trás de um alias ProxyJump. O orçamento de conexão vai de 10 para 30, o limite por comando para 60 e a prontidão do túnel para 40. Quando o ssh sai no meio do upload, seu erro real é relatado em vez de EPIPE, e um LocalForward no alias não colide mais com o túnel
  • As respostas do ask_question são enquadradas para que o modelo continue após uma simples escolha. Respostas vazias são rejeitadas e uma resposta com apenas um anexo conta como respondida
  • run_commands rejeita uma lista commands vazia com um erro de ferramenta e seu esquema agora anuncia minItems: 1
  • No PowerShell, a descrição run_commands explica backtick escaping, caminhos literais com aspas simples, preferindo cmdlets a cmd /c e confirmando exclusões recursivas primeiro
  • Os comandos do plug-in são executados no tempo de execução da sessão ativa e no hub. Os relógios de plug-in começam a funcionar novamente quando os diretórios de descoberta aparecem
  • Binários compilados carregam plug-ins incorporados e recursos de painel diretamente do binário, e cada exportação de tempo de execução SDK declarada é empacotada
  • Um CLINE_PLUGIN_RUNTIME_DIR configurado é resolvido para um caminho absoluto
  • Quando o OpenRouter não corresponde a um modelo recomendado Cline, suas capacidades são preenchidas no catálogo Vercel
  • Orquestração de sessões de desktop em nuvem movida para o hub. session.list relata activeCloudCommands, e o hub não é substituído enquanto os comandos da nuvem ainda estão em execução
  • Core adiciona resumos de conversas e suporte de continuação na nuvem
  • Telemetria de estol de execução: agent.run-finished e agent.run-failed transportam sinais de estol de um novo RunHealthObserver
  • @cline/ui agora vem com os pacotes SDK na versão compartilhada. Ele adiciona um componente Kbd e chips de token para comandos de barra e menções de arquivo em AgentComposer
  • Atualizado o catálogo de modelos (7.041 → 6.457 modelos). Adiciona os provedores Liquid Inference, Munito AI e Munito AI (UE) e descarta CrofAI, iFlow e Llama. A lista gratuita Cline adiciona Reflection Beam, Nemotron 3.5 Lightning e Laguna S 2.1 e elimina Mimo V2.6 Flash e Muse Spark 1.3 Contributor. ClinePass adiciona Kimi K3.1 Pro (agora seu padrão), MiniMax M3.1 Flash e DeepSeek V4.1 Flash 1017 e descarta Mimo V2.5 e V2.5 Pro. Os modelos padrão mudam para 56 outros fornecedores, principalmente para Kimi K3.1 Pro, MiniMax M3.1 Flash ou DeepSeek V4.1 Flash 1017 Changelog completo: https://github.com/cline/cline/compare/sdk/sdk/v0.0.95...sdk/sdk/v0.2.0

cline sdk/sdk/v0.2.0

  • Starting a session that already has a run in progress now reattaches to the live session instead of replacing its runtime. Before, the original run kept going but couldn't be reached, and its transcript writes landed on a stale snapshot. A start that includes a prompt while a run is in progress is rejected
  • The hub records every client that registered a capability for a session, including clients that join a task that's already running, and sends each request to the first one still connected. If none is left, the request fails quickly with a message the user can act on, instead of waiting forever
  • A turn whose connection drops after the model has streamed only reasoning is now retried, and the partial reasoning is discarded. Turns with text, media or tool calls are still never retried
  • Model requests retry at most 3 times after the first attempt (down from 5). Failed attempts are recorded in Langfuse traces, and cancelled requests are no longer reported as Langfuse errors
  • AI SDK updated to ai 7.0.136 / @ai-sdk/provider-utils 5.0.58. max reasoning now reaches the provider: the gateway no longer turns it into xhigh, and Kimi K3 gets max for Extra High and Max. Empty Anthropic turns are still retried despite the new anthropic.* custom stream parts
  • The gemini provider no longer sends native Google Search. On Gemini 3+, free-tier keys failed every turn with a 429 quota error, and on Gemini 2.x it dropped every Cline tool. Vertex keeps native search
  • Auto-compaction no longer runs when the model's input limit is unknown. Manual and overflow-recovery compaction still work
  • After the first compaction, the size estimate now uses the messages as they are actually sent, with tool results truncated. Before, it overestimated about 7x and compaction ran again every few tool calls
  • Checkpoint diffs read file contents with a single git cat-file --batch process instead of up to two git show processes per file. Workspaces with many untracked files used to spawn thousands of git processes
  • SSH remotes work behind a ProxyJump alias. The connect budget goes from 10s to 30s, the per-command limit to 60s, and tunnel readiness to 40s. When ssh exits mid-upload, its real error is reported instead of EPIPE, and a LocalForward on the alias no longer collides with the tunnel
  • ask_question answers are framed so the model keeps going after a bare choice. Empty answers are rejected, and an answer with only an attachment counts as answered
  • run_commands rejects an empty commands list with a tool error, and its schema now advertises minItems: 1
  • On PowerShell, the run_commands description explains backtick escaping, single-quoting literal paths, preferring cmdlets over cmd /c, and confirming recursive deletes first
  • Plugin commands run in the active session runtime and the hub. Plugin watches start working again when discovery directories appear
  • Compiled binaries load embedded plugin and dashboard resources straight from the binary, and every declared SDK runtime export is packaged
  • A configured CLINE_PLUGIN_RUNTIME_DIR is resolved to an absolute path
  • When OpenRouter has no match for a Cline recommended model, its capabilities are filled in from the Vercel catalog
  • Desktop cloud session orchestration moved into the hub. session.list reports activeCloudCommands, and the hub isn't replaced while cloud commands are still running
  • Core adds conversation summaries and cloud continuation support
  • Run stall telemetry: agent.run-finished and agent.run-failed carry stall signals from a new RunHealthObserver
  • @cline/ui now ships with the SDK packages on the shared version. It adds a Kbd component and token chips for slash commands and file mentions in AgentComposer
  • Refreshed the model catalog (7,041 → 6,457 models). Adds the Liquid Inference, Munito AI and Munito AI (EU) providers and drops CrofAI, iFlow and Llama. The Cline free list adds Reflection Beam, Nemotron 3.5 Lightning and Laguna S 2.1 and drops Mimo V2.6 Flash and Muse Spark 1.3 Contributor. ClinePass adds Kimi K3.1 Pro (now its default), MiniMax M3.1 Flash and DeepSeek V4.1 Flash 1017, and drops Mimo V2.5 and V2.5 Pro. Default models change for 56 other providers, mostly to Kimi K3.1 Pro, MiniMax M3.1 Flash or DeepSeek V4.1 Flash 1017
