caddy v2.9.1

Highlights

  • FastCGI buffering enabled by default — PR #6759 flips the reverse proxy to buffer full request bodies before handing off to FastCGI backends (PHP-FPM and friends). This is the most consequential behavioral change in the release: it trades a little latency and memory for more reliable request framing, so apps that depend on streaming uploads or early response behavior may see different timing. If you had explicitly tuned buffering off, re-check your config.

  • HTTP/3 disabled on Unix domain sockets — PR #6769 stops Caddy from trying to negotiate QUIC/h3 on UDS listeners. Since QUIC needs UDP and a Unix socket can't carry it, this removes a nonsensical negotiation path that could produce failed connections; no action needed unless you were relying on h3 across a UDS upstream (you shouldn't have been).

  • Idempotent graceful shutdown — Core change makes exit fire only once, addressing #6707 where repeated TERM signals kicked off duplicate shutdown sequences. This matters in orchestrated environments (systemd, Kubernetes) where multiple signals can land during drain—it eliminates double-close errors and flaky restarts.

  • header gains a match subdirective — PR #6765 brings response-matcher support to the Caddyfile header directive, so you can conditionally add or strip headers based on the response (e.g., security headers only on HTML). Previously this required a route with @matcher workarounds; the migration is a straightforward config simplification, not a requirement.

  • Log permission handling tightened — PR #6761 makes Caddy chmod log files only when the permission bits actually differ and creates the log directory when missing. Relevant if you manage log files with external tooling or hit permission drift/startup failures from missing dirs—expect fewer redundant filesystem writes and more predictable permissions.

  • CertMagic bumped to 0.21.6 — Upgrades the ACME stack to fix an ARI (ACME Renewal Information) handshake maintenance edge case, improving renewal reliability for subscribers. This is a drop-in dependency fix with no config changes required.

No breaking changes.

This is a patch release fixing a few issues related to FastCGI, HTTP/3 and unix sockets, log file permissions, repeated TERM signals, and an ARI edge case. It also adds Caddyfile support for response matching in the header directive.

Thanks to everyone who reported bugs and helped with fixes!
