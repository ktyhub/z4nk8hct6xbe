#AstrBot v4.23.0

  • Registro de atualização (chinês simplificado)
  • Changelog(Inglês) <a id="chinês"></a>

O que mudou

Novo

  • Suporta leitura (leitura), gravação (gravação), edição (edição) de arquivos, pesquisa Grep (ripgrep) e espaço de trabalho isolado por sessão para recursos de uso do computador. (#7402)
  • O adaptador de conta pessoal WeChat suporta a análise de mensagens de referência. (#7380)
  • Adicionada a ferramenta de pesquisa na web Brave Search e removida a antiga implementação de pesquisa na web padrão. (#6847)
  • Adicionado suporte ao adaptador da plataforma Mattermost. (#7369)
  • Adicionado provedor de reclassificação NVIDIA. (#7227)
  • Adicionado provedor LongCat LLM. (#7360)
  • Adicionado suporte para modos de entrada de áudio OpenAI e Gemini e corrigidos problemas relacionados à gravação ChatUI. (#7378)
  • A plataforma Discord adiciona uma nova configuração de filtragem de mensagens de Bot, permitindo controlar se deseja receber mensagens de outros Bots. (#6505)
  • Adicionada a capacidade do LLM de orientar chamadas repetidas de ferramentas para reduzir a situação em que o modelo cai em chamadas repetidas de ferramentas. (#7388)
  • QQ oficial API adiciona um mecanismo de nova tentativa para upload de arquivos para melhorar a estabilidade do envio de arquivos. (#7430)

Otimização

  • Reconstruir o estilo ChatUI, a renderização de mensagens e a experiência de entrada para melhorar a capacidade geral de manutenção e a consistência de interação da interface de chat. (#7485)
  • Combine ferramentas relacionadas ao Cron em uma ferramenta de gerenciamento unificada e adicione recursos de edição de tarefas Cron. (#7445)
  • Reconstrua a lógica de gerenciamento de ferramentas integrada para melhorar a manutenção do registro e chamada da ferramenta integrada do AstrBot. (#7418)
  • Removeu a maioria dos comandos integrados de baixa frequência e integrou as funções de comando, moveu esses comandos para o plug-in builtin-command-extension e atualizou a documentação. (#7478)
  • Removida a implementação padrão de pesquisa na web e substituída por um novo link para ferramenta de pesquisa. (#7416)
  • Removidas dependências lxml e beautifulsoup4 para reduzir o tamanho da instalação e a complexidade da dependência. (#7449)
  • Adicionada verificação de configuração stdio do MCP para reduzir falhas de inicialização e custos de solução de problemas causados por configurações inválidas. (#7477)
  • Docker Habilite no-new-privileges na configuração em execução para melhorar a segurança padrão do contêiner. (confirmar)
  • Reduza a frequência de pesquisa de status do servidor MCP e reduza a sobrecarga de solicitações em segundo plano. (#7399)
  • Os comandos de ajuda ignoram comandos internos válidos, como dashboard_update, para reduzir o ruído da lista de ajuda. (confirmar)
  • Corrigido o exemplo de emenda de caminho no documento para evitar que documentos de armazenamento de desenvolvimento de plug-ins enganem os usuários. (#7448)
  • Constantes de plataforma Matrix complementadas, ícones de plataforma e documentação relacionada. (#7368)

Correção

  • Corrigido um problema em que o STT ou o Provedor TTS ainda podiam ser usados quando desativados na configuração. (#7363)
  • Corrigido o problema da saída do modelo vazio do Gemini acionando acidentalmente o processamento de erros. (#7377)
  • Corrigido um problema em que o campo id não suportado no Gemini FunctionResponse causava falha na solicitação. (#7386)
  • Correção do problema em que FunctionCallingConfig ainda é aprovado quando apenas ferramentas nativas estão presentes. (#7407)
  • Corrigido um problema em que as afirmações de resultados da ferramenta eram inconsistentes com os limites dinâmicos. (comprometer)
  • Corrigido o problema de compatibilidade do formato de retorno do Bailian Rerank para diferentes endpoints de URL. (#7250)
  • Corrigido o problema de limpeza incompleta do processo de fechamento oficial do WebSocket do QQ. (#7395)
  • Corrigido o problema de recuperação de polling após anormalidade na rede do Telegram e adicionados testes relacionados. (#7468)
  • Corrigido o problema em que o segmento final de uma mensagem longa do Telegram era muito longo. (#7432)
  • Corrigido o problema em que o Telegram sendMessageDraft enviava texto vazio causando erro 400 ao limpar a tela. (#7398)
  • Corrigido o problema onde o manipulador do plug-in não estava em star_map causando KeyError quando o Telegram coletava comandos. (#7405)
  • Corrigido o problema em que o Discord Slash Command não adiava a tempo, causando 10062 Unknown interaction. (#7474)
  • Corrigida a mensagem de aviso quando o adaptador de conta pessoal WeChat não possui token de contexto. (confirmar)
  • Corrigido o problema do group_icl_enable não usar a configuração de ligação UMO ao processar mensagens. (#7397)
  • Corrigido o problema em que o caminho do módulo da ferramenta de função do plug-in é inconsistente com o caminho do módulo principal do plug-in. (#7462)
  • Corrigido o suporte da lógica de verificação de versão do plug-in para versões de pré-lançamento. (comprometer)
  • Corrigido o problema em que caracteres não ASCII escapavam na resposta da execução do comando Shell JSON. (#7475)
  • Correção de um problema em que o carregamento de dependências do plug-in da área de trabalho do Windows não era seguro ou falhava. (#7446)
  • Corrigido o problema em que faiss era importado prematuramente durante a fase de inicialização, causando falha na inicialização de alguns ambientes. (#7400)
  • Correção da renderização do modo escuro da WebUI e de vários problemas de interação. (#7173)
  • Corrigidas constantes ausentes do projeto ChatUI e adicionados casos de teste relacionados. (#7414)
  • Corrigido o problema de botões flutuantes saltando ao mudar de página. (#7214)
  • Corrigido o problema de falta da dependência da página de gerenciamento de diálogo MessageList.vue, causando falha na construção do Dashboard do ambiente Linux. (comprometer)
  • Corrigido o problema de exibição causado pelo ícone de chamada de ferramenta usando o ícone ausente do subconjunto MDI. (comprometer)
  • Corrigido o problema de uso do tipo defineStore na loja Dashboard. (#7490)
  • Corrigido erro de nome de imagem Docker no arquivo de composição. (#7488) <a id="english"></a>

AstrBot v4.23.0

Highlights

  • Session-isolated local file tools — Computer Use gains file read, write, edit, ripgrep-backed search, and per-session workspaces (#7402), allowing agents to inspect and modify project files without sharing session state. Scope granted workspaces carefully to data the agent is permitted to change.

  • Web search migration — Brave Search replaces the old default web-search implementation (#6847, #7416). Update tool bindings, prompts, and workflows that call the removed implementation directly; existing search configurations should not be assumed to carry over unchanged.

  • Built-in command relocation — Many low-frequency built-in commands move to the builtin_commands_extension plugin (#7478). Install that extension if you depend on the affected commands, and update scripts or documentation that still treat them as core features.

  • Multimodal and platform expansion — OpenAI and Gemini gain audio input (#7378), while LongCat and NVIDIA Rerank add model and ranking options (#7360, #7227). Mattermost support arrives (#7369), Weixin OC gains reply-message parsing (#7380), and Discord can optionally accept messages from other bots (#6505)—useful for bot-to-bot workflows, but potentially loop-prone without filtering.

  • Tool-calling reliability and configuration changes — LLM guidance reduces repeated tool-call loops (#7388), and Cron tools are consolidated into an editable management tool (#7445). Disabled STT/TTS providers now return None instead of still being resolved (#7363), so integrations should handle missing providers explicitly; native-only tool configurations also stop receiving FunctionCallingConfig (#7407).

  • Deployment and plugin compatibility — Removing lxml and beautifulsoup4 (#7449) means plugins importing them directly must declare their own dependencies. MCP stdio configurations are validated earlier (#7477), while fixes address faiss startup imports and Windows plugin dependency loading (#7400, #7446). Docker now enables no-new-privileges (68a195e12), which may affect custom images relying on setuid-based privilege escalation.
