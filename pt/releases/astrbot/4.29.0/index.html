#AstrBot v4.29.0

[4.29.0] - 14/10/2026

Esta versão inclui todas as alterações de v4.29.0-beta.1 e v4.29.0-beta.2, além de alterações desde v4.29.0-beta.2. A gama completa de lançamentos começa em v4.28.0.

Principais adições

  • Uso do computador: Adicionado suporte sandbox específico do sistema operacional para o ambiente de execução local, disponível no macOS com Seatbelt e Linux apenas com bubblewrap. Consulte: https://docs.astrbot.app/use/astrbot-agent-sandbox.html (#9472)
  • ChatUI: Adicionado histórico de bate-papo e paginação de sessão da barra lateral, rascunhos de entrada persistentes, seleção de modelo por sessão e foco automático de entrada ao alternar projetos. (#9667, #10279, #10247, #10301)
  • ChatUI: Adicionados filtros de origem do provedor e grupos fixos para seleção de modelos, além de pesquisa nas páginas Habilidades e MCP. (#10084, #10217)
  • As configurações de texto para imagem mudaram de Configurações para Perfis de configuração → Extensões e agora são configuradas separadamente para cada perfil.
  • As configurações do administrador e da lista de permissões foram movidas de Perfis de configuração → Plataforma para Perfis de configuração → Controle de acesso. (#10321)
  • WebUI: Adicionado um seletor de diretório de espaço de trabalho e atualização do progresso do download no aplicativo de desktop. (#10222, #10227, #10050)
  • Área de trabalho: Adicionados efeitos de vidro fosco do macOS à barra lateral e à barra superior do WebUI. (#10222, #10227, #10050)
  • Básico: Adicionados lembretes de orçamento de etapas do agente, limites legados migrados, aumento do limite padrão de etapas do agente e esperas estendidas de sessões de shell. (#10131, #10133)
  • Core: Adicionado o cabeçalho de ID de conversação x-astrbot-conversation-id às solicitações do provedor. (#10218, #10237)
  • WebUI: Adicionados atalhos de configurações de modelo ao lado dos modelos selecionados e nos menus de modelo/substituição. As alterações são salvas imediatamente para cada perfil de configuração que usa esse modelo. (#10321)
  • WebUI: Adicionada pesquisa de log do console e destaque de palavras-chave, emblemas de origem para habilidades, visualizações de imagens preparadas no ChatUI e lembrança da última guia Dados e registros aberta. (#10327, #10339, #10376, #10251)
  • WebUI: Adicionada edição de perfil de configuração em uma gaveta lateral do editor de bot. (#10310)
  • Docker: Incluso o astrbot CLI para redefinição de senha dentro de containers. (#10442)
  • Logs: Adicionada filtragem combinada de nível, fonte, plugin, plataforma e palavras-chave, uma opção para ocultar logs de bate-papo do usuário e controles de tamanho de fonte de 8 a 16px (12px por padrão, em etapas de 2px). Os seletores de plug-in mostram nomes de exibição com IDs como legendas. (#10514)

  • 电脑使用:本地执行环境新增按操作系统适配的沙箱隔离，目前支持 macOS Seatbelt e Linux bubblewrap。参考：https://docs.astrbot.app/use/astrbot-agent-sandbox.html (#9472)

  • Core: 新增 Agent 剩余步数提醒，迁移旧版步数限制，提高默认步数上限，并延长 Shell 会话等待时间。 (#10131, #10133)
  • Núcleo: 为模型提供商请求新增 x-astrbot-conversation-id 会话 ID 请求头。 (#10218, #10237)
  • WebUI：模型选择器旁及模型、回退模型菜单内新增设置入口, 修改后立即影响引用该模型的所有配置文件。 (#10321)
  • WebUI: 新增控制台日志搜索与关键词高亮、Habilidades 来源标识、ChatUI待发送图片预览，并记住「数据与日志」页上次打开的标签。 (#10327, #10339, #10376, #10251)
  • WebUI:支持在机器人编辑器的侧边抽屉中编辑配置文件。 (#10310)

AstrBot v4.29.0

Highlights

  • OS-native sandboxing for Computer Use — Local agent execution can now be isolated with macOS Seatbelt or Linux bubblewrap (#9472), shrinking the blast radius of shell/file tool calls. Watch out: coverage is deliberately narrow (no Windows isolation), and when local isolation is unavailable the execution/file-access controls remain visible but unenforced (#10444–#10487) — don't assume you're sandboxed on unsupported hosts.

  • Configuration keys moved — budget upgrade time — Text-to-image rendering moves from Settings to Configuration Profiles → Extensions and is now isolated per profile (#10306); admin/whitelist moves from Profiles → Platform to Profiles → Access Control, and Platform is renamed Platforms & Messages (#10321); the Customize Sidebar feature is removed (#10480). Scripts or docs targeting old labels/paths will need updating, and users should expect to re-locate these settings after upgrading.

  • /reset and /new semantics restored — /reset again clears only the current conversation context while /new creates and switches to a fresh conversation, undoing a regression (#10118, #10003, #9983). Bot logic and user docs written against the recent (broken) behavior must be re-validated; persisted conversation deletion and history titles are fixed in the same pass.

  • Provider-facing wire changes — Provider requests now carry an x-astrbot-conversation-id header (#10218, #10237), letting custom/proxy endpoints correlate turns. The retired Gemini embedding default is replaced with gemini-embedding-001 (#10393) — re-check pinned configs — and full Anthropic tool parameter schemas (including refs and constraints) are preserved while non-object root schemas are now rejected (#10520).

  • Agent budgets and lifecycle tightened — Step-budget reminders arrive alongside a higher default agent step limit and migrated legacy limits (#10131, #10133), and stopping a session now genuinely halts background agent work and blocks late wakeups (#10323, #10347, #10474). Per-run scheduled-task context also moved after conversation history to keep the system prompt stable and preserve prompt-cache reuse (#10549) — a quiet latency/cost win for scheduled agents.

  • WebUI load and upload performance — Initial load drops via lazy-loaded VAD, Monaco, translations and ApexCharts plus gzip responses (#10413), and uploads are now resumable/chunked with bounded memory (#10123); desktop adds a workspace directory picker and update-download progress (#10222, #10227, #10050). Low adoption risk, but expect different asset-loading behavior on first use of the editor and charts.
