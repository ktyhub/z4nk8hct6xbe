#AstrBot v4.27.3

[4.27.3] - 13/08/2026

E então saímos para ver as estrelas novamente. Saímos de lá e vimos as estrelas novamente.

Adicionado

  • AstrBot Desktop agora usa sessões sem senha e abre o WebUI diretamente sem exigir login. (#9585)
  • Adicionado o horário efetivo do AstrBot às configurações e feito com que os cron jobs herdassem o fuso horário configurado. (#9579, #9581)
  • Uploads expandidos de arrastar e soltar do WebChat para toda a área de bate-papo. (#9564)
  • Adicionada uma opção one-click para restaurar os padrões de configuração do plugin. (#9599)
  • Adicionado suporte do PowerShell 7 para o shell local do Windows. (#9622)
  • Adicionada classificação de contagem de downloads ao mercado de plugins. (#9570)
  • Adicionados uploads de arquivos em partes para QQ Official para suportar arquivos grandes de forma mais confiável. (#9646)
  • Usou favicons como ícone de plug-in padrão e contraste de texto com tema escuro aprimorado. (#9547, #9643)

Alterado

  • Migração de SharedPreferences e acesso preferencial de configuração para caminhos assíncronos e sem bloqueio, melhorando o desempenho nos fluxos afetados e reduzindo o risco de congelamentos e impasses aparentes. (#9582, #9584, #9649)
  • Pesquisa estabilizada de documentos na base de conhecimento, distinção entre falhas de carregamento e resultados vazios, resultados de recuperação completos restaurados e suporte para fallback de UUID ao resolver bases de conhecimento por nome. (#9577, #9578, #9618, #9636)
  • Configuração atualizada do provedor na memória após exclusão e estado sincronizado da habilidade do plugin no Dashboard. (#9568, #9596)
  • Impediu que sessões transitórias do projeto aparecessem no ChatUI e restaurou sessões perdidas do WebChat. (#9587, #9607)
  • Nomes de ferramentas MCP higienizados para LLM APIs e esquemas de configuração vazios tratados como não tendo itens configuráveis. (#9534, #9619)
  • Avisado quando uma distribuição WebUI explicitamente configurada está obsoleta. (#9518)
  • Horários de término do agente registrados antes da publicação de estatísticas e execuções de agentes interrompidas canceladas imediatamente. (#9597, #9602)
  • Usei miniaturas estáticas para adesivos animados do Telegram e converti notas de vídeo do Telegram em componentes de vídeo. (#9610, #9627)
  • Falhas de upload de mídia QQ propagadas em vez de continuar silenciosamente. (#9644)

Manutenção

  • Dependências de ações GitHub agrupadas atualizadas, digitação aprimorada do agendador de pipeline e testes OpenAI HTTP client estabilizados. (#9620, #9621)

  • Adicionada função de um clique para restaurar os valores padrão de configuração do plug-in. (#9599)
  • Exibir o tempo efetivo real do AstrBot nas configurações e fazer com que as tarefas agendadas herdem o fuso horário configurado. (#9579, #9581)

Correção

  • Melhorou algum desempenho e reduziu possíveis situações de animação suspensa e impasse (SharedPreferences migradas e acesso de preferência de configuração para caminhos assíncronos e sem bloqueio). (#9582, #9584, #9649)
  • Estabilize a pesquisa de documentos da base de conhecimento, distinga falhas de carregamento de resultados vazios, restaure resultados completos da pesquisa e ofereça suporte ao substituto de UUID ao pesquisar bases de conhecimento por nome. (#9577, #9578, #9618, #9636)
  • Atualize o status da memória após excluir a configuração do provedor e sincronize o status da habilidade do plug-in no Dashboard. (#9568, #9596)
  • Impedir que sessões temporárias do projeto apareçam na lista de sessões do ChatUI e restaurar sessões perdidas do WebChat. (#9587, #9607)
  • Limpe os nomes das ferramentas MCP enviados ao LLM API e trate corretamente os esquemas de configuração vazios como nenhum item de configuração. (#9534, #9619)
  • Avisar quando os arquivos de versão do WebUI explicitamente configurados estiverem desatualizados. (#9518)
  • Registrar o horário de término do agente antes de publicar as estatísticas e cancelar imediatamente as execuções interrompidas do agente. (#9597, #9602)
  • Os adesivos dinâmicos do Telegram são substituídos por miniaturas estáticas e as mensagens de vídeo do Telegram são convertidas em componentes de vídeo. (#9610, #9627)
  • Quando o upload de mídia QQ falha, o erro é transmitido corretamente para cima e não continua mais silenciosamente. (#9644)

AstrBot v4.27.3

Highlights

  • Passwordless desktop access — The desktop app now opens the WebUI directly without a login, simplifying first-run and everyday access; this is a meaningful security-behavior change to account for in workstation or remote-access policies (#9585).
  • More reliable knowledge-base retrieval — Document search no longer truncates results or conflates loading failures with genuinely empty answers, and name resolution can fall back to UUIDs. This makes RAG behavior more predictable for users and easier to diagnose (#9577, #9578, #9618, #9636).
  • Less main-thread blocking — SharedPreferences and configuration preference access moved to asynchronous, non-blocking paths, reducing apparent freezes and deadlock risk in affected workflows. Plugin authors relying on synchronous settings access should check their integration assumptions (#9582, #9584, #9649).
  • Improved scheduling and agent lifecycle — Cron jobs now inherit the configured timezone, settings expose AstrBot’s effective time, and stopped runs are cancelled immediately. Ending agents also have their end time recorded before statistics are emitted, improving timing accuracy and reducing wasted background work (#9579, #9581, #9597, #9602).
  • More robust platform integrations — QQ Official supports chunked large-file uploads and now surfaces media upload failures instead of silently continuing, while the Windows local shell adds PowerShell 7 support. Error handling and retry logic should account for these newly visible failures (#9622, #9644, #9646).
  • Better administration and compatibility diagnostics — A one-click reset restores plugin configuration defaults, Dashboard plugin Skill state stays synchronized, MCP tool names are sanitized for LLM APIs, and explicitly configured stale WebUI distributions trigger a warning. These changes simplify recovery, reduce cross-system state drift, and surface compatibility problems earlier (#9534, #9518, #9596, #9599).

Added

  • AstrBot Desktop now uses passwordless sessions and opens the WebUI directly without requiring a login. (#9585)
  • Added the effective AstrBot time to settings and made cron jobs inherit the configured timezone. (#9579, #9581)
  • Expanded WebChat drag-and-drop uploads to the whole chat area. (#9564)
  • Added a one-click option to restore plugin configuration defaults. (#9599)
  • Added PowerShell 7 support for the Windows local shell. (#9622)
  • Added download-count sorting to the plugin marketplace. (#9570)
  • Added chunked file uploads for QQ Official to support large files more reliably. (#9646)
  • Used favicons as the default plugin icon and improved dark-theme text contrast. (#9547, #9643)

Changed

  • Migrated SharedPreferences and configuration preference access to asynchronous, non-blocking paths, improving performance in affected flows and reducing the risk of apparent freezes and deadlocks. (#9582, #9584, #9649)
  • Stabilized knowledge base document search, distinguished loading failures from empty results, restored complete retrieval results, and supported UUID fallback when resolving knowledge bases by name. (#9577, #9578, #9618, #9636)
  • Refreshed in-memory provider configuration after deletion and synchronized plugin Skill state across the Dashboard. (#9568, #9596)
  • Prevented transient project sessions from appearing in ChatUI and restored missing WebChat sessions. (#9587, #9607)
  • Sanitized MCP tool names for LLM APIs and treated empty configuration schemas as having no configurable items. (#9534, #9619)
  • Warned when an explicitly configured WebUI distribution is stale. (#9518)
  • Recorded agent end times before publishing statistics and cancelled stopped agent runs immediately. (#9597, #9602)
  • Used static thumbnails for animated Telegram stickers and converted Telegram video notes into video components. (#9610, #9627)
  • Propagated QQ media upload failures instead of silently continuing. (#9644)

Maintenance

  • Updated grouped GitHub Actions dependencies, improved pipeline scheduler typing, and stabilized OpenAI HTTP client tests. (#9620, #9621)

中文

新增

  • AstrBot 桌面端实行免登录机制，无需登录即可直接进入 WebUI。 (#9585)
  • Windows 本地 Shell 新增 PowerShell 7 支持。 (#9622)
  • QQ 官方机器人新增分片文件上传，修复大文件无法正常发送的问题。 (#9646)
  • 将 WebChat 拖放上传区域扩展至整个聊天区域。 (#9564)
  • 新增一键恢复插件配置默认值的功能。 (#9599)
  • 在设置中展示 AstrBot 的实际生效时间，并使定时任务继承已配置的时区。 (#9579, #9581)
  • 插件市场新增按下载量排序。 (#9570)
  • 使用 favicon 作为插件默认图标，并改善深色主题的文字对比度。 (#9547, #9643)

修复

  • 提升了一部分性能，减少潜在假死和死锁情况（将 SharedPreferences 与配置偏好访问迁移到异步、非阻塞路径）。 (#9582, #9584, #9649)
  • 稳定知识库文档搜索，区分加载失败与空结果，恢复完整检索结果，并在按名称查找知识库时支持 UUID 回退。 (#9577, #9578, #9618, #9636)
  • 删除提供商配置后刷新内存状态，并同步 Dashboard 中的插件 Skill 状态。 (#9568, #9596)
  • 防止临时项目会话出现在 ChatUI 会话列表中，并恢复缺失的 WebChat 会话。 (#9587, #9607)
  • 清理发送给 LLM API 的 MCP 工具名称，并将空配置 Schema 正确视为无配置项。 (#9534, #9619)
  • 显式配置的 WebUI 发行文件过期时给出警告。 (#9518)
  • 在发布统计前记录 Agent 结束时间，并立即取消已停止的 Agent 运行。 (#9597, #9602)
  • Telegram 动态贴纸改用静态缩略图，并将 Telegram 视频留言转换为视频组件。 (#9610, #9627)
  • QQ 媒体上传失败时正确向上传递错误，不再静默继续。 (#9644)

维护

  • AstrBot 桌面端使用 Cloudflare R2 作为更新源。
  • 更新 GitHub Actions 依赖组，完善流水线调度器类型标注，并稳定 OpenAI HTTP 客户端测试。 (#9620, #9621)
