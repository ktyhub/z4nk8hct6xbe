#AstrBot v4.29.3

[4.29.3] - 24/10/2026

A vida é como uma caixa de chocolates.

Novo

  • Rastreamento de mensagens: melhora ainda mais a capacidade de rastreamento de mensagens, suportando a gravação e observação de todos os eventos de mensagens recebidas, bem como as chamadas de plug-in e chamadas de Agente correspondentes aos eventos. (Primeiro precisa ser ativado nas configurações no canto inferior esquerdo da WebUI) (#10614)
  • Exportação de diagnóstico: suporta a exportação de um pacote de diagnóstico do sistema dessensibilizado do console e das configurações do sistema, incluindo logs, rastreamento, configuração, status do plug-in, ambiente e outras informações. (#10418, #10659)
  • Script de instalação: Adicionado processo de instalação em vários idiomas e suporte a imagens da China continental. (#10629)

Correção

  • Backup: Conclua o backup e recuperação de tarefas agendadas, arquivos persistentes e diretórios de dados relacionados para evitar perda de dados. (#10644, #10661)
  • Gemini: Suporta parâmetros de geração personalizados de modelo, mantendo valores zero definidos explicitamente; corrige o problema de incompatibilidade de esquema de ferramenta causado por enumeração sem string. (#10719, #10635)
  • Reclassificação NVIDIA: preserva os caminhos de endpoint API específicos do modelo para evitar a solicitação do endereço universal errado. (#10732)
  • Uso do PC: análise corrigida dos resultados de execução do Shipyard Bay e limpeza do processo filho no tempo limite ou cancelamento do Windows Shell. (#10671, #10729)
  • WebUI: Corrigida a perda de metadados do modelo após atualização da configuração, seleção do modelo de chat padrão, localização do nome da barra lateral do plugin, notificações de atualização da área de trabalho e valores padrão do campo do modelo de configuração. (#10522, #10663, #10576, #10622, #10517)
  • WebUI: Otimize a exibição de instruções de configuração e opções condicionais, corrija a janela pop-up de instalação do Pip no log de tela inteira, registre a espera de conexão de fluxo e logs duplicados após a troca de página e esclareça o intervalo de filtragem do plug-in. (#10647, #10608, #10666, #10694, #10691)
  • Banco de dados: use expressões de consulta JSON compatíveis com bancos de dados cruzados. (#10664)

Adicionado

  • Rastreamento de mensagens: rastreamento aprimorado para registrar e inspecionar todos os eventos de mensagens recebidas e seus plug-ins associados e chamadas de agente. Ative-o primeiro em Configurações no canto inferior esquerdo da WebUI. (#10614)
  • Diagnóstico: exporte pacotes de diagnóstico do sistema com suporte para redação do console e configurações do sistema, incluindo logs, rastreamentos, configuração, status do plug-in e informações do ambiente. (#10418, #10659)
  • Instalador: Adicionada configuração multilíngue e espelhos da China continental. (#10629)

Corrigido

  • Backups: incluem tarefas agendadas, arquivos persistentes e diretórios de dados relacionados em operações de backup e restauração. (#10644, #10661)
  • Gemini: respeite parâmetros de geração específicos do modelo e valores zero explícitos e lide com enumerações sem string em esquemas de ferramentas. (#10719, #10635)
  • Reclassificação NVIDIA: preserva caminhos de endpoint específicos do modelo em vez de substituir um endpoint genérico. (#10732)
  • Uso do computador: analise corretamente os envelopes de execução do Shipyard Bay e limpe os processos filhos do shell do Windows em caso de tempo limite ou cancelamento. (#10671, #10729)
  • WebUI: preserva os metadados do modelo buscado após atualização da configuração; restaurar a seleção do modelo de chat padrão; localizar nomes da barra lateral do plugin; corrigir avisos de atualização da área de trabalho e padrões de campo de modelo. (#10522, #10663, #10576, #10622, #10517)
  • WebUI: Esclareça dicas de configuração e configurações condicionais; mantenha a caixa de diálogo Pip visível nos registros em tela cheia; liberar cabeçalhos de fluxo de log imediatamente; evitar registros duplicados após a navegação; esclarecer o escopo do filtro do plugin. (#10647, #10608, #10666, #10694, #10691)
  • Banco de dados: use expressões de consulta portáteis JSON. (#10664)

AstrBot v4.29.3

Highlights

  • End-to-end message tracing — Inbound events now link to their plugin and Agent calls, making multi-step message flows easier to debug. Tracing is opt-in via the WebUI’s lower-left Settings and adds bounded SQLite history to limit local growth (#10614).
  • Redacted diagnostic bundles — Export logs, traces, configuration, plugin status, and environment details from the console or system settings, with sensitive data redacted for support tickets and bug reports (#10418, #10659).
  • More complete backups — Scheduled tasks, persistent files, and associated data directories are now included in backup/restore operations. Recreate backup artifacts after upgrading if you previously relied on incomplete archives (#10644, #10661).
  • Gemini generation and tool-schema fixes — Model-specific generation parameters now apply, including explicitly set zero values that were previously discarded. Non-string enum handling also prevents incompatible tool schemas, reducing failures in function-calling workflows (#10719, #10635).
  • Provider endpoint and execution fixes — NVIDIA Rerank retains model-specific endpoint paths rather than falling back to a generic URL (#10732). Computer-use fixes correctly unwrap Shipyard Bay execution envelopes (#10671) and clean up Windows shell child processes on timeout or cancellation (#10729).
  • WebUI and cross-database reliability — Model metadata survives configuration refresh, default chat-model selection is restored, and SSE/log handling avoids delayed streams and duplicate entries after navigation (#10522, #10663, #10666, #10694). Portable JSON queries improve compatibility across database backends (#10664).

No breaking changes.

[4.29.3] - 2026-10-24

Life is like a box of chocolates.

新增

  • 消息追踪：进一步完善消息追踪能力，支持记录和观测所有入站消息事件，以及事件对应的插件调用和 Agent 调用。（需要先在 WebUI 左下角设置中开启） (#10614)
  • 诊断导出：支持从控制台和系统设置导出支持脱敏的系统诊断包，包含日志、追踪、配置、插件状态和环境等信息。 (#10418, #10659)
  • 安装脚本：新增多语言安装流程和中国大陆镜像支持。 (#10629)

修复

  • 备份：补全定时任务、持久化文件和相关数据目录的备份与恢复，避免数据遗漏。 (#10644, #10661)
  • Gemini：支持模型自定义生成参数，保留显式设置的零值；修复非字符串枚举导致工具 Schema 不兼容的问题。 (#10719, #10635)
  • NVIDIA Rerank：保留模型专属 API 端点路径，避免请求错误的通用地址。 (#10732)
  • 电脑使用：修复 Shipyard Bay 执行结果的解析，以及 Windows Shell 超时或取消时的子进程清理。 (#10671, #10729)
  • WebUI：修复配置刷新后模型元数据丢失、默认聊天模型选择、插件侧栏名称本地化、桌面更新通知和配置模板字段默认值。 (#10522, #10663, #10576, #10622, #10517)
  • WebUI：优化配置说明与条件选项显示，修复全屏日志中的 Pip 安装弹窗、日志流连接等待和页面切换后的重复日志，并明确插件筛选范围。 (#10647, #10608, #10666, #10694, #10691)
  • 数据库：使用跨数据库兼容的 JSON 查询表达式。 (#10664)

Added

  • Message tracing: Improved tracing to record and inspect all incoming message events and their associated plugin and Agent calls. Enable it first in Settings in the lower-left corner of the WebUI. (#10614)
  • Diagnostics: Export system diagnostic bundles with redaction support from the console and system settings, including logs, traces, configuration, plugin status, and environment information. (#10418, #10659)
  • Installer: Added multilingual setup and mainland China mirrors. (#10629)

Fixed

  • Backups: Include scheduled tasks, persistent files, and related data directories in backup and restore operations. (#10644, #10661)
  • Gemini: Honor model-specific generation parameters and explicit zero values, and handle non-string enums in tool schemas. (#10719, #10635)
  • NVIDIA Rerank: Preserve model-specific endpoint paths instead of substituting a generic endpoint. (#10732)
  • Computer use: Parse Shipyard Bay execution envelopes correctly and clean up Windows shell child processes on timeout or cancellation. (#10671, #10729)
  • WebUI: Preserve fetched model metadata after configuration refresh; restore default chat model selection; localize plugin sidebar names; fix desktop update notices and template field defaults. (#10522, #10663, #10576, #10622, #10517)
  • WebUI: Clarify configuration hints and conditional settings; keep the Pip dialog visible in fullscreen logs; flush log stream headers promptly; prevent duplicate logs after navigation; clarify plugin filter scope. (#10647, #10608, #10666, #10694, #10691)
  • Database: Use portable JSON query expressions. (#10664)
