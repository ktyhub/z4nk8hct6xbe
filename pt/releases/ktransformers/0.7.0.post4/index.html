ktransformadores v0.7.0.post4

KTransformadores 0.7.0.post4

Treinamento LoRA de texto Kimi K2.5, currículo de ponto de verificação e carregamento de adaptador SGLang com especialistas roteados RAWINT4 nativos.

Instalação Python 3.11 / 3.12

Comece com o guia passo a passo e o kit do usuário r2. Verifique SHA256SUMS-r2.txt antes de extraí-lo. O guia atualizado é rastreado em PR #2207. O kit contém três YAMLs, ferramentas de preparação de dados e conversão LoRA e bloqueios de dependência Python 3.11 / 3.12 separados. Somente o modelo e os caminhos de saída precisam ser alterados. Os pacotes principais são instalados a partir do PyPI; a roda de ramificação LF aprovada e as rodas PEFT/TRL somente de metadados são fornecidas com o kit. Não instale pacotes upstream Transformers/Accelerate sobrepostos nesses ambientes.

  • Linux x86_64, glibc 2.35+, Python 3.11 ou 3.12, CUDA 12.8, tocha 2.9.1.
  • Hardware validado: dual AMD EPYC 9355, aproximadamente 1.5 TiB RAM; 8 GPUs RTX 5090 para treinamento e 4 para inferência. Esta não é uma reivindicação de especificação mínima.
  • ktransformadores / kt-kernel / sglang-kt 0.7.0.post4; transformadores-kt 5.6.0.post5; acelerar-kt 1.14.0.post3.
  • A embalagem está desativada. Use o modelo original fixado e a etapa explícita de preparação de dados. Os hosts sem acesso ao Hugging Face devem obter os instantâneos de modelo/dados fixados separadamente. O suplemento de 14 de setembro adiciona uma roda CPython 3.11 real, incluindo encadernações nativas correspondentes. As versões existentes, os arquivos originais de cinco rodas e o kit r1 permanecem inalterados. Python 3.11 requer r2; não reutilize os arquivos de bloqueio r1 Python 3.12 nem renomeie uma roda cp312. Se um espelho não sincronizou o novo arquivo, use o índice oficial do PyPI.

Validação e escopo

Ambientes candidatos limpos Python 3.11 e 3.12 separados passaram no treinamento básico Kimi, currículo de novo processo com bit exato em 20 comparações de estado, conversão LoRA comum/especializada e nova geração de SGLang com todas as 60 camadas LoRA especializadas carregadas. A reconstrução independente do Python 3.12 com principal congelado também foi aprovada. Evidências candidatas e referências de fontes congeladas estão incluídas em r2. O ciclo de vida público-PyPI original do Python 3.12 passou em 13 de setembro; consulte PUBLIC_WHEEL_VERIFICATION.json. A instalação pós-publicação do r2 e a verificação do ciclo de vida estão em execução; a publicação por si só não é relatada como conclusão dessa verificação. O Neko checkpoint-100 treinado separadamente foi recarregado em ambas as versões Python e completou 32 respostas retidas por versão com texto correspondente. Ele exibe o estilo pretendido, mas ainda falha em algumas verificações rigorosas de formato e qualidade de conteúdo. O treinamento de fumaça em quatro etapas não é um experimento completo de convergência de estilo ou uma garantia geral de qualidade/segurança. A validação de versão anterior cobriu treinamento/inferência Qwen3-30B-A3B BF16, treinamento FP8 nativo DeepSeek-V3.1 e inferência de texto GLM next-0808 designada pelo usuário; estes não foram repetidos para este suplemento Python. K2.5 é validado por hardware. O caminho da arquitetura compartilhada do K2.6 não foi testado separadamente em hardware. Treinamento visual, outras arquiteturas e comprimentos de sequência arbitrários não são certificados aqui. A equivalência da fonte original permanece registrada em equivalência principal.json. As rodas reconstruídas de forma independente da mesma versão não substituem os artefatos publicados.

ktransformers v0.7.0.post4

KTransformers 0.7.0.post4

Kimi K2.5 text LoRA training, checkpoint resume, and SGLang adapter loading with native RAWINT4 routed experts.

Python 3.11 / 3.12 installation

Start with the step-by-step guide and the r2 user kit. Check SHA256SUMS-r2.txt before extracting it. The updated guide is tracked in PR #2207.

The kit contains three YAMLs, data preparation and LoRA conversion tools, and separate Python 3.11 / 3.12 dependency locks. Only model and output paths need changing. Core packages install from PyPI; the approved LF branch wheel and metadata-only PEFT/TRL wheels are bundled with the kit. Do not install overlapping upstream Transformers/Accelerate packages into these environments.

  • Linux x86_64, glibc 2.35+, Python 3.11 or 3.12, CUDA 12.8, Torch 2.9.1.
  • Validated hardware: dual AMD EPYC 9355, approximately 1.5 TiB RAM; 8 RTX 5090 GPUs for training and 4 for inference. This is not a minimum-spec claim.
  • ktransformers / kt-kernel / sglang-kt 0.7.0.post4; transformers-kt 5.6.0.post5; accelerate-kt 1.14.0.post3.
  • Packing is disabled. Use the pinned original model and explicit data-preparation step. Hosts without Hugging Face access must obtain the pinned model/data snapshots separately.

The September 14 supplement adds one real CPython 3.11 wheel, including matching native bindings. Existing versions, the original five wheel files, and the r1 kit are unchanged. Python 3.11 requires r2; do not reuse the r1 Python 3.12 lock files or rename a cp312 wheel. If a mirror has not synchronized the new file, use the official PyPI index.

Validation and scope

Separate Python 3.11 and 3.12 clean candidate environments passed Kimi base training, bit-exact new-process resume across 20 state comparisons, ordinary/expert LoRA conversion, and fresh SGLang generation with all 60 expert-LoRA layers loaded. The independent frozen-main Python 3.12 rebuild also passed. Candidate evidence and frozen source references are included in r2.

The original Python 3.12 public-PyPI lifecycle passed on September 13; see PUBLIC_WHEEL_VERIFICATION.json. Post-publication r2 installation and lifecycle verification is now running; publication alone is not reported as completion of that check.

The separately trained Neko checkpoint-100 was reloaded in both Python versions and completed 32 held-out answers per version with matching text. It displays the intended style, but still fails some strict-format and content-quality checks. Four-step smoke training is not a full style-convergence experiment or a general-quality/safety guarantee.

Earlier release validation covered Qwen3-30B-A3B BF16 training/inference, DeepSeek-V3.1 native FP8 training, and user-designated GLM next-0808 text inference; these were not repeated for this Python supplement. K2.5 is hardware-validated. K2.6's shared architecture path was not separately hardware-tested. Vision training, other architectures, and arbitrary sequence lengths are not certified here.

Original source equivalence remains recorded in main-equivalence.json. Same-version independently rebuilt wheels do not replace published artifacts.
