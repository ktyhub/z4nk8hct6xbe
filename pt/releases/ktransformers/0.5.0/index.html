ktransformadores v0.5.0

🚀 Destaques principais

  • Kernel MoE FP8 nativo: Apresentando suporte de precisão FP8 nativo para inferência MoE com um novo kernel baseado em AVX. Execute modelos FP8 diretamente, sem sobrecarga de conversão de precisão, preservando a precisão do modelo original e maximizando a eficiência do hardware.
  • kt-cli para inferência local sem esforço: uma nova ferramenta CLI projetada para simplicidade e facilidade de uso. Gerenciamento de modelos, configuração automática, fluxos de trabalho contínuos de bate-papo/conclusões e detecção de ambiente SGLang integrada: comece com inferência LLM local em minutos.
  • Pré-preenchimento em camadas aprimorado: desempenho aprimorado de pré-preenchimento em camadas por meio de pipeline de especialista por especialista. A arquitetura de pré-preenchimento em camadas permite um streaming de memória eficiente durante o pré-preenchimento, melhorando significativamente o rendimento e reduzindo a latência para cargas de trabalho de contexto longo.

📌 Modelos, Hardware e Ferramentas

  • Atualizações de suporte de modelo
    • Estenda o caminho de ativação do FP8 nesta versão, concentrando-se no suporte nativo do FP8 MoE e nas melhorias de compatibilidade.
    • Adicione suporte nativo a MiniMax-M2, MiniMax-M2.1, DeepSeek-V3.2 e ativação relacionada.
  • Melhorias de kernel e hardware
    • Adicionar kernel FP8 MoE baseado em AVX.
    • Reduza os requisitos de DRAM para a maioria dos modelos durante o pré-preenchimento da CPU.
    • Melhore o pré-preenchimento em camadas para melhor rendimento.
  • Ferramentas e integração
    • Apresentar kt-cli, um novo CLI unificado para gerenciamento de modelo, chat, configuração automática e gerenciamento de servidor de inferência.
  • Implantação e instalação
    • Refatorar fluxos de trabalho/scripts de instalação para o novo CLI/caminho de ferramentas (incluindo limpeza de etapas de instalação legadas).
    • Melhorar a detecção automática do conjunto de instruções da CPU.

📝 Documentos e comunidade

  • Adicione MiniMax-M2.1 [tutorial] de ponta a ponta (https://github.com/kvcache-ai/ktransformers/blob/main/doc/en/kt-kernel/MiniMax-M2.1-Tutorial.md).

ktransformers v0.5.0

🚀 Core Highlights

  • Native FP8 MoE Kernel: Introducing native FP8 precision support for MoE inference with a new AVX-based kernel. Run FP8 models directly without precision conversion overhead, preserving the original model accuracy while maximizing hardware efficiency.

  • kt-cli for Effortless Local Inference: A new CLI tool designed for simplicity and ease of use. Model management, automatic configuration, seamless chat/completions workflows, and built-in SGLang environment detection—get started with local LLM inference in minutes.

  • Enhanced Layerwise Prefill: Improved layerwise prefill performance through expert-by-expert pipelining. The layerwise prefill architecture enables efficient memory streaming during prefill, significantly improving throughput and reducing latency for long-context workloads.

📌 Models, Hardware & Tooling

  • Model support updates

    • Extend the FP8 enablement path in this release, focusing on native FP8 MoE support and compatibility improvements.
    • Add native MiniMax-M2, MiniMax-M2.1, DeepSeek-V3.2 support and related enablement.

  • Kernel & hardware improvements

    • Add AVX-based FP8 MoE kernel.
    • Reduce DRAM requirements for most models during prefill in CPU.
    • Improve layerwise prefill for better throughput.

  • Tooling & integration

    • Introduce kt-cli, a new unified CLI for model management, chat, automatic configuration and inference server management.

  • Deployment & installation

    • Refactor installation workflows/scripts for the new CLI/tooling path (including cleanup of legacy install steps).
    • Improve CPU instruction set auto detection.

📝 Docs & Community

  • Add MiniMax-M2.1 end-to-end tutorial.
  • Refine DPO tutorial.

🌟 Contributors

  • Thanks to all contributors who helped ship this release.
