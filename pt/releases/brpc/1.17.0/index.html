#brpc 1.17.0

Apache bRPC 1.17.0 é um lançamento de recurso centrado na otimização de desempenho, destacado pela introdução do SingleIOBuf para serialização/desserialização eficiente de FlatBuffers. Esta versão também expande os recursos de protocolo e transporte com suporte nativo ao canal Redis Cluster, uma nova camada de transporte para extensões de protocolo de comunicação e suporte RDMA ECE. Melhorias adicionais incluem políticas de solicitação de backup com taxa limitada, limite de taxa de erro para atenuação de punição e suporte a fila de prioridade de bthread. A versão oferece ainda correções de bugs críticos para problemas de uso após liberação, visibilidade de memória ARM e compatibilidade com Protobuf, juntamente com vários aprimoramentos de estabilidade e testes de fuzz.

brpc 1.17.0

Highlights

  • FlatBuffers gets a dedicated fast path — SingleIOBuf (#3062) adds efficient serialization/deserialization built around a single IOBuf, targeting overhead in FlatBuffers RPC payloads. Evaluate it for latency-sensitive services and validate buffer ownership and zero-copy assumptions against your existing message setup.
  • Protocol coverage expands — Native Redis Cluster channels (#3222) provide built-in cluster-aware Redis support, while the new transport layer (#3199) creates an extension point for additional communication protocols. RDMA ECE support (#3255) broadens RDMA negotiation compatibility; review existing custom adapters before adopting these built-ins.
  • Backup requests are bounded and isolated — The rate-limited backup policy (#3229) limits retry amplification under load, while fixes for backup-response isolation (#3294) and overwritten attachments (#3235) keep primary and backup response state separate. Retune and load-test clients that rely heavily on backup requests.
  • Timing and memory visibility are more deterministic — RPC timing and bvar sampling move toward monotonic time (#3268, #3283, #3278), and bthread_join adds an ARM acquire fence (#3276). This improves interval measurement and cross-core synchronization, but code assuming wall-clock timestamps or weak ARM ordering should be reviewed.
  • Upgrade hardening covers async lifetimes and Protobuf — Use-after-free fixes in EventDispatcher::LatencyRecorder (#3267), AgentCombiner (#3291), and async callback spans (#3140) are especially relevant to long-running, highly concurrent services. Protobuf v34+ builds are supported (#3241), with fixes for pre-3.4 APIs (#3292) and descriptor extension ranges (#3210); rerun sanitizer tests and multi-version Protobuf CI.
  • Breaking changes — None declared.

Apache bRPC 1.17.0 is a feature release centered around performance optimization, highlighted by the introduction of SingleIOBuf for efficient FlatBuffers serialization/deserialization. This release also expands protocol and transport capabilities with native Redis Cluster channel support, a new transport layer for communication protocol extensions, and RDMA ECE support. Additional improvements include rate-limited backup request policies, error rate threshold for punishment attenuation, and bthread priority queue support. The release further delivers critical bugfixes for use-after-free issues, ARM memory visibility, and Protobuf compatibility, alongside multiple stability and fuzz testing enhancements.
