#pymilvus v3.0.3 PyMilvus 3.0.3 é o Python SDK recomendado para Milvus 3.0.6. Requer Python 3.9 ou posterior.

O que mudou

Novos APIs e capacidades

  • Adicione suporte para subcampos escalares e vetoriais anuláveis e matrizes escalares aninhadas com elementos anuláveis em Struct Arrays. Tanto clients síncronos quanto assíncronos podem adicionar ou eliminar subcampos Struct Array em coleções existentes e substituir elementos individuais ou valores de subcampos por FieldOp.path_replace(). [#3927](https://github.com/milvus-io/pymilvus/pull/3927)
  • Adicione cadeias de funções ao hybrid_search() em ambos os clients. Cada solicitação de RNA pode executar sua própria cadeia e uma cadeia de nível superior pode mesclar e reclassificar os resultados. [#3810](https://github.com/milvus-io/pymilvus/pull/3810)
  • Adicione commit_import() e abort_import() para trabalhos de importação em massa em duas fases enviados com auto_commit=False. Os auxiliares de importação em massa também aceitam cabeçalhos HTTP personalizados, incluindo Idempotency-Key. [#3819](https://github.com/milvus-io/pymilvus/pull/3819) · [#3807](https://github.com/milvus-io/pymilvus/pull/3807)
  • Adicione política de linha e gerenciamento de tags principais ao MilvusClient e AsyncMilvusClient para implantações que suportam segurança em nível de linha. Clients pode passar um principal RLS com leituras, gravações e importações. [#3852](https://github.com/milvus-io/pymilvus/pull/3852)

pymilvus v3.0.3

PyMilvus 3.0.3 is the recommended Python SDK for Milvus 3.0.6. It requires Python 3.9 or later.

What's Changed

New APIs and capabilities

  • Add support for nullable scalar and vector sub-fields and nested scalar arrays with nullable elements in Struct Arrays. Both synchronous and asynchronous clients can add or drop Struct Array sub-fields on existing collections and replace individual elements or sub-field values with FieldOp.path_replace(). [#3927](https://github.com/milvus-io/pymilvus/pull/3927)
  • Add function chains to hybrid_search() in both clients. Each ANN request can run its own chain, and a top-level chain can merge and rerank the results. [#3810](https://github.com/milvus-io/pymilvus/pull/3810)
  • Add commit_import() and abort_import() for two-phase bulk import jobs submitted with auto_commit=False. Bulk import helpers also accept custom HTTP headers, including Idempotency-Key. [#3819](https://github.com/milvus-io/pymilvus/pull/3819) · [#3807](https://github.com/milvus-io/pymilvus/pull/3807)
  • Add row-policy and principal-tag management to MilvusClient and AsyncMilvusClient for deployments that support row-level security. Clients can pass an RLS principal with reads, writes, and imports. [#3852](https://github.com/milvus-io/pymilvus/pull/3852)

Bug fixes

  • Preserve Struct Array parameters such as mmap_enabled and warmup in describe_collection() results. [#3923](https://github.com/milvus-io/pymilvus/pull/3923)
  • Preserve null Struct Array values in CSV and null sparse-vector values in Parquet when writing bulk import files. [#3861](https://github.com/milvus-io/pymilvus/pull/3861)
  • Fix AsyncMilvusClient.flush_all(), get_flush_all_state(), get_compaction_plans(), and update_replicate_configuration() by implementing their missing RPC handlers. [#3887](https://github.com/milvus-io/pymilvus/pull/3887)
  • Keep application logging handlers open when importing pymilvus and remove root logger configuration from pymilvus.bulk_writer imports. [#3848](https://github.com/milvus-io/pymilvus/pull/3848) · [#3850](https://github.com/milvus-io/pymilvus/pull/3850)
  • Return None for QueryIterator.get_cursor().str_pk before reading the first page. [#3859](https://github.com/milvus-io/pymilvus/pull/3859)
  • Reject out-of-range port numbers before opening a connection. [#3834](https://github.com/milvus-io/pymilvus/pull/3834)

Test tooling

  • Propagate Python test failures to Windows CI job results and expand unit-test coverage while consolidating overlapping cases. [#3831](https://github.com/milvus-io/pymilvus/pull/3831) · [#3878](https://github.com/milvus-io/pymilvus/pull/3878)
