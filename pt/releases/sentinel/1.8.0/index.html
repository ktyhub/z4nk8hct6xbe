Sentinela v1.8.0

Esta nova versão vem com inúmeros recursos e melhorias, especificamente para interrupção de circuito. Fizemos progresso na refatoração e na melhoria do recurso de interrupção de circuito, incluindo suporte a duração estatística arbitrária, recuperação semiaberta, estratégia aprimorada de taxa de solicitação lenta, observador de mudança de estado e muito mais. Também trouxemos várias integrações versáteis, incluindo Java EE (JAX-RS e CDI), Quarkus e HTTP client (Apache HttpClient e OkHttp), que podem abranger mais desenvolvedores.

Recursos/Aprimoramentos

  • Refatorar a hierarquia de degradação com novo mecanismo de disjuntor e melhorar a estratégia (suportar duração estatística arbitrária, suportar recuperação semiaberta, adicionar estratégia de taxa de solicitação lenta) (#1490, #1645)
  • Suporte à configuração de project.name por meio do arquivo de propriedades e descontinuação do caminho de configuração herdado (#1412, #1437)
  • Refatorar o mecanismo de gravação de exceção (quando concluído) e polir o Tracer (#1420)
  • Suporte à configuração de defaultFallback em nível de classe para extensão de anotação (#1493)
  • Adicionar módulo de integração JAX-RS (#1396)
  • Adicionar extensão de anotação para Java EE CDI (#1541)
  • Adicionar anotação Sentinel e plug-ins JAX-RS para Quarkus (#1542)
  • Adicionar módulo de integração Apache HttpClient (#1455)
  • Adicionar módulo de integração OkHttp (#1456)
  • Adicionar extensão de fonte de dados Eureka (#1502)
  • Adicionar exceçãoPredicate no Tracer para lógica de filtragem de exceção personalizada (#1496)
  • Melhorar o mecanismo de eliminação para ParameterMetric obsoleto (#1372)
  • Suporta analisador de origem personalizado no adaptador Dubbo 2.6.x/2.7.x e mecanismo de configuração polonês (#1555, #1572, #1617)
  • Adicionado suporte para extrair valor de parâmetro de objeto complexo (#1491)
  • Adicionar interface estendida para gancho de extensão métrica para suportar tipos de tráfego diferenciados (#1665)
  • Melhorar o substituto padrão para o adaptador Apache Dubbo 2.7.x (#1680)
  • Adicionar suporte ao manipulador de saída por entrada (whenTerminate) (#1645)
  • Otimize a ordem dos slots na configuração do ProcessorSlot SPI (#1649)

Correções de bugs

  • Corrigir bug de GC completo do adaptador sentinel-apache-dubbo-adapter (#1431)
  • Corrigido o bug que pode causar ErrorEntryFreeException ao encaminhar solicitações no adaptador sentinel-spring-webmvc (#1533, #1681)
  • Corrigido o bug de extração de cookie de solicitação no adaptador Spring Cloud Gateway (#1400)
  • Corrigido o bug de bloqueios perdidos em ContextUtil e ClusterNode (#1429)

Painel

  • Refatorar o frontend/controlador degradado e adaptar-se a novos recursos de interrupção de circuito
  • Corrigido o bug de que o cookie pode entrar em conflito com aplicativos da web no mesmo domínio (#1443)
  • Corrigido problema de compatibilidade de versão histórica para verificação de autenticação via localStorage (#1473)

Dependências

  • Atualize fastjson para 1.2.71, nacos-client para 1.3.0 (no módulo sentinel-datasource-nacos)

Sentinel v1.8.0

Highlights

  • Circuit breaking rebuilt from the ground up — The degrade hierarchy was refactored into a new circuit breaker mechanism (#1490, #1645): you now get arbitrary statistic durations instead of fixed windows, a half-open recovery state, a slow-request-ratio strategy, a state-change observer, and per-Entry whenTerminate exit hooks. This is the headline change — expect rule semantics to shift, especially how the "slow request ratio" strategy depends on RT thresholds and how half-open probes gate recovery. Re-validate existing degrade rules against the new implementation rather than assuming drop-in behavior.
  • Config migration for project.name — You can now set project.name directly in the properties file, and the legacy config path is deprecated (#1412, #1437). Not a hard break, but a clear signal: move this setting now, since the old lookup path is on the removal track in a future release.
  • Exception and fallback handling got more controllable — Exception recording moved to onCompleted with Tracer polish (#1420), and a new exceptionPredicate lets you filter which exceptions count toward circuit breaking (#1496). Paired with class-level defaultFallback for the annotation extension (#1493), this means you can now fine-tune what trips a breaker instead of accepting the built-in classification — useful when wrapping exceptions in framework layers.
  • Outbound and Java EE/Quarkus coverage expanded — New integrations for JAX-RS (#1396), Java EE CDI (#1541), Quarkus annotations + JAX-RS (#1542), Apache HttpClient (#1455), OkHttp (#1456), and a Eureka data source (#1502). The HTTP client modules matter most: Sentinel protection is no longer limited to inbound traffic, so you can apply flow/degrade rules to downstream calls directly.
  • Watch the slot chain and stability fixes on upgrade — The ProcessorSlot SPI slot order was reordered (#1649), so custom slot chains should be re-checked. Meanwhile, real production pain points are addressed: a full-GC bug in the Dubbo adapter (#1431), misplaced locks in ContextUtil/ClusterNode (#1429), and ErrorEntryFreeException on forwarded requests in Spring WebMVC (#1533, #1681).

No breaking changes in this release.

This nouveau release ships with countless features and improvements, specifically for circuit breaking. We've made progress on refactoring and improving circuit breaking feature, including arbitrary statistic duration support, half-open recovery, enhanced slow request ratio strategy, state change observer and more. We've also brought various versatile integrations including Java EE (JAX-RS and CDI), Quarkus and HTTP client (Apache HttpClient and OkHttp), which could cover more developers.

Features / Enhancements

  • Refactor degrade hierarchy with new circuit breaker mechanism and improve strategy (support arbitrary statistic duration, support half-open recovery, add slow request ratio strategy) (#1490, #1645)
  • Support setting project.name via the properties file and deprecate legacy config path (#1412, #1437)
  • Refactor the mechanism of recording exception (on completed) and polish Tracer (#1420)
  • Support setting class-level defaultFallback for annotation extension (#1493)
  • Add JAX-RS integration module (#1396)
  • Add annotation extension for Java EE CDI (#1541)
  • Add Sentinel annotation and JAX-RS plugins for Quarkus (#1542)
  • Add Apache HttpClient integration module (#1455)
  • Add OkHttp integration module (#1456)
  • Add Eureka data-source extension (#1502)
  • Add exceptionPredicate in Tracer for customized exception filtering logic (#1496)
  • Improve purge mechanism for deprecated ParameterMetric (#1372)
  • Support customized origin parser in Dubbo 2.6.x/2.7.x adapter and polish config mechanism (#1555, #1572, #1617)
  • Add support for extracting parameter value from complex object (#1491)
  • Add extended interface for metric extension hook to support distinguishing traffic type (#1665)
  • Improve default fallback for Apache Dubbo 2.7.x adapter (#1680)
  • Add per-Entry exit handler (whenTerminate) support (#1645)
  • Optimize the order of slots in ProcessorSlot SPI config (#1649)

Bug fixes

  • Fix sentinel-apache-dubbo-adapter full GC bug (#1431)
  • Fix the bug that may cause ErrorEntryFreeException when forwarding requests in sentinel-spring-webmvc-adapter (#1533, #1681)
  • Fix the bug of extracting request cookie in Spring Cloud Gateway adapter (#1400)
  • Fix the bug of misplaced locks in ContextUtil and ClusterNode (#1429)

Dashboard

  • Refactor degrade frontend/controller and adapt to new circuit breaking features
  • Fix the bug that cookie may have conflict with web applications under the same domain (#1443)
  • Fix historical version compatibility problem for auth checking via localStorage (#1473)

Dependencies

  • Upgrade fastjson to 1.2.71, nacos-client to 1.3.0 (in sentinel-datasource-nacos module)
