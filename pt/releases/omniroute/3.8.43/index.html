Highlights

  • Compression gains an opt-in engine suite (all default-off) — v3.8.43 adds five gated compression features: an llm prose condenser whose default backend is a no-op pass-through until you wire one via setLlmCompressorBackend() (fails open on every error), a lossy read-lifecycle engine that collapses superseded file-Read tool results, a per-engine process-local circuit breaker (COMPRESSION_PIPELINE_BREAKER_ENABLED), a graded CCR retrieval ramp (retrievalRampFactor, default 2; set 1 for the old binary cliff), and usage-observed prefix freezing (COMPRESSION_PREFIX_FREEZE_ENABLED) that preserves recurring system prompts to keep prompt-cache hits.   • Usage output changes: percentages replace USD, flat-rate providers read $0 — @@om-usage and /api/usage now report personal-key quotas as remaining percentages (USD no longer appears in command output), provider quota is scaled by the configured cutoff so the protected reserve reads 0% left, and a management-auth-gated provider USD drilldown returns (/api/usage/provider-window-costs, ProviderUsdCostModal, #5863).   • CLI profile auto-sync for Codex and Claude Code (opt-in) — model-catalog changes can regenerate tool profiles from the live catalog: Codex (~/.codex/*.config.toml) and now Claude Code (~/.claude/profiles/<name>/settings.json, new claudeProfileAutoSync.ts). Separately, requests now carry a correlation ID threaded through logs for end-to-end tracing (#5834). Small additions, but useful for debugging the compression pipeline or running agents against it.

No breaking changes.
