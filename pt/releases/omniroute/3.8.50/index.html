OmniRoute v3.8.50

Highlights

  • Smarter routing under load — Capability filtering at the router (#5696) now works alongside image-combo fallback (#9239), quota-only fallback (#9983), adaptive overload protection (#9262), and an opt-in slow-provider watchdog (#9709). Requests can move between providers based on capability, quota, and latency—not just configured priority—so review fallback order and quota overrides before rollout.
  • Gateway-wide multimodal support — Multi-provider /v1/ocr routing (#10283), imageToText service metadata (#10275, #10400), vision-aware modality bridging (#9759, #10289), audio transcription for text-only models (#9807), and Soniox STT/TTS (#9579) centralize OCR, vision, and audio handling. Integrations can use gateway-level interfaces instead of provider-specific paths, but should account for the bridge’s transformation and caching behavior.
  • Agent automation and post-stream telemetry — Conductor adds long-lived A2A SSE consumption, Agent Card discovery, and inbound delegation (#8080, #8119, #8223). Plugin authors gain marketplace installation (#6752), request-header access (#9570), and onStreamComplete, which reports token usage, latency, TTFT, model/provider, and error codes after SSE completion (#9571). Existing { streamed: true } onResponse hooks remain unchanged.
  • Faster, safer OpenCode startup — Catalog startup now reads the last disk snapshot, reducing provider registration from roughly 30 seconds to 1–2 seconds. Six fetchers run concurrently, failed refreshes preserve the last-known-good snapshot, and duplicate same-key refreshes are suppressed (#9490). Set features.diskCache: false to opt out, accepting the slower cold-start path.
  • Logging and reasoning-privacy changes — Opaque encrypted reasoning values are omitted from persisted call logs (#9000), while encrypted reasoning replay is opt-in (#9876). The chat-log array tail default increases from 24 to 128 entries, with configurable truncation (#9863, #9864), and cache read/write tokens are surfaced in logs and reports (#9620). Expect larger default log output and explicitly enable replay when debugging encrypted reasoning.
  • Breaking changes — None declared.
