arquivar v3.2.0

Arquivar v3.2.0

Crie uma resposta de uma página com a conclusão do Markdown, com fontes citadas, diagramas interativos e exportações do navegador.

Adicionado

  • Respostas de uma página (explicador) (#993). Peça ao seu agente para responder como uma página e o Archify cria um explicador de conclusão a partir de um rascunho do Markdown. Cada painel responde a uma pergunta, usando prosa, tabelas, etapas, listas de verificação, gráficos, código e diagramas nativos validados.
    • Autoria e entrega: finalize explainer valida, entrega atomicamente e verifica a página. Os gráficos vêm de uma cerca Mermaid ou de um arquivo CSV/JSON próximo ao rascunho. Os trechos do repositório são lidos do commit fixado. patch explainer substitui um painel por ID.
    • Leitura:
      • As etapas ficam ao lado do diagrama que elas percorrem e você pode percorrê-las.
      • Os nós de texto e diagrama se destacam.
      • Cli clicar em um nó abre o Viewer completo focado nele.
      • Citações e cartões de código aberto de nós vinculados à fonte.
      • Cada painel ou passagem selecionada produz uma pergunta de acompanhamento direcionada a esse painel.
    • Compartilhamento: a página é enviada em quatro estilos (limpo, editorial, produto, suíço) com temas claros e escuros e exporta uma imagem longa PNG, WebP ou JPG ou imprime em PDF.
    • Exemplos: quatro páginas ativas em docs/cases/explainer/.
    • Crédito: a direção do documento de uma página nº 942 de @goatliamia moldou este trabalho.
    • Agradecimento: obrigado a @QingYunA pela proposta inicial de diagrama e explicação de uma página e pelo protótipo de demonstração.

Corrigido

  • As páginas explicativas não carregam mais caminhos locais. O rascunho incorporado em uma página nomeia seus arquivos de origem e de dados relativos à página, portanto, uma página compartilhada não revela os diretórios do autor. patch explainer os resolve na página novamente.
  • Imagens longas explicativas mantêm o estilo e tema da página. Uma exportação PNG, WebP ou JPG de uma página dark, ou do editorial, produto ou estilo suíço, saiu no estilo light clean, pois a página é desenhada dentro de um SVG onde seu <html> não é :root. A exportação agora seleciona a raiz da página por seu próprio atributo.
  • Dados em branco do gráfico são um erro, não zero. Uma célula CSV vazia, um JSON null ou um campo ausente em uma coluna do gráfico não se torna mais uma barra zero. Finalize nomeia a coluna e a linha.
  • Contratos semânticos de migração de fluxo de trabalho (#497). O planejamento de layout não verifica mais os requisitos de topologia completa em um gráfico temporário com bordas roteadas removidas. Os documentos migrados mantêm seus contratos de autoria e devem passar por validação completa antes da publicação.
  • **Escala de fuso horário da linha do tempo (#926). ** A escala é alinhada de acordo com o deslocamento UTC do fuso horário exibido em cada tempo real, e o problema da mudança da escala diária para 01:00/23:00 após o horário de verão e a mudança da escala horária após o salto de meia hora são corrigidos. Momentos repetidos de retorno de chamada permanecem independentes e horas ou datas ignoradas não geram ticks fictícios; o tempo do evento, a precisão do rótulo, a escala da linha do tempo e as regras de quebra de eixo permanecem inalteradas.

Alterado

  • Controles do leitor e índice de nós. As linhas compactas do índice inferior mantêm as descrições abaixo dos títulos; a navegação no menu e no teclado móvel respeita as teclas modificadoras.
  • Avisos de atualização. As atualizações disponíveis incluem um resumo da versão e uma oferta de ajuda na atualização. As falhas de rede permanecem sem bloqueio.
  • Site e portabilidade. A página inicial e a galeria bilíngues apresentam respostas de uma página, mantendo guias e casos baseados em fontes. A descoberta do navegador, os caminhos de comando do Windows, os espaços em branco do diretório de origem e a limpeza da árvore de trabalho temporária recebem correções específicas.

Distribuição

  • Baixe archify.zip abaixo. As notificações de atualização estável são publicadas separadamente após a verificação do arquivo.
  • O plugin DSH com versão separada não é republicado nesta versão; os mantenedores devem selecionar uma fonte fixada e concluir a aceitação do host/pacote em um acompanhamento separado. changelog completo: https://github.com/tt-a1i/archify/compare/v3.1.0...v3.2.0

archify v3.2.0

Highlights

  • One-page explainers (#993) — finalize explainer now validates and atomically publishes conclusion-first Markdown pages with interactive native diagrams, source citations, follow-up questions, and PNG/WebP/JPG/PDF exports. patch explainer supports targeted panel updates by ID, while repository excerpts remain tied to the pinned commit.

  • Migration validation is stricter (#497) — layout planning no longer evaluates full-topology contracts against a temporary graph with routed edges removed. Migrated documents retain their authored semantic contracts and must pass complete validation before publication, so previously accepted drafts may require correction.

  • Packaging requires a separate DSH follow-up — the independently versioned DSH plugin is not included in this release. Maintainers must pin a plugin source and complete its host/package acceptance separately rather than assuming the Archify archive updates it.

  • Missing chart data now blocks finalization — empty CSV cells, JSON null values, and absent fields no longer silently become zero-valued bars. Errors identify the offending column and row, making data-quality problems actionable before publication.

  • Shared pages are more private and exports are faithful — embedded drafts reference source and data files relatively, preventing authors’ local directory paths from leaking into shared pages; patch explainer resolves those references against the page. Long-image exports now preserve the selected style and dark theme instead of reverting to light “clean” styling.

  • Timeline ticks handle timezone transitions correctly (#926) — ticks align to the UTC offset at each actual displayed time, preventing day/hour drift across daylight-saving changes. Repeated times remain distinct, skipped periods produce no invented ticks, and event timing and timeline scaling remain unchanged.

  • Breaking changes — None are announced in this release.

Archify v3.2.0

Create a conclusion-first one-page answer from Markdown, with cited sources, interactive diagrams and browser exports.

Added

  • One-page answers (explainer) (#993). Ask your agent to answer as a page and Archify builds a conclusion-first explainer from a Markdown draft. Each panel answers one question, using prose, tables, steps, checklists, charts, code and validated native diagrams.
    • Authoring and delivery: finalize explainer validates, delivers atomically and checks the page. Charts come from a Mermaid fence or a CSV/JSON file next to the draft. Repository excerpts are read from the pinned commit. patch explainer replaces one panel by ID.
    • Reading:
      • Steps sit beside the diagram they walk through, and you can step through them.
      • Text and diagram nodes highlight each other.
      • Clicking a node opens the full Viewer focused on it.
      • Citations and source-linked nodes open source cards.
      • Each panel or selected passage produces a follow-up question that targets that panel.
    • Sharing: the page ships in four styles (clean, editorial, product, Swiss) with light and dark themes, and exports a PNG, WebP or JPG long image or prints to PDF.
    • Examples: four live pages in docs/cases/explainer/.
    • Credit: the one-page document direction of #942 by @goatliamia shaped this work.
    • Acknowledgment: thanks to @QingYunA for the early one-page diagram-and-explanation proposal and demo prototype.

Fixed

  • Explainer pages no longer carry local paths. The draft embedded in a page names its source and data files relative to the page, so a shared page does not reveal the author's directories. patch explainer resolves them against the page again.

  • Explainer long images keep the page's style and theme. A PNG, WebP or JPG export of a dark page, or of the editorial, product or Swiss style, came out in the light clean style, because the page is drawn inside an SVG where its <html> is not :root. The export now selects the page root by its own attribute.

  • Blank chart data is an error, not zero. An empty CSV cell, a JSON null or a missing field in a charted column no longer becomes a zero bar. Finalize names the column and row instead.

  • Workflow migration semantic contracts (#497). Layout planning no longer checks full-topology requirements against a temporary graph with routed edges removed. Migrated documents retain their authored contracts and must pass complete validation before publication.

  • Timeline 时区刻度（#926）。 刻度按显示时区在各真实时刻的 UTC 偏移对齐，修复跨夏令时后日刻度漂移到 01:00／23:00、半小时跳变后小时刻度漂移的问题。回拨的重复时刻保持独立，跳过的小时或日期不生成虚构刻度；事件时间、标签精度、时间轴比例与断轴规则保持不变。

Changed

  • Reader controls and node index. Compact bottom index rows keep descriptions below titles; menu and roving keyboard navigation respect modifier keys.
  • Update notices. Available updates include a release summary and an offer to help update. Network failures remain non-blocking.
  • Website and portability. The bilingual homepage and gallery introduce one-page answers while retaining guides and source-backed cases. Browser discovery, Windows command paths, source-directory whitespace and temporary-worktree cleanup receive focused fixes.

Distribution

  • Download archify.zip below. Stable update notifications are published separately after the archive has been verified.
  • The separately versioned DSH plugin is not republished with this release; maintainers must select a pinned source and complete its host/package acceptance in a separate follow-up.
