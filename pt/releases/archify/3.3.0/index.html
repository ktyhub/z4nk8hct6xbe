archify v3.3.0

Highlights

  • Code Analysis lands in-tree with an Atlas — The Labs module is now part of the main distribution (#979, #1007): an Atlas view (#1103) surfaces module entry points and flags imports that bypass them (#1206), jscpd C6 finds duplicated code with highlighted source evidence (#1308), and external diagnostics can be imported with evidence/review (#1332). Typed-array Tarjan cycle detection (#1331) and batched Git diffs (#1326) make it viable on large repos. Watch out: cycle severity is language-dependent — promoted to errors by the refactor (#1315) but downgraded to warnings for Java class cycles (#1349) — so CI gating won't be uniform.

  • License switched to Apache-2.0 — #1098/#1099 relicense the project to Apache-2.0 while preserving historical MIT grants. Prior MIT permission survives, but Apache-2.0 adds NOTICE/attribution and patent-grant terms, so run a compliance pass before vendoring or redistributing.

  • Explainer now defaults to proactive pages — #1300 flips shared pages to proactive rendering with an on-demand switch, so existing pages may render differently without a config change. It ships with pipe-robustness fixes: full receipts are flushed before exit so piped stdout isn't truncated (#1131, backported to stable in #1240), and local inputs are protected from publication sidecars (#1094).

  • Renderer/CLI output contracts tightened — #1033 delivers the complete --layout-json report through pipes, while docs now codify the atomic capture→verify→publish protocol (#607) and treat the brand URL as the network trust boundary (#606). #1100 repairs source end lines past EOF and #1031 validates the whole root SVG rather than stopping at the first nested close. If you parse renderer output in CI, consume the full report instead of assuming truncation.

  • Story adds native HTML walkthroughs and 1080p export — #1036 introduces native HTML walkthroughs plus 1080p video export; #1047 keeps flowless guides out of the opening clock, and #1062 tolerates FFmpeg 8.0's Opus flush warning. Check your FFmpeg version if video export runs in automated pipelines.

  • Distribution/install flow now overwrites on update — Lightweight website/Skill sources and a one-sentence agent install prompt land in #1167/#1169/#1170, with DSH 1.1.0 published (#1156/#1157, #1294/#1295). Updates replace installed files (#1171) and #1172 explicitly says to preserve unmanaged files first — treat upgrades as overwrites and back up local customizations.

  • Compatibility — No breaking API changes in this release.
