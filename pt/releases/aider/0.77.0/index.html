aider v0.77.0

Highlights

  • Language support overhaul (tree-sitter-language-pack) — Aider replaces its parser backend with tree-sitter-language-pack, adding 130 languages with linter support and 20 with repo-map support. Because repo-map is the mechanism Aider uses to build its code-context graph, this is the headline change: it materially widens the set of repositories it can intelligently navigate, not just syntax-highlight. The real win is for previously unsupported languages in mixed or niche codebases.
  • Reasoning controls become first-class — New /think-tokens and /reasoning-effort commands tune model thinking at runtime, and both report their current values when invoked with no arguments. --thinking-tokens now takes human-readable strings (8k, 10.5k, 0.5M) instead of raw integers, and both settings surface in model info — practical for dialing cost/latency mid-session without restarting.
  • Architect edits auto-accepted by default — The new --auto-accept-architect flag defaults to true, so output from the architect coder format is applied without a confirmation prompt. Watch out: this shifts the trust boundary — explicitly disable it if you want to review architect-generated changes before they hit your files.
  • /drop now preserves read-only inputs — A bare /drop no longer clears files originally supplied via args.read, so resetting conversation context won't strip intentionally read-only files. A subtle behavioral fix that matters mainly to scripted/automated Aider workflows.
  • New models — Adds cohere_chat/command-a-03-2025 and gemini/gemma-3-27b-it to the supported roster, expanding provider choice for those already on Cohere/Gemini.
  • Robustness and ergonomics fixes — Deprecated --shortcut switches no longer clobber a model explicitly set on the CLI; autocomplete now requires 3 characters to cut noise; model-cache JSONDecodeError and git-config GitCommandError are handled gracefully; and the file watcher gains ignore_permission_denied (h/t Yutaka Matsubara) so restricted files stop throwing errors.

No breaking changes.

  • Big upgrade in programming languages supported by adopting tree-sitter-language-pack.

    • 130 new languages with linter support.
    • 20 new languages with repo-map support.

  • Added /think-tokens command to set thinking token budget with support for human-readable formats (8k, 10.5k, 0.5M).

  • Added /reasoning-effort command to control model reasoning level.

  • The /think-tokens and /reasoning-effort commands display current settings when called without arguments.

  • Display of thinking token budget and reasoning effort in model information.

  • Changed --thinking-tokens argument to accept string values with human-readable formats.

  • Added --auto-accept-architect flag (default: true) to automatically accept changes from architect coder format without confirmation.

  • Added support for cohere_chat/command-a-03-2025 and gemini/gemma-3-27b-it

  • The bare /drop command now preserves original read-only files provided via args.read.

  • Fixed a bug where default model would be set by deprecated --shortcut switches even when already specified in the command line.

  • Improved AutoCompleter to require 3 characters for autocompletion to reduce noise.

  • Fixed handling of JSONDecodeError when loading model cache file.

  • Fixed handling of GitCommandError when retrieving git user configuration.

  • Added ignore_permission_denied option to file watcher to prevent errors when accessing restricted files, by Yutaka Matsubara.
