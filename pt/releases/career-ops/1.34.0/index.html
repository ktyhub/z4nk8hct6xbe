<!-- co:notas de lançamento:career-ops-v1.34.0 -->

Este é o primeiro lançamento desde que comecei a trabalhar em operações de carreira em tempo integral. O prompt de atualização agora aparece apenas quando uma nova versão é lançada. Até agora, quase qualquer mudança que ocorresse no main poderia acioná-lo, muitas vezes todos os dias. Este lançamento também traz trabalhos de 63 pessoas, 43 delas contribuindo pela primeira vez.

Destaques

  • Atualização solicita apenas para novas versões. update-system.mjs instala a última versão publicada em vez de main, check pergunta apenas quando existe uma versão mais recente e dizer não dura até a próxima versão em vez de para sempre. O rastreamento main permanece disponível com --channel main. Baseado na resolução de lançamento de @obielin em #3845.
  • Menos ofertas ao vivo marcadas como fechadas. Liveness agora verifica as páginas da empresa com Greenhouse gh_jid, SmartRecruiters, Arbeitsagentur e We Work Remotely por meio de seus APIs públicos (#4444), e uma página de carreiras que carrega seu ATS em um iframe não é mais lida como uma postagem morta (#4439), ambos por @luochen211.
  • Verificações mais nítidas. Detecção em nível de domínio de republicações do agregador por @vaishaldsouza (#4263), um filtro de localização estrito opcional que falha ao fechar locais vazios por @Zoubeir23 (#4033), linhas de lista negra que podem cobrir um domínio inteiro (#4169) e um aviso quando um portal retorna zero trabalhos sem uma única resposta bem-sucedida (#4441), ambos por @luochen211.
  • Novas fontes. Um provedor de empregos Python.org de @lasithadilshan (#4173), um provedor de conselho mundial generalista de @ConnorCloze (#4100) e um distintivo de locatário Personio explícito de @duathron (#4001), todas as três primeiras contribuições.

Atualizando

Seu agente oferece esta atualização no início da sua próxima sessão. Se você recebeu um prompt de atualização antes, execute-o uma vez para acessá-lo:

node update-system.mjs apply --confirm

Novas instalações: npx @santifer/career-ops init.

This is the first release since I started working on career-ops full time. The update prompt now shows up only when a new version is actually out. Until now, almost any change landing on main could trigger it, often every day. This release also carries work from 63 people, 43 of them contributing for the first time.

Highlights

  • Update prompts only for new versions. update-system.mjs installs the latest published release instead of main, check asks only when a newer release exists, and saying no lasts until the next version instead of forever. Tracking main stays available with --channel main. Built on @obielin's release resolution in #3845.
  • Fewer live offers marked as closed. Liveness now checks company pages with a Greenhouse gh_jid, SmartRecruiters, Arbeitsagentur and We Work Remotely through their public APIs (#4444), and a careers page that loads its ATS in an iframe is no longer read as a dead posting (#4439), both by @luochen211.
  • Sharper scans. Domain-level detection of aggregator reposts by @vaishaldsouza (#4263), an opt-in strict location filter that fails closed on empty locations by @Zoubeir23 (#4033), blacklist rows that can cover a whole domain (#4169), and a warning when a portal returns zero jobs without a single successful response (#4441), both by @luochen211.
  • New sources. A Python.org Jobs provider by @lasithadilshan (#4173), a generalist-world board provider by @ConnorCloze (#4100) and an explicit Personio tenant pin by @duathron (#4001), all three first contributions.

Updating

Your agent offers this update at the start of your next session. If you declined an update prompt before, run this once to pick it up:

node update-system.mjs apply --confirm

New installs: npx @santifer/career-ops init.
