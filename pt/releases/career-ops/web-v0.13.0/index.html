career-ops web-v0.13.0

Highlights

  • Headless agent execution — Hermes Agent now supports headless CLI runs, and Pi is registered as a supported CLI host (#4623, #4157). Saved cliId values are validated against installed CLIs before execution (#4019), so stale automation configurations fail early.
  • Faster, fault-tolerant discovery — Explore streams matched cards during scans (#4200), preserves results from completed sources when another times out (#4431), and adds location filtering and title-vs-profile fit bands (#4397, #3261). This makes long scans more usable without losing valid partial results.
  • More actionable pipeline reporting — Analytics gains a pipeline Sankey (#3373), the evaluated-role report is restructured around a decision rather than a raw dump (#4210), and Pipeline displays tracker numbers (#3477), reducing manual cross-referencing.
  • Corrected deployment paths — User-layer files in batch-tailor, cv-templates, and openrouter-runner now resolve through the configured data root, while engine scripts resolve from the checkout; dashboard CV runs honor cv.template (#4570, #4518, #4035). Custom deployments should verify these path assumptions after upgrading.
  • Safer apply and state updates — Code-fence stripping no longer corrupts JSON string values in apply output (#3302), failed backups halt replacement (#4499), malformed follow-up IDs are rejected (#3482), and Inbox Skip actions persist to pipeline.md (#3632).
  • Cross-platform and file compatibility — npm CLIs launch correctly on Windows (#2626), CRLF pipeline.md files no longer produce an empty Inbox (#3566), localized tracker headers are recognized (#3931), and Apply Link and Follow-up columns survive web reads (#3603).
  • Compatibility — No breaking changes.
