#agno v2.5.10 #Changelog

Novos recursos:

  • Ferramenta de pesquisa paralela: adicione suporte ao Parallel AI Search para Vertex AI com integração nativa do ToolParallelAiSearch
  • Observabilidade: Suporte estendido com MLflow para ter observabilidade completa dos rastreamentos de seus agentes. Consulte documentos.
  • Leitor Docling: Biblioteca integrada Docling como um novo leitor, permitindo o processamento de documentos em vários formatos de arquivo.
  • Interface do WhatsApp V2:
    • Adicionado suporte de mídia (imagens, vídeo, áudio, documentos), mensagens interativas (botões de resposta, menus de lista, locais, reações) e suporte de equipe/fluxo de trabalho.
    • Os usuários podem enviar /new para iniciar novas conversas.
    • Adicionado parâmetro enable_encryption para criptografar números de telefone
  • Interface de telegrama:
    • Adicionadas novas interfaces do Telegram para AgentOS com suporte para agentes, equipes e fluxos de trabalho.
    • Suporte multimodal e use /new para iniciar novas conversas.
  • Ferramentas de Telegram: Adicionadas novas ferramentas para que os agentes possam enviar fotos, documentos, vídeos, áudio, animações, adesivos entre outras coisas

Melhorias:

  • Fluxo de trabalho:
    • Adicionado parâmetro de consulta version ao GET /workflows/{id} para buscar versões específicas do fluxo de trabalho.
    • Adicionados parâmetros de nível de execução como metadata, dependencies, add_dependencies_to_context, add_session_state_to_context semelhantes a agente/equipe.
  • Mistral: Adicionado suporte para mistralai v2, mantendo a compatibilidade com versões anteriores com v1.
  • Gemini: Adicionado parâmetro de tempo limite à classe de modelo Gemini.

Correções de bugs:

  • MCPTools: Corrigida a condição de corrida em que chamadas paralelas da ferramenta MCP com header_provider criavam sessões duplicadas, fazendo com que o agente travasse.
  • Claude: Corrigida detecção de saída estruturada para modelos suportados
  • Chamadas de ferramentas de streaming: Corrigida execução duplicada de ferramentas no modo de streaming causada por referências de dict compartilhadas em parse_tool_calls
  • MongoDb: Corrigida a importação incorreta dos módulos assíncronos do pymongo.

agno v2.5.10

Highlights

  • AgentOS messaging interfaces — WhatsApp V2 (#6466) and Telegram (#6377) add full AgentOS support for agents, teams, and workflows, including media, interactive controls, and outbound Telegram media tools. /new resets conversation state, while WhatsApp’s enable_encryption adds opt-in phone-number protection.
  • Versioned workflow execution — GET /workflows/{id} now accepts a version query parameter (#6956), and Workflow.run()/arun() accept run-level metadata, dependencies, and context flags (#6927). This lets you pin production runs to reviewed workflow versions and keep per-run configuration out of shared definitions.
  • Safer parallel tool execution — Fixes prevent MCP header_provider fan-out from creating duplicate sessions and deadlocking (#6821, #6949), plus duplicate streaming tool calls caused by shared dictionary references (#6579). Upgrading reduces the risk of stuck runs and repeated side-effecting tool calls.
  • Expanded ingestion and grounded search — The new Docling reader (#6981) broadens document-format coverage for RAG pipelines, while Vertex AI Gemini gains native Parallel AI Search grounding (#6060). Validate extraction quality and search latency/cost before replacing existing readers or search integrations.
  • Provider integration hardening — Mistral v2 support remains backward compatible with v1 (#6969), Gemini gains a configurable timeout (#7021), Claude structured-output detection now uses model prefixes instead of a fragile blocklist (#6643), and MLflow tracing via OpenInference provides full agent traces (#6930). Existing Mistral v1 users need no migration, but should recheck structured outputs and tune timeouts for slow model calls.
  • Compatibility — No breaking changes are listed in this release.

Changelog

New Features:

  • Parallel Search Tool: Add Parallel AI Search support for Vertex AI with native ToolParallelAiSearch integration
  • Observability: Extended support with MLflow to have full traces observability of your agents. See docs.
  • Docling Reader: Integrated Docling library as a new reader, enabling document processing across a multiple range of file formats.
  • WhatsApp Interface V2:
    • Added media support (images, video, audio, documents), interactive messages (reply buttons, list menus, locations, reactions), and Team/Workflow support.
    • Users can send /new to start fresh conversations.
    • Added enable_encryption parameter for encrypting phone numbers
  • Telegram Interface:
    • Added new Telegram interfaces for AgentOS with support for agents, teams, and workflows.
    • Multi-modal support and use /new to start fresh conversations.
  • Telegram Tools: Added new tools so agents can send photos, documents, videos, audio, animations, stickers among other things

Improvements:

  • Workflow:
    • Added version query param to GET /workflows/{id}to fetch specific workflow versions.
    • Added run level params like- metadata, dependencies, add_dependencies_to_context, add_session_state_to_context similar to agent/team.
  • Mistral: Added mistralai v2 support while maintaining backward compatibility with v1.
  • Gemini: Added timeout parameter to Gemini model class.

Bug Fixes:

  • MCPTools: Fixed race condition where parallel MCP tool calls with header_provider would each create duplicate sessions, causing the agent to get stuck.
  • Claude: Fixed structured output detection for supported models
  • Streaming Tool Calls: Fixed duplicate tool execution in streaming mode caused by shared dict references in parse_tool_calls
  • MongoDb: Fixed the incorrect import of the pymongo async modules.
