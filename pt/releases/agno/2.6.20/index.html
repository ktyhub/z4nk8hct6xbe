#agno v2.6.20 #Changelog

Novos recursos:

  • ClickhouseDB para Traces: Adicionado suporte para ClickHouse para ingestão de rastreamento de alto volume e varreduras OLAP. Veja os documentos.
  • Scavio Search Toolkit: nova integração do kit de ferramentas de pesquisa com o Scavio.

Melhorias:

  • OpenAI: citações de respostas de pesquisa na web agora aparecem no response.citations para provedores OpenAIChat e OpenAILike.
  • AgentOS: Suporta FastAPI >= 0.137 para que get_routes() liste todas as rotas.
  • LiteLLM: Suporta saídas estruturadas nativas e saídas de esquema JSON (habilitar por provedor com supports_native_structured_outputs ou supports_json_schema_outputs).
  • Refator de autenticação de kits de ferramentas do Google: classe base de autenticação unificada para kits de ferramentas do Google.
  • AgentOS: Atualizado para não limitar quick_prompts a 3 por agente/equipe/fluxo de trabalho.

Correções de bugs:

  • MCP: preserva _meta e structuredContent dos resultados da ferramenta MCP em ToolResult.metadata.
  • Compactação do resultado da ferramenta: Foi corrigida a contagem incorreta de tokens para ferramentas com parâmetros de enum numéricos, para que a compactação seja acionada no momento certo.
  • Fluxo de trabalho: isola step_id em execuções simultâneas, mantendo-o estável durante pausa/continuação em execuções HITL.
  • Ferramentas: Toolkit e Searxng não reutilizam mais uma lista padrão mutável entre instâncias.
  • Traces: use a chave de condições canônicas ao definir o escopo de filtros de rastreamento para usuários com escopo definido.
  • Reddit: as ações de gravação agora têm como escopo os subreddits permitidos configurados.
  • MoviePy: as saídas geradas são escritas atomicamente para evitar arquivos parciais.
  • OpenAI: Corrigido OpenAIResponses para suportar esquemas de saída json_schema no estilo Chat Completions.

agno v2.6.20

Highlights

  • Scalable trace storage — ClickHouse support enables high-volume trace ingestion and OLAP scans, giving teams a more suitable backend for large observability workloads (#7799).
  • Richer structured outputs and citations — LiteLLM now forwards response_format for native structured outputs and JSON Schema; enable the appropriate provider capability flag. OpenAI chat/web-search citations are exposed through response.citations, and OpenAIResponses accepts Chat Completions–style json_schema output schemas (#5881, #5885).
  • Complete MCP result metadata — _meta and structuredContent are preserved in the consolidated ToolResult.metadata field, so integrations can retain structured MCP payloads instead of losing them during tool execution (#7715, #8580).
  • Safer concurrency and access scoping — Workflow step_id values are isolated across concurrent runs and regenerated on deep_copy, while remaining stable through HITL pause/continue. Trace filters now use the canonical conditions key, and Reddit write actions are restricted to configured allowed subreddits (#8465, #8564, #8539).
  • AgentOS and media behavior updates — AgentOS supports FastAPI >= 0.137 for complete get_routes() enumeration, removes the three-item quick_prompts limit, and writes MoviePy outputs atomically to prevent consumers from observing partial files (#8577, #8537).
  • Breaking changes — None.

Changelog

New Features:

  • ClickhouseDB for Traces: Added support for ClickHouse for high-volume trace ingest and OLAP scans. See docs.
  • Scavio Search Toolkit: New search toolkit integration with Scavio.

Improvements:

  • OpenAI: Citations from web-search responses are now surfaced on response.citations for OpenAIChat and OpenAILike providers.
  • AgentOS: Support FastAPI >= 0.137 so get_routes() lists every route.
  • LiteLLM: Support native structured outputs and JSON schema outputs (enable per provider with supports_native_structured_outputs or supports_json_schema_outputs).
  • Google Toolkits Auth Refactor: Unified auth base class for Google toolkits.
  • AgentOS: Updated to not limit quick_prompts to 3 per agent/team/workflow.

Bug Fixes:

  • MCP: Preserve _meta and structuredContent from MCP tool results on ToolResult.metadata.
  • Tool-Result Compression: Fixed token miscount for tools with numeric enum params, so compression triggers at the right time.
  • Workflow: Isolate step_id across concurrent runs while keeping it stable across pause/continue in HITL runs.
  • Tools: Toolkit and Searxng no longer reuse a mutable default list across instances.
  • Traces: Use canonical conditions key when scoping trace filters for scoped users.
  • Reddit: Write actions are now scoped to the configured allowed subreddits.
  • MoviePy: Generated outputs are written atomically to avoid partial files.
  • OpenAI: Fixed OpenAIResponses to support Chat Completions–style json_schema output schemas.
