#agno v2.6.8 #Changelog

Novos recursos:

  • Antigravidade: Adicionado suporte primário para o Antigravity API do Google em dois formatos: AntigravityAgent (um BaseExternalAgent servido por meio do AgentOS com sessões/streaming/UI nativas) e AntigravityTools (um Toolkit que permite que qualquer agente Agno delegue uma subtarefa a uma sandbox gerenciada do Antigravity).
  • Agentes gerenciados Gemini: suporte GeminiInteractions adicionado para agentes gerenciados do Google — Pesquisa profunda (pesquisa autônoma com citações, streaming em segundo plano com reconexão/currículo last_event_id) e Antigravidade (agente de uso geral em uma sandbox Linux gerenciada). Novos campos agent/agent_config/environment, forçamento por agente de background e store e suporte para mcp_servers + file_search_store_names no caminho do agente.
  • Livro de receitas - Rotulagem de dados: cookbook/data_labeling/ adicionado com 18 fluxos de trabalho independentes cobrindo texto, imagem, áudio, vídeo, documento e primitivas de rotulagem compostas (LLM como juiz, revisão de qualidade).
  • Cookbook - Slack HITL: Adicionada uma demonstração determinística do comandante de incidentes do Slack HITL mostrando pausas estruturadas via tool_choice="required", eco user_input e terminação limpa via stop_after_tool_call=True.

Melhorias:

  • Segurança de caminho (segurança): Segurança de caminho centralizada em um novo módulo agno.utils.path_safety com safe_join e safe_join_subpath. FileGenerationTools, SlackTools, Toolkit._check_path, agno.skills.utils.is_safe_path e FileTools.check_escape reforçados contra passagem de caminho, escape de link simbólico, injeção de caractere de controle, Windows MagicDot e ataques de normalização Unicode. Introduzido o PathSecurityError (FileGenerationSecurityError mantido como alias de descontinuação). Mudou requires-python para >=3.9,<4.
  • MCP paralelo: ParallelMCPBackend agora envia User-Agent: agno/<version> em cada solicitação para que o Parallel possa atribuir tráfego ao agno.
  • Evals Config: Removido o campo available_models não utilizado de EvalsDomainConfig; o AgentOSConfig.available_models de nível superior agora é a única fonte suportada para o menu suspenso Evals UI.
  • Chonkie: Pin de dependência chonkie atualizado (acompanhamento de #7869).
  • Livro de receitas: Renomeado gemini-3-flash-preview para gemini-3.5-flash nos livros de receitas da Gemini Interactions.

Correções de bugs:

  • Equipes AG-UI: Corrigido um erro de digitação (stream_steps → stream_events) que fazia com que as equipes executadas via AG-UI eliminassem silenciosamente todos os eventos de streaming intermediários (ciclo de vida, raciocínio, chamadas de ferramentas, delegações de membros) por aproximadamente 7 meses.
  • Slack Extra: Adicionado aiohttp>=3.7.3,<4 ao extra opcional slack — AsyncWebClient importa aiohttp no carregamento do módulo, então pip install agno[slack] foi quebrado para todas as operações do Slack.
  • Google Drive: apareceu o sinalizador Drive API incompleteSearch de GoogleDriveTools.search_files() para que os chamadores corpora="allDrives" possam detectar quando o Drive não pesquisou todas as unidades.
  • GeminiInteractions: Adicionado um campo de passagem generation_config para controles avançados (top_k, presence_penalty, etc.) e manipulação de histórico fixa — quando previous_interaction_id é definido, apenas o novo turno é enviado em vez de reproduzir o histórico completo. Agora, na verdade, aproveita a monitoração de estado do lado do servidor.
  • Ferramentas de servidor Anthropic: server_tool_use e blocos de conteúdo de execução de código preservados no histórico de mensagens para que os fluxos de ferramentas de servidor de vários turnos não sejam mais interrompidos entre os turnos.
  • Endurecimento antrópico: Acompanhamento do acima - alterado para o literal canônico do tipo redacted_thinking (o SDK rejeita redacted_reasoning_content), aceitou ambas as grafias no evento de início de streaming, adicionou um protetor de desduplicação em blocos de ferramentas de servidor de ida e volta, tornou as falhas de coerção visíveis via log_warning e coagiu itens de resultado de ferramenta sem bloqueio para texto.
  • Erros Gemini: Os erros genéricos do Gemini agora incluem o tipo de exceção quando str(error) está vazio ou fraco, preservando o contexto de erro em invoke/invoke_stream/ainvoke/ainvoke_stream.
  • N1N: Adicionado o mapeamento do provedor n1n ausente em get_model() para que os caminhos de cadeia de modelo Agent(model="n1n:...") agora sejam resolvidos corretamente.

agno v2.6.8

Changelog

New Features:

  • Antigravity: Added first-party support for Google's Antigravity API in two shapes — AntigravityAgent (a BaseExternalAgent served through AgentOS with native sessions/streaming/UI) and AntigravityTools (a Toolkit that lets any Agno agent delegate a sub-task to a managed Antigravity sandbox).
  • Gemini Managed Agents: Added GeminiInteractions support for Google's managed agents — Deep Research (autonomous research with citations, background streaming with reconnect/last_event_id resume) and Antigravity (general-purpose agent in a managed Linux sandbox). New agent / agent_config / environment fields, per-agent forcing of background and store, and support for mcp_servers + file_search_store_names on the agent path.
  • Cookbook - Data Labeling: Added cookbook/data_labeling/ with 18 self-contained workflows covering text, image, audio, video, document, and composed (LLM-as-judge, quality review) labeling primitives.
  • Cookbook - Slack HITL: Added a deterministic Slack HITL incident-commander demo showing structured pauses via tool_choice="required", user_input echo, and clean termination via stop_after_tool_call=True.

Improvements:

  • Path Safety (Security): Centralized path-safety into a new agno.utils.path_safety module with safe_join and safe_join_subpath. Hardened FileGenerationTools, SlackTools, Toolkit._check_path, agno.skills.utils.is_safe_path, and FileTools.check_escape against path traversal, symlink escape, control-char injection, Windows MagicDot, and Unicode normalization attacks. Introduced PathSecurityError (FileGenerationSecurityError kept as deprecation alias). Bumped requires-python to >=3.9,<4.
  • Parallel MCP: ParallelMCPBackend now sends User-Agent: agno/<version> on every request so Parallel can attribute traffic to agno.
  • Evals Config: Dropped the unused available_models field from EvalsDomainConfig; the top-level AgentOSConfig.available_models is now the only supported source for the Evals UI dropdown.
  • Chonkie: Updated chonkie dependency pin (follow-up to #7869).
  • Cookbook: Renamed gemini-3-flash-preview to gemini-3.5-flash across the Gemini Interactions cookbooks.

Bug Fixes:

  • AG-UI Teams: Fixed a typo (stream_steps → stream_events) that caused teams running via AG-UI to silently drop all intermediate streaming events (lifecycle, reasoning, tool calls, member delegations) for ~7 months.
  • Slack Extra: Added aiohttp>=3.7.3,<4 to the slack optional extra — AsyncWebClient imports aiohttp at module load, so pip install agno[slack] was broken for all Slack operations.
  • Google Drive: Surfaced the Drive API incompleteSearch flag from GoogleDriveTools.search_files() so corpora="allDrives" callers can detect when Drive did not search every drive.
  • GeminiInteractions: Added a generation_config passthrough field for advanced controls (top_k, presence_penalty, etc.) and fixed history handling — when previous_interaction_id is set, only the new turn is sent rather than replaying the full history. Now actually leverages server-side statefulness.
  • Anthropic Server Tools: Preserved server_tool_use and code-execution content blocks in message history so multi-turn server-tool flows no longer break across turns.
  • Anthropic Hardening: Follow-up to the above — switched to the canonical redacted_thinking type literal (the SDK rejects redacted_reasoning_content), accepted both spellings on the streaming start event, added a dedup guard on round-tripped server tool blocks, made coercion failures visible via log_warning, and coerced non-block tool-result items to text.
  • Gemini Errors: Generic Gemini errors now include the exception type when str(error) is empty or weak, preserving error context across invoke / invoke_stream / ainvoke / ainvoke_stream.
  • N1N: Added the missing n1n provider mapping in get_model() so Agent(model="n1n:...") model-string paths now resolve correctly.
