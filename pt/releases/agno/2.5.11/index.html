agno v2.5.11

#Changelog

Novos recursos:

  • Google Sides Toolkit: novos kits de ferramentas de slides adicionados para criar/editar e trabalhar com slides do Google
  • Kit de ferramentas de autenticação do Google: kit de ferramentas GoogleAuth adicionado e decorador de autenticação compartilhado para kits de ferramentas do Google.

  • Chunking: Adicionado suporte de prompt personalizado ao AgenticChunking

  • Migração: Adicionada migração para coluna run_status da tabela de aprovações válida para ≥v2.5.6
  • LanceDb: atualizado para desduplicar os resultados da pesquisa em search() para evitar que a pesquisa híbrida retorne o mesmo documento das filiais vetorial e FTS.
  • Seltz Toolkit: Atualizações para integração do Seltz SDK de 0.1.x para 0.2.0.

Correções de bugs:

    • Adicionado suporte para o parâmetro de solicitação de nível superior output_config da Anthropic para wrappers Claude, para que os usuários possam passar valores como output_config={"effort": "high"} junto com o pensamento adaptativo.
    • Preservar $defs na formatação do esquema da ferramenta Claude
    • Extraia file_ids e informações do contêiner no caminho de streaming para habilidades de Claude
  • Chamada de ferramenta: Corrigida a análise de chamadas de ferramenta para usar atribuir em vez de anexar o nome da função no streaming parse_tool_calls.
  • LiteLLM: Atualizado para evitar que strings vazias substituam nomes de ferramentas no streaming LiteLLM
  • AWS Bedrock: Corrigido para ****falha rápida para autenticação AWS_BEDROCK_API_KEY não suportada em Claude.
  • Azure OpenAI: corrigido para substituir deepcopy para preservar as referências client.
  • Openrouter: Corrigido para pular bloco de raciocínio vazio para modelos sem raciocínio.
  • Respostas de cache: Atualizado para lidar com tipos não serializáveis ​​na geração de chave de cache.

agno v2.5.11

Highlights

  • Cross-model tool interchangeability — PR #6971 adds cross-model tool call compatibility so calls produced by one provider parse cleanly when you swap in another. For anyone doing failover or A/B comparisons across model families, this removes the need to normalize tool-call formats yourself; interoperability still rests on shared schema conventions, so validate with your own tool definitions.
  • Google toolkits consolidate around shared auth — A new GoogleAuth toolkit plus a shared auth decorator (#7098) lets one OAuth grant back multiple Google tools instead of wiring credentials per toolkit. This release also adds GoogleSlidesTools (#6830) and rewrites GoogleDriveTools with smart export and async support (#6995). The Drive rewrite is the watch item: re-test export paths and async calls, since signatures and behavior may have shifted.
  • Claude reasoning controls and schema fidelity — Anthropic's top-level output_config now passes through (#7067), so you can set output_config={"effort": "high"} alongside adaptive thinking instead of routing it through other params. Two fixes matter for tool-heavy agents: $defs are preserved in Claude tool schema formatting (#6085), and file_ids/container info are now extracted on the streaming path for Claude skills (#7109) — both close gaps where nested schemas and skill outputs were silently dropped.
  • Streaming tool-call parsing hardened — #6989 fixes parse_tool_calls appending rather than assigning function names, and #7132 stops empty strings from overwriting tool names in LiteLLM streaming. If you saw tools with duplicated or blank names in streamed responses, these are the fixes; re-run tool-call regression tests on your streaming path.
  • Retrieval and auth behavior changes — LanceDB search() now deduplicates hybrid results across the vector and FTS branches (#7061), so result counts drop where the same document previously appeared twice — adjust any logic keyed on result length. Separately, AWS Bedrock now fails fast on unsupported AWS_BEDROCK_API_KEY auth for Claude (#6855), turning a silent misconfiguration into an immediate error; audit Bedrock credentials before upgrading.
  • Migration and ecosystem upkeep — PR #7158 adds a migration for the approvals table run_status column (valid for ≥v2.5.6); run it if you're on an older schema. Also new: PerplexitySearch toolkit (#6951), custom prompts in AgenticChunking (#7085), Seltz SDK bumped to 0.2.0 (#6891), and cache-key generation that tolerates non-serializable types (#7155).

No breaking changes are formally declared in this release.

Changelog

New Features:

  • Google Sides Toolkit: Added new slides toolkits for creating / editing and working with Google slides
  • Google Auth Toolkit: Added GoogleAuth toolkit and shared auth decorator for Google toolkits.
  • Models: Added cross-model tool call compatibility to facilitate interchanging model pattern.
  • Chunking: Added custom prompt support to AgenticChunking
  • Perplexity: Added a PerplexitySearch toolkit.

Improvements:

  • Migration: Added migration for approvals table run_status column valid for ≥v2.5.6
  • LanceDb: Updated to deduplicate search results in search() in order to avoid hybrid search returning the same document from both vector and FTS branches.
  • Seltz Toolkit: Updates for Seltz SDK integration from 0.1.x to 0.2.0.

Bug Fixes:

  • Team: Fixed async toolkit tools not appearing in team system message tool names.
  • LanceDB: Fixed duplicate results when using hybrid search.
  • Claude:
    • Added support for Anthropic's top-level output_config request parameter for Claude wrappers, so users can pass values like output_config={"effort": "high"} together with adaptive thinking.
    • Preserve $defs in Claude tool schema formatting
    • Extract file_ids and container info in streaming path for Claude skills
  • Tool Calling: Fixed parsing of tool calls to use assign instead of append function name in streaming parse_tool_calls.
  • LiteLLM: Updated to prevent empty strings from overwriting tool names in LiteLLM streaming
  • AWS Bedrock: Fixed to ****fail fast for unsupported AWS_BEDROCK_API_KEY auth in Claude.
  • Azure OpenAI: Fixed to override deepcopy to preserve client references.
  • Openrouter: Fixed to skip empty reasoning block for non-reasoning models.
  • Caching Responses: Updated to handle non-serializable types in cache key generation.
