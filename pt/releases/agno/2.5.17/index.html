agno v2.5.17

Highlights

  • More configurable integrations — Claude file citations can now be disabled (#7511), giving downstream consumers control over citation output. GitHubConfig.repo can be overridden per request (#7496), allowing the same integration to target different repositories without rebuilding configuration.
  • Transport and authentication behavior — header_provider headers are now applied during MCP initialization (#7507), fixing authenticated servers that reject the handshake before any tool call. Providers no longer receive a shared HTTP/2 client automatically (#7492); configure custom transports or connection-pool assumptions on the provider itself.
  • Safer persistence and input schemas — Component loading now preserves custom database table names (#7508), avoiding accidental reads or writes against default tables. Framework-injected parameters are excluded from user_input_schema (#7485), keeping caller-facing schemas aligned with actual user input.
  • More reliable streaming and JSON parsing — Router streaming generators now catch CancelledError explicitly (#7379), preventing cancellations from leaking as ordinary streaming failures. JSON parsing tries the raw payload before cleanup (#7402), preserving fenced code blocks embedded in string values.
  • Better nested workflow observability — Inner workflow events retain their identity, and agent/team events gain nested_depth (#7491), making parent/child execution easier to correlate and nesting levels easier to distinguish in traces and event consumers.
  • Breaking changes — None documented.
