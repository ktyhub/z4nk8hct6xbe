#agno v3.0.6

Changelog

Novos recursos

  • Serviço MCP sem estado. MCPConfig(stateless=True) servirá /mcp sem rastreamento de sessão, portanto, qualquer réplica pode responder a qualquer solicitação e uma implantação de várias instâncias não precisa de afinidade de sessão. Custa notificações iniciadas pelo servidor e capacidade de retomada do SSE, portanto permanece desativado por padrão. Consulte livro de receitas.
  • MCPTools(protocol_mode=...) seleciona qual era do protocolo MCP negociar. O padrão é "legacy", preservando o comportamento atual baseado em sessão; "auto" negocia a mais nova era de suporte para ambos os lados (sem sessão de 2026-07-28). Os servidores existentes não são afetados – um servidor moderno ainda aceita o handshake legado. Internamente, os MCP clients agora são construídos em fastmcp.Client. Veja livro de receitas.
  • Placa de servidor AgentOS MCP em GET /mcp/server-card, listando as ferramentas servidas e contendo um nome, versão e instruções configuráveis.
  • Uploads de arquivos .zip e .eml no AgentOS. Veja livro de receitas.
  • AuthorizationConfig.excluded_route_paths marca rotas personalizadas como públicas sem desativar a autenticação globalmente.
  • Bedrock: passe seu próprio client assíncrono para o modelo ou incorporador.

Correções de bugs

  • Antrópico: o assistente de replay muda literalmente para que os bloqueios de pensamento não sejam mais rejeitados.
  • Gemini: resolve o tipo MIME da imagem em vez de codificar image/jpeg.
  • RecursiveChunking: pare de emitir pedaços finais duplicados.
  • AG-UI: envia campos de transferência em vez de RunContext para entidades remotas.
  • AG-UI: expõe erros de execução de streaming.
  • Fixe tree-sitter-language-pack<1.16 para desbloquear o chunker de código chonkie.

agno v3.0.6

Highlights

  • Stateless MCP serving for horizontal scaling — Set MCPConfig(stateless=True) to let any replica handle /mcp requests without sticky sessions. This is useful for load-balanced deployments, but it disables server-initiated notifications and SSE resumability, so applications relying on either should keep the default.
  • Explicit MCP protocol negotiation — MCPTools(protocol_mode=...) defaults to "legacy" for compatibility, while "auto" negotiates the newest mutually supported protocol, including sessionless operation from 2026-07-28. MCP 2.x and fastmcp.Client underpin the client implementation (#9269, #9927); existing legacy servers remain supported.
  • Discoverable AgentOS MCP endpoint — GET /mcp/server-card exposes served tools alongside configurable server name, version, and instructions (#9930, #9932, #9949), helping clients discover capabilities rather than hard-coding them.
  • Broader uploads and route-level auth control — AgentOS now accepts .zip and .eml uploads (#9193). AuthorizationConfig.excluded_route_paths lets specific custom routes remain public without disabling authentication globally (#9295), reducing the need for global auth workarounds.
  • More reliable multimodal and streaming integrations — Anthropic assistant turns are replayed verbatim to prevent rejected thinking blocks (#9924), and Gemini images now use their actual MIME type instead of being forced to image/jpeg (#9887). AG-UI also exposes streamed run errors and sends wire fields rather than RunContext to remote entities (#9487, #9909), improving remote observability and compatibility.
  • Chunking and dependency fixes — RecursiveChunking no longer emits duplicate trailing chunks (#9919), avoiding redundant processing and embeddings. A tree-sitter-language-pack<1.16 constraint restores compatibility with the chonkie code chunker (#9901); watch this pin when upgrading related dependencies.

No breaking changes.

Changelog

New Features

  • Stateless MCP serving. MCPConfig(stateless=True) serves /mcp without session tracking, so any replica can answer any request and a multi-instance deployment needs no session affinity. Costs server-initiated notifications and SSE resumability, so it stays off by default. See cookbook.
  • MCPTools(protocol_mode=...) selects which MCP protocol era to negotiate. Defaults to "legacy", preserving today's session-based behaviour; "auto" negotiates the newest era both sides support (sessionless from 2026-07-28). Existing servers are unaffected — a modern server still accepts the legacy handshake. Internally, MCP clients are now built on fastmcp.Client. See cookbook.
  • AgentOS MCP Server Card at GET /mcp/server-card, listing the served tools and carrying a configurable name, version and instructions.
  • .zip and .eml file uploads in AgentOS. See cookbook.
  • AuthorizationConfig.excluded_route_paths marks custom routes public without disabling auth globally.
  • Bedrock: pass your own async client to the model or embedder.

Bug Fixes

  • Anthropic: replay assistant turns verbatim so thinking blocks are no longer rejected.
  • Gemini: resolve image MIME type instead of hard-coding image/jpeg.
  • RecursiveChunking: stop emitting duplicate trailing chunks.
  • AG-UI: send wire fields instead of RunContext to remote entities.
  • AG-UI: expose streamed run errors.
  • Pin tree-sitter-language-pack<1.16 to unblock the chonkie code chunker.
