#agno v2.5.13 #Changelog

Melhorias:

  • ReliabilityEval: Adicione correspondência de subconjunto, validação de argumentos e rastreamento de chamadas de ferramentas ausentes com correções de coleta de chamadas de ferramentas de várias rodadas.
  • AgentOS: Melhore a lista /sessions API para retornar campos adicionais (user_id, agent_id, team_id, workflow_id, session_summary, métricas, total_tokens, metadados).
  • AgentOS: adicione o endpoint /info API para retornar a contagem de agente, equipe e fluxo de trabalho como metadados de instância leves e não autenticados.
  • ChromaDB: implemente a divisão dinâmica de lote para grandes operações de upsert/consulta.
  • Reader: propaga chunk_size para estratégias de chunking padrão em classes de leitor.
  • Slack Interface: Adicionado parâmetro show_member_tool_calls e rotação automática de estouro de cartão – gira para uma nova mensagem quando o texto excede um limite

Correções de bugs:

  • VertexAI/Bedrock Claude: Suporte ao parâmetro messages em _prepare_request_kwargs para subclasses de Claude
  • Fluxos de trabalho: Correção de continue_run para pausar corretamente nas etapas HITL de Condição, Loop e Roteador — anteriormente apenas instâncias de Etapa eram verificadas.
  • AgentOS: exclui rotas de interface (Slack, Telegram, WhatsApp, A2A) do middleware JWT para que as entregas de webhook não sejam rejeitadas com 401.
  • Rastreamento: Corrige o agrupamento de estatísticas da sessão de rastreamento para usar apenas session_id, evitando linhas duplicadas quando uma sessão é executada por usuários diferentes.
  • SurrealDB: Corrige estatísticas de sessão de rastreamento para usar array::first() em vez de math::max() para campos de string.
  • ReliabilityEval: Corrige a extração de chamadas de ferramenta de múltiplas rodadas para que todas as rodadas sejam coletadas; corrigir bug de mutação modificando mensagens RunOutput.messages originais; corrija arun() usando ID errado para salvar o arquivo.

agno v2.5.13

Highlights

  • AgentOS API surface expands — /sessions now returns user/agent/team/workflow IDs plus summary, metrics, token counts, and metadata (#6270), letting clients drop follow-up lookups; a new lightweight /info endpoint exposes agent/team/workflow counts (#7190, auth/response hardened in #7256). Watch out: /info is deliberately unauthenticated instance metadata — gate it at the edge if your topology is sensitive.
  • Messaging webhooks escape JWT middleware — interface routes for Slack, Telegram, WhatsApp, and A2A are excluded from JWT auth (#7252), fixing inbound deliveries being rejected with 401. If you customized auth around AgentOS, re-verify you weren't relying on those routes being protected.
  • HITL resume behavior changes — continue_run now pauses at Condition, Loop, and Router HITL steps instead of only plain Step instances (#7227). Resumed workflows will stop more often by design; make sure your runners handle the new pause points and persisted state.
  • ReliabilityEval gets tool-call fidelity — subset matching and argument validation arrive with missing-call tracking and complete multi-round extraction (#7230); a mutation bug that rewrote the original RunOutput.messages and an arun() wrong-ID file-save bug are also fixed. Expect eval scores to shift on multi-round traces — earlier rounds were silently dropped.
  • Claude on Vertex AI / Bedrock receives history — _prepare_request_kwargs now accepts the messages parameter for Claude subclasses (#7245), so conversation context actually reaches the model on those backends instead of being dropped.
  • Storage and analytics correctness at scale — ChromaDB gains dynamic batch splitting for large upsert/query operations (#7148) and readers propagate chunk_size into default chunking strategies (#7212); trace session stats group by session_id only (#7243) and SurrealDB uses array::first() for string fields (#7257), eliminating duplicate and mistyped analytics rows.

No breaking changes in this release.

Changelog

Improvements:

  • ReliabilityEval: Add subset matching, argument validation, and missing tool call tracking with multi-round tool call collection fixes.
  • AgentOS: Enhance /sessions list API to return additional fields (user_id, agent_id, team_id, workflow_id, session_summary, metrics, total_tokens, metadata).
  • AgentOS: Add /info API endpoint to return agent, team, and workflow count as lightweight, unauthenticated instance metadata.
  • ChromaDB: Implement dynamic batch splitting for large upsert/query operations.
  • Reader: Propagate chunk_size to default chunking strategies in reader classes.
  • Slack Interface: Add show_member_tool_calls param and automatic card overflow rotation — rotates to a new message when text exceeds a threshold

Bug Fixes:

  • VertexAI/Bedrock Claude: Support messages parameter in _prepare_request_kwargs for Claude sub classes
  • Workflows: Fix continue_run to correctly pause at Condition, Loop, and Router HITL steps — previously only Step instances were checked.
  • AgentOS: Exclude interface routes (Slack, Telegram, WhatsApp, A2A) from JWT middleware so webhook deliveries are not rejected with 401.
  • Tracing: Fix trace session stats grouping to use session_id only, preventing duplicate rows when a session has runs from different users.
  • SurrealDB: Fix trace session stats to use array::first() instead of math::max() for string fields.
  • ReliabilityEval: Fix multi-round tool call extraction so all rounds are collected; fix mutation bug modifying original RunOutput.messages; fix arun() using wrong ID for file save.
