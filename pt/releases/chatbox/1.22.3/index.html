chatbox v1.22.3

Highlights

  • Regeneration latency in long threads — The headline fix targets a concrete pain point: regenerating a reply in a long conversation used to lag. For anyone building or scripting around re-generation, this signals the app no longer rebuilds/parses the entire message history on each retry — expect noticeably snappier "regenerate" behavior in long-lived chats. Re-test any timing-sensitive automation that waits on a regenerated response, since the UI flow may now complete faster.

  • Response-branch switching — Switching between response branches in long conversations was the second half of the same performance problem. This matters because side-by-side branch comparison is a core power-user workflow; the fix implies more incremental state handling rather than re-rendering the whole conversation tree. Watch for smoother rapid branch toggling, and re-run any rapid-switch UI tests that previously hit the lag.

  • Backup export compatibility — Export now works on devices where it previously failed. This is a data-portability fix, not a feature change: it most likely touches export path/format handling (storage location, file permissions, or encoding). If your users or team were blocked from exporting on certain devices, that blocker should be gone after upgrading — worth re-verifying on exactly those devices rather than assuming.

  • Migration / what to watch — Because the export improvement is compatibility-driven rather than a format change, treat it as a reliability fix: re-export and validate a backup after upgrading, especially on devices that failed before. Existing backups should still be readable; there's no indication of a schema change requiring a migration step.

No breaking changes in this release.
