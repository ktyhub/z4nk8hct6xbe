#gráfico de código v1.6.3

[1.6.3] - 17/11/2026

Destaques

  • Mais nove agentes e editores. codegraph install agora configura IBM Bob, Factory Droid, Windsurf, Qwen Code, DeepSeek Harness, Grok Build, Kimi Code, o Qoder CLI e Pi.
  • Correções de segurança. Uma pasta confidencial como ~/.ssh não pode mais ser aberta como um projeto por meio de um link, uma junção ou outra grafia de seu caminho, e o pacote Node.js é movido para 24.22.1, que corrige CVE-2026-111497.
  • Links mais precisos em todos os idiomas. Centenas de correções ajudam chamadas, importações e tipos a alcançar o código que desejam, principalmente em JavaScript e TypeScript, Go, C e C++, Rust, Python, C#, Java e Dart. Tauri, CodeIgniter 3, serviços e plug-ins Drupal, middleware Next.js e manipuladores MediatR agora também são cobertos.
  • Melhores respostas para seu agente. codegraph_explore não fica mais paralisado em um grande projeto, responde a um log ou arquivo colado em segundos, encontra códigos nomeados em chinês, japonês ou coreano, e seu fluxo alcança todos os símbolos dos nomes de sua consulta.
  • Novos comandos. codegraph cycles encontra arquivos que importam uns aos outros em um círculo, codegraph implementations lista o que implementa um tipo, codegraph files --format package divide um monorepo por pacote e codegraph init --local-only mantém .codegraph/ fora do git.
  • Um servidor em segundo plano mais estável. Uma nova sessão não espera mais minutos quando o servidor em segundo plano fica travado, a atualização durante uma sessão muda para a nova versão e codegraph sync e o inspetor de arquivos mantêm os links conforme os arquivos são adicionados, excluídos e restaurados.
  • Mais rápido e mais leve. Comandos que apenas leem o índice iniciam mais rápido e a indexação consome menos CPU e memória, principalmente em projetos pequenos e em C e C++.
  • Atualização: reindexe seus projetos após este lançamento com codegraph index. A maioria dessas correções é escrita durante a indexação, e codegraph status e seu agente informam quando um índice foi criado por uma versão mais antiga.

Segurança

  • Uma pasta confidencial como ~/.ssh, /etc ou C:\Windows não pode mais ser usada como um projeto através de um link ou junção, um nome diferentemente capitalizado, um caminho \\?\ ou um caminho para uma pasta ausente dentro de uma. Antes, qualquer um deles permitia que a consulta de um agente lesse os arquivos contidos nele. Obrigado @mixxer. (#2929)
  • O servidor MCP não utiliza mais uma pasta confidencial como ~/.ssh ou /etc como projeto padrão da sessão, seja ela proveniente do espaço de trabalho do agente, da pasta em que foi iniciado ou --path. Antes, uma sessão era iniciada em uma que continha um índice respondido pelos arquivos internos. (#3012)
  • O tempo de execução Node.js empacotado muda para 24.22.1, a versão de segurança de outubro do Node, que corrige CVE-2026-111497, uma gravação fora dos limites de alta gravidade em seu decodificador Brotli, e cada versão agora verifica o Node que ele agrupa em relação às somas de verificação que o nodejs.org publica. Ele também corrige uma falha do Windows quando um comando como codegraph sync é encerrado após a conclusão do trabalho. Obrigado @Ancienttwo e @ IdealBoy709. (#2617, #2780)

Correções

####Janelas

  • No Windows, excluir a pasta para a qual um link em seu projeto aponta, como uma junção para uma biblioteca fora dela, não faz mais com que o servidor do CodeGraph use um núcleo de CPU completo ou pare de coletar suas edições. Obrigado @L0garithmic.
  • No Windows, um projeto na raiz de uma unidade, como uma unidade de rede mapeada como Z:\, uma unidade subst ou a raiz de um compartilhamento de rede, agora indexa em vez de recusar todos os arquivos como "Travessia de caminho bloqueada". Obrigado @Kamilslaoui93.
  • No Windows, uma pasta temporária em uma unidade que não está lá, como um disco desconectado ou uma unidade RAM desmontada, não trava mais todos os comandos do codegraph na inicialização.
  • No Windows, uma árvore de trabalho git dentro de seu checkout principal, como uma em .claude/worktrees/, agora é reconhecida independentemente de seu caminho ser escrito, como com a letra minúscula da unidade VS Code e a passagem do Cursor. Obrigado @nk33-dev.
  • O instalador do Windows, irm …/install.ps1 | iex, não para mais com "(403) Proibido" quando o limite de solicitações anônimas do GitHub é esgotado, e uma versão definida sem seu v, como CODEGRAPH_VERSION=1.6.2, agora é instalada. Obrigado @hiyochi.
  • Nos arquivos JavaScript e TypeScript com finais de linha Windows (CRLF), um store exportado em uma linha posterior, como export default useStore;, agora tem suas ações indexadas, assim como acontece com os finais de linha Unix.
  • No Windows, uma chamada Swift escrita após try!, como try! Settings.Defaults.load(), agora é vinculada ao que chama, como já acontecia no macOS e no Linux.

Highlights

  • Nine more agents and editors. codegraph install now sets up IBM Bob, Factory Droid, Windsurf, Qwen Code, DeepSeek Harness, Grok Build, Kimi Code, the Qoder CLI and Pi.

Tauri, CodeIgniter 3, Drupal services and plugins, Next.js middleware and MediatR handlers are now covered too.
  • Better answers for your agent. codegraph_explore no longer stalls on a large project, answers a pasted log or file in seconds, finds code named in Chinese, Japanese or Korean, and its Flow reaches every symbol your query names.
