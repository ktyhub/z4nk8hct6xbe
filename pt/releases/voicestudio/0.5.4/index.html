#VoiceStudio v0.5.4

Mecanismos funcionais, áudio de formato longo mais suave e integrações locais úteis. CosyVoice repara seu tempo de execução e preserva o contexto de fala com Transformers mais recentes. Histórias e audiolivros ganham junções de áudio mais limpas, melhores controles de script e importações de EPUB mais confiáveis. A configuração e o diagnóstico do Electron facilitam a recuperação de falhas sem descartar modelos baixados ou projetos existentes.

Já usa o Electron? Instale sobre seu aplicativo existente e mantenha seus dados. Se solicitado, escolha Instalar tempo de execução local para atualizar suas dependências. Mudando de Tauri? Faça backup do seu diretório de dados com o aplicativo fechado, instale o Electron e verifique suas vozes e projetos antes de remover o Tauri. Siga o guia de migração. Tauri v0.5.3 continua sendo o lançamento final do Tauri; seu atualizador não pode instalar o Electron.

VoiceStudio v0.5.4

Highlights

  • Tauri → Electron is a manual migration, not an in-place update — Tauri v0.5.3 is the final Tauri build and its updater cannot install Electron, so auto-update won't carry users across. Back up the data directory with the app closed, install Electron, verify voices/projects before removing Tauri, and pick Install local runtime when prompted; this is the one change that needs operator action rather than just relaunching.
  • Engine repair no longer costs you your downloaded models — CosyVoice restores missing runtime dependencies, preserves speech context on newer Transformers, and matches float32 weights/inputs off-CUDA to kill worker-thread dtype failures (#2096); IndexTTS installs under Python 3.11 and repairs broken environments on retry without deleting cached weights (#2098). Also watch the dots.tts path/pin fixes (#2101) and VoxCPM2's native control format, which changes style delivery (#2093).
  • Clean-install engine installs finally work — The backend now points at its bundled uv instead of relying on PATH: the packaged binary sits in app resources (on no PATH) and GUI launches inherit no shell PATH additions, which previously made one-click installs fail preflight with "uv was not found" (#2221, #2215). Combined with dependency validation before reusing a desktop runtime (#2176), this removes the classic "works in a terminal, fails in the app" case.
  • Long-form audio joins and script defaults changed — Per-line engine padding is trimmed and replaced with an explicit, adjustable gap between lines and paragraphs (#2216), and Paste & Split now defaults to Paragraphs instead of one take per sentence (#2217) — expect existing projects to render with different pacing. EPUB import now honors the book's declared start and TOC, skipping teaser/copyright/footnote pages as front/back matter (#2228, #2208), while a one-step Clear script keeps the cast (#2203).
  • Dubbing and subtitle fidelity tightened — Rolling-caption dubs speak each line once while preserving intentional repeated dialogue (#2222), and background preservation works with newer FFmpeg that dropped the legacy filter-file option (#2236). Subtitles now keep milliseconds across second boundaries (#2074), retain cues containing --> or I <3 you intact in exports (#2226), decode entities (#2223), and stop tab-through from resnapping segment times (#2224).
  • Local toolchain and diagnostics level up — Export local n8n speech workflows (#2261) and wire Claude Code/Cursor to the current backend via MCP setup pages (#2257). Completed generations are no longer discarded when worker completion races the timeout check (#2264), and failures now carry the backend error class into reports (#2197) with actionable messages for unsupported GPUs or blocked files instead of generic "Generation failed" text (#2195, #2177).

Working engines, smoother long-form audio, and useful local integrations. CosyVoice repairs its runtime and preserves speech context with newer Transformers. Stories and audiobooks gain cleaner audio joins, better script controls, and more reliable EPUB imports. Electron setup and diagnostics make failures easier to recover from without discarding downloaded models or existing projects.

  • The desktop app points the backend at the uv it already ships, so one-click engine installs stop failing preflight with "uv was not found" on a clean install — the packaged binary sits in the app's own resources directory, which is on no PATH, and a GUI launch inherits none of the shell's PATH additions either (#2221, #2215) — thanks @shivsin25 for the fix and @baoyu0 for the diagnosis!

  • IndexTTS installs with Python 3.11 and repairs incompatible environments on retry without removing downloaded weights (#2098) — thanks @martinezpl!

  • VoxCPM2 voice design uses its native control format, and style requests no longer inherit the reference transcript’s delivery (#2093) — thanks @nevilbutani and @martinezpl!

  • Dubbing background preservation and long exports work with newer FFmpeg builds that removed the legacy filter-file option (#2236) — thanks @quan0pek!

  • Stories: the book-wide reading speed moved from the bottom of the collapsed Cast card to the setup card beside voice and language, shows how many lines override it, and resets them in one click (#2230) — thanks @jaketame!

  • Projects: a finished Story or Audiobook shows its title and how it was made (voice, speed, engine, length, settings) instead of a bare filename (#2233) — thanks @jaketame!

  • Audiobook and Stories renders no longer sound broken between lines: each line's engine padding is trimmed and a deliberate, adjustable gap goes between lines and paragraphs instead (#2216) — thanks @jaketame!

  • Repair dots.tts dependency pins and paths containing spaces, with OpenFst build guidance for source installs (#2101) — thanks @martinezpl!

  • Reject unsupported synthesis languages before model loading, including named picker choices and per-item batch languages (#2219) — thanks @rollroyces!

  • EPUB import narrates the book, not its print furniture: page numbers no longer glue onto words or appear as lone lines, cover/title/dedication/copyright/contents pages are skipped, and chapters are titled from the book's table of contents (#2208) — thanks @jaketame!

  • Stories: a long script no longer paints over the generation progress panel and the Generate/Stop footer while an audiobook renders (#2213) — thanks @jaketame!

  • Keep macOS dictation keyboard operations on the main thread to prevent paste-delivery crashes (#2123)

  • Accept both valid SIGKILL diagnostics in the desktop lifecycle regression check (#2170)

  • Connect GPT-SoVITS to its api_v2 endpoint, accept healthy probe responses, and require a reference clip before generation (#2180, #2102) — thanks @rollroyces, @martinezpl and @jaketame!
