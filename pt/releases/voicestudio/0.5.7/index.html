#VoiceStudio v0.5.7

Primeiro, um pedido de desculpas. Este lançamento demorou muito mais do que deveria. Assuntos familiares urgentes me mantiveram afastado por um tempo, e sinto muito pela espera e pelas questões que ficaram sem resposta nesse meio tempo. Obrigado por sua paciência e por todos os relatórios, correções e palavras gentis entretanto.

Bem-vindo Shimul Debnath (velixio) à equipe principal. Shimul agora ajuda a manter o VoiceStudio — revisando solicitações pull, fazendo triagem de problemas e mantendo os lançamentos em andamento — para que o projeto não espere mais por uma pessoa.

O VoiceStudio agora funciona em seu telefone e em PCs sem GPU, e todo o aplicativo é mais calmo. Os aplicativos iOS e Android de visualização executam modelos no próprio telefone, os computadores sem GPU obtêm a construção PyTorch de CPU pequena e a barra lateral, as páginas Modelos, Dublagem, Histórias e Fluxos de trabalho foram redesenhadas em torno de menos controles e mais claros.

Esta versão também adiciona um canal de atualização Beta opcional, um player inferior para tomadas, um painel de aceleração de GPU com relatórios Radeon honestos e o agente Ask VoiceStudio, além de centenas de correções para clonagem, dublagem, audiolivros, downloads e ditado.

Atualização: Instale sobre seu aplicativo Electron existente; vozes, projetos e configurações são mantidos. Se a instalação solicitar, escolha Instalar tempo de execução local para atualizar suas dependências.

  • Dispositivos de computação remota, trabalhadores remotos e compartilhamento de GPU foram transferidos para o VoiceStudio Pro e não estão mais no aplicativo de código aberto; projetos salvos, vozes e configurações não são afetados (#2748)
  • Modelos sem licença claramente comercial, incluindo o modelo OmniVoice padrão, solicitam que você aceite sua licença uma vez no Catálogo de Modelos; até então, as solicitações API e MCP que os utilizam retornam um erro de licença (#2689)
  • Acesso Docker, LAN ou proxy reverso por nome de host, sem chave ou sessão API, necessita desse nome em OMNIVOICE_ALLOWED_HOSTS; Os endereços IP, localhost, *.ts.net e host.docker.internal funcionam como antes.
  • As importações de URL de servidores em sua própria rede precisam do OMNIVOICE_ALLOW_PRIVATE_URL_IMPORTS=1.
  • Onde definir essas variáveis: uma linha em ~/.config/omnivoice/env (macOS, Linux) ou %USERPROFILE%\.config\omnivoice\env (Windows) para o aplicativo de desktop, -e para Docker.

Mudança do Tauri: Feche o aplicativo, faça backup de seu diretório de dados, instale o Electron e verifique suas vozes e projetos antes de remover o Tauri. Siga o guia de migração. Tauri v0.5.3 continua sendo o lançamento final do Tauri; seu atualizador não pode instalar o Electron.

Instalador trust: os instaladores do macOS são assinados. Os instaladores do Windows ainda não foram assinados por código, então o SmartScreen pode avisar; a tabela Assinatura do instalador acima mostra o resultado de cada plataforma. Consulte o guia de instalação.

VoiceStudio v0.5.7

Highlights

  • On-device and CPU-only deployment — Preview iOS/Android apps run models locally and work offline once models are downloaded; GPU-less PCs get a small CPU PyTorch build, and Windows ARM64 gains an experimental native installer (#2500, #2611). Treat mobile as preview: iOS requires sideloading an unsigned IPA, while unsigned Windows installers may trigger SmartScreen.

  • Breaking: remote compute is now Pro-only — Remote compute devices, remote workers and GPU sharing are removed from the open-source app (#2748). Projects, voices and settings remain intact, but deployments relying on those features need Pro or another compute arrangement.

  • Model licences gate API and MCP access — Models without an explicitly commercial licence—including the default OmniVoice model—require one-time acceptance in Model Catalogue; API/MCP requests using them otherwise return a licence error (#2689). Acceptance records the date and exact terms, and changed terms require re-acceptance (#2755).

  • Hostname and private-network access need configuration — Docker, LAN and reverse-proxy access by hostname without an API key/session now requires OMNIVOICE_ALLOWED_HOSTS; URL imports from private-network servers require OMNIVOICE_ALLOW_PRIVATE_URL_IMPORTS=1. IP addresses, localhost, *.ts.net and host.docker.internal remain unaffected. Set these in the desktop env file or pass them through Docker -e.

  • Tauri users must migrate explicitly to Electron — Electron upgrades preserve voices, projects and settings. Tauri users should close the app, back up its data directory, install Electron, and verify their data before removing Tauri; v0.5.3 is the final Tauri release, and its updater cannot install Electron. Desktop filenames also drop “Electron” (VoiceStudio-<version>-<platform>-<arch>), though install scripts still recognize older artifacts (#3504).

  • Beta updates and mobile re-pairing — Settings → Updates adds an opt-in Beta channel that automatically returns to the next stable release. Phone apps now use app ID sh.voicestudio.mobile, so previous previews install alongside rather than upgrade; re-pair and verify before removing the old app (#3194).

First, an apology. This release took much longer than it should have. Urgent family matters kept me away for a while, and I'm sorry for the wait and for the issues that sat unanswered meanwhile. Thank you for your patience and for every report, fix and kind word in the meantime.

Welcome Shimul Debnath (velixio) to the core team. Shimul now helps maintain VoiceStudio — reviewing pull requests, triaging issues and keeping releases moving — so the project no longer waits on one person.

VoiceStudio now runs on your phone and on PCs without a GPU, and the whole app is calmer. Preview iOS and Android apps run models on the phone itself, GPU-less computers get the small CPU PyTorch build, and the sidebar, Models, Dubbing, Stories and Workflows pages were redesigned around fewer, clearer controls.

This release also adds an opt-in Beta update channel, a bottom player for takes, a GPU acceleration panel with honest Radeon reporting and the Ask VoiceStudio Agent, plus hundreds of fixes to cloning, dubbing, audiobooks, downloads and dictation.
