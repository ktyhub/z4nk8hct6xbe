Distribuído

  • Tensor Local:
    • LocalTensor é uma poderosa ferramenta de depuração e simulação no ecossistema de tensores distribuídos do PyTorch. Ele permite simular cálculos de tensores distribuídos em várias classificações SPMD (Programa Único, Dados Múltiplos) em um único processo. Isso é extremamente valioso para: 1) depurar código distribuído sem ativar vários processos; 2) compreender o comportamento do DTensor inspecionando os estados do tensor por classificação; 3) testar operações do DTensor com fragmentação desigual entre classificações; 4) prototipagem rapid de algoritmos distribuídos. Observe que LocalTensor foi projetado apenas para fins de depuração. Tem sobrecarga significativa e não é adequado para treinamento distribuído em produção.
    • LocalTensor é uma subclasse torch.Tensor que mantém internamente um mapeamento de IDs de classificação para fragmentos de tensores locais. Quando você executa uma operação PyTorch em um LocalTensor, a operação é aplicada independentemente a cada fragmento local, imitando a computação distribuída (LocalTensor simula operações coletivas localmente sem comunicação de rede real). LocalTensorMode é o gerenciador de contexto que permite o despacho LocalTensor. Ele intercepta operações PyTorch e as roteia adequadamente. O decorador @maybe_run_for_local_tensor é essencial para lidar com lógica específica de classificação ao implementar código distribuído.
    • Para começar a usar o LocalTensor, os usuários importam do torch.distributed._local_tensor, inicializam um grupo de processos falso e agrupam seu código distribuído em um contexto LocalTensorMode. Dentro deste contexto, as operações do DTensor produzem automaticamente LocalTensors.

Distributed

  • LocalTensor:

    • LocalTensor is a powerful debugging and simulation tool in PyTorch's distributed tensor ecosystem. It allows you to simulate distributed tensor computations across multiple SPMD (Single Program, Multiple Data) ranks on a single process. This is incredibly valuable for: 1) debugging distributed code without spinning up multiple processes; 2) understanding DTensor behavior by inspecting per-rank tensor states; 3) testing DTensor operations with uneven sharding across ranks; 4) rapid prototyping of distributed algorithms. Note that LocalTensor is designed for debugging purposes only. It has significant overhead and is not suitable for production distributed training.
    • LocalTensor is a torch.Tensor subclass that internally holds a mapping from rank IDs to local tensor shards. When you perform a PyTorch operation on a LocalTensor, the operation is applied independently to each local shard, mimicking distributed computation (LocalTensor simulates collective operations locally without actual network communication.). LocalTensorMode is the context manager that enables LocalTensor dispatch. It intercepts PyTorch operations and routes them appropriately. The @maybe_run_for_local_tensor decorator is essential for handling rank-specific logic when implementing distributed code.
    • To get started with LocalTensor, users import from torch.distributed._local_tensor, initialize a fake process group, and wrap their distributed code in a LocalTensorMode context. Within this context, DTensor operations automatically produce LocalTensors.
    • PRs: (#164537, #166595, #168110,#168314,#169088,#169734)
