Projeto

  • Corrigido Duplicate class found devido ao objetivo delombok.

Servidor OAP

  • Corrigida camada errada da métrica user error no monitoramento do DynamoDB.
  • O armazenamento ElasticSearch não verifica os tipos de campo quando o OAP é executado no modo no-init.
  • Suporte para vincular o status TLS como parte do componente da topologia de serviço.
  • Corrigido bug de prioridade de ID de componente.
  • Correção do ID do componente de sobreposição de topologia devido a bugs na camada de armazenamento.
  • [Alteração significativa] Aprimore o armazenamento JDBC mesclando tabelas e gerenciando a rolagem de tabelas com base no dia.
  • [Alteração significativa] Implementações e testes de Sharding-MySQL são removidos porque temos o mecanismo de rolagem baseado em dia por padrão
  • Correção da regra otel k8s-cluster e adição de dimensão de namespace para cálculo de agregação MAL (status de implantação, réplicas de especificações de implantação)
  • Suporte ao recurso de perfil contínuo.
  • Suporte para coleta de métricas relacionadas ao nível do processo.
  • Fix K8sRetag lê o serviço k8s errado do cache devido a uma possível incompatibilidade de namespace.
  • [Alteração significativa] Suporte ao perfil de rastreamento entre threads. A estrutura de dados e a consulta dos APIs foram alteradas.
  • Correção da resposta PromQL HTTP API /api/v1/labels sem rótulo service.
  • Corrigido possível NPE ao inicializar IntList.
  • A expressão PromQL de análise de suporte possui rótulos vazios entre colchetes para consulta de metadados.
  • Suporte à métrica de alarme OP !=.
  • A consulta de métricas de suporte indica se o valor == 0 representa realmente zero ou nenhum dado.
  • Correção de NPE ao consultar índices de série inexistentes no armazenamento ElasticSearch.
  • Suporte à coleta de métricas de buff/cache de memória no monitoramento de VM.
  • PromQL: Remova valores vazios do resultado da consulta, corrija o parâmetro /api/v1/metadata que limit pode causar fora do limite.
  • Suporte ao monitoramento do número total de métricas de k8s StatefulSet e DaemonSet.
  • Suporte ao monitoramento do gateway Amazon API.
  • Aumente o graphql-java para corrigir cve.
  • Aumente Kubernetes Java client.
  • Suporte ao monitoramento Redis.
  • Adicione o ID do componente para amqp, amqp-producer e amqp-consumer.
  • Suporte ao modo sem proxy para receptor aws-firehose
  • Aumente a armeria para 1.23.1
  • Suporte ao monitoramento Elasticsearch.
  • Correção da resposta PromQL HTTP API /api/v1/series sem rótulo service ao corresponder à métrica.
  • Suporte ServerSide TopN para BanyanDB.
  • Adicione o ID do componente para Jersey.
  • Remova o suporte do OpenCensus, os códigos e documentos relacionados como está sendo encerrado.
  • Suporte à configuração dinâmica de searchableTracesTags
  • Suporte exportErrorStatusTraceOnly para exportar os segmentos de rastreamento de status de erro através do canal Kafka
  • Adicione ID de componente para Grizzly.
  • Corrija o potencial NPE no receptor Zipkin quando o Span estiver faltando alguns campos.
  • Filtre os dados da métrica desconhecido_cluster.
  • Suporte ao monitoramento RabbitMQ.
  • Suporte à coleta de logs lentos Redis.
  • Corrija a perda de dados ao consultar o registro de tarefa de criação de perfil contínuo.
  • Adapte a consulta de tarefa de criação de perfil contínua GraphQL.
  • Suporta Expressão de Consulta de Métricas (MQE) e permite que os usuários façam cálculos simples do estágio de consulta por meio da expressão.
  • Protocolo obsoleto de consulta de métricas v2.
  • Protocolo de consulta de registro obsoleto.
  • Adicione o ID do componente para go-redis.
  • Adicione OpenSearch 2.8.0 ao caso de teste.
  • Adicione o módulo ai-pipeline.
  • Suporta formatação HTTP URI através de ai-pipeline para fazer reconhecimento de padrões.
  • Adicione novo mecanismo de agrupamento HTTP URI com benchmark.
  • [Alteração significativa] Use o novo mecanismo de agrupamento HTTP URI para substituir o antigo mecanismo baseado em regex.
  • Suporte sumLabeled em MAL.
  • Migrar de kubernetes-client/java para fabric8 client.
  • As métricas de relação geradas pelo Envoy ALS consideram que os códigos de status http >= 400 apresentam um erro no lado client.
  • Adicionar campo de mensagem de causa ao consultar tarefa de criação de perfil contínua.

IU

  • Reverter: função cpm5d. Este recurso foi cancelado no back-end.
  • Correção: alertando quebras de link na topologia.
  • Refatore o widget Topologia para torná-lo mais hierárquico.
    1. Escolha User como o primeiro nó.
    2. Se o nó User estiver ausente, escolha o nó mais ocupado (que tem o maior número de chamadas de todos).
    3. Faça um processo de fluxo da esquerda para a direita.
    4. No mesmo nível, liste os nós de cima para baixo em ordem alfabética.
  • Correção do ID do filtro quando a métrica ReadRecords é associada ao rastreamento.
  • Adicionar menu AWS API Gateway.
  • Altere o protocolo de perfil de rastreamento.
  • Adicione o menu Redis.
  • Otimize os tipos de dados.
  • Suporte ao sinalizador isEmptyValue para consulta de métricas.
  • Adicione o menu elasticsearch.
  • [Limpe os modelos de UI antes da atualização] Defina showSymbol: true e faça com que o ponto de dados seja exibido no gráfico de linha. Limpe o índice ui_template no armazenamento elasticsearch ou a tabela no armazenamento JDBC.
  • [Limpe os modelos de UI antes da atualização] Modelos de UI: simplifique o nome da métrica com o rótulo.
  • Adicionar menu MQ.
  • Adicione o ícone Jeysey.
  • Correção: defina os seletores de endpoint e instância com parâmetros de URL corretamente.
  • Aumente as versões de dependências ícones-vue 1.1.4, element-plus 2.1.0, nanoid 3.3.6, postcss 8.4.23
  • Adicionar suporte ao protocolo de log OpenTelemetry.
  • [Alteração significativa] A chave de configuração enabledOtelRules foi renomeada para enabledOtelMetricsRules e a variável de ambiente correspondente foi renomeada para SW_OTEL_RECEIVER_ENABLED_OTEL_METRICS_RULES.
  • Adicione ícone pardo.
  • Correção: erro de exibição de dados da Lista de Instâncias.
  • Correção: defina o tipo topN como Número.
  • Suporta Expressão de Consulta de Métricas (MQE) e permite que os usuários façam cálculos simples do estágio de consulta por meio da expressão.
  • Aumente a dependência da interface do zipkin para 2.24.1.
  • Aumente a velocidade para 4.0.5.
  • Aplique MQE nos modelos de interface do usuário da camada General e Virtual-Database.

Documentação

  • Adicione documentações relacionadas ao perfil.
  • Adicione SUM_PER_MIN à documentação do MAL.
  • Torne os documentos relativos ao log mais claros e fáceis para obter suporte a mais formatos.
  • Atualize os documentos de gerenciamento de cluster e implantação avançada.

skywalking v9.5.0

Download

https://skywalking.apache.org/downloads/

Notice

Don't download source codes from this page. Please follow build document, if you want to build source codes by yourself.

New Topology Layout

<img width="1237" alt="image" src="https://github.com/apache/skywalking/assets/5441976/34ca963d-43f7-437e-8836-1e93d3b779be">

Elasticsearch Server Monitoring

<img width="1259" alt="image" src="https://github.com/apache/skywalking/assets/5441976/9c363aad-9af7-4fe4-bda2-2011f0ba3383">

Project

  • Fix Duplicate class found due to the delombok goal.

OAP Server

  • Fix wrong layer of metric user error in DynamoDB monitoring.
  • ElasticSearch storage does not check field types when OAP running in no-init mode.
  • Support to bind TLS status as a part of component for service topology.
  • Fix component ID priority bug.
  • Fix component ID of topology overlap due to storage layer bugs.
  • [Breaking Change] Enhance JDBC storage through merging tables and managing day-based table rolling.
  • [Breaking Change] Sharding-MySQL implementations and tests get removed due to we have the day-based rolling mechanism by default
  • Fix otel k8s-cluster rule add namespace dimension for MAL aggregation calculation(Deployment Status,Deployment Spec Replicas)
  • Support continuous profiling feature.
  • Support collect process level related metrics.
  • Fix K8sRetag reads the wrong k8s service from the cache due to a possible namespace mismatch.
  • [Breaking Change] Support cross-thread trace profiling. The data structure and query APIs are changed.
  • Fix PromQL HTTP API /api/v1/labels response missing service label.
  • Fix possible NPE when initialize IntList.
  • Support parse PromQL expression has empty labels in the braces for metadata query.
  • Support alarm metric OP !=.
  • Support metrics query indicates whether value == 0 represents actually zero or no data.
  • Fix NPE when query the not exist series indexes in ElasticSearch storage.
  • Support collecting memory buff/cache metrics in VM monitoring.
  • PromQL: Remove empty values from the query result, fix /api/v1/metadata param limit could cause out of bound.
  • Support monitoring the total number metrics of k8s StatefulSet and DaemonSet.
  • Support Amazon API Gateway monitoring.
  • Bump up graphql-java to fix cve.
  • Bump up Kubernetes Java client.
  • Support Redis Monitoring.
  • Add component ID for amqp, amqp-producer and amqp-consumer.
  • Support no-proxy mode for aws-firehose receiver
  • Bump up armeria to 1.23.1
  • Support Elasticsearch Monitoring.
  • Fix PromQL HTTP API /api/v1/series response missing service label when matching metric.
  • Support ServerSide TopN for BanyanDB.
  • Add component ID for Jersey.
  • Remove OpenCensus support, the related codes and docs as it's sunsetting.
  • Support dynamic configuration of searchableTracesTags
  • Support exportErrorStatusTraceOnly for export the error status trace segments through the Kafka channel
  • Add component ID for Grizzly.
  • Fix potential NPE in Zipkin receiver when the Span is missing some fields.
  • Filter out unknown_cluster metric data.
  • Support RabbitMQ Monitoring.
  • Support Redis slow logs collection.
  • Fix data loss when query continuous profiling task record.
  • Adapt the continuous profiling task query GraphQL.
  • Support Metrics Query Expression(MQE) and allows users to do simple query-stage calculation through the expression.
  • Deprecated metrics query v2 protocol.
  • Deprecated record query protocol.
  • Add component ID for go-redis.
  • Add OpenSearch 2.8.0 to test case.
  • Add ai-pipeline module.
  • Support HTTP URI formatting through ai-pipeline to do pattern recognition.
  • Add new HTTP URI grouping engine with benchmark.
  • [Breaking Change] Use the new HTTP URI grouping engine to replace the old regex based mechanism.
  • Support sumLabeled in MAL.
  • Migrate from kubernetes-client/java to fabric8 client.
  • Envoy ALS generated relation metrics considers http status codes >= 400 has an error at the client side.
  • Add cause message field when query continuous profiling task.

UI

  • Revert: cpm5d function. This feature is cancelled from backend.
  • Fix: alerting link breaks on the topology.
  • Refactor Topology widget to make it more hierarchical.
    1. Choose User as the first node.
    2. If User node is absent, choose the busiest node(which has the most calls of all).
    3. Do a left-to-right flow process.
    4. At the same level, list nodes from top to bottom in alphabetical order.
  • Fix filter ID when ReadRecords metric associates with trace.
  • Add AWS API Gateway menu.
  • Change trace profiling protocol.
  • Add Redis menu.
  • Optimize data types.
  • Support isEmptyValue flag for metrics query.
  • Add elasticsearch menu.
  • [Clean UI templates before upgrade] Set showSymbol: true, and make the data point shows on the Line graph. Please clean ui_template index in elasticsearch storage or table in JDBC storage.
  • [Clean UI templates before upgrade] UI templates: Simplify metric name with the label.
  • Add MQ menu.
  • Add Jeysey icon.
  • Fix: set endpoint and instance selectors with url parameters correctly.
  • Bump up dependencies versions icons-vue 1.1.4, element-plus 2.1.0, nanoid 3.3.6, postcss 8.4.23
  • Add OpenTelemetry log protocol support.
  • [Breaking Change] Configuration key enabledOtelRules is renamed to enabledOtelMetricsRules and the corresponding environment variable is renamed to SW_OTEL_RECEIVER_ENABLED_OTEL_METRICS_RULES.
  • Add grizzly icon.
  • Fix: the Instance List data display error.
  • Fix: set topN type to Number.
  • Support Metrics Query Expression(MQE) and allows users to do simple query-stage calculation through the expression.
  • Bump up zipkin ui dependency to 2.24.1.
  • Bump up vite to 4.0.5.
  • Apply MQE on General and Virtual-Database layer UI-templates.

Documentation

  • Add Profiling related documentations.
  • Add SUM_PER_MIN to MAL documentation.
  • Make the log relative docs more clear, and easier for further more formats support.
  • Update the cluster management and advanced deployment docs.
