nota de instalação do macOS

O aplicativo ainda não está assinado com um Apple Developer ID, então o macOS pode chamar um compilação baixada "danificada" - é a quarentena do Gatekeeper, não um arquivo ruim. Depois de mover o aplicativo para Aplicativos, limpe o sinalizador uma vez e abra normalmente:

xattr -dr com.apple.quarantine "/Applications/OpenHands Agent Canvas.app"

OpenHands v1.29.0

Highlights

  • Profiles now own their configuration — PR #18679, #18685, #18686, and #18720 move condenser/verification settings, Model Router selection, and skill choices into the profile itself, and default is now launched by id. If your workflow assumed one global config applied everywhere, re-audit each profile after upgrading: settings you never explicitized now come from the profile rather than inheriting a global default, so expect behavior drift in long-lived profiles. Also note prompt and plugin presets no longer offer an agent-profile picker at all (#18708).
  • Skills become a server-catalog capability — Launchers read public skills out of the bundled @openhands/extensions package (#18683, bumped to 0.32.0 in #18730) and profiles select skills from the server catalog (#18686). This makes skills versioned and discoverable instead of purely local configuration — great for reproducibility, but it means your effective skill set now depends on the extension bundle, so pin/verify that version when cloning an environment or reproducing a bug.
  • npm embedders get a scoped stylesheet — #18663 ships a scoped stylesheet with the library. If you were importing global CSS to make the UI render, switch to the bundled styles: that is the supported way to keep OpenHands' rules from leaking into the host app (and to stop host styles from breaking the widget).
  • Python 3.15 is a deliberate no-go for now — #18731 pins uvx to Python 3.12–3.14 until dependencies publish 3.15 wheels. CI images or local shells defaulting to 3.15 will hit dependency resolution failures; pin the interpreter explicitly rather than treating this as a regression to report.
  • Cloud sessions lose less state, chat feels snappier — Connected repositories are now persisted on cloud conversations (#18158), the first Cloud message survives when the history page lags the runtime (#18719), and model catch-up shrinks from ten seconds to one (#18651). For cloud-hosted users this directly reduces the confusing "my context vanished / the UI is behind the agent" moments and improves perceived responsiveness.
  • macOS installs still hit Gatekeeper — The build is not Apple-signed or notarized yet (tracked in #16774), so a fresh download may be flagged as "damaged"; CI now surfaces the unquarantine workaround on the release page (#18723). Automate clearing com.apple.quarantine after moving the app to Applications, or expect a false malware alarm on every new machine.

No breaking changes in this release.

macOS install note

The app isn't signed with an Apple Developer ID yet, so macOS may call a downloaded build "damaged" — it's Gatekeeper quarantine, not a bad file. After moving the app to Applications, clear the flag once, then open normally:

xattr -dr com.apple.quarantine "/Applications/OpenHands Agent Canvas.app"

Signing + notarization is tracked in OpenHands/OpenHands#16774.
