ant-design 6.7.0

Highlights

  • App-wide visual variants — ConfigProvider.variant now supports Button, Tag, Steps, Alert, and Timeline, while Divider gains divider.variant, enabling consistent styling with component-level overrides. Button also correctly applies configured non-solid variants when color is omitted (#59589).

  • Clear controls become more configurable—and consistently hidden when disabled — allowClear.tabIndex manages keyboard order across input and selection components, while allowClear.label supplies accessible names with field-level ConfigProvider inheritance. Cascader, TreeSelect, and AutoComplete now support global clear-button configuration. Important behavioral change: allowClear.disabled: true now removes the clear button entirely, matching allowClear={false}, rather than rendering it disabled (#59548).

  • Deprecated customization APIs now have targeted replacements — Migrate suffixIcon to state-aware suffix on selectable inputs (#59240), DatePicker/TimePicker components.button to components.nowButton and components.okButton (#59778), and Table expandable.expandIcon to components.ExpandIcon (#59036). Compatibility is retained, but adopting the new hooks avoids future breakage.

  • Alert theme overrides require a token migration — The Alert container radius token changes from borderRadius to containerBorderRadius. Custom themes overriding the old token must move those values, or their container-radius styling will stop applying (#59305).

  • Table and pagination gain better data-navigation controls — Tables can expand or collapse all expandable rows on the current page via expandable.showExpandAll and expandable.onExpandAll; this does not span other pages. Pagination’s onChange now receives an optional third info argument with recommendPage, also exposed through Table and List, allowing page-size changes to better preserve the user’s data position. Multi-filter performance for deeply nested table data also improves (#59036, #58604, #59719).

  • Keyboard accessibility and state handling see broad fixes — DatePicker/TimePicker add arrow-key navigation, Enter/Space selection, and skipping disabled times; selection components hide decorative icons from screen readers and improve clear-button focus visibility. Tree also fixes explicitly undefined expandedKeys/selectedKeys being treated as controlled and unwanted scrolling when focusable node content receives focus—recheck custom controlled-state wrappers and keyboard flows (#59778, #59709, #59274).
