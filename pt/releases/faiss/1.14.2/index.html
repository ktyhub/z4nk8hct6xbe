#faisse v1.14.2

Destaques

  • SuperKMeans — k-means mais rápido via ADSampling + poda progressiva PDX (#5168)
  • Backend de GPU de metal para Apple Silicon, começando com IndexFlat (#5144)
  • Backend SIMD RVV (vetor RISC-V) + CI de compilação cruzada RISC-V (#5156, #5184)
  • suporte para instalação de pip via scikit-build-core + cibuildwheel (#4862)
  • Índice SVS FIV habilitado; SVS atualizado para 0.3.0 (#4801, #4999); SVSVamana utilizável como quantizador grosso de fertilização in vitro via index_factory (#5175)
  • TurboQuant (CPU) quantizador (#5049)
  • Melhorias HNSW — bloqueios persistentes opcionais para adições incrementais (#5031), prune_headroom para evitar poda O(n²) (#4847), seção crítica de tempo de adição mais estreita (#4915)
  • Extenso endurecimento de desserialização de índice — validação e proteção OOM/overflow em aproximadamente 40 PRs (binário, IVF, HNSW, FastScan, ScalarQuantizer, AdditiveQuantizer, ProductQuantizer, SVS, VectorTransform,…)
  • Refator principal do Dynamic Dispatch através de distâncias, hamming, particionamento, RaBitQ, FastScan; despacho dinâmico agora baseado no Windows (#5127)
  • cuVS atualizado para 26.02 (#4945, #4788); CI mudou para CUDA 13.2 (#5207); C++20 para cuVS (#4881); pesquisa filtrada para índices cuVS (#4858)
  • Segurança de exceção OMP em IndexHNSW, IndexNNDescent, IndexNSG, IndexFlatCodes, IndexIVF (#5106, #5105, #5111, #5133, #5037, #5053)
