#faiss v1.14.3

Destaques

  • Expansão de back-end de GPU Metal — novo MetalIndexIVFFlat com kernels de varredura/mesclagem de fertilização in vitro e suporte expandido para top-k (#5202); Metal agora habilitado por padrão em máquinas Apple Silicon (#5280)
  • TurboQuant em ScalarQuantizer — Algoritmo 2 completo (estágio QJL) com SIMD e otimizações (#5170)
  • Otimizações Sapphire Rapids (SPR) — ScalarQuantizer L2/IP (#5173), HammingComputer baseado em VPOPCNTDQ (#5183) e kernel RaBitQ baseado em VPOPCNTDQ (#5149)
  • faiss-gpu pipwheels — novo pacote de roda GPU (#5131); rodas musllinux reativadas para faiss-cpu (#5299)
  • Suporte a vamana estático SVS (#5224)
  • Modo HNSW is_similarity para métricas de IP/similaridade (#5246, #5226)
  • Desempenho de pesquisa HNSW — reserve a capacidade do VisitedTableSet para evitar rehashes (#5290), search_from_candidate_unbounded modelado para desvirtualização do VisitedTable (#5270) e verificações de tempo de execução evitadas no VisitedTable (#5234)
  • NEON FINE_SIZE=2 especializações para Index2LevelDecoderImpl e IndexPQDecoder (#5255)
  • cuVS atualizado para 26.06 (#5240); CI atualizado para ROCm 7 (#5196)
  • Reforço de desserialização — validação de campo bool (#5279) e rejeição de índice interno nulo em IDMap / BinaryFromFloat (#5239)
  • Robustez de construção — correção de importação não-AVX2 SIGILL por meio de tabelas de particionamento .rodata (#5298), correção de compilação NEON do Windows ARM64 (MSVC) (#5274) e correção de despacho AVX512_SPR em AMD (#5281)

faiss v1.14.3

Highlights

  • Metal GPU backend expansion — new MetalIndexIVFFlat with IVF scan/merge kernels and expanded top-k support (#5202); Metal now enabled by default on Apple Silicon machines (#5280)
  • TurboQuant in ScalarQuantizer — full Algorithm 2 (QJL stage) with SIMD and optimizations (#5170)
  • Sapphire Rapids (SPR) optimizations — ScalarQuantizer L2/IP (#5173), VPOPCNTDQ-based HammingComputer (#5183), and VPOPCNTDQ-based RaBitQ kernel (#5149)
  • faiss-gpu pip wheels — new GPU wheel packaging (#5131); musllinux wheels re-enabled for faiss-cpu (#5299)
  • SVS static vamana support (#5224)
  • HNSW is_similarity mode for IP/similarity metrics (#5246, #5226)
  • HNSW search performance — reserve VisitedTableSet capacity to avoid rehashes (#5290), search_from_candidate_unbounded templatized for VisitedTable devirtualization (#5270), and runtime checks avoided in VisitedTable (#5234)
  • NEON FINE_SIZE=2 specializations for Index2LevelDecoderImpl and IndexPQDecoder (#5255)
  • cuVS upgraded to 26.06 (#5240); CI updated to ROCm 7 (#5196)
  • Deserialization hardening — bool-field validation (#5279) and null inner-index rejection in IDMap / BinaryFromFloat (#5239)
  • Build robustness — fix non-AVX2 import SIGILL via .rodata partitioning tables (#5298), Windows ARM64 (MSVC) NEON build fix (#5274), and AVX512_SPR dispatch fix on AMD (#5281)
