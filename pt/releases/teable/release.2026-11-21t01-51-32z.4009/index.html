versão testável.2026-11-21T01-51-32Z.4009

Atualizações de recursos

  • Adicionados endpoints MCP estritos e somente leitura. O endpoint estrito separa as ações de leitura e gravação para que AI clients compatíveis possam solicitar confirmação antes de fazer alterações. O endpoint somente leitura suporta clients que não podem confirmar gravações. As integrações MCP existentes permanecem inalteradas.
  • Adicionada uma Biblioteca de Consultas para cada Base. Os membros podem salvar, localizar, comparar e compartilhar revisões de consultas privadas por padrão. As consultas são executadas com as permissões de dados atuais do chamador, e os aplicativos publicados podem fixar uma revisão específica. A revogação do acesso impede que os aplicativos executem a consulta fixada até que o acesso seja restaurado ou o aplicativo seja atualizado. Este recurso requer que a Biblioteca de Consultas e a execução de consultas nativas estejam habilitadas.
  • A colagem de texto simples em tabelas agora oferece suporte a links bidirecionais muitos para muitos. Os títulos colados correspondem aos registros existentes na tabela vinculada e os links recíprocos são atualizados sem criar duplicatas.
  • Os membros da tabela agora podem ver se a aceleração de pesquisa está ativa, quais campos ela cobre e quando seu status muda. As visualizações compartilhadas mostram a disponibilidade apenas para campos visíveis na visualização.

Correções de bugs e melhorias

  • Atualizado o pacote de plugins OpenAI para a versão 1.0.1 e instruções de IA encurtadas para que não sejam mais cortadas no Claude Code.
  • Maior confiabilidade do campo computado v2, reduzindo a carga desnecessária do banco de dados.
  • Melhoria na confiabilidade da restauração e exclusão de recursos, incluindo uma correção para tabelas v2 restauradas que poderiam permanecer listadas na lixeira.
  • O pré-preenchimento de linha agora mantém os valores permitidos e ignora apenas novas opções de seleção que o editor não pode criar. Se colar contiver apenas uma opção restrita, ainda retornará um erro de permissão.
  • Corrigidas falhas quando os campos eram criados simultaneamente na mesma tabela ou enquanto uma operação de longa duração estava em andamento. Novos campos agora aparecem de forma confiável na lista de campos e na visualização padrão.
  • Cuppy agora explica quando uma tarefa é interrompida porque fica sem memória. As etapas concluídas permanecem visíveis e os usuários da web podem retomar a partir da resposta mais recente sem recomeçar.
  • Foram corrigidas pesquisas e rollups filtrados para que a exclusão de registros vinculados recalcule apenas os registros pai afetados. A exclusão também é mais rápida para grandes conjuntos de dados vinculados.
  • Segurança aprimorada do compartilhamento Base para que os visitantes possam acessar apenas o conteúdo dentro do escopo de compartilhamento configurado.
  • Corrigidos erros em gráficos do Dashboard que utilizam dados da tabela. Os totais do gráfico agora refletem os dados que cada visualizador tem permissão para ler, incluindo restrições em nível de linha.
  • Melhor desempenho do V2 API para atualizações em lote em vários campos de registros vinculados, preservando a ordem dos links e mantendo os links recíprocos sincronizados.

teable release.2026-11-21T01-51-32Z.4009

Feature Updates

  • Added strict and read-only MCP endpoints. The strict endpoint separates read and write actions so compatible AI clients can ask for confirmation before making changes. The read-only endpoint supports clients that cannot confirm writes. Existing MCP integrations are unchanged.
  • Added a Query Library for each Base. Members can save, find, compare, and share private-by-default query revisions. Queries run with the caller’s current data permissions, and published apps can pin a specific revision. Revoking access prevents apps from running the pinned query until access is restored or the app is updated. This feature requires both Query Library and native query execution to be enabled.
  • Plain-text paste across tables now supports two-way many-to-many links. Pasted titles match existing records in the linked table, and reciprocal links are updated without creating duplicates.
  • Table members can now see whether search acceleration is active, which fields it covers, and when its status changes. Shared views show availability only for fields visible in the view.

Bug Fixes & Improvements

  • Updated the OpenAI plugin package to version 1.0.1 and shortened AI instructions so they are no longer cut off in Claude Code.
  • Improved v2 computed-field reliability while reducing unnecessary database load.
  • Improved resource restore and deletion reliability, including a fix for restored v2 tables that could remain listed in the trash.
  • Row prefilling now keeps permitted values and skips only new select options the editor cannot create. If the paste contains only a restricted option, it still returns a permission error.
  • Fixed failures when fields were created concurrently on the same table or while a long-running operation was in progress. New fields now reliably appear in the field list and default view.
  • Cuppy now explains when a task stops because it runs out of memory. Completed steps remain visible, and web users can resume from the latest reply without starting over.
  • Fixed filtered lookups and rollups so deleting linked records recalculates only the affected parent records. Deletion is also faster for large linked datasets.
  • Improved Base share security so visitors can access only content within the configured share scope.
  • Fixed errors in Dashboard charts that use table data. Chart totals now reflect the data each viewer has permission to read, including row-level restrictions.
  • Improved V2 API performance for batch updates across multiple linked-record fields while preserving link order and keeping reciprocal links in sync.
