#claude-mem v15.3.0

O que mudou

Resultados no cartão Meu Trabalho (#5109)

Peça a um agente uma apresentação, um relatório, uma página HTML ou qualquer outro arquivo, e ele estará a um click de distância na frente do cartão da solicitação em Meu Trabalho, em Entregas.

  • O gancho Stop copia o que a curva fez para você em ~/.claude-mem/deliverables/<project>/, endereçado ao conteúdo (report-3f9a1c2b.md), para que a cópia sobreviva à árvore de trabalho, pasta de rascunho ou diretório temporário em que foi feita. Arquivos que um agente anexa por meio de work_state_write (work_product, deliverable ou qualquer campo que nomeie um arquivo que uma pessoa abre) contam, assim como decks, documentos, páginas, imagens, vídeos e planilhas escritas fora da árvore de origem. Os arquivos de origem nunca são copiados por inferência. SubagentStop captura o que um subagente fez a partir de sua própria transcrição.
  • O trabalhador registra e entrega cada cópia em GET /api/deliverables/:id/:filename, com as mesmas regras de loopback, mesma origem e sandbox dos arquivos gravados; markdown e texto aberto embutido. Embora uma cópia esteja no disco e o arquivo não tenha sido gravado desde então, ela representa o registro de onde o arquivo foi feito.
  • Privacidade e limites são explícitos. Um turno cujo prompt é inteiramente <private> não deixa cópia nem registro. Nada é copiado para um trabalhador em outro host, que não conseguiu abrir a cópia. 50 arquivos por Stop e 512 MiB por arquivo, relatados quando atingidos, nunca silenciosos. CLAUDE_MEM_DELIVERABLES_ENABLED=false desativa a cópia.
  • A regra de estado de trabalho SessionStart agora pede aos agentes que escrevam o que você pediu como um arquivo e anexem-no como work_product antes de terminarem.

Também novo

  • Snapshots automáticos de banco de dados locais com restauração segura contra falhas: npx claude-mem backup [run|status|list] e npx claude-mem restore. Desativado por padrão; CLAUDE_MEM_BACKUP_ENABLED=true com CLAUDE_MEM_BACKUP_INTERVAL_HOURS e CLAUDE_MEM_BACKUP_RETAIN_COUNT. (#3751)
  • Exportação do Notion. Cada nova observação é inserida em um banco de dados do Notion assim que é armazenada. Opt-in através de CLAUDE_MEM_NOTION_ENABLED, um token e um id de banco de dados; nunca bloqueia a captura. (#4799)
  • Os subagentes do Codex iniciam com a linha do tempo da memória. Um novo gancho SubagentStart fornece a um novo subagente o mesmo contexto que SessionStart fornece a uma sessão; forks, que herdam o histórico de seus pais, são ignorados. Codex pede uma vez para trust o novo gancho. (#4760)
  • Predefinição Runcrate para o provedor compatível com openai. (#5067)

Correções

  • Antigravidade CLI: claude-mem não registra mais PreToolUse, que aprovava automaticamente cada chamada de ferramenta agy e enfileirava cada chamada duas vezes (#5085). Os prompts agy agora são registrados uma vez por turno, então o trabalho agy aparece em Meu Trabalho e os arquivos lidos em agy obtêm seu histórico de observação (#5092).
  • Edição: as credenciais temporárias da AWS são redigidas por completo: IDs de chave de acesso ASIA, tokens de sessão e SecretAccessKey na saída aws sts JSON (#5066, #5073, #5080).
  • Transcrições: os pontos de verificação do inspetor são mantidos até que o trabalho em buffer seja armazenado (#5072); o caminho de configuração transcript-watch segue CLAUDE_MEM_DATA_DIR (#5070).
  • Analisador de observador: lê o tipo em que o modelo se estabeleceu, nunca marca em torno dele (#5077).
  • Windows: o inicializador compila através do caminho curto 8.3 quando bun.exe está em um caminho não-ASCII (#5089).
  • SessionStart a visualização do terminal deixa espaço para o rodapé (#5084); a ajuda de instalação diz quais provedores precisam de um login cmem.ai (#5086).
  • Ferramentas de lançamento: cada manifesto de plug-in enviado carrega a mesma versão, sincronizada pela compilação e verificada no CI (#5083, #5082, #5075). Changelog completo: https://github.com/thedotmack/claude-mem/compare/v15.2.1...v15.3.0

claude-mem v15.3.0

What changed

Deliverables on the My Work card (#5109)

Ask an agent for a deck, a report, an HTML page or any other file, and it is one click away on the front of the request's card in My Work, under Deliverables.

  • The Stop hook copies what the turn made for you into ~/.claude-mem/deliverables/<project>/, content-addressed (report-3f9a1c2b.md), so the copy outlives the worktree, scratch folder or temp directory it was made in. Files an agent attaches through work_state_write (work_product, deliverable, or any field naming a file a person opens) count, as do decks, documents, pages, images, video and spreadsheets written outside the source tree. Source files are never copied by inference. SubagentStop captures what a subagent made from its own transcript.
  • The worker records and serves each copy at GET /api/deliverables/:id/:filename, with the same loopback, same-origin and sandbox rules as recorded files; markdown and text open inline. While a copy is on disk and the file has not been written since, it stands in for the record of where the file was made.
  • Privacy and limits are explicit. A turn whose prompt is entirely <private> leaves no copy and no record. Nothing is copied for a worker on another host, which could not open the copy. 50 files per Stop and 512 MiB per file, reported when hit, never silent. CLAUDE_MEM_DELIVERABLES_ENABLED=false turns the copy off.
  • The SessionStart work-state rule now asks agents to write the thing you asked for as a file and attach it as work_product before they finish.

Also new

  • Automatic local database snapshots with crash-safe restore: npx claude-mem backup [run|status|list] and npx claude-mem restore. Off by default; CLAUDE_MEM_BACKUP_ENABLED=true with CLAUDE_MEM_BACKUP_INTERVAL_HOURS and CLAUDE_MEM_BACKUP_RETAIN_COUNT. (#3751)
  • Notion export. Each new observation is upserted into a Notion database as soon as it is stored. Opt-in through CLAUDE_MEM_NOTION_ENABLED, a token and a database id; never blocks capture. (#4799)
  • Codex subagents start with the memory timeline. A new SubagentStart hook gives a fresh subagent the same context SessionStart gives a session; forks, which inherit their parent's history, are skipped. Codex asks once to trust the new hook. (#4760)
  • Runcrate preset for the openai-compatible provider. (#5067)

Fixes

  • Antigravity CLI: claude-mem no longer registers PreToolUse, which auto-approved every agy tool call and queued each call twice (#5085). agy prompts are now recorded once per turn, so agy work shows up in My Work, and files read in agy get their observation history (#5092).
  • Redaction: temporary AWS credentials are redacted in full: ASIA access key IDs, session tokens, and the SecretAccessKey in aws sts JSON output (#5066, #5073, #5080).
  • Transcripts: watcher checkpoints are held until buffered work is stored (#5072); the transcript-watch config path follows CLAUDE_MEM_DATA_DIR (#5070).
  • Observer parser: reads the type the model settled on, never markup around it (#5077).
  • Windows: the launcher compiles through the 8.3 short path when bun.exe is on a non-ASCII path (#5089).
  • SessionStart terminal preview leaves room for its footer (#5084); install help says which providers need a cmem.ai sign-in (#5086).
  • Release tooling: every shipped plugin manifest carries the same version, synced by the build and checked in CI (#5083, #5082, #5075).
