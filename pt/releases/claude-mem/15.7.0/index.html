#claude-mem v15.7.0

Meu trabalho: a atualização permanece no seu agente e um botão de feedback (#5190)

Quando a atualização automática do My Work obteve uma resposta de Claude Code que Claude-mem recusou (na maioria das vezes uma revisão com mais de 1.200 caracteres), toda a atualização passou para o próximo agente logado. Em máquinas com Codex instalado, isso significava que o codex exec --ephemeral oculto era executado na conta ChatGPT do proprietário, mesmo com CLAUDE_MEM_PROVIDER=claude (#5189: cerca de 230 execuções em quatro dias).

  • Uma resposta recusada agora encerra a atualização do agente que a deu. A próxima execução agendada tenta o mesmo agente novamente, com a espera de falha existente. Um agente que não consegue executar (não conectado, travou) ainda passa a execução para o próximo.
  • Botão Feedback no cabeçalho Meu Trabalho, próximo à Estrela. Ele abre um pequeno formulário de problema "Comentários sobre meu trabalho".

O anotador sempre usa o Haiku mais recente (#5195)

O modelo padrão do anotador agora é o alias de haiku de Claude Code, que sempre resolve para o Haiku mais recente, em vez de um ID Haiku 4.5 fixado. As configurações salvas que ainda carregam o ID fixado enviado são movidas para o alias na atualização. Um modelo que você mesmo digitou é deixado sozinho. O CLAUDE.md do repositório agora declara isso como política: nunca fixe um ID de modelo datado como padrão.

Meu Trabalho e o trabalhador

  • As reconstruções em segundo plano orientadas por atividades de Meu Trabalho são unidas, portanto, uma página Meu Trabalho aberta não é mais reconstruída a cada confirmação do banco de dados (#5133, mitiga #5124).
  • Work View espera que o banco de dados termine de iniciar antes de compilar (#5157).
  • O status de processamento do visualizador é reconciliado após uma lacuna na transmissão (#5139).
  • Os logs diários de trabalho anteriores a CLAUDE_MEM_LOG_RETENTION_DAYS (padrão 30, 0 mantém para sempre) são removidos. Os arquivos de hoje e de ontem são sempre mantidos (#5186).

Projetos

  • Ambientes nomeados dentro de um repositório Git pai podem declarar herança explícita, de forma que a memória pai não relacionada não vaze mais em seu contexto (#5022).
  • Oh My Pi mantém a memória transitória do projeto no contexto do modelo (#5183).
  • Claude Duet: captura e recordação (#5188).

Mídia (desativado por padrão)

  • Primeira fase de observações com reconhecimento de imagem: contratos de mídia limitados e um conversor preguiçoso Sharp 0.35.5 com limites de tamanho, pixel e prazo. CLAUDE_MEM_MEDIA_CAPTURE_ENABLED e CLAUDE_MEM_MEDIA_INFERENCE_ENABLED são padronizados como falso (#4341).

Segurança

  • A descoberta do executável nunca procura no diretório atual (#5148).
  • Os URLs do instalador são https e o Bun é executado em um diretório controlado pelo proprietário (#5149).
  • O trabalhador rejeita gravações de navegador de origem cruzada em terminais de sessão e em POST /api/memory/ingest (#5162, #5161).
  • As chaves Postgres API são armazenadas como hashes de criptografia salgados (#5160) e cada modo SSL do Postgres é respeitado (#5152).
  • As gravações atômicas usam nomes temporários aleatórios de criação exclusiva (#5151).
  • As tags privadas são removidas antes dos limites, e o último turno de Hermes é bloqueado (#5150).
  • A redação agora cobre GitLab, Hugging Face e tokens npm (#5174), senhas em credenciais de URL (#5173) e texto de sincronização de entrada quando a redação local está ativada (#5171).

Correções

  • Hook stdin é enquadrado quando concluído, sem esperar por EOF (#5126).
  • O EPIPE de uma sessão fechada não é mais registrado como fatal (#5177).
  • As recusas do sandbox do Windows Codex são explicadas (#5140).
  • O provedor compatível com OpenAI lê o status HTTP de um envelope de erro 200 com um código textual (#5191).
  • SessionStart conta o bloco de uso de memória em seu orçamento sem TeamBrain (#5181).
  • Um ~ inicial em CLAUDE_MEM_DATA_DIR é expandido (#5179).
  • Log tails lê apenas linhas completas (#5166).
  • O fallback filtrado do Chroma se restringe aos IDs de linha do SQLite (#5154). changelog completo: https://github.com/thedotmack/claude-mem/compare/v15.6.0...v15.7.0

claude-mem v15.7.0

My Work: refresh stays on your agent, and a Feedback button (#5190)

When My Work's automatic refresh got an answer from Claude Code that claude-mem refused (most often a review over 1,200 characters), the whole refresh moved on to the next logged-in agent. On machines with Codex installed, that meant hidden codex exec --ephemeral runs on the owner's ChatGPT account, even with CLAUDE_MEM_PROVIDER=claude (#5189: about 230 runs in four days).

  • A refused answer now ends that refresh on the agent that gave it. The next scheduled run tries the same agent again, with the existing failure backoff. An agent that can't run at all (not signed in, crashed) still hands the run to the next one.
  • Feedback button in the My Work header, next to Star. It opens a short "My Work feedback" issue form.

Note-taker always uses the newest Haiku (#5195)

The note-taker's default model is now Claude Code's haiku alias, which always resolves to the newest Haiku, instead of a pinned Haiku 4.5 ID. Saved settings that still carry the shipped pinned ID move to the alias on upgrade. A model you typed yourself is left alone. The repo's CLAUDE.md now states this as policy: never pin a dated model ID as a default.

My Work and the worker

  • Activity-driven background rebuilds of My Work are coalesced, so an open My Work page no longer rebuilds on every database commit (#5133, mitigates #5124).
  • Work View waits for the database to finish starting before it builds (#5157).
  • The viewer's processing status reconciles after a stream gap (#5139).
  • Daily worker logs older than CLAUDE_MEM_LOG_RETENTION_DAYS (default 30, 0 keeps forever) are pruned. Today's and yesterday's files are always kept (#5186).

Projects

  • Named environments inside a parent Git repository can declare explicit inheritance, so unrelated parent memory no longer leaks into their context (#5022).
  • Oh My Pi keeps transient project memory in model context (#5183).
  • Claude Duet: capture and recall (#5188).

Media (off by default)

  • First phase of image-aware observations: bounded media contracts and a lazy Sharp 0.35.5 converter with size, pixel and deadline limits. CLAUDE_MEM_MEDIA_CAPTURE_ENABLED and CLAUDE_MEM_MEDIA_INFERENCE_ENABLED both default to false (#4341).

Security

  • Executable discovery never looks in the current directory (#5148).
  • Installer URLs are https, and Bun runs from an owner-controlled directory (#5149).
  • The worker rejects cross-origin browser writes to session endpoints and to POST /api/memory/ingest (#5162, #5161).
  • Postgres API keys are stored as salted scrypt hashes (#5160), and every Postgres sslmode is honored (#5152).
  • Atomic writes use exclusive-create random temp names (#5151).
  • Private tags are stripped before caps, and Hermes' last turn is gated (#5150).
  • Redaction now covers GitLab, Hugging Face and npm tokens (#5174), passwords in URL credentials (#5173), and inbound sync text when local redaction is on (#5171).

Fixes

  • Hook stdin is framed when complete, without waiting for EOF (#5126).
  • A closed session's EPIPE is no longer logged as fatal (#5177).
  • Windows Codex sandbox refusals are explained (#5140).
  • The OpenAI-compatible provider reads the HTTP status from a 200 error envelope with a textual code (#5191).
  • SessionStart counts the memory-use block in its budget without TeamBrain (#5181).
  • A leading ~ in CLAUDE_MEM_DATA_DIR is expanded (#5179).
  • Log tails read only complete lines (#5166).
  • The filtered Chroma fallback narrows to SQLite row ids (#5154).

Full changelog: https://github.com/thedotmack/claude-mem/compare/v15.6.0...v15.7.0
