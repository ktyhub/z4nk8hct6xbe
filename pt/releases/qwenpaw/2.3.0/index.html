#QwenPaw v2.3.0

O que mudou

✨ Adicionado

Modelos de decisão local Piccolo

  • Adicione Piccolo 4B, 9B e 27B como modelos de decisão locais para revisão de ferramentas e compactação de contexto, com recomendações BF16 e Q8_0, instalação e atualizações em tempo de execução e downloads de Hugging Face ou ModelScope. A revisão e a compactação permanecem opcionais; o tempo de execução local atende um modelo por vez (#8463, #8573)

Comunidade QwenPaw

  • Navegue, classifique e comente as postagens da comunidade QwenPaw no console, elabore relatórios de problemas vinculados a recursos com assistência de modelo e abra o editor da comunidade. Conecte uma conta para sincronizar categorias de mensagens selecionadas com a caixa de entrada e notificações na área de trabalho (#7903)

Console e área de trabalho

  • Adicione o plug-in OpenUI opcional para exibir formulários e componentes interativos nas respostas, preservar seu estado durante o streaming e enviar ações para a conversa de origem (#8239, #8248)
  • Adicione um filtro somente não lido às mensagens push da Caixa de entrada para que as mensagens não lidas mais antigas sejam mais fáceis de encontrar (#8484)
  • Permitir que as janelas da área de trabalho compartilhem um serviço em segundo plano, mantenham as tarefas em execução após fechar a última janela e coordenem as atualizações nas janelas; preservar rascunhos não enviados quando o serviço se reconectar (#8373)
  • Receba notificações do navegador e da área de trabalho para aprovações, respostas concluídas e tarefas em segundo plano, inclusive quando a área de trabalho é minimizada na bandeja; cli receba uma notificação para retornar à conversa ou aprovação relevante (#8504)

Modos de Agente

  • Adicionar modo Advisor: emparelhe um modelo Advisor com um modelo Worker, prepare um plano de abertura, consulte o Advisor quando necessário e ajuste o plano após falhas repetidas da ferramenta (#7569)
  • Adicione o modo de código experimental Python para combinar ferramentas habilitadas em um script, incluindo chamadas simultâneas e saída ordenada de texto e mídia. As permissões da ferramenta nativa ainda se aplicam; O modo de código não ativa o sandbox, que está desativado por padrão (#8224)
  • Selecione um modo de Agente inicial para novas sessões ACP com qwenpaw acp --agent-mode (#8352)
  • Opcionalmente, use um modelo de decisão para verificar evidências de conversas e ferramentas para trabalhos inacabados durante autoverificações de conclusão; retenha a autoverificação original quando o modelo estiver indisponível ou incerto. Esta opção está desativada por padrão (#8544)

Memória

  • Atualize o ReMe para 0.4.2.0 com memória de imagem, tags automáticas, pesquisa filtrada por tags e compactação de contexto de modelo de decisão que retém referências à saída original da ferramenta. A memória de imagem, a marcação automática e a compactação de decisão estão desativadas por padrão; Auto-Dream agora se concentra na consolidação de memória (#8347)
  • Navegue pelos arquivos de memória ReMe Light por meio de tags clickable e uma guia Tags, com contagens de arquivos, paginação e edições não salvas preservadas ao abrir o mesmo arquivo em visualizações diferentes (#8470)
  • Adicione um plugin de memória OpenViking com recuperação automática, persistência de volta completa e pesquisa de memória explícita por meio de um serviço OpenViking configurado (#7613)

Modelos e Aprovações

  • Faça login com uma assinatura ChatGPT em instalação local e selecione os modelos disponíveis para a conta sem chave da Plataforma API; suporte para troca e saída de conta. O login remoto e de hub não é compatível (#8437)
  • Configure modelos de decisão TypeSafe/JEV separadamente dos modelos de chat e use-os para aprovações de ferramentas. As negações explícitas permanecem aplicadas; avaliações incertas ou falhas de serviço exigem aprovação manual (#8205, #8283, #8360)

Criador e dados QwenPaw

  • Atualize o Creator para 2.0.4 com gerenciamento de habilidades personalizado, importação direta de script, prevenção de sobreposição de narração e limpeza de arquivos temporários. Melhore o manuseio de mídia local entre provedores, verifique os testes de conexão ASR com mais precisão e mantenha as credenciais salvas nos destinos de teste configurados (#8357, #8529)
  • Atualize o aplicativo Data para 1.0.3 com o tempo de execução 0.3.3: herde o modelo do espaço de trabalho, retenha as seleções do conjunto de dados por chat e mantenha os fluxos de análise abertos até a conclusão. O manifesto do aplicativo publicado ainda tem como alvo QwenPaw 2.2.2 e não declara compatibilidade com 2.3.0; sessões mais antigas sem escopo permanecem no disco, mas não aparecem automaticamente na nova listagem (9af3b184, #8346)

QwenPaw v2.3.0

Highlights

  • Legacy workspace backup APIs removed (breaking) — PR #8508 deletes the workspace ZIP upload/download endpoints because they could overwrite active history databases. Any backup automation scripted against those endpoints must move to Backup & Restore; ordinary file transfers and project ZIP imports are unaffected, so this only bites teams that wired the old APIs into their tooling.
  • Bring-your-own decision models for review and approvals — Piccolo 4B/9B/27B arrive as local decision models (BF16 or Q8_0, fetched from Hugging Face or ModelScope, with only one model served at a time) for tool review and context compaction (#8463, #8573). TypeSafe/JEV decision models can now be configured separately from chat models and used for approvals (#8205, #8283, #8360), with review triggerable directly from the approval menu (#8556): explicit denials are always enforced, while uncertain verdicts or service failures fall back to manual approval, so automated review can't silently green-light a risky call. Decision-model completion self-checks are opt-in (#8544).
  • New Agent modes — and a sandbox caveat — Advisor Mode pairs an advisor model with a worker, drafts an opening plan, and re-plans after repeated tool failures (#7569). Experimental Python Code Mode (#8224) combines enabled tools into a single script with concurrent calls and ordered text/media output, but it does not enable the sandbox (off by default) and native tool permissions still apply — don't assume code runs in isolation. qwenpaw acp --agent-mode lets you set the initial mode for new ACP sessions (#8352).
  • Plugins and channels stop forcing workspace rebuilds — Installing, updating, or removing plugins no longer rebuilds every active workspace, with clean resource shutdown and rollback on failed upgrades (#7565, #8598). Official channels other than Console are now managed as plugins, launched in separate processes only when enabled while preserving existing configs (#8187). Note the new installer floor for update/plugin-install paths: pip 26.2.2+ or uv 0.13.4+ (#8391) — upgrade your tooling before the app.
  • Memory stack gets a substantive upgrade — ReMe 0.4.2.0 adds image memory, automatic tagging, tag-filtered search, and decision-model compaction that preserves references to original tool output (#8347), joined by a Tags tab for ReMe Light files (#8470) and an OpenViking plugin with automatic recall and completed-turn persistence (#7613). The new ReMe behaviors (image memory, auto-tagging, decision compaction) are all off by default, so existing agents keep their current memory semantics until you opt in; Auto-Dream now focuses on consolidation.
  • Defaults and auth shift — check before upgrading — With no saved provider, web search now defaults to AnySearch, though explicit choices are retained (#8536). Local installs can sign in with a ChatGPT subscription and use its models without a Platform API key, with account switching and sign-out, but remote and Hub sign-in are not supported (#8437). Watch the Data app: its published manifest still targets QwenPaw 2.2.2 and does not declare 2.3.0 compatibility, and older unscoped sessions remain on disk but won't surface automatically in the new listing (#8346).

What's Changed

✨ Added

Piccolo Local Decision Models

  • Add Piccolo 4B, 9B, and 27B as local decision models for tool review and context compaction, with BF16 and Q8_0 recommendations, runtime installation and updates, and Hugging Face or ModelScope downloads. Review and compaction remain opt-in; the local runtime serves one model at a time (#8463, #8573)

QwenPaw Community

  • Browse, sort, and comment on QwenPaw Community posts from the Console, draft resource-linked issue reports with model assistance, and open the community editor. Connect an account to sync selected message categories to the Inbox and desktop notifications (#7903)

Console & Desktop

  • Add the optional OpenUI plugin to display interactive forms and components within replies, preserve their state during streaming, and submit actions to the originating conversation (#8239, #8248)
  • Add an unread-only filter to Inbox push messages so older unread messages are easier to find (#8484)
  • Let desktop windows share one background service, keep tasks running after closing the last window, and coordinate updates across windows; preserve unsent drafts when the service reconnects (#8373)
  • Receive browser and desktop notifications for approvals, completed replies, and background tasks, including when the desktop is minimized to the tray; click a notification to return to the relevant conversation or approval (#8504)

Agent Modes

  • Add Advisor Mode: pair an advisor model with a worker model, prepare an opening plan, consult the advisor when needed, and adjust the plan after repeated tool failures (#7569)
  • Add experimental Python Code Mode to combine enabled tools in one script, including concurrent calls and ordered text and media output. Native tool permissions still apply; Code Mode does not enable the sandbox, which is off by default (#8224)
  • Select an initial Agent mode for new ACP sessions with qwenpaw acp --agent-mode (#8352)
  • Optionally use a decision model to check conversation and tool evidence for unfinished work during completion self-checks; retain the original self-check when the model is unavailable or uncertain. This option is off by default (#8544)

Memory

  • Upgrade ReMe to 0.4.2.0 with image memory, automatic tags, tag-filtered search, and decision-model context compaction that retains references to original tool output.
