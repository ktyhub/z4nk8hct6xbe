QwenPaw v2.0.0.post3

Highlights

  • MCP migration made idempotent — Legacy MCP config migration is now one-shot via a schema watermark (#6133), ${VAR} headers are converted to environment credential references during driver migration (#6091), and fallback tool-name namespaces are sanitized to meet OpenAI naming constraints (#6209); connection timeouts also no longer wedge workspace startup (#6174). If you're upgrading a 1.x config, expect a single migration pass and credentials moved into env refs — verify env wiring after first boot.
  • Auto memory becomes opt-down, not always-on — auto_memory_interval now accepts 0 to fully disable automatic memory and is validated as an int >= 0 with empty values rejected (#6135, #6142). Memory writes are also restricted to external user queries, so agent-originated/internal turns stop producing memories (#6120), joined by a dream-schedule toggle (#6171), ReMe indexing safeguards (#6153), and bounded summary task history (#6206). Watch the behavioral shift: internal tool loops no longer write memory unless triggered by a real user message.
  • Per-request model selection lands — model_slot_override now flows from the HTTP request into the model factory (#6218, completing #5731), letting API callers pick a model slot per request instead of mutating global config. Together with the agentscope bump to 2.0.4.post1 (#6179), this is the release's main new capability for programmatic consumers.
  • Multimodal stops silently dropping images — Image stripping on failed model-info lookups or wrong builtin annotations is fixed (#6154), unprobed multimodal models now fail open instead of dropping images (#6217), and file:// URIs in DataBlock are resolved to local paths before formatting (#6191). If attachments vanished intermittently, this should clear it up.
  • Context, lifecycle, and desktop stability — Recoverable tool-result compaction and context-limit guards (#6123), a new history_retention_days compaction control (#6214), retuned doom-loop thresholds (#6184), and bounded multi-agent startup with better readiness UX (#6198); memory leaks are plugged in channels (#6168), skill-hub (#6208), and the shutdown token cache (#6220). Streaming deltas now preserve whitespace (#6166), WKWebView no longer pins a stale console frontend (#6107), and Tauri updates stay OSS-only (#6071). Note: the channel base refactor (#6159) is the one spot where custom channel implementations may need a look.
  • Compatibility — No breaking changes in this patch release.
