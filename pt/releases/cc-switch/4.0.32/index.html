Chave CC v4.0.32

Esta versão adiciona Baixar atualizações automaticamente em segundo plano: Após ativar "Baixar atualizações automaticamente" em "Configurações → Sobre", a nova versão será baixada e verificada em segundo plano. Um prompt aparecerá no canto inferior direito perguntando se você deseja instalá-lo. Ele não será reiniciado sem confirmação. "Configurações → Rede" adicionou detecção de IP, que permite visualizar o IP de saída e a região quando o CC Switch é acessado através de um proxy global, um proxy temporário ou a rede atual. Além disso, corrigimos problemas como quando o Codex continua uma sessão antiga através de provedores de roteamento e comutação, o upstream primeiro retorna 200 e depois relata "Incapaz de descriptografar", fazendo com que toda a rodada seja descartada; As solicitações do Codex reportam 422 ao se conectar ao Mistral AI por meio de roteamento ou agregação; após uma operação dentro do CC Switch travar, a bandeja fica vazia e o provedor não pode ser trocado até ser reiniciado; as ferramentas instaladas com mise exibem dois registros de instalação na página "Aplicativo". Adicionar

Baixar atualizações automaticamente em segundo plano

"Configurações → Sobre" adiciona a opção "Baixar atualizações automaticamente", que está desativada por padrão e pode ser definida individualmente para cada dispositivo.

  • Depois de ligado, o CC Switch irá verificá-lo um minuto após ser iniciado e, a seguir, a cada seis horas. Se houver uma nova versão, ela será baixada e verificada em segundo plano.
  • Após o download, será perguntado se deseja instalá-lo no canto inferior direito da interface principal. A instalação reiniciará o CC Switch, e as solicitações que passarem pelo roteamento local serão interrompidas, portanto você deve clicar em “Instalar e Reiniciar” para prosseguir; isso será indicado no prompt quando o roteamento estiver ativado.
  • Clicar em "Mais tarde" não solicitará mais esta versão. O ponto vermelho nas configurações, o botão na página “Sobre” e o novo “Reiniciar e atualizar para vX” no menu da bandeja e no painel de atalhos ainda podem ser instalados.
  • O pacote de instalação deb/rpm da versão portátil e Linux não pode ser instalado automaticamente. A opção ficará esmaecida e o motivo será explicado.

Detecção de IP

"Configurações → Rede" adiciona uma detecção de IP no proxy global (#9449, consulte #9448 para obter os requisitos): Selecione o proxy global salvo ou preencha um proxy temporário (usado apenas para esta detecção, não salvo). Após clicar em “Detectar IP”, serão exibidos o IP de saída, se os resultados dos dois serviços de detecção são consistentes e informações como país ou região, cidade, operadora, etc. Quando não há proxy global, o proxy do sistema ou conexão direta é usado para detecção; quando um proxy é especificado, a conexão direta não será usada se o proxy não puder se conectar.

  • Só execute após clicar, ele visitará icanhazip.com, ipify.org, e enviará o IP medido para ipwho.is para consultar a localização.
  • O que se mede é a saída do próprio CC Switch por esta linha, que não necessariamente é igual à saída de clientes como Claude Code e Codex.

Outros

  • O cartão de fornecedor reverso do GitHub Copilot exibe a conta GitHub vinculada (#9228, para requisitos, consulte #9480): Anteriormente, apenas o endereço do site oficial do GitHub Copilot era exibido e era difícil distinguir entre várias contas. Se não estiver vinculado, a conta padrão da central de autorização será exibida. Quando a observação é preenchida, a observação tem prioridade.

Correção

  • Quando o Codex continua a sessão antiga através do provedor de comutação, o upstream primeiro retorna 200 e depois relata "O conteúdo da saída da função criptografada não pôde ser descriptografado ou decodificado". Depois que o Codex se reconecta cinco vezes, esta rodada é descartada (#9476): Quando a solicitação contém o registro de pensamento ou conteúdo criptografado gerado pelo provedor anterior, o CC Switch aguardará o upstream iniciar a saída antes de entregá-lo. O Codex, caso seja rejeitado neste momento, remova esse conteúdo e tente novamente automaticamente na mesma empresa, e a sessão poderá continuar. Solicitações sem esse conteúdo serão transmitidas normalmente.
  • Quando o Codex é conectado ao Mistral AI via roteamento ou agregação, a solicitação reporta 422 extra_forbidden (#9507): O campo especial Responses transportado pelo Codex, os parâmetros de pensamento adicionados automaticamente para o modelo DeepSeek / GLM no Mistral, e o reasoning_content carregado em cada rodada após o uso da ferramenta será removido quando enviado para api.mistral.ai. Outros upstreams não são afetados.
  • Após uma operação interna do CC Switch travar uma vez, o menu da bandeja fica vazio, o fornecedor não pode ser trocado e a conexão direta não pode ser restaurada ao sair. Ele só pode ser reiniciado (#9472, #9483, consulte #8058): Banco de dados, configurações, gravação de arquivo de configuração, MCP, palavras de prompt, preços, backup e outras operações agora podem ser restaurados após uma falha, e alterações inacabadas no momento da falha serão revertidas.
  • Ao usar Claude Code/Claude Desktop via GitHub Copilot, modelos como Grok que suportam apenas a interface Responses no Copilot relataram "não acessível através do endpoint /chat/completions" (#6954, #9473): Este tipo de modelo agora está usando a interface Responses, e os modelos suportados por ambas as interfaces permanecem inalterados.
  • Quando Antigravity seleciona Orchestrator, todo o uso é registrado sob o nome de um modelo virtual e o custo é 0 (#9493, #9494): Agora o preço é baseado no modelo real usado em cada etapa, e o preço do Gemini 4 Hydrogen é adicionado. O histórico de antigravidade importado será analisado novamente e o custo será compensado.
  • Após ativar o "Histórico de sessão do Codex unificado" ou migrar o histórico, as sessões de alguns meses atrás são classificadas em primeiro lugar no codex resume (#3866, #9471): Ao reescrever arquivos de sessão .jsonl comuns, o tempo de modificação original será retido e os arquivos compactados serão retidos. O horário de modificação modificado não será restaurado.
  • Para fornecedores excluídos no Hermes, o botão excluir no CC Switch fica sempre cinza (#4816, #9470): Fornecedores que não existem mais no Hermes agora podem ser editados e excluídos; eles ainda estão bloqueados quando a configuração do Hermes não pode ser lida.
  • Ao adicionar um fornecedor OpenClaw a partir de um preset, /model lista os modelos que vêm com o preset, e não o último salvo no formulário (#9474, veja #6729): Os modelos excluídos no formulário não reaparecerão e os modelos recém-adicionados também poderão ser selecionados; ao salvar diretamente sem alterar o preset, todos os modelos preset serão registrados. A edição de um fornecedor existente ainda não é sincronizada, o número 6729 ainda está sendo seguido.
  • Ferramentas instaladas com o mise, a página "Aplicativo" exibe dois registros de instalação (um deles é marcado como homebrew quando o mise é instalado com o Homebrew) (#9515): o shim do mise agora conta como a instalação para a qual ele realmente aponta.
  • Quando a janela é curta, o botão de confirmação da caixa de diálogo "Abrir Terminal" é espremido para fora da tela e não pode ser clicado (#9478): O conteúdo da caixa de diálogo pode ser rolado de forma independente e o botão é fixado na parte inferior; você também pode abrir diretamente o terminal pressionando Enter na caixa de entrada "Parâmetros adicionais (opcional)".
  • O status da taxa de câmbio na página de uso está faltando um ponto e está conectado com a seguinte descrição (#9436).

Agradecimentos

cc-switch v4.0.32

Highlights

  • Automatic update downloads, manual installation — Enable the opt-in setting to check one minute after launch, then every six hours; updates are downloaded and verified in the background. Installation still requires confirmation and restarts CC Switch, interrupting requests through its local router. Portable and Linux deb/rpm builds cannot auto-install. “Later” suppresses the prompt for that version without removing the other update entry points.
  • Proxy-aware IP diagnostics (#9449) — Check the exit IP and geolocation for a saved global proxy or an unsaved temporary proxy. Results show agreement between two IP services, and a failed selected proxy does not fall back to direct access. Note that this measures CC Switch’s own route, not necessarily Claude Code’s or Codex’s traffic.
  • Reliable Codex provider routing (#9476, #9507) — If a new provider rejects encrypted content from a previous provider after starting a 200 response, CC Switch strips that content and retries once with the same provider. Requests to Mistral AI also omit Responses-only fields, model-specific thinking parameters, and stale reasoning_content, eliminating 422 extra_forbidden errors.
  • Copilot model compatibility and account visibility (#9473, #9228) — Models such as Grok that Copilot exposes only through Responses are routed to that endpoint instead of failing on /chat/completions. Provider cards now distinguish accounts using the bound GitHub identity or a custom note.
  • Crash recovery and accurate accounting (9472, #9483, #9494) — Database, settings, configuration, MCP, prompt, pricing, and backup operations can recover after an internal crash and roll back incomplete writes, preventing a broken tray and direct-connect state. Antigravity Orchestrator usage is now charged to the model used at each step, and imported history is reparsed to backfill costs.
  • Provider management fixes — Hermes providers deleted externally become editable and removable (#9470); new OpenClaw providers now register the models actually saved in the form (#9474), though editing existing providers still does not sync them. Codex history ordering is also corrected by preserving original .jsonl modification times (#9471).

No breaking changes.

CC Switch v4.0.32

本版本新增后台自动下载更新：在「设置 → 关于」打开「自动下载更新」后，新版本会在后台下载并校验好，右下角弹出提示问你是否安装，不会未经确认就重启。「设置 → 网络」新增 IP 检测，可以查看 CC Switch 经全局代理、临时代理或当前网络访问时的出口 IP 和所在地区。

另外修复了 Codex 经路由换供应商续接旧会话后，上游先回 200 再报「无法解密」导致整轮报废；Codex 经路由或聚合接 Mistral AI 时请求报 422；CC Switch 内部某个操作崩溃一次后，托盘变空、切不了供应商，直到重启；用 mise 装的工具在「应用」页显示两条安装记录等问题。

新增

后台自动下载更新

「设置 → 关于」新增「自动下载更新」开关，默认关闭，每台设备单独设置。

  • 打开后，CC Switch 启动一分钟后检查一次，之后每六小时检查一次，有新版本就在后台下载并校验。
  • 下载好后，主界面右下角会问你是否安装。安装会重启 CC Switch，正在经本地路由的请求会中断，所以一定要你点「安装并重启」才会进行；路由开着时提示里会写明这一点。
  • 点「稍后」只是不再为这个版本弹提示，设置里的红点、「关于」页的按钮，以及托盘菜单和快捷面板里新增的「重启并更新到 vX」仍然可以安装。
  • 便携版和 Linux 的 deb / rpm 安装包不能自动安装，开关会置灰并说明原因。

IP 检测

「设置 → 网络」在全局代理下方新增 IP 检测（#9449，需求见 #9448）：选已保存的全局代理或填一个临时代理（只用于这次检测，不保存），点「检测 IP」后会显示出口 IP、两个检测服务的结果是否一致，以及国家或地区、城市、运营商等信息。没设全局代理时，按系统代理或直连检测；指定了代理时，代理连不上不会改用直连。

  • 只在点击后运行，会访问 icanhazip.com、ipify.org，并把测得的 IP 发给 ipwho.is 查询位置。
  • 测的是 CC Switch 自己经这条线路的出口，不一定等于 Claude Code、Codex 等客户端的出口。

其他

  • GitHub Copilot 反代供应商卡片显示绑定的 GitHub 账号（#9228，需求见 #9480）：以前只显示 GitHub Copilot 的官网地址，多个账号时分不清。没绑定时显示授权中心的默认账号，填了备注时备注优先。

修复

  • Codex 经路由换供应商续接旧会话时，上游先回 200、再报「Encrypted function output content could not be decrypted or decoded」，Codex 重连五次后这一轮报废（#9476）：请求里带着上一家生成的思考记录或加密内容时，CC Switch 会先等上游开始输出再交给 Codex，这时被拒就去掉这些内容后在同一家自动重试一次，会话可以继续。不带这类内容的请求照常直接流式返回。
  • Codex 经路由或聚合接 Mistral AI 时，请求报 422 extra_forbidden（#9507）：Codex 带的 Responses 专用字段、为 Mistral 上的 DeepSeek / GLM 模型自动加的思考参数，以及用过工具之后每轮都带的 reasoning_content，发往 api.mistral.ai 时都会去掉。其他上游不受影响。
  • CC Switch 内部某个操作崩溃一次后，托盘菜单变空、切不了供应商，退出时也恢复不了直连，只能重启（#9472、#9483，见 #8058）：数据库、设置、配置文件写入、MCP、提示词、价格、备份等操作现在都能在崩溃后恢复，崩溃时没写完的改动会回滚。
  • 经 GitHub Copilot 用 Claude Code / Claude Desktop 时，Grok 这类在 Copilot 里只支持 Responses 接口的模型报「not accessible via the /chat/completions endpoint」（#6954、#9473）：这类模型现在改走 Responses 接口，两种接口都支持的模型不变。
  • Antigravity 选 Orchestrator 时，用量全部记在一个虚拟模型名下、费用为 0（#9493、#9494）：现在按每一步实际使用的模型计价，并新增 Gemini 4 Hydrogen 的价格。已导入的 Antigravity 历史会重新解析一次，补上费用。
  • 开启「统一 Codex 会话历史」或迁移历史后，几个月前的会话在 codex resume 里排到了最前面（#3866、#9471）：改写普通 .jsonl 会话文件时会保留原来的修改时间，压缩过的文件本来就会保留。已经被改乱的修改时间不会恢复。
  • 在 Hermes 里删掉的供应商，CC Switch 里删除按钮一直是灰的（#4816、#9470）：Hermes 里已经没有的供应商现在可以编辑和删除；读不到 Hermes 配置时仍然锁定。
  • 从预设新增 OpenClaw 供应商时，/model 里列的是预设自带的模型，不是表单里最后保存的（#9474，见 #6729）：在表单里删掉的模型不会再出现，新加的模型也能选；不改动预设直接保存时，会登记预设的全部模型。编辑已有供应商时还不会同步，#6729 仍在跟进。
  • 用 mise 安装的工具，「应用」页显示两条安装记录（mise 用 Homebrew 安装时其中一条标成 homebrew）（#9515）：mise 的 shim 现在算作它实际指向的那个安装。
  • 窗口较矮时，「打开终端」对话框的确认按钮被挤出屏幕，点不到（#9478）：对话框内容可以单独滚动，按钮固定在底部；在「附加参数（可选）」输入框里按回车也可以直接打开终端。
  • 用量页的汇率状态缺句号，和后面的说明连在一起（#9436）。
