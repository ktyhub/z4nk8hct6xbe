agentscope v2.0.11

Highlights

  • MCP SDK 2.x unlocked — PRs #2216 and #3325 drop the mcp<2.0.0 pin and add tool-progress streaming. This is the headline change for anyone frozen on the 1.x SDK: you can now move to 2.x, but because the constraint was removed rather than bumped, the SDK version resolved in your environment may jump — pin it in your own project if you depend on 1.x behavior, and retest tool-result shapes (#3389 preserves structured MCP results) and progress callbacks after upgrading.
  • OpenAI Chat vs Responses API selection — PR #1937 adds explicit switching between the two endpoints. This matters because Responses uses different tool and streaming semantics, so request shapes, usage accounting, and tool-call handling can change when you flip the option — validate those paths. It pairs with #3242 (correct WAV sizes in the final streamed audio block) and #3488 (latest chat/TTS/realtime configs), a cluster worth adopting together if you're on realtime voice.
  • Per-call overrides now win over defaults, consistently — a cross-cutting behavioral change in #3333 (ASR transcribe options), #3391 (Decisions classifier), #3404 (Gemini output_dimensionality), and #3424 (model override reaching Jev's system_one call). Good for multi-tenant or per-task tuning, but if any of your code assumed global defaults took precedence, that assumption is now wrong — audit those call sites.
  • Batch transcription for ASR — PR #2667 introduces a batch transcription abstraction with an OpenAI-backed model, complementing the per-call overrides above. Relevant if you transcribe corpora offline instead of streaming: this is the new entry point, and note that per-call options can layer on top of model defaults.
  • Cancellation and tool-event correctness — #2768 keeps a pending cancellation from being lost when tools execute concurrently, and #2551 preserves tool data-block identity during event replay. Subtle but important for stateful or replay-resumed agents: interruption and resume paths that previously could drop a cancel or mismatch tool blocks should be retested.
  • Embedding and trust-store fixes with real cost impact — #3265 isolates Ollama embedding caches by host (cross-host collisions could previously return wrong vectors), #2690 reports cache source for fully cached multi-batch merges, #2967 reports the max batch time instead of the sum (so latency/billing metrics were inflated), and #3410 upgrades certifi/pip/uv/node to drop distrusted CAs — watch out that the CA refresh can break TLS to internal registries using private CAs.

No breaking API changes — the only compatibility caveat is the MCP SDK constraint change noted above.
