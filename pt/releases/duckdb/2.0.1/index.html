duckdb v2.0.1

This is a bug fix release for various issues discovered after we released v2.0.0.

Please also refer to the announcement blog post: https://duckdb.org/2026/11/20/announcing-duckdb-201.html

  • Merge Rust extension CI groups by @smvv in https://github.com/duckdb/duckdb/pull/27600
