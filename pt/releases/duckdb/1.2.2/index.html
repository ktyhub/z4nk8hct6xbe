duckdb v1.2.2

Esta é uma versão de correção de bug para vários problemas descobertos após o lançamento do 1.2.1. Não há novos recursos importantes, apenas correções de bugs. Arquivos de banco de dados criados por versões do DuckDB desde v0.9.* podem ser lidos por esta versão.

duckdb v1.2.2

This is a bug fix release for various issues discovered after we released 1.2.1. There are no new major features, just bug fixes. Database files created by DuckDB versions all the way back to v0.9.* can be read by this version.

What's Changed
