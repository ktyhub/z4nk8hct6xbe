#gstack v1.99.1.0 ##gstack v1.99.1.0 Principalmente correções de segurança: gstack-uninstall não exclui mais trabalhos não salvos, sincronização cerebral e o gancho pré-push captura mais segredos ocultos e /review e /ship iniciam novamente no Windows em hosts que não sejam Claude.

Correções

  • /review e /ship iniciam novamente no Windows no Codex, Cursor e outros hosts não Claude, onde a configuração deixou de fora os arquivos necessários, e /retro e /write-skill tinham a mesma lacuna (obrigado @SatriaSuriaAriffin) #4286.
  • gstack-uninstall não exclui mais uma árvore de trabalho aninhada dentro de outro checkout, uma árvore de trabalho bloqueada, uma pasta .gstack/ que é seu próprio repositório git ou uma árvore de trabalho que você edita enquanto pede para continuar #4267.
  • gstack-uninstall agora verifica todas as pastas que está prestes a excluir em busca de trabalho git não confirmado ou não enviado, não apenas o repositório a partir do qual você o executa, e para com o nome da pasta se encontrar algum #4282.
  • Brain Sync agora verifica arquivos que o git trata como binários e captura um valor de autenticação adicionado em uma chave existente, portanto, uma chave em tal arquivo não é mais enviada #4276.
  • A sincronização cerebral agora captura segredos escondidos atrás dos escapes do JSON, e o gancho de pré-confirmação no ~/.gstack verifica os mesmos tipos de segredos que a sincronização faz #4264.
  • A verificação secreta e o gancho pré-push agora capturam uma divisão secreta em duas linhas de texto UTF-16, e a exclusão de um arquivo binário grande não bloqueia mais um push #4261.
  • A edição QM do gstack não inclui mais o gstack-review, após um benchmark descobrir que ele sinalizou muitos problemas sem melhorar o trabalho; O /review do próprio gstack permanece inalterado #4279.

Mudanças para mantenedores

  • Escrituração contábil de revisão de /ship: uma revisão de acompanhamento concedida que começa após um commit somente de documentos agora conta, e a decisão do proprietário pode limpar novos bloqueadores uma revisão de acompanhamento concedida encontrada para que /ship possa terminar com eles listados #4278 #4260.
  • Correções de pré-mesclagem e fila de mesclagem: uma execução de verificação de pré-mesclagem parcial não passa mais como completa, a fila busca o main mais recente antes de verificar um PR, recusa quando sua nota de prontidão nunca atinge GitHub e avisa quando uma execução somente de ramificação esconde uma verificação vermelha #4258 #4256 #4254 #4270.
  • Os resultados de IC reutilizados agora são aceitos quando apenas um trabalho não relacionado na execução foi executado novamente #4274.
  • Correções de teste: os testes de fila de mesclagem, o teste de política médica que falhou em cada nova versão e seis verificações de teste e avaliação que interpretaram mal o trabalho correto ou executaram seus próprios equipamentos #4271 #4293 #4284. Atualização: execute novamente gstack-artifacts-init (ou gstack-brain-restore em uma máquina que você restaurou) para atualizar o gancho de pré-confirmação de sincronização cerebral. Se você executar a edição QM, exclua a pasta sandbox/skills/gstack-review/ e execute qm up. Comparar v1.99.0.0...v1.99.1.0 · changelog completo

gstack v1.99.1.0

gstack v1.99.1.0

Mostly safety fixes: gstack-uninstall no longer deletes unsaved work, brain sync and the pre-push hook catch more hidden secrets, and /review and /ship start again on Windows under non-Claude hosts.

Fixes

  • /review and /ship start again on Windows under Codex, Cursor and the other non-Claude hosts, where setup had left out files they need, and /retro and /write-skill had the same gap (thanks @SatriaSuriaAriffin) #4286.
  • gstack-uninstall no longer deletes a worktree nested inside another checkout, a locked worktree, a .gstack/ folder that is its own git repo, or a worktree you edit while it asks to continue #4267.
  • gstack-uninstall now checks every folder it is about to delete for uncommitted or unpushed git work, not only the repo you run it from, and stops with the folder's name if it finds any #4282.
  • Brain sync now scans files git treats as binary and catches an auth value added under an existing key, so a key in such a file is no longer pushed #4276.
  • Brain sync now catches secrets hidden behind JSON escapes, and the pre-commit hook in ~/.gstack checks the same kinds of secrets the sync does #4264.
  • The secret check and pre-push hook now catch a secret split across two lines of UTF-16 text, and deleting a large binary file no longer blocks a push #4261.
  • The QM edition of gstack no longer includes gstack-review, after a benchmark found it flagged too many problems without improving the work; gstack's own /review is unchanged #4279.

Changes for maintainers

  • /ship review bookkeeping: a granted follow-up review that starts after a docs-only commit now counts, and an owner's ruling can clear new blockers a granted follow-up review found so /ship can finish with them listed #4278 #4260.
  • Pre-merge and merge-queue fixes: a partial pre-merge check run no longer passes as a full one, the queue fetches the latest main before it checks a PR, it refuses when its ready note never reached GitHub, and it warns when a branch-only run hid a red check #4258 #4256 #4254 #4270.
  • Reused CI results are now accepted when only an unrelated job in the run was rerun #4274.
  • Test fixes: the merge-queue tests, the doctor policy test that failed on every new release, and six test and eval checks that misread correct work or raced their own fixtures #4271 #4293 #4284.

Upgrade: rerun gstack-artifacts-init (or gstack-brain-restore on a machine you restored) to refresh the brain-sync pre-commit hook. If you run the QM edition, delete its sandbox/skills/gstack-review/ folder and run qm up.
