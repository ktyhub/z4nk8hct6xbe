Registro de atualização

Esta versão passou por uma transformação profunda em torno da estrutura organizacional e dos níveis de cargos, apoiando estruturas subsidiárias, superiores e subordinados de cargos e configurações de níveis de cargos, otimizando a manutenção do pessoal do departamento e o gerenciamento de cargos principais e de meio período dos usuários, e melhorando a flexibilidade e clareza da gestão organizacional. Ao mesmo tempo, a configuração da página inicial permite uma personalização personalizada multidimensional, o gerenciamento de inquilinos é mais fácil de usar e o conceito do pacote é mais claro.

  • Em termos de arquitetura subjacente, atualize para Spring Boot 3.5.5, Spring Cloud 2025.0.0, Spring Cloud Alibaba 2023.0.3.3, volte para o contêiner Tomcat, otimize a velocidade de inicialização e suporte ao carregamento atrasado. A geração de código suporta configurações de caminho separadas para front-ends e back-ends, e o menu SQL é automaticamente sincronizado com o diretório Flyway para melhorar a eficiência do desenvolvimento.
  • Além disso, esta versão corrige um grande número de problemas importantes em componentes front-end e funções back-end, melhora o suporte a transações distribuídas, atualiza drivers de banco de dados e melhora a estabilidade e o desempenho do sistema. Os aplicativos de IA e as funções da plataforma de baixo código também foram aprimorados, proporcionando aos usuários uma experiência mais suave e inteligente.
  • Lembrete especial: O tronco padrão foi alterado para Spring Boot 3, abraçando totalmente o ecossistema Java 21 e melhorando o desempenho e a segurança do sistema. v3.8.3 será a última versão do Spring Boot 2. Somente a versão Spring Boot 3 será lançada no futuro. A versão Spring Boot 2 não será mais atualizada e mantida. Os usuários são aconselhados a se prepararem para a atualização com antecedência.

JeecgBoot v3.8.3

Highlights

  • Spring Boot 2 end-of-life and Java 21 migration — v3.8.3 is explicitly the last Spring Boot 2 release; the default branch now targets Spring Boot 3 and the Java 21 ecosystem, and Boot 2 will receive no further maintenance. Treat this as a migration deadline: pin to 3.8.3 if you must stay on Boot 2, otherwise start planning the upgrade now. The Boot 3 branch supports JDK 17/21/24.

  • Framework stack jump — Upgrades to Spring Boot 3.5.5, Spring Cloud 2025.0.0, and Spring Cloud Alibaba 2023.0.3.3. Expect compatibility checks for custom starters and cloud integrations, since this is more than a patch bump across the core dependency tree.

  • Tomcat replaces Undertow, lazy-init startup — The embedded server switches back to Tomcat (Undertow is dropped) and lazy-initialization is enabled to cut cold-start time on large projects. Watch for Undertow-specific config that no longer applies, and re-benchmark startup rather than assuming the speedup is automatic.

  • Organization and position model rewrite — Departments gain inline personnel maintenance, positions now support superior/subordinate relationships and job levels with reporting lines, plus primary and part-time assignments. This is breaking for data using the old "职务" (position) feature: it's deprecated in favor of department-level job-level configuration, so audit and migrate existing position data before upgrading.

  • Code generation paths and Flyway integration — The generator can now write frontend and backend to two separately configured paths (Issue #7197), and generated menu SQL lands directly in the starter project's Flyway directory. This streamlines full-stack workflows but changes where generated artifacts appear — update your generator config and migration pipeline accordingly.

  • Distributed transaction and AI fixes — Seata is upgraded to 1.7.0 with starter fixes for distributed transactions not taking effect (Issues #8697, #7038), and dynamic-datasource to 3.5.2. AI apps regain streaming output for advanced orchestration and direct-reply nodes (Issues #8649, #8776) and fix knowledge-base vectorization (#8639) — relevant if your low-code AI features depended on streaming.

升级日志

本次版本围绕组织机构和岗位职级进行了深度改造，支持子公司架构、岗位上下级及职级设置，优化了部门人员维护和用户主兼职岗位管理，提升组织管理的灵活性和清晰度。同时，首页配置实现多维度个性化定制，租户管理更加易用，套餐概念更明确。

  • 底层架构方面，升级至 Spring Boot 3.5.5、Spring Cloud 2025.0.0、Spring Cloud Alibaba 2023.0.3.3，切换回 Tomcat 容器，优化启动速度并支持延迟加载。代码生成支持前后端分开路径配置，菜单 SQL 自动同步至 Flyway 目录，提高开发效率。

  • 特别提示：默认主干切换成了Spring Boot 3，全面拥抱Java 21生态，提升系统性能和安全性。v3.8.3 将是最后一个Spring Boot 2 的版本，后续只发布Spring Boot 3 版本，Spring Boot 2 版本将不再进行升级维护。用户请提前做好升级准备。
