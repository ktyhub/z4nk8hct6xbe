#JecgBoot v3.9.2

Registro de atualização

**v3.9.2 é a atualização de versão mais significativa do JeecgBoot desde o lançamento da rota AI. ** O low code evoluiu novamente e entrou oficialmente na era v2.0 - de "arrastar e soltar" a "uma frase em linguagem natural", com suporte total de Skills, você pode construir um negócio em uma frase, e a configuração manual se torna uma coisa do passado! Low code não é mais apenas “arrastar e soltar para gerar CRUD”. Criar uma tela grande em uma frase, construir a aprovação OA em uma frase e gerar todo o sistema em uma frase tornou-se uma realidade com JeecgBoot! Esta atualização também aprimora de forma abrangente a experiência de desenvolvimento de baixo código, abrangendo otimização sistemática de formulários, gráficos, telas grandes, segurança e desempenho de front-end, abrindo simultaneamente o código-fonte de front-end on-line e adicionando um novo módulo de gráfico on-line.

✨ A “altura” deste lançamento

1. Habilidades: Deixe a IA realmente se tornar sua parceira de desenvolvimento
  • Claude Code Skills se conecta ao low code: geração de código, formulários on-line, relatórios, telas grandes e processos são totalmente integrados ao Claude Skills, sem necessidade de operar manualmente o gerador de código - IA gera código em uma frase, gera todo o sistema em uma frase, cria formulários on-line em uma frase, cria relatórios on-line em uma frase, projeta telas grandes em uma frase, configura dicionários em uma frase, cria menus e completa a autorização, tudo ao seu alcance.
2. Otimização de aplicativos de IA
  • Formulário online de encaixe Chat2BI / Chart2BI: Gere tabelas paginadas, relatórios e configurações de gráficos em uma frase e abra todo o link de análise de dados.
  • Os recursos de orquestração de processos de IA explodem: Com nova leitura e gravação de variáveis, recuperação de memória, variáveis ​​de loop, saída JSON estruturada, associação de lista de palavras imediatas, nó inicial de upload de arquivos, etc., o AiFlow evoluiu para uma plataforma visual completa de orquestração de agentes.
  • Lista de permissões de ferramentas de aplicação de IA + isolamento entre locatários: a abertura de capacidade e o controle de permissão são implementados simultaneamente, e o limite de segurança multilocatário SaaS é firmemente estabelecido.
  • São lançados os suportes AI Assistant Network Search e AI Process Search Engine Node, para que o processo de IA possa não apenas "saber como usar ferramentas", mas também "saber como procurar informações".
  • Atualização Langchain4j 1.12.2: Redefinindo os limites dos recursos do aplicativo Java AI - o assistente de IA não depende mais de interfaces de ajuste cego de palavra de prompt manual e também oferece suporte a metadados de habilidades para selecionar e chamar automaticamente recursos de negócios.
3. Produtividade multimodal de IA (imagem / áudio / vídeo / troca de roupa)
  • IA real gerada Áudio/Vídeo/Imagem, sem mais demonstração
  • A troca de roupas com IA gera fotos e vídeos ao mesmo tempo
  • Modelo de geração de imagens do Google, síntese de fala local e exemplos de imagens mistas estão todos implementados
  • Preenchimento da matriz do modelo: VLLM / Xinference / LMStudio / qwen-vl-ocr / qwen3.5-plus / Tongyi Qianwen / Qianfan
4. Conjunto on-line de três peças (formulário/relatório/gráfico) otimização única
  • O código-fonte do front-end do módulo online é totalmente de código aberto. Na era da IA, os usuários podem expandir-se de forma livre e flexível, e não há limite para o desenvolvimento secundário.
  • Novo módulo gráfico on-line foi adicionado para configurar rapidamente o painel gráfico e fornecer aos usuários mais opções de visualização.
  • Novo tipo de campo LongText e tipo link_table / link_table_field (registros associados um-para-muitos do Vue3, referências de campo entre tabelas)
  • As subtabelas suportam árvores de dicionário de classificação e árvores de dicionário personalizadas, tornando a configuração hierárquica de dados mais flexível
  • Resolvidos muitos anos de problemas persistentes: Atraso na configuração online (QQYUN-14177), Abertura online lenta, posicionamento do campo de tela pequena não é visível e outros pontos problemáticos da experiência foram totalmente reparados
  • Novo documento de especificação de esquema de formulário on-line foi adicionado para estabelecer uma base sólida para que a IA entenda profundamente os metadados on-line.
5. Carregamento total sob demanda, redução de front-end
  • antd / unplugin-icons / Jvxetable / Vxetable / TinyMCE / JEasyCron / codemirror / módulo de chat, todos carregados sob demanda
  • O tamanho e a velocidade de carregamento da primeira tela foram significativamente reduzidos, abrindo caminho para que os assistentes de IA entrem na página comercial online.
6. Reforço de segurança
  • SSRF de pôster de IA (#9579), Travessia de caminho de anexo de IA (#9519), Escrita entre locatários AiragApp (#9462), Acesso não autorizado de token (#9518), RCE #9335 e muitas outras vulnerabilidades de alto risco foram corrigidas de maneira centralizada
  • Verificação abrangente de permissão para MCP/ferramentas sensíveis subjacentes

🎯 O que significa a era v2.0 de baixo código?

As habilidades permitem que formulários, processos, relatórios e telas grandes acumuladas na plataforma de baixo código se tornem automaticamente recursos de negócios que podem ser chamados diretamente pela IA - sem necessidade de ferramentas manuscritas ou desenvolvimento secundário, a linguagem natural pode impulsionar a execução automatizada de um conjunto completo de processos de negócios e até mesmo gerar o sistema inteiro em uma frase. | Dimensão | v3.9.1 e antes (era de arrastar e soltar) | v3.9.2 (era de uma frase) | |---|---|---| | Posicionamento de baixo código | Formulário/processo/geração de código/relatório e design em tela grande | Exportação de recursos de negócios nativos de IA | | Modo interativo | Arrastar e soltar + configuração manual | Uma frase em linguagem natural, tudo pode ser feito | | Construção de negócios | Arrastar componentes manualmente, configurar campos e configurar processos | **Projete formulários e desenhe processos em uma frase / relatório / tela grande / menu ** | | Uso de IA | Construção totalmente manual: configure manualmente formulários, desenhe processos, crie associações, configure menus e autorize passo a passo | A IA pode criar formulários, desenhar processos, vincular associações, criar menus e preencher autorizações em uma frase, tudo em uma única etapa | | Acesso empresarial à IA | É necessário desenvolvimento secundário de ferramenta manuscrita | Nó de formulário/processo on-line = habilidade natural | | Multimodal | Somente texto | Cobertura modal completa de texto/imagem/áudio/vídeo/habilidades | | Segurança | Reparação descentralizada de vulnerabilidades | Reparo especializado de vulnerabilidades + controle de permissão + isolamento e reforço de inquilinos |

Módulo de função Skills (novo armazém independente jeecgboot/skills)

Um novo armazém independente jeecgboot/skills lançado simultaneamente com a versão principal do v3.9.2 - uma coleção de habilidades de IA baseadas no Claude Code, impulsionadas por linguagem natural, gerando código, formulários, processos, relatórios, gráficos, telas grandes e painéis em uma frase.

Informações básicas do armazém
  • Adaptação: JeecgBoot 3.x/2.x
  • Dependências: Python 3.12+, Código Claude
  • Modelo: Oficial Claude / DeepSeek-v4 / MiniMax 2.7 Três conjuntos de planos para escolher
JeecgBoot Seis Habilidades
  • jeecg-codegen: Gerador de código - um conjunto completo de CRUD para geração de linguagem natural (Java + Vue3 + SQL)
  • jeecg-onlform: Gerador de formulários on-line - criação de formulários CRUD baseada em metadados
  • jeecg-onlreport: gerador de relatórios on-line - relatório de dados orientado por SQL
  • jeecg-desform: Gerador de formulários de designer - Suporta reconhecimento de captura de tela para gerar formulários JSON
  • jeecg-onlchart: Gerador de gráficos on-line - gera automaticamente gráficos de visualização de dados
  • jeecg-bpmn: gerador de processo BPM - gera automaticamente o processo de aprovação XML Flowable BPMN
JimuReport Três Habilidades
  • jimureport: Gerador de relatórios de blocos de construção - relatórios de vários tipos + Reconhecimento e geração de capturas de tela
  • jimubi-bigscreen: Gerador de tela grande - visualização de dados em tela cheia de 1920×1080
  • jimubi-dashboard: Gerador de painel - painel de dados de layout de grade de 24 colunas

JeecgBoot v3.9.2

Highlights

  • Low-code v2.0 ships as Claude Code Skills — A separate repo, jeecgboot/skills, is released alongside 3.9.2. Six JeecgBoot skills (jeecg-codegen, jeecg-onlform, jeecg-onlreport, jeecg-desform, jeecg-onlchart, jeecg-bpmn) plus three JimuReport skills (jimureport, jimubi-bigscreen, jimubi-dashboard) let you generate CRUD (Java + Vue3 + SQL), forms, reports, BPMN XML and 1920×1080 screens from natural language; jeecg-desform and jimureport even accept screenshots as input. Requires Python 3.12+ and Claude Code, with Claude / DeepSeek-v4 / MiniMax 2.7 backends. The shift that matters: Online forms and flow nodes become natively callable "business capabilities," so teams no longer hand-write Tools to expose low-code artifacts to AI.

  • Breaking: AI starter renamed and Langchain4j jumped to 1.12.2 — jeecg-boot-starter-chatgpt is now jeecg-boot-starter-ai, so any module declaring the old Maven coordinate must be updated before compiling. The Langchain4j 1.12.2 upgrade adds Agent Skills metadata auto-selection (models pick business capabilities automatically instead of blind prompt tuning) and adds deepseek-v4 compatibility (#9585). Watch model-specific API requirements when upgrading: qwen3.5-plus needs incremental_output enabled (#9446), qwen-vl-ocr needs extra config (#8 / #9359 family), and PR #9539 handles Tongyi Qianwen rejecting null message content.

  • Online becomes extensible and AI-readable — The Online frontend source is fully open-sourced, a new Online chart module adds configurable visualization panels, and a published Online form Schema spec gives AI a stable metadata contract to reason over. Data-model additions: LongText (#9366) plus link_table / link_table_field for Vue3 one-to-many related records and cross-table field references, dictionary-tree support in sub-tables (#7633), and external-link forms for anonymous fill/edit. Long-standing performance complaints are targeted directly (config lag QQYUN-14177, slow open, small-screen field positioning). For adopters this is the main reason to upgrade if you were blocked on二次开发 or on representing hierarchical/relational data in Online.

  • AiFlow graduates from chatbot to visual Agent orchestration — New variable read/write, memory read/write, loop-variable and structured-JSON-output nodes, prompt-table binding on LLM nodes, file-upload start nodes, and a search-engine node plus web search for the AI assistant. Post-publish read-only node inspection and fixed HTTP request timeout handling (#9533) make flows safer to run in production. Combined with tool/AI-app whitelisting and cross-tenant isolation, this is what turns AiFlow into a platform you can actually delegate multi-step work to, rather than a demo.

  • Security hardening makes 3.9.2 a mandatory upgrade for multi-tenant deployments — High-severity fixes cover AI poster SSRF (#9579, rejects loopback/link-local), attachment path traversal (#9519, path normalization + sandbox enforcement), AiragApp cross-tenant write (#9462), token privilege escalation via getUserSectionInfoByToken (#9518), RCE (#9335), and JDBC URL injection from an incomplete blacklist/missing datasource endpoint permission (#9468). MCP and sensitive underlying tools now require permission checks (#9483, #9464). If you expose AI endpoints to tenants, audit which ones were reachable before patching — several of these were direct cross-tenant data paths.

  • Frontend on-demand loading cuts first paint and enables in-page AI — antd (via unplugin-vue-components), unplugin-icons, Jvxetable/Vxetable, TinyMCE, JEasyCron, codemirror and the chat module are all lazy-loaded; login registration/QR/forgot-password components and AppSearch no longer hit the initial bundle. JCronValidator and custom basicForm components moved out of the global load. One caveat worth flagging to your team: after the Jvxetable conversion, internal self-references are disallowed or the page will hang — check custom tables before rollout (#9452 also addressed Online styles leaking into the host project).
