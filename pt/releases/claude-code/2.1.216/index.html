código claude v2.1.216

O que mudou

  • Adicionada configuração sandbox.filesystem.disabled para ignorar o isolamento do sistema de arquivos enquanto mantém o controle de saída da rede
  • Corrigida uma lentidão em sessões longas, onde o custo de normalização de mensagens crescia quadraticamente com o número de turnos, causando paralisações de vários segundos e retomadas lentas
  • Correção de comandos de negação do modo automático com erros do classificador "HTTP 401" após o token OAuth expirar ou ser girado no meio da sessão
  • Corrigido AskUserQuestion dizendo a Claude para continuar mesmo quando sua resposta pedia para esperar ou explicar primeiro - respostas de texto livre agora têm redação neutra
  • Corrigido o Claude Code na web fazendo novamente a mesma pergunta e descartando sua resposta após a sessão ficar ociosa por alguns minutos
  • Correção de @-menções que não anexavam nada silenciosamente após ganchos de modificação de arquivo, repetição de ponto vim de operadores c e colagem, linha de status sendo executada duas vezes ao retomar e o selecionador de currículo trava em caso de falha
  • Correção de sessões retomadas do agente em segundo plano, revertendo para o agente padrão: o prompt do agente e as restrições de ferramentas agora foram restauradas
  • Corrigidos subagentes isolados da árvore de trabalho redirecionando o git para o checkout compartilhado via git -C, --git-dir ou GIT_DIR/GIT_WORK_TREE
  • Corrigidas sessões da árvore de trabalho que aterrissavam na árvore de trabalho restante de outro projeto quando o diretório de trabalho não correspondia ao projeto selecionado
  • Correção de sessões em segundo plano cuja árvore de trabalho não possui repositório git não podendo ser excluídas
  • Correção do claude daemon stop --any potencialmente encerrando um processo não relacionado por meio de um arquivo de bloqueio de daemon legado obsoleto
  • Corrigido Esc-Esc em um prompt inativo que não abria o seletor de retrocesso em sessões de longa duração com tarefas em segundo plano
  • Corrigida a verificação de permissão do comando Bash para instruções compostas com redirecionamentos dentro de listas ou negações &&
  • Corrigida a falha ao pressionar Ctrl+X duas vezes na lista de agentes ao excluir uma sessão, e as sessões excluídas reapareciam quando o trabalhador em segundo plano morria
  • Correção de subagentes em segundo plano sendo cancelados quando uma mensagem de alta prioridade chegava durante a janela de inicialização
  • Corrigido lixo de mouse e foco no terminal enquanto um editor GUI de /memory, /plan, /keybindings ou Ctrl+G está aberto; /memory não espera mais o fechamento do editor
  • Corrigido o loop 403 do Claude-in-Chrome ao reconectar quando o token OAuth da sessão não possui um escopo necessário
  • Corrigidos salvamentos de fluxo de trabalho e gravações de tarefas agendadas seguindo um link simbólico em .claude, que poderia redirecionar gravações fora do projeto
  • Correção da reautenticação do MCP, revogando credenciais de trabalho antes que o novo login seja bem-sucedido e a mensagem de reconexão precisa de autenticação em sessões em segundo plano apontando para um comando inutilizável
  • Corrigidos comandos somente leitura no Windows acessando caminhos de rede sem um prompt de permissão
  • Corrigida a análise do comando Bash de caracteres não-ASCII para corresponder aos limites reais das palavras do shell
  • Correção da validação de permissão da ferramenta PowerShell de comandos contendo caracteres Unicode invisíveis
  • Corrigidas caixas de diálogo no modo de tela cheia que ultrapassavam a borda direita do painel
  • Corrigida a lista de configurações do /config no modo de tela cheia cli exibindo o rodapé da dica do teclado
  • Corrigida a quebra da dica de rodapé no modo de transcrição (Ctrl+O) em terminais mais estreitos que 104 colunas
  • Corrigido o endpoint de métricas Prometheus (OTEL_METRICS_EXPORTER=prometheus) emitindo linhas # UNIT inválidas
  • Corrigidas habilidades e comandos alterados durante uma sessão que não apareciam no menu de barras até reiniciar
  • Corrigidas habilidades de plugin com um campo frontmatter name perdendo seu prefixo de plugin no preenchimento automático do comando slash
  • Correção de negações de permissão de relatórios incorretos de telemetria: solicitações de solicitação de permissão com falha não contam mais como rejeições do usuário, e as interrupções do usuário agora são relatadas como anulações do usuário em vez de rejeições
  • Melhorada a confirmação do /fork para uma linha com o nome da nova sessão, id do claude attach e uma nota quando a cópia compartilha seu checkout
  • Validação aprimorada dos argumentos dos comandos git e gh na ferramenta PowerShell
  • Melhorado o erro de diferença muito grande do /ultrareview para mostrar limites configurados, tamanho de diferença medido e maiores arquivos contribuintes
  • Mensagem de diferença vazia /code-review ultra aprimorada para nomear a referência de base exata e sugerir a passagem de uma base explícita
  • Melhorou o prompt de ajuste do limite de gastos para mostrar o motivo do servidor quando uma alteração no limite de gastos é rejeitada
  • /context agora mostra um aviso explícito quando a conversa excede a janela de contexto, e um /compact com falha é exibido como um erro
  • /rewind não restaura ou exclui mais arquivos por meio de links simbólicos ou links físicos em caminhos rastreados e informa quantos caminhos foram ignorados
  • Sessões em segundo plano: /mcp e /install-github-app agora estacionam uma solicitação "precisa de entrada" na visualização do agente quando nenhum client está anexado
  • Atualizada a habilidade de dataviz incluída: reordenou a paleta de gráficos padrão e corrigiu a orientação que sugeria rótulos diretos para gráficos de quatro séries
  • [VSCode] Correção da renderização de texto da direita para a esquerda (árabe, hebraico, persa) na ordem errada quando misturado com inglês ou código
  • Correção de sessões na nuvem que deixavam cair a mensagem em andamento quando o contêiner da sessão reiniciava no meio do turno — o turno interrompido agora é executado novamente ao retomar, em vez de deixar a sessão sem resposta

claude-code v2.1.216

What's changed

  • Added sandbox.filesystem.disabled setting to skip filesystem isolation while keeping network egress control
  • Fixed a slowdown in long sessions where message normalization cost grew quadratically with the number of turns, causing multi-second stalls and slow resumes
  • Fixed auto mode denying commands with "HTTP 401" classifier errors after the OAuth token expired or rotated mid-session
  • Fixed AskUserQuestion telling Claude to continue even when your answer asked it to wait or explain first — free-text answers now get neutral wording
  • Fixed Claude Code on the web re-asking the same question and dropping your answer after the session sat idle for a few minutes
  • Fixed @-mentions silently attaching nothing after file-modifying hooks, vim dot-repeat of c-operators and paste, statusline running twice on resume, and resume-picker hangs on failure
  • Fixed resumed background agent sessions reverting to the default agent: the agent's prompt and tool restrictions are now restored
  • Fixed worktree-isolated subagents redirecting git into the shared checkout via git -C, --git-dir, or GIT_DIR/GIT_WORK_TREE
  • Fixed worktree sessions landing in another project's leftover worktree when the working directory did not match the selected project
  • Fixed background sessions whose worktree has no git repository being undeletable
  • Fixed claude daemon stop --any potentially terminating an unrelated process via a stale legacy daemon lockfile
  • Fixed Esc-Esc at an idle prompt not opening the rewind picker in long-running sessions with background tasks
  • Fixed Bash command permission checking for compound statements with redirects inside && lists or negations
  • Fixed pressing Ctrl+X twice in the agent list failing to delete a session, and deleted sessions reappearing when their background worker had died
  • Fixed background subagents getting cancelled when a high-priority message arrives during their startup window
  • Fixed mouse and focus garbage in the terminal while a GUI editor from /memory, /plan, /keybindings, or Ctrl+G is open; /memory no longer waits for the editor to close
  • Fixed Claude-in-Chrome 403-looping on reconnect when the session's OAuth token lacks a required scope
  • Fixed workflow saves and scheduled-task writes following a symlink at .claude, which could redirect writes outside the project
  • Fixed MCP re-authenticate revoking working credentials before the new sign-in succeeds, and the reconnect needs-auth message in background sessions pointing at an unusable command
  • Fixed read-only commands on Windows accessing network paths without a permission prompt
  • Fixed Bash command parsing of non-ASCII characters to match real shell word boundaries
  • Fixed PowerShell tool permission validation of commands containing invisible Unicode characters
  • Fixed dialogs in fullscreen mode stretching past the right-hand edge of their panel
  • Fixed the /config settings list in fullscreen mode clipping its keyboard-hint footer
  • Fixed the transcript-mode (Ctrl+O) footer hint wrapping on terminals narrower than 104 columns
  • Fixed the Prometheus metrics endpoint (OTEL_METRICS_EXPORTER=prometheus) emitting invalid # UNIT lines
  • Fixed skills and commands changed during a session not appearing in the slash menu until restart
  • Fixed plugin skills with a name frontmatter field losing their plugin prefix in slash-command autocomplete
  • Fixed telemetry misreporting permission denials: failed permission-prompt requests no longer count as user rejections, and user interrupts are now reported as user aborts instead of rejections
  • Improved the /fork confirmation to one line with the new session's name, claude attach id, and a note when the copy shares your checkout
  • Improved validation of git and gh command arguments in the PowerShell tool
  • Improved the /ultrareview diff-too-large error to show configured limits, measured diff size, and largest contributing files
  • Improved /code-review ultra empty-diff message to name the exact base ref and suggest passing an explicit base
  • Improved the spend limit adjustment prompt to show the server's reason when a spend limit change is rejected
  • /context now shows an explicit warning when the conversation exceeds the context window, and a failed /compact displays as an error
  • /rewind no longer restores or deletes files through symlinks or hard links at tracked paths and reports how many paths it skipped
  • Background sessions: /mcp and /install-github-app now park a "needs input" request in the agent view when no client is attached
  • Updated the bundled dataviz skill: reordered the default chart palette and fixed guidance that suggested direct labels for four-series charts
  • [VSCode] Fixed right-to-left text (Arabic, Hebrew, Persian) rendering in the wrong order when mixed with English or code
  • Fixed cloud sessions dropping the in-flight message when the session's container restarts mid-turn — the interrupted turn now re-runs on resume instead of leaving the session unresponsive
