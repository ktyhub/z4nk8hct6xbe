código claude v2.1.267

O que mudou

  • Adicionada configuração maxEffortLevel (nível superior ou por modelo em modelSettings): limita o nível de esforço em todos os fornecedores, incluindo Bedrock, Vertex e Foundry; os usuários ainda podem escolher um nível inferior
  • Adicionado --system-prompt-snapshot off para tornar o prompt do sistema atualizado em cada solicitação, em vez de reutilizar o prompt gravado da conversa (para iterar no texto do prompt)
  • Corrigidas tarefas agendadas do Cowork na nuvem que falhavam na inicialização para organizações cujas configurações gerenciadas exigem sandbox
  • Corrigida a renderização de /context e outras saídas de comando locais em branco em clients móveis
  • Corrigido shift+enter e option+backspace que não funcionavam após reconectar a uma sessão tmux ou ssh dentro de uma visualização de agente
  • Corrigido o cabeçalho escuro do último prompt que não aparecia no topo da conversa ao rolar para cima no modo de tela cheia
  • Corrigidas chamadas de fluxo de trabalho agent() com grandes esquemas de saída sendo recusadas no modo automático em vez de serem verificadas pelo classificador de segurança
  • Foi corrigido um caso em que um caminho de entrada do mercado contendo uma barra invertida poderia ignorar a verificação de contenção para mercados buscados no macOS e Linux
  • Correção de credenciais expiradas da AWS ou do Google Cloud em um aplicativo host, como Claude Desktop, tentando novamente dez vezes com uma "solicitação falhada" genérica antes que o erro de nova autenticação aparecesse
  • Corrigida a retomada de uma sessão após /compact ou outro comando de barra executado via -p --resume: um espúrio "Continuar de onde você parou." turn não está mais inserido
  • Corrigida a retomada de uma sessão grande (transcrição acima de 5 MB): chamadas de ferramentas paralelas e sua saída de gancho não são mais descartadas da conversa recarregada
  • Corrigido allowedHttpHookUrls, httpHookAllowedEnvVars e allowedChannelPlugins gerenciados para não admitir nada, nem tudo, quando ilegível
  • Corrigido /login em máquinas cujas configurações gerenciadas exigem login no gateway de aplicativos Claude: Esc agora fecha a caixa de diálogo em vez de não fazer nada
  • Corrigidas publicações de artefatos interrompidas por queda de conexão no meio do upload: agora eles tentam novamente uma vez quando Claude Code pode dizer que o upload nunca foi concluído, em vez de relatar um resultado desconhecido
  • Corrigido frontmatter effort: em comandos personalizados, habilidades e subagentes sendo ignorados em modelos cujo esforço padrão ainda está fixado (Opus 4.7, Opus 4.8, Fable 5)
  • Corrigida falha na publicação do artefato com um erro inútil quando o arquivo de paginação não é UTF-8 válido ou contém um caractere de substituição (U+FFFD); o erro agora nomeia a linha e a coluna a serem corrigidas
  • Corrigido o menu do diretório claude agents @ que não listava os repositórios criados após o início da sessão
  • Corrigido controle remoto clients que ingressava em uma sessão Claude Desktop ou VS Code mostrando um modo de permissão obsoleto até que fosse alterado novamente
  • Corrigido claude remote-control saindo e descartando todas as sessões anexadas quando sua credencial de servidor expirava (cerca de 30 dias após o início); o anfitrião agora se registra novamente e continua
  • Corrigido o aviso de limite de uso que piscava durante uma sessão quando solicitações de diferentes modelos ou modos relatavam diferentes janelas de limite
  • Correção do raciocínio anterior sendo eliminado quando um servidor MCP reenvia ou uma ferramenta integrada renderiza novamente uma ferramenta que o modelo já carregou
  • Corrigida uma ferramenta que desaparecia no meio da conversa, de um servidor MCP desconectado ou de uma atualização, reescrevendo a lista de ferramentas e descartando pensamentos anteriores
  • Corrigido um trabalho em segundo plano bifurcado de uma conversa adicionando EnterWorktree ao bloco de ferramentas da conversa no meio da sessão, o que interrompeu a reutilização do cache de prompt
  • Corrigidas ferramentas de plug-in e MCP no meio da sessão sendo adicionadas à lista de ferramentas em sessões sem ToolSearch, o que interrompeu a reutilização do cache de prompt; modelos suportados agora os recebem como definições diferidas
  • Correção de troca de modelos com /model reenviando cada definição de ferramenta (uma falta de prompt-cache); o texto de atribuição de commit e PR agora chega como uma nota de conversa que atualiza sobre mudanças de modelo
  • Foram corrigidas sessões retomadas que reescreviam o conjunto de ferramentas in-line quando um conector MCP se reconectava em um momento diferente do anterior
  • Corrigidas sessões retomadas que re-renderizavam descrições de ferramentas em vez de reproduzir as gravadas quando uma ferramenta era executada no primeiro turno
  • Foram corrigidas falhas no cache de prompt e eliminação do pensamento estendido quando as ferramentas de um conector claude.ai mudam entre uma sessão e seu currículo
  • Corrigidas sessões retomadas reescrevendo anúncios anteriores da ferramenta MCP (e eliminando o pensamento estendido) antes de seus conectores se reconectarem
  • Corrigida uma quebra de cache de prompt quando uma conversa no modo de impressão (-p) é retomada interativamente: o prefixo do prompt do sistema não muda mais
  • Melhorado o painel /diff: ele não pisca mais "0 arquivos alterados" e um botão giratório antes de se estabelecer, e seu estado vazio fica centralizado no painel
  • Melhorou a orientação de descrição da ferramenta Bash para que Claude descreva o que um comando faz em palavras simples, em vez de repetir o comando
  • Orientação de sandbox aprimorada, então Claude sugere /copy quando comandos clipboard, como pbcopy, falham dentro da sandbox
  • Melhor tempo de primeira renderização do --resume para sessões com muitas chamadas de ferramentas Bash
  • Capacidade de resposta de entrada de prompt aprimorada: as teclas digitadas não esperam mais um quadro atrás do botão giratório ou de repinturas de streaming
  • Melhor estabilidade do cache de prompt: subagentes e sessões iniciadas com --system-prompt ou --append-system-prompt agora registram o prompt do sistema e as definições de ferramenta uma vez, em vez de renderizá-los novamente
  • Erros de publicação da ferramenta Artefato aprimorados: quando uma publicação é recusada, a mensagem agora diz o porquê e o que fazer a respeito
  • Executor auto-hospedado: --use-anthropic-git-proxy alterado para ser reportado ao servidor no registro e para imprimir um aviso para cada sessão que ainda clona através do proxy git legado
  • Gateway: upstreams forward_user_identity alterados para retornar um 429 como está para um desenvolvedor cujo e-mail foi encaminhado, em vez de fazer failover para o próximo upstream, para que os limites por usuário do proxy sejam mantidos
  • [VSCode] Corrigido o host de extensão travando em 100% da CPU ao bifurcar, editar uma mensagem anterior ou retroceder em uma conversa cuja transcrição salva contém um link pai cyclic
  • [VSCode] Corrigida a colagem de uma captura de tela no WSL2/WSLg, inserindo bytes de imagem bruta na entrada do chat; a imagem agora é anexada quando o clipboard a fornece, caso contrário a colagem é ignorada
  • [VSCode] Corrigidos blocos de comparação de bate-papo sempre renderizados com um tema escuro do editor; eles agora seguem o tema de cores ativo do VS Code, incluindo alto contraste
  • [VSCode] Corrigida a renderização mista de texto da direita para a esquerda e em inglês na ordem errada ao digitar a entrada da mensagem
  • [VSCode] Corrigida a aceitação de uma edição na visualização de comparação em um arquivo com terminações de linha do Windows (CRLF) falhando com "String not found in file"
  • [VSCode] Corrigidas @-menções descartando arquivos cujos caminhos contêm espaços
  • [VSCode] Corrigida a falha na visualização da lista de sessões ao carregar em janelas conectadas por SSH remoto quando a pasta do espaço de trabalho existe apenas no host remoto
  • [VSCode] Corrigidos processos ripgrep descontrolados ao visualizar arquivos em espaços de trabalho grandes ou com muitos links simbólicos
  • [Claude Code na web] Corrigidas sessões do GitHub Enterprise Server mostrando sua conta GitHub como desconectada quando seu token expirava; As operações de PR e emissão agora são atualizadas automaticamente
  • [Código Claude na web] Corrigidas falhas nas chamadas gh e GitHub API em organizações sem o App Claude GitHub; eles agora usam sua conta GitHub conectada e dizem isso quando nenhuma está conectada
  • [Claude Tag] Adicionado um link "Usar um conector personalizado" aos formulários de conexão predefinidos nas configurações de administrador do Claude Tag, para que você possa mudar para uma conexão personalizada sem começar de novo
  • [Claude Tag] Corrigido Claude respondendo "O API rejeitou a solicitação como inválida" quando a organização ficou sem créditos de uso; a resposta agora diz isso e explica como adicionar mais
  • [Claude Tag] Corrigidas solicitações do tópico para editar ou excluir uma mensagem que Claude postou no nível superior do canal sendo respondida com uma correção em vez de chegar à sessão que a postou
  • [Claude Tag] Correção de Conexão em solicitações de acesso à ferramenta nas configurações do administrador > Solicitações de revisão falhando com "Falha na autorização" ou mostrando o pacote de acesso solicitado como excluído

claude-code v2.1.267

What's changed

  • Added maxEffortLevel setting (top-level or per model under modelSettings): caps the effort level on every provider, including Bedrock, Vertex and Foundry; users can still pick a lower level
  • Added --system-prompt-snapshot off to render the system prompt fresh on every request instead of reusing the conversation's recorded prompt (for iterating on prompt text)
  • Fixed Cowork scheduled tasks in the cloud failing at startup for organizations whose managed settings require sandboxing
  • Fixed /context and other local command output rendering blank on mobile clients
  • Fixed shift+enter and option+backspace not working after reconnecting to a tmux or ssh session inside an agent view
  • Fixed the dim last-prompt header not appearing at the top of the conversation when scrolling up in fullscreen mode
  • Fixed Workflow agent() calls with large output schemas being refused in auto mode instead of being checked by the safety classifier
  • Fixed a case where a marketplace entry path containing a backslash could bypass the containment check for fetched marketplaces on macOS and Linux
  • Fixed expired AWS or Google Cloud credentials under a host app such as Claude Desktop retrying ten times with a generic "request failed" before the re-authenticate error appeared
  • Fixed resuming a session after /compact or another slash command ran via -p --resume: a spurious "Continue from where you left off." turn is no longer inserted
  • Fixed resuming a large session (transcript over 5 MB): parallel tool calls and their hook output are no longer dropped from the reloaded conversation
  • Fixed managed allowedHttpHookUrls, httpHookAllowedEnvVars and allowedChannelPlugins to admit nothing, not everything, when unreadable
  • Fixed /login on machines whose managed settings require Claude apps gateway sign-in: Esc now closes the dialog instead of doing nothing
  • Fixed artifact publishes cut off by a dropped connection mid-upload: they now retry once when Claude Code can tell the upload never completed, instead of reporting an unknown outcome
  • Fixed effort: frontmatter on custom commands, skills, and subagents being ignored on models whose default effort is still pinned (Opus 4.7, Opus 4.8, Fable 5)
  • Fixed artifact publish failing with an unhelpful error when the page file isn't valid UTF-8 or contains a replacement character (U+FFFD); the error now names the line and column to fix
  • Fixed claude agents @ directory menu not listing repositories created after the session started
  • Fixed Remote Control clients that join a Claude Desktop or VS Code session showing a stale permission mode until it was changed again
  • Fixed claude remote-control exiting and dropping every attached session when its server credential expires (about 30 days after start); the host now re-registers and keeps going
  • Fixed the usage-limit warning flickering on and off during a session when requests for different models or modes report different limit windows
  • Fixed earlier reasoning being dropped when an MCP server re-sends, or a built-in tool re-renders, a tool the model already loaded
  • Fixed a tool that disappears mid-conversation, from a disconnected MCP server or an upgrade, rewriting the tool list and discarding earlier thinking
  • Fixed a background worker forked from a conversation adding EnterWorktree to the conversation's tool block mid-session, which broke prompt-cache reuse
  • Fixed mid-session MCP and plugin tools being added to the tool list in sessions without ToolSearch, which broke prompt-cache reuse; supported models now receive them as deferred definitions
  • Fixed switching models with /model re-sending every tool definition (a prompt-cache miss); commit and PR attribution text now arrives as a conversation note that updates on model changes
  • Fixed resumed sessions rewriting the inline tool set when an MCP connector reconnects at a different moment than before
  • Fixed resumed sessions re-rendering tool descriptions instead of replaying the recorded ones when the first turn ran a tool
  • Fixed prompt-cache misses and dropped extended thinking when a claude.ai connector's tools change between a session and its resume
  • Fixed resumed sessions rewriting earlier MCP tool announcements (and dropping extended thinking) before their connectors reconnect
  • Fixed a prompt-cache break when a print-mode (-p) conversation is resumed interactively: the system prompt prefix no longer changes
  • Improved the /diff panel: it no longer flashes "0 files changed" and a spinner before settling, and its empty state is centered in the panel
  • Improved the Bash tool's description guidance so Claude describes what a command does in plain words instead of echoing the command
  • Improved sandbox guidance so Claude suggests /copy when clipboard commands such as pbcopy fail inside the sandbox
  • Improved --resume first-render time for sessions with many Bash tool calls
  • Improved prompt input responsiveness: keystrokes no longer occasionally wait a frame behind spinner or streaming repaints
  • Improved prompt-cache stability: subagents and sessions started with --system-prompt or --append-system-prompt now record the system prompt and tool definitions once instead of re-rendering them
  • Improved Artifact tool publish errors: when a publish is refused, the message now says why and what to do about it
  • Self-hosted runner: Changed --use-anthropic-git-proxy to be reported to the server at registration and to print a warning for each session that still clones through the legacy git proxy
  • Gateway: Changed forward_user_identity upstreams to return a 429 as-is to a developer whose email was forwarded, instead of failing over to the next upstream, so the proxy's per-user limits hold
  • [VSCode] Fixed the extension host hanging at 100% CPU when forking, editing an earlier message, or rewinding in a conversation whose saved transcript contains a cyclic parent link
  • [VSCode] Fixed pasting a screenshot on WSL2/WSLg inserting raw image bytes into the chat input; the image is now attached when the clipboard provides it, otherwise the paste is ignored
  • [VSCode] Fixed chat diff blocks always rendering with a dark editor theme; they now follow the active VS Code color theme, including high contrast
  • [VSCode] Fixed mixed right-to-left and English text rendering in the wrong order while typing in the message input
  • [VSCode] Fixed accepting an edit in the diff view on a file with Windows (CRLF) line endings failing with "String not found in file"
  • [VSCode] Fixed @-mentions dropping files whose paths contain spaces
  • [VSCode] Fixed the sessions list view failing to load in windows connected over Remote-SSH when the workspace folder exists only on the remote host
  • [VSCode] Fixed runaway ripgrep processes when viewing files in large or symlink-heavy workspaces
  • [Claude Code on the web] Fixed GitHub Enterprise Server sessions showing your GitHub account as disconnected once its token expired; PR and issue operations now refresh it automatically
  • [Claude Code on the web] Fixed gh and GitHub API calls failing in organizations without the Claude GitHub App; they now use your connected GitHub account and say so when none is connected
  • [Claude Tag] Added a "Use a custom connector" link to the preset connection forms in Claude Tag admin settings, so you can switch to a custom connection without starting over
  • [Claude Tag] Fixed Claude replying "The API rejected the request as invalid" when the organization has run out of usage credits; the reply now says so and explains how to add more
  • [Claude Tag] Fixed thread requests to edit or delete a message Claude posted at the channel's top level being answered with a correction instead of reaching the session that posted it
  • [Claude Tag] Fixed Connect on Tool access requests under Admin settings > Review requests failing with "Authorization failed" or showing the requested access bundle as deleted
