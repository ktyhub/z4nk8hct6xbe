código claude v2.1.229

O que mudou

  • claude remote-control --continue documentado para retomar a sessão de controle remoto mais recente
  • Adicionado suporte de gancho Claude Code fornecido pelo servidor para sessões de execução auto-hospedadas, combinando com o comportamento do ambiente gerenciado
  • Adicionados pings de manutenção de atividade SSE para respostas de streaming de gateway durante longas pausas de pensamento, evitando desconexões de tempo limite de inatividade em upstreams Vertex e Bedrock
  • Adicionadas fontes command do mercado de plugins: um comando local (por exemplo, um IDE) imprime o diretório do plugin, que é resolvido novamente a cada sessão e aplicado sem reinicialização; mode: "link" usa-o no lugar
  • ListAgents agora marca sessões de controle remoto desconectadas como offline e rotula suas sessões na nuvem como cloud
  • Corrigidas respostas longas que desapareciam parcialmente durante a transmissão e eram impressas duas vezes no terminal
  • Corrigida uma falha na tela de erro (inclusive em --resume da sessão afetada) quando uma chamada de ferramenta tinha um valor glob, file_path ou command sem string
  • Corrigido um travamento do RangeError quando uma barra de progresso ou tabela de descontos era renderizada em uma janela de terminal muito estreita (também poderia travar o claude --continue/--resume na inicialização)
  • Corrigida uma falha no Windows quando uma chamada de ferramenta ou mensagem referenciava um arquivo por um caminho de comprimento estendido (\\?\) ou UNC
  • Corrigida falha no modo automático em todas as chamadas de ferramenta para usuários que desativam o cabeçalho de atribuição via CLAUDE_CODE_ATTRIBUTION_HEADER (conexões diretas Antrópicas API)
  • Corrigido /model rejeitando Sonnet/Opus 1M para assinantes claude.ai usando um gateway ANTHROPIC_BASE_URL personalizado
  • Corrigido o MCP OAuth com servidores de autorização estrita usando 127.0.0.1 em vez de localhost no URI de redirecionamento
  • Correção do controle remoto clients mostrando um botão giratório travado após um comando de barra digitado no terminal do laptop
  • Corrigido o fluxo de trabalho de revisão de código Claude gerado pela conclusão de /install-github-app sem postar sua revisão na solicitação pull
  • Correção de travamentos de UI de vários segundos após a edição de um arquivo com milhares de diagnósticos IDE enquanto a extensão IDE está conectada
  • Correção de comandos únicos do claude plugin que deixavam um arquivo de atividade perdido que poderia impedir a limpeza de versões desatualizadas do plugin
  • Fluxos de trabalho dinâmicos corrigidos dentro de contêineres limitados por CPU usando a contagem de núcleos da máquina host em vez do limite de CPU do contêiner
  • Corrigido um vazamento de identificador do inspetor de arquivos após substituições de arquivos atômicos e um erro não detectado no Windows quando o inspetor de tarefas agendadas falhava em uma rede ou sistema de arquivos virtual
  • Correção das sessões SDK e --input-format stream-json que recebiam um erro 400 API quando uma mensagem somente com espaços em branco era enviada
  • Corrigidas conversas cujas mensagens por si só excedem o limite de solicitação de 32 MB do API, tentando novamente a compactação quando nenhuma imagem ou documento pode ser removido; agora eles falharam uma vez com uma mensagem clara
  • Foi corrigida a exportação OpenTelemetry das sessões do Claude Desktop sendo rejeitadas pelo gateway gerenciado pelo Desktop quando esse gateway também é o endpoint de telemetria
  • Correção do executor auto-hospedado e outras sessões remotas que saíam na inicialização quando o managed-mcp.json é implantado e o servidor entrega servidores MCP; esses servidores agora são ignorados com um aviso
  • Correção da preparação do repositório do executor auto-hospedado pendurado em um prompt do Git Credential Manager; git agora falha rapidamente quando faltam credenciais
  • Distribuições de fluxo de trabalho aprimoradas para escalonar agentes irmãos com o mesmo prefixo para que os agentes subsequentes leiam o prefixo de prompt armazenado em cache em vez de pagá-lo novamente (CLAUDE_CODE_WORKFLOW_PREFIX_STAGGER_MS=0 desativa)
  • Erros de "prompt é muito longo" aprimorados para explicar por que a compactação automática não pôde ser recuperada em vez de apenas sugerir /compact
  • Sandbox aprimorado: literais IPv6 em listas de domínios de rede agora estão entre colchetes ([::1]:443) e grafias ambíguas são impostas, fechadas com falha e sinalizadas por /doctor
  • /login atualizado para repetir o aviso de substituição do CLAUDE_CODE_OAUTH_TOKEN após um login bem-sucedido
  • /commit-push-pr alterado para que comandos git/gh com sinalizadores perigosos (--force, --amend, --no-verify, etc.) não sejam mais aprovados automaticamente
  • Alterada a inicialização do Windows do executor auto-hospedado para exigir um --base-dir explícito; não há diretório de checkout padrão no Windows
  • [VSCode] "Relatar um problema" e /bug agora abrem a caixa de diálogo de feedback integrada em vez de um link de pesquisa retirado
  • [VSCode] Tornou o painel de perguntas laterais do /btw redimensionável arrastando seu limite, em layouts encaixados lateralmente e empilhados
  • [VSCode] Adicionados grupos de sessão na barra lateral - click direito para criar, renomear ou excluir; Cmd/Ctrl- ou Shift-click para mover várias sessões de uma vez

claude-code v2.1.229

What's changed

  • Documented claude remote-control --continue for resuming the most recent Remote Control session
  • Added server-supplied Claude Code hook support for self-hosted runner sessions, matching managed-environment behavior
  • Added SSE keepalive pings to gateway streaming responses during long thinking pauses, preventing idle-timeout disconnects on Vertex and Bedrock upstreams
  • Added plugin marketplace command sources: a local command (e.g. an IDE) prints the plugin directory, which is re-resolved each session and applied without a restart; mode: "link" uses it in place
  • ListAgents now marks disconnected Remote Control sessions as offline and labels your cloud sessions as cloud
  • Fixed long responses partly disappearing while streaming and being printed twice in the terminal
  • Fixed a crash to the error screen (including on --resume of the affected session) when a tool call had a non-string glob, file_path, or command value
  • Fixed a RangeError crash when a progress bar or markdown table rendered in a very narrow terminal window (could also crash claude --continue/--resume at startup)
  • Fixed a crash on Windows when a tool call or message referenced a file by an extended-length (\\?\) or UNC path
  • Fixed auto mode failing on every tool call for users who disable the attribution header via CLAUDE_CODE_ATTRIBUTION_HEADER (direct Anthropic API connections)
  • Fixed /model rejecting Sonnet/Opus 1M for claude.ai subscribers using a custom ANTHROPIC_BASE_URL gateway
  • Fixed MCP OAuth with strict authorization servers by using 127.0.0.1 instead of localhost in the redirect URI
  • Fixed Remote Control clients showing a stuck working spinner after a slash command typed in the laptop terminal
  • Fixed the Claude Code Review workflow generated by /install-github-app completing without posting its review on the pull request
  • Fixed multi-second UI stalls after editing a file with thousands of IDE diagnostics while the IDE extension is connected
  • Fixed one-shot claude plugin commands leaving a stray liveness file that could prevent cleanup of outdated plugin versions
  • Fixed dynamic workflows inside CPU-limited containers using the host machine's core count instead of the container's CPU limit
  • Fixed a file-watcher handle leak after atomic file replacements, and an uncaught error on Windows when the scheduled-tasks watcher failed on a network or virtual filesystem
  • Fixed SDK and --input-format stream-json sessions getting a 400 API error when a whitespace-only message was submitted
  • Fixed conversations whose messages alone exceed the API's 32 MB request limit retrying compaction when no images or documents can be stripped; they now fail once with a clear message
  • Fixed OpenTelemetry export from Claude Desktop sessions being rejected by the Desktop-managed gateway when that gateway is also the telemetry endpoint
  • Fixed self-hosted runner and other remote sessions exiting at startup when managed-mcp.json is deployed and the server delivers MCP servers; those servers are now skipped with a warning
  • Fixed self-hosted runner repository preparation hanging on a Git Credential Manager prompt; git now fails fast when credentials are missing
  • Improved workflow fan-outs to stagger same-prefix sibling agents so subsequent agents read the cached prompt prefix instead of re-paying it (CLAUDE_CODE_WORKFLOW_PREFIX_STAGGER_MS=0 disables)
  • Improved "prompt is too long" errors to explain why automatic compaction could not recover instead of only suggesting /compact
  • Improved sandbox: IPv6 literals in network domain lists are now bracketed ([::1]:443), and ambiguous spellings are enforced fail-closed and flagged by /doctor
  • Updated /login to repeat the CLAUDE_CODE_OAUTH_TOKEN override warning after a successful login
  • Changed /commit-push-pr so git/gh commands with dangerous flags (--force, --amend, --no-verify, etc.) are no longer auto-approved
  • Changed self-hosted runner Windows startup to require an explicit --base-dir; there is no default checkout directory on Windows
  • [VSCode] "Report a problem" and /bug now open the built-in feedback dialog instead of a retired survey link
  • [VSCode] Made the /btw side-question panel resizable by dragging its boundary, in both side-docked and stacked layouts
  • [VSCode] Added session groups in the sidebar — right-click to create, rename, or delete; Cmd/Ctrl- or Shift-click to move several sessions at once
