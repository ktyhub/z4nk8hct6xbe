código claude v2.1.316

O que mudou

  • Adicionado CLAUDE_CODE_DISABLE_ULTRATHINK, que desativa a palavra-chave ultrathink
  • Adicionados orçamentos de grupo agrupados ao gateway de aplicativos Claude: um orçamento mensal que os membros de um grupo compartilham, além do limite de cada membro, definido com pooled_budget no administrador de limites de gastos API
  • Adicionado CLAUDE_CODE_DISABLE_LOOPED_CROSS_CERT_DROP para manter certificados cruzados de sistema que certificam uns aos outros em um loop, para servidores cuja CA privada precisa de um
  • Adicionado CLAUDE_CODE_SUBAGENT_EFFORT para definir o nível de esforço em que os subagentes são executados quando nada mais nomeia um, em vez de herdar o da sessão
  • Adicionado managed.policy_mode: layered ao gateway de aplicativos Claude: todas as políticas que correspondem a um desenvolvedor se aplicam, cada uma mesclada com as listadas abaixo, não apenas a primeira
  • Adicionado guardrail.input_tagging nos upstreams Bedrock do gateway de aplicativos Claude, que agrupa prompts nas tags de entrada que um filtro de ataques de prompt do Amazon Bedrock precisa; all_messages_and_system também marca o prompt do sistema
  • Modo rápido obsoleto para Opus 4.8 a partir de 30 de outubro de 2026; ele será removido em 30 de novembro de 2026. Após a remoção, as solicitações de modo rápido no Opus 4.8 retornam um erro e não voltam ao Opus 4.8 padrão. Migre para Opus 5.5 para manter a aceleração
  • Correção de comandos shell em execução no macOS e Linux quando o Claude Code sai sozinho, por exemplo, quando as credenciais são recusadas ou uma sessão na nuvem é arquivada
  • Corrigidos aliases de bash com quebras de linha em seu valor (exceto no Git Bash) e funções cujos nomes começam com um travessão, sendo distorcidos ou perdidos no shell da ferramenta Bash
  • Corrigidos scripts bash iniciados a partir da ferramenta Bash parando após o primeiro comando quando SHELLOPTS é exportado
  • Corrigidos ganchos do PowerShell que não bloqueavam o código de saída 2 quando o comando começa com uma conversão de tipo, param, using ou um atributo
  • Correção de algumas solicitações de rede suspensas quando uma resposta compactada era cortada ou corrompida
  • Corrigido sonnet, opus e haiku no Vertex AI e Amazon Bedrock mostrando um erro no meio da sessão em vez de mudar para um modelo mais antigo quando o mais novo ainda não está disponível para a conta ou região
  • Corrigido o gateway de aplicativos Claude que não verificava todos os nomes de solicitação de modelo em relação a availableModels, deniedModels e models; uma solicitação que nomeia um modelo bloqueado agora recebe 400 nomeando o campo
  • Corrigida a recusa de execução do claude auth login onde as configurações gerenciadas exigem um gateway de aplicativos Claude; em um terminal agora mostra o login do gateway
  • Corrigidas sessões --restricted carregando arquivos de fora dos diretórios de trabalho quando uma regra de permissão de leitura os cobria
  • Corrigidos prompts contendo caracteres invisíveis que precisavam de um segundo Enter para serem enviados; prompts simples agora são enviados limpos no primeiro Enter e os comandos ainda aguardam revisão
  • Correção de subagentes que herdavam o modelo de um subagente pai, movendo-se para o modelo principal quando um trabalho ou mensagem em segundo plano os despertava
  • Corrigida uma lista gerenciada de autoMode.allow sem que "$defaults" recuperasse as exceções integradas do --settings de um aplicativo host, uma primeira regra adicionada em /permissions ou /auto-mode-setup
  • Correção de sessões na nuvem e tarefas agendadas na nuvem que não eram marcadas como falhadas quando o modo automático parava um turno porque o servidor não retornava nenhum veredicto de segurança
  • Corrigida a saída de texto do claude -p que às vezes não informava por que o modo automático parava um turno quando um agente em segundo plano ainda estava em execução
  • Corrigido CLAUDE_CODE_AUTO_MODE_SERVER=1 sendo ignorado em sessões iniciadas por um aplicativo host (como Claude Desktop) atrás de um proxy ou gateway LLM com betas experimentais desativados
  • Correção de scripts do plug-in MCP headersHelper que recebiam um CLAUDE_PLUGIN_ROOT e URL do servidor corrompidos quando uma variável de ambiente nomeada pela credencial era definida como um valor de chave como 1
  • Corrigida a solicitação de controle SDK register_repo_root que não carregava o CLAUDE.md de um diretório fora do diretório de trabalho (com CLAUDE_CODE_ADDITIONAL_DIRECTORIES_CLAUDE_MD=1)
  • Corrigida a ferramenta Artefato mostrando ? para regras de acesso ao banco de dados de artefatos no nível self, e não citando essas regras de volta quando recusa uma republicação que as descartaria
  • Corrigido /model <id> que não avisava quando o modelo não era reconhecido por esta versão e a compactação automática assumiria uma janela de contexto de 200K
  • Corrigida a dica "mantenha espaço para falar" usando suas três exibições em uma sessão e mostrando uma tecla vazia quando o push-to-talk está desvinculado
  • Corrigido Grep e Glob que nunca retornavam quando o processo de pesquisa era interrompido no tempo limite, mas não saía, visto no Windows
  • Corrigido um caso raro em que a retomada de uma conversa não restaurava seu plano, quando /clear ou /resume era executado enquanto parte da conversa ainda estava sendo salva
  • Correção da configuração de primeira execução que eliminava palavras das notas de segurança e da explicação de configuração do terminal em terminais estreitos
  • Corrigido o cartão de pesquisa Enterprise recebendo 1 ou 0 digitado após uma pequena pausa; uma resposta digitada agora precisa de Enter
  • Corredor auto-hospedado: Corrigida mensagem enviada enquanto Claude estava trabalhando sendo respondida após uma Parada, após a substituição do processo da sessão
  • Executor auto-hospedado: Corrigido o botão liga/desliga de um servidor MCP que às vezes era perdido quando uma sessão era movida para uma nova máquina
  • Windows: corrigida a ferramenta Bash perdendo seus aliases e funções no Git Bash quando o arquivo rc define errexit e pipefail e apenas aliases winpty, ou nenhum, são definidos
  • /code-review aprimorado iniciado na guia Código no Claude Desktop ou na web: as sessões na nuvem e claude remote-control agora mostram o cartão de descobertas, não uma lista de texto simples
  • /diff aprimorado em repositórios grandes: cada atualização geralmente executa um comando git de repositório completo a menos e as atualizações são espaçadas quando o git está lento
  • Melhoradas as mensagens mostradas quando /ultrareview, uma sessão de nuvem ou um agente de nuvem não encontra nenhum controle remoto GitHub: agora dizem para criar um repositório em https://github.com/new, e /ultrareview não sugere mais um comando gh que gh rejeita
  • Erros de certificado SSL aprimorados para nomear as causas prováveis, entre elas um servidor que deixa de fora um certificado intermediário e a correção para cada um
  • Modo automático alterado para que uma lista autoMode.allow sem "$defaults" não remova mais a regra integrada em prompts de tarefas agendadas
  • Configurações gerenciadas pelo servidor alteradas para logins Team e Enterprise: configurações obtidas do API da Anthropic agora se aplicam sem solicitação de aprovação, e uma cópia armazenada que não é verificada é recusada
  • [VSCode] Adicionado login em um gateway de aplicativos Claude a partir do painel de bate-papo, sem necessidade de terminal
  • [VSCode] Alterado ultrathink para executar seu turno no esforço xhigh e aparecer em um arco-íris na caixa de chat, como no terminal
  • [VSCode] Corrigido o controle deslizante Esforço, switch Ultracode e nome do modelo ausentes quando a configuração do modelo tem a tag [1m], como opus[1m]
  • [VSCode] Corrigido o histórico de perguntas secundárias salvas do /btw sendo excluído muito cedo enquanto um arquivo de configurações apresentava erros
  • [VSCode] Corrigida uma conversa que retornava ao modo Automático após recarregar ou reiniciar quando seu plano era aprovado com "Sim e aprovar edições manualmente"
  • [Sessões na nuvem] Adicionado um cartão de formulário às sessões na nuvem, para que você possa preencher ou decline um formulário solicitado por um servidor MCP em vez de a solicitação ser cancelada sem você vê-la
  • [Sessões na nuvem] Adicionada uma linha "Catching up…" que mostra enquanto uma sessão na nuvem ou de controle remoto para a qual você voltou ainda está atualizando suas mensagens
  • [Sessões na nuvem] Segredos de rede alterados para que os membros da empresa possam adicioná-los e excluí-los em seus próprios ambientes de nuvem, em vez de apenas visualizá-los
  • [Sessões na nuvem] Painel de alterações aprimorado para sessões na nuvem: a nota sobre o que a lista deixa de fora agora é um emblema ao lado do nome da ramificação, não uma linha acima da diferença
  • [Sessões na nuvem] Corrigida a pesquisa de arquivos no painel Arquivos de uma sessão na nuvem, mostrando pastas como caminhos ../.. após Claude mudar de diretório; os resultados agora mostram o caminho desde a raiz do projeto
  • [Claude Tag] Corrigida a recusa de Claude em editar ou anexar a um canvas criado em um canal do Slack, daquele canal, uma vez que o canvas também foi compartilhado com outro canal ou DM
  • [Claude Tag] Corrigidas respostas não marcadas que ficavam sem resposta em um tópico do Slack Connect quando ambas as organizações instalavam Claude e o Slack entregava a resposta ao aplicativo da outra organização
  • [Claude Tag] Corrigida uma lista de verificação de status ao vivo de uma tarefa agendada na nuvem no Slack que ficava pela metade; uma execução agora pode editar as mensagens de nível superior postadas durante essa execução
  • [Claude Tag] Alterou a resposta de um canal do Slack para mudar automaticamente para a opção "Como Claude participa" na página de configuração do canal e nas configurações de administração do Claude Tag
  • [Code Review] Adicionado um cartão de descobertas por gravidade à página de análise de Code Review, mostrando o total de descobertas do período, um gráfico diário empilhado por gravidade e a contagem de cada gravidade

claude-code v2.1.316

What's changed

  • Added CLAUDE_CODE_DISABLE_ULTRATHINK, which turns the ultrathink keyword off
  • Added pooled group budgets to the Claude apps gateway: one monthly budget that a group's members share, on top of each member's own limit, set with pooled_budget on the spend limits admin API
  • Added CLAUDE_CODE_DISABLE_LOOPED_CROSS_CERT_DROP to keep system cross-certificates that certify each other in a loop, for servers whose private CA needs one
  • Added CLAUDE_CODE_SUBAGENT_EFFORT to set the effort level subagents run at when nothing else names one, instead of inheriting the session's
  • Added managed.policy_mode: layered to the Claude apps gateway: every policy that matches a developer applies, each merged over the ones listed below it, not only the first
  • Added guardrail.input_tagging on Claude apps gateway Bedrock upstreams, which wraps prompts in the input tags that an Amazon Bedrock guardrail's prompt attacks filter needs; all_messages_and_system also tags the system prompt
  • Deprecated fast mode for Opus 4.8 as of October 30, 2026; it will be removed on November 30, 2026. After removal, fast mode requests on Opus 4.8 return an error and do not fall back to standard Opus 4.8. Migrate to Opus 5.5 to keep the speedup
  • Fixed shell commands being left running on macOS and Linux when Claude Code exits by itself, for example when credentials are refused or a cloud session is archived
  • Fixed bash aliases with line breaks in their value (except in Git Bash), and functions whose names start with a dash, being garbled or lost in the Bash tool's shell
  • Fixed bash scripts started from the Bash tool stopping after their first command when SHELLOPTS is exported
  • Fixed PowerShell hooks not blocking on exit code 2 when the command begins with a type cast, param, using or an attribute
  • Fixed some network requests hanging when a compressed response was cut off or corrupted
  • Fixed sonnet, opus and haiku on Vertex AI and Amazon Bedrock showing an error mid-session instead of switching to an older model when the newest is not yet available to the account or region
  • Fixed the Claude apps gateway not checking every model a request names against availableModels, deniedModels and models; a request that names a blocked model now gets a 400 naming the field
  • Fixed claude auth login refusing to run where managed settings require a Claude apps gateway; in a terminal it now shows the gateway sign-in
  • Fixed --restricted sessions uploading files from outside the working directories when a Read allow rule covered them
  • Fixed prompts containing invisible characters needing a second Enter to send; plain prompts now send cleaned on the first Enter, and commands still wait for review
  • Fixed sub-agents that inherited a parent sub-agent's model moving to the main model when a background job or message woke them
  • Fixed a managed autoMode.allow list without "$defaults" getting the built-in exceptions back from a host app's --settings, a first rule added in /permissions, or /auto-mode-setup
  • Fixed cloud sessions and cloud scheduled tasks not being marked as failed when auto mode stopped a turn because the server returned no safety verdict
  • Fixed claude -p text output sometimes not saying why auto mode stopped a turn when a background agent was still running
  • Fixed CLAUDE_CODE_AUTO_MODE_SERVER=1 being ignored in sessions started by a host application (such as Claude Desktop) behind a proxy or LLM gateway with experimental betas turned off
  • Fixed plugin MCP headersHelper scripts receiving a corrupted CLAUDE_PLUGIN_ROOT and server URL when a credential-named environment variable was set to a switch value such as 1
  • Fixed the SDK register_repo_root control request not loading the CLAUDE.md of a directory outside the working directory (with CLAUDE_CODE_ADDITIONAL_DIRECTORIES_CLAUDE_MD=1)
  • Fixed the Artifact tool showing ? for artifact database access rules at the self level, and not quoting those rules back when it refuses a republish that would drop them
  • Fixed /model <id> not warning when the model isn't recognized by this version and auto-compact will assume a 200K context window
  • Fixed the "hold space to speak" hint using up its three showings in one session, and showing an empty key when push-to-talk is unbound
  • Fixed Grep and Glob never returning when the search process is killed at the timeout but does not exit, seen on Windows
  • Fixed a rare case where resuming a conversation did not restore its plan, when /clear or /resume had been run while part of that conversation was still being saved
  • Fixed first-run setup dropping words from the security notes and the terminal-setup explanation in narrow terminals
  • Fixed the Enterprise survey card taking a typed 1 or 0 after a short pause; a typed answer now needs Enter
  • Self-hosted runner: Fixed a message sent while Claude was working being answered after a Stop, once the session's process had been replaced
  • Self-hosted runner: Fixed an MCP server's on/off switch sometimes being lost when a session moved to a new machine
  • Windows: Fixed the Bash tool losing your aliases and functions in Git Bash when the rc file sets errexit and pipefail and only winpty aliases, or none, are defined
  • Improved /code-review started from the Code tab in Claude Desktop or on the web: cloud and claude remote-control sessions now show the findings card, not a plain-text list
  • Improved /diff on large repositories: each refresh usually runs one fewer full-repository git command, and refreshes are spaced out when git is slow
  • Improved the messages shown when /ultrareview, a cloud session or a cloud agent finds no GitHub remote: they now say to create a repository at https://github.com/new, and /ultrareview no longer suggests a gh command that gh rejects
  • Improved SSL certificate errors to name the likely causes, among them a server that leaves out an intermediate certificate, and the fix for each
  • Changed auto mode so that an autoMode.allow list without "$defaults" no longer removes the built-in rule on scheduled-task prompts
  • Changed server-managed settings for Team and Enterprise logins: settings fetched from Anthropic's API now apply without an approval prompt, and a stored copy that doesn't verify is refused
  • [VSCode] Added sign-in to a Claude apps gateway from the chat panel, with no terminal needed
  • [VSCode] Changed ultrathink to run its turn at xhigh effort and show in a rainbow in the chat box, as in the terminal
  • [VSCode] Fixed the missing Effort slider, Ultracode switch and model name when the model setting has the [1m] tag, such as opus[1m]
  • [VSCode] Fixed saved /btw side-question history being deleted too early while a settings file has errors
  • [VSCode] Fixed a conversation coming back in Auto mode after a reload or restart when its plan was approved with "Yes, and manually approve edits"
  • [Cloud sessions] Added a form card to cloud sessions, so you can fill in or decline a form an MCP server asks for instead of the request being canceled without you seeing it
  • [Cloud sessions] Added a "Catching up…" line that shows while a cloud or Remote Control session you switch back to is still bringing its messages up to date
  • [Cloud sessions] Changed network secrets so Enterprise members can add and delete them on their own cloud environments, instead of only viewing them
  • [Cloud sessions] Improved the Changes pane for cloud sessions: the note about what the list leaves out is now a badge beside the branch name, not a row above the diff
  • [Cloud sessions] Fixed file search in a cloud session's Files pane showing folders as ../.. paths after Claude changed directory; results now show their path from the project's root
  • [Claude Tag] Fixed Claude refusing to edit or append to a canvas it made in a Slack channel, from that channel, once the canvas was also shared to another channel or a DM
  • [Claude Tag] Fixed untagged replies going unanswered in a Slack Connect thread when both organizations have installed Claude and Slack delivered the reply to the other organization's app
  • [Claude Tag] Fixed a cloud scheduled task's live status checklist in Slack staying half-done; a run can now edit the top-level messages it posted during that run
  • [Claude Tag] Changed a Slack channel's Respond automatically switch to a "How Claude participates" choice on the channel's Configure page and in Claude Tag admin settings
  • [Code Review] Added a findings-by-severity card to the Code Review analytics page, showing the period's total findings, a daily chart stacked by severity, and each severity's count
