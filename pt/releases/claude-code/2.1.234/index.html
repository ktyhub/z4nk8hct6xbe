código claude v2.1.234

O que mudou

  • Adicionada a variável de ambiente opcional CLAUDE_CODE_PROJECT_DIR_NAME: hosts que fornecem a cada sessão seu próprio diretório de configuração podem escolher um nome abreviado para o diretório de transcrição por projeto
  • Adicionada a ação de atalho de teclado selection:clear, para que uma tecla possa ser vinculada para limpar uma seleção de texto no aplicativo; também funciona na visualização de agentes
  • Adicionado um emblema de solicitação de mesclagem GitLab ao rodapé e à linha de status: repositórios com um controle remoto GitLab e um glab autenticado CLI mostram MR !N com estados rascunho/pendente/verde
  • Claude Code agora continua sua sessão automaticamente quando o limite de uso do claude.ai é redefinido; desligue-o no /config ("Continuar automaticamente no limite de uso")
  • Claude agora é instruído a usar o e-mail da sua conta apenas para identificá-lo e não enviá-lo para serviços não relacionados, a menos que você solicite
  • Segurança: leituras remotas de arquivos, restauração de sessão, inclusão de CLAUDE.md, scripts de fluxo de trabalho e uploads de arquivos agora rejeitam caminhos de namespace do Windows NT (\??\), fortalecendo os acessos restantes a arquivos de pré-aprovação contra o vetor de vazamento de credenciais NTLM
  • Corrigido o modo automático em sessões muito longas, verificando e negando repetidamente o acesso à rede dos comandos em sandbox após a conversa ter sido compactada
  • Corrigidas respostas de permissão no escopo da sessão (incluindo negações) que eram descartadas ao responder a solicitações de permissão da ferramenta de subagente em segundo plano
  • Corrigida uma falha quando uma resposta API no caminho alternativo sem streaming (normalmente por meio de gateways de terceiros) continha um bloco de pensamento sem seu campo de pensamento ou um bloco de texto sem seu campo de texto
  • Corrigida a renderização de markdown que se tornava extremamente lenta para algumas mensagens contendo sequências Unicode incomuns
  • Corrigido SendMessage rejeitando um destinatário copiado de ListAgents quando o nome da sessão tem limite de 200 caracteres ou muitos emojis
  • Corrigida detecção de repositório que fazia leitura incorreta do host de controles remotos git com informações de usuário incomuns, produzindo links e comportamento específico do repositório para o host errado
  • Correção de diagnóstico de MCP que imprime segredos resolvidos: avisos de conflito de escopo agora mostram o formulário ${VAR} configurado e detalhes de falha de conexão mostram apenas a origem do servidor
  • Listas de permissão strictKnownMarketplaces corrigidas aceitando fontes de mercado git estilo SCP cujo host difere daquele ao qual o git realmente se conectaria
  • Corrigido texto modal, como o URL /login OAuth, perdendo caracteres quando copiado em tela cheia
  • Corrigida uma regra horizontal --- na marcação renderizada indo para a linha depois dela
  • Correção de comandos de shell consecutivos divididos em várias linhas "Ran 1 shell command" quando atualizações de tarefas/tarefas eram intercaladas entre elas
  • Corrigidas caixas de diálogo como /permissions abertas enquanto um comando shell ! estava em execução, sendo descartadas quando o comando terminava
  • Corrigido um comando shell ! na fila sendo enviado ao modelo como texto simples após pressionar a seta para cima para editar a entrada na fila
  • Correção de mensagens na fila que reapareciam no histórico de prompt enquanto ainda estavam na fila, Esc ao selecionar uma mensagem na fila não interrompe mais o turno e o modo ! não trava mais após um envio no meio do turno
  • Corrigida a aceitação da mensagem "Experimentar o novo renderizador de tela cheia?" prompt para reiniciar a sessão sem seu modo de permissão (por exemplo, --dangerously-skip-permissions), regras de permissão/negação da ferramenta, modelo ou sinalizadores de esforço
  • Corrigida a queda do /tui nas regras de lançamento do --allowed-tools/--disallowed-tools ao reiniciar; agora declines para mudar, com o motivo, quando a sessão tem restrições, uma reinicialização não pode ser transferida
  • Corrigidos prompts trust que omitiam o aviso de escopo de todo o repositório quando o diretório era visto pela primeira vez antes de o repositório existir lá
  • Corrigido um caso em que uma guia diff do IDE fechando durante um novo prompt de permissão poderia responder ao novo prompt com a entrada anterior
  • Corrigido: arquivos enviados ao usuário durante sessões de controle remoto hospedadas por Claude Code Desktop ou VS Code agora são carregados, então eles abrem no telefone e na web em vez de mostrar um cartão vazio
  • Corrigido: após /login enquanto CLAUDE_CODE_OAUTH_TOKEN está definido, o lembrete de token obsoleto não vaza mais no turno automaticamente retomado de Claude - agora aparece apenas para você
  • Corrigido: as visualizações de permissão agora são retransmitidas apenas para servidores de canal admitidos pela porta trust de entrada, e a desativação explícita da capacidade de permissão do servidor é respeitada
  • Corrigido: o mascaramento de credenciais em visualizações de permissão retransmitidas não pode mais ocultar comandos, caminhos ou destinos do aprovador; blocos de chave privada superdimensionados agora são editados sob redação total
  • Corrigido: os tokens do provedor API que são mascarados nas visualizações de permissão agora são mascarados mesmo quando seguidos diretamente por delimitadores de shell
  • Correção de mensagens entre sessões do Claude Desktop sendo descartadas silenciosamente pela sessão do destinatário quando as mensagens entre sessões eram lidas como desativadas, o que deixava a consulta do remetente "pensando" por muitos minutos
  • Controle remoto: fazer login neste computador em uma conta ou organização claude.ai diferente agora interrompe a sessão em execução em segundos e informa o motivo, em vez de um HTTP 404 enganoso horas depois
  • Sessões de controle remoto iniciadas no Claude Code Desktop ou VS Code agora mantêm os telefones e claude.ai/code atualizados no modo de permissão da sessão (e claude.ai/code no modelo) conforme eles mudam
  • Controle remoto: escolhas de esforço feitas em um telefone ou em claude.ai/code agora se aplicam a sessões hospedadas em terminal e Desktop/VS Code, e a sessão publica seu nível de esforço para clients conectados
  • SendMessage e ListAgents agora informam quando a lista de sessões da sua conta era muito longa para ser verificada completamente, em vez de tratar sessões não vistas como ausentes
  • A credencial de perfil Anthropic expirada agora aponta para /login quando um login claude.ai teria precedência
  • Melhoria na transcrição: seus próprios prompts agora renderizam markdown (blocos de código destacados, código embutido, listas) da mesma forma que as respostas
  • Melhorado o erro "API retornou uma resposta vazia ou malformada" para dizer o que retornou (tipo de conteúdo, tipo de corpo, tamanho, ID da solicitação) e por que a solicitação de streaming original falhou
  • Títulos de sessão gerados automaticamente aprimorados para serem lidos como nomes curtos e específicos (por exemplo, "bug do botão de login") em vez de frases reafirmando sua solicitação (por exemplo, "Corrigir o botão de login no celular")
  • Reduziu o custo de contexto de carregamento da habilidade claude-api integrada de aproximadamente 200 mil + tokens para aproximadamente 25 mil, carregando documentos de referência sob demanda
  • /permissions agora pode ser aberto enquanto Claude está trabalhando — as mudanças nas regras se aplicam ao resto do turno atual
  • /add-dir <path> agora pode ser usado enquanto Claude está trabalhando; As caixas de diálogo /add-dir, /autocompact, /theme, /help, /config e /advisor abrem no meio do giro na TUI em tela cheia
  • /goal agora se limpa com um aviso quando um turno morre devido a um erro irrecuperável (por exemplo, autenticação revogada, saldo de crédito esgotado ou estouro de contexto) em vez de permanecer armado
  • /goal: quando as tarefas em segundo plano mantêm uma meta esperando por mais de 30 minutos, Claude agora verifica-as em vez de esperar indefinidamente (configure CLAUDE_CODE_GOAL_CHECKIN_MINUTES=0 para cancelar)
  • claude setup-token agora rejeita argumentos extras inesperados em vez de ignorá-los silenciosamente
  • Esc alterado no modo de tela cheia para não limpar mais a seleção de texto do mouse: ele interrompe ou descarta normalmente e a seleção permanece destacada
  • Removida a linha redundante "Permitido pelo classificador de modo automático" que o modo automático mostrava em cada chamada de ferramenta do Agente
  • Removida a configuração "Modelo de companheiro de equipe padrão" do /config; companheiros de equipe de agente agora usam o modelo do líder, a menos que o spawn nomeie um
  • O contador de tempo decorrido no cabeçalho da ferramenta em execução foi esmaecido para que ele não concorra mais com as contagens em negrito
  • Notificações de tarefas em segundo plano entregues entre turnos agora são enviadas ao modelo dentro das tags <system-reminder>, correspondendo à entrega no meio do turno
  • Mantle: ignore a sonda de disponibilidade do pino de administrador na inicialização quando um modelo de loop principal já estiver escolhido
  • Windows: a inicialização não para mais em repetidas tentativas de renomeação quando ~/.claude.json é somente leitura

claude-code v2.1.234

What's changed

  • Added the optional CLAUDE_CODE_PROJECT_DIR_NAME environment variable: hosts that give each session its own config directory can choose a short name for the per-project transcript directory
  • Added the selection:clear keybinding action, so a key can be bound to clear an in-app text selection; also works in the agents view
  • Added a GitLab merge request badge to the footer and statusline: repos with a GitLab remote and an authenticated glab CLI show MR !N with draft/pending/green states
  • Claude Code now continues your session automatically when a claude.ai usage limit resets; turn it off in /config ("Continue automatically at usage limit")
  • Claude is now told to use your account email only to identify you, and not to send it to unrelated services unless you ask
  • Security: remote file reads, session restore, CLAUDE.md includes, workflow scripts and file uploads now reject Windows NT-namespace (\??\) paths, hardening the remaining pre-approval file accesses against the NTLM credential-leak vector
  • Fixed auto mode in very long sessions repeatedly re-checking and denying sandboxed commands' network access after the conversation had been compacted
  • Fixed session-scoped permission answers (including denies) being dropped when answering background subagent tool permission prompts
  • Fixed a crash when an API response on the non-streaming fallback path (typically via third-party gateways) contained a thinking block missing its thinking field or a text block missing its text field
  • Fixed markdown rendering becoming extremely slow for some messages containing unusual Unicode sequences
  • Fixed SendMessage rejecting a recipient copied from ListAgents when the session name is at the 200-character cap or emoji-heavy
  • Fixed repository detection mis-reading the host of git remotes with unusual userinfo, producing links and repo-specific behavior for the wrong host
  • Fixed MCP diagnostics printing resolved secrets: scope-conflict warnings now show the configured ${VAR} form, and connection-failure details show only the server origin
  • Fixed strictKnownMarketplaces allowlists accepting SCP-style git marketplace sources whose host differs from the one git would actually connect to
  • Fixed modal text such as the /login OAuth URL losing characters when copied in fullscreen
  • Fixed a --- horizontal rule in rendered markdown running into the line after it
  • Fixed consecutive shell commands splitting into multiple "Ran 1 shell command" rows when todo/task updates were interleaved between them
  • Fixed dialogs like /permissions opened while a ! shell command was running being dismissed when the command finished
  • Fixed a queued ! shell command being sent to the model as plain text after pressing up-arrow to edit the queued input
  • Fixed queued messages reappearing in the prompt history while still queued, Esc while selecting a queued message no longer interrupts the turn, and ! mode no longer sticks after a mid-turn submit
  • Fixed accepting the "Try the new fullscreen renderer?" prompt restarting the session without its permission mode (e.g. --dangerously-skip-permissions), tool allow/deny rules, model or effort flags
  • Fixed /tui dropping launch --allowed-tools/--disallowed-tools rules when it restarts; it now declines to switch, with the reason, when the session has restrictions a restart can't carry over
  • Fixed trust prompts omitting the repository-wide scope warning when the directory was first seen before the repository existed there
  • Fixed a case where an IDE diff tab closing during a permission re-prompt could answer the new prompt with the previous input
  • Fixed: files sent to the user during Remote Control sessions hosted by Claude Code Desktop or VS Code now upload, so they open on phone and web instead of showing an empty card
  • Fixed: after /login while CLAUDE_CODE_OAUTH_TOKEN is set, the stale-token reminder no longer leaks into Claude's automatically resumed turn — it now appears only to you
  • Fixed: permission previews now relay only to channel servers admitted by the inbound trust gate, and a server's explicit permission-capability opt-out is honored
  • Fixed: credential masking on relayed permission previews can no longer hide commands, paths, or destinations from the approver; oversized private-key blocks now redact under full-strength redaction
  • Fixed: provider API tokens that mask on permission previews now mask even when directly followed by shell delimiters
  • Fixed Claude Desktop inter-session messages being silently dropped by the recipient session when cross-session messaging read as disabled, which left the sender's query "thinking" for many minutes
  • Remote Control: signing this computer in to a different claude.ai account or organization now stops the running session within seconds and says why, instead of a misleading HTTP 404 hours later
  • Remote Control sessions started from Claude Code Desktop or VS Code now keep phones and claude.ai/code updated on the session's permission mode (and claude.ai/code on the model) as they change
  • Remote Control: effort picks made on a phone or on claude.ai/code now apply to terminal- and Desktop/VS Code-hosted sessions, and the session publishes its effort level to connected clients
  • SendMessage and ListAgents now say when your account's session list was too long to check completely, instead of treating unseen sessions as absent
  • Expired Anthropic profile credential now points you at /login when a claude.ai login would take precedence
  • Improved the transcript: your own prompts now render markdown (highlighted code blocks, inline code, lists) the same way replies do
  • Improved the "API returned an empty or malformed response" error to say what came back (content type, body kind, size, request ID) and why the original streaming request failed
  • Improved auto-generated session titles to read as short, specific names (e.g. "Login button bug") rather than sentences restating your request (e.g. "Fix the login button on mobile")
  • Reduced the context cost of loading the built-in claude-api skill from ~200k+ tokens to ~25k by loading reference docs on demand
  • /permissions can now be opened while Claude is working — rule changes apply to the rest of the current turn
  • /add-dir <path> can now be used while Claude is working; /add-dir, /autocompact, /theme, /help, /config and /advisor dialogs open mid-turn in the fullscreen TUI
  • /goal now clears itself with a notice when a turn dies on an unrecoverable error (e.g. revoked auth, an exhausted credit balance, or a context overflow) instead of staying armed
  • /goal: when background tasks keep a goal waiting for 30+ minutes, Claude now checks in on them instead of waiting indefinitely (set CLAUDE_CODE_GOAL_CHECKIN_MINUTES=0 to opt out)
  • claude setup-token now rejects unexpected extra arguments instead of silently ignoring them
  • Changed Esc in fullscreen mode to no longer clear a mouse text selection: it interrupts or dismisses as usual and the selection stays highlighted
  • Removed the redundant "Allowed by auto mode classifier" line that auto mode showed under every Agent tool call
  • Removed the "Default teammate model" setting from /config; agent-team teammates now use the leader's model unless the spawn names one
  • Dimmed the elapsed-time counter on the running tool header so it no longer competes with the bold counts
  • Background task notifications delivered between turns are now sent to the model inside <system-reminder> tags, matching mid-turn delivery
  • Mantle: skip the admin-pin availability probe at startup when a main-loop model is already picked
  • Windows: startup no longer stalls on repeated rename retries when ~/.claude.json is read-only
