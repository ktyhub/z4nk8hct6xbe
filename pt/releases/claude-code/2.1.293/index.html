código claude v2.1.293

O que mudou

  • Adicionado Claude Haiku 5.5 (claude-haiku-5-5), agora o modelo Haiku padrão no Anthropic API — contexto 1M, $0.10/$0.50 por Mtok ($0.50/$2.50 para prompts acima de 100K)
  • Adicionado agentType à carga útil subagentStatusLine, para que os scripts possam diferenciar os tipos de subagentes personalizados
  • Adicionado isDeferred ao $.tool.register para mods: false lista o esquema da ferramenta no prompt desde o início, em vez de atrás da pesquisa de ferramentas
  • Foi corrigido um problema em que Claude às vezes tratava suas últimas ações antes de uma compactação de contexto como feitas depois dela, e retraía ou refazia o trabalho finalizado
  • Corrigido um vazamento de memória em que uma conexão HTTP MCP mantinha todas as solicitações enviadas até ser fechada
  • Corrigida mensagem enviada enquanto Claude estava trabalhando sendo perdida quando ← movia a sessão para segundo plano; se uma mensagem na fila não puder ser movida, ← agora permanece onde está e diz isso
  • Corrigido o esforço /model ←/→ ultrapassando o nível mais alto ou mais baixo, o que poderia acidentalmente salvar Low como o esforço padrão de um modelo
  • Corrigido /tui desconectando Claude no Chrome em uma sessão iniciada com --chrome, e ignorando --no-chrome
  • Corrigido o problema de Claude sendo instruído a continuar ou enviar mensagens aos subagentes com SendMessage em sessões, inclusive retomadas, onde um host, uma regra de permissão ou uma lista --tools removeu essa ferramenta
  • Subagentes corrigidos e sessões --agent sendo informados de que uma ferramenta integrada foi desativada para toda a sessão quando apenas sua própria lista de ferramentas a deixava de fora
  • Corrigida a descrição editada de uma habilidade sincronizada com claude.ai que às vezes não alcançava o modelo até uma nova conversa ou /clear
  • Corrigido claude logs, stop, kill, rm e claude daemon status, stop, uninstall às vezes desconectando você quando seu login expirou ou estava prestes a expirar
  • Corrigida a contagem de agentes do rodapé que desaparecia após uma falha momentânea na leitura da pasta de sessões (por exemplo, muitos arquivos abertos)
  • Corrigido um agente personalizado chamado worker sendo mostrado como "Agente" quando é iniciado, e o título da caixa de diálogo de detalhes do agente perdia o tipo de agente quando o agente terminava
  • Corrigida a linha de transcrição da ferramenta Artefato lendo brevemente Artifact("(unprintable path)") enquanto uma chamada de publicação ainda estava sendo transmitida
  • Corrigido o upload do /ultrareview no Linux recusando erroneamente alguns repositórios, como um dentro de outro checkout, sobre um arquivo de configurações que "não pôde ser analisado" enquanto um comando em sandbox estava em execução
  • Corrigida a recusa de upload do /ultrareview em arquivos de índice dividido, avisando um comando git que poderia deixar o git incapaz de ler seu índice
  • Corrigidas respostas em sessões muito longas de controle remoto e na nuvem que ainda podiam aparecer um bloco de cada vez em vez de transmitir
  • Corrigido o controle remoto que carregava o histórico inicial de uma sessão novamente após cada recuperação de credencial
  • Corrigido o relatório PushNotification de "Controle remoto inativo" em sessões iniciadas com claude remote-control
  • Corrigidos os ganchos de um mod em eventos classic.* sendo ignorados enquanto o plugin travava reinicializações do trabalhador, o que deixava ganchos de configurações para responder sem eles
  • Corrigida falha de claude plugin test para mods que chamam $.session.append; os testes podem ler as linhas anexadas de volta com o novo mock.session
  • Corrigido claude plugin eval recusando toda execução de concessão de Bash em Macs com Docker Desktop (links em ~/.docker/bin); a recusa agora indica qual parte de um armazenamento de credenciais mantinha o link
  • Corrigido o gateway de aplicativos Claude que se recusava a iniciar quando uma política desktop definia as chaves integradas do navegador do Claude Desktop, como builtinBrowserEnabled
  • Corrigido claude agents oferecendo permissões de bypass que sessões em segundo plano ignoravam quando o consentimento era salvo apenas em .claude/settings.local.json ou em um arquivo --settings; agora ele pede consentimento primeiro, e uma sessão que ignora o bypass mostra um breve aviso que permanece
  • Corrigido o problema de ← colocar uma sessão em segundo plano após 10 segundos enquanto o prompt continha texto não enviado (agora cancela a movimentação) ou uma pergunta aguardava sua resposta
  • Corrigido Esc, ou Não sem feedback, em um prompt de permissão que não parava a curva quando ← acabava de ser pressionado para mover a sessão para segundo plano
  • Correção da visualização dos agentes substituindo brevemente a lista de sessões por linhas de espaço reservado quando a pasta de sessões não podia ser lida (por exemplo, muitos arquivos abertos)
  • Corrigidas regras com escopo de caminho e arquivos CLAUDE.md aninhados que não carregavam quando Claude visualiza um arquivo com um comando cat, head, tail, sed -n ou grep de arquivo único na ferramenta Bash em vez da ferramenta Read
  • Corrigido texto colado que começa e termina com as mesmas palavras, às vezes sendo enviado para Claude como se tivesse sido digitado
  • Corrigido um nome de habilidade no texto colado sendo tratado como digitado quando um acento digitado ou colado logo após a colagem ser mesclado em sua última letra
  • Corrigido /feedback retornando à lista de rascunhos após Ctrl+O ou Ctrl+Z durante o envio de um relatório, impossibilitando o cancelamento do envio
  • Corrigida a parada silenciosa do claude purge (saída 0 ou travamento em um terminal) quando um arquivo ou pasta não podia ser excluído; agora exclui o resto, lista o que não pôde excluir e sai de 1
  • Corrigidas verificações de keybindings.json: um único " " (tecla de espaço) não é mais relatado como um erro, e teclas como "ctrl+ k" agora recebem um aviso
  • Corrigido o modo vim >> e << em uma linha com apenas espaços deixando o cursor além do final da linha, onde um x seguinte não excluía nada
  • Modo vim corrigido: após excluir linhas inteiras no modo Visual (V e depois d) o cursor pousa no primeiro não-branco e . após atuar na linha do cursor
  • Windows: corrigida a interrupção de uma linha de status, gancho ou comando shell, às vezes encerrando um processo não relacionado que recebeu o mesmo ID de processo
  • Revertida a alteração da mensagem de negação do modo automático do 2.1.281 que dizia a Claude que uma negação cobre o resultado, não apenas o comando exato
  • Revertida a correção do 2.1.290 para sessões de nuvem que permaneciam adormecidas após a reinicialização de um contêiner perder uma ativação pendente do /loop ou tarefa agendada; Claude não é mais avisado e a sessão fica dormindo
  • Inicialização aprimorada para organizações Team e Enterprise: políticas e configurações gerenciadas são obtidas mais cedo e uma solicitação paralisada é repetida após 3 segundos
  • Claude aprimorado no Chrome: menos ações de página são recusadas quando o navegador demora para relatar suas guias
  • Melhorada a mensagem do Claude no Chrome em sessões na nuvem quando o navegador não pode ser acessado: se você pertence a mais de uma organização, agora diz que a extensão deve estar conectada à mesma e como alterar isso
  • Melhorada a nota de comparação de edição do Bash para informar que os arquivos listados foram alterados durante a execução do comando, o que pode incluir gravações de outros processos
  • Artefatos aprimorados: Claude fixa bibliotecas em versões exatas com duas semanas ou mais
  • Alteração da sincronização de habilidades claude.ai para verificar alterações a cada 40 minutos, em vez de a cada 10, enquanto nenhuma sessão estiver em uso
  • Alterada a ordem das listas de agentes e dos servidores MCP anunciados ao modelo: nomes com caracteres não-ASCII agora são classificados após nomes ASCII
  • Alterado o registro do OpenTelemetry claude_code.at_mention para emitir no máximo 100 eventos de agente e 100 eventos de recurso MCP cada vez que um prompt é lido
  • Executor auto-hospedado: o orquestrador foi alterado para dormir de 4 a 6 segundos entre as pesquisas em vez de uma constante 5, para que várias réplicas de um ambiente parem de pesquisar ao mesmo tempo
  • [Claude Tag] Corrigido Claude no Slack dizendo que um espaço de trabalho não está configurado em canais Enterprise Grid compartilhados entre espaços de trabalho quando o Slack rotula uma mensagem com um espaço de trabalho que não está conectado
  • [Claude Tag] Corrigido Claude no Slack parando no meio de uma tarefa em um canal quando um administrador alterava os conectores, plug-ins, habilidades ou regras do canal; a mudança agora se aplica quando Claude terminar
  • [Claude Tag] Corrigida a solicitação de Claude no Slack para executar a rotina de um tópico agora com notas extras iniciando uma execução separada que não podia ser postada de volta; a execução agora continua nesse tópico
  • [Claude Tag] Corrigida a caixa de diálogo Adicionar um conector de um pacote de acesso nas configurações de administração do Claude Tag, mostrando todos os conectores do Google conectados após um login do Google
  • [Claude Tag] Configurações de administração do Claude Tag aprimoradas para listar um Enterprise Grid que ainda não está conectado, com um botão Conectar
  • [Claude Tag] Claude alterado no Slack para ingressar em canais de anúncios, onde apenas administradores podem postar, sem postar sua introdução
  • [Claude Tag] Alterado o limite de regras do canal nas configurações de administração do Claude Tag de 20 para 50 para cada espaço de trabalho e para a página do Slack em toda a organização
  • [Revisão de código] Caixa de diálogo Adicionar um repositório de revisão de código aprimorada para listar cada repositório que não pôde ser adicionado e por quê, como falta de acesso de gravação GitHub

claude-code v2.1.293

What's changed

  • Added Claude Haiku 5.5 (claude-haiku-5-5), now the default Haiku model on the Anthropic API — 1M context, $0.10/$0.50 per Mtok ($0.50/$2.50 for prompts over 100K)
  • Added agentType to the subagentStatusLine payload, so scripts can tell custom subagent types apart
  • Added isDeferred to $.tool.register for mods: false lists the tool's schema in the prompt from the start instead of behind tool search
  • Fixed Claude sometimes treating its own last actions before a context compaction as done after it, and retracting or redoing finished work
  • Fixed a memory leak where an HTTP MCP connection kept every request it had sent until it closed
  • Fixed a message sent while Claude was working being lost when ← moved the session to the background; if a queued message can't move, ← now stays put and says so
  • Fixed /model effort ←/→ wrapping past the highest or lowest level, which could accidentally save Low as a model's default effort
  • Fixed /tui disconnecting Claude in Chrome in a session started with --chrome, and ignoring --no-chrome
  • Fixed Claude being told to continue or message subagents with SendMessage in sessions, including resumed ones, where a host, a permission rule or a --tools list removed that tool
  • Fixed subagents and --agent sessions being told a built-in tool was disabled for the whole session when only their own tool list left it out
  • Fixed a claude.ai-synced skill's edited description sometimes not reaching the model until a new conversation or /clear
  • Fixed claude logs, stop, kill, rm and claude daemon status, stop, uninstall sometimes signing you out when your login had expired or was about to
  • Fixed the footer's agents count disappearing after a momentary failure to read the sessions folder (for example, too many open files)
  • Fixed a custom agent named worker being shown as "Agent" when it starts, and the agent detail dialog's title losing the agent type once the agent finishes
  • Fixed the Artifact tool's transcript row briefly reading Artifact("(unprintable path)") while a publish call was still streaming in
  • Fixed the /ultrareview upload on Linux wrongly refusing some repositories, such as one inside another checkout, over a settings file that "could not be parsed" while a sandboxed command was running
  • Fixed the /ultrareview upload's refusal over split-index files advising a git command that could leave git unable to read its index
  • Fixed replies in very long Remote Control and cloud sessions that could still appear a block at a time instead of streaming in
  • Fixed Remote Control uploading a session's starting history again after every credential recovery
  • Fixed PushNotification reporting "Remote Control inactive" in sessions started with claude remote-control
  • Fixed a mod's hooks on classic.* events being skipped while the plugin hooks worker restarts, which left settings hooks to answer without them
  • Fixed claude plugin test failing for mods that call $.session.append; tests can read the appended rows back with the new mock.session
  • Fixed claude plugin eval refusing every Bash-granting run on Macs with Docker Desktop (links under ~/.docker/bin); the refusal now names which part of a credential store held the link
  • Fixed the Claude apps gateway refusing to start when a desktop policy sets Claude Desktop's built-in browser keys, such as builtinBrowserEnabled
  • Fixed claude agents offering bypass permissions that background sessions then ignored when consent was saved only in .claude/settings.local.json or a --settings file; it now asks for consent first, and a session that ignores bypass shows a short notice that stays
  • Fixed ← backgrounding a session after 10 seconds while the prompt held unsent text (it now cancels the move) or a question was waiting for your answer
  • Fixed Esc, or No without feedback, on a permission prompt not stopping the turn when ← had just been pressed to move the session to the background
  • Fixed the agents view briefly replacing the session list with placeholder rows when the sessions folder could not be read (for example, too many open files)
  • Fixed path-scoped rules and nested CLAUDE.md files not loading when Claude views a file with a single-file cat, head, tail, sed -n or grep command in the Bash tool instead of the Read tool
  • Fixed pasted text that begins and ends with the same words sometimes being sent to Claude as if it had been typed
  • Fixed a skill name in pasted text being treated as typed when an accent typed or pasted right after the paste merged into its last letter
  • Fixed /feedback returning to the drafts list after Ctrl+O or Ctrl+Z while a report was sending, leaving the send impossible to cancel
  • Fixed claude purge stopping silently (exit 0, or a hang in a terminal) when a file or folder could not be deleted; it now deletes the rest, lists what it could not delete, and exits 1
  • Fixed keybindings.json checks: a lone " " (space key) is no longer reported as an error, and keys like "ctrl+ k" now get a warning
  • Fixed vim mode >> and << on a line of only spaces leaving the cursor past the end of the line, where a following x deleted nothing
  • Fixed vim mode: after deleting whole lines in Visual mode (V then d) the cursor lands on the first non-blank, and . after it acts on the cursor's line
  • Windows: Fixed stopping a status line, hook, or shell command sometimes terminating an unrelated process that had been given the same process ID
  • Reverted the auto mode denial message change from 2.1.281 that told Claude a denial covers the outcome, not only the exact command
  • Reverted the 2.1.290 fix for cloud sessions staying asleep after a container restart lost a pending /loop wakeup or scheduled task; Claude is no longer told, and the session stays asleep
  • Improved startup for Team and Enterprise organizations: policy and managed settings are fetched earlier, and a stalled request is retried after 3 seconds
  • Improved Claude in Chrome: fewer page actions are refused when the browser is slow to report its tabs
  • Improved the Claude in Chrome message in cloud sessions when the browser can't be reached: if you belong to more than one organization, it now says the extension must be signed in to the same one, and how to change that
  • Improved the Bash edit diff note to say the listed files changed while the command ran, which can include writes by other processes
  • Improved artifacts: Claude pins libraries to exact versions two weeks old or older
  • Changed claude.ai skill syncing to check for changes about every 40 minutes, instead of every 10, while no session is in use
  • Changed the order of agent lists and of MCP servers announced to the model: names with non-ASCII characters now sort after ASCII names
  • Changed OpenTelemetry claude_code.at_mention logging to emit at most 100 agent and 100 MCP-resource events each time a prompt is read
  • Self-hosted runner: Changed the orchestrator to sleep 4 to 6 seconds between polls instead of a constant 5, so several replicas for one environment stop polling at the same moment
  • [Claude Tag] Fixed Claude in Slack saying a workspace isn't set up in Enterprise Grid channels shared across workspaces when Slack labels a message with a workspace that isn't connected
  • [Claude Tag] Fixed Claude in Slack stopping mid-task in a channel when an admin changed the channel's connectors, plugins, skills or rules; the change now applies once Claude finishes
  • [Claude Tag] Fixed asking Claude in Slack to run a thread's routine now with extra notes starting a separate run that couldn't post back; the run now continues in that thread
  • [Claude Tag] Fixed an access bundle's Add a connector dialog in Claude Tag admin settings showing every Google connector as connected after one Google sign-in
  • [Claude Tag] Improved Claude Tag admin settings to list an Enterprise Grid that isn't connected yet, with a Connect button
  • [Claude Tag] Changed Claude in Slack to join announcement channels, where only admins can post, without posting its intro
  • [Claude Tag] Changed the limit on channel rules in Claude Tag admin settings from 20 to 50 for each workspace and for the organization-wide Slack page
  • [Code Review] Improved Code Review's Add a repository dialog to list each repository that couldn't be added and why, such as missing GitHub write access
