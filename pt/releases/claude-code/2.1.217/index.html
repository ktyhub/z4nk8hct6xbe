código claude v2.1.217

O que mudou

  • Adicionado preenchimento automático de código de acesso emoji na entrada do prompt: digite :heart: para inserir ❤️ ou :hea para sugestões - desative com a configuração emojiCompletionEnabled
  • Adicionados avisos quando as gravações de transcrições falham (por exemplo, disco cheio) ou quando o salvamento da sessão está desativado devido a uma variável de ambiente herdada, em vez de perder as transcrições silenciosamente
  • Corrigido um vazamento de memória em que as saídas truncadas da ferramenta MCP mantinham o resultado completo não truncado na memória pelo resto da sessão
  • Corrigidas falhas de atualização automática do Windows que poderiam deixar o claude.exe ausente; atualizações com falha agora restauram o executável preservado automaticamente
  • Corrigido o isolamento da sessão em segundo plano que não canonizava diretórios de trabalho com links simbólicos, o que poderia permitir que as sessões escapassem da pasta do espaço de trabalho
  • Corrigida a compactação automática que nunca era acionada para Claude Opus 4.8 em Bedrock e /compact falhando uma vez acima do limite
  • Corrigidas configurações corporativas de mTLS, verificação de TLS, escopo OAuth e proxy sendo ignoradas nas sessões do Claude Desktop
  • Foi corrigido um problema em que o anúncio de inicialização do modo leitor de tela era interrompido pela primeira renderização do prompt e a re-renderização da linha de status de pensamento a cada poucos segundos para atualizar o tempo decorrido e a contagem de tokens
  • Corrigidas configurações gerenciadas que faziam com que OTEL_EXPORTER_OTLP_ENDPOINT não governasse todos os sinais – substituições específicas de sinais de escopo inferior não redirecionam mais a telemetria para longe do endpoint gerenciado
  • Correção de falha de --resume/--continue e /resume com TypeError quando uma transcrição tem uma entrada de anexo malformada
  • Correção de sessões de controle remoto que não exibiam um prompt de permissão pendente ou uma caixa de diálogo para visualizadores que se conectavam depois que ele aparecia
  • Correção de shells em segundo plano que às vezes se tornavam impossíveis de parar depois que uma sessão era enviada para segundo plano (/background ou ←) ou quando a sessão terminava em uma máquina muito carregada, mais visível no Windows
  • Corrigido um valor de frontmatter de caminhos CLAUDE.md ou SKILL.md com muitos grupos de chaves OOM matando ou paralisando o CLI na inicialização - a expansão de chaves agora é limitada pelo orçamento
  • Corrigida a visualização da transcrição alinhada com a área de entrada ao anexar a uma sessão inicial em segundo plano; agora deixa o mesmo espaço de uma linha que o layout ao vivo, de modo que a transcrição não muda mais quando a sessão assume
  • Links de emblema PR de rodapé aprimorados para serem hiperlinks clickable mesmo quando o suporte do terminal não pode ser detectado (por exemplo, através de ssh/tmux); configure FORCE_HYPERLINK=0 para cancelar
  • Alterado o aviso de expiração de login para aparecer 3 dias antes da expiração em vez de 5
  • Limitou a dica de sugestão do plug-in de design de front-end em 3 impressões vitalícias, em vez de repetir indefinidamente
  • Adicionado um limite para subagentes em execução simultânea (padrão 20, substituição por CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS) para que uma mensagem não possa distribuir agentes em segundo plano ilimitados
  • Subagentes alterados para não gerar mais subagentes aninhados por padrão; configure CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH para permitir um aninhamento mais profundo
  • Corrigido --max-budget-usd que não parava os subagentes em segundo plano: quando o limite é atingido, novos spawns são negados e a execução de agentes em segundo plano é interrompida

claude-code v2.1.217

What's changed

  • Added emoji shortcode autocomplete in the prompt input: type :heart: to insert ❤️, or :hea for suggestions — disable with the emojiCompletionEnabled setting
  • Added warnings when transcript writes are failing (e.g. disk full) or when session saving is off due to an inherited environment variable, instead of losing transcripts silently
  • Fixed a memory leak where truncated MCP tool outputs kept the full untruncated result in memory for the rest of the session
  • Fixed Windows auto-update failures that could leave claude.exe missing; failed updates now restore the preserved executable automatically
  • Fixed background session isolation not canonicalizing symlinked working directories, which could let sessions escape their workspace folder
  • Fixed auto-compact never triggering for Claude Opus 4.8 on Bedrock and /compact failing once over the limit
  • Fixed corporate mTLS, TLS-verify, OAuth scope, and proxy settings being ignored in Claude Desktop sessions
  • Fixed screen reader mode's startup announcement being cut off by the first prompt render, and the thinking status row re-rendering every few seconds to update elapsed time and token counts
  • Fixed managed settings that set OTEL_EXPORTER_OTLP_ENDPOINT not governing all signals — lower-scope signal-specific overrides no longer redirect telemetry away from the managed endpoint
  • Fixed --resume/--continue and /resume failing with a TypeError when a transcript has a malformed attachment entry
  • Fixed Remote Control sessions not showing a pending permission prompt or dialog to viewers that connected after it appeared
  • Fixed background shells sometimes becoming impossible to stop after a session is sent to the background (/background or ←) or when the session exits on a heavily loaded machine, most visible on Windows
  • Fixed a CLAUDE.md or SKILL.md paths frontmatter value with many brace groups OOM-killing or stalling the CLI at startup — brace expansion is now budget-bounded
  • Fixed the transcript preview sitting flush against the input area when attaching to a starting background session; it now leaves the same one-line gap as the live layout, so the transcript no longer shifts when the session takes over
  • Improved footer PR badge links to be clickable hyperlinks even when terminal support can't be detected (e.g. over ssh/tmux); set FORCE_HYPERLINK=0 to opt out
  • Changed the login-expiry warning to appear 3 days before expiry instead of 5
  • Capped the frontend-design plugin suggestion tip at 3 lifetime impressions instead of repeating indefinitely
  • Added a cap on concurrently-running subagents (default 20, override with CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS) so one message can't fan out unbounded background agents
  • Changed subagents to no longer spawn nested subagents by default; set CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH to allow deeper nesting
  • Fixed --max-budget-usd not stopping background subagents: once the cap is reached, new spawns are denied and running background agents are halted
