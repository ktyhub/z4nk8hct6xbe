código claude v2.1.281

O que mudou

  • Adicionado suporte de gateway de aplicativos Claude para chaves Claude Desktop mais recentes em blocos de políticas desktop, incluindo blockReadsOutsideWorkingDirectories e disableBypassPermissionsMode
  • Adicionado assume_role nos upstreams Bedrock do gateway de aplicativos Claude: o gateway chama Bedrock como uma função IAM que assume por meio de STS, em outra conta AWS, se necessário, opcionalmente uma sessão por desenvolvedor
  • Adicionado guardrail: {id, version} nos upstreams Bedrock do gateway de aplicativos Claude para aplicar um guardrail Amazon Bedrock a cada solicitação enviada por meio deles (configure-o em todos os upstreams Bedrock ou nenhum)
