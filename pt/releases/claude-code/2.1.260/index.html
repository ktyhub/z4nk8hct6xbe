claude-code v2.1.260

código claude v2.1.260

O que mudou

  • Adicionado um painel de comparação que abre ao lado da conversa em modo tela cheia e mostra suas alterações não confirmadas conforme Claude edita; alterne com /diff
  • Adicionada uma causa provável para falhas de cache de prompt (por exemplo, definições de ferramenta ou prompt do sistema alterados, inatividade após o TTL) para /cost e o campo prompt_cache da linha de status
  • Adicionado /reload-plugins às sessões headless, para que apareça nas listas de comandos Claude Code Desktop e SDK
  • Adicionado um formato de texto de /advisor (/advisor, /advisor <model>, /advisor off) para o aplicativo de desktop, controle remoto e outras sessões sem cabeça (-p/Agente SDK)
  • Adicionado oidc.scope_on_refresh ao gateway de aplicativos Claude para IdPs que retornam um id_token na atualização somente quando solicitado novamente por openid
  • Adicionado suporte de gateway de aplicativos Claude para chaves Claude Desktop mais recentes em blocos de políticas desktop, incluindo userPluginMarketplacesEnabled e userPluginUploadsEnabled
  • Corrigidas regras de permissão Edit/Write/Read cujo caminho contém parênteses sendo descartados como inválidos ou ignorados pelo sandbox Bash, o que deixava pastas "somente leitura" graváveis
  • Corrigida uma regra de permissão de arquivo com um padrão não compilável (por exemplo, um [ não fechado) fazendo com que cada edição de arquivo falhasse com Invalid regular expression; tal regra de negação agora protege o caminho literal que ela indica
  • Correção da permissão Bash que verifica a aprovação automática de comandos zsh que ocultam uma substituição de comando em uma atribuição REPORTTIME, REPORTMEMORY ou DIRSTACKSIZE; estes agora solicitam aprovação
  • Correção da descoberta do modelo Bedrock, contagem de tokens e chamadas de credenciais AWS SSO/STS falhando com "incapaz de obter certificado do emissor local" quando a CA raiz corporativa está apenas no armazenamento de certificados do sistema operacional
  • Corrigido permissions.blockReadsOutsideWorkingDirectories no macOS, ocultando a configuração git do usuário do git em sandbox e ocultando o próprio checkout de um subagente isolado da árvore de trabalho
  • Corrigidas configurações gerenciadas que não carregavam para usuários claude.ai Enterprise/Team que também tinham uma chave API restante de um /login anterior
  • Corrigido /status listando uma conta claude.ai conectada e uma chave API configurada como se ambas estivessem em vigor; a credencial que não está em uso agora está marcada
  • Corrigidas entradas skillOverrides gerenciadas digitadas no alias de uma habilidade agrupada (por exemplo, checkup para /doctor) que não se aplicavam e regras de negação Skill(name) que não cobriam uma habilidade aninhada listada como <dir>:name
  • Correção de agentes model: fable ignorando a tag [1m] em um pino ANTHROPIC_DEFAULT_FABLE_MODEL e executando silenciosamente com uma janela de contexto de 200K
  • Corrigido o seletor /model não exibindo Fable 5.1 para organizações que podem utilizá-lo, o que só era aceito quando digitado como /model claude-fable-5-1
  • Corrigido o cache de prompt em Claude Fable 5.1 que não cobria o contexto anexado após os resultados da ferramenta, por isso era reenviado como entrada não armazenada em cache em cada turno de chamada de ferramenta
  • Corrigida a troca de modelo que ficava bloqueada pelo resto da sessão após uma falha no carregamento do gancho do plugin; cada switch agora verifica novamente e a recusa nomeia a causa
  • Corrigida a troca de modelo bloqueada para a sessão quando o mercado de um plugin gerenciado pela organização não podia ser carregado
  • Correção de servidores MCP fornecidos pelo SDK (por exemplo, conectores de desktop) que às vezes faltavam no primeiro turno e só apareciam no próximo.
  • Foi corrigida a falha de Claude nas ferramentas do Chrome com a tarefa "Não conectado" no meio da tarefa em sessões Claude.ai hospedadas na nuvem quando um conector era adicionado ou removido
  • Bandeiras corrigidas, emojis unidos e letras acentuadas divididas em linhas quebradas e texto obsoleto permanecendo na tela quando uma bandeira ou emoji unido cai nas duas últimas colunas do terminal (agora mostrado como …)
  • Corrigido controle remoto aceitando uma escolha de modelo que não é um nome de modelo válido; agora é recusado com um erro em vez de falhar na próxima mensagem
  • Corrigido o sucesso do relatório /rewind e --rewind-files quando os arquivos de backup do ponto de verificação estavam faltando e nada foi realmente restaurado
  • Corrigido /rewind deixando rastreamento de leitura de arquivo obsoleto nas voltas rebobinadas, o que causava stubs "Arquivo inalterado desde a última leitura" e reinjeção de arquivo completo após edições externas
  • Correção de falha de -p --resume/--continue (conforme usado pelo aplicativo de desktop) em cada nova tentativa quando o diretório da árvore de trabalho de uma sessão perdia seus metadados git; agora falha uma vez e depois retoma sem a árvore de trabalho
  • Corrigido um subagente que retomava outro agente via SendMessage e nunca era acordado pela conclusão desse agente (em vez disso, a notificação ia para a conversa principal)
  • Equipes de agentes corrigidas: a transcrição de um colega de equipe em processo perdia mensagens ou ficava em branco durante longas esperas de repetição do API (por exemplo, em CLAUDE_CODE_RETRY_WATCHDOG) à medida que avisos de repetição expulsavam mensagens reais
  • Correção de uma sessão que passava para segundo plano aparecendo duas vezes em ListAgents (uma vez como um gêmeo "interativo" fantasma com o mesmo nome) e recebendo entregas SendMessage no visualizador
  • Correção de erros intermitentes de "troca de saída de tarefa recusada" quando muitas sessões compartilham um diretório de projeto
  • Corrigido Ctrl+Z em tela cheia deixando o shell na tela alternativa, desenhado sobre a interface pausada
  • Correção de subagentes da ferramenta Workflow sendo reiniciados como paralisados enquanto uma longa compactação de contexto ainda estava em andamento
  • Correção de plug-ins de um mercado de URL que não eram instalados com "o caminho de entrada do mercado não permanece dentro do diretório do mercado" quando um aplicativo host (por exemplo, Claude Desktop) o armazena como um diretório
  • Corrigida uma abertura extra de guia do navegador quando um artefato é publicado em uma sessão que você está dirigindo em claude.ai, no aplicativo de desktop ou no celular (Controle Remoto)
  • Corrigida falha na primeira chamada da ferramenta Artefato com erro de validação de "Parâmetros de ferramenta inválidos" em algumas sessões do Cowork
  • Corrigidas as seleções de linha do IDE sendo descartadas ao executar uma habilidade ou comando de barra (o contexto "N linhas selecionadas" agora chega a Claude)
  • Corrigida detecção de repositório para projetos GitLab em subgrupos aninhados (por exemplo, gitlab.com/group/subgroup/project)
  • Corrigidas referências de problemas do owner/repo#123 na saída renderizada vinculando ao github.com ao trabalhar em um repositório GitLab; eles agora estão vinculados ao problema gitlab.com
  • Glob/Grep: Corrigido o caminho de busca sendo sondado no disco antes da verificação de permissão; um caminho ausente agora é relatado após a permissão ser decidida, como Read faz
  • Revertida a alteração do 2.1.259 aplicando regras de negação do Read() aos argumentos Bash; negou npm run build sob uma regra Read(./**/build/**) em todos os modos e fez o prompt cd … && grep mesmo no modo automático
  • Saída estruturada aprimorada: o fluxo de trabalho agent({schema}) rejeita um esquema JSON que nunca pode ser satisfeito antecipadamente, e os erros de limite de repetição agora incluem a última falha de validação
  • Melhoria na exclusão de uma sessão em segundo plano cuja árvore de trabalho tem commits não enviados: a mensagem agora nomeia a ramificação e a contagem de commits, e a exclusão novamente descarta a árvore de trabalho
  • Melhorado o registro de falhas de atualização do gateway de aplicativos Claude para nomear a etapa que falhou
  • Melhor uso ocioso da CPU de sessões não interativas (-p / SDK)
  • Melhoria do gateway de aplicativos Claude no Amazon Bedrock: tokens de entrada para uma solicitação abortada agora são contados com CountTokens API gratuitos da AWS (concessão bedrock:CountTokens) em vez de uma solicitação de um token
  • Melhorado o erro de configuração para regras como Edit(C:\dir\(name)\**), onde \( é lido como um parêntese escapado em vez de um separador de caminho, para sugerir uma ortografia inequívoca
  • Compactação automática aprimorada para modelos de contexto de 1 milhão: as sessões Opus e Fable agora são compactadas pouco antes do limite de token de 1 milhão, e a compactação de recuperação em contextos muito grandes não atinge mais o tempo limite em 10 minutos
  • /ultrareview e claude ultrareview aprimorados para aguardar até 45 minutos (anteriormente 30) para análises de nuvem de longa duração
  • /effort aprimorado em Claude Fable 5.1 para que a alteração do esforço no meio da sessão não invalide mais o cache de prompt
  • Atualizada a habilidade claude-api agrupada para que suas amostras Go, Java e C# usem IDs de modelo da geração atual e esclareceu que modelos de trabalhadores ou subagentes mais baratos também devem ser da geração atual
  • Alterado ctrl+l / cmd+k no modo tela cheia para limpar a visualização da transcrição como um terminal clear; role para cima para ver mensagens anteriores
  • Regras de permissão alteradas com texto após o parêntese de fechamento (por exemplo, Bash(ls) x), que nunca correspondeu a nada, para serem relatadas como configurações inválidas em vez de serem ignoradas silenciosamente
  • Alteradas as configurações gerenciadas pelo servidor para que um CLAUDE.md gerenciado (claudeMd) não acione mais a caixa de diálogo de aprovação de segurança; ganchos, comando shell, sandbox e configurações inseguras do env ainda exigem aprovação
  • Claude alterado no Chrome para seguir a configuração de administrador do Claude na sua organização no Chrome; quando um administrador o desliga, --chrome, /chrome e as ferramentas do navegador ficam indisponíveis
  • Alterado o gateway de aplicativos Claude para enviar orgPluginSettings no formato de lista lida pelo Claude Desktop 1.15200.0 e posterior; desktops mais antigos ignoram isso
  • Alterado o gateway de aplicativos Claude para também se recusar a iniciar, nomeando o campo, quando uma política desktop digita incorretamente um campo em um objeto aninhado de uma entrada managedMcpServers ou orgPluginSettings
  • Comandos alterados digitados no prompt do modo bash do ! para serem executados fora da sandbox mesmo quando o modo sandbox estrito (sandbox.allowUnsandboxedCommands: false) estiver ativado, como digitar em seu próprio terminal
  • Alterado o executor auto-hospedado --kill-session-after-min para liberar uma sessão que está apenas aguardando seu usuário (pausada, retomável na próxima mensagem) em vez de encerrá-la e relatar uma falha
  • Removido o limite de uma hora para comandos em segundo plano iniciados por subagentes; eles agora são executados até saírem ou serem parados, correspondendo à sessão principal
  • [VSCode] Adicionado o nível de esforço selecionado ao comprimido do modelo de rodapé, corrigiu um nível de esforço obsoleto após a troca de modelos e retornou os comprimidos de rodapé ao seu tamanho compacto anterior
  • [VSCode] Adicionado Aberto e Fechado ao menu de filtro de status da lista de sessões
  • [VSCode] Corrigida a tela de boas-vindas que desaparecia em uma nova sessão quando o Controle Remoto era ativado automaticamente
  • [VSCode] Corrigido o seletor de histórico de sessão carregando uma segunda vez uma sessão quando ela já está aberta em outra aba; agora ele muda para essa guia
  • [VSCode] Corrigido o comando Renomear da aba da sessão silenciosamente sem fazer nada enquanto a visualização da aba estava sendo recarregada; agora sempre se aplica
  • [VSCode] Corrigida uma mensagem incompleta, um cartão de ferramenta vazio ou uma linha extra "Pensada em" que permanecia na tela após Claude Code tentar novamente uma resposta perdida
  • [VSCode] Corrigido "Ativar controle remoto para todas as sessões" que não se aplicava a uma guia de sessão que ainda estava iniciando quando o botão de alternância foi ativado

claude-code v2.1.260

What's changed

  • Added a diff panel that opens beside the conversation in fullscreen mode and shows your uncommitted changes as Claude edits; toggle it with /diff
  • Added a likely cause for prompt-cache misses (e.g. tool definitions or system prompt changed, idle past the TTL) to /cost and the status line's prompt_cache field
  • Added /reload-plugins to headless sessions, so it appears in the Claude Code Desktop and SDK command lists
  • Added a text form of /advisor (/advisor, /advisor <model>, /advisor off) for the desktop app, Remote Control, and other headless (-p/Agent SDK) sessions
  • Added oidc.scope_on_refresh to the Claude apps gateway for IdPs that return an id_token on refresh only when asked for openid again
  • Added Claude apps gateway support for newer Claude Desktop keys in desktop policy blocks, including userPluginMarketplacesEnabled and userPluginUploadsEnabled
  • Fixed Edit/Write/Read permission rules whose path contains parentheses being dropped as invalid or ignored by the Bash sandbox, which left "read-only" folders writable
  • Fixed one file permission rule with an uncompilable pattern (e.g. an unclosed [) making every file edit fail with Invalid regular expression; such a deny rule now guards the literal path it spells
  • Fixed Bash permission checks auto-approving zsh commands that hide a command substitution in a REPORTTIME, REPORTMEMORY or DIRSTACKSIZE assignment; these now prompt for approval
  • Fixed Bedrock model discovery, token counting and AWS SSO/STS credential calls failing with "unable to get local issuer certificate" when the corporate root CA is only in the OS certificate store
  • Fixed permissions.blockReadsOutsideWorkingDirectories on macOS hiding the user's git config from sandboxed git and hiding a worktree-isolated sub-agent's own checkout
  • Fixed managed settings not loading for claude.ai Enterprise/Team users who also had a leftover API key from an earlier /login
  • Fixed /status listing a signed-in claude.ai account and a configured API key as if both were in effect; the credential not in use is now marked
  • Fixed managed skillOverrides entries keyed on a bundled skill's alias (e.g. checkup for /doctor) not applying, and Skill(name) deny rules not covering a nested skill listed as <dir>:name
  • Fixed model: fable agents ignoring the [1m] tag on an ANTHROPIC_DEFAULT_FABLE_MODEL pin and silently running with a 200K context window
  • Fixed the /model picker not showing Fable 5.1 for organizations that can use it, which was only accepted when typed as /model claude-fable-5-1
  • Fixed prompt caching on Claude Fable 5.1 not covering the context attached after tool results, so it was re-sent as uncached input on every tool-call turn
  • Fixed model switching staying blocked for the rest of the session after a plugin hook load failure; each switch now re-checks and the refusal names the cause
  • Fixed model switching being blocked for the session when an organization-managed plugin's marketplace could not be loaded
  • Fixed SDK-provided MCP servers (e.g. Desktop connectors) sometimes missing from the first turn and only appearing on the next one
  • Fixed Claude in Chrome tools failing with "Not connected" mid-task in cloud-hosted claude.ai sessions when a connector was added or removed
  • Fixed flags, joined emoji and accented letters splitting across wrapped lines, and stale text staying on screen when a flag or joined emoji falls in the terminal's last two columns (now shown as …)
  • Fixed Remote Control accepting a model pick that is not a valid model name; it is now refused with an error instead of failing on the next message
  • Fixed /rewind and --rewind-files reporting success when checkpoint backup files were missing and nothing was actually restored
  • Fixed /rewind leaving stale file-read tracking from the rewound-away turns, which caused "File unchanged since last read" stubs and full-file re-injection after external edits
  • Fixed -p --resume/--continue (as used by the desktop app) failing on every retry once a session's worktree directory lost its git metadata; it now fails once, then resumes without the worktree
  • Fixed a subagent that resumed another agent via SendMessage never being woken by that agent's completion (the notification went to the main conversation instead)
  • Fixed agent teams: an in-process teammate's transcript losing messages, or going blank, during long API retry waits (e.g. under CLAUDE_CODE_RETRY_WATCHDOG) as retry notices evicted real messages
  • Fixed a session that moved to the background appearing twice in ListAgents (once as a phantom "interactive" twin with the same name) and receiving SendMessage deliveries in the viewer
  • Fixed intermittent "task output swap refused" errors when many sessions share a project directory
  • Fixed Ctrl+Z in fullscreen leaving the shell on the alternate screen, drawn over the paused interface
  • Fixed Workflow tool subagents being restarted as stalled while a long context compaction was still in progress
  • Fixed plugins from a URL marketplace failing to install with "marketplace entry path does not stay inside the marketplace directory" when a host app (e.g. Claude Desktop) stores it as a directory
  • Fixed an extra browser tab opening when an artifact is published in a session you're driving from claude.ai, the desktop app, or mobile (Remote Control)
  • Fixed the Artifact tool's first call failing with an "Invalid tool parameters" validation error in some Cowork sessions
  • Fixed IDE line selections being dropped when running a skill or slash command (the "N lines selected" context now reaches Claude)
  • Fixed repository detection for GitLab projects in nested subgroups (e.g. gitlab.com/group/subgroup/project)
  • Fixed owner/repo#123 issue references in rendered output linking to github.com when working in a GitLab repository; they now link to the gitlab.com issue
  • Glob/Grep: Fixed the search path being probed on disk before the permission check; a missing path is now reported after permission is decided, as Read does
  • Reverted the 2.1.259 change applying Read() deny rules to Bash arguments; it denied npm run build under a Read(./**/build/**) rule in every mode and made cd … && grep prompt even in auto mode
  • Improved structured output: Workflow agent({schema}) rejects a JSON Schema that can never be satisfied up front, and retry-cap errors now include the last validation failure
  • Improved deleting a background session whose worktree has unpushed commits: the message now names the branch and commit count, and deleting again discards the worktree
  • Improved the Claude apps gateway's refresh-failure log to name the step that failed
  • Improved idle CPU usage of non-interactive (-p / SDK) sessions
  • Improved the Claude apps gateway on Amazon Bedrock: input tokens for an aborted request are now counted with AWS's free CountTokens API (grant bedrock:CountTokens) instead of a one-token request
  • Improved the settings error for rules such as Edit(C:\dir\(name)\**), where \( is read as an escaped parenthesis rather than a path separator, to suggest an unambiguous spelling
  • Improved auto-compact for 1M-context models: Opus and Fable sessions now compact shortly before the 1M-token limit, and recovery compaction on very large contexts no longer times out at 10 minutes
  • Improved /ultrareview and claude ultrareview to wait up to 45 minutes (previously 30) for long-running cloud reviews
  • Improved /effort on Claude Fable 5.1 so changing effort mid-session no longer invalidates the prompt cache
  • Updated the bundled claude-api skill so its Go, Java, and C# samples use current-generation model IDs, and clarified that cheaper worker or sub-agent models should be current-generation too
  • Changed ctrl+l / cmd+k in fullscreen mode to clear the transcript view like a terminal clear; scroll up to see earlier messages
  • Changed permission rules with text after the closing parenthesis (e.g. Bash(ls) x), which never matched anything, to be reported as invalid settings instead of being silently ignored
  • Changed server-managed settings so a managed CLAUDE.md (claudeMd) no longer triggers the security approval dialog; hooks, shell-command, sandbox, and unsafe env settings still require approval
  • Changed Claude in Chrome to follow your organization's Claude in Chrome admin setting; when an admin turns it off, --chrome, /chrome and the browser tools are unavailable
  • Changed Claude apps gateway to send orgPluginSettings in the list form read by Claude Desktop 1.15200.0 and later; older desktops ignore it
  • Changed Claude apps gateway to also refuse to start, naming the field, when a desktop policy misspells a field in a nested object of a managedMcpServers or orgPluginSettings entry
  • Changed commands typed at the ! bash-mode prompt to run outside the sandbox even when strict sandbox mode (sandbox.allowUnsandboxedCommands: false) is on, like typing into your own terminal
  • Changed self-hosted runner --kill-session-after-min to release a session that is only waiting on its user (paused, resumable on the next message) instead of killing it and reporting a failure
  • Removed the one-hour time limit on background commands started by subagents; they now run until they exit or are stopped, matching the main session
  • [VSCode] Added the selected effort level to the footer model pill, fixed a stale effort level after switching models, and returned the footer pills to their earlier compact size
  • [VSCode] Added Open and Closed to the session list's status filter menu
  • [VSCode] Fixed the welcome screen disappearing in a new session when Remote Control turns on automatically
  • [VSCode] Fixed the session history picker loading a session a second time when it is already open in another tab; it now switches to that tab
  • [VSCode] Fixed the session tab's Rename command silently doing nothing while the tab's view was reloading; it now always applies
  • [VSCode] Fixed a half-finished message, an empty tool card or an extra "Thought for" line staying on screen after Claude Code retried a dropped response
  • [VSCode] Fixed "Enable Remote Control for all sessions" not applying to a session tab that was still starting when the toggle was flipped
