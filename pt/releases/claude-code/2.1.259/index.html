código claude v2.1.259

O que mudou

  • Adicionada configuração gerenciada managedMcpServers: as organizações podem fornecer servidores HTTP/SSE MCP para todos os usuários (mesmo formato de entrada do .mcp.json); entradas que nomeiam um comando a ser executado são ignoradas
  • Adicionado --permission-prompts none para hosts headless autônomos: qualquer coisa que solicite é negada automaticamente enquanto o modo de permissão ativo (incluindo o modo automático) continua decidindo
  • Adicionado reconhecimento de glab mr create/merge/close/reopen/note/update para que as solicitações de mesclagem GitLab sejam exibidas como MR !N no resumo da ferramenta recolhida e atualizem o emblema MR do rodapé
  • Adicionado --json a claude plugin validate para um relatório de validação legível por máquina
  • Correção de sessões simultâneas revertendo silenciosamente as alterações ~/.claude.json umas das outras — o espaço de trabalho trust não é mais redefinido e o estado do MCP/projeto não é mais perdido ao executar muitas sessões ao mesmo tempo
  • Corrigida uma conversa cujo pensamento era rejeitado ao ser rejeitado novamente a cada turno posterior
  • Corrigidas regras de negação do Bash Read() que não cobriam arquivos dados como valores de opção (--ignore-revs-file=.env, -f.env, @file), operandos de arquivo git diff/git grep ou compostos cd DIR && cat FILE; grep -r/cp -r em um diretório que contém um arquivo negado agora pergunta
  • Corrigido o cache de prompt sendo invalidado quando o token OAuth era atualizado em sessões com telemetria desativada
  • Corrigido o modo de tela cheia mostrando uma conversa em branco após um longo turno com centenas de chamadas de ferramentas
  • Corrigido o modo automático executando uma curva em um modelo que não suporta quando um comando ou frontmatter da habilidade model: nomeava um; a vez agora mantém o modelo de sessão
  • Corrigido CLAUDE_CODE_MAX_CONTEXT_TOKENS sendo ignorado para IDs de modelo estilo Vertex (sufixo @YYYYMMDD) de versões de modelo que Claude Code não reconhece
  • Corrigida a visualização da saída ao vivo de um comando shell em execução, ocultando suas linhas mais recentes quando uma linha anterior era quebrada
  • Corrigida uma verificação de conexão em segundo plano do GitHub que era executada em cada inicialização para usuários claude.ai; o resultado agora é lembrado em todos os lançamentos
  • Correção da falha do --resume (e --continue abrindo uma conversa vazia) quando uma sessão salva contém uma entrada de anexo sem carga útil
  • Corrigido o frontmatter model: em comandos e habilidades personalizados sendo ignorados em sessões interativas
  • Corrigida falha na publicação de artefato uma vez com um erro de "parâmetro inesperado note" em conversas continuadas de uma versão mais antiga
  • Corrigido o problema do forceRemoteSettingsRefresh gerenciado sendo ignorado na inicialização quando um auxiliar de política configurado pelo MDM ou o arquivo de configurações gerenciadas já havia sido executado
  • Corrigido o isolamento da árvore de trabalho recusando árvores de trabalho criadas por gancho em máquinas onde git rev-parse falha com uma mensagem diferente de "não é um repositório git"
  • Corrigidas métricas e eventos OpenTelemetry de sessões na nuvem sem os atributos user.email, organization.id e user.account_uuid
  • Servidores MCP corrigidos que se desconectavam enquanto suas ferramentas estavam sendo listadas na inicialização, mostrando como conectados sem ferramentas em vez de relatar o erro
  • Corrigida a caixa de diálogo de permissão de edição de arquivo, às vezes mostrando uma linha alterada cortada sem indicação
  • Correção da detecção de repositório eliminando uma identidade de repositório conhecida após uma falha transitória do teste git
  • Corrigidas configurações gerenciadas que não eram aplicadas silenciosamente quando o arquivo de configurações gerenciadas, um drop-in, o plist MDM ou o valor HKLM não podiam ser analisados: Claude Code agora se recusa a iniciar e nomeia a fonte
  • Foi corrigido um problema de parada que não parava realmente agentes e fluxos de trabalho em segundo plano em sessões de controle remoto: as tarefas eliminadas agora permanecem visíveis e podem ser interrompidas novamente até que seus processos sejam encerrados
  • Correção da retomada da execução de um fluxo de trabalho enquanto a execução anterior interrompida ainda estava em andamento, o que poderia executar cópias duplicadas de seus agentes
  • Correção de URLs de repositório de mercado em github.com com uma barra final ou ?/# pendente, produzindo um URL de clone .git inutilizável
  • Corrigidos ganchos de parada de bloqueio fazendo com que a curva após um bloqueio perdesse o raciocínio do modelo daquela curva e, em alguns modelos, perdesse o cache de prompt
  • Correção de sessões remotas (claude.ai) que levavam 60 segundos para iniciar um turno após a página de um servidor MCP hospedado no navegador ter desaparecido
  • Foram corrigidas sessões isoladas da árvore de trabalho que recusavam loops Bash comuns, pipelines xargs e comandos encapsulados no iniciador que não conseguem alcançar o checkout principal
  • Redimensionamento de terminal aprimorado e desempenho de primeira renderização para respostas longas, reutilizando medidas de texto
  • Detalhe aprimorado do agente /workflows: os resultados do JSON são bem impressos com cores de sintaxe e quebras de linha reais, e os resultados longos são dobrados atrás de um botão de expansão
  • Início de sessão headless/SDK aprimorado: o primeiro turno começa até 50 ms antes quando os servidores MCP terminam de se conectar
  • /install-github-app aprimorado para explicar que é apenas GitHub e apontar para os documentos CI/CD do GitLab quando executado dentro de um repositório GitLab
  • Resultados aprimorados do subagente em segundo plano aninhado para serem salvos na transcrição do subagente pai, para que os subagentes retomados os mantenham e as transcrições compartilhadas mostrem a entrega
  • allowedMcpServers alterado para controlar apenas os servidores que os usuários adicionam: um servidor managed-mcp.json literal que sua lista de permissões usava para filtrar agora carrega na atualização; use deniedMcpServers para mantê-lo desligado
  • [VSCode] Adicionado um filtro rápido ativo e um menu de filtro de status (Necessita entrada, Em funcionamento, Concluído) à barra lateral da lista de sessões
  • Correção de sessões remotas e agendadas que não faziam nada depois que um prompt de permissão da ferramenta de conector era aprovado enquanto a sessão estava pausada

claude-code v2.1.259

What's changed

  • Added managedMcpServers managed setting: organizations can provide HTTP/SSE MCP servers to every user (same entry shape as .mcp.json); entries that name a command to run are skipped
  • Added --permission-prompts none for unattended headless hosts: anything that would prompt is denied automatically while the active permission mode (including auto mode) keeps deciding
  • Added recognition of glab mr create/merge/close/reopen/note/update so GitLab merge requests show as MR !N in the collapsed tool summary and refresh the footer MR badge
  • Added --json to claude plugin validate for a machine-readable validation report
  • Fixed concurrent sessions silently reverting each other's ~/.claude.json changes — workspace trust no longer resets and MCP/project state is no longer lost when running many sessions at once
  • Fixed a conversation whose thinking was rejected once being rejected again on every later turn
  • Fixed Bash Read() deny rules not covering files given as option values (--ignore-revs-file=.env, -f.env, @file), git diff/git grep file operands, or cd DIR && cat FILE compounds; grep -r/cp -r over a directory holding a denied file now asks
  • Fixed the prompt cache being invalidated when the OAuth token refreshed in sessions with telemetry disabled
  • Fixed fullscreen mode showing a blank conversation after a long turn with hundreds of tool calls
  • Fixed auto mode running a turn on a model it doesn't support when a command or skill's frontmatter model: named one; the turn now keeps the session model
  • Fixed CLAUDE_CODE_MAX_CONTEXT_TOKENS being ignored for Vertex-style model IDs (@YYYYMMDD suffix) of model versions Claude Code doesn't recognize
  • Fixed the live output preview of a running shell command hiding its newest lines when an earlier line wrapped
  • Fixed a background GitHub connection check that ran on every launch for claude.ai users; the result is now remembered across launches
  • Fixed --resume failing (and --continue opening an empty conversation) when a saved session contains an attachment entry with no payload
  • Fixed frontmatter model: on custom commands and skills being ignored in interactive sessions
  • Fixed Artifact publishing failing once with an "unexpected parameter note" error in conversations continued from an older version
  • Fixed managed forceRemoteSettingsRefresh being ignored at startup when a policy helper configured by MDM or the managed settings file had already run
  • Fixed worktree isolation refusing hook-created worktrees on machines where git rev-parse fails with a message other than "not a git repository"
  • Fixed OpenTelemetry metrics and events from cloud sessions missing the user.email, organization.id, and user.account_uuid attributes
  • Fixed MCP servers that disconnect while their tools are being listed at startup showing as connected with no tools instead of reporting the error
  • Fixed the file edit permission dialog sometimes showing a changed line cut short with no indication
  • Fixed repository detection dropping a known repo identity after a transient git probe failure
  • Fixed managed settings silently going unenforced when the managed-settings file, a drop-in, the MDM plist, or the HKLM value cannot be parsed: Claude Code now refuses to start and names the source
  • Fixed Stop not actually stopping background agents and workflows in remote-control sessions: killed tasks now stay visible and re-stoppable until their processes exit
  • Fixed resuming a workflow run while its previous stopped run was still exiting, which could run duplicate copies of its agents
  • Fixed marketplace repo URLs on github.com with a trailing slash or dangling ?/# producing an unusable .git clone URL
  • Fixed blocking Stop hooks causing the turn after a block to lose the model's reasoning from that turn and, on some models, miss the prompt cache
  • Fixed remote (claude.ai) sessions taking 60 seconds to start a turn after a browser-hosted MCP server's page had gone away
  • Fixed worktree-isolated sessions refusing common Bash loops, xargs pipelines and launcher-wrapped commands that cannot reach the main checkout
  • Improved terminal resize and first-render performance for long responses by reusing text measurements
  • Improved /workflows agent detail: JSON outcomes are pretty-printed with syntax colors and real line breaks, and long outcomes fold behind an expand toggle
  • Improved headless/SDK session start: the first turn begins up to 50 ms sooner when MCP servers finish connecting
  • Improved /install-github-app to explain it is GitHub-only and point to the GitLab CI/CD docs when run inside a GitLab repository
  • Improved nested background subagent results to be saved in the parent subagent's transcript, so resumed subagents keep them and shared transcripts show the delivery
  • Changed allowedMcpServers to govern only servers users add: a literal managed-mcp.json server your allowlist used to filter out now loads on upgrade; use deniedMcpServers to keep it off
  • [VSCode] Added an Active quick filter and a status filter menu (Needs input, Working, Completed) to the session list sidebar
  • Fixed remote and scheduled sessions doing nothing after a connector-tool permission prompt was approved while the session was paused
