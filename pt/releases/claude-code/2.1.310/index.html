O que mudou

  • Adicionada a ferramenta Monitor e plugin de monitores em Bedrock, Vertex e Foundry, e quando a telemetria ou tráfego não essencial está desabilitado; longas pausas em primeiro plano agora também estão bloqueadas lá
  • Corrigidas falhas de solicitações em alguns gateways e servidores compatíveis que rejeitam o valor beta effort-2025-11-24 ou mensagens do sistema no meio da conversa; Claude Code agora tenta novamente sem eles
  • Corrigida a limpeza do plano de fundo, excluindo alguns arquivos recentes, como imagens coladas, quando cleanupPeriodDays está definido com um valor muito grande
  • Corrigida a compactação após um erro "O prompt é muito longo", mantendo uma conversa muito longa com texto denso, como base64 ou SVG, para que a próxima solicitação pudesse falhar novamente
  • Corrigidos avisos de permissão de leitura de arquivo que não mostravam aonde um link simbólico levava
  • Corrigido o tempo limite de continuação automática de uma pergunta disparando no momento em que o editor externo fechava após uma longa edição
  • Windows: ganchos PreToolUse e PermissionRequest corrigidos, permitindo que uma ferramenta seja chamada quando o Git Bash está ausente e o comando do gancho contém apenas strings entre aspas, como um caminho entre aspas
  • Melhorado o prompt do modo automático antes da primeira leitura fora dos diretórios de trabalho: agora diz que quando o bloqueio dessas leituras faz com que os comandos do shell peçam permissão
  • Melhor uso de memória de sessões não interativas (-p, Agente SDK) durante a compactação quando o arquivo de transcrição é muito grande
  • Melhorado o Image de um mod para desenhar dentro do tmux com allow-passthrough e focus-events ativado, no kitty, Ghostty e iTerm2 3.5+ com renderização em tela cheia, onde mostrava apenas o texto alt
  • Linux: /sandbox aprimorado e o aviso de inicialização do sandbox para nomear a restrição do AppArmor do Ubuntu em namespaces de usuário e como retirá-la, quando impede que o bubblewrap inicie o sandbox
  • Alterado o erro de uma chamada da ferramenta MCP que atinge o tempo limite em uma sessão não interativa enquanto a elicitação do servidor não é atendida: agora informa ao Claude que não houve resposta e não deve repetir a chamada
  • [VSCode] Corrigido o pressionamento de Enter no botão "Enviar feedback e continuar planejando" do cartão de revisão do plano, aprovando o plano em vez de enviar seus comentários de volta
  • [VSCode] Corrigido o painel que mostrava "Algo deu errado" após "Alternar ramificação e continuar" em uma sessão de nuvem aberta na guia Web do histórico de sessões
  • [Sessões na nuvem] Adicionadas sessões na nuvem do Claude Code e permissões de controle remoto às funções personalizadas da empresa, para que os proprietários possam controlar o acesso a cada uma por função
  • [Sessões de nuvem] Adicionado um botão Escolher arquivo para carregar o script de configuração de um ambiente de nuvem a partir de um arquivo
  • [Sessões na nuvem] Corrigidas falhas ao salvar e arquivar na caixa de diálogo de edição do ambiente de nuvem, mostrando nenhum erro dentro da caixa de diálogo
  • [Sessões na nuvem] Corrigidas ações de rotina do token API com falha mostrando apenas um brinde; o erro agora aparece na caixa de diálogo de edição da rotina
  • [Sessões de nuvem] Melhoria na lista de verificação de início de sessão para mostrar a saída do script de configuração de um ambiente de nuvem em uma caixa de rolagem
  • [Sessões na nuvem] Alterada a ativação de sessões na nuvem ou controle remoto nas configurações de administrador para solicitar confirmação e listar as funções personalizadas que têm essa permissão
  • [Sessões de nuvem] A caixa de diálogo do ambiente de nuvem foi alterada para abrir acesso à rede, configurar script e variáveis de ambiente de linhas em vez de listar todos os editores de uma vez
  • [Claude Tag] Corrigida a tag Claude tratando comandos ! como !restart e !help como mensagens comuns quando enviadas em negrito, itálico ou tachado
  • [Claude Tag] Correção do canal de administração do Claude Tag e das páginas da área de trabalho sendo substituídas por um erro de carregamento quando uma atualização em segundo plano da lista de pacotes falha.
  • [Claude Tag] Corrigida a página de limites de gastos de Claude Tag nas configurações de administração, informando que nenhum canal corresponde a um filtro enquanto os nomes dos canais ainda estão carregando
  • [Code Review] Corrigida a seção administrativa do Code Review que ocultava seus repositórios e switches após uma falha na atualização da lista de repositórios
  • [Code Review] Melhorou a seção de administração do Code Review para tentar novamente o primeiro carregamento e mostrar um banner Tente novamente quando ainda falhar

claude-code v2.1.310

What's changed

  • Added the Monitor tool and plugin monitors on Bedrock, Vertex, and Foundry, and when telemetry or nonessential traffic is disabled; long foreground sleeps are now blocked there too
  • Fixed requests failing behind some gateways and compatible servers that reject the effort-2025-11-24 beta value or mid-conversation system messages; Claude Code now retries without them
  • Fixed background cleanup deleting some recent files, such as pasted images, when cleanupPeriodDays is set to a very large value
  • Fixed compaction after a "Prompt is too long" error keeping too much of a conversation with dense text, such as base64 or SVG, so the next request could fail again
  • Fixed file read permission prompts not showing where a symbolic link leads
  • Fixed a question's auto-continue timeout firing the moment the external editor closed after a long edit
  • Windows: Fixed PreToolUse and PermissionRequest hooks letting a tool call through when Git Bash is missing and the hook's command is only quoted strings, such as a quoted path
  • Improved auto mode's prompt before the first read outside the working directories: it now says when blocking those reads makes shell commands ask for permission
  • Improved memory use of non-interactive sessions (-p, Agent SDK) during compaction when the transcript file is very large
  • Improved a mod's Image to draw inside tmux with allow-passthrough and focus-events on, in kitty, Ghostty, and iTerm2 3.5+ with fullscreen rendering, where it showed only its alt text
  • Linux: Improved /sandbox and the sandbox startup warning to name Ubuntu's AppArmor restriction on user namespaces, and how to lift it, when it keeps bubblewrap from starting the sandbox
  • Changed the error for an MCP tool call that times out in a non-interactive session while the server's elicitation is unanswered: it now tells Claude that no answer came and not to repeat the call
  • [VSCode] Fixed pressing Enter on the plan review card's "Send feedback and keep planning" button approving the plan instead of sending your comments back
  • [VSCode] Fixed the panel showing "Something went wrong" after "Switch branch & continue" on a cloud session opened from Session history's Web tab
  • [Cloud sessions] Added Claude Code cloud sessions and Remote Control permissions to Enterprise custom roles, so Owners can control access to each by role
  • [Cloud sessions] Added a Choose file button to load a cloud environment's setup script from a file
  • [Cloud sessions] Fixed failed saves and archives in the cloud environment edit dialog showing no error inside the dialog
  • [Cloud sessions] Fixed failed routine API token actions showing only a toast; the error now appears in the routine edit dialog
  • [Cloud sessions] Improved the session start checklist to show a cloud environment's setup script output in a scrolling box
  • [Cloud sessions] Changed turning on Cloud sessions or Remote Control in admin settings to ask for confirmation and list the custom roles that have that permission
  • [Cloud sessions] Changed the cloud environment dialog to open network access, setup script and environment variables from rows instead of listing every editor at once
  • [Claude Tag] Fixed Claude Tag treating ! commands such as !restart and !help as ordinary messages when sent in bold, italic or strikethrough
  • [Claude Tag] Fixed Claude Tag admin channel and workspace pages being replaced by a load error when a background refresh of the bundle list fails
  • [Claude Tag] Fixed Claude Tag's spend limits page in admin settings reporting that no channels match a filter while channel names are still loading
  • [Code Review] Fixed the Code Review admin section hiding its repositories and switches after a failed refresh of the repository list
  • [Code Review] Improved the Code Review admin section to retry the first load and show one Try again banner when it still fails
