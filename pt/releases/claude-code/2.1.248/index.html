claude-code v2.1.248

código claude v2.1.248

O que mudou

  • Adicionado --restricted (ou CLAUDE_CODE_RESTRICTED=1): remove as ferramentas integradas que executam comandos ou código e WebFetch (a menos que nomeado em --tools), mantém ferramentas de arquivo dentro do diretório de trabalho, recusa bypassPermissions e ignora arquivos de usuário, projeto e configurações locais
  • Adicionado experimental.cacheTtl ("5m" ou "1h") ao frontmatter do agente: um TTL de cache de prompt por agente usado quando nenhuma configuração de TTL de subagente está configurada
  • Adicionado claude self-hosted-runner --client-label <label> (ou SELF_HOSTED_RUNNER_CLIENT_LABEL) para substituir o rótulo com o qual o runner registra (padrão: nome do host)
  • Adicionado diagnóstico de configurações gerenciadas pelo servidor: um aviso de inicialização quando as configurações falham ao carregar e uma linha /doctor e /status explicando uma falha de carregamento ou por que elas não foram buscadas (Bedrock/Vertex/provedor de terceiros, ANTHROPIC_BASE_URL personalizado)
  • Adicionado um aviso em /web-setup quando o token GitHub CLI não possui o escopo workflow, uma vez que pushes para repositórios muito grandes podem ser rejeitados sem ele
  • Adicionado /usage-credits para organizações empresariais faturadas por meio do AWS Marketplace, autoatendimento empresarial e avaliações empresariais, para que os membros possam solicitar um limite de uso mais alto ao administrador
  • Adicionadas mensagens entre sessões (SendMessage / ListAgents) entre sessões na mesma máquina em Bedrock, Vertex e Foundry e quando a telemetria está desativada
  • Corrigida uma falha no cache de prompt (e perda de contexto de pensamento estendido) aproximadamente uma vez por hora em sessões longas, causada por definições de ferramentas sendo renderizadas novamente após uma atualização de token OAuth
  • Corrigida a alteração da definição da ferramenta ScheduleWakeup entre uma sessão e seu --resume quando a conta entrava em excesso de uso, causando uma falha completa no prompt-cache no primeiro turno da sessão retomada
  • Correção do desaparecimento das sessões do Claude Desktop e Cowork após 30 dias: a limpeza da transcrição agora mantém as sessões gravadas no desktop enquanto elas estão no aplicativo (a menos que a política da organização gerencie a retenção); a nova configuração desktopSessionCleanupPeriodDays limita a isenção
  • Corrigido envio para tela de login quando outro processo do Claude Code segurava o bloqueio de atualização do token enquanto o token de sessão estava expirado; a solicitação agora falha com um erro que pode ser repetido
  • Windows: corrigida a lista claude agents que não respondia ao teclado após desconectar de uma sessão ou quando iniciada em uma guia de terminal deixada no modo de entrada win32
  • Correção da falha de login recomendado do console em /login com um erro OAuth antes de mostrar uma URL de login em máquinas onde não pode ser usado (por exemplo, quando ANTHROPIC_API_KEY ou um auxiliar de chave API está definido); agora ele volta para o login da tecla API
  • Nomes de modelos corrigidos em /model e avisos de mudança de modo rápido para renderizar como código, de modo que sufixos como [1m] sejam exibidos literalmente em vez de como um link
  • Corrigido claude agents ignorando o prompt trust da área de trabalho quando a variável de ambiente CI é definida
  • Corrigido o travamento do claude agents na inicialização quando o cache de status PR continha uma entrada malformada
  • Corrigida a visualização do agente ressuscitando uma sessão em segundo plano de semanas após a máquina ser desligada: essa sessão agora aparece como interrompida no seu final real e ao abri-la pergunta antes de retomar a conversa salva
  • Correção da visualização do agente que às vezes abria uma conversa antiga e descartava o prompt digitado ao iniciar uma nova sessão
  • Corrigido claude agents: abrir uma sessão parada que você já retomou em outro terminal não inicia mais um segundo processo naquela conversa; a linha agora diz que está aberta em um terminal
  • Corrigida a recusa de claude agents e claude rm em excluir uma sessão ("possui commits que não são enviados para lugar nenhum") quando sua ramificação da árvore de trabalho já foi mesclada em sua ramificação padrão com check-out (por exemplo, main local), mas ainda não foi enviada por push
  • Corrigidas sessões em segundo plano aguardando silenciosamente quando um gancho PermissionRequest ou PreToolUse imprime uma resposta inválida: a linha claude agents agora nomeia o gancho e o erro de esquema
  • Corrigidos hooks tratando silenciosamente um objeto stdout {…} que não é JSON válido como texto simples; agora é relatado como um erro de gancho com a mensagem de análise
  • Correção de /mcp listando uma entrada do projeto .mcp.json que declara o tipo de conector claude.ai sob o cabeçalho trusted "claude.ai"; agora aparece sob seu escopo real
  • Servidores MCP corrigidos cujo headersHelper fornece o cabeçalho Authorization caindo na descoberta OAuth em um 401 em vez de executar novamente o auxiliar e tentar novamente a chamada conforme documentado
  • Corrigido /login para um gateway de aplicativos Claude travado quando a caixa de diálogo de aprovação de segurança de configurações gerenciadas era necessária
  • Foi corrigida a descoberta do modelo de gateway (CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY) que nunca funcionava quando apiKeyHelper era a única credencial
  • Corrigido claude logs deixando o rastreamento do mouse, colagem entre colchetes e a tela alternativa ligada no terminal a partir do qual foi executado
  • Corrigida a lista de regras de permissão de repositório da caixa de diálogo trust mostrando um caracter ilegível quando uma regra longa era cortada no meio de um emoji
  • Corrigido o indicador do modo de permissão que ficava oculto atrás da dica "Pressione Ctrl-C novamente para sair" quando você pressiona shift+tab logo após ctrl+c
  • Corrigido /ultrareview e sessões de nuvem semeadas localmente carregando edições não confirmadas para arquivos estilo prod.env e *.tfvars, ou para troca de editor, temporárias e cópias de backup de arquivos de credenciais (por exemplo, key.pem.tmp, id_rsa.swo); eles agora ficam na sua máquina
  • Corrigidas sessões de controle remoto que ocasionalmente nunca exibiam um prompt de permissão ou as mensagens mais recentes no dispositivo conectado após o CLI se reconectar silenciosamente
  • Foram corrigidas sessões de nuvem que falhavam ocasionalmente na inicialização quando as credenciais de sessão do contêiner ainda não eram legíveis
  • Corrigido claude remote-control rejeitando seus próprios sinalizadores (por exemplo, --spawn, --name) quando um sinalizador global ou uma opção injetada no wrapper precede o subcomando
  • Corrigidos avisos de inicialização (por exemplo, "N servidores MCP precisam de autenticação") renderizando uma coluna à direita do restante da transcrição
  • Corrigida uma sessão da árvore de trabalho em segundo plano que perdia seu checkout: a sessão em segundo plano agora mantém o bloqueio da árvore de trabalho enquanto ela é executada, então a limpeza e o git worktree remove deixam-na em paz
  • Corrigidas menções @ de outras sessões que não correspondiam a nomes digitados com caracteres não latinos (por exemplo, coreano inserido por meio de um IME)
  • Corrigido um valor inválido de crossSessionInbound sendo ignorado silenciosamente: agora ele avisa e retém mensagens de sessão cruzada (configurações do usuário) ou as recusa (configurações gerenciadas) até ser corrigido
  • Corrigidas mensagens de limite de taxa, uso e modo rápido solicitando que você execute /usage-credits quando esse comando não estiver disponível para sua organização (por exemplo, oculto com DISABLE_EXTRA_USAGE_COMMAND)
  • [VSCode] Corrigida uma aba de chat que ficava travada em "Nenhuma conversa encontrada" quando sua sessão nunca era salva; agora ele inicia uma nova conversa
  • Melhorou o tamanho do prompt da ferramenta Workflow: sua descrição agora é de cerca de 1k tokens em vez de 5,7k, com a referência de escrita de script movida para uma habilidade workflow-authoring agrupada
  • Melhorado o emblema PR do rodapé do prompt para verificar GitHub com menos frequência enquanto a solicitação pull permanece inalterada; um push ou um comando gh pr ainda o atualiza imediatamente
  • Configurações gerenciadas aprimoradas: tempo limite do lado client, modo de inicialização MCP e variáveis de ambiente stream-watchdog não acionam mais o prompt de aprovação de configurações
  • /ultrareview <PR#> aprimorado para verificar antes do lançamento se a conta GitHub conectada à sua conta Claude pode acessar o repositório e para explicar como corrigi-lo, em vez de falhar após o início da sessão na nuvem
  • Mensagens entre sessões aprimoradas: volta para um diretório /tmp privado por usuário quando o padrão não pode ser usado, e o aviso e /status nomeiam o diretório para correção
  • Alterado shift+enter na entrada de despacho da visualização do agente para inserir uma nova linha (correspondendo ao prompt); ctrl+enter agora despacha e anexa
  • /loop alterado: o modo dinâmico individualizado e o padrão autônomo sem aviso agora estão sempre disponíveis, inclusive em Bedrock/Vertex/Foundry
  • Alteradas as falhas de exportação de telemetria antrópica para registrar no nível de depuração como [Anthropic telemetry] em vez de [3P telemetry] OTEL diag error, para que não sejam confundidas com a falha do seu coletor OTel
  • Mensagens entre sessões alteradas em namespaces de usuários do Linux: trust equivalente à raiz para proprietários não mapeados é limitado a diretórios de sistema canônicos
  • SendMessage alterado de um subagente para outra sessão: o resultado agora indica que qualquer resposta é entregue à conversa da sessão pai, não ao subagente

claude-code v2.1.248

What's changed

  • Added --restricted (or CLAUDE_CODE_RESTRICTED=1): removes the built-in tools that run commands or code and WebFetch (unless named in --tools), keeps file tools inside the working directory, refuses bypassPermissions, and ignores user, project and local settings files
  • Added experimental.cacheTtl ("5m" or "1h") to agent frontmatter: a per-agent prompt cache TTL used when no subagent TTL setting is configured
  • Added claude self-hosted-runner --client-label <label> (or SELF_HOSTED_RUNNER_CLIENT_LABEL) to override the label the runner registers with (default: hostname)
  • Added server-managed settings diagnostics: a startup warning when the settings fail to load, and a /doctor and /status line explaining a load failure or why they weren't fetched (Bedrock/Vertex/third-party provider, custom ANTHROPIC_BASE_URL)
  • Added a warning in /web-setup when the GitHub CLI token lacks the workflow scope, since pushes to very large repositories can be rejected without it
  • Added /usage-credits for Enterprise organizations billed through AWS Marketplace, self-serve Enterprise, and Enterprise trials, so members can request a higher usage limit from their admin
  • Added cross-session messaging (SendMessage / ListAgents) between sessions on the same machine on Bedrock, Vertex, and Foundry, and when telemetry is disabled
  • Fixed a prompt-cache miss (and lost extended-thinking context) roughly once an hour in long sessions, caused by tool definitions being re-rendered after an OAuth token refresh
  • Fixed the ScheduleWakeup tool definition changing between a session and its --resume when the account had entered usage overage, causing a full prompt-cache miss on the resumed session's first turn
  • Fixed Claude Desktop and Cowork sessions disappearing after 30 days: the transcript cleanup now keeps desktop-written sessions while they are in the app (unless org policy manages retention); the new desktopSessionCleanupPeriodDays setting caps the exemption
  • Fixed being sent to the login screen when another Claude Code process held the token refresh lock while the session token had expired; the request now fails with a retryable error instead
  • Windows: Fixed the claude agents list not responding to the keyboard after detaching from a session, or when launched in a terminal tab left in win32-input-mode
  • Fixed the recommended Console sign-in in /login failing with an OAuth error before showing a sign-in URL on machines where it can't be used (for example when ANTHROPIC_API_KEY or an API key helper is set); it now falls back to the API-key sign-in
  • Fixed model names in /model and fast-mode switch notices to render as code, so suffixes like [1m] display literally instead of as a link
  • Fixed claude agents skipping the workspace trust prompt when the CI environment variable is set
  • Fixed claude agents crashing on launch when the PR-status cache held a malformed entry
  • Fixed agent view resurrecting a weeks-old background session after the machine was off: such a session now shows as stopped at its real end, and opening it asks before resuming its saved conversation
  • Fixed agent view sometimes opening an older conversation, and dropping the typed prompt, when starting a new session
  • Fixed claude agents: opening a stopped session that you already resumed in another terminal no longer starts a second process on that conversation; the row now says it is open in a terminal
  • Fixed claude agents and claude rm refusing to delete a session ("has commits that are not pushed anywhere") when its worktree branch was already merged into your checked-out default branch (e.g. local main) but not yet pushed
  • Fixed background sessions waiting silently when a PermissionRequest or PreToolUse hook prints an invalid answer: the claude agents row now names the hook and the schema error
  • Fixed hooks silently treating a stdout {…} object that isn't valid JSON as plain text; it's now reported as a hook error with the parse message
  • Fixed /mcp listing a project .mcp.json entry that declares the claude.ai connector type under the trusted "claude.ai" heading; it now appears under its real scope
  • Fixed MCP servers whose headersHelper supplies the Authorization header falling into OAuth discovery on a 401 instead of re-running the helper and retrying the call as documented
  • Fixed /login to a Claude apps gateway hanging when the managed-settings security approval dialog was required
  • Fixed gateway model discovery (CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY) never running when apiKeyHelper is the only credential
  • Fixed claude logs leaving mouse tracking, bracketed paste and the alternate screen switched on in the terminal it was run from
  • Fixed the trust dialog's list of repo permission rules showing a garbled character when a long rule was cut off in the middle of an emoji
  • Fixed the permission mode indicator staying hidden behind the "Press Ctrl-C again to exit" hint when you press shift+tab right after ctrl+c
  • Fixed /ultrareview and locally seeded cloud sessions uploading uncommitted edits to prod.env-style and *.tfvars files, or to editor swap, temp, and backup copies of credential files (e.g. key.pem.tmp, id_rsa.swo); they now stay on your machine
  • Fixed Remote Control sessions occasionally never showing a permission prompt or the latest messages on the connected device after the CLI silently reconnected
  • Fixed cloud sessions occasionally failing at startup when the container's session credentials were not yet readable
  • Fixed claude remote-control rejecting its own flags (e.g. --spawn, --name) when a global flag or a wrapper-injected option precedes the subcommand
  • Fixed startup warnings (e.g. "N MCP servers need authentication") rendering one column right of the rest of the transcript
  • Fixed a backgrounded worktree session losing its checkout: the background session now holds the worktree's lock while it runs, so cleanup and git worktree remove leave it alone
  • Fixed @-mentions of other sessions not matching names typed with non-Latin characters (for example Korean entered through an IME)
  • Fixed an invalid crossSessionInbound value being silently ignored: it now warns and holds cross-session messages (user settings) or refuses them (managed settings) until fixed
  • Fixed rate-limit, usage, and fast-mode messages telling you to run /usage-credits when that command isn't available for your organization (e.g. hidden with DISABLE_EXTRA_USAGE_COMMAND)
  • [VSCode] Fixed a chat tab getting stuck on "No conversation found" when its session was never saved; it now starts a new conversation instead
  • Improved the Workflow tool's prompt footprint: its description is now about 1k tokens instead of 5.7k, with the script-writing reference moved into a bundled workflow-authoring skill
  • Improved the prompt-footer PR badge to check GitHub less often while the pull request is unchanged; a push or a gh pr command still refreshes it right away
  • Improved managed settings: client-side timeout, MCP startup-mode, and stream-watchdog env vars no longer trigger the settings-approval prompt
  • Improved /ultrareview <PR#> to check before launch that the GitHub account connected to your Claude account can access the repository, and to explain how to fix it, instead of failing after the cloud session starts
  • Improved cross-session messaging: falls back to a private per-user /tmp directory when the default one can't be used, and the notice and /status name the directory to fix
  • Changed shift+enter in the agent view dispatch input to insert a newline (matching the prompt); ctrl+enter now dispatches and attaches
  • Changed /loop: self-paced dynamic mode and the no-prompt autonomous default are now always available, including on Bedrock/Vertex/Foundry
  • Changed Anthropic telemetry export failures to log at debug level as [Anthropic telemetry] instead of [3P telemetry] OTEL diag error, so they are not mistaken for your OTel collector failing
  • Changed cross-session messaging in Linux user namespaces: root-equivalent trust for unmapped owners is limited to canonical system directories
  • Changed SendMessage from a subagent to another session: the result now notes that any reply is delivered to the parent session's conversation, not to the subagent
