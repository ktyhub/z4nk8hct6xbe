código claude v2.1.212

O que mudou

  • /fork agora copia sua conversa para uma nova sessão em segundo plano (sua própria linha em claude agents) enquanto você continua trabalhando; o subagente na sessão usado para iniciar agora é /subtask
  • Adicionado claude auto-mode reset para restaurar a configuração padrão do modo automático, com um prompt de confirmação (passe --yes para pular)
  • Adicionado um limite para toda a sessão nas chamadas da ferramenta WebSearch (padrão 200, ajustável via CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION) para interromper loops de pesquisa descontrolados
  • Adicionado um limite por sessão em spawns de subagentes (padrão 200, substituição por CLAUDE_CODE_MAX_SUBAGENTS_PER_SESSION) para interromper loops de delegação descontrolados; /clear redefine o orçamento
  • As chamadas da ferramenta MCP com duração superior a 2 minutos agora passam para o segundo plano automaticamente para que a sessão permaneça utilizável; configure o limite ou desative com CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS
  • Digitar /resume na visualização do agente agora abre um seletor de sessões anteriores — incluindo sessões excluídas da lista — e retoma sua escolha como uma sessão em segundo plano
  • Correção de comandos Bash de modificação de arquivo de execução automática no modo de plano (por exemplo, touch, rm) sem um prompt de permissão ou retorno de chamada SDK canUseTool
  • Corrigida a criação da árvore de trabalho seguindo um link simbólico confirmado pelo repositório em .claude/worktrees, que poderia criar arquivos fora do repositório
  • Corrigida a interrupção de um gancho continue:false sendo descartada quando a ferramenta falha ou conclui o mid-stream, e erros de infraestrutura de gancho sendo relatados incorretamente como rejeições do usuário
  • Corrigido SIGTERM durante uma ferramenta Bash em execução, deixando a árvore de processos do comando órfã no modo print/SDK; o CLI agora aborta a curva, mata a árvore e sai 143
  • Corrigida falha de /background e claude --bg com "EUNKNOWN: erro desconhecido, uv_spawn" no Windows quando a Política de Grupo bloqueia o PowerShell 5.1; o daemon agora prefere o PowerShell 7
  • Corrigido o modo shell (!) que não executava comandos contendo caminhos de arquivo enquanto o pop-up de preenchimento automático de caminho estava aberto
  • Corrigidas notificações de negação no modo automático que renderizavam caracteres quebrados quando um motivo de negação longo era truncado no meio do emoji
  • Correção de Ctrl+J que não inseria uma nova linha na entrada de despacho da visualização do agente em terminais com relatórios de chave estendidos e apareceu o atalho de nova linha na sobreposição de ajuda do ?
  • Corrigido /ultrareview rejeitando referências de PR como #123, PR 123 e URLs de PR colados; dicas de erro agora nomeiam o comando que você realmente digitou
  • Corrigido /ultrareview <branch> que não buscava o branch na origem quando ele existe remotamente; agora sugere o nome da filial mais próxima em caso de erros de digitação
  • Corrigido /ultrareview ignorando a confirmação de cobrança em uma nova conversa após /clear
  • Corrigido o erro "não é um repositório git" do /ultrareview no Claude Desktop, agora sugerindo a pasta do repositório do projeto em vez de comandos de terminal
  • Correção de sessões hospedadas (gerenciadas por host) que falhavam na inicialização quando as configurações do repositório configuravam certificados mTLS, pacotes extras de CA ou escopos OAuth; essas configurações de transporte agora são ignoradas com um aviso
  • Corrigido um erro espúrio "O arquivo ainda não foi lido" ao editar um arquivo que foi lido com deslocamento/limite antes de retomar uma sessão
  • Corrigida falha de ExitWorktree com "nenhuma sessão EnterWorktree ativa" após retomar uma sessão com --continue/--resume no modo de impressão/SDK
  • Corrigida a grade do agente de fluxo de trabalho que ficava vazia para clients de controle remoto que ingressam em uma sessão no meio da execução
  • Corrigidas solicitações de controle no modo de streaming sendo marcadas como concluídas antes da conclusão do manipulador, o que poderia perder a solicitação no reinício da sessão
  • Corrigidas sessões em segundo plano criadas com /fork perdendo sua proteção pai ao vivo após uma falha de gravação de estado
  • Corrigida a falha silenciosa da reabertura de uma sessão em segundo plano interrompida a partir da visualização do agente. Agora ela retoma a sessão ou mostra por que não pode e permite forçar uma reinicialização
  • Equipes de agentes fixas: um colega de equipe que parasse poderia enviar ao líder notificações duplicadas de inatividade quando a inicialização da equipe fosse executada novamente dentro de uma sessão
  • Corrigida a divisão do rodapé da caixa de diálogo de aprovação do plano "ctrl+g para editar no <editor>" quando o caminho do arquivo é longo
  • Corrigido o banner de boas-vindas mantendo suas antigas larguras de painel após um redimensionamento combinado de largura + altura do terminal no modo de tela cheia
  • Corrigidas visualizações de diferenças que perdiam seus números de linha e marcadores +/- em layouts estreitos
  • Corrigidas @-menções que não anexavam nada após uma leitura parcial do arquivo, desinstalação do plugin visando o mercado errado e falso "Tempo limite do comando esgotado" no código de saída 143
  • Foram corrigidas as exportações HTTP OpenTelemetry sendo rejeitadas com 411/400 pelo Azure Monitor e outros pontos de extremidade que não aceitam codificação de transferência em partes
  • Corrigidos registros de log de eventos OTLP faltando trace_id/span_id quando TRACEPARENT está definido no modo SDK/headless
  • Correção de conversas com muitas imagens falhando incorretamente com erros de "Solicitação muito grande" e melhoria da mensagem de erro para explicar a causa real
  • Corrigida a pesquisa na web e a busca na web que retornavam o texto "API Error" como resultados de pesquisa ou conteúdo da página quando o API estava sobrecarregado
  • Melhoria na confiabilidade da pesquisa na Web e da busca na Web, repetindo 529 erros e solicitações com taxa limitada com espera limitada
  • Cache de prompt aprimorado: o bloco do sistema no meio da conversa agora funciona atrás de gateways LLM e URLs base personalizados (Bedrock, Vertex, 1P)
  • Anexação de agente em segundo plano aprimorada: a anexação a frio agora mostra instantaneamente a transcrição formatada enquanto a sessão é inicializada, em vez de uma espera em branco
  • Uso reduzido de tokens em mensagens entre agentes: os corpos SendMessage não são mais duplicados no histórico reproduzido e nos resultados da ferramenta
  • /fork foi alterado para nomear a cópia após seu prompt quando a sessão não tem título, para que a linha seja reconhecível na visualização do agente
  • /btw simples alterado para reabrir o painel de perguntas laterais em sua troca mais recente para que você possa navegar pelas respostas anteriores
  • Alterada a dica do rodapé ← para pulsar N done por um momento quando um agente em segundo plano termina enquanto nada precisa de sua entrada
  • Parâmetro mode da ferramenta Task descontinuado (agora ignorado); os subagentes herdam o modo de permissão da sessão pai por padrão
  • Alteração do Enterprise forceLoginMethod para ser aplicada à extensão VS Code, logins SDK, setup-token e install-github-app, não apenas ao terminal
  • Transcrições de sessão alteradas para registrar o nível de esforço de raciocínio em cada mensagem do assistente
  • Alteradas sessões headless/SDK para aplicar uma solicitação de controle set_model no meio do giro; a próxima viagem de ida e volta do modelo usa o novo modelo em vez de esperar pela próxima curva
  • Visualização do agente alterada / claude agents --json: sessões aguardando em um sandbox, entrada de MCP ou prompt de configurações gerenciadas agora são exibidas como "Necessita de entrada" em vez de "Em funcionamento"
  • Atualizado o título do painel de status de autenticação de "Autenticação na nuvem" para "Autenticação"
  • Corrigido um release note anterior (2.1.200): tmux através da série 3.6 não possui saída sincronizada; tmux mais recente com suporte é detectado automaticamente

claude-code v2.1.212

What's changed

  • /fork now copies your conversation into a new background session (its own row in claude agents) while you keep working; the in-session subagent it used to launch is now /subtask
  • Added claude auto-mode reset to restore the default auto-mode configuration, with a confirmation prompt (pass --yes to skip)
  • Added a session-wide limit on WebSearch tool calls (default 200, tunable via CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION) to stop runaway search loops
  • Added a per-session cap on subagent spawns (default 200, override with CLAUDE_CODE_MAX_SUBAGENTS_PER_SESSION) to stop runaway delegation loops; /clear resets the budget
  • MCP tool calls running longer than 2 minutes now move to the background automatically so the session stays usable; configure the threshold or disable with CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS
  • Typing /resume in the agent view now opens a picker of past sessions — including sessions deleted from the list — and resumes your pick as a background session
  • Fixed plan mode auto-running file-modifying Bash commands (e.g. touch, rm) without a permission prompt or SDK canUseTool callback
  • Fixed worktree creation following a repository-committed symlink at .claude/worktrees, which could create files outside the repository
  • Fixed a continue:false hook's halt being dropped when the tool fails or completes mid-stream, and hook infrastructure errors being misreported as user rejections
  • Fixed SIGTERM during a running Bash tool orphaning the command's process tree in print/SDK mode; the CLI now aborts the turn, kills the tree, and exits 143
  • Fixed /background and claude --bg failing with "EUNKNOWN: unknown error, uv_spawn" on Windows when Group Policy blocks PowerShell 5.1; the daemon now prefers PowerShell 7
  • Fixed shell mode (!) not executing commands containing file paths while the path autocomplete popup was open
  • Fixed auto-mode denial notifications rendering broken characters when a long denial reason was truncated mid-emoji
  • Fixed Ctrl+J not inserting a newline in the agent view dispatch input on terminals with extended key reporting, and surfaced the newline shortcut in the ? help overlay
  • Fixed /ultrareview rejecting PR references like #123, PR 123, and pasted PR URLs; error hints now name the command you actually typed
  • Fixed /ultrareview <branch> not fetching the branch from origin when it exists remotely; it now suggests the closest branch name on typos
  • Fixed /ultrareview skipping the billing confirmation in a new conversation after /clear
  • Fixed /ultrareview's "not a git repository" error on Claude Desktop now suggesting the project's repository folder instead of terminal commands
  • Fixed hosted (host-managed) sessions failing at startup when repository settings configured mTLS certs, extra CA bundles, or OAuth scopes; these transport settings are now ignored with a warning
  • Fixed a spurious "File has not been read yet" error when editing a file that had been read with offset/limit before resuming a session
  • Fixed ExitWorktree failing with "no active EnterWorktree session" after resuming a session with --continue/--resume in print/SDK mode
  • Fixed the workflow agent grid staying empty for Remote Control clients that join a session mid-run
  • Fixed streaming-mode control requests being marked complete before their handler finished, which could lose the request on session restart
  • Fixed background sessions created with /fork losing their live-parent protection after a state write failure
  • Fixed reopening a stopped background session from the agent view failing silently — it now resumes the session, or shows why it can't and lets you force a restart
  • Fixed agent teams: a stopping teammate could send the leader duplicate idle notifications when team initialization re-ran within a session
  • Fixed the plan-approval dialog footer splitting "ctrl+g to edit in <editor>" apart when the file path is long
  • Fixed the welcome banner keeping its old panel widths after a combined width+height terminal resize in fullscreen mode
  • Fixed diff previews losing their line numbers and +/- markers in narrow layouts
  • Fixed @-mentions attaching nothing after a partial file read, plugin uninstall targeting the wrong marketplace, and false "Command timed out" on exit code 143
  • Fixed OpenTelemetry HTTP exports being rejected with 411/400 by Azure Monitor and other endpoints that don't accept chunked transfer encoding
  • Fixed OTLP event log records missing trace_id/span_id when TRACEPARENT is set in SDK/headless mode
  • Fixed conversations with many images incorrectly failing with "Request too large" errors, and improved the error message to explain the actual cause
  • Fixed web search and web fetch returning "API Error" text as search results or page content when the API was overloaded
  • Improved web search and web fetch reliability by retrying 529 errors and rate-limited requests with bounded backoff
  • Improved prompt caching: the mid-conversation system block now works behind LLM gateways and custom base URLs (Bedrock, Vertex, 1P)
  • Improved background agent attach: cold-attaching now instantly shows the formatted transcript while the session boots, instead of a blank wait
  • Reduced token usage in inter-agent messaging: SendMessage bodies are no longer duplicated into replayed history and tool results
  • Changed /fork to name the copy after your prompt when the session has no title, so the row is recognizable in the agent view
  • Changed bare /btw to reopen the side-question panel on your most recent exchange so you can browse earlier answers
  • Changed the ← footer hint to pulse N done for a moment when a background agent finishes while nothing needs your input
  • Deprecated the Task tool's mode parameter (now ignored); subagents inherit the parent session's permission mode by default
  • Changed Enterprise forceLoginMethod to be enforced for VS Code extension, SDK, setup-token, and install-github-app logins, not just the terminal
  • Changed session transcripts to record the reasoning effort level on each assistant message
  • Changed headless/SDK sessions to apply a set_model control request mid-turn; the next model round-trip uses the new model instead of waiting for the next turn
  • Changed agent view / claude agents --json: sessions waiting on a sandbox, MCP-input, or managed-settings prompt now show as "Needs input" instead of "Working"
  • Updated the auth status panel title from "Cloud authentication" to "Authentication"
  • Corrected an earlier release note (2.1.200): tmux through the 3.6 series lacks synchronized output; newer tmux with support is detected automatically
