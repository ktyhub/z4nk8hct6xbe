código claude v2.1.218

O que mudou

  • /code-review alterado para ser executado como um subagente em segundo plano, para que o trabalho de revisão não preencha mais sua conversa e mantenha comandos de barra empilhados como alvo de revisão
  • Adicionados anúncios de leitor de tela de texto excluído para exclusões de palavras e linhas (Option+Delete, Ctrl+W, Cmd+Backspace, Ctrl+U, Ctrl+K) no modo --ax-screen-reader
  • Correção de caminhos do Windows com segmentos prefixados \u (como C:\Users\unicorn) sendo corrompidos em caracteres CJK nas entradas de ferramentas, o que tornava esses arquivos inacessíveis
  • Corrigida a tecla de seta para esquerda descartando a conversa sem desfazer: pressionar logo após a edição agora pede para confirmar, e Esc na visualização do agente retorna para a conversa em segundo plano
  • Adicionado status HTTP e texto de erro para claude mcp list e /mcp quando um servidor falha ao se conectar e um aviso para valores de configuração MCP com espaços em branco iniciais ou finais ocultos
  • Correção da colagem de várias linhas colapsando em uma linha com j no lugar de novas linhas em terminais que codificam novas linhas coladas como Ctrl+J
  • Correção do relatório /context de uso obsoleto de token pré-compactado após a compactação do seletor de mensagens
  • Corrigida a falha do /ultrareview em argumentos descritivos como "revisar minhas alterações de autenticação" — eles agora executam uma revisão do seu branch atual com o texto aplicado como uma nota às descobertas
  • Correção do /code-review ultra executando silenciosamente uma revisão local em sessões não interativas — agora inicia a revisão na nuvem
  • Correção da medição de gastos do gateway para precificar ARNs de perfil de inferência de aplicativo Bedrock e outros IDs de modelo upstream mapeados por configuração nas taxas do modelo configurado
  • Corrigido o mojibake quando uma seleção longa do IDE era truncada no meio do emoji e um caso em que um erro do executor da ferramenta poderia ser descartado silenciosamente
  • Corrigida uma corrida de desmontagem do motor que poderia iniciar e abandonar uma curva fantasma, e fazer com que a entrada pressionada após o fechamento fosse consistentemente rejeitada
  • Correção de mensagens falsas "[Solicitação interrompida pelo usuário]" após chamadas de ferramenta interrompidas e um bloco tool_use desemparelhado deixado na transcrição quando uma ferramenta abortava no meio da resposta
  • Corrigido o VoiceOver lendo "nova linha" em vez de ecoar o espaço digitado no final da entrada no modo --ax-screen-reader
  • Corrigido o plugin e os painéis de configurações que não moviam o cursor do terminal para a linha em foco, para que leitores de tela e ampliadores pudessem seguir a navegação com as teclas de seta
  • Corrigidas falhas (pilha de chamadas máxima excedida) quando uma árvore de diretórios monitorada profundamente aninhada era excluída ou movida e ao renderizar árvores de UI profundamente aninhadas
  • Correção de eventos de pull request que ocasionalmente eram perdidos quando uma sessão era encerrada imediatamente após a criação ou vinculação de um PR
  • Correção de falha na verificação de perfil do assistente de configuração Bedrock para perfis de função assumida em regiões particionadas da AWS e em redes somente proxy
  • Corrigidas medições raras de duração de giro negativas ou incorretas após um ajuste do relógio do sistema cronometrando giros com um relógio monotônico
  • Corrigido o aviso de inicialização "N servidores MCP precisam de autenticação" contando excessivamente conectores claude.ai que não estão conectados em claude.ai
  • Corrigidas entradas do histórico de prompt sendo descartadas ou duplicadas quando as gravações do histórico eram aceleradas ou falhavam
  • Corrigido um loop de repetição que reenviava solicitações idênticas condenadas após um erro de estouro de contexto com um grande orçamento de pensamento; O plano de fundo Ctrl+B agora aplica os mesmos limites de fundo de outros caminhos
  • Corrigidos ganchos frontmatter do agente em execução em pastas untrusted: os ganchos agora exigem que a própria pasta do arquivo do agente tenha espaço de trabalho aceito trust
  • Corrigida a perda da linhagem da sessão fork após a compactação em sessões headless e SDK
  • Corrigida uma sessão retomada que falhava a cada turno ou travava ao retomar, quando seu histórico continha um anexo delta malformado
  • Feedback de erro /ultrareview aprimorado para que Claude possa corrigir um argumento inválido em vez de tentar novamente inalterado
  • Modo automático aprimorado: as verificações de perigoso-rm, background-& e caminho suspeito do Windows não abrem mais caixas de diálogo de permissão; o classificador de modo automático os julga
  • Restrições de comando de sandbox aprimoradas para interações IDE
  • Diálogos trust aprimorados para nomear a raiz do repositório que a concessão cobre
  • Alterado /deep-research para iniciar somente quando invocado manualmente; Claude não lança mais sozinho
  • Alterado o modo de plano com auto para não solicitar mais comandos Bash, o analisador estático não pode ser somente leitura; o classificador de modo automático os julga
  • Adicionado um anúncio quando o modo rápido muda como resultado da troca de modelos via /config model=<x> ou controle remoto
  • Configurações gerenciadas pelo servidor alteradas para que recursos benignos e alternâncias de custos não acionem mais o prompt de aprovação de configurações
  • Arquivos de marcação de agente alterados para rejeitar nomes de agentes contendo :, que é reservado para namespace de plugin
  • Habilidades alteradas com context: fork para rodar em segundo plano por padrão; cancelar por habilidade com background: false
  • Adicionados yes/no/on/off/1/0 (sem distinção entre maiúsculas e minúsculas) como valores aceitos para booleanos frontmatter de habilidade e plug-in, juntamente com true/false
  • Correção de sessões remotas que continuavam a enviar pulsações após a substituição do trabalhador, o que deixava processos de desktop e IDE de longa duração repetindo uma solicitação rejeitada a cada poucos segundos para sempre

claude-code v2.1.218

What's changed

  • Changed /code-review to run as a background subagent, so review work no longer fills your conversation and keeps stacked slash commands as its review target
  • Added screen-reader announcements of deleted text for word and line deletions (Option+Delete, Ctrl+W, Cmd+Backspace, Ctrl+U, Ctrl+K) in --ax-screen-reader mode
  • Fixed Windows paths with \u-prefixed segments (like C:\Users\unicorn) being corrupted into CJK characters in tool inputs, which made those files inaccessible
  • Fixed the left arrow key discarding the conversation with no undo: presses right after editing now ask to confirm, and Esc in the agent view returns to the conversation it backgrounded
  • Added HTTP status and error text to claude mcp list and /mcp when a server fails to connect, and a warning for MCP config values with hidden leading or trailing whitespace
  • Fixed multi-line paste collapsing into one line with j in place of newlines in terminals that encode pasted newlines as Ctrl+J
  • Fixed /context reporting stale pre-compact token usage after compacting from the message picker
  • Fixed /ultrareview failing on descriptive arguments like "review my auth changes" — they now run a review of your current branch with the text applied as a note to the findings
  • Fixed /code-review ultra silently running a local review in non-interactive sessions — it now launches the cloud review
  • Fixed gateway spend metering to price Bedrock application-inference-profile ARNs and other config-mapped upstream model IDs at the configured model's rates
  • Fixed mojibake when a long IDE selection was truncated mid-emoji, and a case where a tool executor error could be silently dropped
  • Fixed an engine teardown race that could start and abandon a phantom turn, and made input pushed after close consistently rejected
  • Fixed spurious "[Request interrupted by user]" messages after interrupted tool calls, and an unpaired tool_use block left in the transcript when a tool aborted mid-response
  • Fixed VoiceOver reading "new line" instead of echoing the typed space at the end of the input in --ax-screen-reader mode
  • Fixed plugin and settings panels not moving the terminal cursor to the focused row, so screen readers and magnifiers can follow arrow-key navigation
  • Fixed crashes (maximum call stack exceeded) when a deeply nested watched directory tree was deleted or moved, and when rendering deeply nested UI trees
  • Fixed pull request events occasionally being lost when a session exited immediately after creating or linking a PR
  • Fixed the Bedrock setup wizard failing profile verification for assume-role profiles in partitioned AWS regions and on proxy-only networks
  • Fixed rare negative or incorrect turn duration measurements after a system clock adjustment by timing turns with a monotonic clock
  • Fixed the "N MCP servers need authentication" startup notice over-counting claude.ai connectors that aren't connected in claude.ai
  • Fixed prompt history entries being dropped or duplicated when history writes raced or failed
  • Fixed a retry loop that re-sent identical doomed requests after a context-overflow error with a large thinking budget; Ctrl+B backgrounding now applies the same background-shell caps as other paths
  • Fixed agent frontmatter hooks running from untrusted folders: hooks now require the agent file's own folder to have accepted workspace trust
  • Fixed fork-session lineage being lost after compaction in headless and SDK sessions
  • Fixed a resumed session failing every turn, or crashing on resume, when its history held a malformed delta attachment
  • Improved /ultrareview error feedback so Claude can correct an invalid argument instead of retrying it unchanged
  • Improved auto mode: the dangerous-rm, background-&, and suspicious-Windows-path checks no longer open permission dialogs; the auto-mode classifier adjudicates them instead
  • Improved sandbox command restrictions for IDE interactions
  • Improved trust dialogs to name the repository root the grant covers
  • Changed /deep-research to start only when invoked manually; Claude no longer launches it on its own
  • Changed plan mode with auto to no longer prompt for Bash commands the static analyzer can't prove read-only; the auto-mode classifier judges them instead
  • Added an announcement when fast mode changes as a result of switching models via /config model=<x> or Remote Control
  • Changed server-managed settings so benign feature and cost toggles no longer trigger the settings-approval prompt
  • Changed agent markdown files to reject agent names containing :, which is reserved for plugin namespacing
  • Changed skills with context: fork to run in the background by default; opt out per skill with background: false
  • Added yes/no/on/off/1/0 (case-insensitive) as accepted values for skill and plugin frontmatter booleans, alongside true/false
  • Fixed remote sessions continuing to send heartbeats after their worker was replaced, which left long-lived desktop and IDE processes retrying a rejected request every few seconds forever
