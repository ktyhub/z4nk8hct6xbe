código claude v2.1.223

O que mudou

  • Adicionadas entradas curinga de proprietário ("owner/*") às configurações gerenciadas de strictKnownMarketplaces e blockedMarketplaces para permitir ou bloquear todos os repositórios de mercado em uma organização GitHub
  • Adicionado um aviso quando agentes de fluxo de trabalho, habilidades bifurcadas, comandos de barra ou modelo de subagente solicitado por agentes em segundo plano retomados são restritos e o modelo pai é executado em seu lugar
  • Adicionada uma dica /teleport nas sessões de nuvem mostrando como continuar localmente com claude --teleport <session id>
  • Corrigido um desvio de permissão do Bash, onde um comando criado poderia ocultar partes de si mesmo das verificações de permissão
  • Corrigidos prompts de permissão para que comandos preenchidos com guias ou Unicode invisíveis não possam mais ocultar parte do comando da caixa de diálogo de aprovação
  • Correção de scripts de fluxo de trabalho que podiam usar import() dinâmico para executar código fora da área restrita do fluxo de trabalho
  • Correção de uma lacuna de permissão em que o modo bypassPermissions de uma definição de agente ignorava a política de desabilitação de permissões de bypass da organização
  • Corrigida a retomada de uma sessão após um /cd no meio da sessão voltar vazio
  • Corrigida descoberta de modelo de gateway que ocultava modelos Claude registrados sob IDs prefixados pelo provedor, como vertex_ai/claude-* ou bedrock/anthropic.claude-*
  • Corrigidas chaves modelOverrides que não são IDs de modelo Antrópico sendo tratadas como ID de modelo canônico da sessão; chaves desconhecidas agora são ignoradas conforme documentado
  • Configurações gerenciadas corrigidas: as configurações entregues pelo servidor não desabilitam mais o bloco env de um perfil managed-settings.json ou MDM local da máquina; admin env agora mescla por chave
  • Correção de comandos em sandbox que não iniciavam no Linux quando sandbox.filesystem.denyWrite cobre o diretório de trabalho
  • Correção de agentes bifurcados em segundo plano que ficavam presos "já retomando" pelo resto da sessão quando a reconstrução do prompt pai do fork falhava durante a retomada
  • Corrigida uma sessão retomada que falhava a cada turno ou deixava o aplicativo interativo em uma tela de erro que não respondia, quando seu histórico continha um anexo de diagnóstico malformado
  • Corrigido um travamento raro ao analisar a saída incomum do git push
  • CLAUDE_CODE_DISABLE_1M_CONTEXT alterado para armazenar todos os modelos Claude com uma janela nativa de 1M para 200K via compactação automática, não apenas uma lista fixa; um aviso de inicialização agora aparece quando a compactação automática não mantém a sessão em 200K
  • Alteração da compactação automática para manter as sessões em IDs de modelo não reconhecidos dentro da janela de contexto presumida, em vez de deixá-las crescer além dela; configure CLAUDE_CODE_DISABLE_UNKNOWN_MODEL_WINDOW_ENFORCEMENT=1 para restaurar o comportamento anterior
  • Alterado /review para ser um alias de /code-review, que analisa o diff atual ou PR (/code-review <level> <pr#>); use /code-review ultra para uma revisão profunda da nuvem
  • Alterado /code-review sem nível de esforço para reutilizar o nível digitado por último; digite um nível como /code-review high para alterá-lo

claude-code v2.1.223

What's changed

  • Added owner wildcard entries ("owner/*") to the strictKnownMarketplaces and blockedMarketplaces managed settings for allowing or blocking all marketplace repos under a GitHub org
  • Added a warning when workflow agents, forked skills, slash commands, or resumed background agents' requested subagent model is restricted and the parent model runs instead
  • Added a /teleport hint in cloud sessions showing how to continue locally with claude --teleport <session id>
  • Fixed a Bash permission bypass where a crafted command could hide parts of itself from permission checks
  • Fixed permission prompts so commands padded with tabs or invisible Unicode can no longer hide part of the command from the approval dialog
  • Fixed workflow scripts being able to use dynamic import() to run code outside the workflow sandbox
  • Fixed a permission gap where an agent definition's bypassPermissions mode ignored the org bypass-permissions disable policy
  • Fixed resuming a session after a mid-session /cd coming back empty
  • Fixed gateway model discovery hiding Claude models registered under provider-prefixed IDs such as vertex_ai/claude-* or bedrock/anthropic.claude-*
  • Fixed modelOverrides keys that aren't Anthropic model IDs being treated as the session's canonical model ID; unknown keys are now ignored as documented
  • Fixed managed settings: server-delivered settings no longer disable the env block of a machine-local managed-settings.json or MDM profile; admin env now merges per key
  • Fixed sandboxed commands failing to start on Linux when sandbox.filesystem.denyWrite covers the working directory
  • Fixed forked background agents getting stuck "already resuming" for the rest of the session when rebuilding the fork's parent prompt failed during resume
  • Fixed a resumed session failing every turn, or leaving the interactive app on an unresponsive error screen, when its history held a malformed diagnostics attachment
  • Fixed a rare hang when parsing unusual git push output
  • Changed CLAUDE_CODE_DISABLE_1M_CONTEXT to hold every Claude model with a native 1M window to 200K via auto-compaction, not just a fixed list; a startup warning now appears when auto-compaction isn't holding the session to 200K
  • Changed auto-compact to keep sessions on unrecognized model IDs within the assumed context window instead of letting them grow past it; set CLAUDE_CODE_DISABLE_UNKNOWN_MODEL_WINDOW_ENFORCEMENT=1 to restore the previous behavior
  • Changed /review to be an alias of /code-review, which reviews the current diff or a PR (/code-review <level> <pr#>); use /code-review ultra for a deep cloud review
  • Changed /code-review with no effort level to reuse the level you typed last; type a level like /code-review high to change it
