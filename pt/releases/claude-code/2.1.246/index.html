código claude v2.1.246

O que mudou

  • Adicionado um aviso de inicialização para regras de permissão do Bash com um curinga antes do subcomando (por exemplo, Bash(git * main)), uma vez que também correspondem às opções inseridas antes do subcomando
  • Adicionada uma guia de modo automático ao /permissions para visualizar e editar regras do classificador de modo automático
  • Adicionado o tempo de conclusão do turno à linha de duração do final do turno, por ex. ✻ Sautéed for 23s · done 6:05 PM
  • Corrigido o modo de tela cheia mostrando uma transcrição em branco após redimensionar o terminal e pular para baixo até o próximo pressionamento de tecla
  • Corrigida uma lentidão grave na transcrição quando uma comparação continha uma única linha muito longa (por exemplo, uma string base64); essas linhas agora ficam truncadas com um marcador
  • Correção da rolagem errática em tela cheia quando posicionado em uma mensagem anterior, incluindo pular para baixo e travar no meio da transcrição
  • Correção de sessões em segundo plano que falhavam ao abrir após 45 segundos quando o diretório inicial de Claude Code era excluído, a máquina dormia ou o host demorava para iniciar processos
  • Corrigidas sessões em segundo plano que falhavam ao abrir com "Não foi possível iniciar o serviço em segundo plano... EACCES" quando outro processo do Claude Code estava reinstalando o pacote npm naquele momento
  • Correção da renderização de markdown sendo desativada para uma mensagem inteira quando seus primeiros 500 caracteres não continham markdown e para listas +/N) e cabeçalhos de texto
  • Corrigidas chamadas de ferramenta MCP interrompidas por uma mensagem recebida em sessões headless/remotas sendo relatadas ao modelo como "concluídas sem saída" em vez de um erro explícito de interrupção
  • Corrigidos argumentos da ferramenta MCP sendo enviados como strings JSON quando o esquema do parâmetro está vazio ({}), em vez de seu tipo real
  • Corrigido um comando interrompido no meio da execução mostrando como "Ran 1 shell command" sem nenhum sinal de que foi cortado
  • Corrigido o pressionamento de ← ou a execução de /background durante um fluxo de trabalho dinâmico reiniciando seus subagentes finalizados; agora pergunta primeiro e diz quantos subagentes seriam reiniciados
  • Corrigida a abertura de uma sessão recém-iniciada no claude agents enquanto seu trabalhador ainda estava inicializando (comum no Windows), parando-a com "foi interrompida enquanto o respawn estava em andamento"
  • Corrigido claude agents listando uma sessão nomeada em segundo plano duas vezes; colocar a mesma conversa em segundo plano novamente agora numera a nova linha (por exemplo, my-session (2))
  • Corrigida a varredura de retenção em segundo plano, removendo árvores de trabalho git em .claude/worktrees/ que você mesmo criou quando um antigo registro de sessão em segundo plano apontava para elas
  • Corrigidas chamadas de ferramenta no modo automático negadas como "temporariamente indisponíveis" em sessões muito grandes, aumentando o prazo de verificação de segurança com o tamanho do prompt
  • Corrigido o cache do plugin criando diretórios duplicados com nomes SHA para o mesmo plugin
  • Corrigidas habilidades de plugin cujo frontmatter name já inclui o prefixo <plugin>: mostrando-o duplicado no menu de barras (por exemplo, /plugin:plugin:skill)
  • Corrigida falha de claude plugin update em um plugin instalado devido ao seu nome simples (apenas o nome totalmente qualificado funcionava)
  • Corrigida falha na instalação do plugin quando plugin.json era salvo com uma marca de ordem de bytes (BOM) UTF-8
  • Corrigido /reload-plugins reportando 0 habilidades para plugins que definem habilidades em skills/*/SKILL.md
  • Corrigidas mensagens de erro de gancho mostrando um ${CLAUDE_PLUGIN_ROOT} literal em vez do caminho do plugin resolvido
  • Corrigido /rename substituindo a cor da borda do prompt do tema (incluindo promptBorder de um tema personalizado) pelo ciano padrão; a borda agora mantém a cor do seu tema, a menos que você escolha uma com /color
  • Corrigidas cores de comparação de tema personalizado (diffAdded/diffRemoved e suas variantes esmaecidas) sendo ignoradas nas diferenças e na visualização do /theme
  • Corrigida uma ligação keybindings.json com um nome de ação desconhecido, amortecendo silenciosamente essa chave; agora ele foi ignorado para que a ligação padrão continue funcionando e um aviso seja registrado em --debug
  • Corrigido o mapa de calor da atividade /stats mostrando a atividade de cada dia com uma célula de folga (contagem de domingo abaixo de segunda-feira) em fusos horários a leste de UTC
  • Corrigido /fork de uma sessão já bifurcada ou em segundo plano iniciando a nova sessão com uma conversa vazia
  • Correção de prompts começando com /-- (por exemplo, comentários de documentos Lean) sendo rejeitados como um comando de barra desconhecido em vez de serem enviados para Claude
  • Corrigido o seletor de arquivo @ que permanecia aberto após o texto digitado parar de corresponder a um caminho real
  • Corrigido o custo e a duração da linha de status, redefinidos para zero após navegar até a visualização dos agentes e voltar
  • Corrigido o modo de tela cheia movendo o foco do teclado para o controle sob o ponteiro quando você cli clicava na janela do terminal apenas para trazê-la de volta ao foco
  • Corrigida falha na conclusão do caminho quando o token de conclusão ou diretório de trabalho continha um byte nulo
  • Windows/macOS: Corrigidas sessões headless que não limpavam entradas obsoletas no ~/.claude/sessions deixadas por sessões que terminaram de forma imprópria
  • Correção da interrupção da interface do usuário com um erro de renderização na primeira chamada de ferramenta quando um endpoint compatível com Anthropic de terceiros (ANTHROPIC_BASE_URL) transmite um bloco tool_use sem um id
  • Correção da ferramenta de gravação informando "Sem memória" ou travando por um longo tempo após substituir um arquivo existente muito grande, mesmo que o arquivo tenha sido gravado
  • Corrigida a saída silenciosa do claude plugin install <name> (ou travado em um terminal) em vez de reportar um erro quando o ~/.claude/plugins/known_marketplaces.json está vazio ou corrompido
  • Correção de sessões retomadas que falhavam a cada turno com um 400 quando o histórico salvo continha blocos de ferramentas que o Antrópico API não aceita (normalmente escrito por um proxy API de terceiros)
  • Correção da falha do curl -fsSL https://claude.ai/install.sh | bash com "Modo bruto não suportado" para alguns usuários Team/Enterprise com configurações gerenciadas pelo servidor
  • Corrigidas sessões que terminavam no modo de plano, retomando fora do modo de plano na extensão VS Code e em claude -p --continue/--resume com uma ferramenta de prompt de permissão, quando nenhum modo de permissão era definido
  • Corrigido o gancho Notification que não disparava enquanto o prompt de permissão "Solicitação de rede fora do sandbox" do sandbox estava aguardando
  • Correção das verificações de permissão do Bash para sempre exigir aprovação para comandos malformados com um operador && ou || pendente
  • Corrigidas sessões --strict-mcp-config solicitando a aprovação de servidores .mcp.json que eles nunca carregariam, o que deixava sessões em segundo plano aguardando na inicialização
  • Corrigidas solicitações de telemetria e métricas para a Anthropic portando a chave API configurada para gateway de terceiros (ANTHROPIC_BASE_URL); uma credencial agora é enviada apenas para seu próprio host
  • Corrigido um erro API visível no primeiro prompt após inatividade quando apiKeyHelper retorna JWTs de curta duração: um token expirado em cache agora é atualizado antes do envio e erros de autenticação 401/403 tentam novamente silenciosamente
  • Corrigido o aumento da memória com a duração da sessão nas visualizações de transcrição em tela cheia e Ctrl+O: cada linha de mensagem renderizada não retém mais uma cópia completa das pesquisas da ferramenta de transcrição
  • Corrigidas execuções e sessões de nuvem do /ultrareview iniciadas ao mesmo tempo a partir de um repositório (por exemplo, de várias árvores de trabalho), às vezes começando com alterações não confirmadas de outro lançamento
  • Corrigida a contagem de progresso da tarefa (por exemplo, 3/5) mostrada para sessões de nuvem em segundo plano, como /autofix-pr ocasionalmente perdendo uma tarefa
  • Corrigidas sessões de Controle Remoto mantendo seu nome de espaço reservado em claude.ai e no aplicativo Claude até o segundo prompt; o título gerado automaticamente agora aparece após o primeiro prompt
  • Corrigidas ferramentas MCP marcadas como requiresUserInteraction que ainda oferecem "Sim e não pergunte novamente" em seu prompt de permissão; a opção escreveu uma regra de permissão que a ferramenta ignorou
  • Corrigido o executor auto-hospedado que encerrava suas sessões ao vivo ou saía quando uma resposta da pesquisa de trabalho estava malformada (por exemplo, uma página HTML de um proxy interceptador); agora ele tenta novamente a enquete
  • /cd aprimorado: as configurações do projeto do novo diretório, ganchos, servidores .mcp.json (atrás do prompt de aprovação usual), habilidades e agentes agora entram em vigor logo após a mudança, em vez de no --resume
  • Latência aprimorada da ferramenta Bash em shells bash, reproduzindo funções de snapshot sem um subshell base64 por função
  • Resultados aprimorados do subagente: um subagente que para no seu limite maxTurns agora retorna sua saída marcada como parcial, com uma dica para continuar via SendMessage, em vez de parecer concluído
  • Sessões não interativas aprimoradas (-p, SDK, sessões na nuvem) para continuar automaticamente uma resposta interrompida no meio do fluxo por um erro do servidor, perda de conexão ou travamento, em vez de terminar com um erro
  • Atribuição aprimorada de telemetria de uso à sua organização para sessões de federação de identidade de carga de trabalho, eventos enviados enquanto o apiKeyHelper é executado na inicialização e após um token de login expirar enquanto ocioso
  • /code-review alterado para que Claude também possa iniciá-lo sozinho no Bedrock, Vertex AI e Foundry, através do gateway de aplicativos Claude e quando a telemetria ou tráfego não essencial estiver desativado
  • /goal: Sessões ociosas alteradas para iniciar no máximo três check-ins em trabalhos em segundo plano de longa duração por meta; sua próxima mensagem permite mais três
  • claude install e claude update alterados para adiar um prompt de consentimento de configurações gerenciadas pendentes para a próxima sessão interativa em vez de solicitar o comando intermediário
  • Alterados eventos do plugin OpenTelemetry para plugins sincronizados de claude.ai: plugin_id_hash agora reflete o mercado real do plugin, e enabled_via é admin-install para plugins instalados pelo administrador
  • Corrigida configuração do sistema de arquivos do sandbox de comando não respeitando --setting-sources

claude-code v2.1.246

What's changed

  • Added a startup warning for Bash allow rules with a wildcard before the subcommand (e.g. Bash(git * main)), since they also match options inserted before the subcommand
  • Added an Auto mode tab to /permissions for viewing and editing auto mode classifier rules
  • Added the turn's completion time to the end-of-turn duration line, e.g. ✻ Sautéed for 23s · done 6:05 PM
  • Fixed fullscreen mode showing a blank transcript after resizing the terminal and jumping to the bottom until the next keypress
  • Fixed a severe transcript slowdown when a diff contained a very long single line (e.g. a base64 string); such lines now render truncated with a marker
  • Fixed erratic fullscreen scrolling when positioned at an earlier message, including jump-to-bottom getting stuck mid-transcript
  • Fixed background sessions failing to open after 45 seconds when Claude Code's starting directory had been deleted, the machine had slept, or the host is slow to start processes
  • Fixed background sessions failing to open with "Couldn't start the background service … EACCES" when another Claude Code process was re-installing the npm package at that moment
  • Fixed markdown rendering being disabled for a whole message when its first 500 characters contained no markdown, and for +/N) lists and setext headings
  • Fixed MCP tool calls interrupted by an incoming message in headless/remote sessions being reported to the model as "completed with no output" instead of an explicit interrupted error
  • Fixed MCP tool arguments being sent as JSON strings when the parameter's schema is empty ({}), instead of their real type
  • Fixed a command interrupted mid-run showing as "Ran 1 shell command" with no sign it was cut
  • Fixed pressing ← or running /background during a dynamic workflow restarting its finished subagents; it now asks first and says how many subagents would restart
  • Fixed opening a just-started session in claude agents while its worker was still booting (common on Windows) stopping it with "was stopped while the respawn was in flight"
  • Fixed claude agents listing a backgrounded named session twice; backgrounding the same conversation again now numbers the new row (e.g. my-session (2))
  • Fixed the background retention sweep removing git worktrees under .claude/worktrees/ that you created yourself when an old background-session record pointed at them
  • Fixed auto mode tool calls being denied as "temporarily unavailable" on very large sessions by scaling the safety-check deadline with prompt size
  • Fixed the plugin cache creating duplicate SHA-named directories for the same plugin
  • Fixed plugin skills whose frontmatter name already includes the <plugin>: prefix showing it doubled in the slash menu (e.g. /plugin:plugin:skill)
  • Fixed claude plugin update failing for an installed plugin given its bare name (only the fully-qualified name worked)
  • Fixed plugin installation failing when plugin.json was saved with a UTF-8 byte-order mark (BOM)
  • Fixed /reload-plugins reporting 0 skills for plugins that define skills under skills/*/SKILL.md
  • Fixed hook error messages showing a literal ${CLAUDE_PLUGIN_ROOT} instead of the resolved plugin path
  • Fixed /rename replacing the theme's prompt border color (including a custom theme's promptBorder) with the default cyan; the border now keeps your theme's color unless you pick one with /color
  • Fixed custom theme diff colors (diffAdded/diffRemoved and their dimmed variants) being ignored in diffs and the /theme preview
  • Fixed a keybindings.json binding with an unknown action name silently deadening that key; it is now skipped so the default binding keeps working, and a warning is logged under --debug
  • Fixed /stats activity heatmap showing each day's activity one cell off (Sunday's count under Monday) in timezones east of UTC
  • Fixed /fork from an already-forked or backgrounded session starting the new session with an empty conversation
  • Fixed prompts beginning with /-- (e.g. Lean doc comments) being rejected as an unknown slash command instead of being sent to Claude
  • Fixed the @ file picker staying open after the typed text stopped matching a real path
  • Fixed the status line's cost and duration resetting to zero after navigating to the agents view and back
  • Fixed fullscreen mode moving keyboard focus onto the control under the pointer when you clicked the terminal window only to bring it back into focus
  • Fixed path completion failing when the completion token or working directory contained a null byte
  • Windows/macOS: Fixed headless sessions not cleaning up stale entries in ~/.claude/sessions left by sessions that exited uncleanly
  • Fixed the UI stopping with a render error on the first tool call when a third-party Anthropic-compatible endpoint (ANTHROPIC_BASE_URL) streams a tool_use block without an id
  • Fixed the Write tool reporting "Out of memory" or freezing for a long time after overwriting a very large existing file, even though the file had been written
  • Fixed claude plugin install <name> exiting silently (or hanging in a terminal) instead of reporting an error when ~/.claude/plugins/known_marketplaces.json is empty or corrupted
  • Fixed resumed sessions failing every turn with a 400 when the saved history contains tool blocks the Anthropic API does not accept (typically written by a third-party API proxy)
  • Fixed curl -fsSL https://claude.ai/install.sh | bash failing with "Raw mode is not supported" for some Team/Enterprise users with server-managed settings
  • Fixed sessions that ended in plan mode resuming outside plan mode in the VS Code extension, and in claude -p --continue/--resume with a permission prompt tool, when no permission mode was set
  • Fixed the Notification hook not firing while the sandbox "Network request outside of sandbox" permission prompt is waiting
  • Fixed Bash permission checks to always require approval for malformed commands with a dangling && or || operator
  • Fixed --strict-mcp-config sessions prompting to approve .mcp.json servers they would never load, which left background sessions waiting at startup
  • Fixed telemetry and metrics requests to Anthropic carrying the API key configured for a third-party gateway (ANTHROPIC_BASE_URL); a credential is now only sent to its own host
  • Fixed a visible API error on the first prompt after idle when apiKeyHelper returns short-lived JWTs: an expired cached token is now refreshed before sending, and 401/403 auth errors retry quietly
  • Fixed memory growing with session length in the fullscreen and Ctrl+O transcript views: each rendered message row no longer retains a full copy of the transcript-wide tool lookups
  • Fixed /ultrareview runs and cloud sessions launched at the same time from one repository (e.g. from several worktrees) sometimes starting with another launch's uncommitted changes
  • Fixed the task progress count (e.g. 3/5) shown for background cloud sessions such as /autofix-pr occasionally missing a task
  • Fixed Remote Control sessions keeping their placeholder name in claude.ai and the Claude app until the second prompt; the auto-generated title now appears after the first prompt
  • Fixed MCP tools marked requiresUserInteraction still offering "Yes, and don't ask again" in their permission prompt; the option wrote an allow rule the tool then ignored
  • Fixed the self-hosted runner ending its live sessions or exiting when a work-poll response is malformed (e.g. an intercepting proxy's HTML page); it now retries the poll
  • Improved /cd: the new directory's project settings, hooks, .mcp.json servers (behind the usual approval prompt), skills, and agents now take effect right after the move instead of on --resume
  • Improved Bash tool latency on bash shells by replaying snapshot functions without a base64 subshell per function
  • Improved subagent results: a subagent that stops at its maxTurns limit now returns its output marked as partial, with a hint to continue it via SendMessage, instead of appearing finished
  • Improved non-interactive sessions (-p, SDK, cloud sessions) to automatically continue a response cut off mid-stream by a server error, connection loss, or stall instead of ending with an error
  • Improved attribution of usage telemetry to your organization for workload identity federation sessions, events sent while apiKeyHelper runs at startup, and after a login token expired while idle
  • Changed /code-review so Claude can also start it on its own on Bedrock, Vertex AI, and Foundry, through the Claude apps gateway, and when telemetry or non-essential traffic is disabled
  • /goal: Changed idle sessions to start at most three check-ins on long-running background work per goal; your next message allows three more
  • Changed claude install and claude update to defer a pending managed-settings consent prompt to the next interactive session instead of prompting mid-command
  • Changed OpenTelemetry plugin events for plugins synced from claude.ai: plugin_id_hash now reflects the plugin's real marketplace, and enabled_via is admin-install for admin-installed plugins
  • Fixed the command sandbox's filesystem configuration not respecting --setting-sources
