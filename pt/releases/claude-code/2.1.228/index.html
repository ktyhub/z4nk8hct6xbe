código claude v2.1.228

O que mudou

  • Correção de sessões interativas que poderiam interromper totalmente o redesenho, enquanto o processo continuava em execução, após um raro erro de layout interno
  • Corrigido git / Git Bash não sendo encontrado no Windows quando Claude Code é iniciado a partir de uma pasta pai da instalação do git
  • Corrigido /tui revertendo a sessão para um modelo anterior quando /model havia sido alterado desde a última resposta
  • Correção de mensagens entre sessões que às vezes iniciavam sem uma caixa de entrada na primeira sessão após a instalação ou atualização
  • Corrigido o controle remoto /resume enquanto conectado, vazando o título ou histórico da conversa retomada na sessão conectada
  • Correção de falha de sessões claude self-hosted-runner em todos os novos executores quando o gancho checkout falha em um repositório para o qual a sessão não faz push; esse repositório agora foi ignorado com um aviso
  • Correção de corredores auto-hospedados encerrando sessões no intervalo entre o término de uma tarefa em segundo plano e o início do turno de acompanhamento
  • Corrigida limpeza de sessão excluindo conteúdo dentro da pasta de memória de um projeto
  • Corrigida a limpeza do cache do plugin em segundo plano, excluindo o cache de um plugin quando sua única versão é um checkout de desenvolvimento com link simbólico
  • Corrigido um problema de mesclagem de configurações em que uma entrada de mercado redefinida em um nível de configurações de precedência mais alta poderia herdar os cabeçalhos personalizados de outro nível; entradas do mercado agora são mescladas como entradas inteiras
  • Corrigido o lembrete de ferramentas adiadas que ocasionalmente era enviado ao modelo duas vezes após a invocação de uma habilidade
  • Habilidades reforçadas sincronizadas com claude.ai: elas não ocultam mais comandos locais ou prompts MCP, suas descrições são higienizadas e rotuladas e, em sua máquina, seus corpos não executam comandos ! nem expandem arquivos @
  • Mensagens de sessão cruzada aprimoradas: o remetente e o corpo agora são exibidos em linha em vez de uma linha recolhida, e as mensagens para sessões de Controle Remoto em outras máquinas mostram o nome da sessão de Controle Remoto como remetente
  • Tratamento aprimorado de credenciais da Vertex AI: credenciais expiradas ou ausentes do Google Cloud agora falham em segundos, em vez de tentar novamente por minutos
  • Progresso de compactação aprimorado: a contagem regressiva de novas tentativas e a dica de travamento agora aparecem durante a compactação, em vez de apenas uma barra de progresso
  • Atualizados os glifos do ocupado-spinner do título do terminal para reduzir o tremor da barra de guias em alguns terminais
  • Alterada a ferramenta Write para que modelos mais novos possam sobrescrever um arquivo existente que não tenham lido nesta sessão, correspondendo às regras da ferramenta Edit; modelos mais antigos ainda exigem a leitura primeiro
  • Removida a nota desatualizada sobre sessões no modo automático custando um pouco mais do aviso de primeiro uso para os planos Pro, Max e Team

claude-code v2.1.228

What's changed

  • Fixed interactive sessions that could stop redrawing entirely, while the process kept running, after a rare internal layout error
  • Fixed git / Git Bash not being found on Windows when Claude Code is launched from a parent folder of the git installation
  • Fixed /tui reverting the session to an earlier model when /model had been changed since the last response
  • Fixed cross-session messaging sometimes starting without an inbox in the first session after install or upgrade
  • Fixed Remote Control /resume while connected leaking the resumed conversation's title or history into the connected session
  • Fixed claude self-hosted-runner sessions failing on every fresh runner when the checkout hook fails for a repository the session doesn't push to; that repository is now skipped with a warning
  • Fixed self-hosted runners ending sessions in the gap between a background task finishing and the follow-up turn starting
  • Fixed session cleanup deleting contents inside a project's memory folder
  • Fixed background plugin-cache cleanup deleting a plugin's cache when its only version is a symlinked development checkout
  • Fixed a settings-merge issue where a marketplace entry redefined in a higher-precedence settings tier could inherit another tier's custom headers; marketplace entries now merge as whole entries
  • Fixed the deferred-tools reminder occasionally being sent to the model twice after a skill invocation
  • Hardened skills synced from claude.ai: they no longer shadow local commands or MCP prompts, their descriptions are sanitized and labeled, and on your machine their bodies don't run ! commands or expand @ files
  • Improved cross-session messages: the sender and body now display inline instead of a collapsed line, and messages to Remote Control sessions on other machines show your Remote Control session name as the sender
  • Improved Vertex AI credential handling: expired or missing Google Cloud credentials now fail within seconds instead of retrying for minutes
  • Improved compaction progress: the retry countdown and stall hint now appear during compaction instead of only a progress bar
  • Updated terminal title busy-spinner glyphs to reduce tab-bar jitter on some terminals
  • Changed the Write tool so newer models can overwrite an existing file they haven't read this session, matching the Edit tool's rules; older models still require the read first
  • Removed the outdated note about auto mode sessions costing slightly more from the first-use notice for Pro, Max, and Team plans
