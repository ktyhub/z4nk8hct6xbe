firecrawl v2.8.0

#v2.8.0

Firecrawl v2.8.0 está aqui!

Firecrawl v2.8.0 traz grandes melhorias para fluxos de trabalho de agentes, ferramentas de desenvolvedor e implantações auto-hospedadas em API e SDKs, incluindo nosso novo Skill.

  • Agentes paralelos para executar milhares de consultas /agent simultaneamente, alimentados por nosso novo modelo Spark 1 Fast.
  • Firecrawl CLI com suporte completo para comandos de raspar, pesquisar, rastrear e mapear.
  • Firecrawl Skill para permitir que agentes de IA (Claude Code, Codex, OpenCode) usem Firecrawl de forma autônoma.
  • Três novos modelos alimentando /agente: Spark 1 Fast para recuperação instantânea (atualmente disponível apenas no Playground), Spark 1 Mini para consultas de pesquisa complexas e Spark 1 Pro para tarefas de extração avançadas.
  • Aprimoramentos de agentes, incluindo webhooks, seleção de modelos e novas ferramentas de servidor MCP.
  • Melhorias de desempenho em toda a plataforma, incluindo execução de pesquisa mais rápida e chamadas Redis otimizadas.
  • Melhorias no SDK, incluindo compatibilidade com Zod v4.

E muito mais, confira abaixo!

Novos recursos

  • Agentes Paralelos
    Execute milhares de consultas /agent em paralelo com tratamento automático de falhas e execução inteligente em cascata. Desenvolvido por Spark 1-Fast para recuperação instantânea, atualizando automaticamente para Spark 1 Mini para consultas complexas que exigem pesquisa completa.

  • Fogo rastreador CLI
    Nova interface de linha de comando para Firecrawl com suporte completo para comandos scrape, search, crawl e map. Instale com npm install -g firecrawl-cli.

  • Habilidade de rastreamento de fogo
    Permite que agentes como Claude Cursor, Codex e OpenCode usem Firecrawl para web scraping e extração de dados, instalável via npx skills add firecrawl/cli.

  • Família Modelo Spark
    Três novos modelos alimentando /agente: Spark 1 Fast para recuperação instantânea (atualmente disponível no Playground), Spark 1 Mini (padrão) para tarefas diárias de extração com custo 60% menor e Spark 1 Pro para pesquisas complexas em vários domínios que exigem precisão máxima. O Spark 1 Pro atinge aproximadamente 50% de recall, enquanto o Mini oferece aproximadamente 40% de recall, ambos superando significativamente as ferramentas que custam de 4 a 7 vezes mais por tarefa.

  • Ferramentas do agente do servidor Firecrawl MCP
    Novas ferramentas firecrawl_agent e firecrawl_agent_status para coleta autônoma de dados da web por meio de agentes habilitados para MCP.

  • Webhooks do agente
    O endpoint do agente agora oferece suporte a webhooks para notificações em tempo real sobre a conclusão e o progresso do trabalho.

  • Seleção de modelo de agente
    O endpoint do agente agora aceita um parâmetro model e inclui informações do modelo nas respostas de status.

  • Imagens Docker de múltiplos arcos
    As implantações auto-hospedadas agora suportam a arquitetura linux/arm64 além da amd64.

  • Modo de rastreamento somente mapa do site
    Nova opção de rastreamento para usar exclusivamente URLs de sitemap sem seguir links.

  • Parâmetro do mapa ignoreCache
    Nova opção para ignorar resultados armazenados em cache ao mapear URLs.

  • Cabeçalhos personalizados para /map
    O endpoint do mapa agora oferece suporte a cabeçalhos de solicitação personalizados.

  • Extração de imagem de fundo
    O Scraper agora extrai imagens de fundo de estilos CSS.

  • Mensagens de erro aprimoradas
    Todas as mensagens de erro apresentadas ao usuário agora incluem explicações detalhadas para ajudar a diagnosticar problemas.

Melhorias no API

  • Pesquisa sem limites de simultaneidade – os scrapes na pesquisa agora são executados diretamente, sem sobrecarga de fila.
  • Retorne 400 para ações não suportadas com erros claros quando as ações solicitadas não são suportadas pelos mecanismos disponíveis.
  • ID do trabalho agora incluído nos metadados de pesquisa para facilitar o rastreamento.
  • As respostas de metadados agora incluem o fuso horário detectado.
  • Preencha o título dos metadados de og:title ou twitter:title quando ausente.
  • Preserve o parâmetro gid ao reescrever URLs do Planilhas Google.
  • Caminho v2 corrigido na paginação de status de raspagem em lote.
  • Valide a propriedade da equipe ao anexar rastreamentos existentes.
  • Capturas de tela com janela de visualização personalizada ou configurações de qualidade agora ignoram o cache.
  • Chamadas Redis otimizadas em endpoints.
  • Redução da busca e análise excessiva de robots.txt.
  • Parâmetro mínimo de tempo limite de solicitação agora configurável.

Melhorias no SDK

JavaScript SDK

  • Compatibilidade com Zod v4 — a conversão de esquema agora funciona com Zod v4 com detecção de erros aprimorada.
  • Exportações do Watcher — Watcher e WatcherOptions agora exportados do ponto de entrada SDK.
  • Suporte de webhook para agentes — novas opções de webhook para chamadas de agentes.
  • Erro de nova tentativa de pesquisa — SDK tenta novamente a pesquisa após erros transitórios.
  • ID do trabalho em exceções — as exceções de erro agora incluem jobId para depuração.

Python SDK

  • Auxiliares de paginação manual para iterar os resultados.
  • Suporte de webhook do agente adicionado ao agente client.
  • O endpoint do agente agora aceita parâmetros de seleção de modelo.
  • Os metadados agora incluem informações de limite de simultaneidade.
  • Corrigido o tratamento de max_pages em solicitações de rastreamento.

Melhorias no painel

  • O modo escuro agora é compatível.
  • Na página de uso, agora você pode visualizar o uso do crédito dividido por dia.
  • Na página de registros de atividades, agora você pode filtrar pela chave API que foi usada.
  • O formato de saída "imagens" agora é compatível com o Playground.
  • Todos os administradores agora podem gerenciar as assinaturas de suas equipes.

Qualidade e Desempenho

  • Ignore as verificações de conversão de descontos para documentos HTML grandes.
  • Exporte Google Docs como HTML em vez de PDF para melhorar o desempenho.
  • Formato de marca aprimorado com melhor detecção de logotipo e mensagens de erro para PDFs e documentos.
  • Melhor desempenho de carregamento de metadados lopdf.
  • Módulo html-to-markdown atualizado com várias correções de bugs.
  • Aumento do limite do corpo do serviço de redução e adição de registro de ID de solicitação.
  • Melhor filtragem do Sentry para trabalhos cancelados e erros de mecanismo.
  • Corrigidas condições de corrida de extração e manuseio de pílulas venenosas RabbitMQ.
  • Configuração centralizada do Firecrawl em toda a base de código.
  • Várias correções de vulnerabilidade de segurança, incluindo CVE-2025-59466 e poluição de protótipo lodash.

Melhorias auto-hospedadas

  • Suporte a URL API personalizado CLI via firecrawl --api-url http://localhost:3002 para instâncias locais.
  • Suporte ARM64 Docker por meio de imagens multi-arch para servidores Apple Silicon e ARM.
  • Corrigidas credenciais de banco de dados compostas por docker prontas para uso.
  • Corrigida a inicialização do serviço Playwright causada por problemas no caminho do Chromium.
  • Node.js atualizado para a versão principal 22 em vez de uma versão menor fixada.
  • Adicionado endpoint de verificação de integridade do RabbitMQ.
  • Corrigida a exposição da porta PostgreSQL no docker-compose.

firecrawl v2.8.0

v2.8.0

Firecrawl v2.8.0 is here!

Firecrawl v2.8.0 brings major improvements to agent workflows, developer tooling, and self-hosted deployments across the API and SDKs, including our new Skill.

  • Parallel Agents for running thousands of /agent queries simultaneously, powered by our new Spark 1 Fast model.
  • Firecrawl CLI with full support for scrape, search, crawl, and map commands.
  • Firecrawl Skill for enabling AI agents (Claude Code, Codex, OpenCode) to use Firecrawl autonomously.
  • Three new models powering /agent: Spark 1 Fast for instant retrieval (currently only available in Playground), Spark 1 Mini for complex research queries, and Spark 1 Pro for advanced extraction tasks.
  • Agent enhancements including webhooks, model selection, and new MCP Server tools.
  • Platform-wide performance improvements including faster search execution and optimized Redis calls.
  • SDK improvements including Zod v4 compatibility.

And much more, check it out below!

New Features

  • Parallel Agents
    Execute thousands of /agent queries in parallel with automatic failure handling and intelligent waterfall execution. Powered by Spark 1-Fast for instant retrieval, automatically upgrading to Spark 1 Mini for complex queries requiring full research.

  • Firecrawl CLI
    New command-line interface for Firecrawl with full support for scrape, search, crawl, and map commands. Install with npm install -g firecrawl-cli.

  • Firecrawl Skill
    Enables agents like Claude Cursor, Codex, and OpenCode to use Firecrawl for web scraping and data extraction, installable via npx skills add firecrawl/cli.

  • Spark Model Family
    Three new models powering /agent: Spark 1 Fast for instant retrieval (currently available in Playground), Spark 1 Mini (default) for everyday extraction tasks at 60% lower cost, and Spark 1 Pro for complex multi-domain research requiring maximum accuracy. Spark 1 Pro achieves ~50% recall while Mini delivers ~40% recall, both significantly outperforming tools costing 4-7x more per task.

  • Firecrawl MCP Server Agent Tools
    New firecrawl_agent and firecrawl_agent_status tools for autonomous web data gathering via MCP-enabled agents.

  • Agent Webhooks
    Agent endpoint now supports webhooks for real-time notifications on job completion and progress.

  • Agent Model Selection
    Agent endpoint now accepts a model parameter and includes model info in status responses.

  • Multi-Arch Docker Images
    Self-hosted deployments now support linux/arm64 architecture in addition to amd64.

  • Sitemap-Only Crawl Mode
    New crawl option to exclusively use sitemap URLs without following links.

  • ignoreCache Map Parameter
    New option to bypass cached results when mapping URLs.

  • Custom Headers for /map
    Map endpoint now supports custom request headers.

  • Background Image Extraction
    Scraper now extracts background images from CSS styles.

  • Improved Error Messages
    All user-facing error messages now include detailed explanations to help diagnose issues.

API Improvements

  • Search without concurrency limits — scrapes in search now execute directly without queue overhead.
  • Return 400 for unsupported actions with clear errors when requested actions aren't supported by available engines.
  • Job ID now included in search metadata for easier tracking.
  • Metadata responses now include detected timezone.
  • Backfill metadata title from og:title or twitter:title when missing.
  • Preserve gid parameter when rewriting Google Sheets URLs.
  • Fixed v2 path in batch scrape status pagination.
  • Validate team ownership when appending to existing crawls.
  • Screenshots with custom viewport or quality settings now bypass cache.
  • Optimized Redis calls across endpoints.
  • Reduced excessive robots.txt fetching and parsing.
  • Minimum request timeout parameter now configurable.

SDK Improvements

JavaScript SDK

  • Zod v4 Compatibility — schema conversion now works with Zod v4 with improved error detection.
  • Watcher Exports — Watcher and WatcherOptions now exported from the SDK entrypoint.
  • Agent Webhook Support — new webhook options for agent calls.
  • Error Retry Polling — SDK retries polling after transient errors.
  • Job ID in Exceptions — error exceptions now include jobId for debugging.

Python SDK

  • Manual pagination helpers for iterating through results.
  • Agent webhook support added to agent client.
  • Agent endpoint now accepts model selection parameter.
  • Metadata now includes concurrency limit information.
  • Fixed max_pages handling in crawl requests.

Dashboard Improvements

  • Dark mode is now supported.
  • On the usage page, you can now view credit usage broken down by day.
  • On the activity logs page, you can now filter by the API key that was used.
  • The "images" output format is now supported in the Playground.
  • All admins can now manage their team's subscriptions.

Quality & Performance

  • Skip markdown conversion checks for large HTML documents.
  • Export Google Docs as HTML instead of PDF for improved performance.
  • Improved branding format with better logo detection and error messages for PDFs and documents.
  • Improved lopdf metadata loading performance.
  • Updated html-to-markdown module with multiple bug fixes.
  • Increased markdown service body limit and added request ID logging.
  • Better Sentry filtering for cancelled jobs and engine errors.
  • Fixed extract race conditions and RabbitMQ poison pill handling.
  • Centralized Firecrawl configuration across the codebase.
  • Multiple security vulnerability fixes, including CVE-2025-59466 and lodash prototype pollution.

Self-Hosted Improvements

  • CLI custom API URL support via firecrawl --api-url http://localhost:3002 for local instances.
  • ARM64 Docker support via multi-arch images for Apple Silicon and ARM servers.
  • Fixed docker-compose database credentials out of the box.
  • Fixed Playwright service startup caused by Chromium path issues.
  • Updated Node.js to major version 22 instead of a pinned minor.
  • Added RabbitMQ health check endpoint.
  • Fixed PostgreSQL port exposure in docker-compose.
