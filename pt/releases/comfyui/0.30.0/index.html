ComfyUI v0.30.0

Highlights

  • Low-VRAM memory management — A new MRU (most-recently-used) weight-loading policy built on the pinning infrastructure (#15027) lands with deferred pin cleanup until model destruction (#15183), corrected pin registration priority (#15226), and comfy-aimdo 0.4.11 (#15215); #15219 also handles failed Windows swap-memory queries. Together these make model streaming in and out of RAM far more predictable — the most consequential change here for anyone running large diffusion/video models on constrained GPUs, so retest offload workflows and watch OOM behavior.

  • Attention backend resilience — cuDNN attention now takes over on Linux when Flash Attention fails (#15146), and k/v tensors are expanded when the backend would otherwise drop to math because of GQA (#15190), alongside a Flux KV fix in comfy-kitchen (#15144). Expect fewer hard failures on non-Flash setups and correct outputs from GQA-based models — this quietly fixes a class of "works on my machine" generation errors.

  • Security hardening around dataset paths — Dataset operations are confined to a dedicated dataset folder to block arbitrary filesystem access (#14807), and containment checks now use a real path-within-directory helper (#15216); SVG previews are also repaired after the stored-XSS forced-download change (#15149). This is the change most likely to break existing node packs: custom nodes that read/write outside sanctioned directories or serve SVG previews will need path adjustments.

  • New model coverage — MiniMax-H3 support via CORE-375 (#15224) plus 768P for H3 (#15227), Ideogram P-Image (#15154), and xAI grok-imagine-video-1.5 (#15197). On the decode side, PrunaVAED offers a faster LTX2.3 decoder (#15129) and int8 convrot embedding lookup (#15035, CORE-371) trims embedding memory — swapping in PrunaVAED is the quickest perf win in this release for LTX2.3 video work.

  • Logging internals change — A configurable DETAIL logging side channel (#15064, CORE-369) ships disabled by default (#15159) and is hardened against samplers that lack a __name__ attribute (#15179). Watch the internal module rename comfy/logging.py → comfy/internal_logging.py (#15231): any custom node importing comfy.logging directly must update its import.

  • Node UX and partner-node costs — Save Video gains a CRF option (#15191) and MP4 metadata is written at the front of the file when possible (#15195) for better streaming/seek; VAEDecodeAudio decodes nested audio, nested latents get previews (#15196), Save Text supports CSV (#15217), and gradients are disabled on diffusion models (#15218) to save memory. Separately, Bria video background-removal pricing was adjusted repeatedly (#15155, #15171, #15186) — heavy users of those partner nodes should recheck costs.
