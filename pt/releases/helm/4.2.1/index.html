#leme v4.2.1

Helm v4.2.1 é uma versão de patch. Os usuários são incentivados a atualizar para obter a melhor experiência.

A comunidade continua crescendo e adoraríamos ver você lá!

  • Participe da discussão no Kubernetes Slack:
    • para perguntas e apenas para sair
    • para discutir PRs, código e bugs
  • Participe da chamada pública para desenvolvedores: quinta-feira, 9h30 (horário do Pacífico) via Zoom
  • Teste, depure e contribua com gráficos: ArtifactHub/packages

Mudanças notáveis

  • Correção de corrida de dados detectada pelo sinalizador -race quando goroutines simultâneas (atualização + reversão, instalação + desinstalação) chamam GetWaiterWithOptions na mesma instância FailingKubeClient #31925
  • Corrigidas mensagens de sucesso do comando helm gravando em stderr em vez de stdout. Agora gerando saída corretamente para stdout #32056
  • Corrigido o problema do Helm 4 emitindo "incapaz de encontrar a versão exata" ao usar restrições de intervalo de versão #31757
  • Corrigida uma condição de corrida em WaitForDelete onde o observador de status cancelava a observação muito cedo, causando falhas intermitentes ao executar um conjunto de testes completo #32081
  • Transferido golang.org/x/net para v0.55.0 para endereçar GO-2026-5026 #32153
  • Corrigidos erros de SDK atualizando dependências: cli-utils 1.2.1, controlador-runtime 0.24.1 e k8s 1.36.1 #32128
  • Atualizações de dependências

helm v4.2.1

Helm v4.2.1 is a patch release. Users are encouraged to upgrade for the best experience.

The community keeps growing, and we'd love to see you there!

  • Join the discussion in Kubernetes Slack:
    • for questions and just to hang out
    • for discussing PRs, code, and bugs
  • Hang out at the Public Developer Call: Thursday, 9:30 Pacific via Zoom
  • Test, debug, and contribute charts: ArtifactHub/packages

Notable Changes

  • Fixed data race detected by -race flag when concurrent goroutines (upgrade + rollback, install + uninstall) both call GetWaiterWithOptions on the same FailingKubeClient instance #31925
  • Fixed helm command success messages writing to stderr instead of stdout. Now correctly outputing to stdout #32056
  • Fixed Helm 4 emitting "unable to find exact version" when using version range constraints #31757
  • Fixed a race condition in WaitForDelete where the status observer canceled the watch too early, causing intermittent failures when running a full test suite #32081
  • Bumped golang.org/x/net to v0.55.0 to address GO-2026-5026 #32153
  • Fixed SDK errors by upgrading dependencies: cli-utils 1.2.1, controller-runtime 0.24.1 and k8s 1.36.1 #32128
  • Dependency updates
