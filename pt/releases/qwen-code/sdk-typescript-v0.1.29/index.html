Destaques

O pacote CLI 0.23.0 inclui duas correções solicitadas em #11022:

  • A disponibilidade de memória gerenciada agora respeita a configuração memory.enableManagedAutoMemory (#6941). Os hosts que desativam a memória automática gerenciada não veem mais solicitações de lembrança/sonho admitidas ou instruções de memória gerenciada no prompt do sistema; patches locais podem ser removidos.
  • A microcompactação acionada por tamanho agora limpa os resultados da ferramenta antiga em direção a uma marca d'água baixa (#8464), de modo que não reescreve mais outra parte do prefixo da conversa em cada turno subsequente. A reutilização do prompt de cache do provedor é preservada em sessões longas e com muitas ferramentas, reduzindo o custo de entrada em cache.

Highlights

The bundled CLI 0.23.0 includes two fixes requested in #11022:

  • Managed memory availability now respects the memory.enableManagedAutoMemory setting (#6941). Hosts that disable managed auto memory no longer see remember/dream requests admitted or managed-memory instructions in the system prompt; local patches can be removed.
  • Size-triggered microcompaction now clears old tool results toward a low watermark (#8464), so it no longer rewrites another part of the conversation prefix on every subsequent turn. Provider prompt-cache reuse is preserved across long tool-heavy sessions, reducing cached-input cost.
