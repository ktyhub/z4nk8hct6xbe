qwen-code v0.27.2

código qwen v0.27.2

<!-- qwen-release-notes:v1 -->

Destaques

  • O Web Shell pode configurar canais WeChat, QQ e Email, incluindo login QR, progresso da digitalização, exibição de identidade e logout quando compatível. (#16736, #16724, #16746)
  • Os mods podem executar chamadas únicas de $.model.complete, reescrever o texto exibido do AssistantMessage via ui.render e persistir os valores do plugin com $.store. (#16737, #16794, #16791)
  • As perguntas paralelas /btw são reproduzidas para fins de contexto, e o Agente Gerenciado adiciona acompanhamentos privados com recapitulações de sessão manuais ou automáticas opcionais. (#16408, #16758)
  • As aprovações pendentes agora aparecem no painel ativo e podem acionar uma campainha do terminal ou uma notificação na área de trabalho quando o terminal está fora de foco. (#16800, #16809)
  • Web Shell mostra turnos, velocidade de saída, total de tokens e taxa de acertos de cache no compositor, com detalhes de foco e acesso ao uso de token. (#16815)
  • Os usuários podem importar uma habilidade do espaço de trabalho Runtime original de uma sessão selecionada e instalá-la explicitamente sem carregá-la novamente. (#16638)

Mudanças significativas

  • fix(deps)!: atualizar dependências enviadas por SDK e Web Shell (#16452) por @ yiliang114

Lista completa de alterações

Recursos

  • Permite que os usuários importem uma habilidade do espaço de trabalho Runtime original de uma sessão selecionada e instalem-na explicitamente sem recarregá-la. (#16638) por @doudouOUC
  • Torna as perguntas paralelas /btw parte da sessão e reproduz as últimas 20 perguntas paralelas respondidas para que os acompanhamentos possam fazer referência às anteriores. (#16408) por @sorrycc
  • Adiciona medidas de execução da Ferramenta v4 ao diagnóstico de atividades gerenciadas, mostrando duração, contagens de amostras válidas e alterações de linha propostas versus aplicadas. (#16498) por @doudouOUC
  • Daemon PR-state watch adiciona descoberta de host permitido a partir da configuração gh e desligamento ordenado enquanto permanece desligado. (#16732) por @wenshao
  • Com experimental.unifiedAgentLoop habilitado, as rodadas do modelo OpenTUI agora são executadas através do loop de agente compartilhado, melhorando a paridade com o Ink enquanto mantém sua própria etapa de ferramenta. (#16743) por @qqqys
  • Os mods agora podem executar conclusões de texto únicas com $.model.complete(request, {signal}), usando a sessão client sem ferramentas, histórico ou um prompt de sistema adicionado. (#16737) por @qqqys
  • Agente gerenciado adiciona acompanhamentos privados de BTW e recapitulação de sessão manual ou automática opcional, com painéis WebShell usando resultados persistentes; a recapitulação automática está desativada por padrão. (#16758) por @doudouOUC
  • Os veredictos do verificador de metas agora mostram o motivo da última verificação no idioma de saída da sessão, enquanto os valores de decisão permanecem aceitos ou rejeitados. (#15806) por @4ekuct25
  • Os mods agora podem usar o site de renderização AssistantMessage e o gancho ui.render para reescrever o texto de resposta do modelo exibido no terminal Ink sem alterar o texto armazenado ou copiado. (#16794) por @qqqys
  • As execuções de correção automática auto-hospedadas agora têm um orçamento de agente de 240 minutos, reduzindo tempos limite prematuros para longas rodadas de correção automática. (#16777) por @wenshao
  • feat(web-shell): configure o canal Email do channel manager (#16746) por @wenshao
  • feat(cli): execute lotes de ferramentas do OpenTUI no loop de agente compartilhado (#16789) por @qqqys
  • feat(mods): mantenha os valores de cada plugin entre sessões com $.store (#16791) por @qqqys
  • Sessões gerenciadas pelo web shell podem reutilizar o cromo do shell do host com showManagedSessionHeader e alignManagedChatWithHost, reduzindo cabeçalhos e dicas duplicados. (#16324) por @yiliang114
  • O livro-razão de entrega do canal de agente gerenciado agora registra cada segmento de entrega separadamente, preservando os recebimentos de segmento para entregas de vários segmentos. (#16797) por @wenshao
  • Adiciona requireBoundWatch ao canal GitHub para que as ligações de revisão ou verificação recebam eventos PR apenas enquanto uma observação /autofix-pr ou /verify-pr ativa é mantida. (#16772) por @wenshao
  • Adiciona o WeChat como um canal Web Shell configurável com login QR no navegador, progresso da verificação, exibição de identidade, logout e atualização de código expirado. (#16736) por @wenshao
  • Adiciona configuração de canal QQ e um fluxo de gerenciamento de login QR opcional que permite que o Web Shell vincule contas digitalizando um código QR. (#16724) por @wenshao
  • Adiciona uma matriz de segmentos ao recurso de entrega de canal público, mantendo compatíveis os campos de segmentos singulares existentes. (#16807) por @wenshao
  • Mostra turnos, velocidade de saída, total de tokens e taxa de acertos de cache no compositor Web Shell, com detalhes de foco e acesso ao painel Token Usage. (#16815) por @qqqys

Correções de bugs

  • Corrige a verificação de atualização de lint do CI para comparar o conjunto completo de ignorar mais bonito na ponta base para que os veredictos não sejam reduzidos incorretamente. (#16729) por @wenshao
  • Permite que um Host do Agente tente novamente com segurança uma inscrição perdida ou um comando Substituir para que termine com o Host existente em vez de falhar ou criar uma duplicata. (#16722) por @wenshao
  • Rejeita valores authorExclude malformados em registros de tarefas de entrada antes que eles cheguem à entrega de comentários, evitando falhas e comportamento de entrega inválido. (#16740) por @wenshao
  • Faz com que o registro de estreitamento de lint de CI seja um aviso quando uma árvore truncada impede o estreitamento e manipula corretamente as referências de base com barra. (#16747) por @wenshao
  • Impede falhas de PR CI de bifurcação, mantendo Ctrl+C fora do shell em foco, fornecendo ao fork de teste do Agente Gerenciado 40% da memória da máquina e estabilizando as verificações de renovação de leasing. (#16150) por @TianYuan1024
  • Corrige a análise do comando shell para que a proteção de auto-eliminação e as verificações de permissão de arquivo lidem corretamente com escapes ANSI-C e terminadores de opção -c. (#16540) por @yiliang114
  • Impede que atualizações de base obsoletas de correção automática reiniciem revisões automatizadas de PR que expiraram, evitando ciclos repetidos de revisão e atualização de base. (#16749) por @wenshao
  • Volta para a visualização da tabela de dados quando um renderizador de gráfico falha, mas os dados embutidos são legíveis, em vez de mostrar o gráfico como indisponível. (#16021) por @zhangxy-zju
  • Os orçamentos do tamanho do renderizador de exportação de documentos são aumentados para o tamanho do pacote mesclado, corrigindo falhas de compilação de execução do npm causadas pelo aumento do Web Shell pós-mesclagem. (#16774) por @yiliang114
  • Comandos de barra somente ociosos, como /branch, /cd, /fork, /recap e /advisor, agora são executados quando despachados de uma sessão inativa do Ink TUI, em vez de serem bloqueados pelo estado de todo o aplicativo. (#16731) por @qqqys
  • O menu de barras do Web Shell agora dá prioridade aos nomes de comandos e habilidades, truncando as descrições primeiro enquanto os detalhes completos permanecem em foco. (#16790) por @callmeYe
  • Solicitações de aprovação de fluxo de trabalho e em segundo plano agora acionam uma campainha de terminal ou notificação na área de trabalho quando estão fora de foco, honrando general.terminalBell e general.notificationMode. (#16800) por @qqqys
  • O CLI agora abre o compositor silenciosamente quando um modelo de assinatura salvo não está disponível e adia o erro para envio, mostrando a resposta do gateway. (#16798) por @liuxuely0626
  • fix(core): escreva títulos de sessões automáticas no idioma da conversa (#16806) por @qqqys
  • fix(cli): mostra a aprovação pendente de um agente em primeiro plano no painel ao vivo (#16809) por @qqqys
  • correção (cli): habilita apenas a depuração de sandbox para valores DEBUG explícitos (#16805) por @ yiliang114
  • Solicitações pull criadas com gh pr create agora são vinculadas usando o diretório onde o comando é executado, melhorando a precisão da vinculação da árvore de trabalho. (#16725) por @wenshao
  • A reaquisição do gravador de sessão gerenciada HTTP agora aguarda selos em andamento e evita a aquisição de um arrendamento enquanto um selo ainda pode ser liquidado. (#16726) por @wenshao
  • Impede que sessões obsoletas sejam relatadas como ativas quando seu PID é reciclado, validando um token de início de processo no Linux. (#16128) por @yiliang114
  • Permite que os campos de configuração do canal declarem um limite inferior inclusivo para que valores zero sejam aceitos corretamente nas mensagens de validação e intervalo. (#16783) por @wenshao

Desempenho

  • perf(memory): elimine a referência de memória automática incluída e mantenha a política residente (#16739) por @qqqys
  • A lista de notificações e observação do estado de PR do canal GitHub agora usa solicitações condicionais e armazena em cache respostas inalteradas para evitar gastar cota em dados inalterados. (#16741) por @wenshao
  • Melhora o desempenho do agente gerenciado, reduzindo a cópia de prova de CSI, otimizando a pesquisa de CSI e usando a espera de pesquisa de inicialização limitada. (#16828) por @doudouOUC
  • Melhora a capacidade de resposta do agente gerenciado, removendo consultas redundantes de caminho de leitura sem alterar o comportamento. (#16827) por @doudouOUC

  • documentos: esclareça os requisitos da ponte de ferramentas ao migrar de tools.core (#16750) por @521Peter
  • Adiciona propostas de design bilíngues para trazer /loop para Sessões Gerenciadas, cobrindo programações e ativações sem alterar o comportamento da produção. (#16792) por @wenshao
  • docs(agente gerenciado): Projetos de agendamento gerenciado — correções de revisão de loop e agendadores externos (#16796) por @wenshao
  • Corrige a documentação do projeto para declarar wakeDormant falso, podendo atrasar a entrega até o próximo tick de atualização, em vez de encalhar as transições pendentes. (#16834) por @wenshao

qwen-code v0.27.2

<!-- qwen-release-notes:v1 -->

Highlights

  • Web Shell can configure WeChat, QQ, and Email channels, including QR login, scan progress, identity display, and logout where supported. (#16736, #16724, #16746)
  • Mods can run one-off $.model.complete calls, rewrite displayed AssistantMessage text via ui.render, and persist plugin values with $.store. (#16737, #16794, #16791)
  • /btw side questions are replayed for context, and Managed Agent adds private follow-ups with manual or optional automatic session recaps. (#16408, #16758)
  • Pending approvals now appear in the live panel and can trigger a terminal bell or desktop notification when the terminal is unfocused. (#16800, #16809)
  • Web Shell shows turns, output speed, total tokens, and cache hit rate under the composer, with hover details and Token Usage access. (#16815)
  • Users can import a Skill from the original Runtime workspace of a selected Session and install it explicitly without re-uploading it. (#16638)

Breaking Changes

  • fix(deps)!: upgrade dependencies shipped by SDK and Web Shell (#16452) by @yiliang114

Complete Change List

Features

  • Lets users import a Skill from the original Runtime workspace of a selected Session and install it explicitly without re-uploading it. (#16638) by @doudouOUC
  • Makes /btw side questions part of the session and replays the last 20 answered side questions so follow-ups can reference earlier ones. (#16408) by @sorrycc
  • Adds Tool v4 execution measurements to Managed activity diagnostics, showing duration, valid sample counts, and proposed versus applied line changes. (#16498) by @doudouOUC
  • Daemon PR-state watch adds allowed-host discovery from gh configuration and ordered shutdown while remaining turned off. (#16732) by @wenshao
  • With experimental.unifiedAgentLoop enabled, OpenTUI model rounds now run through the shared agent loop, improving parity with Ink while keeping its own tool step. (#16743) by @qqqys
  • Mods can now run one-off text completions with $.model.complete(request, {signal}), using the session client without tools, history, or an added system prompt. (#16737) by @qqqys
  • Managed Agent adds private BTW follow-ups and manual or optional automatic session recap, with WebShell panels using persisted results; automatic recap is off by default. (#16758) by @doudouOUC
  • Goal verifier verdicts now show the Last check reason in the session output language while decision values remain accept or reject. (#15806) by @4ekuct25
  • Mods can now use the AssistantMessage render site and ui.render hook to rewrite displayed model reply text in the Ink terminal without changing stored or copied text. (#16794) by @qqqys
  • Self-hosted autofix runs now have a 240-minute agent budget, reducing premature timeouts for long autofix rounds. (#16777) by @wenshao
  • feat(web-shell): configure the Email channel from the channel manager (#16746) by @wenshao
  • feat(cli): run OpenTUI's tool batches on the shared agent loop (#16789) by @qqqys
  • feat(mods): keep each plugin's values between sessions with $.store (#16791) by @qqqys
  • Web shell managed sessions can reuse host shell chrome with showManagedSessionHeader and alignManagedChatWithHost, reducing duplicate headers and hints. (#16324) by @yiliang114
  • Managed Agent channel delivery ledger now records each delivery segment separately, preserving segment receipts for multi-segment deliveries. (#16797) by @wenshao
  • Adds requireBoundWatch to the GitHub channel so review or verify bindings receive PR events only while an active /autofix-pr or /verify-pr watch is held. (#16772) by @wenshao
  • Adds WeChat as a configurable Web Shell channel with in-browser QR login, scan progress, identity display, logout, and expired-code refresh. (#16736) by @wenshao
  • Adds QQ channel configuration and an optional QR-login management flow that lets the Web Shell bind accounts by scanning a QR code. (#16724) by @wenshao
  • Adds a segments array to the public channel delivery resource while keeping existing singular segment fields compatible. (#16807) by @wenshao
  • Shows turns, output speed, total tokens, and cache hit rate under the Web Shell composer, with hover details and Token Usage panel access. (#16815) by @qqqys

Bug Fixes

  • Fixes the CI lint freshness check to compare the full prettier ignore set at the base tip so verdicts are not narrowed incorrectly. (#16729) by @wenshao
  • Lets an Agent Host safely retry a lost enrollment or Replace command so it finishes with the existing Host instead of failing or creating a duplicate. (#16722) by @wenshao
  • Rejects malformed authorExclude values on inbound task records before they reach comment delivery, preventing crashes and invalid delivery behavior. (#16740) by @wenshao
  • Makes CI lint narrowing log a warning when a truncated tree prevents narrowing and handles slash-bearing base refs correctly. (#16747) by @wenshao
  • Stops fork PR CI failures by keeping Ctrl+C out of the focused shell, giving the Managed Agent test fork 40% of machine memory, and stabilizing lease renewal checks. (#16150) by @TianYuan1024
  • Fixes shell command parsing so the self-kill guard and file-permission checks correctly handle ANSI-C escapes and -c option terminators. (#16540) by @yiliang114
  • Prevents autofix stale-base updates from restarting automated PR reviews that timed out, avoiding repeated review and base-update cycles. (#16749) by @wenshao
  • Falls back to the Data table view when a chart renderer fails but inline data is readable, instead of showing the chart as unavailable. (#16021) by @zhangxy-zju
  • Document export renderer size budgets are raised to the merged bundle size, fixing npm run build failures caused by the post-merge Web Shell increase. (#16774) by @yiliang114
  • Idle-only slash commands such as /branch, /cd, /fork, /recap, and /advisor now run when dispatched from an idle Ink TUI session instead of being blocked by app-wide state. (#16731) by @qqqys
  • The Web Shell slash menu now gives command and Skill names priority, truncating descriptions first while full details remain on hover. (#16790) by @callmeYe
  • Background and workflow approval requests now trigger a terminal bell or desktop notification when unfocused, honoring general.terminalBell and general.notificationMode. (#16800) by @qqqys
  • The CLI now opens the composer silently when a saved subscription model is unavailable and defers the error to send, showing the gateway response. (#16798) by @liuxuely0626
  • fix(core): write auto session titles in the conversation's language (#16806) by @qqqys
  • fix(cli): show a foreground agent's pending approval in the live panel (#16809) by @qqqys
  • fix(cli): only enable sandbox debugging for explicit DEBUG values (#16805) by @yiliang114
  • Pull requests created with gh pr create are now bound using the directory where the command runs, improving worktree binding accuracy. (#16725) by @wenshao
  • HTTP Managed Session writer reacquisition now waits for in-flight seals and avoids acquiring a lease while a seal may still settle. (#16726) by @wenshao
  • Prevents stale sessions from being reported active when their PID is recycled by validating a process-start token on Linux. (#16128) by @yiliang114
  • Allows channel config fields to declare an inclusive lower bound so zero values are accepted correctly in validation and range messages. (#16783) by @wenshao

Performance

  • perf(memory): drop the bundled auto-memory reference and keep the resident policy (#16739) by @qqqys
  • GitHub channel's PR state watch and notifications list now use conditional requests and cache unchanged responses to avoid spending quota on unchanged data. (#16741) by @wenshao
  • Improves managed-agent performance by reducing CSI proof copying, optimizing CSI lookup, and using capped startup polling backoff. (#16828) by @doudouOUC
  • Improves managed-agent responsiveness by removing redundant read-path queries without changing behavior. (#16827) by @doudouOUC

Documentation

  • docs: clarify tool bridge requirements when migrating from tools.core (#16750) by @521Peter
  • Adds bilingual design proposals for bringing /loop to Managed Sessions, covering schedules and wakeups without changing production behavior. (#16792) by @wenshao
  • docs(managed-agent): Managed scheduling designs — loop review fixes and external schedulers (#16796) by @wenshao
  • Corrects design documentation to state wakeDormant false may delay delivery until the next refresh tick rather than stranding pending transitions. (#16834) by @wenshao

Internal Changes

  • Renames Managed Agent JDBC persistence implementations to distinguish them from repository interfaces and simplify imports. (#16759) by @doudouOUC
  • Shares Hosted Harness capability tokens across connectors so feature checks remain consistent without changing connector behavior. (#16763) by @doudouOUC
  • Reduces all sharded CI lanes to two shards and raises the smoke job cap to 75 minutes while preserving run headroom. (#16764) by @wenshao
  • Excludes background activation renewal from a Managed Session log test to prevent unrelated log writes from affecting its byte-offset check. (#16756) by @wenshao
  • Managed Runtime worker HTTP routes now derive from a single route plan, improving consistency between route gating and mounting. (#16788) by @doudouOUC
  • Removes unused managed-agent-server constructors and helpers without changing runtime behavior. (#16822) by @doudouOUC
  • Refactors session restore into a shared core so in-process callers can restore workspace sessions without HTTP. (#16810) by @wenshao

New Contributors

  • @521Peter made their first contribution in #16750
