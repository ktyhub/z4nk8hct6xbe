hiperframes v0.9.34

#HiperFrames v0.9.34 Lançado em 11/11/2026. O HyperFrames agora executa programas auxiliares como o FFmpeg apenas de onde estão instalados, nunca de uma pasta de projeto. As renderizações também podem recusar variáveis ​​que uma página não declara, quando essa verificação está ativada.

Recursos

  • Produtor: Com variáveis estritas ativadas, uma renderização falha quando recebe uma variável que a página não declara. Está desativado por padrão, portanto as renderizações permanecem inalteradas (f312fca7e, #7548).

Correções

  • Studio Server: Carregue fontes e módulos apenas nos quadros de visualização do próprio Studio (ffb13c3b6, #7553).
  • Habilidades: O iniciador de plug-ins e os ajudantes de mídia executam o CLI fixado, não uma cópia do projeto (a8fe3a5b6, #7552).
  • CLI: A visualização usa o Studio incluído, a menos que o modo Studio local esteja ativado (668983e1a, #7551).
  • Segurança: FFmpeg, FFprobe e outros programas auxiliares são obtidos apenas de onde estão instalados ou de um caminho que você definiu, nunca de uma pasta de projeto (84799bdc5, #7524).
  • Principal: Salvar um arquivo funciona em unidades que recusam links físicos com um erro de permissão (f36463e29, #7474).
  • Studio: As miniaturas são capturadas em uma página selada, e as transições de shader ainda funcionam onde o navegador bloqueia o armazenamento local (80cda85d7, #7528).

Catálogo

  • CLI: Recusar mais arquivos de instruções do agente de codificação nas instalações do registro (9bab57ab4, #7549).
  • CLI e Studio: As instalações do registro e as gravações de arquivos do Studio ficam dentro das pastas de conteúdo do projeto (b96c82b78, #7523).

Interno

  • Mecanismo: O teste de simultaneidade de leitura de URL é aprovado em máquinas com 32 ou mais núcleos (3ad7611f9, #7544).

hyperframes v0.9.34

HyperFrames v0.9.34

Released on 2026-11-11.

HyperFrames now runs helper programs like FFmpeg only from where they are installed, never from a project folder. Renders can also refuse variables a page does not declare, when that check is turned on.

Features

  • Producer: With strict variables turned on, a render fails when it is given a variable the page does not declare. It is off by default, so renders are unchanged (f312fca7e, #7548).

Fixes

  • Studio Server: Load fonts and modules only in the Studio's own preview frames (ffb13c3b6, #7553).
  • Skills: Plugin launcher and media helpers run the pinned CLI, not a project copy (a8fe3a5b6, #7552).
  • CLI: Preview uses the bundled Studio unless local Studio mode is opted in (668983e1a, #7551).
  • Security: FFmpeg, FFprobe and other helper programs are taken only from where they are installed or a path you set, never from a project folder (84799bdc5, #7524).
  • Core: Saving a file works on drives that refuse hard links with a permission error (f36463e29, #7474).
  • Studio: Thumbnails are captured in a sealed page, and shader transitions still work where the browser blocks local storage (80cda85d7, #7528).

Catalog

  • CLI: Refuse more coding-agent instruction files in registry installs (9bab57ab4, #7549).
  • CLI and Studio: Registry installs and Studio file writes stay inside the project content folders (b96c82b78, #7523).

Internal

  • Engine: The URL-read concurrency test passes on machines with 32 or more cores (3ad7611f9, #7544).
