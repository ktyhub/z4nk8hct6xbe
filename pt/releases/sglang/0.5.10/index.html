gíria v0.5.10

Destaques

  • Gráfico CUDA por partes habilitado por padrão: A captura de gráfico CUDA por partes agora é o modo de execução padrão, reduzindo a sobrecarga de memória e melhorando o rendimento para modelos com padrões de fluxo de controle complexos: #16331
  • Elastic EP para tolerância a falhas parciais: integre o Elastic NIXL-EP ao SGLang, permitindo tolerância a falhas parciais para implantações do DeepSeek MoE. Quando uma GPU falha, o sistema redis atribui pesos especializados e continua servindo sem reinicialização completa: #19248, #17374, #12068 blog
  • Buffer de teste de GPU para desagregação PD: reúne fatias de cabeçote dispersas em memória contígua para transferência RDMA em massa, reduzindo a contagem de solicitações RDMA em modelos GQA em aproximadamente 1.000 vezes. TPS/GPU em grande simultaneidade aumentou cerca de 5x com Prefill TP4+Decode DEP4 em Qwen3.5: #19890
  • HiSparse para atenção esparsa: integre o back-end de atenção escassa HiSparse para inferência eficiente de contexto longo com computação reduzida por meio de atenção com reconhecimento de dispersão: #20343
  • Atualização de difusão SGLang:
    • Suporte de modelo: LTX-2, Hunyuan3D-2, Helios
    • Melhorias de desempenho na imagem Qwen, imagem Z aumentada em 1,5x
    • Nova plataforma: macOS
    • Novo recurso: melhore o desempenho do back-end dos difusores integrando toda a otimização do Cache-DiT
    • HABILIDADES: sinta-se à vontade para explorar as habilidades selecionadas para desenvolver e otimizar a difusão de gírias!
  • Suporte ao kernel FlashInfer MXFP8: Integre kernels FlashInfer mxfp8 para operações GEMM e MoE, permitindo inferência FP8 de precisão mista com maior precisão por meio de microescalamento para RL e cargas de trabalho gerais: #19537
  • Atualização dos transformadores 5.3.0: Grande atualização dos transformadores 4.57.1 para 5.3.0, desbloqueando suporte para as arquiteturas de modelo mais recentes e recursos do HuggingFace. O modelo GLM-5 agora é suportado nesta imagem em vez da imagem personalizada: #17784
  • Otimização DeepSeek V3.2 / GLM-5: GLM-5 executável na ramificação principal (com transformadores atualizados). Kernel Triton fundido para busca de cache KV pré-preenchido, indexador de armazenamento de fusível NSA para cache K, kernels DSA de pré-preenchimento/decodificação TRT-LLM como padrão no SM100/SM103 e IndexCache para rendimento melhorado em mais de 10% em altas cargas de trabalho: #19319, #19148, #20062, #21914, #21405
  • Otimização Qwen3.5 GDN/KDA: transpõe o layout do estado de atenção linear de [N, HV, K, V] para [N, HV, V, K] e funde operações de divisão/remodelação/cat na projeção GDN com kernel Triton, além de suporte de kernel de decodificação CuTeDSL KDA para desempenho aprimorado do Qwen3.5: #20283, #21019, #21203
  • Suporte LoRA para camadas MoE: Adicione suporte de ajuste fino LoRA para camadas Mixture-of-Experts com kernels de alinhamento JIT, kernels Triton fundidos, suporte TP, suporte gráfico CUDA e detecção automática de módulos de destino LoRA - permitindo ajuste eficiente baseado em adaptador em modelos MoE como DeepSeek: #19710, #19711, #14105, #21439, #21647
  • Prefill Context Parallel for MHA (Qwen3): Habilite o paralelismo de contexto durante o pré-preenchimento para modelos de atenção com vários cabeçotes, como Qwen3 MoE, distribuindo sequências longas entre GPUs para reduzir a memória por GPU e acelerar o pré-preenchimento: #18233
  • Suporte à biblioteca oficial do Flash Attention 4: atualize para o pacote oficial do FlashAttention 4, trazendo as mais recentes otimizações de atenção e suporte à GPU Blackwell: #20303
  • Skip-Softmax Attention para FlashInfer TRT-LLM Kernels: Reduza a sobrecarga de computação em camadas de atenção ignorando a normalização softmax redundante: #19089
  • Decodificação especulativa com backend FA4: Habilite a decodificação especulativa para o backend de atenção FA4, combinando inferência especulativa com atenção flash de próxima geração para geração mais rápida: #21080
  • MM Attention FA4 padrão no SM100: A atenção multimodal agora usa FA4 por padrão no hardware Blackwell para melhorar o desempenho do VLM: #21595
  • Back-end de modelagem de transformadores mais fortes: back-end de transformadores aprimorado com suporte completo a TP, PP, MoE, VLM e compatibilidade com torch.compile: #19163
  • sglang-kernel 0.4.1: Lançamento do pacote principal do kernel com pacote renomeado (sgl-kernel → sglang-kernel), kernels consolidados e limpeza de operações obsoletas: #20440, #22009
  • Backend MLX nativo para Apple Silicon: Adicione back-end de execução MLX nativo, permitindo que o SGLang execute inferência diretamente em Apple Silicon Macs sem CUDA: #20342

sglang v0.5.10

Highlights

  • Piecewise CUDA Graph Enabled by Default: Piecewise CUDA graph capture is now the default execution mode, reducing memory overhead and improving throughput for models with complex control flow patterns: #16331

  • Elastic EP for Partial Failure Tolerance: Integrate Elastic NIXL-EP into SGLang, enabling partial failure tolerance for DeepSeek MoE deployments — when a GPU fails, the system redistributes expert weights and continues serving without full restart: #19248, #17374, #12068 blog

  • GPU Staging Buffer for PD Disaggregation: Gathers scattered head slices into contiguous memory for bulk RDMA transfer, reducing RDMA request count on GQA models by ~1000x. TPS/GPU on large concurrency increased by ~5x with Prefill TP4+Decode DEP4 on Qwen3.5: #19890

  • HiSparse for Sparse Attention: Integrate HiSparse sparse attention backend for efficient long-context inference with reduced compute through sparsity-aware attention: #20343

  • SGLang-Diffusion Update:

    • Model support: LTX-2, Hunyuan3D-2, Helios
    • Performance improvements on Qwen-image, Z-image increased by 1.5x
    • New platform: macOS
    • New feature: enhance the performance of diffusers backend by integrating all optimization from Cache-DiT
    • SKILLs: feel free to explore the curated skill for developing and optimizing sglang-diffusion!

  • FlashInfer MXFP8 Kernel Support: Integrate FlashInfer mxfp8 kernels for GEMM and MoE operations, enabling mixed-precision FP8 inference with higher accuracy through microscaling for RL and general workloads: #19537

  • Transformers 5.3.0 Upgrade: Major upgrade from transformers 4.57.1 to 5.3.0, unlocking support for the latest model architectures and features from HuggingFace. GLM-5 model is now supported in this image instead of the custom built image: #17784

  • DeepSeek V3.2 / GLM-5 Optimization: GLM-5 runnable on main branch (with upgraded transformers). Fused Triton kernel for prefill KV cache fetching, NSA fuse store indexer for K cache, TRT-LLM prefill/decode DSA kernels as default on SM100/SM103, and IndexCache for improved throughput by more than 10% on high workloads: #19319, #19148, #20062, #21914, #21405

  • Qwen3.5 GDN/KDA Optimization: Transpose linear attention state layout from [N, HV, K, V] to [N, HV, V, K] and fuse split/reshape/cat ops in GDN projection with Triton kernel, plus CuTeDSL KDA decode kernel support for improved Qwen3.5 performance: #20283, #21019, #21203

  • LoRA Support for MoE Layers: Add LoRA fine-tuning support for Mixture-of-Experts layers with JIT alignment kernels, fused Triton kernels, TP support, CUDA graph support, and auto-detection of LoRA target modules — enabling efficient adapter-based tuning on MoE models like DeepSeek: #19710, #19711, #14105, #21439, #21647

  • Prefill Context Parallel for MHA (Qwen3): Enable context parallelism during prefill for multi-head attention models like Qwen3 MoE, distributing long sequences across GPUs to reduce per-GPU memory and accelerate prefill: #18233

  • Flash Attention 4 Official Library Support: Upgrade to the official FlashAttention 4 package, bringing the latest attention optimizations and Blackwell GPU support: #20303

  • Skip-Softmax Attention for FlashInfer TRT-LLM Kernels: Reduce computation overhead in attention layers by skipping redundant softmax normalization: #19089

  • Speculative Decoding with FA4 Backend: Enable speculative decoding for the FA4 attention backend, combining speculative inference with next-generation flash attention for faster generation: #21080

  • MM Attention FA4 Default on SM100: Multi-modal attention now uses FA4 by default on Blackwell hardware for improved VLM performance: #21595

  • Stronger Transformers Modeling Backend: Enhanced transformers backend with full TP, PP, MoE, VLM support, and torch.compile compatibility: #19163

  • sglang-kernel 0.4.1: Major kernel package release with renamed package (sgl-kernel → sglang-kernel), consolidated kernels, and cleanup of deprecated ops: #20440, #22009

  • Native MLX Backend for Apple Silicon: Add native MLX execution backend enabling SGLang to run inference directly on Apple Silicon Macs without CUDA: #20342
