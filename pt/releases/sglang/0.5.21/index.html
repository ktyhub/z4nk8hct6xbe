Principais recursos

  • As instâncias PD podem alternar entre pré-preenchimento e decodificação em tempo real, sem necessidade de reinicialização (#28403).
  • O cache de prefixo agora é executado em um núcleo Rust por padrão (#39627).
  • DeepSeek-V4.1 obtém o primeiro token 22% mais rápido em prompts longos (#40352).
  • Kimi K3 obtém rendimento de pré-preenchimento 20.6% maior na veiculação PD (#40045).
  • GLM-5.3-Flash agora roda em AMD MI355X, com FP8 / MXFP4 MoE e decodificação especulativa MTP (#38546, #39341, #39778).
  • Resultados mais precisos sob PP, atenção DP e CP, com comunicação de camada agora gerenciada por SGLang (guide, #41557).
  • Novas decisões API (/v1/decisions) transforma um LLM / VLM em um classificador e marcador de baixa latência (docs, #41208).
  • Pontuação API (/v1/score) pontua todos os candidatos em uma solicitação (#38965, #41188).
  • Execute MiniMax-H3 com SGLang Diffusion dentro do ComfyUI (#35990).

Mudanças recentes e notas de atualização

  • A árvore radix unificada usa o núcleo Rust por padrão. Configurações que o núcleo Rust não suporta retrocedem para Python automaticamente; configure SGLANG_UNIFIED_RADIX_TREE_CORE_BACKEND=python para forçar o núcleo Python em todos os lugares: #39627
  • A finalização fundida do FlashInfer MoE está desativada por padrão para precisão numérica. Isso custa alguma latência W4A4 MoE; configure SGLANG_FLASHINFER_MOE_FUSED_FINALIZE=1 para restaurar a finalização atômica fundida: #40105
  • A decodificação PD agora adia a liberação de KV na interrupção por padrão nos back-ends Mooncake e NIXL, mantendo as páginas até que cada classificação de pré-preenchimento seja confirmada (tempo limite de 30 s, SGLANG_DISAGGREGATION_DEFERRED_DECODE_KV_RELEASE_TIMEOUT). Defina SGLANG_DISAGGREGATION_DEFERRED_DECODE_KV_RELEASE=False para restaurar a liberação imediata: #41023
  • Os modelos de chat fornecidos pela solicitação são rejeitados. Uma chave chat_template dentro de chat_template_kwargs em /v1/chat/completions ou /v1/tokenize agora retorna um erro, a menos que o servidor inicie com --trust-request-chat-template; outros chat_template_kwargs permanecem inalterados: #28135
  • Endpoints, env vars e aliases obsoletos foram removidos. Use /model_info em vez de /get_weight_version e /weight_version, /v1/loads em vez de /get_load e POST /hicache/storage-backend/clear em vez de /clear_hicache_storage_backend. Os aliases SGLANG_NSA_* dão lugar a SGLANG_DSA_*, SGLANG_ENABLE_SPEC_V2 desapareceu, --elastic-ep-rejoin torna-se --elastic-ep-join-mode recover, --kv-cache-dtype fp4_e2m1 torna-se fp4_mx_block16 e python -m sglang.bench_offline_throughput / sglang.bench_one_batch passa para sglang.benchmark.offline_throughput / sglang.benchmark.one_batch: #40795
  • Implementações de cache radix legado foram removidas. A árvore radix C++ experimental (SGLANG_EXPERIMENTAL_CPP_RADIX_TREE) desapareceu (#40775) e SGLANG_ENABLE_UNIFIED_RADIX_TREE não faz mais nada, embora ainda imprima um aviso de descontinuação (#40780). O código que importa SWARadixCache, MambaRadixCache ou HiRadixCache deve ser movido para UnifiedRadixCache: #40313, #40787
  • Os processadores logit personalizados devem retornar logits em formato completo. Um CustomLogitProcessor que retornou um formato reduzido, como (1, vocab) e dependia de transmissão, agora aumenta no tempo de decodificação. Os processadores integrados não são afetados: #39234
  • As atualizações de peso RL são executadas dentro de uma sessão. update_weights_from_tensor e update_weights_from_distributed devem ser chamados entre begin_weight_update() e end_weight_update(). UpdateWeightsFromTensorReqInput.disable_draft_model foi substituído por selector="target" e ChecksumInfo.parallelism_info agora é uma lista com uma entrada por função: #40777
  • Getters de estado paralelo estão obsoletos. Eles não são mais reexportados do sglang.srt.distributed; leia grupos através de get_parallel() (por exemplo get_parallel().tp_group) ou importe diretamente de parallel_state: #40342, #40344, #40707
  • Imagens Ascend A2 (910b) não são mais publicadas. Lançamento e imagens noturnas são enviadas apenas para A3 e 950 (A5), em CANN 9.1.0 com Python 3.12: #40524

Breaking Changes & Upgrade Notes

  • The unified radix tree uses the Rust core by default. Configurations the Rust core does not support fall back to Python automatically; set SGLANG_UNIFIED_RADIX_TREE_CORE_BACKEND=python to force the Python core everywhere: #39627
  • FlashInfer MoE fused finalize is off by default for numerical accuracy. This costs some W4A4 MoE latency; set SGLANG_FLASHINFER_MOE_FUSED_FINALIZE=1 to restore the fused atomic finalize: #40105
  • PD decode now defers KV release on abort by default on the Mooncake and NIXL backends, holding pages until every prefill rank acks (30 s timeout, SGLANG_DISAGGREGATION_DEFERRED_DECODE_KV_RELEASE_TIMEOUT). Set SGLANG_DISAGGREGATION_DEFERRED_DECODE_KV_RELEASE=False to restore immediate release: #41023
  • Request-supplied chat templates are rejected. A chat_template key inside chat_template_kwargs on /v1/chat/completions or /v1/tokenize now returns an error unless the server starts with --trust-request-chat-template; other chat_template_kwargs are unchanged: #28135
  • Deprecated endpoints, env vars, and aliases are removed. Use /model_info instead of /get_weight_version and /weight_version, /v1/loads instead of /get_load, and POST /hicache/storage-backend/clear instead of /clear_hicache_storage_backend. SGLANG_NSA_* aliases give way to SGLANG_DSA_*, SGLANG_ENABLE_SPEC_V2 is gone, --elastic-ep-rejoin becomes --elastic-ep-join-mode recover, --kv-cache-dtype fp4_e2m1 becomes fp4_mx_block16, and python -m sglang.bench_offline_throughput / sglang.bench_one_batch move to sglang.benchmark.offline_throughput / sglang.benchmark.one_batch: #40795
  • Legacy radix cache implementations are removed. The experimental C++ radix tree (SGLANG_EXPERIMENTAL_CPP_RADIX_TREE) is gone (#40775), and SGLANG_ENABLE_UNIFIED_RADIX_TREE no longer does anything, though it still prints a deprecation warning (#40780). Code importing SWARadixCache, MambaRadixCache, or HiRadixCache must move to UnifiedRadixCache: #40313, #40787
  • Custom logit processors must return full-shape logits. A CustomLogitProcessor that returned a reduced shape such as (1, vocab) and relied on broadcasting now raises at decode time. The built-in processors are unaffected: #39234
  • RL weight updates run inside a session. update_weights_from_tensor and update_weights_from_distributed must be called between begin_weight_update() and end_weight_update(). UpdateWeightsFromTensorReqInput.disable_draft_model is replaced by selector="target", and ChecksumInfo.parallelism_info is now a list with one entry per role: #40777
  • Parallel-state getters are deprecated. They are no longer re-exported from sglang.srt.distributed; read groups through get_parallel() (for example get_parallel().tp_group) or import from parallel_state directly: #40342, #40344, #40707
  • Ascend A2 (910b) images are no longer published. Release and nightly images ship for A3 and 950 (A5) only, on CANN 9.1.0 with Python 3.12: #40524
