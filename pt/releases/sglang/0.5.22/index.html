Novidades

  • DeepSeek-V4.1 obtém até 2,3x mais rendimento por GPU no H200 e agora roda em AMD MI350X / MI355X com até 1,9x rendimento do DSpark (#41251, #41308).
  • Qwen3.8-Flash-Next decodifica 12% mais rápido no B200 e GLM-5.3-Flash com DFlash 10% mais rápido no B300 (#42175, #42489).
  • MiMo-V2.6-Pro obtém taxa de transferência de decodificação de 1,85x com DFlash no B300 (#41886).
  • Os modelos carregam 10x mais rápido com o novo carregador InstantTensor (#40453).
  • A desagregação PD obtém até 27% mais rendimento e metade do TTFT p95 em cargas de trabalho de prompt longo (#40703).
  • HiSparse agora suporta EAGLE e MTP para servir de contexto longo com o cache KV na memória da CPU (#37771).
  • GLM-5.2 e GLM-5.3 agora podem combinar paralelismo de contexto de decodificação com MTP, com decodificação até 2,1x mais rápida em GLM-5.3 (#43735).
  • SGLang agora roda em Apple Silicon Macs com o backend PyTorch padrão, junto com MLX (#36780).
  • MiniMax-H3 e Qwen-Image 2.1 agora são executados em ComfyUI com SGLang Diffusion, que também carrega pontos de verificação GGUF da comunidade e LoRAs (#43504, #43581, #42556, #39523, #42174).
  • Correção importante: modelos lineares híbridos poderiam ser retomados a partir de estados mamba errados quando a decodificação especulativa e a saída estruturada fossem usadas juntas. Obrigado a @Wirick e Baseten por encontrá-lo (#43029).

Mudanças recentes e notas de atualização

  • SGLang requer Python 3.11 ou mais recente. Em Python 3.10, pip install sglang não falha; ele resolve para a última versão compatível com 3.10. Mude para Python 3.11+ (por exemplo, fora do sistema Ubuntu 22.04 Python) para obter esta e versões posteriores: #43021
  • --enable-dp-attention está obsoleto; use --attn-dp-size N. --dp-size agora conta apenas réplicas de modelo. O antigo --dp-size N --enable-dp-attention ainda resolve para --attn-dp-size N com um aviso; combinar réplicas com atenção DP, ou passar ambas as grafias, é rejeitado na inicialização: #41818. No paralelismo de contexto DeepSeek, --dp-size N ainda significa atenção DP, mas agora avisa e será rejeitado após 31/12/2026: #42348
  • --disaggregation-decode-host-receive-threshold inverte sua codificação. 1 (o novo padrão) desativa o recebimento do host e 0 agora significa sempre receber no host. Configurações que passaram por 0 para desabilitá-lo devem passar por 1: #43407
  • ChunkCache foi removido. Com --disable-radix-cache, os modelos híbrido-SWA e Mamba com atenção total executam UnifiedRadixCache no modo desativado e os modelos SWA puro executam PureSWARadixCache (#43198, #43199, #43200, #42354, #43201). As sessões de streaming agora começam apenas no UnifiedRadixCache; caches pure-SWA, FlexKV e árvore de plug-ins falham na inicialização com um erro "não verificado" (#42295), e a pesquisa de feixe também rejeita modelos Mamba com --disable-radix-cache (#42354)
  • O back-end do gráfico CUDA de pré-preenchimento tc_piecewise foi removido. Passar --cuda-graph-backend-prefill tc_piecewise ou uma configuração tc_compiler agora gera um erro; CUDA mantém breakable como back-end de gráfico de pré-preenchimento padrão, e outras plataformas não têm gráfico de pré-preenchimento como padrão: #42287
  • Variáveis de ambiente renomeadas e descontinuadas. SGLANG_AITER_MLA_DCP_DECODE_BACKEND se torna SGLANG_AITER_MLA_DECODE_BACKEND e seu padrão muda de gluon para asm (#34537); SGLANG_OPT_SWA_RELEASE_LEAF_LOCK_AFTER_WINDOW torna-se SGLANG_OPT_RELEASE_PREFILL_SWA (#42657); os nomes antigos continuam funcionando com um aviso de descontinuação. SGLANG_DSPARK_FAST_SAMPLING, SGLANG_DSPARK_FOLDED_SAMPLING e SGLANG_DSPARK_OPT_FUSED_GREEDY_MARKOV estão obsoletos e não fazem mais nada (#43622, #43668), e SGLANG_TRITON_PREFILL_TRUNCATION_ALIGN_SIZE está obsoleto: #43444
  • As respostas do bate-papo OpenAI foram alteradas de três pequenas maneiras. tool_choice: "none" não mostra mais esquemas de ferramentas para modelos DeepSeek (#43006), um campo tool_calls ausente é omitido em vez de retornado como null (#43027), e um fluxo mantém um carimbo de data/hora created durante toda a sua vida útil: #43026
  • --enable-layernorm-sp foi rejeitado com paralelismo de pipeline. Falha no primeiro pré-preenchimento antes de: #43458
  • Para autores de modelos e plugins: ModelRunner.tp_group foi removido; leia get_parallel().tp_group no escopo em que o código é executado (#41817). Atributos de posicionamento não lidos, como model.tp_size, desapareceram; leia get_parallel() (#41812). Um modelo que declara limites de estágio e executa sob paralelismo de pipeline deve passar sua declaração de estágio compartilhado (stage_facts) para make_layers/make_pp_layers: #43460

Breaking Changes & Upgrade Notes

  • SGLang requires Python 3.11 or newer. On Python 3.10, pip install sglang does not fail; it resolves to the last release that supported 3.10. Move to Python 3.11+ (for example off the Ubuntu 22.04 system Python) to get this and later releases: #43021
  • --enable-dp-attention is deprecated; use --attn-dp-size N. --dp-size now counts model replicas only. The old --dp-size N --enable-dp-attention still resolves to --attn-dp-size N with a warning; combining replicas with attention DP, or passing both spellings, is rejected at startup: #41818. Under DeepSeek context parallelism, --dp-size N still means attention DP but now warns and will be rejected after 2026-12-31: #42348
  • --disaggregation-decode-host-receive-threshold flips its encoding. 1 (the new default) disables host receive and 0 now means always receive on host. Configurations that passed 0 to disable it must pass 1: #43407
  • ChunkCache is removed. With --disable-radix-cache, full-attention, hybrid-SWA and Mamba models run UnifiedRadixCache in disabled mode and pure-SWA models run PureSWARadixCache (#43198, #43199, #43200, #42354, #43201). Streaming sessions now start only on UnifiedRadixCache; pure-SWA, FlexKV and plugin tree caches fail at startup with a "not verified" error (#42295), and beam search rejects Mamba models with --disable-radix-cache too (#42354)
  • The tc_piecewise prefill CUDA graph backend is removed. Passing --cuda-graph-backend-prefill tc_piecewise or a tc_compiler setting now raises an error; CUDA keeps breakable as the default prefill graph backend, and other platforms default to no prefill graph: #42287
  • Renamed and retired environment variables. SGLANG_AITER_MLA_DCP_DECODE_BACKEND becomes SGLANG_AITER_MLA_DECODE_BACKEND and its default changes from gluon to asm (#34537); SGLANG_OPT_SWA_RELEASE_LEAF_LOCK_AFTER_WINDOW becomes SGLANG_OPT_RELEASE_PREFILL_SWA (#42657); the old names keep working with a deprecation warning. SGLANG_DSPARK_FAST_SAMPLING, SGLANG_DSPARK_FOLDED_SAMPLING and SGLANG_DSPARK_OPT_FUSED_GREEDY_MARKOV are deprecated and no longer do anything (#43622, #43668), and SGLANG_TRITON_PREFILL_TRUNCATION_ALIGN_SIZE is deprecated: #43444
  • OpenAI chat responses changed in three small ways. tool_choice: "none" no longer shows tool schemas to DeepSeek models (#43006), an absent tool_calls field is omitted instead of returned as null (#43027), and a stream keeps one created timestamp for its whole lifetime: #43026
  • --enable-layernorm-sp is rejected with pipeline parallelism. It failed on the first prefill before: #43458
  • For model and plugin authors: ModelRunner.tp_group is removed; read get_parallel().tp_group in the scope the code runs in (#41817). Unread placement attributes such as model.tp_size are gone; read get_parallel() (#41812). A model that declares stage boundaries and runs under pipeline parallelism must pass its shared stage declaration (stage_facts) to make_layers / make_pp_layers: #43460
