gateway de gíria-v0.3.1

🚀 Lançado SMG v0.3.1!

Temos o prazer de anunciar o SMG v0.3.1 – um lançamento revolucionário com melhoria de desempenho de 10 a 12x e redução de 99% de memória no roteamento com reconhecimento de cache, além de segurança de nível empresarial!

🌲 Roteamento Radix Tree / Cache-Aware: 10-12x mais rápido + 99% menos memória ⚡

Revisão completa da otimização do nosso mecanismo de roteamento com reconhecimento de cache com desempenho impressionante e ganhos de memória:

Melhorias de desempenho

  • Nosso roteamento com reconhecimento de cache agora pode lidar com mais de 216.000 inserções de cache por segundo (acima de 18.900), com latência caindo de microssegundos 52.9 para apenas microssegundos 4.6 por operação.
  • Para correspondência de prefixos em 10.000 entradas de árvore, a produtividade saltou de 41.000 para 124.000 operações por segundo.
  • Sob carga simultânea com 64 threads, o sistema processa 474.000 operações por segundo – uma melhoria de 7,9x em relação às 59.000 operações/s anteriores.

Processamento de dados

  • As operações INSERT agora processam 440 MB/s (acima de 38 MB/s),
  • As operações MATCH lidam com 253 MB/s (acima de 83 MB/s).

Melhorias de memória:

  • ~99% de redução de memória por nó de árvore:
  • Antes: ~180 KB por nó (configuração padrão do DashMap em máquinas com 170 núcleos)
  • Depois: ~1.4 KB por nó Resultado: implante 100 vezes mais entradas de cache no mesmo espaço de memória! Para uma implantação típica com 10.000 prefixos em cache, o uso de memória cai de ~1.8 GB para apenas ~14 MB – liberando recursos para cargas de trabalho de inferência reais. Impacto: o roteamento com reconhecimento de cache agora é 10 a 12 vezes mais rápido e usa 99% menos memória. Isso é fundamental para implantações multilocatários em larga escala.

🔐 Autenticação JWT/OIDC

Segurança de nível de produção para planos de controle APIs com suporte nativo para provedores OIDC padrão do setor: Google, Azure, Oracle, GitHub e muito mais. Proteja o gerenciamento de tokenizer, o registro de trabalhadores e os endpoints administrativos com a infraestrutura de autenticação empresarial que você já usa. Crítico para implantações empresariais – integre perfeitamente o SMG aos seus sistemas existentes de gerenciamento de identidade e acesso.

📊 Classificação Suporte API

Suporte nativo para cargas de trabalho de classificação! Implante e forneça modelos de classificação junto com sua frota de inferência existente com estágios de pipeline e tipos de protocolo dedicados.

✨ Recursos adicionais

  • Balanceamento de carga PrefixHash: nova política de balanceamento de carga com reconhecimento de cache KV usando hash de prefixo para melhorar as taxas de acerto de cache em ambientes multilocatários.
  • Analisador Nemotron Nano V3
  • Métricas de idade da solicitação em voo: rastreie a idade da solicitação em voo para melhor observabilidade e monitoramento de SLA.

🛠️ Melhorias

Experiência do desenvolvedor:

  • Argumentos CLI organizados em grupos lógicos
  • Destinos de registro reduzidos (sgl_model_gateway → smg)
  • Testes abrangentes de correção de incorporação contra HuggingFace
  • Gerar automaticamente arquivos protobuf durante a construção da roda

Confiabilidade:

  • Corrigir roteamento IGW para trabalhadores externos do OpenAI
  • Contornar problemas de processos órfãos
  • Evite possíveis travamentos no manuseio de subprocessos
  • Use 504 Gateway Timeout para tempos limite de upstream (semântica HTTP adequada)

🐛 Correções de bugs

  • Corrigida falha na verificação de integridade do trabalhador de incorporação
  • Correção do tokenizer para corresponder ao tratamento especial de tokens dos transformadores
  • Corrigido problema de renderização do intervalo de idade
  • Correção da lista de permissões de cabeçalho HTTP do roteador não PD
  • Prefixo de classificação duplicado corrigido no ID de resposta
  • Corrigidos erros de teste WASM em máquinas com muitos núcleos

sglang gateway-v0.3.1

🚀 SMG v0.3.1 Released!

We're excited to announce SMG v0.3.1 – a game-changing release with 10-12x performance improvement and 99% memory reduction in cache-aware routing, plus enterprise-grade security!

🌲 Radix Tree / Cache-Aware Routing: 10-12x Faster + 99% Less Memory ⚡

Complete optimization overhaul of our cache-aware routing engine with stunning performance and memory gains:

Performance Improvements

  • Our cache-aware routing can now handle over 216,000 cache insertions per second (up from 18,900), with latency dropping from 52.9 microseconds to just 4.6 microseconds per operation.
  • For prefix matching across 10,000 tree entries, throughput jumped from 41,000 to 124,000 operations per second.
  • Under concurrent load with 64 threads, the system processes 474,000 operations per second – a 7.9x improvement over the previous 59,000 ops/sec.

Data processing

  • INSERT operations now process 440 MB/s (up from 38 MB/s),
  • MATCH operations handle 253 MB/s (up from 83 MB/s).

Memory Improvements:

  • ~99% memory reduction per tree node:
  • Before: ~180 KB per node (DashMap default config on 170-core machines)
  • After: ~1.4 KB per node Result: Deploy 100x more cache entries in the same memory footprint! For a typical deployment with 10,000 cached prefixes, memory usage drops from ~1.8 GB to just ~14 MB – freeing up resources for actual inference workloads. Impact: Cache-aware routing is now 10-12x faster and uses 99% less memory. This is critical for large-scale multi-tenant deployments.

🔐 JWT/OIDC Authentication

Production-grade security for control plane APIs with native support for industry-standard OIDC providers: Google, Azure, Oracle, GitHub, and more. Protect tokenizer management, worker registration, and admin endpoints with enterprise authentication infrastructure you already use. Critical for enterprise deployments – seamlessly integrate SMG into your existing identity and access management systems.

📊 Classification API Support

Native support for classification workloads! Deploy and serve classification models alongside your existing inference fleet with dedicated pipeline stages and protocol types.

✨ Additional Features

  • PrefixHash Load Balancing: New KV cache-aware load balancing policy using prefix hashing for improved cache hit rates in multi-tenant environments.
  • Nemotron Nano V3 Parser
  • In-Flight Request Age Metrics: Track request age in-flight for better observability and SLA monitoring.

🛠️ Enhancements

Developer Experience:

  • Organized CLI arguments into logical groups
  • Shortened logging targets (sgl_model_gateway → smg)
  • Comprehensive embedding correctness tests against HuggingFace
  • Auto-generate protobuf files during wheel build

Reliability:

  • Fix IGW routing for external OpenAI workers
  • Work around orphan process problems
  • Prevent potential hangs in subprocess handling
  • Use 504 Gateway Timeout for upstream timeouts (proper HTTP semantics)

🐛 Bug Fixes

  • Fixed embedding worker health check crash
  • Fixed tokenizer to match transformers special token handling
  • Fixed age bucket rendering issue
  • Fixed non-PD router HTTP header whitelist
  • Fixed duplicate classify prefix in response ID
  • Fixed WASM test errors on machines with many cores

⚡ Built for speed. Engineered for scale. Production-proven.
