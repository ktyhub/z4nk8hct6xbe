#openhuman v0.57.52

A atualização do mundo do agente e da segurança da carteira

Esta versão traz um grande salto na profundidade do Agent World, navegação mais suave pelo aplicativo e uma grande correção de segurança da carteira, além de aprimoramento da qualidade de vida por toda parte. 🎉

Destaques

Agent World se torna nativo 🌍

Agent World (tiny.place) agora está profundamente integrado com uma camada de dados Rust completa e uma UI React portada, desbloqueando superfícies principais como Feed, Mensagens, Trabalhos/Recompensas, Diretórios/Identidades e fluxos de pagamento devnet com confirmação antes de gastar. Além dessa base, o Explore agora extrai dados reais ao vivo, o registro de identidade é publicado corretamente no Diretório, os DMs resolvem os identificadores de maneira confiável e os grupos/criação de recompensas fornecem feedback de experiência do usuário mais claro.
(#3780, #3839, #3847, #3846, #3840, #3837, #3835) - Obrigado @graycyrus!

Fluxos de trabalho e orquestração de agentes mais inteligentes 🤖

Subagentes de segundo plano desanexados agora cancelam de forma limpa quando seu thread pai é fechado, evitando execuções do tipo “disparar e esquecer” em conversas excluídas. E o agente agora está vinculado a um relógio ativo por turno para que as declarações relativas ao tempo (“bom dia”, “hoje/amanhã”) permaneçam precisas durante longas sessões.
(#3742, #3752) — Obrigado @sanil-23!

Segurança da carteira, visibilidade e trust 🔐

Uma correção crítica da carteira garante que a experiência da Frase de Recuperação revele a frase existente em vez de regenerar/substituir acidentalmente a carteira de um usuário – agora protegida por um caminho de “força” explícito e uma máquina de estado de UI mais clara. O acesso à carteira também é mais detectável com uma entrada proeminente na barra lateral, e o Agent World agora mostra um prático chip de endereço da carteira no cabeçalho da barra lateral.
(#3849, #3836, #3838) — Obrigado @graycyrus!

Navegação e aprimoramento do shell de bate-papo 🧭

O shell é mais fácil de usar quando recolhido graças a um trilho de navegação apenas com ícones que permanece totalmente navegável, completo com dicas de ferramentas e estado ativo. O cabeçalho da barra lateral também está mais limpo (seletor de idioma movido para Configurações), e a experiência de bate-papo/barra lateral recebe um retrabalho significativo com a renomeação do título do tópico fluindo para a barra lateral e outros refinamentos no shell do bate-papo.
(#3802, #3810, #3854) — Obrigado @graycyrus e @senamakel!

Recompensas + link do Discord tornado real 🎁

A vinculação do Discord agora executa o OAuth na página Recompensas (e retorna você de volta), e a experiência do Rewards adiciona desconexão/revinculação, além de status claro de atribuição de função por conquista - portanto, a reivindicação de funções é transparente e acionável.
(#3748, #3766) — Obrigado @YellowSnnowmann!

Correções de localização e correção de UX 🌐

Mais strings voltadas para o usuário agora estão totalmente localizadas, incluindo mensagens de conta/notificação do OpenHuman Link e os rótulos do seletor de dicas do Model Council – fechando lacunas onde os literais em inglês contornavam o i18n. Além disso, os gatilhos de loop consciente agora são protegidos para evitar execuções duplicadas em rapid clicks.
(#3702, #3704, #3708) — Obrigado @obchain!

Provedores de webview incorporados expandem 🧩

O seletor de conta webview incorporado agora oferece suporte a mais provedores convencionais – Gmail, Outlook, Instagram e X – em frontend, shell Tauri, detecção de login principal e receitas de provedor.
(#3755) — Obrigado @senamakel!

Teste e libere melhorias de saúde 🧪

A cobertura E2E e a configuração Playwright/Vitest foram adaptadas ao shell chat-as-home, corrigindo corridas de navegação e estabilizando os tempos limites de cobertura.
(#3754) — Obrigado @senamakel!

Alinhamento da UI do Agent World e limpeza da barra lateral 🧹

O Agent World continua a ser simplificado: os trabalhos agora estão ocultos na barra lateral do Agent World (mantendo a rota acessível para links diretos), e a candidatura a empregos ganha uma ferramenta de agente, além de uma UX de sucesso de “proposta enviada” mais clara.
(#3855, #3848) — Obrigado @graycyrus!

Confiabilidade do empacotamento Linux 🐧

O pacote AppImage agora substitui consistentemente o pacote ld-linux do sistema host CI para evitar travamentos de incompatibilidade de glibc vistos em distros mais recentes (por exemplo, Fedora com glibc ≥ 2.42).
(#3645) — Obrigado @0xhis!

openhuman v0.57.52

The Agent World & Wallet Safety Upgrade

This release brings a big leap in Agent World depth, smoother navigation across the app, and a major wallet-safety fix—plus quality-of-life polish throughout. 🎉

Highlights

Agent World goes native 🌍

Agent World (tiny.place) is now deeply integrated with a full Rust data layer and a ported React UI, unlocking core surfaces like Feed, Messages, Jobs/Bounties, Directory/Identities, and devnet payment flows with confirm-before-spend. On top of that foundation, Explore now pulls real live data, identity registration publishes to the Directory correctly, DMs resolve handles reliably, and groups/creating bounties give clearer UX feedback.
(#3780, #3839, #3847, #3846, #3840, #3837, #3835) — Thank you @graycyrus!

Smarter agent workflows & orchestration 🤖

Detached background sub-agents now cleanly cancel when their parent thread is closed, preventing “fire-and-forget” runs against deleted conversations. And the agent is now grounded to a live per-turn clock so time-relative statements (“good morning”, “today/tomorrow”) stay accurate across long sessions.
(#3742, #3752) — Thank you @sanil-23!

Wallet safety, visibility, and trust 🔐

A critical wallet fix ensures the Recovery Phrase experience reveals the existing phrase instead of accidentally regenerating/overwriting a user’s wallet—now guarded by an explicit “force” path and a clearer UI state machine. Wallet access is also more discoverable with a prominent sidebar entry, and Agent World now shows a handy wallet address chip in its sidebar header.
(#3849, #3836, #3838) — Thank you @graycyrus!

Navigation & chat shell polish 🧭

The shell is easier to use when collapsed thanks to an icon-only navigation rail that stays fully navigable, complete with tooltips and active state. The sidebar header is also cleaner (language picker moved to Settings), and the chat/sidebar experience gets a meaningful rework with thread-title rename flowing into the sidebar and other chat shell refinements.
(#3802, #3810, #3854) — Thank you @graycyrus and @senamakel!

Rewards + Discord linking made real 🎁

Discord linking now actually runs OAuth from the Rewards page (and returns you right back), and the Rewards experience adds disconnect/re-link plus clear per-achievement role assignment status—so claiming roles is transparent and actionable.
(#3748, #3766) — Thank you @YellowSnnowmann!

Localization & UX correctness fixes 🌐

More user-facing strings are now fully localized, including OpenHuman Link account/notification messaging and the Model Council hint picker labels—closing gaps where English literals bypassed i18n. Also, Conscious loop triggers are now guarded to prevent duplicate runs on rapid clicks.
(#3702, #3704, #3708) — Thank you @obchain!

Embedded webview providers expand 🧩

The embedded webview account picker now supports more mainstream providers—Gmail, Outlook, Instagram, and X—across frontend, Tauri shell, core login detection, and provider recipes.
(#3755) — Thank you @senamakel!

Test & release health improvements 🧪

E2E coverage and Playwright/Vitest setup were adapted to the chat-as-home shell, fixing navigation races and stabilizing coverage timeouts.
(#3754) — Thank you @senamakel!

Agent World UI alignment & sidebar cleanup 🧹

Agent World continues to be streamlined: Jobs is now hidden from the Agent World sidebar (while keeping the route accessible for deep links), and job applying gains an agent tool plus a clearer “proposal submitted” success UX.
(#3855, #3848) — Thank you @graycyrus!

Linux packaging reliability 🐧

AppImage bundling now consistently replaces the bundled ld-linux from the CI host system to prevent glibc mismatch crashes seen on newer distros (e.g., Fedora with glibc ≥ 2.42).
(#3645) — Thank you @0xhis!

New Contributors

  • Thank you @0xhis for fixing AppImage glibc mismatch crashes by ensuring the bundled ld-linux is always replaced from the host system. (#3645)

Hope you’ll join our Discord—come grab your exclusive roles and contributor rewards!

Contributor Credits

Huge thanks to everyone who shipped this release: @0xhis, @graycyrus, @obchain, @sanil-23, @senamakel, @YellowSnnowmann, and our ever-helpful automation friend @github-actions[bot].
