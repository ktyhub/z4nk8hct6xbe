open-webui v0.13.3

Adicionado

  • 🦾 Agentes em automações. O editor de automação agora permite escolher um terminal e uma pasta de trabalho e, em seguida, selecionar um agente de codificação disponível lá. As execuções agendadas usam o terminal e a pasta salvos e verificam se o terminal e o agente ainda estão disponíveis antes de iniciar. As automações dos agentes enviam seus resultados para um chat; os destinos dos canais permanecem disponíveis para modelos comuns. Confirmar
  • 📂 Alterar terminal e pasta durante um bate-papo. Agora você pode escolher um terminal ou pasta de trabalho diferente após enviar mensagens, inclusive em bate-papos temporários. Ambos os controles permanecem desativados enquanto uma resposta está sendo gerada. Confirmar
  • 🇧🇷 Traduções para o português do Brasil. Adicionadas traduções ausentes para controles de terminal e pasta, ações Git, edição de planilhas, notas de voz, atalhos de guias, sons de notificação e configurações de ferramentas. Atualizadas as explicações para recuperação de documentos, permissões de ferramentas e configurações de voz. #33945

Corrigido

  • 📂 As guias Arquivos seguem as alterações do terminal. Mudar um bate-papo para outro terminal agora atualiza as guias Arquivos abertas para mostrar os arquivos desse terminal, em vez de deixar as pastas do terminal anterior na tela. Com um terminal definido como “Por chat”, a aba Arquivos também muda para os arquivos do próprio chat após a primeira mensagem. #33954
  • 🧭 Agentes em seletores de modelos não suportados. Conectar um terminal não adiciona mais seus agentes de codificação a modelos de administrador, seletores de modelo base, candidatos de Arena, configurações de modelo de tarefa, padrões de grupo, configurações de subagentes, menções de canal ou Playground. O Notes também deixa de escolher um agente terminal para geração de títulos. Os agentes não podem ser salvos ou importados como modelos personalizados ou modelos básicos, e o menu de bate-papo não oferece mais Editar. Confirmar, Confirmar
  • 🔌 Lista de agentes após trocar de terminal. A mudança de terminal remove imediatamente os agentes do terminal anterior da lista de modelos do chat enquanto a nova lista é carregada. Uma solicitação de lista de modelos de um bate-papo que você deixou não pode mais substituir a lista atual. Confirmar
  • 📋 Botões de cópia por HTTP simples. Em um endereço HTTP simples em sua rede local, copiar links de comentários, links de pesquisa, links de bate-papo compartilhado, URLs de webhook, IDs de bate-papo, nomes de ramificações do Git, hashes de commit e células de planilhas agora funciona. Copiar texto formatado preserva a formatação e o texto copiado mantém sua quebra de linha final. #33939
  • 📝 Avisos do Clipboard e resposta de cópia automática por HTTP simples. Os prompts que usam o espaço reservado do clipboard agora são inseridos em bate-papos e canais mesmo quando o navegador bloqueia o acesso ao clipboard, com uma mensagem explicando que o clipboard não pôde ser lido. A resposta de cópia automática permanece desativada e mostra uma mensagem de permissão em vez de falhar silenciosamente ao ativar; desligá-lo não requer mais acesso ao clipboard. #33939
  • 🧠 Modo de pensamento DeepSeek com habilidades, conhecimento e memórias. Esses bate-papos não falham mais com erro de raciocínio ausente quando o Provedor da conexão é definido como "llama.cpp". O modo de pensamento DeepSeek ainda requer essa configuração; as conexões usando "Padrão" permanecem inalteradas. #33950
  • 🏷️ Rótulos em chamadas de ferramenta agrupadas. Com Rótulos de chamada de ferramenta habilitados, um grupo de chamadas de ferramenta mantém os rótulos que estão presentes mesmo que uma chamada não tenha nenhum. A chamada sem rótulo mostra o nome da ferramenta em vez de fazer com que todo o grupo perca seus rótulos. #33932
  • 💬 Rótulos de ferramentas em respostas posteriores. O modelo agora vê os rótulos que escreveu para chamadas de ferramentas anteriores ao continuar uma resposta ou responder outra mensagem, eliminando o motivo pelo qual ele poderia parar de escrever rótulos à medida que a conversa continuava. #33953
  • 🔎 Pesquisas de conhecimento contendo pontuação. Pesquisas em arquivos de conhecimento agora encontram textos como "Art. 40" quando o modelo marca o ponto final como pontuação literal, em vez de não retornar nenhuma correspondência. #33936
  • 🪟 Bate-papo paralelo com bate-papo temporário desativado. Deixar o recurso Aplicar bate-papo temporário ativado enquanto o bate-papo temporário desativado não impede mais que os usuários enviem e salvem bate-papos paralelos ou arrastem um bate-papo existente para o painel lateral. #33930
  • 🏠 Título da guia da pasta inicial. Uma guia Arquivos no diretório inicial da máquina conectada agora diz "Home" em vez de mostrar o nome do diretório, inclusive ao reabrir guias salvas. Outras pastas mantêm seus nomes. Confirmar
  • 🦙 Ollama ausente nas imagens Docker. A construção da imagem que inclui o Ollama agora falha se o Ollama não estiver instalado, em vez de produzir uma imagem que não pode iniciar o Ollama após falha no download. #33944
  • 📄 Erros após sair de um bate-papo. Fechar ou sair de um bate-papo enquanto o layout da guia está sendo salvo não preenche mais o log do servidor com um relatório de erro para a conexão interrompida. #33929

open-webui v0.13.3

Added

  • 🦾 Agents in automations. The automation editor now lets you choose a terminal and working folder, then select a coding agent available there. Scheduled runs use that saved terminal and folder, and check that the terminal and agent are still available before starting. Agent automations send their results to a chat; channel destinations remain available for ordinary models. Commit
  • 📂 Change terminal and folder during a chat. You can now choose a different terminal or working folder after sending messages, including in temporary chats. Both controls remain disabled while a reply is being generated. Commit
  • 🇧🇷 Brazilian Portuguese translations. Added missing translations for terminal and folder controls, Git actions, spreadsheet editing, voice notes, tab shortcuts, notification sounds and tool settings. Updated the explanations for document retrieval, tool permissions and voice settings. #33945

Fixed

  • 📂 Files tabs follow terminal changes. Switching a chat to another terminal now updates its open Files tabs to show that terminal's files, instead of leaving the previous terminal's folders on screen. With a terminal set to "Per chat", the Files tab also switches to the chat's own files after the first message. #33954
  • 🧭 Agents in unsupported model pickers. Connecting a terminal no longer adds its coding agents to Admin Models, base-model selectors, Arena candidates, task-model settings, group defaults, sub-agent settings, channel mentions or the Playground. Notes also stop choosing a terminal agent for title generation. Agents cannot be saved or imported as custom models or their base models, and their chat menu no longer offers Edit. Commit, Commit
  • 🔌 Agent list after switching terminals. Changing terminals immediately removes the previous terminal's agents from the chat's model list while the new list loads. A model-list request from a chat you have left can no longer replace the current list. Commit
  • 📋 Copy buttons over plain HTTP. At a plain HTTP address on your local network, copying comment links, search links, shared-chat links, webhook URLs, chat IDs, Git branch names, commit hashes and spreadsheet cells now works. Copy Formatted Text preserves formatting, and copied text keeps its final line break. #33939
  • 📝 Clipboard prompts and Auto-Copy Response over plain HTTP. Prompts using the clipboard placeholder now insert into chats and channels even when the browser blocks clipboard access, with a message explaining that the clipboard could not be read. Auto-Copy Response stays off and shows a permission message instead of silently failing to turn on; turning it off no longer requires clipboard access. #33939
  • 🧠 DeepSeek thinking mode with skills, knowledge and memories. These chats no longer fail with a missing reasoning error when the connection's Provider is set to "llama.cpp". DeepSeek thinking mode still requires that setting; connections using "Default" are unchanged. #33950
  • 🏷️ Labels on grouped tool calls. With Tool Call Labels enabled, a group of tool calls keeps the labels that are present even if one call has none. The unlabeled call shows its tool name instead of making the whole group lose its labels. #33932
  • 💬 Tool labels in later replies. The model now sees the labels it wrote for earlier tool calls when continuing a reply or answering another message, removing a reason it could stop writing labels as the conversation continued. #33953
  • 🔎 Knowledge searches containing punctuation. Searches in knowledge files now find text such as "Art. 40" when the model marks the period as literal punctuation, instead of returning no matches. #33936
  • 🪟 Side Chat with Temporary Chat disabled. Leaving Enforce Temporary Chat switched on while disabling Temporary Chat no longer prevents users from sending and saving side chats or dragging an existing chat into the side panel. #33930
  • 🏠 Home folder tab title. A Files tab at the connected machine's home directory now says "Home" instead of showing the directory name, including when reopening saved tabs. Other folders keep their names. Commit
  • 🦙 Missing Ollama in Docker images. Building the image that includes Ollama now fails if Ollama was not installed, instead of producing an image that cannot start Ollama after its download failed. #33944
  • 📄 Errors after leaving a chat. Closing or leaving a chat while its tab layout is being saved no longer fills the server log with an error report for the dropped connection. #33929
