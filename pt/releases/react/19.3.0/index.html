  • browser(): um novo react-dom API que retorna um usável que apresenta erros durante a renderização do servidor e resolve no navegador. use(browser()) dentro de um limite <Suspense> marca uma subárvore como somente navegador sem relatar um erro recuperável (@gnoff: #37143, #37241)

  • Added a DEV-only warning when a component appears to have been unblocked by calling use() conditionally (@hoxyq, @eps1lon: #37104, #37203, #37491)
