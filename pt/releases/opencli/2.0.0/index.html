OpenCLI v2.0.0

Major Publicado17 de out. de 2026 Fontejackwener/OpenCLI Original em inglês

#AbertoCLI v2.0.0 Um grande lançamento focado na experiência do agente: uma superfície CLI menor, resultados JSON previsíveis, APIs nativos do Chrome e desenvolvimento de adaptador baseado em evidências. Inclui extensão do Chrome 1.0.25.

Mudanças importantes e migração

  • As sessões do navegador são opções explícitas: use opencli browser <command> ... --session research em vez de nomes de sessão posicionais.
  • Os resultados CLI são padronizados como { "ok": true, "data": ... }; as falhas usam { "ok": false, "error": { "code", "message", "hint", ... } } e um status de saída diferente de zero. Atualizar os consumidores para lerem data; Os modos seguintes emitem linhas JSON. Formatos explícitos legíveis e exportações brutas permanecem disponíveis.
  • Use opencli adapter init, adapter test e adapter check para criação e validação do adaptador. Eles substituem os antigos pontos de entrada de inicialização/verificação do navegador e validação do adaptador.
  • Use opencli browser network --static para solicitações capturadas, além de evidências de endpoint derivadas de AST, e opencli browser state --diagnostics para diagnóstico de página. O fluxo de trabalho separado de descoberta/análise foi removido.
  • A automação do desktop Electron, seu registro de aplicativo e exportação de iniciador público, conhecimento do mapa do site e passagem externa do CLI Hub foram removidos. As conexões CDP diretas com o Chrome continuam suportadas.
  • Os contratos existentes de registro e execução do adaptador JS (cli({...}), func(args), func(page, args)) permanecem suportados. O adaptador defaultFormat não substitui mais o padrão JSON do CLI.

Recursos

  • Descoberta e chamadas nativas do Chrome API por meio de opencli browser chrome describe e chrome call, incluindo gerenciamento de guias/janelas e criação e edição de grupos de guias sem anexar uma sessão de página. Os recursos de sessão gerenciada são protegidos.
  • Descoberta de comando compacta e paginada com opencli list [query] --site --limit --offset; habilidades simplificadas do agente agrupado e criação de adaptadores.
  • Descoberta de endpoint estático baseada em AST integrada com evidências de rede capturadas, com capturas de rede incompletas retidas quando solicitadas.
  • Os pools de slots por site fornecem guias exclusivas para execuções simultâneas de adaptadores e ritmo de nível de execução; limpeza opcional da guia de propriedade e tempo limite de inatividade do navegador configurável.
  • Caixa de entrada Proton API e autenticação verificada do navegador; Comandos de comentário/exclusão de comentário Xiaohongshu e comentários do YouTube; metadados mais ricos do Twitter, YouTube e Bilibili.

Correções

  • Exclua os destinos da barra de ferramentas do navegador Chrome 155 da seleção direta de páginas do CDP para que as guias em branco permaneçam utilizáveis.
  • Uploads de arquivos/imagens ChatGPT mais confiáveis ​​e direcionamento do compositor; fluxos atuais do compositor Gemini, Grok e DeepSeek.
  • Manipulação de captcha/pesquisa/comentários Xiaohongshu, confirmação de carrinho Taobao e detecção de páginas bloqueadas, leituras XML suportadas por navegador DBLP e resolução de identificador de canal do YouTube.
  • Contenção de caminho de plug-in e vinculação de pacote host, ativação do seletor de arquivo de upload do navegador, dicas de recuperação de autenticação e tratamento estruturado de erro/código de saída.
  • Vitest atualizado para abordar GHSA-82fw-gwwq-j7x9. changelog completo: https://github.com/jackwener/OpenCLI/compare/v1.8.8...v2.0.0

Original em inglês / English original

OpenCLI v2.0.0

A major release focused on agent experience: a smaller CLI surface, predictable JSON results, native Chrome APIs, and evidence-driven adapter development. Includes Chrome extension 1.0.25.

Breaking changes and migration

  • Browser sessions are explicit options: use opencli browser <command> ... --session research instead of positional session names.
  • CLI results default to { "ok": true, "data": ... }; failures use { "ok": false, "error": { "code", "message", "hint", ... } } and a nonzero exit status. Update consumers to read data; follow modes emit JSON Lines. Explicit human-readable formats and raw exports remain available.
  • Use opencli adapter init, adapter test, and adapter check for adapter authoring and validation. These replace the former browser init/verify and adapter validation entry points.
  • Use opencli browser network --static for captured requests plus AST-derived endpoint evidence, and opencli browser state --diagnostics for page diagnostics. The separate discover/analyze workflow is removed.
  • Electron desktop automation, its app registry and public launcher export, site sitemap knowledge, and external CLI Hub passthrough are removed. Direct CDP connections to Chrome remain supported.
  • Existing JS adapter registration and execution contracts (cli({...}), func(args), func(page, args)) remain supported. Adapter defaultFormat no longer overrides the CLI's JSON default.

Features

  • Native Chrome API discovery and calls through opencli browser chrome describe and chrome call, including tab/window management and tab-group creation and editing without attaching a page session. Managed session resources are protected.
  • Compact, paginated command discovery with opencli list [query] --site --limit --offset; streamlined bundled agent skills and adapter authoring.
  • AST-based static endpoint discovery integrated with captured network evidence, with incomplete network captures retained when requested.
  • Per-site slot pools give concurrent adapter runs exclusive tabs and run-level pacing; optional owned-tab cleanup and configurable browser idle timeout.
  • Proton API inbox and verified browser authentication; Xiaohongshu comment/comment-delete and YouTube comment commands; richer Twitter, YouTube, and Bilibili metadata.

Fixes

  • Exclude Chrome 155 browser toolbar targets from direct CDP page selection so blank tabs remain usable.
  • More reliable ChatGPT file/image uploads and composer targeting; current Gemini, Grok, and DeepSeek composer flows.
  • Xiaohongshu captcha/search/comment handling, Taobao cart confirmation and blocked-page detection, DBLP browser-backed XML reads, and YouTube channel-handle resolution.
  • Plugin path containment and host-package linking, browser upload file chooser activation, auth recovery hints, and structured error/exit-code handling.
  • Updated Vitest to address GHSA-82fw-gwwq-j7x9.

Full changelog: https://github.com/jackwener/OpenCLI/compare/v1.8.8...v2.0.0
