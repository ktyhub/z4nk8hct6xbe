goose v1.60.0

✨ Features

  • SkillOperation and drop the Skills extension #13574
  • Executable commands and SlashCommandOperation in oi-kit #13533
  • Bang command operation in oi-kit #13535
  • Steering operation in oi-kit #13502
  • Dutch (nl) translation #13240
  • Cortecs declarative provider #12617
  • Onysoft declarative provider #13582
  • Reusable turn limits in GDK #13194

🐛 Bug Fixes

  • Restore AGENT and GOOSE_TERMINAL in developer shell #13598
  • Validate cron before changing existing schedules #13599
  • Keep think tags in Ollama XML tool-call arguments #13563
  • Send tool_choice auto when tools are present (OpenAI) #12716
  • Update missing and outdated zh-CN translations #13494
  • Load supporting files for skills under symlinked directories #13531
  • Bound empty response retries in oi-kit #13516
  • Drop thinking blocks bound to a different prefix (Databricks) #13551
  • Handle a closed stdout pipe when exporting a session #13385
  • Build llama.cpp without OpenSSL so goose builds with openssl 4 #13492
  • Keep request logs private on Unix #13253
  • Keep goose temporary directories private on shared systems #12868
  • Do not retry 400s that reject the thinking setting #13325
  • Send adaptive thinking to MiniMax-M3.1-Flash #13305
  • Exclude native libraries from Kotlin sources jar #13446
  • Give Gemini tool calls unique ids (Databricks) #13483
  • Use adaptive thinking for Claude Fable 5.2 (Anthropic) #13478
  • Report auto-compaction pending at the capped threshold #13476
  • Store token counts as i64 #13422
  • Refresh Vercel AI Gateway models from the API #13442
  • Finish Windows ZIP updates after the app quits #13423
  • Make final_output visible only to the model #13382
  • Surface stream errors and premature completion #13226
  • Enable tokio rt for mcp example under --all-targets #13346
  • Omit repeated advertised_tools from persisted metadata #13359
  • Report Bedrock truncation with streaming disabled #13266
  • Preserve tool-image batch ordering in persisted transcripts #13294

🔧 Improvements

  • Separate platform extensions from the MCP runtime #13568
  • Fire tool hooks from goose's own run loop #13566
  • Remove chat mode #13571
  • Move ExitOnErrorOperation to oi-kit #13500
  • Remove hook APIs from the GDK and fire hooks directly in Goose #13486
  • Prepare Goose extension configs and shared MCP types for GDK extraction #13467
  • Bump Electron to 45.2.3 and raise the macOS minimum to 13 #13455
  • Register status with state machine operations #13436
  • Declare form elicitation capability explicitly (MCP) #13428
  • Remove the goose review subcommand #13469
  • Raise MSRV to 1.95.0 for rustyline 19 #13597
  • Publish lean goose-acp as soon as it is built #13562

📚 Documentation

  • Update the EmpirioLabs AI provider (retired model id, description, catalog link) #13229
  • Fix stale agent entry point in AGENTS.md #13539
  • Document the Windows installer for goose Desktop #12942
  • Update grants page for Spiral administration #13418
