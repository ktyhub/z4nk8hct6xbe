#terraforma v1.17.0

1.17.0 (21 de outubro de 2026)

NOVOS RECURSOS:

  • Terraform agora oferece suporte a variáveis e locais nos requisitos do provedor (#39153)
  • Foi adicionada uma nova opção de planejamento -minimal-refresh, que atualizará apenas os recursos que possuem alterações propostas. (#35290)
  • política: a Política do Terraform agora está disponível para o público geral. O sinalizador -policies para plan, apply e query não requer mais uma construção experimental ou o sinalizador -allow-experimental-features. As políticas de consulta avaliam os recursos descobertos pelos blocos de lista e relatam resultados legíveis por humanos ou JSON. Consulte https://developer.hashicorp.com/terraform/policy para obter mais informações. (#38970) MELHORIAS:
  • comando/init: enriquecer mensagens de log com versões do provedor (#38918)
  • teste: Adicionar suporte mock_provider para recursos efêmeros (#38928)
  • comando/login: exibe aviso após login bem-sucedido se o usuário estiver sujeito à política TTL de uma organização CORREÇÕES DE ERROS:
  • funcs: pow e log não entram mais em pânico quando o resultado não é um número (#38912)
  • efêmero: o Terraform agora usará e exibirá diagnósticos gerados ao renovar um recurso efêmero. Isso pode fazer com que apareçam avisos que foram perdidos anteriormente. Esperamos que qualquer diagnóstico de erro perdido anteriormente tenha causado erros confusos no downstream, portanto, não prevemos que essa alteração seja interrompida. (#38989)
  • teste: ordenação de dependência determinística no gráfico de limpeza (#38247)
  • consulta: relatar resultados desconhecidos e N/A para avaliações de políticas de recursos descobertos (#39058)
  • consulta: terraform query -policies agora rejeita um caminho que não seja um diretório, em vez de passá-lo para o mecanismo de política (#39238)
  • funcs: As funções log e pow agora geram erros quando retornam +/- Infinity, pois esse resultado não pode ser usado no código downstream. (#39304)
  • show: Ler valores de variáveis do arquivo de plano ao mostrar um plano local (#39362) NOTAS:
  • versão: A saída JSON agora inclui um novo campo format_version, que permitirá alterações futuras mais seguras do formato de saída JSON do comando. Presume-se que as ferramentas existentes ignoram campos desconhecidos e, portanto, essa mudança não deve ocorrer por si só, mas aconselhamos os consumidores a prestar atenção ao format_version em versões futuras e/ou usar a versão mais recente de hashicorp/terraform-json & hashicorp/terraform-exec que faz isso. (#38930)
  • Terraform agora é construído com Go 1.26.10, que não possui mais certificados trusts emitidos por meio de um conjunto de CAs intermediários eMudhra comprometidos (CVE-2026-111943) (#39417)

terraform v1.17.0

1.17.0 (October 21, 2026)

NEW FEATURES:

  • Terraform now supports variables and locals in provider requirements (#39153)

  • A new -minimal-refresh planning option has been added, which will only refresh resources that have proposed changes. (#35290)

  • policy: Terraform Policy is now generally available. The -policies flag for plan, apply, and query no longer requires an experimental build or the -allow-experimental-features flag. Query policies evaluate resources discovered by list blocks and report human-readable or JSON results. See https://developer.hashicorp.com/terraform/policy for more information. (#38970)

ENHANCEMENTS:

  • command/init: Enrich log messages with provider versions (#38918)

  • test: Add mock_provider support for ephemeral resources (#38928)

  • command/login: display warning after successful login if user is subject to an organization's TTL policy

BUG FIXES:

  • funcs: pow and log no longer panic when result is not a number (#38912)

  • ephemeral: Terraform will now use and display diagnostics raised when renewing an ephemeral resource. This may cause warnings to appear that previously were lost. We expect that any error diagnostics that were previously lost would have caused confusing downstream errors, so we do not anticipate this change to be breaking. (#38989)

  • test: Deterministic dependency ordering in cleanup graph (#38247)

  • query: report Unknown and N/A results for policy evaluations of discovered resources (#39058)

  • query: terraform query -policies now rejects a path that is not a directory, instead of passing it on to the policy engine (#39238)

  • funcs: The log and pow functions now raise errors when they return +/- Infinity, as this result is not usable in downstream code. (#39304)

  • show: Read variable values from the plan file when showing a local plan (#39362)

NOTES:

  • version: JSON output now includes a new format_version field, which will enable safer future changes of the command's JSON output format. It is assumed existing tooling ignores unknown fields and therefore this change should not be breaking in itself but we advice consumers to pay attention to format_version in future releases and/or use latest version of hashicorp/terraform-json & hashicorp/terraform-exec which does. (#38930)

  • Terraform is now built with Go 1.26.10, which no longer trusts certificates issued through a set of compromised eMudhra intermediate CAs (CVE-2026-111943) (#39417)
