⚠️ Os carimbos de data e hora incluem milissegundos. No PostgreSQL e SQLite, os valores de data e hora nas respostas API, cargas úteis de webhook e exportações CSV agora incluem milissegundos (12:34:56.000+00:00). Verifique integrações que leem datas em formato fixo. MCP lista todas as ferramentas. O servidor MCP em /mcp agora lista todas as ferramentas. Se o Windsurf ou o VS Code Copilot mostrar muitas ferramentas, conecte-o novamente com o URL /mcp-discovery. Saiba mais Alterações de senha desconectam seus aplicativos. Alterar sua senha exclui seus tokens API e desconecta aplicativos autorizados com OAuth. Saiba mais

Melhorias

  • Aplicativos clássicos em telefones - Os aplicativos clássicos publicados cabem nas telas do telefone, incluindo a barra lateral, barras de ferramentas, formulários de registro, grupos de painéis e widgets dinâmicos.
  • Agrupar por mais tipos de campo - Grupo de páginas de aplicativos clássicos por campos de links, fórmula, pesquisa, rollup e contagem de links, e os widgets de lista obtêm um grupo por configuração. Saiba mais
  • Redimensionar colunas em aplicativos clássicos - Arraste a borda de uma coluna em um widget de Lista para redimensioná-la. Os construtores salvam a largura para todos. Saiba mais
  • Abrir registros a partir de widgets de visualização - Os widgets Calendário, Linha do tempo e Gantt em um painel podem abrir um registro quando você click nele. Saiba mais
  • Ocultar títulos de widgets - Widgets de dados, gráficos e números em um aplicativo clássico têm uma opção Mostrar título.
  • Visibilidade dos botões por função - Os botões de página em um aplicativo clássico podem ser exibidos apenas para as funções que você escolher. Saiba mais
  • Reordenar guias de filtro do usuário - Os construtores arrastam as guias de filtro do usuário para uma nova ordem. Saiba mais
  • Classificar seleção única por ordem de opção - Uma classificação em um campo Seleção única pode seguir a ordem de suas opções em vez de A a Z. Saiba mais
  • Sair de outros dispositivos - Conta > Segurança desconecta você em todos os lugares, exceto no navegador atual no NocoDB Cloud. Saiba mais
  • Modelos na página inicial - A página inicial e Novo projeto mostram uma galeria de modelos no NocoDB Cloud, e os projetos criados com IA começam com alguns registros de amostra. Saiba mais
  • Grego - NocoDB agora está disponível em grego. Saiba mais
  • Limites de taxa MCP - O MCP tem seu próprio limite por conta. Um client que passa por cima dele é informado quanto tempo deve esperar.
  • Aplicativos conectados ao MCP - A lista de aplicativos conectados mostra quando cada aplicativo foi usado pela última vez. Saiba mais
  • Tela de consentimento do OAuth - A tela de consentimento mostra para onde você será enviado e avisa quando um aplicativo não é verificado pelo NocoDB.
  • Atualizações ao vivo - Galeria, Kanban, mapa, painéis e revisão de registro de aplicativo clássico são atualizados quando os colaboradores editam.

O que foi corrigido

  • Fluxos de trabalho e webhooks - Quando o registro é atualizado fluxos de trabalho e webhooks de atualização são executados quando os registros são vinculados ou desvinculados por meio do API, colagem ou alteração de chave estrangeira. Saiba mais
  • Fórmulas - Fórmulas com ? dentro da avaliação do texto, os valores da caixa de seleção atuam como 1 e 0 nas fórmulas PostgreSQL e os resultados XOR podem ser filtrados.
  • Filtros - está em branco filtros em Rollups funcionam, e filtros semelhantes em campos de usuário correspondem apenas a nomes.
  • Links - Campos individuais autovinculados mostram o registro vinculado, e projetos duplicados mantêm seus links.
  • Copiando dados - Duplicar e importar um projeto mantém os valores de Texto Longo e JSON com mais de 100.000 caracteres.
  • Aplicativos clássicos - Pesquisa no construtor, seletores de links em formulários, rótulos de linha do tempo, nomes de páginas padrão, campos de formulário não ocultos, barras de rolagem de lista e cores de linhas condicionais se comportam conforme o esperado.
  • Compartilhamento - A caixa de diálogo Compartilhar do aplicativo clássico pode dar a um membro existente uma função mais elevada, e um segundo convite mantém o link do primeiro convite funcionando.
  • Anexos - As teclas Escape e de seta funcionam na visualização do anexo em todos os lugares em que ele é aberto.
  • Tabelas - Uma nova tabela pode receber o nome de uma tabela descartada, mesmo próximo ao limite de comprimento do nome do banco de dados.
  • SQL Server e Oracle - Classificações que repetem um trabalho de campo no SQL Server, e no Oracle um campo Número é convertido em classificação decimal e de fórmulas de texto.
  • AI chat - O chat funciona com integrações Claude Opus 5.5, Sonnet 5.5 e Fable 5.1.
  • Login - Esquecer sua senha não desconecta mais você, e erros de login mostram uma mensagem para cada caso.

Notas de auto-hospedagem

  • Primeira inscrição - Em uma nova instalação licenciada, o primeiro superadministrador obtém o espaço de trabalho e a organização padrão sem reiniciar.
  • Atualização de licença - Atualizar na página Licença, ou uma reinicialização, ativa uma licença que aparece como pendente. Saiba mais
  • Anexos seguros - Definir apenas NC_ATTACHMENT_ACCESS_CONTROL_ENABLED=true agora ativa anexos seguros, então /download e /dl param de servir arquivos. Use os URLs assinados retornados pelas respostas dos anexos. Saiba mais
  • Bancos de dados locais - ClickHouse em uma rede privada, e MySQL ou PostgreSQL em um soquete Unix, precisam de NC_ALLOW_LOCAL_EXTERNAL_DBS=true. Saiba mais
  • Tokens MCP - Os segredos do token MCP são armazenados em hash e mostrados apenas uma vez. Os tokens que já estão em seu MCP clients continuam funcionando.
  • Nomes de tabelas longos - Os novos nomes de tabelas do SQL Server e Oracle são limitados a 125 caracteres.
  • Reforço de segurança - Inscrições, convites, OAuth, visualizações compartilhadas, exportações de dados, conexões de banco de dados e segredos armazenados são reforçados e as dependências são corrigidas.

nocodb 2026.10.1

<img width="1865" height="1147" alt="Group 115" src="https://github.com/user-attachments/assets/1f72ed6f-1f2b-4f89-a033-66b572c6bd90" />

⚠️ Timestamps include milliseconds. On PostgreSQL and SQLite, date and time values in API responses, webhook payloads and CSV exports now include milliseconds (12:34:56.000+00:00). Check integrations that read dates in a fixed format.

MCP lists every tool. The MCP server at /mcp now lists every tool. If Windsurf or VS Code Copilot shows too many tools, connect it again with the /mcp-discovery URL. Learn more

Password changes sign out your apps. Changing your password deletes your API tokens and disconnects apps you authorized with OAuth. Learn more

Improvements

  • Classic apps on phones - Published classic apps fit phone screens, including the sidebar, toolbars, record forms, dashboard groups and pivot widgets.
  • Group by more field types - Classic app pages group by Links, Formula, Lookup, Rollup and link count fields, and List widgets get a group by setting. Learn more
  • Resize columns in classic apps - Drag a column edge in a List widget to resize it. Builders save the width for everyone. Learn more
  • Open records from view widgets - Calendar, Timeline and Gantt widgets on a dashboard can open a record when you click it. Learn more
  • Hide widget titles - Data, chart and number widgets in a classic app have a Show title switch.
  • Button visibility by role - Page buttons in a classic app can show only to the roles you choose. Learn more
  • Reorder user filter tabs - Builders drag user filter tabs into a new order. Learn more
  • Sort Single Select by option order - A sort on a Single Select field can follow the order of its options instead of A to Z. Learn more
  • Sign out of other devices - Account > Security signs you out everywhere except the current browser on NocoDB Cloud. Learn more
  • Templates on Home - Home and the New project page show a template gallery on NocoDB Cloud, and projects built with AI start with a few sample records. Learn more
  • Greek - NocoDB is now available in Greek. Learn more
  • MCP rate limits - MCP has its own limit per account. A client that goes over it is told how long to wait.
  • MCP connected apps - The list of connected apps shows when each app was last used. Learn more
  • OAuth consent screen - The consent screen shows where you will be sent and warns when an app is not verified by NocoDB.
  • Live updates - Gallery, Kanban, Map, dashboards and classic app record review refresh in place when collaborators edit.

What's Fixed

  • Workflows and webhooks - When record updated workflows and update webhooks run when records are linked or unlinked through the API, paste or a foreign key change. Learn more
  • Formulas - Formulas with ? inside text evaluate, Checkbox values act as 1 and 0 in PostgreSQL formulas, and XOR results can be filtered.
  • Filters - is blank filters on Rollups work, and like filters on User fields match names only.
  • Links - Self-linking one-to-one fields show the linked record, and duplicated projects keep their links.
  • Copying data - Duplicating and importing a project keeps Long Text and JSON values longer than 100,000 characters.
  • Classic apps - Search in the builder, link pickers in forms, Timeline labels, default page names, unhidden form fields, list scrollbars and conditional row colors behave as expected.
  • Sharing - The classic app Share dialog can give an existing member a higher role, and a second invite keeps the first invite link working.
  • Attachments - Escape and arrow keys work in the attachment preview everywhere it opens.
  • Tables - A new table can take a trashed table's name, even near the database name length limit.
  • SQL Server and Oracle - Sorts that repeat a field work on SQL Server, and on Oracle a Number field converts to Decimal and text formulas sort.
  • AI chat - Chat works with Claude Opus 5.5, Sonnet 5.5 and Fable 5.1 integrations.
  • Sign-in - Forgetting your password no longer signs you out, and sign-in errors show one message for every case.

Self-Hosting Notes

  • First sign-up - On a new licensed install, the first super admin gets the default workspace and organization without a restart.
  • License refresh - Refresh on the License page, or a restart, activates a license that shows as pending. Learn more
  • Secure attachments - Setting only NC_ATTACHMENT_ACCESS_CONTROL_ENABLED=true now turns on secure attachments, so /download and /dl stop serving files. Use the signed URLs that attachment responses return. Learn more
  • Local databases - ClickHouse on a private network, and MySQL or PostgreSQL over a Unix socket, need NC_ALLOW_LOCAL_EXTERNAL_DBS=true. Learn more
  • MCP tokens - MCP token secrets are stored hashed and shown only once. Tokens already in your MCP clients keep working.
  • Long table names - New SQL Server and Oracle table names are limited to 125 characters.
  • Security hardening - Sign-up, invitations, OAuth, shared views, data exports, database connections and stored secrets are hardened, and dependencies are patched.

For more details on the features introduced in 2026.10.0, see the 2026.10.0 changelog.
