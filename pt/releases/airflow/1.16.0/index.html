airflow helm-chart/1.16.0

Highlights

  • Airflow 3 is now the default architecture — The chart defaults to Airflow 2.10.5 (up from 2.9.3) and FabAuthManager (#46624, #47976). Airflow 3 deployments run a standalone DAG processor and API server, while Airflow 2 keeps the webserver (#45659, #47085); validate your airflowVersion, auth manager, and component topology before upgrading.
  • The public API moves to /api/v2 and port 8080 — AIP-84 relocates the public API under /api/v2, and the API server moves to port 8080 (#47760, #47310). Update ingress rules, service probes, health checks, and clients; the CLI command also changes from fastapi-api to api-server (#47076).
  • Multi-executor support is operationalized — The chart supports multiple executors, with executor-specific scheduler and role-binding fixes (#43606, #44424, #46039, #46486). Executor metric names and role bindings have changed to avoid collisions (#40778), so review custom RBAC, scheduler configuration, and Prometheus queries.
  • Infrastructure defaults receive substantial version bumps — git-sync rises to 4.3.0, PgBouncer to 1.23.1, PgBouncer Exporter to 0.18.0, and StatsD Exporter to 0.28.0 (#41411, #47416, #43393). These defaults affect repository synchronization, connection pooling, and metrics behavior even if your Airflow image is pinned.
  • More deployment-level controls are available — New options cover webserver HPA (#41955), Redis NodePort (#41811), existing Redis PVCs (#41619), worker extraPorts and podManagementPolicy (#46679, #42673), migration-job environment variables (#42345), and log-groomer sidecars and frequency (#46003, #46237).
  • Configuration and observability fixes need explicit review — The triggerer option default_capacity is renamed to capacity (#48032), execution_api_server_url moves into the core section (#46969), and new ti.running and DAG-processor heartbeat metrics improve task visibility (#47773, #42398). Review values overrides and alerting dashboards for renamed or relocated settings.

No breaking changes are explicitly identified in the upstream changelog.

The default PgBouncer image that is used with the chart is now airflow-pgbouncer-2025.03.05-1.23.1, previously it was airflow-pgbouncer-2024.01.19-1.21.0.

Default PgBouncer Exporter image is updated to v0.18.0 (#47416)

The default PgBouncer Exporter image that is used with the chart is now airflow-pgbouncer-exporter-2025.03.05-0.18.0, previously it was airflow-pgbouncer-exporter-2024.06.18-0.17.0.

Default StatsD exporter image is updated to v0.28.0 (#43393)

The default StatsD exporter image that is used with the chart is now v0.28.0, previously it was v0.26.1.
