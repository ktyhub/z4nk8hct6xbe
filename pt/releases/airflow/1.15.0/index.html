airflow helm-chart/1.15.0

Highlights

  • Base image bump to 2.9.3 — The chart's default Airflow image moves from 2.9.2 to 2.9.3 (#40816). If you deploy with chart defaults rather than an explicit tag, your scheduler/workers/triggerer silently pick up the new patch on helm upgrade; pin the tag if you need reproducible environments. Low risk as a patch bump, but validate custom operators and provider versions against 2.9.3 before rolling out.
  • PgBouncer exporter security refresh — The exporter advances to airflow-pgbouncer-exporter-2024.06.18-0.17.0 (#40318, also listed under Misc) to remediate CVE-2024-24786. Treat this as a security upgrade if you run PgBouncer with metrics enabled, and check whether you override the exporter image — an explicit pin will keep the vulnerable version in place.
  • Git-sync configuration gets first-class support — The SSH private key can now be set directly via dags.gitSync.sshKey (#39936), extraEnvFrom lets you pull git-sync env from secrets/configmaps (#39031), and lifecycle hooks give control over startup/shutdown ordering (#40369). The companion fix wiring the SSH secret into the DAG processor (#40691) is the one to watch if you run a standalone DAG processor — that path previously risked incomplete credentials. Keys placed in values end up in the release secret, so teams using externally managed keys should keep the existing secret workflow.
  • PVC retention and job init containers — A persistent volume claim retention policy (#40271) and init containers for jobs (#40454) are the most operationally meaningful additions: retention controls whether claim data survives uninstall/upgrade, which matters for stateful components and for avoiding accidental data loss in ephemeral clusters, while init containers enable secret seeding or pre-flight checks before jobs run.
  • GitOps-oriented knobs and quiet fixes — extraConfigMaps/extraSecrets can now skip Helm hooks (#40294), useful when a GitOps controller owns apply ordering; Redis StatefulSet accepts annotations (#40281) and duplicate safeToEvict annotations are cleaned up (#40554). Two config-level fixes are worth verifying if they touch you: triggerer.keda.usePgbouncer was absent from values.yaml (#40614), so KEDA+triggerer+PgBouncer setups should confirm the value now takes effect, and the MySQL backend trims a leading // (#40401).
  • Breaking changes — None in this release.

Significant Changes

Default Airflow image is updated to 2.9.3 (#40816)

The default Airflow image that is used with the Chart is now 2.9.3, previously it was 2.9.2.

Default PgBouncer Exporter image has been updated (#40318)

The PgBouncer Exporter image has been updated to airflow-pgbouncer-exporter-2024.06.18-0.17.0, which addresses CVE-2024-24786.

New Features

  • Add git-sync container lifecycle hooks (#40369)
  • Add init containers for jobs (#40454)
  • Add persistent volume claim retention policy (#40271)
  • Add annotations for Redis StatefulSet (#40281)
  • Add dags.gitSync.sshKey, which allows the git-sync private key to be configured in the values file directly (#39936)
  • Add extraEnvFrom to git-sync containers (#39031)

Improvements

  • Link in UIAlert to production guide when a dynamic webserver secret is used now opens in a new tab (#40635)
  • Support disabling helm hooks on extraConfigMaps and extraSecrets (#40294)

Bug Fixes

  • Add git-sync ssh secret to DAG processor (#40691)
  • Fix duplicated safeToEvict annotations (#40554)
  • Add missing triggerer.keda.usePgbouncer to values.yaml (#40614)
  • Trim leading // character using mysql backend (#40401)

Doc only changes

  • Updating chart download link to use the Apache download CDN (#40618)

Misc

  • Update PgBouncer exporter image to airflow-pgbouncer-exporter-2024.06.18-0.17.0 (#40318)
  • Default airflow version to 2.9.3 (#40816)
  • Fix startupProbe timing comment (#40412)
