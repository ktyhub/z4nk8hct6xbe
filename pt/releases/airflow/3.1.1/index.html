airflow 3.1.1

Highlights

  • Upgrade blockers removed — Fixes address NULL dag_run.conf from older deployments (#56729), Pydantic 2.12 migration failures (#56581), and scheduler crashes during 3.0→3.1 migration when retry_delay is None (#56236). After upgrading, smoke-test scheduling and notifications before rolling broadly.

  • More reliable retries and dynamic tasks — Deferred tasks now retry the correct method (#56737), externally terminated tasks again invoke retry callbacks (#56607), and MappedOperator gains correct retry_delay handling plus max_retry_delay support (#56605, #56951). Zero-length mapped inputs are accepted on rerun (#56162), avoiding failures when upstream filtering removes all work.

  • Backfill and task-control corrections — airflow dags backfill --dag_run_conf now parses JSON correctly (#56599), manual runs invoke a custom timetable’s generate_run_id (#56699), and the task-clear API accepts map indexes (#56945). These changes make automated backfill, custom run naming, and mapped-task recovery behave predictably.

  • Operational stability and performance — Fixes include scheduler crashes with email notifications (#56431), remote-logging cache memory growth (#56695), and DAG processor crashes with pre-import optimization (#56779). Grid queries and topological sorting are also improved (#56937, #56938, #56963), benefiting large DAGs and long-running deployments.

  • Execution API and UI improvements — Execution API requests gain a configurable timeout (#56969). The UI adds task display-name support, richer Task Instance columns, and ANSI log rendering (#56511, #56410, #55922, #56721). Gantt is now disabled by default (#56242), so users relying on it must re-enable the view.

  • Compatibility watch-outs — The dagReports API endpoint is removed (#56621), sla_miss_callback now emits a deprecation warning (#56127), and backend JWT handling is updated (#56677). Migrate any dagReports consumers, plan to replace the deprecated SLA callback, and regression-test custom authentication integrations.
