airflow 2.9.3

Highlights

  • Duration metrics switch to milliseconds — scheduled_duration and queued_duration are now emitted in milliseconds rather than seconds (#37936). This aligns with the statsd convention expected by the Prometheus statsd-exporter, but it's a silent 1000× shift: rescale any dashboards, alerts, or PromQL queries keyed on these metrics before upgrading, or you'll misinterpret scheduling latency.

  • OpenTelemetry metrics graduate to stable — After landing as experimental in 2.7.0 and accumulating fixes, OTel metrics support is officially declared production-ready (#40286). Teams that held off because of the "experimental" label can now adopt it without that caveat; no migration step is required for existing users beyond dropping any experimental-gating assumptions.

  • Jinja rendering disabled for doc_md — DAG documentation strings are no longer passed through the Jinja templating engine (#40522). This closes a template-injection surface but is a visible behavior change: DAGs whose doc_md relied on templated values will now render those expressions literally, so audit any generated docs.

  • Scheduler and ORM reliability fixes — #40563 corrects a bug in SchedulerJobRunner._process_executor_events, #40345 restores DAG pause/unpause on deployments where DAG files are missing, and #40314 fixes compatibility with older MySQL 8.0 while #40391 stops an Extra value leaking into SQLAlchemy. Collectively these reduce scheduler exceptions and prevent state corruption on edge-case backends — worth taking note of if you run a mixed or legacy MySQL environment.

  • Deprecation signals to plan around — The docs now warn that PostgresOperator is deprecated (#40662), [webserver]update_fab_perms joins the deprecated-config list (#40317), and the deprecated API docs explicitly note that access control is not applied (#40129). Don't build new integrations on those APIs/operator; treat the access-control note as a security caveat for anything still calling the legacy API.

  • Operational guidance worth reading — New docs cover passing secrets via environment variables (#40519) and clarify that serializers do not support bytes (#40597). If you serialize DAG state or inject credentials at runtime, these two notes will save you debugging time — especially the bytes limitation, which is easy to trip over in custom serializers.

Significant Changes

Time unit for scheduled_duration and queued_duration changed (#37936)

scheduled_duration and queued_duration metrics are now emitted in milliseconds instead of seconds.

By convention all statsd metrics should be emitted in milliseconds, this is later expected in e.g. prometheus statsd-exporter.

Support for OpenTelemetry Metrics is no longer "Experimental" (#40286)

Experimental support for OpenTelemetry was added in 2.7.0 since then fixes and improvements were added and now we announce the feature as stable.
