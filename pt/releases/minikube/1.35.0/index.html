#minikube v1.35.0

📣😀 Por favor, preencha nossa pesquisa rápida de 5 perguntas para que possamos saber como e por que você usa o minikube e quais melhorias devemos fazer. Obrigado! 💃🎉

#Release Notes

Versão 1.35.0 - 15/01/2025

Recursos:

  • Adicione suporte para GPUs AMD via --gpus=amd #19749
  • Use ativos Github como novo failover para imagem base kic #19464
  • Suporte mais recente Kubernetes v1.32.0 #20091
  • Adiciona suporte para kubeadm.k8s.io/v1beta4 (disponível desde k8s v1.31) #19790

Melhorias:

  • Mesclar nvidia-gpu-device-plugin e nvidia-device-plugin. #19545
  • kicbase: Atualizar pacotes nvidia #19738
  • cílio: remova appArmorProfile para k8s<v1.30.0 #19888
  • pausa automática: reinicie o serviço após a configuração #19900
  • Reverter "Alterar lógica MINIKUBE_HOME" #20045
  • não polua a lista de perfis do minikube com erros se o código de saída estiver ausente #19728
  • consulta unificada de status do cluster minikube #18998
  • Driver Vfkit: corrige falha de TestMachineType no macOS #19726
  • Não há mais restrições de arco no nerdctld #19730
  • Correspondência de endereço MAC mais robusta #19750
  • Adicione instruções para resolver o erro de contexto docker #19197

Correções de bugs:

  • corrigir a falha de --wait em funcionar em pods coredns #19748
  • Corrija o pânico quando não houver serviços no namespace com --all especificado #19957
  • correção do tempo limite ao parar a máquina KVM com tempo de execução do contêiner CRI-O #19758
  • Correção de linhas longas em lastStart.txt que não são exibidas nas saídas de log #19740
  • Correção da detecção incorreta do arco kicbase como incorreto #19664

Quebrando mudanças:

minikube v1.35.0

📣😀 Please fill out our fast 5-question survey so that we can learn how & why you use minikube, and what improvements we should make. Thank you! 💃🎉

Release Notes

Version 1.35.0 - 2025-01-15

Features:

  • Add support for AMD GPUs via --gpus=amd #19749
  • Use Github Assets as New fail over for kic base image #19464
  • Support latest Kubernetes v1.32.0 #20091
  • Adds support for kubeadm.k8s.io/v1beta4 (available since k8s v1.31) #19790

Improvements:

  • Merge nvidia-gpu-device-plugin and nvidia-device-plugin. #19545
  • kicbase: Update nvidia packages #19738
  • cilium: remove appArmorProfile for k8s<v1.30.0 #19888
  • auto-pause: restart service after configuration #19900
  • Revert "Change MINIKUBE_HOME logic" #20045
  • don't pollute minikube profile list with errors if exitcode is absent #19728
  • unified minikube cluster status query #18998
  • Vfkit driver: fix TestMachineType failing on macOS #19726
  • No more arch restriction on nerdctld #19730
  • More robust MAC address matching #19750
  • Add instructions to resolve docker context error #19197

Bug fixes:

  • fix --wait's failure to work on coredns pods #19748
  • Fix panic when no services in namespace with --all specified #19957
  • fix timeout when stopping KVM machine with CRI-O container runtime #19758
  • Fix long lines in lastStart.txt not outputting in log outputs #19740
  • Fix wrongly detecting kicbase arch as incorrect #19664

Breaking Changes:

  • remove arm64 kvm #19985 #20062
  • remove helm-tiller addon #19636

Languages:

  • Add more Chinese translations #19490 #19508 #19718 #19962 #19772
  • Improve french translation #19654 #19978
