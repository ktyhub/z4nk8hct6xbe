#orca v1.4.237

100.000 estrelas. Obrigado! ⭐🐳

Orca acabou de cruzar 100.000 estrelas em GitHub! Cada relatório de bug, solicitação pull, fluxo de trabalho compartilhado e recomendação nos ajudaram a chegar aqui. Obrigado por construir com a Orca e ajudar a moldar o que vem a seguir. ❤️ Para comemorar, esta versão traz uma experiência telefônica mais eficiente, conversas com agentes mais confiáveis e correções que mantêm seu trabalho em andamento entre desktops e máquinas remotas.

A versão curta

  • Mais coisas feitas no seu telefone: Crie e edite notas, salve Markdown em hosts sem cabeça, siga links de arquivos relativos e veja imagens incorporadas. Os rascunhos de terminal em buffer agora também podem sobreviver à navegação no espaço de trabalho.
  • Bate-papos aos quais você pode voltar: Os bate-papos do Codex reabrem corretamente após desfazer, Claude mantém seu contexto rebobinado nas reversões do Orca e as capturas de tela permanecem com a conversa. O seletor de habilidades do Codex agora reflete as habilidades que o Codex realmente carregou.
  • Seu trabalho permanece protegido: Descartar pausa o salvamento automático do mesmo arquivo nos espaços de trabalho. As visualizações Markdown e CSV somente leitura protegem suas edições não salvas, e novos documentos Markdown não preparados são abertos diretamente no editor avançado.
  • Voz além da área de trabalho: O ditado do telefone funciona novamente por meio de hosts orca serve sem cabeça, com um comando CLI para configurar a chave OpenAI do host.
  • Trabalho remoto mais suave: Reconecte as guias ocultas do terminal após uma reinicialização, mantenha os logins do navegador quando os hosts emparelharem novamente e pesquise configurações SSH com milhares de hosts sem congelar a interface.
  • Pequenos detalhes, melhor fluxo: As guias do telefone seguem a ordem da área de trabalho, os layouts em paisagem mostram o título da sessão, os controles do teclado mantêm sua altura e as varreduras de segurança da árvore de trabalho ignoram os espaços de trabalho inalterados. Atualizações do telefone: Atualizar o Orca no computador que atende seu telefone também atualiza a interface servida do telefone. Rascunhos de terminal persistentes também exigem um shell móvel atualizado.

Notas de compatibilidade e atualização

  • Bate-papo nativo (experimental): Atualize hosts SSH e emparelhados junto com o Orca para obter as correções de bate-papo mais recentes. A seleção exata de arquivos de habilidade do Codex está disponível no desktop com um host de suporte; seleções de telefone e hosts mais antigos mantêm nomes de habilidades em texto simples. Envie uma habilidade como uma nova mensagem para o Codex aplicá-la no início de um turno.
  • Ditado sem cabeça: Salve a chave OpenAI no host fazendo a transcrição com orca speech openai-key set (lê a chave do stdin). Os hosts orca serve de aplicativos instalados no Linux e macOS também podem usar o reconhecedor incluído no dispositivo; Servidores Windows, SSH gerenciados e WSL usam modelos de nuvem.
  • Escolha de inicialização do CLI: As opções explícitas do --surface requerem um host de execução atualizado. A omissão da opção mantém os padrões existentes.

Orca just crossed 100,000 stars on GitHub! Every bug report, pull request, shared workflow and recommendation has helped us get here. Thank you for building with Orca and helping shape what comes next. ❤️

To celebrate, this release brings a more capable phone experience, more dependable agent conversations, and fixes that keep your work moving across desktops and remote machines.

The short version

  • More done from your phone: Create and edit notes, save Markdown on headless hosts, follow relative file links, and see embedded images. Buffered terminal drafts can now survive workspace navigation, too.
  • Chats you can come back to: Codex chats reopen correctly after undo, Claude keeps its rewound context across Orca rollbacks, and screenshots stay with the conversation. Codex’s skill picker now reflects the skills Codex actually loaded.
  • Your work stays protected: Discard pauses autosave of the same file across workspaces. Read-only Markdown and CSV views protect your unsaved edits, and new, unstaged Markdown documents open straight into the rich editor.
  • Voice beyond the desktop: Phone dictation works again through headless orca serve hosts, with a CLI command to configure the host’s OpenAI key.
  • Smoother remote work: Reconnect hidden terminal tabs after a restart, keep browser logins when hosts pair again, and search SSH configurations with thousands of hosts without freezing the interface.
  • Small details, better flow: Phone tabs follow desktop order, landscape layouts show the session title, keyboard controls keep their height, and worktree safety sweeps skip unchanged workspaces.

Phone updates: Updating Orca on the computer serving your phone also updates the phone’s served interface. Persistent terminal drafts additionally require an updated mobile shell.

Compatibility & upgrade notes

  • Native chat (experimental): Update paired and SSH hosts alongside Orca to get the latest chat fixes. Exact Codex skill-file selection is available on desktop with a supporting host; phone selections and older hosts retain plain-text skill names. Send a skill as a new message for Codex to apply it at the start of a turn.
  • Headless dictation: Save the OpenAI key on the host doing the transcription with orca speech openai-key set (reads the key from stdin). Installed-app orca serve hosts on Linux and macOS can also use the bundled on-device recognizer; Windows, managed SSH and WSL servers use cloud models.
  • CLI launch choice: Explicit --surface choices require an updated execution host. Omitting the option keeps your existing defaults.
