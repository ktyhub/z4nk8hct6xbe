#orca v1.4.254

Git Graph, ditado no telefone e perguntas paralelas no chat ✨

  • 🌳 Veja todo o repositório: Uma nova aba do Git Graph mostra ramificações e tags locais e remotas, com detalhes de cada commit e arquivos alterados. Os espaços de trabalho de pasta agora recebem Controle de Origem, com um cartão para cada repositório anexado, e o nome da ramificação no Controle de Origem alterna ou cria uma ramificação no local.
  • 💬 Pergunte sem atrapalhar o bate-papo: Na interface do bate-papo, /btw faz uma pergunta paralela em uma bifurcação ao lado do bate-papo enquanto o original continua em execução e /fork ramifica a partir da resposta mais recente. Os chats que abrem ou enviam para uma solicitação pull mostram uma linha curta quando seu CI é aprovado ou falha.
  • 🎙️ Dite de qualquer lugar: Os telefones podem transformar fala em texto no dispositivo (iPhone no iOS 26 ou posterior e Android), com o computador como alternativa. O computador, os telefones e a web client podem ditar ao mesmo tempo, e o ditado no dispositivo é executado em seu próprio processo, de modo que uma falha ou travamento do mecanismo de fala não desativa mais o Orca.
  • 📱 Um telefone que mantém seu trabalho: O chat envia fila enquanto a área de trabalho está inacessível e sai em ordem quando volta. Rascunhos de bate-papo, anexos, edições de arquivos não salvos e rascunhos de automação sobrevivem ao encerramento do aplicativo e as telas reabrem a partir do que o telefone já possui.
  • ⌨️ Não há mais atraso de digitação nas contas do Codex: A digitação pode atrasar no Orca enquanto vincula o histórico do Codex entre as contas. Esse trabalho não bloqueia mais o aplicativo. Os terminais remotos também enviam um único toque de tecla imediatamente e leem a saída compactada de hosts remotos.
  • 🔐 Emparelhamento mais seguro e trust: Um código de emparelhamento para de funcionar quando o dispositivo que o utilizou salva seu próprio login, as conexões de desktop e CLI com servidores remotos usam a criptografia mais recente e o orca serve recusa conexões de endereços públicos da Internet, a menos que haja um motivo para permitir. Orca pergunta uma vez por novo repo antes de trustá-lo para os agentes.
  • 🎨 Torne o Orca seu: Importe o ícone do seu próprio aplicativo, deixe os plug-ins de tema reproduzirem um vídeo de fundo em loop e enviem suas próprias fontes e leia as Configurações nos cartões intitulados. Claude Code pode combinar com o tema do seu terminal Orca se você disser sim.
  • 🤖 Melhor suporte do agente: Os bate-papos antigravidade podem ser executados no próprio host do anfitrião, incluindo bate-papos com acesso total, e o Muse mostra sua cota de assinatura na barra de status.

Destaques

  • Bate-papo: /btw faz uma pergunta paralela em uma bifurcação e /fork bifurca a partir da resposta mais recente, com um botão giratório enquanto a bifurcação abre. Os bate-papos mostram resultados de CI para as solicitações pull que eles abriram ou enviaram, e cada mensagem, comando e direção em espera agora fica em uma fila ordenada da qual você pode mover, excluir ou enviar.
  • Telefone: Envie enquanto a área de trabalho estiver off-line, mantenha rascunhos, anexos, edições de arquivos e rascunhos de automação em eliminações de aplicativos e veja a lista de espaços de trabalho, guias de sessão e Revisão da memória enquanto eles são atualizados. Pastas grandes carregam 500 entradas por vez com Pesquisar tudo, Revisão pré-busca o arquivo seguinte e anterior e uma linha fina abaixo do cabeçalho mostra quando os dados em cache estão sendo atualizados.
  • Ditado: Os telefones podem transcrever no dispositivo e todos os dispositivos podem ditar de uma só vez. No desktop, o modelo de fala é carregado antes do seu primeiro ditado (uma nova configuração escolhe quando descarregá-lo), o ditado para após um minuto de silêncio e mantém o que você disse, o texto ditado recebe um espaço antes dele e o texto que não pode ser inserido é copiado. A web emparelhada client pode ditar através do host.
  • Controle de origem e editor: Git Graph, controle de origem para espaços de trabalho de pasta e um seletor de ramificação no local no cabeçalho do controle de origem. Arquivos totalmente novos e excluídos mostram uma tonalidade limpa, Markdown mantém suas cores de sintaxe sob temas de plugins, visualizações HTML abertas no próprio grupo de guias do editor e Copiar como PNG diz quando uma imagem é muito grande em vez de reivindicá-la copiada.
  • Agentes e contas: O atraso na digitação do histórico da conta do Codex foi corrigido. Os bate-papos antigravidade podem ser executados no host do host quando ele está conectado, as sessões antigravidade no AI Vault podem revelar sua pasta de artefatos e o Muse mostra sua cota e mantém os painéis funcionando enquanto os subagentes em segundo plano são executados. O menu de inicialização da nova guia é mais simples, o seletor de agentes encontra modelos em seus submenus e, após reiniciar, os agentes são instruídos a concluir a tarefa original.
  • Hosts remotos: Os terminais remotos respondem às teclas digitadas mais rapidamente, os bate-papos na área de trabalho em hosts remotos transmitem apenas o novo texto e a pesquisa fica mais lenta enquanto a janela do Orca está visível, mas não focada. Os servidores SSH gerenciados se recuperam após um login lento do ProxyCommand e em mais casos de servidores mortos, e as automações para um host SSH gerenciado vão para seu próprio servidor Orca.
  • Aparência: importe um ícone de aplicativo personalizado, use menus temáticos e controles segmentados mais claros e use fontes da web e vídeos de fundo em loop de plug-ins. Os plug-ins de tema também podem estilizar o texto e a seleção do bate-papo, que agora são mais fáceis de ler no modo escuro. As guias de arquivos e do navegador se ajustam aos seus títulos, portanto, cabem mais antes que a faixa de guias seja rolada.

Notas de compatibilidade e atualização

  • Correspondência de tema do Claude Code: O Orca agora pode combinar o tema do Claude Code com o tema do seu terminal Orca. Está desativado para todos, incluindo novos perfis. Na próxima vez que Claude Code for executado, Orca pergunta uma vez em um brinde. Nada no ~/.claude/settings.json muda a menos que você aceite, e você pode alterar isso mais tarde em Configurações › Aparência › Terminal.
  • Atalho de pesquisa: Novos perfis do Mac abrem a pesquisa com Cmd+K e não possuem atalho padrão para limpar o terminal. Novos perfis do Windows e Linux usam Ctrl+K. Os perfis existentes mantêm seus atalhos, inclusive os personalizados e os desativados.
  • Pasta do agente trust: Na primeira vez que você inicia um agente em um novo repositório, o Orca pergunta se deve trust o repositório ou deixar que cada agente pergunte por si mesmo. Os repositórios que você já usa continuam funcionando como antes, sem aviso prévio. Você pode alterar a resposta nas configurações do repositório.
  • Códigos de emparelhamento de uso único: Quando um telefone, navegador ou Orca atualizado é emparelhado com um desktop atualizado, ele muda para seu próprio login e o código QR ou link usado para de funcionar. Os dispositivos em apps mais antigos continuam funcionando, e as Configurações marcam os dispositivos que ainda usam o código de pareamento original ou a criptografia mais antiga para que você saiba quais atualizar.
  • orca serve e endereços públicos: orca serve aceita conexões localhost, LAN e Tailscale por padrão e aceita endereços públicos da Internet somente quando houver um motivo para isso. As configurações existentes continuam conectadas.
  • Memória do modelo de fala: Com a voz ativada, o Orca agora carrega o modelo de fala no dispositivo antes do seu primeiro ditado. Use a nova configuração Descarregar modelo de fala em Configurações › Voz para liberar essa memória mais rapidamente. O ditado na área de trabalho agora também para sozinho após um minuto de silêncio.
  • Peso da fonte do terminal do Windows: O texto do terminal no Windows agora usa o peso Regular da fonte por padrão em vez de Médio, que o Windows desenhou como SemiBold. macOS e Linux permanecem inalterados.
  • Menu de inicialização da nova guia: Permissões e Argumentos não estão mais no menu de inicialização do agente da nova guia. Eles ainda vêm das configurações do Agente.
  • Integração: O botão Instalação de antigravidade na integração desapareceu. O Antigravity tem o mesmo link de instruções de instalação que qualquer outro agente.

orca v1.4.254

Git Graph, on-phone dictation & side questions in chat ✨

  • 🌳 See the whole repository: A new Git Graph tab shows local and remote branches and tags, with each commit's details and changed files. Folder workspaces now get Source Control, with a card for each attached repo, and the branch name in Source Control switches or creates a branch in place.
  • 💬 Ask without derailing a chat: In Chat UI, /btw asks a side question in a fork beside the chat while the original keeps running, and /fork branches from the latest response. Chats that open or push to a pull request show a short line when its CI passes or fails.
  • 🎙️ Dictate from anywhere: Phones can turn speech into text on the device (iPhone on iOS 26 or later, and Android), with the computer as fallback. The computer, phones and web client can dictate at the same time, and on-device dictation runs in its own process, so a speech engine crash or hang no longer takes Orca down.
  • 📱 A phone that holds on to your work: Chat sends queue while the desktop is unreachable and go out in order when it's back. Chat drafts, attachments, unsaved file edits and automation drafts survive the app being killed, and screens reopen from what the phone already has.
  • ⌨️ No more typing lag from Codex accounts: Typing could lag across Orca while it linked Codex history between accounts. That work no longer blocks the app. Remote terminals also send a lone keystroke right away and read compressed output from remote hosts.
  • 🔐 Safer pairing and trust: A pairing code stops working once the device that used it saves its own sign-in, desktop and CLI connections to remote servers use the newer encryption, and orca serve refuses connections from public internet addresses unless there's a reason to allow them. Orca asks once per new repo before trusting it for agents.
  • 🎨 Make Orca yours: Import your own app icon, let theme plugins play a looping background video and ship their own fonts, and read Settings in titled cards. Claude Code can match your Orca terminal theme if you say yes.
  • 🤖 Better agent support: Antigravity chats can run on the host's own agy, including Full access chats, and Muse shows its subscription quota in the status bar.

Highlights

  • Chat: /btw asks a side question in a fork and /fork forks from the latest response, with a spinner while the fork opens. Chats show CI results for the pull requests they opened or pushed to, and every waiting message, command and steer now sits in one ordered queue you can move, delete or send from.
  • Phone: Send while the desktop is offline, keep drafts, attachments, file edits and automation drafts across app kills, and see the workspace list, session tabs and Review from memory while they refresh. Large folders load 500 entries at a time with Search all, Review prefetches the next and previous file, and a thin line under the header shows when cached data is refreshing.
  • Dictation: Phones can transcribe on the device, and every device can dictate at once. On desktop the speech model loads before your first dictation (a new setting chooses when to unload it), dictation stops after a minute of silence and keeps what you said, dictated text gets a space before it, and text that can't be inserted is copied instead. The paired web client can dictate through the host.
  • Source control & editor: Git Graph, Source Control for folder workspaces, and an in-place branch picker in the Source Control header. Wholly new and deleted files show one clean tint, Markdown keeps its syntax colors under plugin themes, HTML previews open in the editor's own tab group, and Copy as PNG says when an image is too large instead of claiming it copied.
  • Agents & accounts: The Codex account-history typing lag is fixed. Antigravity chats can run on the host's agy when it's signed in, Antigravity sessions in AI Vault can reveal their artifacts folder, and Muse shows its quota and keeps panes working while background subagents run. The new-tab launch menu is simpler, the agent picker finds models from its submenus, and after a restart agents are told to finish the original task.
  • Remote hosts: Remote terminals respond to keystrokes sooner, desktop chats on remote hosts stream only the new text, and polling slows down while the Orca window is visible but not focused. Managed SSH servers recover after a slow ProxyCommand login and in more dead-server cases, and automations for a managed SSH host go to its own Orca server.
  • Look & feel: Import a custom app icon, use themed menus and clearer segmented controls, and use web fonts and looping background videos from plugins. Theme plugins can also style chat text and selection, which is now easier to read in dark mode. File and browser tabs fit their titles, so more fit before the tab strip scrolls.

Compatibility & upgrade notes

  • Claude Code theme matching: Orca can now match Claude Code's theme to your Orca terminal theme. It is off for everyone, including new profiles. The next time Claude Code runs, Orca asks once in a toast. Nothing in ~/.claude/settings.json changes unless you accept, and you can change it later in Settings › Appearance › Terminal.
  • Search shortcut: New Mac profiles open search with Cmd+K and have no default shortcut for clearing the terminal. New Windows and Linux profiles use Ctrl+K. Existing profiles keep their shortcuts, including custom and disabled ones.
  • Agent folder trust: The first time you start an agent in a new repo, Orca asks whether to trust the repo or let each agent ask for itself. Repos you already use keep working as before, with no prompt. You can change the answer in the repo's settings.
  • Single-use pairing codes: When an updated phone, browser or Orca pairs with an updated desktop, it switches to its own sign-in and the QR code or link it used stops working. Devices on older apps keep working, and Settings marks devices that still use the original pairing code or older encryption so you know which to update.
  • orca serve and public addresses: orca serve accepts localhost, LAN and Tailscale connections by default and accepts public internet addresses only when there's a reason to. Existing setups keep connecting.
  • Speech model memory: With voice on, Orca now loads the on-device speech model ahead of your first dictation. Use the new Unload Speech Model setting in Settings › Voice to free that memory sooner. Desktop dictation now also stops by itself after a minute of silence.
  • Windows terminal font weight: Terminal text on Windows now uses the font's Regular weight by default instead of Medium, which Windows drew as SemiBold. macOS and Linux are unchanged.
  • New-tab launch menu: Permissions and Arguments are no longer in the new-tab agent launch menu. They still come from Agent settings.
  • Onboarding: The Antigravity Install button in onboarding is gone. Antigravity has the same Install instructions link as every other agent.
