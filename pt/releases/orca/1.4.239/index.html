#orca v1.4.239 Dois lançamentos hoje! Confira também os v1.4.238 release notes. Essa versão trouxe edições não salvas compartilhadas em espaços de trabalho, bate-papos de agentes mais avançados e configuração de conta remota, um navegador mais capaz e controles de telefone mais suaves.

Seu espaço de trabalho, trabalhando juntos 🐳

Configure as habilidades do agente em um click, mantenha as sessões do navegador separadas entre os projetos e mova-se mais facilmente entre o chat e o terminal. Esta versão também reforça o essencial: os arquivos compartilhados permanecem sincronizados, as sessões SSH se recuperam de forma mais confiável e as interações telefônicas parecem mais previsíveis.

A versão curta

Habilidades, prontas onde quer que você trabalhe: Instale as habilidades do Orca em um click nas telas de configuração e instale ou atualize-as em servidores emparelhados e hosts SSH com o instalador do próprio Orca.

  • Um navegador adequado aos seus projetos: Escolha perfis compartilhados, por repositório ou por espaço de trabalho para novas guias. Mantenha os logins de aplicativos locais separados, use um menu de contexto de página familiar e obtenha explicações mais claras quando uma página não puder ser carregada.
  • Conversas mais fluidas entre agentes: Divida em um novo bate-papo ao lado do atual, continue com um agente de terminal no cabeçalho do painel e mantenha intactas as mensagens na fila e vários anexos de imagem.
  • Edições mais seguras, trabalho em segundo plano mais silencioso: As visualizações de arquivos compartilhados permanecem atuais após desfazer e descartar. Arquivos não UTF-8 perguntam antes da conversão, a observação de arquivos se recupera após lentidão e o Orca monitora menos arquivos não relacionados.
  • Trabalho remoto com retorno: Recupere servidores SSH gerenciados suportados de um bloqueio obsoleto nas Configurações, restaure terminais após login com senha e mantenha o link de acesso SSH de um servidor emparelhado durante reinicializações.
  • Melhor no seu telefone: Tocar em uma notificação abre o agente que a enviou, as guias de bate-papo do agente podem iniciar o ditado, os comandos de cópia do terminal chegam ao telefone clipboard e a rolagem do Android mantém o teclado fora do caminho.
  • Aperfeiçoamento diário, em vários idiomas: Melhor entrada em coreano, renderização de terminal em bengali e outros idiomas índicos, traduções mais completas, seletores de usuários do Jira e links de comentários de relações públicas que vão direto para o editor. Atualizações do telefone: atualizar o Orca no computador que atende seu telefone atualiza a interface servida. As melhorias nativas de download, progresso e navegação exigem um aplicativo de telefone nativo atualizado.

Notas de compatibilidade e atualização

  • Perfis de navegador: Escolha Configurações → Navegador → Perfil para novas guias. Compartilhado continua sendo o padrão; perfis por repositório e por espaço de trabalho se aplicam a novas guias. As páginas de servidores emparelhados usam os próprios perfis do servidor.
  • Bate-papo nativo (experimental): Atualize os hosts SSH e emparelhados junto com o Orca para obter o bate-papo mais recente e as correções de lançamento. A disponibilidade do chat agora verifica o tempo de execução do chat separadamente do terminal CLI, incluindo configurações antigravidade suportadas.
  • Recuperação SSH: Recuperar servidor… está disponível para hosts SSH Linux gerenciados com suporte que relatam uma recusa de bloqueio obsoleto. Ele verifica o bloqueio e pede que você confirme se nenhuma outra máquina compartilhada naquela casa está executando o Orca antes de limpá-lo. Os telefones apontam para as configurações da área de trabalho.
  • Fundamentos experimentais: Os fundamentos do proprietário do layout permanecem desativados. As ações de inicialização de grupo vazio e a alternância de status do espaço de trabalho filho foram revertidas antes do lançamento.

Set up agent skills in one click, keep browser sessions separate between projects, and move more easily between chat and terminal. This release also strengthens the essentials: shared files stay in sync, SSH sessions recover more reliably, and phone interactions feel more predictable.

The short version

  • Skills, ready wherever you work: Install Orca’s skills in one click from setup screens, and install or update them on paired servers and SSH hosts with Orca’s own installer.
  • A browser that fits your projects: Choose shared, per-repo or per-workspace profiles for new tabs. Keep local app logins separate, use a familiar page context menu, and get clearer explanations when a page cannot load.
  • More fluid agent conversations: Split into a fresh chat beside your current one, continue with a terminal agent from the pane header, and keep queued messages and multiple image attachments intact.
  • Safer edits, quieter background work: Shared file views stay current after undo and discard. Non-UTF-8 files ask before conversion, file watching recovers after slowdowns, and Orca watches fewer unrelated files.
  • Remote work with a way back: Recover supported managed SSH servers from a stale lock in Settings, restore terminals after password sign-in, and keep a paired server’s SSH access link through restarts.
  • Better from your phone: Tapping a notification opens the agent that sent it, agent chat tabs can start dictation, terminal copy commands reach the phone clipboard, and Android scrolling keeps the keyboard out of the way.
  • Everyday polish, across languages: Better Korean input, Bengali and other Indic terminal rendering, more complete translations, Jira user pickers, and PR comment links that jump straight to the editor.

Phone updates: Updating Orca on the computer serving your phone updates the served interface. Native download, progress and navigation improvements require an updated native phone app.

Compatibility & upgrade notes

  • Browser profiles: Choose Settings → Browser → Profile for new tabs. Shared remains the default; per-repo and per-workspace profiles apply to new tabs. Paired-server pages use the server’s own profiles.
  • Native chat (experimental): Update paired and SSH hosts alongside Orca for the latest chat and launch fixes. Chat availability now checks the chat runtime separately from the terminal CLI, including supported Antigravity setups.
  • SSH recovery: Recover server… is available for supported managed Linux SSH hosts reporting a stale-lock refusal. It checks the lock and asks you to confirm that no other machine sharing that home is running Orca before clearing it. Phones point you to desktop Settings.
  • Experimental groundwork: The layout-owner groundwork remains disabled. The empty-group launch actions and child-workspace status toggle were reverted before release.
