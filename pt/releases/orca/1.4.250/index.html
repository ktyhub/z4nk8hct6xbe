#orca v1.4.250

Fizemos dois lançamentos hoje! Não deixe de conferir os v1.4.249 release notes, que incluem configuração mais fácil de bate-papo ou terminal, mais controle sobre conversas e uma página inicial de telefone redesenhada.

Menor uso de memória do terminal, alterações de bate-papo mais claras e um gerenciador de senhas compatível com o Chrome ✨

  • ⚡ ** Menor uso de memória do terminal: ** Pare de ler e analisar repetidamente arquivos de fonte para ligaduras de terminal, corrigindo uma fonte de alto uso de memória e iniciando travamentos em sessões com muitos terminais.
  • ⚡ Troca de árvore de trabalho mais rápida: As melhorias de desempenho tornam a troca entre árvores de trabalho mais rápida.
  • 📝 Veja o que os agentes mudaram: Os turnos de bate-papo mostram arquivos alterados e contagens de linhas, com patches disponíveis in-line no desktop e no telefone.
  • 🔐 Gerenciador de senhas compatível com o Chrome: Ative em Configurações → Navegador para salvar, preencher, importar senhas do Chrome e gerenciar logins, criptografados localmente com o armazenamento seguro do seu sistema operacional.
  • 💬 A UI do Chat acompanha o seu agente: Turnos longos e com muitas ferramentas permanecem conectados na UI do Chat, e novos chats seguem a configuração do modelo do próprio agente, a menos que você escolha um modelo.
  • 🖥️ Terminais e hosts mais confiáveis: Evite textos de sequência de escape perdidos após lacunas de saída do terminal e disponibilize trabalhadores de servidores emparelhados e pesquisas de uso em hosts sem cabeça.
  • 📱 Melhor continuidade do telefone: Envie bate-papo com Cmd/Ctrl+Enter e mantenha os dispositivos emparelhados seguindo as guias que eles abrem.

Destaques

  • Desempenho: A troca de árvore de trabalho é mais rápida. As ligaduras de terminal não analisam mais uma fonte inteira para cada terminal. No teste de Windows do PR com Commit Mono, 32 terminais foram reiniciados sem a falha anterior de falta de memória; os resultados dependem das fontes e da carga de trabalho. Fechar uma ferramenta em um turno longo do agente também evita a verificação de todas as outras ferramentas ativas.
  • Bate-papo: Edições bem-sucedidas de Claude e Codex aparecem como resumos de arquivos alterados na conversa, com detalhes do patch carregados na seleção. A interface do bate-papo não interrompe mais o turno de um agente íntegro quando excede 128 entradas de texto ou ferramenta ao vivo. Os bate-papos do Codex mostram as durações de espera solicitadas e suportam pausa, retomada e eliminação de metas.
  • Navegador: Salve e preencha logins no navegador do Orca e gerencie-os nas configurações do navegador. As senhas usam criptografia baseada no sistema operacional; o cofre não está disponível quando o armazenamento seguro não está disponível.
  • Hosts terminais e remotos: A recuperação de fluxo de terminal evita a impressão de sequências de escape parciais após lacunas de saída. Hosts sem cabeça iniciam os serviços necessários para trabalhadores de servidores emparelhados e pesquisa de uso.
  • Espaço de trabalho e integração: escolha a UI do Chat durante a integração, oculte a lista de verificação de integração, encontre árvores de trabalho ocultas descobertas fora do agrupamento de projetos e use a interface aprimorada de limpeza de espaço de trabalho inativo.

Notas de compatibilidade e atualização

  • Ligaduras terminais: Ligaduras comuns permanecem disponíveis. Ligaduras específicas de fontes fora da lista integrada não podem mais ser unidas ao renderizador de GPU.
  • Senhas do navegador: O cofre está disponível no navegador do desktop, incluindo páginas locais e do espaço de trabalho SSH; as páginas de servidor emparelhado transmitidas e a web client não possuem um cofre. É necessária criptografia segura do sistema operacional.
  • Padrões do modelo de chat: um novo chat sem uma escolha de modelo explícita usa a configuração do agente. O padrão exibido pode ficar obsoleto até que o agente seja iniciado e relate seu modelo.
  • Recuperação de terminal: Os fluxos de tempo de execução remoto mantêm seu comportamento de recuperação existente.

orca v1.4.250

We did two releases today! Be sure to check out the v1.4.249 release notes, which include easier Chat or Terminal setup, more control over conversations, and a redesigned phone Home.

Lower terminal memory use, clearer chat changes & a Chrome-compatible password manager ✨

  • ⚡ Lower terminal memory use: Stop repeatedly reading and parsing font files for terminal ligatures, fixing a source of high memory use and launch crashes in sessions with many terminals.
  • ⚡ Faster worktree switching: Performance improvements make switching between worktrees faster.
  • 📝 See what agents changed: Chat turns show changed files and line counts, with patches available inline on desktop and phone.
  • 🔐 Chrome-compatible password manager: Enable in Settings → Browser to save, fill, import Chrome passwords, and manage logins, encrypted locally with your OS’s secure storage.
  • 💬 Chat UI keeps up with your agent: Long, tool-heavy turns stay connected in Chat UI, and new chats follow your agent’s own model configuration unless you choose a model.
  • 🖥️ More reliable terminals and hosts: Prevent stray escape-sequence text after terminal output gaps, and make paired-server workers and usage polling available on headless hosts.
  • 📱 Better phone continuity: Send chat with Cmd/Ctrl+Enter and keep paired devices following the tabs they open.

Highlights

  • Performance: Worktree switching is faster. Terminal ligatures no longer parse an entire font for every terminal. In the PR’s Windows test with Commit Mono, 32 terminals relaunched without the previous out-of-memory crash; results depend on fonts and workload. Closing a tool in a long agent turn also avoids scanning every other live tool.
  • Chat: Successful Claude and Codex edits appear as changed-file summaries in the conversation, with patch details loaded on selection. Chat UI no longer interrupts an otherwise healthy agent turn when it exceeds 128 live text or tool entries. Codex chats show requested wait durations and support goal pause, resume and clear.
  • Browser: Save and fill logins in Orca’s browser and manage them in browser settings. Passwords use OS-backed encryption; the vault is unavailable when secure storage is unavailable.
  • Terminal & remote hosts: Terminal stream recovery avoids printing partial escape sequences after output gaps. Headless hosts start the services needed for paired-server workers and usage polling.
  • Workspace & onboarding: Choose Chat UI during onboarding, hide the onboarding checklist, find hidden discovered worktrees outside project grouping, and use the improved inactive workspace cleanup interface.

Compatibility & upgrade notes

  • Terminal ligatures: Common ligatures remain available. Font-specific ligatures outside the built-in list may no longer join with the GPU renderer.
  • Browser passwords: The vault is available in the desktop browser, including local and SSH workspace pages; streamed paired-server pages and the web client do not have a vault. Secure OS encryption is required.
  • Chat model defaults: A new chat without an explicit model choice uses the agent’s configuration. The displayed default can be stale until the agent starts and reports its model.
  • Terminal recovery: Remote-runtime streams retain their existing recovery behavior.
