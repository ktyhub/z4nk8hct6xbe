#orca v1.4.265 Versão anterior: 1.4.264 — Os comandos de bate-papo encontram seu espaço de trabalho, mantendo o navegador funcionando com o bate-papo certo.

Apresentando Orca Bots (Beta) <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="20" height="20" valign="middle" />

Os Orca Bots funcionam como companheiros de equipe de primeira classe: cada sessão de agente gerenciado recebe suas ferramentas e identidade, os bots podem compartilhar em nome do proprietário, eles seguem threads do Slack e gatilhos do Gmail de forma mais confiável e conectá-los é mais claro e seguro.

  • <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="20" height="20" valign="middle" /> Cada sessão de bot recebe suas ferramentas e identidade: As sessões de agente gerenciado não estão mais limitadas a Claude e Codex; cada um começa com as ferramentas e a identidade de que necessita.
  • 🔗 Os bots podem compartilhar, assim como o proprietário: Os chamadores do agente CLI podem usar o compartilhamento da mesma forma que o proprietário.
  • 💬 Tópicos do Slack mostram o que um bot está fazendo: Um tópico agora reflete no que seu turno está trabalhando, e respostas longas chegam inteiras em vez de cortadas.
  • 📬 Os gatilhos do Gmail correspondem ao remetente real: Os gatilhos correspondem ao endereço real do remetente, não a um nome de exibição que pode ser diferente.
  • 🛡️ Avisos de acesso mais claros: A caixa de diálogo de confirmação de acesso agora explica o que você está permitindo antes de conectar um bot.

Destaques

Bots, conectores e acesso. Conecte um bot por meio de um seletor de conector mais rápido com ícones de categoria, uma caixa de diálogo de conexão do Slack cortada que mostra como mencionar o bot depois de instalado e um aviso de controle de acesso mais claro. Outras conversas são listadas apenas para referência no contexto de um agente, para que o bot permaneça focado naquela sobre a qual foi questionado. Os alertas de conclusão e os relatórios de parada do trabalhador carregam a resposta que uma leitura de transcrição adiciona, e os agentes são informados sobre qual tipo de correio definir, inclusive sobre --on. Uma área de trabalho mais leve para bate-papos e terminais ocupados. Longas faixas de guias renderizam apenas a região visível, a sessão salva, escreve entradas alteradas, novas mensagens são enviadas enquanto outros bate-papos são transmitidos e um loop de rolagem do terminal que poderia congelar a janela foi corrigido. Enviar enquanto outros chats são transmitidos. O trabalho de envio de um novo chat tem prioridade sobre as gravações de streaming em segundo plano. Os compositores ocultos também param de ouvir cada pressionamento de tecla e os bate-papos fechados liberam linhas de status que não são mais necessárias. Essas mudanças reduzem o trabalho concorrente quando diversas conversas estão ativas. Leia o status sem perder o tópico. Expanda as linhas de atividades para obter detalhes ou abra a visualização do próprio subagente. O texto antes de uma pergunta permanece visível após a curva ser encerrada, os diagramas retidos sobrevivem às alternâncias do espaço de trabalho e as cargas com falha de mensagens anteriores oferecem Nova tentativa. Use o agente no host certo. A instalação do Claude e do Codex segue o host onde o chat é executado. Uma instalação pessoal existente tem precedência; As cópias gerenciadas do Orca também estão disponíveis em seus terminais. Os controles remotos de conta e exibições de uso também recebem correções. Escolha atualizações automáticas da área de trabalho. Ative Atualizações automáticas em Configurações → Geral → Sobre para permitir que o Orca baixe, instale e reinicie usando sua cadência, canal e atraso de atualização. O padrão é desativado. A instalação automática aguarda se encerrar um terminal ativo ou em processo de inicialização, se uma movimentação WSL estiver ativa ou se o estado da janela não puder ser salvo. Compatibilidade do telefone. As alterações do telefone listadas abaixo são alterações de origem incluídas neste limite de versão. A instalação desta atualização de desktop não instala uma atualização de aplicativo móvel; esses recursos exigem a construção móvel correspondente.

orca v1.4.265

Previous release: 1.4.264 — Chat commands find their workspace, keeping browser work with the right chat.

Introducing Orca Bots (Beta) <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="20" height="20" valign="middle" />

Orca Bots work like first-class teammates: every managed agent session gets its tools and identity, bots can share on the owner's behalf, they follow Slack threads and Gmail triggers more reliably, and connecting them is clearer and safer.

  • <img src="https://raw.githubusercontent.com/stablyai/orca/main/src/shared/bot-mascots/A1.webp" alt="Orca" width="20" height="20" valign="middle" /> Every bot session gets its tools and identity: Managed agent sessions are no longer limited to Claude and Codex; each one starts with the tools and identity it needs.
  • 🔗 Bots can share, just like the owner: Agent CLI callers can use Sharing the same way the owner does.
  • 💬 Slack threads show what a bot is doing: A thread now reflects what its turn is working on, and long answers arrive whole instead of cut up.
  • 📬 Gmail triggers match the real sender: Triggers match the sender's actual address, not a display name that can differ.
  • 🛡️ Clearer access warnings: The access confirm dialog now spells out what you are allowing before you connect a bot.

Highlights

Bots, connectors and access. Connect a bot through a faster connector picker with category icons, a trimmed Slack connect dialog that shows how to mention the bot once it is installed, and a clearer access-control warning. Other conversations are listed for reference only in an agent's context, so a bot stays focused on the one it was asked about. Finish alerts and worker stop reports carry the reply a transcript read adds, and agents are told which mail type to set, including over --on.

A lighter desktop for busy chats and terminals. Long tab strips render only the visible region, session saves write changed entries, new messages get through while other chats stream, and a terminal scroll loop that could freeze the window is fixed.

Send while other chats stream. A new chat’s sending work gets priority over background streaming writes. Hidden composers also stop listening to every keystroke, and closed chats release status rows they no longer need. These changes reduce competing work when several conversations are active.

Read status without losing the thread. Expand activity rows for details or open a subagent’s own view. Text before a question remains visible after the turn folds, retained diagrams survive workspace switches, and failed loads of earlier messages offer Retry.

Use the agent on the right host. Claude and Codex installation follows the host where the chat runs. An existing personal installation takes precedence; Orca’s managed copies are available to its terminals too. Remote account controls and usage displays also receive fixes.

Choose automatic desktop updates. Enable Automatic updates in Settings → General → About to let Orca download, install and relaunch using your update cadence, channel and delay. It defaults to off. Automatic installation waits if it would terminate a live or launching in-process terminal, a WSL move is active, or window state cannot be saved.

Phone compatibility. The phone changes listed below are source changes included in this release boundary. Installing this desktop update does not install a mobile app update; those features require the corresponding mobile build.
