#orca v1.4.229 Muito obrigado por usar o Orca e por seu apoio contínuo! ❤️

A versão curta

  • Bate-papo nativo (experimental): Revise edições passo a passo in-line, expanda diagramas para panorâmica e zoom, compartilhe recursos visuais de bate-papo com um click e veja os objetivos de Claude e o uso do contexto do Codex. As respostas do teclado, um divisor de não lidos e Copiar em Selecionar facilitam a navegação em longas conversas.
  • Habilidades compartilhadas: A instalação com habilidades compartilhadas agora oferece suporte a 20 agentes adicionais, com descoberta WSL mais ampla e os locais de instalação corretos para ferramentas como Kiro, Qoder e CodeBuddy.
  • Telefone: Filtros, agrupamento e classificação do espaço de trabalho agora seguem as escolhas compartilhadas da área de trabalho. Mantenha pressionado para ver questões e notas vinculadas, trabalhar com áreas de trabalho do servidor e páginas do navegador ou continuar um bate-papo compatível em uma nova conversa de terminal.
  • SSH e terminais remotos: As correções de reconexão preservam painéis divididos, ordem de colagem e grupos de projetos de servidores gerenciados. Os agentes adormecidos retomam suas conversas e a remoção do projeto de uma máquina deixa sua contraparte no mesmo caminho em paz.
  • Espaços de trabalho e aprimoramento diário: Abra um site em Cmd/Ctrl+J, observe o progresso do checkout à medida que uma árvore de trabalho é criada e limpe os espaços de trabalho com uma confirmação explícita antes de interromper a execução de agentes.
  • Planejamento do Jira: alterne entre listas de problemas e quadros, concentre-se no sprint atual, reutilize JQL salvo e favoritos do Jira e inicie espaços de trabalho no desktop ou no telefone. Seus agentes também podem ler e atualizar tickets do Jira por meio do Orca CLI.

Problemas conhecidos

Bate-papo nativo (experimental): Recursos que dependem de um host remoto estão disponíveis quando esse host os oferece suporte. Atualize o host junto com o Orca para obter os recursos mais recentes. O comando orca em hosts SSH: Os hosts existentes mantêm suas preferências de controle salvas do Orca CLI. Para permitir que os agentes gerenciem os espaços de trabalho ou controlem o navegador do desktop, ative Permitir que o orca CLI deste host controle o Orca em Configurações → Hosts SSH → editar o host → Conexão avançada.

orca v1.4.229

Thank you so much for using Orca and for your continued support! ❤️

The short version

  • Native chat (experimental): Review turn-by-turn edits inline, expand diagrams to pan and zoom, share chat visuals with a click, and see Claude goals and Codex context usage. Keyboard answers, an unread divider and Copy on Select make long conversations easier to navigate.
  • Shared skills: Shared-skill installation now supports 20 additional agents, with broader WSL discovery and the right install locations for tools such as Kiro, Qoder and CodeBuddy.
  • Phone: Workspace filters, grouping and sorting now follow the desktop’s shared choices. Long-press for linked issues and notes, work with server workspaces and browser pages, or continue a supported chat in a new terminal conversation.
  • SSH and remote terminals: Reconnect fixes preserve split panes, paste order and managed-server project groups. Sleeping agents resume their conversations, and removing one machine’s project leaves its same-path counterpart alone.
  • Workspaces and everyday polish: Open a website from Cmd/Ctrl+J, watch checkout progress as a worktree is created, and clean up workspaces with an explicit confirmation before stopping running agents.
  • Jira planning: Switch between issue lists and boards, focus on the current sprint, reuse saved JQL and Jira favourites, and start workspaces from desktop or phone. Your agents can read and update Jira tickets through the Orca CLI, too.

Known issues

Native chat (experimental): Features that depend on a remote host are available when that host supports them. Update the host alongside Orca to get the latest capabilities.

The orca command on SSH hosts: Existing hosts keep their saved Orca CLI control preference. To let agents there manage workspaces or control the desktop browser, turn on Allow this host’s orca CLI to control Orca under Settings → SSH Hosts → edit the host → Advanced Connection.
