#orca v1.4.238

Trabalho mais conectado, edições mais seguras 🐳

Esta versão facilita a movimentação entre agentes, arquivos, navegadores e máquinas remotas. As guias do mesmo arquivo agora compartilham edições não salvas, os bate-papos nativos selecionam turnos feitos em outros lugares e o telefone obtém gestos de terminal mais confiáveis ​​e controles de guias mais ricos.

A versão curta

  • Suas edições permanecem juntas: guias do mesmo arquivo compartilham texto não salvo em áreas de trabalho. A revisão de conflitos verifica que o texto ativo, a exclusão do espaço de trabalho lista os arquivos não salvos e o Markdown obsoleto ou as edições do bloco de notas não substituem mais o trabalho mais recente.
  • Bate-papos que acompanham: Codex e Pi mostram turnos feitos fora do chat. Pastas longas podem se tornar anexos de texto, perguntas do Codex recebem cartões de resposta e OMP ganha envio de imagens e cartões de revisão de plano acionáveis.
  • Mais controle sobre os agentes: Escolha chat ou terminal ao criar um espaço de trabalho, defina essa opção para seu agente padrão, adicione contas Claude e Codex em servidores remotos suportados e instale habilidades compartilhadas para mais 11 agentes.
  • Um navegador mais eficiente: uma nova guia compatível com o espaço de trabalho, sugestões na barra de endereço, permissões de site lembradas, aparência e zoom por site e progresso de carregamento de página no computador e no telefone.
  • Uma experiência telefônica mais tranquila: Veja a atividade do agente em guias, renomeie com um toque duplo, role para trás pelas mensagens de bate-papo anteriores, selecione o texto do terminal com mais naturalidade e retorne à posição de leitura do terminal após retomar.
  • Melhor visibilidade e recuperação: Inspecione terminais locais no Resource Manager, use SSH simples quando a mudança de um host para um servidor Orca estiver bloqueada e mantenha os emparelhamentos por meio de atualizações e recuperação de servidores gerenciados.
  • Aperfeiçoamento diário: Português do Brasil, seleção de idioma durante a integração, versões pesquisáveis, progresso de verificação de histórico mais claro e Resolver com IA para mesclagens pausadas, rebases e seleções seletivas, mesmo depois que os conflitos de arquivo forem corrigidos. Atualizações do telefone: atualizar o Orca no computador que atende seu telefone atualiza a interface servida. A nova entrada Home → New Workspace e as correções de ditado nativo do iOS exigem um aplicativo de telefone nativo atualizado; a entrada na tela inicial vem com a próxima versão do aplicativo.

Notas de compatibilidade e atualização

  • Contas remotas: Atualize o servidor emparelhado para o novo fluxo de adição de conta de Claude e Codex. Servidores Windows e hosts mais antigos mantêm a orientação orca account add. As credenciais permanecem no servidor; a reautenticação remota de uma conta existente está fora desta alteração.
  • Bate-papo nativo (experimental): Atualize os hosts SSH e emparelhados junto com o Orca para obter as correções de bate-papo mais recentes. As verificações de versão do agente agora aceitam versões e pré-lançamentos mais recentes que atendem ao mínimo exigido; uma versão mais antiga conhecida mostra orientações de atualização.
  • Gerenciador de Recursos: A nova visualização de PTYs abrange terminais locais. Terminar um terminal requer suporte do host para verificar a sessão selecionada; hosts mais antigos recusam o encerramento não verificado.
  • Arquivos HTML: A abertura do HTML na visualização por padrão foi revertida nesta versão.
  • Fundamentos experimentais: As alterações no proprietário do layout e na barra lateral listadas abaixo permanecem desativadas. Os novos controles opcionais de gravação do agente não têm chamadores existentes habilitados.

orca v1.4.238

More connected work, safer edits 🐳

This release makes it easier to move between agents, files, browsers and remote machines. Tabs of the same file now share unsaved edits, native chats pick up turns made elsewhere, and the phone gets more dependable terminal gestures and richer tab controls.

The short version

  • Your edits stay together: Tabs of the same file share unsaved text across workspaces. Conflict review sees that live text, workspace deletion lists unsaved files, and stale Markdown or notebook edits no longer overwrite newer work.
  • Chats that keep up: Codex and Pi show turns made outside the chat. Long pastes can become text attachments, Codex questions get answer cards, and OMP gains image sending and actionable plan-review cards.
  • More control over agents: Pick chat or terminal when creating a workspace, set that choice for your default agent, add Claude and Codex accounts on supported remote servers, and install shared skills for 11 more agents.
  • A more capable browser: A workspace-aware new tab, address-bar suggestions, remembered site permissions, per-site appearance and zoom, and page-loading progress on desktop and phone.
  • A smoother phone experience: See agent activity in tabs, rename with a double-tap, scroll back through earlier chat messages, select terminal text more naturally, and return to your terminal reading position after resuming.
  • Better visibility and recovery: Inspect local terminals in Resource Manager, use plain SSH when a host’s move to an Orca server is blocked, and keep pairings through managed-server updates and recovery.
  • Everyday polish: Brazilian Portuguese, language selection during onboarding, searchable release builds, clearer history-scan progress, and Resolve with AI for paused merges, rebases and cherry-picks—even after file conflicts are fixed.

Phone updates: Updating Orca on the computer serving your phone updates the served interface. The new Home → New Workspace entry and native iOS dictation fixes require an updated native phone app; the home-screen entry ships with the next app build.

Compatibility & upgrade notes

  • Remote accounts: Update the paired server for the new Claude and Codex Add Account flow. Windows servers and older hosts retain the orca account add guidance. Credentials stay on the server; remote re-authentication of an existing account is outside this change.
  • Native chat (experimental): Update paired and SSH hosts alongside Orca for the latest chat fixes. Agent version checks now accept newer releases and prereleases that meet the required minimum; a known older version shows update guidance.
  • Resource Manager: The new PTYs view covers local terminals. Ending a terminal requires host support for verifying the selected session; older hosts refuse unchecked termination.
  • HTML files: Opening HTML in preview by default was reverted for this release.
  • Experimental groundwork: Layout-owner and sidebar changes listed below remain disabled. The new optional agent-write controls have no existing callers enabled.
