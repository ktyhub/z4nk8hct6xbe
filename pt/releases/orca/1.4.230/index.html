#orca v1.4.230 Muito obrigado por usar o Orca e por seu apoio contínuo! ❤️

A versão curta

  • Bate-papo nativo (experimental): Use Antigravidade no chat, escolha quais agentes abrem como chats e instale um agente ausente no próprio chat. Cole arquivos copiados como anexos, coloque imagens em fila e veja feedback mais claro enquanto anexos e ações de fila estão pendentes.
  • Contas e agentes: Após trocar de conta do Claude, reinicie as sessões em execução na nova conta. Remova os tempos de execução do agente baixados em Configurações e edite ou exclua comentários lineares por meio do Orca CLI.
  • Telefone: edite mensagens na fila no local, acompanhe as execuções da ferramenta com cartões estilo desktop e veja sua conversa imediatamente ao sair do histórico. Os telefones horizontais colocam guias de sessão na barra superior e o Tarefas deixa claro qual área de trabalho você está usando.
  • SSH e espaços de trabalho remotos: a desconexão permanece desconectada, os espaços de trabalho inativos permanecem inativos e as guias fechadas permanecem fechadas após a reconexão. Mensagens mais claras de atualização e emparelhamento do servidor ajudam a recuperar uma conexão.
  • Aperfeiçoamento diário: Os atalhos do Comando rápido seguem a divisão focada, as visualizações das guias aguardam o atraso total do foco e os cabeçalhos dos arquivos oferecem Revelar no Finder. A limpeza do espaço de trabalho protege melhor projetos de mesmo caminho em outras máquinas.

Notas de compatibilidade e atualização

Bate-papo nativo (experimental): Alguns recursos de bate-papo exigem suporte do host remoto. Mantenha o host atualizado junto com o Orca para usar os recursos mais recentes. O comando orca em hosts SSH: Os hosts existentes retêm preferências de controle CLI salvas explicitamente; uma preferência não definida é migrada para desativada. Para permitir que comandos em um host SSH conectado abram e controlem as guias do navegador Orca deste desktop para os espaços de trabalho desse host, ative Permitir que o orca CLI deste host controle o Orca em Configurações → Hosts SSH → editar o host → Conexão avançada.

orca v1.4.230

Thank you so much for using Orca and for your continued support! ❤️

The short version

  • Native chat (experimental): Use Antigravity in chat, choose which agents open as chats, and install a missing agent from the chat itself. Paste copied files as attachments, queue images, and see clearer feedback while attachments and queue actions are pending.
  • Accounts & agents: After switching Claude accounts, restart running sessions on the new account. Remove downloaded agent runtimes from Settings, and edit or delete Linear comments through the Orca CLI.
  • Phone: Edit queued messages in place, follow tool runs with desktop-style cards, and see your conversation immediately when resuming from history. Landscape phones put session tabs in the top bar, and Tasks makes clear which desktop you’re using.
  • SSH & remote workspaces: Disconnect stays disconnected, sleeping workspaces stay asleep, and closed tabs stay closed after reconnecting. Clearer server update and re-pairing messages help you recover a connection.
  • Everyday polish: Quick Command shortcuts follow the focused split, tab previews wait for the full hover delay, and file headers offer Reveal in Finder. Workspace cleanup better protects same-path projects on other machines.

Compatibility & upgrade notes

Native chat (experimental): Some chat features require support from the remote host. Keep the host updated alongside Orca to use the latest capabilities.

The orca command on SSH hosts: Existing hosts retain explicitly saved CLI control preferences; an unset preference is migrated to off. To allow commands on a connected SSH host to open and control this desktop’s Orca browser tabs for that host’s workspaces, enable Allow this host’s orca CLI to control Orca under Settings → SSH Hosts → edit the host → Advanced Connection.
