#orca v1.4.240

Um espaço de trabalho mais confiável 🐳

Esta versão fornece o histórico pesquisável do navegador integrado, facilita o acompanhamento da atividade do agente e melhora a recuperação em chats e terminais remotos. Você também encontrará realce de sintaxe Lean e Zig, suporte para coleções maiores de comandos rápidos e um novo comando orca ports para localizar seus servidores de desenvolvimento.

A versão curta

  • Conversas que ficam com você: Os bate-papos de Claude agora mostram turnos feitos fora do Orca. As mensagens retidas retornam após a reconexão sem reabrir o bate-papo, e a recuperação de falhas não adivinha mais que uma mensagem enviada não foi entregue.
  • Um navegador com melhor memória: Pesquise seu histórico de navegação, reabra páginas, remova sugestões indesejadas e limpe o histórico com Desfazer. O Pages também pode usar arquivos que você escolhe, salva ou solta por meio do File System Access.
  • Trabalho remoto com menos interrupções: Conexões lentas sobrevivem a sondagens de ativação perdidas, avisos de reconexão explicam o que está acontecendo, terminais SSH aguardam login e novas divisões permanecem no servidor emparelhado.
  • Status do agente que você pode trust: Os subagentes Codex concluídos param de aparecer como Trabalhando, as tarefas principais em execução permanecem visíveis por meio de conversas /side e as ferramentas Codex MCP que exigem aprovação recebem um cartão de aprovação.
  • Mais espaço para seu fluxo de trabalho: Salve mais de 40 comandos rápidos, encontre portas de servidor de desenvolvimento detectadas em uma árvore de trabalho com orca ports e recupere instalações de dependências antigas e crie resultados de árvores de trabalho de desenvolvimento.
  • Aperfeiçoe onde é importante: Destaque Lean e Zig, trechos de pesquisa de sessão mais claros, rolagem mais suave do trackpad do Mac em aplicativos de terminal e melhor proteção para ramificações não mescladas e árvores de trabalho compartilhadas entre Windows e WSL. Atualizações por telefone e web: Atualizar o Orca no computador que atende seu telefone ou navegador atualiza a interface servida. Esta versão também mantém a execução de tarefas do Codex visíveis em visualizações emparelhadas e móveis durante conversas /side e corrige anexos de bate-papo escolhidos ou descartados pelo navegador, carregados no servidor emparelhado.

Notas de compatibilidade e atualização

  • Bate-papo nativo (experimental): Atualize hosts SSH e emparelhados junto com o Orca para obter o bate-papo mais recente, o status do agente e as correções de inicialização. Os novos cartões de aprovação do Codex cobrem aprovações de ferramentas MCP que não exigem campos de formulário; Formulários MCP gerais e verificação baseada em URL não são suportados por esta alteração.
  • Histórico do navegador: abra Histórico no menu de páginas ou use Cmd+Y no macOS e Ctrl+H no Linux e Windows. Pesquise, remova entradas individuais ou apague a última hora, hoje ou sempre, com Desfazer para limpeza.
  • Portas detectadas: orca ports suporta seleção de espaço de trabalho e saída JSON em tempos de execução com varredura de porta no escopo do host. Os hosts SSH diretos ainda não suportam detecção; os espaços de trabalho de pasta nativa exigem que --all liste os ouvintes do host.
  • Limpeza de desenvolvimento: pnpm reclaim-space manual e limpeza automática em lançamentos de desenvolvimento podem recuperar instalações de dependência ignoradas e não rastreadas e saída gerada em árvores de trabalho irmãs antigas, usando um limite padrão de 30 dias. As árvores de trabalho selecionadas, invocadas e excluídas permanecem protegidas. Interrompa aplicativos, agentes, instalações, compilações e testes irmãos antes de aplicar a limpeza manual; instalações e saídas recuperadas precisam ser reinstaladas ou reconstruídas quando usadas novamente.
  • Links de arquivos de terminal: A alteração anterior para abrir um link de arquivo na área de trabalho onde estava clicked foi revertida nesta versão.

orca v1.4.240

A more dependable workspace 🐳

This release gives the built-in browser searchable history, makes agent activity easier to follow, and improves recovery across chats and remote terminals. You’ll also find Lean and Zig syntax highlighting, support for larger quick-command collections, and a new orca ports command for finding your dev servers.

The short version

  • Conversations that stay with you: Claude chats now show turns made outside Orca. Retained messages return after reconnect without reopening the chat, and crash recovery no longer guesses that a sent message was undelivered.
  • A browser with a better memory: Search your browsing history, reopen pages, remove unwanted suggestions, and clear history with Undo. Pages can also use files you pick, save or drop through File System Access.
  • Remote work with fewer interruptions: Slow connections survive missed wake probes, reconnect notices explain what is happening, SSH terminals wait for sign-in, and new splits stay on the paired server.
  • Agent status you can trust: Completed Codex subagents stop showing as Working, running main tasks stay visible through /side conversations, and Codex MCP tools that require approval get an approval card.
  • More room for your workflow: Save more than 40 quick commands, find a worktree’s detected dev-server ports with orca ports, and reclaim old dependency installs and build output from development worktrees.
  • Polish where it counts: Lean and Zig highlighting, clearer session-search excerpts, smoother Mac trackpad scrolling in terminal apps, and better protection for unmerged branches and worktrees shared between Windows and WSL.

Phone & web updates: Updating Orca on the computer serving your phone or browser updates the served interface. This release also keeps running Codex tasks visible on paired and mobile views during /side conversations and fixes browser-picked or dropped chat attachments uploading to the paired server.

Compatibility & upgrade notes

  • Native chat (experimental): Update paired and SSH hosts alongside Orca for the latest chat, agent-status and launch fixes. Codex’s new approval cards cover MCP tool approvals that do not require form fields; general MCP forms and URL-based verification are not supported by this change.
  • Browser history: Open History from the page menu, or use Cmd+Y on macOS and Ctrl+H on Linux and Windows. Search, remove individual entries, or clear the last hour, today or all time, with Undo for clearing.
  • Detected ports: orca ports supports workspace selection and JSON output on runtimes with host-scoped port scanning. Direct SSH hosts do not support detection yet; native folder workspaces require --all to list the host’s listeners.
  • Development cleanup: Manual pnpm reclaim-space and automatic cleanup on development launches can reclaim ignored, untracked dependency installs and generated output in old sibling worktrees, using a default 30-day cutoff. Selected, invoking and excluded worktrees remain protected. Stop sibling apps, agents, installs, builds and tests before applying manual cleanup; reclaimed installs and output need reinstalling or rebuilding when used again.
  • Terminal file links: The earlier change to open a file link in the workspace where it was clicked was reverted in this release.
