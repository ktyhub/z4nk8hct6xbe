#orca v1.4.241

Bate-papos e um navegador que se comporta da maneira que você espera 🧭

Esta versão faz com que os bate-papos sigam as configurações do seu agente, traz ferramentas estilo Chrome para o navegador integrado e ajuda na recuperação de conexões SSH e servidores gerenciados. Você também encontrará uma configuração de fonte de bate-papo, navegação de agente ao vivo e terminais Hermes, Kimi, Kiro e Windows mais estáveis.

A versão curta

  • Bate-papos que seguem suas configurações: Novos bate-papos usam a permissão de cada agente em Configurações → Agentes, bate-papos renomeados mantêm seus nomes no Histórico da sessão e um bate-papo não grava uma conversa enquanto o terminal ainda estiver em execução.
  • Um navegador mais próximo do Chrome: Encaixe o DevTools dentro do painel, desative as guias que reproduzem som, veja o URL de um link ao passar o mouse e use os atalhos do Orca e retroceda/avance o mouse nas páginas.
  • Assistir a navegação dos agentes: Um cursor e um crachá mostram onde um agente está digitando ou digitando, o bate-papo leva você para a página e links de terminais e bate-papo são abertos ao lado de sua fonte.
  • SSH com menos becos sem saída: Encaminhamentos de porta salvos retornam após uma reinicialização e explicam falhas, hosts somente certificados se conectam por meio de seu sistema ssh e servidores gerenciados são atualizados sem fechar terminais.
  • Agentes que iniciam e reiniciam de forma confiável: os painéis Hermes e Kimi são retomados após uma reinicialização, Kiro informa o status em seu mecanismo V3 e as chaves digitadas enquanto um agente inicia são mantidas como rascunho.
  • Aperfeiçoe onde for importante: Escolha uma fonte para bate-papo, aplique zoom com Cmd/Ctrl + + em teclados fora dos EUA, abra arquivos somente na nuvem em terminais macOS e obtenha terminais Windows mais estáveis ​​e colagem. Atualizações por telefone e web: Os telefones não soltam mais partes da saída do terminal, e os bate-papos são renomeados e o modo de permissão de cada bate-papo agora é exibido lá. As guias de sessão também continuam funcionando e precisam de você para agentes do Windows que nunca definem um título.

Notas de compatibilidade e atualização

  • Host de terminal novo: Novos terminais iniciam em um host de terminal novo, portanto, as correções de terminal desta versão se aplicam. Os terminais já abertos antes da atualização continuam em execução e permanecem conectados no host anterior até você fechá-los.
  • Permissões de bate-papo: Configurações → O bate-papo não tem mais seu próprio menu suspenso de permissões; defina-o por agente em Configurações → Agentes. Os bate-papos existentes mantêm as permissões salvas, e o menu de permissão do próprio bate-papo altera apenas esse bate-papo.
  • Conversas abertas em um terminal: Se um terminal ainda estiver gravando uma conversa, seu bate-papo não será enviado e solicitará que você saia do agente ou feche esse terminal. Fechar esse terminal permite que o próximo envio seja realizado.
  • Servidores SSH gerenciados: Atualizar mesmo assim continua executando os terminais durante a atualização. A oferta para retomar os bate-papos após uma reinicialização precisa de um servidor que já esteja executando esta versão.
  • Escolhas de modelo OpenCode: OpenCode 2.0.14, 2.0.15, 2.0.17 e 2.0.18 deixam a primeira mensagem não enviada quando um modelo é escolhido, então o Orca recusa escolhas de modelo nessas versões.

orca v1.4.241

Chats and a browser that behave the way you expect 🧭

This release makes chats follow your agent settings, brings Chrome-style tools to the built-in browser, and helps SSH connections and managed servers recover. You’ll also find a chat font setting, live agent browsing, and steadier Hermes, Kimi, Kiro and Windows terminals.

The short version

  • Chats that follow your settings: New chats use each agent’s permission from Settings → Agents, renamed chats keep their names in Session History, and a chat won’t write a conversation a terminal is still running.
  • A browser closer to Chrome: Dock DevTools inside the pane, mute tabs playing sound, see a link’s URL on hover, and use Orca shortcuts and mouse back/forward inside pages.
  • Watch agents browse: A cursor and badge show where an agent is clicking or typing, chat jumps you to the page, and links from terminals and chat open beside their source.
  • SSH with fewer dead ends: Saved port forwards return after a restart and explain failures, certificate-only hosts connect through your system ssh, and managed servers update without closing terminals.
  • Agents that start and resume reliably: Hermes and Kimi panes resume after a restart, Kiro reports status on its V3 engine, and keys typed while an agent starts are kept as a draft.
  • Polish where it counts: Pick a font for chat, zoom with Cmd/Ctrl + + on non-US keyboards, open cloud-only files from macOS terminals, and get steadier Windows terminals and pasting.

Phone & web updates: Phones no longer drop pieces of terminal output, and chat renames and each chat’s permission mode now show there. Session tabs also keep Working and Needs You for Windows agents that never set a title.

Compatibility & upgrade notes

  • Fresh terminal host: New terminals start on a fresh terminal host so this release’s terminal fixes apply. Terminals already open before you update keep running, and stay attached, on the previous host until you close them.
  • Chat permissions: Settings → Chat no longer has its own permission dropdown; set it per agent in Settings → Agents. Existing chats keep their saved permission, and a chat’s own permission menu changes only that chat.
  • Conversations open in a terminal: If a terminal might still be writing a conversation, its chat won’t send and asks you to quit the agent there or close that terminal. Closing that terminal lets the next send go through.
  • Managed SSH servers: Update anyway keeps running terminals going through the update. The offer to resume chats after a restart needs a server already running this release.
  • OpenCode model picks: OpenCode 2.0.14, 2.0.15, 2.0.17 and 2.0.18 leave the first message unsent when a model is picked, so Orca refuses model picks on those versions.
