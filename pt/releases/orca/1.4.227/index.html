#orca v1.4.227 Muito obrigado por usar o Orca e por seu apoio contínuo! ❤️

A versão curta

  • Bate-papos nativos têm seu próprio modo de permissão. Escolha permissões para cada novo bate-papo do Claude ou Codex em Configurações → Bate-papo → Comportamento; os bate-papos existentes mantêm o modo que já estavam usando e a alteração dos modelos não o reinicia mais.
  • Sessões de bate-papo nativas são mais fáceis de continuar. Você pode retomar grandes conversas de terminal em um novo bate-papo nativo, recuperar bate-papos cujo único trabalho foi executado em segundo plano após uma reinicialização e ver todos os provedores de bate-papo suportados com precisão no Histórico da sessão.
  • As contas Claude e a configuração do bate-papo do Codex são mais fáceis. As contas Claude novamente usam pastas separadas, o link de login pode ser copiado, os bate-papos do Codex exigem a versão 0.136.0 ou posterior e o Codex Ultrafast está disponível como uma opção de velocidade.
  • A automação do navegador devolve o teclado de maneira confiável. Os comandos do navegador do agente direcionam a página pretendida e os pop-ups do navegador se comportam mais como o Chrome.
  • Além disso: a limpeza da árvore de trabalho é mais segura, as notificações de leitura do macOS desaparecem da Central de Notificações, bate-papos longos carregam melhor nos telefones e leituras frias do histórico de sessões evitam reindexação desnecessária.

orca v1.4.227

Thank you so much for using Orca and for your continued support! ❤️

The short version

  • Native chats have their own permission mode. Choose permissions for each new Claude or Codex chat from Settings → Chat → Behavior; existing chats keep the mode they were already using, and changing models no longer resets it.
  • Native chat sessions are easier to continue. You can resume large terminal conversations in a new native chat, recover chats whose only work ran in the background after a restart, and see every supported chat provider accurately in Session History.
  • Claude accounts and Codex chat setup are smoother. Claude accounts again use separate folders, the sign-in link can be copied, Codex chats require version 0.136.0 or later, and Codex Ultrafast is available as a speed choice.
  • Browser automation gives your keyboard back reliably. Agent browser commands target the intended page, and browser popups behave more like Chrome.
  • Also: worktree cleanup is safer, read macOS notifications disappear from Notification Center, long chats load better on phones, and cold session-history reads avoid unnecessary reindexing.
