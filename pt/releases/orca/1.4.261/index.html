#orca v1.4.261

Versão anterior: 1.4.259 — Grandes melhorias de desempenho, limpeza automática e visualizações focadas de subagentes.

Grandes melhorias de desempenho, Cursor Chat e um menu + personalizável ✨

Orca 1.4.261 torna os fluxos de trabalho de bate-papo mais responsivos e libera memória das páginas do navegador que você não usa há horas. O cursor entra no bate-papo e um menu + personalizável coloca suas formas preferidas de abrir guias ao seu alcance.

  • ⚡ Movimente-se entre bate-papos ocupados com menos espera: Conversas longas carregam seu histórico nas páginas, e as respostas em segundo plano funcionam menos na barra lateral e nos bate-papos ocultos quando você alterna entre conversas.
  • 🌐 Mantenha as guias do navegador sem manter todas as páginas carregadas: O Memory Saver libera páginas qualificadas após quatro horas fora de visualização por padrão e as recarrega quando você retorna. Os sites que usam cookies de sessão também podem mantê-lo conectado durante as reinicializações.
  • 🤖 Usar o Cursor no Chat: Comece com o login do Cursor no seu computador, escolha um modelo, esforço e Rápido, aprove os comandos e reabra a conversa mais tarde.
  • ➕ Torne o menu + seu: Use a engrenagem ao lado da nova linha de ícones para reordenar ações, ocultar escolhas não utilizadas e definir atalhos. As ações ocultas permanecem disponíveis por meio da pesquisa e de seus atalhos.
  • ⌨️ Carregue o trabalho do terminal com precisão: Copiar Contexto, Bifurcar e Continuar preservam os espaços desenhados pelos programas do terminal. Editar → Colar tem como alvo o painel dividido que realmente está em foco.

Destaques

  • Mais espaço para trabalho ativo: O Memory Saver também se aplica às guias do navegador em um host orca serve atualizado. As guias da área de trabalho retêm seu título, histórico, cookies e dados salvos do site. Configurações → Navegador permite alterar o intervalo de inatividade ou desativar a Economia de memória.
  • Mais opções de agentes: O Antigravity Chat funciona no Windows e o Pi Chat mostra subagentes. Comandos comuns do Orca CLI evitam a inicialização do Electron em Macs suportados; macOS 13.4 mantém o inicializador existente.
  • Resumo dos espaços de trabalho: cartões de espaços de trabalho experimentais mostram atividades, resultados não lidos, falhas e hosts off-line. Escolha Clássico ou Experimental nas opções do espaço de trabalho. Os agentes cujos painéis estão inativos continuam exibindo Concluído.
  • Navegação por telefone: A interface de telefone emparelhada ganha grupos de projetos de desktop e uma preferência de navegador compartilhada para chat e links de terminal, incluindo Perguntar sempre. No desktop, retome todo o controle de retorno das guias do navegador acionadas pelo telefone.

Notas de compatibilidade e atualização

  • Histórico de bate-papo: Os bate-papos existentes são convertidos para a nova loja em segundo plano ou quando abertos pela primeira vez. Os arquivos de bate-papo originais permanecem intactos nesta versão. Após fazer o downgrade e atualizar novamente, os chats continuados na versão mais antiga são recuperados; uma conversa convertida anteriormente pode aparecer ao lado de sua versão mais recente como um segundo bate-papo.
  • Recarregamento do navegador: As páginas liberadas são recarregadas no local; a posição de rolagem e a memória somente de página podem ser redefinidas. O Desktop Memory Saver deixa as páginas carregadas quando detecta edições não salvas ou não consegue avaliá-las com segurança. A economia depende de quais páginas se qualificam.
  • Android: O aplicativo legado orienta os usuários a instalar o novo dev.orca.app separadamente; ele não pode ser atualizado para o novo pacote. Esta versão para desktop não instala um aplicativo de telefone.
  • Agentes finalizados: As linhas saem dos cartões do espaço de trabalho, da lista de Agentes e do painel quando o processo é encerrado ou seu host SSH é desconectado. Os painéis suspensos mantêm o status Concluído.

orca v1.4.261

Previous release: 1.4.259 — Major performance improvements, automatic cleanup and focused subagent views.

Major performance improvements, Cursor Chat & a customizable + menu ✨

Orca 1.4.261 makes busy Chat workflows more responsive and releases memory from browser pages you haven't used in hours. Cursor joins Chat, and a customizable + menu puts your preferred ways to open tabs within reach.

  • ⚡ Move between busy chats with less waiting: Long conversations load their history in pages, and background replies do less work in the sidebar and hidden chats when you switch conversations.
  • 🌐 Keep browser tabs without keeping every page loaded: Memory Saver frees eligible pages after four hours out of view by default, then reloads them when you return. Sites using session cookies can also keep you signed in across restarts.
  • 🤖 Use Cursor in Chat: Start with the Cursor sign-in on your computer, choose a model, effort and Fast, approve commands, and reopen the conversation later.
  • ➕ Make the + menu yours: Use the gear beside the new icon row to reorder actions, hide unused choices and set shortcuts. Hidden actions remain available through search and their shortcuts.
  • ⌨️ Carry terminal work forward accurately: Copy Context, Fork and Continue preserve spaces drawn by terminal programs. Edit → Paste targets the split pane that actually has focus.

Highlights

  • More room for active work: Memory Saver also applies to browser tabs on an updated orca serve host. Desktop tabs retain their title, history, cookies and saved site data. Settings → Browser lets you change the idle interval or turn Memory Saver off.
  • More agent choices: Antigravity Chat works on Windows, and Pi Chat shows subagents. Ordinary Orca CLI commands avoid Electron startup on supported Macs; macOS 13.4 retains the existing launcher.
  • Workspaces at a glance: Experimental workspace cards show activity, unread results, failures and offline hosts. Choose Classic or Experimental from Workspace options. Agents whose panes are asleep keep showing Done.
  • Phone navigation: The paired phone interface gains desktop project groups and a shared browser preference for chat and terminal links, including Ask each time. On desktop, Take back all returns control of phone-driven browser tabs.

Compatibility & upgrade notes

  • Chat history: Existing chats convert to the new store in the background or when first opened. Original chat files stay in place in this release. After downgrading and upgrading again, chats continued in the older version are recovered; a previously converted conversation can appear beside its newer version as a second chat.
  • Browser reloads: Freed pages reload in place; scroll position and page-only memory can reset. Desktop Memory Saver leaves pages loaded when it detects unsaved edits or cannot safely assess them. Savings depend on which pages qualify.
  • Android: The legacy app directs users to install the new dev.orca.app separately; it cannot update into the new package. This desktop release does not install a phone app.
  • Finished agents: Rows leave workspace cards, the Agents list and dashboard when the process exits or its SSH host disconnects. Sleeping panes retain their Done status.
