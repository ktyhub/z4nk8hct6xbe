#orca v1.4.249

Configuração mais fácil, mais controle sobre bate-papos e espaços de trabalho mais organizados ✨

  • 🎛️ Escolha Chat ou Terminal desde o início: A integração agora permite que você escolha a UI do Chat ou Terminal, depois escolha um agente e instale as habilidades para essa configuração.
  • 💬 Mantenha o controle das conversas: preserve as entradas do chat durante entregas incertas e Pare, escolha se o envio move a posição de rolagem e decida quando os agentes de chat ociosos param ou os mantêm em execução.
  • 🗂️ Mantenha os projetos organizados: Adicionar um projeto mantém as árvores de trabalho descobertas ocultas, enquanto a criação e a clonagem lidam com pastas pai com links simbólicos de forma consistente.
  • 📝 Faça sua própria leitura e edição: Defina a visualização Markdown padrão, opcionalmente insira uma nova linha final ao salvar e ajuste a largura do bate-papo nos cabeçalhos do painel.
  • 📱 Uma página inicial mais clara do telefone: O aplicativo de telefone atualizado separa Feed, Uso, Automações e Configurações, mostra mais uso do agente e nomeia conversas recentes.
  • 🧩 Pequenas correções no trabalho diário: Mantenha a posição de rolagem do terminal na entrada, abra links de arquivos em seu espaço de trabalho, renderize Mermaid em comentários de PR e feche divisões flutuantes do navegador em sua própria barra de ferramentas.

Destaques

  • Configuração e habilidades: Escolha Chat ou Terminal durante a integração, use o seletor de agente atualizado e a etapa de tema e instale habilidades de Chat para o provedor selecionado neste computador. Projetos vazios recém-adicionados podem abrir o agente do Chat escolhido quando essa rota for compatível.
  • Comportamento do bate-papo: Entradas e acompanhamentos em fila são retidos por meio de entrega incerta e Parada. Novas configurações controlam a posição de rolagem durante o envio e quando os agentes de bate-papo ociosos param. As imagens de bate-papo carregadas permanecem visíveis na rolagem e nas opções da área de trabalho, e a compactação Pi retém os envios até terminar.
  • Escolhas do agente: As contas gerenciadas do Claude mantêm /model posteriores e opções de esforço quando os padrões não foram alterados. O substituto de Claude é mostrado sem alterar as opções de modelo salvas; O esforço OpenCode segue o modelo selecionado e o chat Claude adiciona o esforço Ultracode.
  • Projetos e navegação: adicionar um projeto mantém as árvores de trabalho descobertas ocultas. A criação e a clonagem do projeto resolvem os pais vinculados de forma consistente; a ordem manual do espaço de trabalho e o tipo para pesquisar no seletor de agente do novo espaço de trabalho recebem correções.
  • Editor e navegador: Escolha a visualização Markdown padrão, ative Inserir nova linha final ao salvar, preserve a aparência HTML do bate-papo nas visualizações de arquivos e feche uma divisão flutuante do navegador sem fechar o terminal ao lado dele.
  • Telefone: O aplicativo atualizado adiciona guias iniciais, uso para mais agentes e nomes de conversas em Voltar. Ele também melhora a entrada do terminal, controles de esforço, visualizações de HTML e comportamento de tema/navegação do Android.
  • Automação e notificações: As automações usam o seletor de agente compartilhado, aceitam argumentos de modelo/pensamento Pi e são atualizadas quando os projetos mudam. As execuções de automação de terminal interrompidas são registradas como falhas, os alertas reconhecidos da área de trabalho são apagados e as notificações de conclusão do OpenCode tratam do OSC 7501.

Notas de compatibilidade e atualização

  • Opções de configuração existentes: As novas opções de integração usam preferências existentes de superfície e de agente. Esta versão não redefine o agente padrão de todos nem alterna todos os espaços de trabalho existentes para o Chat. Um espaço de trabalho com guias existentes os mantém; o caminho do Chat do novo projeto depende de um tempo de execução e agente suportados.
  • Configurações de bate-papo: A rolagem ao enviar e a parada do agente ocioso são configuráveis. Escolha Nunca se quiser que os agentes de chat ociosos continuem em execução; interromper um agente ocioso é diferente de excluir a conversa.
  • Contas gerenciadas do Claude: Os padrões inalterados param de substituir as escolhas de conta posteriores após a sincronização das configurações. Isso não recupera opções substituídas por uma compilação mais antiga e as chaves padrão alteradas ainda se aplicam.
  • Servidores emparelhados: Melhorias nos links de arquivos de servidores emparelhados usam o novo recurso quando disponível; servidores mais antigos mantêm seu caminho existente. Não há nova versão mínima do servidor para as alterações de configuração. As limitações de problemas do GitHub com servidores mais antigos permanecem abaixo.
  • Alterações no telefone: A interface nativa do telefone e as correções do Android exigem um aplicativo Orca Mobile atualizado, bem como um desktop ou servidor compatível. As alterações móveis estão incluídas no Orca Mobile 0.0.64; atualizar o desktop por si só não instala uma versão nativa do telefone.
  • Painel de orquestração: O painel experimental e suas configurações são desativados temporariamente novamente. As alterações nas mensagens de orquestração são separadas da disponibilidade desse painel.

Problemas conhecidos

Configuração de bate-papo sem agente padrão: Com a UI de bate-papo ativada e o agente padrão desmarcado em Configurações, o botão Instalar habilidades do Guia de configuração pode permanecer desativado sem explicação. Escolha um agente padrão, como Claude, antes de instalar.

Histórico do shell após uma reinicialização a frio: alguns painéis do shell do Mac podem reabrir sem mostrar a saída anterior após uma reinicialização completa do aplicativo e do terminal. Esta classe de falha também foi observada no v1.4.248; a causa permanece sem solução. Esta versão não pretende corrigi-lo.

Problemas do GitHub em servidores emparelhados mais antigos: Abrir um problema por meio de um repositório ou URL pode deixar a edição de título, rótulo e responsável indisponível. Problema de telefone Fechar/Reabrir também pode recusar um servidor ou intermediário mais antigo. Aberto em GitHub permanece disponível.

Armazenamento e desempenho de bate-papos salvos: a compactação do histórico ao vivo permanece pausada, para que o armazenamento possa aumentar à medida que as conversas continuam. Esta versão não pretende remover todas as fontes de travamentos de bate-papo. As alterações de gancho reduzem o trabalho do subprocesso, mas a latência de todo o aplicativo, as melhorias de CPU e de heap não foram medidas.

Longos atrasos na atualização: com um atraso de 14 ou 30 dias, uma versão pode sair do feed de atualização antes de se tornar elegível. Nenhum e Pular atraso uma vez permanecem disponíveis.

Substituições de comando de plug-in: Um plug-in que substitui um comando integrado ainda pode ser concluído depois que o Orca tiver usado o comando normal, fazendo com que a ação aconteça duas vezes.

orca v1.4.249

Easier setup, more control over chats & tidier workspaces ✨

  • 🎛️ Choose Chat or Terminal from the start: Onboarding now lets you pick Chat UI or Terminal, then choose an agent and install the skills for that setup.
  • 💬 Keep control of conversations: Preserve chat inputs through uncertain delivery and Stop, choose whether sending moves the scroll position, and decide when idle chat agents stop—or keep them running.
  • 🗂️ Keep projects tidy: Adding a project keeps discovered worktrees hidden, while create and clone handle symlinked parent folders consistently.
  • 📝 Make reading and editing your own: Set the default Markdown view, optionally insert a final newline on save, and adjust chat width from pane headers.
  • 📱 A clearer phone Home: The updated phone app separates Feed, Usage, Automations and Settings, shows more agent usage, and names recent conversations.
  • 🧩 Small fixes across daily work: Keep terminal scroll position on input, open file links in their workspace, render Mermaid in PR comments, and close floating browser splits from their own toolbar.

Highlights

  • Setup & skills: Pick Chat or Terminal during onboarding, use the updated agent picker and theme step, and install Chat skills for the selected provider on this computer. Empty newly added projects can open the chosen Chat agent when that route is supported.
  • Chat behavior: Inputs and queued follow-ups are retained through uncertain delivery and Stop. New settings control scroll position when sending and when idle chat agents stop. Loaded chat images stay visible across scrolling and workspace switches, and Pi compaction holds sends until it finishes.
  • Agent choices: Managed Claude accounts keep later /model and effort choices when the defaults have not changed. Claude fallback is shown without changing saved model choices; OpenCode effort follows the selected model, and Claude chat adds Ultracode effort.
  • Projects & navigation: Adding a project keeps discovered worktrees hidden. Project creation and cloning resolve symlinked parents consistently; manual workspace order and type-to-search in the new-workspace agent picker receive fixes.
  • Editor & browser: Choose the default Markdown view, enable Insert Final Newline on save, preserve chat HTML appearance in file previews, and close a floating browser split without closing the terminal beside it.
  • Phone: The updated app adds Home tabs, usage for more agents and conversation names in Jump back in. It also improves terminal input, effort controls, HTML previews and Android theme/navigation behavior.
  • Automation & notifications: Automations use the shared agent picker, accept Pi model/thinking arguments and refresh when projects change. Interrupted terminal automation runs are recorded as failed, acknowledged desktop alerts clear, and OpenCode completion notifications handle OSC 7501.

Compatibility & upgrade notes

  • Existing setup choices: The new onboarding choices use existing surface and agent preferences. This release does not reset everyone's default agent or switch every existing workspace to Chat. A workspace with existing tabs keeps them; the new-project Chat path depends on a supported runtime and agent.
  • Chat settings: Scroll-on-send and idle-agent stopping are configurable. Choose Never if you want idle chat agents to remain running; stopping an idle agent is separate from deleting the conversation.
  • Managed Claude accounts: Unchanged defaults stop overwriting later account choices after settings synchronization. This does not recover choices overwritten by an older build, and changed default keys still apply.
  • Paired servers: Improvements to paired-server file links use the new capability when available; older servers retain their existing path. There is no new minimum server version for the setup changes. GitHub issue limitations with older servers remain below.
  • Phone changes: Native phone UI and Android fixes require an updated Orca Mobile app as well as a compatible desktop or server. The mobile changes are included in Orca Mobile 0.0.64; updating desktop alone does not install a native phone release.
  • Orchestration panel: The experimental panel and its setting are temporarily disabled again. Orchestration messaging changes are separate from availability of that panel.

Known issues

Chat setup with no default agent: With Chat UI enabled and the default agent cleared in Settings, Setup Guide's Install skills button can remain disabled without an explanation. Choose a default agent, such as Claude, before installing.

Shell history after a cold restart: Some Mac shell panes can reopen without showing their previous output after a full app and terminal restart. This class of failure was also observed on v1.4.248; the cause remains unresolved. This release does not claim to fix it.

GitHub issues on older paired servers: Opening an issue through a repository or URL can leave title, label and assignee editing unavailable. Phone issue Close/Reopen can also refuse an older server or intermediary. Open on GitHub remains available.

Saved chat storage & performance: Live-history compaction remains paused, so storage can grow as conversations continue. This release does not claim to remove every source of chat stalls. Hook changes reduce subprocess work, but whole-app latency, CPU and heap improvements were not measured.

Long update delays: With a 14- or 30-day delay, a release can leave the update feed before it becomes eligible. None and Skip Delay Once remain available.

Plugin command replacements: A plugin replacing a built-in command can still finish after Orca has used the normal command instead, causing the action to happen twice.
