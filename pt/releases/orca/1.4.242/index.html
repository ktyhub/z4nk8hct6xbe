#orca v1.4.242

Com menos memória, Claude subagente a click de distância e servidores remotos que lembram 🪄

Esta versão é mais leve em memória, com menor uso de memória no host do terminal e nas conexões WSL, além de menos uso de CPU ociosa nos terminais. Ele também permite que você abra subagentes Claude diretamente da barra lateral, faz com que os bate-papos do Codex no modo Ask perguntem antes da edição e ajuda servidores emparelhados, hosts SSH e WSL a manter o controle e explicar falhas. Esta versão também corrige problemas no Windows, Linux e macOS.

A versão curta

  • Abra os subagentes Claude na barra lateral: Click uma linha de subagente Claude na barra lateral ou painel para abrir sua transcrição no mesmo terminal e, em seguida, click no pai para voltar. Um olho marca aquele que você está vendo.
  • Bate-papos que perguntam primeiro: Bate-papos do Codex no modo Perguntar agora perguntam antes de editar seu espaço de trabalho, terminais Claude remotos em servidores emparelhados podem continuar no bate-papo, e bate-papos que não podem iniciar informam o porquê.
  • Os agentes retomam como você os deixou: As sessões retomadas do Claude mantêm seu nível de esforço e iniciam sinalizadores, o Codex mantém a permissão que você concedeu pela última vez e o Histórico da sessão encontra bate-papos em mais pastas e em servidores.
  • Servidores remotos que lembram: Os servidores emparelhados mantêm suas guias durante as reinicializações, as guias fechadas permanecem fechadas, os hosts WSL param de emparelhar novamente após cada reinicialização e as falhas de SSH dizem o que realmente deu errado.
  • Menos memória: Os terminais usam muito menos CPU ociosa, o host do terminal usa menos memória na próxima reinicialização, as conexões WSL precisam de muito menos memória e o painel de recursos agora corresponde ao Activity Monitor no macOS.
  • Correções da comunidade: Caminhos de inicialização espaçados do Windows, entrada em coreano, horário de verão em automações, foco segue o mouse, arrastar guias e pacotes Linux funcionam melhor. Atualizações por telefone e web: os telefones agora explicam um computador inacessível em vez de ficar girando para sempre, e as respostas em streaming e os longos bate-papos na web são menos redesenhados. Os programas de terminal que fazem uma pergunta ao terminal também continuam funcionando enquanto o telefone assiste no tamanho de um desktop.

Notas de compatibilidade e atualização

  • Bate-papos do Codex no modo Ask: Ask agora é executado somente leitura e pergunta antes das edições do espaço de trabalho; Aprovar para mim e Acesso total permanecem inalterados, e o trabalho já em execução mantém sua concessão. Os bate-papos em um servidor emparelhado mantêm o comportamento antigo até que o servidor seja atualizado.
  • Navegação do subagente Claude: Ativado por padrão com ganchos de status do Claude. O Orca carrega seu plugin apenas nos painéis do Orca e adiciona um atalho, o primeiro livre de Ctrl+Alt+G, H ou V, para keybindings.json em cada pasta Claude que ele usa. Desative-o em Configurações → Agentes → Navegação do subagente Claude para remover esse atalho. As sessões de Claude já em execução precisam de um novo lançamento.
  • Servidores emparelhados: Mover um painel para uma nova guia e continuar um terminal remoto do Claude no Chat precisa do servidor para executar esta versão. Em servidores mais antigos, a movimentação permanece apenas nesta janela, como antes, e Continuar na interface do bate-papo aparece desabilitado com uma dica de atualização.
  • Troca de conta do Claude: A troca de conta agora também oferece o reinício de sessões em execução na pasta Claude padrão do sistema quando essa pasta estiver conectada à conta antiga. A caixa de diálogo agrupa as sessões naquelas da conta antiga, outras e aquelas que ela não pode mover.
  • Hosts WSL: As conexões com um servidor de host WSL agora passam pelo bash e retornam ao Node quando o bash está ausente ou é muito antigo. Não precisa de atualização do servidor e funciona com qualquer versão do servidor.

orca v1.4.242

Lighter on memory, Claude subagents a click away, and remote servers that remember 🪄

This release is lighter on memory, with lower memory use in the terminal host and WSL connections, plus less idle CPU use in terminals. It also lets you open Claude subagents straight from the sidebar, makes Codex chats in Ask mode ask before editing, and helps paired servers, SSH and WSL hosts keep your tabs and explain failures. This release also fixes problems across Windows, Linux and macOS.

The short version

  • Open Claude subagents from the sidebar: Click a Claude subagent row in the sidebar or dashboard to open its transcript in the same terminal, then click the parent to go back. An eye marks the one you’re viewing.
  • Chats that ask first: Codex chats in Ask mode now ask before editing your workspace, remote Claude terminals on paired servers can continue in Chat, and chats that can’t start tell you why.
  • Agents resume as you left them: Resumed Claude sessions keep their effort level and launch flags, Codex keeps the permission you last gave it, and Session History finds chats in more folders and on servers.
  • Remote servers that remember: Paired servers keep your tabs across restarts, closed tabs stay closed, WSL hosts stop re-pairing after each restart, and SSH failures say what actually went wrong.
  • Lighter on memory: Terminals use far less idle CPU, the terminal host uses less memory once it next restarts, WSL connections need much less memory, and the resource panel now matches Activity Monitor on macOS.
  • Fixes from the community: Spaced Windows launcher paths, Korean input, DST in automations, focus-follows-mouse, tab dragging and Linux packages all work better.

Phone & web updates: Phones now explain an unreachable computer instead of spinning forever, and streaming replies and long web chats redraw less. Terminal programs that ask the terminal a question also keep working while a phone watches at desktop size.

Compatibility & upgrade notes

  • Codex chats in Ask mode: Ask now runs read-only and asks before workspace edits; Approve for me and Full access are unchanged, and work already running keeps its grant. Chats on a paired server keep the old behavior until that server is updated.
  • Claude subagent navigation: On by default with Claude status hooks. Orca loads its plugin only into Orca panes and adds one shortcut, the first free of Ctrl+Alt+G, H or V, to keybindings.json in each Claude folder it uses. Turn it off in Settings → Agents → Claude subagent navigation to remove that shortcut. Claude sessions already running need a fresh launch.
  • Paired servers: Moving a pane into a new tab and continuing a remote Claude terminal in Chat need the server to run this release. On older servers the move stays in this window only, as before, and Continue in Chat UI shows disabled with an update hint.
  • Claude account switching: Switching accounts now also offers to restart sessions running in your System default Claude folder when that folder is signed in to the old account. The dialog groups sessions into those on the old account, others, and ones it can’t move.
  • WSL hosts: Connections to a WSL host’s server now go through bash and fall back to Node when bash is missing or too old. This needs no server update and works with any server version.
