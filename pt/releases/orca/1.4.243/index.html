#orca v1.4.243

Extensões do Chrome no navegador Orca, suporte para iPhone Duo e conversão de uma sessão de agente de terminal ao vivo em uma interface de bate-papo 🧩

Esta versão traz extensões do Chrome para o navegador Orca em fase experimental, permite que uma conversa continue no Chat depois que você sai do agente no terminal e mostra suas árvores de trabalho locais logo após a reinicialização. Ele também adiciona suporte para o iPhone Duo dobrável, menus compactos de estilo nativo, temas claros e escuros no telefone e correções para terminais Windows, hosts SSH e atualizações.

A versão curta

  • Extensões do Chrome (experimental): Adicione extensões da Chrome Web Store com Adicionar ao Orca, para que gerenciadores de senhas como Bitwarden e 1Password possam preencher logins no navegador do Orca. Desativado por padrão.
  • Converta uma sessão de agente de terminal ao vivo em uma interface de chat: Depois de sair do Claude ou do Codex em um terminal, a mesma conversa pode continuar no Chat enquanto a guia do terminal permanece aberta. Os bate-papos do Claude também mantêm suas opções de aprovação salvas nas alterações de modelo e fecham um bate-papo que ainda está funcionando primeiro.
  • Árvores de trabalho logo após a reinicialização: As árvores de trabalho locais são carregadas antes da restauração dos terminais, e a barra lateral informa que a descoberta ainda está em execução em vez de mostrar uma lista vazia.
  • Terminais mais estáveis: Os terminais do Windows mantêm seu histórico por meio de alterações de largura, os terminais inativos são ativados na pasta que você deixou, o bash integrado do macOS mantém o rastreamento de comandos em ordem após uma alteração na armadilha DEBUG e a cópia do pi em um host remoto chega ao seu clipboard.
  • Orquestração: Escolha o intervalo de pulsação do trabalhador ou desative as pulsações e reduza o uso da CPU impedindo que os trabalhadores estabelecidos pesquisem comandos.
  • Aperfeiçoe onde é importante: Menus compactos em estilo nativo, destaque de Markdown no estilo VS Code com títulos fixos e verificações de atualização por meio do proxy de configurações.
  • Correções da comunidade: Sair e parar todas as sessões, matemática em bate-papos, copiar URL remoto com intervalos de linhas, destaque de IME em terminais, fnm no Windows e traduções para japonês e chinês funcionam melhor. Atualizações por telefone e web: os telefones recebem temas claros e escuros, suporte para o iPhone Duo dobrável, PDFs no Quick Look e botões de cópia em bate-papos. Muitas telas de telefone agora seguem as regras do desktop para bate-papos, controle de origem e terminais, e a digitação e a rolagem em bate-papos longos permanecem rápidas.

Notas de compatibilidade e atualização

  • Host de terminal novo: Novos terminais iniciam em um host de terminal novo, portanto as correções de terminal desta versão se aplicam, incluindo a continuação de um bate-papo após a saída do agente de terminal. Os terminais já abertos antes da atualização continuam em execução e permanecem conectados no host anterior até você fechá-los.
  • Extensões de navegador (experimentais): ative Configurações → Experimental → Extensões de navegador, reinicie e abra a Chrome Web Store em uma guia do navegador Orca. As extensões são executadas apenas em perfis de navegador locais. Os bloqueadores de anúncios são instalados, mas ainda não bloqueiam, e algumas extensões, como Tampermonkey, não funcionam.
  • Pulsações do trabalhador: As pulsações permanecem a cada 5 minutos por padrão. As alterações em Configurações → Orquestração de Agentes se aplicam a trabalhadores recém-enviados; os trabalhadores que já estão em execução são breves e os hosts mais antigos, 5 minutos.
  • Navegação do subagente Claude: O olho que marcava o subagente que você está visualizando desapareceu. A linha do subagente visualizado usa o realce normal da linha atual.

orca v1.4.243

Chrome extensions in Orca’s browser, iPhone Duo support, and Convert a terminal agent session live into a chat ui 🧩

This release brings Chrome extensions to Orca’s browser under experimental, lets a conversation continue in Chat once you quit its agent in the terminal, and shows your local worktrees sooner after a restart. It also adds support for the folding iPhone Duo, compact native-style menus, light and dark themes on the phone, and fixes for Windows terminals, SSH hosts and updates.

The short version

  • Chrome extensions (experimental): Add extensions from the Chrome Web Store with Add to Orca, so password managers like Bitwarden and 1Password can fill logins in Orca’s browser. Off by default.
  • Convert a terminal agent session live into a chat ui: Once you quit Claude or Codex in a terminal, the same conversation can continue in Chat while the terminal tab stays open. Claude chats also keep their saved approval choice across model changes, and closing a chat that’s still working asks first.
  • Worktrees sooner after a restart: Local worktrees load before terminals restore, and the sidebar says discovery is still running instead of showing an empty list.
  • Steadier terminals: Windows terminals keep their history through width changes, slept terminals wake in the folder you left, macOS’s built-in bash keeps command tracking in order after a DEBUG trap change, and copying from pi on a remote host reaches your clipboard.
  • Orchestration: Choose the worker heartbeat interval or turn heartbeats off, and reduce CPU use by stopping settled workers from polling for commands.
  • Polish where it counts: Compact native-style menus, VS Code–style Markdown highlighting with sticky headings, and update checks through your Settings proxy.
  • Fixes from the community: Quit and Stop All Sessions, math in chats, Copy Remote URL with line ranges, IME highlighting in terminals, fnm on Windows, and Japanese and Chinese translations all work better.

Phone & web updates: Phones get light and dark themes, support for the folding iPhone Duo, PDFs in Quick Look and copy buttons in chats. Many phone screens now follow desktop’s rules for chats, Source Control and terminals, and typing and scrolling in long chats stay fast.

Compatibility & upgrade notes

  • Fresh terminal host: New terminals start on a fresh terminal host so this release’s terminal fixes apply, including continuing a chat after its terminal agent exits. Terminals already open before you update keep running, and stay attached, on the previous host until you close them.
  • Browser extensions (experimental): Turn on Settings → Experimental → Browser extensions, restart, then open the Chrome Web Store in an Orca browser tab. Extensions run in local browser profiles only. Ad blockers install but don’t block yet, and some extensions, such as Tampermonkey, don’t work.
  • Worker heartbeats: Heartbeats stay on every 5 minutes by default. Changes in Settings → Agent Orchestration apply to newly dispatched workers; workers already running keep their brief, and older hosts keep 5 minutes.
  • Claude subagent navigation: The eye that marked the subagent you’re viewing is gone. The viewed subagent row uses the normal current-row highlight.
