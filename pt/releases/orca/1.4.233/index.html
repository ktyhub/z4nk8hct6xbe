orca v1.4.233

#orca v1.4.233 Muito obrigado por usar o Orca e por seu apoio contínuo! ❤️ Enviamos dois lançamentos hoje! Se você perdeu, dê uma olhada nos v1.4.232 release notes também. Os destaques incluem permissões de agente Manual / Automático / Yolo, OpenCode 2 em bate-papo nativo, um melhor compositor de telefone com anexos de arquivos e habilidades inline, recuperação SSH mais suave e um aplicativo menor com atualizações mais rápidas para Mac. Atualizações do telefone: Atualizar o Orca no seu desktop também atualiza o aplicativo no seu telefone conectado – o telefone o carrega diretamente do seu desktop.

A versão curta

  • SSH e espaços de trabalho remotos: A conexão a um host SSH funciona quando nenhuma máquina pode baixar o Node.js, com um espelho click que o Orca lembra e tenta novamente. Hosts Windows mais antigos (Windows 10 1809 e Server 2019) podem executar o servidor Orca e os túneis se recuperam quando uma porta é mantida por uma conexão SSH antiga.
  • Servidores remotos em Configurações: Servidores Orca Remotos são uma lista em vez de seis seções, e os hosts SSH podem ser removidos em massa e permanecer removidos. O Orca informa quando o mesmo servidor foi salvo duas vezes e, em vez disso, adicionar um servidor que você já salvou o atualiza.
  • Telefone: Criar um espaço de trabalho a partir do telefone é muito mais rápido, a lista de espaços de trabalho acompanha a área de trabalho e os ícones das guias de sessão mantêm seu tamanho ao lado de títulos longos.
  • Editor: O Orca se recusa a salvar as alterações feitas em um arquivo no disco que você não viu, e Recarregar e Desfazer se comportam de maneira previsível depois.
  • Aperfeiçoamento diário: Projetos com o mesmo nome em máquinas diferentes mantêm nomes curtos e mostram em qual máquina estão. Conversas salvas há muito tempo usam muito menos memória quando o Orca as verifica em busca do histórico de sessão.

orca v1.4.233

Thank you so much for using Orca and for your continued support! ❤️

We shipped two releases today! If you missed it, check out the v1.4.232 release notes too. Highlights include Manual / Auto / Yolo agent permissions, OpenCode 2 in native chat, a better phone composer with file attachments and inline skills, smoother SSH recovery, and a smaller app with faster Mac updates.

Phone updates: Updating Orca on your desktop also updates the app on your connected phone—the phone loads it directly from your desktop.

The short version

  • SSH & remote workspaces: Connecting to an SSH host works when neither machine can download Node.js, with a one-click mirror Orca remembers and retries. Older Windows hosts (Windows 10 1809 and Server 2019) can run Orca's server, and tunnels recover when a port is held by an old SSH connection.
  • Remote servers in Settings: Remote Orca Servers is one list instead of six sections, and SSH hosts can be removed in bulk and stay removed. Orca tells you when the same server was saved twice, and adding a server you already saved updates it instead.
  • Phone: Creating a workspace from the phone is much faster, the workspace list stays in step with the desktop, and session tab icons keep their size beside long titles.
  • Editor: Orca refuses to save over changes made to a file on disk that you haven't seen, and Reload and Undo behave predictably afterwards.
  • Everyday polish: Projects with the same name on different machines keep short names and show which machine they're on. Long saved conversations use far less memory when Orca scans them for Session History.
