#garra aberta v2026.10.33 Esta é uma versão extended-stable somente gateway, que é nosso equivalente atual ao LTS. Esta versão é OpenClaw do final de outubro de 2026, além de atualizações críticas de segurança, correções de confiabilidade e desempenho e recursos como suporte a novos modelos. A versão mais recente do OpenClaw no momento deste lançamento é 2026.11.5 ##2026.10.33 Esta versão estável estendida traz melhorias cumulativas de gateway e plug-in principal desde 2026.9.37, além de correções de manutenção selecionadas na linha de base do produto 2026.11.4 aprovada. A distribuição cobre o pacote npm principal, plug-ins npm oficiais correspondentes e imagens do Gateway Docker; versões de aplicativos nativos não estão incluídas.

Destaques

  • Conversas longas e grandes armazenamentos de sessões utilizam trabalho limitado de exportação e recuperação, reduzindo falhas de falta de memória durante bate-papo, exportação de memória, reparo médico e inicialização do Gateway. (#194066, #196158, #195459, #196480, #176737, #181289) De autoria de @steipete. Obrigado @RomneyDa, @vincentkoc, @ericcaiwx-star, @obviyus, @garrytan e @oxen-horse.
  • As atualizações interrompidas são recuperadas quando seu executor morre, em vez de deixar o gateway preso off-line, enquanto as verificações de distorção de versão protegem o estado ainda usado por um serviço instalado. (#181695, #186971, #187819) De autoria de @steipete. Obrigado @RomneyDa, @PonySlayer28, @tomdailey55, @jalehman, @fuller-stack-dev e @vincentkoc.
  • As respostas sobrevivem a mais caminhos de reinicialização e reconexão, preservando os prompts originais, recuperando as respostas do Telegram e evitando respostas perdidas do WhatsApp ou mensagens ignoradas do Signal. (#187157, #195400, #168778, #187667) Obrigado @shakkernerd, @jason-allen-oneal, @mcaxtr, @HermanZeng e @obviyus.
  • A privacidade da sessão compartilhada é mais forte: o bate-papo paralelo permanece privado para o visualizador, os prompts do modelo interno ficam fora da saída exibida e a compactação edita as credenciais nos resumos citados. (#185390, #173460, #197349) De autoria de @steipete. Obrigado @Satoshi-Kusumoto, @RomneyDa, @zhangguiping-xydt, @Patrick-Erichsen e @obviyus.

  • As habilidades instaladas podem ser pesquisadas e lidas sob demanda, ajudando os agentes a encontrar instruções relevantes sem colocar todas as habilidades instaladas no prompt. (#158089, #158090, #158091, #160538) De autoria de @steipete. Obrigado @RomneyDa e @vincentkoc.
  • As sessões podem importar transcrições existentes do Claude Code ou Codex e mover-se entre ambientes locais e de nuvem, com receitas de repositório e progresso de inicialização da nuvem mais claro. (#161955, #171690, #170862, #170895) De autoria de @steipete. Obrigado @joshavant e @RomneyDa.

openclaw v2026.10.33

This is a gateway-only extended-stable release, which is our current equivalent to LTS. This release is OpenClaw from the end of October 2026, plus critical security updates, reliability and performance fixes, and features like new model support. The latest version of OpenClaw at the time of this release is 2026.11.5

2026.10.33

This extended-stable release brings cumulative Gateway and core-plugin improvements since 2026.9.37, plus the selected maintenance fixes on the approved 2026.11.4 product baseline. Distribution covers the core npm package, matching official npm plugins, and Gateway Docker images; native-app releases are not included.

Highlights

  • Long conversations and large session stores use bounded export and recovery work, reducing out-of-memory failures during chat, memory export, Doctor repair, and Gateway startup. (#194066, #196158, #195459, #196480, #176737, #181289) Authored by @steipete. Thanks @RomneyDa, @vincentkoc, @ericcaiwx-star, @obviyus, @garrytan, and @oxen-horse.
  • Interrupted updates recover when their executor dies instead of leaving the Gateway stuck offline, while version-skew checks protect state still used by an installed service. (#181695, #186971, #187819) Authored by @steipete. Thanks @RomneyDa, @PonySlayer28, @tomdailey55, @jalehman, @fuller-stack-dev, and @vincentkoc.
  • Replies survive more restart and reconnect paths, preserving original prompts, recovering Telegram responses, and avoiding lost WhatsApp replies or skipped Signal messages. (#187157, #195400, #168778, #187667) Thanks @shakkernerd, @jason-allen-oneal, @mcaxtr, @HermanZeng, and @obviyus.
  • Shared-session privacy is stronger: Side chat stays private to its viewer, internal model prompts stay out of displayed output, and compaction redacts credentials in quoted summaries. (#185390, #173460, #197349) Authored by @steipete. Thanks @Satoshi-Kusumoto, @RomneyDa, @zhangguiping-xydt, @Patrick-Erichsen, and @obviyus.
  • Automations can react to polled conditions and MCP events, run repeatable scripts, and use explicitly allowed MCP servers. (#101195, #165399, #160996, #160995) Authored by @steipete. Thanks @obviyus.
  • Installed skills can be searched and read on demand, helping agents find relevant instructions without putting every installed skill into the prompt. (#158089, #158090, #158091, #160538) Authored by @steipete. Thanks @RomneyDa and @vincentkoc.
  • Sessions can import existing Claude Code or Codex transcripts and move between local and cloud environments, with repository recipes and clearer cloud-startup progress. (#161955, #171690, #170862, #170895) Authored by @steipete. Thanks @joshavant and @RomneyDa.

Additional maintenance fixes

  • Provider continuity: preserve server compaction checkpoints across credential or model changes on the same provider API and endpoint, avoiding unnecessary history replay. (#200063, #200208) Thanks @obviyus.
  • macOS installation: preserve the controlling terminal during shell installation so onboarding can install plugins without detached Node subprocesses aborting. (#200247) Thanks @miguelbranco80.
