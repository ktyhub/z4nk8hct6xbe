#moby docker-v29.9.1

##29.9.1

Para obter uma lista completa de solicitações pull e alterações nesta versão, consulte os marcos relevantes do GitHub:

  • docker/cli, marco 29.9.1
  • moby/moby, marco 29.9.1

Segurança

A atualização do containerd para v2.4.2 inclui correções para as seguintes vulnerabilidades de segurança:

  • CVE-2026-95839: Extrair ou importar uma imagem por meio do serviço de transferência do containerd poderia travar o containerd se um descritor filho contivesse a anotação io.containerd.manifest.subject e um resumo malformado.
  • GHSA-8647-2jxj-p2rc: Um registro untrusted que retorna um cabeçalho Content-Length criado pode travar o contêiner quando a busca de camada paralela foi habilitada com concurrent_layer_fetch_buffer.
  • GHSA-hc94-p972-ch66: Extrair uma imagem criada ou extrair de um registro malicioso pode esgotar o espaço em disco do host porque o containerd não limitou os dados da camada de entrada ao tamanho declarado antes da validação.

Correções de bugs e melhorias

  • Corrigido --link-local-ip aceitando endereços que não são link-local (169.254.0.0/16 ou fe80::/10) ao criar um contêiner ou conectá-lo a uma rede, o que fazia com que o contêiner não iniciasse. moby/moby#53923
  • Correção de falha de COPY --from no construtor clássico em arquivos que não pertencem ao root quando userns-remap está habilitado. moby/moby#53859
  • Correção de docker ps -s e listagem de contêineres com tamanhos falhando totalmente quando o tamanho de um contêiner não pode ser calculado. moby/moby#53921
  • Corrigido docker save deixando camadas de imagem no disco após a imagem ser removida, quando a imagem contém a mesma camada mais de uma vez (armazenamento de imagens do driver gráfico). moby/moby#53927
  • Corrigido um pânico de daemon ao usar o driver de log fluentd com um endereço TLS que não pode ser conectado e fluentd-async habilitado. moby/moby#53922
  • Correção da falha na resolução do resumo da imagem quando um espelho do registro é bem-sucedido, mas uma pesquisa de registro subsequente falha. moby/moby#53933
  • Correção do sucesso do relatório de pesquisa de privilégios do plug-in quando a busca do plug-in falha. moby/moby#53934

Atualizações de embalagens

  • Atualize o containerd (binários estáticos) para v2.4.2. moby/moby#53936

Rede

  • Não adicione interfaces de rede bridge à zona docker do firewalld quando iptables e ip6tables estiverem desabilitados. moby/moby#53907
  • Correção de falha de restauração de redes de ponte na inicialização do daemon quando sua ponte está vinculada a uma zona firewalld diferente de docker. moby/moby#53907

Sem raiz

  • Corrigir --domainname com namespaces de usuário e modo sem root; isso requer um tempo de execução OCI que suporte o campo domainname (como runc >= v1.2.0). moby/moby#53899
  • Atualize RootlessKit para v3.3.0. moby/moby#53942

moby docker-v29.9.1

29.9.1

For a full list of pull requests and changes in this release, refer to the relevant GitHub milestones:

  • docker/cli, 29.9.1 milestone
  • moby/moby, 29.9.1 milestone

Security

The containerd update to v2.4.2 includes fixes for the following security vulnerabilities:

  • CVE-2026-95839: Pulling or importing an image through containerd's transfer service could crash containerd if a child descriptor contained the io.containerd.manifest.subject annotation and a malformed digest.
  • GHSA-8647-2jxj-p2rc: An untrusted registry returning a crafted Content-Length header could crash containerd when parallel layer fetching was enabled with concurrent_layer_fetch_buffer.
  • GHSA-hc94-p972-ch66: Pulling a crafted image or pulling from a malicious registry could exhaust host disk space because containerd did not limit incoming layer data to the declared size before validation.

Bug fixes and enhancements

  • Fix --link-local-ip accepting addresses that are not link-local (169.254.0.0/16 or fe80::/10) when creating a container or connecting it to a network, which made the container fail to start. moby/moby#53923
  • Fix COPY --from in the classic builder failing for files not owned by root when userns-remap is enabled. moby/moby#53859
  • Fix docker ps -s and container listing with sizes failing entirely when the size of one container cannot be computed. moby/moby#53921
  • Fix docker save leaving image layers on disk after the image is removed, when the image contains the same layer more than once (graph-driver image store). moby/moby#53927
  • Fix a daemon panic when using the fluentd log driver with a TLS address that cannot be connected to and fluentd-async enabled. moby/moby#53922
  • Fix image digest resolution failing when a registry mirror succeeds but a subsequent registry lookup fails. moby/moby#53933
  • Fix plugin privilege lookup reporting success when fetching the plugin fails. moby/moby#53934

Packaging updates

  • Update containerd (static binaries) to v2.4.2. moby/moby#53936

Networking

  • Don't add bridge network interfaces to firewalld's docker zone when iptables and ip6tables are both disabled. moby/moby#53907
  • Fix bridge networks failing to restore on daemon startup when their bridge is bound to a firewalld zone other than docker. moby/moby#53907

Rootless

  • Fix --domainname with user namespaces and rootless mode; this requires an OCI runtime supporting the domainname field (such as runc >= v1.2.0). moby/moby#53899
  • Update RootlessKit to v3.3.0. moby/moby#53942
