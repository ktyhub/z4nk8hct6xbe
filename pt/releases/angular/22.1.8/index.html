angular v22.1.8

Highlights

  • httpResource abort cleanup — 850db9d999 removes the abort listener on the abort branch too, not only on successful completion. If you use the signals-based httpResource with frequent cancellation (type-ahead search, rapid navigation), every cancelled request previously left a dangling listener behind — a slow, cumulative leak in long-lived components. Safe to adopt; no behavioral change beyond cleanup.
  • Hydration stability — cfa8967683 makes cleanup of dehydrated views wait for application stability, and c3e8f29b3f clears references retained by the idle scheduler. For SSR/incremental-hydration apps this closes a teardown race where a deferred view could be reclaimed while still scheduled, and releases stale references that kept components alive. Expect slightly later placeholder cleanup, not different rendering.
  • jsaction map hardening — d7d5401cd5 stops using plain objects as maps for jsaction (global event-delegation) data. Plain-object maps are vulnerable to prototype pollution when keys collide with Object.prototype (__proto__, constructor), so this is a security-flavored correctness fix in Angular's event layer. No API change, but a solid reason to take the patch if any delegated event keys derive from untrusted input.
  • Compiler typing and i18n limits — 02e83dc288 avoids TypeScript's instantiation/complexity limits when a template carries many translations; large i18n templates that failed ngc with opaque TS-limit errors should now compile. The remaining fixes (4e5f4c38a7, 024ebe668c, b3c5824bd6, 9b854f6e76) tighten return/parameter types in pure functions and generated code. Library authors should note fe671d9024: the linker now emits function return types, so partial-compiled packages hold up under downstream strict TS checks.
  • Router, forms, and SSR edge cases — 2cab6f5964 avoids dense-array allocation for numeric URL keys, removing a memory spike for routes keyed by high-cardinality numeric params. 78c7ab3926 creates form controls before registering listeners, eliminating an init-order hazard where an event could fire before its control existed. 330083f250 preserves Unicode whitespace in ServerXhr URLs, so server-side HTTP requests are no longer silently trimmed/normalized. All are correctness/perf fixes with no API impact.
  • Breaking changes — None in this release (fix-only patch).
