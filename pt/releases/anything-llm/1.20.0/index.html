Extensão do navegador atualizada

A [extensão do navegador] (https://github.com/Mintplex-Labs/anythingllm-extension) foi aprimorada além de sua função original de apenas coletar documentos para agora uma barra de bate-papo de IU completa com a capacidade de corrigir click -> Adicionar contexto (texto e imagem) e conversar diretamente no Chrome. Esta barra lateral deve ter paridade total para ferramentas e muito mais com a IU de bate-papo tradicional. Embora seja compatível com versões anteriores e futuras, apenas a funcionalidade completa é esperada quando o servidor e a extensão estão na versão 1.20.0 ou posterior. A loja virtual do Chrome também foi atualizada para esta versão. https://github.com/user-attachments/assets/830069a6-34cb-4f37-80b0-6d52eb4622d0

Revisão da ferramenta PowerPoint

<img largura="1990" altura="1099" alt="geração pptx" src="https://github.com/user-attachments/assets/05689972-1296-4869-b208-dd9301222dd3" /> A ferramenta PowerPoint do agente foi totalmente reconstruída para produzir apresentações mais limpas e com melhor aparência. - **Temas e layouts:** as apresentações usam novos temas de cores e um conjunto de layouts que são escolhidos para se ajustarem ao conteúdo de cada slide, para que o mesmo layout não seja repetido slide após slide. - **Pré-visualizações de slides ao vivo:** os slides aparecem no bate-papo à medida que são criados, para que você possa ver a apresentação se formando. Click uma prévia para vê-lo em tamanho real. - **Conteúdo fundamentado:** figuras, valores de gráficos e citações são mantidos apenas quando seu esboço, pesquisa ou conversa os contém, e o texto é dimensionado para caber em cada slide. ### Cartões de aprovação de e-mail para Gmail e Outlook <img width="1990" height="1099" alt="email-drafting" src="https://github.com/user-attachments/assets/0b571869-c43b-454f-bdf1-0e2e3d4b4beb" /> Quando um agente deseja enviar ou redigir um e-mail com as ferramentas [Gmail](https://docs.anythingllm.com/agent/usage/gmail-agent) ou [Outlook](https://docs.anythingllm.com/agent/usage/outlook-agent), a solicitação de aprovação agora é mostrada como um cartão de e-mail. Você pode editar os destinatários, Cc, Bcc, assunto e corpo diretamente no cartão antes de aprová-lo. O cronômetro de aprovação faz uma pausa enquanto você edita e você pode expandir um e-mail enviado para ver exatamente o que foi enviado. ### Melhorias no MCP - **Encaminhamento de identidade:** os servidores MCP agora podem receber o espaço de trabalho e o usuário que os está chamando. Ative por servidor com `anythingllm.forwardIdentity`. Consulte [Encaminhando identidade para servidores MCP](https://docs.anythingllm.com/mcp-compatibility/forward-identity). - **Tempos limite por servidor:** defina `anythingllm.timeout` (em segundos) em um servidor MCP para controlar por quanto tempo suas chamadas de ferramenta podem ser executadas. O padrão é 60 segundos. - **Desenvolvedor API:** os novos endpoints `/v1/mcp-servers` permitem listar, adicionar, atualizar, excluir, iniciar, parar e recarregar servidores MCP e ativar ou desativar ferramentas individuais. - Servidores MCP com muitas ferramentas agora carregam todas as páginas de ferramentas, iniciar um servidor também coleta quaisquer servidores recém-salvos e servidores anything-llm v1.20.0

Updated browser extension

The browser extension has been improved beyond its original function of just collecting documents to now a full fledged UI chat bar with the ability to right click -> Add context (text and image) and chat directly in Chrome. This sidebar should have mostly full parity for tooling and more with the traditional chat UI.

While it is backward and forward compatible, only full functionality is expected when the server and extension are on version 1.20.0 or later. The Chrome webstore has been updated to this version as well.

https://github.com/user-attachments/assets/830069a6-34cb-4f37-80b0-6d52eb4622d0

PowerPoint tool overhaul

<img width="1990" height="1099" alt="pptx-generation" src="https://github.com/user-attachments/assets/05689972-1296-4869-b208-dd9301222dd3" />

The agent's PowerPoint tool has been rebuilt from the ground up to produce cleaner, better looking presentations.

  • Themes and layouts: decks use new color themes and a set of layouts that are picked to fit each slide's content, so the same layout is not repeated slide after slide.
  • Live slide previews: slides appear in the chat as they are built, so you can watch the deck come together. Click a preview to see it full size.
  • Grounded content: figures, chart values and quotes are only kept when your outline, research or conversation contains them, and text is sized to fit each slide.

Email approval cards for Gmail and Outlook

<img width="1990" height="1099" alt="email-drafting" src="https://github.com/user-attachments/assets/0b571869-c43b-454f-bdf1-0e2e3d4b4beb" />

When an agent wants to send or draft an email with the Gmail or Outlook tools, the approval request is now shown as an email card. You can edit the recipients, Cc, Bcc, subject and body right in the card before you approve it. The approval timer pauses while you edit, and you can expand a sent email to see exactly what went out.

MCP improvements

  • Identity forwarding: MCP servers can now receive the workspace and user that is calling them. Opt in per server with anythingllm.forwardIdentity. See Forwarding identity to MCP servers.
  • Per-server timeouts: set anythingllm.timeout (in seconds) on an MCP server to control how long its tool calls can run. The default is 60 seconds.
  • Developer API: new /v1/mcp-servers endpoints let you list, add, update, delete, start, stop and reload MCP servers, and turn individual tools on or off.
  • MCP servers with many tools now load every page of tools, starting one server also picks up any newly saved servers, and disconnected servers can be deleted.
