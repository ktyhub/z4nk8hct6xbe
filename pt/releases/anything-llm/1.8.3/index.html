anything-llm v1.8.3

Highlights

  • Built-in Browser Tool for authenticated scraping — The headline capability of 1.8.3 (desktop): agents can now scrape private, authenticated, or otherwise gated pages, not just public web content. That makes RAG ingestion and agent web-scraping flows viable against internal wikis, logged-in portals, and paywalled sources that were previously invisible to the collector. Test it against your gated sources before exposing it to end users — the docs link in the release notes governs scope, and this materially widens what an agent can reach.

  • Community Hub publishing for reusable config — System prompts (#3976), agent flows (#4001), and slash commands (#4019) can now be published to the AnythingLLM Community Hub. This turns previously local, copy-pasted configuration into shareable artifacts, which matters if you standardize a prompt/flow setup across teams or deployments — you can distribute and reuse instead of hand-recreating it per instance.

  • Auth hardening and prompt-variable visibility changes — A new flag lets you disable the login UI and its endpoints when running with credentialed auth (#3984), useful for locking down single-user or embedded deployments. Separately, statically defined prompt variables become readable by any authorized user (#4086): convenient, but if your model assumed those variables were owner-scoped, revisit that assumption — the access boundary widened.

  • Embed widget and streaming behavior — The embed chat widget now actually honors prompt, model, and temperature overrides (#4036); if you had pinned those in an embedded integration and wondered why they were ignored, that is fixed — recheck your widget config after upgrading. The generic OpenAI provider gains an env-controlled option to disable streaming (#4079), and query-mode chats get a discoverability hint (#4076). Watch widget behavior if you relied on the previous override semantics.

  • Vector ranking, tokenizer, and collector fixes with downstream effects — Relevance score reporting is corrected for Milvus, Zilliz, and Pinecone (#4106), so ranking and any relevance cutoffs you tuned against the old (wrong) scores may shift — re-validate thresholds after upgrade. Also patched: a tokenizer race condition (#4091), zero-value embeddings from LMStudio (#4084), YouTube transcript scraping broken by Google API changes (#4005), and local credentials-file support for Amazon Bedrock (#3986).

  • No breaking changes in this release.
