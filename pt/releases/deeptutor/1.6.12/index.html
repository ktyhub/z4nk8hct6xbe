#Deep Tutor v1.6.12 #DeepTutor v1.6.12 Release Notes Data de lançamento: 2026.09.27 Com base no v1.6.11, o v1.6.12 permite que cada espaço de trabalho coloque e mova suas bases de conhecimento, conecte arquivos Kiwix pesquisáveis e transfira figuras de origem para respostas fundamentadas. Um quadro de tarefas, interface em alemão e correções de recuperação completam o lançamento. Os dados existentes não precisam de migração; As instalações do systemd agora são atualizadas fora do aplicativo.

Novidades

As bases de conhecimento seguem o espaço de trabalho

Escolha o espaço de trabalho de armazenamento ao criar uma base de conhecimento. Mova uma base existente do painel Configurações após revisar os bloqueadores de destino e as atribuições afetadas; DeepTutor verifica os dados copiados e o índice antes de mudar de referência. Os IDs da base de conhecimento salvos e as atribuições do espaço de trabalho continuam a ser resolvidos. As movimentações são bloqueadas durante o processamento ou quando concessões compartilhadas, colisões de destino ou dados MarginNote não suportados as tornam inseguras.

Conecte arquivos Kiwix

Conecte um arquivo ZIM pesquisável servido pelo kiwix-serve como base de conhecimento do Knowledge Center ou deeptutor kb connect-kiwix. A pesquisa lê o arquivo sob demanda, sem carregar ou indexar uma cópia. Você também pode trazer um artigo para a Leitura Imersiva. A remoção da conexão deixa o arquivo intacto.

Números de origem em respostas fundamentadas

O pipeline de conhecimento LlamaIndex pode reter imagens PDF e EPUB extraídas pelo analisador junto com suas legendas e locais de origem. Quando a recuperação encontra um, um modelo de resposta com capacidade de visão vê os pixels verificados; modelos somente texto recebem a legenda e o contexto com um limite explícito. A leitura imersiva pode inspecionar uma figura armazenada sob demanda. Isso depende de um analisador que emita imagens e reindexa o conteúdo mais antigo; consulte Notas de atualização.

Quadro de tarefas e controles de aprendizagem

Um quadro de tarefas local do espaço de trabalho rastreia cartões de tarefas, em andamento e concluídos com notas, controles de movimentação acessíveis e um arquivo restaurável. A Aprendizagem Guiada agora respeita uma preferência explícita de ensinar primeiro e oferece um próximo passo localizado. Professor e aluno ingressam nos valores aceitos de função não administrativa sem obter privilégios de administrador.

Idiomas e provedores

O alemão junta-se aos idiomas da interface e o malaio torna-se uma opção de idioma de resposta. Cheaper Inference junta-se a provedores de LLM; os embeddings locais do Lemonade funcionam sem uma chave API. As solicitações de imagem, vídeo e fala do DashScope usam endpoints, tamanhos e IDs de modelo suportados; perfis de fala salvos do DashScope paraformer-v2 migram para paraformer-realtime-v2 automaticamente.

Confiabilidade e acessibilidade

Os envios de bate-papo com falha permanecem recuperáveis em novas tentativas e corridas de armazenamento, e os turnos não respondidos podem ser recuperados de um trabalhador perdido. O LightRAG reutiliza apenas caches de indexação compatíveis, os números recuperados permanecem dentro do contexto do modelo limitado e as falhas parciais do Deep Research e do Manim relatam sua causa. As dicas de ferramentas compartilhadas substituem dicas de títulos nativos inacessíveis nos controles de aprendizagem e do espaço de trabalho, incluindo interações por toque.

Notas de atualização

  • Kiwix: execute uma instância kiwix-serve acessível com pesquisa de texto completo para o ZIM escolhido e, em seguida, conecte o URL do servidor e o nome do arquivo. Desconectar apenas remove o ponteiro do DeepTutor.
  • Figuras mais antigas da base de conhecimento: reindexar arquivos de origem LlamaIndex existentes para criar registros visuais. MinerU e PyMuPDF4LLM podem emitir imagens suportadas; o analisador somente texto padrão e o adaptador Docling atual não. Outros motores RAG ainda não indexam os registros visuais.
  • instalações do systemd: a transferência de atualização no aplicativo está desabilitada para um serviço em execução. Pare o serviço, atualize o DeepTutor no ambiente Python desse serviço e reinicie-o com systemctl.
  • Transcrição de microfone do Windows: adaptadores de fala nativos DashScope e Volcengine precisam de ffmpeg no serviço PATH para converter áudio WebM/Opus do navegador; reinicie o DeepTutor após instalá-lo. DeepTutor v1.6.12

Highlights

  • Workspace-scoped knowledge bases — You can now pick a storage workspace at KB creation and relocate an existing base from its Settings panel; DeepTutor verifies the copied data and index before flipping references, and saved KB IDs/workspace assignments keep resolving, so there's nothing to migrate. Treat moves as a maintenance step, not a live operation: they're blocked during processing, with shared grants, on destination collisions, or with unsupported MarginNote data.

  • Kiwix ZIM archives as live knowledge bases — Connect a kiwix-serve URL plus archive name (via the Knowledge Center or deeptutor kb connect-kiwix) and search reads the ZIM on demand — no upload and no indexing copy — so large reference corpora cost no storage or ingest time. The chosen ZIM must have full-text search enabled; disconnecting only drops DeepTutor's pointer and leaves the archive untouched, making it low-risk to trial.

  • Figures reach grounded answers — The LlamaIndex pipeline can retain parser-extracted PDF/EPUB images with captions and source locations: vision-capable answer models see the actual pixels, while text-only models get caption plus context under an explicit token limit, and Immersive Reading can open stored figures on demand. This only activates for parsers that emit images (MinerU, PyMuPDF4LLM) and requires reindexing old files — the default text-only parser, current Docling adapter, and non-LlamaIndex engines won't populate visual records, so don't expect it to light up on existing content automatically.

  • Task Board and role semantics — A workspace-local board (To do / In progress / Done) with notes, accessible move controls, and a restorable archive adds lightweight workflow state without leaving DeepTutor. Note that teacher and student are newly accepted non-admin role values — handy for permission modeling, but they intentionally carry no admin privileges, so any code that treats new role strings as elevated should be reviewed.

  • Providers, languages, and config drift — German UI, Malay reply language, a "Cheaper Inference" provider, and local Lemonade embeddings with no API key broaden deployment options, especially for air-gapped or cost-sensitive setups. DashScope image/video/speech calls now use supported endpoints, sizes, and model IDs, and saved paraformer-v2 speech profiles auto-migrate to paraformer-realtime-v2; on Windows, native DashScope/Volcengine STT now needs ffmpeg on the service PATH to transcode browser WebM/Opus audio (restart after install) — OpenAI-compatible STT is unaffected.

  • Recovery and cache correctness — Failed chat submissions survive retries and storage races, and unanswered turns can be recovered from a lost worker, tightening reliability under concurrency. LightRAG reuses only compatible indexing caches (incompatible ones are ignored, so expect a reindex), retrieved figures stay within bounded model context, and partial Deep Research/Manim failures now surface their cause; native title hints are also replaced with shared, touch-friendly tooltips across learning and workspace controls.

No breaking changes — existing data requires no manual migration.

DeepTutor v1.6.12 Release Notes

Release Date: 2026.09.27

Building on v1.6.11, v1.6.12 lets each workspace place and move its knowledge bases, connects searchable Kiwix archives, and carries source figures into grounded answers. A Task Board, German interface, and recovery fixes round out the release. Existing data needs no migration; systemd installs now update outside the app.

What's New

Knowledge bases follow the workspace

Choose the storage workspace when creating a knowledge base. Move one existing base from its Settings panel after reviewing destination blockers and affected assignments; DeepTutor verifies the copied data and index before switching references. Saved knowledge-base IDs and workspace assignments continue to resolve. Moves are blocked while processing or when shared grants, destination collisions, or unsupported MarginNote data make them unsafe.

Connect Kiwix archives

Connect one searchable ZIM archive served by kiwix-serve as a knowledge base from the Knowledge Center or deeptutor kb connect-kiwix. Search reads the archive on demand without uploading or indexing a copy. You can also bring an article into Immersive Reading. Removing the connection leaves the archive untouched.

Source figures in grounded answers

The LlamaIndex knowledge pipeline can retain parser-extracted PDF and EPUB images alongside their captions and source locations. When retrieval finds one, a vision-capable answer model sees the verified pixels; text-only models receive the caption and context with an explicit limit. Immersive Reading can inspect a stored figure on demand. This depends on a parser that emits images and reindexing older content; see Upgrade Notes.

Task Board and learning controls

A workspace-local Task Board tracks To do, In progress, and Done cards with notes, accessible move controls, and a restorable archive. Guided Learning now respects an explicit teach-first preference and gives a localized next step. Teacher and student join the accepted non-admin role values without gaining admin privileges.

Languages and providers

German joins the interface languages, and Malay becomes a reply-language option. Cheaper Inference joins LLM providers; local Lemonade embeddings work without an API key. DashScope image, video, and speech requests use supported endpoints, sizes, and model IDs; saved DashScope paraformer-v2 speech profiles migrate to paraformer-realtime-v2 automatically.

Reliability and accessibility

Failed chat submissions remain recoverable across retries and storage races, and unanswered turns can recover from a lost worker. LightRAG reuses only compatible indexing caches, retrieved figures stay within bounded model context, and partial Deep Research and Manim failures report their cause. Shared tooltips replace inaccessible native title hints across learning and workspace controls, including touch interactions.

Upgrade Notes

Run pip install -U deeptutor; Docker users pull ghcr.io/hkuds/deeptutor:latest. Existing data needs no manual migration.

  • Kiwix: run a reachable kiwix-serve instance with full-text search for the chosen ZIM, then connect its server URL and archive name. Disconnecting only removes the DeepTutor pointer.
  • Older knowledge-base figures: reindex existing LlamaIndex source files to create visual records. MinerU and PyMuPDF4LLM can emit supported images; the default text-only parser and current Docling adapter do not. Other RAG engines do not index the visual records yet.
  • systemd installs: in-app update handoff is disabled for a running service. Stop the service, upgrade DeepTutor in that service's Python environment, and start it again with systemctl.
  • Windows microphone transcription: native DashScope and Volcengine speech adapters need ffmpeg on the service PATH to convert browser WebM/Opus audio; restart DeepTutor after installing it. OpenAI-compatible STT does not need local conversion.
