#Deep Tutor v1.6.14

#DeepTutor v1.6.14 Release Notes

Data de lançamento: 2026.10.08

Com base no v1.6.13, o v1.6.14 traz prática visual de fonte original, indexação de base de conhecimento recuperável, ferramentas de pesquisa científica e plug-ins gerenciados. A aprendizagem por vídeo agora vive em Reading; As conversas existentes do Watch migram quando reabertas.

Novidades

Figuras originais, páginas e prática visual

Pergunte sobre uma figura, tabela ou página PDF exata em uma base de conhecimento anexa. DeepTutor recupera a imagem original ou renderiza a página ou região selecionada, preservando a identidade do documento e os links de origem. A visualização Arquivos expõe a cobertura visual da origem, incluindo extração ausente ou não verificada. A Aprendizagem Guiada utiliza esta evidência para questões visuais e distingue explicações, prática assistida e domínio independente; evidências inacessíveis ou incertas permanecem sem classificação.

Indexação que pode recuperar

Os detalhes da base de conhecimento mostram o progresso da indexação durável, resultados de fontes individuais e informações de recuperação. As novas tentativas reutilizam análises concluídas compatíveis e fatias de nuvem MinerU validadas; o cancelamento entra em vigor em um limite seguro. LlamaIndex publica uma nova versão somente após recarregamento, validação de vetor e uma investigação de recuperação bem-sucedida, preservando uma versão consultável anterior quando uma reconstrução falha. A recuperação também relata substitutos híbridos para vetores e evidências incompletas de IMA.

A leitura inclui aprendizado por vídeo

A mídia YouTube e Bilibili compartilham o espaço de trabalho de leitura, com discussão baseada em carimbo de data/hora e reprodução nativa. Anterior As conversas, posições e notas podem ser importadas sem modificar sua mídia legada ou registros de notebook. Os painéis de leitura são redimensionados de forma independente, oferecem uma predefinição de foco e mantêm a paginação utilizável e os controles de seleção em telas estreitas.

Pesquisa com evidências rastreáveis

Solicitações científicas e Deep Research ganham ferramentas para ler artigos arXiv versionados e páginas originais, verificar as reivindicações do artigo em relação a uma revisão GitHub fixada e construir matrizes de evidências de literatura. O catálogo MCP adiciona alphaXiv. Os administradores podem aprovar uma origem MCP exata de rede privada para conexões de pesquisa de propriedade da conta, com a aprovação verificada novamente quando as ferramentas são executadas.

Ciclo de vida do plugin revisado

O plugin CLI suporta inspeção, instalação, aprovação de permissão, ativação/desativação, reversão e desinstalação. Rodas gerenciadas são executadas em ambientes separados, com verificações de artefatos e portas de tempo de execução revogáveis. O formato do catálogo oficial suporta pacotes revisados; esta versão vem com um catálogo vazio, portanto não instala automaticamente novos códigos de terceiros.

Continuidade do aprendizado e soluções cotidianas

O Space ganha um diário de aprendizagem no espaço de trabalho mostrando a missão atual, a transferência da última sessão e registros de aprendizagem confirmados. As novas tentativas de bate-papo reutilizam a conversa original após uma confirmação perdida, as perguntas estacionadas sobrevivem às recargas e os rascunhos não enviados permanecem recuperáveis. A navegação de ramificação, o isolamento de conta de memória, a recuperação do iniciador e o relatório de erros foram aprimorados; Visualize também ganha mapas mentais de sereia.

Provedores e configuração

O GitHub Copilot usa login do dispositivo e credenciais por proprietário, com inferência verificada durante a configuração. Opper se junta a provedores de LLM e incorporação, e Y-API se junta a provedores de LLM. As configurações do provedor oferecem um fluxo de adição mais claro, endpoints padrão com reconhecimento de protocolo e descoberta de voz do provedor. Os serviços de incorporação local podem funcionar sem chaves API, enquanto a simultaneidade de incorporação e o tratamento do pensamento Qwen3-Instruct são corrigidos.

A documentação atualizada em inglês e chinês acompanha o lançamento em deeptutor.info.

Notas de atualização

Execute pip install -U deeptutor; Os usuários do Docker puxam o ghcr.io/hkuds/deeptutor:latest.

  • Aprendizado por vídeo: use o Reading para novas sessões de vídeo. A capacidade autônoma immersive_watching e os aliases watching/watch CLI foram desativados. Links de observação existentes entram na migração de compatibilidade; manter os dados do aplicativo existentes disponíveis. Um vídeo herdado ausente deixa sua conversa acessível como um bate-papo comum.
  • GitHub Copilot: execute deeptutor provider login github-copilot novamente se você dependia anteriormente de arquivos de token externos do Copilot/nanobot. Cada conta faz login separadamente; Os perfis do Copilot não podem ser compartilhados por meio de concessões modelo.
  • Fala: selecione explicitamente uma voz nas configurações do modelo; novos perfis não recebem mais uma voz padrão codificada.
  • OrcaRouter: suas predefinições de provedor integradas foram removidas. Configure uma conexão personalizada com um endpoint e um modelo compatíveis explícitos se você ainda usa esse serviço.
  • Bases de conhecimento: índices mais antigos precisam ser reanalisados ​​e reindexados para obter registros de figuras recém-extraídos. A inspeção exata da página PDF pode usar o documento original diretamente. A nova tentativa reutiliza apenas pontos de verificação compatíveis válidos; ele não retoma uma inferência local interrompida do MinerU no meio de um documento.
  • Plugins: revise as permissões solicitadas antes de aprovar um pacote gerenciado. Reinicie o DeepTutor quando a geração do plugin for alterada para que o código revisado seja carregado; desabilitar ou revogar a aprovação bloqueia chamadas subsequentes.
  • instalações do systemd: interrompa o serviço, atualize o DeepTutor em seu ambiente Python e reinicie o serviço.

DeepTutor v1.6.14

Highlights

  • Video learning folds into Reading (breaking) — YouTube/Bilibili now live in the Reading workspace with timestamp-grounded discussion and native playback. The standalone immersive_watching capability and the watching / watch CLI aliases are retired; legacy Watching conversations, positions, and notes migrate on reopen, but only if the old application data is still available — a missing video degrades the session to ordinary chat rather than failing outright.
  • Recoverable indexing with safe rollback — KB details now expose durable progress, per-source outcomes, and recovery info. Retries reuse compatible completed parses and validated MinerU cloud slices (they do not resume mid-document local MinerU inference), and cancellation lands at a safe boundary. LlamaIndex publishes a new version only after reload, vector validation, and a retrieval probe pass, keeping the previous queryable version if a rebuild fails; retrieval also flags hybrid→vector fallback and incomplete IMA evidence.
  • Original-source visual evidence — Ask about a specific figure, table, or PDF page and get the original image or a rendered page/region with document identity and source links intact. The Files view surfaces missing or unverified extraction, and Guided Learning treats this as evidence for visual questions while leaving uncertain/inaccessible material ungraded. Note: older indexes must be re-parsed and reindexed to pick up the new figure records.
  • Traceable research tooling and gated MCPs — Scientific requests gain versioned arXiv reading, original-page review, claim checking against a pinned GitHub revision, and literature evidence matrices; the MCP catalog adds alphaXiv. Admins can approve an exact private-network MCP origin for account-owned connections, with that approval re-checked at tool-run time — worth reviewing if you rely on internal MCP services.
  • Reviewed plugin lifecycle — A new CLI covers inspect/install/permission approval/enable-disable/rollback/uninstall, with managed wheels in isolated environments, artifact checks, and revocable runtime gates. The official catalog ships empty, so nothing third-party is auto-installed; still, review requested permissions before approving, and restart DeepTutor when a plugin generation changes so the reviewed code is actually loaded.
  • Provider and setup changes (breaking) — GitHub Copilot moves to device login with per-owner credentials and inference checked during setup: re-run deeptutor provider login github-copilot if you used external Copilot/nanobot token files, and note profiles can't be shared via model grants. New profiles no longer get a hard-coded voice (select one explicitly), and OrcaRouter built-in presets are removed — configure a Custom connection instead. Opper and Y-API join the providers; local embedding services work without API keys, and embedding concurrency plus Qwen3-Instruct thinking handling are fixed.

DeepTutor v1.6.14 Release Notes

Release Date: 2026.10.08

Building on v1.6.13, v1.6.14 brings original-source visual practice, recoverable knowledge-base indexing, scientific research tools, and managed plugins. Video learning now lives in Reading; existing Watching conversations migrate when reopened.

What's New

Original figures, pages, and visual practice

Ask about an exact figure, table, or PDF page in an attached knowledge base. DeepTutor retrieves the original image or renders the selected page or region, preserving document identity and source links. The Files view exposes source visual coverage, including missing or unverified extraction. Guided Learning uses this evidence for visual questions and distinguishes explanations, assisted practice, and independent mastery; inaccessible or uncertain evidence stays ungraded.

Indexing that can recover

Knowledge-base details show durable indexing progress, individual source outcomes, and recovery information. Retries reuse compatible completed parses and validated MinerU cloud slices; cancellation takes effect at a safe boundary. LlamaIndex publishes a new version only after reload, vector validation, and a retrieval probe succeed, preserving an earlier queryable version when a rebuild fails. Retrieval also reports hybrid-to-vector fallback and incomplete IMA evidence.

Reading includes video learning

YouTube and Bilibili media share the Reading workspace, with timestamp-grounded discussion and native playback. Previous Watching conversations, positions, and notes can be imported without modifying their legacy media or notebook records. Reading panels resize independently, offer a focus preset, and retain usable pagination and selection controls on narrow screens.

Research with traceable evidence

Scientific requests and Deep Research gain tools for reading versioned arXiv papers and original pages, checking paper claims against a pinned GitHub revision, and building literature evidence matrices. The MCP catalog adds alphaXiv. Administrators can approve an exact private-network MCP origin for account-owned research connections, with approval checked again when tools run.

Reviewed plugin lifecycle

The plugin CLI supports inspection, installation, permission approval, enable/disable, rollback, and uninstall. Managed wheels run in separate environments, with artifact checks and revocable runtime gates. The official catalog format supports reviewed packages; this release ships an empty catalog, so it does not install new third-party code automatically.

Learning continuity and everyday fixes

Space gains a workspace learning journal showing the current mission, last-session handoff, and confirmed learning records. Chat retries reuse the original conversation after a lost acknowledgement, parked questions survive reloads, and unsent drafts remain recoverable. Branch navigation, memory account isolation, launcher recovery, and error reporting improve; Visualize also gains Mermaid mindmaps.

Providers and setup

GitHub Copilot uses device login and per-owner credentials, with inference checked during setup. Opper joins LLM and embedding providers, and Y-API joins LLM providers. Provider settings offer a clearer add flow, protocol-aware default endpoints, and provider voice discovery. Local embedding services can work without API keys, while embedding concurrency and Qwen3-Instruct thinking handling are corrected.

Updated English and Chinese documentation accompanies the release at deeptutor.info.

Upgrade Notes

Run pip install -U deeptutor; Docker users pull ghcr.io/hkuds/deeptutor:latest.

  • Video learning: use Reading for new video sessions. The standalone immersive_watching capability and watching / watch CLI aliases are retired. Existing Watching links enter the compatibility migration; keep the existing application data available. A missing legacy video leaves its conversation accessible as ordinary chat.
  • GitHub Copilot: run deeptutor provider login github-copilot again if you previously relied on external Copilot/nanobot token files. Each account signs in separately; Copilot profiles cannot be shared through model grants.
  • Speech: explicitly select a voice in the model settings; new profiles no longer receive a hard-coded default voice.
  • OrcaRouter: its built-in provider presets are removed. Configure a Custom connection with an explicit compatible endpoint and model if you still use that service.
  • Knowledge bases: older indexes need re-parsing and reindexing to gain newly extracted figure records. Exact PDF-page inspection can use the original document directly. Retry reuses only valid compatible checkpoints; it does not resume an interrupted local MinerU inference midway through a document.
  • Plugins: review requested permissions before approving a managed package. Restart DeepTutor when a plugin generation changes so the reviewed code is loaded; disabling or revoking approval blocks subsequent calls.
  • systemd installs: stop the service, upgrade DeepTutor in its Python environment, and restart the service.
