#Deep Tutor v0.4.0

🚀 DeepTutor v0.4.0 Release Notes

Data de lançamento: 2026.01.09 Temos o prazer de anunciar o DeepTutor v0.4.0! Esta versão traz Nova página inicial, Suporte de provedor expandido para provedor LLM e Embeddings, Desacoplamento do módulo RAG, Melhoria da Web e várias pequenas melhorias.

🚧 Possíveis problemas: A implantação do Docker e a configuração local do LLM/Embeddings (Ollama, LM Studio) ainda podem ter problemas de compatibilidade. Estamos trabalhando ativamente em melhorias. Problemas e PRs são bem-vindos! → Abrir um problema | Guia de contribuição

⚠️ Mudanças importantes: configuração do ambiente

Os nomes das variáveis de ambiente foram atualizados. Atualize seu arquivo .env com base em .env.example. | Variável antiga | Nova variável | Notas | |:---|:---|:---| | OPENAI_API_KEY | LLM_API_KEY | Agora independente de provedor | | OPENAI_API_BASE | LLM_HOST | Renomeado para maior clareza | | OPENAI_MODEL | LLM_MODEL | Renomeado para maior clareza | | EMBEDDING_DIM | EMBEDDING_DIMENSION | Nomenclatura completa de palavras | | (codificado) | BACKEND_PORT | Agora configurável em .env (padrão: 8001) | | (codificado) | FRONTEND_PORT | Agora configurável em .env (padrão: 3782) | Novas variáveis obrigatórias:

  • LLM_BINDING — Tipo de provedor: openai, ollama, azure_openai, anthropic, etc.
  • EMBEDDING_BINDING — Tipo de provedor: openai, ollama, jina, cohere, etc. Novas variáveis opcionais:
  • SEARCH_PROVIDER — Provedor de pesquisa na Web: perplexity (padrão) ou baidu
  • BAIDU_API_KEY — Para pesquisa Baidu AI (百度AI搜索)
  • NEXT_PUBLIC_API_BASE — URL de front-end API para acesso remoto/LAN (por exemplo, http://192.168.1.100:8001)

💡 Acesso Remoto: Se estiver acessando o DeepTutor de outro dispositivo da sua rede, configure NEXT_PUBLIC_API_BASE para o IP do seu servidor. Se não for definido, o padrão é http://localhost:8001 (somente máquina local). 📌 Ação necessária: Copie .env.example para .env e atualize sua configuração antes de atualizar.

✨ Destaques

🔌 LLM multi-provedor e suporte de incorporação

Expandido de apenas local para um ecossistema de fornecedor completo: | Provedores de LLM | Provedores de incorporação | |:---|:---| | OpenAI, Antrópico, Azure OpenAI | OpenAI, Azure OpenAI, Jina AI | | Ollama, Ollama Cloud, LM Studio | Cohere, Ollama, LM Studio | | Groq, OpenRouter, DeepSeek, Gemini | HuggingFace (compatível com OpenAI) | A nova arquitetura baseada em adaptador no src/services/embedding/adapters/ permite fácil adição de novos provedores.

🧩 Desacoplamento do Módulo RAG

A nova classe RAGService fornece uma interface unificada e independente de provedor:

from src.services.rag import RAGService

service = RAGService()  # Uses RAG_PROVIDER env var (default: raganything)
await service.initialize("my_kb", ["doc.pdf"])
result = await service.search("query", "my_kb")

📌 Atualmente suporta RAG-Anything (MinerU + LightRAG). Mais back-ends em breve!

🌙 Modo escuro e revisão da interface do usuário

  • Alternância de tema com detecção de preferência do sistema e persistência localStorage
  • Barra lateral dobrável com modo compacto apenas com ícones
  • Reconstrução da página de configurações: gerenciamento de variáveis de ambiente com organização baseada em categorias
  • Estilo consistente no modo escuro em todas as páginas

⚙️ Configuração Centralizada

Novo settings.py usando pydantic-settings para configuração unificada: | Categoria | Variáveis ​​de ambiente | |:---|:---| | LLM | LLM_BINDING, LLM_MODEL, LLM_HOST, LLM_API_KEY | | Incorporação | EMBEDDING_BINDING, EMBEDDING_MODEL, EMBEDDING_HOST, EMBEDDING_API_KEY, EMBEDDING_DIMENSION | | RAG | RAG_PROVIDER | | TTS | TTS_MODEL, TTS_URL, TTS_API_KEY, TTS_VOICE | | Pesquisar | PERPLEXITY_API_KEY | Atualizações de tempo de execução via /api/settings/env com persistência automática .env.

DeepTutor v0.4.0

Highlights

  • Breaking environment migration — OPENAI_API_KEY, OPENAI_API_BASE, and OPENAI_MODEL become LLM_API_KEY, LLM_HOST, and LLM_MODEL; rename EMBEDDING_DIM to EMBEDDING_DIMENSION and add the required LLM_BINDING and EMBEDDING_BINDING. Regenerate .env from .env.example before upgrading, and explicitly set BACKEND_PORT/FRONTEND_PORT if you need ports other than the new defaults, 8001/3782.
  • Broader LLM and embedding choices — LLM support now includes Anthropic, Azure OpenAI, Ollama/Ollama Cloud, LM Studio, Groq, OpenRouter, DeepSeek, and Gemini, while embeddings add Jina, Cohere, and HuggingFace’s OpenAI-compatible endpoint (PRs #77, #79). Providers are independently configurable through adapters; OpenRouter users should retest embedding outputs because PR #64 removes double decoration that could change generated vectors.
  • RAG behind a service interface — RAGService provides asynchronous initialize() and search() methods and selects a pipeline through RAG_PROVIDER (PR #57). The default changes to raganything, combining MinerU and LightRAG; set the variable explicitly and validate existing knowledge bases after upgrading, since the other pipeline files are not yet advertised as supported alternatives.
  • Runtime-managed configuration — pydantic-settings centralizes LLM, embedding, RAG, TTS, and search configuration, while /api/settings/env updates values and persists them to .env. This enables runtime reconfiguration without rebuilding, but the endpoint should be treated as privileged because its changes survive restarts.
  • Remote access and deployment caveats — set NEXT_PUBLIC_API_BASE to the server’s LAN IP or public URL for remote clients; the localhost default only works on the host. The single-container Docker setup exposes ports 8001/3782 and mounts ./config, ./data/user, and ./data/knowledge_bases, with NEXT_PUBLIC_API_BASE_EXTERNAL available for cloud deployments. The release explicitly warns that Docker and Ollama/LM Studio compatibility may still have issues, so smoke-test those paths before rollout.
  • Web, search, and frontend hardening — new home/history pages, persistent system-aware dark mode, collapsible navigation, and SSR theme hydration change the UI and first-load behavior. Search can switch from Perplexity to Baidu AI Search through SEARCH_PROVIDER and BAIDU_API_KEY (PR #55); the frontend also fixes a critical jsPDF vulnerability (PR #62) and moves its Node base image to 25-slim (PR #42).

🚀 DeepTutor v0.4.0 Release Notes

Release Date: 2026.01.09

We're excited to announce DeepTutor v0.4.0! This release brings New home page, Expanded provider support for LLM & Embeddings provider, RAG module decoupling, Web improvement, and a bunch of minor improvements.

🚧 Possible Issues: Docker deployment and local LLM/Embeddings setup (Ollama, LM Studio) may still have compatibility issues. We're actively working on improvements. Issues and PRs are welcome! → Open an Issue | Contributing Guide

⚠️ Breaking Changes: Environment Configuration

Environment variable names have been updated. Please update your .env file based on .env.example.

| Old Variable | New Variable | Notes | |:---|:---|:---| | OPENAI_API_KEY | LLM_API_KEY | Now provider-agnostic | | OPENAI_API_BASE | LLM_HOST | Renamed for clarity | | OPENAI_MODEL | LLM_MODEL | Renamed for clarity | | EMBEDDING_DIM | EMBEDDING_DIMENSION | Full word naming | | (hardcoded) | BACKEND_PORT | Now configurable in .env (default: 8001) | | (hardcoded) | FRONTEND_PORT | Now configurable in .env (default: 3782) |

New required variables:

  • LLM_BINDING — Provider type: openai, ollama, azure_openai, anthropic, etc.
  • EMBEDDING_BINDING — Provider type: openai, ollama, jina, cohere, etc.

New optional variables:

  • SEARCH_PROVIDER — Web search provider: perplexity (default) or baidu
  • BAIDU_API_KEY — For Baidu AI Search (百度AI搜索)
  • NEXT_PUBLIC_API_BASE — Frontend API URL for remote/LAN access (e.g., http://192.168.1.100:8001)

💡 Remote Access: If accessing DeepTutor from another device on your network, set NEXT_PUBLIC_API_BASE to your server's IP. If not set, defaults to http://localhost:8001 (local machine only).

📌 Action Required: Copy .env.example to .env and update your configuration before upgrading.

✨ Highlights

🔌 Multi-Provider LLM & Embedding Support

Expanded from local-only to a full provider ecosystem:

| LLM Providers | Embedding Providers | |:---|:---| | OpenAI, Anthropic, Azure OpenAI | OpenAI, Azure OpenAI, Jina AI | | Ollama, Ollama Cloud, LM Studio | Cohere, Ollama, LM Studio | | Groq, OpenRouter, DeepSeek, Gemini | HuggingFace (OpenAI-compatible) |

New adapter-based architecture in src/services/embedding/adapters/ enables easy addition of new providers.

🧩 RAG Module Decoupling

New RAGService class provides a unified, provider-agnostic interface:

from src.services.rag import RAGService

service = RAGService()  # Uses RAG_PROVIDER env var (default: raganything)
await service.initialize("my_kb", ["doc.pdf"])
result = await service.search("query", "my_kb")

📌 Currently supports RAG-Anything (MinerU + LightRAG). More backends coming soon!

🌙 Dark Mode & UI Overhaul

  • Theme toggle with system preference detection & localStorage persistence
  • Collapsible sidebar with icon-only compact mode
  • Settings page rebuild: Environment variable management with category-based organization
  • Consistent dark mode styling across all pages

⚙️ Centralized Configuration

New settings.py using pydantic-settings for unified configuration:

| Category | Environment Variables | |:---|:---| | LLM | LLM_BINDING, LLM_MODEL, LLM_HOST, LLM_API_KEY | | Embedding | EMBEDDING_BINDING, EMBEDDING_MODEL, EMBEDDING_HOST, EMBEDDING_API_KEY, EMBEDDING_DIMENSION | | RAG | RAG_PROVIDER | | TTS | TTS_MODEL, TTS_URL, TTS_API_KEY, TTS_VOICE | | Search | PERPLEXITY_API_KEY |

Runtime updates via /api/settings/env with automatic .env persistence.
