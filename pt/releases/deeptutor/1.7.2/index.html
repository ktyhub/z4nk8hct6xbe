#Deep Tutor v1.7.2

#DeepTutor v1.7.2 Release Notes

Data de lançamento: 2026.11.06

Com base no v1.7.1, o v1.7.2 adiciona texto selecionado lido em voz alta, configuração de modelo mais fácil e aprendizado, recuperação e atualizações guiadas mais confiáveis. As versões para desktop agora exigem instaladores Apple Silicon e Intel Mac junto com os downloads do Windows.

Novidades

Downloads completos para desktop e suporte mais robusto ao Windows

As versões GitHub fornecem Apple Silicon e Intel DMGs, um instalador do Windows e um ZIP portátil do Windows. O fluxo de trabalho de lançamento verifica todas as plataformas e todos os downloads com versão e aliases estáveis. As correções do Windows cobrem bloqueios de sessão e migração, ambientes de plug-in, descoberta de executável Python, saída não UTF-8 e caminhos contendo espaços.

Leia apenas a passagem que você precisa

Selecione o texto no Chat, Mastery Path ou Reading e escolha Ler em voz alta para ouvi-lo através do seu provedor de voz configurado. A leitura do bate-papo em voz alta também lembra a velocidade de reprodução por conversa no navegador atual. A renderização de voz lida com sinais de porcentagem de escape e notação de grau com mais naturalidade, e o substituto do Video Lesson's Edge seleciona uma voz que corresponda ao idioma da aula.

Configuração mais fácil do provedor e compatibilidade mais ampla

As configurações descobrem modelos disponíveis após edições de credenciais e permitem importar vários de uma vez. Os novos provedores personalizados têm como padrão a seleção automática de protocolo. NVIDIA NIM adiciona incorporações de recuperação de texto com funções distintas de consulta e passagem; os modelos de imagem DashScope mais recentes usam seu protocolo de geração correspondente, com 4K restrito a wan2.7-image-pro. Os argumentos da ferramenta API das respostas, a saída estruturada, o histórico reproduzido e os cabeçalhos personalizados do Codex recebem correções de compatibilidade.

Aprendizagem guiada que mantém o contexto

Escolha um modelo antes de iniciar o esboço do Caminho de Domínio. Esclarecimentos de acompanhamento e partes faltantes são avaliados com a explicação que completam, enquanto respostas de cartões obsoletos e tentativas duplicadas são tratadas com mais cuidado. As incompatibilidades de cotação de origem recebem uma nova tentativa limitada, e a navegação de domínio, a rolagem do quadro e a recuperação da memória de tutoria são mais confiáveis.

Conversas e recuperação mais acessíveis

O coreano está disponível como uma tradução de interface parcial, com substituto em inglês para texto não traduzido. Mais rótulos e datas seguem o idioma da interface selecionado. Os threads do Little Tutor aparecem na paleta de comandos, os leitores de documentos são carregados sob demanda e as falhas e cancelamentos de soquete se recuperam de maneira mais previsível. O BM25 preserva identificadores pontilhados, a extração de documentos permanece fora do loop de eventos API e o notebook e as ferramentas favoritas suportam a recuperação de registros somente leitura.

Atualizações mais seguras e recuperação de raciocínio limitado

As atualizações de pacotes mantêm módulos de recursos instalados na versão principal de destino e registram falhas de inicialização em vez de permanecerem travados na reinicialização. Lançamentos desanexados evitam importações de árvores de origem obsoletas e reversões de aplicativos CLI com falha preservam os backups. O loop de agente compartilhado pode interromper ou fazer uma nova tentativa explicitamente limitada de orçamento mais alto quando o raciocínio esgota o orçamento de produção sem uma resposta visível.

Notas de atualização

  • Aplicativo completo: pare o DeepTutor e faça backup do tempo de execução inicial e, em seguida, execute python -m pip install --upgrade "deeptutor[full]==1.7.2". Mantenha o mesmo DEEPTUTOR_HOME; verifique com python -m pip check e deeptutor module list antes de reiniciar. Quaisquer rodas com recursos adicionais também devem corresponder à versão 1.7.2.
  • Instalações herdadas: atualizações do 1.6.15 ou anterior devem desinstalar o pacote deeptutor-cli legado antes de instalar a família de pacotes modulares. Siga os comandos de migração em v1.7.0.
  • Instalações de origem: instale requirements/full.txt e depois python -m pip install -e . --no-deps. Pare os servidores ativos e o CLI gira antes de trocar os módulos.
  • Docker: extraia ghcr.io/hkuds/deeptutor:1.7.2 ou :latest e recrie o contêiner com o volume de dados existente.
  • Desktop: use o instalador correspondente ou ZIP portátil nesta versão GitHub. As compilações do Windows permanecem sem assinatura. A descoberta automática de atualização da área de trabalho não está conectada; o shell suporta atualizações principais assinadas fornecidas manualmente.
  • NVIDIA NIM: selecione explicitamente sua vinculação de incorporação e reindexe uma base de conhecimento existente ao alterar os modelos de incorporação. Esta associação oferece suporte apenas a texto.
  • Recuperação de fala e raciocínio: a fala do texto selecionado requer um serviço TTS configurado e funcional. Aumentar o orçamento de saída de recuperação é opcional e pode aumentar a latência e o uso; o orçamento padrão para novas tentativas permanece inalterado.

DeepTutor v1.7.2

Highlights

  • Selected-text read-aloud — Text selected in Chat, Mastery Path, or Reading can be spoken through the configured TTS provider; Chat also remembers playback speed per conversation in the current browser. A working TTS configuration is required. Improved handling of escaped percent signs and degree notation, plus language-matched Edge fallback voices, reduces common playback failures.
  • Provider setup and protocol compatibility — Settings now refreshes models after credential edits and supports bulk import, while new custom providers default to automatic protocol selection. Fixes to Responses API tool arguments, structured output, replayed history, and Codex custom headers make this a good release to revalidate custom integrations. DashScope image models use their matching generation protocol, with 4K limited to wan2.7-image-pro.
  • Context-aware guided learning and bounded recovery — Mastery Path selects a model before generating an outline and evaluates clarifications alongside the explanation they complete, reducing lost context. Source-quote mismatches receive a bounded retry, while stale card replies and duplicate retries are handled more safely. The shared agent loop can stop or make one explicitly bounded, opt-in higher-budget retry when reasoning exhausts the output budget; enabling it can increase latency and usage.
  • Retrieval correctness and embedding migration — BM25 now preserves dotted identifiers, improving matches for API names, package paths, and other symbol-heavy content. NVIDIA NIM adds a text-only embedding binding with distinct query and passage roles; select it explicitly and rebuild existing indexes when changing embedding models so retrieval does not mix incompatible vector sets.
  • Desktop distribution and safer upgrades — Use the architecture-matched Apple Silicon or Intel macOS DMG, or the Windows installer/portable ZIP. Windows fixes include paths containing spaces and non-UTF-8 output, but builds remain unsigned and desktop auto-update discovery is not connected. Preserve DEEPTUTOR_HOME, keep full and feature packages on 1.7.2, and uninstall legacy deeptutor-cli before migrating from 1.6.15 or earlier; improved rollback backups and launch-failure recovery reduce stuck installations.
  • Breaking changes — None are called out; legacy installs and NIM embedding switches require the migration steps above.

DeepTutor v1.7.2 Release Notes

Release Date: 2026.11.06

Building on v1.7.1, v1.7.2 adds selected-text read-aloud, easier model setup, and more reliable guided learning, retrieval, and updates. Desktop releases now require Apple Silicon and Intel Mac installers alongside both Windows downloads.

What's New

Complete desktop downloads and sturdier Windows support

GitHub Releases provide Apple Silicon and Intel DMGs, a Windows installer, and a Windows portable ZIP. The release workflow checks every platform and all versioned downloads and stable aliases. Windows fixes cover session and migration locks, plugin environments, Python executable discovery, non-UTF-8 output, and paths containing spaces.

Read just the passage you need

Select text in Chat, Mastery Path, or Reading and choose Read aloud to hear it through your configured speech provider. Chat read-aloud also remembers playback speed per conversation in the current browser. Voice rendering handles escaped percent signs and degree notation more naturally, and Video Lesson's Edge fallback selects a voice matching the lesson language.

Easier provider setup and broader compatibility

Settings discovers available models after credential edits and lets you import several at once. New custom providers default to automatic protocol selection. NVIDIA NIM adds text retrieval embeddings with distinct query and passage roles; newer DashScope image models use their matching generation protocol, with 4K restricted to wan2.7-image-pro. Responses API tool arguments, structured output, replayed history, and Codex custom headers receive compatibility fixes.

Guided learning that keeps the context

Choose a model before a Mastery Path outline starts. Follow-up clarifications and missing parts are assessed with the explanation they complete, while stale card replies and duplicate retries are handled more carefully. Source quotation mismatches receive a bounded retry, and mastery navigation, board scrolling, and tutoring-memory recovery are more reliable.

More accessible conversations and retrieval

Korean is available as a partial interface translation, with English fallback for untranslated text. More labels and dates follow the selected interface language. Little Tutor threads appear in the command palette, document readers load on demand, and socket failures and cancellation recover more predictably. BM25 preserves dotted identifiers, document extraction stays off the API event loop, and notebook and favorite tools support read-only record retrieval.

Safer updates and bounded reasoning recovery

Package updates keep installed feature modules on the target core version and record launch failures instead of remaining stuck at restart. Detached launches avoid stale source-tree imports, and failed CLI-app rollbacks preserve backups. The shared agent loop can stop or make one explicitly bounded higher-budget retry when reasoning exhausts the output budget without a visible answer.

Upgrade Notes

  • Full app: stop DeepTutor and back up the runtime home, then run python -m pip install --upgrade "deeptutor[full]==1.7.2". Keep the same DEEPTUTOR_HOME; verify with python -m pip check and deeptutor module list before restarting. Any additional feature wheels must also match version 1.7.2.
  • Legacy installations: upgrades from 1.6.15 or earlier must uninstall the legacy deeptutor-cli package before installing the modular package family. Follow the migration commands in v1.7.0.
  • Source installs: install requirements/full.txt, then python -m pip install -e . --no-deps. Stop active servers and CLI turns before changing modules.
  • Docker: pull ghcr.io/hkuds/deeptutor:1.7.2 or :latest and recreate the container with the existing data volume.
  • Desktop: use the matching installer or portable ZIP on this GitHub Release. Windows builds remain unsigned. Automatic desktop update discovery is not connected; the shell supports manually supplied signed core updates.
  • NVIDIA NIM: select its embedding binding explicitly and re-index an existing knowledge base when changing embedding models. This binding supports text only.
  • Speech and reasoning recovery: selected-text speech requires a working configured TTS service. Increasing the recovery output budget is opt-in and can increase latency and usage; the default retry budget remains unchanged.
