pyvespa v1.2.8

What's Changed

  • docs: fix hit ratio vs filtered-out ratio in ANN tuning notebook by @thomasht86 in https://github.com/vespa-engine/pyvespa/pull/1352
  • feat: accept data plane cert/key content in Vespa() by @thomasht86 in https://github.com/vespa-engine/pyvespa/pull/1353
  • add support for MatchPhaseRanking total_max_hits parameter by @mackenziestarr in https://github.com/vespa-engine/pyvespa/pull/1354
  • Change pruning age for proton in performance tests by @sebastiannberg in https://github.com/vespa-engine/pyvespa/pull/1356
  • ci: sync the vendored metric preset list with the Vespa CLI by @thomasht86 in https://github.com/vespa-engine/pyvespa/pull/1349
  • Add retry controls and pass real error status to feed callbacks by @sebastiannberg in https://github.com/vespa-engine/pyvespa/pull/1357
  • Make delete_all_docs retry failed chunks and raise instead of silently stopping by @sebastiannberg in https://github.com/vespa-engine/pyvespa/pull/1358
  • Split the performance suite into a k6 instance ceiling and a single-process pyvespa lane by @sebastiannberg in https://github.com/vespa-engine/pyvespa/pull/1359
  • Let feed_async_iterable really run max_workers requests in flight by @sebastiannberg in https://github.com/vespa-engine/pyvespa/pull/1360
  • Size the pyvespa lane by round trip so far runners stop looking like regressions by @sebastiannberg in https://github.com/vespa-engine/pyvespa/pull/1361
  • Pass max_concurrent through to the client in query_many and warn above 1024 threads by @sebastiannberg in https://github.com/vespa-engine/pyvespa/pull/1363
  • Add a gzip on/off performance test with a 4 KB document in both lanes by @sebastiannberg in https://github.com/vespa-engine/pyvespa/pull/1362
  • Keep a performance session under an hour by @sebastiannberg in https://github.com/vespa-engine/pyvespa/pull/1365
  • Run the gzip performance test on mTLS only and set its floors by @sebastiannberg in https://github.com/vespa-engine/pyvespa/pull/1364
  • Bump urllib3 to 2.8.0 + all deps in pyvespa (2 Mend HIGH CVEs) by @odosk in https://github.com/vespa-engine/pyvespa/pull/1366
  • Support listing and revoking data-plane tokens by @ean in https://github.com/vespa-engine/pyvespa/pull/1367

New Contributors

  • @mackenziestarr made their first contribution in https://github.com/vespa-engine/pyvespa/pull/1354
