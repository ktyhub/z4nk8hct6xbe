druida druida-0.6.160

Melhorias

  • Os nós da corretora agora só iniciam após a leitura de todas as informações sobre os segmentos no Zookeeper
  • Consultas groupBy aninhadas agora devem funcionar com agregações de postagem.
  • Consultas groupBy aninhadas agora devem funcionar com métricas complexas.
  • O overlord do serviço de indexação agora pode atribuir tarefas aos trabalhadores com base em estratégias.
  • Firehose local agora pode encontrar todos os arquivos em um diretório.
  • O carimbo de data/hora e as métricas agora são adicionados automaticamente às exclusões de dimensão.
  • Melhor tratamento de falhas durante transferências em tempo real.
  • Download paralelo de segmentos. Vários threads agora podem ser usados ​​para baixar segmentos do armazenamento profundo.
  • Os segmentos podem ser anunciados e consultados à medida que um nó é carregado inicialmente.
  • Agregadores filtrados nativos para filtros de tipo seletor
  • A estratégia de seleção do Custom Broker para o roteador agora pode ser escrita em JavaScript

Documentação

  • Exemplo de configuração do Hadoop agora disponível
  • Melhores práticas e recomendações agora atualizadas
  • O nó do roteador experimental agora está documentado (druid.io/docs/latest/Router.html).
  • A mangueira de incêndio local agora está documentada (http://druid.io/docs/latest/Firehose.html).
  • Inúmeras melhorias nas perguntas frequentes, documentos de metadados de segmento aprimorados, ingestão de documentos firehose aprimorados, visualização completa do cluster explicada. Obrigado @pdeva!
  • Atualizações na documentação do Cassandra. Obrigado @lexicalunit!

Correções de bugs

  • Adicionada uma solução alternativa para um problema de conexão meio aberta do cais que aparece quando as conexões client encerram uma consulta de longa execução. Os sintomas quando esse bug aparece são que o cluster parece travado e sem resposta. Outra solução alternativa para esse problema é simplesmente usar os tempos limite do contexto de consulta.
  • Corrigida a mesclagem de resultados de partições com intervalos de tempo, o que poderia causar resultados não mesclados fora de ordem (#796).
  • O HDFS agora deve funcionar para sistemas de arquivos não padrão. Obrigado @flowbehappy!
  • Múltiplas dimensões espaciais agora podem ser ingeridas.
  • Corrigido um bug com histogramas aproximados que não funcionavam com consultas groupBy.
  • Corrigidos os últimos 8kb que não funcionavam para logs de tarefas não-s3.
  • Correção da configuração dinâmica que não funcionava para limitação de replicação.
  • Correção de consultas de pesquisa gerando exceções ao consultar dimensões inexistentes
  • Corrija a quebra da mangueira de incêndio para dimensões não presentes.
  • Consultas selecionadas agora funcionam se você especificar dimensões não existentes (#778)
  • O cache groupBy agora funciona com métricas complexas
  • Corrigidos alguns problemas de serde que existiam com RabbitMQ (#794)

druid druid-0.6.160

Improvements

  • Broker nodes now only start up after reading all information about segments in Zookeeper
  • Nested groupBy queries should now work with post aggregations.
  • Nested groupBy queries should now work with complex metrics.
  • The overlord in the indexing service can now assign tasks to workers based on strategies.
  • Local firehose can now find all files under a directory.
  • Timestamp and metrics are now automatically added to dimension exclusions.
  • Improved failure handling during real-time hand-offs.
  • Parallel downloading of segments. Multiple threads can now be used to download segments from deep storage.
  • Segments can be announced and queried as a node is initially loading up.
  • Native filtered aggregators for selector type filters
  • Custom Broker selection strategy for Router can now be written in JavaScript

Documentation

  • Example Hadoop Configuration now available
  • Best Practices and Recommendations now updated
  • Experimental Router node is now documented (druid.io/docs/latest/Router.html).
  • Local firehose is now documented (http://druid.io/docs/latest/Firehose.html).
  • Numerous improvements to FAQS, segment metadata docs improved, ingest firehose docs improved, full - cluster view explained. Thanks @pdeva!
  • Updates to Cassandra documentation. Thanks @lexicalunit!

Bug Fixes

  • Added a workaround for a jetty half open connection issue that appears when client connections terminate a long running query. The symptoms when this bug appears are that the cluster appears stuck and unresponsive. Another workaround for this issue is to simply use query context timeouts.
  • Fixed merging results from partitions with time gaps, which could cause out of order unmerged results (#796).
  • HDFS should now work for non-default filesystems. Thanks @flowbehappy!
  • Multiple spatial dimensions can now be ingested.
  • Fixed a bug with approximate histograms not working with groupBy queries.
  • Fixed last 8kb not working for non-s3 task logs.
  • Fixed dynamic configuration not working for replication throttling.
  • Fix search queries throwing exceptions if querying for non-existing dimensions
  • Fix ingest firehose breaking for non-present dimensions.
  • Select queries now work if you specify non-existing dimensions (#778)
  • groupBy cache now works with complex metrics
  • Fixed some serde problems that existed with RabbitMQ (#794)
