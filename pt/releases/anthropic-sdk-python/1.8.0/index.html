anthropic-sdk-python v1.8.0

Highlights

  • New model + in-line tools (beta) — claude-opus-5-5 arrives alongside inline tool definitions and MCP tool-list pinning (b5cc700). Inline definitions let you declare tools directly in the request instead of pre-registering them, and MCP pinning lets you freeze a server's tool list so it can't drift mid-run. Both are beta, so expect to opt in via beta headers and pin to a snapshot — treat the surface as unstable until it graduates.
  • Tool runner: live tool registration + compaction fix (#874, #871) — add_tools() now takes effect immediately (06d0a6b), so agents that discover tools at runtime no longer need to tear down and rebuild a runner. Separately, reply-only params are stripped from the tool runner's internal compaction request (4687310), removing the API errors caused when those fields leaked into an auto-compaction call. If you run long agent loops with automatic context compaction, upgrade for this.
  • Python 3.13 stream shutdown crash — a stream left open at interpreter exit could crash on 3.13 (af029bd). Worth taking if you're on 3.13 with streaming responses, especially in short-lived scripts or serverless functions that don't always close streams before teardown.
  • Managed Agents: unified evaluated_permission enum — all Managed Agents events now share one enum type (f4f51c8). If you compare permission values by identity or type-check against a specific enum class, results are now consistent across event types instead of varying by event.
  • Client serialization refactor — the request-param transform was removed in favour of the JSON encoder (539422c); all params now flow through one path. If you relied on the old transform's coercion or passed custom objects, re-verify your payloads still encode correctly. Note also that mypy was dropped from the project's own toolchain (be01ed6), which doesn't affect consumers.

No breaking changes.
