anthropic-sdk-python v2.7.0

Highlights

  • New model IDs — claude-fable-5-2 and claude-mythos-5-2 join the API model surface. Anyone validating model strings against the SDK's Model literal or maintaining a hard-coded allow-list must add them or valid requests get rejected locally; plain-string callers need no change.
  • Webhook surface expands — a new user_profile.program_status_updated event is emitted and now accepted on organization webhook endpoints. Exhaustive event routers (discriminated unions, strict switch/match) need a new branch or a safe default, otherwise this arrives as an unhandled event rather than a no-op.
  • Admin & reporting additions — usage/cost reports gain parent-organization filtering and grouping, enabling cross-org spend rollups without client-side stitching; verify grouping assumptions if your analytics jobs expect one row per org. Separately, sandbox_egress_restricted is now declared on Admin API write methods — add it to closed error-code catch lists and treat it as a policy rejection, not a retryable blip.
  • Bedrock & Vertex close the parity gap — parse and count_tokens arrive on beta.messages.with_raw_response and with_streaming_response, raw requests now send X-Stainless-Async and stream when no stream class is named, ANTHROPIC_CUSTOM_HEADERS is honored on Bedrock/Mantle/Vertex, and Bedrock signing no longer raises KeyError on requests lacking a Connection header. Code written against the first-party client ports to AWS/Google with fewer shims; note Mantle serializes list params as a[]=1&a[]=2 to match Anthropic, so raw-request assertions may need updating.
  • Structured output & client ergonomics — the parse helper keeps const in generated JSON Schemas and drops type beside const/enum, producing stricter, spec-correct schemas — diff any schema snapshots. API errors are now pickleable and copyable (multiprocessing/deepcopy-safe), and Foundry's copy/with_options/with_middleware stop raising when ANTHROPIC_FOUNDRY_RESOURCE is set. The accompanying error-detail type cleanup is worth a quick import audit if you catch on specific detail classes.
  • Breaking changes — None in this release.

Features

  • api: accept user_profile.program_status_updated on organization webhook endpoints
  • api: add claude-fable-5-2 and claude-mythos-5-2
  • api: add parent organization filtering and grouping to the usage and cost reports
  • api: add the sandbox_egress_restricted error to Admin API write methods
  • api: add the user_profile.program_status_updated webhook event

Bug Fixes

  • bedrock,vertex: add the parse and count_tokens methods missing from beta.messages.with_raw_response and with_streaming_response
  • bedrock,vertex: send the X-Stainless-Async header and stream raw requests that name no stream class
  • bedrock: sign requests that have no Connection header instead of raising KeyError
  • bedrock: write a list in a query as a[]=1&a[]=2 on the Bedrock Mantle clients, as Anthropic does
  • client: allow API errors to be unpickled and copied
  • client: read ANTHROPIC_CUSTOM_HEADERS on the Bedrock, Bedrock Mantle and Vertex clients
  • foundry: stop copy, with_options and with_middleware from raising when ANTHROPIC_FOUNDRY_RESOURCE is set
  • parse: keep const in structured output schemas, and drop type beside const and enum

Chores

  • api: remove some error detail types and update descriptions
  • docs: say when a work heartbeat does not compare its value
  • internal: add this repository's review rules
  • internal: remove two comments from the error classes
