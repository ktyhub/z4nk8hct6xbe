pi v1.4.0

Novos recursos

  • Entrada de imagem para classificadores: o modo de código models.classify() aceita images para os modelos Jev da TypeSafe e Clef da Cloudflare em typesafe, cloudflare-workers-ai e OpenRouter. Consulte Usar modelos de classificador e Modo de código.
  • Referência de configuração de modelos: cada provedor, modelo, substituição de modelo e campo de compatibilidade do models.json, gerado a partir de seu esquema. Consulte Configuração de Modelos.
  • Resumos sem limite de saída fixo: os resumos de compactação e ramificação usam o limite de saída do modelo, portanto, um raciocínio longo não os faz mais falhar. Consulte Compactação.
  • Codemode espera por um trabalhador livre: scripts paralelos e subagentes em processo enfileiram-se em vez de falhar, e PI_CODEMODE_MAX_WORKERS aumenta o limite. Consulte Limites do modo de código.
  • Suporte ao terminal Rex: hiperlinks OSC 8, truecolor e imagens embutidas.

Adicionado

  • Adicionada uma referência de configuração de modelos gerada a partir do esquema models.json, listando todos os campos de provedor, modelo, substituição de modelo e compatibilidade (#10790)
  • Codemode models.classify() agora aceita images para os modelos Jev da TypeSafe e Clef da Cloudflare em typesafe, cloudflare-workers-ai e OpenRouter, e lista Clef Omni e Jev 1.14 em Workers AI.
  • compat de nível de provedor em models.json agora também se aplica a modelos de classificador, com os campos System One imageInput e sendImageOptInHeader para proxies que atendem classificadores de outro serviço. Os modelos de classificador de extensão também aceitam compat.
  • Adicionado MiniMax-M3.1-Flash aos provedores minimax e minimax-cn, com níveis de pensamento de baixo a máximo (#11121)
  • Adicionado suporte para o terminal Rex: hiperlinks OSC 8, truecolor e imagens inline (#11131, #11150 por @petrroll, #11183 por @nihaals)

Alterado

  • Os cabeçalhos de atribuição do provedor agora vêm da identidade client do pi-ai. Os manipuladores before_provider_headers das extensões não veem mais os cabeçalhos de atribuição OpenRouter, NVIDIA NIM e OpenCode; retornar null para um ainda o remove. As solicitações da Cloudflare enviam o User-Agent detalhado do pi em vez do pi-coding-agent, assim como as verificações de versão do GitHub para downloads de ferramentas, e as solicitações do OpenCode enviam o x-opencode-client sempre que a atribuição estiver habilitada, não apenas com uma sessão.
  • generateSummary() e generateSummaryWithUsage() agora ignoram seus parâmetros reserveTokens. As solicitações de resumo usam o limite de saída do modelo.
  • Alterado o modelo padrão do Copilot GitHub de gpt-5.4, que o Copilot retirou, para gpt-6.1-sol.
  • Alterado o modelo padrão da NVIDIA para nvidia/nemotron-3.5-super-vl-120b-a12b (#10910 por @cv)
  • Alterado o modelo padrão da Xiaomi para mimo-v2.6-pro para os provedores xiaomi e Xiaomi Token Plan, já que mimo-v2.5-pro saiu do catálogo.
  • Grok 4.3 e Grok 4.5 no provedor xai agora oferecem o nível de pensamento xhigh.
  • Faça login com ChatGPT: os erros de limite de uso do espaço de trabalho do ChatGPT Business não são repetidos e solicitam ao usuário que peça ao administrador do espaço de trabalho para aumentar o limite.

Corrigido

  • Foi corrigida a falha na compactação e nos resumos de ramificação com "a geração atingiu o limite do token" quando o raciocínio usava a maior parte do limite fixo de saída do resumo. Os resumos agora usam o limite de saída do modelo e compaction.reserveTokens controla apenas quando a compactação começa (#9512, #9075).
  • Corrigidas descrições ausentes do models.schema.json para campos de provedor e modelo, para que os editores não mostrassem dicas para eles (#10790)
  • Correção da falha do pi update com "Marcador de instalação gerenciada ausente ou inválido" quando managed-install.json inicia com uma BOM UTF-8, que o Windows PowerShell 5.1 adiciona ao reescrever o arquivo.
  • Corrigida a exportação de HTML mostrando asteriscos literais para Markdown em negrito e itálico ao lado da pontuação CJK (#3353, #10154)
  • Corrigido o terminal permanecendo nos modos de rastreamento de mouse, relatório de foco, teclado Kitty e tela alternativa quando pi sai sem sua desmontagem normal do terminal, o que inundava o prompt do shell com sequências de escape (#11170)
  • Correção de diálogos de extensão simultânea select/confirm/input/editor e componentes inline custom() no modo interativo: um segundo diálogo substituiu o primeiro e a primeira promessa nunca foi cumprida; fechar a caixa de diálogo visível agora mostra a anterior novamente (#11166, #9909)
  • Corrigida a colagem no shell travada após copiar texto em pi e suspendê-lo com Ctrl+Z no Linux: o processo de fundo wl-copy/xclip/xsel que continua servindo o clipboard foi suspenso junto com pi (#11179)
  • Correção de scripts de modo de código que falhavam imediatamente quando ambos os trabalhadores do modo de código estavam ocupados, por exemplo, com chamadas de modo de código paralelo ou subagentes em processo. Os scripts agora esperam até 60 segundos por um trabalhador livre e PI_CODEMODE_MAX_WORKERS aumenta o limite de dois trabalhadores (#11184)
  • Corrigidas extensões que falhavam ao carregar ao importar @earendil-works/pi-ai/models (por exemplo, para clampThinkingLevel) expondo o subcaminho através dos aliases do carregador de extensão e módulos virtuais (#11156)
  • Corrigidos arquivos mcp.json que iniciam com uma BOM UTF-8 falhando na análise, o que ignorava todos os seus servidores MCP e fazia com que pi mcp add/pi mcp remove falhasse (#11191)
  • Corrigido /compact <instructions> ignorando as instruções ao resumir o início de uma curva em que a compactação se divide. Quando a volta dividida era o único conteúdo novo desde a última compactação, as instruções foram totalmente ignoradas (#11058)
  • Corrigidas sessões retomadas e navegação /tree deixando ferramentas de extensão inativas quando a filial registrava suas ferramentas antes de serem cadastradas, como ferramentas de extensões instaladas após o início da sessão. As ferramentas de extensão que o branch nunca adicionou ou removeu agora estão ativas, a menos que sejam registradas com defaultActive: false (#11062, #11075)
  • Corrigida a quebra de sessões após a recuperação de um corte de resposta no limite de saída: a chamada de ferramenta truncada foi omitida, mas os resultados da ferramenta foram mantidos, de modo que os provedores rejeitaram todas as solicitações posteriores (#11227, #11233 por @petrroll)
  • Corrigida a ferramenta grep seguindo RIPGREP_CONFIG_PATH, onde opções como --fixed-strings mudavam silenciosamente as pesquisas regex para literais. A ferramenta agora executa rg --no-config (#11203, #11230 por @petrroll)
  • Correção da detecção de shell do Windows rejeitando aliases de shell executáveis da Microsoft Store (#9504 por @petrroll)
  • Corrigida a detecção de shell do Windows faltando o PowerShell fora do PATH e o inicializador WSL bash.exe herdado quando o Windows não está instalado no C:\Windows. pi agora verifica %ProgramFiles%\PowerShell\7, %SystemRoot%\System32\WindowsPowerShell\v1.0 e %SystemRoot% (#9501 por @petrroll)
  • Corrigidas sessões do GitHub Copilot com grandes corpos de solicitação, como muitas imagens, falhando com HTTP 413 failed to parse request em vez de compactar e tentar novamente (#11016 por @petrroll)
  • Corrigido o provedor openai-codex oferecendo gpt-5.5 e gpt-5.3-codex-spark, que sempre falham para contas ChatGPT (#11173 por @lucasmeijer)
  • Corrigida a saída da ferramenta apenas com espaços em branco (por exemplo, um \r\n simples do bash), fazendo com que as conclusões do OpenAI, as respostas do OpenAI e as solicitações do Google falhassem com um 400 (#8720)
  • Correção de nova tentativa automática que não era acionada para mais falhas de upstream do gateway, erros stream disconnected before completion retransmitidos por proxies Codex CLI e falhas transitórias de atualização de token OAuth do Google Vertex e erros de nova tentativa devido a dígitos dentro de IDs de solicitação ou contagens de bytes (#10920, #11057, #10996)
  • Corrigidos modelos de respostas OpenAI que perdiam o cache de prompt em cada carregamento de ferramenta adiado após a remoção de uma ferramenta (#10940)
  • Corrigido o preço do classificador Cloudflare Workers AI: Clef Flash custa $ 0.038 e Jev $ 0.042 por milhão de tokens de entrada em vez de Jev ser listado como gratuito.
  • Corrigido um bloco de exibição matemática $$ não fechado engolindo ou corrompendo todas as tabelas Markdown depois dele (#11159)
  • Correção do Markdown em negrito e itálico que não era renderizado próximo à pontuação CJK (#10730 por @theBucky)
  • Corrigido o preenchimento automático do arquivo @ que não retornava resultados para consultas contendo metacaracteres regex, como [ ou ( (#10972)

pi v1.4.0

New Features

  • Image input for classifiers: codemode models.classify() accepts images for TypeSafe's Jev and Cloudflare's Clef models on typesafe, cloudflare-workers-ai, and OpenRouter. See Use classifier models and Codemode.
  • Models Configuration reference: every provider, model, model override, and compatibility field of models.json, generated from its schema. See Models Configuration.
  • Summaries without a fixed output cap: compaction and branch summaries use the model's output limit, so long reasoning no longer makes them fail. See Compaction.
  • Codemode waits for a free worker: parallel scripts and in-process subagents queue instead of failing, and PI_CODEMODE_MAX_WORKERS raises the limit. See Codemode limits.
  • Rex terminal support: OSC 8 hyperlinks, truecolor, and inline images.

Added

  • Added a Models Configuration reference generated from the models.json schema, listing all provider, model, model override, and compatibility fields (#10790)
  • Codemode models.classify() now accepts images for TypeSafe's Jev and Cloudflare's Clef models on typesafe, cloudflare-workers-ai, and OpenRouter, and lists Clef Omni and Jev 1.14 on Workers AI.
  • Provider-level compat in models.json now also applies to classifier models, with the System One fields imageInput and sendImageOptInHeader for proxies that serve another service's classifiers. Extension classifier models accept compat too.
  • Added MiniMax-M3.1-Flash to the minimax and minimax-cn providers, with thinking levels low through max (#11121)
  • Added support for the Rex terminal: OSC 8 hyperlinks, truecolor, and inline images (#11131, #11150 by @petrroll, #11183 by @nihaals)

Changed

  • Provider attribution headers now come from pi-ai's client identity. Extensions' before_provider_headers handlers no longer see the OpenRouter, NVIDIA NIM, and OpenCode attribution headers; returning null for one still removes it. Cloudflare requests send pi's detailed User-Agent instead of pi-coding-agent, as do GitHub release checks for tool downloads, and OpenCode requests send x-opencode-client whenever attribution is enabled, not only with a session.
  • generateSummary() and generateSummaryWithUsage() now ignore their reserveTokens parameter. Summary requests use the model's output limit instead.
  • Changed the default GitHub Copilot model from gpt-5.4, which Copilot retired, to gpt-6.1-sol.
  • Changed the default NVIDIA model to nvidia/nemotron-3.5-super-vl-120b-a12b (#10910 by @cv)
  • Changed the default Xiaomi model to mimo-v2.6-pro for the xiaomi and Xiaomi Token Plan providers, since mimo-v2.5-pro left the catalog.
  • Grok 4.3 and Grok 4.5 on the xai provider now offer the xhigh thinking level.
  • Sign in with ChatGPT: ChatGPT Business workspace usage-limit errors are not retried and tell the user to ask their workspace admin to increase the limit.

Fixed

  • Fixed compaction and branch summaries failing with "generation hit the token cap" when reasoning used most of the fixed summary output limit. Summaries now use the model's output limit, and compaction.reserveTokens only controls when compaction starts (#9512, #9075).
  • Fixed models.schema.json missing descriptions for provider and model fields, so editors showed no hints for them (#10790)
  • Fixed pi update failing with "Managed install marker is missing or invalid" when managed-install.json starts with a UTF-8 BOM, which Windows PowerShell 5.1 adds when it rewrites the file.
  • Fixed HTML export showing literal asterisks for Markdown bold and italic next to CJK punctuation (#3353, #10154)
  • Fixed the terminal staying in mouse-tracking, focus-reporting, Kitty keyboard, and alternate-screen modes when pi exits without its normal terminal teardown, which flooded the shell prompt with escape sequences (#11170)
  • Fixed concurrent extension select/confirm/input/editor dialogs and inline custom() components in interactive mode: a second dialog replaced the first and the first promise never settled; closing the visible dialog now shows the previous one again (#11166, #9909)
  • Fixed pasting in the shell hanging after copying text in pi and suspending it with Ctrl+Z on Linux: the background wl-copy/xclip/xsel process that keeps serving the clipboard was suspended along with pi (#11179)
  • Fixed codemode scripts failing immediately when both codemode workers are busy, for example with parallel codemode calls or in-process subagents. Scripts now wait up to 60 seconds for a free worker, and PI_CODEMODE_MAX_WORKERS raises the limit of two workers (#11184)
  • Fixed extensions failing to load when importing @earendil-works/pi-ai/models (e.g. for clampThinkingLevel) by exposing the subpath through the extension loader aliases and virtual modules (#11156)
  • Fixed mcp.json files that start with a UTF-8 BOM failing to parse, which skipped all their MCP servers and made pi mcp add/pi mcp remove fail (#11191)
  • Fixed /compact <instructions> ignoring the instructions when summarizing the start of a turn that compaction splits. When the split turn was the only new content since the last compaction, the instructions were ignored entirely (#11058)
  • Fixed resumed sessions and /tree navigation leaving extension tools inactive when the branch recorded its tools before they were registered, such as tools from extensions installed after the session started. Extension tools the branch never added or removed are now active unless they are registered with defaultActive: false (#11062, #11075)
  • Fixed sessions breaking after recovery from a response cut off at the output limit: the truncated tool call was omitted but its tool results were kept, so providers rejected every later request (#11227, #11233 by @petrroll)
  • Fixed the grep tool following RIPGREP_CONFIG_PATH, where options such as --fixed-strings silently changed regex searches into literal ones. The tool now runs rg --no-config (#11203, #11230 by @petrroll)
  • Fixed Windows shell detection rejecting runnable Microsoft Store shell aliases (#9504 by @petrroll)
  • Fixed Windows shell detection missing PowerShell outside PATH and the legacy WSL bash.exe launcher when Windows is not installed in C:\Windows. pi now checks %ProgramFiles%\PowerShell\7, %SystemRoot%\System32\WindowsPowerShell\v1.0, and %SystemRoot% (#9501 by @petrroll)
  • Fixed GitHub Copilot sessions with large request bodies, such as many images, failing with HTTP 413 failed to parse request instead of compacting and retrying (#11016 by @petrroll)
  • Fixed the openai-codex provider offering gpt-5.5 and gpt-5.3-codex-spark, which always fail for ChatGPT accounts (#11173 by @lucasmeijer)
  • Fixed whitespace-only tool output (for example a bare \r\n from bash) making OpenAI Completions, OpenAI Responses, and Google requests fail with a 400 (#8720)
  • Fixed automatic retry not triggering for more gateway upstream failures, stream disconnected before completion errors relayed by Codex CLI proxies, and transient Google Vertex OAuth token refresh failures, and retrying errors because of digits inside request ids or byte counts (#10920, #11057, #10996)
  • Fixed OpenAI Responses models losing the prompt cache on every deferred tool load after a tool was removed (#10940)
  • Fixed Cloudflare Workers AI classifier pricing: Clef Flash costs $0.038 and Jev $0.042 per million input tokens instead of Jev being listed as free.
  • Fixed an unclosed $$ display-math block swallowing or corrupting every Markdown table after it (#11159)
  • Fixed Markdown bold and italic not rendering next to CJK punctuation (#10730 by @theBucky)
  • Fixed @ file autocomplete returning no results for queries containing regex metacharacters such as [ or ( (#10972)
