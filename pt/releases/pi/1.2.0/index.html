pi v1.2.0

Novos recursos

  • Listas de modelos OpenRouter por chave: com uma chave OpenRouter, Pi lista apenas os modelos que essa chave pode usar, com o tamanho do contexto da chave, saída máxima e preços, incluindo endpoints regionais definidos em models.json. Consulte OpenRouter.
  • Esquemas de configuração publicados: adicione $schema a settings.json, models.json, atalhos de teclado e temas para validação e conclusão do editor. Consulte Configurações, Modelos, Atalhos de teclas e Temas.
  • Clipboard copia em sessões remotas: PI_CLIPBOARD_OSC52=1 envia texto copiado para um clipboard de client remoto quando Pi não consegue detectar a sessão remota, como um multiplexador conectado de outra máquina. Consulte Configuração do Processo Pi.
  • Melhorias no modo de código: as declarações da ferramenta mostram restrições de entrada, como número inteiro, mínimo/máximo e padrão, e as linhas do modo de código mostram o tempo decorrido e total. Consulte Modo de código.
  • before_agent_start para execuções acionadas por extensão: as execuções iniciadas por pi.sendMessage(..., { triggerTurn: true }) passam pela mesma configuração dos prompts. Consulte Eventos e simultaneidade.

Mudanças importantes

  • Publicação de esquemas de configuração gerados para modelos, configurações, atalhos de teclado e temas na https://pi.dev/schemas/*.schema.json. O esquema do tema foi movido para https://pi.dev/schemas/theme.schema.json; temas carregados durante a inicialização agora recebem a mesma validação de esquema que recarregamentos posteriores. Atualize as referências do tema $schema, defina cores reutilizáveis em vars e remova metadados não suportados (#9880, #10751 por @christianklotz)
  • before_agent_start alterado para também disparar para execuções iniciadas por pi.sendMessage(..., { triggerTurn: true }) enquanto ocioso. BeforeAgentStartEvent agora é uma união em messageType: os eventos "user" carregam prompt e images, e os eventos "custom" carregam o message inicial e nenhum prompt. As mensagens retornadas pelos manipuladores são adicionadas a ambos os tipos de execução, e as mensagens deliverAs: "nextTurn" pendentes são entregues com a execução de mensagem personalizada. Os manipuladores que devem agir apenas nos prompts do usuário devem verificar event.messageType === "user" (#10267, #5581, #10739 por @davidbrai)
  • Alteração da sessão para contar como ocupada enquanto uma execução é iniciada, inclusive durante os manipuladores before_agent_start: ctx.isIdle() é falso, pi.sendMessage() entra na fila da execução inicial em vez de iniciar uma segunda execução que falhou com "O agente já está processando", pi.sendUserMessage() requer deliverAs e um aborto solicitado enquanto isso aborta a execução assim que ela é iniciada (#10739 por @davidbrai)
  • Alterado pi mcp list --json para reportar resources: true para servidores que oferecem recursos em vez de contagens resources e resourceTemplates; Pi não lista mais recursos ao conectar (#10526)

Adicionado

  • Adicionado reachesTools nas definições de ferramentas, para que ferramentas que alcançam outras ferramentas (como codemode e tool_search) declarem quais ferramentas uma chamada pode atingir; o ramal MCP o utiliza para aguardar os servidores necessários para uma chamada e para decidir se uma ferramenta codemode ou tool_search substituta pode alcançar as ferramentas MCP
  • Adicionado aliases aos namespaces de ferramentas; describeNamespace() do codemode e a opção namespace de searchTools() correspondem a eles, e os namespaces MCP usam o nome do servidor
  • Adicionadas listas de modelos OpenRouter por chave: com uma chave OpenRouter, Pi lista apenas os modelos de bate-papo que a chave pode usar, com o tamanho do contexto da chave, saída máxima e preços, incluindo proteções e endpoints regionais definidos como URL base em models.json. A lista é salva e usada offline (#10353, #10672 por @davidbrai)
  • Adicionado PI_CLIPBOARD_OSC52=1 para enviar texto copiado para o terminal com OSC 52 após a gravação local do clipboard, para que as cópias cheguem ao clipboard de um client remoto quando Pi não consegue detectar a sessão remota, como multiplexadores anexados de outra máquina ou daemons IDE remotos (#10826, #10835, #10114)
  • Adicionado tempo decorrido enquanto um script de modo de código é executado e seu tempo total, uma vez concluído, na linha da ferramenta de modo de código, como linhas bash (#10708)

Alterado

  • Alterada a configuração showHardwareCursor para usar apenas o cursor do terminal em vez de desenhar também o cursor de vídeo reverso do Pi
  • Alteradas as declarações da ferramenta codemode para mostrar restrições de entrada como número inteiro, mínimo/máximo, comprimento, padrão e padrão como tags @ em comentários de propriedade, para que os scripts as vejam sem que a ferramenta as repita nas descrições (#10707)
  • Alteradas as declarações de modo de código das ferramentas MCP para especificar o tipo de resultado (content, structuredContent, isError) em vez de se referir a CallToolResult<T>, que describeTool(), searchTools() e ALL_TOOLS mostravam sem defini-lo; a descrição do modo de código não inclui mais os tipos de MCP compartilhados
  • Alterado serializeConversation() (compactação, resumos de ramificações, relatórios de bugs) para omitir blocos de pensamento; o pensamento repetido muitas vezes não está no contexto ao vivo, portanto, incluí-lo poderia tornar uma solicitação de resumo maior do que o contexto que ele resume e falhar

Corrigido

  • Corrigido codemode ignorando uma linha // @options: que não é a primeira linha do script, que rodava o script sem o timeout_ms solicitado; a chamada agora falha com um erro antes da execução do script (#10631)
  • Correção de fluxos Mistral sendo abortados no meio da geração (por exemplo, durante um longo pensamento) após o tempo limite da solicitação; o tempo limite agora se aplica apenas à espera por cabeçalhos de resposta (#10609)
  • Corrigido um AGENTS.md com link simbólico em uma árvore de trabalho git aninhada dentro de seu repositório principal, fazendo com que nenhum arquivo de contexto do projeto fosse carregado (#10681)
  • Corrigida a descrição da ferramenta no modo de código, alegando todas as rejeições de chamadas de ferramenta com falha; uma ferramenta que declara um esquema de saída também resolve seu valor em caso de falha (por exemplo, bash com uma saída diferente de zero)
  • Corrigidas execuções iniciadas por pi.sendMessage(..., { triggerTurn: true }), removendo seções de prompt do sistema adicionadas em before_agent_start após sua primeira chamada de ferramenta, o que alterava o prompt no meio da execução e quebrava o cache de prompt do provedor duas vezes por execução (#10267, #10739 por @davidbrai)
  • Corrigido codemode bloqueando o processo por segundos a minutos após scripts com muitas chamadas text(); a junção dos itens de saída era quadrática (#10678)
  • Corrigido modo de impressão (-p) saindo de 0 sem aviso quando a resposta final era cortada no limite de token de saída do modelo; agora imprime o texto parcial, grava um aviso em stderr e sai de 1 (#10799)
  • Corrigidos os documentos pi mcp login --help e CLI descrevendo --timeout como apenas a espera pelo navegador; limita todo o login (#10636)
  • Corrigido ~ não sendo expandido nas entradas !pattern, +path e -path das configurações extensions, skills, prompts e themes, então entradas como !~/skills/pdf não correspondiam a nada (#10765)
  • Correção de servidores MCP com recursos não registrando nenhuma ferramenta até que todos os recursos fossem listados; Pi não lista mais recursos ao conectar, então /mcp e pi mcp list mostram que um servidor oferece recursos em vez de contá-los (#10526)
  • Corrigida falha nas chamadas da ferramenta MCP quando o servidor retorna conteúdo estruturado que não é um objeto (um array, null, ou um primitivo, conforme permitido pelo MCP 2026-07-28); Declarações de modo de código de ferramentas MCP sem um esquema de saída agora digitam structuredContent como unknown em vez de um objeto (#10416)
  • Corrigida falha na leitura ou gravação de auth.json no Windows com EPERM quando a pasta de bloqueio anterior ainda estava sendo excluída; Pi agora tenta brevemente antes de relatar o erro (#10801)
  • Modelos de roteador OpenRouter corrigidos, como openrouter/auto, mostrando um custo de -$1.000.000 por 1 milhão de tokens; Os preços de espaço reservado negativo do OpenRouter agora são 0 (#10672 por @davidbrai)
  • Corrigida falha nas solicitações antrópicas quando o provedor rejeita o conjunto estrito de ferramentas para tamanho de gramática, contagem de ferramentas ou limites de união; Pi agora tenta novamente uma vez com ferramentas preferenciais não estritas (#10409)
  • Corrigido "O provedor upstream retornou um erro" não sendo repetido como um erro transitório do provedor (#10842)
  • Corrigidas sobreposições de tela cheia focadas que bloqueavam a rolagem da transcrição com a roda do mouse (#10769)
  • Correção de respostas de cores de terminal fragmentadas vazando valores hexadecimais no prompt e abrindo o editor externo (relatórios relacionados: #10256, #10657)
  • Corrigidas imagens inline que não eram renderizadas no Herdr desde 1.1.0 (#10774 por @ogulcancelik)
  • Correção de atalhos de teclas que nomeiam um símbolo deslocado, como + ou ctrl++, não correspondendo ao protocolo de teclado Kitty ou modificaOtherKeys (#9880 por @christianklotz)
  • Corrigido o indicador de status de compactação incorporado em um editor personalizado usando as cores silenciadas padrão em vez da borda do editor ou cor de nível de pensamento, como faz o indicador de trabalho (#10809, #10810 por @Jay-Madden)
  • Corrigidas chamadas de ferramenta MCP que foram canceladas ou atingiram o tempo limite enquanto aguardavam por uma atualização OAuth ainda sendo enviada ao servidor após a conclusão da atualização (#10598)
  • Foi corrigido o login do MCP OAuth que aceitava uma resposta de autorização com um parâmetro iss que não podia ser verificado porque nenhum metadado do servidor de autorização foi descoberto; o login agora falha devido a uma incompatibilidade de emissor. Relatado por @AizenvoltPrime
  • Corrigida falha no modo de código com um erro de ponte quebrada quando Pi é executado em node --watch no nó 24 ou 26 (#10725)

Removido

  • Removido o servidor experimental não lançado, client, e a pilha de plugins (src/experimental, src/cli/experimental) e suas exportações ./client e ./experimental/plugin somente de origem; nada disso fazia parte do pacote publicado. Os pacotes @earendil-works/pi-client, @earendil-works/pi-protocol e @earendil-works/pi-server usados foram removidos e não serão mais lançados
  • Removida a dependência do @earendil-works/chord

pi v1.2.0

New Features

  • Per-key OpenRouter model lists: with an OpenRouter key, Pi lists only the models that key may use, with the key's context size, max output, and prices, including regional endpoints set in models.json. See OpenRouter.
  • Published configuration schemas: add $schema to settings.json, models.json, keybindings, and themes for editor validation and completion. See Settings, Models, Keybindings, and Themes.
  • Clipboard copies over remote sessions: PI_CLIPBOARD_OSC52=1 sends copied text to a remote client's clipboard when Pi cannot detect the remote session, such as a multiplexer attached from another machine. See Pi Process Configuration.
  • Codemode improvements: tool declarations show input constraints such as integer, minimum/maximum, and default, and codemode rows show elapsed and total time. See Codemode.
  • before_agent_start for extension-triggered runs: runs started by pi.sendMessage(..., { triggerTurn: true }) go through the same setup as prompts. See Events and concurrency.

Breaking Changes

  • Published generated configuration schemas for models, settings, keybindings, and themes at https://pi.dev/schemas/*.schema.json. The theme schema moved to https://pi.dev/schemas/theme.schema.json; themes loaded during startup now receive the same schema validation as later reloads. Update theme $schema references, define reusable colors under vars, and remove unsupported metadata (#9880, #10751 by @christianklotz)
  • Changed before_agent_start to also fire for runs started by pi.sendMessage(..., { triggerTurn: true }) while idle. BeforeAgentStartEvent is now a union on messageType: "user" events carry prompt and images, and "custom" events carry the starting message and no prompt. Messages returned by handlers are added to both kinds of run, and pending deliverAs: "nextTurn" messages are delivered with the custom-message run. Handlers that should act only on user prompts must check event.messageType === "user" (#10267, #5581, #10739 by @davidbrai)
  • Changed the session to count as busy while a run starts, including during before_agent_start handlers: ctx.isIdle() is false, pi.sendMessage() queues into the starting run instead of starting a second run that failed with "Agent is already processing", pi.sendUserMessage() requires deliverAs, and an abort requested meanwhile aborts the run once it starts (#10739 by @davidbrai)
  • Changed pi mcp list --json to report resources: true for servers that offer resources instead of resources and resourceTemplates counts; Pi no longer lists resources when connecting (#10526)

Added

  • Added reachesTools to tool definitions, so tools that reach other tools (such as codemode and tool_search) declare which tools a call may reach; the MCP extension uses it to wait for the servers a call needs and to decide whether a replacement codemode or tool_search tool can reach MCP tools
  • Added aliases to tool namespaces; codemode's describeNamespace() and the namespace option of searchTools() match them, and MCP namespaces use the server name
  • Added per-key OpenRouter model lists: with an OpenRouter key, Pi lists only the chat models that key may use, with the key's context size, max output, and prices, including guardrails and regional endpoints set as the base URL in models.json. The list is saved and used offline (#10353, #10672 by @davidbrai)
  • Added PI_CLIPBOARD_OSC52=1 to send copied text to the terminal with OSC 52 after the local clipboard write, so copies reach a remote client's clipboard when Pi cannot detect the remote session, such as multiplexer attaches from another machine or remote IDE daemons (#10826, #10835, #10114)
  • Added elapsed time while a codemode script runs and its total time once finished to the codemode tool row, like bash rows (#10708)

Changed

  • Changed the showHardwareCursor setting to use only the terminal cursor instead of also drawing Pi's reverse-video cursor
  • Changed codemode tool declarations to show input constraints such as integer, minimum/maximum, length, pattern, and default as @ tags on property comments, so scripts see them without the tool repeating them in descriptions (#10707)
  • Changed codemode declarations of MCP tools to spell out the result type (content, structuredContent, isError) instead of referring to CallToolResult<T>, which describeTool(), searchTools(), and ALL_TOOLS showed without defining it; the codemode description no longer includes the shared MCP types
  • Changed serializeConversation() (compaction, branch summaries, bug reports) to omit thinking blocks; replayed thinking is often not in the live context, so including it could make a summarization request larger than the context it summarizes and fail

Fixed

  • Fixed codemode ignoring a // @options: line that is not the first line of the script, which ran the script without the requested timeout_ms; the call now fails with an error before the script runs (#10631)
  • Fixed Mistral streams being aborted mid-generation (e.g. during long thinking) after the request timeout; the timeout now applies only to waiting for response headers (#10609)
  • Fixed a symlinked AGENTS.md in a git worktree nested inside its main repo causing no project context file to load (#10681)
  • Fixed the code mode tool description claiming every failed tool call rejects; a tool that declares an output schema resolves with its value on failure too (e.g. bash with a nonzero exit)
  • Fixed runs started by pi.sendMessage(..., { triggerTurn: true }) removing system prompt sections added in before_agent_start after their first tool call, which changed the prompt mid-run and broke the provider prompt cache twice per run (#10267, #10739 by @davidbrai)
  • Fixed codemode blocking the process for seconds to minutes after scripts with many text() calls; joining the output items was quadratic (#10678)
  • Fixed print mode (-p) exiting 0 without a warning when the final response was cut off at the model's output token limit; it now prints the partial text, writes a warning to stderr, and exits 1 (#10799)
  • Fixed pi mcp login --help and the CLI docs describing --timeout as only the wait for the browser; it limits the whole sign-in (#10636)
  • Fixed ~ not being expanded in !pattern, +path, and -path entries of the extensions, skills, prompts, and themes settings, so entries like !~/skills/pdf matched nothing (#10765)
  • Fixed MCP servers with resources registering no tools until every resource was listed; Pi no longer lists resources when connecting, so /mcp and pi mcp list show that a server offers resources instead of counting them (#10526)
  • Fixed MCP tool calls failing when the server returns structured content that is not an object (an array, null, or a primitive, as MCP 2026-07-28 allows); codemode declarations of MCP tools without an output schema now type structuredContent as unknown instead of an object (#10416)
  • Fixed reading or writing auth.json on Windows failing with EPERM when the previous lock folder was still being deleted; Pi now retries briefly before reporting the error (#10801)
  • Fixed OpenRouter router models such as openrouter/auto showing a cost of -$1,000,000 per 1M tokens; OpenRouter's negative placeholder prices are now 0 (#10672 by @davidbrai)
  • Fixed Anthropic requests failing when the provider rejects the strict tool set for grammar size, tool count, or union limits; Pi now retries once with preferred tools non-strict (#10409)
  • Fixed "The upstream provider returned an error" not being retried as a transient provider error (#10842)
  • Fixed focused fullscreen overlays blocking mouse-wheel scrolling of the transcript (#10769)
  • Fixed fragmented terminal color replies leaking hex values into the prompt and opening the external editor (related reports: #10256, #10657)
  • Fixed inline images not rendering in Herdr since 1.1.0 (#10774 by @ogulcancelik)
  • Fixed key bindings that name a shifted symbol, such as + or ctrl++, not matching under the Kitty keyboard protocol or modifyOtherKeys (#9880 by @christianklotz)
  • Fixed the compaction status indicator embedded in a custom editor using the default muted colors instead of the editor border or thinking-level color, as the working indicator does (#10809, #10810 by @Jay-Madden)
  • Fixed MCP tool calls that were cancelled or timed out while waiting for an OAuth refresh still being sent to the server once the refresh finished (#10598)
  • Fixed MCP OAuth sign-in accepting an authorization response with an iss parameter that could not be checked because no authorization server metadata was discovered; sign-in now fails with an issuer mismatch. Reported by @AizenvoltPrime
  • Fixed codemode failing with a broken bridge error when Pi runs under node --watch on Node 24 or 26 (#10725)

Removed

  • Removed the unreleased experimental server, client, and plugin stack (src/experimental, src/cli/experimental) and its source-only ./client and ./experimental/plugin exports; none of it was part of the published package. The @earendil-works/pi-client, @earendil-works/pi-protocol, and @earendil-works/pi-server packages it used are removed and no longer released
  • Removed the dependency on @earendil-works/chord
