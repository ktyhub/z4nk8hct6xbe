pi v1.0.0

Novos recursos

  • Tela cheia por padrão — A TUI agora funciona em tela cheia. Defina tuiMode como "regular" para manter a rolagem normal do terminal. Consulte Terminal e display.
  • Modo de código mais enxuto — Cerca de 40% menos tokens de prompt e erros que informam ao modelo como se recuperar. Consulte Modo de código.
  • Geração de imagem em codemode — Os scripts chamam models.generateImages() com as credenciais da sessão. Consulte Gerar imagens e Usar modelos de imagem.
  • Radius em /login — Faça login no Radius e configure seu servidor MCP em uma única etapa. Consulte Raio.
  • Login com código de cópia antrópica — Faça login quando o navegador for executado em outra máquina. Consulte Autenticar interativamente.
  • Proteção MCP OAuth — verificações oauth.authServerMetadataUrl, RFC 9207 iss, credenciais por servidor e login avançado que mantém os escopos concedidos. Consulte Autenticar com OAuth.
  • Inicialização silenciosa apenas no cabeçalho — quietStartup: "header" mantém a versão e as principais dicas e oculta o resto. Consulte Terminal e display.

Adicionado

  • Adicionada uma configuração oauth.authServerMetadataUrl para servidores MCP que anunciam um servidor de autorização OAuth errado ou nenhum. Pi usa o documento de metadados configurado em vez da descoberta (#10172).
  • Adicionado quietStartup: "header", que mantém o cabeçalho de inicialização com versão e dicas principais, mas oculta a linha de escopo do modelo e a listagem de recursos carregados.
  • Adicionado models.generateImages() aos scripts de modo de código. Ele executa modelos de imagem como o OpenRouter com as credenciais da sessão e retorna blocos de imagem base64 que image() anexa ao resultado; o uso conta para o custo da sessão como models.classify(). Os ramais podem chamar ctx.modelRegistry.generateImages(). Consulte Usar modelos de imagem.
  • Adicionado um método de login de código de cópia ao Anthropic /login para configurações headless onde o navegador é executado em outra máquina (#10194 por @lucasmeijer).

Alterado

  • Alterado o modo TUI padrão para tela cheia. Defina tuiMode como "regular" ou passe --tui-mode regular para manter a rolagem normal do terminal.
  • /login agora oferece "Sign in with Radius" no nível superior, como última opção, com seu status. Após um login no Radius, /login se oferece para configurar o servidor Radius MCP no mcp.json global com "auth": { "provider": "radius" } e recarrega. Cancelar um login retorna ao menu a partir do qual foi iniciado.
  • A página de documentos do provedor foi renomeada para Provedores, sua seção "Provedores de nuvem" agora é "Configuração específica do provedor" e documenta o Radius primeiro.
  • As credenciais do MCP OAuth agora são armazenadas por nome de servidor e URL, para que servidores MCP com o mesmo URL possam fazer login com contas diferentes. As credenciais armazenadas apenas por URL são movidas para o primeiro servidor que as utiliza (#10252).
  • Codemode custa muito menos tokens de prompt: com as ferramentas padrão e codemode ativos, uma solicitação GPT-5.6 diminui de cerca de 5.300 para 3.300 tokens. A descrição do codemode lista os scripts globais em uma linha cada e aponta para a nova referência Codemode para o models API, que o modelo lê quando precisa. As ferramentas declaradas dizem em uma linha como os scripts as chamam e o que a chamada resolve, em vez de repetir sua declaração completa, e a orientação do modo de código do prompt do sistema e a seção do servidor MCP são mais curtas.
  • Erros de modo de código agora dizem como recuperar: ler uma ferramenta ou membro models que não existe nomeia as correspondências próximas (tools.Bash sugere tools.bash), models.classify() e models.generateImages() rejeitam argumentos malformados com a forma esperada, um modelo desconhecido aponta para models.getAvailableOfType(), um valor store() superdimensionado explica para que serve o armazenamento e um script que gera imagens sem mostrá-las recebe uma nota. Os scripts que testaram uma ferramenta com typeof tools.name devem usar "name" in tools.
  • /login e /logout agora rotulam provedores sem credenciais como "não configurados" em vez de "desconfigurados".
  • As páginas do navegador OAuth agora mostram o logotipo colorido do Pi.

Corrigido

  • Corrigido o login do MCP OAuth aceitando uma resposta de autorização cujo parâmetro iss nomeia outro servidor de autorização; o código agora é rejeitado antes de ser trocado (RFC 9207).
  • Corrigida falha de login do MCP OAuth com Invalid scope quando a resposta do token contém "scope": "" e falhas semelhantes para outros campos OAuth vazios ou opcionais null (#10266).
  • Corrigido o URL de login impresso por /mcp login que não era clickable quando encapsulado (#10186).
  • Corrigido --provider sem que --model fosse silenciosamente ignorado e executando o modelo padrão de outro provedor; agora falha com um erro (#10236).
  • Servidores MCP corrigidos que solicitam mais escopo (insufficient_scope) solicitando login repetidamente. O novo login solicitou apenas os escopos ausentes, portanto o novo token perdeu o acesso que o anterior tinha; agora mantém os escopos concedidos.
  • Corrigidas mensagens do usuário na transcrição mantendo duas cópias de largura total de cada linha renderizada; eles mantêm um, com saída idêntica.
  • Correção de /login e /logout rotulando cada login do OAuth, incluindo Radius, como uma assinatura; apenas provedores apoiados por assinatura dizem "assinatura", outros logins do OAuth dizem "conta".
  • Corrigida a renderização do logotipo do cabeçalho de inicialização com lacunas no Terminal Apple; agora mostra um "Pi" colorido com a versão.
  • Correção de ferramentas MCP adiadas que tool_search carregavam sendo descartadas ao retomar e /reload mesmo quando seu servidor se reconectava antes do próximo prompt, porque a sessão restaurava suas ferramentas antes dos servidores MCP serem reconectados.
  • Corrigido o tema do sistema tornando paletas pastéis como Catppuccin Frappe muito mais vivas; as cores da paleta agora mantêm seu croma (#10255, #10293 por @dgtlntv).
  • Corrigido o preenchimento automático do comando de barra que não era acionado quando a entrada começa com espaço em branco (#10218 por @haoqixu).
  • Correção do sangramento de cor após as seleções do mouse e destaques de pesquisa no modo de tela cheia quando um token estilizado termina no limite de destaque (#10169).
  • Corrigida memória retida por mensagem renderizada na transcrição; uma mensagem longa do assistente mantém cerca de um quinto da pilha que mantinha antes.

pi v1.0.0

New Features

  • Fullscreen by default — The TUI now runs fullscreen. Set tuiMode to "regular" to keep the terminal's normal scrollback. See Terminal and display.
  • Leaner codemode — About 40% fewer prompt tokens, and errors that tell the model how to recover. See Codemode.
  • Image generation in codemode — Scripts call models.generateImages() with the session's credentials. See Generate images and Use image models.
  • Radius in /login — Sign in with Radius and set up its MCP server in one step. See Radius.
  • Anthropic copy code login — Sign in when the browser runs on another machine. See Authenticate interactively.
  • MCP OAuth hardening — oauth.authServerMetadataUrl, RFC 9207 iss checks, credentials per server, and step-up sign-in that keeps granted scopes. See Authenticate with OAuth.
  • Header-only quiet startup — quietStartup: "header" keeps the version and key hints and hides the rest. See Terminal and display.

Added

  • Added an oauth.authServerMetadataUrl setting for MCP servers that advertise a wrong OAuth authorization server or none. Pi uses the configured metadata document instead of discovery (#10172).
  • Added quietStartup: "header", which keeps the startup header with version and key hints but hides the model scope line and loaded-resource listing.
  • Added models.generateImages() to codemode scripts. It runs image models such as OpenRouter's with the session's credentials and returns base64 image blocks that image() attaches to the result; usage counts toward the session cost like models.classify(). Extensions can call ctx.modelRegistry.generateImages(). See Use image models.
  • Added a copy code login method to Anthropic /login for headless setups where the browser runs on another machine (#10194 by @lucasmeijer).

Changed

  • Changed the default TUI mode to fullscreen. Set tuiMode to "regular" or pass --tui-mode regular to keep the terminal's normal scrollback.
  • /login now offers "Sign in with Radius" at the top level, as the last option, with its status. After a Radius sign-in, /login offers to configure the Radius MCP server in the global mcp.json with "auth": { "provider": "radius" } and reloads. Cancelling a login returns to the menu it was started from.
  • The provider docs page is renamed to Providers, its "Cloud Providers" section is now "Provider Specific Config", and it documents Radius first.
  • MCP OAuth credentials are now stored per server name and URL, so MCP servers with the same URL can sign in with different accounts. Credentials stored by URL alone move to the first server that uses them (#10252).
  • Codemode costs far fewer prompt tokens: with the default tools and codemode active, a GPT-5.6 request shrinks from about 5,300 to 3,300 tokens. The codemode description lists the script globals in one line each and points to the new Codemode reference for the models API, which the model reads when it needs it. Declared tools say in one line how scripts call them and what the call resolves to, instead of repeating their full declaration, and the system prompt's codemode guidance and MCP server section are shorter.
  • Codemode errors now say how to recover: reading a tool or models member that does not exist names the close matches (tools.Bash suggests tools.bash), models.classify() and models.generateImages() reject malformed arguments with the expected shape, an unknown model points to models.getAvailableOfType(), an oversized store() value explains what the store is for, and a script that generates images without showing them gets a note. Scripts that probed for a tool with typeof tools.name must use "name" in tools.
  • /login and /logout now label providers without credentials as "not configured" instead of "unconfigured".
  • OAuth browser pages now show the color Pi logo.

Fixed

  • Fixed MCP OAuth sign-in accepting an authorization response whose iss parameter names another authorization server; the code is now rejected before it is exchanged (RFC 9207).
  • Fixed MCP OAuth sign-in failing with Invalid scope when the token response contains "scope": "", and similar failures for other empty or null optional OAuth fields (#10266).
  • Fixed the sign-in URL printed by /mcp login not being clickable when it wraps (#10186).
  • Fixed --provider without --model being silently ignored and running the default model from another provider; it now fails with an error (#10236).
  • Fixed MCP servers that ask for more scope (insufficient_scope) requesting sign-in over and over. The new sign-in requested only the missing scopes, so the new token lost access the previous one had; it now keeps the granted scopes.
  • Fixed user messages in the transcript keeping two full-width copies of every rendered line; they keep one, with identical output.
  • Fixed /login and /logout labeling every OAuth sign-in, including Radius, as a subscription; only subscription-backed providers say "subscription", other OAuth sign-ins say "account".
  • Fixed the startup header logo rendering with gaps in Apple Terminal; it now shows a colored "Pi" with the version instead.
  • Fixed deferred MCP tools that tool_search loaded being dropped on resume and /reload even when their server reconnected before the next prompt, because the session restored its tools before the MCP servers reconnected.
  • Fixed the system theme making pastel palettes such as Catppuccin Frappe much more vivid; palette colors now keep their chroma (#10255, #10293 by @dgtlntv).
  • Fixed slash command autocompletion not triggering when the input starts with whitespace (#10218 by @haoqixu).
  • Fixed color bleeding past mouse selections and search highlights in fullscreen mode when a styled token ends at the highlight boundary (#10169).
  • Fixed memory retained per rendered message in the transcript; a long assistant message keeps about a fifth of the heap it kept before.
