pi v1.3.0

Novos recursos

  • Escolha onde /share faz upload: sessionShareDestination seleciona auto, gist ou radius. Consulte Sessões e contexto e Exportar ou compartilhar uma sessão.
  • Alterações no nível de pensamento para preservação de cache no OpenAI GPT-6: alterar o nível de pensamento no meio da sessão com uma chave API mantém o cache de prompt.
  • Kimi Code over Chat Completions: ferramentas adicionadas no meio da conversa não invalidam mais o cache de prompt. As substituições de URL base models.json agora devem incluir /v1. Consulte Provedores.
  • Troca de modelo limpo: o pensamento de um modelo anterior é descartado em vez de ser mostrado para o novo modelo como texto.
  • As sessões retomadas mantêm suas ferramentas ativas: --tools +name/-name se aplica sobre elas. Consulte Ferramentas.

Adicionado

  • Alterar o nível de pensamento no meio da sessão nos modelos OpenAI GPT-6 (chave API) agora mantém o cache de prompt (#10853)
  • Adicionada a configuração sessionShareDestination para escolher uploads automáticos, GitHub Gist ou Radius para /share (#10870 por @vegarsti)

Alterado

  • Alterado o provedor kimi-coding para usar OpenAI Chat Completions em https://api.kimi.com/coding/v1, protocolo usado pelo Kimi Code oficial client. K3, K3-256K e Kimi For Coding agora aceitam ferramentas adicionadas no meio da conversa sem invalidar o cache de prompt. As substituições models.json do URL base kimi-coding agora devem incluir /v1 (#10720)
  • Mudança de modelo para eliminar blocos de pensamento de mensagens anteriores do assistente produzidas por um modelo diferente, em vez de enviá-las como texto simples. O novo modelo anteriormente via o raciocínio do modelo antigo como parte de suas respostas e poderia começar a escrever seu próprio raciocínio na resposta visível (#10995)

Corrigido

  • Fixadas dependências internas do Pi em versões de lançamento exatas para evitar que novas instalações misturem pacotes incompatíveis (#10865)
  • Corrigidas sessões retomadas que descartavam ferramentas ativadas durante a sessão. Retomar agora restaura as ferramentas ativas da sessão, com entradas --tools +name/-name aplicadas a elas, a menos que --tools com nomes de ferramentas, --no-tools ou --no-builtin-tools selecione ferramentas explicitamente (#10785)
  • Corrigida a interrupção de um script de modo de código ou o cumprimento do prazo aguardando o retorno de um built-in ininterrupto no Bun (#10748)
  • Corrigidos tempos limite repetidos do modo de código ou abortos acumulando trabalhadores sobreviventes; a admissão agora limita os trabalhadores ativos a dois entre sessões, contando os trabalhadores cancelados até a saída real (#10748)
  • Corrigido --model escolhendo um fornecedor por ordem de catálogo quando vários fornecedores oferecem o match; Pi agora prefere o provedor com credenciais e relata a ambigüidade. --models e enabledModels adicionam um modelo para cada provedor que o oferece e alertam sobre a ambiguidade (#10160)
  • Corrigidos rótulos de intervalo de linha read para string numérica ou argumentos nulos na TUI, árvore de sessão, exportações HTML e exemplos (#9887)
  • Corrigida a falha de compilação do Nix Flake quando um provedor trocava APIs: o pino do catálogo de modelos agora é atualizado a partir do catálogo publicado mais recente quando seus grupos de modelo API diferem e os lançamentos fixam o catálogo mais recente e compilam com ele antes da marcação (#10985)
  • Corrigido o pacote Nix colocando seu Node.js primeiro em PATH, o que fazia com que os shells de ferramentas bash usassem o Node Pi em vez do node/npm do usuário. O nó do Pi agora é apenas um substituto (#10519)
  • Corrigidos modelos de prompt eliminando argumentos vazios entre aspas ("" ou ''), que mudavam argumentos posicionais posteriores e impediam a aplicação de padrões posicionais (#10867)
  • Corrigida falha na compilação do pacote Nix em sua verificação de instalação porque ainda esperava acorde e esbuild, dos quais Pi não depende mais
  • Argumento de chamada de ferramenta corrigido analisando campos descartados quando uma string contém um escape \u inválido, como \usepackage (#10868)
  • Corrigidas solicitações de Anthropic e Bedrock Claude que falhavam com 400 quando um resultado de ferramenta de erro continha imagens; as imagens agora são enviadas após os resultados da ferramenta do giro, então o modelo ainda as vê (#10794)
  • Corrigidos modelos OpenCode Go Gemini que falhavam com um 404 movendo OpenCode Zen e OpenCode Go para os endpoints opencode.ai/inference e adicionado suporte Google Generative AI ao provedor OpenCode Go
  • Corrigida falha do OpenCode Go MiniMax M2.7 com "Modelo não suporta este protocolo" usando o Anthropic Messages API
  • Corrigida nova tentativa automática que não era acionada para erros do gateway Unable to forward upstream stream (#10920)
  • Correção de nova tentativa automática que não era acionada para erros The service is temporarily unavailable, o que também fazia a compactação falhar na primeira tentativa (#10965)
  • Corrigidas respostas compatíveis com OpenAI mostrando o pensamento após a resposta quando um proxy como LiteLLM envia raciocínio e conteúdo no mesmo bloco de fluxo (#10926)
  • Correção de falha nas solicitações do Gemini 4 Argon no Google Vertex com "O orçamento de pensamento não é suportado" e seu nível de pensamento sendo ignorado no Gemini API (#10890)
  • Corrigidos modelos Xiaomi MiMo falhando com 400 no nível de pensamento minimal; eles agora expõem apenas os níveis off e high (#10818)
  • Corrigido openai-codex/gpt-6.1-sol usando uma janela de contexto de 272K em vez da janela de 500K que o Codex agora fornece (#10840)
  • Corrigidas chamadas de ferramenta cujos argumentos finais estão mal formados JSON rodando silenciosamente apenas com os campos analisados antes do erro; eles agora falham na validação e mostram ao modelo os argumentos brutos enviados (#10897)
  • Corrigido Claude Haiku 5.5 e Claude Opus 5 que não suportavam o nível de pensamento off (#10753)
  • Corrigido done() do ctx.ui.custom({ overlay: true }) de uma extensão fechando a sobreposição superior em vez da sua própria, o que deixava a sobreposição finalizada na tela e a caixa de diálogo de outra extensão sem resolução (#10648, #10999 por @masonc15)

pi v1.3.0

New Features

  • Choose where /share uploads: sessionShareDestination selects auto, gist, or radius. See Sessions and context and Export or share a session.
  • Cache-preserving thinking level changes on OpenAI GPT-6: changing the thinking level mid-session with an API key keeps the prompt cache.
  • Kimi Code over Chat Completions: tools added mid-conversation no longer invalidate the prompt cache. models.json base URL overrides must now include /v1. See Providers.
  • Clean model switching: thinking from a previous model is dropped instead of being shown to the new model as text.
  • Resumed sessions keep their active tools: --tools +name/-name applies on top of them. See Tools.

Added

  • Changing the thinking level mid-session on OpenAI GPT-6 models (API key) now keeps the prompt cache (#10853)
  • Added the sessionShareDestination setting to choose automatic, GitHub gist, or Radius uploads for /share (#10870 by @vegarsti)

Changed

  • Changed the kimi-coding provider to use OpenAI Chat Completions at https://api.kimi.com/coding/v1, the protocol used by the official Kimi Code client. K3, K3-256K, and Kimi For Coding now accept tools added mid-conversation without invalidating the prompt cache. models.json overrides of the kimi-coding base URL must now include /v1 (#10720)
  • Changed model switching to drop thinking blocks from earlier assistant messages produced by a different model, instead of sending them as plain text. The new model previously saw the old model's reasoning as part of its replies and could start writing its own reasoning into the visible answer (#10995)

Fixed

  • Pinned internal Pi dependencies to exact release versions to prevent fresh installs from mixing incompatible packages (#10865)
  • Fixed resumed sessions dropping tools activated during the session. Resume now restores the session's active tools, with --tools +name/-name entries applied to them, unless --tools with tool names, --no-tools, or --no-builtin-tools selects tools explicitly (#10785)
  • Fixed stopping a codemode script or reaching its deadline waiting for a non-interruptible built-in to return on Bun (#10748)
  • Fixed repeated codemode timeouts or aborts accumulating surviving workers; admission now limits live workers to two across sessions, counting cancelled workers until actual exit (#10748)
  • Fixed --model choosing a provider by catalog order when several providers offer the match; Pi now prefers the provider with credentials and otherwise reports the ambiguity. --models and enabledModels add a model for each provider that offers it and warn about the ambiguity (#10160)
  • Fixed read line-range labels for numeric-string or null arguments in the TUI, session tree, HTML exports, and examples (#9887)
  • Fixed the Nix flake build failing when a provider switched APIs: the model catalog pin is now refreshed from the newest published catalog when its model API groups differ, and releases pin the newest catalog and build with it before tagging (#10985)
  • Fixed the Nix package putting its Node.js first on PATH, which made bash tool shells use Pi's Node instead of the user's node/npm. Pi's Node is now only a fallback (#10519)
  • Fixed prompt templates dropping empty quoted arguments ("" or ''), which shifted later positional arguments and prevented positional defaults from applying (#10867)
  • Fixed the Nix package build failing in its install check because it still expected chord and esbuild, which Pi no longer depends on
  • Fixed tool-call argument parsing dropping fields when a string contains an invalid \u escape such as \usepackage (#10868)
  • Fixed Anthropic and Bedrock Claude requests failing with a 400 when an error tool result contains images; the images are now sent after the tool results of the turn, so the model still sees them (#10794)
  • Fixed OpenCode Go Gemini models failing with a 404 by moving OpenCode Zen and OpenCode Go to the opencode.ai/inference endpoints, and added Google Generative AI support to the OpenCode Go provider
  • Fixed OpenCode Go MiniMax M2.7 failing with "Model does not support this protocol" by using the Anthropic Messages API
  • Fixed automatic retry not triggering for gateway Unable to forward upstream stream errors (#10920)
  • Fixed automatic retry not triggering for The service is temporarily unavailable errors, which also made compaction fail on the first attempt (#10965)
  • Fixed OpenAI-compatible responses showing thinking after the answer when a proxy such as LiteLLM sends reasoning and content in the same stream chunk (#10926)
  • Fixed Gemini 4 Argon requests on Google Vertex failing with "Thinking budget is not supported", and its thinking level being ignored on the Gemini API (#10890)
  • Fixed Xiaomi MiMo models failing with a 400 at the minimal thinking level; they now expose only the off and high levels (#10818)
  • Fixed openai-codex/gpt-6.1-sol using a 272K context window instead of the 500K window Codex now provides (#10840)
  • Fixed tool calls whose final arguments are malformed JSON silently running with only the fields parsed before the error; they now fail validation and show the model the raw arguments it sent (#10897)
  • Fixed Claude Haiku 5.5 and Claude Opus 5 not supporting the off thinking level (#10753)
  • Fixed done() of an extension's ctx.ui.custom({ overlay: true }) closing the topmost overlay instead of its own, which left the finished overlay on screen and another extension's dialog unresolved (#10648, #10999 by @masonc15)
