pi v0.99.0

Novos recursos

  • Codemode e MCP — Conecte servidores MCP e deixe os modelos executarem JavaScript que chama ferramentas em paralelo. Consulte Servidores MCP e Ativar modo de código.
  • Tema do sistema — As cores do Pi agora vêm da paleta do próprio terminal por padrão. Consulte Use as cores do seu terminal.
  • Faça login com ChatGPT — Use uma assinatura ChatGPT com o provedor OpenAI por meio de /login openai. Consulte Autenticar interativamente.
  • Modelos virtuais — As extensões podem rotear cada solicitação para um modelo físico diferente. Consulte Modelos Virtuais.
  • Modelos de classificador — Execute classificadores Jev a partir de scripts de modo de código ou use qualquer modelo llama.cpp como classificador. Consulte Como funciona o codemode e Classificação.

Adicionado

  • Adicionado modo de código, pesquisa de ferramentas e suporte MCP como extensões integradas. A ferramenta codemode executa JavaScript escrito em modelo em uma sandbox QuickJS que chama as ferramentas do pi; habilite-o com defaultTools ou --tools e configure-o com codemode.mode e codemode.inlineBudget. tool_search encontra ferramentas que não estão declaradas no modelo e as declara. Servidores MCP sobre stdio ou HTTP streamable, com OAuth, vêm de mcp.json (global, ou por projeto uma vez trusted) ou pi.registerMcpServer() e são gerenciados com /mcp e pi mcp add|remove|list|login|logout. Consulte Servidores MCP e Ativar modo de código (#10040).
  • Adicionadas ferramentas de extensão APIs para orquestrar ferramentas: exposure (direct, model-only, codemode, deferred ou hidden), namespace, annotations, outputSchema com resultados structuredContent, isError, prepareLoadout() e ctx.executeTool() para chamadas de ferramentas aninhadas, que emitem eventos com parentToolCallId e são registrados como nestedCalls limitado no resultado da ferramenta de chamada. Consulte Exposição da ferramenta.
  • Adicionado um aviso quando uma extensão que registra a mesma ferramenta, comando ou sinalizador substitui uma extensão integrada (#10174 por @cristinaponcela).
  • Adicionados modelos virtuais experimentais: extensões os registram no pi.registerVirtualModel() e escolhem um modelo físico e nível de pensamento para cada solicitação. O rodapé mostra o modelo roteado, /session lista o custo por modelo físico e examples/extensions/jev-router.ts roteia com o classificador Jev. Consulte Modelos Virtuais.
  • Adicionado login com ChatGPT ao provedor OpenAI em /login, que usa uma assinatura ChatGPT com o OpenAI API. Pi armazena um deviceId estável nas configurações globais para este login e o omite dos relatórios de bugs.
  • Adicionado o tema system, agora o padrão, que deriva as cores do pi do primeiro plano, plano de fundo e paleta ANSI relatados do terminal e os reconstrói quando o terminal alterna entre claro e escuro. Consulte Use as cores do seu terminal.
  • Adicionadas cores #rgb, oklch() e okhsl() e um campo appearance opcional para arquivos de tema e theme.style(), theme.colors e theme.appearance para extensões. Consulte Temas e TUI.
  • Adicionado um modelo classificador para cada modelo de chat llama.cpp, respondido a partir das probabilidades do rótulo do próximo token. Consulte Classificação.
  • Adicionados modelos de classificador Jev herdados no OpenRouter, Cloudflare Workers AI, Vercel AI Gateway e OpenCode Zen.
  • Adicionada a configuração fullscreenWheelScrollLines e a entrada /settings para rolagem da roda do mouse em tela cheia. O "auto" padrão acelera giros rápidos da roda fora dos terminais macOS locais (#9758).
  • Adicionada disposição por entrada para respostas RPC prompt, steer e follow_up bem-sucedidas, AgentSession.steer()/followUp() e RpcClient.prompt()/steer()/followUp(); RpcClient.prompt() também aceita streamingBehavior (#9098, #9803).
  • Adicionada geração de imagem ao ModelRuntime: generateImages() com autenticação resolvida em tempo de execução (credenciais armazenadas, OAuth, chaves API de tempo de execução, cabeçalhos models.json), além de getModelsOfType(), getModelOfType(), getAvailableOfType(), getAllModels() e getAllAvailable(). Os modelos de imagem OpenRouter estão listados no provedor openrouter e compartilham sua credencial; um ID upstream pode ter entradas separadas de bate-papo e imagem. Provedores models.json e registros de extensão sem lista de modelos mantêm geração de imagem integrada. As listas de modelos de extensão podem incluir entradas discriminadas de bate-papo, imagem e classificador com implementações de operação; quando fornecidos, eles substituem o catálogo do fornecedor em todas as operações. As leituras voltadas para bate-papo (getModels(), getAvailableSnapshot(), o seletor de modelo) permanecem inalteradas.
  • Adicionado suporte de classificador para ModelRuntime, incluindo classify(), acessadores de modelo de classificador, autenticação resolvida em tempo de execução e o modelo TypeSafe jev-latest integrado.
  • Adicionado types=chat,image,classifier às solicitações de catálogo de modelos pi.dev para que atualizações remotas se sobreponham a todos os tipos de modelos suportados; entradas de tipos de modelo desconhecidos são ignoradas.
  • Adicionado o evento de extensão provider_stream_event para observar eventos de provedor analisados ​​antes da normalização, com um visualizador de exemplo /debug-provider opcional (#9784, #9901 por @davidbrai).
  • Adicionado um botão mostrar/ocultar (H) nas exportações HTML para mensagens personalizadas marcadas como display: false. As mensagens permanecem ocultas por padrão e também podem ser reveladas na barra lateral (#8896, #10020 por @rwachtler).
  • Adicionado suporte herdado de Claude Sonnet 5.5 para Anthropic com pensamento adaptativo e uma janela de contexto de 1M.
  • Adicionada uma seção integrada em pi config para desativar as extensões integradas mcp, llama.cpp, codemode e tool-search globalmente ou por projeto, armazenadas como -builtin:<name> na configuração extensions. As extensões em linha SDK são compatíveis com builtin: true.
  • Adicionadas entradas +name e -name à configuração defaultTools para adicionar ou remover ferramentas sem repetir os padrões, por exemplo "defaultTools": ["+codemode"]. As entradas do projeto neste formulário se aplicam às configurações do usuário. Documentado como habilitar codemode sem MCP e como usar modelos classificadores como Jev a partir de scripts de modo de código.
  • Adicionado o uso de token e o custo das chamadas codemode models.classify() ao resultado da ferramenta codemode, para que sejam contabilizados no custo da sessão; o resultado do codemode mostra o custo de cada chamada.

Alterado

  • Mudou a compilação da visualização nativa TypeScript para TypeScript 7.0 com um destino ES2024 e substituiu tsx pela remoção de tipo integrada do Node para execução a partir da fonte (#9965).
  • Removida a seção [Themes] do banner de inicialização. Os temas personalizados permanecem disponíveis no /settings e os conflitos de tema ainda são relatados.
  • Alterado o cabeçalho de inicialização para mostrar o logotipo pi com a versão em vez do nome do aplicativo.
  • Alterados os temas integrados dark e light para as cores pi revisadas, escritas em OKHSL.
  • Alterada a detecção do terminal claro/escuro para usar primeiro a cor de fundo relatada, depois o relatório claro/escuro do terminal e depois COLORFGBG. A configuração inicial não mostra mais a aparência detectada.
  • Renomeado o provedor OpenAI Codex herdado para "OpenAI Codex (legado)"; O login com ChatGPT no provedor OpenAI o substitui.
  • Alterada a detecção de terminal herdado para tratar TERM=*-direct como truecolor.
  • Extensões e ferramentas integradas são denominadas builtin:<name> (por exemplo, builtin:mcp e builtin:read) em erros, diagnósticos, informações de origem RPC e relatórios de bugs, em vez de <inline:name> e <builtin:name>. Seus comandos de barra não carregam mais uma tag de preenchimento automático [t].
  • --no-extensions também desativa as extensões integradas, incluindo o provedor llama.cpp. Carregue um explicitamente com -e builtin:<name>, por exemplo pi -ne -e builtin:mcp.
  • Chamadas de ferramentas sem um renderizador de chamada personalizado, incluindo chamadas diretas de ferramentas MCP, agora mostram seus argumentos: como pares key=value na linha de título quando recolhidos e uma linha key: value por argumento quando expandidos. As chamadas MCP são intituladas server/tool e seus resultados são reduzidos para 5 linhas.
  • Os resultados estruturados bash e powershell, que os scripts de modo de código recebem, agora suportam até 1 MiB de saída em vez das 2.000 linhas ou 50 KB voltadas para o modelo, e adicionam truncated e full_output_path. A saída mais longa mantém seus primeiros e últimos 512 KiB. A saída vazia é "" em vez de (no output).

Corrigido

  • Corrigido o texto do X11 clipboard sendo identificado incorretamente como uma imagem quando o proprietário do clipboard aceita alvos de imagem não anunciados (#9786).
  • Impediu que pacotes git gerenciados instalassem automaticamente dependências de pares Pi e adicionou avisos para pacotes de extensão que listam módulos fornecidos pelo host em dependencies (#9863).
  • Corrigidas extensões git fixadas carregadas com -e continuando a usar o primeiro commit baixado após as alterações de referência (#9982).
  • Corrigido RpcClient ignorando o próximo ouvinte de evento quando um ouvinte cancela a assinatura ao manipular um evento, o que poderia fazer com que waitForIdle() expirasse após collectEvents() (#9990).
  • Correção de chamadas de arquivo completo read renderizadas como :1 quando os modelos enviam null para offset e limit omitidos (#9996).
  • Corrigidas novas sessões sendo perdidas quando pi sai antes da primeira resposta do assistente. O arquivo de sessão agora é criado quando a primeira mensagem do usuário é enviada (#10000).
  • Corrigidas predefinições de carregamento automático de llama.cpp descarregadas sobrescrevendo uma janela de contexto de tempo de execução em cache com o contexto de treinamento GGUF (#10077, #10158 por @cristinaponcela).
  • Corrigidos temas personalizados ignorando terminal.trueColor e outras substituições de capacidade de terminal e renderização com 256 cores (#9973, #10039 por @christianklotz).
  • Corrigida a colagem de arquivos copiados no Finder inserindo a imagem do ícone do arquivo em vez dos caminhos dos arquivos; os caminhos são citados no modo bash (#9999, #10136 por @christianklotz).
  • Corrigido o cabeçalho de inicialização, recursos carregados e avisos de bate-papo mantendo suas cores antigas após uma mudança de tema.
  • Corrigido o modelo padrão do Fireworks apontando para o modelo Kimi K2.6 removido; agora o padrão é Kimi K3.
  • Corrigido o modelo padrão do OpenCode Go apontando para o modelo Kimi K2.6 removido; agora o padrão é Kimi K3.
  • Corrigido o modelo padrão do Together apontando para o modelo Kimi K2.6 removido; agora o padrão é Kimi K3.
  • Uso reduzido da CPU durante o streaming em sessões longas e ao visualizar temas: o rodapé armazena em cache os totais de uso da sessão, os resultados do bash recolhidos armazenam em cache sua visualização e o sanitizeBinaryOutput() não divide mais a saída em matrizes por caractere.
  • Corrigida a utilização de ferramentas chamadas através do ctx.executeTool(), por exemplo a partir de scripts codemode, sendo descartadas do custo da sessão; agora é adicionado ao uso de resultados da ferramenta de chamada.
  • Corrigido o preenchimento automático herdado de /skill que aparecia vazio quando os nomes de habilidades carregadas não continham as letras em skill (#9944).
  • Corrigido o caminho herdado e o preenchimento automático @ que não funcionava após a abertura de wrappers como (, [, {, < ou um backtick.
  • Corrigido o alongamento de imagem herdado em terminais que usam o protocolo gráfico Kitty (#8938, #9957 por @rwachtler).
  • Correção do cursor do shell herdado que ficava oculto após a saída quando uma extensão fechava uma sobreposição durante o desligamento (#10026).
  • Corrigida a perda de entrada de teclado herdada após um mouse click em um submenu /settings fechá-lo.
  • Corrigidas gravações de cache Antrópico herdadas de 1 hora por meio do Vercel AI Gateway com preço de 5 minutos (#9210).
  • Correção do samplingParams de nível de modelo herdado sendo descartado por chamadas diretas stream()/complete() em APIs compatíveis com OpenAI (#9506).
  • Correção de solicitações herdadas do Mistral GLM que falhavam com "Esperado no máximo um ThinkChunk principal" após deltas de conteúdo vazios (#9674).
  • Corrigidas solicitações herdadas do modo OpenAI Fast com preços na taxa padrão (#10034).
  • Corrigidos modelos de raciocínio Mistral herdados que ignoravam o nível de pensamento solicitado (#9678).
  • Corrigido o pensamento herdado de OpenCode Zen e OpenCode Go qwen3.8-flash sendo reproduzido como texto simples em turnos posteriores (#10047).
  • Corrigidos fluxos de respostas OpenAI herdados de servidores que omitem output_index, como llama.cpp, executando chamadas de ferramentas confusas; esses fluxos agora terminam com um erro (#9974).
  • Foi corrigido o login herdado do navegador Anthropic e OpenAI Codex que aguardava indefinidamente após o provedor ser redirecionado com um erro de autorização e a falha de login do Anthropic quando sua porta de retorno de chamada estava em uso.

pi v0.99.0

New Features

  • Codemode and MCP — Connect MCP servers and let models run JavaScript that calls tools in parallel. See MCP Servers and Enable codemode.
  • System theme — Pi's colors now come from your terminal's own palette by default. See Use your terminal's colors.
  • Sign in with ChatGPT — Use a ChatGPT subscription with the OpenAI provider through /login openai. See Authenticate interactively.
  • Virtual models — Extensions can route each request to a different physical model. See Virtual Models.
  • Classifier models — Run Jev classifiers from codemode scripts, or use any llama.cpp model as a classifier. See How codemode works and Classification.

Added

  • Added codemode, tool search, and MCP support as built-in extensions. The codemode tool runs model-written JavaScript in a QuickJS sandbox that calls pi's tools; enable it with defaultTools or --tools and configure it with codemode.mode and codemode.inlineBudget. tool_search finds tools that are not declared to the model and declares them. MCP servers over stdio or streamable HTTP, with OAuth, come from mcp.json (global, or per project once trusted) or pi.registerMcpServer() and are managed with /mcp and pi mcp add|remove|list|login|logout. See MCP Servers and Enable codemode (#10040).
  • Added extension tool APIs for orchestrating tools: exposure (direct, model-only, codemode, deferred, or hidden), namespace, annotations, outputSchema with structuredContent, isError results, prepareLoadout(), and ctx.executeTool() for nested tool calls, which emit events with parentToolCallId and are recorded as bounded nestedCalls on the calling tool's result. See Tool exposure.
  • Added a warning when an extension that registers the same tool, command, or flag replaces a built-in extension (#10174 by @cristinaponcela).
  • Added experimental virtual models: extensions register them with pi.registerVirtualModel() and pick a physical model and thinking level for each request. The footer shows the routed model, /session lists cost per physical model, and examples/extensions/jev-router.ts routes with the Jev classifier. See Virtual Models.
  • Added Sign in with ChatGPT to the OpenAI provider in /login, which uses a ChatGPT subscription with the OpenAI API. Pi stores a stable deviceId in the global settings for this login and omits it from bug reports.
  • Added the system theme, now the default, which derives pi's colors from the terminal's reported foreground, background, and ANSI palette and rebuilds them when the terminal switches between light and dark. See Use your terminal's colors.
  • Added #rgb, oklch(), and okhsl() colors and an optional appearance field to theme files, and theme.style(), theme.colors, and theme.appearance for extensions. See Themes and TUI.
  • Added a classifier model for every llama.cpp chat model, answered from next-token label probabilities. See Classification.
  • Added inherited Jev classifier models on OpenRouter, Cloudflare Workers AI, Vercel AI Gateway, and OpenCode Zen.
  • Added the fullscreenWheelScrollLines setting and /settings entry for fullscreen mouse-wheel scrolling. The default "auto" accelerates fast wheel spins outside local macOS terminals (#9758).
  • Added per-input disposition to successful RPC prompt, steer, and follow_up responses, AgentSession.steer()/followUp(), and RpcClient.prompt()/steer()/followUp(); RpcClient.prompt() also accepts streamingBehavior (#9098, #9803).
  • Added image generation to ModelRuntime: generateImages() with runtime-resolved auth (stored credentials, OAuth, runtime API keys, models.json headers), plus getModelsOfType(), getModelOfType(), getAvailableOfType(), getAllModels(), and getAllAvailable(). OpenRouter image models are listed under the openrouter provider and share its credential; an upstream ID can have separate chat and image entries. models.json providers and extension registrations without a model list keep built-in image generation. Extension model lists can include discriminated chat, image, and classifier entries with operation implementations; when supplied, they replace the provider catalog across every operation. Chat-facing reads (getModels(), getAvailableSnapshot(), the model picker) are unchanged.
  • Added classifier support to ModelRuntime, including classify(), classifier model accessors, runtime-resolved authentication, and the built-in TypeSafe jev-latest model.
  • Added types=chat,image,classifier to pi.dev model catalog requests so remote refreshes overlay every supported model type; entries of unknown model types are ignored.
  • Added the provider_stream_event extension event for observing parsed provider events before normalization, with an opt-in /debug-provider example viewer (#9784, #9901 by @davidbrai).
  • Added a show/hide toggle (H) in HTML exports for custom messages marked display: false. Messages remain hidden by default and can also be revealed from the sidebar (#8896, #10020 by @rwachtler).
  • Added inherited Claude Sonnet 5.5 support for Anthropic with adaptive thinking and a 1M context window.
  • Added a Built-in section in pi config to disable the built-in mcp, llama.cpp, codemode, and tool-search extensions globally or per project, stored as -builtin:<name> in the extensions setting. SDK inline extensions opt in with builtin: true.
  • Added +name and -name entries to the defaultTools setting to add or remove tools without repeating the defaults, for example "defaultTools": ["+codemode"]. Project entries of this form apply on top of the user setting. Documented how to enable codemode without MCP and how to use classifier models such as Jev from codemode scripts.
  • Added the token usage and cost of codemode models.classify() calls to the codemode tool result, so they count toward the session cost; the codemode result shows each call's cost.

Changed

  • Switched the build from the TypeScript native preview to TypeScript 7.0 with an ES2024 target, and replaced tsx with Node's built-in type stripping for running from source (#9965).
  • Removed the [Themes] section from the startup banner. Custom themes remain available in /settings, and theme conflicts are still reported.
  • Changed the startup header to show the pi logo with the version instead of the app name.
  • Changed the built-in dark and light themes to the revised pi colors, written in OKHSL.
  • Changed light/dark terminal detection to use the reported background color first, then the terminal's light/dark report, then COLORFGBG. The first-time setup no longer shows the detected appearance.
  • Renamed the inherited OpenAI Codex provider to "OpenAI Codex (legacy)"; Sign in with ChatGPT on the OpenAI provider supersedes it.
  • Changed inherited terminal detection to treat TERM=*-direct as truecolor.
  • Built-in extensions and tools are named builtin:<name> (for example builtin:mcp and builtin:read) in errors, diagnostics, RPC source info, and bug reports, instead of <inline:name> and <builtin:name>. Their slash commands no longer carry a [t] autocomplete tag.
  • --no-extensions also disables the built-in extensions, including the llama.cpp provider. Load one explicitly with -e builtin:<name>, for example pi -ne -e builtin:mcp.
  • Tool calls without a custom call renderer, including direct MCP tool calls, now show their arguments: as key=value pairs on the title line when collapsed and one key: value line per argument when expanded. MCP calls are titled server/tool and their results collapse to 5 lines.
  • bash and powershell structured results, which codemode scripts receive, now hold up to 1 MiB of output instead of the model-facing 2000 lines or 50KB, and add truncated and full_output_path. Longer output keeps its first and last 512 KiB. Empty output is "" instead of (no output).

Fixed

  • Fixed X11 clipboard text being misidentified as an image when the clipboard owner accepts unadvertised image targets (#9786).
  • Prevented managed git packages from automatically installing Pi peer dependencies and added warnings for extension packages that list host-provided modules in dependencies (#9863).
  • Fixed pinned git extensions loaded with -e continuing to use the first downloaded commit after the ref changes (#9982).
  • Fixed RpcClient skipping the next event listener when a listener unsubscribes while handling an event, which could make waitForIdle() time out after collectEvents() (#9990).
  • Fixed full-file read calls rendering as :1 when models send null for omitted offset and limit (#9996).
  • Fixed new sessions being lost when pi exits before the first assistant response. The session file is now created when the first user message is sent (#10000).
  • Fixed unloaded llama.cpp autoload presets overwriting a cached runtime context window with the GGUF training context (#10077, #10158 by @cristinaponcela).
  • Fixed custom themes ignoring terminal.trueColor and other terminal capability overrides and rendering with 256 colors (#9973, #10039 by @christianklotz).
  • Fixed pasting files copied in Finder inserting the file icon image instead of the file paths; paths are quoted in bash mode (#9999, #10136 by @christianklotz).
  • Fixed the startup header, loaded resources, and chat notices keeping their old colors after a theme change.
  • Fixed the Fireworks default model pointing at the removed Kimi K2.6 model; it now defaults to Kimi K3.
  • Fixed the OpenCode Go default model pointing at the removed Kimi K2.6 model; it now defaults to Kimi K3.
  • Fixed the Together default model pointing at the removed Kimi K2.6 model; it now defaults to Kimi K3.
  • Reduced CPU use while streaming in long sessions and when previewing themes: the footer caches session usage totals, collapsed bash results cache their preview, and sanitizeBinaryOutput() no longer splits output into per-character arrays.
  • Fixed the usage of tools called through ctx.executeTool(), for example from codemode scripts, being dropped from the session cost; it is now added to the calling tool's result usage.
  • Fixed inherited /skill autocomplete appearing empty when loaded skill names did not contain the letters in skill (#9944).
  • Fixed inherited path and @ autocomplete not working after opening wrappers such as (, [, {, <, or a backtick.
  • Fixed inherited image stretching in terminals that use the Kitty graphics protocol (#8938, #9957 by @rwachtler).
  • Fixed inherited shell cursor staying hidden after exit when an extension closed an overlay during shutdown (#10026).
  • Fixed inherited keyboard input being lost after a mouse click in a /settings submenu closed it.
  • Fixed inherited 1-hour Anthropic cache writes through Vercel AI Gateway being priced at the 5-minute rate (#9210).
  • Fixed inherited model-level samplingParams being dropped by direct stream()/complete() calls on OpenAI-compatible APIs (#9506).
  • Fixed inherited Mistral GLM requests failing with "Expected at most one leading ThinkChunk" after empty content deltas (#9674).
  • Fixed inherited OpenAI Fast mode requests being priced at the standard rate (#10034).
  • Fixed inherited Mistral reasoning models ignoring the requested thinking level (#9678).
  • Fixed inherited OpenCode Zen and OpenCode Go qwen3.8-flash thinking being replayed as plain text on later turns (#10047).
  • Fixed inherited OpenAI Responses streams from servers that omit output_index, such as llama.cpp, running mixed-up tool calls; such streams now end with an error (#9974).
  • Fixed inherited Anthropic and OpenAI Codex browser sign-in waiting indefinitely after the provider redirected with an authorization error, and Anthropic sign-in failing when its callback port is in use.
  • Fixed inherited GitHub Copilot Claude Opus 5.5 offering unsupported thinking levels when upstream model metadata is incomplete.
