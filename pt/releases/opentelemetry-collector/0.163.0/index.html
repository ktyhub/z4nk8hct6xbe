Usuário final Changelog

💡 Melhorias 💡

  • cmd/builder: Adicione dist.resource.detection.detectors à configuração do construtor, permitindo que as distribuições optem por um conjunto menor de detectores de processador de detecção de recursos por meio de tags go build geradas. (#16075)
  • cmd/mdatagen: gera padrões de fila do exportador/remetente de lote a partir de um campo sending_queue opcional em metadata.yaml. Consulte a RFC de migração em lote. (#15963) Declarar sending_queue é opcional; um exportador que o omita não será afetado até que opte explicitamente por um de cada vez durante a Fase 2 da migração. Defina MDATAGEN_SENDING_QUEUE_OPT_OUT=true para gerar o padrão padrão para cada exportador não declarado durante a auditoria de um repositório inteiro.
  • pkg/pprofile: Implementar metadados de versão de desenvolvimento de Profiles no receptor e exportadores OTLP. (#16147, #16009) O receptor rejeita versões malformadas, repetidas ou não suportadas antes da decodificação. Os exportadores OTLP enviam a versão associada ao esquema de Perfis compilado. A versão não é configurável e clients existentes sem identificação de metadados a versão inicial de desenvolvimento.

🧰 Correções de bugs 🧰

  • cmd/mdatagen: Substitua a varredura O(n) no recordDataPoint gerado por uma pesquisa de hash O(1), corrigindo um custo O(n²) por raspagem quando muitos pontos de dados chegam a um recurso. (#15912)
  • cmd/mdatagen: Quando ambas as portas de migração estão habilitadas, apenas a métrica mais recente com seus atributos v1 é emitida (os atributos legados não são mais incluídos). (#15979)
  • pkg/exporterhelper: Corrige o envio de deadlocks na fila quando ofertas bloqueadas são canceladas com block_on_overflow habilitado. (#15700)
  • pkg/exporterhelper: Elimine apenas o perfil superdimensionado ao dividir um lote de perfis, em vez de descartar todos os perfis enfileirados atrás dele (#16087) Mesma correção que
  • pkg/exporterhelper: Elimine apenas o intervalo superdimensionado ao dividir um lote de rastreamentos, em vez de descartar todos os intervalos enfileirados atrás dele (#16087) Mesma correção que
  • pkg/pprofile: Use o dicionário de perfis para sequências de atributos de recurso e escopo enviadas por OTLP/gRPC. (#15861) Os perfis OTLP/gRPC client agora armazenam strings de atributos antes da transmissão, correspondendo ao caminho OTLP/HTTP. O servidor resolve as referências antes de expor o pdata aos consumidores.
  • pkg/xpdata: Corrige xhash produzindo o mesmo hash para mapas diferentes por meio de prefixação de comprimento de chaves, strings e bytes. (#16048) Todos os valores de hash produzidos por xhash mudam.

opentelemetry-collector v0.163.0

Images and binaries here: https://github.com/open-telemetry/opentelemetry-collector-releases/releases/tag/v0.163.0

End User Changelog

💡 Enhancements 💡

  • cmd/builder: Add dist.resource.detection.detectors to the builder config, letting distributions opt into a smaller set of resourcedetectionprocessor detectors via generated go build tags. (#16075)
  • cmd/mdatagen: Generate exporter queue/batch sender defaults from an opt-in sending_queue field in metadata.yaml. See the batching migration RFC. (#15963) Declaring sending_queue is opt-in; an exporter that omits it is unaffected until it explicitly opts in one at a time during Phase 2 of the migration. Set MDATAGEN_SENDING_QUEUE_OPT_OUT=true to generate the standard default for every undeclared exporter while auditing a whole repository.
  • pkg/pprofile: Implement Profiles development-version metadata in the OTLP receiver and exporters. (#16147, #16009) The receiver rejects malformed, repeated, or unsupported versions before decoding. OTLP exporters send the version associated with their compiled-in Profiles schema. The version is not configurable, and existing clients without metadata identify the initial development version.

🧰 Bug fixes 🧰

  • cmd/mdatagen: Replace the O(n) scan in generated recordDataPoint with an O(1) hash lookup, fixing an O(n²) cost per scrape when many data points land on one resource. (#15912)

  • cmd/mdatagen: When both migration gates are enabled, only the latest metric with its v1 attributes is emitted (legacy attributes are no longer included). (#15979)

  • pkg/exporterhelper: Fix sending queue deadlocks when blocked offers are cancelled with block_on_overflow enabled. (#15700)

  • pkg/exporterhelper: Drop only the oversized profile when splitting a profiles batch, instead of discarding every profile queued behind it (#16087) Same fix as

  • pkg/exporterhelper: Drop only the oversized span when splitting a traces batch, instead of discarding every span queued behind it (#16087) Same fix as

  • pkg/pprofile: Use the profiles dictionary for resource and scope attribute strings sent over OTLP/gRPC. (#15861) The OTLP/gRPC profiles client now interns attribute strings before transmission, matching the OTLP/HTTP path. The server resolves the references before exposing pdata to consumers.

  • pkg/xpdata: Fix xhash producing the same hash for different maps by length-prefixing keys, strings and bytes. (#16048) All hash values produced by xhash change.
