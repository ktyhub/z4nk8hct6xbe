Usuário final Changelog

🛑 Mudanças radicais 🛑

  • pkg/confighttp: Remova os campos obsoletos IdleConnTimeout, MaxIdleConns, MaxIdleConnsPerHost, DisableKeepAlives. (#15973)

🚀 Novos componentes 🚀

  • pkg/xreceiverhelper: Adicione xreceiverhelper com um ObsReport que relata métricas de amostra de perfil por tipo de amostra. (#16251) ObsReport.EndProfilesOpBySampleType registra o Métricas otelcol_receiver_{accepted,refused,failed}_profile_samples com um adicional Atributo sample_type, formatado como "type:unit", já que uma única carga útil pode conter vários perfis com diferentes tipos de amostra. Use ProfileSampleCountsByType para calcular as contagens de amostras antes os perfis são passados para o próximo consumidor, pois os dados podem sofrer mutação no downstream. O receptor OTLP agora usa EndProfilesOpBySampleType.

💡 Melhorias 💡

  • pkg/configmiddleware: permite substituir o discador usado por confighttp.ToClient e configgrpc.ToClient (#16019)
  • pkg/featuregate: permite sublinhados em IDs de portas de recurso. (#16243)
  • pkg/pdata: Melhore o desempenho das funções pcommon.Map Get, Range e All. (#16282, #16321)
  • pkg/pdata: Reduz o número de alocações ao atualizar uma primitiva oneof (#16226)
  • pkg/service: O serviço agora suporta a configuração de detectores de recursos adicionais para telemetria interna conforme a atualização para otelconf v0.26.0. (#15869)
  • pkg/service: Avisa na inicialização quando um pipeline combina o processador em lote com o lote exporterhelper. (#15965) A detecção não cruza conectores nem inspeciona wrappers do exportador que ocultam a capacidade de processamento em lote do exporterhelper.
  • pkg/xprocessorhelper: Instrumento xprocessorhelper.NewProfiles com otelcol_processor_incoming_items, otelcol_processor_outgoing_items e otelcol_processor_internal_duration, consistente com os demais construtores de sinal. (#15523)
  • processor/memory_limiter: Adicionada seção de configuração do garbage_collector para permitir desabilitar a coleta forçada de lixo via campo enabled. (#15081)
  • processor/queue_batch: promova o processador queue_batch para beta para rastreamentos, métricas e logs e para alfa para perfis. (#12022)
  • processor/queue_batch: Relatar métricas de fila e lote como métricas do processador (#14038)

🧰 Correções de bugs 🧰

  • cmd/mdatagen: Corrige o pânico em Attribute.TestValue() e Attribute.TestValueTwo() ao manipular atributos de elemento único ou enum vazios. (#15644)
  • cmd/mdatagen: corrige falha nos testes de métricas geradas quando as portas de recurso through_gates de uma migração de métrica são promovidas após o alfa. (#16249) Os testes gerados agora definem explicitamente as portas do recurso de migração para cada caso de teste e restauram seu estado anterior na limpeza, em vez de assumir que os portões estão desabilitados por padrão. Quando o estágio de um portão proíbe o estado que um caso precisa, como desabilitar um portão estável, o construtor de métricas test ignora apenas sua contagem dependente de porta e asserções de aviso, e a métrica versionada por combinação os subtestes para essa combinação são ignorados.
  • cmd/mdatagen: Gere documentos de configuração README para definições exported_configs. (#16164) Definições de objetos e aliases de tipo escalar em exported_configs agora são renderizados no README após a tabela config:. Pacotes que declaram apenas exported_configs agora podem obter documentos gerados uma vez que seu README contenha os marcadores de configuração. Componentes que declaram apenas exported_configs não recebem mais uma tabela de configuração vazia.
  • cmd/schemagen: Lidar com erros de arquivo não encontrado ao carregar esquemas (#15925)
  • pkg/configgrpc: Vincula a janela do decodificador zstd pelo tamanho máximo de mensagem de recebimento configurado em vez do padrão da biblioteca. (#16280) Um quadro zstd declara sua janela no cabeçalho e o decodificador a aloca antes de produzir qualquer resultado, portanto, uma pequena mensagem elaborada pode gerar um grande alocação independentemente de max_recv_msg_size_mib. O decodificador também retornado ao seu pool assim que gRPC termina com uma mensagem.
  • pkg/confighttp: Vincula a janela do decodificador zstd por max_request_body_size em vez do padrão da biblioteca. (#16280) Um quadro zstd declara sua janela no cabeçalho e o decodificador a aloca antes de produzir qualquer saída, então um pequeno corpo trabalhado poderia conduzir um grande alocação independentemente do tamanho do corpo da solicitação configurado.
  • pkg/confighttp: Aceita codificação de conteúdo: identidade como equivalente a nenhuma codificação. (#15122)
  • pkg/exporterhelper: Corrige um pânico Cannot unref freed data quando uma fila de envio persistente encaminha solicitações para outro pipeline (#15256)
  • pkg/exporterhelper: Com wait_for_result, cancelar uma requisição que a fila de envio já aceita não retorna mais antecipadamente (#16255) Anteriormente, um contexto cancelado fazia com que ele retornasse context.Canceled enquanto a solicitação ainda estava entregue, para que os chamadores pudessem relatar uma falha nos dados que foram enviados. O cancelamento ainda leva efeito enquanto nada tiver sido feito com a solicitação.
  • pkg/pdata: Adicione limite de profundidade de recursão (100) à desempacotamento proto de AnyValue, ArrayValue, KeyValueList e KeyValue para evitar o estouro de pilha de cargas úteis profundamente aninhadas criadas com códigos maliciosos. (#15301)
  • pkg/service: Ignora nós gráficos que não foram construídos durante o desligamento para evitar pânico quando uma recarga parcial do receptor falha ao construir um receptor. (#16261)

opentelemetry-collector v0.165.0

Images and binaries here: https://github.com/open-telemetry/opentelemetry-collector-releases/releases/tag/v0.165.0

End User Changelog

🛑 Breaking changes 🛑

  • pkg/confighttp: Remove deprecated fields IdleConnTimeout, MaxIdleConns, MaxIdleConnsPerHost, DisableKeepAlives. (#15973)

🚀 New components 🚀

  • pkg/xreceiverhelper: Add xreceiverhelper with an ObsReport that reports profile sample metrics per sample type. (#16251) ObsReport.EndProfilesOpBySampleType records the otelcol_receiver_{accepted,refused,failed}_profile_samples metrics with an additional sample_type attribute, formatted as "type:unit", as a single payload can hold multiple profiles with different sample types. Use ProfileSampleCountsByType to compute the sample counts before the profiles are passed to the next consumer, as the data may be mutated downstream. The OTLP receiver now uses EndProfilesOpBySampleType.

💡 Enhancements 💡

  • pkg/configmiddleware: allow to override the dialer used by confighttp.ToClient and configgrpc.ToClient (#16019)
  • pkg/featuregate: Allow underscores in feature gate IDs. (#16243)
  • pkg/pdata: Improve performance of pcommon.Map Get, Range, and All functions. (#16282, #16321)
  • pkg/pdata: Reduce number of allocations when updating an oneof primitive (#16226)
  • pkg/service: Service now supports configuring additional resource detectors for internal telemetry as per the update to otelconf v0.26.0. (#15869)
  • pkg/service: Warn at startup when a pipeline combines the batch processor with exporterhelper batching. (#15965) Detection does not cross connectors or inspect exporter wrappers that hide exporterhelper's batching capability.
  • pkg/xprocessorhelper: Instrument xprocessorhelper.NewProfiles with otelcol_processor_incoming_items, otelcol_processor_outgoing_items, and otelcol_processor_internal_duration, consistent with the other signal constructors. (#15523)
  • processor/memory_limiter: Add garbage_collector config section to allow disabling forced garbage collection via enabled field. (#15081)
  • processor/queue_batch: Promote the queue_batch processor to beta for traces, metrics, and logs, and to alpha for profiles. (#12022)
  • processor/queue_batch: Report queue and batch metrics as processor metrics (#14038)

🧰 Bug fixes 🧰

  • cmd/mdatagen: Fix panic in Attribute.TestValue() and Attribute.TestValueTwo() when handling single-element or empty enum attributes. (#15644)

  • cmd/mdatagen: Fix generated metrics tests failing when a metric migration's through_gates feature gates are promoted past alpha. (#16249) The generated tests now explicitly set the migration feature gates for each test case and restore their previous state on cleanup, instead of assuming the gates are disabled by default. When a gate's stage forbids the state a case needs, such as disabling a stable gate, the metrics-builder test skips only its gate-dependent count and warning assertions, and the per-combination versioned-metric sub-tests for that combination are skipped.

  • cmd/mdatagen: Generate README configuration docs for exported_configs definitions. (#16164) Object definitions and scalar type aliases under exported_configs are now rendered in the README after the config: table. Packages that only declare exported_configs can now get generated docs once their README contains the config markers. Components that only declare exported_configs no longer get an empty configuration table.

  • cmd/schemagen: Handle file-not-found errors when loading schemas (#15925)

  • pkg/configgrpc: Bound the zstd decoder window by the configured maximum receive message size instead of the library default. (#16280) A zstd frame declares its window in the header and the decoder allocated it before producing any output, so a small crafted message could drive a large allocation regardless of max_recv_msg_size_mib. The decoder is also returned to its pool as soon as gRPC is done with a message.

  • pkg/confighttp: Bound the zstd decoder window by max_request_body_size instead of the library default. (#16280) A zstd frame declares its window in the header and the decoder allocated it before producing any output, so a small crafted body could drive a large allocation regardless of the configured request body size.

  • pkg/confighttp: Accept Content-Encoding: identity as equivalent to no encoding. (#15122)

  • pkg/exporterhelper: Fix a Cannot unref freed data panic when a persistent sending queue forwards requests into another pipeline (#15256)

  • pkg/exporterhelper: With wait_for_result, canceling a request that the sending queue already accepted no longer returns early (#16255) Previously a canceled context made it return context.Canceled while the request was still delivered, so callers could report a failure for data that had been sent. Canceling still takes effect while nothing has been done with the request.

  • pkg/pdata: Add recursion depth limit (100) to proto unmarshalling of AnyValue, ArrayValue, KeyValueList, and KeyValue to prevent stack overflow from maliciously crafted deeply nested payloads. (#15301)

  • pkg/service: Skip graph nodes that have not been built during shutdown to prevent a panic when a partial receiver reload fails to build a receiver. (#16261)

  • pkg/componentstatus: Deprecate componentstatus.Watcher in favour of extensioncapabilities.ComponentStatusWatcher (#16304)

🚀 New components 🚀

  • pkg/xreceiverhelper: Add xreceiverhelper with an ObsReport that reports profile sample metrics per sample type.
