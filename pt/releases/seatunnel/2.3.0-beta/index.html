[Motor SeaTunnel]

[Recursos e melhorias]

[Gerenciador de cluster]

  • Suporte para execução do SeaTunnel Engine de forma independente.
  • Suporte para executar cluster do SeaTunnel Engine.
  • Não confie em serviços de terceiros (zookeeper etc.) para realizar a arquitetura master-worker.
  • Cluster autônomo (não centralizado).
  • Descoberta automática de membros do cluster.

[Núcleo]

  • Suporte para envio de trabalho ao SeaTunnel Engine em modo local.
  • Suporte para envio de Job para SeaTunnel Engine em modo cluster.
  • Suporte para trabalho em lote.
  • Trabalho de fluxo de suporte.
  • Suporta integração de fluxo em lote, e o recurso de integração de fluxo em lote de todos os conectores SeaTunnel V2 pode ser garantido no SeaTunnel Engine.
  • Suporte ao algoritmo de snapshot distribuído, algoritmo Chandy Ramport e Two-phase Commit. Semântica Exatamente Uma Vez baseada nessas implementações.
  • Suporte ao agendamento de trabalhos de granularidade de pipeline, garantindo que o trabalho possa ser iniciado com recursos limitados.
  • Suporte à restauração de trabalhos de granularidade de pipeline.
  • Compartilhamento de threads entre tarefas para obter sincronização em tempo real de um grande número de pequenos conjuntos de dados.

[SeaTunnel Engine]

[Feature & Improve]

[Cluster Manager]

  • Support Run SeaTunnel Engine in stand-alone.
  • Support Run SeaTunnel Engine cluster.
  • Do not rely on third-party services(zookeeper etc) to realize the master-worker architecture.
  • Autonomous cluster (non centralized).
  • Automatic discovery of cluster members.

[Core]

  • Support submit Job to SeaTunnel Engine in local mode.
  • Support submit Job to SeaTunnel Engine in cluster mode.
  • Support Batch Job.
  • Support Stream Job.
  • Supports batch stream integration, and the batch stream integration feature of all SeaTunnel V2 Connectors can be guaranteed in SeaTunnel Engine.
  • Support Distributed Snapshot algorithm Chandy Ramport algorithm and Two-phase Commit. Exactly-Once semantics based on these implementations.
  • Support pipeline granularity job scheduling, Ensure that the job can be started under limited resources.
  • Support pipeline granularity job restore.
  • Sharing threads between tasks to achieve real-time synchronization of a large number of small datasets.
