Cherry Studio 2.2.2 - Aprovações de agentes, correções de provedores e polimento

✨ Novos recursos

  • [Uso do computador] O uso do computador agora está ativado por padrão e pergunta antes de acessar cada aplicativo. Escolha Sempre, Aprovar para sessão ou Rejeitar e gerencie as aprovações salvas em Configurações. O modo Ignorar ignora esses prompts sem salvar as permissões. (ação necessária: desative-o em Configurações se não desejar).
  • [Habilidades] Adicionada uma opção "Exportar habilidades para agentes externos" em Configurações → Habilidades. Ele está desativado por padrão para novas instalações, portanto o diretório de habilidades compartilhadas não é mais criado sem uma aceitação explícita; as instalações já exportadas o mantêm ativado e desligá-lo remove apenas os links criados pelo Cherry Studio.
  • [Agente] Os agentes nos modelos DeepSeek agora mostram uma pequena linha de intenção acima de cada chamada de ferramenta. As sessões do agente mantêm as etapas da ferramenta expandidas por padrão e incluem chamadas repetidas do mesmo tipo.
  • [App] Adicionado suporte ao idioma polonês.

💄 Melhorias

  • [MCP] QVeris agora oferece suporte ao login do navegador OAuth como sua credencial primária, com QVERIS_API_KEY como um substituto opcional, para que possa ser habilitado sem uma chave API.
  • [Arquivos] Os tamanhos dos arquivos usam um formato consistente em todo o aplicativo.
  • [Agente] A sessão aprimorada detalha a tipografia, o alinhamento dos ícones, o espaçamento e o espaço reservado sem espaço de trabalho.

🐛 Correções de bugs

  • [Modelos] As solicitações da ferramenta CherryIN Claude Sonnet 4.5 não falham mais com um erro de validação de parâmetro Bedrock.
  • [Modelos] Solicitações de Claude Opus 5.5 no AWS Bedrock agora usam raciocínio adaptativo.
  • [Modelos] SiliconFlow usa entrada manual de chave API; o login obsoleto do OAuth foi removido (ação necessária se você fez login com o OAuth).
  • [Bate-papo] Erros "A entrada excede o limite de contexto" agora são reconhecidos como rejeições de comprimento de contexto, portanto, a orientação de recuperação existente aparece.
  • [Bate-papo] Links de arquivo Markdown local agora abrem em superfícies de bate-papo que não fornecem uma visualização do artefato.
  • [Bate-papo] Corrigida a perda da ativação da primeira barra de ferramentas do compositor durante o carregamento, e a navegação na guia interna não bloqueia mais a interação.
  • [Agente] Corrigido o cartão AskUserQuestion ausente quando uma solicitação de aprovação transmitida chegava antes da origem da ferramenta.
  • [Agente] Corrigido o botão Ignorar que ficava preso no AskUserQuestion final quando todas as perguntas eram ignoradas.
  • [Agente] A expansão de uma chamada da ferramenta de leitura durável do Pi não mostra mais detalhes do arquivo em branco.
  • [Agente] Os agentes duráveis ​​Pi agora carregam automaticamente arquivos de instruções do espaço de trabalho, como AGENTS.md.
  • [Agente] As ferramentas MCP comuns podem ser descobertas por meio da pesquisa de ferramentas no tempo de execução do Pi Durável, em vez de retornar "Nenhuma ferramenta correspondente encontrada".
  • [Agente] A orientação da ferramenta do agente agora trata as ferramentas adiadas como disponíveis por meio de descoberta e usa os nomes exatos das ferramentas da sessão, para que os agentes parem de relatar as ferramentas disponíveis como ausentes.
  • [Agente] Quando o raciocínio esgota o orçamento de resposta, agora você obtém orientação precisa sobre limite de token de saída e a capacidade Flash do DeepSeek V4.1 é resolvida corretamente para IDs de modelo versionados.
  • [API Gateway] Os resultados do Claude Code MCP ToolSearch não são mais descartados para modelos de terceiros.
  • O seletor de modelos Unified Gateway do [Código] Code Mate agora lista os modelos Cherry Cloud que estão disponíveis apenas para agentes.
  • [Doctor] Doctor não relata mais a falta de uma chave API ou uma lista de modelos indisponíveis para CherryAI e Cherry Cloud; para Cherry Cloud agora informa quando você precisa fazer login.
  • [IU] Os favicons do site permanecem visíveis no modo escuro com uma placa traseira cinza claro suave, mantendo suas cores originais.
  • [Atualizador] Release notes na caixa de diálogo de atualização agora seguem o idioma resolvido do aplicativo, inclusive quando o aplicativo segue o idioma do sistema.
</detalhes>

Cherry Studio 2.2.2 - Agent Approvals, Provider Fixes, and Polish

✨ New Features

  • [Computer Use] Computer Use is now on by default and asks before accessing each app. Choose Always, Approve for session, or Reject, and manage saved approvals in Settings. Bypass mode skips these prompts without saving permissions. (action required: turn it off in Settings if you do not want it.)
  • [Skills] Added an "Export skills to external agents" switch in Settings → Skills. It is off by default for new installations, so the shared skills directory is no longer created without an explicit opt-in; installations that already exported keep it on, and turning it off removes only the links Cherry Studio created.
  • [Agent] Agents on DeepSeek models now show a short intent line above each tool call. Agent sessions keep tool steps expanded by default and fold repeated calls of the same kind.
  • [App] Added Polish language support.

💄 Improvements

  • [MCP] QVeris now supports OAuth browser sign-in as its primary credential, with QVERIS_API_KEY as an optional fallback, so it can be enabled without an API key.
  • [Files] File sizes use one consistent format across the app.
  • [Agent] Polished session details typography, icon alignment, spacing, and the no-workspace placeholder.

🐛 Bug Fixes

  • [Models] CherryIN Claude Sonnet 4.5 tool requests no longer fail with a Bedrock parameter validation error.
  • [Models] Claude Opus 5.5 requests on AWS Bedrock now use adaptive reasoning.
  • [Models] SiliconFlow uses manual API key entry; the obsolete OAuth login was removed (action required if you signed in with OAuth).
  • [Chat] "Input exceeds the context limit" errors are now recognized as context-length rejections, so the existing recovery guidance appears.
  • [Chat] Local Markdown file links now open from chat surfaces that do not provide an artifact preview.
  • [Chat] Fixed the first composer toolbar activation being lost while loading, and internal tab navigation no longer blocks interaction.
  • [Agent] Fixed the missing AskUserQuestion card when a streamed approval request arrives before its tool source.
  • [Agent] Fixed the Skip button getting stuck on the final AskUserQuestion when all questions are skipped.
  • [Agent] Expanding a Pi Durable read tool call no longer shows blank file details.
  • [Agent] Pi Durable agents now automatically load workspace instruction files such as AGENTS.md.
  • [Agent] Ordinary MCP tools are discoverable through tool search in the Pi Durable runtime instead of returning "No matching tools found."
  • [Agent] Agent tool guidance now treats deferred tools as available through discovery and uses the exact tool names from the session, so agents stop reporting available tools as missing.
  • [Agent] When reasoning exhausts the response budget, you now get accurate output-token-limit guidance, and DeepSeek V4.1 Flash capacity resolves correctly for versioned model IDs.
  • [API Gateway] Claude Code MCP ToolSearch results are no longer dropped for third-party models.
  • [Code] Code Mate's Unified Gateway model picker now lists Cherry Cloud models that are available only to agents.
  • [Doctor] Doctor no longer reports a missing API key or an unavailable model list for CherryAI and Cherry Cloud; for Cherry Cloud it now tells you when you need to sign in.
  • [UI] Website favicons stay visible in dark mode with a soft light-gray backplate while keeping their original colors.
  • [Updater] Release notes in the update dialog now follow the app's resolved language, including when the app follows the system language.
</details>
