oh-meu-pi v18.20.3

@oh-my-pi/pi-ai

Mudanças importantes

  • Removida a exportação pública isXdDevicePath de providers/cursor-pi-args. Leituras variadas de documentos xd:// agora usam o comportamento padrão do seletor de linha.

Corrigido

  • Correção do tratamento de limite de taxa para Mistral e outros provedores compatíveis com OpenAI, de modo que solicitações sem permissão disponível falhem imediatamente com um erro acionável sugerindo uma mudança de modelo ou plano.
  • Corrigidas solicitações do Anthropic OAuth para contas agrupadas do Claude para relatar informações precisas do dispositivo e da conta, inclusive após a rotação de credenciais durante uma solicitação.

@oh-my-pi/pi-catalog

Adicionado

  • Adicionados auxiliares de dimensionamento de imagem disponíveis publicamente para determinar as dimensões da imagem entregue pelo modelo e ajustar as imagens a uma borda longa especificada antes do mapeamento de coordenadas.

Corrigido

  • Corrigidas entradas de imagem sendo descartadas para DeepSeek V4 Flash, restaurando o suporte consistente de imagens multimodais.
  • Opções de esforço de raciocínio restrito para Mistral GLM 5.3, GLM 5.3 Flash e Mistral Large 4 para os níveis suportados por esses modelos.

@oh-my-pi/pi-coding-agent

Mudanças importantes

  • Renomeada a opção tab.clickAt() do navegador de clickCount para count, correspondendo a tab.click().
  • As coordenadas da captura de tela da janela de visualização do navegador agora usam as coordenadas da imagem exibida quando a captura de tela é dimensionada para o modelo; passe css: true (ou { x, y, css: true } para pontos de arrastar) para fornecer pixels CSS da janela de visualização explicitamente.
  • Adicionado mnemopi.recallRelevance opcional (off, auto ou on; padrão off) para filtrar a recuperação automática de memória para relevância da tarefa usando a função judge.
  • Adicionadas entradas com escopo de caminho para bash.patterns e bashInterceptor.patterns, resolvidas por diretório de trabalho. As sobreposições do projeto e --config agora acrescentam essas regras às regras globais em vez de substituí-las.
  • Adicionadas listas bash.allowedEnvVars e env por regra para permitir prefixos de variáveis ​​de ambiente nomeados explicitamente em regras allow correspondentes.
  • Os subagentes agora preservam a fixação do provedor @upstream em modelos herdados.
  • Adicionadas opções --no-judge, --no-spotlight e --offline para restringir serviços auxiliares ao provedor do modelo ativo ou desabilitar serviços entre provedores.
  • Adicionado frontmatter TTSR repeatMode por regra (once, after-gap ou always) para substituir a política de repetição global.
  • Os prompts de aprovação do bash composto agora mostram cada segmento de comando separadamente, distinguindo os segmentos permitidos daqueles que requerem aprovação.
  • Removido o agente seance, o comando /seance e o parâmetro sourceSession da ferramenta de tarefas.

Adicionado

  • Adicionada configuração mnemopi.embeddingQueryPrefix e mnemopi.embeddingInputType para modelos de incorporação assimétricos e ajustados por instrução, incluindo provedores que exigem um input_type.

Alterado

  • As capturas de tela do navegador são entregues ao modelo em pixels CSS até o tamanho não dimensionado suportado, tornando as coordenadas da captura de tela da janela de visualização diretamente utilizáveis com ações do navegador; a orientação de dimensionamento permanece para capturas de elementos e páginas inteiras dimensionadas.
  • Os navegadores waitForUrl, waitForResponse e requests({ filter }) agora suportam padrões glob * em strings de URL, enquanto outras strings mantêm a correspondência de substring.
  • O mecanismo do navegador WebKit agora instala e atualiza automaticamente para a versão estável mais recente do ABKit, com instalações versionadas que permitem atualizações sem esperar a saída dos hosts do navegador existentes.
  • Melhor capacidade de resposta e recuperação do navegador: páginas WebKit que não respondem falham rapidamente com erros acionáveis, a navegação pode recuperar páginas ocupadas e as operações do navegador fornecem diagnósticos mais claros para tempos limite, guias fechadas, ouvintes de eventos não suportados, rotas inválidas, dados de cookies e alterações na janela de visualização.
  • Pressionar Delete no final do campo de pesquisa Ctrl+R remove o prompt selecionado do histórico.
  • /copy agora funciona durante a visualização de um subagente e copia da transcrição desse subagente.
  • find agora retorna correspondências literais de palavras-chave não classificadas quando todas as solicitações de juiz falham.
  • take() e drop() agora rejeitam unidades inexistentes com um erro claro.
  • As mensagens de rejeição do edit agora sugerem a tag atual do arquivo e as edições feitas antes da resolução do conflito são transferidas para o arquivo resolvido.
  • Os comandos de instalação/desinstalação do /marketplace e do Marketplace agora relatam erros de seletor e carregamento de catálogo sem sair da sessão.
  • As sessões ACP honram mcp.startupTimeoutMs para servidores MCP declarados pelo client, ​​e as elicitações de formulário ACP não repetem mais rótulos de campo desnecessariamente.
  • O progresso da tarefa de cada etapa do subagente task.steps agora é preservado, em vez de apenas o relatório da etapa final.
  • Colar HTML no compositor agora preserva espaços de elementos embutidos somente com espaços em branco e recuo dentro de blocos <pre>.
  • Os acompanhamentos na fila editados com Alt+Up são restaurados como mensagens na fila em vez de serem enviados para o turno ativo.

Corrigido

  • Correção da saída ida exec no IDA 9.5+, suprimindo avisos de descontinuação do auxiliar e preservando os metadados de função atualizados API.
  • Logins e cookies expirados do Perplexity não retornam mais uma página de erro como resposta de pesquisa; o provedor é relatado como expirado e a cadeia de pesquisa continua.
  • Corrigida a descoberta e invocação do WebMCP do navegador no Chrome e Chromium 157 e posterior.
  • Hosts privados escritos com um ponto final agora são manipulados corretamente pelo Ask e always-ask-cached antes que as ferramentas de arquivo os acessem.
  • Corrigido o congelamento da TUI ao alternar sessões a partir de um prompt de aprovação de ferramenta aberta.
  • Correção de /commit e eval commit eliminando BOMs UTF-8 ou manipulação incorreta de nomes de arquivos entre aspas e Unicode durante o rastreamento de alterações e confirmações seletivas.
  • Corrigidos avisos enganosos do Wayland clipboard ao colar uma imagem ou quando o clipboard está vazio.
  • Corrigida a avaliação do JavaScript após uma atualização local do Linux, mantendo os trabalhadores da sessão vinculados à construção da sessão.
  • Excluir uma sessão que não pode ser removida não exclui mais seu histórico e estatísticas de prompts.
  • Corrigido o manuseio de seletores de linha read e write em URLs de dispositivos xd://.
  • Corrigido eval wait() rejeitando ou manipulando atrasos numéricos; as esperas do navegador agora direcionam os usuários para os auxiliares de espera apropriados.
  • Correção do navegador open com um perfil existente do Arch Chromium, navegação Tern, blocos Tern externos fechados e emulação de viewport Tern encaixada.
  • Corrigidas chamadas de navegador Tern e WebKit que expunham incorretamente APIs de ouvintes de eventos de página não suportados; erros agora identificam as alternativas suportadas.
  • Corrigido o tempo limite do navegador e erros de página ocupada para incluir o URL atual, a guia afetada e orientações de recuperação acionáveis.
  • Corrigidas falhas de incorporação do Mnemopi sendo rebaixadas silenciosamente para pesquisa por palavra-chave; erros de provedor agora produzem um aviso, inclusive no modo de impressão em stderr.

oh-my-pi v18.20.3

@oh-my-pi/pi-ai

Breaking Changes

  • Removed the public isXdDevicePath export from providers/cursor-pi-args. Ranged reads of xd:// documents now use the standard line-selector behavior.

Fixed

  • Fixed rate-limit handling for Mistral and other OpenAI-compatible providers so requests with no available allowance fail immediately with an actionable error suggesting a model or plan change.
  • Fixed Anthropic OAuth requests for pooled Claude accounts to report accurate device and account information, including after credentials are rotated during a request.

@oh-my-pi/pi-catalog

Added

  • Added publicly available image-sizing helpers for determining model-delivered image dimensions and fitting images to a specified long edge before coordinate mapping.

Fixed

  • Fixed image inputs being dropped for DeepSeek V4 Flash, restoring consistent multimodal image support.
  • Restricted reasoning-effort options for Mistral GLM 5.3, GLM 5.3 Flash, and Mistral Large 4 to the levels supported by those models.

@oh-my-pi/pi-coding-agent

Breaking Changes

  • Renamed the browser tab.clickAt() option from clickCount to count, matching tab.click().
  • Browser viewport screenshot coordinates now use the displayed image coordinates when the screenshot is scaled for the model; pass css: true (or { x, y, css: true } for drag points) to provide viewport CSS pixels explicitly.
  • Added opt-in mnemopi.recallRelevance (off, auto, or on; default off) to filter automatic memory recall for task relevance using the judge role.
  • Added path-scoped entries for bash.patterns and bashInterceptor.patterns, resolved per working directory. Project and --config overlays now prepend these rules to global rules instead of replacing them.
  • Added bash.allowedEnvVars and per-rule env lists to permit explicitly named environment-variable prefixes on matching allow rules.
  • Subagents now preserve @upstream provider pinning on inherited models.
  • Added --no-judge, --no-spotlight, and --offline options to restrict auxiliary services to the active model's provider or disable cross-provider services.
  • Added per-rule TTSR repeatMode frontmatter (once, after-gap, or always) to override the global repeat policy.
  • Compound bash approval prompts now show each command segment separately, distinguishing allowed segments from those requiring approval.
  • Removed the seance agent, /seance command, and the task tool's sourceSession parameter.

Added

  • Added mnemopi.embeddingQueryPrefix and mnemopi.embeddingInputType configuration for asymmetric and instruction-tuned embedding models, including providers that require an input_type.

Changed

  • Browser screenshots are delivered to the model in CSS pixels up to the supported unscaled size, making viewport screenshot coordinates directly usable with browser actions; scaling guidance remains for scaled full-page and element captures.
  • Browser waitForUrl, waitForResponse, and requests({ filter }) now support * glob patterns in URL strings, while other strings retain substring matching.
  • The WebKit browser engine now automatically installs and updates to the newest stable ABKit release, with versioned installations that allow updates without waiting for existing browser hosts to exit.
  • Improved browser responsiveness and recovery: unresponsive WebKit pages fail fast with actionable errors, navigation can recover busy pages, and browser operations provide clearer diagnostics for timeouts, closed tabs, unsupported event listeners, invalid routes, cookie data, and viewport changes.
  • Pressing Delete at the end of the Ctrl+R search field removes the selected prompt from history.
  • /copy now works while viewing a subagent and copies from that subagent's transcript.
  • find now returns unranked literal keyword matches when all judge requests fail.
  • take() and drop() now reject nonexistent hunk units with a clear error.
  • edit rejection messages now suggest the file's current tag, and edits made before conflict resolution carry over to the resolved file.
  • /marketplace and marketplace install/uninstall commands now report picker and catalog-load errors without exiting the session.
  • ACP sessions honor mcp.startupTimeoutMs for MCP servers declared by the client, and ACP form elicitations no longer repeat field labels unnecessarily.
  • Task progress from every task.steps subagent step is now preserved, rather than only the final step's report.
  • Pasting HTML into the composer now preserves spaces from whitespace-only inline elements and indentation inside <pre> blocks.
  • Queued follow-ups edited with Alt+Up are restored as queued messages instead of being sent into the active turn.

Fixed

  • Fixed ida exec output on IDA 9.5+ by suppressing helper deprecation warnings and preserving the updated function metadata API.
  • Expired Perplexity logins and cookies no longer return an error page as a search answer; the provider is reported as expired and the search chain continues.
  • Fixed browser WebMCP discovery and invocation on Chrome and Chromium 157 and later.
  • Private hosts written with a trailing dot are now correctly handled by Ask and always-ask-cached before file tools access them.
  • Fixed the TUI freezing when switching sessions from an open tool-approval prompt.
  • Fixed /commit and eval commit dropping UTF-8 BOMs or mishandling quoted and Unicode filenames during change tracking and selective commits.
  • Fixed misleading Wayland clipboard warnings when pasting an image or when the clipboard is empty.
  • Fixed JavaScript evaluation after an in-place Linux upgrade by keeping session workers tied to the session's build.
  • Deleting a session that cannot be removed no longer deletes its prompt history and statistics.
  • Fixed read and write handling of line selectors on xd:// device URLs.
  • Fixed eval wait() rejecting or mishandling numeric delays; browser waits now direct users to the appropriate wait helpers.
  • Fixed browser open with an existing Arch Chromium profile, Tern navigation, closed external Tern blocks, and docked Tern viewport emulation.
  • Fixed Tern and WebKit browser calls that incorrectly exposed unsupported page event-listener APIs; errors now identify the supported alternatives.
  • Fixed browser timeout and busy-page errors to include the current URL, affected tab, and actionable recovery guidance.
  • Fixed Mnemopi embedding failures being silently downgraded to keyword search; provider errors now produce a warning, including in print mode on stderr.

@oh-my-pi/pi-mnemopi

Added

  • Added configurable embedding query prefixes and input types for instruction-tuned and asymmetric embedding models, including Qwen3-Embedding, E5, and NVIDIA NIM.
  • Added the embeddings.onRequestFailed callback, allowing hosts to handle and surface failed embedding API requests.

@oh-my-pi/pi-natives

Fixed

  • Committing or writing trees now correctly reports unresolved index conflicts instead of silently omitting conflicted files.
  • Fixed shell compatibility with GNU grep for end-of-line-anchored patterns, including -o and -z modes, and corrected sed substitutions on multibyte-character lines.
  • Fixed native diff and patch handling for filenames containing spaces and other characters requiring quoting, including binary changes.

@oh-my-pi/pi-utils

Fixed

  • Fixed HTML-to-Markdown conversion for fetched and pasted HTML to preserve whitespace in inline elements, maintain code indentation in preformatted blocks, and avoid inserting stray blank lines between block elements.
