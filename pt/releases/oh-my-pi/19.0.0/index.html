oh-meu-pi v19.0.0

@oh-my-pi/pi-agent-core

Adicionado

  • Adicionado suporte para exclusão de mensagens personalizadas do contexto do modelo e compactação ou resumos de ramificação, permitindo ao mesmo tempo que mensagens de orientação e acompanhamento em fila continuem corretamente após mensagens excluídas.

@oh-my-pi/pi-ai

Adicionado

  • Adicionada uma opção de stream prewarm para solicitações de mensagens antrópicas para atualizar caches de prompt sem gerar saída faturável; é rejeitado pela reflexão orçamental, pela escolha forçada de ferramentas e pelos resultados estruturados.
  • Os relatórios de uso do Claude agora incluem o plano de assinatura da conta no metadata.subscriptionPlan, suportando os planos Max 5x, Max 20x, Pro, Team e Enterprise.
  • Adicionadas opções retryUnreachableBroker e onBrokerRetry ao discoverAuthStorage, permitindo que os hosts controlem novas tentativas de inicialização para corretores de autenticação temporariamente indisponíveis e exibam o status de novas tentativas.

Corrigido

  • Correção do failover da conta Claude após a recuperação de um limite de uso semanal compartilhado, garantindo que as contas fiquem disponíveis novamente quando o relatório de uso não mostrar mais essa janela.
  • A inicialização do corretor de autenticação agora tolera reinicializações temporárias do corretor e interrupções de conexão, tentando novamente por até 30 segundos, mas ainda falhando imediatamente devido a tokens rejeitados ou instantâneos malformados.
  • Melhor compatibilidade do corretor de autenticação entre client e versões do corretor, tolerando campos e valores desconhecidos de credenciais, uso e uso observado.
  • Medidores de uso do Codex Spark corrigidos para que os relatórios que identificam o medidor apenas por metered_feature permaneçam com escopo correto para o modelo Spark.
  • Corrigidas solicitações de antigravidade CLI para modelos cujos IDs disponíveis incluem sufixos de esforço, como resolver gemini-4-hydrogen quando apenas gemini-4-hydrogen-high é oferecido.

@oh-my-pi/pi-catalog

Adicionado

  • Adicionado suporte para pré-aquecimento de cache de prompt no endpoint Antrópico primário por meio do recurso de compatibilidade isPromptCachePrewarmSupported.

Corrigido

  • Corrigidas solicitações de julgamento hospedadas para TypeSafe, OpenRouter, Command Code e OpenCode Zen ao avaliar mais de 32 questões.
  • Tratamento de imagens Devin aprimorado para suportar mais imagens de conversação dentro dos limites do provedor e compactação de imagem atualizada para modelos Devin Gemini para refletir o uso de token cobrado.
  • Corrigido o preço do modelo Devin Gemini para que os modelos mudem do preço promocional para o preço de tabela quando as promoções terminarem.
  • Corrigida a autenticação da chave Kiro API (KIRO_API_KEY e ksk_…) para que a listagem de modelos, bate-papo e solicitações /usage funcionem corretamente.

@oh-my-pi/pi-coding-agent

Mudanças importantes

  • Alterados controles de aquecimento de cache SDK: createAgentSession.cacheWarming agora aceita o limite de modo "off", "streaming" ou "idle"; o menor entre esse valor e provedores.cacheWarming se aplica. Use "off" em vez de falso.
  • Substituídos links artefato://N por arquivos local://N.log legíveis, listáveis ​​e completáveis ​​na raiz local:// da sessão. Os links artefato:// em sessões existentes não são migrados.
  • Substituído session.handoff(focus) por session.compact(focus, { mode: "handoff" }); use abortCompaction() para cancelá-lo.
  • Processos de segundo plano compartilhados consolidados em um daemon por usuário, em vez de agentes específicos do projeto. Daemons e serviços de versões mais antigas não são adotados; omp ps agora relata unidades globais, de projeto e de sessão juntas, remove --global, altera a saída --json para {daemon, reports} e não adiciona mais ?project= aos identificadores dsm://.
  • SDK deferSkillDescriptionCompression renomeado para deferHintCompression e startSkillDescriptionCompression() para startHintCompression(); essas configurações e métodos agora também abrangem dicas de namespace MCP.

Adicionado

  • Adicionadas transformações MCP integradas, incluindo a substituição do Codex Desktop node_repl. Os integrados podem ser desabilitados com mcp.builtinTransforms; /mcp list identifica servidores substituídos e /mcp enable node_repl pode conectar explicitamente um.
  • Adicionados namespaces de avaliação MCP opcionais por meio de mcp.evalNamespaces, expondo servidores como namespaces JavaScript e Python com documentação em xd://eval/<server>. Os resultados preservam texto e dados estruturados, e os recursos binários são salvos como arquivos local://.
  • Adicionados nomes gerados por modelo para agentes /tan e seus cartões de bandeja, com um substituto aleatório legível quando a nomeação falha ou expira.
  • Adicionadas estratégias configuráveis ​​de aquecimento de cache (automático, keepalive e compacto), incluindo keepalive de chamada de ferramenta longa e compactação de prompt de pré-expiração. Os eventos de aquecimento de cache agora informam o método e os custos selecionados.
  • Adicionadas descobertas opcionais de tarefas entre instâncias e mensagens com task.crossInstance, expondo instâncias da mesma pasta por meio de agent://peers.
  • Adicionado modo aliás: rascunhos começando com? envie como /btw perguntas e receba indicações de UI distintas.
  • Adicionados cartões dinâmicos Tern para execução de subagentes e trabalhos em segundo plano, incluindo progresso, contagens de ferramentas, status, controles, transcrições e acesso restaurado a agentes finalizados.
  • Adicionada sobrevivência de atualização de daemon e hospedagem TCP opcional por meio de OMP_DAEMON_TCP, preservando serviços em execução, PTYs e servidores de idioma em atualizações de daemon.
  • Carregou modelos de fala para texto e texto para fala uma vez por máquina, descarregando-os após 15 minutos de inatividade.
  • Adicionado suporte à árvore de trabalho ovnfs para /wt, o seletor de currículo do projeto e lista/limpeza da árvore de trabalho omp, preservando o resumo da sessão do repositório de origem após a remoção do checkout.
  • Adicionados planos de assinatura do Claude para uso de OMP e saída de /usage.
  • Adicionado relatório de progresso para descrição de habilidades em segundo plano e geração de dicas de namespace MCP.
  • Adicionado excludeFromContext às cargas pi.sendMessage para que as extensões possam exibir e salvar mensagens por turno sem enviá-las ao modelo.
  • Adicionada uma janela de nova tentativa de 30 segundos para CLI e comandos de modo de impressão enquanto o agente de autenticação reinicia ou fica brevemente indisponível.
  • Adicionada uma opção de notificação à ferramenta bash para relatar resultados correspondentes de comandos em segundo plano e serviços nomeados, ativando sessões ociosas ou encerrando esperas bloqueadas.

Alterado

  • Aquecimento de cache aprimorado para provedores compatíveis com Anthropic com pré-aquecimento sem saída quando suportado e faturamento baseado em custos reais de reprodução; os subagentes de tarefas agora mantêm os caches de prompt aquecidos durante longas chamadas de ferramenta quando o aquecimento de streaming está habilitado.
  • Descrições de habilidades geradas e dicas de namespace MCP uma vez por máquina, compartilhando resultados e progresso em janelas omp.
  • Níveis de pensamento preservados ao trocar de modelo, ajustando apenas quando o modelo selecionado não consegue suportar o nível atual; os padrões do modelo se aplicam somente quando nenhum nível é definido.
  • Respostas repetidas estendidas e esperas de subagentes para usar o tempo de vida do cache de prompt da sessão e fizeram esperas de subagentes seguirem a próxima mensagem do pai ativo quando apropriado.
  • Feito /handoff executado como compactação em segundo plano, preservando a resposta atual e as mensagens recém-chegadas.
  • Prompts de pergunta redesenhados como um único formulário de rolagem acima do compositor, preservando respostas parciais e permitindo que os usuários pulem perguntas pendentes enviando uma mensagem.
  • Previsões do compositor habilitadas por padrão, mostrando a próxima mensagem sugerida do modelo ativo após turnos concluídos; desative-os em Configurações → Interação.
  • Rastreamento de intenção de chamada de ferramenta desativado por padrão em sessões de impressão, RPC, ACP e SDK; habilite-o com tools.intentTracing ou PI_INTENT_TRACING.
  • Orientações de checkout do ovnfs atualizadas e mensagens do git guard para explicar como efetuar, extrair ou descartar alterações.
  • Sondagens de conclusão de subagentes e solicitações secundárias aprimoradas para que se concentrem nas entregas e não incluam o raciocínio de streaming contínuo como histórico simples.
  • Comportamento de espera padronizado para uma espera inativa inicial de 5 segundos seguida por esperas consecutivas de quatro minutos.
  • Sempre forneça aos subagentes a ferramenta LSP compartilhada; task.enableLsp agora controla apenas a formatação LSP e diagnósticos para edições.
  • Serviços bash, PTYs e shells incorporados aprimorados com herança de ambiente de sessão, suporte a URL de arquivo de sessão, validação de prontidão mais clara e saída minimizada mais transparente.
  • Nomeado claramente o Chromium gerenciado ao ser executado em uma janela e comportamento aprimorado do navegador, captura de tela, upload, quadro, seletor, rede e CDP em guias e back-ends do navegador.
  • Edição de hashline aprimorada com corpos de substituição textuais, validação de intervalo e caminho mais segura, análise mais clara e diagnóstico de sintaxe, suporte para arquivos maiores e arquivos SSH e leituras brutas e seletores de linha mais previsíveis.
  • Maior confiabilidade do MCP com prazos de chamada de ferramenta de dez minutos, prazos mais longos quando o progresso é relatado, tempo limite e erros de conexão mais claros e uma nova tentativa após sessões HTTP expiradas.
  • Expandiu o shell incorporado com recursos integrados portáteis e suporte a URL interno para fluxos de trabalho comuns, incluindo inspeção de arquivos, arquivamento, controle de processos, carregamento de ambiente, observação de arquivos, bloqueio, fala, abertura de arquivos e aplicação de patch.
  • Diagnósticos aprimorados de LSP e depuração, cobertura de idiomas, detecção de espaço de trabalho, referências, renomeação, ações de código e relatórios de ciclo de vida do servidor.
  • Ferramentas de avaliação aprimoradas com validação Python 3.9 +, execução UTF-8, atualizações de instalação de pacotes, resultados completos da ferramenta, acesso a arquivos de protocolo, auxiliares Python encadeados e mensagens mais claras de perda de kernel e tempo limite.
  • Rascunhos e resumos de commit aprimorados para lidar com ganchos, operações de alteração, árvores de trabalho, filtros, finais de linha, grandes árvores não rastreadas, arquivos de revisão e paridade JavaScript/Python API com mais precisão.
  • URL, arquivo, GitHub, Registro Terraform, documentação de pacote, pesquisa na web e manipulação remota de arquivos aprimorados, incluindo filtragem, paginação, conversão binária, acesso a membros de arquivo e erros de provedor mais claros.
  • Relatórios aprimorados de uso e política de conta para que os limites de assinatura e o esgotamento do escopo identifiquem com precisão o plano ou medidor afetado.
  • Melhorias na árvore de trabalho, processo, espera, mensagens do agente, restauração de sessão, retenção de memória, Spotlight, shell do Windows e comportamento de desempenho do macOS.

  • Corrigidos rascunhos de commit após ganchos de pré-commit e commits anteriores parciais para que o índice, diff, blocos selecionados, pai alterado, arquivos de revisão e resumos gerados permaneçam precisos.
  • Correção da retenção automática de Hindsight e Mnemopi durante execuções com trabalho assíncrono, subagentes ou mensagens de pares, evitando retenção duplicada ou sobreposta.

  • Corrigida a retomada da sessão e o tratamento de resultados de processos em atualizações de daemon unificado.
  • Corrigida a exibição do nível de pensamento e o comportamento de troca de modelo para subagentes, sessões de pensamento automático e níveis ajustados manualmente.
  • Corrigida clonagem de árvore de trabalho, transições ovnfs/Git, verificações de prontidão de serviço, herança de ambiente shell, remoção de junção do Windows, substituição de processo, somas de verificação e cancelamento de comando em segundo plano.
  • Corrigida a confiabilidade da automação do navegador em capturas de tela, clicks, preenchimentos, guias, quadros, diálogos, uploads, endpoints CDP, conexões obsoletas, avaliações simultâneas, inicialização do navegador, emulação de viewport, clipboard e entrada específica da plataforma.
  • Hashline corrigido, edição AST, detecção de arquivo gerado, conteúdo numerado, edição remota de arquivo, diagnóstico de sintaxe, manipulação de caminho e comportamento de final de linha.
  • Kernels de avaliação corrigidos, auxiliares Python e JavaScript, importações de pacotes, chamadas de ferramentas aninhadas, URLs internos e diretórios de trabalho movidos.
  • Corrigido LSP, inicialização do servidor de linguagem, diagnóstico, referências, renomeação, ações de código, carregamento de projeto, tipos de arquivo e seleção de adaptador de depurador.
  • Correção do resumo da saída do comando para que o contexto relevante, os metadados, a saída do Git, o tempo de teste, a saída da AWS, o diagnóstico de lint e a detecção binária sejam preservados em vez de serem classificados incorretamente.
  • Correção de leitura, grep, glob, URL, arquivo, SQLite, vídeo, RSS, GitHub, documentação de pacote, SSH e manipulação de pesquisa na web em seletores, filtros, paginação, arquivos, conteúdo binário e falhas de provedor.
  • Correção de operações de tarefas, compatibilidade de solicitação e comportamento de tempo limite, validação de geração de imagem, push de PR GitHub, propostas de plano e contabilização de sessão para chamadas de modelo de canal lateral.
  • Foram corrigidos erros de reautenticação do MCP OAuth para expor endpoints de registro, detalhes de status e soluções, e foi corrigido o desligamento do agente de autenticação para que os tokens atualizados sejam salvos com segurança.
  • Novas tentativas e manipulação de contas do Spotlight corrigidas, incluindo contas em lista de espera, limites de taxa, interrupções e identificação de solicitação.
  • Corrigido o comportamento do shell e da área de trabalho entre plataformas, incluindo inicialização do macOS e desempenho de redesenho, operações de arquivos do Windows e pesquisa de aplicativos, saída de fala e abertura da área de trabalho.

@oh-my-pi/pi-tui

Mudanças importantes

  • As referências de saída completa e o rodapé [raw output: …] agora usam local://N.log em vez de artifact://N.

Adicionado

  • Adicionado o modo compositor btw, incluindo a cor do tema btwMode em todos os temas incluídos.
  • Adicionado encaixe nativo com recursos limitados para filhos de tempo de execução, permitindo que os componentes apareçam apenas em terminais que anunciam a capacidade necessária.
  • Adicionadas opções para preservar sublinhados intrapalavras ao remover Markdown inline e para abrir JobsSheet em um trabalho selecionado.
  • Cargas de mensagens personalizadas agora podem ser excluídas do contexto do modelo, permanecendo disponíveis em entradas salvas normalizadas e restauradas.
  • Adicionados blocos de transcrição para saída relatada pela execução de trabalhos e serviços em segundo plano.

Alterado

  • Diálogos de perguntas reformulados em um único fluxo empilhado: a pergunta ativa permanece aberta enquanto as perguntas respondidas são dobradas em resumos compactos com as opções selecionadas visíveis. Isso se aplica a interfaces terminais e nativas e melhora a navegação do teclado, o dimensionamento e a integração do compositor de host.
  • Melhor comportamento do compositor enquanto uma caixa de diálogo de pergunta está pendente: o compositor indica que digitar ali irá pular a pergunta, dobra para um estado compacto quando apropriado e oferece uma ação explícita de Pular e enviar para rascunhos que ignoram a pergunta.
  • Adicionado suporte para estados de compositor dobrados e fracos e indicação visual mais clara quando a interface está aguardando uma resposta.
  • A pesquisa de modelo agora suporta consultas provider/model, priorizando correspondências exatas de provedor e pesquisando primeiro os IDs de modelo desse provedor.

Corrigido

  • Avisos de trabalho em segundo plano aprimorados no Tern, agrupando todas as saídas em um cabeçalho e mostrando as linhas completas.
  • Corrigida a manipulação do compositor Tern de -> e => para que digitá-los não insira mais uma quebra de linha inesperadamente.
  • Resultados de pesquisa na web corrigidos sem uma resposta sintetizada para mostrar cada fonte uma vez com um trecho conciso e limpo.
  • Corrigidos prompts longos de aprovação da ferramenta Tern para que seus detalhes rolem dentro da janela disponível e as opções e controles Aprovar/Negar permaneçam visíveis.
  • Corrigida a exibição da unidade do gráfico de tabela e cálculos de fator de mudança para medições com unidades dimensionadas.
  • Corrigidos grupos de caixas de seleção, então pressionar Enter sem nada selecionado primeiro marca a caixa em foco.
  • Os formulários Ask agora abrem cada pergunta com sua resposta pré-selecionada, permitindo que Enter aceite a recomendação sem substituí-la.

oh-my-pi v19.0.0

@oh-my-pi/pi-agent-core

Added

  • Added support for excluding custom messages from model context and compaction or branch summaries, while allowing queued steering and follow-up messages to continue correctly after excluded messages.

@oh-my-pi/pi-ai

Added

  • Added a prewarm stream option for Anthropic Messages requests to refresh prompt caches without generating billable output; it is rejected for budget thinking, forced tool choice, and structured output.
  • Claude usage reports now include the account subscription plan in metadata.subscriptionPlan, supporting Max 5x, Max 20x, Pro, Team, and Enterprise plans.
  • Added retryUnreachableBroker and onBrokerRetry options to discoverAuthStorage, allowing hosts to control startup retries for temporarily unavailable authentication brokers and display retry status.

Fixed

  • Fixed Claude account failover after a shared weekly usage limit recovers, ensuring accounts become available again when usage reporting no longer shows that window.
  • Authentication broker startup now tolerates temporary broker restarts and connection interruptions by retrying for up to 30 seconds, while still failing immediately for rejected tokens or malformed snapshots.
  • Improved authentication broker compatibility across client and broker versions by tolerating unknown credential, usage, and observed-usage fields and values.
  • Fixed Codex Spark usage meters so reports that identify the meter only by metered_feature remain correctly scoped to the Spark model.
  • Fixed Antigravity CLI requests for models whose available IDs include effort suffixes, such as resolving gemini-4-hydrogen when only gemini-4-hydrogen-high is offered.

@oh-my-pi/pi-catalog

Added

  • Added support for prompt-cache prewarming on the first-party Anthropic endpoint via the isPromptCachePrewarmSupported compatibility capability.

Fixed

  • Fixed hosted judgment requests for TypeSafe, OpenRouter, Command Code, and OpenCode Zen when evaluating more than 32 questions.
  • Improved Devin image handling to support more conversation images within provider limits, and updated image compaction for Devin Gemini models to reflect their billed token usage.
  • Fixed Devin Gemini model pricing so models switch from promotional to list pricing when promotions end.
  • Fixed Kiro API key authentication (KIRO_API_KEY and ksk_…) so model listing, chat, and /usage requests work correctly.

@oh-my-pi/pi-coding-agent

Breaking Changes

  • Changed SDK cache warming controls: createAgentSession.cacheWarming now accepts the mode cap "off", "streaming", or "idle"; the lower of this value and providers.cacheWarming applies. Use "off" instead of false.
  • Replaced artifact://N links with readable, listable, and completable local://N.log files at the session's local:// root. artifact:// links in existing sessions are not migrated.
  • Replaced session.handoff(focus) with session.compact(focus, { mode: "handoff" }); use abortCompaction() to cancel it.
  • Consolidated shared background processes under one per-user daemon rather than project-specific brokers. Daemons and services from older versions are not adopted; omp ps now reports global, project, and session units together, removes --global, changes --json output to {daemon, reports}, and no longer adds ?project= to dsm:// handles.
  • Renamed SDK deferSkillDescriptionCompression to deferHintCompression and startSkillDescriptionCompression() to startHintCompression(); these settings and methods now also cover MCP namespace hints.

Added

  • Added built-in MCP transforms, including the Codex Desktop node_repl replacement. Built-ins can be disabled with mcp.builtinTransforms; /mcp list identifies replaced servers and /mcp enable node_repl can explicitly connect one.
  • Added optional MCP eval namespaces through mcp.evalNamespaces, exposing servers as JavaScript and Python namespaces with documentation at xd://eval/<server>. Results preserve text and structured data, and binary resources are saved as local:// files.
  • Added model-generated names for /tan agents and their tray cards, with a readable random fallback when naming fails or times out.
  • Added configurable cache-warming strategies (auto, keepalive, and compact), including long-tool-call keepalive and pre-expiry prompt compaction. Cache-warming events now report the selected method and costs.
  • Added optional cross-instance task discovery and messaging with task.crossInstance, exposing same-folder instances through agent://peers.
  • Added btw mode: drafts beginning with ? submit as /btw questions and receive distinct UI indication.
  • Added Tern live cards for running subagents and background jobs, including progress, tool counts, status, controls, transcripts, and restored access to finished agents.
  • Added daemon update survival and optional TCP hosting through OMP_DAEMON_TCP, preserving running services, PTYs, and language servers across daemon upgrades.
  • Loaded speech-to-text and text-to-speech models once per machine, unloading them after 15 minutes of inactivity.
  • Added ovnfs worktree support to /wt, the project resume picker, and omp worktree list/clear, while preserving session resume from the source repository after checkout removal.
  • Added Claude subscription plans to omp usage and /usage output.
  • Added progress reporting for background skill-description and MCP namespace hint generation.
  • Added excludeFromContext to pi.sendMessage payloads so extensions can display and save per-turn messages without sending them to the model.
  • Added a 30-second retry window for CLI and print-mode commands while the authentication broker restarts or is briefly unavailable.
  • Added a notify option to the bash tool for reporting matching output from background commands and named services, waking idle sessions or ending blocked waits.

Changed

  • Improved cache warming for Anthropic-compatible providers with no-output prewarming where supported and billing based on actual replay costs; task subagents now keep prompt caches warm during long tool calls when streaming warming is enabled.
  • Generated skill descriptions and MCP namespace hints once per machine, sharing results and progress across omp windows.
  • Preserved thinking levels when switching models, adjusting only when the selected model cannot support the current level; model defaults apply only when no level is set.
  • Extended repeated reply and subagent waits to use the session's prompt-cache lifetime, and made subagent waits follow the live parent's next message when appropriate.
  • Made /handoff run as background compaction while preserving the current response and newly arriving messages.
  • Redesigned ask prompts as a single scrolling form above the composer, preserving partial answers and allowing users to skip pending questions by sending a message.
  • Enabled composer predictions by default, showing the active model's suggested next message after completed turns; disable them in Settings → Interaction.
  • Disabled tool-call intent tracing by default in print, RPC, ACP, and SDK sessions; enable it with tools.intentTracing or PI_INTENT_TRACING.
  • Updated ovnfs checkout guidance and git guard messages to explain how to land, pull, or discard changes.
  • Improved subagent completion probes and side requests so they focus on deliverables and do not include still-streaming reasoning as plain history.
  • Standardized wait behavior to a 5-second initial idle wait followed by four-minute back-to-back waits.
  • Always provide subagents with the shared LSP tool; task.enableLsp now controls only LSP formatting and diagnostics for edits.
  • Improved bash services, PTYs, and embedded shells with session environment inheritance, session-file URL support, clearer readiness validation, and more transparent minimized output.
  • Named managed Chromium clearly when running in a window and improved browser, screenshot, upload, frame, selector, network, and CDP behavior across tabs and browser backends.
  • Improved hashline editing with verbatim replacement bodies, safer range and path validation, clearer parse and syntax diagnostics, support for larger files and SSH files, and more predictable raw reads and line selectors.
  • Improved MCP reliability with ten-minute tool-call deadlines, longer deadlines when progress is reported, clearer timeout and connection errors, and one retry after expired HTTP sessions.
  • Expanded the embedded shell with portable built-ins and internal-URL support for common workflows, including file inspection, archiving, process control, environment loading, file watching, locking, speech, opening files, and patch application.
  • Improved LSP and debugging diagnostics, language coverage, workspace detection, references, rename, code actions, and server lifecycle reporting.
  • Improved eval tooling with Python 3.9+ validation, UTF-8 execution, package installation refreshes, full tool results, protocol-file access, threaded Python helpers, and clearer kernel-loss and timeout messages.
  • Improved commit drafts and summaries to handle hooks, amend operations, worktrees, filters, line endings, large untracked trees, review files, and JavaScript/Python API parity more accurately.
  • Improved URL, archive, GitHub, Terraform Registry, package documentation, web search, and remote-file handling, including filtering, pagination, binary conversion, archive member access, and clearer provider errors.
  • Improved usage and account policy reporting so subscription limits and scoped exhaustion identify the affected plan or meter accurately.
  • Improved worktree, process, wait, agent messaging, session restore, memory retention, Spotlight, Windows shell, and macOS performance behavior.

Fixed

  • Fixed MCP resource links and binary resources so they remain accessible as readable files or inline content rather than being dropped or shown only as placeholders.
  • Fixed commit drafts after pre-commit hooks and partial prior commits so the index, diff, selected blocks, amended parent, review files, and generated summaries remain accurate.
  • Fixed automatic Hindsight and Mnemopi retention during runs with async work, subagents, or peer messages, preventing duplicate or overlapping retention.
  • Fixed blocked agents and waits by reporting waiters and dependency chains, delivering messages to queued agents, and correctly handling killed, evicted, resumed, or empty-output jobs.
  • Fixed session resume and process-result handling across unified-daemon upgrades.
  • Fixed thinking-level display and model-switcher behavior for subagents, auto-thinking sessions, and manually adjusted levels.
  • Fixed worktree cloning, ovnfs/Git transitions, service readiness checks, shell environment inheritance, Windows junction removal, process substitution, checksums, and background command cancellation.
  • Fixed browser automation reliability across screenshots, clicks, fills, tabs, frames, dialogs, uploads, CDP endpoints, stale connections, concurrent evaluations, browser startup, viewport emulation, clipboard, and platform-specific input.
  • Fixed hashline, AST editing, generated-file detection, numbered content, remote-file editing, syntax diagnostics, path handling, and line-ending behavior.
  • Fixed eval kernels, Python and JavaScript helpers, package imports, nested tool calls, internal URLs, and moved working directories.
  • Fixed LSP, language-server startup, diagnostics, references, rename, code actions, project loading, file types, and debugger adapter selection.
  • Fixed command-output summarization so relevant context, metadata, Git output, test timing, AWS output, lint diagnostics, and binary detection are preserved instead of being misclassified.
  • Fixed read, grep, glob, URL, archive, SQLite, video, RSS, GitHub, package-documentation, SSH, and web-search handling across selectors, filters, pagination, archives, binary content, and provider failures.
  • Fixed todo operations, ask compatibility and timeout behavior, image generation validation, GitHub PR pushes, plan proposals, and session accounting for side-channel model calls.
  • Fixed MCP OAuth reauthentication errors to expose registration endpoints, status details, and remedies, and fixed auth-broker shutdown so refreshed tokens are saved safely.
  • Fixed Spotlight retry and account handling, including waitlisted accounts, rate limits, outages, and request identification.
  • Fixed cross-platform shell and desktop behavior, including macOS startup and redraw performance, Windows file operations and application lookup, speech output, and desktop opening.

@oh-my-pi/collab-web

Fixed

  • Fixed web search cards without a synthesized answer displaying raw numbered result lists; they now show a concise excerpt for each source instead.

@oh-my-pi/pi-natives

Added

  • Added VcsGitRepo.worktreeToGit() to convert worktree content into the blob representation produced by git add.
  • Added support for using a Shell as a process's shell, routing commands through the process's standard streams while preserving the process session and terminal for external commands.
  • Added ShellRunOptions.speech to connect the host speech handler to the shell's say command.
  • Added an in-process file shell builtin with broad file-type detection, MIME and encoding output, archive/image/document support, and compatibility with the commonly used file command options.

Changed

  • Improved typing and key-press responsiveness in iPhone Mirroring, reducing per-character latency by approximately half.

Fixed

  • Fixed screenshots of partially off-screen Linux windows on Wayland and X11 so the visible region is captured and coordinate-based zoom targets correctly.
  • Fixed Wayland input operations on desktops without an available input route to fail immediately with a clear PermissionDenied error instead of attempting unnecessary screen capture first.
  • Fixed macOS computer interactions so background clicks, key presses, pop-up menu actions, and takeover calls restore the previously active window within the call.
  • Fixed macOS pop-up menu reads immediately after typing so they reflect the option selected by the entered letters.

@oh-my-pi/omp-stats

Breaking Changes

  • Spotlight recovery counts reads from local spill files toward recovery counts; reads from artifact references in older sessions continue to count as before.

Added

  • Expanded the Overview's Token mix to include off-transcript model calls—such as title generation, job captions, judge queries, and cache warming—with per-source request counts, token totals, and usage shares.
  • Added a Decision models card to the Overview showing requests, tokens, and usage share by judgment use case for native judgment models.
  • Request details for title-generation and judge calls now display the generated reply or recorded judge answers.

Changed

  • Token mix shares for the main agent, subagents, and advisor now reflect conversation turns only, excluding side-channel model calls.

Fixed

  • Hardened the dashboard against DNS rebinding by rejecting requests made through unconfigured public host names. IP addresses, localhost, LAN short names, local network domains, and Tailscale names remain supported; configure reverse-proxy or other custom domains with OMP_STATS_ALLOWED_HOSTS, including wildcard subdomains such as *.example.com.

@oh-my-pi/pi-tui

Breaking Changes

  • Full-output references and the [raw output: …] footer now use local://N.log instead of artifact://N.

Added

  • Added the btw composer mode, including the btwMode theme color in all bundled themes.
  • Added feature-gated native docking for runtime children, allowing components to appear only on terminals that advertise the required capability.
  • Added options to preserve intraword underscores when stripping inline Markdown and to open JobsSheet on a selected job.
  • Custom message payloads can now be excluded from model context while remaining available in normalized and restored saved entries.
  • Added transcript blocks for output reported by running background jobs and services.

Changed

  • Reworked ask dialogs into a single stacked flow: the active question stays open while answered questions fold into compact summaries with their selected options visible. This applies across terminal and native interfaces and improves keyboard navigation, sizing, and host composer integration.
  • Improved composer behavior while an ask dialog is pending: the composer indicates that typing there will skip the question, folds to a compact state when appropriate, and offers an explicit Skip & send action for drafts that bypass the ask.
  • Added support for folded and faint composer states and clearer visual indication when the interface is awaiting an answer.
  • Model search now supports provider/model queries, prioritizing exact provider matches and searching that provider's model IDs first.

Fixed

  • Improved background-job notices in Tern by grouping all output under one header and showing the complete lines.
  • Fixed Tern composer handling of -> and => so typing them no longer unexpectedly inserts a line break.
  • Fixed web search results without a synthesized answer to show each source once with a concise cleaned excerpt.
  • Fixed long Tern tool-approval prompts so their details scroll within the available window and the choices and Approve/Deny controls remain visible.
  • Fixed table chart unit display and change-factor calculations for measurements with scaled units.
  • Fixed checkbox groups so pressing Enter with nothing selected first checks the focused box.
  • Ask forms now open each question with its preselected answer, allowing Enter to accept the recommendation without replacing it.

@oh-my-pi/pi-utils

Added

  • Added utilities for formatting and parsing session spill URLs using the local://N.log format.
  • Added postmortem.exitCleanlyOnStopSignals() so long-running services exit successfully after completing cleanup on SIGINT or SIGTERM.

Fixed

  • Fixed Windows shell discovery incorrectly selecting the WSL bash.exe launcher, which could cause services to run under WSL.
  • Fixed archive opening so the extraction-size limit is enforced when an oversized member is read rather than preventing access to the entire archive.
  • Fixed OMP_LOG_LEVEL so it also controls console output from services such as omp auth-broker serve, not just log-file output.
  • Fixed Markdown parsing so emphasis and link labels are not prematurely terminated by marker characters inside code spans, autolinks, inline HTML tags, or link destinations.

@oh-my-pi/pi-wire

Added

  • Added tray state and interaction properties, including focus, peek, quiet, main status, item references, card status and actions, and event state.
  • Added layout transition properties to nodes for coordinating layout animations.
  • Added support for folding a dock composer into its compact row.
