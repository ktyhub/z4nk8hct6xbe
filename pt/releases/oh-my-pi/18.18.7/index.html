oh-meu-pi v18.18.7

@oh-my-pi/pi-ai

Adicionado

  • Adaptador de uso LiteLLM (@oh-my-pi/pi-ai/usage/litellm) relatando a chave de um gateway e os orçamentos em dólares dos usuários (#17873 por @maykonmichel)
  • UsageApi.replaceConfiguredProviders registra provedores de uso de origem de configuração entre substituições de tempo de execução e o resolvedor integrado, e UsageProvider.usesRequestKey faz a investigação de uso agregado apenas a inferência de chave enviaria (#17873 por @maykonmichel)

Alterado

  • Provedores com regra de autenticação login-warning mostram o risco de sua conta antes de um novo login e iniciam-no somente após o usuário responder yes; qualquer outra resposta ou cancelamento não armazena nada, e sua entrada na lista de login é marcada como "(por sua conta e risco)" (#18499)

Corrigido

  • As redefinições de lançamento do Claude Fable agora informam o limite semanal do Fable que eles limpam em vez de uma janela desconhecida (#18661 por @TheAifam5)

@oh-my-pi/pi-catalog

Adicionado

  • Adicionado Muse Ember (muse-ember-1.0) no Meta Model API e Muse Code com a escada de esforço de raciocínio minimal – max e seu preço de contexto longo> 200K
  • Adicionada a regra de autenticação login-warning "<text>", que faz com que um novo login aceite primeiro o risco declarado da conta (#18499)

Alterado

  • O Google Antigravity foi retomado com um aviso de login em vez de pausá-lo (#18499)

Corrigido

  • Solicitações Morph (api.morphllm.com) agora enviam x-session-id, mantendo uma conversa no trabalhador que mantém seu cache de prompt (#18704 por @wolfiesch)

@oh-my-pi/pi-coding-agent

Adicionado

  • /usage e omp usage mostram chave LiteLLM e orçamentos de usuário para o provedor litellm integrado e todos os provedores models.yml com discovery.type: litellm, a menos que listado em disabledProviders (#17873 por @maykonmichel)
  • Os ramais podem solicitar à operadora antes de um encerramento interativo, ou cancelá-lo, com session_before_shutdown; outro /exit ou Ctrl+D ignora os prompts pendentes e fecha (#18424 por @aw1cks)

Alterado

  • O resgate automático com reset salvo é definido por janela: codexResets.autoRedeem5h/autoRedeemWeekly e claudeResets.autoRedeem5h/autoRedeemWeekly/autoRedeemFable substituem o autoRedeem de cada provedor, cujo valor migra para as chaves 5h e semanal; uma redefinição de lançamento de Claude Fable é governada apenas por autoRedeemFable e gasta apenas para um bloco que inclui o limite semanal de Fable ou antes de expirar quando o uso de Fable estiver acima de zero (#18661 por @TheAifam5)
  • Sessões sem uma UI de prompt (como omp -p) não gastam mais redefinições salvas enquanto o resgate automático é unset, mesmo aquelas prestes a expirar (#18661)
  • O Google Antigravity está de volta em /login e omp login, marcado como "(por sua conta e risco)": um novo login explica primeiro que o Google pode suspender contas que fazem login a partir de ferramentas de terceiros e continua somente depois que você digita yes; Logins antigravidade salvos funcionam novamente (#18499)
  • No Windows, a descrição da ferramenta bash informa o modelo que ela executa em um ambiente bash emulado, não em cmd ou PowerShell, portanto, ela grava bash em vez de dir, %VAR% e outras sintaxes cmd

Corrigido

  • Os prompts de extensão mostrados pelos manipuladores session_before_* não expiram mais após 30 segundos enquanto o operador ainda está respondendo (#18424 por @aw1cks)
  • Uma segunda solicitação de saída agora ignora prompts pendentes do worktree.onExit e mantém essas árvores de trabalho em vez de esperar por uma resposta (#18424 por @aw1cks)
  • O conselho que faz o agente continuar trabalhando depois de concluído não volta mais uma segunda vez, muitas vezes como um bloqueador, enquanto o agente está consertando: as revisões do consultor da resposta anterior são canceladas e o consultor revisa a correção (#18735 por @H4vC)
  • No Windows, o shell da ferramenta bash resolve caminhos de unidade MSYS (/c/Users/..., /mnt/c/...) em todos os lugares, portanto, executar /c/.../tool.exe, cd /c/..., [ -f /c/... ] e < /c/... alcança a unidade C: como já fizeram para ls e outros utilitários integrados
  • No Windows, linhas de comando no estilo cmd, como dir | find /c /v "", sort /r, timeout /t 5 e whoami /all na ferramenta bash, executam os programas do Windows para os quais foram escritos, em vez do estilo GNU find/sort/timeout/whoami do pi (que lê /c como unidade C: e pode percorrer toda a unidade)
  • Alterar ou desabilitar PATH no shell da ferramenta bash agora esquece os locais de comando lembrados, como o bash faz, então um comando não é mais executado a partir de um diretório que saiu de PATH
  • Um convidado de colaboração lento ou inundado não termina mais o compartilhamento da sala: o anfitrião descarta o backlog do convidado e pede para ele voltar, sessões maiores que o orçamento de envio podem ser ingressadas e as perguntas do convidado que ninguém recebeu são resolvidas como indisponíveis (#18629 por @iliaal)

@oh-my-pi/pi-tui

Alterado

  • Os resultados grep e ast_grep sem correspondências são renderizados como uma linha com 0 matches na cor de aviso, eliminando a linha No matches found separada (#18700 por @JustasMasiulis)

Corrigido

  • Mensagens de redefinição salvas nomeiam o limite semanal de Claude Fable como "Claude Fable semanalmente" em vez de seu ID bruto (#18661 por @TheAifam5)

oh-my-pi v18.18.7

@oh-my-pi/pi-ai

Added

  • LiteLLM usage adapter (@oh-my-pi/pi-ai/usage/litellm) reporting a gateway's key and user USD budgets (#17873 by @maykonmichel)
  • UsageApi.replaceConfiguredProviders registers configuration-sourced usage providers between runtime overrides and the built-in resolver, and UsageProvider.usesRequestKey makes aggregate usage probe only the key inference would send (#17873 by @maykonmichel)

Changed

  • Providers with a login-warning auth rule show their account risk before a new login and start it only after the user answers yes; any other answer or a cancel stores nothing, and their login-list entry is marked "(at your own risk)" (#18499)

Fixed

  • Claude Fable launch resets now report the Fable weekly limit they clear instead of an unknown window (#18661 by @TheAifam5)

@oh-my-pi/pi-catalog

Added

  • Added Muse Ember (muse-ember-1.0) on Meta Model API and Muse Code with the minimal–max reasoning effort ladder and its >200K long-context pricing
  • Added the login-warning "<text>" auth rule, which makes a new login accept the stated account risk first (#18499)

Changed

  • Resumed Google Antigravity behind a login warning instead of pausing it (#18499)

Fixed

  • Morph (api.morphllm.com) requests now send x-session-id, keeping a conversation on the worker that holds its prompt cache (#18704 by @wolfiesch)

@oh-my-pi/pi-coding-agent

Added

  • /usage and omp usage show LiteLLM key and user budgets for the built-in litellm provider and every models.yml provider with discovery.type: litellm, unless listed in disabledProviders (#17873 by @maykonmichel)
  • Extensions can ask the operator before an interactive quit, or cancel it, with session_before_shutdown; a further /exit or Ctrl+D skips the pending prompts and closes (#18424 by @aw1cks)

Changed

  • Saved-reset auto-redeem is set per window: codexResets.autoRedeem5h/autoRedeemWeekly and claudeResets.autoRedeem5h/autoRedeemWeekly/autoRedeemFable replace each provider's autoRedeem, whose value migrates into the 5h and weekly keys; a Claude Fable launch reset is governed by autoRedeemFable alone and spent only for a block that includes the Fable weekly cap, or before expiry when Fable usage is above zero (#18661 by @TheAifam5)
  • Sessions without a prompt UI (such as omp -p) no longer spend saved resets while auto-redeem is unset, even ones about to expire (#18661)
  • Google Antigravity is back in /login and omp login, marked "(at your own risk)": a new login first explains that Google may suspend accounts that sign in from third-party tools and continues only after you type yes; saved Antigravity logins work again (#18499)
  • On Windows, the bash tool's description tells the model it runs in an emulated bash environment, not cmd or PowerShell, so it writes bash instead of dir, %VAR% and other cmd syntax

Fixed

  • Extension prompts shown from session_before_* handlers no longer time out after 30 seconds while the operator is still answering (#18424 by @aw1cks)
  • A second exit request now skips pending worktree.onExit prompts and keeps those worktrees instead of waiting for an answer (#18424 by @aw1cks)
  • Advice that makes the agent keep working after it finished no longer comes back a second time, often as a blocker, while the agent is fixing it: advisor reviews of the earlier answer are cancelled and the advisor reviews the fix instead (#18735 by @H4vC)
  • On Windows, the bash tool's shell resolves MSYS drive paths (/c/Users/..., /mnt/c/...) everywhere, so running /c/.../tool.exe, cd /c/..., [ -f /c/... ] and < /c/... reach drive C: like they already did for ls and other built-in utilities
  • On Windows, cmd-style command lines such as dir | find /c /v "", sort /r, timeout /t 5 and whoami /all in the bash tool run the Windows programs they were written for, instead of pi's GNU-style find/sort/timeout/whoami (which read /c as drive C: and could walk the whole drive)
  • Changing or unsetting PATH in the bash tool's shell now forgets remembered command locations, as bash does, so a command no longer runs from a directory that has left PATH
  • One slow or flooding collab guest no longer ends sharing for the room: the host drops that guest's backlog and asks it to rejoin, sessions larger than the send budget can be joined, and guest questions nobody received settle as unavailable (#18629 by @iliaal)

@oh-my-pi/pi-tui

Changed

  • grep and ast_grep results with no matches render as one line with 0 matches in the warning color, dropping the separate No matches found row (#18700 by @JustasMasiulis)

Fixed

  • Saved-reset messages name the Claude Fable weekly limit as "Claude Fable weekly" instead of its raw id (#18661 by @TheAifam5)

What's Changed

  • fix(shell): run cmd-syntax command lines through the Windows programs pi's utilities shadow by @H4vC in https://github.com/can1357/oh-my-pi/pull/18711
