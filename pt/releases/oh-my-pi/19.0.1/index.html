oh-meu-pi v19.0.1

@oh-my-pi/pi-ai

Corrigido

  • Corrigidas imagens GIF que falhavam nos julgamentos da Liquid AI com HTTP 422; eles agora são enviados como PNG (#19757 por @alphastorm)
  • O substituto de ferramenta estrita antrópica agora trata uma rejeição de política organizacional da Vertex de structured_outputs (allowedPartnerModelFeatures / "recurso não permitido saídas estruturadas") como uma rejeição de ferramentas estritas, tenta novamente uma vez sem strict e fixa strictToolsDisabled (#19576) (#19655 por @koeria)
  • Solicitações Kiro rejeitadas com Input is too long. ou CONTENT_LENGTH_EXCEEDS_THRESHOLD agora podem ser recuperadas por meio de compactação de conversa (#19723 por @emotionbug)
  • Kiro pensando agora desativa o raciocínio em vez de executar o esforço padrão do modelo; modelos que não podem desabilitar o raciocínio usam seu menor esforço (#19722 por @emotionbug)
  • Kiro /usage mostra os créditos complementares adquiridos, e uma conta cujos créditos do plano foram gastos continua sendo veiculada enquanto os créditos adicionais permanecem (#19724 por @emotionbug)
  • Os logins do Kiro Identity Center no AWS GovCloud (EUA) agora listam perfis em us-gov-west-1 e us-gov-east-1 em vez das regiões comerciais, que rejeitam tokens GovCloud (#19726 por @TechDufus)
  • Erros de gateway sem status ao ler stream interrupted agora tentam novamente como stream was interrupted em vez de encerrar o turno (#19709).

@oh-my-pi/browser-relay

Corrigido

  • A extensão de retransmissão do navegador sobrevive a um navegador cujo conjunto de permissões carregado é anterior à permissão downloads: o service worker continua trabalhando sem emparelhamento de download em vez de travar antes de se conectar (#19659 por @pavel-kalmykov)

@oh-my-pi/pi-catalog

Adicionado

  • Adicionados modelos de juiz d1.2 e d1.2-ultra da Liquid AI; liquid agora tem como padrão d1.2 (#19753 por @alphastorm)
  • Adicionado gemini-4-neon à lista de Antigravidade CLI, com os níveis de pensamento low/medium/high/xhigh que agy oferece para ele (#19787 por @ataberkus).
  • Model.snapcompactShape ({ variant, frameSize? }) dá ao modelo seu próprio formato de moldura snapcompact (#19591 por @ryanskidmore)

Corrigido

  • Os modelos Kiro descobertos que não conseguem desligar o raciocínio agora usam seu menor esforço suportado quando o pensamento está desligado (#19722 por @emotionbug)
  • Kiro aceita ARNs de perfil AWS GovCloud (EUA) (arn:aws-us-gov:codewhisperer:…), que foram ignorados anteriormente durante a listagem de perfis (#19726 por @TechDufus)
  • O Google Antigravity não lista mais o slot de monitor de sonar do Gemini 4 Hydrogen ou seus SKUs High/XHigh em camadas como modelos separados; os SKUs em camadas se dobram em um modelo Gemini 4 Hydrogen (#19795 por @eggpeat)
  • Gemini 4 Neon no Google Antigravity agora é exibido como um modelo cujo nível de pensamento (baixo, médio, alto, xalto) seleciona o SKU correspondente, em vez de quatro modelos separados, e custa US$ 3/US$ 15 por milhão de tokens ($0.15 em cache) em vez de US$ 0 (#19789 por @eggpeat)
  • Gemini 4 Neon agora se transforma em um modelo no Gemini CLI também, e no Gemini API e Vertex AI oferece alto nível de pensamento e saídas longas de até 262.144 tokens, com seu preço Gemini API de US$ 3/US$ 15

@oh-my-pi/pi-coding-agent

Adicionado

  • /session mostra o caminho do diretório local:// da sessão, e /copy local o copia, criando primeiro o diretório para que possa ser inserido antes de qualquer coisa ser escrita lá (#19778 por @farnoy)
  • snapcompactShape nos modelos models.yml, modelOverrides e modelos de extensão registerProvider definem o formato da moldura snapcompact desse modelo (#19591 por @ryanskidmore)

Corrigido

  • Correção de transcrições de comandos PTY que às vezes ganhavam uma linha em branco onde o final de uma linha \r\n era dividido em duas leituras de terminal.
  • Corrigido o dirname do shell integrado no Windows, ignorando os separadores \ e prefixos de unidade (dirname 'C:\a\b' impresso .), que quebrava scripts como o inicializador code do VS Code (./Code.exe: No such file or directory)
  • Corrigida a saída do bash que minimizava ser ignorada no Windows quando um comando é nomeado por um caminho \ ou com .exe ("C:\Program Files\Git\cmd\git.exe" status, git.exe log)
  • Corrigidos os documentos omp://tools incluídos que ainda descreviam a ferramenta ida removida; tools/dsm.md agora documenta o namespace dsm e as configurações disassembler.* do eval, e tools/read.md documenta leituras executáveis somente de metadados (#19608)
  • Corrigidos hosts de terminais nativos, como Tern, colocando a extensão acima dos widgets do Editor e uma linha em branco entre a linha de status e a bandeja; os widgets agora ficam acima da linha de status (#19767)
  • Corrigidas menções de ^model em mensagens enfileiradas (->/=> enquanto o agente está ocupado, itens posteriores de uma lista numerada, RPC steer/follow_up, direção ACP) atingindo o modelo como texto literal ^provider/model em vez de registrar seu agente m<N> (#19683 por @a-glapinski)
  • Corrigidas menções a ^model em mensagens de extensão enviadas com sendUserMessage({ deliverAs: "steer" | "followUp" | "aside" }) enquanto o agente está ocupado alcançando o modelo como texto literal (#19799 por @H4vC)
  • Corrigidas todas as mensagens enfileiradas atrás de uma menção ^model não entregue, repetindo o aviso "m<N> agora disponível" para o modelo (#19799 por @H4vC)
  • Um manifesto de plugin com uma entrada extensions sem string (por exemplo, um objeto) não trava mais o carregamento da extensão com ERR_INVALID_ARG_TYPE; a entrada é relatada como não encontrada e entradas válidas ainda são carregadas (#19674 por @koeria)
  • Correção do bash script.sh incorporado resolvendo BASH_SOURCE[0] para bash em vez do caminho do script, o que interrompeu o carregamento de arquivos de scripts fora de si (#19792)
  • Foi corrigida a descoberta do modelo de proxy ignorando as modalidades de entrada anunciadas de um gateway e o limite de token de saída (#19754 por @zhyc9de).
  • Corrigido um provedor roteado através de um gateway de autenticação (transport: pi-native em models.yml) ainda listando modelos do próprio endpoint do provedor, enviando a chave do gateway para lá; esses provedores agora ignoram a descoberta do modelo do provedor e mantêm seus modelos agrupados e em cache (#19646 por @ray8828)
  • Corrigido um marcador falso de "cache miss" no primeiro turno após uma compactação: a compactação reescreve o prefixo do prompt, de modo que a falha é esperada e não é mais sinalizada (#19679 por @Petyok)
  • Corrigido omp --resume <id> sob --mode rpc, --mode rpc-ui e --mode acp falhando na inicialização quando o diretório da sessão não existe mais; a sessão agora abre onde está armazenada, com o diretório de inicialização como seu diretório de trabalho, sem perguntar se deve movê-la (#19651 por @sjawhar)
  • Corrigida a extensão de retransmissão do navegador morrendo silenciosamente em um navegador cujo conjunto de permissões carregado é anterior à permissão downloads: agora ela continua funcionando sem emparelhamento de download, e o retransmissor relata uma lacuna de rastreamento de download em vez de um genérico não encontrado (#19659 por @pavel-kalmykov)
  • O compartilhamento de uma sessão cujos subagentes relatam progresso mais rápido do que o esgotamento do uplink não termina mais com "o backlog de envio de colaboração excedeu seu limite" enquanto um convidado ingressa
  • Corrigidas iterações /loop e continuações /goal disparando ~800ms após um turno render para esperar em subagentes ou jobs em segundo plano; eles agora esperam até que a execução termine (#19781)
  • Corrigida pesquisa na web Codex e OpenAI API ignorando o nível de pensamento do papel web (openai-codex/gpt-6-luna:xhigh); o nível agora atinge a solicitação como reasoning.effort (#19793)
  • Foi corrigida a medição da revisão do plano "Aprovar e manter o contexto" em relação ao modelo pré-plano em vez do nível escolhido no controle deslizante "continuar com", portanto, mudar para um nível de contexto maior agora permite isso (#19660)

oh-my-pi v19.0.1

@oh-my-pi/pi-ai

Fixed

  • Fixed GIF images failing Liquid AI judgments with HTTP 422; they are now sent as PNG (#19757 by @alphastorm)
  • Anthropic strict-tool fallback now treats a Vertex org-policy rejection of structured_outputs (allowedPartnerModelFeatures / "disallowed feature structured_outputs") as a strict-tools rejection, retries once without strict, and pins strictToolsDisabled (#19576) (#19655 by @koeria)
  • Kiro requests rejected with Input is too long. or CONTENT_LENGTH_EXCEEDS_THRESHOLD can now recover through conversation compaction (#19723 by @emotionbug)
  • Kiro thinking off now turns reasoning off instead of running the model's default effort; models that cannot disable reasoning use their lowest effort (#19722 by @emotionbug)
  • Kiro /usage shows purchased add-on credits, and an account whose plan credits are spent keeps serving while add-on credits remain (#19724 by @emotionbug)
  • Kiro Identity Center logins in AWS GovCloud (US) now list profiles in us-gov-west-1 and us-gov-east-1 instead of the commercial regions, which reject GovCloud tokens (#19726 by @TechDufus)
  • Statusless gateway errors reading stream interrupted now retry like stream was interrupted instead of ending the turn (#19709).

@oh-my-pi/browser-relay

Fixed

  • The browser relay extension survives a browser whose loaded permission set predates the downloads permission: the service worker keeps working without download pairing instead of crashing before it ever connects (#19659 by @pavel-kalmykov)

@oh-my-pi/pi-catalog

Added

  • Added Liquid AI's d1.2 and d1.2-ultra judge models; liquid now defaults to d1.2 (#19753 by @alphastorm)
  • Added gemini-4-neon to the bundled Antigravity CLI roster, with the low/medium/high/xhigh thought levels agy offers for it (#19787 by @ataberkus).
  • Model.snapcompactShape ({ variant, frameSize? }) gives a model its own snapcompact frame shape (#19591 by @ryanskidmore)

Fixed

  • Discovered Kiro models that cannot turn reasoning off now use their lowest supported effort when thinking is set to off (#19722 by @emotionbug)
  • Kiro accepts AWS GovCloud (US) profile ARNs (arn:aws-us-gov:codewhisperer:…), which were previously skipped during profile listing (#19726 by @TechDufus)
  • Google Antigravity no longer lists Gemini 4 Hydrogen's sonar monitor slot or its tiered High/XHigh SKUs as separate models; the tiered SKUs fold into the one Gemini 4 Hydrogen model (#19795 by @eggpeat)
  • Gemini 4 Neon on Google Antigravity now shows as one model whose thinking level (low, medium, high, xhigh) selects the matching SKU, instead of four separate models, and is priced at $3/$15 per million tokens ($0.15 cached) instead of $0 (#19789 by @eggpeat)
  • Gemini 4 Neon now collapses into one model on Gemini CLI too, and on the Gemini API and Vertex AI offers the xhigh thinking level and long outputs up to 262,144 tokens, with its $3/$15 Gemini API price

@oh-my-pi/pi-coding-agent

Added

  • /session shows the path of the session's local:// directory, and /copy local copies it, creating the directory first so it can be entered before anything was written there (#19778 by @farnoy)
  • snapcompactShape on models.yml models, modelOverrides and extension registerProvider models sets that model's snapcompact frame shape (#19591 by @ryanskidmore)

Fixed

  • Fixed PTY command transcripts sometimes gaining a blank line where a \r\n line ending was split across two terminal reads.
  • Fixed the shell's dirname builtin on Windows ignoring \ separators and drive prefixes (dirname 'C:\a\b' printed .), which broke scripts like VS Code's code launcher (./Code.exe: No such file or directory)
  • Fixed bash output minimizing being skipped on Windows when a command is named by a \ path or with .exe ("C:\Program Files\Git\cmd\git.exe" status, git.exe log)
  • Fixed the bundled omp://tools docs still describing the removed ida tool; tools/dsm.md now documents eval's dsm namespace and disassembler.* settings, and tools/read.md documents metadata-only executable reads (#19608)
  • Fixed native terminal hosts such as Tern placing extension aboveEditor widgets and a blank row between the status row and the tray; the widgets now sit above the status row (#19767)
  • Fixed ^model mentions in queued messages (->/=> while the agent is busy, later items of a numbered list, RPC steer/follow_up, ACP steering) reaching the model as literal ^provider/model text instead of registering their m<N> agent (#19683 by @a-glapinski)
  • Fixed ^model mentions in extension messages sent with sendUserMessage({ deliverAs: "steer" | "followUp" | "aside" }) while the agent is busy reaching the model as literal text (#19799 by @H4vC)
  • Fixed every message queued behind an undelivered ^model mention repeating the "m<N> now available" notice to the model (#19799 by @H4vC)
  • A plugin manifest with a non-string extensions entry (e.g. an object) no longer crashes extension loading with ERR_INVALID_ARG_TYPE; the entry is reported as not found and valid entries still load (#19674 by @koeria)
  • Fixed embedded bash script.sh resolving BASH_SOURCE[0] to bash instead of the script path, which broke scripts loading files beside themselves (#19792)
  • Fixed proxy model discovery ignoring a gateway's advertised input modalities and output-token cap (#19754 by @zhyc9de).
  • Fixed a provider routed through an auth gateway (transport: pi-native in models.yml) still listing models from the provider's own endpoint, sending the gateway key there; such providers now skip the provider's model discovery and keep their bundled and cached models (#19646 by @ray8828)
  • Fixed a spurious "cache miss" marker on the first turn after a compaction: compaction rewrites the prompt prefix, so that miss is expected and no longer flagged (#19679 by @Petyok)
  • Fixed omp --resume <id> under --mode rpc, --mode rpc-ui and --mode acp failing at start when the session's directory no longer exists; the session now opens where it is stored, with the launch directory as its working directory, without asking whether to move it (#19651 by @sjawhar)
  • Fixed the browser relay extension dying silently in a browser whose loaded permission set predates the downloads permission: it now keeps working without download pairing, and the relay reports a download tracking gap instead of a generic not-found (#19659 by @pavel-kalmykov)
  • Sharing a session whose subagents report progress faster than the uplink drains no longer ends with "collab send backlog exceeded its limit" while a guest joins
  • Fixed /loop iterations and /goal continuations firing ~800ms after a turn yields to wait on background subagents or jobs; they now wait until the run finishes (#19781)
  • Fixed Codex and OpenAI API web search ignoring the web role's thinking level (openai-codex/gpt-6-luna:xhigh); the level now reaches the request as reasoning.effort (#19793)
  • Fixed plan review measuring "Approve and keep context" against the pre-plan model instead of the tier chosen in the "continue with" slider, so switching to a larger-context tier now enables it (#19660)

@oh-my-pi/pi-natives

Fixed

  • Fixed omp freezing for seconds to minutes on WSL2 while saving sessions: Linux FileLock now locks a sidecar file instead of binding a socket, which takes about 10 ms per call there. Older omp versions still running do not see these locks, so restart them after updating (#19704 by @turgaybulut)

@oh-my-pi/snapcompact

Added

  • resolveShape() uses a model's configured snapcompactShape in place of its model-line default; an explicit variant still wins and billing still follows the model (#19591 by @ryanskidmore)

@oh-my-pi/omp-stats

Added

  • Added 2d and 3d range presets with hourly buckets to the stats dashboard time selector (#19766, #19774 by @thekitaev).

@oh-my-pi/pi-tui

Added
