WeKnora v0.6.3

Highlights

  • MCP services reach production readiness — OAuth2 authorization (#1762), code import (#1763), and custom headers (#1764) land alongside a dedicated MCP config section (#1749). This removes the main blocker for wiring WeKnora agents into auth-protected tool servers and lets you inject secrets/headers per service. Existing configs keep working, but any server requiring OAuth2 now needs credential setup before it can be used as an agent tool.
  • Agents become embeddable — #1673 adds iframe/floating-widget embedding so agents can be dropped into third-party sites, and #1821 makes the channel key always available via the detail API. This opens a new distribution surface beyond the built-in chat UI; treat the channel key as intentionally public for embed clients and scope it accordingly.
  • Embedding dimension handling is hardened — #1686 adds a dimension override, #1654 fixes dimensions being omitted from embedding API requests, and #1575 improves Tencent VectorDB collection compatibility. These directly affect model swaps and collection reuse: mismatched dimensions cause insert failures, so verify your collection dimension against the chosen model before upgrading, and re-create collections if you were relying on the previously broken request payload.
  • Ingestion gets broader and cheaper — EPUB and MHTML support arrives in #1695 and is restored in #1714; #1808 forces OCR on scanned PDF pages; #1700 carries deep sub-heading context into large chunks; #1755 normalizes PaddleOCR-VL HTML tables to cut token waste and chunk fragmentation; #1705 front-loads static rules in the chunk-citation prompt for prefix caching. Widens usable corpus coverage and reduces embedding/LLM cost, but existing documents must be reparsed to benefit (batch repair tooling in #1815/#1818 helps).
  • Agent observability and control improve — Langfuse tracing, rerank thresholds, and tool-persist trimming (#1692), a model-readiness gate (#1813), reasoning shown in the RAG timeline (#1773), and RAG progress events (#1691) make agent runs traceable and debuggable end-to-end. Note a behavioral change: #1772 removes the RunnableByViewer gate that previously blocked viewer-role chat, so viewer permissions are now effectively broader — audit your role policies.
  • APIs, connectors, and lifecycle hygiene — hybrid-search gains POST while retaining GET compatibility (#1754), an RSS connector with full-text ingestion is added (#1769), Tencent VectorDB replicas become env-configurable (#1759), workspace deletion purges memberships (#1706/#1718), model deletion is blocked while referenced by a KB or agent (#1774), and logout clears cached session resources (#1685). Mostly backwards-compatible expansion with safer multi-tenant teardown and fewer stale references; the only API change preserves the old GET path.

No breaking changes in v0.6.3.
