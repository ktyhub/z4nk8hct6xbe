WeKnora v0.7.1

Highlights

  • Tracing moves to OTLP/OTel — Langfuse now uses the OTLP/OTel wire protocol (#2099), with finish metadata merged and root spans exported automatically (#2111). Update observability configuration and verify collector ingestion, especially for corrected graph and multimodal traces (#2190).
  • Neo4j conversation memory is removed — This is the main breaking change (#2130). Deployments relying on Neo4j-backed memory must revise affected workflows before upgrading; the changelog does not document a drop-in replacement.
  • API keys gain safer control-plane scoping — Platform-scoped keys (#2165), scoped file-serving and ingest routes (#2154), and prevention of owner-role assignment through API keys (#2225) require automation credentials to be reviewed and rescoped. Source-file downloads are also restricted to Editor and above (#2250).
  • Reranking and retrieval behavior changes — Volcengine reranking now batches requests that exceed API document limits (#2147, #2155). vLLM calls stop sending truncate_prompt_tokens by default (#2160), so verify backend-side truncation and context limits. Stabilized top-k ordering (#2091) may also change exact result sequences in regression tests.
  • Knowledge-base lifecycle fixes reduce stale data — Ingest timeouts no longer leave pending tasks (#2106), deleted knowledge bases have queued work removed without depending on request context (#2202, #2215), and asynchronous deletion no longer leaves visible zombie rows (#2195). Clone/export fixes also preserve chunk and parent-text image URLs (#2183, #2188, #2191).
  • Self-hosted deployments need configuration checks — Compose environment variables now match the code and a Helm GraphRAG bug is fixed (#2164), so reconcile deployment manifests with current examples. PDF rendering parallelism now follows CPU-aware defaults (#2168), while embedding/model clients and Doris Stream Load share SSRF-safe HTTP transports (#2201, #2213, #2276); revalidate custom internal endpoints accordingly.
