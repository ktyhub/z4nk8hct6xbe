WeKnora v0.3.6

Highlights

  • OIDC authentication — Adds opt-in OIDC login for providers such as Dex and Keycloak while preserving email/password authentication (#833). The callback payload now contains only success, message, token, and refresh_token; custom login integrations must fetch user and tenant details from /api/v1/auth/me instead (#871). This prevents oversized redirect headers for users with many tenants.

  • Feishu-backed data sources — Introduces knowledge-base-scoped datasource management with Feishu sync, manual and cron scheduling, async jobs, sync logs, and ownership enforcement (#846). Apply migration 000028_datasource_tables before rollout and ensure the scheduler and task queue are healthy; cross-knowledge-base access and unauthorized reassignment are now rejected.

  • Faster, more resilient agents — Opt-in AgentConfig.ParallelToolCalls executes independent tool calls concurrently, preserves result ordering, and collects partial failures without cancelling sibling calls (#835). Enable it only for stateless tools. MCP tool calls and tool discovery also gain automatic reconnection after transient failures (#851).

  • Richer multimodal ingestion — Adds ASR models and audio parsing plus audio previews (#894, #899), resolves remote images during uploads (#843), extracts document metadata (#866), and preserves Markdown table headers across chunks (#863). Use the new DOCX max-pages environment setting to bound expensive parsing jobs (#884); knowledge deletion now also cleans up extracted images (#880).

  • Search, networking, and retrieval fixes — Adds configurable Tavily alongside provider management UI (#849, #858), system-proxy support for remote APIs (#836), and IPv6-aware SSRF validation (#856, #859). S3 schemes are accepted by frontend/backend allowlists (#845), storage-provider settings now persist correctly (#869), and Elasticsearch ID queries use dynamically detected keyword suffixes (#874, #889).

  • Breaking changes — None.
