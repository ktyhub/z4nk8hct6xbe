unsloth v0.1.915-beta

Pré-lançamento Publicado4 de nov. de 2026 Fonteunslothai/unsloth Original em inglês

Esta página é traduzida automaticamente. O texto original em inglês é a referência.

indolente v0.1.915-beta

Esta versão apresenta o Qwen3.8-Flash-Next Dynamic V3.1, aprimora os temas do Glass (agora em Beta), adiciona um controle deslizante de posição do Composer e permite que os modelos interajam com os arquivos no navegador integrado. Ele também traz menor uso de memória ociosa, contexto de bate-papo preservado ao trocar de modelo GGUF, carregamento mais rápido do MLX e treinamento FP8 LoRA.

Destaques

  • Qwen3.8-Flash-Next Dinâmico V3.1 - 10-15% de precisão extra Guia
  • Melhorias no tema Glass em páginas, menus, barra lateral e navegador
  • A interação com arquivos do navegador permite que os modelos click leiam e editem HTML, arquivos e páginas
  • ** Menor memória ociosa ** com carregamento e recarregamento mais rápido do MLX
  • Contexto de bate-papo preservado ao alternar entre modelos GGUF
  • Treinamento LoRA FP8 com menor uso de memória GPU
  • Controle deslizante Posição do compositor para colocar a caixa de bate-papo em qualquer lugar em novos bate-papos

Vidro e aparência

  • Defina a posição da caixa de bate-papo, de cima para baixo, em Configurações > Aparência > Compositor.
  • Os temas de vidro agora têm realces mais suaves, sombras mais claras e efeitos foscos aprimorados em menus, painéis e no navegador.
  • Páginas como Biblioteca, Imagens e Trem não desfocam mais as imagens de fundo.
  • Conversas abertas agora escurecem levemente o fundo e usam vidro mais denso para o compositor.
  • As barras de título do Windows e Linux combinam melhor com os temas e imagens de fundo do Glass.
  • As alterações nas configurações feitas em uma guia do navegador agora são sincronizadas com outras guias abertas.

Navegador integrado

  • Com o Uso do navegador ativado, os modelos podem click e digitar páginas HTML e React criadas no chat.
  • Os modelos podem ler e editar arquivos HTML, React, Markdown, código e texto diretamente no navegador. Voltar restaura a versão anterior.
  • Os modelos também podem ler PDFs e outros documentos abertos no navegador.
  • Os prompts de download podem lembrar as permissões por site ou em todos os sites, inclusive para arquivos de programas.

Bate-papo

  • Os chats agora mostram atividade entre chamadas de ferramentas, incluindo compactação de contexto em modelos GGUF.
  • Anexe arquivos salvos da biblioteca usando + > Mais > Anexar da biblioteca.
  • Sair do modelo GGUF e voltar agora preserva o contexto do chat, evitando a necessidade de reler longos históricos.
  • Os modelos GGUF podem ler até quatro páginas da web ao mesmo tempo quando as ferramentas são executadas sem solicitação.

Conexões e API

  • Os modelos OpenRouter agora carregam ao vivo, com suporte funcional para modelos de recarga.
  • Melhor compatibilidade com servidores MCP mais recentes.
  • A Decisão API adiciona os modelos d1 e Decider 2B da LiquidAI (somente MLX).
  • Configurações > API > Início rápido agora inclui exemplos de curl, Python e JavaScript.

Desempenho e mídia

  • Unsloth não carrega mais PyTorch e outras bibliotecas de ML na inicialização, reduzindo significativamente o uso de memória ociosa. Configure os recursos de inicialização em Configurações > Geral > Desempenho de inicialização.
  • Os modelos MLX carregam e recarregam muito mais rápido, e reduzir o contexto de um modelo carregado agora leva segundos.
  • Prompts longos em modelos MLX suportados usam menos memória.
  • SDXL renderiza mais rápido com VRAM muito limitado, incluindo configurações de 4 GB.
  • Imagens LoRAs nas pastas do seu modelo agora aparecem na página Imagens.

Treinamento

  • Treinamento LoRA mais rápido e com menos memória em bases de 16 bits com GPUs NVIDIA recentes usando float8_training = "fp8_lora".
  • O treinamento DPO, ORPO, KTO, GRPO e CPO agora é executado no MLX.
  • Corrigidas falhas durante o ajuste completo do Gemma 4 em float16.

unsloth v0.1.915-beta

This release introduces Qwen3.8-Flash-Next Dynamic V3.1, polishes the Glass themes (now in Beta), adds a Composer position slider and lets models interact with files in the built-in browser. It also brings lower idle memory usage, preserved chat context when switching GGUF models, faster MLX loading and FP8 LoRA training.

Highlights

  • Qwen3.8-Flash-Next Dynamic V3.1 - 10-15% extra accuracy Guide
  • Glass theme improvements across pages, menus, the sidebar and browser
  • Browser file interaction lets models click, read and edit HTML, files and pages
  • Lower idle memory with faster MLX loading and reloading
  • Preserved chat context when switching between GGUF models
  • FP8 LoRA training with lower GPU memory usage
  • Composer position slider to place the chat box anywhere on new chats

Glass and appearance

  • Set the chat box position, from top to bottom, in Settings > Appearance > Composer.
  • Glass themes now have softer highlights, lighter shadows and improved frosted effects across menus, panels and the browser.
  • Pages like Library, Images and Train no longer heavily blur background images.
  • Open conversations now slightly dim the background and use denser glass for the composer.
  • Windows and Linux title bars better match Glass themes and background images.
  • Settings changes made in one browser tab now sync across other open tabs.

Built-in browser

  • With Browser use enabled, models can click and type in HTML and React pages created in chat.
  • Models can read and edit HTML, React, Markdown, code and text files directly in the browser. Back restores the previous version.
  • Models can also read PDFs and other documents open in the browser.
  • Download prompts can remember permissions per site or across all sites, including for program files.

Chat

  • Chats now show activity between tool calls, including context compaction on GGUF models.
  • Attach saved Library files using + > More > Attach from Library.
  • Switching away from a GGUF model and back now preserves chat context, avoiding the need to re-read long histories.
  • GGUF models can read up to four web pages at once when tools run without asking.

Connections and API

  • OpenRouter models now load live, with working Reload models support.
  • Improved compatibility with newer MCP servers.
  • The Decision API adds LiquidAI's d1 models and Decider 2B (MLX only).
  • Settings > API > Quickstart now includes curl, Python and JavaScript examples.

Performance and media

  • Unsloth no longer loads PyTorch and other ML libraries at startup, significantly reducing idle memory usage. Configure startup features in Settings > General > Startup performance.
  • MLX models load and reload much faster, and reducing a loaded model's context now takes seconds.
  • Long prompts on supported MLX models use less memory.
  • SDXL renders faster with very limited VRAM, including 4 GB setups.
  • Image LoRAs in your model folders now appear on the Images page.

Training

  • Faster, lower-memory LoRA training on 16-bit bases with recent NVIDIA GPUs using float8_training = "fp8_lora".
  • DPO, ORPO, KTO, GRPO and CPO training now run on MLX.
  • Fixed crashes when full fine-tuning Gemma 4 in float16.
