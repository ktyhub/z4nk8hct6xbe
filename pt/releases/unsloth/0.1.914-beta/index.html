indolente v0.1.914-beta

Unsloth agora tem temas Glass e mais opções de personalização para planos de fundo, saudações e bate-papos. Esta versão também traz geração mais rápida, mais opções de treinamento multi-GPU e treinamento de CPU no Unsloth.

<img width="800" alt="unsloth glass theme" src="https://github.com/user-attachments/assets/bc38677f-9e49-4b46-b0ac-f16522541a57" />

Destaques

  • Novos temas do Glass com 5 temas, transparência + vidro nativo do macOS
  • Personalização com saudações personalizadas, controles de fundo e fontes de código
  • Os benchmarks de contexto DeepSeek-V4.1 512K mostram que os GGUFs da Unsloth têm a classificação mais forte no Terminal Bench, DeepSWE e AutomationBench. Análise
  • Navegação no bate-papo para visualizar, marcar como favorito e alternar entre os turnos anteriores
  • Treinamento de texto da CPU diretamente da página Train

Faça o seu

  • Escolha entre cinco estilos de vidro com resistência ajustável e menus de vidro opcionais, com ou sem imagem de fundo.
  • Unsloth Desktop no Mac suporta vidro nativo, permitindo que sua área de trabalho apareça pela janela.
  • Ajuste o tamanho e a posição do plano de fundo e escolha onde ele aparece nos seus bate-papos.
  • Adicione sua própria saudação com texto, ícone ou imagem, ou oculte-a totalmente.
  • Personalize fontes de código, números de linha, quebra automática de palavras e ligaduras com uma visualização ao vivo.
  • Use o tema Doces ou Travessuras o ano todo, sem os extras sazonais.

Bate-papo

  • Visualize mensagens anteriores, marque turnos e salte por longas conversas com o novo navegador de bate-papo.
  • Cole conteúdo formatado como Markdown, incluindo links, listas e tabelas de planilhas.
  • As mensagens em árabe, persa, hebraico e urdu são exibidas da direita para a esquerda, enquanto o código mantém sua direção original.
  • Bate-papos longos permanecem mais responsivos enquanto as respostas são transmitidas e você rola.
  • As conexões MCP são recuperadas após a reinicialização do servidor.
  • Os agentes de codificação podem seguir instruções dos arquivos na pasta de trabalho do seu projeto.

Desempenho e mídia

  • Os modelos Llama e Qwen3 de GPU único suportados são gerados mais rapidamente no back-end Transformers da Unsloth em GPUs NVIDIA com Linux ou WSL. Em nosso teste A100, o Qwen3-8B de 4 bits atingiu tokens/s 99.1, acima do 25.7, uma aceleração de 3,9x.
  • SDXL agora renderiza com um orçamento de VRAM de 4 GiB, testado em GPUs T4 e L4.
  • Pesquise grandes coleções de documentos com mais rapidez com um novo índice para RAG.
  • Salve as imagens geradas como PNG mais rapidamente, sem alterar a saída.
  • Os modelos de vídeo reutilizam pesos INT8 armazenados em cache para cargas repetidas mais rápidas.
  • Wan2.2 A14B usa menos memória do sistema ao construir pesos INT8 para geração descarregada.
  • Ajuste os pontos fortes da imagem LoRA sem recarregar os arquivos do adaptador.
  • Transcreva áudio de até quatro horas com audio.cpp, sujeito a limites de upload e armazenamento.

##Mac

  • Experimente o Fast Verify experimental para geração mais rápida com modelos de decodificação especulativa MLX suportados. As respostas podem diferir ligeiramente.
  • O streaming MLX gasta menos tempo processando texto à medida que as respostas aumentam.
  • Unsloth agora usa a fonte do sistema Mac por padrão.

Treinamento

  • Ajuste modelos de texto na CPU na página Train quando nenhuma GPU estiver disponível.
  • Instalações somente por chat podem adicionar treinamento de CPU por meio de Treinamento de instalação.
  • Ajuste fino de modelos de audiovisão, como Gemma 3n e Gemma 4, usando áudio e imagens juntos no mesmo conjunto de dados.
  • Carregue modelos não quantizados suportados maiores que uma única GPU, carregando apenas as camadas de pipeline atribuídas a cada GPU.
  • Configure combinações suportadas de dados, tensor, pipeline e paralelismo de contexto com UNSLOTH_PARALLEL.
  • Reduza a memória de ativação MLP durante o treinamento com unsloth.tile_mlp(model).
  • Envie imagens para modelos de visão através de chat CLI e comandos de inferência.

unsloth v0.1.914-beta

Unsloth now has Glass themes and more customization options for backgrounds, greetings and chats. This release also brings faster generation, more multi-GPU training options and CPU training in Unsloth.

<img width="800" alt="unsloth glass theme" src="https://github.com/user-attachments/assets/bc38677f-9e49-4b46-b0ac-f16522541a57" />

Highlights

  • New Glass themes with 5 themes, transparency + native macOS glass
  • Customization with custom greetings, background controls and code fonts
  • DeepSeek-V4.1 512K context benchmarks show Unsloth's GGUFs rank strongest across Terminal Bench, DeepSWE and AutomationBench. Analysis
  • Chat navigation to preview, bookmark and jump between earlier turns
  • CPU text training directly from the Train page

Make it yours

  • Choose from five Glass styles with adjustable strength and optional glass menus, with or without a background image.
  • Unsloth Desktop on Mac supports native glass, letting your desktop show through the window.
  • Adjust background size and position, and choose where it appears across your chats.
  • Add your own greeting with text, an icon or an image, or hide it entirely.
  • Customize code fonts, line numbers, word wrapping and ligatures with a live preview.
  • Use the Trick or Treat theme year-round without the seasonal extras.

Chat

  • Preview earlier messages, bookmark turns and jump through long conversations with the new chat navigator.
  • Paste formatted content as Markdown, including links, lists and spreadsheet tables.
  • Arabic, Persian, Hebrew and Urdu messages display right to left while code keeps its original direction.
  • Long chats stay more responsive while replies stream and you scroll.
  • MCP connections recover after a server restart.
  • Coding agents can follow instructions from files in your project's working folder.

Performance and media

  • Supported single-GPU Llama and Qwen3 models generate faster in Unsloth's Transformers backend on NVIDIA GPUs with Linux or WSL. In our A100 test, 4-bit Qwen3-8B reached 99.1 tokens/s, up from 25.7, a 3.9x speedup.
  • SDXL now renders under a 4 GiB VRAM budget, tested on T4 and L4 GPUs.
  • Search large document collections faster with a new index for RAG.
  • Save generated images as PNG faster without changing the output.
  • Video models reuse cached INT8 weights for faster repeat loads.
  • Wan2.2 A14B uses less system memory when building INT8 weights for offloaded generation.
  • Adjust image LoRA strengths without reloading adapter files.
  • Transcribe audio up to four hours long with audio.cpp, subject to upload and storage limits.

Mac

  • Try experimental Fast Verify for faster generation with supported MLX speculative decoding models. Replies may differ slightly.
  • MLX streaming spends less time processing text as replies grow.
  • Unsloth now uses the Mac system font by default.

Training

  • Fine-tune text models on CPU from the Train page when no GPU is available.
  • Chat-only installs can add CPU training through Install Training.
  • Fine-tune audio vision models such as Gemma 3n and Gemma 4 using audio and images together in the same dataset.
  • Load supported non-quantized models larger than a single GPU by loading only each GPU's assigned pipeline layers.
  • Configure supported combinations of data, tensor, pipeline and context parallelism with UNSLOTH_PARALLEL.
  • Reduce MLP activation memory during training with unsloth.tile_mlp(model).
  • Send images to vision models through CLI chat and inference commands.
