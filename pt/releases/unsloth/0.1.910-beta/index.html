indolente v0.1.910-beta

Flint da Recursive, MOSS-Image e Nemotron Bolt 4B da NVIDIA estão aqui! Execute-os localmente no Unsloth. Também novo: uma instalação Unsloth Desktop somente para bate-papo, modelos MLX MoE maiores que a memória do seu Mac e um API de ajuste fino compatível com OpenAI.

Destaques

  • Modelos MoE maiores no Mac: Os modelos MLX MoE grandes demais para a memória mantêm os especialistas no SSD, então o Qwen3.8-Flash-Next é executado em um Mac de 32 GB.
  • Instalação somente para bate-papo: um Unsloth Desktop muito menor para bate-papo GGUF; adicione treinamento posteriormente em Configurações.
  • Flint: MoE do agente de codificação 40B da Recursive, roda em 24 GB a 3 bits Guia
  • MOSS-Image: modelo de imagem 5.1B projetado para geração de nível superior GGUF + FP8
  • NVIDIA Nemotron 3.5 Bolt E4B: novo ajuste fino do Gemma 4 E4B da NVIDIA, 63.2 no Tau2-Bench versus o 38.7 do original [Guia] (https://unsloth.ai/docs/models/nemotron-3.5-bolt)
  • Remoção de especialistas do MoE: exporte um modelo de MoE menor removendo 25% ou 50% de seus especialistas menos úteis com REAP.
  • Revisão da UI: UI nova e mais consistente em Unsloth (API, redondeza, etc.)

Imagens + vídeo

  • Gere imagens contendo texto em inglês ou chinês com 5.1B MOSS-Image, SFT ou Base do OpenMOSS. GGUF · Base GGUF
  • MOSS-Image, o novo modelo de imagem, roda em GPUs de 16 GB; seus GGUFs também funcionam em Macs e computadores sem GPU compatível.
  • A maioria dos modelos de imagem e vídeo grandes demais para uma GPU agora são divididos entre suas GPUs NVIDIA, se couberem, em vez de transmitir da memória do sistema.
  • Os novos Hires corrigem upscales e refinam uma renderização em uma única etapa em SDXL, FLUX.1, Qwen-Image e Z-Image.
  • A nova grade Compare renderiza um prompt enquanto varia até três configurações, como seed, CFG ou peso LoRA, em grades rotuladas.
  • Os safetensors SDXL obtêm ponderação de prompt no estilo AUTOMATIC1111, salto CLIP, redimensionamento CFG, sementes de variação e inversão textual.
  • Os blocos de parâmetros AUTOMATIC1111, Forge ou Civitai colados preenchem as configurações da página Imagens.
  • Se o SAM 3 ainda não tiver sido baixado, a ferramenta Máscara de texto agora usa o SAM 3.1: menor, sem login do Hugging Face.

Bate-papo + Área de trabalho

  • Escolha Somente bate-papo (GGUF) ao iniciar o Unsloth Desktop pela primeira vez para uma instalação muito menor; adicione treinamento posteriormente em Configurações.
  • Configurações> Bate-papo agora permite visualizar, editar, limpar ou desligar as notas de memória que o Unsloth envia para cada bate-papo.
  • Em bate-papos de pesquisa de documentos, Mostrar passagens lista o texto exato que o modelo obteve e abre cada passagem em sua página.
  • A página de áudio pode falar e transcrever por meio de uma conexão API salva, como OpenAI ou um servidor local.
  • Instalações, atualizações e pip install -U unsloth do Unsloth agora rejeitam os certificados emSign comprometidos do eMudhra, que permitem que invasores se façam passar por sites. Os motores opcionais vLLM e SGLang ainda os trust.

Pederneira

  • Executar o Flint do Recursive, um modelo MoE 40B com parâmetros ativos de 2,5B para agentes de codificação, com raciocínio, uso de ferramentas e contexto de 256K. Guia · GGUF
  • Em 3 bits, Flint cabe em 24 GB em contextos curtos.
  • No SWE-bench Pro v2, Flint pontua 89.7 contra 73.8 de Qwen 3.6.

NVIDIA Nemotron 3.5 Parafuso E4B

  • Execute e ajuste o Gemma Nemotron 4B da NVIDIA, um ajuste de raciocínio Gemma 4 E4B para chamada de ferramentas e acompanhamento de instruções.
  • Gemma Nemotron 4B vence Gemma 4 E4B em 16 dos 21 testes da NVIDIA, ganhando mais em uso de ferramentas e bate-papo multivoltas.
  • DPO no Gemma 4 E2B e E4B, incluindo Gemma Nemotron 4B, não trava mais.

Treinamento

  • O ajuste fino dos modelos de fala Whisper, Canary, Moonshine, Dia e CTC com FastModel não falha mais.
  • O treinamento de fala de Periquito, Canário e CTC usa até 55% menos memória.
  • A nova receita de Livros e Documentos para Texto em Receitas de Dados transforma e-books e documentos em um conjunto de dados de texto de pré-treinamento, sem necessidade de modelo.
  • No Windows e no Linux, a página Exportar agora pode eliminar 25% ou 50% dos especialistas menos úteis de um modelo de MoE com REAP, com algum custo de qualidade.
  • No Python, o reap_prune executa a poda especializada REAP até 54x mais rápido que o compressor llm.
  • unsloth train agora treina visão e, exceto no Mac, modelos de áudio.
  • Unsloth agora suporta o ajuste fino API da OpenAI, então o SDK da OpenAI pode fazer upload de conjuntos de dados e executar o ajuste fino supervisionado de modelos locais.

Desempenho

  • Modelos MLX MoE grandes demais para o seu Mac mantêm especialistas em SSD, com respostas mais lentas. Qwen3.8-Flash-Next cabe em um Mac de 32 GB; DeepSeek-V4-Flash e GLM-5.3-Flash precisam de muito menos memória do que seu tamanho.
  • DPO e outros treinamentos que preenchem sequências são executados até 3,8x mais rápido com menos memória no NVIDIA Ampere ou mais recente.
  • O treinamento Qwen3-MoE, Gemma 3 e Gemma 4 em GPUs sem bf16 agora usa até 7x menos memória de atenção com a tocha 2.13 ou anterior.

Agentes de codificação + API

  • No chat, os modelos agora podem ler arquivos de texto e documentos em servidores MCP conectados, e não apenas usar suas ferramentas.
  • Ao iniciar agentes de codificação, unsloth start não envia mais sua chave Unsloth API em texto simples através de seu proxy HTTP para um Unsloth local.
  • No Windows, o unsloth start não quebra mais os ganchos do Claude Code ou o login do Codex ao iniciá-los.
  • Solicitações com uma chave Unsloth API não podem mais executar Python e ferramentas de terminal sem sandbox; apenas a UI do Unsloth pode permitir isso.
  • O novo botão Salvar para este modelo nas configurações de bate-papo torna as configurações de amostragem desse modelo o padrão para novos bate-papos e solicitações API.

Modelos + hardware

  • Um ponto de verificação BF16 gpt-oss carregado com load_in_4bit = True não recebe mais pesos aleatórios de especialistas e roteadores.
  • O seletor de modelo novamente permite executar modelos em Ryzen AI série 300 e NPUs mais recentes, sem variável de ambiente.
  • Em alguns PCs Linux AMD com ROCm para todo o sistema, os GGUFs que rodavam na CPU agora rodam na GPU novamente.

unsloth v0.1.910-beta

Recursive's Flint, MOSS-Image and NVIDIA's Nemotron Bolt 4B are here! Run them locally in Unsloth. Also new: a chat-only Unsloth Desktop install, MLX MoE models bigger than your Mac's memory and an OpenAI-compatible fine-tuning API.

Highlights

  • Bigger MoE models on Mac: MLX MoE models too big for memory keep experts on SSD, so Qwen3.8-Flash-Next runs on a 32 GB Mac.
  • Chat-only install: a much smaller Unsloth Desktop for GGUF chat; add training later in Settings.
  • Flint: Recursive's 40B coding-agent MoE, runs in 24 GB at 3-bit Guide
  • MOSS-Image: 5.1B image model designed for top-tier generation GGUF + FP8
  • NVIDIA Nemotron 3.5 Bolt E4B: NVIDIA's new Gemma 4 E4B fine-tune, 63.2 on Tau2-Bench vs the original's 38.7 Guide
  • MoE expert pruning: Export a smaller MoE model by removing 25% or 50% of its least useful experts with REAP.
  • UI overhaul: New + more consistent UI across Unsloth (API, roundness etc)

Images + video

  • Generate images containing English or Chinese text with OpenMOSS's 5.1B MOSS-Image, SFT or Base. GGUF · Base GGUF
  • MOSS-Image, the new image model, runs on 16 GB GPUs; its GGUFs also run on Macs and computers without a supported GPU.
  • Most image and video models too big for one GPU now split across your NVIDIA GPUs, if they fit, instead of streaming from system memory.
  • The new Hires fix upscales and refines a render in one step on SDXL, FLUX.1, Qwen-Image and Z-Image.
  • The new Compare grid renders one prompt while varying up to three settings, such as seed, CFG or LoRA weight, in labelled grids.
  • SDXL safetensors get AUTOMATIC1111-style prompt weighting, CLIP skip, CFG rescale, variation seeds and textual inversion.
  • Pasted AUTOMATIC1111, Forge or Civitai parameter blocks fill in the Images page settings.
  • If SAM 3 isn't already downloaded, the Mask from text tool now uses SAM 3.1: smaller, with no Hugging Face login.

Chat + Desktop

  • Pick Chat only (GGUF) when first launching Unsloth Desktop for a much smaller install; add training later in Settings.
  • Settings > Chat now lets you view, edit, clear or turn off the memory notes Unsloth sends to every chat.
  • In document-search chats, Show passages lists the exact text the model got and opens each passage at its page.
  • The Audio page can speak and transcribe via a saved API connection, such as OpenAI or a local server.
  • Unsloth installs, updates and pip install -U unsloth now reject eMudhra's compromised emSign certificates, which let attackers impersonate websites. The optional vLLM and SGLang engines still trust them.

Flint

  • Run Recursive's Flint, a 40B MoE model with 2.5B active parameters for coding agents, with reasoning, tool use and 256K context. Guide · GGUF
  • At 3-bit, Flint fits in 24 GB at short contexts.
  • On SWE-bench Pro v2, Flint scores 89.7 vs Qwen 3.6's 73.8.

NVIDIA Nemotron 3.5 Bolt E4B

  • Run and fine-tune NVIDIA's Gemma Nemotron 4B, a Gemma 4 E4B reasoning tune for tool calling and instruction following.
  • Gemma Nemotron 4B beats Gemma 4 E4B on 16 of 21 NVIDIA tests, gaining most in tool use and multi-turn chat.
  • DPO on Gemma 4 E2B and E4B, including Gemma Nemotron 4B, no longer crashes.

Training

  • Fine-tuning Whisper, Canary, Moonshine, Dia and CTC speech models with FastModel no longer fails.
  • Parakeet, Canary and CTC speech training uses up to 55% less memory.
  • The new Books & Documents to Text recipe in Data Recipes turns ebooks and documents into a pretraining text dataset, no model needed.
  • On Windows and Linux, the Export page can now prune 25% or 50% of a MoE model's least useful experts with REAP, at some quality cost.
  • In Python, reap_prune runs REAP expert pruning up to 54x faster than llm-compressor's.
  • unsloth train now trains vision and, except on Mac, audio models.
  • Unsloth now supports OpenAI's fine-tuning API, so OpenAI's SDK can upload datasets and run supervised fine-tuning of local models.

Performance

  • MLX MoE models too big for your Mac keep experts on SSD, with slower replies. Qwen3.8-Flash-Next fits a 32 GB Mac; DeepSeek-V4-Flash and GLM-5.3-Flash need far less memory than their size.
  • DPO and other training that pads sequences runs up to 3.8x faster with less memory on NVIDIA Ampere or newer.
  • Qwen3-MoE, Gemma 3 and Gemma 4 training on GPUs without bf16 now uses up to 7x less attention memory with torch 2.13 or older.

Coding agents + API

  • In chat, models can now read text files and documents on connected MCP servers, not just use their tools.
  • When launching coding agents, unsloth start no longer sends its Unsloth API key in plain text through your HTTP proxy to a local Unsloth.
  • On Windows, unsloth start no longer breaks Claude Code hooks or Codex sign-in when launching them.
  • Requests with an Unsloth API key can no longer run Python and terminal tools unsandboxed; only the Unsloth UI can allow that.
  • The new Save for this model button in Chat settings makes your sampling settings that model's default for new chats and API requests.

Models + hardware

  • A BF16 gpt-oss checkpoint loaded with load_in_4bit = True no longer gets random expert and router weights.
  • The model picker again lets you run models on Ryzen AI 300-series and newer NPUs, with no environment variable.
  • On some Linux AMD PCs with a system-wide ROCm, GGUFs that ran on the CPU now run on the GPU again.
