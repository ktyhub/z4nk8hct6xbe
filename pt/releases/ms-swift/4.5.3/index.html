#ms-rápido v4.5.3

Novos Modelos

  • Qwen3.8-Flash-Next, um modelo MoE multimodal com parâmetros totais de 125B (~6B ativados por token, incluindo uma tabela de incorporação de 51B N-gramas). Ele combina um backbone híbrido GDN + Qwen Sparse Attention (QSA), hiperconexões e uma tabela N-gram descarregável por host, com contexto nativo de 262K. O treinamento Megatron é suportado. Prática recomendada: Qwen3.8-Flash-Next-Best-Practice

  • deepseek-ai/DeepSeek-V4-Pro-0813

  • inclusãoAI/Ling-3.0-tiny e inclusãoAI/Ling-3.0-flash -XHToken/Spark-X2.5

  • lmms-lab/LLaVA-OneVision-2-8B-Instruir

  • iic/UEmbed-2B

  • Incorporação Tencent-Hunyuan/WeMM

Novos recursos

  • O otimizador Megatron-SWIFT Muon suporta diferentes taxas de aprendizagem para diferentes parâmetros.
  • A destilação OPD (GRPO) agora suporta entradas de visão separadas para professor e aluno, permitindo a destilação multimodal. Documento de referência: https://swift.readthedocs.io/en/latest/Instruction/Distillation.html
  • Um link last-checkpoint é mantido ao salvar pontos de verificação, facilitando a retomada.
  • dataloader_persistent_workers agora tem como padrão True para evitar inicialização a frio do carregador de dados em cada avaliação.
  • Desempenho: restauração de log-prob sem preenchimento vetorizado e reduções de sequência; Perda Megatron totalmente reduzida adiada para o tempo de registro; extração LSE de atenção de anel vetorizada em NPU.
  • Adicionado back-end de inferência vllm_kunlun para implementação/implantação.
  • Removida a dependência gradio.

Correções de bugs

  • Treinamento: resume_from_checkpoint com transformadores 4.x, normalização log-prob DPO/IPO, margens do modelo de recompensa alinhadas com pares, avaliação predict_with_generate DDP, escalonamento de perdas com paralelismo de sequência, perda de vocabulário e arquivos externos em multiprocessamento, decapagem de modelos, compatibilidade com py3.14, etc.
  • RL: gradientes de log-prob paralelos de vocabulário Megatron GRPO, sincronização de peso vLLM no modo colocate (LoRA IndexError, alinhamento do dispositivo remetente), ordenação de limpeza vLLM colocated em falhas de implementação, consistência de entrada/saída de token em implementações de várias etapas de agentes.
  • Megatron: partição CP de repetição do roteador e índices especializados, pesos compartilhados MTP para frente, carregamento do adaptador de referência, taxas zero de aprendizado multimodal, salvamento/carregamento do ponto de verificação Megatron-FSDP DTensor, etc.
  • Correções de modelo: Qwen3.5 (pesos FP32 de atenção linear, kwargs de embalagem multimodal), fps de vídeo Qwen-Omni, entradas de vídeo MiniCPM-o 4.5, mplug_owl2_1, etc.

ms-swift v4.5.3

New Models

  • Qwen3.8-Flash-Next, a multimodal MoE model with 125B total parameters (~6B activated per token, including a 51B N-gram embedding table). It combines a hybrid GDN + Qwen Sparse Attention (QSA) backbone, hyper-connections, and a host-offloadable N-gram table, with native 262K context. Megatron training is supported. Best practice: Qwen3.8-Flash-Next-Best-Practice

  • deepseek-ai/DeepSeek-V4-Pro-0813

  • inclusionAI/Ling-3.0-tiny & inclusionAI/Ling-3.0-flash

  • XHToken/Spark-X2.5

  • lmms-lab/LLaVA-OneVision-2-8B-Instruct

  • iic/UEmbed-2B

  • Tencent-Hunyuan/WeMM-Embedding

New Features

  • Megatron-SWIFT Muon optimizer supports different learning rates for different parameters.
  • OPD distillation (GRPO) now supports separate vision inputs for teacher and student, enabling multimodal distillation. Reference doc: https://swift.readthedocs.io/en/latest/Instruction/Distillation.html
  • A last-checkpoint link is maintained when saving checkpoints, making resume easier.
  • dataloader_persistent_workers now defaults to True to avoid dataloader cold start on each eval.
  • Performance: vectorized padding-free log-prob restore and sequence reductions; Megatron loss all-reduce deferred to logging time; vectorized ring attention LSE extraction on NPU.
  • Added the vllm_kunlun inference backend for rollout/deploy.
  • Removed the gradio dependency.

Bug Fixes

  • Training: resume_from_checkpoint with transformers 4.x, DPO/IPO log-prob normalization, reward model margins aligned with pairs, predict_with_generate DDP evaluation, loss scaling with sequence parallelism, vocab loss & external files in multi-processing, template pickling, py3.14 compatibility, etc.
  • RL: Megatron GRPO vocab-parallel log-prob gradients, vLLM weight sync in colocate mode (LoRA IndexError, sender device alignment), colocated vLLM cleanup ordering on rollout failures, token-in/token-out consistency in agentic multi-step rollouts.
  • Megatron: router replay CP partition and expert indices, MTP shared weights forward, reference adapter loading, zero multimodal learning rates, Megatron-FSDP DTensor checkpoint save/load, etc.
  • Model fixes: Qwen3.5 (linear attention FP32 weights, multimodal packing kwargs), Qwen-Omni video fps, MiniCPM-o 4.5 video inputs, mplug_owl2_1, etc.
