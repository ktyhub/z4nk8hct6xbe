TypeScript v5.7.3

Highlights

  • Recovery patch for the 5.7 line — v5.7.3 adds no new language features but fixes several adoption blockers: React Native fragment diagnostics now correctly flag missing React imports (#60615), JSON attributes are no longer over-required for node16 or erased type-only imports (#60673, #60749), and target: "es2024" includes its library declarations (#60622).
  • One import style for direct execution and builds — --rewriteRelativeImportExtensions (#59767) rewrites static relative .ts, .tsx, .mts, and .cts specifiers to JavaScript extensions in emitted files. This lets one source tree support Node/tsx/Deno-style execution and package builds; paths aliases, package exports/imports, and computed dynamic paths remain untouched and still need runtime-safe specifiers.
  • ES2024 support, with typed-array compatibility work — --target es2024 and --lib es2024 expose Promise.withResolvers, Object.groupBy/Map.groupBy, updated buffer APIs, and Atomics.waitAsync (#58573). Typed arrays are now generic over ArrayBufferLike (#59417); Node projects seeing new Buffer/Uint8Array assignment errors should update @types/node.
  • NodeNext JSON imports follow runtime rules — ESM value imports now require with { type: "json" }, and JSON is treated as a default export rather than a source of named bindings (#60019). The 5.7.3 fixes preserve node16 behavior and exempt erased type-only imports, so check module mode before changing existing imports.
  • Stricter bug detection and more responsive editors — TypeScript now rejects closure reads of variables that are never initialized, while remaining lenient about possibly initialized ones (#55887). Ancestor configuration discovery and root-file-only ownership checks for composite projects (#57196, #59688) improve multi-config workspaces and avoid loading entire referenced projects when opening stray files.
  • Breaking changes — None specific to 5.7.3; upgrading from older 5.x lines may still expose new diagnostics.

For release notes, check out the release announcement.
