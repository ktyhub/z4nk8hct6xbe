#parlant v3.3.0

[3.3.0] - 15/03/2026

Adicionado

  • Adicione planejadores por agente via Server.create_agent(planner=...), permitindo que cada agente use uma implementação Planner personalizada
  • Aceitar Tag como alvo em depend_on(), exclude() e prioritize_over() em Guideline e Tag, permitindo relacionamentos que visem todas as diretrizes que compartilham uma tag personalizada
  • Adicionar métodos Tag.depend_on(), Tag.exclude() e Tag.prioritize_over() ao SDK, permitindo dependência baseada em tags e relacionamentos de prioridade com diretrizes e jornadas
  • Suporte a TAG customizada como fonte para relacionamentos DEPENDENCY no resolvedor relacional
  • Adicione o parâmetro tags a create_guideline, create_observation e create_journey em Agent e Journey, permitindo que tags personalizadas sejam anexadas a entidades no momento da criação
  • Adicionar o método Tag.reevaluate_after() ao SDK, permitindo relacionamentos de reavaliação baseados em tags com ferramentas
  • Adicionar suporte de reavaliação baseado em tags no mecanismo: quando uma ferramenta é acionada, todas as diretrizes que carregam uma tag que tenha um relacionamento de reavaliação com essa ferramenta agora são reavaliadas
  • Adicionar staged_events ao GuidelineMatchingContext em SDK
  • Adicionar propriedade priority às diretrizes e jornadas para filtragem baseada em prioridade no resolvedor relacional
  • Adicionar diretrizes transitórias (renomeadas a partir de diretrizes fornecidas pela ferramenta), permitindo que as ferramentas injetem dinamicamente diretrizes comportamentais no contexto do agente
  • Adicione Agent.utter() ao SDK, permitindo a geração de mensagens de agente programático com diretrizes transitórias
  • Adicione Customer.update() e CustomerMetadata ao SDK, permitindo que ferramentas atualizem o nome e os metadados do cliente
  • Adicione Session.update(), SessionMetadata e SessionLabels ao SDK, permitindo que ferramentas atualizem propriedades de sessão, metadados e rótulos
  • Adicionar propriedades customer, agent, mode e title à classe SDK Session
  • Adicione Server.get_tag() ao SDK, suportando pesquisa por id ou name
  • Adicione filtragem baseada em nome a TagStore.list_tags() e ao endpoint GET /tags API por meio de um parâmetro de consulta name opcional
  • Aplicar exclusividade do nome da tag no TagStore, gerando um erro ao criar uma tag com nome duplicado

Alterado

  • Tornou o indicador de pensamento estendido opcional na política de desempenho percebido
  • Altere reevaluate_after() para Tag e Guideline para aceitar múltiplas ferramentas (*tools) e retornar Sequence[Relationship]
  • Altere o tipo de campo tags de Sequence[TagId] para Sequence[Tag] em Guideline, Journey, Capability, Term, Variable, Customer e Agent no SDK
  • Altere Tag.preamble() para retornar um objeto Tag completo em vez de um TagId
  • Atualize o serviço MCP e elimine versões de dependência para resolver vulnerabilidades de segurança

Obsoleto

  • Os serviços da ferramenta OpenAPI estão obsoletos; migre para os serviços de ferramentas SDK

Corrigido

  • Correção de impasse ao enviar uma nova mensagem logo após um preâmbulo
  • Correção da filtragem transitiva no resolvedor relacional para alvos de dependência de tags personalizadas (as diretrizes que dependem de uma tag personalizada agora são desativadas corretamente quando um membro marcado é despriorizado)
  • Correção da paralisação do endpoint SSE read_event após o primeiro pedaço de streaming até a conclusão completa
  • Correção de logs de análise de resposta que nem sempre alcançam a UI integrada
  • Corrija a formatação das diretrizes nos modos de resposta automática e streaming quando a condição estiver ausente
  • Corrigir o tamanho da dimensão de incorporação de texto pequeno do AzureService
  • Corrigir compatibilidade onnxruntime com Python 3.10 e alterações do tipo 5.x dos transformadores
  • Corrigir o esclarecimento imediato do proponente da intenção do agente
  • Corrigido o despejo de cache LRU incorporado, corrompendo o índice de comprimento quando as entradas compartilham o mesmo comprimento de texto
  • Correção de falha de resolução do LiteLLMEmbedder via contêiner lagom quando LITELLM_EMBEDDING_MODEL_NAME está definido
  • Correção de chamadas de ferramenta não consequenciais sendo rejeitadas quando faltam parâmetros opcionais

Removido

  • Remova o ponto de entrada obsoleto do parlant-test e a documentação da estrutura de teste do README

parlant v3.3.0

[3.3.0] - 2026-03-15

Added

  • Add per-agent planners via Server.create_agent(planner=...), allowing each agent to use a custom Planner implementation
  • Accept Tag as a target in depend_on(), exclude(), and prioritize_over() on both Guideline and Tag, enabling relationships that target all guidelines sharing a custom tag
  • Add Tag.depend_on(), Tag.exclude(), and Tag.prioritize_over() methods to the SDK, enabling tag-based dependency and priority relationships with guidelines and journeys
  • Support custom TAG as source for DEPENDENCY relationships in the relational resolver
  • Add tags parameter to create_guideline, create_observation, and create_journey on both Agent and Journey, allowing custom tags to be attached to entities at creation time
  • Add Tag.reevaluate_after() method to the SDK, enabling tag-based reevaluation relationships with tools
  • Add tag-based reevaluation support in the engine: when a tool fires, all guidelines carrying a tag that has a reevaluation relationship with that tool are now re-evaluated
  • Add staged_events to GuidelineMatchingContext in SDK
  • Add priority property to guidelines and journeys for priority-based filtering in the relational resolver
  • Add transient guidelines (renamed from tool-provided guidelines), allowing tools to dynamically inject behavioral guidelines into the agent's context
  • Add Agent.utter() to the SDK, enabling programmatic agent message generation with transient guidelines
  • Add Customer.update() and CustomerMetadata to the SDK, allowing tools to update customer name and metadata
  • Add Session.update(), SessionMetadata, and SessionLabels to the SDK, allowing tools to update session properties, metadata, and labels
  • Add customer, agent, mode, and title properties to SDK Session class
  • Add Server.get_tag() to the SDK, supporting lookup by either id or name
  • Add name-based filtering to TagStore.list_tags() and the GET /tags API endpoint via an optional name query parameter
  • Enforce tag name uniqueness in TagStore, raising an error when creating a tag with a duplicate name

Changed

  • Made extended thinking indicator optional in perceived performance policy
  • Change reevaluate_after() on Tag and Guideline to accept multiple tools (*tools) and return Sequence[Relationship]
  • Change tags field type from Sequence[TagId] to Sequence[Tag] on Guideline, Journey, Capability, Term, Variable, Customer, and Agent in the SDK
  • Change Tag.preamble() to return a full Tag object instead of a TagId
  • Upgrade MCP service and bump dependency versions to resolve security vulnerabilities

Deprecated

  • OpenAPI tool services are now deprecated; please migrate to SDK tool services

Fixed

  • Fix deadlock when sending a new message right after a preamble
  • Fix transitive filtering in relational resolver for custom tag dependency targets (guidelines depending on a custom tag are now correctly deactivated when a tagged member is deprioritized)
  • Fix SSE read_event endpoint stalling after first streaming chunk until full completion
  • Fix response analysis logs not always reaching the integrated UI
  • Fix guideline formatting in canned response and streaming modes when condition is absent
  • Fix AzureService small text embedding dimension size
  • Fix onnxruntime compatibility with Python 3.10 and transformers 5.x type changes
  • Fix agent intention proposer prompt clarification
  • Fix embedding LRU cache eviction corrupting the length index when entries share the same text length
  • Fix LiteLLMEmbedder failing to resolve via lagom container when LITELLM_EMBEDDING_MODEL_NAME is set
  • Fix non-consequential tool calls being rejected when optional parameters are missing

Removed

  • Remove stale parlant-test entry point and testing framework documentation from README
