Destaques

Esta versão apresenta 752 commits de 320 colaboradores (123 novos)!

  • DeepSeek V4: suporte inicial para DeepSeek V4 (#40860), com correção de vazamento de token DSML em DSV4/3.2 (#40806), correção de DSA + MTP IMA (#40772) e um limite de fixação silu no especialista compartilhado (#40950).
  • Padrão CUDA 13.0: Roda CUDA padrão na imagem PyPI e vllm/vllm-openai:v0.20.0 alterada para CUDA 13.0; listas de arquitetura e argumentos de construção limpos (#39878) e CUDA passou para 13.0.2 para corresponder ao PyTorch 2.11.0 (#40669). Como regra geral, nossa política de versão CUDA segue a do PyTorch. É altamente recomendável instalar o vLLM com uv e usar --torch-backend=cu129 se você estiver no CUDA 12.9.
  • Atualização do PyTorch 2.11 (#34644): o vLLM é enviado na tocha 2.11 para CUDA, e o XPU agora também está na tocha 2.11 (#37947) — XPU não está mais fixado no 2.10. Esta é uma mudança significativa para a dependência do ambiente.
