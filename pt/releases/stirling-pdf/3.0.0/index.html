Stirling-PDF_0.33.1 Docker hub movido para stirlingtools v3.0.0

Stirling PDF V3.0 está no ar! Com esta atualização, estamos introduzindo muitas mudanças novas e interessantes, um novo sistema de automação, SSO OAuth gratuito para todos, um novo editor de texto e uma série de novos recursos, correções de bugs e correções de segurança.

Temos um novo sistema junto com o "Editor de PDF" chamado "Processador de PDF" O Processador de PDF pega as ferramentas que você já usa no Stirling PDF e permite executá-las em um grande número de arquivos com uma variedade de fontes (pastas/FTP/S3 etc.) A ideia é: se você precisar fazer o OCR de 10.000 arquivos, compactar uma pasta inteira ou converter uma biblioteca de documentos inteira, esta deve ser uma ferramenta que pode ajudar com isso e permitir que ele ouça e execute arquivos futuros à medida que eles chegam Este é o primeiro grande lançamento do Processor e iremos melhorá-lo rapidamente com base na forma como as pessoas o utilizam. Guia completo do processador com exemplos AI também está disponível como parte opcional do processador. Você pode usar IA para compreender documentos, classificá-los, extrair informações e ajudar a automatizar o processamento. A IA é totalmente opcional (e desativada por padrão) e pode usar vários modelos, incluindo modelos localmente/auto-hospedados, dependendo da sua configuração. A automação agora inclui 1.000 PDFs gratuitos por mês. Esta permissão se aplica ao processamento automatizado por meio de recursos do Processador, API e IA. Vincular seu servidor a stirling.com oferece 500 PDFs adicionais por mês e acesso à nossa IA hospedada (se você não quiser hospedar a sua própria). O uso normal do PDF Editor permanece gratuito e ilimitado. Além disso, também estamos tornando o SSO OAuth gratuito para todos os usuários.

A V3.0 também inclui melhorias importantes no lado do Editor de PDF:

  • O já mencionado SSO OAuth gratuito
  • Editor de texto totalmente novo, agora fora do alfa, você deve esperar UI, desempenho e compatibilidade drasticamente melhores
  • Editor de formulários e criação de formulários aprimorados
  • Detecção automática de formulário
  • Nova barra de acesso rápido
  • Rotação automática
  • Grandes melhorias na redação
  • Conversão de PDF/UA (WIP)
  • Suporte ao portfólio PDF
  • Visualização do leitor dedicado
  • Assine do seu telefone usando um código QR
  • Carimbos de data e hora RFC3161
  • Pesquise em todos os PDFs de Stirling
  • Melhorias na interface móvel
  • Manipulação de arquivos e histórico de arquivos aprimorados para desktop, portanto, arquivos excluídos são excluídos na UI Stirling
  • Nova biblioteca de arquivos
  • Novas pastas da área de trabalho para montar pastas do disco no Stirling para executar a automação (serão expandidas em atualizações futuras)
  • Nova página de configurações
  • Sugestões de ferramentas mais inteligentes com base no uso anterior de ferramentas
  • Melhorias gerais na interface do usuário e correções de bugs
  • Várias correções de bugs e melhorias de segurança!

Experimente a V3.0 e diga-nos o que você pensa. Estaremos lançando correções, melhorias e novos recursos de processador e editor nas próximas semanas, com lançamentos previstos para serem quase semanais, com um foco maior nos PRs da comunidade daqui para frente.

Stirling-PDF_0.33.1 Docker hub move to stirlingtools v3.0.0

Highlights

  • PDF Processor ships as a v1 automation engine — A second system alongside the Editor runs existing Stirling tools across thousands of files from folders, FTP, S3 and MCP sources (#6795), with watched folders that process files as they arrive — aimed squarely at bulk OCR/compress/convert jobs. It's explicitly billed as a first major release, and the fix list bears that out: circular dependencies in watched folders (#7308), locking files until processing completes (#8120), mounted-subfolder processing (#8141), and removal of the Automate operation timeout (#7082) all landed here, so treat it as fast-moving rather than stable. AI document classification and extraction are wired in but fully optional and off by default, with self-hosted model support.
  • Automation is now quota-metered — the key behavioral change — Processor/API/AI automation gets 1,000 PDFs/month free; linking your instance to stirling.com adds 500/month plus hosted AI, while normal Editor usage stays free and unlimited. Anyone running large batch or automated workflows must now budget allowance or link their server before relying on Processor in production — operationally the most significant change in the release despite being buried in the intro.
  • OAuth SSO is free for everyone — Previously gated behind paid tiers, SSO is now open to all users, removing a common adoption blocker and materially improving the self-hosted enterprise story.
  • Text Editor exits alpha; editor surface expands — The rebuilt text editor is out of alpha with major UI, performance and compatibility gains, joined by an improved form editor with auto-detection, quick access bar, redaction overhaul, PDF Portfolio support, RFC3161 timestamps, QR-code sign-from-phone and a dedicated reader view. PDF/UA conversion is still WIP — don't depend on it for accessibility compliance yet. Supporting fixes include signature placement (#7093), viewer search reporting "0 of 0" (#7228), and PDF preview/worker memory leaks (#7281).
  • Security and operational hardening worth upgrading for — Share-link route tokens are now constrained to UUID length (#7626), Telegram bot tokens are masked in settings output (#6822), the signup page is removed from self-hosted builds (#7406), SMTP timeouts are bounded so a wedged relay can't park a thread (#7879), and partial admin saves are merged instead of clobbered (#7545). Deployment note: the Docker Hub image has moved to the stirlingtools namespace — update your image references and pull policies.
  • Breaking changes — None explicitly documented; the Docker Hub namespace move above is the only deployment migration to plan for.
