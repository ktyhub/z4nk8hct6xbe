Stirling-PDF v3.0.2

Highlights

  • Selective page cropping — Cropping can now target individual pages instead of applying one operation across the entire document (#7753). This is useful for mixed-size or mixed-orientation scans: correct only the affected pages while leaving the rest unchanged.
  • More predictable editing and startup — Page reordering now provides visual feedback (#6289), reducing ordering mistakes. Fixes to startup views and desktop session restoration (#8309) also address the default viewer/reader mode not working correctly.
  • Deployment defaults changed — Server builds now ship with the processor enabled by default and hide its links when unavailable (#8280); latest-fat no longer enables the AI engine automatically (#8276). Configure AI explicitly if your workflow relied on automatic activation. The listed Node.js 24 and PDF-toolchain Docker upgrades are deferred to the next minor release, not included in v3.0.2 images.
  • Clearer API failure semantics — Unrepairable documents now return HTTP 422 instead of 500 (#8083), so clients should treat them as rejected input rather than server failures. parsePageList also skips malformed page tokens consistently (#8127); validate page parameters client-side if your integration requires malformed requests to fail loudly.
  • Broader localization coverage — Settings-search placeholders are resolved (#6814), hardcoded UI and service/error messages are translated (#8284, #8288), and translations are synchronized across 40 locales (#8308). Serbian now loads under the canonical sr-Latn-RS tag (#8293); recheck custom locale overrides and locale-sensitive tests.
  • Breaking changes — None announced.

This release contains bug fixes and various other improvements Enhancements:

  • add support for selective page cropping
  • better tool recommendation based on user usage
  • add visual feedback during page reordering

Bugs fixed:

  • translations missing
  • Certain languages not loading correctly
  • Processor not correctly loading in certain versions of the app
  • latest-fat having file upload issues
  • Default mode as viewer/reader not correctly working
