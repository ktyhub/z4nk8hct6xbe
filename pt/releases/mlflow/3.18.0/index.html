#mlflow v3.18.0

O MLflow 3.18.0 ajuda você a reutilizar a experiência do agente, encontrar regressões antes do envio e monitorar a qualidade na produção.

Principais novos recursos

  • Detecção automática de problemas: Transforme falhas recorrentes do agente em problemas que você pode investigar e corrigir. A guia Questões dedicada agrupa problemas relacionados e vincula descobertas a evidências de rastreamento; programação de detecção para continuar verificando novo tráfego. (#27193, #26751, #26754, #26791, #26919, #26955, #26961, #26967, #27009, #27002, #27003, #27006, #27137, #27181, #27249, @tanghaoji; #27070, @B-Etapa 62)
  • Registro de habilidades: compartilhe a experiência da sua equipe entre agentes e projetos com um catálogo central de habilidades reutilizáveis. Descubra as competências existentes e escolha a versão ou alias a utilizar em cada agente. Experimental. (#26736, @mprahl; #26900, @bardenr; #27088, @Rohitkanithi)
  • Avaliação renovada e comparações de rastreamento para encontrar regressões: Encontre as regressões escondidas atrás das pontuações agregadas antes de enviar uma atualização do agente. A interface de comparação redesenhada leva você desde as alterações de pontuação até as entradas, conversas e etapas de rastreamento por trás delas. Um Python API experimental adiciona comparações estatísticas para ajudar a distinguir melhorias de ruído. (#26991, #26733, #26739, #26740, #26770, #26771, #26782, #26783, #26784, #26927, #26799, #26803, #26808, #26868, #26880, #26889, #26896, #27011, #27014, #27015, @joshuawong-db #27332, @filip-urbanski;
  • Avaliação on-line: detecte regressões de qualidade de produção com verificações personalizadas baseadas em código que avaliam automaticamente novos rastreamentos e conversas multivoltas à medida que chegam. A avaliação online baseada em código é experimental e requer um servidor auto-hospedado configurado com contêineres de trabalho. (#26689, #26430, #26684, #26685, #26687, @kriscon-db)

Mudanças importantes

  • [Rastreamento] Filtre e classifique as métricas search_logged_models pela etapa mais alta e, em seguida, pelo carimbo de data e hora mais recente, em armazenamentos SQL; aplique datasets à filtragem e classificação (#27215, @agtzrubio)
  • [Registro de Modelo] Pare de adicionar registered_model_meta aos downloads de models:/; leitores personalizados devem usar o URI ou Model Registry (#27173, @sunilmehta-si)
  • [Rastreamento] Tornar a identidade da versão do servidor MCP sensível a maiúsculas e minúsculas em MySQL e SQL Server; corrija referências com incompatibilidade de maiúsculas e minúsculas antes de atualizar (#25920, @LobsterQBA)

Atualização do banco de dados: Faça backup do back-end SQL e planeje uma janela de manutenção. Pare os servidores MLflow e outros gravadores, execute mlflow db upgrade <database-url> com MLflow 3.18.0 e reinicie na nova versão. A migração da versão MCP verifica as referências MySQL e SQL Server para correspondências exatas de casos e para antes que seu próprio esquema seja alterado se a correção for necessária. Em bancos de dados que não diferenciam maiúsculas de minúsculas, as permissões de registro e MCP agora usam nomes de recursos armazenados. Salve novamente as concessões com caixas diferentes sob a ortografia armazenada. Siga as orientações de atualização do banco de dados.

mlflow v3.18.0

MLflow 3.18.0 helps you reuse agent expertise, find regressions before shipping, and monitor quality in production.

Major New Features

  • Automatic Issue Detection: Turn recurring agent failures into issues you can investigate and fix. The dedicated Issues tab groups related problems and links findings to trace evidence; schedule detection to keep checking new traffic. (#27193, #26751, #26754, #26791, #26919, #26955, #26961, #26967, #27009, #27002, #27003, #27006, #27137, #27181, #27249, @tanghaoji; #27070, @B-Step62)
  • Skill Registry: Share your team's expertise across agents and projects with a central catalog of reusable skills. Discover existing skills and choose the version or alias to use in each agent. Experimental. (#26736, @mprahl; #26900, @bardenr; #27088, @Rohitkanithi)
  • Revamped Evaluation and Trace Comparisons for Finding Regressions: Find the regressions hidden behind aggregate scores before you ship an agent update. The redesigned comparison UI takes you from score changes to the inputs, conversations, and trace steps behind them. An experimental Python API adds statistical comparisons to help distinguish improvements from noise. (#26991, #26733, #26739, #26740, #26770, #26771, #26782, #26783, #26784, #26927, #26799, #26803, #26808, #26868, #26880, #26889, #26896, #27011, #27014, #27015, @joshuawong-db; #27332, @filip-urbanski; #26396, @AbdulAliMamnun)
  • Online Evaluation: Catch production quality regressions with custom code-based checks that automatically assess new traces and multi-turn conversations as they arrive. Code-based online evaluation is experimental and requires a self-hosted server configured with job containers. (#26689, #26430, #26684, #26685, #26687, @kriscon-db)

Breaking Changes

  • [Tracking] Filter and sort search_logged_models metrics by the highest step, then latest timestamp, on SQL stores; apply datasets to both filtering and sorting (#27215, @agtzrubio)
  • [Model Registry] Stop adding registered_model_meta to models:/ downloads; custom readers should use the URI or Model Registry (#27173, @sunilmehta-si)
  • [Tracking] Make MCP server version identity case-sensitive on MySQL and SQL Server; correct case-mismatched references before upgrading (#25920, @LobsterQBA)

Database upgrade: Back up the SQL backend and plan a maintenance window. Stop MLflow servers and other writers, run mlflow db upgrade <database-url> with MLflow 3.18.0, and restart on the new version. The MCP version migration checks MySQL and SQL Server references for exact-case matches and stops before its own schema changes if correction is required. On case-insensitive databases, registry and MCP permissions now use stored resource names. Re-save differently cased grants under the stored spelling. Follow the database upgrade guidance.
