daily_stock_análise v3.19.0

Novos recursos

  • Implementado #1391 Fase 1 Link mínimo para execução de diagnóstico: tarefa/SSE anexa trace_id e registra snapshots ProviderRun de mercado diários e em tempo real.
  • A central de alarme adiciona regras estruturadas de semáforos em grande escala P7, suporta market_light_status e market_light_score_drop e reutiliza trabalhadores existentes, histórico de acionamentos, notificações e links de resfriamento.
  • Implementado o Resumo de Diagnóstico de Execução #1391 Fase 2: Gere RunDiagnosticSummary legível pelo usuário, fornecendo diagnóstico de relatório histórico API e texto de cópia dessensibilizado.
  • Implementada a visibilidade do diagnóstico de execução #1391 Fase 3: os detalhes do relatório e os painéis de tarefas são recolhidos por padrão para exibir o status da execução, rastreamento e informações replicáveis ​​de solução de problemas; o back-end fornece preenchimento de link histórico por meio de api/v1/history/{record_id}/diagnostics e context_snapshot.diagnostics.
  • Adicionado contrato interno AnalysisContextPack P1 e testes de serialização dessensibilizados.
  • Adicionado o construtor AnalysisContextPack P2 para montar pacotes de contexto interno de artefatos existentes em pipelines de análise comuns.
  • Wengu adicionou compactação de contexto de conversa visível que é desativada por padrão, suporta troca de Web, predefinição avançada de agente, resumo contínuo e proteção de texto original de rodada recente, reduzindo o consumo de token de sessão longa.
  • O índice de preenchimento automático de ações suporta atualização remota e cache do GitHub principal para local por padrão. Quando a entrada de análise Web/CLI falhar, ela será automaticamente rebaixada para o índice integrado, reduzindo a probabilidade de a abreviatura antiga contaminar a análise após decapitação e mudança de nome.
  • A análise comum e o prompt de tempo de execução do agente estão conectados ao resumo de baixa sensibilidade do AnalysisContextPack para manter a compatibilidade com o histórico/API/saída da Web.

Melhorias

  • scripts/fetch_tushare_stock_list.py pode preencher e corrigir nomes com o prefixo XD/XR/DR/N/C em ações A para uso padrão no processo de atualização de conclusão automática.
  • A página de roteamento da Web é alterada para carregamento sob demanda, o tamanho do primeiro pacote é reduzido e um prompt de recuperação para falha no carregamento da rota é adicionado.
  • Gaveta Markdown de relatórios completos da Web alterada para carregamento sob demanda.
  • Adicionadas linhas de base de inferência de fase de mercado e esclareceu a semântica de pré-mercado, intra-mercado, intervalo para almoço, quase fechamento, pós-mercado e dias sem negociação.
  • Adicionados testes de degradação e construção de contexto de estágio de mercado em execução.
  • A configuração da página de configurações ajuda a completar gradualmente a redação bilíngue em chinês e inglês dos campos reais de exibição/configuráveis ​​da página de configurações da Web, abrangendo agente, backtesting, relatórios, roteamento de notificação, tempo de execução do sistema, legado de IA, fontes de dados e configuração avançada de notificação.
  • P2-min: LLM Prompt injeta contexto de estágio de mercado.

Correção

  • A geração do índice de preenchimento automático de ações falhará diretamente quando pypinyin estiver faltando para evitar a gravação de índices rebaixados com campos pinyin ausentes.
  • Normalizar o volume de negociação do mercado em tempo real da Tencent como calibre de ações para evitar a amplificação dos múltiplos de mudança de energia do volume e relatórios de análise enganosos.
  • A implantação padrão do Docker remove a montagem de arquivo único .env para evitar que o Device or resource busy seja acionado pela atualização do ponto de montagem do os.replace quando o WebUI salva a configuração.
  • Convergência #1391 Fase 0 Limite de propriedade do código de compartilhamento A: Conclua a consistência de propriedade dos cenários de prefixo SH/SZ e esclareça o escopo desta rodada de reparos para data_provider/baostock_fetcher.py, data_provider/pytdx_fetcher.py e data_provider/tushare_fetcher.py.
  • Corrigida a conversão de formato interno de fonte de dados substituta, como Baostock, quando STOCK_LIST usa códigos simples de compartilhamento A, mantendo a configuração do usuário para continuar usando números de ações de 6 dígitos.
  • As atualizações automáticas da área de trabalho do Windows serão alteradas para executar o instalador silenciosamente após o usuário confirmar a reinicialização da instalação e limpar as referências do processo após interromper o back-end integrado, reduzindo a probabilidade do instalador solicitar "A análise diária de estoque não pode ser fechada".
  • O desktop macOS migra a configuração do tempo de execução para o diretório de dados do usuário e migra .env, banco de dados e logs enquanto os arquivos do pacote .app antigo ainda estão acessíveis, para evitar reconfiguração após substituições e atualizações subsequentes.
  • Restaurou a extração de seções associadas e campos de vinculação de seção em instantâneos compatíveis com agente/histórico e corrigiu o problema de regressão de falta de "vinculação de seção" no novo relatório da página inicial.
  • Corrigido o nome do campo do alarme legado JSON e a descrição semântica de entrega do período silencioso na ajuda de configurações da Web.
  • Corrigido o problema de falta do título de configuração, da descrição e das principais opções suspensas nas áreas de fonte de dados, notificação, sistema e agente da página de configurações da Web em chinês.
  • Corrigido um problema em que o status da tarefa de agente/análise em andamento poderia permanecer após alternar a sessão e reconectar-se à tarefa da página inicial.
  • Adicionado subtrilho de rastreamento com reconhecimento de provedor para agente único e retido reasoning_content e materiais de protocolo de ferramenta do pensamento DeepSeek V4 + chamada de ferramenta entre rodas.
  • Adicionado um tempo limite de nível de chamada à interface ascendente histórica Akshare Sina/Tencent A-share e concluído o teste de regressão de roteamento de código de ações Tushare 605xxx Shanghai para evitar que a análise programada seja interrompida devido à falta de resposta da fonte de dados.
  • Elevar o limite inferior de dependência de exchange-calendars para 4.13.0 para evitar falha de análise devido à falha da unidade Timedelta T ao importar o calendário de negociação no ambiente pandas 3.
  • Os resultados da análise acionados por comandos interativos (conversas DingTalk, conversas Feishu, Telegram) são retornados apenas para a conversa de origem e não são mais transmitidos simultaneamente para canais de notificação estáticos.
  • Adaptado à autenticação Longbridge OAuth 2.0 e recuperação de cache de token para evitar que a fonte de dados Longbridge seja mal avaliada como não configurada quando o novo back-end não possui um token de acesso legado.
  • O caminho Longbridge OAuth registra explicitamente downgrades quando o SDK atual não suporta OAuthBuilder/Config.from_oauth para evitar falhas de construção quando o Linux/Docker só pode instalar o SDK mais antigo.
  • Compatível com o cenário onde a linha diária do YFinance retorna um índice de data sem nome, para evitar a interrupção do fallback diário das ações dos EUA causada pela falta da coluna date após a padronização.

daily_stock_analysis v3.19.0

新功能

  • 落地 #1391 Phase 1 运行诊断最小链路：任务/SSE 追加 trace_id，并记录日线与实时行情 ProviderRun 快照。
  • 告警中心新增 P7 大盘红绿灯结构化规则，支持 market_light_status 与 market_light_score_drop 并复用现有 worker、触发历史、通知和冷却链路。
  • 落地 #1391 Phase 2 运行诊断摘要：生成用户可读 RunDiagnosticSummary，提供历史报告诊断 API 与脱敏复制文本。
  • 落地 #1391 Phase 3 运行诊断可见性：报告详情和任务面板默认折叠展示运行状态、trace 与可复制排障信息；后端通过 api/v1/history/{record_id}/diagnostics 与 context_snapshot.diagnostics 提供历史链路回填。
  • 新增 AnalysisContextPack P1 内部契约与脱敏序列化测试。
  • 新增 AnalysisContextPack P2 builder，从普通分析 pipeline 已有 artifacts 组装内部上下文包。
  • 问股新增默认关闭的可见对话上下文压缩，支持 Web 开关、Agent 高级 preset、滚动摘要和最近轮次原文保护，降低长会话 token 消耗。
  • 股票自动补全索引默认支持从 GitHub main 远程刷新并缓存到本地，Web/CLI 分析入口失败时自动降级到内置索引，降低摘帽和更名后旧简称污染分析的概率。
  • 普通分析与 Agent 运行时 Prompt 接入 AnalysisContextPack 低敏摘要，保持 history/API/Web 输出兼容。

改进

  • scripts/fetch_tushare_stock_list.py 可对 A 股中带 XD/XR/DR/N/C 前缀的名称进行回填修正，供自动补全刷新流程默认使用。
  • Web 路由页面改为按需加载，降低首包体积并增加路由加载失败恢复提示。
  • Web 完整报告 Markdown 抽屉改为按需加载。
  • 新增市场阶段推断基线并明确盘前、盘中、午休、临近收盘、盘后和非交易日语义。
  • 新增运行态市场阶段上下文构造与降级测试。
  • 设置页配置帮助阶段性补齐 Web 设置页实际展示/可配置字段的中英双语文案，覆盖 Agent、回测、报告、通知路由、系统运行时、AI legacy、数据源和通知高级配置。
  • P2-min：LLM Prompt 注入市场阶段上下文。

修复

  • 股票自动补全索引生成缺少 pypinyin 时改为直接失败，避免写出缺失拼音字段的降级索引。
  • 归一腾讯实时行情成交量为股口径，避免量能变化倍数被放大并误导分析报告。
  • Docker 默认部署移除 .env 单文件挂载，避免 WebUI 保存配置时因 os.replace 更新挂载点触发 Device or resource busy。
  • 收敛 #1391 Phase 0 A 股代码归属边界：补齐 SH/SZ 前缀场景的归属一致性，明确 data_provider/baostock_fetcher.py、data_provider/pytdx_fetcher.py、data_provider/tushare_fetcher.py 的本轮修复范围。
  • 修复 STOCK_LIST 使用裸 A 股代码时 Baostock 等数据源 fallback 的内部格式转换，保持用户配置继续使用 6 位股票编号。
  • Windows 桌面端自动更新在用户确认重启安装后改为静默执行安装器，并在停止内置后端后清理进程引用，降低安装器提示“每日股票分析无法关闭”的概率。
  • macOS 桌面端将运行时配置迁移到用户数据目录，并在旧 .app 包内文件仍可访问时迁移 .env、数据库和日志，避免后续替换升级后重新配置。
  • 恢复 Agent/历史兼容快照中的关联板块与板块联动字段提取，修复新版首页报告缺少“板块联动”的回归问题。
  • 修正 Web 设置帮助中 legacy 告警 JSON 字段名与静默时段投递语义说明。
  • 修复 Web 中文设置页在数据源、通知、系统与 Agent 区域的配置标题、说明和关键下拉选项漏翻问题。
  • 修复问股会话切换和首页任务重连后可能残留 Agent/分析任务进行中状态的问题。
  • 问股 single-agent 新增 provider-aware trace 分轨，跨轮保留 DeepSeek V4 thinking + tool-call 的 reasoning_content 与工具协议材料。
  • 为 Akshare 新浪/腾讯 A 股历史兜底接口增加调用级超时，并补齐 Tushare 605xxx 沪市代码路由回归测试，避免定时分析因数据源无响应而挂起。
  • 将 exchange-calendars 依赖下限提升到 4.13.0，避免 pandas 3 环境导入交易日历时因 Timedelta 单位 T 失效导致分析失败。
  • 交互式命令（钉钉会话、飞书会话、Telegram）触发的分析结果只回到来源会话，不再同时广播到静态通知渠道。
  • 适配 Longbridge OAuth 2.0 认证与 token 缓存恢复，避免新后台无 Legacy Access Token 时长桥数据源被误判为未配置。
  • Longbridge OAuth 路径在当前 SDK 不支持 OAuthBuilder / Config.from_oauth 时明确日志降级，避免 Linux/Docker 仅可安装旧 SDK 时构建失败。
  • 兼容 YFinance 日线返回未命名日期索引的场景，避免标准化后缺少 date 列导致美股日线 fallback 中断。

文档
