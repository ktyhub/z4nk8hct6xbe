🚀 Instruções de instalação

  • 💻 Windows: clique duas vezes no pacote de instalação baixado e siga as instruções para concluir a instalação. ARM64 requer .NET Framework 4.8.1, que o Windows 11 mais recente vem integrado.
  • 🍎 Mac (macOS 14 e superior): Clique duas vezes no .pkg baixado e siga as instruções para continuar a instalação; ele baixará e preparará automaticamente o tempo de execução necessário durante a instalação. Após a conclusão, abra o Toonflow em "Aplicativos".
  • 🐧 Linux (Debian/Ubuntu): Selecione o DEB da arquitetura correspondente e execute sudo apt install ./toonflow-版本号-linux-架构.deb no diretório de download. Após a instalação, você pode atualizá-lo em “Configurações → Sobre”; os usuários que usam 2.0.10 precisam sobrescrevê-lo e instalá-lo manualmente primeiro.
  • 📱 Android: abra o APK no seu telefone e siga as instruções do sistema para permitir que esta fonte instale aplicativos. As versões subsequentes podem ser substituídas e instaladas diretamente. Ambos os aplicativos Mac são assinados com o Developer ID Application, e o pacote de instalação PKG é assinado com o Developer ID Installer e concluído com reconhecimento de firma da Apple. O macOS ainda pode solicitar confirmação para abrir um aplicativo baixado da Internet ao abri-lo pela primeira vez. Ao migrar um cliente Intel Mac mais antigo para a versão unificada SDK pela primeira vez, baixe a instalação completa da sobreposição PKG; a atualização incremental da versão mais antiga não pode ser migrada diretamente. Saia do aplicativo e faça backup do diretório de dados original antes da instalação.

Toonflow-app v2.0.11

Highlights

  • Cross-platform packages — v2.0.11 provides architecture-specific installers for Windows x64/ARM64, macOS Intel/Apple Silicon, Linux x64/ARM64, and Android ARM64. Match the package to the device CPU; Android requires Android 8 or later.
  • macOS distribution and requirements — Both Mac builds require macOS 14+ and are signed with Developer ID Application; PKGs use Developer ID Installer and are notarized. Installation downloads the required runtime, so allow network access, and expect a possible first-launch confirmation for an internet-downloaded app.
  • Intel Mac migration — Older Intel clients moving to the unified SDK must quit the app, back up the data directory, and perform a full PKG overwrite installation. The incremental updater cannot complete this migration.
  • Linux updater bootstrap — Users on 2.0.10 must manually overwrite-install the architecture-matched DEB once before relying on in-app updates under Settings → About. Install locally with sudo apt install ./toonflow-<version>-linux-<arch>.deb.
  • Windows ARM64 prerequisite — ARM64 installations require .NET Framework 4.8.1. Newer Windows 11 systems include it; older ARM64 machines may need it installed first.
  • Breaking changes — None explicitly documented.

🚀 安装说明

  • 💻 Windows：双击下载的安装包，按提示完成安装。ARM64 需要 .NET Framework 4.8.1，较新的 Windows 11 已内置。
  • 🍎 Mac（macOS 14 及以上）：双击下载的 .pkg，按提示继续安装；安装期间会自动下载并准备必要运行时，完成后从“应用程序”打开 Toonflow。
  • 🐧 Linux（Debian / Ubuntu）：选择对应架构的 DEB，在下载目录执行 sudo apt install ./toonflow-版本号-linux-架构.deb。安装后可在「设置 → 关于」更新；使用 2.0.10 的用户需先手动覆盖安装一次。
  • 📱 Android：在手机上打开 APK，按系统提示允许此来源安装应用。后续版本可直接覆盖安装。

两种 Mac 应用使用 Developer ID Application 签名，PKG 安装包使用 Developer ID Installer 签名，并完成 Apple 公证。首次打开时，macOS 仍可能提示确认打开从互联网下载的应用。 旧版 Intel Mac 客户端首次迁移到统一 SDK 版本时，请下载完整 PKG 覆盖安装；旧版增量更新不能直接迁移。安装前请退出应用并备份原数据目录。
