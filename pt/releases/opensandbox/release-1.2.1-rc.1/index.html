Versão OpenSandbox-1.2.1-rc.1

Primeiro candidato a lançamento na linha de patch 1.2.1, cortado de release-1.2.0 (27/10/2026). Título: OSEP-0025 Credential Vault Exchange — uma fonte de credenciais exchange com resolução de cabeçalho por solicitação por meio de um resolvedor conectável, conectado de ponta a ponta na saída, servidor, todos os cinco SDKs, fast-sandbox e2e e o guia Credential Vault. Também digno de nota: uploads atômicos de execd, validação de resumo para snapshots rootfs, diagnóstico de inicialização de tempo limite de criação Kubernetes e escopo de cache de informante para clusters grandes. A linha de base para cada seção é release-1.2.0. Os lançamentos rc publicam imagens, mas contêm pacotes - os artefatos SDK/CLI são enviados no nível estável do 1.2.1.

Destaques

  • Credential Vault Exchange (OSEP-0025): resolução de cabeçalho dinâmica por solicitação, fechada com falha e nunca persistida, no servidor e em todos os cinco SDKs (#2457 #2535 #2534 #2560)
  • Segurança de dados: uploads de execd são substituídos atomicamente para que uma falha na gravação mantenha o arquivo antigo (#2433); o controlador recusa snapshots rootfs cujo resultado do commit não possui resumos (#2482)
  • Operabilidade: criar timeouts reportar o motivo da falha na inicialização do pod (#2434); controlador e controlador fsb ganham escopo de cache --namespaces (#2571 #2581)

Servidor

  • A lista sandbox envia filtros de igualdade de metadados para o seletor de rótulo Kubernetes, para que grandes namespaces não materializem mais todas as cargas de trabalho antes da filtragem (#2559)
  • Proteção do modelo OCI: a sintaxe do repositório de publicação é validada na criação, e a criação do sandbox requer uma referência de publicação fixada por resumo — um modelo bem-sucedido não pode mais ser resolvido para um manifesto mutável ou não relacionado (#2491)
  • Kubernetes cria tempos limite acrescentando o motivo da falha de inicialização do pod (não programável, ImagePullBackOff, eventos de aviso) antes da reversão - falhas de extração de imagem e agendamento são diagnosticáveis através do API novamente (#2434)
  • Docker: uma remoção simultânea de contêiner não aborta mais a restauração de expiração de inicialização e os erros Docker restantes falham na inicialização em vez de descartar temporizadores silenciosamente (#2533); destinos duplicados, raiz e com conflito de montagem de servidor são rejeitados com 400 antes do provisionamento (#2421 #2505)
  • Uma raiz POSIX explícita em storage.allowed_host_paths agora cobre seus descendentes; a verificação descendente produziu // e nunca correspondeu (#2474)
  • Proxy: um GET que declara um corpo é encaminhado com ele, então requisições estilo Elasticsearch param de falhar com 500 (#2518); a exaustão do pool retorna 503 PROXY_POOL_EXHAUSTED em vez de uma espera de 180 segundos terminando em 500 (#2519)
  • Correções menores: metadata=env= filtra o valor vazio em vez de combinar tudo (#2461); validadores de gateway, nome de bucket e nome de ambiente rejeitam novas linhas finais (#2499)

SDKs

As cargas úteis do cofre de credenciais do Exchange (fonte exchange + autenticação de ligação sem tipo) são aceitas em todos os cinco SDKs, alinhadas com o contrato de servidor e de saída (#2534 #2560); consulte a nota Kotlin/C# ABI em Atualização e compatibilidade. Métodos de download detalhados expõem metadados de resposta (status, Content-Range, isPartial) em todos os cinco idiomas; assinaturas existentes inalteradas, implementações de sistemas de arquivos personalizados devem adicioná-las (#1597) ###Python

  • Os fluxos de comando SSE obtêm um tempo limite de leitura: commands.run() aumenta SandboxTimeoutException após max(request_timeout, 30s) de silêncio em vez de bloquear para sempre em um execd parado (#2527)
  • O desligamento normal do pool assíncrono drena mortes pendentes em vez de cancelá-las e deixar sandboxes não rastreadas até o TTL (#2507)
  • Os fluxos de download liberam a resposta HTTP quando descartados, fechados antecipadamente ou abandonados no meio da iteração - não há mais esgotamento do pool de conexões (#2487 #2531)
  • Erros de transporte durante solicitações de fluxo e leituras de corpo geram exceções SDK em vez de vazar erros brutos httpx (#2515 #2525)
  • Correções menores: invalidação do cache do endpoint com escopo para a chave em andamento (#2409); NetworkPolicyAdapter propaga opções de redirecionamento e ganchos de eventos (#2553); o servidor MCP relata erros SDK em vez de uma mensagem genérica (#2524) ###JavaScript
  • Solicitações de sessão isolada lançam SandboxApiException com ID de status/solicitação/código de erro em vez de um Error simples (#2466)
  • Um prazo de redirecionamento infinito ou negativo é tratado como nenhum — requestTimeoutSeconds: Infinity não falha mais em todas as solicitações autenticadas (#2488)
  • Fechar um fluxo de download dentro de seu próprio loop encerra a iteração de forma limpa, em vez de lançar um TypeError (#2514) ###Kotlin
  • Tempo limite de comando inferior a milissegundos arredondado para até 1 ms; 500 µs anteriormente serializados como 0, que execd trata como ilimitado (#2537) ###C# Coberto pelos modelos de troca cross-SDK (#2560).

Vá

  • Reforço de nova tentativa/tempo limite: a saturação Retry-After e o limite de 60 s agora se aplicam ao caminho genérico de nova tentativa (#2452 #2508); backoff satura em vez de envolver negativo (#2509); ReadyTimeout é aplicado em prazos de chamada mais longos (#2528); as sondagens de prontidão do intérprete têm prazos limitados e exigem uma saída zero confirmada (#2504 #2480); POSTs de telemetria obtêm seu próprio limite de cinco segundos (#2540)
  • Cache de endpoint: buscas em andamento protegidas contra invalidação (#2503); mutações do ciclo de vida invalidam endpoints armazenados em cache (#2564); o último garçom saindo cancela a busca compartilhada (#2579); cabeçalhos de configuração/endpoint mesclam sem distinção entre maiúsculas e minúsculas (#2529)
  • Pool: FIFO ocioso sobrevive à remoção/reinserção (#2453); garçons de desligamento honram o cancelamento do chamador (#2542); Destroy limita a drenagem do armazenamento de estado (#2580)
  • Execution.Text() concatena fragmentos de código sem separadores, portanto "Loading" + "...done\n" não ganha mais nova linha; formatação do comando inalterada (#2447)
  • Correções menores: o analisador SSE aceita eventos delimitados por CR (#2439); multipart uploads mantêm seu limite gerado (#2468); uma afirmação de diagnóstico instável verifica net.Error.Timeout() (#2479)

Controlador

  • Os commits de instantâneos do Rootfs cujo resultado não possui resumos agora falham (CommitResultUnavailable/CommitResultIncomplete) e reportam PauseFailed com pods mantidos — pausa anteriormente relatada com sucesso, excluiu os pods e cada retomada posterior falhou permanentemente (#2482)
  • --namespaces faz o escopo do cache do informante, corrigindo OOM de inicialização em grandes clusters compartilhados; o padrão vazio mantém a semântica do cluster completo; valor do gráfico controller.namespaces (#2571)

Executado

  • Os uploads são atômicos: arquivo temporário preparado + renomeação, preservação de modo/proprietário e seguintes links simbólicos — um upload com falha (ENOSPC, erro de E/S, eliminação) não destrói mais o arquivo substituído (#2433)
  • O token Jupyter é descoberto a partir do jpserver-*.json da imagem do interpretador de código quando JUPYTER_TOKEN não está definido; vitórias de configuração explícita (#2448)
  • A espera de inicialização do Jupyter foi restaurada para aproximadamente 5 minutos - uma interação de backoff Cap foi abortada após aproximadamente 11 s contra imagens frias (#2486)
  • EXECD_SSE_LEGACY_COMPAT (padrão desativado) omite exit_code de eventos SSE para SDKs pré-1.0.18 cujo tempo de execução kotlinx falha na chave desconhecida (#2472)
  • filename* é codificado com caracteres de atributo RFC 8187, portanto, nomes com =, :, ' são analisados em clients estritos (#2516)

Rede

saída

  • Credential Vault Exchange (OSEP-0025): fonte exchange (endpoint do resolvedor UDS/HTTPS), autenticação de ligação sem tipo, vinculações de snapshot somente de marcador, um endpoint POST /credential-vault/_resolve e integração de complemento injetando cabeçalhos resolvidos com 407/stream-kill com falha fechada — o material resolvido nunca é persistido, armazenado em cache ou lido novamente; cofres somente inline inalterados (#2457 #2495 #2501 #2500 #2535 #2538); perfil sidecar integrado de ponta a ponta com fast-sandbox e2e (#2549 #2547 #2561); capítulo do guia adicionado (#2563)
  • A autenticação do chamador do resolvedor é adiada (D5): os endpoints do resolvedor https:// devem ser acessíveis somente por saída (permissões UDS ou regras NFT com escopo de rede) como o limite trust atual (#2549)
  • O trabalho de base do OSEP-0023 continua [EXPERIMENTAL]: Leitor seguro do Vault v2 (#2441), gerenciamento legado rigoroso com cerca de proprietário (#2460), gravador Vault v2 de modo estrito com chamador de servidor (#2493) — os padrões permanecem v1; o modo estrito requer o produtor de sandbox rápido emparelhado
  • Um gancho data-plane-ready repetido é idempotente (200) em vez de um 409 espúrio (#2510)

entrada

  • Validação de inicialização: --wake-park-budget deve estar abaixo de --wake-max-flight-lifetime; a configuração incorreta respondeu anteriormente às solicitações estacionadas com 400 ou 200 vazio em vez de 503 + Retry-After (#2511)
  • Uma solicitação de ativação na fila é limitada pelo orçamento de um parque em vez de quase dois (#2513)
  • Correções menores: o status final é registrado após uma resposta 1xx, então 103 Early Hints não se disfarça mais como o status da solicitação (#2484); portas de rota de host herdadas são validadas (sb-70000 não é mais 502s, sb-08080 não atinge mais a porta 8080) (#2578); uma corrida de dados somente de teste corrigida (#2512)

Caixa de areia rápida

  • As cadeias de pontos de verificação permanecem limitadas: as cadeias da camada de pontos de verificação de pausa/restauração são esmagadas por overlaybd-merge durante a confirmação, de modo que ciclos repetidos não aumentam mais a cadeia de restauração sem limite (#2546 fast-sandbox#158)
  • Descoberta de VM local do nó: o tempo de execução do firecracker grava um registro fast-sandbox.json de gravação única por VM – UID completo do sandbox, namespace, nome, posicionamento – próximo ao log do processo, para que os agentes locais do nó descubram VMs locais por varredura de diretório em vez de observar CRs do Sandbox em todo o cluster; a publicação nunca bloqueia o provisionamento e a desmontagem remove o registro (#2546 fast-sandbox#154)
  • Memória: recuperação opcional de memória de convidado com admissão baseada em pressão e relatórios de página livre habilitados por padrão em modelos criados (#2546 fast-sandbox#114)
  • Fortalecimento de Fastlet: transporte de Actions v2 estritamente gerenciado (metade do produtor do receptor de gerenciamento estrito de saída desta versão), correções de corrida de aposentadoria de proprietário, preservação de cerca de terminal em inventário ausente e sondagens de admissão paralelizadas (#2546 fast-sandbox#152)
  • controlador fsb: --namespaces faz o escopo do cache do informante (se recusa a iniciar quando o conjunto perde o namespace do ambiente de tempo de execução) e --kube-client-qps/--kube-client-burst ajusta o limitador de taxa client do servidor API compartilhado — valores de gráfico opt-in controller.namespaces/controller.kubeClientQPS/controller.kubeClientBurst, os padrões não renderizam novos sinalizadores (#2581 caixa de areia rápida#161)
  • Topologia de inicialização: runtime.execd_run_as_init agora incorpora EXECD_INIT=1 em ambientes de modelo de imagem dourada fsb - anteriormente ignorados no fsb, então execd nunca assumiu a função de inicialização OSEP-0018; o valor injetado vence uma chave fornecida por client (#2494); o ambiente de integração fixa a topologia in-guest completa e toda a superfície e2e a padroniza (#2497)
  • Ambiente de integração: compilações de modelo overlaybd investigam o caminho add/del ublk antecipadamente e auto-reparam dispositivos de kernel em vez de falhar cerca de 16 minutos em uma compilação condenada, e a desmontagem libera dispositivos órfãos (#2454); asserções de fumaça revelam erros NFT reais em vez de lê-los como regras ausentes (#2543); um estágio de verificação do resolvedor de troca de cadeia completa (retransmissão do servidor → saída _resolve → cabeçalhos injetados observados pelo convidado) monta verify-native/verify-overlaybd (#2561)

Diversos

  • CLI: o texto é escapado em vez de analisado como marcação Rich — caminhos como /tmp/notes[draft].txt são impressos corretamente e não falham mais em comandos bem-sucedidos (#2520); arquivos de configuração quebrados reportam de forma limpa em vez de travar todos os comandos (#2521); config set armazena valores de chave de string literalmente (007123 permanece 007123) (#2522); a sessão PTY é excluída quando o WebSocket nunca abre (#2523)
  • node-agent: um fluxo de log cujo diretório nunca apareceu é esquecido após a janela de retenção em vez de persistir para sempre (#2471)
  • Documentos: declarações de assinatura de imagem alinhadas com a cobertura real do fluxo de trabalho (#2467); Estatuto da AAIF e consolidação da governança – as contribuições do código agora exigem aprovações do DCO (#2490); Exemplos de modelos S3 definem format: native (#2506); Status OSEP-0025 e pinos de contrato (#2539)
  • Housekeeping: código morto removido entre módulos (#2496); execd CI monta tracefs para a fumaça eBPF (#2473)

  • Fast Sandbox: relatórios de página gratuita ativados por padrão; registro fast-sandbox.json por VM; controller.namespaces deve cobrir pools/sandboxes e o namespace do ambiente de tempo de execução ou o controlador se recusa a iniciar (#2546 #2581)

OpenSandbox release-1.2.1-rc.1

First release candidate on the 1.2.1 patch line, cut from release-1.2.0 (2026-10-27). Headline: OSEP-0025 Credential Vault Exchange — an exchange credential source with per-request header resolution through a pluggable resolver, wired end to end across egress, server, all five SDKs, fast-sandbox e2e, and the Credential Vault guide. Also notable: execd atomic uploads, digest validation for rootfs snapshots, Kubernetes create-timeout startup diagnostics, and informer-cache scoping for large clusters. Baseline for every section is release-1.2.0. rc releases publish images but hold packages — SDK/CLI artifacts ship at the 1.2.1 stable bump.

Highlights

  • Credential Vault Exchange (OSEP-0025): per-request dynamic header resolution, fail-closed and never persisted, across server and all five SDKs (#2457 #2535 #2534 #2560)
  • Data-safety: execd uploads replace atomically so a failed write keeps the old file (#2433); the controller refuses rootfs snapshots whose commit result lacks digests (#2482)
  • Operability: create timeouts report the pod startup failure reason (#2434); controller and fsb controller gain --namespaces cache scoping (#2571 #2581)

Server

  • Sandbox list pushes metadata equality filters into the Kubernetes label selector, so large namespaces no longer materialize every workload before filtering (#2559)
  • Template OCI hardening: publish repository syntax is validated at create, and sandbox creation requires a digest-pinned publish reference — a succeeded template can no longer resolve to a mutable or unrelated manifest (#2491)
  • Kubernetes create timeouts append the pod startup failure reason (unschedulable, ImagePullBackOff, warning events) before rollback — image pull and scheduling failures are diagnosable through the API again (#2434)
  • Docker: a concurrent container removal no longer aborts the startup expiration restore, and remaining Docker errors fail startup instead of silently dropping timers (#2533); duplicate, root, and server-mount-clashing destinations are rejected with 400 before provisioning (#2421 #2505)
  • An explicit POSIX root in storage.allowed_host_paths now covers its descendants; the descendant check produced // and never matched (#2474)
  • Proxy: a GET that declares a body is forwarded with it, so Elasticsearch-style requests stop failing with 500 (#2518); pool exhaustion returns 503 PROXY_POOL_EXHAUSTED instead of a 180-second wait ending in 500 (#2519)
  • Smaller fixes: metadata=env= filters on the empty value instead of matching everything (#2461); gateway, bucket-name, and env-name validators reject trailing newlines (#2499)

SDKs

Exchange credential vault payloads (exchange source + typeless binding auth) are accepted across all five SDKs, aligned with the server and egress wire contract (#2534 #2560); see the Kotlin/C# ABI note in Upgrade & Compatibility. Detailed download methods expose response metadata (status, Content-Range, isPartial) in all five languages; existing signatures unchanged, custom filesystem implementations must add them (#1597)

Python

  • SSE command streams get a read timeout: commands.run() raises SandboxTimeoutException after max(request_timeout, 30s) of silence instead of blocking forever on a stalled execd (#2527)
  • Async pool graceful shutdown drains pending kills instead of cancelling them and leaving untracked sandboxes until TTL (#2507)
  • Download streams release the HTTP response when dropped, closed early, or abandoned mid-iteration — no more connection-pool exhaustion (#2487 #2531)
  • Transport errors during stream requests and body reads raise SDK exceptions instead of leaking raw httpx errors (#2515 #2525)
  • Smaller fixes: endpoint cache invalidation scoped to the inflight key (#2409); NetworkPolicyAdapter propagates redirect options and event hooks (#2553); the MCP server reports SDK errors instead of a generic message (#2524)

JavaScript

  • Isolated-session requests throw SandboxApiException with status/request id/error code instead of a flat Error (#2466)
  • An infinite or negative redirect deadline is treated as none — requestTimeoutSeconds: Infinity no longer fails every authenticated request (#2488)
  • Closing a download stream inside its own loop ends iteration cleanly instead of throwing a TypeError (#2514)

Kotlin

  • Sub-millisecond command timeouts round up to 1 ms; 500 µs previously serialized as 0, which execd treats as unbounded (#2537)

C#

Covered by the cross-SDK exchange models (#2560).

Go

  • Retry/timeout hardening: Retry-After saturation and the 60 s cap now apply on the generic retry path (#2452 #2508); backoff saturates instead of wrapping negative (#2509); ReadyTimeout is enforced under longer caller deadlines (#2528); interpreter readiness probes are deadline-bounded and require a confirmed zero exit (#2504 #2480); telemetry POSTs get their own five-second bound (#2540)
  • Endpoint cache: in-flight fetches fenced across invalidation (#2503); lifecycle mutations invalidate cached endpoints (#2564); the last waiter leaving cancels the shared fetch (#2579); config/endpoint headers merge case-insensitively (#2529)
  • Pool: idle FIFO survives remove/reinsert (#2453); shutdown waiters honor caller cancellation (#2542); Destroy bounds state-store draining (#2580)
  • Execution.Text() concatenates code fragments without separators, so "Loading" + "...done\n" no longer gains a newline; command formatting unchanged (#2447)
  • Smaller fixes: SSE parser accepts CR-delimited events (#2439); multipart uploads keep their generated boundary (#2468); a flaky diagnostic assertion checks net.Error.Timeout() (#2479)

Controller

  • Rootfs snapshot commits whose result lacks digests now fail (CommitResultUnavailable/CommitResultIncomplete) and report PauseFailed with pods kept — previously pause reported success, deleted the pods, and every later resume failed permanently (#2482)
  • --namespaces scopes the informer cache, fixing startup OOM on large shared clusters; empty default keeps full-cluster semantics; chart value controller.namespaces (#2571)

Execd

  • Uploads are atomic: staged temp file + rename, preserving mode/owner and following symlinks — a failed upload (ENOSPC, I/O error, kill) no longer destroys the replaced file (#2433)
  • The Jupyter token is discovered from the code-interpreter image's jpserver-*.json when JUPYTER_TOKEN is unset; explicit config wins (#2448)
  • The Jupyter startup wait is restored to ~5 minutes — a backoff Cap interaction had aborted after ~11 s against cold images (#2486)
  • EXECD_SSE_LEGACY_COMPAT (default off) omits exit_code from SSE events for pre-1.0.18 SDKs whose kotlinx runtime crashes on the unknown key (#2472)
  • filename* is encoded with RFC 8187 attr-chars, so names with =, :, ' parse in strict clients (#2516)

Networking

egress

  • Credential Vault Exchange (OSEP-0025): exchange source (UDS/HTTPS resolver endpoint), typeless binding auth, marker-only snapshot bindings, a POST /credential-vault/_resolve endpoint, and addon integration injecting resolved headers with fail-closed 407/stream-kill — resolved material is never persisted, cached, or read back; inline-only vaults unchanged (#2457 #2495 #2501 #2500 #2535 #2538); sidecar profile integrated end to end with fast-sandbox e2e (#2549 #2547 #2561); guide chapter added (#2563)
  • Resolver caller auth is deferred (D5): https:// resolver endpoints must be egress-only reachable (UDS permissions or network-scoped nft rules) as the current trust boundary (#2549)
  • OSEP-0023 groundwork continues [EXPERIMENTAL]: Vault v2 safe reader (#2441), strict legacy management with owner fencing (#2460), strict-mode Vault v2 writer with server caller (#2493) — defaults remain v1; strict mode requires the paired fast-sandbox producer
  • A replayed data-plane-ready hook is idempotent (200) instead of a spurious 409 (#2510)

ingress

  • Startup validation: --wake-park-budget must be below --wake-max-flight-lifetime; the misconfiguration previously answered parked requests with 400 or empty 200 instead of 503 + Retry-After (#2511)
  • A queued wake request is bounded by one park budget instead of nearly two (#2513)
  • Smaller fixes: the final status is recorded after a 1xx response, so 103 Early Hints no longer masquerades as the request status (#2484); legacy host-route ports are validated (sb-70000 no longer 502s, sb-08080 no longer reaches port 8080) (#2578); a test-only data race fixed (#2512)

Fast Sandbox

  • Checkpoint chains stay bounded: pause/restore checkpoint layer chains are squashed through overlaybd-merge during commit, so repeated cycles no longer grow the restore chain without limit (#2546 fast-sandbox#158)
  • Node-local VM discovery: the firecracker runtime writes a write-once fast-sandbox.json record per VM — full sandbox UID, namespace, name, placement — next to the process log, so node-local agents discover local VMs by directory scan instead of watching Sandbox CRs cluster-wide; publication never blocks provisioning and teardown removes the record (#2546 fast-sandbox#154)
  • Memory: opt-in guest memory reclamation with pressure-based admission, and free-page reporting enabled by default in built templates (#2546 fast-sandbox#114)
  • Fastlet hardening: the strict managed Actions v2 transport (producer half of this release's egress strict-management receiver), owner-retirement race fixes, terminal-fence preservation across absent inventory, and parallelized admission probes (#2546 fast-sandbox#152)
  • fsb controller: --namespaces scopes the informer cache (refuses to start when the set misses the runtime-environment namespace) and --kube-client-qps/--kube-client-burst tune the shared API-server client rate limiter — opt-in chart values controller.namespaces/controller.kubeClientQPS/controller.kubeClientBurst, defaults render no new flags (#2581 fast-sandbox#161)
  • Init topology: runtime.execd_run_as_init now bakes EXECD_INIT=1 into fsb golden-image template envs — previously ignored on fsb, so execd never took the OSEP-0018 init role; the injected value wins over a client-provided key (#2494); the integration environment pins the full in-guest topology and the whole e2e surface defaults it on (#2497)
  • Integration environment: overlaybd template builds probe the ublk add/del path up front and self-heal wedged kernel devices instead of failing ~16 minutes into a doomed build, and teardown releases orphan devices (#2454); smoke assertions surface real nft errors instead of reading them as missing rules (#2543); a full-chain exchange-resolver verify stage (server relay → egress _resolve → injected headers observed by the guest) rides verify-native/verify-overlaybd (#2561)

Misc

  • CLI: text is escaped instead of parsed as Rich markup — paths like /tmp/notes[draft].txt print correctly and no longer fail successful commands (#2520); broken config files report cleanly instead of crashing every command (#2521); config set stores string-key values verbatim (007123 stays 007123) (#2522); the PTY session is deleted when the WebSocket never opens (#2523)
  • node-agent: a log stream whose directory never appeared is forgotten after the retention window instead of persisting forever (#2471)
  • Docs: image-signing claims aligned with actual workflow coverage (#2467); AAIF charter and governance consolidation — code contributions now require DCO sign-offs (#2490); S3 template examples set format: native (#2506); OSEP-0025 status and contract pins (#2539)
  • Housekeeping: dead code removed across modules (#2496); execd CI mounts tracefs for the eBPF smoke (#2473)

Upgrade & Compatibility

  • Kotlin/C# SDKs are source-compatible but not ABI-compatible with 1.2.0 — recompile; no wire changes (#2560)
  • Python: silent SSE streams now raise SandboxTimeoutException after max(request_timeout, 30s) (#2527); download-body errors raise SDK exceptions instead of raw httpx errors (#2525)
  • Go: Execution.Text() no longer inserts separators between code fragments (#2447); nonempty positional Execution{...} literals no longer compile — use keyed literals
  • Execd atomic uploads: writable file in non-writable directory is rejected, device/FIFO destinations refused, xattrs/ACLs/setgid bits not carried, bind-mounted destinations fail (EBUSY), a SIGKILL mid-upload can leave a .osb-upload-* staging file, peak disk ~3× file size (#2433)
  • Server startup: a Docker error during expiration restore (other than concurrent removal) now prevents startup — run under a restarting supervisor (#2533)
  • Ingress: --wake-park-budget below --wake-max-flight-lifetime is now enforced at startup; defaults unaffected (#2511)
  • Template list: metadata=env= now filters on the empty value (#2461)
  • OSEP-0025: exchange is additive and opt-in, but resolver caller auth is deferred — https:// resolver endpoints must be egress-only reachable (#2549 #2563)
  • Fast Sandbox: free-page reporting on by default; per-VM fast-sandbox.json record; controller.namespaces must cover pools/sandboxes and the runtime-environment namespace or the controller refuses to start (#2546 #2581)
  • Images: opensandbox/<component>:release-1.2.1-rc.1 (all three registries; fsb images for fast-sandbox)
  • Packages: unchanged — SDK/CLI artifacts publish at the 1.2.1 stable release
  • Charts: render from this tag (helm template ./manifests/charts/opensandbox)
  • Kubernetes: supported range v1.21 – v1.34
  • Skew: server ↔ CLI/SDK same line supported; ±1 minor warns
