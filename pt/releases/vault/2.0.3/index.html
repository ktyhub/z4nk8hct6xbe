cofre v2.0.3

SEGURANÇA:

  • auth/radius: Adicionada alternância case_insensitive_names para evitar colisões de nomes de usuário e permitir o tratamento de usuários sem distinção entre maiúsculas e minúsculas.
  • core/acl: Corrige o desvio de LIST ACL onde uma solicitação de barra final poderia ignorar uma regra de negação mais específica.
  • core: Use comparação de token de recuperação em tempo constante
  • secrets/spiffe (enterprise): certifique-se de que os valores do modelo tenham escape adequado.
  • transform (enterprise): Adicione cotação específica apropriada do banco de dados e escaping. MUDANÇAS:
  • auth/cf: Atualizar plugin para v0.23.1
  • core/acl: Solicitações LIST com uma barra final agora respeitam corretamente políticas de negação mais específicas. Anteriormente, uma negação em path "kv/*" { deny } poderia ser ignorada para LIST kv/private/ se também existisse uma permissão mais ampla de path "kv/*". As políticas que se baseiam no comportamento anterior (incorreto) podem agora ser negadas.
  • core: o Vault agora redirecionará caminhos não canônicos (contendo /./, /../ ou //) para um caminho limpo, em vez de rejeitar essas solicitações
  • secrets/azure: Atualize o plugin para v0.26.5+ent RECURSOS:
  • Suporte a agentes de IA (Beta/Enterprise): Adiciona suporte beta para agentes de IA de primeira classe. Adiciona um registro de agente para registrar agentes e adiciona suporte para usar o Vault como um servidor de recursos OAuth para entidades agentes registradas. Quando configurado, permite que JWTs OAuth 2.0 sejam usados para autorizar diretamente solicitações para o Vault, sem precisar de um token do Vault. MELHORIAS:
  • faturamento de consumo: Adicione um novo endpoint sys/billing/config para permitir a configuração da retenção de dados de faturamento (mínimo 13 meses, máximo 6 anos).
  • core (Enterprise): Torne a detecção de deadlock no sealwrap configurável adicionando "sealwrap" à configuração existente detect_deadlocks. *identity/scim (enterprise): Atualizar operações PATCH em scim/v2/Users para permitir múltiplas modificações na mesma chamada de patch, suporte para operações de patch em metadados e nome do usuário, além do status ativo, e permitir a especificação do valor path em operações de patch
  • sdk/helper/keysutil: A função GetPolicy do gerenciador de bloqueio agora sempre retorna uma política bloqueada, mesmo quando o cache é habilitado. A estrutura PolicyRequest possui um novo campo para indicar se o chamador requer um bloqueio de gravação na política.
  • ui (empresa): migre gráficos de gráficos lineares para gráficos de carbono na visão geral de uso do Client e no painel de uso do Vault. CORREÇÕES DE ERROS:
  • core/rotationMgr: corrige o roteamento de armazenamento para montagens locais em namespaces para evitar a replicação de metadados e garantir a conformidade com o GDPR.
  • kmip (empresa): Corrige um bug que impede que a CA legada funcione em um ouvinte nomeado.
  • secret-sync (enterprise): corrige a persistência da política de replicação do GCP Secret Manager nas reinicializações do Vault.
  • secrets/database/mssql: Cancela o registro de configurações TLS obsoletas quando as configurações TLS da conexão MySQL mudam ou a conexão é fechada, evitando o acúmulo de conjuntos de certificados retidos.
  • secrets/pki: corrige a emissão do certificado PKI not_after time para respeitar o TTL máximo.
  • segredos/trânsito: Adicione suporte de chave gerenciada ao endpoint de reformulação do Transit.
  • armazenamento/jangada: rejeitar valores performance_multiplier menores ou iguais a zero

vault v2.0.3

SECURITY:

  • auth/radius: Added case_insensitive_names toggle to prevent username collisions and enable case-insensitive user handling.
  • core/acl: Fix LIST ACL bypass where a trailing-slash request could skip a more-specific deny rule.
  • core: Use constant-time recovery token comparison
  • secrets/spiffe (enterprise): Ensure template values are properly escaped.
  • transform (enterprise): Add appropriate db specific quoting and escaping.

CHANGES:

  • auth/cf: Update plugin to v0.23.1
  • core/acl: LIST requests with a trailing slash now correctly respect more-specific deny policies. Previously, a deny on path "kv/*" { deny } could be bypassed for LIST kv/private/ if a broader allow path "kv/*" also existed. Policies relying on the previous (incorrect) behavior may now be denied.
  • core: Vault will now redirect non-canonicalized paths (containing /./, /../, or //) to a cleaned path, instead of rejecting these requests
  • secrets/azure: Update plugin to v0.26.5+ent

FEATURES:

  • AI Agent Support (Beta/Enterprise): Adds beta support for first-class AI agents. Adds an Agent Registry to register agents, and adds support for using Vault as an OAuth resource server for registered agent entities. When configured, allows OAuth 2.0 JWTs to be used to directly authorize requests to Vault, without needing a Vault token.

IMPROVEMENTS:

  • consumption-billing: Add a new sys/billing/config endpoint to allow configuration of billing data retention (min 13 months, max 6 years).
  • core (Enterprise): Make deadlock detection in sealwrap configurable by adding "sealwrap" to existing configuration detect_deadlocks.
  • identity/scim (enterprise): Update PATCH operations on scim/v2/Users to allow multiple modifications in the same patch call, support for patch operations on user metadata and name in addition to active status, and allow specifying path value in patch operations
  • sdk/helper/keysutil: The lock manager's GetPolicy function now always returns a locked Policy, even when caching is enabled. The PolicyRequest struct has a new field to indicate whether the caller requires a write lock on the policy.
  • ui (enterprise): Migrate charts from Lineal to Carbon Charts in the Client usage overview and Vault usage dashboard.

BUG FIXES:

  • core/rotationMgr: Fix storage routing for local mounts in namespaces to prevent metadata replication and ensure GDPR compliance.
  • kmip (enterprise): Fix a bug that prevents the legacy CA from working on a named listener.
  • secret-sync (enterprise): Fix GCP Secret Manager replication policy persistence across Vault restarts.
  • secrets/database/mssql: Deregister stale TLS configurations when MySQL connection TLS settings change or the connection is closed, preventing retained certificate pools from accumulating.
  • secrets/pki: Fix PKI certificate issuance not_after time to respect max TTL.
  • secrets/transit: Add managed key support to Transit rewrap endpoint.
  • storage/raft: reject performance_multiplier values less than or equal to zero
