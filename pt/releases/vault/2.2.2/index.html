cofre v2.2.2

12 de novembro de 2026

SEGURANÇA:

  • core/acl: fortalece a avaliação explícita da regra de negação combinando os caminhos solicitados sem distinção entre maiúsculas e minúsculas. MUDANÇAS:
  • auth/alicloud: Atualizar plugin para v0.24.1
  • auth/cf: Atualizar plugin para v0.24.1
  • auth/jwt: Atualizar plugin para v0.27.2
  • auth/kerberos: Atualizar plugin para v0.18.1
  • auth/oci: Atualizar plugin para v0.22.1
  • núcleo: versão Bump Go para 1.27.4
  • core/acl: Corrige um problema em que regras de política de negação explícitas não eram aplicadas contra variantes de caso do caminho negado. As regras de negação explícitas agora também correspondem ao caminho solicitado sem distinção entre maiúsculas e minúsculas, sujeitas à especificidade usual da regra. Por exemplo, uma negação em secret/data/example agora também nega solicitações a secret/data/EXAMPLE.
  • banco de dados/couchbase: Atualizar plugin para v0.17.1
  • banco de dados/elasticsearch: Atualizar plugin para v0.21.1
  • database/mongodbatlas: Atualizar plugin para v0.18.1
  • banco de dados/redis: Atualizar plugin para v0.9.1
  • banco de dados/floco de neve: atualize o plugin para v0.17.1
  • proxy/agente: plug-ins personalizados ou integrações que retornam HTML interativo por meio de agente ou proxy não serão mais renderizados interativamente em um navegador.
  • secrets/alicloud: Atualizar plugin para v0.23.1
  • secrets/azure: Atualizar plugin para v0.28.5+ent
  • secrets/keymgmt: Atualizar plugin para v0.20.2+ent
  • secrets/mongodbatlas: Atualize o plugin para v0.18.1
  • secrets/terraform: Atualizar plugin para v0.15.1 MELHORIAS:
  • core: inclui o ID do namespace nos logs de falhas de configuração de montagem
  • núcleo: atualize github.com/go-jose/go-jose/v4 para v4.1.6 e golang.org/x/net para v0.62.0
  • ui: Mostra "Nunca" como a última rotação do Vault na página de credenciais da função LDAP quando uma função estática não foi rotacionada, em vez de uma data no ano 0001. CORREÇÕES DE ERROS:
  • Trânsito (corporativo): correção de bug de cache que fazia com que valores auto_rotate_period diferentes de zero fossem gravados no cache com chaves gerenciadas
  • agente/pki-external-ca (empresa): corrige a reemissão prematura do certificado na reautenticação de autenticação automática para que a renovação do certificado respeite percent_renew_before_expiry em vez de ser acionada por atualizações de token.
  • auditoria: corrigido um bug em que o Vault retornava HTTP 500 quando uma resposta grande (por exemplo, uma solicitação PKI ?help=1) não podia ser gravada em um dispositivo de auditoria syslog devido ao limite de tamanho do soquete de datagrama do sistema operacional Unix (EMSGSIZE / ENOBUFS). O coletor de syslog agora divide cargas úteis de auditoria superdimensionadas em pedaços de tamanho seguro e tenta novamente buffers de soquete completos transitoriamente.
  • auditoria: corrige um pânico que pode ocorrer quando o corretor de auditoria não é inicializado durante a desmontagem.
  • auth/approle: rejeita SecretIDs expirados durante o login, em vez de depender de uma limpeza periódica.
  • auth/spiffe (empresa): Corrige um problema em que os tokens renováveis não estavam sendo renovados
  • core (enterprise): Corrige um pânico e criação parcial de namespace quando a montagem do registro do agente raiz está indisponível
  • núcleo/censo (empresa): corrige o relatório do medidor do censo previous_month_complete como 0 no primeiro mês após a rolagem automática da data de início do faturamento, para que a contagem final de client do ciclo de faturamento anterior seja relatada.
  • core/plugin: Corrige um problema em que o mecanismo de segredos externos e os plug-ins de autenticação permaneciam somente leitura após falha no carregamento durante a inicialização ou remoção do lacre. Os operadores agora podem restaurar o binário ou registro ausente e recarregar o plug-in para retomar as gravações sem reiniciar o Vault.
  • core: Corrige um problema em que a correspondência do caminho da política poderia ser inconsistente para solicitações que diferem apenas por uma barra final. *identidade: Use o resolvedor de conflitos de relatório apenas ao recarregar no modo que diferencia maiúsculas de minúsculas, para evitar a coleta de duplicatas após a remoção do lacre.
  • pki-external-ca: Corrige a exclusão prematura de registros de certificados revogados durante a limpeza; pedidos revogados agora são retidos até a data NotAfter do certificado, em vez da data de vencimento do pedido ACME
  • secrets/azure: continua a limpeza permanente do aplicativo quando o aplicativo ativo já estiver ausente, permitindo tentativas de limpeza posteriores para tentar novamente a limpeza.
  • secrets/azure: Tente novamente erros transitórios do Microsoft Graph 403/404 ao adicionar entidades de serviço recém-criadas a grupos do Azure.
  • secrets/kv: Corrigido um problema no KV v1 em que escrever um caminho secreto contendo barras consecutivas fazia com que as operações de lista retornassem "/" como uma entrada de diretório, produzindo um loop infinito na localização atual da IU do Vault.
  • tpm: tpm auth agora respeita a opção InsecureSkipVerify
  • ui: Corrige a página de visão geral do banco de dados para listar funções dinâmicas e estáticas e permitir a geração de credenciais e restaurar a guia Funções para usuários com apenas permissões de função estática
  • ui: corrige a paginação na tabela da lista de entidades
  • proxy do vault: suporta o método tpm no bloco auto_auth para corresponder à paridade com o agente.

vault v2.2.2

November 12, 2026

SECURITY:

  • core/acl: Harden explicit deny rule evaluation by matching requested paths case-insensitively.

CHANGES:

  • auth/alicloud: Update plugin to v0.24.1
  • auth/cf: Update plugin to v0.24.1
  • auth/jwt: Update plugin to v0.27.2
  • auth/kerberos: Update plugin to v0.18.1
  • auth/oci: Update plugin to v0.22.1
  • core: Bump Go version to 1.27.4
  • core/acl: Fix an issue where explicit deny policy rules were not enforced against case variants of the denied path. Explicit deny rules now also match the requested path case-insensitively, subject to the usual rule specificity. For example, a deny on secret/data/example now also denies requests to secret/data/EXAMPLE.
  • database/couchbase: Update plugin to v0.17.1
  • database/elasticsearch: Update plugin to v0.21.1
  • database/mongodbatlas: Update plugin to v0.18.1
  • database/redis: Update plugin to v0.9.1
  • database/snowflake: Update plugin to v0.17.1
  • proxy/agent: Custom plugins or integrations that return interactive HTML through Agent or Proxy will no longer render interactively in a browser.
  • secrets/alicloud: Update plugin to v0.23.1
  • secrets/azure: Update plugin to v0.28.5+ent
  • secrets/keymgmt: Update plugin to v0.20.2+ent
  • secrets/mongodbatlas: Update plugin to v0.18.1
  • secrets/terraform: Update plugin to v0.15.1

IMPROVEMENTS:

  • core: Include the namespace ID in mount setup failure logs
  • core: Update github.com/go-jose/go-jose/v4 to v4.1.6 and golang.org/x/net to v0.62.0
  • ui: Show "Never" as the last Vault rotation on the LDAP role credentials page when a static role has not been rotated, instead of a date in year 0001.

BUG FIXES:

  • Transit (enterprise): Fix cache bug that led to non-zero auto_rotate_period values being written to the cache with managed keys
  • agent/pki-external-ca (enterprise): Fix premature certificate reissuance on auto-auth re-authentication so certificate renewal respects percent_renew_before_expiry instead of being triggered by token updates.
  • audit: Fixed a bug where Vault returned HTTP 500 when a large response (e.g. a PKI ?help=1 request) could not be written to a syslog audit device due to the OS Unix datagram socket size limit (EMSGSIZE / ENOBUFS). The syslog sink now splits oversized audit payloads into safe-sized chunks and retries transiently full socket buffers.
  • audit: Fixes a panic that can occur when audit broker not initialized during teardown.
  • auth/approle: Reject expired SecretIDs during login instead of relying on periodic tidy cleanup.
  • auth/spiffe (enterprise): Fix an issue where renewable tokens were not being renewed
  • core (enterprise): Fix a panic and partial namespace creation when the root agent-registry mount is unavailable
  • core/census (enterprise): Fix the previous_month_complete census gauge reporting 0 in the first month after the billing start date auto-rolls, so the previous billing cycle's final client count is reported.
  • core/plugin: Fix an issue where external secrets engine and auth plugins remained read-only after failing to load during startup or unseal. Operators can now restore the missing binary or registration and reload the plugin to resume writes without restarting Vault.
  • core: Fix an issue where policy path matching could be inconsistent for requests that differ only by a trailing slash.
  • identity: Use the reporting conflict resolver only while reloading in case-sensitive mode, to avoid collecting duplicates after unseal.
  • pki-external-ca: Fix premature deletion of revoked certificate records during tidy; revoked orders are now retained until the certificate's NotAfter date rather than the ACME order expiry
  • secrets/azure: Continue permanent application cleanup when the active application is already absent, allowing later cleanup attempts to retry the purge.
  • secrets/azure: Retry transient Microsoft Graph 403/404 errors when adding newly created service principals to Azure groups.
  • secrets/kv: Fixed an issue in KV v1 where writing a secret path containing consecutive slashes caused list operations to return "/" as a directory entry, producing an infinite loop in the Vault UI breadcrumb.
  • tpm: tpm auth now respects the InsecureSkipVerify option
  • ui: Fix the database overview page to list both dynamic and static roles and allow credential generation, and restore the Roles tab for users with only static-role permissions
  • ui: fixes pagination on entities list table
  • vault proxy: Support tpm method in the auto_auth block to match parity with agent.
