Servidores Python: mudanças para clients

mcp-server-fetch, mcp-server-git e mcp-server-time não possuem CHANGELOG, então aqui está o que muda para um client em 2026.10.19. Eles agora são construídos no MCPServer de alto nível do MCP Python SDK (#5175).

  • Ferramenta desconhecida: um erro JSON-RPC -32602 (Unknown tool: <name>) em ambas as eras do protocolo, conforme exigido pelas especificações. Costumava ser um resultado isError.
  • Erros de ferramenta leia Error executing tool <name>: <message>. Erros de validação de argumentos agora usam o texto do pydantic. Ambos ainda são resultados isError.
  • Capacidades: cada servidor agora anuncia as capacidades prompts e resources (com listChanged: false). o prompt fetch do fetch é a única entrada nessas listas.
  • tempo: get_current_time e convert_time declaram um outputSchema e retornam structuredContent. O conteúdo do texto permanece inalterado.
  • fetch: o description de um resultado prompts/get agora é sempre a descrição registrada do prompt.
  • Requer mcp>=2.3,<3.

Python servers: changes for clients

mcp-server-fetch, mcp-server-git and mcp-server-time have no CHANGELOG, so here is what changes for a client in 2026.10.19. They are now built on the MCP Python SDK's high-level MCPServer (#5175).

  • Unknown tool: a JSON-RPC -32602 error (Unknown tool: <name>) in both protocol eras, as the spec requires. It used to be an isError result.
  • Tool errors read Error executing tool <name>: <message>. Argument-validation errors now use pydantic's wording. Both are still isError results.
  • Capabilities: each server now advertises prompts and resources capabilities (with listChanged: false). fetch's fetch prompt is the only entry in those lists.
  • time: get_current_time and convert_time declare an outputSchema and return structuredContent. The text content is unchanged.
  • fetch: a prompts/get result's description is now always the prompt's registered description.
  • Requires mcp>=2.3,<3.
