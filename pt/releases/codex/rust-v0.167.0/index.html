#códice rust-v0.167.0

Novos recursos

  • Abra o centro de comando do agente com codex agents --no-daemon. O centro de comando e o seletor de sessão agora marcam resultados não lidos (#58238, #58239, #58263, #58264).
  • Alterne entre back-ends conectados no seletor de sessão do terminal e mantenha seus rascunhos ao alternar (#58280, #58457).
  • Visualize anexos de imagens locais enquanto compõe em terminais suportados e abra imagens locais visualizadas de caminhos de transcrição clickable (#58261, #58446).
  • Encontre as opções de chave API e provedor de nuvem em “Fazer login de outra maneira”. Ative gcp_setup_wizard para configurar o Google Cloud Vertex AI com credenciais padrão do aplicativo ou um arquivo de credencial (#57857, #58427).
  • Ative as configurações de proxy do sistema macOS ou Windows em /experimental (#58157).
  • Expanda os detalhes do patch diretamente na transcrição enquanto um prompt de aprovação estiver aberto (#58281).

Correções de bugs

  • Os bate-papos salvos permanecem visíveis depois que você troca de provedor de modelo. Se um bate-papo não puder ser retomado, você poderá ler sua transcrição e preparar um aviso editável para continuar em um novo bate-papo (#58202).
  • Ctrl+L limpa o display do terminal enquanto mantém mensagens anteriores disponíveis através de Ctrl+T (#58266).
  • Excluir texto que expõe um ! inicial mantém um rascunho comum no modo de bate-papo (#58412).
  • Os prompts de aprovação da rede fecham quando suas solicitações terminam. Solicitações simultâneas para o mesmo endpoint solicitam uma de cada vez (#58350, #58351).
  • Longas conversas V3 em tempo real salvam a fala concluída no histórico de bate-papo à medida que a transcrição aumenta (#58221).
  • A compactação automática de contexto agora é responsável pela saída retida de respostas com falha e respostas com dados de uso de token ausentes (#58404).

Documentação

  • O README do servidor de aplicativos cobre restrições de rede gerenciadas sob regras de comando [permissions.network] e prompt-user que exigem nova aprovação humana (#58045, #58182).
  • A habilidade openai-docs recomenda a substituição documentada ao migrar de um modelo obsoleto (#58134).

  • Os manifestos DotSlash agora fazem referência aos pacotes Cargo enviados com o lançamento (#58717, #58757).

codex rust-v0.167.0

New Features

  • Open the agent command center with codex agents --no-daemon. The command center and session picker now mark unread results (#58238, #58239, #58263, #58264).
  • Switch between connected backends from the terminal session picker and keep your drafts when switching (#58280, #58457).
  • Preview local image attachments while composing on supported terminals, and open viewed local images from clickable transcript paths (#58261, #58446).
  • Find API key and cloud provider options under “Sign in another way.” Enable gcp_setup_wizard to set up Google Cloud Vertex AI with Application Default Credentials or a credential file (#57857, #58427).
  • Opt into macOS or Windows system proxy settings from /experimental (#58157).
  • Expand patch details directly in the transcript while an approval prompt is open (#58281).

Bug Fixes

  • Saved chats stay visible after you switch model providers. If a chat can’t resume, you can read its transcript and prepare an editable prompt to continue in a new chat (#58202).
  • Ctrl+L clears the terminal display while keeping earlier messages available through Ctrl+T (#58266).
  • Deleting text that exposes a leading ! keeps an ordinary draft in chat mode (#58412).
  • Network approval prompts close when their requests end. Concurrent requests to the same endpoint prompt one at a time (#58350, #58351).
  • Long realtime V3 conversations save completed speech to chat history as the transcript grows (#58221).
  • Automatic context compaction now accounts for retained output from failed responses and responses with missing token usage data (#58404).

Documentation

  • The app-server README covers managed network constraints under [permissions.network] and prompt-user command rules that require fresh human approval (#58045, #58182).
  • The openai-docs skill recommends the documented replacement when migrating away from a deprecated model (#58134).

Chores

  • DotSlash manifests now reference the Cargo packages shipped with the release (#58717, #58757).
  • Linux musl builds use fewer allocator arenas to reduce idle memory after conversations unload (#58399).
