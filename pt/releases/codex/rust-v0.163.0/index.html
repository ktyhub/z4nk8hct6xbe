#códice rust-v0.163.0

Novos recursos

  • Abra /config para pesquisar preferências em categorias, alterar as configurações suportadas imediatamente e ver quais alterações exigem reinicialização. (#52990, #53429)
  • Envie um acompanhamento enquanto o Codex estiver respondendo para orientá-lo imediatamente. Interromper um turno também interrompe as células ativas do modo de código e suas chamadas de ferramenta aninhadas. (#51812, #51835)
  • Configure uma chave líder em /keymap. O padrão é Ctrl+X, as dicas de atalho permanecem abertas até você escolher ou cancelar e o silenciamento de voz passa para F9. (#52273)
  • Reinicie um servidor gerenciado em segundo plano do /daemon. O Codex avisa sobre o trabalho que a reinicialização pode interromper e depois se reconecta automaticamente. (#53173)
  • O Codex pode executar ferramentas independentes somente leitura em paralelo, incluindo pesquisas de habilidades, memória e histórico de conversas. (#52245)
  • Daybreak está habilitado por padrão para contas qualificadas. codex exec também pode selecioná-lo com uma chave OpenAI API quando o servidor oferecer acesso. (#53701, #53717)

Correções de bugs

  • A retomada de um thread salvo restaura suas permissões e aprovações de rede, respeitando as substituições explícitas e a política gerenciada atual. (#53150, #53419, #53424)
  • O proxy de rede agora verifica a permissão antes de uma pesquisa de DNS, rejeita cabeçalhos Host duplicados e evita que aliases de credenciais contornem os ganchos de inspeção. (#51650, #52661, #53506)
  • Retorne a uma conversa paralela existente com /side após trocar de tópico. As respostas às solicitações pendentes também remontam ao tópico que solicitou. (#52184, #53436)
  • No Windows, Ctrl+V e Shift+Insert colam texto e também imagens. No WSL, as colas repetidas reutilizam o leitor clipboard e as tentativas de cópia atingem o tempo limite em vez de travar. (#53224, #52967, #53453)
  • Os comandos locais terminam imediatamente quando um filho mantém um canal de saída aberto. Os comandos remotos preservam a saída atrasada para que a pesquisa final ainda possa coletá-la. (#52652, #53331, #53622)
  • codex exec não imprime mais o mesmo arquivo diff novamente após um comando não relacionado. (#53444)

Documentação

  • Atualizada a orientação do OpenAI Docs para migrações para a família GPT-6, incluindo raciocínio específico do modelo, uso de ferramentas e considerações de residência de dados. (#51768)
  • Esclarecido como o sandbox do Linux usa bubblewrap para isolamento do sistema de arquivos e seccomp para filtragem de syscall. (#52610)

codex rust-v0.163.0

New Features

  • Open /config to search preferences across categories, change supported settings immediately, and see which changes require a restart. (#52990, #53429)
  • Send a follow-up while Codex is responding to steer it immediately. Interrupting a turn also stops active Code Mode cells and their nested tool calls. (#51812, #51835)
  • Configure a leader key in /keymap. The default is Ctrl+X, shortcut hints stay open until you choose or cancel, and voice mute moves to F9. (#52273)
  • Restart a managed background server from /daemon. Codex warns about work the restart could interrupt, then reconnects automatically. (#53173)
  • Codex can run independent read-only tools in parallel, including skill, memory, and conversation-history lookups. (#52245)
  • Daybreak is enabled by default for eligible accounts. codex exec can also select it with an OpenAI API key when the server offers access. (#53701, #53717)

Bug Fixes

  • Resuming a saved thread restores its permissions and network approvals, while respecting explicit overrides and current managed policy. (#53150, #53419, #53424)
  • The network proxy now checks permission before a DNS lookup, rejects duplicate Host headers, and prevents credential aliases from bypassing inspection hooks. (#51650, #52661, #53506)
  • Return to an existing side conversation with /side after switching threads. Answers to pending prompts also go back to the thread that asked. (#52184, #53436)
  • On Windows, Ctrl+V and Shift+Insert paste text as well as images. On WSL, repeated pastes reuse the clipboard reader, and copy attempts time out instead of hanging. (#53224, #52967, #53453)
  • Local commands finish promptly when a child keeps an output pipe open. Remote commands preserve late-arriving output so the final poll can still collect it. (#52652, #53331, #53622)
  • codex exec no longer prints the same file diff again after an unrelated command. (#53444)

Documentation

  • Updated the bundled OpenAI Docs guidance for migrations to the GPT-6 family, including model-specific reasoning, tool use, and data residency considerations. (#51768)
  • Clarified how the Linux sandbox uses bubblewrap for filesystem isolation and seccomp for syscall filtering. (#52610)

Chores

  • Codex now uses its standard shell executor and no longer bundles a patched zsh. Configurations using the retired shell flags receive a migration notice. (#52160, #52213)
  • Reduced Linux and macOS release package size by stripping symbols from packaged binaries while preserving them in the original build outputs. (#52178)
