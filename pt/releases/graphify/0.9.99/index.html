#grafificar v0.9.99 ##0.9.99 (30/10/2026)

  • Proeza: caminho quando várias rotas se vinculam em comprimento, graphify path e a ferramenta MCP shortest_path relatam o mais conservador: entre todos os caminhos mais curtos, a rota cujo salto mais fraco é o mais fraco é escolhida, e o resumo observa que era a mais fraca de N rotas de igual comprimento. Anteriormente, uma rota arbitrária de comprimento igual era retornada, portanto a confiança poderia exagerar a certeza da conexão. Esta é a segunda metade de #4881 (a primeira metade, mantendo a evidência mais fraca de uma borda colapsada em also_seen, enviada em 0.9.98 via #4891, obrigado @SyedFahad7).
  • Correção: go uma chamada em um inicializador var em nível de pacote (incluindo dentro de um fechamento func-literal, o padrão swappable-hook comum) é creditada no nó do arquivo em vez de ser descartada (#2360, #4867, obrigado @nothariharan).
  • Correção: go um valor de método passado como argumento de função (Wrap(s.Health)) é vinculado como um indirect_call, trazendo Go à paridade com Python/JS para retorno de chamada por valor de método; protegido de forma conservadora contra falsos positivos de acesso ao campo (#1566, #4868, obrigado @nothariharan).
  • Correção: go um campo do receptor cuja struct é declarada em um arquivo irmão do mesmo pacote é digitado, de modo que suas chamadas de membro são resolvidas no layout Go usual de struct-aqui-métodos-lá, e os tipos de campo persistem em reconstruções incrementais (#3368, #4866, obrigado @nothariharan).
  • Correção: python Os valores module.func listados em uma tabela de despacho ({"a": mod.func_a}, incluindo coleções aninhadas) são resolvidos para as funções referenciadas como indirect_calls em vez de serem descartados; valores não solicitáveis, de classe e de receptor local são deixados de lado (#1566, #4773, obrigado @nothariharan).
  • Correção: install gemini obtém seu próprio diretório de habilidade global (~/.gemini/skills/graphify) no Windows em vez de colidir com o diretório da plataforma agents; uma habilidade agents pré-existente é anotada, não excluída (#2800, #4770, obrigado @nothariharan).
  • Correção: instalar o plugin OpenCode global é gravado em ~/.config/opencode (co-localizado com a habilidade global) em vez do diretório atual, com instalação/desinstalação/atualização mantidas simétricas e locais legados ainda limpos (#3398, #4771, obrigado @nothariharan).
  • Documentos: habilidade "Siga estas etapas na ordem. Não pule as etapas." a instrução foi reformulada para "a menos que o caminho rápido acima se aplique", resolvendo a contradição com o caminho rápido do gráfico existente em todos os hosts gerados (#4061, #4721, obrigado @nothariharan).
  • Talento: servir path, explain e neighbors/get_neighbors imprimem o confidence_score armazenado de uma borda ao lado de sua tag ([INFERRED 0.75]); EXTRACTED permanece vazio (1.0 por definição) e uma pontuação ausente ou não finita mantém a tag vazia. Compõe com o resumo do caminho de salto mais fraco e as tags de evidência also_seen (#4882, #4888, obrigado @SyedFahad7).

graphify v0.9.99

0.9.99 (2026-10-30)

  • Feat: path when several routes tie on length, graphify path and the MCP shortest_path tool report the most conservative one: among all shortest paths, the route whose weakest hop is weakest is chosen, and the summary notes it was the weakest of N equal-length routes. Previously an arbitrary equal-length route was returned, so the confidence could overstate how sure the connection is. This is the second half of #4881 (the first half, keeping a collapsed edge's weaker evidence in also_seen, shipped in 0.9.98 via #4891, thanks @SyedFahad7).
  • Fix: go a call in a package-level var initialiser (including inside a func-literal closure, the common swappable-hook pattern) is credited to the file node instead of being dropped (#2360, #4867, thanks @nothariharan).
  • Fix: go a method value passed as a function argument (Wrap(s.Health)) is linked as an indirect_call, bringing Go to parity with Python/JS for callback-by-method-value; conservatively guarded against field-access false positives (#1566, #4868, thanks @nothariharan).
  • Fix: go a receiver's field whose struct is declared in a sibling file of the same package is typed, so its member calls resolve across the usual struct-here-methods-there Go layout, and the field types persist across incremental rebuilds (#3368, #4866, thanks @nothariharan).
  • Fix: python module.func values listed in a dispatch table ({"a": mod.func_a}, including nested collections) resolve to the referenced functions as indirect_calls instead of being dropped; non-callable, class, and local-receiver values are left alone (#1566, #4773, thanks @nothariharan).
  • Fix: install gemini gets its own global skill dir (~/.gemini/skills/graphify) on Windows instead of colliding with the agents platform's dir; a pre-existing agents skill is noted, not deleted (#2800, #4770, thanks @nothariharan).
  • Fix: install the global OpenCode plugin is written to ~/.config/opencode (co-located with the global skill) instead of the current directory, with install/uninstall/refresh kept symmetric and legacy locations still cleaned up (#3398, #4771, thanks @nothariharan).
  • Docs: skill the "Follow these steps in order. Do not skip steps." instruction is reworded to "unless the fast path above applies," resolving the contradiction with the existing-graph fast path across all generated hosts (#4061, #4721, thanks @nothariharan).
  • Feat: serve path, explain and neighbors/get_neighbors print an edge's stored confidence_score alongside its tag ([INFERRED 0.75]); EXTRACTED stays bare (1.0 by definition) and a missing or non-finite score keeps the bare tag. Composes with the weakest-hop path summary and the also_seen evidence tags (#4882, #4888, thanks @SyedFahad7).
