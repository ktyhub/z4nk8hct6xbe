#grafificar v0.9.100 ##0.9.100 (01/11/2026)

  • Correção: ids um tipo e uma função cujos nomes diferem apenas no caso (Foo a classe, foo a função) obter ids de nó distintos em vez de colidir (o que derrubou um nó e criou um auto-loop falso) (#4904, #4908, obrigado @bercedev).
  • Correção: php um acesso Scope::MEMBER em um inicializador de nível de classe (um valor const, um padrão de propriedade ou um padrão de parâmetro/construtor promovido) emite uma borda references_constant; self::/static::/parent:: são ignorados e escopos desconhecidos não possuem stub (#4648, #4895, obrigado @Jitendarmahara).
  • Correção: hooks A saída git rev-parse é decodificada como UTF-8, portanto, uma árvore de trabalho vinculada em um caminho não ASCII é resolvida corretamente no Windows em vez de mojibake (#4903, obrigado @LukeTheoJohnson).
  • Correção: analisar em um gráfico somente de código o motivo da pergunta do nó isolado diz "possíveis arestas ausentes" em vez de fazer referência a lacunas de documentação que não podem ser aplicadas (#4887, obrigado @oleksii-tumanov).
  • Perf: resolver as bordas de referência são indexadas pela origem uma vez, portanto, a resolução de importação JS/TS não percorre mais cada borda por importação (saída inalterada) (#4909, #4913, obrigado @Deepjyoti-Sarmah).
  • Documentos: habilidade a habilidade agora diz quando vale a pena construir um gráfico, em todos os hosts gerados, preservando a invariante "se o usuário invocou /graphify, faça conforme solicitado" (#4829, #4906, obrigado @TanmayShah29).
  • Correção: deps o video extra limita o PyAV abaixo de 19 (av>=11,<19), porque o PyAV 19 removeu o argumento metadata_errors de que o sussurro mais rápido passa incondicionalmente ao abrir o áudio; sem a tampa, uma nova instalação no Python 3.12 + falhou na transcrição (# 4842, obrigado @SyedFahad7).
  • Correção: r setClass/setRefClass A herança S4/R5 declarada com contains= agora emite uma borda de herança (anteriormente apenas o inherit= da R6Class era reconhecido) (#4902, obrigado @ayushcodes10).
  • Correção: elixir uma chamada de função simples resolve para uma função no próprio módulo do chamador antes de outros módulos, em vez de vincular à última definição de mesmo nome percorrida (# 4900, obrigado @ayushcodes10).
  • Correção: dart uma cláusula mixin on A, B resolve todas as restrições da superclasse, não apenas a primeira (#4899, obrigado @ayushcodes10).
  • Correção: fortran o extends(base) de um tipo derivado emite uma borda herdada, alinhando o Fortran com os outros extratores OOP (#4897, obrigado @ayushcodes10).
  • Correção: scala um extension (x: T) def m tem como escopo seu tipo de receptor T (uma borda method para T) em vez de vazar para o escopo do arquivo (#2044, #4856, obrigado @divakantpandey).
  • Correção: terraform um nó carrega seu escopo original para que os ids permaneçam estáveis ​​quando um diretório de projeto em cache é movido, em vez de derivar novamente o escopo do novo caminho (#4858, #4861, obrigado @yUm1k4).
  • Correção: extração (JVM) Importações Java e Kotlin, extends/implements e chamadas de membros são resolvidas entre arquivos e entre os dois idiomas quando um FQN escrito nomeia exatamente um tipo de origem (#4874, #4879, obrigado @Deepjyoti-Sarmah).
  • Correção: exportar uma renderização de caminho/explicar/wiki lista todas as relações paralelas entre dois nós (via edge_datas), e uma gravação --no-cluster bruta marca o gráfico multigraph para que bordas paralelas sobrevivam à recarga (#4794, obrigado @ensell-yes).
  • Correção: exportação um backup parcial ou com falha é relatado como sem backup e tentado novamente na próxima execução, em vez de ser registrado como um falso sucesso (#3769, #4834, obrigado @barlowa124).
  • Correção: afetado graphify affected (e query --seed) resolve o mesmo path::Symbol e formulários de referência pontilhados que explain aceita, reutilizando o resolvedor de explicação e sai diferente de zero (3 ambíguo / 4 não encontrado) em uma semente que não resolve (#4792, #4797, obrigado @dupeisen).
  • Correção: instalar graphify uninstall remove todas as habilidades de escopo do usuário da plataforma (13 foram deixadas para trás) e o comando global kilo; e graphify kilo uninstall remove o sidecar references/ da habilidade quilo (#4782, #4789, obrigado @bercedev).
  • Proeza: llm o backend Claude armazena em cache seu prompt de sistema (estável, grande) com cache_control, contando os tokens armazenados em cache de volta em input_tokens, e GRAPHIFY_CLAUDE_PROMPT_CACHE=0 o desativa para gateways que rejeitam cache_control (#4835, #4855, #4880, obrigado @Jvxoq e @1akashkalita).
  • Correção: prompt a descrição do formato do node-id no prompt de extração corresponde ao que ids.py realmente produz (caracteres de palavras mantidos, letras/dígitos não-ASCII preservados, ASCII em minúsculas) em vez do texto obsoleto "somente [a-z0-9_]" (#4432, #4799, obrigado @dupeisen).
  • Documentos: como funciona a contagem de idiomas suportados é atualizada (cerca de 40: 33 gramáticas de árvore mais 7 analisadores integrados) e a Passagem 3 é descrita como executando o backend LLM configurado, não apenas Claude (#4873, obrigado @SyedFahad7).

graphify v0.9.100

0.9.100 (2026-11-01)

  • Fix: ids a type and a function whose names differ only in case (Foo the class, foo the function) get distinct node ids instead of colliding (which dropped one node and minted a bogus self-loop) (#4904, #4908, thanks @bercedev).
  • Fix: php a Scope::MEMBER access in a class-level initializer (a const value, a property default, or a parameter/promoted-constructor default) emits a references_constant edge; self::/static::/parent:: are skipped and unknown scopes mint no stub (#4648, #4895, thanks @Jitendarmahara).
  • Fix: hooks git rev-parse output is decoded as UTF-8, so a linked worktree under a non-ASCII path resolves correctly on Windows instead of mojibake (#4903, thanks @LukeTheoJohnson).
  • Fix: analyze on a code-only graph the isolated-node question reason says "possible missing edges" rather than referencing documentation gaps that cannot apply (#4887, thanks @oleksii-tumanov).
  • Perf: resolve reference edges are indexed by source once, so JS/TS import resolution no longer re-walks every edge per import (output unchanged) (#4909, #4913, thanks @Deepjyoti-Sarmah).
  • Docs: skill the skill now says when a graph is worth building, across all generated hosts, while preserving the "if the user invoked /graphify, do it as asked" invariant (#4829, #4906, thanks @TanmayShah29).
  • Fix: deps the video extra caps PyAV below 19 (av>=11,<19), because PyAV 19 removed the metadata_errors argument that faster-whisper passes unconditionally when opening audio; without the cap a fresh install on Python 3.12+ failed to transcribe (#4842, thanks @SyedFahad7).
  • Fix: r setClass/setRefClass S4/R5 inheritance declared with contains= now emits an inherits edge (previously only R6Class's inherit= was recognised) (#4902, thanks @ayushcodes10).
  • Fix: elixir a bare function call resolves to a function in the caller's own module before other modules, instead of binding to the last-walked same-named definition (#4900, thanks @ayushcodes10).
  • Fix: dart a mixin on A, B clause resolves every superclass constraint, not just the first (#4899, thanks @ayushcodes10).
  • Fix: fortran a derived type's extends(base) emits an inherits edge, bringing Fortran in line with the other OOP extractors (#4897, thanks @ayushcodes10).
  • Fix: scala an extension (x: T) def m is scoped to its receiver type T (a method edge to T) instead of leaking to file scope (#2044, #4856, thanks @divakantpandey).
  • Fix: terraform a node carries its original scope so ids stay stable when a cached project directory is moved, instead of re-deriving the scope from the new path (#4858, #4861, thanks @yUm1k4).
  • Fix: extract (JVM) Java and Kotlin imports, extends/implements and member calls resolve across files and across the two languages when a written FQN names exactly one sourced type (#4874, #4879, thanks @Deepjyoti-Sarmah).
  • Fix: export a path/explain/wiki rendering lists every parallel relation between two nodes (via edge_datas), and a raw --no-cluster write marks the graph multigraph so parallel edges survive reload (#4794, thanks @ensell-yes).
  • Fix: export a partial or failed backup is reported as no backup and retried on the next run, instead of being recorded as a false success (#3769, #4834, thanks @barlowa124).
  • Fix: affected graphify affected (and query --seed) resolve the same path::Symbol and dotted reference forms explain accepts, reusing explain's resolver, and exit non-zero (3 ambiguous / 4 not-found) on a seed that does not resolve (#4792, #4797, thanks @dupeisen).
  • Fix: install graphify uninstall removes every platform's user-scope skill (13 were left behind) and the kilo global command; and graphify kilo uninstall removes the kilo skill's references/ sidecar (#4782, #4789, thanks @bercedev).
  • Feat: llm the Claude backend caches its (stable, large) system prompt with cache_control, counting the cached tokens back into input_tokens, and GRAPHIFY_CLAUDE_PROMPT_CACHE=0 disables it for gateways that reject cache_control (#4835, #4855, #4880, thanks @Jvxoq and @1akashkalita).
  • Fix: prompt the node-id format description in the extraction prompt matches what ids.py actually produces (word characters kept, non-ASCII letters/digits preserved, ASCII lowercased) instead of the stale "[a-z0-9_] only" wording (#4432, #4799, thanks @dupeisen).
  • Docs: how-it-works the supported-language count is updated (about 40: 33 tree-sitter grammars plus 7 built-in parsers) and Pass 3 is described as running the configured LLM backend, not Claude only (#4873, thanks @SyedFahad7).
