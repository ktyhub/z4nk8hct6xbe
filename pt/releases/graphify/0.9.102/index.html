#grafificar v0.9.102

grafificar 0.9.102

Uma grande liberação de correção, desempenho e fluxo de trabalho abrangendo os extratores, a camada de consulta, a atualização incremental, os ganchos, o runbook de habilidades e a instalação.

Resolução de chamadas (extratores)

  • go: chamadas de membros do mesmo arquivo são resolvidas através do tipo do receptor; receptores pkg.T de pacote cruzado são vinculados apenas por meio da importação do arquivo; o método de interface chama o envio para implementadores implícitos (#4966, #4853, #4934).
  • rust: chamadas qualificadas por módulo (crate::b::helper()) resolvem arquivos cruzados; chamadas dentro de argumentos de macro de expressão são vinculadas (#4944, #4945).
  • kotlin: chamadas sobrecarregadas e do bloco init {} são resolvidas; chamadas herdadas externas inacessíveis são descartadas (#4956).
  • python: as chamadas de membro de um singleton em nível de módulo são resolvidas por meio de seu tipo; uma chamada de método simples não se vincula mais (#4972, #4933).
  • js/ts: a classe extends através de um CommonJS requer resoluções; um modelo marcado digitado e uma anotação import("mod").T<X> não analisam mais pela metade ou criam uma borda dynamic_import falsa; métodos de objeto exportados por padrão resolvem (#4700, #4976, #4967).
  • solididade: as importações do ../ são resolvidas para o arquivo real (#4985).
  • cpp: digitação do receptor a partir de parâmetros/campos, ligação do proprietário do cabeçalho dividido, supressão de chamada local, ortografia exata do alias de tipo (#4946, #4920, #4921, #4951).

Consulta

  • Os nós de origem são classificados acima dos testes e documentos (um peso suave, não uma exclusão), e as respostas são arquivadas primeiro (#4982).
  • graphify query lê query_budget/query_depth de .graphifyrc e ganha uma flag --depth (#4760).

Atualização / observação incremental

  • graphify update reextrai apenas os arquivos cujo conteúdo foi alterado, com gráfico idêntico a uma reconstrução completa; uma solicitação incremental contestada é registrada em vez de descartada (#4800, #4801, #4802).

Construir/cache

  • O protetor de gravação não conta mais dobras fantasmas ou dobras de desduplicação intencionais como nós descartados; evidências semânticas de fontes independentes sobrevivem; as chaves de cache preservam maiúsculas de minúsculas (#4957, #4952, #4927, #4950, #4937).

Ganchos

  • Um arquivo com conteúdo inalterado não é sinalizado novamente como obsoleto pelo mtime; um Grep dedicado é mantido no portão de orientação estrito; pesquisas externas não emitem nenhuma dica de projeto (#4974, #4973, #4979).

Desempenho

  • Menor pico de memória em carga, resolução e extração, e um repoint de arquivos cruzados mais rápido - tudo com saída idêntica (#4960, #4958, #4959, #4981).

Habilidade / instalação

  • O runbook --update recoloca na fila documentos parcialmente lidos em vez de carimbá-los como concluídos; Etapa 4 roscas --force; um relatório de desvio de hub é adicionado; desinstalar remove o registro de habilidade global (#4816, #4805, #4704, #4975). O esquema de cache AST aumentou para 37; caches quentes executam novamente as extrações afetadas. graphify v0.9.102

graphify 0.9.102

A large correctness, performance and workflow release spanning the extractors, the query layer, incremental update, the hooks, the skill runbook and install.

Call-resolution (extractors)

  • go: same-file member calls resolve through the receiver's type; cross-package pkg.T receivers bind only via the file's import; interface method calls dispatch to implicit implementers (#4966, #4853, #4934).
  • rust: module-qualified calls (crate::b::helper()) resolve cross-file; calls inside expression-macro arguments are linked (#4944, #4945).
  • kotlin: overloaded and init {}-block calls resolve; unreachable external-inherited calls are dropped (#4956).
  • python: a module-level singleton's member calls resolve through its type; a bare method call no longer self-binds (#4972, #4933).
  • js/ts: class extends through a CommonJS require resolves; a typed tagged template and an import("mod").T<X> annotation no longer half-parse or mint a false dynamic_import edge; default-exported object methods resolve (#4700, #4976, #4967).
  • solidity: ../ imports resolve to the real file (#4985).
  • cpp: receiver typing from params/fields, split-header owner binding, local-callable suppression, type-alias exact-spelling (#4946, #4920, #4921, #4951).

Query

  • Source nodes rank above tests and docs (a soft weight, not exclusion), and answers are file-first (#4982).
  • graphify query reads query_budget/query_depth from .graphifyrc and gains a --depth flag (#4760).

Incremental update / watch

  • graphify update re-extracts only the files whose content changed, with a graph identical to a full rebuild; a contended incremental request is recorded instead of dropped (#4800, #4801, #4802).

Build / cache

  • The write guard no longer counts intentional ghost folds or dedup folds as dropped nodes; independently-sourced semantic evidence survives a fold; cache keys are case-preserving (#4957, #4952, #4927, #4950, #4937).

Hooks

  • A file unchanged in content is not re-flagged stale by mtime; a dedicated Grep is held to the strict orientation gate; external searches emit no project hint (#4974, #4973, #4979).

Performance

  • Lower peak memory in load, resolution and extraction, and a faster cross-file repoint — all with identical output (#4960, #4958, #4959, #4981).

Skill / install

  • The --update runbook re-queues partly-read docs instead of stamping them done; Step 4 threads --force; a hub-bypass report is added; uninstall removes the global skill registration (#4816, #4805, #4704, #4975).

The AST cache schema is bumped to 37; warm caches re-run the affected extractions.
