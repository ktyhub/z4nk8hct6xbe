#grafificar v0.9.107

  • Correção: cpp uma declaração de membro dobrada sem parâmetros (bar()) registra sua implementação em definition_file como um caminho ancorado na mesma raiz que source_file, em vez de um passeio ../ relativo à raiz de cache/saída. A reconciliação de argumento zero adicionada em 0.9.106 armazenou o formulário de prova interno _cpp_source_key, que _norm_source_file não pode ancorar novamente (ele apenas relativiza caminhos absolutos), então um corpus fora da árvore obteve um definition_file mutilado. A fusão irmã decl/def já armazenou o source_file bruto por esse motivo; ambos os caminhos agora concordam. A prova do caminho de inclusão ainda usa o formato de chave.
  • Correção: llm uma fatia cujo tempo limite ou estouro de contexto é reconhecido e abandonado (não pode ser mais dividido ou a profundidade de novas tentativas está esgotada) agora marca seu arquivo como parcial, portanto, um documento cujo tempo limite da fatia final expirou não é mais armazenado em cache e carimbado como completo de suas outras fatias; ele é colocado novamente na fila na próxima execução enquanto os resultados dos arquivos irmãos são mantidos (#5099, obrigado @khrisshie).
  • Correção: php uma varredura do caminho da rota para no próprio argumento do fechamento, então $app->get('/users', function () { ... }) mantém GET /users em vez de ler um argumento de string final após o fechamento como a rota; um caminho legítimo antes do fechamento permanece inalterado (#5135, obrigado @mppyxx).
  • Correção: ids duas declarações em nível de módulo do mesmo tipo em um arquivo cujos nomes diferem apenas por sublinhados iniciais/finais (function _save(){} e function save(){ return _save() }) são dois nós novamente em vez de um, e a chamada entre eles é uma borda save -> _save real em vez de uma autochamada save -> save fabricada; a declaração que aparece primeiro mantém o id simples e a outra é salgada. Afeta JS, TS, C, C++, PHP, Ruby, Kotlin, Swift e Lua (#2810, obrigado @khrisshie).
  • Correção: métodos php de uma classe, característica, interface ou enum cujos nomes diferem apenas por um _ inicial/final (_x() / x()) são nós separados em vez de um engolir o outro: um nome público mantém seu id e os outros são salgados, como em Python, C#, JS/TS e Solidity, então $this->x() e $b->x() alcançam x() em vez de estar perdido e $this->_x() não parece mais uma autochamada (#5137, obrigado @khrisshie).
  • Correção: membros java de uma classe cujos nomes diferem apenas por um _ inicial/final (_name / name) ou apenas por caso (run / Run, que Java trata como distinto) obtêm ids de nó separados em vez de um engolir o outro; um nome público mantém seu id e os gêmeos são salgados, como nas outras línguas, então as chamadas para cada uma são resolvidas corretamente (#5151, obrigado @rohit-jsfreaky).
  • Correção: teste o teste de id do terraform do cache copiado aceita um pool de trabalhadores que não pôde ser iniciado sob pressão de recursos (ele volta para sequencial e avisa), em vez de afirmar que o pool sempre inicia; um pool genuinamente quebrado ainda falha no teste (#5136, obrigado @mppyxx).
  • Correção: php/js uma chamada por meio de um membro do namespace ESM (import * as ns; ns.handler()) ou módulo inteiro requer resolução apenas quando o destino é realmente chamável, portanto, um membro do namespace que nomeia uma exportação não chamável (um objeto literal, uma constante) não obtém mais uma borda de chamada espúria (#5144, obrigado @ayushcodes10).
  • Perf: consulta o caminho de leitura (consulta/explicação/caminho/afetado e carga do gráfico MCP) não importa mais todos os extratores de linguagem, reduzindo o custo de importação em comandos somente leitura; a saída do gráfico permanece inalterada (obrigado @ rohit-jsfreaky).
  • Perf: extrair o pool de trabalhadores AST é dimensionado pela quantidade de trabalho não armazenado em cache (um trabalhador por aproximadamente 500 KB de origem não armazenada em cache, limitado à contagem de CPU e à contagem de arquivos) quando nenhuma contagem de trabalhadores é definida, portanto, pequenas compilações incrementais param de gerar um pool completo; a saída é invariável à contagem de trabalhadores (obrigado @ rohit-jsfreaky).
  • Alteração: nuvem as superfícies OSS (README, texto de ajuda/instalação do CLI, os documentos traduzidos em todos os 31 locais e a habilidade do agente) agora apontam para o plano gratuito sem cartão no app.graphify.com/signup, em vez de um "teste de 14 dias" no /login (o teste é apenas para planos pagos e precisa de um cartão, então a cópia antiga combinava os dois). Os links carregam UTMs utm_campaign=oss marcados por superfície, portanto, uma inscrição pode ser atribuída ao local de origem.
  • Alteração: nuvem o empurrão pós-construção do CLI é contextual. É apenas TTY (nunca no CI ou no pipeline do agente), respeita GRAPHIFY_NO_TIPS/GRAPHIFY_NO_CTA e é exibido nas compilações 1, 5 e 20 e permanece silencioso para sempre. Quando um gráfico local atinge 25 mil nós, o limite por repositório do plano gratuito, o empurrão muda para uma linha específica da escala (marcada como utm_content=scale) que vende o Graphify Pro e vincula os preços com o teste de 14 dias, em vez da inscrição gratuita: um repositório desse tamanho não cabe mais no plano gratuito, portanto, apontá-lo para o plano gratuito chegaria diretamente ao limite. O esquema de cache AST aumentou para 44; caches quentes executam novamente as extrações afetadas de C++, PHP, Java e ID de nível de módulo.

graphify v0.9.107

  • Fix: cpp a folded parameterless member declaration (bar()) records its implementation in definition_file as a path anchored to the same root as source_file, instead of a ../-walk relative to the cache/out root. The zero-argument reconciliation added in 0.9.106 stored the internal _cpp_source_key proof form, which _norm_source_file cannot re-anchor (it only relativizes absolute paths), so an out-of-tree corpus got a mangled definition_file. The sibling decl/def merge already stored the raw source_file for this reason; both paths now agree. The include-path proof still uses the key form.
  • Fix: llm a slice whose timeout or context overflow is recognised and given up on (it cannot be split further, or the retry depth is exhausted) now marks its file partial, so a document whose tail slice timed out is no longer cached and stamped complete from its other slices; it is re-queued on the next run while sibling files' results are kept (#5099, thanks @khrisshie).
  • Fix: php a route path scan stops at the closure's own argument, so $app->get('/users', function () { ... }) keeps GET /users instead of reading a trailing string argument after the closure as the route; a legitimate path before the closure is unchanged (#5135, thanks @mppyxx).
  • Fix: ids two module-level declarations of the same kind in one file whose names differ only by leading/trailing underscores (function _save(){} and function save(){ return _save() }) are two nodes again instead of one, and the call between them is a real save -> _save edge instead of a fabricated save -> save self-call; the declaration that appears first keeps the plain id and the other is salted. Affects JS, TS, C, C++, PHP, Ruby, Kotlin, Swift and Lua (#2810, thanks @khrisshie).
  • Fix: php methods of one class, trait, interface or enum whose names differ only by a leading/trailing _ (_x() / x()) are separate nodes instead of one swallowing the other: the one public name keeps its id and the others are salted, as in Python, C#, JS/TS and Solidity, so $this->x() and $b->x() reach x() instead of being lost and $this->_x() no longer looks like a self-call (#5137, thanks @khrisshie).
  • Fix: java members of one class whose names differ only by a leading/trailing _ (_name / name) or only by case (run / Run, which Java treats as distinct) get separate node ids instead of one swallowing the other; a public name keeps its id and the twins are salted, as in the other languages, so calls to each resolve correctly (#5151, thanks @rohit-jsfreaky).
  • Fix: test the copied-cache terraform id test accepts a worker pool that could not start under resource pressure (it falls back to sequential and warns), instead of asserting the pool always starts; a genuinely broken pool still fails the test (#5136, thanks @mppyxx).
  • Fix: php/js a call through an ESM namespace member (import * as ns; ns.handler()) or whole-module require resolves only when the target is actually callable, so a namespace member that names a non-callable export (an object literal, a constant) no longer gets a spurious call edge (#5144, thanks @ayushcodes10).
  • Perf: query the read path (query/explain/path/affected and the MCP graph load) no longer imports every language extractor, cutting import cost on read-only commands; graph output is unchanged (thanks @rohit-jsfreaky).
  • Perf: extract the AST worker pool is sized by the amount of uncached work (one worker per ~500 KB of uncached source, capped at CPU count and file count) when no worker count is set, so small incremental builds stop spinning up a full pool; output is invariant to worker count (thanks @rohit-jsfreaky).
  • Change: cloud the OSS surfaces (README, CLI help/install text, the translated docs in all 31 locales, and the agent skill) now point at the free plan with no card at app.graphify.com/signup, instead of a "14-day trial" at /login (the trial is paid-plans-only and needs a card, so the old copy conflated the two). Links carry utm_campaign=oss UTMs tagged per surface, so a signup can be attributed to where it came from.
  • Change: cloud the post-build CLI nudge is contextual. It is TTY-only (never in CI or the agent pipeline), respects GRAPHIFY_NO_TIPS/GRAPHIFY_NO_CTA, and shows on builds 1, 5 and 20 then stays quiet for good. When a local graph reaches 25k nodes, the free plan's per-repo cut-off, the nudge switches to a scale-specific line (tagged utm_content=scale) that sells Graphify Pro and links to pricing with the 14-day trial, instead of the free signup: a repo that size no longer fits the free plan, so pointing it at the free plan would land straight on the limit. The AST cache schema is bumped to 44; warm caches re-run the affected C++, PHP, Java and module-level-id extractions.
