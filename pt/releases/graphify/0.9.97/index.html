#grafificar v0.9.97 ##0.9.97 (27/10/2026)

  • Segurança: redação de justificativa a redação de credenciais para rótulos de justificativa se move para um único ponto de estrangulamento pré-cache (_redact_rationale_labels dentro de _safe_extract), para que nenhum extrator possa ignorá-la e agora cobre mais formas de vazamento: URL userinfo com um usuário vazio ou com //@ na senha, corpos de chave privada PEM, tokens colados ao texto circundante por _ (por exemplo, ghp_...), Slack Tokens de atualização xoxe-, JWTs curtos e docstrings Common Lisp que construíram rótulos anteriormente sem edição. Strings benignas (hashes, prosa sk-, URLs sem informações do usuário) são deixadas de lado (# 4647, obrigado @ 0xkaushik-ai).
  • Segurança: deps anyio é reduzido para >=4.14.2 no extra mcp, acima de CVE-2026-63374 (um desvio de validação de nome de host IDNA 2003 vs 2008 que permite que um MITM em um domínio não ASCII apresente um certificado para um host ASCII diferente, CVSS 9.3). anyio é apenas uma dependência transitiva e o arquivo de bloqueio já resolve 4.15.1, portanto, este é um piso para impedir a regressão de uma nova resolução futura.
  • Correção: markdown Análise de títulos ATX por CommonMark: uma execução final de # não faz parte do texto do título (## Setup ## é "Configuração"), são permitidos até três espaços de recuo (quatro é um bloco de código recuado) e uma linha somente hash como ## ## não contém nenhum nó (#4790, #4791, obrigado @jaimemartinez).
  • Correção: markdown blocos de código protegidos são rastreados pelas regras CommonMark (backtick e til cercas, strings de informação, correspondência de comprimento próximo), então uma linha que se parece com um título dentro de uma cerca não vaza mais como estrutura, e um título após um bloco ~~~ que contém uma linha ``` não é mais perdido (#4787, #4788, obrigado @jaimemartinez).
  • Correção: yaml a extração estrutural lê a árvore de nós composta, de modo que as chaves carregam sua ortografia escrita e sua própria linha de origem em vez de todas pousarem na linha 1, e chaves simples YAML 1.1 como on/off/yes/no não são mais dobradas para booleanos (um bloco de fluxo de trabalho on: é extraído, não transformado em um nó True) (#4784, #4785, obrigado @jaimemartinez).
  • Correção: razor as interfaces @implements de um componente são extraídas como bordas implements em vez de serem descartadas silenciosamente (#4820, obrigado @ayushcodes10).
  • Correção: terraform um bloco de provedor com alias obtém seu próprio nó qualificado para alias (para que dois blocos provider "aws" não sejam mais colapsados ​​em um e percam atributos) e uma referência provider = aws.west é resolvida para ele em vez de ficar pendente; um local literalmente chamado provider não é mais mal interpretado (#4819, obrigado @ayushcodes10).
  • Correção: cobol parágrafos que seguem um END PROGRAM aninhado são reconectados ao programa anexo em vez de aderir ao aninhado, por meio de uma pilha de programas (#4824, obrigado @ayushcodes10).
  • Correção: blade uma diretiva wire:click vincula o nome do método simples: modificadores pontilhados (wire:click.prevent="submit") são correspondidos, os argumentos de chamada são cortados do nome (deleteItem(5) vincula deleteItem) e uma ação mágica com prefixo $ não produz nenhuma borda fabricada (# 4823, obrigado @ayushcodes10).
  • Correção: pascal um record é reconhecido como um tipo com seus próprios métodos no fallback de regex (o caminho padrão sem o extra opcional pascal), correspondendo ao caminho do tree-sitter; Os membros operator também foram extraídos (#4825, obrigado @ayushcodes10).
  • Correção: vbnet uma declaração Operator é extraída como um membro do tipo operator de sua classe e seu corpo é percorrido para chamadas, então uma chamada auxiliar dentro de um operador não desaparece mais (#4821, obrigado @ayushcodes10).
  • Correção: fortran um call resolve para a sub-rotina que ele realmente nomeia em vez de um destino salgado com o nome do arquivo de chamada (que nunca foi resolvido), usando o próprio idioma de stub de arquivo cruzado do extrator (#4795, obrigado @ayushcodes10).
  • Correção: cli graphify query --help/-h (e agora graphify explain --help/-h) sem mais nada imprime o uso em vez de executar uma consulta literal para o texto "--help"; uma pergunta mais longa que contém apenas "--help" como substring ainda é executada como uma consulta (#4830, obrigado @curl-man).
  • Correção: js uma função aninhada (interna) não vaza mais para o mapa de nomes de todo o arquivo, portanto, uma chamada em outro lugar no arquivo é vinculada à função de nível superior desse nome, em vez de uma função interna que ela não pode ver; recursão, sombreamento e escopos irmãos são resolvidos corretamente (porta o esquema de escopo Python para JS/TS) (#4767, obrigado @smngvlkz).
  • Correção: ocaml todas as ligações em um module ... and ... ou class ... and ... encadeado por and são extraídas, não apenas a primeira, para que as ligações posteriores não sejam mais descartadas silenciosamente; cada um carrega sua própria linha de origem (#4822, obrigado @ayushcodes10).
  • Correção: verilog um método task da classe SystemVerilog é modelado como um function (seu próprio nó, borda method e referências de tipo de parâmetro), e uma variável local de tarefa não vaza mais como uma referência de campo falsa na classe (#4774, obrigado @ayushcodes10).
  • Correção: build uma borda sem relation é descartada em vez de persistida, tanto no build quanto nos caminhos de gravação brutos do --no-cluster, e a dobra de alias (relationship a relation) é executada antes da verificação (#4810, obrigado @legendteddy; reprodutor também arquivado como #4826 por @sunhouy).
  • Correção: build o protetor de redução conta um nó de menção de documento salvo que se dobra em seu arquivo gêmeo AST ao recarregar como presente, não perdido, portanto, uma gravação somente de cluster não é mais recusada quando nada foi realmente perdido (#4778, #4779, obrigado @AndresDiagoM).
  • Correção: detecta uma árvore de trabalho git vinculada cujo checkout principal é resolvido dentro da raiz de varredura é removida, de modo que uma árvore de trabalho irmã não é mais indexada como uma segunda cópia completa do repositório (#4683, #4833, obrigado @barlowa124; trabalho duplicado em #4685 por @AndresDiagoM).
  • Correção: resolução um comentário embutido em um glob pnpm-workspace é removido de acordo com as regras YAML, e um glob que Path.glob rejeita (um componente ** ou um padrão absoluto) é ignorado com um aviso em vez de travar toda a execução do extract (#4681, #4687, obrigado @Deepjyoti-Sarmah).
  • Correção: relatório um hub comunitário [[wikilink]] é inserido no mesmo export._obsidian_safe_stem que a exportação usa, então o link corresponde ao arquivo que a exportação realmente grava em vez de ficar pendurado (#4696, obrigado @ayushcodes10).
  • Correção: wiki uma comunidade renomeada apenas por maiúsculas e minúsculas mantém seu artigo em vez de fazer com que a varredura exclua o arquivo que a execução acabou de escrever; em um sistema de arquivos que diferencia maiúsculas de minúsculas, o gêmeo obsoleto em minúsculas é desvinculado em vez de renomeado sobre o arquivo novo (o que restauraria silenciosamente o corpo antigo) (#4508, #4798, obrigado @dupeisen).
  • Correção: consulta verbos de preenchimento get/gets/got/getting são eliminados dos termos de consulta (como o work/works existente), portanto, um hub de estrutura denominado "Get" não é extraído como uma semente BFS por um bônus de correspondência exata; pesquisas de nó para um Get literal ainda são resolvidas (# 4686, obrigado @AndresDiagoM).

graphify v0.9.97

0.9.97 (2026-10-27)

  • Security: rationale redaction credential redaction for rationale labels moves to a single pre-cache choke point (_redact_rationale_labels inside _safe_extract), so no extractor can skip it, and it now covers more leak shapes: URL userinfo with an empty user or with //@ in the password, PEM private-key bodies, tokens glued to surrounding text by _ (for example ghp_...), Slack xoxe- refresh tokens, short JWTs, and Common Lisp docstrings that previously built labels without redacting. Benign strings (hashes, sk- prose, URLs without userinfo) are left alone (#4647, thanks @0xkaushik-ai).
  • Security: deps anyio is floored to >=4.14.2 in the mcp extra, above CVE-2026-63374 (an IDNA 2003 vs 2008 hostname-validation bypass that let a MITM on a non-ASCII domain present a cert for a different ASCII host, CVSS 9.3). anyio is only a transitive dependency and the lockfile already resolves 4.15.1, so this is a floor to stop a future re-resolution from regressing.
  • Fix: markdown ATX headings parse per CommonMark: a trailing run of # is not part of the heading text (## Setup ## is "Setup"), up to three spaces of indent are allowed (four is an indented code block), and a hash-only line like ## ## mints no node (#4790, #4791, thanks @jaimemartinez).
  • Fix: markdown fenced code blocks are tracked by CommonMark rules (backtick and tilde fences, info strings, matching close length), so a line that looks like a heading inside a fence no longer leaks as structure, and a heading after a ~~~ block that contains a ``` line is no longer lost (#4787, #4788, thanks @jaimemartinez).
  • Fix: yaml structural extraction reads the composed node tree, so keys carry their written spelling and their own source line instead of all landing on line 1, and YAML 1.1 bare keys like on/off/yes/no are no longer folded to booleans (a workflow on: block is extracted, not turned into a True node) (#4784, #4785, thanks @jaimemartinez).
  • Fix: razor a component's @implements interfaces are extracted as implements edges instead of being silently dropped (#4820, thanks @ayushcodes10).
  • Fix: terraform an aliased provider block gets its own alias-qualified node (so two provider "aws" blocks no longer collapse into one and lose attributes), and a provider = aws.west reference resolves to it instead of dangling; a local literally named provider is no longer misread (#4819, thanks @ayushcodes10).
  • Fix: cobol paragraphs that follow a nested END PROGRAM reattach to the enclosing program instead of sticking to the nested one, via a program stack (#4824, thanks @ayushcodes10).
  • Fix: blade a wire:click directive binds the bare method name: dotted modifiers (wire:click.prevent="submit") are matched, call arguments are trimmed from the name (deleteItem(5) binds deleteItem), and a $-prefixed magic action mints no fabricated edge (#4823, thanks @ayushcodes10).
  • Fix: pascal a record is recognised as a type with its own methods in the regex fallback (the default path without the optional pascal extra), matching the tree-sitter path; operator members are extracted too (#4825, thanks @ayushcodes10).
  • Fix: vbnet an Operator declaration is extracted as an operator-kind member of its class and its body is walked for calls, so a helper call inside an operator no longer vanishes (#4821, thanks @ayushcodes10).
  • Fix: fortran a call resolves to the subroutine it actually names instead of a target salted with the calling file's name (which never resolved), using the extractor's own cross-file stub idiom (#4795, thanks @ayushcodes10).
  • Fix: cli graphify query --help/-h (and now graphify explain --help/-h) with nothing else prints usage instead of running a literal query for the text "--help"; a longer question that merely contains "--help" as a substring still runs as a query (#4830, thanks @curl-man).
  • Fix: js a nested (inner) function no longer leaks into the file-wide name map, so a call elsewhere in the file binds to the top-level function of that name rather than an inner one it cannot see; recursion, shadowing and sibling scopes resolve correctly (ports the Python scope scheme to JS/TS) (#4767, thanks @smngvlkz).
  • Fix: ocaml every binding in an and-chained module ... and ... or class ... and ... is extracted, not just the first, so later bindings are no longer silently dropped; each carries its own source line (#4822, thanks @ayushcodes10).
  • Fix: verilog a SystemVerilog class task method is modeled like a function one (its own node, method edge and parameter-type references), and a task-local variable no longer leaks as a false field reference on the class (#4774, thanks @ayushcodes10).
  • Fix: build an edge with no relation is dropped instead of persisted, on both the build and the raw --no-cluster write paths, and alias folding (relationship to relation) runs before the check (#4810, thanks @legendteddy; reproducer also filed as #4826 by @sunhouy).
  • Fix: build the shrink guard counts a saved document-mention node that folds into its AST file twin on reload as present, not lost, so a cluster-only write is no longer refused when nothing was actually lost (#4778, #4779, thanks @AndresDiagoM).
  • Fix: detect a linked git worktree whose main checkout resolves inside the scan root is pruned, so a sibling worktree no longer gets indexed as a second full copy of the repo (#4683, #4833, thanks @barlowa124; duplicate work in #4685 by @AndresDiagoM).
  • Fix: resolution an inline comment in a pnpm-workspace glob is stripped per YAML rules, and a glob that Path.glob rejects (a ** component or an absolute pattern) is skipped with a warning instead of crashing the whole extract run (#4681, #4687, thanks @Deepjyoti-Sarmah).
  • Fix: report a community hub [[wikilink]] is slugged through the same export._obsidian_safe_stem the export uses, so the link matches the file the export actually writes instead of dangling (#4696, thanks @ayushcodes10).
  • Fix: wiki a community relabelled only by letter case keeps its article instead of having the sweep delete the file the run just wrote; on a case-sensitive filesystem the stale lower-case twin is unlinked rather than renamed over the fresh file (which would silently restore the old body) (#4508, #4798, thanks @dupeisen).
  • Fix: query filler verbs get/gets/got/getting are dropped from query terms (like the existing work/works), so a framework hub labelled "Get" is not pulled in as a BFS seed by an exact-match bonus; node lookups for a literal Get still resolve (#4686, thanks @AndresDiagoM).
