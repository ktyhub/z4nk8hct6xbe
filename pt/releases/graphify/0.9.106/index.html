#grafificar v0.9.106

grafificar 0.9.106

  • Correção: instalar requires-python é limitado a >=3.10,<3.15, então uv tool install graphifyy (e pip) em uma máquina nova não seleciona mais Python 3.15 — para o qual tree-sitter não tem roda — e então falha com uma compilação de código-fonte que precisa de um compilador C (No such file or directory: 'cc'). uv agora escolhe um interpretador com roda (3.14) por padrão, sem sinalizador --python e sem necessidade de compilador. A linha README do Ubuntu/Debian que solicitava python3.12 (ausente no Debian 12 e Ubuntu 22.04) é substituída pelo instalador uv ou por uma linha python3/pipx simples (#5134).
  • Correção: cpp uma declaração direta de classe/estrutura simples é dobrada em sua definição exclusiva exatamente qualificada quando um arquivo atinge o outro por meio de inclusões exatas incondicionais entre aspas, e uma declaração de membro sem parâmetros é dobrada em sua definição fora de linha comprovada combinando tipo de retorno e qualificadores; sobrecargas, modelos, declarações condicionais e inclusões não comprovadas permanecem separados (#5117, obrigado @xRedLeader).
  • Correção: cpp uma chamada de membro é resolvida por meio de um alias de tipo com escopo definido (using Alias = ns::Type;) e por meio de campos/métodos herdados, e um tipo de ponteiro declarado para frente é concluído no site de uso; receptores ambíguos, virtuais ou herdados de diamante falham no fechamento (#5118, obrigado @xRedLeader).
  • Correção: cpp um membro do modelo fora de linha mantém seu proprietário comprovado do modelo primário e as chamadas dentro de um inicializador protegido por #if ou lista de argumentos são recuperadas de visualizações de ramificação com preservação de bytes (limitadas, fechadas com falha em entradas mal formadas/acima do orçamento); receptores dependentes permanecem sem solução (#5115, obrigado @xRedLeader).
  • Correção: python uma anotação de subscrito pontilhada (mod.MyBox[Foo]) conta seu valor uma vez como o tipo em vez de também como seu próprio argumento genérico, então a referência falsa generic_arg não substitui mais a borda parameter_type/return_type real (#5113, obrigado @rohit-jsfreaky).
  • Correção: ts/js uma chamada por meio de uma importação de namespace ESM (import * as ns from './m'; ns.f()), um requerimento de módulo inteiro CommonJS (const m = require('./m'); m.f()) ou um TS import = require resolve para a declaração real; fechado com falha em um módulo desconhecido, um nome não exportado ou um barril ambíguo (#5114, #5129, obrigado @mohitdixit02).
  • Correção: llm uma entrada FileSlice pré-computada é preservada por meio de extract_corpus_parallel em vez de travar ou carimbar um pai parcial completo; uma fatia que cobre apenas parte de seu arquivo marca o pai parcial para reenvio (#5106, #5128, obrigado @aadilrizwan).
  • Correção: consulta O BFS percorre os níveis em uma ordem fixa e independente de hash, de modo que as linhas de borda de uma consulta (e que sobrevivem ao orçamento do token) não variam mais com PYTHONHASHSEED (#5109, #5112, obrigado @rohit-jsfreaky).
  • Façanha: query --no-doc-demotion (e a chave demote_docs rc / argumento MCP) desativa o peso suave de origem sobre documentos para um corpus de documentos primeiro; os corpora de código não são afetados por padrão (#5084, #5116, obrigado @mohitdixit02).
  • Perf: resolução _collision_aware indexa IDs de irmãos salgados uma vez, em vez de verificar novamente todos os nós por uso, reduzindo o tempo de resolução em grandes corpora com muita colisão (byte de saída do gráfico idêntico) (#5108, #5111, obrigado @rohit-jsfreaky).
  • Correção: manifestar um pom.xml usando um xmlns prefixado, entre aspas simples ou espaçado mantém seu pacote Maven e nós de dependência em vez de perdê-los; um namespace estrangeiro não é contado duas vezes (#5126, obrigado @sdivyanshu90).
  • Correção: merge-graphs graphify merge-graphs informa quantos nós externos foram unificados entre repositórios em vez de absorvê-los silenciosamente; o resultado da mesclagem permanece inalterado (#5127, obrigado @igorpugatschev).
  • Correção: diagnóstico diagnose_extraction não trava mais em um contêiner nodes malformado (nulo ou escalar); a extração malformada ainda aparece por meio do erro de compilação (#5125, obrigado @sdivyanshu90).
  • Correção: html o gráfico interativo não desenha mais uma região de hiperborda sobre membros ocultos por uma alternância de comunidade; uma região desaparece quando menos de dois de seus membros permanecem visíveis (#5122, obrigado @Yi-111-a). O esquema de cache AST aumentou para 43; caches quentes executam novamente as extrações Python e C++ afetadas.

graphify v0.9.106

graphify 0.9.106

  • Fix: install requires-python is capped to >=3.10,<3.15, so uv tool install graphifyy (and pip) on a fresh machine no longer selects Python 3.15 — for which tree-sitter has no wheel — and then fails with a source build that needs a C compiler (No such file or directory: 'cc'). uv now picks a wheel-having interpreter (3.14) by default, with no --python flag and no compiler needed. The Ubuntu/Debian README line that asked for python3.12 (absent on Debian 12 and Ubuntu 22.04) is replaced with the uv installer or a plain python3/pipx line (#5134).
  • Fix: cpp a plain class/struct forward declaration folds into its unique exactly-qualified definition when one file reaches the other through unconditional exact quoted includes, and a parameterless member declaration folds into its proven out-of-line definition by matching return type and qualifiers; overloads, templates, conditional declarations and unproven includes stay separate (#5117, thanks @xRedLeader).
  • Fix: cpp a member call resolves through a scoped type alias (using Alias = ns::Type;) and through inherited fields/methods, and a forward-declared pointee type is completed at the use site; ambiguous, virtual or diamond-inherited receivers fail closed (#5118, thanks @xRedLeader).
  • Fix: cpp an out-of-line template member keeps its proven primary-template owner, and calls inside a #if-guarded initializer or argument list are recovered from byte-preserving branch views (bounded, fail-closed on malformed/over-budget input); dependent receivers stay unresolved (#5115, thanks @xRedLeader).
  • Fix: python a dotted subscript annotation (mod.MyBox[Foo]) counts its value once as the type instead of also as its own generic argument, so the false generic_arg reference no longer replaces the real parameter_type/return_type edge (#5113, thanks @rohit-jsfreaky).
  • Fix: ts/js a call through an ESM namespace import (import * as ns from './m'; ns.f()), a CommonJS whole-module require (const m = require('./m'); m.f()), or a TS import = require resolves to the real declaration; fail-closed on an unknown module, a non-exported name, or an ambiguous barrel (#5114, #5129, thanks @mohitdixit02).
  • Fix: llm a precomputed FileSlice input is preserved through extract_corpus_parallel instead of crashing or stamping a partial parent complete; a slice that covers only part of its file marks the parent partial for re-dispatch (#5106, #5128, thanks @aadilrizwan).
  • Fix: query BFS walks levels in a fixed, hash-independent order, so a query's edge lines (and which survive the token budget) no longer vary with PYTHONHASHSEED (#5109, #5112, thanks @rohit-jsfreaky).
  • Feat: query --no-doc-demotion (and the demote_docs rc key / MCP arg) disables the source-over-docs soft weight for a docs-first corpus; code corpora are unaffected by default (#5084, #5116, thanks @mohitdixit02).
  • Perf: resolution _collision_aware indexes salted sibling ids once instead of rescanning all nodes per use, cutting resolution time on large collision-heavy corpora (graph output byte-identical) (#5108, #5111, thanks @rohit-jsfreaky).
  • Fix: manifest a pom.xml using a prefixed, single-quoted or spaced xmlns keeps its Maven package and dependency nodes instead of losing them; a foreign namespace is not double-counted (#5126, thanks @sdivyanshu90).
  • Fix: merge-graphs graphify merge-graphs reports how many external nodes were unified across repos instead of silently absorbing them; the merge result is unchanged (#5127, thanks @igorpugatschev).
  • Fix: diagnostics diagnose_extraction no longer crashes on a malformed nodes container (null or scalar); the malformed extraction is still surfaced through the build error (#5125, thanks @sdivyanshu90).
  • Fix: html the interactive graph no longer draws a hyperedge region over members hidden by a community toggle; a region vanishes once fewer than two of its members stay visible (#5122, thanks @Yi-111-a).

The AST cache schema is bumped to 43; warm caches re-run the affected Python and C++ extractions.
