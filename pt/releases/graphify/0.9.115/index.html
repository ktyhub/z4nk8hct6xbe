  • caminho: um ID de nó exato é resolvido antes da correspondência de nível, portanto, um ID não é mais recusado como ambíguo (#5367, obrigado @Arav-Arun).
  • python: uma chamada de arquivo cruzado por meio de um from ... import ... explícito é restrita ao nome e módulo importados (#5229, obrigado @Arav-Arun).
  • rust: os membros do impl-block em colisão (fn foo/fn _foo) obtêm, cada um, um ID de nó salgado distinto (#5380, obrigado @ayushcodes10).
  • csharp: uma chamada através de um membro estático de um tipo (Audio.Instance.Click()) é resolvida através do tipo declarado do membro (#5376, obrigado @ArnabOPP).
  • php: as chamadas dos membros são resolvidas em arquivos remapeados e através da cadeia de heranças/traços, mantendo cada site de chamada (#5362, obrigado @livingforelvis).
  • observar: uma reconstrução de gancho reconcilia alterações somente de corpus (renomeação somente de destino, edição de arquivo ignorado) para que o gráfico não fique mais obsoleto (#5331, obrigado @sdivyanshu90).
  • atualização: um arquivo JSON superdimensionado é relatado como ignorado, portanto, um update sem alteração entra em curto-circuito no portão inicial (# 5131, obrigado @madhusudanpatnaik).

graphify v0.9.115

Security fix for a forced-SMB-authentication issue on Windows (GHSA-g6c9-j4vm-mwq4), plus a batch of extractor, resolution and incremental-update fixes. The extractor fixes that change output share one AST cache schema bump (50 → 51), so the first build after upgrading re-extracts the affected languages.

Security

  • extract/detect: indexing a repository no longer stats a corpus-chosen path that resolves outside the scan root. A .sh source/script-invocation line or a .git file naming a UNC gitdir:/commondir could coerce outbound SMB authentication on Windows (leaking a NetNTLMv2 response) on default offline settings. Probes are now bounded to the scan root and UNC paths are refused before they are resolved (GHSA-g6c9-j4vm-mwq4, thanks @Torch4084).

Fixes

  • path: an exact node id resolves before tier matching, so an id is no longer refused as ambiguous (#5367, thanks @Arav-Arun).
  • python: a cross-file call through an explicit from ... import ... is constrained to the imported name and module (#5229, thanks @Arav-Arun).
  • rust: colliding impl-block members (fn foo/fn _foo) each get a distinct salted node id (#5380, thanks @ayushcodes10).
  • csharp: a call through a static member of a type (Audio.Instance.Click()) resolves through the member's declared type (#5376, thanks @ArnabOPP).
  • php: member calls resolve in remapped files and through the inherits/trait chain, keeping every call site (#5362, thanks @livingforelvis).
  • watch: a hook rebuild reconciles corpus-only changes (destination-only rename, ignore-file edit) so the graph no longer goes stale (#5331, thanks @sdivyanshu90).
  • update: an oversized JSON file is reported as skipped so a no-change update short-circuits at the early gate (#5131, thanks @madhusudanpatnaik).
