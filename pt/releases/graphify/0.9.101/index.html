#grafificar v0.9.101

grafificar 0.9.101

Liberação de precisão de resolução e correção de cache em C++, Rust, Python, Go, proteção contra gravação de construção e reconstruções incrementais. ###C++

  • Uma chamada de membro x.m() é vinculada pelo tipo do receptor, agora digitado a partir de parâmetros de função e campos de classe e não apenas locais (void render(Base* b){ b->draw(); } resolve para Base::draw); um receptor não digitado ou ambíguo mantém sua ligação no arquivo (#3215, #4946).
  • Uma definição fora de linha ou de cabeçalho dividido é anexada ao proprietário exclusivo cujo arquivo de classe está em seu conjunto de inclusão, em vez de ligação cruzada a uma função não relacionada de mesmo nome; proprietários ambíguos falham no fechamento (#4916, #4920).
  • Um valor local que pode ser chamado (um lambda ou std::function) é mantido fora da resolução de chamada global por tempos de vida de ligação de intervalo de bytes, de modo que não gera mais uma chamada INFERRED espúria para um global de mesmo nome; uma chamada global legítima posterior sobrevive (#4917, #4921).
  • Uma referência de alias de tipo (using Foo = Bar; e depois Foo x;) é vinculada pela ortografia exata e um alias salgado mantém sua própria borda contains (#4951). ###Rust
  • Uma chamada qualificada por módulo (crate::b::helper(), super::m::f()) é resolvida através da resolução de arquivos cruzados verificada pelo qualificador, permanecendo dentro da caixa do chamador (#2135, #4944).
  • Uma chamada escrita dentro dos argumentos de uma macro de expressão (println!("{}", f()), vec![g()]) é vinculada, restrita a uma lista de permissões para que os corpos macro_rules! e DSLs personalizados sejam deixados em paz (#4945).

Python / Ir

  • Uma chamada simples dentro de um método não se vincula mais a um método de mesmo nome; ele resolve para a função importada ou em nível de módulo que ele nomeia (#4933).
  • As importações são resolvidas em pacotes de namespace PEP 420 divididos em múltiplas raízes src/ (#4929).
  • Um valor do método Go alcançado através de um campo receptor é vinculado como indirect_call (#1566, #4931).
  • Um inicializador var em nível de pacote Go faz referência aos tipos que ele nomeia (#2360, #4932).

Construir / armazenar em cache / reconstruir / observar

  • O protetor de gravação não recusa mais um gráfico íntegro quando a desduplicação de entidade dobra um nó salvo em um gêmeo sobrevivente; uma perda genuína ainda é recusada (#4940, #4952).
  • A evidência de arquivo semântico de origem independente sobrevive a uma dobra em um nó próprio de arquivo AST; INFERRED comum menciona fantasmas ainda dobrados para que os gráficos não acumulem duplicatas (#4896, #4927).
  • O índice de alias da raiz do arquivo apenas religa uma borda quando o arquivo da borda e o destino do alias compartilham uma família de idiomas (#4949).
  • As chaves de cache mantêm sua caixa escrita para que README.md e readme.md não colidam mais e os arquivos com hash/contagem de palavras sejam abertos por meio de os_long_path (#4925, #4937).
  • Um gráfico --code-only permanece somente código através do gancho, update e reconstruções de relógio (#4923, #4939).
  • Uma reconstrução não espera mais para sempre quando msvcrt.locking não é compatível (#4924, #4926).
  • Uma reconciliação completa remove registros de origem de uma árvore de trabalho git vinculada excluída (#4919).
  • As atualizações somente AST preservam a evidência semântica entre arquivos cujo ID do nó colide com uma definição de código (#4950).
  • Um arquivo fatiado é armazenado em cache somente quando cada fatia é bem-sucedida e é montada em ordem de blocos (#4943, #4947). O esquema de cache AST aumentou para 36; caches quentes executam novamente as extrações afetadas. graphify v0.9.101

graphify 0.9.101

Resolution-accuracy and cache-correctness release across C++, Rust, Python, Go, the build write guard, and incremental rebuilds.

C++

  • A member call x.m() binds by the receiver's type, now typed from function parameters and class fields and not only locals (void render(Base* b){ b->draw(); } resolves to Base::draw); an untyped or ambiguous receiver keeps its in-file binding (#3215, #4946).
  • An out-of-line or split-header definition attaches to the unique owner whose class file is in its include set, instead of cross-binding to an unrelated same-named function; ambiguous owners fail closed (#4916, #4920).
  • A local callable value (a lambda or std::function) is kept out of global call resolution by byte-range binding lifetimes, so it no longer mints a spurious INFERRED call to a same-named global; a later legitimate global call survives (#4917, #4921).
  • A type-alias reference (using Foo = Bar; then Foo x;) binds by exact spelling and a salted alias keeps its own contains edge (#4951).

Rust

  • A module-qualified call (crate::b::helper(), super::m::f()) resolves through qualifier-verified cross-file resolution, staying inside the caller's crate (#2135, #4944).
  • A call written inside an expression macro's arguments (println!("{}", f()), vec![g()]) is linked, gated to an allowlist so macro_rules! bodies and custom DSLs are left alone (#4945).

Python / Go

  • A bare call inside a method no longer self-binds to a same-named method; it resolves to the imported or module-level function it names (#4933).
  • Imports resolve across PEP 420 namespace packages split over multiple src/ roots (#4929).
  • A Go method value reached through a receiver field is linked as an indirect_call (#1566, #4931).
  • A Go package-level var initialiser references the types it names (#2360, #4932).

Build / cache / rebuild / watch

  • The write guard no longer refuses a healthy graph when entity dedup folds a saved node into a surviving twin; a genuine loss is still refused (#4940, #4952).
  • Independently sourced semantic file evidence survives a fold into an AST file-self node; ordinary INFERRED mention ghosts still fold so graphs do not accumulate duplicates (#4896, #4927).
  • The file-stem alias index only rebinds an edge when the edge's file and the alias target share a language family (#4949).
  • Cache keys keep their written case so README.md and readme.md no longer collide, and hashed/word-count files are opened through os_long_path (#4925, #4937).
  • A --code-only graph stays code-only across hook, update and watch rebuilds (#4923, #4939).
  • A rebuild no longer waits forever when msvcrt.locking is unsupported (#4924, #4926).
  • A full reconcile evicts source records for an excluded linked git worktree (#4919).
  • AST-only updates preserve cross-file semantic evidence whose node id collides with a code definition (#4950).
  • A sliced file is cached only once every slice has succeeded and is assembled in chunk order (#4943, #4947).

The AST cache schema is bumped to 36; warm caches re-run the affected extractions.

Thanks to @nothariharan, @Deepjyoti-Sarmah, @azizur100389, @andrebrait, @ayushcodes10, @madhusudanpatnaik, @Ethan-Ethan-Ethan and @AndresDiagoM.
