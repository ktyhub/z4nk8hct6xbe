fluxo de fluxo v1.0.0-rc3

1.0.0-rc3 é o terceiro e último candidato a lançamento antes do lançamento oficial do v1.0.0. Ele corrige vários problemas encontrados no rc2 e introduz novos recursos e melhorias.

Principais atualizações:

  1. Introduziu o modelo de decisão para julgamento de suficiência de evidências dentro do ciclo de ferramentas de agentes e o componente Categorizar para agentes.
  2. Adicionado suporte para múltiplas versões de pipeline de ingestão DSL.
  3. O histórico de bate-papo agora armazena e exibe prompts, uso de token e tempo de execução.
  4. Compatível com o esquema v1.0.0-rc2 existente, permitindo uma atualização direta.

ragflow v1.0.0-rc3

1.0.0-rc3 is the third and final release candidate before the official v1.0.0 release. It fixes several issues found in rc2 and introduces new features and enhancements.

Key updates:

  1. Introduced the decision model for evidence sufficiency judgment within the agentic tool loop, and the Categorize component for agents.
  2. Added support for multiple versions of ingestion pipeline DSL.
  3. Chat history now stores and displays prompts, token usage, and execution time.
  4. Compatible with existing v1.0.0-rc2 schema, allowing a direct upgrade.
