fluxo de fluxo v0.25.6

Resumo

Lançado em 26 de maio de 2026.

Novos recursos

  • Agente: adiciona um componente Navegador que permite que a IA navegue e interaja de forma autônoma com páginas da web. #14888

Melhorias

  • RAG: a construção do RAPTOR agora introduz o modo AHC (Ψ-RAG), que expande a semântica do nível do documento para o nível do conjunto de dados. O desempenho de construção do índice não apenas é significativamente superior ao do RAPTOR anterior, mas também supera o antigo RAPTOR no Recall@5 e na média F1. Os usuários podem alternar entre os modos AHC e GMM. Este recurso foi introduzido no v0.25.3 e esta versão corrige vários bugs. #14674#14679
  • Agente: apresenta o decorador @tool leve para agilizar o processo de registro da função Python para modelos de chat. #15047
  • Agente: permite que as mensagens do agente exibam imagens codificadas em base64. #15212
  • Agente: expõe os metadados do arquivo do componente Doc Generator como variáveis discretas. #15080
  • Agente: permite que os desenvolvedores passem chat_template_kwargs para o endpoint de conclusão do chat do agente. #14182#14542

Correções de bugs

  • Corrige /chat/completions para permitir o envio apenas da mensagem mais recente na carga útil API e remove a necessidade de transmitir o histórico completo da conversa. #15197 Consulte também Converse com assistente de chat.
  • O peso atribuído à similaridade vetorial não foi aplicado durante a fase de recuperação. #15108
  • Corrige configurações do analisador que não são salvas na página de configuração do conjunto de dados.
  • Os registros não foram totalmente exibidos na página de detalhes da fonte de dados.
  • Corrige falha na filtragem do status do documento.
  • Corrige proteção contra colisão para respostas de opções LLM vazias.
  • RAG: Processo de construção do RAPTOR interrompido ao usar o mecanismo de documento Infinity. #14998
  • Corrige a análise de resposta de streaming para modelos de raciocínio Mistral/Upstage.
  • Corrige tags HTML na saída do analisador do pipeline de ingestão.
  • Corrige metadados do analisador de tabela.
  • Corrige problemas de aninhamento de loop de eventos assíncronos e tarefas de disparar e esquecer.
  • Corrige asyncio.Semaphore vinculado a diferentes erros de loop de eventos.
  • Agente: corrige o desaparecimento da variável de prompt do componente Agente e problemas de pesquisa vector_similarity_weight.

ragflow v0.25.6

Summary

Released on May 26, 2026.

New features

  • Agent: Adds a Browser component that enables AI to autonomously navigate and interact with web pages. #14888

Improvements

  • RAG: RAPTOR construction now introduces AHC mode (Ψ-RAG), which expands semantics from the document level to the dataset level. Not only is index construction performance significantly higher than the previous RAPTOR, but it also outperforms the old RAPTOR on Recall@5 and average F1. Users can switch between AHC and GMM modes. This feature was introduced in v0.25.3, and this release fixes several bugs. #14674#14679
  • Agent: Introduces lightweight @tool decorator to streamline Python function registration process for chat models. #15047
  • Agent: Enables agent messages to display base64-encoded images. #15212
  • Agent: Exposes Doc Generator component's file metadata as discrete variables. #15080
  • Agent: Allows developers to pass chat_template_kwargs to agent chat completion endpoint. #14182#14542

Bug fixes

  • Fixes /chat/completions to allow sending only latest message in API payload and removes requirement to transmit full conversation history. #15197 See also Converse with chat assistant.
  • Weight assigned to vector similarity was not applied during the retrieval phase. #15108
  • Fixes parser configs not saving on dataset configuration page.
  • Logs wer not fully displayed on data source details page.
  • Fixes document status filtering failure.
  • Fixes crash guard for empty LLM choices responses.
  • RAG: RAPTOR construction process halted when using the Infinity document engine. #14998
  • Fixes streaming response parsing for Mistral/Upstage reasoning models.
  • Fixes HTML tags in ingestion pipeline parser output.
  • Fixes table parser metadata.
  • Fixes asyncio event loop nesting and fire-and-forget task issues.
  • Fixes asyncio.Semaphore bound to different event loop error.
  • Agent: Fixes Agent component prompt variable disappearing and search vector_similarity_weight issues.
