sim v0.9.42

Improvements

  • improvement(chat): let Chat review organization access requests (#9610)
  • improvement(billing): open a Chat plan popup on send instead of a static card above the composer (#9608)
  • improvement(workspaces): move workspace updates behind an application operation and let Chat rename workspaces (#9607)
  • improvement(chat): let Chat manage sim links, bulk-add permission group members, and preview member removal (#9600)
  • improvement(sandbox): verify the workbench CLI inside each command's launch (#9606)
  • improvement(sandbox): return a timed-out workbench run's output and the files it already wrote (#9596)
  • improvement(media): record a hosted-key auth failure when fal refuses Sim's account (#9593)

Bug Fixes

  • fix(sandbox,db): keep a short workbench run's output on timeout; require dev push for the Project bootstrap switch (#9617)
  • fix(release): report short workbench timeouts, gate Sim links in Chat settings, scope the Chat plan modal (#9616)
  • fix(billing): close the Chat plan popup when its shell unmounts and name the organization's plan on organization routes (#9614)
  • fix(chat): hide the Sim links settings section where Sim links are off (#9615)
  • fix(db): bootstrap Projects for development push databases that predate them (#9611)
  • fix(organizations): refuse self-leave for directory-managed members and keep the renamed name visible (#9609)
  • fix(sim-links): hand off a departing member's links to the successor (#9597)
  • fix(knowledge): let members connect their own account to a member-access connector (#9602)
  • fix(organizations): let members leave their organization; remove sign out other devices (#9595)
  • fix(credentials): let members leave a shared credential (#9605)
  • fix(organizations): let admins rename their organization (#9603)
  • fix(settings): let people revoke the accounts they connected for an organization, even after leaving (#9601)
  • fix(ui): disable MCP URL edits and table rename for roles the server refuses (#9599)
  • fix(test): assert recovery backoff on the claims, not worker request arrival (#9591)

Other Changes

  • chore(release): merge staging into the v0.9.42 release
  • chore(release): merge staging into the v0.9.42 release
  • chore(billing): drop the unreachable organization branch from the plan upgrade copy (#9618)
  • docs(library): update best-self-hosted-ai-workflow-automation-platforms-2026 (#9598)
  • docs(library): update best-zapier-alternatives (#9592)
  • docs(library): update best-ai-agent-evaluation-platforms-2026 (#9594)
