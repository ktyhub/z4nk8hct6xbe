sim v0.9.54

Features

  • feat(aws-marketplace): gate Enterprise on the AWS Marketplace container license and add the EKS install profile (#9917)
  • feat(credentials): audit fixes and non-OAuth auth for CrowdStrike, Datadog, Gong, PlanetScale, SailPoint, ServiceNow, Zendesk, ZoomInfo, Shopify, Atlassian, Linear and Twilio (#9911)
  • feat(api): failing block on polled runs, deployed input schema, paused-runs list, and applied limits (#9906)
  • feat(api): workflow outline, workspace schedules list, clearer v2 errors, and catalog value types (#9905)
  • feat(api): agent identity on v2 meta, scoped CLI pairing keys, and v2 workspace rename (#9904)
  • feat(table): add Columns to Return to the legacy Table block's Query Rows (#9887)
  • feat(library): Best AI Agents for Spreadsheet Analysis in Excel and Google Sheets (#9886)
  • feat(library): Best AI Agents for GitHub Pull Requests, Issue Triage, and Code Review (#9884)
  • feat(library): Best AI Agent Platforms for HR Teams Answering Employee Questions (#9883)

Improvements

  • refactor(credentials): resolve Vanta tokens through the coordinated client-token resolver (#9919)
  • improvement(table): document that a column selection matching no column returns empty row data (#9915)

Bug Fixes

  • fix(credentials): age-gate 403 token eviction and tidy the client-credential paths (#9918)
  • fix(api): attribute a polled run's failure only to the block that caused it (#9916)
  • fix(credentials): match JSON 403s case-insensitively and refuse a malformed ZoomInfo access token (#9914)
  • fix(security): refuse an extra slash after https:// in typed base URLs (#9913)
  • fix(api): release-audit follow-ups for the agent API work (#9910)
  • fix(http): keep unwrapping legacy success envelopes for existing workflows (#9909)
  • fix(selectors): redact email path segments from provider failure logs; correct table timeout guidance (#9908)
  • fix(workflows): refuse operation edits that would overwrite a concurrent change (#9902)
  • fix(chat): bring a restored workflow's chat back online when it is relaunched (#9888)
  • fix(http): stop treating 200 bodies with status and data keys as proxy responses (#9889)
  • fix(tables): show rejected filter errors in the grid and fill imports to the row limit (#9881)
  • fix(errors): actionable table read timeouts, 409 for duplicate custom tools, Instagram revocation, selector failure logs (#9880)

Other Changes

  • chore(deps): tidy comments and override order from the dependency sweep (#9907)
  • docs(api): guide for building and running workflows with the API (#9901)
  • chore(deps): update minor and patch dependencies past the release-age gate (#9894)
  • chore(deps): bump turbo to 2.11.10 (#9903)
  • chore(deps): bump AWS SDK to 3.1162.0, OpenTelemetry to 0.223.0/2.12.0, and @daytona/sdk to 0.227.3 (#9900)
  • chore(deps): upgrade docx to 9.15.2 (#9895)
  • chore(deps): bump mdast-util-to-markdown to 2.2.2 (#9899)
  • chore(deps): bump tiptap to 3.32.2 and keep headings that open a list item (#9898)
  • chore(deps): bump knip to 6.44.1 (#9896)
  • chore(deps): bump streamdown to 2.7.1 (#9897)
  • chore(deps): bump electron-builder to 26.18.0 (#9893)
  • chore(deps): upgrade monaco-editor to 0.57.0 (#9892)
  • chore(deps): upgrade cronstrue to 3.38.0 (#9891)
  • docs(library): update postgres-mcp-server-ai-agents (#9885)
  • docs(library): update best-ai-agents-sales-crm-automation (#9882)
  • chore(api-keys): remove the api-key-read-only flag now that read-only keys are live (#9879)
