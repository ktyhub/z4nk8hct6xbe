Vibe-Trading v0.1.5

Destaques

Dois novos loops de herói em cima do agente de pesquisa — extraia sua própria estratégia do diário do corretor e, em seguida, teste a sombra de como você deveria ter negociado.

👥 Conta Sombra (nova)

Carregue um diário do corretor → LLM extrai suas regras → execute o livro de regras em todos os mercados → Relatório HTML/PDF de 8 seções mostrando exatamente quanto P&L você deixa na mesa para disciplinar quebras (violações de regras, saídas antecipadas, entradas perdidas, negociações contrafactuais). 4 novas ferramentas (extract_shadow_strategy, run_shadow_backtest, render_shadow_report, scan_shadow_signals) + 1 habilidade.

📊 Analisador de diário comercial (novo)

analyze_trade_journal ingere exportações 同花顺 / 东方财富 / 富途 / CSV genérico → perfil de negociação completo (dias de manutenção, taxa de vitória, relação PnL, rebaixamento) + 4 diagnósticos de comportamento (efeito de disposição, overtrading, perseguição de impulso, ancoragem).

📄 Leitor de arquivos universal (novo)

read_document envia PDF, Word, Excel, PowerPoint, imagens (OCR) e mais de 40 formatos de texto em um envelope unificado. read_url via Jina para web.

🧠 Agente Harness v2

  • Memória persistente de sessão cruzada (~/.vibe-trading/memory/)
  • Pesquisa de sessão SQLite FTS5
  • Habilidades de autoevolução — CRUD completo (save/patch/delete/skill_file)
  • Compressão de contexto de 5 camadas
  • Lote de ferramentas de leitura/gravação
  • 107 novos testes

Manutenção 0.1.5

  • Segurança: python-multipart >= 0.0.18 (piso CVSS 7.5 CVE)
  • MCP: 5 novas ferramentas expostas (diário comercial + família de contas sombra), corrigida incompatibilidade de nome de registro pattern_recognition → pattern (estava retornando 404)
  • **Paridade Docker **: 9 dependências de tempo de execução adicionadas ao requirements.txt (openpyxl, python-docx, python-pptx, pypdfium2, Pillow, ddgs, jinja2, matplotlib, weasyprint) - a imagem Docker estava silenciosamente faltando estes
  • CLI: versão do banner passou para 0.1.5 (estava travada em 0.1.0)
  • Frontend: barra lateral + versão package.json transferida para 0.1.5
  • Testes: test_skills.py não vaza mais para ~/.vibe-trading/skills/user/
  • Manifesto de HABILIDADE: sincronizado com 22 ferramentas MCP / 71 habilidades / 29 predefinições de enxame

Vibe-Trading v0.1.5

Highlights

Two new hero loops on top of the research agent — extract your own strategy from your broker journal, then backtest the shadow of how you should have traded.

👥 Shadow Account (new)

Upload a broker journal → LLM extracts your rules → run the rulebook across markets → 8-section HTML/PDF report showing exactly how much P&L you leave on the table to discipline breakdowns (rule violations, early exits, missed entries, counterfactual trades). 4 new tools (extract_shadow_strategy, run_shadow_backtest, render_shadow_report, scan_shadow_signals) + 1 skill.

📊 Trade Journal Analyzer (new)

analyze_trade_journal ingests 同花顺 / 东方财富 / 富途 / generic CSV exports → full trading profile (holding days, win rate, PnL ratio, drawdown) + 4 behavior diagnostics (disposition effect, overtrading, chasing momentum, anchoring).

📄 Universal File Reader (new)

read_document dispatches PDF, Word, Excel, PowerPoint, images (OCR), and 40+ text formats behind one unified envelope. read_url via Jina for web.

🧠 Agent Harness v2

  • Persistent cross-session memory (~/.vibe-trading/memory/)
  • SQLite FTS5 session search
  • Self-evolving skills — full CRUD (save / patch / delete / skill_file)
  • 5-layer context compression
  • Read/write tool batching
  • 107 new tests

0.1.5 maintenance

  • Security: python-multipart >= 0.0.18 (CVSS 7.5 CVE floor)
  • MCP: 5 new tools exposed (trade journal + shadow account family), fixed pattern_recognition → pattern registry name mismatch (was returning 404)
  • Docker parity: 9 runtime deps added to requirements.txt (openpyxl, python-docx, python-pptx, pypdfium2, Pillow, ddgs, jinja2, matplotlib, weasyprint) — Docker image was silently missing these
  • CLI: banner version bumped to 0.1.5 (was stuck at 0.1.0)
  • Frontend: sidebar + package.json version bumped to 0.1.5
  • Tests: test_skills.py no longer leaks into ~/.vibe-trading/skills/user/
  • SKILL manifest: synced to 22 MCP tools / 71 skills / 29 swarm presets

Install / upgrade

pip install -U vibe-trading-ai==0.1.5

Docker:

docker compose pull && docker compose up -d

By the numbers

  • 32 tools (27 registry + 5 new)
  • 22 MCP tools exposed
  • 71 bundled skills (+ user-created)
  • 7 backtest engines + options portfolio
  • 13 LLM providers, 5 data sources with auto-fallback
  • 29 swarm presets
