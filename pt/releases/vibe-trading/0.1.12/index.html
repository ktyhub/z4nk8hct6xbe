Vibe-Trading v0.1.12

🌀 v0.1.12 — Cronograma do regime de correlação, três novos provedores, MetaTrader 5 + uma onda de confiabilidade

v0.1.12 acumula quase duas semanas de trabalho desde 0.1.11 (10/07/2026) — as manchetes: uma linha do tempo do regime de correlação que responde "quando o mercado se fundiu em um bloco, e estamos nesse estado agora?", três novos provedores LLM mais resolução de endpoint baseada em catálogo que faz com que cada provedor trabalhe com apenas uma chave, o conector de corretor MetaTrader 5 (Exness) (12 corretores), o Habilidade de Gerente de Desenvolvimento de Estratégia, Binance USD-M perpétuos com financiamento histórico e uma ampla onda de confiabilidade — endurecimento estrito JSON/finito, robustez de sessão/diário, vetorização de 80× e correção de streaming nativa zai. Esta versão está disponível nas versões PyPI, ClawHub e GitHub.

pip install -U vibe-trading-ai
# or
uv tool install --reinstall vibe-trading-ai

Destaques

🌀 Cronograma do regime de correlação

Um novo endpoint GET /correlation/regime aditivo e uma faixa opcional "Linha do tempo do regime" na guia Correlação (#756, fecha #719, obrigado @ebujinovch). Ele reutiliza os mesmos dados de preço que /correlation já busca: correlações de pares rolantes são reduzidas a um escalar de densidade de borda por barra (a fração de pares de ativos cujo |ρ| limpa um limite), a série é suavizada causalmente (janela final - nunca lê o futuro) e uma máquina de estado de histerese de dois limites marca episódios FUSED contíguos, com uma banda morta que suprime a vibração. Ele compartilha o orçamento de autorização + limite de taxa do /correlation, reduz a janela para que prazos curtos não possam retornar vazios e é explicitamente contexto descritivo de risco, não um sinal de negociação. Apoiado pela habilidade correlation-regime (#557).

🔌 Três novos provedores LLM + resolução robusta de endpoint

Adaptadores nativos para SiliconFlow (CN + Global, nº 565, obrigado @UNHNQ), iFlytek Spark (nº 537, obrigado @FenjuFu) e mensagens antrópicas nativas API (nº 695, obrigado @jelech; pip install "vibe-trading-ai[anthropic]"), além de endpoints regionais MiniMax (nº 731, obrigado @octo-patch). Abaixo, as credenciais do provedor são resolvidas por meio de um caminho centralizado (nº 563, obrigado @shadowinlife), e duas arestas de longa data são corrigidas (nº 758): quando nenhum *_BASE_URL é definido, o backend agora volta para o endpoint de catálogo canônico de cada provedor (as mesmas configurações da Web padrão já usadas) em vez de padronizar silenciosamente para api.openai.com - então um provedor funciona com apenas uma chave - e um endpoint que transmite zero pedaços voltam para um invocação sem streaming em vez de erro, com uma dica de página de erro HTML quando um URL base está configurado incorretamente.

📈 Conector MetaTrader 5 (Exness) + fonte de dados mt5 — 12 corretoras

Um conector de corretor MetaTrader 5 de primeira classe (#481, obrigado @StaniellG) — superfície de leitura completa, além de colocação de pedidos em um terminal em execução local, com um protetor de identidade bidirecional (perfil em papel ⇔ demonstração trade_mode, login fixado, concurso rejeitado) e limites max_order_volume / max_order_notional_usd em nível de conector na demonstração E ao vivo. O portão de mandato ao vivo ganha vocabulário de instrumento forex/cfd e um gancho de dimensionamento com reconhecimento de lote para que os limites em USD sejam vinculados a pedidos de tamanho de lote (lote 0.1 EURUSD ≈ US$ 10.800, nunca 0.1 × cotação). O carregador mt5 lidera a cadeia de fallback forex (símbolos exatos do corretor com descoberta de sufixo Exness, barras de 1m – 1D). Conectores do corretor: 11 → 12; fontes de dados de mercado → 23.

🧬 Gerente de Desenvolvimento de Estratégia

sdm_register / sdm_status / sdm_decay_scan transformam artigos acadêmicos e pesquisas de corretores em fatores e estratégias registrados (#457, fecha #455, obrigado @shadowinlife), apoiados por um armazenamento de artefato SQLite persistente (UNIQUE(name, universe)) e monitoramento de decaimento IC/Sharpe automatizado conduzindo um ciclo de vida active → monitoring → decayed → disabled. É fornecido com OCR conectável para read_document (RapidOCR local por padrão; a nuvem Qwen-VL é apenas opcional explícita, nunca selecionada automaticamente).

₿ Binance USD-M perpétuos

Roteamento BTC-USDT-PERP explícito com separação de preço de execução/marcação (falha no fechamento quando os dois não estão sincronizados com carimbo de data e hora) e acordos de financiamento históricos (#470/#716, obrigado @honginp). Os colchetes de manutenção são dissociados da busca autenticada ao vivo e fornecidos como um artefato validado com hash de conteúdo (#757), de modo que um backtest -PERP simples permanece com credencial zero — a regressão em que cada busca criminosa exigia uma chave Binance API desapareceu.

👁️ OCR conectável + extração de visão LLM

read_document ganha uma arquitetura de mecanismo de OCR conectável com extração LLM-vision opcional e um limite de densidade de texto configurável (nº 548, obrigado @shadowinlife) - local por padrão, mecanismos de nuvem apenas opcionais, nunca selecionados automaticamente.

🧰 Plataforma e segurança

  • Correção do viés de antecipação em todos os cinco otimizadores de portfólio (#487, obrigado @YZY0108) — os pesos executados na abertura de uma barra não incluem mais o retorno próximo ao fechamento dessa barra. Além de métricas de rotatividade de portfólio realizadas para cada otimizador (nº 478, obrigado @Robin1987China).
  • Reforço de segurança — todas as 10 descobertas da auditoria externa de 10/07/2026 foram encerradas (nº 476): sandbox de backtest reforçado com AST, tíquetes de autenticação SSE de curta duração, Compose reforçado, autenticação /correlation + limitação de taxa, cabeçalhos de segurança, dependências bloqueadas por hash e ações fixadas por SHA.
  • Vetorização de alinhamento de sinal 80× (#698, obrigado @shadowinlife) e cache de descoberta de ferramenta MCP de enxame (#704) cortam o relógio de parede em painéis largos e execuções de vários trabalhadores.
  • Modo TAP opcional para Alpaca (nº 377, obrigado @0xZKnw), conjunto de conexão local de thread IBKR + cotações de instantâneos (nº 636, obrigado @MikeCer), fiação Robinhood account_number (nº 726, obrigado @nareshkps), o provedor de gateway Requesty (nº 474, obrigado @Thibaultjaigu) e predefinições de enxame de usuário descoberta (#570, obrigado @darkknight4563).
  • Dois novos fatores acadêmicos — Frazzini-Pedersen apostando contra beta (#480, obrigado @YogeshModi24) e academic_corr_rewire (#705, obrigado @ebujinovch): Alpha Zoo 460 → 462 em 5 famílias.

🛠️ Onda de confiabilidade e correção

  • Strict-JSON / endurecimento de número finito em todo o backtest + pilha de ferramentas (obrigado @santhreal) — as taxas de risco permanecem finitas quando o patrimônio ultrapassa zero (#765) ou anualiza um caminho explosivo (#739/#740); métricas escalares (# 766), fator IC padrão (# 767) e inclinação de tendência do padrão (# 764) emitem RFC-8259 JSON estrito (null, nunca NaN/Infinity); Os ajudantes de Black-Scholes tratam spot/strike não positivo como intrínseco (#744).
  • Robustez de sessão/diário — uma linha session.json corrompida (#762) ou linha messages.jsonl com esquema ruim (#763) não aborta mais a listagem/leitura; Códigos de compartilhamento A com string flutuante do Excel (# 770), intervalos de páginas PDF unicode-dash (# 769), linhas export KEY= dotenv (# 768) e barras 1m do Google (# 761) são analisados ​​​​corretamente.
  • Ampla confiabilidade — o cancelamento é honrado antes da primeira iteração do AgentLoop (#641, fecha #638), uma corrida DOM de streaming insertBefore de frontend é corrigida (#717, obrigado @Marnie0415), o mecanismo composto recorre a símbolos desconhecidos (#734), falhas de HTTP de fluxo de códice são classificadas para nova tentativa correta (#663) e #584 (obrigado @xkam7ar) fecha um lote de problemas de embalagem/web/agendador/swarm/CLI.

Vibe-Trading v0.1.12

🌀 v0.1.12 — Correlation regime timeline, three new providers, MetaTrader 5 + a reliability wave

v0.1.12 rolls up nearly two weeks of work since 0.1.11 (2026-07-10) — the headlines: a correlation regime timeline that answers "when did the market fuse into one bloc, and are we in that state now?", three new LLM providers plus catalog-based endpoint resolution that makes every provider work with just a key, the MetaTrader 5 (Exness) broker connector (12 brokers), the Strategy Development Manager skill, Binance USD-M perpetuals with historical funding, and a broad reliability wave — strict-JSON/finite hardening, session/journal robustness, an 80× vectorization, and the native zai streaming fix.

This release is available on PyPI, ClawHub, and GitHub Releases.

pip install -U vibe-trading-ai
# or
uv tool install --reinstall vibe-trading-ai

Highlights

🌀 Correlation regime timeline

A new additive GET /correlation/regime endpoint and an opt-in "Regime timeline" strip on the Correlation tab (#756, closes #719, thanks @ebujinovch). It reuses the same price data /correlation already fetches: rolling pairwise correlations reduce to an edge-density scalar per bar (the fraction of asset pairs whose |ρ| clears a threshold), the series is causally smoothed (trailing window — never reads the future), and a two-threshold hysteresis state machine marks contiguous FUSED episodes, with a dead band that suppresses chatter. It shares /correlation's auth + rate-limit budget, floors the window so short timelines can't return empty, and is explicitly descriptive risk context, not a trading signal. Backed by the correlation-regime skill (#557).

🔌 Three new LLM providers + robust endpoint resolution

Native adapters for SiliconFlow (CN + Global, #565, thanks @UNHNQ), iFlytek Spark (#537, thanks @FenjuFu), and the native Anthropic Messages API (#695, thanks @jelech; pip install "vibe-trading-ai[anthropic]"), plus MiniMax regional endpoints (#731, thanks @octo-patch). Underneath, provider credentials are resolved through one centralized path (#563, thanks @shadowinlife), and two long-standing rough edges are fixed (#758): when no *_BASE_URL is set, the backend now falls back to each provider's canonical catalog endpoint (the same default Web Settings already used) instead of silently defaulting to api.openai.com — so a provider works with just a key — and an endpoint that streams zero chunks falls back to a non-streaming invoke rather than erroring, with an HTML-error-page hint when a base URL is misconfigured.

📈 MetaTrader 5 (Exness) connector + mt5 data source — 12 brokers

A first-class MetaTrader 5 broker connector (#481, thanks @StaniellG) — full read surface plus order placement against a locally running terminal, with a bidirectional identity guard (paper profile ⇔ demo trade_mode, login pinned, contest rejected) and connector-level max_order_volume / max_order_notional_usd caps on demo AND live. The live mandate gate gains forex/cfd instrument vocabulary and a lot-aware sizing hook so USD caps bind on lot-sized orders (0.1 lot EURUSD ≈ $10,800, never 0.1 × quote). The mt5 loader heads the forex fallback chain (broker-exact symbols with Exness suffix discovery, 1m–1D bars). Broker connectors: 11 → 12; market-data sources → 23.

🧬 Strategy Development Manager

sdm_register / sdm_status / sdm_decay_scan turn academic papers and broker research into registered factors and strategies (#457, closes #455, thanks @shadowinlife), backed by a persistent SQLite artifact store (UNIQUE(name, universe)) and automated IC/Sharpe decay monitoring driving an active → monitoring → decayed → disabled lifecycle. Ships with pluggable OCR for read_document (local RapidOCR by default; cloud Qwen-VL is explicit opt-in only, never auto-selected).

₿ Binance USD-M perpetuals

Explicit BTC-USDT-PERP routing with execution/mark price separation (fail-closed when the two aren't timestamp-synchronized) and historical funding settlements (#470/#716, thanks @honginp). Maintenance brackets are decoupled from the live authenticated fetch and supplied as a validated, content-hashed artifact instead (#757), so a plain -PERP backtest stays zero-credential — the regression where every perp fetch required a Binance API key is gone.

👁️ Pluggable OCR + LLM-vision extraction

read_document gains a pluggable OCR engine architecture with optional LLM-vision extraction and a configurable text-density threshold (#548, thanks @shadowinlife) — local by default, cloud engines opt-in only, never auto-selected.

🧰 Platform & safety

  • Look-ahead-bias fix across all five portfolio optimizers (#487, thanks @YZY0108) — weights executed at a bar's open no longer include that bar's close-to-close return. Plus realized portfolio turnover metrics for every optimizer (#478, thanks @Robin1987China).
  • Security hardening — all 10 findings from the 2026-07-10 external audit closed (#476): AST-hardened backtest sandbox, short-lived SSE auth tickets, hardened Compose, /correlation auth + rate limiting, security headers, hash-locked dependencies, and SHA-pinned Actions.
  • 80× signal-alignment vectorization (#698, thanks @shadowinlife) and swarm MCP tool-discovery caching (#704) cut wall-clock on wide panels and multi-worker runs.
  • Opt-in TAP mode for Alpaca (#377, thanks @0xZKnw), IBKR thread-local connection pool + snapshot quotes (#636, thanks @MikeCer), Robinhood account_number wiring (#726, thanks @nareshkps), the Requesty gateway provider (#474, thanks @Thibaultjaigu), and user swarm-presets discovery (#570, thanks @darkknight4563).
  • Two new academic factors — Frazzini-Pedersen betting-against-beta (#480, thanks @YogeshModi24) and academic_corr_rewire (#705, thanks @ebujinovch): Alpha Zoo 460 → 462 across 5 families.

🛠️ Reliability & correctness wave

  • Strict-JSON / finite-number hardening across the backtest + tools stack (thanks @santhreal) — risk ratios stay finite when equity crosses zero (#765) or annualizes an explosive path (#739/#740); scalar metrics (#766), factor IC std (#767), and pattern trend-slope (#764) emit strict RFC-8259 JSON (null, never NaN/Infinity); Black-Scholes helpers treat non-positive spot/strike as intrinsic (#744).
  • Session / journal robustness — one corrupt session.json (#762) or schema-bad messages.jsonl line (#763) no longer aborts listing/reading; Excel float-stringified A-share codes (#770), unicode-dash PDF page ranges (#769), export KEY= dotenv lines (#768), and yahoo 1m bars (#761) all parse correctly.
  • Broad reliability — cancellation is honored before the first AgentLoop iteration (#641, closes #638), a frontend insertBefore streaming DOM-race is fixed (#717, thanks @Marnie0415), the composite engine falls back for unknown symbols (#734), codex stream HTTP failures are classified for correct retry (#663), and #584 (thanks @xkam7ar) closes a batch of packaging/web/scheduler/swarm/CLI issues.

🙌 Contributor cycle

~90 correctness/reliability fixes and features from a wide contributor cohort — @santhreal (a 30-PR correctness sweep), @xkam7ar (reliability + QVeris hardening), @shadowinlife (SDM, OCR, vectorization), @ebujinovch (regime timeline), @honginp (Binance perps), @StaniellG (MetaTrader 5), and many more. Full per-person credits live in the README Contributors section and the CHANGELOG. Thanks also to @GabbaTauchi for the zai bug report (#758).

Install / upgrade

Remote API/Web deployments should set API_AUTH_KEY and explicit trusted CORS origins; local CLI and localhost Web UI workflows stay low-friction.

By the numbers

Numbers at 0.1.12: 8 backtest engines + options_portfolio · 462 alphas / 5 families · 88 skills · 30 swarm presets · 23 market-data sources · 12 broker connectors · 75 free-mode tools (78 with QVeris) · 54 MCP tools · 5 optimizers · 16 IM adapters.

Validation

Full backend suite 6,019 passed (only pre-existing env/network fails, confirmed against clean main); frontend build + 310 vitest green; wheel verified (vibe_trading_ai-0.1.12, contents spot-checked). Protected agent core (src/agent, src/session, src/providers) reviewed for every change.
