Vibe-Trading v0.1.9

pip install -U vibe-trading-ai · 36 ferramentas MCP · 77 habilidades · 29 predefinições de enxame Um lançamento roll-up cobrindo tudo desde 0.1.8.

Destaques

  • Perfis de corretores que priorizam o conector (IBKR + Robinhood). O acesso à negociação começa a partir de um perfil de conector selecionável em vez de pontos de entrada separados de corretor/ao vivo; As ferramentas vibe-trading connector list/use/check/account/positions/orders/quote/history e MCP trading_* compartilham o perfil selecionado, tendo paper/live como atributo do conector. O IBKR pode ser usado imediatamente como um perfil local de gateway TWS/IB somente leitura; o caminho MCP remoto oficial do IBKR é propagado como um teste OAuth mcp.read até que nomes de ferramentas de leitura estáveis ​​sejam enviados. Robinhood Agentic Trading é um conector local por trás do OAuth, um mandato comprometido, um protetor de pedidos, um livro de auditoria e um interruptor de parada instantânea.
  • Tempo de execução da meta de pesquisa. Metas de longa duração somente para pesquisa com critérios de lista de verificação auditáveis, orçamentos e um comando /goal CLI, além de endpoints REST + MCP e um Web GoalDrawer.
  • Swarm pass. Reconciliação ao vivo + manutenção de atividade do MCP (nº 132), ferramentas MCP externas configuradas pelo operador em trabalhadores (nº 142), controle de DAG quando uma tarefa upstream falha (nº 145), um controle aleatório de banco alfa estrito (nº 143) e um novo retry_run para relançar execuções com falha/obsoletas — 36 ferramentas MCP agora.
  • Refator de pacote CLI (agent/cli/) com uma interface de usuário de terminal atualizada, além de um carregador de compartilhamento A sem token mootdx e suporte a ambiente de proxy CCXT.

Correções

  • --version não deriva mais (#156) — deriva dos metadados do pacote, voltando para pyproject.toml; nenhuma constante codificada deixada para esquecer no lançamento.
  • Passagem de robustez: validação pré-voo para mecanismos de sinal gerados por LLM (nº 149), saída elegante do loop do agente no orçamento de iteração (nº 148), gravações de sessão flush + fsync que ignoram JSONL corrompido na leitura (nº 147) e manipulação de IME Enter no compositor da Web (nº 146).
  • O indicador de status de execução da sessão sobrevive à reconexão/recarregamento/navegação na barra lateral; links de relatório completo entre navegadores (#150); tempo limite de inatividade SSE configurável via VIBE_TRADING_SSE_TIMEOUT (#157); alinhamento de carimbo de data/hora de correlação entre mercados (#158).

Vibe-Trading v0.1.9

pip install -U vibe-trading-ai · 36 MCP tools · 77 skills · 29 swarm presets

A roll-up release covering everything since 0.1.8.

Highlights

  • Connector-first broker profiles (IBKR + Robinhood). Trading access starts from a selectable connector profile instead of separate broker/live entry points; vibe-trading connector list/use/check/account/positions/orders/quote/history and the MCP trading_* tools share the selected profile, with paper/live as an attribute of the connector. IBKR is usable immediately as a local read-only TWS / IB Gateway profile; the official IBKR remote MCP path is seeded as an OAuth mcp.read probe until stable read tool names ship. Robinhood Agentic Trading is a bounded connector behind OAuth, a committed mandate, an order guard, an audit ledger, and an instant halt switch.
  • Research Goal runtime. Long-running, research-only goals with auditable checklist criteria, budgets, and a /goal CLI command, plus REST + MCP endpoints and a Web GoalDrawer.
  • Swarm pass. Live reconcile + MCP keepalive (#132), operator-configured external MCP tools in workers (#142), DAG gating when an upstream task fails (#145), a strict alpha-bench random control (#143), and a new retry_run to relaunch failed/stale runs — 36 MCP tools now.
  • CLI package refactor (agent/cli/) with a refreshed terminal UI, plus a mootdx no-token A-share loader and CCXT proxy-env support.

Fixes

  • --version no longer drifts (#156) — derives from package metadata, falling back to pyproject.toml; no hardcoded constant left to forget on release.
  • Robustness pass: pre-flight validation for LLM-generated signal engines (#149), graceful agent-loop exit at the iteration budget (#148), flush + fsync session writes that skip corrupted JSONL on read (#147), and IME Enter handling in the Web composer (#146).
  • Session running-status indicator survives reconnect / reload / sidebar nav; cross-browser Full Report links (#150); configurable SSE idle timeout via VIBE_TRADING_SSE_TIMEOUT (#157); cross-market correlation timestamp alignment (#158).
