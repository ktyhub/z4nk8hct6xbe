Vibe-Trading v0.1.8

🧬 v0.1.8 — Alpha Zoo v1 + polimento do fluxo de trabalho de pesquisa

v0.1.8 é um importante lançamento de conteúdo para Vibe-Trading. The headline is the Alpha Zoo: 452 pre-built quantitative alphas across four bundled libraries — qlib158, alpha101, gtja191, and academic — with a one-line CLI to bench any zoo on your universe, agent integration via two new tools, four new REST routes with SSE-streamed progress, and a browse/detail/bench Web UI at /alpha-zoo. The release also lands the long-running MCP client integration, a Trust Layer run card in the Web UI, the public wiki launch at vibetrading.wiki, the Hypothesis Registry MVP, and a substantial security + hardening pass driven by community PRs. Esta versão está disponível nas versões PyPI, ClawHub e GitHub.

pip install -U vibe-trading-ai
# or
uv tool install --reinstall vibe-trading-ai

Destaques

🧬 Alpha Zoo — 452 quant alphas pré-construídos em 4 zoológicos

Cross-sectional formulaic alphas with metadata, lookahead-banned at the operator layer, registry-validated, and reachable from CLI, agent, REST API, and Web UI:

  • qlib158 — 154 alfas. Apache-2.0 port of Microsoft Qlib's Alpha158 feature handler, with the upstream commit SHA pinned in every adapted module's header and the upstream NOTICE bundled.
  • alpha101 — 101 alfas. Implementação de Kakushadze (2015) "101 Formulaic Alphas" (arXiv:1601.00991), escrito a partir do apêndice do artigo. 19 alfas neutros no setor sinalizam requires_sector=True e pulam de forma limpa em universos sem tags de setor.
  • gtja191 — 191 alfas. Implementação do relatório de pesquisa de 2014 da Guotai Junan Securities "191 Fatores Alfa de Negociação de Curto Prazo". Decisões de mapeamento de operadores (interpretações SMA / WMA / REGBETA / HIGHDAY) documentadas por alfa.
  • acadêmico — 6 fatores. Fama-French 5 + Carhart momentum, shipped as honest price-based proxies (the canonical FF series need book-to-market / profitability / investment growth fundamentals we don't bundle). Os apelidos carregam o prefixo [PRICE PROXY]; A biblioteca de dados de Kenneth French é referenciada para usuários que precisam de retornos mensais canônicos. Each alpha carries a __alpha_meta__ dict (formula LaTeX, theme, universe, columns_required, warmup, decay horizon, notes) validated by a pydantic extra="forbid" schema.

🖥️ CLI de uma linha

vibe-trading alpha list --zoo gtja191 --theme momentum --limit 10
vibe-trading alpha show gtja191_171
vibe-trading alpha bench --zoo gtja191 --universe csi300 --period 2018-2025 --top 20
vibe-trading alpha compare --all
vibe-trading alpha export-manifest --out wiki/alpha-library/manifest.json

bench aciona uma rica barra de progresso com banner alfa-id + ETA ao vivo, retorna códigos de saída adequados em caso de falha e silencia o ruído scipy ConstantInputWarning. Todos os cinco subcomandos respeitam dicas TTY e um modo --json para scripts.

🌐 Web UI em /alpha-zoo + 4 rotas REST com SSE

Three views in the React Web UI: Browse (4 zoo cards, filter bar, paginated table), Detail (formula, metadata, source code), Bench (form → SSE-streamed progress → Alive/Reversed/Dead stat cards + Top-5-by-IR + Most-Reversed tables + by-theme bar chart). Rota Auto-Vite em /alpha-zoo, entrada de navegação no Layout.

GET  /alpha/list?zoo=&theme=&universe=&limit=
GET  /alpha/{alpha_id}
POST /alpha/bench               (body: {zoo, universe, period, top}) → 202 + job_id
GET  /alpha/bench/{job_id}/stream   (SSE: progress / result / done / error)

Background bench jobs run via asyncio.to_thread with a 2-concurrent-job semaphore (429 on saturation), in-memory state with 1-hour TTL, 15-second heartbeat comment frames to keep proxies from closing idle streams, and sanitised error messages so unexpected exceptions don't leak server-side paths.

🤖 Integração do agente

Duas novas ferramentas de descoberta automática (AlphaZooTool, AlphaBenchTool) mais uma fábrica ZooSignalEngine.from_zoo(...) estilo painel na habilidade multifatorial que compõe um ou mais alfas em um sinal longo-curto compatível com os mecanismos de backtest existentes. O legado example_signal_engine.py por símbolo é preservado para compatibilidade com versões anteriores.

🛡️ Piso de segurança

Portões de qualidade que disparam em cada execução PR e vibe-trading alpha bench:

  • Porta de pureza AST (test_alpha_purity.py) — verifica todos os módulos zoo/**/*.py, permite apenas importações de pandas, numpy, scipy.*, src.factors.base, __future__, typing, math, dataclasses; proíbe os / sys / subprocess / socket / urllib / requests / httpx / pathlib / Path / open / eval / exec / compile / __import__ mais breakpoint / input / globals / locals / vars / __class__ / __subclasses__ / __mro__ / __globals__ / __builtins__, além de acesso dunder-string getattr (incluindo dunders concatenados com BinOp).
  • Teste sentinela Lookahead (test_lookahead.py) — painel sintético de 300 linhas; linhas corrompidas após a investigação; fator de afirmação na sonda inalterado dentro de 1e-9.
  • Integração pytest-socket — o conjunto de testes de fatores é executado em rede desabilitada.
  • CI grep gates (tools/ci_grep_gates.sh) — rejeita yaml.load( sem safe_load, a string de nome de marca registrada em artefatos enviados e qualquer vazamento de dados por código de estoque em wiki/**/*.{json,csv,html}.

📡 Integração MCP client (stdio v1)

O agente agora pode carregar ferramentas de servidores MCP externos via ~/.vibe-trading/agent.json, opt-in por sessão via ALLOW_SESSION_MCP_SERVERS=1. Transporte Stdio apenas na v1; HTTP/SSE adiado. As colisões de nomes de ferramentas recebem um sufixo hash determinístico; as falhas da ferramenta remota são normalizadas para cargas úteis de erro em vez de borbulhar. Muito obrigado a @shadowinlife (#83) pela implementação ponta a ponta e pelos padrões preocupados com a segurança.

🧠 Registro de hipóteses (MVP backend)

create_hypothesis / update_hypothesis / link_backtest / search_hypotheses fornecem às hipóteses de pesquisa um ciclo de vida durável, links para cartões de execução e notas de invalidação. Integração da UI a seguir.

Caveats / Known limitations

  • btc-usdt universe is single-asset. Cross-sectional IC needs ≥2 instruments, so alpha101_btc returns alive/reversed/dead = 0/0/0 by construction. A curated crypto-majors multi-symbol basket is planned for 0.2.
  • SP500 universe uses today's constituent list as a proxy for point-in-time index membership, introducing survivorship bias. Documented in bench_summary.json["meta"] and in the wiki blog caveat section. Point-in-time constituent source is a 0.2 follow-up.
  • MCP server does not yet expose alpha_zoo / alpha_bench tools. The Python agent layer, REST API, CLI, and Web UI all expose them; MCP wrap-up planned for 0.1.9.
  • 19 industry-neutral alpha101 alphas (#48, 56, 58, 59, 63, 67, 69, 70, 76, 79, 80, 82, 87, 89, 90, 91, 93, 97, 100) need a sector tag. Tushare provides this; yfinance does not, so SP500 benches skip these 19. Cross-zoo SP500 follow-up will plug a sector data source.
  • docs/ is gitignored, internal planning only. Do not push contents of docs/ to public branches.
