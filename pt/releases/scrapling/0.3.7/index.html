Raspagem v0.3.7

Uma nova atualização com muitas mudanças importantes

🚀 Coisas novas e mudanças na qualidade de vida

  • Argumento solve_cloudflare retrabalhado em StealthyFetcher para torná-lo capaz de resolver todos os tipos de implementações personalizadas de Turnstile.
  • Refatoração de toda a base de código para ser aceitável pela Pyright, então espere uma experiência IDE impecável agora com todo o software e muitos bugs resolvidos.
  • Refatorou a lógica de solicitações para ser mais limpa e rápida (também resolve #97)
  • Adicionada uma nova opção user_data_dir a todas as classes de sessão baseadas em navegador para permitir ao usuário reutilizar os dados da sessão do navegador (cookies/armazenamento/etc...) de sessões anteriores. Deixá-lo fará com que o Playwright use um diretório aleatório em cada execução, como estava acontecendo antes.
  • Adicionada uma nova opção de customização additional_args ao Dynamic fetcher e sua classe de sessão para permitir ao usuário passar argumentos extras para o contexto do Playwright, como fizemos com StealthyFetcher antes.
  • Foi melhorada a lógica de rota para coletar a última resposta de navegação para todos os navegadores, o que permite que as respostas brutas sejam passadas ao analisador antes de serem processadas pelos navegadores como antes. Isso será muito útil com respostas de texto/JSON.

🐛 Correções de bugs

  • O retrabalho da lógica de rota resolveu um problema de recuperação do conteúdo de sites instáveis em alguns dispositivos Windows.
  • Todas as refatorações que aconteceram nesta versão resolveram muitos bugs ao longo do caminho que eram difíceis de detectar antes, e problemas estranhos de preenchimento automático com alguns IDEs.
  • Muitas correções no site de documentação 🙏 Agradecimentos especiais à nossa comunidade Discord por todos os testes e feedback contínuos

Scrapling v0.3.7

Highlights

  • Custom Turnstile support in StealthyFetcher — solve_cloudflare was reworked to handle arbitrary/custom Turnstile implementations, not just the standard widget. If you've been maintaining manual workarounds for nonstandard Turnstile sites, this is the release to drop them and retest your hardest targets.

  • Persistent browser sessions via user_data_dir — all browser-based session classes now accept user_data_dir, letting you reuse cookies/storage across runs. Previously Playwright silently allocated a fresh random profile each run, so login state was always lost. Set it explicitly to keep sessions — just be aware a persistent profile can also carry stale state between runs.

  • Raw responses reach the parser earlier — the route logic that captures the last navigation response was reworked so raw responses are handed to the parser before browser processing. That's a genuine win for text/JSON endpoints browsers would otherwise mangle, and it also fixes content retrieval failures on unstable sites on some Windows devices.

  • Playwright context tuning for DynamicFetcher — a new additional_args option on DynamicFetcher and its session class brings it to parity with StealthyFetcher, letting you pass extra arguments into Playwright's browser context for finer launch/context control.

  • Rewritten request layer (#97) — the requests logic was refactored cleaner and faster, closing issue #97. Combined with the wider cleanup, expect measurable correctness and performance gains in any fetch path that flows through this layer.

  • Pyright-clean codebase — the entire codebase was refactored to pass Pyright, which upstream says eliminates long-standing autocompletion glitches and IDE quirks. Worth adopting if you lean on type hints and intellisense when integrating Scrapling.

  • No breaking changes in this release.

A new update with many important changes

🚀 New Stuff and quality of life changes

  • Reworked solve_cloudflare argument in StealthyFetcher to make it able to solve all kinds of custom implementations of Turnstile.
  • Refactored the entire codebase to be acceptable by Pyright, so expect a flawless IDE experience now with all software and many bugs solved.
  • Refactored the requests logic to be cleaner and faster (Also solves #97 )
  • Added a new option user_data_dir to all browser-based session classes to allow the user to reuse the browser session data (cookies/storage/etc...) from previous sessions. Leaving it will cause Playwright to use a random directory on each run, as was happening before.
  • Added a new customization option additional_args to Dynamic fetcher and its session class to enable the user to pass extra arguments to Playwright's context, as we had with StealthyFetcher before.
  • The route logic for collecting the last navigation response for all browsers has been improved, which allows the raw responses to be passed to the parser before being processed by the browsers as before. This will be very helpful with text/JSON responses.

🐛 Bug Fixes

  • The rework of the route logic solved an issue with retrieving the content of unstable websites on some Windows devices.
  • All the refactors that happened in this version solved a lot of bugs along the way that were hard to spot before, and weird autocompletion issues with some IDEs.
  • Many fixes to the documentation website
