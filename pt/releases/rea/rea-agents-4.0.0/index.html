rea reagente-4.0.0

4.0.0 (05/10/2026)

⚠ MUDANÇAS ÚLTIMAS

  • Os metadados de comparação gerenciada adicionam correspondência de assinatura exata e sua contagem, e name_matching agora relata substituto de assinatura exata.
  • configuração: a configuração sem escopo atualiza apenas os registros existentes de propriedade do REA. Use --all-detected para configurar cada client detectado. Configuração JSON contém um resumo médico compacto; use o rea doctor para um diagnóstico completo. O cancelamento e os testes bem-sucedidos agora são encerrados com êxito.
  • Remova reprodução controlada, caracterização de nó, máquina de reprodução finita, planejamento de tempo de execução gerenciado e ferramentas redundantes de rastreamento de string. Retire a reprodução de processos, correções, cenários reativos, pontos de verificação personalizados e reprodução ativa do navegador e entradas de escopo de origem.
  • ferramentas: Configuração de permissão e comandos de política removidos, campos de aprovação, entradas de escopo do sistema de arquivos e opções de confirmação fixas. A captura de processos herda o ambiente host e aceita nomes de comandos; os chamadores devem atualizar os esquemas da ferramenta e migrar os campos removidos.

rea rea-agents-4.0.0

4.0.0 (2026-10-05)

⚠ BREAKING CHANGES

  • Managed comparison metadata adds exact-signature matching and its count, and name_matching now reports exact-signature-fallback.
  • setup: unscoped setup refreshes only existing REA-owned registrations. Use --all-detected to configure every detected client. Setup JSON contains a compact doctor summary; use rea doctor for full diagnostics. Cancellation and successful dry runs now exit successfully.
  • Remove controlled replay, Node characterization, finite replay-machine, managed runtime planning, and redundant string-tracing tools. Retire process replay, shims, reactive scenarios, custom checkpoints, and active browser replay and origin-scope inputs.
  • tools: Removed permission configuration and policy commands, approval fields, filesystem scope inputs, and fixed confirmation options. Process capture inherits the host environment and accepts command names; callers must refresh tool schemas and migrate removed fields.
