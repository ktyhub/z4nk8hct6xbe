rea reagente-6.3.0

6.3.0 (09/10/2026)

⚠ MUDANÇAS ÚLTIMAS

  • capturas: Capturas históricas sem contabilidade atual do produtor ou identidade de transação e diferenças da web sem acessibilidade ou dimensões de armazenamento são rejeitadas. Preservar capturas originais e recapturar com o produtor atual; atualizar os consumidores de comparação para incluir todas as dimensões, em vez de sintetizar observações ausentes. Consulte o guia de captura de processo e contrato de cenário do navegador. (3283a45)
  • navegador: Os caminhos de forma JSON agora contêm propriedades digitadas e segmentos de elementos de matriz. WebMCP input_schema_shape é substituído por input_schema e input_schema_sha256, mantendo exemplos e padrões declarados.
  • processo: As entradas de omissão do resumo do sistema de arquivos agora exigem system_code; as omissões de orçamento e arquivos alterados usam nulo, e as omissões de arquivos indisponíveis preservam o código de erro do sistema operacional.
  • contratos: os resultados da análise do fornecedor devem fornecer explicitamente metadados previamente corrigidos com padrões; facetas anuláveis ​​não suportadas devem ser relatadas como nulas.
  • javascript: Os fatos do gráfico semântico agora armazenam IDs e locais de contexto de evidências. Os resultados do gráfico e do rastreio semântico requerem uma tabela de evidencia_contexts sequencial.
  • contratos: URLs do mapa de origem agora residem em observações de destino selecionadas por declarado_url_sha256, e a identidade da habilidade do médico não emite mais instalado_catalog_digest. Use a junção de observação documentada e identidade.skill.state.
  • javascript: remova a estatística truncated_scopes nunca incrementada dos resultados e esquemas da análise do aplicativo JavaScript.
  • nativo: Os tokens de atributo Objective-C agora contêm apenas nome e valor. Propriedades relatam atomicidade anulável e fatos somente leitura; sinalizadores de classe, contagens de ivar e sinalizadores de requisitos de método são anuláveis ​​quando não observados.

rea rea-agents-6.3.0

6.3.0 (2026-10-09)

⚠ BREAKING CHANGES

  • captures: Historical captures without current producer accounting or transaction identity, and web diffs missing accessibility or storage dimensions, are rejected. Preserve original captures and recapture with the current producer; update comparison consumers to include every dimension rather than synthesizing missing observations. See the process capture guide and browser scenario contract. (3283a45)
  • browser: JSON shape paths now contain typed property and array-element segments. WebMCP input_schema_shape is replaced by input_schema and input_schema_sha256, retaining declared examples and defaults.
  • process: Filesystem digest omission entries now require system_code; budget and changed-file omissions use null, and unavailable-file omissions preserve the operating-system error code.
  • contracts: Provider analysis outputs must explicitly supply metadata previously repaired with defaults; unsupported nullable facets must be reported as null.
  • javascript: Semantic graph facts now store evidence context IDs and locations. Graph and semantic trace results require an inline evidence_contexts table.
  • contracts: source-map URLs now live in target observations selected by declared_url_sha256, and doctor skill identity no longer emits installed_catalog_digest. Use the documented observation join and identity.skill.state instead.
  • javascript: remove the never-incremented truncated_scopes statistic from JavaScript application analysis results and schemas.
  • native: Objective-C attribute tokens now contain only name and value. Properties report nullable atomicity and readonly facts; class flags, ivar counts, and method requirement flags are nullable when unobserved.
