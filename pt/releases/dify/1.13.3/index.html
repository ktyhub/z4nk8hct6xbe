#difícil 1.13.3

🚀 O que há de novo no v1.13.3?

Nosso lançamento de patch mais recente, v1.13.3, concentra-se na estabilidade e correção na execução do fluxo de trabalho, streaming e recuperação de conhecimento. Aqui está uma rápida olhada nas atualizações mais importantes:

🎬 Novos recursos

  • Configuração do fluxo de trabalho: Adicionado suporte de referência de variável para parâmetros de modelo em nós LLM, Classificador de perguntas e Extrator de variáveis por @scdeng em #33082.

🛠️ Correções de bugs

  • Confiabilidade de streaming: Corrigidos problemas de reprodução e simultaneidade do StreamsBroadcastChannel para manter estável a entrega de eventos de front-end/backend por @QuantumGhost em #34030 e #34061.
  • Comportamento do Editor de Fluxo de Trabalho: Corrigidos nós colados que retinham metadados de Loop/Iteração e impediam que nós HumanInput fossem colados em contêineres inválidos por @majiayu000 e @hjlarry em #29983 e #34077.
  • Execução em tempo de execução: Lógica de transformação de mensagem de prompt restaurada e manipulação max_retries=0 corrigida para execução de solicitação HTTP orientada por executor por @QuantumGhost, @fatelei e @kurokobo em #33666, #33619 e #33688.
  • Recuperação de conhecimento: metadados de citações preservados em respostas da web, falhas corrigidas quando os metadados do ícone do conjunto de dados estão faltando, filtragem de consulta de contagem de ocorrências corrigida e visualizações restauradas de blocos de documentos indexados por @Theysua, @copilot-swe-agent e @fatelei em #33778, #33907, #33757 e #33942.

🔧 Nos bastidores

  • Estabilidade de patch: esta versão prioriza correções direcionadas para comportamento de tempo de execução de fluxo de trabalho, streaming em tempo real e usabilidade da base de conhecimento para equipes que atualizam do v1.13.2.

Guia de atualização

[!IMPORTANTE] A imagem Sandbox usada pelo Dify v1.13.3 espera os seguintes caminhos Python e Node.js. Se você atualizou de uma implantação Docker Compose mais antiga e já possui docker/volumes/sandbox/conf/config.yaml, atualize-o na máquina host:

python_path: /opt/python/bin/python3
nodejs_path: /usr/local/bin/node

Não edite o arquivo dentro do contêiner sandbox. O diretório docker/volumes/sandbox/conf é montado no contêiner como /conf, portanto, as alterações no host persistem após a reinicialização do contêiner.

Docker Compor implantações

  1. Faça backup de seu arquivo YAML composto por docker personalizado (opcional)

    cd docker
cp docker-compose.yaml docker-compose.yaml.$(date +%s).bak

  2. Obtenha o código mais recente da ramificação principal

    git checkout main
git pull origin main

  3. Pare o serviço. Por favor execute no diretório docker

    docker compose down

  4. Faça backup dos dados

    tar -cvf volumes-$(date +%s).tgz volumes

  5. Serviços de atualização

    docker compose up -d

Implantações de código-fonte

  1. Pare o servidor API, o Worker e o servidor front-end da Web.

  2. Obtenha o código mais recente do branch de lançamento:

    git checkout 1.13.3

  3. Atualize as dependências do Python:

    cd api
uv sync

  4. Em seguida, vamos executar o script de migração:

    uv run flask db upgrade

  5. Por fim, execute o servidor API, Worker e servidor Web frontend novamente.

🚀 What's New in v1.13.3?

Our latest patch release, v1.13.3, focuses on stability and correctness across workflow execution, streaming, and knowledge retrieval. Here's a quick look at the most important updates:

🎬 New Features

  • Workflow Configuration: Added variable-reference support for model parameters in LLM, Question Classifier, and Variable Extractor nodes by @scdeng in #33082.

🛠️ Bug Fixes

  • Streaming Reliability: Fixed StreamsBroadcastChannel replay and concurrency issues to keep frontend/backend event delivery stable by @QuantumGhost in #34030 and #34061.
  • Workflow Editor Behavior: Fixed pasted nodes retaining Loop/Iteration metadata and prevented HumanInput nodes from being pasted into invalid containers by @majiayu000 and @hjlarry in #29983 and #34077.
  • Runtime Execution: Restored prompt message transformation logic and corrected max_retries=0 handling for executor-driven HTTP Request execution by @QuantumGhost, @fatelei, and @kurokobo in #33666, #33619, and #33688.
  • Knowledge Retrieval: Preserved citation metadata in web responses, fixed crashes when dataset icon metadata is missing, corrected hit-count query filtering, and restored indexed document chunk previews by @Theysua, @copilot-swe-agent, and @fatelei in #33778, #33907, #33757, and #33942.

🔧 Under the Hood

  • Patch Stability: This release prioritizes targeted fixes for workflow runtime behavior, real-time streaming, and knowledge base usability for teams upgrading from v1.13.2.

Upgrade Guide

[!IMPORTANT] The Sandbox image used by Dify v1.13.3 expects the following Python and Node.js paths. If you upgraded from an older Docker Compose deployment and already have docker/volumes/sandbox/conf/config.yaml, update it on the host machine:

python_path: /opt/python/bin/python3
nodejs_path: /usr/local/bin/node

Do not edit the file inside the sandbox container. The directory docker/volumes/sandbox/conf is mounted into the container as /conf, so host changes persist after container restarts.

Docker Compose Deployments

  1. Back up your customized docker-compose YAML file (optional)

    cd docker
cp docker-compose.yaml docker-compose.yaml.$(date +%s).bak

  2. Get the latest code from the main branch

    git checkout main
git pull origin main

  3. Stop the service. Please execute in the docker directory

    docker compose down

  4. Back up data

    tar -cvf volumes-$(date +%s).tgz volumes

  5. Upgrade services

    docker compose up -d

Source Code Deployments

  1. Stop the API server, Worker, and Web frontend Server.

  2. Get the latest code from the release branch:

    git checkout 1.13.3

  3. Update Python dependencies:

    cd api
uv sync

  4. Then, let's run the migration script:

    uv run flask db upgrade

  5. Finally, run the API server, Worker, and Web frontend Server again.
