#difícil 1.13.1

🚀 Principais mudanças funcionais

Plataforma de dados e operações de conjunto de dados

  • Adicionado Hologres como uma opção de back-end compatível para recuperação de vetor e pesquisa de texto completo.
  • Adicionados endpoints de serviço API para downloads de documentos de conjuntos de dados:
    • Download ZIP em lote para documentos selecionados.
    • Download de URL assinado para arquivos originais de documento único.

Melhorias no fluxo de trabalho e na experiência de bate-papo

  • Alteração significativa: O conteúdo do e-mail HITL agora usa renderização de redução antes da entrega. Os modelos de e-mail existentes que dependiam do comportamento bruto/simples podem ser renderizados de maneira diferente após a atualização.
  • As variáveis ​​de rascunho agora têm escopo do usuário em vez do escopo do aplicativo. As variáveis ​​históricas de rascunho não estarão disponíveis após a atualização.
  • Adicionado suporte ao menu de contexto de borda na tela do fluxo de trabalho, incluindo exclusão direta de borda.
  • Conexões existentes preservadas ao alterar os tipos de nós na edição do fluxo de trabalho.
  • Adicionado comportamento de envio de chave configurável (Enter vs Shift+Enter) para entrada de chat incorporada.
  • Adicionadas cargas de arquivo em respostas de fluxo de final de mensagem.
  • Removido o comportamento codificado específico do GPT-4 da lógica de seleção de modelo padrão.
  • Adicionado um novo comando export-app-messages CLI para exportar mensagens do aplicativo e feedback relacionado para JSONL.GZ (armazenamento local ou em nuvem).

🔐 Atualizações de segurança

  • Preveniu riscos de injeção de SQL em caminhos de consulta de armazenamento de vetores, mudando para SQL parametrizado em implementações afetadas.
  • Entrega de e-mail HITL reforçada:
    • Higienizar assunto e conteúdo corporal.
    • Retire CR/LF dos assuntos para evitar vetores de injeção de cabeçalho SMTP.
  • Verificações de propriedade impostas para APIs de exclusão de conversa.
  • Foram eliminadas credenciais de provedor obsoletas durante a desinstalação do plug-in para reduzir o risco de credencial residual.
  • Melhor tratamento de erros corporativos API e comportamento de aplicação de licença para estados de licença inválidos/expirados.

🏗️ Atualizações de configuração, arquitetura e implantação

Implantação e operações

  • Adicionada uma fila Celery dedicada: dataset_summary para tarefas de geração de resumo pesadas em LLM.
    • Certifique-se de que os trabalhadores se inscrevam nesta fila para evitar pendências de trabalhos de resumo.
  • Adicionadas métricas de telemetria para tarefas de limpeza de retenção (mensagens/execuções de fluxo de trabalho), além de comportamento de liberação para trabalhos de comando de curta duração.

Mudanças de configuração

  • Adicionado REDIS_MAX_CONNECTIONS.
  • Configurações obsoletas do barramento de eventos PUBSUB_* em favor das configurações EVENT_BUS_*.

🛠 Outras mudanças dignas de nota

  • Corrigido workflow_runs.started_at sendo substituído ao retomar.
  • Correção de falhas silenciosas na edição em lote de metadados causadas por casos extremos de transação dividida.
  • Corrigidos problemas de extração de filtro de metadados na recuperação de conhecimento (condições {{...}}).
  • Visibilidade de citação restaurada em aplicativos de bate-papo avançados.
  • Corrigido comportamento de redefinição de variáveis ​​de conversação após nós HITL.
  • Corrigida uma falha de página no fluxo de configuração do nó de recuperação de conhecimento.
  • Corrigido assistente de bate-papo bloqueando o comportamento do modo de resposta.
  • Adicionado manuseio doc_type nos atributos do vetor Weaviate para melhor compatibilidade.
  • Dependências OpenTelemetry atualizadas para resolver erros de desconexão de contexto.

Docker Compor implantações

  1. Faça backup de seu arquivo YAML composto por docker personalizado (opcional)

    cd docker
cp docker-compose.yaml docker-compose.yaml.$(date +%s).bak

  2. Obtenha o código mais recente da ramificação principal

    git checkout main
git pull origin main

  3. Pare o serviço. Por favor execute no diretório docker

    docker compose down

  4. Faça backup dos dados

    tar -cvf volumes-$(date +%s).tgz volumes

  5. Serviços de atualização

    docker compose up -d

dify 1.13.1

🚀 Major Functional Changes

Data platform and dataset operations

  • Added Hologres as a supported backend option for both vector retrieval and full-text search.
  • Added Service API endpoints for dataset document downloads:
    • Batch ZIP download for selected documents.
    • Signed URL download for single-document original files.

Workflow and chat experience improvements

  • Breaking change: HITL email content now uses markdown rendering before delivery. Existing email templates that relied on raw/plain behavior may render differently after upgrade.
  • Draft variables are now user-scoped instead of app-scoped. Historical draft variables will not be available after upgrading.
  • Added edge context menu support in workflow canvas, including direct edge deletion.
  • Preserved existing connections when changing node types in workflow editing.
  • Added configurable send-key behavior (Enter vs Shift+Enter) for embedded chat input.
  • Added file payloads in message-end stream responses.
  • Removed GPT-4-specific hardcoded behavior from default model selection logic.
  • Added a new export-app-messages CLI command to export application messages and related feedback to JSONL.GZ (local or cloud storage).

🔐 Security Updates

  • Prevented SQL injection risks in vector-store query paths by switching to parameterized SQL in affected implementations.
  • Hardened HITL email delivery:
    • Sanitize subject and body content.
    • Strip CR/LF from subjects to prevent SMTP header-injection vectors.
  • Enforced ownership checks for conversation deletion APIs.
  • Cleared stale provider credentials during plugin uninstall to reduce residual credential risk.
  • Improved enterprise API error handling and license-enforcement behavior for invalid/expired license states.

🏗️ Configuration, Architecture, and Deployment Updates

Deployment and operations

  • Added a dedicated Celery queue: dataset_summary for LLM-heavy summary generation tasks.
    • Ensure workers subscribe to this queue to avoid summary-job backlog.
  • Added telemetry metrics for retention cleanup tasks (messages/workflow runs), plus flush behavior for short-lived command jobs.

Configuration changes

  • Added REDIS_MAX_CONNECTIONS.
  • Deprecated PUBSUB_* event-bus settings in favor of EVENT_BUS_* settings.

🛠 Other Noteworthy Changes

  • Fixed workflow_runs.started_at being overwritten on resume.
  • Fixed metadata batch-edit silent failures caused by split-transaction edge cases.
  • Fixed metadata filter extraction issues in knowledge retrieval ({{...}} conditions).
  • Restored citation visibility in advanced chat applications.
  • Fixed conversation variable reset behavior after HITL nodes.
  • Fixed a page crash in knowledge-retrieval node configuration flow.
  • Fixed chat assistant blocking response-mode behavior.
  • Added doc_type handling in Weaviate vector attributes for better compatibility.
  • Upgraded OpenTelemetry dependencies to resolve context-detach errors.

  1. Back up your customized docker-compose YAML file (optional)

    cd docker
cp docker-compose.yaml docker-compose.yaml.$(date +%s).bak

  2. Get the latest code from the main branch

    git checkout main
git pull origin main

  3. Stop the service. Please execute in the docker directory

    docker compose down

  4. Back up data

    tar -cvf volumes-$(date +%s).tgz volumes

  5. Upgrade services

    docker compose up -d
