Colaboração

<img width="2632" height="1190" alt="img_v3_02117_67a67218-1ae5-4d68-a45b-3ada592f87fg" src="https://github.com/user-attachments/assets/1d4a3660-8a6a-4b29-9766-4d5b5fd9a51b" />

A colaboração permite que os membros do espaço de trabalho editem o mesmo fluxo de trabalho juntos, com atualizações de gráficos sincronizadas, presença on-line e visibilidade compartilhada sobre quem está trabalhando e onde.

Em implantações auto-hospedadas, a colaboração fica desativada por padrão. Habilite-o configurando:

ENABLE_COLLABORATION_MODE = true
SERVER_WORKER_CLASS = geventwebsocket.gunicorn.workers.GeventWebSocketWorker
NEXT_PUBLIC_SOCKET_URL = your deployment’s WebSocket URL (e.g., wss://dify.example.com)

Para mais detalhes, consulte Documentação completa

Humano no circuito (HITL)

  • Serviço API para HITL — suporte programático para fluxos humanos no circuito juntamente com o comportamento existente do console.

MCP e plug-ins

  • Metadados da ferramenta MCP — atualize após as atualizações para que a IU permaneça sincronizada.
  • URL do servidor MCP — corrija o /v1 duplo que poderia quebrar o OAuth e a autorização (404).
  • Descoberta MCP OAuth — manipule JSON malformado com segurança.
  • Publicação de esquema MCP — mapeie os tipos checkbox e json_object corretamente.
  • Plugins — persistência da estratégia de atualização automática, instalador local e comportamento de entrada de arquivo, escopo do locatário para pesquisa interna do usuário final do API.

Mercado e OAuth

  • Marketplace e OAuth — correções direcionadas para fluxos de mercado e login OAuth (incluindo casos extremos, como e-mail nulo no GitHub OAuth).

Kit UI e plataforma front-end

  • @langgenius/dify-ui — primitivas compartilhadas (por exemplo PreviewCard, Meter), tokens de design e ampla migração do web/base/ui ad-hoc para o pacote.
  • Acessibilidade — seletores de data e hora, seletor de estratégia de atualização automática, barras de rolagem em seletores de plugins e modelos e ajustes relacionados.
  • Goto Anything — itens recentes, comando /go, subseções mais profundas do aplicativo; correção para Cmd+K (removida importação dinâmica problemática).
  • Editor de prompts — filtragem de variáveis acionada por barra; teclado para cima/para baixo em listas de variáveis.
  • Perguntas de acompanhamento — configurações aprimoradas e limites de token para perguntas sugeridas.
  • Modais — ApiKey, configuração do provedor e outros refatorados em direção a um padrão Dialog compartilhado com testes.

Observabilidade e análise

  • Langfuse — relatório opcional de tempo até o primeiro token (TTFT).
  • Explorar — rastreamento de impressões de banner; rastreamento de eventos de visualização de aplicativos em cartões.

Faturamento e cotas

  • Integração do Quota v3 na pilha de produtos.
  • IU de faturamento — Apresentação de uso baseada em medidor; limpeza mais resiliente quando os APIs de faturamento falham.
  • Carregador de arquivos — comportamento baseado em cobrança e atualizações de cópia.

Dados, RAG e conhecimento

  • Índice de resumo e Weaviate — correções de compatibilidade ao usar o índice de resumo com o Weaviate.
  • Projeção vetorial — incluir is_summary e original_chunk_id na projeção padrão quando relevante.
  • Conjuntos de dados externos e vinculados — verificações mais fortes do locatário sobre o conhecimento APIs.

Infraestrutura e operações

  • Docker Compose — verificações de integridade para api, worker e worker_beat; atualizações de exemplo de modelo e ambiente (por exemplo, estilo de endereço S3).
  • Celery — simultaneidade do trabalhador padrão aumentada para 4; correção de fila ausente.
  • PostgreSQL — padrão mais alto máximo de conexões (200) para o caminho do banco de dados do aplicativo atualizado.
  • Redis — prefixo de chave configurável; repetir lógica para operações Redis.
  • TiDB — suporte de endpoint e migração de ligação de autenticação relacionada (endpoint Qdrant em ligações de autenticação TiDB).
  • Markdown — variável de ambiente opcional ALLOW_INLINE_STYLES para permitir CSS embutido em Markdown renderizado quando necessário.

Segurança

  • Fluxo de alteração de e-mail — tratamento de token vinculado à fase mais rigoroso (GHSA-4q3w-q5mc-45rq).
  • Reforço IDOR — validação de locatário na vinculação de fonte de dados; conjunto de dados e verificações de propriedade API onde foram encontradas lacunas.

Desempenho

  • Desempenho otimizado de inicialização do gráfico.

API e componentes internos da plataforma

  • Graphon — atualização para Graphon 0.2.2 independente (substituindo nomenclatura e empacotamento dify_graph na árvore).
  • OpenAPI — script para gerar OpenAPI v2 JSON e ponteiro de documentação.
  • Descontinuação — alguns consoles legados APIs foram marcados como obsoletos em favor de padrões mais recentes.
  • Grande migração SQLAlchemy 2.0 select(), Pydantic BaseModel para muitas respostas de console e serviço e testes baseados em testcontainers para estabilidade.

🚀 What's New in v1.14.0?

Collaboration

<img width="2632" height="1190" alt="img_v3_02117_67a67218-1ae5-4d68-a45b-3ada592f87fg" src="https://github.com/user-attachments/assets/1d4a3660-8a6a-4b29-9766-4d5b5fd9a51b" />

Collaboration allows workspace members to edit the same workflow together, with synced graph updates, online presence, and shared visibility into who is working where.

On self-hosted deployments, collaboration is turned off by default. Enable it by setting:

ENABLE_COLLABORATION_MODE = true
SERVER_WORKER_CLASS = geventwebsocket.gunicorn.workers.GeventWebSocketWorker
NEXT_PUBLIC_SOCKET_URL = your deployment’s WebSocket URL (e.g., wss://dify.example.com)

For more details, see Full Documentation

Human-in-the-loop (HITL)

  • Service API for HITL — programmatic support for human-in-the-loop flows alongside existing console behavior.

MCP and plugins

  • MCP tool metadata — refresh after updates so the UI stays in sync.
  • MCP server URL — fix double /v1 that could break OAuth and authorization (404).
  • MCP OAuth discovery — handle malformed JSON safely.
  • MCP schema publishing — map checkbox and json_object types correctly.
  • Plugins — auto-upgrade strategy persistence, local installer and file-input behavior, tenant scoping for inner API end-user lookup.

Marketplace and OAuth

  • Marketplace and OAuth — targeted fixes for marketplace flows and OAuth sign-in (including edge cases such as null email on GitHub OAuth).

UI kit and front-end platform

  • @langgenius/dify-ui — shared primitives (for example PreviewCard, Meter), design tokens, and broad migration from ad-hoc web/base/ui toward the package.
  • Accessibility — date and time pickers, auto-update strategy picker, scrollbars in plugin and model selectors, and related polish.
  • Goto Anything — recent items, /go command, deeper app sub-sections; fix for Cmd+K (removed problematic dynamic import).
  • Prompt editor — slash-triggered variable filtering; keyboard up/down in variable lists.
  • Follow-up questions — improved settings and token limits for suggested questions.
  • Modals — ApiKey, provider config, and others refactored toward a shared Dialog pattern with tests.

Observability and analytics

  • Langfuse — optional time-to-first-token (TTFT) reporting.
  • Explore — banner impression tracking; app preview event tracking on cards.

Billing and quotas

  • Quota v3 integration in the product stack.
  • Billing UI — Meter-based usage presentation; more resilient cleanup when billing APIs fail.
  • File uploader — billing-aware behavior and copy updates.

Data, RAG, and knowledge

  • Summary index and Weaviate — compatibility fixes when using the summary index with Weaviate.
  • Vector projection — include is_summary and original_chunk_id in default projection where relevant.
  • External and bound datasets — stronger tenant checks on knowledge APIs.

Infrastructure and operations

  • Docker Compose — healthchecks for api, worker, and worker_beat; template and env example updates (for example S3 address style).
  • Celery — default worker concurrency raised to 4; missing queue fix.
  • PostgreSQL — higher default max connections (200) for the updated app DB path.
  • Redis — configurable key prefix; retry logic for Redis operations.
  • TiDB — endpoint support and related auth binding migration (Qdrant endpoint on TiDB auth bindings).
  • Markdown — optional ALLOW_INLINE_STYLES environment variable to allow inline CSS in rendered Markdown when needed.

Security

  • Change-email flow — stricter phase-bound token handling (GHSA-4q3w-q5mc-45rq).
  • IDOR hardening — tenant validation on data-source binding; dataset and API ownership checks where gaps were found.

Performance

  • Optimized performance of graph initialization.

API and platform internals

  • Graphon — upgrade to standalone Graphon 0.2.2 (replacing in-tree dify_graph naming and packaging).
  • OpenAPI — script to generate OpenAPI v2 JSON and documentation pointer.
  • Deprecation — some legacy console APIs marked deprecated in favor of newer patterns.
  • Large SQLAlchemy 2.0 select() migration, Pydantic BaseModel for many console and service responses, and testcontainers-based tests for stability.
