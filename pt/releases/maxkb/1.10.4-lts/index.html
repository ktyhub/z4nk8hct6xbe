MaxKB v1.10.4-lts

Highlights

  • Priority security fix — Closes a reverse-shell vulnerability in the function library (CVE-2025-3238, #2830). Upgrade promptly, especially if function-library functionality is externally accessible, and review permissions for creating and invoking functions.
  • More expressive workflow routing — Advanced-arrangement decision nodes support drag-to-reorder IF/ELSE IF branches (#2810) and explicit true/false conditions (#2806). This enables prioritized exception handling and simple boolean gates; verify routing when reordering existing branches because condition order can change the selected path.
  • Fewer silent application-runtime failures — Quick questions now retain interface parameters (#2808), answers render after form submission (#2824), and model parameters refresh after switching models (#2826). Re-test parameter-driven flows and model-switching scenarios to catch configurations that previously produced missing inputs, empty responses, or stale settings.
  • Improved Q&A and composition reliability — Fixes lost conversation history (#2843), incorrect required-field validation for multi-select inputs (#2839), and nested sub-applications appearing unavailable (#2819). After upgrading, verify session persistence and composed-app entry points, as these issues could prevent users from resuming conversations or reaching downstream applications.
  • Data and integration corrections — PDF imports tolerate segment titles longer than 256 characters (#2803), while dialogue-log exports now include the user field for attribution (#2817). X-Pack also corrects create-knowledge-base API documentation, makes API debugging respect HTTPS configuration, and prioritizes corporate email during passwordless WeChat for Enterprise login—confirm the resulting identity mapping.
  • Compatibility — No breaking changes announced.

Enhancements

  • Application: In the judgement node of advanced arrangement, support adjusting the order of IF and ELSE IF branches by dragging and dropping; @wangdan-fit2cloud published in https://github.com/1Panel-dev/MaxKB/pull/2810
  • Application: In the judgement node of advanced arrangement, the value of the judgment condition can be set to true or false; by @shaohuzhang1 in https://github.com/1Panel-dev/MaxKB/pull/2806
  • Application: In the basic information node of advanced arrangement, optimize the display style problem when the default value of the interface parameter is long;
  • Login authentication (X-Pack): Optimize the priority of obtaining the user's corporate email when logging in without password in WeChat for Enterprise.

Bug Fixes

  • Security: Solve the vulnerability of reverse shell in the function library module (CVE-2025-3238); by @shaohuzhang1 in https://github.com/1Panel-dev/MaxKB/pull/2830
  • Knowledge base: Fix the problem of error when the segment title exceeds 256 characters in the imported PDF document; by @liuruibin in https://github.com/1Panel-dev/MaxKB/pull/2803
  • Application: Fix the problem that the interface parameters are not carried when the user asks questions using quick questions; @shaohuzhang1 in https://github.com/1Panel-dev/MaxKB/pull/2808
  • Application: Fix the problem that the answer content is not output after the user submits the form collection when asking questions; by @shaohuzhang1 in https://github.com/1Panel-dev/MaxKB/pull/2824
  • Application: Fix the problem that the model parameters are not updated after switching the selected AI model; by @shaohuzhang1 in https://github.com/1Panel-dev/MaxKB/pull/2826
  • Application: Fixed the problem that the application name was not updated after the application name was modified and published on the workflow orchestration page; @wangdan-fit2cloud in https://github.com/1Panel-dev/MaxKB/pull/2825
  • Application: Fixed the problem that the basic model was not listed after selecting the large language model when adding a model in the AI ​​dialogue node; by @liuruibin in https://github.com/1Panel-dev/MaxKB/pull/2804
  • Application: Fixed the problem that the user field was not carried when exporting the dialogue log; by @wxg0103 in https://github.com/1Panel-dev/MaxKB/pull/2817
  • Application: Fixed the problem that the nested sub-applications in the application would be displayed as unavailable in some cases; @wxg0103 in https://github.com/1Panel-dev/MaxKB/pull/2819
  • Q&A page: fix the problem that the avatar is not displayed by default on the Q&A page; by @wangdan-fit2cloud in https://github.com/1Panel-dev/MaxKB/pull/2832
  • Q&A page: fix the problem that the user's historical conversation record is lost; by @shaohuzhang1 in https://github.com/1Panel-dev/MaxKB/pull/2843
  • Q&A page: fix the problem that the user input parameter is set as a required field when the multi-select box component is not verified when the user asks a question; by @shaohuzhang1 in https://github.com/1Panel-dev/MaxKB/pull/2839
  • Model settings: fix the problem that the error is reported when adding a local rearrangement model; by @shaohuzhang1 in https://github.com/1Panel-dev/MaxKB/pull/2805
  • Team members: fix the problem that the icon in the knowledge base list is not displayed according to the knowledge base type; by @wangdan-fit2cloud in https://github.com/1Panel-dev/MaxKB/pull/2806
  • API Documentation (X-Pack): Fix the problem that the parameter description of the creation knowledge base interface in the API documentation is incorrect;
  • API Documentation (X-Pack): Fix the problem that the access address is configured as https, but the interface API is still http during debugging.
