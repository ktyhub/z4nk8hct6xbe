#Max KB v2.10.4-lts

Correções de vulnerabilidade de segurança

  • Vulnerabilidade: Corrigida uma falha de permissão de arquivos do sistema que permitia acesso anônimo aos recursos;
  • Vulnerabilidade: Corrigida uma vulnerabilidade IDOR nos logs de bate-papo do administrador que permitia ignorar a autenticação do caminho do aplicativo para ler registros de bate-papo entre aplicativos;
  • Vulnerabilidade: Adicionado mecanismo independente de verificação de autorização para agendamento de agentes e ferramentas de fluxo de trabalho;
  • Vulnerabilidade: Corrigida a falta de validação de host quando UpdateStoreTool busca URLs de lojas de aplicativos externas;
  • Vulnerabilidade: Corrigido o problema de escalonamento horizontal de privilégios que permitia aos usuários acessar e modificar documentos e segmentos não autorizados em bases de conhecimento;
  • Vulnerabilidade: Corrigidas chaves expiradas do agente API sendo utilizáveis ​​no endpoint /chat/api/mcp;
  • Vulnerabilidade: Correção do escalonamento horizontal de privilégios causado por lógica de autorização da ferramenta MCP defeituosa;
  • Vulnerabilidade: Corrigida exposição de IDs de aplicações na página de classificação da página inicial, o que poderia levar a chamadas não autorizadas para nós de aplicações de outros usuários;
  • Vulnerabilidade: Corrigido o risco de escalonamento de privilégios entre espaços de trabalho ao visualizar e editar formulários de parâmetros de modelo;
  • Vulnerabilidade: Corrigida a vulnerabilidade de injeção imediata para mitigar o risco de execução de comandos do agente;
  • Vulnerabilidade: validação de IP interna aprimorada para importação de documentos da Web e sincronização de rastreadores para remediar riscos de SSRF.

Correções de bugs

  • Agente: Corrigido o problema em que modelos de visão recém-adicionados para nós de compreensão de imagem em agentes avançados não eram exibidos na lista de modelos em tempo real (#6402);
  • Agente: Corrigidas mensagens de prompt incorretas durante conversas após a exclusão do LLM vinculado a agentes básicos;
  • Agente: Corrigidas falhas quando agentes chamam modelos compartilhados com erro "Modelo não existe";
  • Base de Conhecimento: Corrigida classificação incorreta de texto segmentado como conteúdo de tabela quando não há linha em branco entre tabelas e conteúdo subsequente em arquivos Word (#6396);
  • Base de conhecimento: Corrigida contaminação entre documentos de dados de posição de segmento ao arrastar e reordenar segmentos de documento (#6373);
  • Página inicial: Corrigido o problema em que agentes sem permissões de usuário podiam ser pesquisados ​​por nome na página de detalhes da classificação;
  • Trigger: Corrigida a exibição de tarefas duplicadas nos detalhes das tarefas das listas de gatilhos agendadas;
  • Trigger: Corrigida a falta de passagem de valor padrão para parâmetros de entrada do usuário de agentes avançados em cenários de trigger, resultando em valores de parâmetros vazios (#6320);
  • Trigger: Corrigidos erros de passagem de parâmetros quando as entradas do usuário do agente incluem parâmetros do tipo alternância nos gatilhos;
  • Gerenciamento de usuários: Corrigido o problema de a listagem de usuários API retornar apenas os primeiros 200 usuários e não poder buscar todos os registros de usuários (#6375).

MaxKB v2.10.4-lts

Highlights

  • Broad authorization hardening — Fixes IDOR, cross-knowledge-base document access, MCP authorization bypasses, and cross-workspace model-form escalation. Upgrade promptly if MaxKB is internet-accessible or hosts multiple tenants.
  • Agent and workflow execution controls — Tool scheduling now verifies authorization independently, and prompt injection risks affecting agent command execution are mitigated. Review tool permissions and untrusted-input handling as part of adoption.
  • SSRF and credential fixes — External app-store fetches validate hosts, crawlers strengthen internal-IP checks, and expired agent API keys can no longer access /chat/api/mcp. Verify any workflows that previously relied on these paths.
  • Agent and trigger reliability — Shared-model calls now work, advanced-agent vision models appear immediately (#6402), and trigger user inputs correctly pass defaults (#6320) and toggle parameters. Recheck trigger configurations rather than compensating in prompts.
  • Knowledge-base ingestion and ordering — Word table segmentation no longer absorbs following content without a blank line (#6396), and drag-and-drop reordering no longer cross-contaminates segment positions (#6373).
  • User-management scale fix — The user listing API now returns more than the previous 200-record ceiling (#6375), allowing management tools to retrieve complete user inventories.
  • No breaking changes are documented in this release.

Security Vulnerability Fixes

  • Vulnerability: Fixed a system file permission flaw that allowed anonymous access to resources;
  • Vulnerability: Fixed an IDOR vulnerability in admin chat logs which allowed bypassing application path authentication to read cross-application chat records;
  • Vulnerability: Added independent authorization verification mechanism for agent and workflow tool scheduling;
  • Vulnerability: Fixed missing host validation when UpdateStoreTool fetches external app store URLs;
  • Vulnerability: Fixed the horizontal privilege escalation issue that enabled users to access and modify unauthorized documents and segments across knowledge bases;
  • Vulnerability: Fixed expired agent API keys being usable at the /chat/api/mcp endpoint;
  • Vulnerability: Fixed horizontal privilege escalation caused by defective MCP tool authorization logic;
  • Vulnerability: Fixed exposure of application IDs on the homepage ranking page, which could lead to unauthorized calls to other users' application nodes;
  • Vulnerability: Fixed the risk of cross-workspace privilege escalation when viewing and editing model parameter forms;
  • Vulnerability: Fixed prompt injection vulnerability to mitigate the risk of agent command execution;
  • Vulnerability: Improved internal IP validation for web document import and sync crawlers to remediate SSRF risks.

Bug Fixes

  • Agent: Fixed the issue that newly added vision models for image understanding nodes in advanced agents were not displayed in the model list in real time (#6402);
  • Agent: Fixed incorrect prompt messages during conversations after deleting the LLM bound to basic agents;
  • Agent: Fixed failures when agents call shared models with the error "Model does not exist";
  • Knowledge Base: Fixed misclassification of segmented text as table content when there is no blank line between tables and subsequent content in Word files (#6396);
  • Knowledge Base: Fixed cross-document contamination of segment position data when dragging and reordering document segments (#6373);
  • Homepage: Fixed the issue where agents without user permissions could be searched by name on the ranking detail page;
  • Trigger: Fixed duplicated task display in task details of scheduled trigger lists;
  • Trigger: Fixed missing default value passing for user input parameters of advanced agents under trigger scenarios, resulting in empty parameter values (#6320);
  • Trigger: Fixed parameter passing errors when agent user inputs include toggle-type parameters in triggers;
  • User Management: Fixed the issue that the user listing API only returns the first 200 users and cannot fetch all user records (#6375).
