MaxKB v2.9.1

Highlights

  • Two high-severity CVEs patched — treat as a mandatory upgrade — CVE-2026-45413 fixed plaintext password transmission through the reset_password interface, and CVE-2026-45412 closed an authenticated SSRF vector caused by missing callback-URL validation during workflow template import/update. If you expose MaxKB beyond a trusted intranet or let non-admin users import templates, upgrade immediately; until then, audit who holds template import/update permissions, since the SSRF path requires an authenticated caller.

  • Infinite-loop agents no longer break chat or the non-streaming API — Two linked fixes: exceeding the max loop count no longer clears the reply and throws a spurious network error, and calling an agent containing infinite-loop nodes with stream=false no longer returns empty data plus a read timeout. This specifically unblocks API integrators using non-streaming mode with cyclic agent graphs — that code path was effectively unusable before.

  • Gemini image and video nodes corrected — Gemini image generation failed whenever parameters were supplied to the model (#5233); the Image Understanding node had incorrect text descriptions, and the Image-to-Video node's end-frame image is now optional. If you maintain multimodal pipelines, re-test parameterized Gemini image calls and expect to be able to simplify Image-to-Video inputs.

  • Template imports and dependency tracking repaired — Creating agents imported from the Template Center no longer fails (#5231), and agents that use reranking models for multi-way recall now appear in those models' dependent-resource lists (#5249). The dependency-list fix matters operationally: those agents were previously invisible there and could be orphaned or deleted without warning during cleanup.

  • Knowledge-base scoping bug could query unintended sources — In knowledge-base retrieval nodes, unchecking associated KBs and saving with a different KB selected still left the unchecked KBs attached. Retrieval could therefore keep searching knowledge bases you believed you had removed — a correctness and potential data-exposure risk worth verifying on existing RAG flows after upgrade.

  • Search and member management work at scale — Workspace member addition can now find users who weren't rendered in the picker on large user bases, and resources can be searched by creator in both Resource Management and Shared Resources. Largely an admin/UX fix, but it removes real friction for large-tenant deployments.

No breaking changes are noted in this release.

Security Vulnerability Fixes

  • Security Vulnerability: Fixed a high‑risk vulnerability where passwords were transmitted in plaintext via the MaxKB reset_password interface (CVE‑2026‑45413).
  • Security Vulnerability: Fixed authenticated SSRF risks caused by missing validation of callback URLs during workflow template import/update (CVE‑2026‑45412).

Bug Fixes

  • Agent: Fixed the issue where reply messages were cleared and a network error appeared after the loop count exceeded the maximum limit in agents with infinite loops.
  • Agent: Fixed the issue where the API returned no data and reported a read‑timeout error under stream=false when calling an agent containing infinite‑loop nodes via API.
  • Agent: Fixed image generation failures after adding parameters for the Gemini image generation model (#5233).
  • Agent: Fixed incorrect text descriptions for the Image Understanding node, and set the end‑frame image of the Image‑to‑Video node as non‑required.
  • Agent: Fixed creation failures when importing agents from the Template Center (#5231).
  • Agent: Fixed the issue where unselected knowledge bases were still retained after unchecking associated knowledge bases and saving with another selected knowledge base in knowledge base retrieval nodes.
  • Agent: Fixed the issue where associated agents were not displayed in the dependent resource list of reranking models used for multi‑way recall (#5249).
  • Agent: Fixed the issue where a new tab was not opened when accessing the agent page by holding Ctrl and clicking the agent panel.
  • Tools: Fixed the issue that startup parameters of newly created tools required manual saving to use default values.
  • Workspace: Fixed the issue that users not displayed could not be searched when adding members with a large user base.
  • Resource Management: Fixed the inability to search resources by creator.
  • Shared Resources: Fixed the inability to search resources by creator.
