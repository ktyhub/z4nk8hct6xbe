✨ Primeiro plano de design do mundo: modelos acessíveis para todos

Subsídio mensal generoso. Explore e refine seus designs com DeepSeek V4.1 Flash, GLM-5.3 Flash e MiMo 2.6 Flash. Comece com o Go por $8 no primeiro mês ou escolha Plus ou superior por até $200 em créditos de bônus. Acesso API em todo o seu fluxo de trabalho. Todos os níveis de assinatura pessoal suportam chamadas API. Use sua chave OpenDesign API com Codex, Claude Code, DSH, OpenCode, Hermes e outros agentes de IA. Créditos gratuitos para novos usuários. Cada novo usuário recebe aproximadamente $0.50 em créditos gratuitos para experimentar o OpenDesign.

🐛 Corrigido

🧠 Agentes, tempos de execução e diagnósticos

  • Uma execução concluída de forma limpa permanece visivelmente concluída. Um bloqueio no nível da tarefa não transforma mais uma saída de agente limpa em um cartão enganoso de execução com falha; travamentos reais e saídas malsucedidas ainda permanecem falhas. (#8350) Obrigado @itscheems.
  • Os pacotes de suporte retêm as pistas importantes. Os diagnósticos agora trazem evidências de integridade do daemon para pressão de memória, crescimento de SQLite e saídas impuras, seja você exportando do aplicativo ou com od diagnostics export. (#8354) Obrigado @PerishCode.
  • Evidências de falha podem ser coletadas antes que a trilha esfrie. Com o consentimento existente ativado, as falhas detectadas no agente e na entrega são limitadas à fila e os diagnósticos são redigidos automaticamente; a desativação interrompe a coleta. (#8357) Obrigado @Siri-Ray.
  • OD As próximas execuções em sandbox são limpas depois de si mesmas. A raiz de acesso de entrada de execução permanece gravável para desmontagem da sandbox em vez de deixar uma execução presa na limpeza. (#8024) Obrigado @arqueon.
  • Falhas fatais do MCP dizem o que aconteceu. Um processo stdio do MCP agora grava seu erro fatal antes de sair, portanto, o client tem um diagnóstico utilizável em vez de um desaparecimento silencioso. (#7340) Obrigado @lorenzozanee.

🖥️ Área de trabalho e apresentação

  • A atualização do aplicativo de desktop não gera mais seu próprio desligamento. O tráfego do renderizador é interrompido antes que o tempo de execução do pacote seja desativado, tornando a transferência de reinicialização mais segura. (#8348) Obrigado @PerishCode.
  • O botão de saída de tela cheia pertence ao tema que você escolheu. Suas cores, estado de foco e foco do teclado agora permanecem legíveis em apresentações claras e escuras. (#7272) Obrigado @dennytosp.
  • Uma sessão do macOS MCP pode se tornar uma janela da área de trabalho. Abrir o aplicativo após o início do tempo de execução sem interface agora revela a janela normal sem perder a sessão local. (#8398) Obrigado @PerishCode.

🏠 Início e campanhas

  • O menu de tipo de tarefa permanece aberto quando você o solicita. Um click imediatamente após Home escolher um tipo não abre mais o seletor apenas para ele fechar. (#8386) Obrigado @Siri-Ray.
  • Uma campanha válida permanece presente mesmo com interrupções normais. Mudanças de rede, interrupções curtas e trocas de guias não removem mais desnecessariamente uma campanha ativa; o conteúdo armazenado em cache segue a programação conhecida do servidor enquanto estiver off-line. (#8292) Obrigado @alchemistklk.

open-design open-design-v0.24.1

✨ World’s First Design Plan: Affordable models for everyone

Generous monthly allowance. Explore and refine your designs with DeepSeek V4.1 Flash, GLM-5.3 Flash and MiMo 2.6 Flash. Get started with Go for $8 for your first month, or choose Plus or above for up to $200 in bonus credits.

API access across your workflow. All personal subscription tiers support API calls. Use your OpenDesign API key with Codex, Claude Code, DSH, OpenCode, Hermes and other AI agents.

Free credits for new users. Every new user receives approximately $0.50 in free credits to try OpenDesign.

🐛 Fixed

🧠 Agents, runtimes and diagnostics

  • A cleanly finished run stays visibly finished. A task-level block no longer turns a clean agent exit into a misleading failed-run card; real crashes and failed exits still remain failures. (#8350) Thanks @itscheems.
  • Support bundles retain the clues that matter. Diagnostics now carry daemon health evidence for memory pressure, SQLite growth and unclean exits, whether you export from the app or with od diagnostics export. (#8354) Thanks @PerishCode.
  • Failure evidence can be collected before the trail goes cold. With existing consent enabled, detected Agent and delivery failures queue bounded, redacted diagnostics automatically; opting out stops collection. (#8357) Thanks @Siri-Ray.
  • OD Next sandboxed runs clean up after themselves. The run input access root remains writable for sandbox teardown instead of leaving a run stranded on cleanup. (#8024) Thanks @arqueon.
  • Fatal MCP failures say what happened. An MCP stdio process now writes its fatal error before it exits, so the client has a usable diagnostic instead of a silent disappearance. (#7340) Thanks @lorenzozanee.

🖥️ Desktop and presentation

  • Updating the desktop app no longer races its own shutdown. Renderer traffic is stopped before the packaged runtime retires, making the restart handoff safer. (#8348) Thanks @PerishCode.
  • The fullscreen exit button belongs to the theme you chose. Its colors, hover state and keyboard focus now remain readable in both light and dark presentations. (#7272) Thanks @dennytosp.
  • A macOS MCP session can become a desktop window in place. Opening the app after its headless runtime started now reveals the normal window without losing the local session. (#8398) Thanks @PerishCode.

🏠 Home and campaigns

  • The task-type menu stays open when you ask for it. A click immediately after Home chooses a type no longer opens the picker only for it to snap shut. (#8386) Thanks @Siri-Ray.
  • A valid campaign remains present through ordinary interruptions. Network changes, short sleeps and tab switches no longer unnecessarily remove an active campaign; cached content follows its known server schedule while offline. (#8292) Thanks @alchemistklk.
