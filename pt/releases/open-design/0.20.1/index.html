🌟 Codinome: Plano Meet Go: acesso ilimitado a três modelos poderosos

🟢 28 PRs · 10 colaboradores · 2 dias — Crie sem se preocupar com limites de uso. Go Plan oferece acesso ilimitado ao DeepSeek V4, DeepSeek Pro e GLM 5.2 - para que você possa explorar, criar e iterar o quanto quiser.

🔥 Destaques

  • 🟢 Go está aqui — um plano que você pode realmente começar. O novo nível de entrada é enviado ponta a ponta: uma coluna Go na página de preços, um banner de lançamento na página inicial, e entradas de atualização no aplicativo que levam você diretamente para Preços, em vez de um diálogo sem saída. Planeje nomes, peça e copie agora leia o mesmo no aplicativo e em diante o site. (#7121, #7122, #7167)
  • 🔋 Um saldo zero não bloqueia mais os modelos pelos quais você paga. Se seu plano inclui uso ilimitado de um modelo, o selecionador continua oferecendo mesmo quando sua carteira indica 0 — o saldo e o direito são dois diferentes coisas, e apenas um deles deve bloquear a lista de modelos. (#7187)
  • 🖼️ Quando uma imagem não volta, você descobre o porquê. Falhas de geração usado para ser recolhido em uma mensagem genérica. Agora a verdadeira razão aparece - uma recusa de segurança, um erro do provedor, uma solicitação incorreta - para que você saiba se deve tente novamente, reformule a frase ou troque de modelo. (#7118)
  • 💬 A primeira coisa que você pede nas transmissões do Home até o fim. Começando uma corrida de casa poderia deixar a produção parcialmente congelada enquanto o trabalho continuava em segundo plano. A primeira execução agora permanece ativa desde o primeiro token até o último. (#7071)
  • ⏱️ "Quanto tempo demorou" finalmente significa o que diz. O tempo de execução é agora ancorado no momento em que o modelo realmente começa a responder, então enfileirar e startup não inflaciona mais o tempo de geração em seu histórico. (#7155)
  • 🧩 Transferência para OpenCode. Um novo plugin da comunidade entrega a parte atual do trabalhar no OpenCode, para que uma tarefa iniciada no Open Design possa continuar no agente que você preferir. (#6948) Obrigado @ross-sec.
  • 🏷️ Um nome, em todos os lugares: OpenDesign. O nome do produto, navegação e CTAs agora leia de forma consistente no aplicativo e no site, em vez de ficar vagando entre duas grafias. (# 6983, # 6998) Obrigado @ joeylee12629-star.
  • ⚡ Abrir sua lista de conversas evita trabalhos desnecessários. A lista não não materializa mais logs de eventos completos apenas para se desenhar, o que aparece diretamente como um painel mais rápido em projetos com longos históricos. (#6978) Obrigado @jiulongche.

🩹 Corrigido

  • A linha de atualização do painel Sobre mantém o espaçamento e o quadro do projeto não é mais pisca duas vezes quando um projeto é aberto. (#7174)
  • As falhas de implantação retornam códigos de erro específicos em vez de um 400 opaco, portanto, um falha na implantação diz o que deu errado. (#5897)
  • Remover uma habilidade a limpa do seletor de menções @ em vez de deixar um entrada obsoleta atrás. (#6920) Obrigado @T-sanjay-ram.
  • Reanexar a uma conversa em execução reúne eventos de repetição em vez de reproduzindo-os um por um. (#6926) Obrigado @roian6.
  • Os tempos de execução do agente são iniciados em máquinas Windows cujo PATHEXT está malformado. (#6937) Obrigado @github-lover-9999.
  • od media wait e od media generate liberam sua saída antes de sair, então o uso canalizado e com script não perde mais as últimas linhas. (#6800) Obrigado @lorenzozanee.
  • O upsell do artefato aparece apenas para modelos em nuvem, não para modelos que você já possui trouxe você mesmo. (#6995)
  • As folhas de estilo de fonte de visualização são carregadas sem bloquear a visualização em si. (#7134)
  • A versão de bootstrap do DeepSeek Harness é derivada dos bytes do instalador, portanto a versão relatada corresponde à que realmente foi instalada. (#7107)

🌐 Site

  • Uma vitrine de geração de imagens na landing page. (#6904)
  • Um guia GUI do DeepSeek Harness que responde diretamente à intenção de pesquisa, com o as etapas 2 a 5 são divididas. (#7073) Obrigado @joeylee12629-estrela.
  • As rotas detalhadas do plugin com curadoria do DeepSeek funcionam novamente. (#6976) Obrigado @ roian6.

🙏 Obrigado a todos que enviaram 0.20.1

open-design open-design-v0.20.1

🌟 Codename: Meet Go Plan: Unlimited Access to Three Powerful Models

🟢 28 PRs · 10 contributors · 2 days — Create without worrying about usage limits. Go Plan gives you unlimited access to DeepSeek V4, DeepSeek Pro, and GLM 5.2—so you can explore, create, and iterate as much as you want.

🔥 Highlights

  • 🟢 Go is here — a plan you can actually start on. The new entry tier ships end to end: a Go column on the pricing page, a launch banner on the homepage, and in-app upgrade entries that take you straight to Pricing instead of a dead-end dialog. Plan names, order and copy now read the same in the app and on the site. (#7121, #7122, #7167)

  • 🔋 A zero balance no longer locks you out of the models you pay for. If your plan includes unlimited use of a model, the picker keeps offering it even when your wallet reads 0 — the balance and the entitlement are two different things, and only one of them should gate the model list. (#7187)

  • 🖼️ When an image doesn't come back, you find out why. Generation failures used to collapse into one generic message. Now the real reason comes through — a safety refusal, a provider error, a bad prompt — so you know whether to retry, rephrase, or switch models. (#7118)

  • 💬 The first thing you ask for on Home streams all the way through. Starting a run from Home could leave the output frozen partway while the work continued in the background. The first run now stays live from the first token to the last. (#7071)

  • ⏱️ "How long did that take" finally means what it says. Run timing is now anchored to the moment the model actually starts responding, so queueing and startup no longer inflate generation time in your history. (#7155)

  • 🧩 Handoff to OpenCode. A new community plugin hands the current piece of work over to OpenCode, so a task started in Open Design can continue in the agent you prefer. (#6948) Thanks @ross-sec.

  • 🏷️ One name, everywhere: OpenDesign. The product name, navigation and CTAs now read consistently across the app and the site, instead of drifting between two spellings. (#6983, #6998) Thanks @joeylee12629-star.

  • ⚡ Opening your conversation list stops doing unnecessary work. The list no longer materializes full event logs just to draw itself, which shows up directly as a faster panel on projects with long histories. (#6978) Thanks @jiulongche.

🩹 Fixed

  • The About panel's update row keeps its spacing, and the project frame no longer flashes twice when a project opens. (#7174)
  • Deploy failures return specific error codes instead of one opaque 400, so a failed deploy says what went wrong. (#5897)
  • Removing a skill clears it from the @ mention picker instead of leaving a stale entry behind. (#6920) Thanks @T-sanjay-ram.
  • Reattaching to a running conversation coalesces replay events instead of replaying them one by one. (#6926) Thanks @roian6.
  • Agent runtimes start on Windows machines whose PATHEXT is malformed. (#6937) Thanks @github-lover-9999.
  • od media wait and od media generate flush their output before exiting, so piped and scripted usage no longer loses the last lines. (#6800) Thanks @lorenzozanee.
  • The artifact upsell only appears for Cloud models, not for models you already brought yourself. (#6995)
  • Preview font stylesheets load without blocking the preview itself. (#7134)
  • The DeepSeek Harness bootstrap version is derived from the installer bytes, so the reported version matches what actually installed. (#7107)

🌐 Website

  • An image generation showcase on the landing page. (#6904)
  • A DeepSeek Harness GUI guide that answers the search intent directly, with the steps 2–5 walkthrough split out. (#7073) Thanks @joeylee12629-star.
  • DeepSeek curated plugin detail routes work again. (#6976) Thanks @roian6.

🙏 Thanks to everyone who shipped 0.20.1
