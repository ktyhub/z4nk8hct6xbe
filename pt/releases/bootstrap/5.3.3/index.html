#inicialização v5.3.3

Destaques

  • Corrigida uma alteração significativa introduzida nos modos de cores onde era necessário importar manualmente variables-dark.scss ao construir Bootstrap com Sass. Agora, _variables.scss importará automaticamente _variables-dark.scss. Se você já estava importando _variables-dark.scss manualmente, continue fazendo isso, pois não quebrará nada e será o caminho a seguir na v6.
  • Corrigida uma regressão no mecanismo do seletor que não conseguia mais lidar com vários IDs.

Modos de cores

  • Os emblemas agora usam os utilitários de texto .text-bg-* para garantir que o texto esteja sempre legível (especialmente quando as cores personalizadas são diferentes nos modos claro e escuro).
  • Corrigido nosso script color-modes.js para lidar com o caso em que o sistema operacional está configurado para o modo claro e o modo de cor automática é usado no site. Se você copiou o script de nossos documentos, você deve aplicar esta alteração ao seu próprio script.
  • Corrigida a descrição dos esquemas de cores na documentação dos modos de cores para mostrar que color-scheme() aceita apenas valores light e dark como parâmetros.

Diversos

  • Permitido <dl>, <dt> e <dd> no sanitizante.
  • Distribuição uniforme de itens descartados para cabeçalhos modais e offcanvas.
  • Corrigidos os seletores CSS do acordeão para evitar problemas de herança ao aninhar acordeões.
  • Corrigida a sombra da caixa de foco para os controles de formulário indicados na validação.
  • Corrigido o anel de foco nos botões marcados em foco.
  • Corrigido o alternador da barra de navegação móvel do exemplo do produto.
  • Alterado o processamento RTL dos ícones de controle do carrossel.

bootstrap v5.3.3

Highlights

  • Fixed a breaking change introduced with color modes where it was required to manually import variables-dark.scss when building Bootstrap with Sass. Now, _variables.scss will automatically import _variables-dark.scss. If you were already importing _variables-dark.scss manually, you should keep doing it as it won't break anything and will be the way to go in v6.
  • Fixed a regression in the selector engine that wasn't able to handle multiple IDs anymore.

Color modes

  • Badges now use the .text-bg-* text utilities to be certain that the text is always readable (especially when the customized colors are different in light and dark modes).
  • Fixed our color-modes.js script to handle the case where the OS is set to light mode and the auto color mode is used on the website. If you copied the script from our docs, you should apply this change to your own script.
  • Fixed color schemes description in the color modes documentation to show that color-scheme() only accept light and dark values as parameters.

Miscellaneous

  • Allowed <dl>, <dt> and <dd> in the sanitizer.
  • Dropped evenly items distribution for modal and offcanvas headers.
  • Fixed the accordion CSS selectors to avoid inheritance issues when nesting accordions.
  • Fixed the focus box-shadow for the validation stated form controls.
  • Fixed the focus ring on focused checked buttons.
  • Fixed the product example mobile navbar toggler.
  • Changed the RTL processing of carousel control icons.
