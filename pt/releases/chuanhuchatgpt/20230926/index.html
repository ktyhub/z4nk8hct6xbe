ChuanhuChatGPT 20230926

Highlights

  • Local LLaMA through llama.cpp — Adds Llama-2-7B-Chat with streaming, automatic Q6_K GGUF download from TheBloke, custom .gguf discovery under models/<model>/, and LoRA loading from lora/. Install requirements_advanced.txt: llama-cpp-python replaces LMFlow, so existing LMFlow deployments must migrate to GGUF weights.
  • Automatic chat titles now consume tokens by default — The default chat_name_method_index changes from 0 to 2, triggering an extra non-streaming completion at temperature 0.0 after the first exchange. Explicit existing configuration values remain unchanged; select 0 (date/time) or 1 (first question) to avoid the added latency and token spend.
  • Agent tools are easier to verify — Switching to Chuanhu Agent Pro now lists enabled tools and gates SerpAPI, Google CSE, and Wolfram Alpha on their respective environment variables, with warnings for missing credentials. The missing google-search-results dependency is also added, enabling those integrations after a dependency refresh.
  • Retry and startup reliability — Retry now handles single-message histories, strips <div class="user-message"> wrappers from fallback input, and keeps token accounting synchronized with history rollback. First-launch and reset paths are hardened, while PR #882 removes the U+A789 colon from generated history timestamps to prevent local encoding failures.
  • Maintainer-facing packaging changes — Model clients are split from modules/models/models.py into dedicated modules, including Azure/PaLM module renames and the XMChat class rename; custom integrations must update import paths. PR #899 raises the duckduckgo-search floor to >=3.8, and PR #896 adds the vi_VN locale, so rebuild environments or images rather than reusing cached dependencies.
  • Compatibility — No user-facing breaking changes are documented.
