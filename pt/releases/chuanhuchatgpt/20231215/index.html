ChuanhuChatGPT 20231215

Highlights

  • Breaking configuration changes — API keys have moved to the right sidebar, with an option to hide them, and first-run setup is now wizard-driven. Update onboarding docs, screenshots, and UI automation that target the old configuration flow.
  • Expanded model catalog and explicit allowlists — Adds support for three major 文心一言 models, DALL·E 3, and ChatGLM3. Use the new available_models setting to define the models exposed to users rather than relying on the full default catalog.
  • Manual upgrades require dependency reinstall — After updating, run pip install -r requirements.txt. The assistant now targets the latest OpenAI and LangChain APIs; validate custom integrations against those versions before deploying.
  • More reproducible conversation history — More conversation parameters are persisted, and frontend sliders and checkboxes now synchronize with saved history. Rename/delete operations no longer leave orphaned Markdown files, while fixes to history repair reduce recovery failures.
  • Earlier validation and tighter upload security — OpenAI requests now detect empty API keys before making calls, and file uploads are subject to type restrictions and broader security hardening. Audit automation and workflows that previously accepted arbitrary file types.
  • Runtime and rendering fixes — Startup is faster, online search is restored, and new-user chat failures are fixed. Fine-tuned GPT model usage and dependent API changes are addressed; raw messages now use monospace text, and LaTeX is no longer incorrectly rendered in raw output.
