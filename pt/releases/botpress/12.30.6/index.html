botpress v12.30.6

Highlights

  • Flexible web-chat layouts — Choices can now render below the message instead of inline (#12224), giving developers more layout control for long prompts and option lists. This is an additive UI capability, so existing flows do not need changes.

  • Web-chat branding controls — The web channel gains branding support (#12279), helping developers deliver a more customized chat experience. Adoption impact is presentation-only; the changelog does not specify new configuration fields or defaults.

  • Explicit message scroll behavior — Messages can now force a scroll-down (#12247), useful when a bot needs to direct attention to newly streamed or delayed content. Use this deliberately: forced scrolling can override a user’s reading position.

  • More reliable choice rendering — The web channel now handles a null choice without throwing (#12228), preventing malformed or incomplete payloads from breaking the UI. This complements the new layout options, but does not replace server-side validation of choice data.

  • HITL tag-update consistency — Tag updates now expire the relevant cache (#12341), reducing the chance that agents see stale tags after a change. Teams relying on immediate HITL metadata updates should see more consistent behavior without a migration step.

  • QnA transition traceability and localization fixes — QnA transitions preserve source details (#12216, closing #11748), improving debugging of transition provenance. Studio also restores the skill bar on non-default languages (Studio #407) and adds multilingual transition captions (#12240 / Studio #405), improving cross-language authoring. Review localized skill transitions and captions to confirm they display as intended.

No breaking changes or required migration steps are listed.
