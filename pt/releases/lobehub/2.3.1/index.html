🚀 LobeHub Lançamento v2.3.1

Promova o snapshot canary completo e atual para main para uma versão estável normal, substituindo a proposta de hotfix fechada e não mesclada #22186. Este não é um hotfix de duas confirmações.

  • Estável Anterior: v2.3.0.
  • Instantâneo canário: 1a6ba7ad3853f140cc5795c5baf5ae37f78c9a13.
  • Escopo: 87 commits/PRs upstream, incluindo #22122 (aprovação automática) e #22069 (correção de token de publicação de lançamento).
  • O branch de lançamento começa diretamente a partir desse instantâneo do Canary, além do aumento da versão de propriedade do bot e do reparo do pacote Linux em #22190. Nenhuma seleção de hotfix ou recursos adicionais do aplicativo são colocados na parte superior.

Destaques

  • Aprovações e confiabilidade do agente: mude para aprovação automática diretamente do cartão de aprovação; evite envios duplicados de aprovação, execução duplicada de ferramentas na retomada e continuações de intervenção travadas. (#22122, #22058, #22060, #22068)
  • Tarefas e Linear: ações de seleção múltipla e lote de lista grande, filtros de estilo linear, ações de criação de grupos de tarefas, atividade paginada, sincronização de comentários lineares, importações de problemas concluídos e confiabilidade de sincronização em segundo plano. (#22055, #22083, #22136, #22155, #22087, #22086, #22050)
  • Páginas, documentos e arquivos: edição de título/corpo como um documento, correções de reescrita de agente de página, favoritos de documentos, downloads de unidades e ZIPs de pastas e pastas grandes mais suaves. (#22154, #22141, #22147, #22095, #22106)
  • Projetos, canais e bots: avatares do projeto e seleção do agente principal, confirmação de exclusão do projeto, escolha de membros do canal, correções de restauração/eliminação, registros de ativação paginados e retrospectivas noturnas de bots. (#22091, #22101, #22161, #22163, #22081, #22098)
  • Pesquisa, painéis e modelos: Pesquisa/rastreamento do DeepSeek, cartões de widget HTML em sandbox, correções de saída estruturada, correções de contabilidade de uso/custo e metadados de cartão de modelo oficial. (#21298, #22123, #21385, #22071, #22079, #22124)
  • Desktop e CLI: Copiar imagem, listas de atalhos da área de trabalho, empacotamento mais rápido da área de trabalho, melhorias de reinicialização/atualização do conector e CLI v0.0.74. (#22067, #22113, #22121, #22165, #22166, #22179)
  • Lançamentos e infraestrutura: integração de planos de novo nível e suporte percentual de lançamento; o layout alternativo do trilho permanece atrás do im_layout. A publicação de lançamento usa explicitamente o token do aplicativo para que os fluxos de trabalho de publicação downstream possam ser iniciados. (#22115, #22143, #22003, #22069)

Reparo de embalagens Linux (#22190)

A primeira compilação de desktop Linux falhou porque o modelo Snap target do construtor de elétrons 26.16.1 excluiu chrome-sandbox do diretório linux-unpacked compartilhado enquanto AppImage o estava lendo. As janelas passaram; os trabalhos do macOS foram cancelados por falha rápida da matriz.

  • Atualizado o electron-builder para 26.18.0 e atualizado o lockfile de desktop isolado, incluindo a correção upstream electron-userland/electron-builder#10333.
  • Adicionada uma regressão de integração contra o empacotador instalado e arquivos temporários reais: falha com ENOENT em 26.16.1, passa em 26.18.0. A execução de downloads/compressores é fragmentada; teste real, filtragem e mutações do sistema de arquivos são exercidas. O auxiliar permanece intacto para outros alvos, mas é excluído das entradas do Snap.
  • Lint de arquivo alterado, testes de regressão e empacotamento integrado (2 aprovados), instalação de arquivo de bloqueio congelado e git diff --check aprovado.
  • O reparo foi mesclado através do #22190 porque as filiais release/* exigem PRs; nenhuma proteção de ramificação foi ignorada.
  • Nenhuma nova aceitação da UI é necessária para este reparo somente da ferramenta de construção. O pacote multiplataforma completo está sendo verificado novamente pela nova execução do PR CI; os testes locais não reivindicam uma construção ou inicialização real do instalador.

🚀 LobeHub Release v2.3.1

Promote the complete current canary snapshot to main for a normal Stable release, replacing the closed, unmerged hotfix proposal #22186. This is not a two-commit hotfix.

  • Previous Stable: v2.3.0.
  • Canary snapshot: 1a6ba7ad3853f140cc5795c5baf5ae37f78c9a13.
  • Scope: 87 upstream commits/PRs, including both #22122 (auto approve) and #22069 (release publication token fix).
  • The release branch starts directly from that Canary snapshot, plus the bot-owned version bump and the Linux packaging repair in #22190. No hotfix cherry-picks or additional application features are layered on top.

Highlights

  • Approvals and agent reliability: switch to auto approve directly from the approval card; prevent duplicate approval submissions, duplicate tool execution on resume, and stuck intervention continuations. (#22122, #22058, #22060, #22068)
  • Tasks and Linear: large-list multi-select and batch actions, Linear-style filters, task-group create actions, paged activity, Linear comment sync, completed-issue imports, and background sync reliability. (#22055, #22083, #22136, #22155, #22087, #22086, #22050)
  • Pages, documents and files: title/body editing as one document, page-agent rewrite fixes, document favorites, drive downloads and folder ZIPs, and smoother large folders. (#22154, #22141, #22147, #22095, #22106)
  • Projects, channels and bots: project avatars and main-agent selection, project deletion confirmation, channel member picking, restore/purge fixes, paged wake records, and nightly bot retrospectives. (#22091, #22101, #22161, #22163, #22081, #22098)
  • Search, dashboards and models: DeepSeek search/crawling, sandboxed HTML widget cards, structured-output fixes, usage/cost accounting fixes, and official model-card metadata. (#21298, #22123, #21385, #22071, #22079, #22124)
  • Desktop and CLI: Copy Image, desktop shortcut listings, faster desktop packaging, connector restart/update improvements, and CLI v0.0.74. (#22067, #22113, #22121, #22165, #22166, #22179)
  • Rollouts and infrastructure: new-tier plan integration and percentage rollout support; the alternate rail layout remains behind im_layout. Release publication explicitly uses the App token so downstream publishing workflows can start. (#22115, #22143, #22003, #22069)

Upgrade and release sources

  • This release includes database migration 0199_topic_analyses.sql, adding the topic-analysis table, foreign keys and indexes. Self-hosted operators should include the normal database backup/migration procedure when upgrading.
  • Use the ordinary release initialization flow: resolve and pin the Cloud revision for this new release. Do not inherit the v2.3.0 hotfix Cloud pin.
  • Keep the exact title 🚀 release: v2.3.1 so the version bot and tag workflow agree on the intended version.

Linux packaging repair (#22190)

The first Linux desktop build failed because electron-builder 26.16.1's template Snap target deleted chrome-sandbox from the shared linux-unpacked directory while AppImage was reading it. Windows passed; the macOS jobs were cancelled by matrix fail-fast.

  • Upgraded electron-builder to 26.18.0 and updated the isolated desktop lockfile, including the upstream fix electron-userland/electron-builder#10333.
  • Added an integration regression against the installed packager and real temporary files: fails with ENOENT on 26.16.1, passes on 26.18.0. Downloads/compressor execution are stubbed; real staging, filtering and filesystem mutations are exercised. The helper stays intact for other targets but is excluded from Snap inputs.
  • Changed-file lint, the regression and builtin-core packaging tests (2 passed), frozen-lockfile installation and git diff --check passed.
  • The repair was merged through #22190 because release/* branches require PRs; no branch protection was bypassed.
  • No new UI acceptance is needed for this build-tool-only repair. Full multi-platform packaging is being rechecked by the new PR CI run; the local tests do not claim a real installer build or launch.
