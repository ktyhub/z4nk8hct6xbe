🚀 Lançamento do LobeHub (20261018)

Data de lançamento: 18 de outubro de 2026
Desde v2.2.19: 419 PRs mesclados · 14 colaboradores

Os agentes agora chegam mais longe em seus dispositivos e o aplicativo abre mais rapidamente. Tópicos, documentos e dados do dispositivo são carregados primeiro a partir de cópias locais, e as execuções do servidor podem usar modelos que existem apenas no seu dispositivo.

✨ Destaques

  • Metas com implementação em lote — Uma meta permanece como rascunho até você iniciá-la, e uma meta pode implementar uma tarefa repetida em lotes. Cada lote para em um portão de decisão para o proprietário revisar. (#20840, #20704, #20917, #20833)
  • Widgets e painéis — Painéis iniciais e de projetos, uma ferramenta de widget para agentes, visualizações de bate-papo e novos comandos lh widget / lh dashboard. (#20421, #20771)
  • Retransmissão LLM para seu dispositivo — execuções no lado do servidor, tarefas predefinidas, listas de modelos e downloads do Ollama agora podem usar modelos que estão disponíveis apenas na guia do navegador ou no aplicativo de desktop. (#20453, #20454, #20455, #20456, #20457)
  • Terminais remotos e manutenção de dispositivos — Abra shells interativos em dispositivos conectados a partir da web e atualize ou reinicie daemons CLI nas configurações do dispositivo. (#20600, #20527, #20528)
  • Carregamento local primeiro — Tópicos, documentos do agente, dispositivos, status do git e dados recentes da casa são carregados primeiro das réplicas locais, para que as páginas mostrem o conteúdo antes que a rede responda. (#20449, #20869, #20838, #20841, #20851)
  • Pastas de documentos do agente — Pastas, movimentações em lote, documentos como pais e classificação por nome, hora de criação ou modificação. (#20761, #20926)
  • Memória dos seus materiais — A memória pode extrair regras de textos colados, arquivos, documentos e conversas. (#20266)
  • Fork de uma resposta — Inicie um novo tópico a partir de qualquer mensagem do assistente. (#20610)

🏗️ Agente Principal e Arquitetura

  • Os subagentes passam pelo executor pai e os controles afterToolCall podem controlar os resultados da ferramenta. (#20446, #20297)
  • Habilidades selecionadas no compositor ou CLI são injetadas nas execuções do servidor. Adicionar um agente instala as habilidades do Market às quais ele faz referência. (#20961, #21059)
  • As mensagens entre agentes agora mostram qual agente as enviou. (#20548)
  • Menos pesquisas repetidas de dispositivos e de mercado em cada envio, e os envios de projetos aparecem imediatamente. (#20465, #20897, #20628)

📱 Plataformas/Integrações

  • Agentes heterogêneos: Adaptador DeepSeek Harness. O servidor de aplicativos Codex pode ser executado em dispositivos conectados (atrás do Labs). As mensagens do usuário do Codex podem ser editadas e reenviadas. Codex e Pi podem usar qualquer modelo LobeHub compatível com ferramentas. Droid e OpenCode suportam modelos padrão de servidor. (#18333, #20820, #20467, #20612, #20965, #20963)
  • Desktop: Aplicativo de uso de computador incluído no macOS, permissões de privacidade guiadas do macOS, menu Dock com tópicos em execução, arrastar guias com fixar/desafixar e troca instantânea de tópicos. (#20780, #20932, #20635, #20650, #21001)
  • Modelos: Claude Haiku 5.5, fal H3 Max e vídeo Seedance 2.5. (#20517, #20210)
  • OpenAPI: Canal de IM assíncrono e recursos REST de token push. (#20440)

🖥️ CLI e experiência do usuário

  • Tarefas: arquivar, criar tarefas a partir de colunas Kanban e criar ou pesquisar tarefas no menu de comando. (#20990, #21020, #21000, #21002)
  • Os tópicos da barra lateral podem ser agrupados por dispositivo, horário, status ou agente dentro de um projeto. (#20811, #20592, #20715)
  • Os projetos podem ter logotipo, e a lixeira pode ser filtrada por projeto. (#20641, #20739)
  • lh connect --auv oferece uso de computador e lh connect service install aceita --workspace. (#20983, #20818)
  • A pesquisa de configurações classifica melhor os resultados e lida com a entrada do IME. (#20620)

🔒 Segurança e Confiabilidade

  • Segurança: O Desktop pode exigir atualizações de segurança e verificações na primeira inicialização de versões Canary. As credenciais são coletadas através de um formulário seguro. nodemailer é atualizado para ^9.1.1. (#20168, #20469, #20338)
  • Confiabilidade: OAuth não passa mais pela validação de e-mail e as réplicas ignoram hidratos e erros que chegam atrasados. (#20545, #20754)

Commit Message

🚀 LobeHub Release (20261018)

Release Date: October 18, 2026
Since v2.2.19: 419 merged PRs · 14 contributors

Agents now reach further across your devices, and the app opens faster. Topics, documents and device data load from local copies first, and server runs can use models that only exist on your device.

✨ Highlights

  • Goals with batch rollout — A goal stays a draft until you start it, and a Goal can roll out one repeated task in batches. Each batch stops at a decision gate for the owner to review. (#20840, #20704, #20917, #20833)
  • Widgets & dashboards — Home and project dashboards, an agent widget tool, chat previews, and new lh widget / lh dashboard commands. (#20421, #20771)
  • LLM relay to your device — Server-side runs, preset tasks, model lists and Ollama downloads can now use models that are only available in your browser tab or desktop app. (#20453, #20454, #20455, #20456, #20457)
  • Remote terminals & device maintenance — Open interactive shells on connected devices from the web, and update or restart CLI daemons from device settings. (#20600, #20527, #20528)
  • Local-first loading — Topics, agent documents, devices, git status and home recents load from local replicas first, so pages show content before the network responds. (#20449, #20869, #20838, #20841, #20851)
  • Agent document folders — Folders, batch moves, documents as parents, and sorting by name, created or modified time. (#20761, #20926)
  • Memory from your materials — Memory can extract rules from pasted text, files, documents and conversations. (#20266)
  • Fork from a reply — Start a new topic from any assistant message. (#20610)

🏗️ Core Agent & Architecture

  • Sub-agents run through the parent's executor, and afterToolCall controls can gate tool results. (#20446, #20297)
  • Skills selected in the composer or CLI are injected on server runs. Adding an agent installs the Market skills it references. (#20961, #21059)
  • Agent-to-agent messages now show which agent sent them. (#20548)
  • Fewer repeated device and Market lookups on each send, and project sends appear right away. (#20465, #20897, #20628)

📱 Platforms / Integrations

  • Heterogeneous agents: DeepSeek Harness adapter. Codex app-server can run on connected devices (behind Labs). Codex user messages can be edited and resent. Codex and Pi can use any tool-capable LobeHub model. Droid and OpenCode support server-default models. (#18333, #20820, #20467, #20612, #20965, #20963)
  • Desktop: Bundled Computer Use app on macOS, guided macOS privacy permissions, Dock menu with running topics, tab drag with pin/unpin, and instant topic switching. (#20780, #20932, #20635, #20650, #21001)
  • Models: Claude Haiku 5.5, fal H3 Max and Seedance 2.5 video. (#20517, #20210)
  • OpenAPI: Async IM channel and push-token REST resources. (#20440)

🖥️ CLI & User Experience

  • Tasks: archiving, creating tasks from Kanban columns, and creating or searching tasks from the command menu. (#20990, #21020, #21000, #21002)
  • Sidebar topics can be grouped by device, time, status or agent within a project. (#20811, #20592, #20715)
  • Projects can have a logo, and the trash can be filtered by project. (#20641, #20739)
  • lh connect --auv offers Computer Use, and lh connect service install accepts --workspace. (#20983, #20818)
  • Settings search ranks results better and handles IME input. (#20620)

🔒 Security & Reliability

  • Security: Desktop can require security updates and checks the first launch of Canary builds. Credentials are collected through a secure form. nodemailer is updated to ^9.1.1. (#20168, #20469, #20338)
  • Reliability: OAuth no longer goes through email validation, and replicas ignore hydrates and errors that arrive late. (#20545, #20754)
