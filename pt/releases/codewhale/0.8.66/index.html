Codewhale v0.8.66

CodeWhale é o projeto canônico, comando, pacote npm e nome do ativo de liberação. O pacote npm legado deepseek-tui é obsoleto e não recebe mais lançamentos. Usuários vindos de Nomes legados v0.8.x deepseek / deepseek-tui devem migrar com docs/REBRAND.md.

Instalar

Recomendado — npm (um comando, ambos os binários)

npm install -g codewhale

O wrapper faz download dos binários de tempo de execução correspondentes desta versão e os coloca no mesmo diretório.

Docker/GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v ~/.deepseek:/home/codewhale/.deepseek \
  ghcr.io/hmbown/codewhale:v0.8.66

A imagem envia o despachante codewhale, o calço codew e o tempo de execução codewhale-tui. A tag latest também é atualizada no lançamento.

Carga (Linux / macOS)

cargo install codewhale-cli codewhale-tui --locked

Ambas as caixas são necessárias - codewhale-cli produz o despachante codewhale e o calço codew, enquanto codewhale-tui produz o tempo de execução interativo ao qual o despachante delega. A instalação de apenas uma caixa falhará em tempo de execução com um erro MISSING_COMPANION_BINARY.

Codewhale v0.8.66

Highlights

  • Rebrand and legacy-state migration — deepseek-tui and the deepseek binaries are deprecated in favor of codewhale/codew; legacy users must follow docs/REBRAND.md. The new codewhale doctor --json (#3727) audits ~/.deepseek vs ~/.codewhale dual-root state and flags unmigrated paths, while relocation now prints a visible migration notice (#3726) and backfills missing legacy sessions without overwriting newer data (#3724). Run doctor before deleting old directories — silent history loss was the risk this closes.
  • Install paths and the companion-binary trap — npm install -g codewhale drops both binaries in one step; Cargo users must install both codewhale-cli and codewhale-tui or hit MISSING_COMPANION_BINARY at runtime. The native codew shim now ships in archives, Windows installer inputs, and checksum manifests, so manual installs match Cargo. Verify with the sha256 manifests; note the Windows NSIS installer is unsigned (expect a SmartScreen prompt) and the portable zip skips the install script entirely.
  • New providers and real context budgets — Sakana AI Fugu joins as a first-class OpenAI-compatible provider (sakana/fugu aliases, FUGU_API_KEY/SAKANA_API_KEY, harvested from #3748), alongside OpenModel as an Anthropic Messages provider (#3585). New provider-level context_window overrides (#3545) let OpenAI-compatible gateways and self-hosted backends budget against their actual model window instead of a hardcoded default — relevant if you saw premature truncation or odd cache misses behind a gateway.
  • Approval and mode behavior shifts — Auto mode is deferred from the picker, cycle, hotbar, /mode, and thread overrides until it has a distinct prompt and auto-review; existing auto config now folds back to Agent (#3730, #3733). Approvals resolve through a single authority source (#3795) and render inline/bottom-anchored (#3799); workspace trust no longer auto-resolves ordinary tool approvals (#3736), leaving YOLO/auto-approve as the only bypass — and even YOLO now force-approves cargo publish, npm publish, and tag pushes (#3735). Plan mode enforces its "no writes" promise at the turn loop (#3734), read-only commands like git status --porcelain are no longer flagged as destructive (#3730), and the Agent shell defaults to approval-gated on (#3756). Watch for automation that relied on trust-based auto-approval — it will now prompt.
  • Fleet/WhaleFlow and UI defaults — WhaleFlow-to-Fleet launch validation caps plans at 100 agents and 5 recursive rings, requires bounded loops/expands before launch, and preserves per-slot model selection; Fleet is now framed as the durable sub-agent config layer and WhaleFlow as the orchestration plan. Hotbar gains Alt+1–Alt+8 quick slots (#3796, #3788) but is hidden until you opt in (#3807). Also new: a read-only /config ask-rules view (#3569) and a typed [verifier] table with verdict_policy = "hunt" (#2093).
  • Cost, telemetry, and sub-agent throughput — The scorecard command (#3388) enables offline release gating, baseline regression checks, and per-turn cost visibility; stream-JSON exec now reports input_analysis and visible_final_answer_chars (#2956, #2957) so harnesses can measure transcript growth and answer bloat, and /cache gains provider/model route columns (#3738). CODEWHALE_TOOL_SURFACE=shell-only now hides native tools from the model-visible catalog and warns on unknown values instead of silently falling back (#2954), while sub-agent fanout and lock hot paths were reworked for parallel dispatch and off-lock disk I/O (#3783, #3801–#3805).

No breaking changes in this release.

CodeWhale is the canonical project, command, npm package, and release-asset name. The legacy npm package deepseek-tui is deprecated and receives no further releases. Users coming from v0.8.x legacy deepseek / deepseek-tui names should migrate with docs/REBRAND.md.

Install

Recommended — npm (one command, both binaries)

npm install -g codewhale

The wrapper downloads the matched runtime binaries from this Release and places them in the same directory.

Docker / GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v ~/.deepseek:/home/codewhale/.deepseek \
  ghcr.io/hmbown/codewhale:v0.8.66

The image ships the codewhale dispatcher, codew shim, and codewhale-tui runtime. The latest tag is also updated on release.

Cargo (Linux / macOS)

cargo install codewhale-cli codewhale-tui --locked

Both crates are required — codewhale-cli produces the codewhale dispatcher and codew shim, while codewhale-tui produces the interactive runtime that the dispatcher delegates to. Installing only one crate will fail at runtime with a MISSING_COMPANION_BINARY error.

Changed

  • Clarified the Fleet setup surface and docs so Fleet is treated as the durable sub-agent configuration layer while WhaleFlow is the agent-authored orchestration plan that selects and monitors Fleet slots.
  • Slimmed the default Constitution prompt while keeping its required structural anchors under regression coverage, reducing the static prompt footprint for cache-sensitive turns (#2953).
  • Made the approval prompt inline and bottom-anchored instead of a full-screen takeover, so context and controls stay visible while a tool awaits a decision (#3799).
  • The Hotbar is now hidden by default until explicit setup opt-in (#3807); the interactive Agent shell also defaults to approval-gated on with a shared baseline (#3756).
  • Mode authority now resolves approval prompts through a single authority source instead of per-surface checks (#3795).

Fixed

  • Surfaced legacy state relocation with a user-visible migration notice whenever ~/.deepseek/<state> is moved or copied into ~/.codewhale/<state>, so upgraded users know their data was preserved and where the canonical state now lives (#3726).

  • Approval honesty: labeled session-scoped approvals accurately instead of "always", and surfaced approval decisions in tool results (#3766).
