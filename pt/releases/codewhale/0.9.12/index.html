Codewhale v0.9.12

Codewhale é o produto público da Shannon Labs. O codewhale os nomes de comando, pacote npm e release-asset permanecem técnicos em letras minúsculas identificadores. O pacote npm legado deepseek-tui está obsoleto e não recebe mais lançamentos. Usuários provenientes do legado v0.8.x deepseek / Os nomes deepseek-tui deverão migrar com docs/REBRAND.md.

Instalar

Recomendado – lançamento oficial do GitHub

Nova instalação do macOS/Linux (binários com soma de verificação desta versão):

curl -fsSL https://codewhale.net/install.sh | CODEWHALE_VERSION="v0.9.12" sh
"$HOME/.local/bin/codewhale" --version

Para Windows, use o instalador ou arquivo correspondente abaixo. Para um existente instalação direta, execute codewhale update; ele imprime o caminho do executável e mantém compilações mais recentes. Se o diretório de instalação estiver ocupado por uma compilação diferente, use a migração de diretório novo no guia de instalação.

Embalagem secundária — npm e Cargo

npm install -g codewhale
# or build from source
cargo install codewhale-cli --locked

O wrapper baixa os ativos de comando codewhale e codew correspondentes deste lançamento. Ambos contêm o mesmo tempo de execução compilado.

Docker/GHCR

docker run --rm -it \
  -e DEEPSEEK_API_KEY="$DEEPSEEK_API_KEY" \
  -v codewhale-home:/home/codewhale/.codewhale \
  ghcr.io/hmbown/codewhale:v0.9.12

A imagem expõe o mesmo tempo de execução que codewhale e codew. O A tag latest também é atualizada no lançamento.

Carga (Linux / macOS)

cargo install codewhale-cli --locked

O pacote Cargo instala o codewhale. Cargo não pode criar um segundo comando alias de um destino binário; usuários que desejam uma ortografia mais curta podem adicionar um Link simbólico codew para o executável instalado. O npm, Homebrew, arquivo, shell-installer e canais de contêiner instalam ambos os nomes de comando diretamente.

O que há em v0.9.12

Codewhale v0.9.12 coloca o uso do computador no binário, abre duas novas rotas - Alibaba Model Studio por meio da tabela de provedores baseada em dados e Concentrate como um gateway de respostas BYOK opcional - e adiciona envio na nuvem mais um soquete de controle por sessão controlado por configuração. A casca é a outra metade do lançamento: um novo cartão de lançamento, a superfície de trabalho encaixada sob o compositor, um proprietário de foco para Tab, células de ferramentas que carregam seu próprio estado e fleet como a palavra pública para o coletivo ao vivo. A mudança completa no nível do item o registro é mantido abaixo dos destaques de lançamento categorizados.

Adicionado

  • O uso do computador acompanha o binário. O plugin computer-use – 38 ferramentas em macOS, Windows, Linux e HarmonyOS, observação que prioriza a acessibilidade com substituto de pixel, capturas de tela, zoom, gravação de tela e registro computadores remotos via ssh e hdc - é incorporado no Codewhale e gravado em $CODEWHALE_HOME/builtin-plugins na primeira execução, então cada canal de instalação carrega isso. Ele é listado como builtin · not-reviewed e permanece desativado até você revisa e ativa: enviá-lo não é consentir. O O servidor de uso do computador stdlib-Python que ele substitui desapareceu.
  • Alibaba Model Studio junta-se à tabela de provedores baseados em dados como um Descritor openai-compatible: endpoint de modo compatível internacional, Credencial DASHSCOPE_API_KEY, descoberta /v1/models ao vivo. Qwen 3.8 Flash e Qwen 3.8 Max chegam através da autoridade do catálogo – nunca um ID codificado.
  • Concentrado: gateway de respostas BYOK opcional de primeira classe com modelos ao vivo descoberta e streaming SSE digitado (#5725).
  • Despacho na nuvem: o executor remoto descarrega tarefas do agente de codificação para tarefas isoladas sandboxes na nuvem com autenticação de token de máquina e rastreamento de trabalho estruturado (#5701, #5712).
  • Soquete de controle por sessão: vinculações de tabela [control_socket] controladas por configuração <sessions-dir>/<session-id>/control.sock por sessão de corrida, expondo mensagem, interrupção, reinicialização e verbos JSON-RPC de status (#5533, #5831).

Cada desativação registrada permanece desativada: um recurso durável telemetry = false, um decline registrado sob o antigo aviso de aceitação, estado de privacidade ilegível e o CODEWHALE_TELEMETRY=0 / --telemetria false interruptores de eliminação. Mostrando nos registros de divulgação apenas que foi mostrado, nunca uma aceitação. codewhale config set telemetry false gira desliga e limpa as contagens na fila; codewhale config set telemetry true deliberadamente o reativa. Nada de novo é coletado: nenhuma conversa, código, prompts, arquivos, nomes, conteúdo do modelo, credenciais ou IP.

Corrigido

  • A digitação rápida não corrompe mais o compositor. A heurística paste-burst foi executada em cada sessão até que uma pasta real entre colchetes chegasse, segurando, armazenando em buffer, retro-agarrando e absorvendo Enter em suposições de tempo; é agora somente fallback (desligado quando o terminal fornece colagem entre colchetes), o retro-grab é excluído e Enter no texto do comando retido libera e envia.

  • Ctrl+C funciona no menu de inicialização da pré-sessão e fala em todos os lugares: o primeira pressão arma a janela de saída de dois segundos com um sinal localizado visível Dica "Pressione Ctrl + C novamente para sair" (anteriormente silenciosa), a segunda sai. A entrada do nome da árvore de trabalho mantém Ctrl+C como entrada de cancelamento.

  • Novas sessões interativas não deixam mais uma mensagem fantasma duplicada atrás. A TUI reivindicou um ID de sessão (bloqueio de armazenamento de tempo de execução, falha de inicialização ponto de verificação) enquanto o motor cunhava um segundo; o primeiro SessionUpdated redigitou o aplicativo, o commit de conclusão apagou apenas o ID do mecanismo ponto de verificação, e codewhale --continue posteriormente "recuperou" o órfão ponto de verificação como uma sessão duplicada em vez da sessão real. O motor agora adota o ID de propriedade do host no spawn (EngineConfig::session_id) e /clear cunha o próximo ID no aplicativo, como /new. Um --continue não TTY não é mais promove e consome o ponto de verificação de travamento antes de falhar no terminal verifique e os sinalizadores raiz codewhale --resume <id> / --session-id <id> documentado no runbook de operações agora é analisado em vez de ser engolido como um aviso.

Codewhale v0.9.12

Codewhale is the public product from Shannon Labs. The codewhale command, npm package, and release-asset names remain lowercase technical identifiers. The legacy npm package deepseek-tui is deprecated and receives no further releases. Users coming from v0.8.x legacy deepseek / deepseek-tui names should migrate with docs/REBRAND.md.

Recommended — official GitHub release

curl -fsSL https://codewhale.net/install.sh | CODEWHALE_VERSION="v0.9.12" sh
"$HOME/.local/bin/codewhale" --version

npm install -g codewhale
