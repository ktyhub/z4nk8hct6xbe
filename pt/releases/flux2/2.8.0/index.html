#fluxo2 v2.8.0

Destaques

Flux v2.8.0 é um lançamento de recurso. Os usuários são incentivados a atualizar para obter a melhor experiência. Para uma visão geral compacta dos novos recursos e alterações do API incluídas nesta versão, consulte a [postagem do blog Anunciando o Flux 2.8 GA] (https://fluxcd.io/blog/2026/02/flux-v2.8.0/). Visão geral dos novos recursos:

  • Suporte ao Helm v4, incluindo aplicação no servidor e verificação de integridade baseada em kstatus (HelmRelease)
  • Avaliação de prontidão de objetos gerenciados pelo Helm com expressões CEL (HelmRelease)
  • Melhor observabilidade de lançamentos do Helm com rastreamento de inventário em .status.inventory (HelmRelease)
  • Redução do tempo médio de recuperação de aplicações gerenciadas por Flux via feature gate CancelHealthCheckOnNewRevision (Kustomization, HelmRelease)
  • Suporte para comentar em Pull Requests diretamente das notificações do Flux (Provider)
  • Estágios de aplicação de SSA personalizados para solicitar aplicação de recursos no controlador kustomize (Kustomization)
  • Pesquisa automática de ID de instalação do aplicativo GitHub do proprietário do repositório (GitRepository, ImageUpdateAutomation, Provider)
  • Suporte para Cosign v3 para verificação de artefatos OCI e imagens de contêiner (OCIRepository)
  • Suporte ArtifactGenerator para extrair e modificar gráficos Helm (ArtifactGenerator)
  • Ignorar cache ao buscar objetos de origem via porta de recursos DirectSourceFetch (Kustomization, HelmRelease, ArtifactGenerator) ❤️ Muito obrigado a todos os colaboradores do Flux que nos ajudaram com este lançamento!

Compatibilidade com Kubernetes

Esta versão é compatível com as seguintes versões Kubernetes: | Versão Kubernetes | Mínimo exigido | |--------------------|------------------| | v1.33 | >= 1.32.0 | | v1.34 | >= 1.34.1 | | v1.35 | >= 1.35.0 |

[!NOTA] Observe que o projeto Flux oferece suporte apenas para as três versões secundárias mais recentes do Kubernetes. A compatibilidade retroativa com versões mais antigas do Kubernetes e OpenShift é oferecida por fornecedores como ControlPlane que fornece suporte empresarial para Flux.

Compatibilidade com OpenShift

O Flux pode ser instalado no cluster Red Hat OpenShift diretamente do OperatorHub usando Flux Operator. A operadora permite a configuração de bloqueio de multilocação Flux, políticas de rede, armazenamento persistente, sharding, escalonamento vertical e sincronização do estado do cluster a partir de repositórios Git, artefatos OCI e armazenamento compatível com S3.

Procedimento de atualização

: aviso: Os Flux APIs v1beta2 e v2beta2 (obsoletos em 2024) atingiram o fim da vida útil e foram removidos dos CRDs. Siga o Procedimento de atualização do Flux v2.7+ para uma atualização tranquila de versões mais antigas do Flux para v2.8.

flux2 v2.8.0

Highlights

Flux v2.8.0 is a feature release. Users are encouraged to upgrade for the best experience.

For a compressive overview of new features and API changes included in this release, please refer to the Announcing Flux 2.8 GA blog post.

Overview of the new features:

  • Helm v4 support, including server-side apply and kstatus-based health checking (HelmRelease)
  • Readiness evaluation of Helm-managed objects with CEL expressions (HelmRelease)
  • Improved observability of Helm releases with inventory tracking in .status.inventory (HelmRelease)
  • Reduced the mean time to recovery of Flux-managed applications via CancelHealthCheckOnNewRevision feature gate (Kustomization, HelmRelease)
  • Support for commenting on Pull Requests directly from Flux notifications (Provider)
  • Custom SSA apply stages for ordering resource application in kustomize-controller (Kustomization)
  • Automatic GitHub App installation ID lookup from the repository owner (GitRepository, ImageUpdateAutomation, Provider)
  • Support for Cosign v3 for verifying OCI artifacts and container images (OCIRepository)
  • ArtifactGenerator support for extracting and modifying Helm charts (ArtifactGenerator)
  • Bypass cache when fetching source objects via DirectSourceFetch feature gate (Kustomization, HelmRelease, ArtifactGenerator)

❤️ Big thanks to all the Flux contributors that helped us with this release!

Kubernetes compatibility

This release is compatible with the following Kubernetes versions:

| Kubernetes version | Minimum required | |--------------------|------------------| | v1.33 | >= 1.32.0 | | v1.34 | >= 1.34.1 | | v1.35 | >= 1.35.0 |

[!NOTE] Note that the Flux project offers support only for the latest three minor versions of Kubernetes. Backwards compatibility with older versions of Kubernetes and OpenShift is offered by vendors such as ControlPlane that provide enterprise support for Flux.

OpenShift compatibility

Flux can be installed on Red Hat OpenShift cluster directly from OperatorHub using Flux Operator. The operator allows the configuration of Flux multi-tenancy lockdown, network policies, persistent storage, sharding, vertical scaling and the synchronization of the cluster state from Git repositories, OCI artifacts, and S3-compatible storage.

Upgrade procedure

:warning: The Flux APIs v1beta2 and v2beta2 (deprecated in 2024) have reached end-of-life and have been removed from the CRDs.

Please follow the Upgrade Procedure for Flux v2.7+ for a smooth upgrade from older versions of Flux to v2.8.
