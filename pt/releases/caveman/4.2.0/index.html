#homem das cavernas v4.2.0 Caveman 4.2.0 adiciona um gateway MCP QuickJS Code-Mode (caveman codemode / caveman wrap --codemode) com sobreposições de multiagentes, desembrulhamento de envelope de ferramenta de múltiplos chicotes no mecanismo de compactação, otimizações de proxy seguras em cache (gating de esforço de giro local, colapso de leitura duplicada, ordenação de ferramentas canônicas e defer_loading), @caveman-ai/middleware/codemode, suporte de modo de código opcional em @caveman-ai/pi 0.4.0 e um provedor nativo do Codex CLI para caveman-compress.

Novo

Gateway MCP de modo de código QuickJS (#1559)

  • caveman-mcp codemode e caveman codemode recolhem grandes catálogos upstream stdio e HTTP MCP em um conjunto estático e seguro de cache de prefixo de ferramentas de modo de código (codemode_search_tools, codemode_execute, codemode_mutate) apoiado por uma sandbox Pure-Go QuickJS incorporada (modernc.org/quickjs) além de repositório integrado e ajudantes de PR (batch_read, symbol_outline, pr_read, ci_logs).
  • caveman wrap --codemode instala sobreposições temporárias de modo de código por sessão para Claude Code, Codex, OpenCode, Gemini CLI, Qwen Code, Kilo, OpenClaw, Pi e Hermes (incluindo sincronização config.yaml de edições Hermes na sessão; as configurações do Cursor MCP são descobertas por caveman codemode).
  • A descoberta do MCP do espaço de trabalho é explícita: as definições do MCP local do espaço de trabalho são carregadas somente quando --trust-workspace-mcp ou CAVEMAN_TRUST_WORKSPACE_MCP=1 está configurado.
  • Recuperação exata e fidelidade sem texto: Saídas de execução em modo de código e ferramentas integradas armazenam originais em CCR antes da elisão; A decodificação upstream HTTP e stdio MCP preserva números inteiros acima de 2^53 e blocos de anexos não textuais (imagens, áudio, recursos), transmite respostas HTTP SSE de forma incremental e remove cabeçalhos de autenticação/personalizados em redirecionamentos de origem cruzada. Otimizações de proxy seguras em cache (#1559)
  • --turn-effort aplica bloqueio de esforço por turno seguro em cache em Anthropic (incluindo Opus 4.7/modelos de raciocínio adaptativo), OpenAI/Codex e Gemini sem quebrar caches de prefixo, reproduzindo marcas de esforço Codex/ChatGPT em turnos substanciais.
  • Recolhimento de leitura duplicada, ordenação canônica tools[] (--canonical-tools), adiamento da ferramenta MCP (--defer-mcp-tools) e redução do catálogo de ferramentas (--shrink-tools) mantêm os prefixos de prompt do provedor estáveis ​​em bytes enquanto cortam o contexto de entrada redundante. As solicitações de respostas OpenAI de streaming desabilitadas por MCP permanecem idênticas em bytes. Envelopes de motor com vários chicotes (#1559)
  • O mecanismo de compactação desembrulha os envelopes de resultados da ferramenta emitidos por Claude Code, Codex, OpenCode e Hermes para que o código, os resultados da pesquisa e os relatórios de teste sejam compactados de forma limpa entre os chicotes, preservando o diagnóstico de falhas de construção e configuração do Go na saída detalhada do go test. Middleware de estrutura e Pi (#1559)
  • @caveman-ai/middleware 1.2.0 adiciona @caveman-ai/middleware/codemode (createCodeModeToolset), um conjunto de ferramentas de modo de código em processo de dependência zero com descoberta BM25, pipelines estruturados e separação de leitura/gravação.
  • @caveman-ai/pi 0.4.0 adiciona ferramentas opcionais de modo de código (CAVEMAN_PI_CODEMODE=1) apoiadas por um CodemodeClient preguiçoso, honra CAVEMAN_MCP_PREFIX_ARGS e estende os tempos limite de RPC além dos prazos de script do chamador. compressa do homem das cavernas
  • Provedor Codex CLI nativo para caveman-compress, isolado de ferramentas locais (#1427 por @danez).

  • OpenCode: preserva espaços em branco no OPENCODE_CONFIG_DIR configurado (#1518).
  • CLI: remove comandos dev e deploy aws obsoletos que referenciavam alvos removidos.
  • Python SDK: restaura o orçamento de bytes TLS após a leitura do HTTP CONNECT (#1502).

caveman v4.2.0

Highlights

  • QuickJS Code-Mode MCP gateway — #1559 introduces caveman codemode / caveman wrap --codemode, collapsing sprawling stdio and HTTP MCP catalogs into three static, prefix-cache-safe tools (codemode_search_tools, codemode_execute, codemode_mutate) backed by an embedded pure-Go QuickJS sandbox plus built-in repo/PR helpers. This is the headline capability: large tool catalogs stop bloating every prompt, and the static toolset keeps prefix caches intact. Code-Mode is opt-in per harness, and config.yaml sync-back preserves in-session Hermes edits — a fidelity win, but scoped to Hermes only.

  • Cache-safe proxy optimizations — #1559 adds --turn-effort, --canonical-tools, --defer-mcp-tools, and --shrink-tools plus duplicate-read collapsing, all aimed at trimming redundant input while keeping provider prompt prefixes byte-stable so Anthropic, OpenAI/Codex, and Gemini caches are not invalidated. Worth adopting for cost/latency: MCP-disabled streaming OpenAI Responses requests remain byte-identical, so risk is contained — but expect reasoning-effort marks to now be replayed across substantive turns.

  • Multi-harness tool-envelope unwrapping — the compression engine now unwraps tool-result envelopes from Claude Code, Codex, OpenCode, and Hermes (#1559), so code, search results, and test reports compress cleanly regardless of harness. Combined with #1518's per-segment panic recovery (engine panics fail open while http.ErrAbortHandler is still re-raised) and preservation of Go build/setup diagnostics in verbose go test, this makes the engine materially more robust in mixed-tool CI.

  • Behavioral changes to plan for — workspace-local MCP definitions are now loaded only with --trust-workspace-mcp or CAVEMAN_TRUST_WORKSPACE_MCP=1; setups relying on implicit discovery will silently lose workspace tools until they opt in explicitly. The CLI also removes the stale dev and deploy aws commands, so any scripts invoking them will break. Toolchain moves to Go 1.26.11 (#1532).

  • Middleware and Pi integration — @caveman-ai/middleware 1.2.0 ships @caveman-ai/middleware/codemode (createCodeModeToolset), a zero-dependency in-process Code-Mode toolset with BM25 discovery, structured pipelines, and read/write separation (#1559). @caveman-ai/pi 0.4.0 adds opt-in Code-Mode tools behind CAVEMAN_PI_CODEMODE=1, honors CAVEMAN_MCP_PREFIX_ARGS, and extends RPC timeouts past caller script deadlines — relevant if you embed the middleware or build on Pi.

  • Data fidelity and compress provider — upstream HTTP/stdio MCP decoding now preserves integers above 2^53 and non-text attachment blocks (images, audio, resources), streams HTTP SSE incrementally, and strips auth/custom headers on cross-origin redirects, with Code-Mode outputs stored in CCR before elision for exact recovery. caveman-compress gains a native Codex CLI provider isolated from local tools (#1427, @danez), and the Python SDK restores its TLS byte budget after CONNECT reads (#1502).

Caveman 4.2.0 adds a QuickJS Code-Mode MCP gateway (caveman codemode / caveman wrap --codemode) with multi-agent overlays, multi-harness tool-envelope unwrapping in the compression engine, cache-safe proxy optimizations (local turn-effort gating, duplicate-read collapsing, canonical tool ordering, and defer_loading), @caveman-ai/middleware/codemode, opt-in Code-Mode support in @caveman-ai/pi 0.4.0, and a native Codex CLI provider for caveman-compress.

New

QuickJS Code-Mode MCP gateway (#1559)

  • caveman-mcp codemode and caveman codemode collapse large upstream stdio and HTTP MCP catalogs into a static, prefix-cache-safe set of Code-Mode tools (codemode_search_tools, codemode_execute, codemode_mutate) backed by an embedded pure-Go QuickJS sandbox (modernc.org/quickjs) plus built-in repo and PR helpers (batch_read, symbol_outline, pr_read, ci_logs).
  • caveman wrap --codemode installs temporary per-session Code-Mode overlays for Claude Code, Codex, OpenCode, Gemini CLI, Qwen Code, Kilo, OpenClaw, Pi, and Hermes (including config.yaml sync-back of in-session Hermes edits; Cursor MCP configs are discovered by caveman codemode).
  • Workspace MCP discovery is explicit: workspace-local MCP definitions are loaded only when --trust-workspace-mcp or CAVEMAN_TRUST_WORKSPACE_MCP=1 is set.
  • Exact recovery and non-text fidelity: Code-Mode execution outputs and built-in tools store originals in CCR before elision; upstream HTTP and stdio MCP decoding preserves integers above 2^53 and non-text attachment blocks (images, audio, resources), streams HTTP SSE replies incrementally, and strips auth/custom headers across cross-origin redirects.

Cache-safe proxy optimizations (#1559)

  • --turn-effort applies cache-safe per-turn effort gating across Anthropic (including Opus 4.7 / adaptive reasoning models), OpenAI/Codex, and Gemini without breaking prefix caches, replaying Codex/ChatGPT effort marks across substantive turns.
  • Duplicate-read collapsing, canonical tools[] ordering (--canonical-tools), MCP tool deferral (--defer-mcp-tools), and tool catalog shrinking (--shrink-tools) keep provider prompt prefixes byte-stable while trimming redundant input context. MCP-disabled streaming OpenAI Responses requests remain byte-identical.

Multi-harness engine envelopes (#1559)

  • The compression engine unwraps tool-result envelopes emitted by Claude Code, Codex, OpenCode, and Hermes so code, search results, and test reports compress cleanly across harnesses while preserving Go build and setup failure diagnostics in verbose go test output.

Framework middleware and Pi (#1559)

  • @caveman-ai/middleware 1.2.0 adds @caveman-ai/middleware/codemode (createCodeModeToolset), a zero-dependency in-process Code-Mode toolset with BM25 discovery, structured pipelines, and read/write separation.
  • @caveman-ai/pi 0.4.0 adds opt-in Code-Mode tools (CAVEMAN_PI_CODEMODE=1) backed by a lazy CodemodeClient, honors CAVEMAN_MCP_PREFIX_ARGS, and extends RPC timeouts past caller script deadlines.

caveman-compress

  • Native Codex CLI provider for caveman-compress, isolated from local tools (#1427 by @danez).

Fixed

  • Engine and proxy: guard unwrapFileWrapper against whitespace-only input; recover per segment so an engine panic fails open while still re-raising http.ErrAbortHandler (#1518).
  • OpenCode: preserve whitespace in configured OPENCODE_CONFIG_DIR (#1518).
  • CLI: remove stale dev and deploy aws commands that referenced removed targets.
  • Python SDK: restore the TLS byte budget after HTTP CONNECT reads (#1502).

Maintenance

  • Go toolchain bumped to Go 1.26.11 (#1532).
  • Documentation consolidated around AGENTS.md and docs/WHY.md, with public benchmark sample sizes stated alongside published figures.
  • Binaries: bin-v4.2.0. CLI: @caveman-ai/cli 4.2.0. Middleware: @caveman-ai/middleware 1.2.0. Pi: @caveman-ai/pi 0.4.0.
