#homem das cavernas v3.2.0 Caveman 3.2.0 traz a varredura de lançamento e subsequentes correções de instalação nativa para o instalador, plug-ins, habilidades e tempo de execução local.

Compactação e tempo de execução seguros para cache

  • Mantenha as decisões de compactação anteriores estáveis durante uma conversa, incluindo decisões de envio de bytes brutos. As verificações do prefixo de cache registram alterações causadas pelo homem das cavernas na telemetria de solicitação local e caveman status.
  • Passagem por respostas de limite de taxa com Retry-After; pin aceitou novas tentativas brutas em sua linhagem de conversa.
  • Construa o proxy e o mecanismo com suporte de tree-sitter para TypeScript, JavaScript, Python, Rust, Java, C e C++ na matriz binária de seis plataformas. O contêiner continua sendo uma construção pura do Go.
  • Roteie /v1/models simples por protocolo de solicitação, suporte CCR em sistemas de arquivos sem links físicos e compacte relatórios JUnit, pytest e Jest com suporte.
  • Roteie o tráfego ChatGPT OAuth do Pi por meio do proxy de assinatura, incluindo decodificação de solicitação zstd. A compactação do resultado da ferramenta requer um identificador recuperável.

Instalações, ganchos e habilidades nativas

  • As instalações Native Claude e Codex incluem as três habilidades de voz. Desativar o roteamento nativo mantém essas habilidades disponíveis e desativa todos os perfis Claude configurados.
  • Os subagentes herdam o modo de sua sessão. As sessões Headless claude -p e Agent SDK começam com a voz desligada.
  • Grave estatísticas de sessão em SessionEnd, com pesquisa de sessão no escopo do projeto.
  • Adicione ou estenda a integração sempre ativa para Codex, Cursor, Copilot CLI, Antigravity CLI e Grok Build; adicione a instalação do CodeBuddy Code.
  • Instale agentes cavecrew OpenCode como subagentes e avise quando um provedor ativo ignora o proxy.
  • Mova o instalador independente de bin/ para installer/ para compatibilidade com o mercado empresarial; melhorar o tratamento de correção de comandos do Windows e a detecção de agentes.
  • Refine as regras de voz para respostas diferenciadas, perguntas, comentários e relatórios de status sem gancho.

Compactação, avaliação e extensão

  • Adicione provedores autônomos compatíveis com OpenCode e OpenAI ao caveman-compress, seleção de modelo específico do provedor e regiões nocompress protegidas.
  • Registre o uso da avaliação, adicione um conjunto de fidelidade determinística, ofereça suporte a conjuntos de prompts específicos de idioma e retenha resultados parciais após execuções interrompidas. As medidas de estilo publicadas existentes permanecem rotuladas com suas regras e métodos originais. A extensão do navegador 1.3.0 melhora os instantâneos do editor avançado e a descoberta de controle de envio. A publicação da loja do navegador é separada desta versão GitHub.

Lançamentos complementares

  • extensão npm Pi: @caveman-ai/pi@0.3.0, incluindo a transição de licença Apache-2.0 e arquivos LICENSE/NOTICE da versão não publicada 0.2.0.
  • middleware npm TypeScript: @caveman-ai/middleware@1.0.1, suportando versões testadas do Anthropic SDK através do 0.131.0. Todas as quatro versões complementares são publicadas por meio dos fluxos de trabalho de tags assinadas do repositório. caveman v3.2.0

Highlights

  • Cache-stable compression decisions — Compression choices (including sending raw bytes) now stay fixed for the life of a conversation, and Retry-After responses are passed through instead of being swallowed. This matters because a decision that flips mid-stream invalidates cache prefixes; pinning raw retries to their conversation lineage also prevents one session's uncached bytes poisoning another's. caveman status and local telemetry now surface these cache-prefix changes, which is your main debugging lever when hit rates shift.

  • Tree-sitter enters the binaries, not the container — The proxy and engine ship tree-sitter grammars for TypeScript, JavaScript, Python, Rust, Java, C, and C++ across the six-platform binary matrix, enabling language-aware compression beyond plain text. Watch the deployment split: the container stays a pure-Go build, so identical input can compress differently in containers versus native binaries. If you rely on reproducible output across both, test against the artifact you actually deploy.

  • Protocol-aware routing and portable CCR — Bare /v1/models requests are now routed by request protocol, CCR works on filesystems without hard links, and JUnit/pytest/Jest reports are compressed. Pi's ChatGPT OAuth traffic moves through the subscription proxy with zstd request decoding. The portability fix unlocks CCR on NFS/Windows-style volumes; the catch is that tool-result compression now requires a recoverable handle, so tool outputs without one will no longer compress — worth checking if your agents lean heavily on tool results.

  • Native installs change voice and subagent defaults — Native Claude and Codex installs bundle the three voice skills, subagents inherit their parent session's mode, and session stats are written at SessionEnd with project-scoped lookup. Two behavior changes to plan around: headless claude -p and Agent SDK sessions start with voice off (automation won't inherit your interactive setup), and disabling native routing keeps the skills but disables every configured Claude profile — an easy footgun if you expected routing and profiles to be independent.

  • Installer relocation and broader integration surface — The standalone installer moves from bin/ to installer/ for enterprise marketplace compatibility, so any script pinning the old path needs updating. Alongside it: always-on integration for Codex, Cursor, Copilot CLI, Antigravity CLI, and Grok Build, new CodeBuddy Code support, OpenCode cavecrew agents installed as subagents, and a warning when an active provider bypasses the proxy (a useful signal that you're leaking uncompressed traffic). Companion artifacts are signed with npm provenance, and Pi 0.3.0 completes the Apache-2.0 transition — relevant if license compliance blocked your adoption.

  • No breaking changes are declared in this release.

Caveman 3.2.0 brings the release sweep and subsequent native-install fixes to the installer, plugins, skills, and local runtime.

Cache-safe compression and runtime

  • Keep previous compression decisions stable across a conversation, including decisions to send raw bytes. Cache-prefix checks record caveman-caused changes in local request telemetry and caveman status.
  • Pass through rate-limit responses with Retry-After; pin accepted raw retries to their conversation lineage.
  • Build the proxy and engine with tree-sitter support for TypeScript, JavaScript, Python, Rust, Java, C, and C++ in the six-platform binary matrix. The container remains a pure-Go build.
  • Route bare /v1/models by request protocol, support CCR on filesystems without hard links, and compress supported JUnit, pytest, and Jest reports.
  • Route Pi's ChatGPT OAuth traffic through the subscription proxy, including zstd request decoding. Tool-result compression requires a recoverable handle.

Native installs, hooks, and skills

  • Native Claude and Codex installs include the three voice skills. Disabling native routing keeps those skills available and disables every configured Claude profile.
  • Subagents inherit their session's mode. Headless claude -p and Agent SDK sessions start with the voice off.
  • Record session stats at SessionEnd, with project-scoped session lookup.
  • Add or extend always-on integration for Codex, Cursor, Copilot CLI, Antigravity CLI, and Grok Build; add CodeBuddy Code installation.
  • Install OpenCode cavecrew agents as subagents and warn when an active provider bypasses the proxy.
  • Move the standalone installer from bin/ to installer/ for enterprise marketplace compatibility; improve Windows command-shim handling and agent detection.
  • Refine voice rules for diff-first answers, questions, comments, and hookless status reporting.

Compression, evaluation, and extension

  • Add standalone OpenCode and OpenAI-compatible providers to caveman-compress, provider-specific model selection, and protected nocompress regions.
  • Record evaluation usage, add a deterministic fidelity suite, support language-specific prompt sets, and retain partial results after interrupted runs. Existing published style measurements remain labeled with their original rules and methods.
  • Browser extension 1.3.0 improves rich-editor snapshots and send-control discovery. Browser-store publication is separate from this GitHub release.

Companion releases

  • Signed binaries and container: bin-v2.1.0.
  • npm CLI: @caveman-ai/cli@2.1.0.
  • npm Pi extension: @caveman-ai/pi@0.3.0, including the Apache-2.0 license transition and LICENSE/NOTICE files from the unpublished 0.2.0 version.
  • npm TypeScript middleware: @caveman-ai/middleware@1.0.1, supporting tested Anthropic SDK versions through 0.131.0.

All four companion releases are published through the repository's signed-tag workflows. All 36 runtime binaries download anonymously; their checksum manifest and release identity are signed. The container signature is verified against the exact release workflow identity. npm packages carry GitHub Actions provenance. Platform integration tests, local cache checks, and release artifacts do not establish customer savings or production outcomes.

Published CLI smoke passed on macOS ARM, Linux x64 and Windows x64: clean npm installation, signed companion setup, wrapper endpoint injection in record mode, compression with byte-exact retrieval, and isolated npm uninstall preserving unrelated configuration.
