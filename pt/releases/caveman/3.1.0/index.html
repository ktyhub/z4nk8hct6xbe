#homem das cavernas v3.1.0 Três habilidades substituem seis níveis de intensidade, a pilha de correções revisada chega e a manutenção do repositório que se acumulou desde que 3.0.0 veio com ela. 106 commits em main.

A habilidade, repensada para os modelos atuais

/caveman é a voz. /ultracave elimina a gramática. /megacave fala chinês clássico. Cada um é um skills/<id>/SKILL.md independente no mesmo formato: tese, persistência, porquê, regras numeradas com pares ruins/bons, quando quebrar as regras, pré-envio de verificação. O Inglês Técnico Simplificado (ASD-STE100) é o piso sob todos os três, em vez de um registro concorrente. A proibição de silenciar a chamada de ferramenta torna-se uma linha de status por fase (#1127, #1154), e o equipamento do anfitrião supera a habilidade de quando falar (#1125). /caveman lite|full|ultra|wenyan* continua funcionando como apelido; sessões armazenadas migram na leitura. Ganchos: os IDs dos modos agora são caveman, ultracave, megacave (+ one-shots, off); mapa de valores legados em cada caminho de leitura; o gancho SessionStart injeta toda a habilidade ativa; o reforço por turno é derivado da linha de tese da habilidade; statusline renderiza [CAVEMAN], [ULTRACAVE], [MEGACAVE]; uma cópia desatualizada da linha de status fixada em um caminho de cache de plug-in agora aciona o empurrão de reparo. As cópias de regras sempre ativas (regras IDE, opencode AGENTS.md, OpenClaw, extensão, agentes cavecrew, stubs Codex/Gemini, espelho de plugin Codex) são regeneradas ou sincronizadas manualmente com um teste de desvio. Registro de projeto: docs/technical/three-skills-refactor.md. As avaliações foram executadas novamente em claude-opus-5-5 com configurações de host isoladas: versus um controle Answer concisely. simples, a redução média de saída é homem das cavernas 3%, ultracave 35%, megacave 9% (n = 10, execução única, comprimento apenas). README e HONEST-NUMBERS citam exatamente isso. Decisão do proprietário: a voz padrão acrescenta pouco além de "seja conciso" neste modelo; ultracave traz a economia.

caveman v3.1.0

Highlights

  • Three self-contained skills replace six intensity levels — /caveman provides the baseline voice, /ultracave strips grammar, and /megacave uses classical Chinese. All three share Simplified Technical English (ASD-STE100) as their floor, so this is a structural change to how behavior is packaged rather than another intensity setting.
  • Hook and interaction semantics change — Canonical mode IDs are now caveman, ultracave, and megacave, alongside one-shots and off. SessionStart injects the complete active skill, per-turn reinforcement derives from its thesis, and statusline labels now identify each mode (#1125, #1127, #1154). The host harness takes precedence over the skill’s speaking rules, while tool-call silence allows one status line per phase; stale plugin-cache statuslines trigger a repair nudge.
  • Compression gains are model-specific — Against an Answer concisely. control on claude-opus-5-5, median output reduction was 3% for /caveman, 35% for /ultracave, and 9% for /megacave. With only 10 cases, one run, and length as the sole metric, treat this as directional evidence: /ultracave is the meaningful compression option on that model, while the default voice adds little.
  • Reviewed reliability fixes land as one batch — #1163 includes proxy session-marker correlation and silent CCR failure fixes (#1105, #1110, #1149, #1113), engine JSON elision/non-finite cell/shrink-sentinel corrections (#1151, #1095), and compression streaming, ceiling, and pairing repairs (#1131, #1107). It also addresses dangling hooks, shrink-hook permissions, Codex TOML, opencode OAuth, Remote Control, and watermark locks—worth upgrading for if you depend on those paths, not just the prompt style.
  • Host integration improves, but Pi remains gated — Codex SessionStart now honors defaultMode (#185, #1139), Grok Build installation closes #547 (#1084), and regenerated always-on rule copies now have a drift test. Pi 1.0.0 recovery is intentionally absent: #1164 must wait for a published caveman-mcp binary.
  • Compatibility — No breaking changes: legacy hook mode IDs map on every read path, CLI aliases remain valid, and stored sessions migrate on read. Custom integrations should still check for the new statusline labels and canonical mode IDs.

Three skills replace six intensity levels, the reviewed fix stack lands, and the repo maintenance that piled up since 3.0.0 comes with it. 106 commits over main.

The skill, rethought for current models

/caveman is the voice. /ultracave strips the grammar. /megacave speaks classical Chinese. Each is a self-contained skills/<id>/SKILL.md in the same shape: thesis, persistence, why, numbered rules with bad/good pairs, when to break the rules, pre-send check. Simplified Technical English (ASD-STE100) is the floor under all three instead of a competing register. The tool-call silence ban becomes one status line per phase (#1127, #1154), and the host harness outranks the skill on when to speak (#1125). /caveman lite|full|ultra|wenyan* keep working as aliases; stored sessions migrate on read.

Hooks: mode ids are now caveman, ultracave, megacave (+ one-shots, off); legacy values map on every read path; the SessionStart hook injects the active skill whole; per-turn reinforcement is derived from the skill's thesis line; statusline renders [CAVEMAN], [ULTRACAVE], [MEGACAVE]; an outdated statusline copy pinned to a plugin-cache path now triggers the repair nudge. The always-on rule copies (IDE rules, opencode AGENTS.md, OpenClaw, extension, cavecrew agents, Codex/Gemini stubs, Codex plugin mirror) are regenerated or hand-synced with a drift test. Design record: docs/technical/three-skills-refactor.md.

Evals were rerun on claude-opus-5-5 with host settings isolated: vs a plain Answer concisely. control, median output reduction is caveman 3%, ultracave 35%, megacave 9% (n=10, single run, length only). README and HONEST-NUMBERS cite exactly that. Owner decision: the default voice adds little over "be concise" on this model; ultracave carries the savings.

Fix stack (PRs #1163 #1157 #1158 #1159 #1160 #1161 #1162, merged as one)

Proxy session-marker correlation and silent CCR failures (#1105 #1110 #1149 #1113); engine JSON elision, non-finite cells, shrink sentinel (#1151 #1095); CLI dangling hooks, shrink hook permissions, Codex TOML, Remote Control, opencode OAuth, watermark locks (#1137 #1138 #1133 #1134 #1101 #1119 #1116 #1132); statusline nudge path (#1147); Codex SessionStart honors defaultMode (#185 #1139); caveman-compress streaming/ceiling/pairing (#1131 #1107). #1164 (Pi recovery proof, Pi 1.0.0) is not here: it must wait for a caveman-mcp binary release.
