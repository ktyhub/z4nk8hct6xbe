Agente Hermes v0.2.0 (v2026.3.12)

Data de lançamento: 12 de março de 2026

Primeiro lançamento marcado desde v0.1.0 (a fundação pré-pública inicial). Em pouco mais de duas semanas, o Hermes Agent passou de um pequeno projeto interno para uma plataforma de agente de IA completa – graças a uma explosão de contribuições da comunidade. Esta versão abrange 216 pull requests mesclados de 63 colaboradores, resolvendo 119 problemas.

✨ Destaques

  • Gateway de mensagens multiplataforma — Plataformas Telegram, Discord, Slack, WhatsApp, Signal, Email (IMAP/SMTP) e Home Assistant com gerenciamento de sessão unificado, anexos de mídia e configuração de ferramentas por plataforma.
  • MCP (Model Context Protocol) Client — Suporte MCP nativo com transportes stdio e HTTP, reconexão, descoberta de recursos/prompt e amostragem (solicitações LLM iniciadas pelo servidor). (#291 — @0xbyt4, #301, #753)
  • Ecossistema de habilidades — mais de 70 habilidades agrupadas e opcionais em mais de 15 categorias com um Skills Hub para descoberta da comunidade, ativação/desativação por plataforma, ativação condicional com base na disponibilidade da ferramenta e validação de pré-requisitos. (#743 — @teyrebaz33, #785 — @teyrebaz33)
  • Roteador de provedor centralizado — call_llm()/async_call_llm() unificado API substitui a lógica de provedor dispersa em visão, resumo, compactação e economia de trajetória. Todos os consumidores auxiliares roteiam através de um único caminho de código com resolução automática de credenciais. (#1003)
  • Servidor ACP — Integração do editor VS Code, Zed e JetBrains por meio do padrão Agent Communication Protocol. (#949)
  • CLI Skin/Theme Engine — Personalização visual baseada em dados: banners, spinners, cores, branding. 7 skins integradas + skins YAML personalizadas.
  • Isolamento de árvore de trabalho Git — hermes -w lança sessões de agente isoladas em árvores de trabalho git para trabalho paralelo seguro no mesmo repositório. (#654)
  • Pontos de verificação e reversão do sistema de arquivos — Instantâneos automáticos antes de operações destrutivas com /rollback para restauração. (#824)
  • 3.289 testes — Desde cobertura de teste quase nula até um conjunto de testes abrangente que abrange agente, gateway, ferramentas, cron e CLI.

hermes-agent v2026.3.12

Hermes Agent v0.2.0 (v2026.3.12)

Release Date: March 12, 2026

First tagged release since v0.1.0 (the initial pre-public foundation). In just over two weeks, Hermes Agent went from a small internal project to a full-featured AI agent platform — thanks to an explosion of community contributions. This release covers 216 merged pull requests from 63 contributors, resolving 119 issues.

✨ Highlights

  • Multi-Platform Messaging Gateway — Telegram, Discord, Slack, WhatsApp, Signal, Email (IMAP/SMTP), and Home Assistant platforms with unified session management, media attachments, and per-platform tool configuration.

  • MCP (Model Context Protocol) Client — Native MCP support with stdio and HTTP transports, reconnection, resource/prompt discovery, and sampling (server-initiated LLM requests). (#291 — @0xbyt4, #301, #753)

  • Skills Ecosystem — 70+ bundled and optional skills across 15+ categories with a Skills Hub for community discovery, per-platform enable/disable, conditional activation based on tool availability, and prerequisite validation. (#743 — @teyrebaz33, #785 — @teyrebaz33)

  • Centralized Provider Router — Unified call_llm()/async_call_llm() API replaces scattered provider logic across vision, summarization, compression, and trajectory saving. All auxiliary consumers route through a single code path with automatic credential resolution. (#1003)

  • ACP Server — VS Code, Zed, and JetBrains editor integration via the Agent Communication Protocol standard. (#949)

  • CLI Skin/Theme Engine — Data-driven visual customization: banners, spinners, colors, branding. 7 built-in skins + custom YAML skins.

  • Git Worktree Isolation — hermes -w launches isolated agent sessions in git worktrees for safe parallel work on the same repo. (#654)

  • Filesystem Checkpoints & Rollback — Automatic snapshots before destructive operations with /rollback to restore. (#824)

  • 3,289 Tests — From near-zero test coverage to a comprehensive test suite covering agent, gateway, tools, cron, and CLI.
