Agente Hermes v0.12.0 (v2026.4.30)

Data de lançamento: 30 de abril de 2026 Desde v0.11.0: 1.096 commits · 550 PRs mesclados · 1.270 arquivos alterados · 217.776 inserções · 213 colaboradores da comunidade (incluindo coautores)

A versão Curador — Agente Hermes agora se mantém. Um curador autônomo de experiência avalia, elimina e consolida sua biblioteca de habilidades de acordo com seu próprio cronograma. O ciclo de autoaperfeiçoamento que analisa o que economizar recebeu uma atualização substancial. Quatro novos provedores de inferência, uma 18ª plataforma de mensagens, uma 19ª via plugin Teams, integrações nativas Spotify + Google Meet, ComfyUI e TouchDesigner-MCP passaram de opcional para pacote por padrão e um corte de aproximadamente 57% na inicialização a frio da TUI visível.

✨ Destaques

  • Curador Autônomo — hermes curator é executado como um agente de segundo plano no cron ticker do gateway (ciclo padrão de 7 dias). Ele avalia sua biblioteca de habilidades, consolida habilidades relacionadas, remove as mortas e grava relatórios por execução para logs/curator/run.json + REPORT.md. As habilidades arquivadas são classificadas consolidadas versus eliminadas por meio de modelo + heurística. Portões de defesa profunda protegem habilidades agrupadas/hub contra mutação. Unificado em auxiliary.curator — escolha o modelo do curador em hermes model e gerencie-o no painel. hermes curator status classifica as habilidades por uso (mais usadas/menos usadas). (#17277, #17307, #17941, #17868, #18033)

Restrito a conjuntos de ferramentas de memória + habilidades para que não possa se espalhar. Os provedores de memória são desligados de forma limpa. Release Date: April 30, 2026 Since v0.11.0: 1,096 commits · 550 merged PRs · 1,270 files changed · 217,776 insertions · 213 community contributors (including co-authors)

The Curator release — Hermes Agent now maintains itself. An autonomous background Curator grades, prunes, and consolidates your skill library on its own schedule. The self-improvement loop that reviews what to save got a substantial upgrade. Four new inference providers, a 18th messaging platform, a 19th via Teams plugin, native Spotify + Google Meet integrations, ComfyUI and TouchDesigner-MCP moved from optional to bundled-by-default, and a ~57% cut to visible TUI cold start.

✨ Highlights

  • Autonomous Curator — hermes curator runs as a background agent on the gateway's cron ticker (7-day cycle default). It grades your skill library, consolidates related skills, prunes dead ones, and writes per-run reports to logs/curator/run.json + REPORT.md. Archived skills are classified consolidated-vs-pruned via model + heuristic. Defense-in-depth gates protect bundled/hub skills from mutation. Unified under auxiliary.curator — pick the curator's model in hermes model, manage it from the dashboard. hermes curator status ranks skills by usage (most-used / least-used). (#17277, #17307, #17941, #17868, #18033)

  • Self-improvement loop — substantially upgraded — The background review fork (the core of Hermes' self-improvement: after each turn it decides what memories/skills to save or update) is now class-first (rubric-based rather than free-form), active-update biased (prefers the skill the agent just loaded), handles references//templates/ sub-files, and properly inherits the parent's live runtime (provider, model, credentials actually propagate). Restricted to memory + skills toolsets so it can't sprawl. Memory providers shut down cleanly. Prior-turn tool messages excluded from the summary so the fork sees a clean context. (#16026, #17213, #16099, #16569, #16204, #15057)
